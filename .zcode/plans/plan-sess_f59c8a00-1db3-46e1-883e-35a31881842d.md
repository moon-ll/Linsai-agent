# 界面精简方案 v2（v6.0）：仪表盘 + 双核心 + 三导航

## 核心理念

打开 Copilot → **仪表盘首页**（今日待处理一目了然）→ 三个导航切换到对应功能区。聊天常驻可见。

## 布局设计

```
┌──────────────────────────────────────────────────────────┐
│ 顶栏：林赛协作引擎  [模式] [provider]     📊 ⚙️          │
├──────┬───────────────────────────────────┬───────────────┤
│ 左栏  │                                   │               │
│ 会话  │       主内容区（按导航切换）        │  💬 聊天侧栏   │
│ 列表  │                                   │  （常驻）      │
│      │  [🏠仪表盘] [📚知识库] [🔧hermes]  │               │
│      │                                   │  消息列表      │
│      │                                   │               │
│      │                                   │  输入框        │
├──────┴───────────────────────────────────┴───────────────┤
│ 🏠仪表盘  │  📚知识库  │  🔧hermes工作台      │ ← 顶部导航   │
└──────────────────────────────────────────────────────────┘
```

## 三个导航页

### 🏠 仪表盘（首页，打开就看到）

你每天打开后第一眼看到的——**今日待处理项一目了然**：

```
┌─────────────────────────────────────────┐
│ 早上好。你有 5 件事待处理。              │ ← 林赛主动开场
│                                         │
│ 📄 文献简报 (12篇待处理)                 │
│   ┌─────┐┌─────┐┌─────┐               │
│   │论文1 ││论文2 ││论文3 │ → 点开讨论    │
│   └─────┘└─────┘└─────┘               │
│   [查看全部 →]                           │
│                                         │
│ 📋 任务 (3个进行中)                      │
│   • 调研MoS2圆偏振HHG（hermes执行中）     │
│   • 审稿回复PRL（我自己）                │
│   • [查看全部 →]                         │
│                                         │
│ 📌 NSFC决策 (2项待拍板)                  │
│   • T3 采用SBE还是TDDFT？  [✓][✗][💬]  │
│   • [查看全部 →]                         │
│                                         │
│ 📡 hermes 今日已完成                      │
│   • 检索入池 4次（45篇新论文）            │
│   • 简报推送 1次（5篇推送飞书）           │
└─────────────────────────────────────────┘
```

- 文献区：今日候选的前3篇卡片（快速预览），点"查看全部"进文献简报
- 任务区：进行中任务摘要，点"查看全部"进 hermes 工作台
- 决策区：待决策项，可直接通过/否决/讨论
- hermes 区：今日 cron 执行摘要

### 📚 知识库（现有中间主区，保留不变）

- 文件树 + 内容预览（现有功能，不动）
- 新增"文献简报"子分支（在文件树顶部，独立于 NSFC）
  - 文献简报有自己的入口（候选池卡片 + 讨论 + 归档）
  - NSFC 项目知识库有自己的入口（课题报告 + 决策 + 调研资料）

### 🔧 hermes 工作台（合并任务+控制台+追踪）

- Tab 1: 任务管理（统一看板，合并 task.js + projects任务tab）
- Tab 2: cron 定时任务（hermes控制台）
- Tab 3: 执行追踪（派活记录和输出）
- 底部：AI 辅助派活（只说目标，AI 生成指令）

## 实施步骤

### 步骤 1：创建仪表盘组件
- 新建 `web/js/dashboard.js`：仪表盘首页（4 区域：文献/任务/决策/hermes）
- 后端新增 `/api/dashboard`：聚合今日文献候选+任务+决策+hermes状态

### 步骤 2：导航系统
- index.html：底部导航条（🏠仪表盘 / 📚知识库 / 🔧hermes）+ 顶栏⚙️设置
- 删除 8 按钮工具栏 + 右侧栏
- 聊天侧栏保留常驻

### 步骤 3：功能迁移
- 文献简报：从 projects-overlay 拆出，仪表盘卡片 + "查看全部"展开
- 任务管理：task.js + projects任务tab → hermes工作台 Tab 1
- hermes控制台：hermes_console.js → hermes工作台 Tab 2
- 技能/学习/用量：→ 设置页
- NSFC：仪表盘决策卡片 + 知识库内浏览

### 步骤 4：CSS 布局
- 三栏：左会话栏 + 主内容区（导航切换）+ 右聊天侧栏
- 删除右侧栏，知识库预览更宽
- 仪表盘卡片样式

## 关键约束
- 聊天常驻不折叠（核心功能）
- 文献简报和 NSFC 项目独立分开（各自入口）
- 仪表盘是首页（打开第一眼看到待处理项）
- 现有知识库功能不动（只改导航入口）
- 前端零框架（原生 JS）
