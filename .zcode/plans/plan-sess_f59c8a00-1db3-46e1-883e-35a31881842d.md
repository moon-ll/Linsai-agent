## 二、核心结构规则

### 2.1 三层分层（不变，但职责重新界定）

```
knowledge/
├── raw/                    # 第一层：原始材料（只增不改）
│   ├── papers/             # arXiv 论文元数据（deepxiv抓取，带 frontmatter）
│   ├── notes/              # 手写调研笔记
│   └── webclips/           # 网页剪藏
│
├── wiki/                   # 第二层：结构化知识（林赛研究笔记）
│   ├── concepts/           # 核心概念笔记（一个概念一篇）
│   ├── methods/            # 方法与技术笔记
│   ├── people/             # 学者笔记
│   ├── reviews/            # 综述与报告（原 papers/，重命名区分论文）
│   └── projects/           # 项目子库
│       ├── 文献阅读/        # 文献讨论+归档（原 deepxiv-论文库）
│       │   ├── discussions/  # 讨论记录（原 讨论记录/，英文名）
│       │   └── analyses/     # 深度分析（原直接放子库根的论文）
│       └── NSFC-强场超快/   # NSFC课题
│           ├── topics/       # 课题报告（原直接放根的T1-T5）
│           └── decisions/    # 决策记录
│
├── templates/              # 第三层：模板
├── .obsidian/              # Obsidian配置
│
├── index.json              # 倒排索引（自动生成）
├── graph.json              # 知识图谱（自动生成）
├── aliases.json            # 别名映射
├── growth-log.json         # 生长日志
└── categories.json         # 自定义分类
```

### 2.2 关键变更

| 变更 | 原因 |
|------|------|
| `wiki/papers/` → `wiki/reviews/` | 区分"综述报告"和"论文"（论文在 raw/papers） |
| `讨论记录/` → `discussions/` | 目录名用英文，避免编码问题 |
| deepxiv 论文从子库根移入 `analyses/` | 区分"讨论记录"和"深度分析" |
| NSFC 的 T1-T5 移入 `topics/` | 子目录组织更清晰 |

### 2.3 type 字段规则（与目录严格对应）

| 目录 | type 值 | 说明 |
|------|---------|------|
| concepts/ | `concept` | 核心概念 |
| methods/ | `method` | 方法技术 |
| people/ | `person` | 学者 |
| reviews/ | `review` | 综述报告/简报 |
| projects/文献阅读/analyses/ | `analysis` | 论文深度分析 |
| projects/文献阅读/discussions/ | `discussion` | 讨论记录 |
| projects/NSFC-强场超快/topics/ | `topic` | 课题报告 |
| projects/NSFC-强场超快/decisions/ | `decision` | 决策记录 |
| projects/*/MOC.md | `moc` | 索引页 |
| raw/papers/ | （无 type，raw 不参与 wiki 检索） | 原始元数据 |

**规则**：type 一律单数（concept 不是 concepts），一律单值（不允许管道符）。

### 2.4 frontmatter 规范

**所有 wiki 文件必须包含**：
```yaml
---
title: "标题"           # 必填
type: "concept"         # 必填，与目录对应
created: "2026-01-01T00:00:00Z"
updated: "2026-01-01T00:00:00Z"
tags: ["标签"]          # 至少1个
related: ["关联概念"]   # 可空，用于图谱连边
growth_stage: "growing" # seedling/growing/mature
confidence: 0.7         # 0-1
---
```

**可选字段**（按类型）：
- 论文类：`arxiv_id`, `authors`, `year`, `direction`, `source`
- 项目类：`project`, `topic_id`
- 讨论类：`arxiv_id`, `participants`

### 2.5 文件命名规则

| 类型 | 格式 | 示例 |
|------|------|------|
| 概念/方法/人物 | `{中文名}.md` | `三步模型.md` |
| 论文(raw) | `{year}-{arxiv_id}-{slug}.md` | `2024-2403.15337-bright-squeezed-vacuum.md` |
| 深度分析 | `{arxiv_id}-{slug}.md` | `2403.15337-bright-squeezed-vacuum.md` |
| 讨论记录 | `{date}-{arxiv_id}.md` | `20260704-2403.15337.md` |
| 简报 | `briefing-{date}.md` | `briefing-2026-07-20.md` |
| 课题报告 | `T{N}-{名称}.md` | `T3-带动力学.md` |
| 决策 | `decision-{date}.md` | `decision-2026-06-15.md` |
| MOC | `MOC.md` | 固定 |

### 2.6 raw → wiki 关系规则

- `raw/papers/` 是**只增不改**的论文元数据层
- `wiki/projects/文献阅读/analyses/` 是**深度分析**层（归档讨论后生成）
- **同一篇论文**：raw 有元数据，wiki 有分析+讨论，二者通过 `arxiv_id` 关联
- **不允许**在 wiki 下重复存放 raw 已有的论文元数据（当前的问题）
