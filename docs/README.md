# docs/ — 项目文档与报告

本目录存放 LinSai-CoPilot 的项目级文档、评估报告和 prompt 模板。

## 文件清单

| 文件 | 说明 |
|------|------|
| `PROJECT-PLAN.md` | 项目总策划案：愿景、技术路线、里程碑、风险分析 |
| `DEEP-AUDIT-REPORT-v1.7.2.md` | 深度评估报告（v1.7.2）：9 维度架构稳定性审查结果（历史归档） |
| `DEEP-AUDIT-REPORT-v2.0.0.md` | 深度评估报告（v2.0.0）：5 大维度 18 子项综合评估，综合评分 80.4/100 |
| `EVALUATION-PLAN.md` | 深度评估方案：评估框架、竞品分析、执行计划 |
| `IMPLEMENTATION-PLAN-v2.1.0.md` | 工具型协作者实现计划：Phase 0（工具感知）+ Phase 1（多轮执行）+ Phase 2（知识沉淀）+ Phase 3（议程），含架构设计/任务分解/验收标准 |
| `IMPLEMENTATION-PLAN-v3.0.0.md` | 旧版计划（已废弃）：原 Phase 1 自主研究议程，方向已重构 |
| `FUNCTIONAL-TEST-REPORT-v1.7.2.md` | 功能测试报告（v1.7.2）：子代理模拟用户测试、Web API 测试（历史归档） |
| `CLAUDE-CLI-ADMIN.md` | Claude CLI 人工管理指南：人工审查与维护 |
| `prompts/` | LLM prompt 模板（质量审查/维护审查/概念合并/论文精读） |

## 使用规范

- 文档使用 Markdown 格式
- 报告类文档包含：测试方法、结果数据、结论建议
- prompt 模板独立存放，便于版本管理和复用
