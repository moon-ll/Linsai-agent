# 方法学手册：

> 本手册为研究参考文档，详细阐述申请书涉及的核心理论方法与实验技术。

## 方法一：含时密度泛函理论（Time-Dependent Density Functional Theory） {#method-time-dependent-density-functional-theory}

**类别**：理论方法
**难度**：高级
**预计学习时间**：4-6 周
**出现章节**：立项依据
**状态**：已生成

### 理论基础

含时密度泛函理论（TDDFT）是密度泛函理论（DFT）的时间推广，由 Runge 和 Gross 在 1984 年 建立[1]。其核心定理指出：对于任意含时外势，存在一一对应的含时电子密度映射，使得多体问题可以严格转化为单粒子问题。

TDDFT 的基本方程是含时 Kohn-Sham 方程：
$$i\hbar\frac{\partial}{\partial t}\psi_k(\mathbf{r},t) = \hat{H}_{KS}(t)\psi_k(\mathbf{r},t)$$

其中有效哈密顿量含外势、Hartree 势和交换关联势：
$$\hat{H}_{KS}(t) = -\frac{\hbar^2}{2m}\nabla^2 + v_{ext}(\mathbf{r},t) + v_H[n](\mathbf{r},t) + v_{xc}[n](\mathbf{r},t)$$

在固体高次谐波产生（HHG）研究中，TDDFT 可直接模拟电子在强激光场下的非微扰动力学，捕获带间跃迁、带内加速以及复合辐射的完整过程[1]。相较于半经典模型，TDDFT 不依赖先验假设，能自然包含能带色散、多带耦合与拓扑效应。

### 实现细节

TDDFT 计算的关键参数选择：
- **时间步长**：通常取 0.01-0.05 a.u.（原子单位），需满足 $\Delta t \ll T_{laser}/100$，以保证含时演化稳定。
- **空间网格**：三维均匀网格间距 0.1-0.3 a.u.，过粗会丢失原子核附近的快速振荡，过细则计算量急剧上升。
- **交换关联泛函**：常用 ALDA（绝热局域密度近似），计算效率高但缺乏记忆效应；对非线性响应需谨慎评估泛函选择的影响。
- **k 点采样**：固体计算需充分采样布里渊区，典型使用 16x16x16 或更高密度 Monkhorst-Pack 网格。
- **边界条件**：为避免边界反射，需引入吸收边界（如 mask function 或 CAP）。

常用软件包：Octopus（实时 TDDFT）、YAMBO（线性响应 TDDFT）、TDAP（基于 ABINIT 的实时 TDDFT）。固体 HHG 模拟推荐 Octopus，支持周期性边界与规范不变实现。

### 数据分析

HHG 频谱提取流程：
1. **收集含时偶极矩**：从 TDDFT 输出中提取宏观极化 P(t)，偶极矩 d(t) = P(t) * V_cell。
2. **傅里叶变换**：对 d(t) 做快速傅里叶变换（FFT），获取谐波强度 |FFT[d(t)]|^2。
3. **谐波阶次识别**：谐波阶次 q = omega_q / omega_0，其中 omega_0 为驱动光频率。
4. **截止频率分析**：验证 q_cutoff 是否符合半经典三步模型预测 E_g / hbar + 3.17 Up。

时间频率分析：使用 Gabor 变换或小波分析获取谐波发射的时间结构，区分带间与带内贡献。需注意窗函数选择对时间分辨的影响。

收敛性检验：检查 k 点密度、网格间距、时间步长对谐波谱的影响，通常需在目标精度内（如 5%）确认参数收敛。

### 局限性

主要局限：
- **单粒子近似**：标准 TDDFT 采用独立 Kohn-Sham 粒子，无法描述强关联效应（如 Mott 绝缘体中的电子-电子散射）。
- **交换关联泛函**：ALDA 等绝热泛函缺乏记忆效应，对超快动力学（< 1 fs）的描述可能不准确。
- **计算成本**：三维固体的实时 TDDFT 计算量随体系增大急剧上升，典型超胞计算需数百至上千 CPU 核时。
- **自相互作用误差**：常用 GGA/LDA 泛函存在自相互作用，导致能带带隙低估，影响带间跃迁阈值的准确性。
- **退相干缺失**：标准 TDDFT 不含退相干机制，需人为引入退相干因子才能描述部分相干过程。

### 知识库链接

> **认知边界**：知识库中暂无该方法的条目，可作为知识库增长点。

## 方法二：半导体布洛赫方程（Semiconductor Bloch Equations） {#method-semiconductor-bloch-equations}

**类别**：理论方法
**难度**：中级
**预计学习时间**：2-3 周
**出现章节**：立项依据
**状态**：已生成

### 理论基础

半导体布洛赫方程（SBE）描述强场下固体中电子的相干动力学，是固体 HHG 理论分析的核心工具之一。其基础是密度矩阵形式下的光学布洛赫方程，将电子态用能带指标和 k 矢量标记。

在两带近似下，SBE 的基本形式为：
$$i\hbar\frac{\partial}{\partial t}\rho_{cv}(\mathbf{k},t) = \epsilon_{cv}(\mathbf{k},t)\rho_{cv}(\mathbf{k},t) - \mathbf{E}(t)\cdot\mathbf{d}_{cv}(\mathbf{k})[\rho_{vv} - \rho_{cc}]$$

其中 $\rho_{cv}$ 为带间相干（极化），$\rho_{cc}$、$\rho_{vv}$ 为布居数，$\epsilon_{cv} = \epsilon_c - \epsilon_v$ 为带间能量差，$\mathbf{d}_{cv}$ 为跃迁偶极矩。

SBE 的优势在于物理图像清晰：带间极化对应 HHG 中的电子-空穴复合辐射，带内加速则通过 k 矢量的半经典运动方程 $\hbar\dot{\mathbf{k}} = -e\mathbf{E}(t)$ 描述。这使得 SBE 成为理解固体 HHG 机制的半经典三步模型的微观基础。

### 实现细节

SBE 数值求解的关键考量：
- **能带输入**：需从 DFT 或紧束缚模型获取能带结构 $\epsilon_{n}(\mathbf{k})$ 和跃迁偶极矩 $\mathbf{d}_{nm}(\mathbf{k})$，通常在布里渊区均匀采样。
- **k 点采样**：1D 模型典型 1000-5000 个 k 点；3D 完整计算需 50^3 量级，计算量可观。
- **时间步进**：采用四阶 Runge-Kutta 或分裂算符法，时间步长需满足 $\Delta t < 0.1 T_{laser}$。
- **退相干项**：引入唯象退相干时间 T2（带间）和 T1（带内），典型 T2 ~ 10-50 fs，T1 ~ 100-500 fs。
- **规范选择**：长度规范（E·r）或速度规范（A·p），需确保跃迁偶极矩的规范一致性。

多带扩展：两带近似适用于宽带隙绝缘体；对拓扑材料或简并体系需扩展至多带 SBE，计算复杂度显著增加。

### 数据分析

从 SBE 提取 HHG 谱：
1. **宏观极化计算**：$P(t) = \sum_{\mathbf{k}} \mathbf{d}_{cv}(\mathbf{k})\rho_{cv}(\mathbf{k},t) + c.c.$，对所有 k 点求和。
2. **频谱变换**：FFT[P(t)] 得到谐波谱。
3. **机制分解**：将极化拆分为带间和带内分量，分析各阶谐波的来源。
4. **k 空间分析**：追踪电子在 k 空间的轨迹，识别带间跃迁和带内加速事件。

对称性分析：利用晶体对称性分析谐波偏振与晶体取向的关系，可提取 Berry 曲率等几何量的贡献。

与 TDDFT 对比：SBE 结果可与 TDDFT 交叉验证，差异通常源于 SBE 中省略的多体效应和带间耦合细节。

### 局限性

局限与陷阱：
- **能带输入依赖**：SBE 结果高度依赖输入能带和偶极矩的质量，DFT 带隙低估会直接影响 HHG 截止频率预测。
- **退相干唯象处理**：T1、T2 为可调参数，缺乏第一性原理依据，不同体系取值差异大。
- **带数截断**：两带近似忽略远带贡献，对宽带激光或多光子过程可能不适用。
- **偶极矩规范**：长度规范与速度规范的偶极矩不同，混用会导致非物理结果。
- **电场强度上限**：极强场下布居数可能溢出 [0,1] 区间，需注意数值稳定性。
- **无电子-电子散射**：标准 SBE 不含碰撞项，无法描述载流子热化和散射退相干。

## 方法三：Floquet 理论（Floquet Theory） {#method-floquet-theory}

**类别**：理论方法
**难度**：中级
**预计学习时间**：2-3 周
**出现章节**：研究方案
**状态**：已生成

### 理论基础

Floquet 理论是处理周期性含时哈密顿量的标准框架，类比 Bloch 定理在空间周期势中的应用。对于周期为 T = 2π/ω 的含时哈密顿量 H(t) = H(t+T)，Floquet 定理保证其解可写为：

$$\psi_\alpha(\mathbf{r},t) = e^{-i\epsilon_\alpha t/\hbar} \phi_\alpha(\mathbf{r},t)$$

其中 $\epsilon_\alpha$ 为 Floquet 准能量（quasi-energy），$\phi_\alpha(\mathbf{r},t) = \phi_\alpha(\mathbf{r},t+T)$ 为周期函数。准能量定义在 Floquet Brillouin 区 $[-\hbar\omega/2, \hbar\omega/2)$ 内。

在强场物理中，Floquet 理论提供了“光子缀饰态”（photon-dressed states）的图像：驱动激光场将静态能带“折叠”为以 ℏω 为周期的 Floquet 能带。这种图像揭示了光诱导的带隙闭合、拓扑变化以及动态局域化等非平衡现象。

Floquet 理论与 SBE 的关系：稳态 Floquet 态对应 SBE 的长时间极限解，准能量差即为缀饰带间的跃迁频率。

### 实现细节

Floquet 计算的实现路径：
- **Floquet 矩阵构造**：将哈密顿量在 Floquet 基 $|n,\alpha\rangle$ （n 为光子副本指标，α 为静态能带指标）下展开，构造无穷维矩阵 H_F，其对角元为 $\epsilon_\alpha + n\hbar\omega$，非对角元为 V_±（光耦合矩阵元）。
- **截断**：光子副本数 N_max 通常取 5-20，需检查准能量收敛性。
- **对角化**：对截断后的 Floquet 矩阵对角化，得到准能量谱和 Floquet 态。
- **电场参数化**：线偏振场 H_int = -eE_0 cos(ωt) x，圆偏振场需含两个分量。

Sambe 空间-时间基：将 Floquet 态在空间和时间基上联合展开，可直接处理含时波函数。该方法精度高但矩阵维度大。

常用工具：自研代码为主，部分 DFT 软件包（如 Wannier90 + 后处理）可构建 Floquet 哈密顿量。

### 数据分析

Floquet 准能量分析：
1. **准能带绘制**：以 k 为横轴绘制准能量 $\epsilon_\alpha(\mathbf{k})$，观察带隙闭合与 reopen 现象。
2. **拓扑分析**：计算 Floquet 能带的 Chern 数，检测光诱导拓扑相变。
3. **态密度**：Floquet 态密度 $D_F(\epsilon) = \sum_{\alpha,\mathbf{k}} \delta(\epsilon - \epsilon_\alpha(\mathbf{k}))$，与实验 ARPES 对比。
4. **吸收谱**：从 Floquet 极化率提取非线性吸收谱。

收敛性检验：检查 N_max 对准能量的影响，通常准能量收敛速度 ~1/N_max^2。

与实验对比：注意 Floquet 理论描述稳态（无限长脉冲），实际实验为有限脉冲，需引入瞬态 Floquet 分析。

### 局限性

局限与注意事项：
- **稳态假设**：标准 Floquet 理论假设无限长周期驱动，不适用于超短脉冲（< 10 周期）。
- **退相干缺失**：不含耗散和退相干，预测的“拓扑相变”在实际体系中可能被退相干抹平。
- **矩阵维度**：多带 + 多光子副本的 Floquet 矩阵维度可达数千，对角化成本高。
- **共振发散**：在共振条件（$\epsilon_c - \epsilon_v \approx n\hbar\omega$）附近，光子副本间强耦合可能导致数值困难。
- **规范依赖**：长度规范与速度规范下的 Floquet 态不同，需确保一致使用。
- **物理诠释**：Floquet 态为数学构造，其“实在性”在物理社区仍有争议。
