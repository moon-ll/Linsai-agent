# 后选择测量

## 定义定位

后选择测量（post-selected measurement）指在测量协议末端追加一次标准（强）投影测量，只保留测量结果落在指定子集内的实验样本、丢弃其余数据的操作。它与“预选择”（制备初态 |ψᵢ⟩）相对，共同划定弱测量理论中的条件系综。后选择绝不等同于事后的数据筛选：按 Lüders 规则，被保留子系综的态更新为 ρ → Π_f ρ Π_f / Tr(Π_f ρ)，条件态与无条件系综可有质的差别。它既是出现异常弱值的必要条件，也是量子态工程中“条件制备/ heralding”的核心机制。

## 物理内涵/技术原理

标准弱测量链路为：预选择制备 |ψᵢ⟩ → 弱耦合（H_int = g(t) Â⊗P̂，指针只被轻微移动）→ 后选择投影到 |ψ_f⟩。仅对通过后选择的样本统计指针，其位置与动量偏移分别为

- Δq = g·Re A_w
- Δp = 2g·Im A_w·(Δp₀)²

其中弱值 A_w = ⟨ψ_f|Â|ψᵢ⟩ / ⟨ψ_f|ψᵢ⟩。当 ⟨ψ_f|ψᵢ⟩ 接近正交时弱值急剧增大，可远超可观测量本征值范围（“异常弱值”），这是弱值放大（WVA）技术的物理基础。代价是成功率 P_ps = |⟨ψ_f|ψᵢ⟩|² 同步下降：单事件信息量上升、总事件数下降，在理想探测器下总 Fisher 信息不变；但面对探测器饱和、加性噪声、模式失配等技术噪声时，WVA 可带来真实的信噪比收益——分析任何后选实验都必须同时报告成功率的取舍。

超越弱测量语境，后选择本质上提供了一种“非线性的态制备”：对子系统 A 的测量结果取条件，可在子系统 B 上条件性制备出用幺正演化难以直接得到的态（如光子扣除/增产生成猫态、零差探测后选择制备非高斯态、纠缠纯化）。在强激光场物理中，后选择表现为对电子末态动量或重碰能量窗口的筛选，把原本纠缠混合的系综切分为对应特定量子轨迹的条件样本，再借弱值读取实现对微小耦合参数（椭率、延迟等）的放大探测——这正是样本一中弱测量方案得以落地的桥梁。

## 与现有方法/概念的关联

- 后选择是 [[弱测量]] 三要素（预选择–弱耦合–后选择）的收口，直接决定 [[弱值]] 是否出现异常放大；
- 与 [[预选择]] 共同定义条件系综，二者近似正交是 [[弱值放大]] 的设计目标；
- 在量子光学中，后选择即 heralding/条件测量，是 [[量子态工程]]（样本二的光态工程）里生成单光子态、猫态、非高斯态的标准手段，亦构成 [[纠缠纯化]] 与后选择型量子计算的逻辑内核；
- 由后选择弱值可重构 [[直接测量波函数|波函数的直接测量]]（Lundeen 方案），可视为 [[量子层析]] 的弱耦合替代路线。
