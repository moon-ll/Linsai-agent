# 光致拓扑相变

## 定义定位

光致拓扑相变（photoinduced topological phase transition）指利用相干光场（从太赫兹到可见波段的激光或脉冲）与固体耦合，在**非平衡条件**下改变体系能带的拓扑不变量（陈数、Z₂ 不变量、绕数等），使材料在拓扑平庸相与拓扑非平庸相之间、或不同拓扑相之间发生转变的现象。与依赖化学掺杂、静压、静电栅压等“静态”调控的常规拓扑相变不同，它发生在飞秒—皮秒时间尺度，本质是含时驱动过程，“相”由 Floquet 准能量谱或含时序参量刻画，是超快科学与拓扑物态研究的交叉概念。

## 物理内涵/技术原理

核心机制可归为三类：

1. **Floquet–布洛赫机制**：周期光场使哈密顿量满足 H(t)=H(t+T)，布洛赫态推广为 Floquet 态。高频展开给出有效哈密顿量，跃迁项被贝塞尔函数 Jₙ(A/ω) 修饰；圆偏振光破坏时间反演对称性，可在狄拉克点打开手性能隙并产生非零陈数——相当于动力学实现的 Haldane 模型（Oka–Aoki 光致霍尔效应、Floquet 拓扑绝缘体）。
2. **共振耦合与动态带反转**：当 ℏω 与带间跃迁共振时高频近似失效，需处理多光子共振及准能隙的闭合—重开；线偏振强场还可通过瞬时改变键长/轨道杂化，诱导类似静压的带反转。
3. **非平衡拓扑不变量**：周期驱动系统的拓扑由 Floquet 布里渊区中的绕数定义，允许出现平衡态没有的“反常边态”（Rudner et al.），即绕数与边态数目的对应需在准能量维度上重新表述。

理论工具包括 Floquet 有效哈密顿量、含时严格对角化、含时密度泛函（TDDFT），以及面向强关联体系的 Krylov 演化/tDMRG；实验探针以泵浦—探测时间分辨 ARPES 与瞬态霍尔测量为主。

## 与现有方法/概念的关联

- 与 [[Floquet 工程]] 直接同源，可视为其在拓扑物态方向最重要的应用。
- 拓扑判据依赖 [[拓扑不变量]]（陈数/Z₂）与能带反转判据，可回链贝里曲率与反常霍尔响应。
- 在摩尔体系中与 [[魔角双层石墨烯]] 的平带结构结合：光驱动可动态修改摩尔跃迁与 t/U 比例，为无磁场分数陈态提供可能路径。
- 光物质耦合矩阵元与真实能带底座常由 [[第一性原理计算]] 提供，与本项目收录的电子结构工作互补。

## 林赛理解

在本项目知识图谱中，光致拓扑相变并非核心研究对象（引用 2 次、优先级 low），而是一个**跨域枢纽**概念：它把平衡态拓扑物态（陈数、带反转）与超快非平衡物理连接起来。两篇样本各代表一条互补路径——魔角石墨烯的精确对角化工作提示光场是平带体系中调节有效跃迁、打开手性能隙的额外旋钮；第一性原理电子结构
