# 量子输运

## 定义定位

量子输运是指载流子（电子、空穴、激子等准粒子）在介观或纳米尺度体系中传输时，由波动性、相位相干性与能级量子化主导的输运行为，以及描述这类行为的理论框架的总称。当体系特征尺寸与相位相干长度、弹性散射平均自由程或热德布罗意波长相当或更小时，经典漂移—扩散描述失效，输运必须借助 Landauer–Büttiker 散射理论、非平衡格林函数（NEGF）或量子主方程等量子力学框架刻画。它涵盖弹道输运、隧穿输运、相干输运与强场非平衡输运等多种机制，是介观物理、纳米电子学与量子器件研究的核心基础概念。

## 物理内涵/技术原理

量子输运的物理内涵可从三个层面理解。

**尺度与量子化**：当导线或器件沟道进入纳米量级，横向约束使连续能带劈裂为分立子带，电导以量子电导 $G_0 = 2e^2/h$ 为单位量子化；外磁场下回旋运动量子化形成朗道能级，磁输运呈现 Shubnikov–de Haas 振荡乃至量子霍尔效应。二维材料（如 WSE₂）因面外受限与低载流子有效质量，是观察这类量子化输运的理想平台。

**相位与相干**：弹性散射保留载流子相位信息，非弹性散射则破坏相干性。在相干输运区，干涉效应显著——Aharonov–Bohm 振荡、弱局域化、普适电导涨落等均为相位的直接可观测后果。

**非平衡与强场驱动**：在强激光场或大偏压下，体系远离热平衡，载流子分布、隧穿电流与非线性响应需由含时量子动力学描述。NEGF 的 Keldysh 形式体系可自洽演化谱函数、粒子数与流，统一处理隧穿、耗散及光子/声子耦合。强场驱动的非平衡电子在能带间的相干跃迁与再辐射，正是非线性光学响应（如谐波产生）的微观来源，构成输运物理与超快光学交叉的桥梁。

## 与现有方法/概念的关联

- 与 [[量子限域]] 直接相关：磁诱导限域与尺寸限域通过能级量子化重塑输运通道，是磁场下 WSE₂ 等二维体系中受限输运的物理载体。
- 强场非平衡输运与 [[非平衡动力学]]、[[高次谐波产生]] 相衔接：偶次谐波可理解为非平衡载流子在驱动场中相干输运与再辐射的宏观表现，对称性破缺则决定了偶次分量的出现。
- 理论工具链上，与 [[朗道能级]]、[[隧穿]]、非平衡格林函数等方法概念共同构成从“模型”到“可观测量”的推理路径。

## 林赛理解

在本项目（二维材料强场/超快动力学方向）中，量子输运主要扮演“微观量子动力学 ↔ 宏观可观测量”之间的桥梁角色，目前定位为背景支撑概念（引用频次 2，优先级 low）。具体体现在两处：其一，磁诱导限域下 WSE₂ 中载流子的朗道量子化与受限通道，为理解样品中的限域态及其谱学特征提供输运视角的语言；其二，偶次谐波产生中的非平衡载流子行为，本质上可视为强场驱动的相干量子输运过程，输运框架有助于把光学响应与载流子迁移、带间隧穿通道定量关联。后续若项目延伸至器件化输运测量或输运—光学交叉问题，应回头升级本页深度。
