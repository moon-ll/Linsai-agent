# Mott转变（Mott Transition）

## 定义定位

Mott 转变是由电子—电子强关联效应驱动的金属—绝缘体相变，以 Nevill Mott 命名。当同一格点上电子间的库仑排斥能 U 与电子动能尺度（能带宽度 W）之比 U/W 超过临界值时，电子的巡游运动被关联效应“冻结”，体系从金属态转变为电子局域化的绝缘态（Mott 绝缘体）。与常规能带绝缘体不同，Mott 转变发生在能带半满、按单电子能带论本应导电的体系中，是区分“单电子图像失效”与“多体关联主导”的分水岭，也是强关联电子物理的核心范式。

## 物理内涵/技术原理

Mott 转变的标准理论载体是 Hubbard 模型：H = −t Σ c†ᵢⱼcⱼ + U Σ nᵢ↑nᵢ↓。半满填充下，当 U/t 超过临界值 Uc 时，低能激发谱打开 Mott 隙 Δ ≈ U − W（强耦合极限），电子为避免双占据而局域化；剩余的自旋自由度通过超交换 J ≈ 4t²/U 在低温下形成反铁磁关联，使磁性成为 Mott 态的“伴生指纹”。

主要理论图像与结果：

- **Brinkman–Rice / Gutzwiller 图像**：临近转变点，准粒子有效质量 m* 发散、准粒子权重 Z → 0，刻画关联增强的金属态；
- **DMFT（动力学平均场理论）**：定量给出有限温下的一级相变线与临界终点（critical endpoint），成功解释 V₂O₃ 的压力—温度相图与金属/绝缘体共存区；
- **熵与晶格自由度耦合**：可展宽相变区域，产生滞回与亚稳“隐藏态”。

实验体系中 Mott 转变极少“干净”出现，常与电荷序、Peierls 畸变、轨道序交织：V₂O₃ 由 Cr 掺杂与压力调控；有机电荷转移盐 κ-(BEDT-TTF)₂X 在压力诱导的 Mott 边界附近出现反铁磁与量子自旋液体竞争；1T-TaS₂ 则由 commensurate CDW（Star-of-David 畸变）剧烈窄化半满能带，使 U/W 越过阈值，形成轨道选择的 Mott 态，并表现出 Mott 绝缘体与能带绝缘体的“双重性”。此外，铜氧化物高温超导体作为**掺杂** Mott 绝缘体，在 Mott 边界附近涌现赝能隙与非常规超导，表明 Mott 转变还纠缠着量子临界涨落与新型有序态。
