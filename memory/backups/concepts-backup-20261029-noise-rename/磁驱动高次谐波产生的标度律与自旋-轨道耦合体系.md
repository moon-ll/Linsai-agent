# 磁驱动高次谐波产生的标度律与自旋-轨道耦合体系

## 定义定位

本概念页刻画三类物理要素的交叉：（1）**磁驱动高次谐波产生**（magnetically driven HHG）——以磁场、磁序（交换场）或超快自旋动力学作为驱动或调制手段，在固体中产生非线性谐波辐射的过程，区别于纯电场驱动的常规 HHG；（2）**标度律**——谐波截止能量、产率、偏振与自旋极化度等可观测量随驱动场强、光子能量、材料参数（带隙、有效质量、自旋-轨道耦合强度、退相干时间）变化的幂律或普适函数关系；（3）**自旋-轨道耦合体系**——SOC 主导的量子材料，如拓扑绝缘体表面态、Rashba 异质结、Weyl/Dirac 半金属、磁性重金属界面等。该页在知识库中作为低频交叉节点，统一归档上述方向的文献笔记与判据。
