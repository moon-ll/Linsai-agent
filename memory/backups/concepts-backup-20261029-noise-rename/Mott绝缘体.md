# Mott 绝缘体

## 定义定位

Mott 绝缘体是一类“按能带理论应为金属、实际却绝缘”的反常材料：价带半满、单电子图像预言金属性，但电子间强在位库仑排斥（Hubbard U）冻结了电荷自由度，使体系在低温下打开关联能隙。典型体系包括 NiO、MnO 等过渡金属氧化物、有机电荷转移盐，以及自旋–轨道耦合 Mott 绝缘体 Sr₂IrO₄。其绝缘性不源于能带填充或对称性，而源于多体关联本身，因而是强关联电子物理的原型平台，也是本项目中区别于半导体能带体系的强场光学研究对象。

## 物理内涵/技术原理

最简描述是半满单带 Hubbard 模型：H = −t Σ⟨ij⟩σ c†ᵢσ cⱼσ + U Σᵢ nᵢ↑nᵢ↓。当 U 与带宽 W 同量级以上时，谱函数劈裂为上下 Hubbard 带，中间打开 Mott 能隙（典型 0.1–2 eV），其电荷激发不是单粒子带间激发，而是“双占据–空穴”（doublon–holon）对；U 越大、跳跃 t 越小，隙越宽。虚拟跳跃同时产生超交换 J = 4t²/U，使大多数 Mott 绝缘体基态呈反铁磁有序；U/W 扫过临界值则发生 Mott 金属–绝缘转变。

在强激光场下（本项目关注点），Mott 能隙提供低于常规带隙的击穿阈值：电场以隧穿方式在隙边激发 doublon–holon 对，随后在 Hubbard 带内加速并复合，带内非线性电流与复合能量释放共同辐射高次谐波，机制上不同于半导体的带间极化“三步模型”。在扩展 Hubbard 模型（含近邻排斥 V）及强场极限下，doublon–holon 的亚周期动力学使谐波谱出现对场幅敏感的非整数次谐波峰，可视为关联电荷运动（U、V、t 的组合）的亚周期指纹。这使 HHG 成为全光学、超快探测关联强度与 Mott 转变动力学的手段。

## 与现有方法/概念的关联

- Mott 绝缘体是 [[Hubbard模型]] 半满填充在 U/W 足够大时的基态相，与 [[能带绝缘体]] 形成机制对照（关联能隙 vs 带隙）。
- 在本项目中，它是 [[高次谐波产生]]（HHG）的一类强关联载体：谐波来源于 doublon–holon 对的激发–加速–复合，而非半导体中的带间极化；非整数次谐波进一步对应亚周期关联动力学（见 [[doublon-holon对]]）。
- 与 [[强场超快动力学]]／光诱导 Mott 转变方向的文献共享 THz–中红外强场调控的语言。

## 林赛理解

在本项目知识库中，Mott 绝缘体是“强关联体系高次谐波”这条线的核心物质平台：两篇样本论文——扩展 Hubbard 模型中非整数次 HHG 的理论（arXiv:2403.08327）与 Mott 绝缘体 HHG 的实验观测（PRL 135, 166902）——分别对应该方向的理论预言与实验确认。我在整理 HHG 相关笔记时，应把 Mott 型机制（关联能隙 + doublon–holon 亚周期运动）与半导体带间机制分开标签管理；非整数谐波峰可作为区分两类机制、并反推 U/V 等关联参数的判据，这也是该概念在后续综述与关联分析中的引用锚点。
