# 能谷电子学

## 定义定位

能谷电子学是利用晶体能带结构中的**能谷自由度**——即电子在动量空间中占据的不等价能量极值点（如六角晶格布里渊区中的 K 与 K' 谷）——作为信息载体的交叉学科，研究能谷指标的写入、相干操控、输运与读出。它与自旋电子学互补，试图摆脱对电荷输运的依赖，追求低功耗、非易失的信息处理方案。能谷指标在时间反演下守恒，只有在破缺空间反演对称性的体系（单层过渡金属硫族化合物、hBN、金刚石色心等）中才能被光场或电场选择性操控，由此构成凝聚态物理与超快光学交叉的前沿领域。

## 物理内涵/技术原理

能谷电子学的核心物理可归结为“几何属性 + 光学选择定则 + 动力学”三层：

1. **贝里曲率与能谷霍尔效应**：在破缺面内反演对称的单层 TMD（如 MoS₂、WSe₂）中，K 与 K' 谷处的贝里曲率大小相等、符号相反。面内电场驱动下载流子获得符号相反的反常速度，两谷电荷向晶体两侧分离，产生能谷霍尔效应——这是电学读出能谷极化的基础，也使能谷成为可探测的宏观可观测量。

2. **圆偏振选择定则**：由于光学跃迁角动量守恒与自旋-能谷锁定，σ⁺ 与 σ⁻ 圆偏振光分别选择性激发 K 与 K' 谷激子。泵浦-探测圆二色性因此成为最常用的能谷全光学写入/读出手段，但其只能给出极化的幅度信息。

3. **能谷相干与线偏振操控**：线偏振光是等幅 σ⁺/σ⁻ 的相干叠加，可激发 K–K‘ 谷的相干叠加态，产生能谷布居的量子拍频与角度依赖的各向异性响应，为相干操控提供通道（对应样本 2022-2203_14286）。
