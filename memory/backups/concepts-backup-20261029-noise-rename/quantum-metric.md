# 量子度规（Quantum Metric）

## 定义定位

量子度规（quantum metric）是定义在量子态空间或参数化布洛赫态流形上的实对称张量，用于描述相邻量子态在几何意义上的分离程度。它通常取量子几何张量（quantum geometric tensor）的实部，与描述量子态相位绕行的 Berry 曲率共同构成量子几何的两部分。量子度规可将波函数随动量、晶格参数或外场的变化转化为局域长度、距离与角度信息，因此能够刻画能带间的混合、态的展宽以及多能级系统中的量子几何效应。它本身通常不是拓扑不变量，但可与 Berry 曲率、拓扑指标及响应系数共同用于判断材料的量子几何性质。

## 物理内涵/技术原理

设无简并能级对应的本征态为 \(\lvert u_n(\mathbf{k})\rangle\)，密度矩阵为 \(\rho_{\mathbf{k}}=\lvert u_n\rangle\langle u_n\rvert\)。量子几何张量可写为

\[
Q_{ij}=\operatorname{Tr}\!\left[(\partial_i\rho_{\mathbf{k}})(\partial_j\rho_{\mathbf{k}})\right]
=\langle\partial_i u_n|(1-P)|\partial_j u_n\rangle ,
\]

其中 \(P=\lvert u_n\rangle\langle u_n\rvert\) 是该能级的投影算符。量子度规定义为 \(g_{ij}=\operatorname{Re}Q_{ij}\)，而 \(\operatorname{Im}Q_{ij}\) 对应 Berry 曲率。单个能级在动量空间中的局域线元为

\[
ds^2=g_{ij}\,dk_i\,dk_j,
\]

因此，度规张量的不同方向分量反映量子态对不同扰动的敏感性。较大的度规通常意味着本征态在有限参数变化下具有更显著的展宽或能级混合。

对于有限温度、混合态或多能级系统，可以采用投影算符

\[
P_{\mathbf{k}}=\sum_n\lvert u_n(\mathbf{k})\rangle\langle u_n(\mathbf{k})\rvert
\]

构造规范不变的度规，但不同文献在能带求和方式、归一化因子以及是否采用 Bures 度规约定方面可能存在差异，比较结果时需要统一定义。量子度规具有规范不变性：规范变换只会在态上乘以相位或幺正矩阵，不会改变投影算符及其导数所定义的度规。

在物理效应方面，量子度规与 Berry 曲率并非同一概念。Berry 曲率主要描述态空间曲率及整数量子几何，对霍尔响应和拓扑性质尤其重要；量子度规则描述局域距离和态的重叠。二者通过量子几何张量相互联系，并满足如 \(g_{ij}\geq |\Omega_{ij}|/2\) 等约束。量子度规因此可用于研究非线性霍尔效应、光学跃迁与选择定则、超辐射、量子传感、隧穿过程中的几何相位，以及拓扑材料中的能带展宽和量子几何不等式。

## 与现有方法/概念的关联

量子度规是[[量子几何]]中与 Berry 曲率并列但侧重不同的核心对象。与只记录相位绕行的 [[Berry 曲率]]相比，它直接度量相邻量子态的重叠和分离，可视为量子态空间中的“距离张量”。在 [[拓扑不变量]]研究中，Berry 曲率或 \(Z_2\) 不变量通常用于提取整体拓扑性质，而量子度规常用于描述拓扑态附近的几何色散、形变程度和能带混合；非零度规不能直接等同于非平凡拓扑。

在多带 [[能带结构]]中，量子度规能够反映不同能级之间的量子干涉，并通过投影算符或约化密度矩阵实现规范不变描述。它也与 [[Bures 度规]]、[[Fubini–Study 度规]]及 [[量子几何张量]]密切相关，这些概念在物理内涵上高度重叠，但归一化约定和适用的态空间并不完全相同。

在光学研究中，基于量子度规的 [[光学选择定则]]可解释为什么某些跃迁在特定偏振、传播方向或偏振结构下被增强或禁止。其关键思想是：电磁场不仅耦合电荷和偶极矩，也可能通过跨能级矩阵元感受到量子态的几何重叠。此外，在 [[隧穿效应]]与 Berry 相位的研究中，量子度规可作为 Berry 曲率的实部补充，帮助区分相位积累与态重叠变化。

## 林赛理解

在林赛的项目语境中，量子度规是连接“微观能带结构—量子几何—可观测响应”的中间概念。现有样本分别从量子材料、光学选择定则以及隧穿过程中的 Berry 相位切入：单独讨论 Berry 曲率容易把注意力集中在拓扑和相位上，而量子度规能够进一步解释波函数如何随动量或外场变化、多个能级如何混合，以及这种局域几何如何影响光吸收、偏振响应或隧穿特征。因而，林赛可以把量子度规作为跨论文比较和概念组织的核心节点：先用 Berry 曲率确认几何与拓扑背景，再用度规张量分析各向异性、态展宽和响应强度，最后借助光学或隧穿实验验证相关几何信息。

## 学习路径/参考

建议按照以下顺序建立理解：

1. 掌握布洛赫态、投影算符与规范变换，理解量子态的重叠如何定义几何距离。
2. 学习 Berry 曲率、Berry 连接与 Berry 相位，区分“曲率”与“度规”。
3. 推导量子几何张量，明确其虚部与实部分别对应什么物理量。
4. 研究单带、多带及混合态定义，并核对 Bures 度规等归一化约定。
5. 进一步阅读量子几何不等式、非线性霍尔效应、光学选择定则和量子传感等应用。
