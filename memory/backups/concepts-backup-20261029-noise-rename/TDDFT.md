# TDDFT（含时密度泛函理论）

## 定义定位

TDDFT（Time-Dependent Density Functional Theory，含时密度泛函理论）是 [[DFT]]（密度泛函理论）向非平衡、含时体系的自然推广。其理论基石是 Runge–Gross 定理（1984）：给定初始态，含时外场与含时电子密度之间存在一一对应关系，从而可把求解多体含时薛定谔方程的问题映射为求解一组无相互作用的含时 Kohn–Sham（TDKS）方程。TDDFT 以电子密度而非多体波函数为基本变量，计算代价远低于含时薛定谔方程或含时 Hartree–Fock，是从头算研究激发态、光与物质相互作用、超快电子与自旋动力学的主流方法，也是连接基态电子结构与飞秒/阿秒时间尺度非平衡现象的核心工具。

## 物理内涵/技术原理

**理论内核。** Runge–Gross 定理保证了密度的 v-可表示性（外势在差一个纯时间函数的意义下由密度唯一确定），由此得到 TDKS 方程：

$$i\frac{\partial}{\partial t}\varphi_i(\mathbf{r},t)=\left[-\frac{1}{2}\nabla^2+v_{\text{ext}}(\mathbf{r},t)+v_{\text{H}}[n](\mathbf{r},t)+v_{\text{xc}}(\mathbf{r},t)\right]\varphi_i(\mathbf{r},t)$$

其中交换关联势 $v_{\text{xc}}$ 严格来说依赖于密度的整个历史（具有记忆效应），但实用中普遍采用**绝热近似**——用瞬时密度代入基态泛函（ALDA、AGGA 等），这是 TDDFT 主要的误差来源之一（如无法描述双激发、长时间电荷转移激发）。

**两种工作模式。**（1）*线性响应 TDDFT*：在 Casida 方程框架下求解激发能与振子强度，适合微扰区（吸收谱、光学性质），与 [[线性响应理论]]/Kubo 形式直接相通；（2）*实时 TDDFT（RT-TDDFT）*：显式演化 TDKS 轨道，可处理任意强场（飞秒激光脉冲）等非微扰问题；与核运动耦合时通常采用 [[Ehrenfest 动力学]]。

**磁性扩展。** 自旋极化/非共线 TDDFT 允许磁化矢量随时空演化，可显式计算激光诱导退磁、自旋流与自旋转移矩，是 [[超快磁化动力学]] 研究中超越唯象模型（LLG/原子级自旋动力学）的从头算手段。

**数值实现。** 实时传播对算法敏感：常用 Magnus、Crank–Nicolson、强制时间反演对称等传播子，配合实空间网格+有限差分。传播步进中小规模稠密运算密集，天然适合 GPU 异构加速——这正是样本文献 2603.21835（数值代码统一异构实现）所代表的方向。

## 与现有方法/概念的关联

- **基态理论**：TDDFT 直接复用 [[DFT]] 的 Kohn–Sham 机器与 xc 泛函库，绝热近似即“借用”基态泛函；
- **响应与谱学**：线性响应 TDDFT 是 [[线性响应理论]] 的第一性原理实现，与 Kubo/Green–Kubo 方法互补；
- **电子–核耦合**：与 [[Ehrenfest 动力学]] 结合处理光致相变、离子动量谱；需要非绝热性时转向面跳跃/NEGF；
- **应用场景**：样本 2507.15199（光致超快磁化动力学）属于其自旋动力学方向的应用；性能层面则关联 [[异构计算]]/电子结构代码 GPU 化这一工程主题；
- **与其他激发态方法比较**：比 GW/BSE 便宜但精度受限于 xc 泛函；对强场非微扰问题几乎是唯一可负担的从头算选择。
