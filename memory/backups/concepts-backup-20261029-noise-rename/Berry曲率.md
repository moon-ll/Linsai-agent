# Berry曲率（Berry Curvature）

布洛赫能带的几何曲率，表征准动量空间中自旋/能带本征态的绝热演化几何相位（Berry 相位）的涡旋密度，作用类似动量空间的等效磁场：产生反常速度与反常霍尔效应，谷体系中支持谷霍尔输运，并对非线性光学响应（位移电流、非线性霍尔、圆二色性等）有决定性贡献。布里渊区积分（陈数）给出拓扑分类。

## 与本库的关联

量子几何反演课题的核心提取对象之一；此前本词作为引用出现 20+ 次而无实体页（2026-09-25 体检红链），本页为体检补建。
