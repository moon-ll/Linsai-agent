# 强场驱动

## 定义定位

强场驱动（strong-field driving）指用强度足以与体系内禀能量尺度相比拟的外场——激光、太赫兹脉冲、微波或量子化腔场——对量子材料施加周期性或脉冲式激发，使系统进入非微扰、非平衡区域。判据大致为：场耦合能 eEa（a 为晶格常数，E 为场强）达到能带宽度、激子/配对束缚能或 Hubbard U 的可观比例。它区别于线性响应区的弱探测（[[线性响应]]），核心特征是场本身重塑哈密顿量，而非仅仅“读取”它。

## 物理内涵/技术原理

强场驱动的物理内涵可按耦合强度分层理解：

- **微扰失效与机制分支**：以 Keldysh 参数或等价的隧穿/多光子判据区分机制——场致电离型的 Landau–Zener 隧穿、多光子吸收、以及介于其间的非线性混合路径。在固体中这对应带间 Zener 击穿与多光子带间跃迁的竞争。
- **Floquet 图像**：周期驱动下能量守恒 replaced 为准能量守恒，等效哈密顿量可作高频展开 H_eff = H₀ + [V₋₁,V₁]/ħω + …。跃迁振幅被贝塞尔函数 J₀(eAa/ħ) 重整，可实现动力学局域化（有效冻结隧穿）、带隙开合与拓扑修饰，是 [[Floquet 工程]] 的理论根基。
- **平带放大效应**：[[魔角双层石墨烯]] 等平带体系带宽仅 ~10 meV 量级，中等强度的 THz/中红外场即满足强场判据，使关联与拓扑可在实验可达场强下被主动调控，也放大了加热与预热化（prethermalization）问题。
- **量子化极限（腔驱动）**：当耦合强度 g/ω → 0.1 以上（超强/深强耦合），驱动源从经典波变为腔真空涨落，可修饰基态性质（如 [[腔修饰超导]]），但 A² 抗磁项及其 no-go 定理限制了可选的工程方案。
- **读出端**：强场非线性光谱（χ⁽³⁾、二维相干光谱）能把多体相互作用——激子-激子散射、束缚态、集体模式指纹——映射到多维频谱上。

## 与现有方法/概念的关联

- 与 [[Floquet 工程]]：强场驱动是实现 Floquet 能带修饰的物理手段，前者强调“场够强”，后者强调“周期调制下的等效哈密顿量”这一理论框架。
- 与 [[腔修饰超导]]：把驱动场量子化后，强场驱动退化为“真空强耦合驱动”，两者共享非微扰处理但 heating 机制截然不同（量子涨落 vs 经典吸收）。
- 与 [[平带]] 体系（[[魔角双层石墨烯]]）：平带天然降低强场阈值，是强场调控关联态的首选平台。
- 与 [[激子集体模式]]：强场非线性光谱是该集体模式的主要实验指纹通道。

## 林赛理解

在本知识库中，强场驱动是贯穿三篇样本文献的统一“控制旋钮”：平带体系把强场阈值压到 THz 实验可达区间（魔角起源一文）；腔修饰超导把驱动场推广到量子化真空涨落；激子集体模式指纹则以强场非线性光谱作为读出通道。因此它是“非平衡量子材料操控”主线与具体材料平台之间的接口概念。引用 5 次、优先级 mid，建议后续与 [[Floquet 工程]]、[[非平衡动力学]] 两页互链，并补足加热/预热化与 A² 项约束的量化讨论。
