# TMD异质结

## 定义定位

TMD异质结（过渡金属硫族化合物异质结，Transition Metal Dichalcogenide heterostructure）是将两种或多种不同的 TMD 单层（如 MoS₂、WSe₂、MoTe₂、NbSe₂ 等）沿法向通过范德华力堆叠而成的二维复合结构，广义上也涵盖同种材料以特定扭转角堆叠的“转角同质双层”。由于层间不存在共价键、对晶格失配高度宽容，扭转角与层间相对滑移成为全新的设计自由度；晶格失配与扭转角共同产生长周期摩尔纹，使 TMD 异质结成为构筑摩尔超晶格、平带与人工强关联物态的标准实验平台。

## 物理内涵/技术原理

1. **摩尔超晶格与平带**：双层晶格矢量之差形成拍频，摩尔周期可达数纳米至十余纳米；布里渊区折叠为极小的摩尔布里渊区，能带带宽被压缩至数十 meV 以下，动能被相互作用压制，从而涌现莫特关联、Wigner 结晶、分数陈数态与非常规超导等物相。
2. **能带对齐与层间激子**：Type-II 对齐使电子与空穴分居两层，形成具有永久面外偶极矩、寿命长的层间激子，是激子物理与光—物质调控的天然载体。
3. **谷与自旋物理**：单层 TMD 的 K/K′ 谷受破缺镜像对称保护，具有自旋—谷锁定与圆二色性；摩尔势可把谷中心重构到摩尔布里渊区拐角附近形成“隐藏谷”（hidden valleys），使表观圆二色性急剧减弱甚至消失——这是判断隐藏谷主导低能动力学的光学指纹。
4. **非常规配对通道**：摩尔平带的高态密度叠加层间交换与磁振子耦合，可支持高角动量配对通道（如 g 波，L=4），并给出特征性的电子与磁振子谱学信号。
5. **三大调控旋钮**：垂直位移场（层间极化）、载流子填充（摩尔填充因子 ν）、扭转角，共同把异质结变成一台“可编程”的凝聚态量子模拟器。

## 与现有方法/概念的关联

- 属于 [[范德华异质结]] 中最重要的一类，与 [[转角石墨烯]] 并列为 twistronics（转角电子学）的两大分支；
- 摩尔条纹的具体实现与低能描述见 [[摩尔超晶格]] 与 [[平带]]；
- 谷自由度工程承接 [[谷电子学]]，“隐藏谷—圆二色性消失”是其摩尔化版本的关键现象；
- 其关联物态输出包括 [[莫特绝缘体]]、[[Wigner晶体]]、[[分数量子反常霍尔效应]] 与 [[非常规超导]]；
- 与传统 III-V 族半导体异质结相比，TMD 异质结以弱范德华耦合换取几乎不受失配约束的堆叠自由度，这是二者在制备理念上的本质差异。

## 林赛理解

在本项目中，TMD异质结是两份样本文献共同的平台前提，而非孤立词条：

1. g-wave 超导的电子与磁振子性质一文，默认关联平带来自 TMD 摩尔双层；其 L=4 高阶角动量配对与磁振子谱是“摩尔相互作用诱导非常规配对”的具体案例；
2. 隐藏谷动力学与圆二色性消失一文，展示了摩尔势如何把谷中心从 K 点搬移到隐藏谷位置，圆二色性信号由强转弱乃至消失可作为隐藏谷参与低能输运/光学响应的判据。

因此在我的知识网络里，TMD异质结承担“平台节点”角色：向下连接平带与谷物理，向上支撑非常规超导与摩尔拓扑态的分析；后续凡遇“转角 + 硫族化合物”语境的文献，均应回链到本页建立统一物理图景。
