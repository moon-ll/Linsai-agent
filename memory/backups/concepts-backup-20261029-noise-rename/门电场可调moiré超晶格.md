# 门电场可调moiré超晶格

## 定义定位

门电场可调moiré超晶格（gate-tunable moiré superlattice）指通过静电栅极对二维材料堆叠中形成的 moiré 长周期结构进行原位电学调控的体系与手段。当两层存在晶格失配或小扭转角的二维材料（石墨烯/hBN、TMD 异质双层、扭转双层石墨烯等）垂直堆叠时，形成周期远大于原胞的 moiré 超晶格；而顶栅/背栅/双栅提供的电场不仅注入载流子填充 moiré 微带，还能通过垂直位移场调节层间耦合与能带结构，实现对超导、关联绝缘、激子等物性的开关式、可逆调控。它是“可编程量子材料”理念的典型载体，区别于依赖化学掺杂或固定转角的静态超晶格。

## 物理内涵/技术原理

其技术内涵可拆解为三个层次：

1. **Moiré 超晶格的形成**：小扭转角 θ 或晶格失配 δ 产生长程周期调制，moiré 周期约为 a/√(θ²+δ²)，原布里渊区被折叠为 moiré 迷你布里渊区，涌现准平直微带，带宽可低至十余 meV，使库仑相互作用相对动能显著增强，为关联与超导提供能带基础（参见 [[moiré平带]]）。

2. **栅极调控的两个独立通道**：(a) 载流子密度 n 直接设定 moiré 带填充因子 ν = n·A_moire（A_moire 为 moiré 原胞面积），扫描 ν 可遍历整数与分数填充处的关联绝缘态、超导穹顶、磁性相等；(b) 垂直位移场 D 调制层间电偶极与杂化强度，改变能隙大小、层极化乃至能带拓扑陈数，是双层体系中独立于 n 的第二调控轴（参见 [[位移场调控]]）。

3. **器件与表征**：典型器件采用 hBN 封装配合顶/底石墨烯栅，实现 n 与 D 的解耦扫描；常用表征包括变温输运与霍尔测量、扫描隧道谱、电容/太赫兹谱，用于绘制填充—位移场二维相图。相比磁场调控，门电场是无损耗、可集成的静电调控手段，支撑可重构电子学与量子模拟应用。

## 与现有方法/概念的关联

- 与 [[魔角双层石墨烯]]：以门电压扫描填充因子、原位切换超导—绝缘—金属相的原型体系。
- 与 [[moiré平带]]：电场调控的直接对象是平带中的关联物性与拓扑。
- 与 [[位移场调控]]：双栅独立解耦 n 与 D，构成二维相图的两个坐标轴。
- 与 [[关联绝缘态]]、[[moiré激子]]：分别在输运与光学通道上体现门电场可调性的实验窗口。
- 相对传统磁场驱动的 [[量子霍尔效应]] 体系，门电场提供静电、高速、可微缩的替代调控维度。

## 林赛理解

在本项目研究语境中，门电场可调 moiré 超晶格扮演“把哈密顿量参数变成实验旋钮”的核心平台角色：填充因子 ν 与位移场 D 作为两个可编程变量，允许在同一器件上系统考察关联、拓扑与超导机制的竞争与演化。对样本 arXiv:2606.27963 而言，该概念提示其器件依赖双栅结构完成 moiré 微带的填充扫描与层间耦合调控，相关测量数据应按 (ν, D) 相图组织。在知识图谱中，本页定位为连接 [[moiré平带]]、[[魔角双层石墨烯]] 与 [[位移场调控]] 的枢纽节点，为后续关联绝缘/超导机理的对比综述提供结构支点。
