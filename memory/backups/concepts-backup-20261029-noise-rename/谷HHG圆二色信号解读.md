# 谷HHG圆二色信号解读

## 定义定位

“谷HHG圆二色信号解读”指对具有谷自由度的二维材料（如 hBN、MoS₂、WSe₂ 等）在左旋/右旋圆偏振强激光驱动下产生的高次谐波（HHG）产率差异——即圆二色（Circular Dichroism, CD）信号——进行物理溯源与信息提取的分析框架。典型观测量为第 $q$ 阶谐波的圆二色度：

$$CD(q) = \frac{2\,(I_{+}(q) - I_{-}(q))}{I_{+}(q) + I_{-}(q)}$$

其中 $I_{\pm}$ 为右旋/左旋驱动下的谐波产率。由于谷选择定则、贝里曲率与轨道磁矩的谷反差特性，CD 信号携带谷分辨的能带结构、拓扑几何与超快电子动力学信息，是“以谐波谱识谷”的关键诊断量。

## 物理内涵/技术原理

信号产生的微观链条可分为三层：

1. **谷选择性激发**：在破缺空间反演对称的二维晶格中，K 与 K′ 谷由时间反演对称联系，谷光学选择定则使 $\sigma^{+}$ 与 $\sigma^{-}$ 光分别耦合不同谷（角动量匹配 $\Delta m = \pm 1$），造成左/右旋驱动下谷布居与电流路径的系统性差异。

2. **谐波发射的双重通道**：固态 HHG 由带内电流（电子–空穴在布里渊区中被加速并回碰）与带间极化（复合并辐射）共同贡献；谷反差的贝里曲率 $\Omega_n(\mathbf{k})$ 引入反常速度 $\dot{\mathbf{r}} = \nabla_{\mathbf{k}}\varepsilon - \dot{\mathbf{k}}\times\Omega_n$，使两个通道均带有手性印记。此外，C₃ 转动对称在圆偏驱动下施加动力学选择定则：共旋谐波仅出现在 $q = 3n+1$ 阶、反旋谐波出现在 $q = 3n+2$ 阶，$3n$ 阶熄灭。

3. **CD 的可分解来源**：解读时须区分 (a) 拓扑/几何贡献（贝里曲率、轨道磁矩、波包自旋转动）；(b) 动力学贡献（谷布居失衡、两谷退相速率差异、波包在 B 区非对称加速路径）；(c) 结构贡献（反演破缺导致的单谷响应不对称）。数值上常用“谷交换检验”（人为互换 K↔K′ 参数重算）分离谷布居项与单谷内禀响应项。

**解读陷阱**：CD 非零不等于拓扑非平庸——平庸能带的不对称性同样可产生 CD；实验上还需扣除椭偏度不完美与宏观传播效应。
