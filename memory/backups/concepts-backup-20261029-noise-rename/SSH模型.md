# SSH模型

## 定义定位

SSH模型（Su–Schrieffer–Heeger 模型）是 Su、Schrieffer、Heeger 三人于 1979 年为解释聚乙炔（polyacetylene）中单双键交替（二聚化）导致的孤子输运而提出的一维双能带紧束缚模型。模型由两套子格 A/B 构成元胞，通过交替跃迁幅度 $t_1$（胞内）与 $t_2$（胞间）连接。它是体现拓扑物态的最小晶格模型，是“拓扑绝缘体领域的氢原子”，也是本项目中讨论拓扑相位（Zak 相位、绕数）与边界态如何影响非线性光学响应、特别是高次谐波谱时的首选理论基准。

## 物理内涵/技术原理

布洛赫哈密顿量可写为 $H(k)=(t_1+t_2\cos ka)\,\sigma_x+(t_2\sin ka)\,\sigma_y\equiv \mathbf d(k)\cdot\boldsymbol\sigma$，能带为 $E_\pm(k)=\pm|\mathbf d(k)|$。其核心物理包含：

1. **手征对称性**：子格对称 $\sigma_z H\sigma_z=-H$ 禁止 $\sigma_z$ 分量，使 $\mathbf d(k)$ 被限制在 $x$-$y$ 平面内演化，能隙只能在 $\mathbf d=0$（即 $t_1=t_2,\ k=\pi/a$）处闭合。
2. **拓扑不变量（绕数）**：$\nu=\frac{1}{2\pi}\oint \partial_k\varphi(k)\,dk$，其中 $\varphi=\arg(d_x+i d_y)$。当 $|t_2|>|t_1|$ 时 $\mathbf d(k)$ 随 $k$ 扫过布里渊区绕原点一圈，$\nu=1$（拓扑相）；$|t_1|>|t_2|$ 时 $\nu=0$（平凡相）。填充能带的 [[Zak相位]] 量子化为 $\gamma=\pi\nu$，并与现代极化理论中的电极化直接挂钩。
3. **体边对应**：开边界拓扑相链的两端出现零能边缘态，波函数包络 $\psi_n\sim(-t_1/t_2)^n$ 指数局域，局域长度 $\xi=1/\ln|t_2/t_1|$ 在相变点发散，体现 [[体边对应关系]]。
4. **动力学与光学**：掺入 $\sigma_z$（在位能差）或 $\sigma_y$ 项即退化为 Rice–Mele 模型，破坏手征/反演对称、解除 Zak 相位量子化；在强场驱动下，带间电流中的反常速度项含 [[贝里联络]]，边缘态的浅能级则可显著增强低阶谐波并延伸截止能量。

## 与现有方法/概念的关联

- 与 [[高次谐波产生]]：Luu–Wörner（arXiv:1711.05783）以 SSH 型双带纳米带（锯齿边 BN 链）证明拓扑边缘态参与 HHG 并改变谱形与截止位置，是“用 HHG 探测拓扑”的早期证据链。
- 与 [[拓扑相变]]：调 $t_1/t_2$ 走过 1 即经历拓扑相变；谐波产率、偏振对带反转的敏感性被用于探测相变（arXiv:2305.02025、arXiv:2406.14946 中 AuB 体系的高压/应变驱动相变即属此类两带图像）。
- 与 [[Haldane模型]]、[[紧束缚模型]]：SSH 是其降维/去质量项的祖先；与 [[贝里相位]]、[[拓扑不变量]] 互为定义级依托。
- 与 [[动力学Bloch振荡]]/[[含时薛定谔方程]] 数值方案：SSH 链是检验实空间 TDSE 与半导体布洛赫方程代码的标准考题。

## 林赛理解

在本项目（高次谐波探测拓扑物性）中，SSH 模型扮演“可控变量分离器”的角色：真实材料（如 AuB）的能带复杂度会把拓扑信号与能色散、跃迁元、退相干等因素混叠，而 SSH 模型只保留拓扑自由度（绕数、边缘态），使谐波谱中的拓扑指纹可以被解析地归因。我把它用作三层用途：(1) 作为 TDSE/含时密度泛函类数值流程的正确性基准（绕数 0↔1 切换时谐波响应的定性跳变）；(2) 提供解释框架——Zak 相位/边缘态如何通过反常速度与带间复合进入谐波偏振与产率；(3) 反向设计探测器：先在 SSH 上确认“哪个谐波观测量对拓扑最敏感”，再到真实材料中寻找对应信号。
