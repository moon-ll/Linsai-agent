# HHG选择定则

## 定义定位

HHG选择定则（High Harmonic Generation Selection Rules）指高次谐波产生过程中，由介质与驱动场的**联合对称性**决定的谐波阶数允许/禁戒规则。最核心的一条：在具有空间反演对称性的介质中，单色线偏振驱动场只能产生**奇次谐波**，偶次谐波严格禁戒；只有反演对称性或半周期时间对称性被打破（异核分子、双色场、静电场、非平衡载流子分布等），偶次谐波才被允许。选择定则相当于体系对称性的“指纹”，也是从谐波谱反推电子动力学（布居、电流、轨道对称性）的诊断工具。

## 物理内涵/技术原理

**1. 奇次定则的对称性证明。** 对中心对称介质，$H_0$ 与反演算符 $P$ 对易，偶极算符 $P d P^\dagger = -d$；单色场满足 $E(t+T/2) = -E(t)$。于是联合操作（反演 × 半光周期平移）保持 $H(t) = H_0 - d\cdot E(t)$ 不变，若初态具有确定宇称，则偶极期望值满足 $d(t+T/2) = -d(t)$。代入傅里叶展开 $d(t)=\sum_q d_q e^{-iq\omega t}$，得 $e^{-iq\pi}=-1$，即 $q$ 只能取奇数。这与 [[HHG三步模型]] 图像一致：相邻半周期的电子轨迹互为镜像，电离与复合脉冲反相叠加，只留下奇次分量。

**2. 偶次谐波的产生机制（破缺渠道）。**

| 机制 | 破缺的对称性 | 典型场景 |
|---|---|---|
| 双色场 $\omega+2\omega$ | 半周期时间平移 | 气体/固体偶次控制、阿秒脉冲 |
| 外加静电场 | 空间反演 | 表面、偏置器件 |
| 异核分子、非中心对称晶体 | 空间反演 | CO、GaAs、hBN、MoS₂ |
| **非平衡分布（载流子注入、DC 输运电流、$\pm k$ 布居失衡）** | 反演或半周期对称性 | 固体超快输运（见样本论文） |

样本论文（arXiv:2607.27847）正属于最后一类：非平衡载流子动力学本身充当对称破缺源，使原本中心对称体系辐射偶次谐波——此时偶次强度成为非平衡电流的时域探针。

**3. 固体中的推广。** 圆偏振驱动下，$C_n$ 晶格只允许 $q = mn\pm 1$ 阶（如石墨烯的 $3n\pm1$），可用于提取能带 Berry 曲率与谷自由度信息。

**4. 分子轨道选择定则。** 对齐分子中，HOMO 的不可约表示决定谐波偏振：$\sigma$ 型轨道以平行分量为主，$\pi$ 型（如 O₂）允许垂直分量，是轨道层析（TOMOPY）的基础。
