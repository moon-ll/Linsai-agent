# Bright Squeezed Vacuum（明亮压缩真空，BSV）

## 定义定位

明亮压缩真空是一类介于“真空态”与“明亮相干场”之间的宏观非经典光场：它是压缩真空态 $S(\xi)|0\rangle$ 在高增益条件（压缩参数 $r$ 达数个 nat）下的实现，平均光子数 $\bar n=\sinh^2 r$ 可高达每脉冲 $10^8$–$10^{12}$ 量级，宏观上“明亮”到可用经典探测器直接测量；但其相干振幅（场的一阶矩）严格为零，保留了“真空”的本质。BSV 通常由无种子的脉冲参量下转换（PDC）或四波混频在高增益区产生，兼具高亮度、超热光子统计与相位敏感的压缩噪声结构，是把单光子对层面的非经典性“放大”到宏观尺度的标准载体。

## 物理内涵/技术原理

**产生机制**：脉冲泵浦的 SPDC/参量放大器在低增益时输出稀疏光子对，增益提高后多对发射相干叠加，单模近似下态为 $|\psi\rangle=\exp\!\left[\tfrac12(\xi a^{\dagger 2}-\xi^* a^2)\right]|0\rangle$，$\bar n=\sinh^2 r$ 随增益指数增长，即得 BSV。

**噪声结构**：正交分量噪声 $\mathrm{Var}\,X_\theta \propto e^{-2r}\cos^2\theta + e^{2r}\sin^2\theta$ 随探测相位（本地振荡相位/采样窗口相位）剧烈摆动：某一相位低于真空涨落（压缩），共轭相位反压缩。由于平均场为零，BSV 的压缩通常不是靠相干零拍直接读出，而是通过强度关联、相位敏感放大或电光采样等手段间接/直接表征量子噪声。样本文献一（2020-1905）系统考察了随光子数（增益）增大，$\bar n$、$g^{(2)}$、Schmidt 模式数等性质的标度行为。

**统计与多模性**：单模 BSV 呈超热统计，$g^{(2)}(0)=3+1/\bar n$，大增益时趋近 3（超过热光的 2）；谱宽可达数百纳米，signal–idle 间存在亚散粒噪声强度关联（孪生光束行为）；空间-频率-角度的多模 Schmidt 结构及高增益下的“增益聚焦”、X 形时空关联是重要宏观特征。

**应用**：SU(1,1) 非线性干涉仪、亚散粒噪声量子成像、量子增强传感，以及样本文献二（2026-2604）所代表的阿秒/亚周期分辨的量子噪声直接采样。
