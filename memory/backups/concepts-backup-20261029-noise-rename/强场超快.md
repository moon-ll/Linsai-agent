# 强场超快（Strong-Field Ultrafast Science）

研究激光场强可与原子内场（库仑场）相比拟时物质电子动力学的学科，时间分辨深入阿秒（10⁻¹⁸ s）量级。核心物理：隧穿/越垒电离、高次谐波产生（HHG）、阿秒脉冲产生与条纹测量；固体中则包括强场驱动带间隧穿、动态布洛赫振荡与亚周期电流调控。
