# 时间反演对称性破缺

## 定义定位

时间反演对称性破缺（Time-Reversal Symmetry Breaking, TRSB）指系统的宏观状态或量子序参量在时间反演算符 $\mathcal{T}$ 作用下不再保持不变。时间反演操作将时间坐标 $t \to -t$，同时反转所有速度、电流与自旋方向，是一个反幺元（antiunitary）算符。当哈密顿量本身具有时间反演不变性，但基态（如磁矩排列、配对相位、环流序）不满足该对称性时，即发生**自发破缺**。TRSB 是磁有序、手性超导、量子霍尔态等物态的核心判据，也是区分“真实磁序”与“结构各向异性”的关键物理标记，在零净磁矩体系中尤为重要。

## 物理内涵/技术原理

数学上，对自旋 1/2 体系 $\mathcal{T} = i\sigma_y K$（$K$ 为复共轭），且 $\mathcal{T}^2 = -1$，由此导出 **Kramers 定理**：保持 TRS 的体系中每条能带至少二重简并。TRSB 的直接能谱学后果即解除 Kramers 简并、产生自旋劈裂，并往往伴随非零 Berry 曲率与反常输运响应。具体机制可分几类：

1. **磁有序**：铁磁中自旋共线排列使 $\mathcal{T}$ 单独不再是对称操作；常规共线反铁磁虽破缺 $\mathcal{T}$，却常与晶格平移/旋转组合成有效“隐藏时间反演”对称性（如 $\mathcal{S} = \mathcal{T}\times$ 转动），导致许多 $T$-奇观测量为零——这正是探测上的难点。
2. **交变磁性（altermagnetism）**：$\mathcal{T}$ 与 $PT$ 同时破缺，动量空间呈现 $d$ 波型自旋劈裂且与反常霍尔效应共存，是“零净磁矩 + 真实 TRSB”的典型代表。
3. **手性/环流序**：手性超导 $\Delta = \Delta_1 + i\Delta_2$、轨道环流、量子霍尔态等打破 $\mathcal{T}$。
4. **超快动力学**：飞秒退磁、自旋翻转过程中 TRSB 随时间演化，需要时间分辨探针跟踪。

实验探测手段包括磁光克尔效应（MOKE）、$\mu$ 子自旋弛豫、圆二色（ARPES 与高次谐波圆二色）、反常霍尔/能斯特测量，以及超快光学的时间分辨跟踪。

## 与现有方法/概念的关联

- 与 [[高次谐波产生]]：HHG 作为全光学、飞秒尺度探针，其螺旋度依赖与奇/偶次谐波强度比对磁序与 TRSB 高度敏感——样本 PhysRevB 105, 155140（2022）展示了用高次谐波谱学读出反铁磁序与 TRSB 的方案，谐波偏振与圆二色信号直接编码 $T$-奇观测量，可在退磁动力学中在线监测。
- 与 [[交变磁性]]：样本 2411.00717 所述的 altermagnet 是 TRSB 研究的新载体——零净磁矩却真实破缺 $\mathcal{T}$，兼具反铁磁的高频动力学与铁磁式自旋电子学响应。
- 因果链条：TRSB → 解除 [[Kramers 简并]]/自旋劈裂 → Berry 曲率 → [[反常霍尔效应]]；其可观测性由 [[自旋-轨道耦合]] 与晶格对称性共同决定。
- 对照参考：[[反铁磁]]、[[铁磁]]、手性超导等破缺方式各异，构成“破缺强度 × 破缺方式”的分类谱系。

## 林赛理解

在本项目中，时间反演对称性破缺是贯穿高次谐波谱学与交变磁性两条主线的公共物理坐标，其角色有三：**其一，作为待探测的物理量**——我们以 HHG 的圆二色与偏振重建作为 TRSB 的超快光学代理，规避常规磁探针在时间分辨率上的短板；**其二，作为判据**——在 altermagnet 候选材料中判断体系是否真正破缺 $\mathcal{T}$（而非仅结构各向异性），直接决定零净磁矩下自旋劈裂与反常霍尔能否自洽解释；**其三，作为对照轴**——把铁磁/反铁磁/交变磁/顺磁置于 TRSB 的强弱与方式谱系上比较，支撑统一分析框架。后续补全 [[交变磁性]] 与 HHG 谱学相关页面时应与本页互链。

## 学习路径/参考

1. 基础：Sakurai《Modern Quantum Mechanics》时间反演章节（反幺元算符、Kramers 定理）；
2. 磁有序新类：altermagnetism 综述（样本 2025-arXiv:2411.00717）；
3. 超快探测：PhysRevB 105, 155140（2022），高次谐波谱学探测磁序/TRSB（样本 2022）；
4. 延伸：TRSB 超导的 Kerr/μSR 证据；Nagaosa et al., *Rev. Mod. Phys.* 82, 1539 (2010) 反常霍尔效应综述。

建议学习顺序：Kramers 简并 → 磁有序分类 → 交变磁性 → 高次谐波谱学 → 时间分辨磁测量。
