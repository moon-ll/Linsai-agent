# 贝叶斯反演

## 定义定位

贝叶斯反演是在贝叶斯统计框架下求解反问题的一类方法论体系：把待反演的物理参数视为随机变量，通过贝叶斯定理将先验知识（物理约束、历史实验、理论边界）与观测数据的似然函数融合，得到参数的**后验概率分布**。与经典最小二乘反演只输出单一点估计不同，贝叶斯反演的核心输出是完整的后验分布，因而能定量刻画解的不确定性、多解性与参数简并，天然适合处理病定性、强非线性的物理反演问题。在本项目语境中，它特指从观测数据出发、对组分相关物理量（如致密物质性质随成分/相的变化）进行的概率化参数反演。

## 物理内涵/技术原理

贝叶斯反演的数学骨架是贝叶斯定理：

p(θ|D) ∝ L(D|θ) · π(θ)

其中 θ 为模型参数向量，D 为观测数据，π(θ) 为先验分布，L(D|θ) 为似然函数，p(θ|D) 为后验分布，归一化因子（证据 Z）可用于模型比较。其技术要点可拆为三层：

1. **先验编码物理**：将因果性条件（如声速亚光速）、单调性、实验/观测下界等物理知识转化为先验约束，正则化病定问题。
2. **似然建模观测**：通常在近高斯噪声假设下构造似然，需妥善处理测量误差、系统误差与模型误差的传播。
3. **后验采样计算**：高维后验无解析解，主流手段是 [[马尔可夫链蒙特卡罗]]（Metropolis–Hastings、仿射不变系综采样、哈密顿动力学）与嵌套采样。当后验呈强相关、多峰或“香蕉形”几何结构时，固定提案的 MCMC 收敛极慢，需要几何自适应提案、并行回火或代理模型（emulator）加速——样本 2024-2404_05671 的混合几何自适应 MCMC 正是针对这一痛点的改进。

后验分析的常见产出包括可信区间、参数相关结构（corner 图）以及基于证据的模型比较，共同构成本概念区别于点估计方法的“分布即答案”哲学。

## 与现有方法/概念的关联

- 贝叶斯反演是 [[贝叶斯推断]] 在反问题场景下的具体化，后者提供其公理基础与推断逻辑。
- 其计算实现高度依赖 [[马尔可夫链蒙特卡罗]] 与嵌套采样等算法；[[先验分布]] 的选取（最大熵、分层先验）直接影响后验稳健性，是敏感性分析的重点。
- 输出层面与 [[不确定性量化]] 深度耦合：后验可信区间即参数级 UQ 的标准语言。
- 应用层面，本项目将其用于 [[致密物质状态方程]] 等组分相关物理量的数据驱动约束（样本 2023-2309.01271 属此类范式），与传统的正演建模-拟合-卡方检验流程形成对照。

## 林赛理解

在本项目的研究版图中，贝叶斯反演扮演“数据到物理的桥梁”这一双重角色：一方面它是**应用目标**——用观测数据约束组分相关的物理量，把正演模型中的自由参数收敛为带可信区间的后验知识；另一方面它是**方法研究对象**——两个样本（组分相关推断、几何自适应 MCMC）说明项目关注的不仅是“反演出什么”，还包括“如何更高效稳健地采样后验”。本概念当前引用频次仅 2、优先级 low，属于基础设施型概念：单点出现频率不高，但作为众多推断类工作的公共底座，值得在后续阅读新论文时持续回填案例与算法细节。

## 学习路径/参考

1. 入门：Gelman et al., *Bayesian Data Analysis*（第3版）第 1–3、11 章，建立先验/似然/后验语言体系。
2. 物理向：Gregory, *Bayesian Logical Data Analysis for the Physical Sciences*；再读 emcee（Foreman-Mackey+ 2013）与 dynesty 文档理解采样实现。
3. 项目内样本精读：
   - `2023-2309_01271-bayesian-inference-of-composition-dependent-`：组分相关量的贝叶斯推断范式，重点看先验构造与物理约束。
   - `2024-2404_05671-hybrid-geometry-adaptive-mcmc-for-bayesian-i`：几何自适应混合 MCMC，重点比较其与标准 emcee 在强相关后验上的收敛效率。
4. 实践：用 PyMC/emcee 复现一个低维反演例子，画出先验→后验的“收缩”过程，建立直觉。
