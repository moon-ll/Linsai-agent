# 多通道谷发射补偿假象

## 定义定位

多通道谷发射补偿假象（multi-channel valley-emission compensation artifact）是指在谷分辨光谱（如单层过渡金属硫族化合物的圆偏振分辨荧光）测量中，总信号实为若干具有不同本征谷极化度的发射通道按权重叠加的结果；当通道间权重迁移与各通道谷极化度的变化方向相反、数值上相互抵消时，宏观测得的谷极化度会呈现“稳定”或“反常”行为，从而掩盖真实通道动力学的系统性测量假象。其核心判据是：观测量（加权平均极化度）对外部参量（温度、功率、栅压）不敏感，并非源于谷弛豫被物理抑制，而是多通道贡献发生了对消。该概念在样本 2606.27963 中被引用两次，属于低频但易被忽视的数据解释陷阱。

## 物理内涵/技术原理

单层 TMD（如 WSe₂、MoS₂）中，σ⁺/σ⁻ 光子选择定则将 K/K′ 谷与发射螺旋性绑定，实验上定义谷极化度 P = (I₊ − I₋)/(I₊ + I₋)。但实测光谱通常包含多个发射通道：中性激子 X⁰、带电激子（三离子）、局域激子、声子辅助发射及被磁场/应变“点亮”的暗激子等。设第 i 个通道权重为 wᵢ、本征谷极化度为 Pᵢ，则

P_测 = Σᵢ wᵢ·Pᵢ / Σᵢ wᵢ

补偿假象的典型发生路径包括：

1. **权重迁移补偿**：升温或增大激发功率使自由激子布居向局域激子转移；局域激子因势垒抑制谷间散射而 Pᵢ 偏高，导致总 P 反常地不随温度下降。
2. **三离子混合补偿**：栅压调节费米面使三离子权重上升（单态/三重态混合使 Pᵢ 下降），同时中性激子权重下降而其 Pᵢ 上升，两者在加权平均中对消。
3. **光谱不可分辨叠加**：通道线宽交叠且能量差低于仪器分辨时，逐通道 Pᵢ 无法提取，任何依赖总 P 的谷弛豫时间拟合都会系统性偏差。
4. **再吸收与通道间转移**：高极化通道的发射被部分再吸收后经低极化通道再发射，等效于非相干传递，进一步扭曲权重分布。

数学上，只要 ∂(wᵢPᵢ)/∂x 在通道间反号（x 为扫描变量），dP_测/dx ≈ 0 就可能被误读为“谷极化鲁棒”。规避手段包括：全斯托克斯参量的光谱分辨测量、时间分辨 PL/泵浦探测以分离各通道寿命、栅压—温度—功率多维参量扫描并以多通道模型独立拟合各 Pᵢ，以及对光谱做多峰解叠后的逐通道极化分析。
