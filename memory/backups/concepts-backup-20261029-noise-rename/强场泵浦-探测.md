# 强场泵浦-探测

## 定义定位

强场泵浦-探测（strong-field pump–probe）是超快时间分辨光谱的核心实验范式：一束高峰值功率的泵浦脉冲将体系驱动至远离平衡的非线性激发态，随后以延迟时间 Δt 精确可控的（通常较弱的）探测脉冲测量体系的瞬态响应——瞬态反射率/透过率、谐波信号、光电子谱等。“强场”指泵浦强度足以超越线性响应区间，直接参与并重塑体系动力学：激发高密度载流子、驱动相干声子乃至诱发结构相变。由此，泵浦光从“被动的测量扰动”转变为“主动的物态调控手段”，使该方法成为研究非平衡量子物态与光致相变的关键工具。

## 物理内涵/技术原理

**基本配置**：飞秒激光源（Ti:宝石放大器或 OPCPA）经分束镜分为两路，强泵浦路激发样品，探测路经电动延迟线改变光程差；配合斩波器与锁相放大提取差分信号 ΔR/R(Δt)，时间分辨率由脉宽决定（典型 20–150 fs），时间窗口可从飞秒延伸至纳秒。**强场特征**体现在泵浦峰值电场已可与晶体内场或跃迁偶极相互作用能标相比拟（约 10⁷–10⁹ V/m），由此打开多条非热调控通道：

1. **电子激发通道**——带间跃迁注入高密度载流子，瞬时改变屏蔽与化学势，可“熔化”电荷序、轨道序或超导序；
2. **非线性声子通道**——中红外泵浦共振驱动红外活性声子，经非简谐耦合牵引拉曼活性侧带模式，实现无需升温的相干晶格操控（nonlinear phononics）；
3. **周期性驱动/Floquet 通道**——强场对布洛赫态进行周期性缀饰，瞬时重塑能带色散、能隙乃至拓扑性质。

探测端可选择瞬态反射率、瞬态二次谐波（对中心对称/对称性破缺极为敏感）、时间分辨 ARPES 等，从而构建“延迟时间—注量—泵浦频率—温度”多维参数空间，分离电子、声子与自旋的不同时间尺度响应。强场区实验需特别注意热效应、多脉冲累积与样品损伤的甄别，通常依赖注量标度律与重复频率依赖测量加以分离。

## 与现有方法/概念的关联

- 强场泵浦-探测是 [[超快光谱]] 在非线性驱动区的自然延伸，与其弱场（小信号）极限形成互补；
- 其非热相变机制直接联系 [[非线性声子学]] 与 [[Floquet 工程]] 两大调控路线；
- 探测端常与 [[瞬态二次谐波]]、时间分辨 ARPES 联用，追踪 [[亚稳相]] 与光致隐藏相的对称性及序参量演化；
- 与平衡态表征（静态衍射、静态 SHG、输运）互补，为相图提供非平衡时域切片。
