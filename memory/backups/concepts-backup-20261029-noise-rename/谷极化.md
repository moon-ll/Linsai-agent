# 谷极化

## 定义定位

谷极化（valley polarization）指当材料能带在布里渊区中存在多个等效能谷（valley，即能量极值点，如过渡金属硫族化合物单层的 K 与 K′ 谷、空穴系统的 Γ 与 K 谷）时，载流子在各谷中的占据数不相等的状态，通常用谷极化度 $P_v=(n_1-n_2)/(n_1+n_2)$ 定量描述，$|P_v|=1$ 对应完全极化。它与自旋极化构成类比：把“谷指标”这一内部自由度激活为可写入、可读出、可调控的信息载体，是谷电子学（valleytronics）的核心态，也是判定时间反演/反演对称性破缺与多体基态性质的重要谱学探针。

## 物理内涵/技术原理

谷极化的产生、弛豫与读出依赖三类机制：

1. **谷选择性光学选择定则**：在破缺反演对称且自旋-轨道耦合强的二维晶体（MoS₂、WSe₂ 单层等）中，K 与 K′ 谷的带边跃迁分别与 σ⁺/σ⁻ 圆偏振光锁定，圆偏振泵浦可定向注入某一谷的载流子或激子，形成非平衡谷极化；稳态幅度由谷间散射速率与辐射/非辐射弛豫竞争决定。
2. **谷塞曼效应与磁场调控**：垂直磁场下，贝里曲率与自旋轨道耦合使 K/K′ 谷获得符号相反的有效 g 因子劈裂 $\Delta E = g_v\mu_B B$（单层典型量级为 −4 ~ −20）；低温强场下热占据差直接给出平衡谷极化，磁场还可对掺杂体系的多体谱（如费米极化子精细结构）做连续调谐。
3. **应变与交换场**：形变势与伪磁场移动谷能量；磁近邻/交换场可零外场劈裂谷简并，而在手性磁畴或畴壁附近，轨道磁化与量子几何响应（贝里曲率、量子度规）可与谷自由度耦合，提供新的劈裂与锁定通道。

读出手段包括圆二色性谱与圆分辨 PL、时间分辨 Kerr 旋转（探测谷相干）、以及基于贝里曲率的谷霍尔电学探测；谷寿命 $\tau_v$ 受声子辅助谷间散射与缺陷浓度制约。
