# 自旋劈裂

## 定义定位

自旋劈裂（spin splitting）指固体能带中原本自旋简并的能级沿自旋自由度在能量上发生分离的现象，通常以劈裂能 Δ 或动量空间劈裂量 2|αk| 来量化。按物理来源可分为：外磁场引起的 Zeeman 劈裂、自旋轨道耦合在非中心对称体系中引起的 Rashba/Dresselhaus 劈裂、磁有序交换作用引起的交换劈裂，以及交错磁体（altermagnet）中零净磁矩条件下的动量依赖自旋劈裂。一个体系是否存在自旋劈裂、劈裂的对称性与大小，直接决定其能否实现电学自旋操控、自旋流产生与拓扑非平庸响应，是自旋电子学与拓扑物态研究的核心观测量之一。

## 物理内涵/技术原理

自旋劈裂的微观机制与对称性约束可归纳为以下几类：

1. **Zeeman 机制**：外磁场 B 使自旋能级移动 ±gμ_B B/2，各向同性且小。
2. **自旋轨道耦合机制**：结构反演不对称给出 Rashba 项 H_R = α_R(σ_x k_y − σ_y k_x)，体反演不对称给出 Dresselhaus 项。能带在动量空间中劈裂并伴随螺旋式自旋织构；Kramers 简并仅保留在时间反演对价的 k 与 −k 处，因而是“动量分辨”而非“能量整体”的劈裂。
3. **交换劈裂**：铁磁体中内禀交换场使自旋上/下通道整带错开 Δ_ex，伴随时间反演对称性破缺与净磁矩。
4. **交错磁体自旋劈裂**：在净磁矩严格为零的反铁磁中，自旋群对称性（而非完整 SU(2) 自旋转动）允许动量依赖的交换场，形成 d 波、g 波等各向异性自旋劈裂带。这类劈裂决定了对称性受限方向上的电偶极自旋共振频率与选择定则（对应样本 2026-2608_25265 电激励自旋共振方案）。
5. **Floquet 光致劈裂**：周期驱动（如圆偏振光）通过 Floquet 准能带在带隙处等效注入光致质量项/交换场，可在原本非磁性体系中诱导自旋劈裂并引发反常霍尔响应与拓扑相变（对应样本 2026-2606_26667）。

分析流程上，通常先写出低能有效哈密顿量中的劈裂项（α k·σ 型或 Δ_ex σ_z 型），再核对体系对称性（PT、镜面、自旋群操作）判断劈裂允许的方向与阶数，最后用劈裂量估计共振频率、Berry 曲率或拓扑不变量的变化。

## 与现有方法/概念的关联

- 自旋劈裂是 [[自旋轨道耦合]] 在非中心对称体系中的直接能带后果（Rashba/Dresselhaus 型），也是 [[Rashba 效应]] 讨论的核心量。
- 与 [[反常霍尔效应]]：自旋劈裂打破自旋简并后，SOC 使两支能带携带相反 Berry 曲率，净 Berry 曲率贡献反常霍尔电导；Floquet 光致劈裂是本项目中实现非磁性体系反常霍尔输出的通道。
- 与 [[交错磁体]]：零净磁矩下的动量依赖自旋劈裂是交错磁区别于传统反铁磁体的标志性特征。
- 与 [[自旋共振]] / [[自旋流]] 产生：劈裂能隙决定共振频率窗口与偏振选择性，是电学驱动方案的设计依据。

## 林赛理解

在本项目“电场驱动 + 拓扑/磁序”的自旋动力学框架里，自旋劈裂不是背景参数，而是主要调控把手。其一，交错磁体中各向异性的自旋劈裂决定了电激励自旋共振的频率窗口、偏振选择与功率效率（2026-2608_25265 的核心图像）；其二，Floquet 光驱动诱导的光致自旋劈裂是我们在非磁性体系中打开拓扑能隙、产生反常霍尔响应的路径（2026-2606_26667 的机制）。我在建模时的习惯做法是：先在低能有效哈密顿量中显式写出劈裂项并核对对称性约束，再讨论动力学与拓扑后果；同时提醒自己不要把所有自旋劈裂默认为 Rashba 型——交错磁劈裂与 Floquet 劈裂的动量结构与时间反演性质都与之不同，混淆会导致选择定则判断错误。

## 学习路径/参考

1. 入门：黄昆《固体物理》或 Ashcroft & Mermin 中自旋简并、Zeeman 效应章节。
2. SOC 型劈裂：Rashba (1960) 原始文献；Manchon et al., *Nat. Rev. Mater.* (2015) 自旋轨道电子学综述。
3. 交错磁体：Šmejkal, Sinova, Jungwirth, *Phys. Rev. X* 12, 040501 (2022)；后续交错磁自旋劈裂与自旋动力学的系列工作。
4. Floquet 工程：Oka & Aoki, *PRB* (2009)；Rudner & Lindner, *Nat. Rev. Phys.* (2020)。
5. 项目内样本：arxiv 2026-2608_25265（电激励自旋共振，交错磁）、arxiv 2026-2606_26667（Floquet 拓扑相与反常霍尔）。
