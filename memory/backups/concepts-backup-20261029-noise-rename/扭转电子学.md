# 扭转电子学

## 定义定位

扭转电子学（Twistronics，twist angle + electronics）是指通过控制二维材料层层间堆叠的相对扭转角来调控体系电子态与物性的研究方向。它将“扭转角”提升为一个全新的、可连续调节的实验自由度，与传统依赖化学成分、静电掺杂或应变的调控手段形成互补。2018 年魔角双层石墨烯中发现平带超导与关联绝缘态后，该方向迅速成为凝聚态物理与二维材料研究的核心范式，研究对象涵盖扭转石墨烯、扭转过渡金属硫族化合物（tTMD）以及各类扭转/失配异质双层。

## 物理内涵/技术原理

物理核心是**莫尔超晶格与莫尔势**。两层晶格常数为 a 的材料相对扭转 θ 后形成长程调制结构，莫尔周期约为 λ ≈ a/(2 sin(θ/2))，θ 越小周期越大，小角度下可达十纳米量级。该超晶格在动量空间把能带折叠进微型布里渊区，层间杂化与莫尔周期势共同重塑低能电子结构，主要体现为三条主线：

1. **平带与强关联**：石墨烯体系在魔角（约 1.1°）附近狄拉克费米速度被强烈压制，形成带宽仅数 meV 的平带；动能被“冻结”后库仑相互作用主导，涌现超导、莫特/关联绝缘态、磁性、陈绝缘体与奇异金属行为。
2. **深莫尔势与人工晶格**：在扭转 WSe₂、tMoTe₂ 等 tTMD 中，层间原子重构使莫尔势深度可达数十至上百 meV，远超室温热能；电子被局域于莫尔元胞内的特定堆叠位点，形成可设计的量子点阵列，用于模拟 Hubbard 模型、Wigner 晶格与分数量子化态，并衍生出可调的莫尔激子。
3. **对称性调制与非线性光学**：扭转与层间滑移普遍改变点群并常破坏反转对称，使二次谐波生成（SHG）等非线性响应成为表征扭转角、层间耦合与对称性破缺（如电荷不平衡诱导的 SHG 增强）的灵敏探针；小角度下的原子重构（畴—畴界结构）进一步调制局域对称性。

技术上，该方向依赖干法转移与“撕-叠”（tear-and-stack）组装、低温输运与量子振荡、纳米 ARPES、扫描隧道显微/光谱以及非线性光学显微等多参量手段的协同。

## 与现有方法/概念的关联

- 与 [[莫尔超晶格]]：莫尔超晶格是扭转电子学的结构基础，扭转角是决定其周期与对称性的主控参数。
- 与 [[魔角石墨烯]]：作为领域起点性体系，提供了平带超导与关联绝缘态的范式证据。
- 与 [[平带]]：平带物理是扭转电子学通往强关联的桥梁，进一步连接 [[平带超导]] 与拓扑平带研究。
- 与 [[过渡金属硫族化合物]]：tTMD 凭借深莫尔势与强自旋-轨道耦合，成为人工 Hubbard 晶格与莫尔激子的关键平台（对应 2021 年深莫尔势样本）。
- 与 [[二次谐波生成]]：SHG 对反转对称性破缺敏感，可读出扭转角、层间电荷转移与关联序（对应 2025 年电荷不平衡诱导 SHG 样本）。
- 与 [[范德华异质结]]：干法转移堆叠是两者共同的技术底座。

## 林赛理解

在本项目知识库中，扭转电子学承担“结构—对称性—物性”链条的中枢纽带角色：一方面，它解释了扭转 TMD 深莫尔势类工作（2021，arXiv:2008.07696）为何能构造人工量子点阵列并模拟 Hubbard 物理；另一方面，它为电荷不平衡诱导 SHG 类工作（2025）提供对称性分析框架——扭转堆叠与层间电荷再分布共同决定非线性光学张量的非零分量与强度。后续笔记凡涉及莫尔周期、魔角、平带或层间对称性破缺，均应回链本页，以保持“扭转角作为调控自由度”这条主线在知识库中的一致性。

## 学习路径/参考

- 术语与理论起点：S. Carr et al., "Twistronics: Manipulating the Electronic Properties of Two-Dimensional Layered Structures through Twist Angle", PRL 118, 116401 (2017)。
- 魔角里程碑：Cao et al., Nature 556, 43 & 80 (2018)。
- 深莫尔势实验：Shabani et al., "Deep Moiré Potentials in Twisted Transition Metal Dichalcogenide Bilayers", PRX 11, 011005 (2021)（即样本 arXiv:2008.07696）。
- 对称性与非线性探针：本项目样本 ae3557（2025，电荷不平衡诱导二次谐波生成）。
- 建议路径：先掌握双层几何与莫尔周期公式 → 平带形成机制（连续模型）→ 强关联物性（Hubbard 视角）→ 点群对称性与 SHG 选择定则，逐层递进。
