# moiré强场探针

## 定义定位

「moiré强场探针」指以强场光与物质相互作用——强飞秒近红外/中红外脉冲、固体高次谐波产生（HHG）、强场电离等——作为全光学读出手段，探测转角双层石墨烯（TBG）、TMD 异质结等莫尔超晶格体系中由转角角调控的平带、拓扑与自旋/能谷织构的实验—理论交叉范式。与弱场探针（ARPES、STM、输运测量）相对，它利用阿秒—飞秒时间尺度的带内电流与带间极化响应，把莫尔角度、平带填充、对称性破缺与关联重构等信息编码进谐波产额、偏振态与圆二色谱中。该概念位于阿秒强场物理与转角电子学（twistronics）的交界处，在本知识库中由三篇样本（HHG 自旋织构判据、TBG 实时 TDDFT、飞秒近红外烧蚀阈值）共同支撑，目前引用频次仅 3 次，属低优先级但方向新兴的观察类概念。

## 物理内涵/技术原理

**（1）莫尔平带的强场响应增强。** 转角形成长周期莫尔势，布里渊区折叠为小型 mini-BZ，平带处态密度高、有效质量大、带宽被压低至 meV 量级。带间极化率对带隙有强反比依赖，小带隙的莫尔平带在强场下可产生显著增强的非线性极化；同时 mini-BZ 尺寸缩小限制了纯带内电流的谐波截止阶数，使固体 HHG 中带内与带间通道的相对权重随转角角系统性变化——这本身就是“转角角光谱计”的物理基础。

**（2）全光学读出机制。** 固体 HHG 可类比扩展的三步模型：强场驱动布洛赫波包在能带间隧穿与加速，复合/去极化辐射高次谐波。谐波产额谱携带能带色散信息，而偏振分辨与左/右圆偏光二色谱对贝里曲率分布、镜面对称性与自旋织构的奇偶性高度敏感——样本一指出特定自旋织构会在谐波偏振与二色信号中留下可识别的“判据”（hallmarks），实现无需自旋分辨电子谱仪的自旋织构读出。

**（3）第一性原理模拟支柱。** 莫尔超胞在通用转角角下含数千至上万个原子，样本二将实时 TDDFT（rt-TDDFT）扩展到该尺度：在激光脉冲下传播 Kohn–Sham 轨道、取含时电流的傅里叶变换得到谐波谱，从而在计算上验证“莫尔体系 HHG 可行性”并预言转角/填充依赖，是连接实验与理论的核心工具。

**（4）探测剂量窗口与损伤边界。** 样本三的飞秒近红外烧蚀阈值测量界定了探针通量的上限：强场探针必须在低于多光子/雪崩电离触发烧蚀的窗口内工作；莫尔平带的强吸收与热载流子动力学可能显著移动该阈值，需要针对每个转角角与封装条件重新标定，否则“探针”会退化为“写入/破坏”。

## 与现有方法/概念的关联

- 与 [[高次谐波产生]]：HHG 是本概念的核心读出通道，莫尔平带提供共振增强与转角可调性，是固体 HHG 从拓扑绝缘体、半导体向强关联平带体系的自然延伸。
- 与 [[莫尔超晶格]]／[[转角双层石墨烯]]：作为被探测对象提供平带、关联与自旋织构等目标自由度，反向要求强场探针具备转角角分辨与对称性分辨能力。
- 与 [[实时含时密度泛函理论]]：提供数千原子超胞下强场响应的正向模拟，是判别谐波信号中“莫尔特征” versus 基底/衬底贡献的必要手段。
- 与 [[贝里曲率]]、[[自旋织构]]：谐波圆二色与偏振谱的直接观测量，衔接“全光学拓扑表征”这一更成熟的方向。
- 与 [[飞秒激光烧蚀]]：给出非破坏探测的通量上界，构成实验设计的硬约束。
- 相对 ARPES/STM 等弱场探针：无需超高真空与表面终端、时间分辨率高 3–6 个量级，但空间分辨与动量直接成像能力弱，二者互补。

## 林赛理解

在本项目中，moiré 强场探针是“全光学拓扑/自旋织构表征”路线向强关联平带体系的扩展候选。它的价值在于：把我在 HHG 判据方向上积累的偏振/二色谱分析工具直接迁移到转角体系，用 rt-TDDFT 的大超胞计算结果校准可观测信号（转角角依赖、平带共振增强），并以烧蚀阈值数据约束实验通量窗口，形成“可探测、可模拟、不破坏样品”的闭环。鉴于当前语料仅 3 次引用，我将其标记为低优先级观察项：不投入专门推导，但在每次 HHG-on-moiré 新实验出现时回填；潜在申请角度是“谐波二色谱作为转角角与平带填充的无接触光度计”。
