# 交变磁体（Altermagnet）

继铁磁体、反铁磁体之后被划分出的第三类共线磁性体：宏观磁化为零（似反铁磁），但因晶体对称性（而非自旋轨道耦合的自旋劈裂）在 ±k 处产生自旋劈裂能带（似铁磁），由 Šmejkal 等人于 2021-2022 年系统提出。候选与实证材料包括 MnTe、CrSb 等，按对称性分为 d 波、g 波等序。物理意义：零杂散场却具备反常霍尔响应、自旋流与自旋劈裂输运，兼具反铁磁的 THz 快动力学与铁磁的功能性，是自旋电子学与拓扑物态研究的前沿材料类。

## 强场超快视角

HHG 与超快磁光测量正成为探测交变磁性对称性与自旋动力学的新探针（本库多篇论文笔记涉及 altermagnetic MnTe/CrSb/CoF₃ 的高次谐波与瞬态磁光研究）。
