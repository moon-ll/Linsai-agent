# 非共振驱动

## 定义定位

非共振驱动（off-resonant driving，亦称高频驱动）指驱动场光子能量 ℏω 显著大于或远离系统相关跃迁能量（带隙 E_g、带宽 W、激子能量等）的周期性驱动方式，即 ℏω ≫ max(E_g, W) 或至少避开所有强跃迁通道。在该区间内，真实光子吸收与伴随的载流子激发、加热被强烈抑制，系统与外场的耦合以虚光子过程为主，外场的作用退化为对能带的“光修饰”（photon dressing）：重整带隙、有效质量、自旋-轨道耦合与量子几何量。它是 [[Floquet 工程]]中最常用、物理图像最清晰的参数区间，也是光致拓扑相变与光致铁谷调控的默认工作点，本项目两篇样本论文均以此为前提。

## 物理内涵/技术原理

对周期驱动哈密顿量 H(t) = H₀ + Σ_m V_m e^{imωt}，Floquet–Bloch 理论将问题转入扩展的 Sambe 空间（动量 ⊗ 光子扇区），准能谱由块矩阵 H_F^{mn} = H₀δ_{mn} + mℏωδ_{mn} + V_{m−n} 决定。非共振条件使各光子扇区的复本带在能量上远离交叠，共振通道关闭，可通过简并微扰（van Vleck / 1/ω 展开）积掉光子扇区，得到静态等效哈密顿量：

H_eff = H₀ + Σ_{m≠0} [V_{−m}, V_m]/(mℏω) + O(1/ω²)。
