# 阿秒脉冲串

## 定义定位

阿秒脉冲串（Attosecond Pulse Train, APT）是一串脉宽为阿秒（10⁻¹⁸ s）量级、以驱动激光的半光学周期为间隔（800 nm 驱动时约 1.3 fs）周期性排列的极紫外（XUV）超短光脉冲序列。它与[[孤立阿秒脉冲]]相对，是[[高次谐波产生]]（HHG）最自然的时域输出形态：频域上，APT 对应于一组相位锁定、以 2ħω 等间隔排列的奇次谐波；时域上，这组谐波的相干叠加在每个半周期坍缩为一个阿秒级光猝发。本项目两个样本文献——rainbow-RABBITT 探测相干 Rabi 动力学与腔控 HHG——均以 APT（或其梳状对应物）为核心光源。

## 物理内涵/技术原理

APT 的物理根源是强场 HHG 的三步模型：每半个光学周期，驱动场隧穿电离一个电子波包，波包在连续态中被加速、回归并复合，辐射出一个数百阿秒的 XUV 猝发。由于电场每半周期反转、且气体介质的中心对称性抑制偶次谐波，周期性重复的发射在频域形成锁相奇次谐波梳（线间隔 2ω），经傅里叶合成即得半周期间隔的脉冲串。频域与时域通过傅里叶对偶互译：谐波间的相对相位（群延迟）决定时域脉冲的形状与发射时刻，由长短量子轨迹带来的正“阿秒啁啾”（高能光子发射更晚）会拉伸单脉冲宽度；谐波截断（cutoff）决定脉冲串的谱包络，脉冲串的持续时间决定梳线线宽。

谐波锁相使 APT 与弱 IR 延迟场共同作用时，相邻奇次谐波各通过“吸收/发射一个 IR 光子”到达同一偶次 sideband 的两条双光子路径发生干涉，sideband 产额随延迟以 2ω 频率振荡——这正是 [[RABBITT]] 重建谐波相位（群延迟）的基础。在腔增强方案中，光学腔内循环的飞秒脉冲序列将 HHG 的锁相谐波拓展为窄线宽、长时相干的 XUV 频率梳，等效于在腔重复频率尺度上“重排”脉冲串。

## 与现有方法/概念的关联

- [[高次谐波产生]]：APT 是 HHG 的默认时域产物；三步模型、轨迹相位与截止定律是理解 APT 的前提。
- [[RABBITT]]：以 APT + 弱 IR 为探针，通过 sideband 的 2ω 拍频提取相邻谐波相位差与群延迟，是 rainbow-RABBITT 探测相干 Rabi 振荡的方法学主干。
- [[孤立阿秒脉冲]]：通过振幅门、偏振门、双光学门等选通技术从脉冲串中截取单个半周期猝发，消除半周期模糊。
- [[光学频率梳]]：腔控 HHG 将 APT 的锁相谐波梳置入谐振腔，获得 XUV 频率梳——这是腔方向样本的物理落点。

## 林赛理解

在本项目语境里，APT 对我而言不是“产品”而是“周期性阿秒时钟”：RABBITT 一线工作利用相邻谐波的相干拍频读出电子动力学（如相干 Rabi 振荡）的相位与时间信息，腔控 HHG 一线工作则关心如何在腔内维持并相位锁定这样的梳状 XUV 输出。两个方向共享同一组傅里叶对偶词汇——“锁相谐波梳 ⇄ 半周期脉冲串”，以及“谱相位 ⇄ 发射时刻”。因此我读这两类文献时，应重点跟踪：谐波相对相位如何被介质/腔/强驱动场修改，以及这些相位扰动如何在 RABBITT 测量中以群延迟或拍频相位的形式显影。后续需补齐阿秒啁啾补偿与腔内相位自洽两块知识。
