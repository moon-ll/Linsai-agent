# 三步模型

## 林赛的理解

三步模型是理解气体高次谐波产生（HHG）的基石。Corkum 于 1993 年提出，用半经典图像把强场下原子的 HHG 过程拆成三个连续步骤，物理直觉极其清晰。我每次给学生讲 HHG，都从这个模型开始。

## 核心要点

**三步**：
1. **隧穿电离**（Tunneling Ionization）：强激光场弯曲原子势垒，价电子通过隧道效应逸出，出现在连续态。
2. **加速**（Propagation）：自由电子在随时间变化的激光电场中被加速，获得动能。电子在电场过零点附近返回原子核的概率最高。
3. **复合**（Recombination）：电子返回母离子，以高能光子形式释放多余能量。光子能量 = 电离势 I_p + 电子动能。

**截止定律**（Cutoff Law）：最大谐波光子能量 ħω_cutoff = I_p + 3.17 U_p，其中 U_p = e²E²/4mω² 是有质动能。

## 触发上下文

> 三步模型是固体 HHG 讨论中常被引用的对照——固体 HHG 的机制（带间跃迁 + 带内电流）与气体三步模型有本质区别，但"电离-加速-复合"的概念框架仍可类比迁移。
