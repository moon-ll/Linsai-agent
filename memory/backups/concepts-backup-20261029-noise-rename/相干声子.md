# 相干声子

## 定义定位

相干声子（coherent phonon）指晶体中大量原子以**确定相位关系**集体振荡所形成的声子模式，通常由飞秒激光泵浦脉冲激发产生。与热平衡下相位随机、非相干的热声子不同，相干声子在整个激发区域内保持宏观统一的相位，晶格像“被敲击的音叉”一样整体振动，频率处于 THz 频段。它在时域上表现为可被光学探测的周期性振荡信号，是超快光谱学连接“微观晶格振动”与“宏观结构动力学”的核心对象，也是“以光控晶格、以晶格控物性”这一超快调控范式的物理载体。

## 物理内涵/技术原理

量子力学上，相干声子对应声子的相干态（位移谐振子波包）；经典图像即晶格坐标围绕平衡位置的集体简谐振荡
