# 光致相变

## 定义定位

光致相变（photoinduced phase transition）指材料在光激发下从一种物相（结构序、电子序、磁性序或拓扑序）转变为另一种物相的现象。与依赖温度、压力等热力学参量的常规相变不同，光激发是一种非平衡、非热乃至“超越热力学路径”的调控手段：它可以在飞秒—皮秒尺度上重塑体系的自由能曲面，把系统推入常规平衡路径难以到达的亚稳态或“隐藏相”。在二维磁性材料、电荷密度波、过渡金属氧化物等体系中，光致相变已成为获取和操控新奇物态的重要途径，也是本项目“外场调控低维物相与磁性”主题下的核心概念之一。

## 物理内涵/技术原理

从微观机制看，光致相变大致可分为三类通道：

1. **电子激发主导**：光生载流子改变成键与电荷屏蔽，使原有结构失稳，典型如 Peierls 型畸变与电荷密度波（CDW）序的“光致熔化”、VO₂ 的光致绝缘体—金属转变。此时相变由电子布居而非晶格温度驱动，具有阈值性与超快特征。
2. **晶格/声子通道**：红外泵浦共振激发特定振动模，相干声子沿反应坐标定向“踢”过势垒，实现路径选择性相变（如光诱导铁电化），区别于全局加热。
3. **自旋态通道**：光激发改变局域自旋态（自旋交叉体系低自旋→高自旋），或通过磁光耦合、光生载流子间接调制超交换/双交换作用，诱导铁磁—反铁磁等磁相转变。

理论描述需要非平衡框架：含时密度泛函（TDDFT）、非平衡格林函数、经验温升/有效温度模型等，并配合第一性原理评估末态相的形成能、势垒与声子稳定性。关键表征量包括激发通量阈值、可逆性与滞回、亚稳态寿命（从皮秒到宏观时标跨越十余个量级）。在二维磁性体系中，光还可经由衬底光电压、光热梯度、层间交换调制等次级效应间接触发相变，分析时必须把真正的非热机制与激光热效应区分开。

## 与现有方法/概念的关联

- 与 [[亚稳态]]：光致相变是制备与读取亚稳相/隐藏相的核心手段，样本来源 1（PRB 113, 035113，光控亚稳相）即为典型实例。
- 与 [[电场调控磁性]]：光激发与静电门控是平行的非热调控旋钮，样本来源 3（电场切换层间磁构型）展示了“电学通道”，两者常在同一体系中互补对照。
- 与 [[二维磁性材料]]：低维体系势垒小、表面效应强，对光场响应显著，是光致磁性相变的高产平台。
- 与 [[超快光谱]]、[[非平衡态动力学]]：泵浦—探测技术是判定相变时间尺度、中间态与路径的主要实验手段。
- 相邻概念：[[磁光效应]]、[[电荷密度波]]、[[自旋交叉]]、[[隐藏相]]。

## 林赛理解

在本项目文献库中，光致相变被引用 6 次，与三篇样本（光控亚稳相、磁性参数调谐、电场切换层间磁性）共同构成“光/电双通道外场调控”的叙事骨架。我把它定位为连接第一性原理计算（末态亚稳相能量与转变势垒）和超快实验（泵浦—探测判定相变路径）的桥梁概念：计算回答“光能把体系带到哪里、末态稳不稳”，实验回答“走什么路径、多快到达”。后续写综述章节时，可用该概念统摄“非热路径到达亚稳磁相”这一线索，并特别留意甄别文献中激光热效应伪装成非热相变的情形，这是该领域综述最易踩的坑。
