# 超快磁光

## 定义定位

超快磁光（ultrafast magneto-optics）是超快激光科学与磁学交叉形成的研究方向：利用飞秒—皮秒量级的泵浦—探测技术，借助磁光效应（法拉第效应、磁光克尔效应及其非线性推广）对磁性材料中自旋与磁有序的超快动力学进行时间分辨测量与相干调控。其典型研究对象包括超快退磁、全光磁翻转、相干磁振子、反铁磁太赫兹自旋动力学以及磁性高次谐波产生等，时间分辨率可达数十飞秒，是连接微观自旋–轨道耦合与宏观磁化动力学的关键实验窗口。在本知识库中，它充当“对称性分类 → 可观测信号”这一链条上的探测端枢纽概念。

## 物理内涵/技术原理

线性磁光响应源于自旋–轨道耦合诱导的介电张量非对角元 ε_xy ∝ M（磁化强度），时间分辨磁光克尔实验（TR-MOKE）以泵浦脉冲激发、探测脉冲读出 ΔM(t)，可在飞秒尺度追踪退磁—回复全过程。经典图像包括三温模型（电子、晶格、自旋浴之间的能量弛豫）、超扩散自旋流与 Elliott–Yafet 型自旋翻转散射等退磁机制。

非线性与超快方向的延伸尤为重要：

- **磁性高次谐波**：磁有序本身破坏时间反演对称性，使谐波强度在 M 反转时呈现奇/偶选择定则，谐波符号随磁化翻转可成为磁序的“指纹”。
- **纯磁学路径**：在具有空间反演对称的磁体中，电偶极高次谐波被禁戒，此时磁有序（经由磁偶极与各向异性通道）可独立承载谐波发射，使高次谐波谱学成为“纯磁性”的谱学探针——这正是样本 2601.20777 提出的路线。
- **对称性判据**：自旋点群将自旋空间旋转与实空间操作解耦，可系统判定哪些磁光/非线性响应张量元被对称性禁戒或允许，为超快磁光实验提供选择定则层面的预言。

## 林赛理解

在本项目的知识体系中，超快磁光扮演的是“把对称性变成可测量”的角色。样本一（自旋点群，arXiv:2307.12784）提供的是静态对称性分类语言，而超快磁光／磁性高次谐波则是这些分类在时间维度上的实验出口：自旋点群判定禁戒的线性磁光响应，可能恰好在非线性谐波通道中“显形”。样本二（纯磁学高次谐波，arXiv:2601.20777）进一步表明，即便在线性磁光很弱甚至消失的中心对称磁体（如部分反铁磁／交替磁体候选）中，磁序仍可独占谐波发射通道。因此我把本概念定位为筛选与检验自旋点群候选材料的诊断工具：对称性预言 → 高次谐波信号验证的闭环。当前引用频次低（2），先作为枢纽概念挂链，待非线性光学笔记扩充后再深化。
