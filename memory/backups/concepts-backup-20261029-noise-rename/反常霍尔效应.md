# 反常霍尔效应

## 定义定位

反常霍尔效应指在不存在外加磁场（或外磁场洛伦兹力贡献无法解释）的条件下，磁性材料中伴随自发磁化而出现的横向霍尔响应：沿纵向通以电流时，横向产生正比于磁化强度的电压。该现象由 Edwin Hall 于 1881 年在铁磁体中发现，因“无磁场却有霍尔信号”而得名“反常”。其横向电阻率通常远超普通霍尔效应量级，且符号与符号随材料磁有序状态改变。现代凝聚态物理将其本质定性为：磁有序破坏时间反演对称性后，由贝里曲率驱动的电子横向输运。

## 物理内涵/技术原理

在半经典输运框架（Xiao–Chang–Niu）中，布洛赫电子的群速度除能带色散梯度外，还包含反常速度项：

- ṙ = (1/ħ)∇ₖεₙ(k) − (e/ħ) **E** × **Ω**ₙ(k)

即使没有磁场，电场通过贝里曲率 Ωₙ(k) 也能产生垂直于电场的横向速度分量。本征反常霍尔电导由占据带贝里曲率的布里渊区积分给出：

- σₓᵧ = −(e²/ħ) Σₙ ∫ (dᵏk/(2π)ᵏ) fₙ(k) Ωₙ,z(k)

对称性逻辑是其核心：时间反演要求 Ω(k) = −Ω(−k)，空间反演要求 Ω(k) = Ω(−k)；二者共存时 Ω ≡ 0。磁化破坏时间反演，使贝里曲率在动量空间不再成对相消，积分得以非零。除本征项外，还存在 skew-scattering（斜散射）与 side-jump（侧跳）两类杂质散射外在机制，三者的实验分解长期是难点。极端情形下，二维体系中贝里曲率积分量子化为陈数，给出量子反常霍尔效应（Haldane 模型；Cr 掺杂 (Bi,Sb)₂Te₃ 的实验实现）；三维外尔半金属中作为贝里曲率单极源的外尔点则可导致巨大反常霍尔响应。此外，反常霍尔效应与磁光克尔效应共享同一 Kubo/贝里曲率语言——前者是直流极限，后者是光频极限。

## 与现有方法/概念的关联

- [[贝里曲率]]：反常霍尔效应是贝里曲率最直接的直流输运探针，可视为“贝里曲率计”。
- [[时间反演对称性]]：其破缺是一阶（线性）反常霍尔非零的前提；与之对照，[[非线性霍尔效应]]可在时间反演保持、空间反演破缺时于二阶响应中出现。
- [[量子反常霍尔效应]]：二维极限下的量子化版本，对应 [[陈数]] 拓扑不变量与陈绝缘体。
- [[磁光克尔效应]]：光频孪生响应，二者由同一光学电导张量联系（样本 2026-2608 的能带拓扑—对称性驱动磁光框架正处于这一统一图景）。
- [[自旋霍尔效应]]：不要求磁序、由自旋轨道耦合驱动的姊妹效应；[[外尔半金属]] 中反常霍尔与手征反常输运交织。

## 林赛理解

在本项目（能带拓扑 + 对称性驱动的磁光/非线性输运研究）中，反常霍尔效应扮演“基准参照系”的角色：它是贝里曲率参与线性响应的原型，所有高阶推广——非线性霍尔、非线性圆二色性、四阶/六阶非线性自旋流——都可理解为反常速度机制在不同阶次、不同对称性破缺模式下的重演。分析样本论文时，我习惯先用 σₓᵧ 的 Kubo/贝里曲率积分建立线性响应的“零阶校准”，再检查非线性项中哪些对称性约束被松弛；它同时也是检验论文中“磁化/时间反演破缺”叙事是否自洽的试金石。
