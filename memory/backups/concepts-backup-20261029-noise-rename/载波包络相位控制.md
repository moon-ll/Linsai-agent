# 载波包络相位控制

## 定义定位

载波包络相位（Carrier-Envelope Phase, CEP，记作 φ_CEP）指超短激光脉冲中载波光场振荡相对于脉冲包络峰值的相位差。当脉冲被压缩至少周期（few-cycle）乃至单周期量级时，包络内仅剩少数几个光振荡周期，φ_CEP 不再是可被多周期平均掉的快变参数，而是直接决定瞬时电场波形（场峰与包络峰的重合程度、正负半周期的不对称性）。载波包络相位控制即通过主动测量与反馈（或无源共模设计），将 φ_CEP 锁定于设定值或按需阶梯扫描的技术体系，是少周期强场物理与阿秒科学的核心使能技术之一。

## 物理内涵/技术原理

**物理层面**：多周期脉冲下，强场过程对光周期取相位平均，观测结果与 CEP 无关；而少周期脉冲下，隧穿电离、高次谐波产生、分子解离电离等非线性过程的产率与动量谱强烈依赖 φ_CEP。典型效应包括：

- 单周期/少周期驱动隧穿电离中，不同 CEP 导致前向与后向发射电子产率不对称，stereo-ATI 电子谱的非对称参数可作为 CEP 的在线诊断量；
- HHG 中孤立阿秒脉冲的发射时刻、截止位置与偶极干涉结构随 CEP 漂移，幅度门控依赖 CEP 将电离限制在单个半周期内；
- 分子（如 H₂⁺/D₂⁺）在临界核间距发生增强电离后，碎片离子发射方向与分子内电子局域化方向由 CEP 决定，是“波形单分子反应控制”的实验证据。

**技术层面**：CEP 稳定通常分两级闭环——快环锁定振荡器腔内载波包络偏移频率 f_CEO（反馈至泵浦功率或腔镜位置），慢环补偿放大器链路引入的相位漂移。核心探测手段是 f-to-2f 自参考干涉：利用展宽至一个倍频程的光谱，让低频端的倍频分量与高频端基频分量拍频，直接读出 f_CEO。差频产生（DFG）路线中两路脉冲的 CEP 漂移共模相消，可构建无需反馈的本征 CEP 稳定光源。实验中还常用 CEP 扫描（CEP jogging）：按阶梯改变 φ_CEP 并逐阶梯采谱，从强场信号中分离出纯 CEP 依赖分量。

## 与现有方法/概念的关联

- CEP 是少周期 [[少周期脉冲|激光波形控制]] 的核心自由度，与光强、脉宽并列的第三类实验变量；
- 在 [[高次谐波产生]]（HHG）中，CEP 决定发射时刻与短/长轨迹选择，是幅度门控产生孤立 [[阿秒脉冲]] 的前提条件；
- 在短驱动脉冲下，CEP 漂移会平移亚周期 [[相位匹配]] 窗口与时间发射门（见样本 2026-2507_06386 中亚周期相位匹配效应对 CEP 的敏感性）；
- 与 [[隧穿电离]]、[[增强电离]] 相联系：CEP 控制再散射电子动量分布与分子内电子局域化方向，构成电子谱非对称性诊断的方法学基础；
- 测量侧与 [[f-to-2f 干涉仪]]、stereo-ATI 诊断共同构成“探测—反馈—锁定/扫描”闭环链路。

## 林赛理解

在本项目的两条研究线中，CEP 控制都是把“光场波形”转化为“可调实验参数”的旋钮。对增强电离电子谱课题（样本 2026-260527612），只有锁定或明确标定 CEP，才能把分子内电子局域化方向的非对称信号从统计涨落与多周期平均中剥离出来，并反演临界核间距附近的电子动力学；对短脉冲阿秒相位匹配课题（样本 2026-2507_06386），CEP 扫描是唯一能在亚周期尺度上平移发射窗口、进而区分短/长轨迹相位匹配贡献的手段。整理笔记时建议为每个样本标注其实验 CEP 状态（锁定值 / 扫描范围 / 未稳定），作为元数据字段，便于跨文献比对 CEP 依赖的物理结论。
