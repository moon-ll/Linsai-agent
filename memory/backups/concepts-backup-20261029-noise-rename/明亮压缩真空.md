# 明亮压缩真空（Bright Squeezed Vacuum, BSV）

## 定义定位

明亮压缩真空（Bright Squeezed Vacuum, BSV）是高增益自发参量下转换（PDC）输出的宏观非经典光场：其平均场为零（“真空”），共轭模式（信号/闲置）间具有低于散粒噪声的正交分量关联（“压缩”），却因增益极高而在每个模式携带大量光子对（“明亮”）。它是[[压缩真空态]]在强泵浦下的多模宏观版本，也是连接单光子离散变量与连续变量量子光学的重要桥梁。在本知识库中，该概念由两篇样本论文（BSV 光子擦除；BSV 高阶关联与超快 Wigner 测量）共同指向，是宏观量子态“制备—表征—操控”链条的核心载体概念。

## 物理内涵/技术原理

BSV 的生成可由双模压缩算符描述：对 χ⁽²⁾ 非线性晶体施加强泵浦，相互作用哈密顿量 H ∝ iħg(aₛ†aᵢ† − aₛaᵢ)，作用于真空得到 exp[r(aₛ†aᵢ† − aₛaᵢ)]|0⟩；当压缩参数 r 足够大（增益 G = cosh²r ≫ 1）时即为 BSV。飞秒超快泵浦下它天然是多模的，按 Schmidt 分解为一系列独立的双模压缩模式对，每对内部光子数完全关联（条件探测可获得极低噪声），模间频谱关联结构则由泵浦脉宽与相位匹配共同决定。其非经典性体现为：共轭模式光子数关联违背 Cauchy–Schwarz 不等式、噪声降低因子远小于 1、以及宏观尺度纠缠（偏振自由度上可形成宏观单态）。表征上需区分强度层面（平衡探测、条纹相机测高阶 g⁽ⁿ⁾、噪声降低因子）与场层面（零差层析重构 Wigner 函数，需克服宽带多模困难）；操控上，通过弱分束加 herald 探测可对 BSV 实施[[光子减除]]——从宏观态中“擦除”单个光子，把微观光子级操作移植到明亮态上，是样本论文 2026-2605 的主题，也是非高斯宏观态工程的关键手段；样本论文 2026-2609 则用超快时间分辨测量其高阶关联与 Wigner 函数，作为宏观态非经典性的实验判据。

## 与现有方法/概念的关联

- [[压缩真空态]]：BSV 是其高增益、多模极限；低增益下退化为单光子对源。
