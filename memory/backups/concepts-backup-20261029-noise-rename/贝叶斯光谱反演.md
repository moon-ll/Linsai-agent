# 贝叶斯光谱反演

## 定义定位

贝叶斯光谱反演是指以贝叶斯统计框架为核心，从观测光谱（发射线或吸收线）中反推介质物理参数的一类逆问题方法。它把反演表述为后验概率推断：p(θ|D) ∝ L(D|θ)·p(θ)，输出的是参数的完整概率分布而非单点最优解，从而显式量化不确定度、参数简并与模型选择风险。与传统的 χ² 最小化拟合相比，它能把先验物理知识（温度非负、速度连续、分量数目上限等）编码进推断过程。在本知识库语境中，它是连接原始谱线数据与物理结论（柱密度、激发温度、速度分量结构）之间的统计桥梁。

## 物理内涵/技术原理

光谱反演本质上是病态逆问题：观测谱 I(ν) 是辐射转移方程沿视线积分的结果，速度场、温度、密度、丰度、光学厚度等参数以非线性方式耦合进谱线形状、线宽与超精细结构中，不同参数组合可产生几乎相同的谱形（强简并）。贝叶斯方法通过四个机制系统性地处理该问题：

1. **似然构造**：假设残差为高斯噪声（或纳入谱噪声协方差、基线畸变），建立 L(D|θ)；多跃迁线可联合似然以增强约束。
2. **先验编码**：将物理合理性约束转化为概率先验，抑制无物理意义的解；先验敏感性本身也是需要报告的诊断量。
3. **后验采样**：用 MCMC（如 affine-invariant 的 emcee）或嵌套采样（dynesty、PyMC/NUTS）探索高维后验，给出置信区间与参数协方差结构。
4. **多分量与变维推断**：谱线常由未知数目的速度分量叠加而成，需同时回答“有几个分量”和“每个分量参数是什么”。这可通过可逆跳跃 MCMC 或基于证据（evidence）的嵌套采样模型比较实现，天然避免频率派多分量拟合中的过拟合风险。

样本语料体现两条互补路线：McFine（arXiv:2409.03835）以蒙特卡罗策略做多分量拟合与不确定度传播，偏混合式方法；bayes_spec（arXiv:2411.00924）则是完全贝叶斯框架（基于 PyMC），支持超精细结构的严格贝叶斯建模与证据比较。二者对照恰好展示了“点估计 + 误差传播”与“全后验推断”在谱线分析中的差异。

## 林赛理解

在本项目的研究链条中，贝叶斯光谱反演承担“从数据到物理”的方法学枢纽角色：我关心的核心量（各速度分量的柱密度、激发温度、光学厚度）都需经由谱线反演获得，若这一步只给点估计，下游的物理结论（如气体性质、湍流线宽关系）就会携带被低估的误差。因此我在文献梳理中刻意并置 McFine 与 bayes_spec 两类工具：前者轻量、适合批量巡天谱的快速分解，后者先验透明、可做模型证据比较，适合关键视线的深度分析。引用频次目前仅 2 次、优先级 low，说明它是支撑性方法概念而非当前研究主线；但 whenever 写方法对比或处理分量数简并争议时，本页应作为方法论参照点被回链。

## 学习路径/参考

1. **入门**：先掌握贝叶斯推断基础（Gelman et al., *Bayesian Data Analysis* 前三章），再读 emcee/PyMC 官方教程跑一个谱线拟合示例。
2. **本项目样本**：
   - McFine: arXiv:2409.03835（Python 蒙特卡罗多分量谱线拟合）
   - bayes_spec: arXiv:2411.00924（贝叶斯谱线建模框架）
3. **进阶**：Green (1995) 可逆跳跃 MCMC；嵌套采样与证据计算（Skilling 2004；dynesty 文档）。
4. **对照阅读**：GaussPy+ 论文，理解非贝叶斯多分解路线的假设差异。
