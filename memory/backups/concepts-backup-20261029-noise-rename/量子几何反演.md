# 量子几何反演（Quantum Geometry Inversion）

从可测的非线性光学/输运响应中重构能带量子几何量——Berry 曲率Ω(k) 与量子度规 g(k)——的反问题方法。候选响应通道：HHG 偏振谱、非线性霍尔/位移电流、圆偏振响应等。
