# 相干控制

## 定义定位

相干控制（Coherent Control）是指利用相干光源（激光场）或量子系统自身的相位相干性，通过精心设计驱动场的振幅、相位、频率与时间波形，诱导系统内多条量子跃迁路径之间发生可控的相长或相消干涉，从而将量子动力学引导至目标末态（指定布居、化学通道、电离通道或宏观物态）的开环控制策略。它区别于依赖弛豫、耗散或随机散射的传统“统计式”调控，本质上是把量子叠加与干涉作为一种可编程资源来使用。相干控制是量子控制理论中最具“物理直觉”的一支，也是连接强场物理、超快光谱与量子反馈控制的核心枢纽概念。

## 物理内涵/技术原理

相干控制的物理根基在于：量子演化由哈密顿量的相位结构决定，若系统保持相干性（退相干时间尺度长于控制脉冲），则不同跃迁路径的概率幅而非概率直接相加，总跃迁率包含交叉干涉项，干涉项的符号与大小可由外场的相对相位（光程差、载波包络相位 CEP、脉冲间隔）调节。

经典方案有两大流派：

1. **频域方案（Brumer–Shapiro）**：利用达到同一末态的多光子路径（如单光子与三光子跃迁）之间的干涉，通过相位调制实现布居在通道间的“装卸”。
2. **时域方案（Tannor–Rice–Gordon）**：泵浦–探测（pump–dump）方案，利用波包在势能面上的演化在不同时刻到达不同区域，在波包聚集于目标通道时施加第二个脉冲将其“倾倒”出去。

当系统复杂、无法显式建模时，采用**闭环学习控制**：脉冲整形器（如 4f 光路 +空间光调制器）生成试探波形，实验目标函数作适应度，遗传算法迭代优化波形，理论支撑即量子最优控制理论（OCT，Krotov 法、GRAPE 等），Pontryagin 极值原理给出最优脉冲的必要条件。

在强场区（样品 2025-2508_09048 的背景），微扰论失效，控制对象转为隧穿后电子波包的再散射轨迹与相位，CEP、双色场（ω–2ω）相对相位成为干涉旋钮；在驱动材料中（样品 2026-2609_30365 的背景），周期性驱动等效于 Floquet 哈密顿量重构能带与配对通道，例如以中红外泵浦相干驱动声子/电荷密度波模式，压制相位涨落或诱导有效吸引，实现光诱导超导一类物态切换。

## 与现有方法/概念的关联

- 与 [[量子反馈控制]]：相干控制是**开环**控制——波形预先设计、执行时不依赖测量；当系统存在噪声、漂移或退相干时，需引入测量—估计—修正的闭环，即 [[量子反馈控制]]。样本 2023-2301_07254 提出的无坍缩精确反馈控制正是“保持被控态相干性”这一相干控制要求在闭环框架下的延续，二者可视为控制“谱系”的两端。
- 与 [[弱测量]]：反馈回路中若采用强（投影）测量会破坏相干性，使后续相干控制失效；样本 2025-2508_09048 将弱测量引入强场体系，说明“弱提取信息 + 保全相干”是反馈式相干控制的可行读出接口。
- 与 [[光诱导超导]] / [[Floquet 工程]]：样本 2026-2609_30365 中排斥驱动的 p+ip 配对，可理解为相干控制在多体物态层面的应用——通过相干驱动改写有效配对相互作用，而非操控单分子通道。
- 与 [[量子最优控制]]：为复杂系统自动搜索波形提供算法层支撑。

## 林赛理解

在本项目的知识网络中，相干控制扮演“控制侧总纲”的角色：三个引用样本恰好覆盖其三个前沿延伸面——(i) 强场物理中电子波包的干涉操控与弱测量读出；(ii) 多体关联体系中通过相干驱动设计配对对称性（p+ip）与物态；(iii) 闭环化（量子反馈）以对抗退相干与噪声。我的核心关切是把“开环波形设计—弱测量读出—反馈闭环”串成一条统一链路：相干控制提供正向通道的物理语言（路径干涉、Floquet 重整、相位旋钮），而反馈与弱测量回答“如何在控制过程中不摧毁被控相干性”。当前引用频次仅 3，但它更适合作为枢纽节点而非叶节点，后续应重点补充其与超导动力学、强场阿秒控制文献的双向链接。
