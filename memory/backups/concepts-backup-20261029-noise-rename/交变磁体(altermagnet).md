# 交变磁体（altermagnet）

## 定义定位

交变磁体（altermagnet，亦译“交替磁体”）是一类由相反自旋子晶格构成、通常具有零净磁矩，同时保持时间反演对称性破缺的自旋有序材料。区别于普通[[反铁磁体]]，交变磁体的关键特征是：两个相反自旋子晶格往往由晶体中的旋转对称操作联系，而不是由平移、反演或平移结合时间反演联系。因此，即使不依赖明显的自旋轨道耦合，也可能在一般动量处产生自旋分裂。其典型响应包括零迹线或节点附近的自旋能带劈裂、各向异性的自旋泵浦，以及在特定对称性条件下出现的非线性霍尔效应。

## 物理内涵/技术原理

交变磁体的核心是“自旋有序的对称性环境”。在共线情形中，磁化方向可记为沿 \(z\) 轴的交错序参量 \(M_z(\mathbf r)\)。普通反铁磁体常可借助“时间反演加平移”把两个相反自旋子晶格联系起来；交变磁体则通常要求一个适当的真旋转把两个子晶格及其局域晶体环境联系起来，同时该操作不把自旋方向恢复到原来的子晶格。由此，时间反演只能把位于 \(\mathbf k\) 的态映射到位于 \(-\mathbf k\) 的态，不能保证同一 \(\mathbf k\) 点的两个自旋态简并，因而形成自旋分裂的能带。

交变磁体的对称性还会体现在磁响应张量中。对于共线磁结构，可考察满足时间反演不变性的反对称部分
\[
\alpha_{ij}(\mathbf k)\equiv \sigma_{ij}(\mathbf k)-\sigma_{ji}(\mathbf k).
\]
普通反铁磁体通常要求该部分因额外对称性而消失；交变磁体则允许其中某些分量非零。理想共线交变磁体在常规线性霍尔响应上仍可能受对称性压制，但其非线性霍尔响应、二次谐波产生等高阶光学或输运信号可以变得敏感，成为区分磁结构与识别对称性的重要探针。

从晶体学分类看，交变磁体常与特定的磁空间群或磁点群相联系，并可进一步区分为 \(d\)-wave、\(g\)-wave 等类型。不同旋转对称性决定哪些能带节点、自旋分裂方向和非线性响应张量分量被允许。[[自旋轨道耦合]]会进一步改变能带与磁振子结构，但不是形成交变磁性必要条件。交变磁体还可能与[[磁各向异性]]、[[铁磁体]]及[[拓扑磁体]]等概念交叉：它具有明确的自旋取向，却不一定产生净磁矩。

## 与现有方法/概念的关联

交变磁体是[[反铁磁体]]的特殊子类，不能把二者完全等同。判断材料是否属于交变磁体，需要先确定相反自旋子晶格之间的实际对称联系，再判断是否存在时间反演与平移的联合对称性。仅有交错磁化或零净磁矩，并不足以构成交变磁性证据。

在实验层面，[[非线性霍尔效应]]和[[二次谐波产生]]可探测传统线性磁响应难以区分的反对称张量与高阶对称性。自旋分辨能带测量、角分辨光电子能谱及自旋泵浦实验则用于确认一般动量处的自旋分裂。磁点群或磁空间群分类能够把实验信号与允许的序参量对应起来。任务所列的“非线性光学探测铁性八极体”工作可作为高阶磁序与光学张量之间的关联案例；“磁性 wallpaper 群中的交变磁性目录”则提示可借助旋转 wallpaper 群系统筛选可能的交变磁结构。

## 林赛理解

在林赛的分析框架中，交变磁体不应只被理解为“净磁矩为零的反铁磁体”，而应被看成由旋转对称性组织起来的自旋分裂体系。研究时，应把材料结构、磁空间群、序参量与可观测量放在同一条因果链上：先判断相反自旋子晶格如何对应，再确定时间反演如何作用，随后预测能带劈裂和非线性响应，最后用光学、输运或谱学信号验证。交变磁体在本项目中的角色，是连接晶体对称性、自旋电子结构与非线性光学探针的桥梁，也可作为拓展[[磁各向异性]]和[[拓扑磁体]]研究对象的基础概念。由于当前引用频次较低，它更适合作为支撑性概念页，而不必与项目中的核心材料体系并列展开。

## 学习路径/参考

建议依次掌握以下内容：

1. 区分[[铁磁体]]、[[反铁磁体]]、亚铁磁体与交变磁体的序参量。
2. 理解时间反演、空间反演、平移和真旋转对磁空间群的约束。
3. 学习自旋分裂能带及其与拓扑能带节点的联系。
4. 推导线性与非线性磁响应的对称性允许条件。
5. 结合磁点群、wallpaper 群和光学张量分析具体候选材料。
