# 圆二色性

## 定义定位

圆二色性（Circular Dichroism, CD）指材料对左旋（σ⁻ / LCP）与右旋（σ⁺ / RCP）圆偏振光吸收强度不同的现象，是线性二向色性在圆偏振基下的对应物。定量上由左右旋吸收系数之差 Δα = α₊ − α₋ 描述，其谱形直接映射材料中与手性相关的电子态结构与跃迁选择定则。在分子光谱中，CD 是探测蛋白质等生物大分子二级结构的经典手段；在固体中，尤其是缺乏空间反演或镜面对称的晶体（如过渡金属硫族化合物 TMD），CD 表现为螺旋度分辨的吸收/反射衬度，是读出手性激子、谷自由度与轨道磁矩的核心光学探针。本项目两篇样本分别涉及非线性 CD 与一阶 CD 消失的表观现象，故该概念在本库中需覆盖“线性—非线性、有信号—零信号”的完整语义。

## 物理内涵/技术原理

CD 的微观起源在于跃迁偶极矩对光子螺旋度的依赖：当体系镜像对称破缺时，左旋与右旋光激发的跃迁矩阵元 |⟨f|p·e±|i⟩|² 不再相等。在具有三重旋转对称 C₃ 的二维材料（MoS₂、WSe₂ 等）中，谷选择定则将 K 与 K′ 谷分别耦合到 σ⁺ 与 σ⁻ 光子；时间反演对称保证两谷的 CD 反号，因此宏观 CD 信号正比于两谷圆极化率之差，可用多能带模型的带间偶极矩阵元差定量计算，并显著受激子效应增强。

实验上，CD 通常以螺旋度分辨的反射/吸收差 ΔR = R(σ⁺) − R(σ⁻) 或归一化圆偏振度测量；非线性版本（圆偏振分辨二次谐波、双光子吸收 CD）可将灵敏度投影到特定宇称通道与局部手性环境，从而探测整体求和后被掩盖的局域信息。需要特别警惕的是“CD 消失 ≠ 手性消失”：当宽带探测平均了相反符号的谷贡献、或激子态发生谷间杂化时，一阶 CD 可相消为零，而隐藏的谷动力学仍存在，需借助时间分辨或非线性手段揭示（对应样本 `2026-260627963`）。此外应区分自然 CD 与磁圆二色性（MCD）：前者源于晶体结构本身的手性/镜面破缺，后者由外磁场或磁序引起的塞曼分裂产生，二者机制与对称性来源不同。

## 与现有方法/概念的关联

- 与 [[手性]] 直接绑定：CD 是手性的光学表征量，含反演对称的非手性体系一阶 CD 严格为零。
- 与 [[谷电子学]]：TMD 中 CD 是谷寻址与谷极化读出的标准探针，与 [[谷霍尔效应]] 形成光学/电学读出的互补对。
- 与 [[线性二向色性]]、[[法拉第旋转]] 同属偏振分辨光谱家族；与 [[二次谐波产生]] 结合即得非线性 CD，探测的是局域与镜面破缺而非整体手性（对应样本 `2026-2604_13729`）。
- 与 [[激子]] 物理耦合：手性激子在 CD 谱中表现为符号反转的吸收峰，谱形分析需耦合激子波函数对称性。

## 林赛理解

在本项目研究框架中，我把圆二色性定位为“结构手性—谷动力学—非线性响应”链条上的读出接口，而非一个孤立的光学常数。两篇样本恰好构成互补警示：一篇用非线性 CD 提取一阶测量看不到的局域手性信息，另一篇在一阶 CD 消失处挖掘出隐藏的谷动力学——这说明 CD 信号的有无必须结合阶数与几何配置谨慎解读。我的工作原则是：CD 是对展宽、谷间杂化和探测带宽高度敏感的弱测量量，用它反推谷极化或手性参数时，必须与对称性指标（C₃、镜面）及时间分辨数据交叉验证，区分“真零手性”与“表观相消”。后续笔记凡引用 CD 数据，应回链本页并标注所测阶数（一阶/二阶）与光路构型。
