# 二次谐波产生（Second Harmonic Generation, SHG）

## 定义定位

二次谐波产生（SHG）是最基本的二阶非线性光学过程：当强度足够的激光（基频 ω）入射介质时，二阶极化 P(2ω) = ε₀χ⁽²⁾E(ω)E(ω) 会辐射出频率翻倍（2ω）的光。1961 年 Franken 等人在石英晶体中首次实验观测到该效应。由于电偶极机制下 χ⁽²⁾ 在反演对称介质中严格为零，SHG 天然具备对称性选择性，被广泛用作探测晶体结构、电子态与磁结构中反演/时间反演破缺（铁电、反铁磁、隐藏多极序等）的灵敏工具，也是飞秒时间分辨泵浦-探测实验中追踪瞬态对称性动力学的核心信道。

## 物理内涵/技术原理

介质极化强度可按外场展开：P = ε₀[χ⁽¹⁾E + χ⁽²⁾E² + χ⁽³⁾E³ + …]，SHG 对应二阶项。在电偶极近似下，反演操作要求 χ⁽²⁾ = −χ⁽²⁾，故只有破缺反演对称的体材料（或任意材料的表面/界面，因表面天然破缺反演）才能产生体 SHG；磁偶极、电四极等机制可放宽该选择定则，但强度通常弱 2–4 个量级，且偏振与几何依赖不同，可用于机制判别。

χ⁽²⁾ 为三阶张量，独立非零分量由介质点群完全决定。通过旋转样品测量 SHG 强度的方位角依赖（转动各向异性，RA-SHG）并组合入射/出射偏振，可反演张量结构、判定实际对称性。因此 SHG 强度常被当作序参量的光学读出：铁电体中 I_SHG ∝ |P|²；反铁磁体中磁致 χ⁽²⁾（源于磁点群对反演+时间反演的联合破缺）携带磁序信息。

共振效应：当 ω 或 2ω 与带间跃迁、激子能级共振时，χ⁽²⁾ 可增强若干量级，其色散谱形可指认电子结构。时间分辨 SHG（tr-SHG）以泵浦激发、以 SHG 探测，可在飞秒尺度监测序参量 melting–恢复、瞬态对称性改变与光致隐藏态；强泵浦还可通过载流子/激子效应在原本中心对称的体系中诱导巨大的瞬态 SHG 增强，成为研究非平衡相变的窗口。

## 与现有方法/概念的关联

- SHG 是 [[非线性光学]] 的基石过程之一，与 [[三次谐波产生]] 等奇次谐波互补：奇次谐波不受反演对称约束，二者联用可分离“对称性信息”与“电子态信息”。
- 其选择定则根植于 [[反演对称性破缺]] 与磁点群，分析工具依赖 [[群论]]，可与 [[相变]] 的朗道序参量描述直接衔接。
- 作为实验手段，SHG 与 [[泵浦-探测技术]]、[[时间分辨光谱]] 结合形成 tr-SHG，用于探测 [[铁电极化]]、[[隐藏序]] 与 [[反铁磁]] 等序参量及其超快动力学。

## 林赛理解

在本项目的研究图景中，SHG 扮演“对称性读出器”的双重角色：其一，作为平衡态探针，利用 χ⁽²⁾ 的选择定则识别常规衍射难以触及的隐藏多极序（如样本中的铁性八极序），把宏观光学响应与微观序参量定量联系；其二，作为非平衡信道，借助光泵浦诱导的巨大瞬态 SHG 增强，研究光致对称性改变与非平衡相的时间演化。林赛在实践中坚持：不能仅凭 SHG 强度变化推断对称性结论，必须结合偏振组态与方位角依赖做张量级论证，并与结构、磁性、电子结构探针交叉验证。
