# 自旋泵浦

## 定义定位

自旋泵浦指铁磁体中磁化强度发生进动（如被微波驱动至铁磁共振）时，通过铁磁/非磁界面把自旋角动量以自旋流的形式持续注入相邻非磁层的输运过程。它由 Tserkovnyak、Brataas 与 Bauer 于 2002 年在 Silsbee 等人早期思想上系统建立，是“无电极、无温度梯度”条件下纯磁学方式产生自旋流的核心机制，也是自旋电子学中测量界面自旋混合电导与自旋霍尔角的标准实验手段。

## 物理内涵/技术原理

界面自旋泵浦的物理图像：进动的磁化矢量 $\mathbf{m}(t)$ 使界面上自旋向上/向下电子的散射相位周期性失配，非磁层中电子自旋沿 $\mathbf{m}$ 方向的投影不断被“刷新”，净效应是向非磁层注入横向极化自旋流：

$$\mathbf{j}_s = \frac{\hbar}{4\pi}\, g^{\uparrow\downarrow}\, \mathbf{m} \times \frac{d\mathbf{m}}{dt}$$

其中 $g^{\uparrow\downarrow}$ 为自旋混合电导（典型量级 $10^{19}\,\mathrm{m^{-2}}$），量化界面传递自旋角动量的能力。三个关键推论：

1. **阻尼增强**：泵出的角动量来自铁磁体自身，表现为附加 Gilbert 阻尼 $\Delta\alpha \propto g^{\uparrow\downarrow}/(M_s t_F)$，实验上以 F/N 双层相对单层 F 的线宽展宽为判据，与 [[吉尔伯特阻尼]] 直接相连。
2. **Onsager 互易**：同一界面参数 $g^{\uparrow\downarrow}$ 也支配逆过程——非磁层自旋积累对铁磁体施加自旋转移矩，对应 [[自旋轨道矩]] 的界面描述。
3. **电学读出**：在强自旋轨道耦合金属（Pt、W、Ta）中，泵浦自旋流经 [[逆自旋霍尔效应]] 转换为直流电压 $V \propto \theta_{\mathrm{SH}}\, \mathbf{j}_s \times \boldsymbol{\sigma}$，构成“磁化动力学 → 电信号”的完整链条。

推广层面，凡时间反演对称性被磁化动力学破坏、且存在自旋选择通路的体系，均可出现泵浦型自旋流，包括超快退磁驱动的瞬态自旋注入与参数调制的量子泵浦，时间尺度可从 GHz 一直延伸至飞秒。

## 与现有方法/概念的关联

- 实验载体：以 [[铁磁共振]] 驱动的 F/N 双层为标准平台，线宽法与电压法互补标定 $g^{\uparrow\downarrow}$ 与 $\theta_{\mathrm{SH}}$。
- 电学转换：与 [[逆自旋霍尔效应]]、[[自旋霍尔效应]] 构成“产生—转换—检测”闭环；反之 SOC 材料中磁化动力学可直接泵出电荷流，即样本 arXiv:2309.08597 讨论的强自旋轨道耦合 [[电荷泵浦]]，可视为自旋泵浦经 SOC 折算后的电荷对偶。
- 超快延伸：飞秒激光驱动磁化进动/退磁产生的瞬态自旋注入是自旋泵浦的超快版本，为 [[高次谐波产生]] 的纯磁学方案（样本 arXiv:2601.20777）与太赫兹发射提供自旋极化电流源。
- 同族概念：[[自旋转移矩]]（互易逆过程）、[[自旋塞贝克效应]]（热驱动自旋流的平行机制）、[[太赫兹自旋电子学]]。

## 林赛理解

在本项目的自旋动力学—输运耦合研究中，自旋泵浦承担“桥梁”角色：它把纯磁学的磁化进动翻译为可电学/光学检测的自旋流，是理解两篇样本论文的公共语言。2601.20777 的纯磁学高次谐波方案中，需要超快自旋流注入来携带自旋信息，可视为自旋泵浦在飞秒尺度的类比；2309.08597 的强 SOC 电荷泵浦则是同一角动量流经 SOC 折算后的电荷响应。掌握 $g^{\uparrow\downarrow}$、阻尼增强与 ISHE 读出这条主线，就能在“磁化动力学 ↔ 电荷/光学信号”之间建立定量通道，为项目中自旋流产生效率的标定提供基准。
