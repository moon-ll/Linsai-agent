# 20-22（20–22 阶谐波窗口）

## 定义定位

“20-22” 是本项目知识库从 arXiv 2507.09234（Revealing material-dependent bicircular high-harmonic generation，2025）中抽取的概念标签，指该文双圆偏振高次谐波谱分析中被重点关注的 20–22 阶谐波窗口（第 20、21、22 阶谐波及其覆盖的光子能量区间；若原文语境为光子能量，亦可解读为 20–22 eV 能区，两种读法下其“诊断窗口”角色一致）。在双圆驱动场（频率比 1:2、反向旋转的双色圆偏振场）下，发射谐波遵循 3q±1 选择定则，故 20–22 恰好构成一个完整的“允许—禁戒—允许”周期：20 = 3×7−1、22 = 3×7+1 为允许阶次，21 = 3×7 被动力学对称性禁止。它是检验材料依赖性差异的最小光谱单元。

## 物理内涵/技术原理

双圆 HHG 中，基频 ω 与倍频 2ω 的反向圆偏振场合成具有三重旋转对称性（C3）的驱动场，其李萨如轨迹呈三叶草形。该对称性强制发射谐波只能落在 3q±1 阶，且相邻允许谐波螺旋度相反；3 的整数倍阶次被禁止。由此，20–22 窗口具有双重诊断价值：
