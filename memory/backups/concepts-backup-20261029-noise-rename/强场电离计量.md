# 强场电离计量

## 定义定位

强场电离计量（Strong-Field Ionization Metrology）是强场物理与量子计量学的交叉概念，指以强激光场驱动的电离过程（隧穿电离、越垒电离、多光子/阈上电离）作为探测与读出通道，对激光场参数（峰值场强、载波包络相位、脉冲时间波形）以及原子/分子参数（电离能、势垒结构、轨道形状、隧穿时刻）进行高精度测量的方法论体系。它把电离产额、光电子动量谱等可观测量视为编码待估参数的统计样本，再用量子参数估计理论刻画其精度极限。在本知识库中引用频次为 2，属低优先级应用型叶节点概念。

## 物理内涵/技术原理

**电离机制与灵敏度根源。** Keldysh 参数 γ = √(Ip/2Up)（Up ∝ I/ω²）划分电离区域：γ≫1 为多光子电离，γ≲1 为隧穿电离，场强继续升高则进入越垒电离。ADK 速率理论给出隧穿电离率对参数的指数依赖 w ∝ exp[−2(2Ip)^{3/2}/(3E)]——电离信号对场强 E 与电离能 Ip 呈指数放大响应。这一指数依赖既是“以电离做计量”的物理基础（单位场强变化可引起产额量级变化，Fisher 信息极大），也是其软肋：对逐发激光强度抖动极度敏感。

**测量通道。** 常用读出包括离子/电子产额、光电子动量分布（含全息与干涉结构）、阈上电离谱及高次谐波谱。attoclock 实验进一步用椭圆偏振场把“隧穿时刻”映射为电子出射偏转角，是“电离事件作为钟表”的典范。

**计量学框架。** 把电离建模为量子信道：输入待估参数 θ（场强、CEP、Ip、隧穿延迟 t₀），输出末态概率分布 p(x|θ)。经典/量子 Fisher 信息与 Cramér–Rao 下界给出无偏估计的方差极限；多参数情形（如场强—相位、Ip—场强的联合估计）受参数估计不确定性关系约束；超越标准量子极限的路径则包括利用电子波包相干性、纠缠或条件测量。技术噪声以激光逐发涨落为主，实用中需贝叶斯或极大似然逐发重构。

## 与现有方法/概念的关联

- **上游理论层**：[[量子参数估计]] 与 [[量子Fisher信息]] 提供精度界语言；样本一（arXiv:2506.15352）的不确定性关系限制多参数联合估计的可达精度。
- **姊妹概念**：[[强场量子计量学]]（样本二，arXiv:2602.13667）以超越 [[标准量子极限]] 为目标，本概念可视为其在“电离读出通道”上的具体实现。
- **强场物理基础**：[[隧穿电离]]、[[ADK理论]]、[[阈上电离]]、[[高次谐波产生]]、[[阿秒时钟]]。
- **与传统场强定标的对比**：常规方案依赖中性密度滤波与光谱仪做相对定标，精度停在百分比量级；电离计量的指数响应理论上可把逐发场强估计推进至 Cramér–Rao 界附近。

## 林赛理解

在本项目的研究地图中，强场电离计量是连接“强场物理机制层”与“量子计量理论层”的应用锚点：两篇引用文献分别给出界的语言（参数估计不确定性关系）与路的方向（超越标准量子极限的强场计量方案），本概念回答的核心问题是“电离信号究竟能以多高精度读出场参数与原子参数”。它当前为低优先级叶节点（引用 2 次），主要价值在于提供精度极限的讨论框架——当项目涉及用隧穿电离做场强定标或阿秒时间测量时，应回到此页调用 Fisher 信息 / CRB / SQL 这套语言；若后续出现“隧穿延迟时间测量精度”类问题，需回溯至本页及其上游两篇笔记。
