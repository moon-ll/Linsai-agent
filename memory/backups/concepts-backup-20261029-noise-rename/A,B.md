# A、B：二阶响应的谱密度与求和规则

## 定义定位

A、B 在输入中以符号形式出现。结合样本文献所讨论的二阶响应、谱密度与求和规则，本文采用如下工作约定：A 表示二阶响应在频率空间中的谱密度或关联函数虚部，B 表示由该谱密度积分得到的求和规则、积分矩或谱权重。二者不是彼此独立的现象，而是同一响应的两种描述方式：A 强调能量或频率如何分布以及共振峰出现在哪里，B 强调这些分布在整个频率范围内必须满足的总量约束。具体归一化方式、频率变量和张量指标应以原始文献的定义为准。

## 物理内涵/技术原理

谱密度通常由适当的推迟响应函数或二阶关联函数构造，示意上可写为 \(A(\omega)\propto-\operatorname{Im}G_R^{(2)}(\omega)\)。它把时域中的衰减、弛豫和量子相干信息转换为频域可观测结构：峰值对应激发态或集体共振，峰宽反映耗散与有限寿命，谱权重则反映相关矩阵元的大小。对于二阶响应，还需要保留 polarization、magnetic-field 等指标，以避免把不同通道的贡献混合。

求和规则 B 可抽象为
\[
B_n=\int d\omega\,\omega^n A(\omega),
\]
并可能附加归一化因子、正则化项或来自等时关联函数的接触项。其物理依据是因果响应在高频下由局域代数决定，而关联函数的等时对易子给出固定矩。由此得到的积分约束既联系微观哈密顿量，也联系光学或输运实验中的高频响应。分析时应区分零频求和规则、有限温求和规则和有限频段积分，并检查积分是否收敛、离散频率网格是否覆盖完整区间以及离散化误差是否得到控制。

## 与现有方法/概念的关联

- [[Kubo 公式]]把线性或二阶响应写成平衡态关联函数的时间关联，为构造 A 提供微观起点。
- [[推迟格林函数]]通过因果延拓确定虚部符号和谱密度边界条件。
- [[求和规则]]利用等时代数约束谱密度的积分矩，相当于为数值谱响应设置整体校验标准。
- [[二阶非线性光学]]中，二阶响应通常表示为三波混频、整流或光整流等过程；其频率依赖和共振结构可用 A 描述。
- [[频域响应]]完成傅里叶变换后，谱峰、相位与求和规则之间的联系最为直接。

## 林赛理解

在本项目中，A、B 主要承担“微观计算—可观测量”之间的校验桥梁角色。先由 A 定位二阶响应的共振区间、通道权重和衰减行为，再用 B 检查计算结果是否满足应有的总量约束，有助于发现遗漏的响应通道、错误的归一化、未收敛的高频尾部或错误的展宽处理。实际研究可按“构造关联函数—提取谱密度—计算积分矩—比较不同近似或数值方法”的顺序推进。对于新出现的谱峰，还应结合 [[线性响应理论]] 判断其属于真实激发、有限尺寸伪影还是非线性混合效应。
