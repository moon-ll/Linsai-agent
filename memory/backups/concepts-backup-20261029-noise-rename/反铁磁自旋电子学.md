# 反铁磁自旋电子学

## 定义定位

反铁磁自旋电子学（Antiferromagnetic Spintronics）是[[自铁磁体]]框架之外的[[自旋电子学]]重要分支：以反铁磁材料（奈尔温度以下、相邻亚晶格磁矩反平行排列、净磁化近似为零）替代传统铁磁体作为信息载体，研究其磁序（奈尔矢量）的电学/光学读出与写入、超快自旋动力学及器件化路径。相比铁磁体系，其核心优势在于：无杂散磁场（利于高密度集成与抗串扰）、抗外磁场干扰（数据鲁棒性）、材料储量丰富且与半导体工艺兼容，以及本征动力学频率达太赫兹量级。自 Jungwirth 等人 2016 年提出纲领性框架以来，该方向已成为凝聚态物理与自旋电子器件的交叉热点。

## 物理内涵/技术原理

**磁序结构**：反铁磁体中两个（或多个）磁亚晶格的磁矩反平行排列，序参量为奈尔矢量 **L** = m₁ − m₂，净磁化 M ≈ 0。交换作用（海森堡耦合 J）主导序的稳定性，Dzyaloshinskii–Moriya 相互作用与磁晶各向异性决定其精细结构（共线、螺旋或非共线摆线序）。

**超快动力学**：交换增强的各向异性场可达数百特斯拉，使反铁磁共振频率进入 THz 频段，比铁磁体系（GHz）高约三个数量级，为超快信息操作提供物理基础。

**读出机制**：由于 M ≈ 0，常规磁电阻信号微弱，需借助与奈尔矢量耦合的信号通道——晶体对称性各向异性磁电阻（AMR，如 CuMnAs 中随 L 翻转变号的双通道信号）、反铁磁隧道结中的隧穿 AMR
