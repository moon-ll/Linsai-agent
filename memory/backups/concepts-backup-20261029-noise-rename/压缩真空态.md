# 压缩真空态

## 定义定位

压缩真空态（squeezed vacuum state）是连续变量量子光学中最基本的非经典光场之一：由压缩算符 $S(\zeta)$ 作用于电磁场真空态 $|0\rangle$ 而成，记作 $|\zeta\rangle = S(\zeta)|0\rangle$，其中 $\zeta = r e^{i\theta}$，$r$ 为压缩幅、$\theta$ 为压缩角。虽然其平均场强为零（故称“真空”），但某一正交分量（振幅分量 $\hat X$ 或相位分量 $\hat P$）的涨落方差被压至低于真空涨落（散粒噪声极限）的水平，共轭分量相应放大，两者乘积仍保持在不确定性关系的最小值上。它是高斯态家族的原型成员，也是多模量子优越性实验中唯一需要物理制备的非经典输入资源。

## 物理内涵/技术原理

压缩算符 $S(\zeta)=\exp\!\left[\tfrac{1}{2}(\zeta^{*}\hat a^{2}-\zeta\,\hat a^{\dagger 2})\right]$ 本质是双光子（二次非线性）变换，对湮灭算符实施 Bogoliubov 变换：

$$S^{\dagger}\hat a\,S=\hat a\cosh r-\hat a^{\dagger}e^{i\theta}\sinh r$$

取正交分量 $\hat X=(\hat a+\hat a^{\dagger})/\sqrt2$、$\hat P=(\hat a-\hat a^{\dagger})/i\sqrt2$（真空方差 $1/2$），则

$$\mathrm{Var}(\hat X)=\tfrac{1}{2}e^{-2r},\qquad \mathrm{Var}(\hat P)=\tfrac{1}{2}e^{+2r}$$
