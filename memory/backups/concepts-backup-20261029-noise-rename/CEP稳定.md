# CEP稳定

## 定义定位

CEP稳定（Carrier-Envelope Phase stabilization，载波包络相位稳定）指对激光脉冲中电场载波相对于脉冲包络的相位差（[[载波包络相位]]，φCE）进行测量、反馈与锁定，使脉冲序列中相邻脉冲间的 CEP 漂移被压缩到远小于 π 的水平，或在单发层面获得确定的绝对相位。当脉冲长度缩短到仅含几个光学周期时，CEP 不再是可平均掉的次要参量，而是决定瞬时电场波形（cos 型峰值场与 sin 型对称场）的关键自由度，直接支配[[强场电离]]、[[高次谐波产生]]等场敏感过程的可重复性与相干控制能力。

## 物理内涵/技术原理

CEP 漂移的物理根源在于激光腔内载波相位与包络重复相位不成严格整数比，腔内每圈累积的相位噪声表现为载波包络偏移频率 f_ceo = f_rep·(ΔφCE/2π) 的抖动。主动稳定的标准方案是 f-2f 自参考干涉仪：利用倍频程超连续谱中低频成分倍频后与高频成分的拍频直接读出 f_ceo，再经反馈回路（泵浦电流、声光调制器或 AOPDF）将其锁定到射频参考或 f_rep 的有理数倍，实现恒定 CEP 或滑移已知的 CEP。噪声源包括泵浦功率涨落、色散与非线性相位波动、机械振动与热漂移，其噪声谱通常分布在亚 Hz 至数百 kHz，决定了环路带宽的设计要求。被动稳定路线则利用差频产生（DFG）中信号光与闲频光 CEP 反相、合成光场相位自然抵消的特性，或全保偏、全共线的光参量链路，无需反馈即可长期平稳，这在[[中红外驱动光源]]与少周期参量系统中尤为常用。CEP 对少周期强场物理的影响体现在：三步模型中电离与再碰撞时刻对应的瞬时场强、谐波截止区谱形（连续谱 vs 半周期调制结构），以及[[阿秒脉冲]]的发射时刻与孤立阿秒脉冲的可重复产生。单发 CEP 诊断技术（stereo-ATI、chirped f-2f 光谱干涉）进一步将验证推进到逐发层面，是高能量标度实验中不可省略的配套环节。

## 与现有方法/概念的关联

- 上位概念：[[载波包络相位]]——CEP稳定是其工程实现层；[[光频梳]]——f_ceo 锁定是光频梳两大自由度之一。
- 技术组件：[[f-2f干涉仪]]（主动测量）、[[光参量放大]]/DFG（被动稳定）、AOPDF 反馈支路。
