# 时间分辨 helicity-resolved 测量

## 定义定位

时间分辨 helicity-resolved 测量是一类把飞秒泵浦–探测（pump–probe）时间分辨技术与光子螺旋度分辨（区分左旋 σ⁻ 与右旋 σ⁺ 圆偏振光及其携带的角动量 ±ħ）耦合起来的超快探测手段。它在“时间轴”和“手性轴”两个维度上同时对量子材料切片：前者给出瞬态动力学，后者对自旋织构、轨道角动量、手性载流子布居等手性敏感的自由度选择性地响应。与静态螺旋度分辨技术（如圆二色 ARPES、螺旋度依赖光电流）相比，其核心增量是能追踪光激发之后手性响应的建立、弛豫、乃至符号翻转的时间过程。在项目知识库中它属于低优先级、低引用（2 次）的支持性方法概念，主要服务于解读样本论文中的超快手性动力学实验。

## 物理内涵/技术原理

物理上，圆偏振光子的螺旋度对应确定的角动量投影，与电子体系耦合时通过偶极跃迁选择定则（Δm = ±1）实现对手性轨道/自旋通道的选择性激发或探测；在存在自旋–轨道耦合与破缺反演对称的材料中，这种轨道选择会进一步映射为自旋或贝里曲率选择。典型可观测量是瞬态螺旋度不对称度 A(t) = [I₊(t) − I₋(t)]/[I₊(t) + I₋(t)]（光电子谱模式），或螺旋度依赖的瞬态光电流差 ΔI(t)（输运模式）。技术上由三要素构成：(1) 泵浦光触发非平衡态（带间激发、体带耗尽、手性泵浦等）；(2) 探测光以电光调制器（PEM）或液晶相位延迟器在 kHz 量级翻转螺旋度，配合锁相放大提取差分信号；(3) 扫描泵浦–探测延迟获得时间轨迹，时间分辨率受两束脉冲互相关限制（典型 50–150 fs）。物理应用包括：拓扑表面态/Rashba 体系自旋织构的瞬态重整、外尔半金属中手性反常泵浦与手性化学势的弛豫时间测量、过渡金属硫族化物中谷对比选择定则的谷布居动力学等。需注意的陷阱：CD-ARPES 型强度不对称同时依赖初态与末态矩阵元，并非纯自旋信号；热效应、磁圆二色伪影、几何配置（泵浦/探测入射角）都会污染螺旋度差分，需线性偏振对照与对称性检验。

## 与现有方法/概念的关联

本概念可视为两条成熟技术路线的时间域交汇：

- 与 [[时间分辨ARPES]] 的关系：当探测通道是光电子能谱时，本概念即“螺旋度分辨的 trARPES”，是 [[圆二色ARPES]] 从静态向瞬态的直接推广，可在无自旋分析器的情况下间接读出自旋织构动力学，与 [[自旋分辨ARPES]] 形成互补（螺旋度通道 vs 直接自旋通道）。
- 与 [[圆偏振光电流效应]]（CPGE）的关系：当探测通道是光电流时，本概念对应瞬态 CPGE 测量，可提取二阶非线性光电响应张量及其在外尔节点附近行为随时间的演化，常用于 [[外尔半金属]] 手性反常与 [[拓扑绝缘体]] 表面态螺旋度光电流研究。
- 方法基座是通用的 [[泵浦-探测技术]]：时间分辨能力并不来自螺旋度分辨本身，而来自延迟扫描与锁相检测的组合。

## 林赛理解

在本项目的知识版图里，这个概念目前是“单源、低权重”的桥接节点：两次引用实际都来自同一样本（arXiv:2606.27963），说明它尚未在语料中被独立复用，我不打算过度铺设细节，而是把它建成一个方法论锚点——将来读到任何“打泵浦 + 翻螺旋度”的实验时，先回到这页核对三个问题：探测的是光电子还是光电流？螺旋度切换和延迟扫描是怎么解耦的？作者做了哪些伪影对照？它的真正价值在于连接 [[时间分辨ARPES]] 与 [[圆偏振光电流效应]] 两大簇，为后续超快拓扑物性笔记提供公共入口。若后续出现第二个独立来源引用该概念，应将其优先级上调并补充定量实例（弛豫时间尺度、不对称度幅值）。

1. 前置：圆偏振光与光子角动量、电偶极跃迁选择定则（任意原子物理/群论教材的相应章节）。
