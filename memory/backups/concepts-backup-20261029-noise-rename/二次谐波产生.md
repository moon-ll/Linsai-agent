# 二次谐波产生

## 定义定位

二次谐波产生（Second Harmonic Generation, SHG）是最基本的二阶非线性光学过程：介质中两个频率为 ω 的光子相干叠加，产生一个频率为 2ω（波长减半）的光子。在电偶极近似下，SHG 来源于二阶极化率张量 χ⁽²⁾，而 χ⁽²⁾ 只在破缺反演对称性的介质中非零——因此 SHG 不只是一种频率变换技术，更是探测晶体与界面对称性的“指纹”探针。在本知识库语境中，它同时承担三个角色：二维材料层数/堆叠方式的表征工具、激子态的非线性光谱窗口、以及光致/动力学反演对称破缺的判据。
