# 亮压缩真空

## 定义定位

亮压缩真空是一类平均光子数达到宏观量级（约 10⁵–10¹²）的多模压缩真空态，通常由强泵浦自发参量下转换（SPDC）或四波混频产生。它与“暗”压缩真空共享同一数学形式——无相干位移的双曲压缩高斯态——但因高增益而携带海量光子，既保持某一正交分量低于散粒噪声的涨落（压缩），又具备可被经典探测器直接测量的亮度。需辨析：其“真空”指模式未被相干位移、平均场为零，而非无光子；“亮”指光子数的宏观性，而非经典相干性。它是量子光学中介于纠缠光子对源与经典强光场之间的关键桥梁态。

## 物理内涵/技术原理

产生机制上，非线性晶体中的 χ⁽²⁾ 相互作用在强泵浦下实现参量放大，有效哈密顿量 H = iħκ(E_p a_s† a_i† − E_p* a_s a_i)。单模情形输出为增益参数 g 的压缩真空态，平均光子数 ⟨N⟩ = sinh²(g)；g ≫ 1 时进入亮压缩区。由于相位匹配与群速色散，实际输出是宽带多模态，可 Schmidt 分解为独立压缩双色分量的直积：

|ψ⟩ = ∏_k (1/cosh G_k) ∑_n (tanh G_k)ⁿ |n⟩_{k,s}|n⟩_{k,i}

每个 Schmidt 模单独服从热光统计，但信号—闲置两束间存在强烈光子数相关与亚散粒噪声的强度差压缩；相位灵敏探测下某一正交分量噪声低于散粒噪声极限。作为纯高斯态，其 Wigner 函数处处为正，但纠缠熵与量子 Fisher 信息随增益持续增长；高增益下介质中的传播、饱和与自相位调制还可诱导出非高斯成分，使其同时成为高斯/非高斯动力学的探针。

## 与现有方法/概念的关联

- 与 [[压缩真空态]]：同一态族，仅增益区不同；BSV 是其宏观光子数极限，区分更多由探测手段而非数学形式决定。
- 与 [[自发参量下转换]]：SPDC 是 BSV 的标准产生通道；低增益产生纠缠光子对，高增益即过渡为 BSV，二者由单一增益参数连续衔接。
- 与 [[高斯态]] / [[高斯纠缠]]：BSV 是典型的多模高斯态，其 Schmidt 谱由增益与色散共同塑造，是研究高斯纠缠涌现与度量的干净平台。
- 与 [[量子化电磁场]]：BSV 波包的传播与统计提供了“何时必须保留场量子性”的直接判据。
- 应用侧连接 [[量子成像]]、[[薛定谔猫态]] 制备与非线性干涉仪（SU(1,1)）。

## 林赛理解

在本项目的三条研究线中，亮压缩真空承担公共边界案例的角色。其一，在近似方法层级研究（2024-2410_19533）中，它光子数宏观到接近经典强度、压缩与纠缠却纯然量子，恰好落在平均场/半经典近似失效的临界带上，可用于标定各层级近似的适用边界。其二，在高斯纠缠涌现研究（2026-2606_22714）中，BSV 的 Schmidt 模纠缠随增益演化，为纠缠谱动力学提供可解析的模型载体。其三，在量子化电磁场波包运动研究（2026-2604_09284）中，它提供了带非经典统计的传播波包实例，可对照经典包络演化逐项检验量子修正。我认为它是把“光源的非经典性”与“场动力学的量子性”两个问题焊接在一起的抓手。
