# Weyl semimetal（外尔半金属）

## 定义定位

外尔半金属是一类三维拓扑半金属相：导带与价带在动量空间中的孤立点处发生线性交叉（外尔点，Weyl node），其附近的低能准粒子由外尔方程描述，等效为手性 χ = ±1 的无质量外尔费米子。外尔点是贝里曲率的“单极子”源，携带量子化的陈数 ±1；由 Nielsen–Ninomiya 定理，相反手性的外尔点必然成对出现。实现外尔相要求破坏空间反演对称或时间反演对称二者之一，因此它在拓扑能带分类中位于拓扑绝缘体与狄拉克半金属的近邻位置，也是研究体边对应与反常输运的标准平台。优先级 low（本项目直接引用仅 2 次），但作为“拓扑半金属基准相”具有概念锚点地位。

## 物理内涵/技术原理

外尔半金属的核心物理可压缩为三条主线：

1. **能带结构与手性**：含外尔点的二维 k 截面具有陈数 ±1，手性即贝里通量的符号。破坏反演对称（TaAs 家族）或时间反演对称（磁性外尔体系 Co₃Sn₂S₂、Co₂MnGa）均可实现。外尔锥的倾斜程度区分 I 型（直立锥）与 II 型（过倾、电子空穴口袋相触）外尔点。
2. **体边对应**：表面态呈现费米弧，连接体内外尔点在表面布里渊区的投影，是 ARPES 实验判定外尔相的直接证据。
3. **反常输运**：贝里曲率对费米面的积分给出内禀反常霍尔效应；E∥B 条件下的手性反常（chiral anomaly）导致负纵向磁阻；在反演破缺体系中，贝里曲率在费米面上的偶极矩（Berry curvature dipole）在二阶响应下产生非线性霍尔效应——这是本项目“非线性响应函数”方向的关键微观机制。

**外场与无序调控**：应变可以移动、产生或湮灭外尔点对，并在特定条件下等效为“轴磁场”诱导赝朗道能级；当化学势贴近外尔点时，无序展宽与外尔点间距、手性弛豫率之间的竞争，决定输运由扩散型还是半经典反常主导——这使外尔半金属成为“拓扑—无序”相互作用的干净测试床。

## 与现有方法/概念的关联

- 与 [[Dirac semimetal]]：狄拉克点可视为两个相反手性外尔点被晶体对称保护的简并；对称性一旦破缺即劈裂为一对外尔点，这是“应变作为拓扑选择器”的最小模型。
- 与 [[altermagnet]]：交错磁同时具备零净磁化与动量依赖的自旋劈裂、破缺时间反演，被预言可承载“无净磁矩的外尔点”，使外尔半金属物理进入零磁矩磁性语境，对应项目样本 strain-as-a-topological-selector-in-altermagnetism 的核心场景。
- 与 [[Berry curvature]]：外尔点是贝里曲率的单极子源；贝里曲率偶极子直接衔接 [[nonlinear Hall effect]] 的二阶响应理论。
- 与 [[chiral anomaly]]：为线性阶纵向反常输运提供基准，对照本项目无序与非线性响应的研究框架。
