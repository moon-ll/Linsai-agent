# 申请书写作纪律（nsfc-writing）

申请书写作与风格评审的单一真相源。量化标准（字数区间/引用次数/评分权重）见 `memory/nsfc-standards.json`，两者冲突时先修订其一保持一致。

## 一、读者视角总纲

课题文档是**给研究人员看的研究手册**（v7.0.2 用户裁决，见 research-proposal skill 〇节）：验收标准是**研究人员读完能否直接据此开始课题研究**——能否复述"做什么、怎么做"，能否按方案开机、采数、跑分析。任何写作决策与该目标冲突时，服从该目标；研究方案的具体操作判据见 research-proposal skill 的操作性五问。

## 二、叙事主线纪律（防"防御性装甲淹没主线"）

多轮评审修订会自然累积防御性表述（边界条件、失败预案、降级路径、交叉引用锚点）。不加约束时，8 轮之后"防失败逻辑"的篇幅会超过"做什么"的篇幅，读者读完只记得会怎么挂。纪律：

1. **顺叙为主**：方案按"方法→装置→应用"或"拿什么→做什么→得到什么"时序推进，主干句只讲主线动作。
2. **防御性内容降权**：边界条件、降级预案、失败处置原则上以从句（"若…则…"限一句）或括号短语内嵌；同类预案集中到方案末尾一个小节统一交代，不在每个步骤后展开。任何一段最多 1 个条件分支句。
3. **禁止前置门控叙事**：不写"X 未通过 Y 不进入 Z"式流程闸门句子，改为正面陈述各环节的输入输出衔接。
4. **交叉引用预算**：括号交叉引用（"见 §x.x"）每千字不超过 1 处，只保留真正必要的（如判据数值的推导出处），其余改为"在研究方案中详述"一笔带过或直接删除。
5. **量化指标嵌入叙述**：研究目标每条以完整叙述句承载 1 个可检验指标，禁止连续堆砌"参数≤数值；参数≤数值"清单。

## 三、禁用词与替换映射（审计语言→申请书语言）

以下词汇是内部管线工作语言，出现在正文即扣分。替换映射：

| 禁用 | 替换为 |
|---|---|
| 交付物 | （删除，直接说"形成/给出/建立…"） |
| 硬门控、入门阈值、门控判据 | 判据、先决条件 |
| 触发 No-Go / 触发降级预案 | 若…失败则…（从句内） |
| 边界一/边界二/边界三 | （删除编号，叙述化） |
| 工作假设 | 初步取值/暂定值 |
| 落地、闭环（项目管理语境） | 实现、验证循环（物理语境的"写-读-反演闭环"可保留） |
| 口径 | 定义、标准、表述（"判据口径"→"判据定义"） |
| R1/R2/R3、块一/块二、第一层/第二层 | 理论/实验/反演（或对应实义） |
| 失败出口、处置路径 | （并入末节"风险与应对"） |
| 锚定、对账、固化 | 以…为基准、一致性校验、确定 |

## 四、叙述式写作规范（语体对标范本）

**范本的角色是语体参考，不是内容深度锚**（v7.0.2：产出的课题文档是研究手册，不是申请书——范本行文怎么写可以学，范本写到什么深度不可以学，操作细节不因范本没写而省略）：

1. 连贯段落式行文：每段 3-6 句、150-300 字，段间以内容逻辑衔接（非"在此基础上"式关联词）。
2. 引用嵌入论证链："某人等人[N]在期刊上报道了 X"，禁止"A 做了 X[1]，B 做了 Y[2]"堆砌。
3. 客观陈述他人成果用"某某等人首次/报道/实现"；本项目主张用"本项目"主语，视角统一。
4. 每个论断配具体数值（分辨率、能量、精度、年份），不用"显著/重要/深入/全面"空泛修饰。
5. 句长：中位数约 56 字，超 120 字必拆；80-120 字技术性长句（多分号分句）属范本正常现象（占比 12%-28%），仅同段密集出现（每段超 2 句）时标记。
6. 模板化表达（"为…提供…基础/支撑/途径"）全文不超过 5 次；"空洞概括句"（"具有决定性意义"类）零容忍。
7. 立项依据五层递进（大背景→领域脉络→核心问题→国内现状→本项目定位）；特色创新四步（现有局限→本项目方案→量化优势→定位收束）；研究方案说明"为什么选这个方法"而非只罗列步骤。

## 五、正反对照（范例）

反例（环节验收式，禁）：
> 样品端。块体 MnTe 单晶经机械解理获得原子级平整表面（尺寸 ≥ 500 μm × 500 μm）。样品验收以 SQUID 磁测量确认 T_N ≈ 310 K、SHG 确认磁点群对称性。安装后置入低温恒温器（10–340 K），温控精度在 T_N 附近加密至 2–5 K。

正例（叙事式，倡）：
> 实验采用块体 α-MnTe 单晶，经机械解理获得 500 μm 见方的原子级平整表面。每块样品进入测量序列前，先以 SQUID 磁测量确认奈尔温度（T_N ≈ 310 K），再以二次谐波测量确认磁点群对称性并筛除多畴区域——多畴平均会抹平自旋劈裂的偏振特征。样品置入 10–340 K 低温恒温器，在奈尔温度附近将控温加密至 2–5 K，以分辨跨相变区间的谱形演化。

差异要点：正例把"验收/安装/温控"三个环节动词换成有物理动机的叙述（为什么筛多畴、为什么加密），参数一个不少但读者认知负荷在主线上。

## 六、文件纯净性与内容边界

1. **章节文件只写正文**：严禁写入任何工作过程记录——核校日志、闭环证据索引、修复声明、"本节由 writer 在 round-N 评审后核校"类段落一律不进章节文件；过程性说明写入 05_review/ 下对应报告文件。
2. **章节文件白名单**：sections/ 下只允许 rationale/content/scheme/full_review/references 五个模块，严禁自创章节文件——非白名单文件不进申请书组装与评审，属内容静默丢失。
3. **references 专属**：references.md 只写文献条目、条目内挂钩注释、章节正文；映射表/核实声明/闭环日志类内容迁移至 05_review/ 并从章节文件删除。
4. **full_review 专属**：full_review.md 只写全文逻辑骨架（≤3000 字），严禁把逐项对照表、处置记录、轮次说明写入该文件。
5. **内容边界**：申请书聚焦研究思路与研究内容，严禁撰写研究基础/实验平台条件/设备参数/合作声明/经费概算/劳务与人员费/知识产权分割协议等内容——系统不掌握申请人的真实平台、合作与预算信息，此类内容写入必是虚构，必须由申请人本人补充。已有此类内容会被孤儿章节守卫迁出存档。
6. **过程性残留零容忍**：轮次编号（round-N）、内部文件名、"本轮修订后"类表述、审校注记、检索时间戳、英文年度标记（Year 1→第 1 年）一律不进正文。

## 七、内容质量纪律

1. 冗余是质量缺陷：同一论证不在多章节复述，章节内重复论证合并为一次完整表述；引用其他章节结论用指代，不复述论证过程。
2. 无关内容是质量缺陷：与课题核心科学问题无关联的段落删除，不以"背景知识"名义保留堆砌。
3. 修复问题优先"改写现有句子"而非"新增句子"；细节下沉方法学手册。
4. 论证密集的长文是合格品——只要冗余/无关零命中，不因字数扣分；质量以密度论，不以字数论。
5. 参考文献条数触顶时（standards 规定 30-40 篇）新增文献的可行解法：把正文承担**同一论证功能**的相邻两篇合并为同一编号条目（条目内以「｜」分隔两篇完整题录），正文只挂一次角标、第二篇作者名与编号解耦（如「同组的 Rudner 与 Lindner 把…」）。此法不增条目数且题录完整可核验；但合并后角标密度上升，须同步删段落内冗余重复角标以守住「正文引用 35-47 次」上限。跨多章重排编号时用 old→new 映射表批量替换，并逐条核对作者名与新编号匹配，不得凭记忆改号。
6. 优先级/战略性断言（"旗舰方向""率先""尚未见报道"）必须逐字核对原文：路线图、白皮书类文献常被摘要式转述夸大，须下载 PDF 全文检索关键词后再落笔（实证：arXiv:2604.15085《Roadmap on Attosecond Science》全文 174 页无 "flagship direction"/"transient topological phase"，原文仅有「探测凝聚态体系中非平凡的动态拓扑相」一句）。改法是按原文实际表述改写并加「（据预印本）」限定，而非补文献或删断言。
7. 单一文献承载两个独立断言时须拆挂（实证：2 μm OPA 的 70 mrad CEP 与 2.3 μm 频梳的 1.5 mrad/1.8 as 出自两篇不同工作）；若因条数上限只能合并条目，正文须写明"同一编号下的另一项工作"而非误写为"同一工作"。

## 八、AI 写作模式修复

检测到 AI 模式时按映射修复：死板关联词（在此基础上/此外/与此同时高频）→ 段间内容逻辑衔接；模板句式 → 删除或改具体；元话语（"值得注意的是""需要指出"）→ 删除，直接陈述科学事实；过度加粗 → 删除加粗标记（范本几乎不用）；编号列表 → 改连贯叙述式段落。
白名单术语（"关键科学问题""系统误差""有效性""同时电离"等科研法定用法）无需修改、不计扣分。修改后与 benchmark_anchors 范本锚点段落对比，确保语体和论证密度达标。

## 九、writer 自检清单（写完逐项过）

- [ ] 通读任一小节后，能否不看原文复述出"做什么、怎么做"？
- [ ] 每段条件分支句 ≤1？防御性预案是否已集中到末节？
- [ ] 禁用词表逐词 grep 归零？
- [ ] 括号交叉引用每千字 ≤1？
- [ ] 目标段是叙述句还是参数清单？
- [ ] 段落 150-300 字、超长句拆分、破折号归零？
- [ ] 文件纯净性：无过程记录/无白名单外内容/无越界内容？
- [ ] 同一论证未跨章节复述？

## 十、critic 检查项（风格维度扣分依据）

1. **主线清晰度（手册标准）**：随机抽一节，若研究人员无法据此复述/执行该节"做什么、怎么做"（方案节尤其要能直接开工），扣叙事分；具体性不足（操作性五问缺答）比语体瑕疵扣分更重。
2. **叙述式违规**：是否以科学问题为主线展开（非罗列文献/数据/概念）；"A做了X，B做了Y"式堆砌；条目式表达替代论证；段落无过渡；方案未说明"为什么选这个方法"；目标条缺可检验量化指标。
3. **防御密度**：统计条件分支句（"若…则/未通过…不进入/触发…"）密度，超过每千字 2 处扣分。
4. **审计语言**：禁用词表（第三节）命中即计 1 处，每处扣分且要求整改。
5. **AI 写作味**：死板关联词高频、模板句式超 15 次、冗余修饰堆砌、空洞概括句、超长句。
6. **指标红线（critical 级）**：同一指标跨章节数值或定义不一致；同时宣称两个违反物理约束的量；理论框架未注明适用条件；"首次/尚未见报道"缺文献支撑；指标无"方案→指标"实现路径。
7. **内容越界**：方案中出现"为什么研究"口吻（应归研究内容）；可行性复述方案细节（应聚焦"为什么能做成"）；跨章节大量重复。
8. **罗列度**：连续 ≥3 行参数/短句清单（非表格、非文献列表）计 1 处机械罗列。

注意：科学正确性、判据数值、口径一致性的优先级高于本清单；本清单不用于要求删除必要的科学内容，只约束表达方式。评分锚点：锚点对比结论=差距明显 → 表达质量 ≤0.69；=基本接近 → ≤0.79；=达标方可进入 0.85+。
