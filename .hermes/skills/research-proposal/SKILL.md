# 研究课题方法学（research-proposal）

课题设想生成、课题文档撰写与"可操作性"判定的方法学。

## 〇、产出定位：研究手册，不是申请书（v7.0.2 用户裁决 2026-09-26）

**本项目产出的课题文档是给研究人员（用户自己）看的研究手册——读完能直接据此开始课题研究。** 它与 NSFC 申请书有本质区别：

| 维度 | NSFC 申请书（范本） | 本项目课题文档（研究手册） |
|------|---------------------|---------------------------|
| 读者 | 评审人（陌生人，要说服） | 研究人员（自己，要能开工） |
| 深度标准 | 讲清思路即可（框架+关键判据） | **可执行**（操作细节、参数、序列齐备） |
| 内容重点 | 论证"为什么值得做、为什么能做成" | 指引"具体做什么、怎么做" |
| 细节归属 | 细节下沉附录/方法手册 | **细节直接进正文**（本文档就是手册） |
| 结构取向 | 连贯叙述说服链 | **结构清晰优先**（小节自解释、可定位、可查阅） |

由此派生三条写作裁决：
1. **范本只是语体参考**（叙述式行文、论证密度、引用嵌入的写法），**不是内容深度锚**——不得以"范本也就写到这个深度"为由压缩操作细节。
2. **具体性与结构清晰优先于说服性**：参数表、操作步骤、判据数值、时间预算直接进正文；一个物理量该给数值就给数值，该给公式就给公式。
3. **不写申请书的说服性包装**：不写研究基础/个人信息/工作条件（既有边界），也不为"让评审信服"设的铺垫性论证——手册的"论证"是物理依据（为什么这个参数、为什么这个判据），不是意义渲染。

量化参数（字数/引用区间）见 `memory/nsfc-standards.json`——注意其中部分区间按申请书范本校准，手册定位下字数上限可适度放宽（密度不降的前提下），引用密度不设说服性目标。

## 一、操作性五问（研究方案的核心判据）

研究方案（scheme）写完必须逐问自检。任何一问答不出具体内容，该节不合格，不得交付：

1. **拿什么做**（装置与样品）：
   - 驱动/探测激光系统：波长、脉宽、重复频率、单脉冲能量、峰值强度窗口、光路关键元件规格（如偏振分析器消光比、延迟线分辨率）
   - 样品：来源/制备方法（解理/生长/转移）、表征验收手段（结构/磁/输运各用什么测）、几何尺寸量级
   - 探测端：探测器类型与关键指标（暗计数/动态范围/能区）
2. **测什么**（可观测量与数据形式）：每个实验给出预期数据的具体形态——不是"测量谐波谱"，而是"11–21 阶谐波强度谱 I_q(T)，T 为 10–340 K 温度网格（T_N 附近加密 5 K）"；数据维度、坐标轴、典型信噪比量级。
3. **怎么测**（测量序列与参数点）：序列的步进/每点驻留/重复次数/平均方式；参数空间扫描的网格定义（哪些变量、各几个点、顺序）；差分/对照实验的配对方式。
4. **多久**（时间预算）：每数据点采集时间 → 单组实验总时长 → 全部实验的累计需求 → 与项目年限/装置机时的匹配结论。给不出时间预算的方案等于没设计。
5. **怎么从数据到结论**（分析链）：原始数据 → 标定/扣本底 → 提取量 → 与理论预言对照 → 判定判据，每一步指明方法与工具。分析链断裂处即方案造假处。

## 二、方案六要素模板（每个实验小节的写法）

按"装置配置 → 样品准备 → 测量序列 → 预期数据 → 分析方法 → 时间预算"六要素以连贯段落叙述（不是表格清单）。要素齐备的判据就是操作性五问逐问有答。理论计算类内容同样适用（"拿什么做"=模型与参数来源，"测什么"=输出量与扫描网格，"多久"=算力与时长估算）。

对照样例：

不合格（只有框架）：
> 开展自旋分辨 HHG 测量，温度覆盖反铁磁相与跨 T_N 区间，验证理论预言。

合格（六要素齐）：
> 测量在自建 3 μm 中红外 HHG 装置上进行：光学参量放大器输出 0.41 eV、脉宽小于 30 fs 的驱动脉冲，峰值强度 0.5–2 TW/cm²，经半波片与四分之一波片组合调控偏振后聚焦至样品（光斑约 100 μm）。块体 α-MnTe 单晶机械解理后以 SQUID 确认 T_N ≈ 310 K，置入 10–340 K 恒温器。每个温度点采集各阶谐波的椭圆率与螺旋度序列，单点积分 60 s、重复 30 次取平均，温度网格在远离 T_N 处取 20 K 步长、T_N ± 10 K 内加密至 5 K，全程约 40 个温度点、累计约 20 小时机时。谐波经消光比大于 10⁴ 的偏振分析器分通道探测，预期 11 阶附近计数率 10²–10⁴ counts/s，SNR 优于 3:1。数据经偏振响应函数标定后，将各阶椭圆率-螺旋度序列与理论正演预言逐温度对照，判定自旋纹理特征是否写入谐波谱。

## 三、课题设想六模块（idea 生成模板）

新课题设想须含六模块，缺一不可（防空泛课题与换皮课题）：
1. **背景与动机**：领域态势两三句 + 为什么此刻值得做（窗口期/新能力/新矛盾）
2. **核心科学问题**：一句话可判定的问题（不是方向名词）
3. **route（技术路线分步）**：3–5 步，每步有输入/动作/输出，能落到方案六要素
4. **validation（验证方案）**：怎么知道做成了——判据、对照、独立交叉验证路径
5. **comparison（与参考工作的区别）**：明确指出最近邻的 2–3 项工作，逐项说清增量（不是"国内外尚未见报道"一句话打发）
6. **feasibility（可行性锚点）**：装置/样品/理论工具的既有基础各一条

新设想与现有课题的方向相关度低于阈值时宁可 defer 积累，不硬立项。

## 四、课题文档五模块职责边界（手册定位）

- **立项依据（rationale）**：领域意义 → 沿革由远及近 → 核心挑战收窄 → 国内现状 → 本项目定位，末尾自然引出科学问题。手册语境下的取舍：国内现状段从简（不服务说服），物理入口与关键文献论证保留（服务理解课题）
- **研究内容（content）**：总述段（问题+路线+机制+产出）→ 2–3 个分方向（每方向自解释标题）→ 研究目标（每条含量化指标）→ 关键科学问题。手册语境：分方向可含核心方法与判据的概述（研究者先在这里看清骨架），装置与序列细节留 scheme
- **研究方案（scheme）**：操作性五问的主战场——六要素模板逐实验展开；手册语境下参数表、采集序列、时间预算直接进正文；风险与应对集中末节
- **全文骨架（full_review）**：≤3000 字逻辑骨架与跨章指标表，不写正文性内容
- **参考文献（references）**：30–40 条，嵌入式引用支撑关键论断（手册语境：引用是溯源工具不是说服工具，关键参数的文献出处必须可回查）

## 五、质量递进链（课题生命周期方法论）

设想（六模块）→ 优化轮（writer-critic 对抗，风格纪律见 nsfc-writing skill）→ 人工验收（操作性与科学性终审）→ 归档知识萃取。每环的产出标准：设想过六模块关、方案过五问关、全文过风格关、终审过人工关。质量不达标的课题宁可退回上环重做，不带病流转。

## 六、常见失败模式

1. 框架性方案（"建立模型、开展测量、实现反演"三段论无实体）→ 用六要素模板重写
2. 参数无来源（拍脑袋数字）→ 每个关键参数注明文献依据或预研标定计划
3. 时间预算缺失 → 强制回答第四问，答不出说明实验设计未完成
4. 分析链断在"数据拿到了"→ 强制回答第五问到判据层
5. 换皮课题（与现有课题方法骨架同构仅换对象）→ comparison 模块逐项说增量，说不出即 defer

## 七、6 章节硬模板（v7.2.32 守卫要求）

writer 落盘的方案文档（`04_proposal/proposal-draft-r*.md`）必须按以下 6 个 H2
章节顺序排列——`scripts/proposal_structure_guard.py` 在每轮优化后自动校验：
- 缺 ≥ 2 章节 → 阻断流程（fail）
- 缺 1 章节 → 警告（warn），不阻断
- 顺序错乱 → 阻断

```
## 〇、产出定位                  （≥ 200 字：与现有课题差异、目标读者、读完该会做什么）
## 一、立项依据（rationale）     （领域 → 沿革 → 挑战收窄 → 本项目定位）
## 二、研究内容（content）        （总述 + 2-3 个分方向 + 量化指标 + 关键科学问题）
## 三、研究方案（scheme）         （六要素逐实验展开：装置/样品/序列/预期/分析/时间预算）
## 四、特色与创新                  （区别于最近邻 2-3 项工作，逐项说增量，不是"国内外尚未见报道"）
## 五、预期成果                    （论文/专利/数据集/方法学资产，明确数量与质量指标）
```

章节识别宽松映射（兼容历史变体）：
- "立项依据" / "选题依据" → 立项依据
- "研究内容" / "主要研究内容" → 研究内容
- "研究方案" / "拟采取的研究方案" → 研究方案
- "特色与创新" / "研究特色" / "创新点" / "特色创新" / "主要创新点" → 特色与创新
- "预期成果" / "预期目标" / "预期结果" → 预期成果
- "产出定位" / "研究定位" / "本课题定位" → 产出定位

**v7.0.3 研究手册化后新增"产出定位"**（v7.0.3 章节 0：定位为研究手册不是申请书），
旧方案普遍缺——writer 下一轮实写时必须补上。

跨章口径表（如 ssh-weyl 7 章节方案中含 3 个跨章口径表）建议移到独立
`04_proposal/params.md` 文件，方案内只放指向 + 简表，不写整张大表。
