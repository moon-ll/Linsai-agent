# 方法学手册维护纪律与就绪度标准（method-manual）

方法学手册是课题方法细节的单一真相源（03_method/method-manual.md），由轮内专职步骤统一维护（v7.3.0 起为 method_manual 评审模块的 critic→writer 对抗链），writer 不得直接写手册。

## 一、更新纪律

1. **修订优先于追加**：更新已有小节时改写合并，禁止在原内容后追加"补充说明"——追加是手册膨胀分裂的根源。
2. **压缩任务**：手册超过 60KB 时先压缩再更新——只读目录与相关小节，合并重复表述，删除过时参数；正常轮指令一律"只读目录与相关小节"。
3. **去重**：同一方法/参数只在一处完整表述，其他位置用小节引用。
4. **无过程记录**：手册只写方法学内容（模型/参数/判据/边界），严禁写入轮次过程、评审意见、修复声明。
5. **膨胀检测**：单次更新后体积增长超过 10% 属异常，需要复核是否违反修订优先原则。
6. **外部方法吸收**（v7.0.5）：每轮更新时检索 knowledge/wiki/methods/ 方法页（文件名即方法名索引），与本课题方案相关的方法/参数按参数溯源纪律并入手册——方案缺装置/序列/参数等可实施细节时，优先从已验证方法页取材（标注来源），不凭空编造；手册是方案细节与文献方法素材的汇合点。

## 二、判据口径表（关键结构）

跨章节共享的判据定义（如加性/乘性分档、三档阈值、量纲身份）必须在手册头部维护"判据口径表"作为单一真相源：每行一个判据，含定义、适用条件、数值、来源。申请书各章节与手册按同一映射执行，发现不一致以口径表为准并报告。

## 三、参数溯源

手册中的每个关键参数注明来源：文献引用（作者+年份）、DFT 计算、或预研标定计划。无来源的参数标记"待标定"，不得伪装成有据。

## 四、手册就绪度标准（v7.3.0 用户裁决 2026-11-02）

课题产出的目的是**提供可以开展的课题**：研究方法手册的详细程度与完整度决定课题能否正式开工。手册是生命周期第六评审模块（method_manual），就绪度是验收硬门——L≥3 且 2 维口径分达标（见下）才允许"建议通过"与归档开工。

### 八要素清单（每个"方法单元"逐项核查）

手册按申请书研究内容/技术路线逐项组织**方法单元**（R1/R2/R3…每项研究内容对应至少一个方法单元），每个方法单元核对：

| # | 要素 | 判定实质 |
|---|---|---|
| ① | 覆盖度 | 每项研究内容都有对应方法单元，无遗漏（缺一项即 critical） |
| ② | 原理表述 | 物理/数学模型与核心机制两三句讲清"算什么/测什么、为什么成立" |
| ③ | 参数表可复算 | 数值+单位+出处一行一参数；无来源标"待标定"；第三方可照表复算 |
| ④ | 实施协议 | 步骤化流程：计算设置/实验序列/软件与装置，操作员可照做 |
| ⑤ | 数据判据 | 输入输出与 Go/No-Go 判据明确，与判据口径表一致 |
| ⑥ | 失效模式与边界 | 适用边界、No-Go 条件、风险与替代方案 |
| ⑦ | 资源估算 | 核时/机时/装置需求量级（与申请书口径一致） |
| ⑧ | 溯源闭环 | 手册↔申请书口径表双向索引；KB 方法页引用落地（wikilink） |

### 就绪度分级（先数档再定级，禁止印象式）

- **L0 占位/缺失**：手册为注册占位或未覆盖多数研究内容（要素①不过）。
- **L1 提纲**：方法单元齐但多数仅列标题/一句话（②③④大面积缺）。
- **L2 参数可复算**：多数方法单元的参数表齐（③过），但协议与判据不完整（④或⑤缺）。
- **L3 协议可执行**：①-⑤全过——具备开工条件（就绪门槛）。
- **L4 失效模式+溯源闭环**：L3 基础上⑥⑦⑧全过——可交付第三方复算（0.90+ 锚）。

### 评分契约（手册 critic 专用，2 维口径 manual_2d）

- **严谨性（rigor）**：参数溯源真实、数值可复算、与口径表/申请书一致（对应要素③⑤⑧）。
- **就绪度（readiness）**：八要素覆盖与可开工程度（对应①-⑧整体 + L 分级）。
- 创新性/可行性/表达质量标记 N/A；综合评分 = 两者均值；锚点纪律与 quality-review skill 一之二同款（先数过项数再打分，L4=0.90+ 锚，L3≈0.85，禁折中摇摆）。
- 报告末尾评分块为纯文本行，且必须含独立一行 `手册就绪度：L<数字>`（0-4）。

### 预演判据（v7.3.10 增补，L3 认证可选强化项）

L 分级评的是"写没写"，不保证"照做会不会卡"——critic 文本层评审对执行者断链存在结构性盲区（ssh-weyl 预演实证 14 条）：

- **引文断链**：手册引文编号与权威 refs 错位且无附录引用表（执行者按号拉文献拿到完全无关论文）
- **资产断链**：引用不存在的代码/数据资产（"已有 src/..." 实为规划）
- **中间量断链**：判据的关键量无定义（如压缩度 κ）、输入量从哪个步骤产出未写
- **数值-窗口自相矛盾**：判据阈值超出手册自身的强度扫描窗
- **KB 参数错引**：与被引方法页原文数值/量级不符（错的是"权威依据"，最难自查）

**强化项**：L3+ 手册建议附"第 1 周推演表"（入职研究生视角：D1 环境/算力 → D7 首产出，逐步标注 ✓/△/✗）作为开工就绪度的实弹证据。执行预演报告（`05_review/execution-rehearsal*.md`）的断链清单由手册 critic 步自动注入评审 prompt（v7.3.10），预演断链视为待核销缺口——已解决须在评审意见中逐条标注。
