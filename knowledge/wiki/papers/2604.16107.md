## 阅读笔记

### general-attosecond-streaking-20260822

### 研究问题（Research Question）
在双缝实验的 bipartite 系统中，干涉条纹可见度取决于"哪条路"信息是否可得；本文追问强场多光子解离电离 D₂ 时光电子与残余离子能否形成 Bell 态、Bell 型纠缠，并证明离子（标记粒子）测量基的选择如何决定光电子全息干涉条纹是被压制还是被恢复——即在分子体系中实现"量子擦除器"。

### 研究背景（Background）
量子擦除实验已在光子、声子、电子、原子等体系实现。超快光致电离领域对相干性、关联与纠缠已有大量理论研究，实验上已分别演示了离子-电子纠缠态的制备与探测、以及纠缠导致单子系统相干性的改变，但两者始终在分开的实验中实现，强场电离的实验研究仍很少。本文首次在单次强场多光子电离实验中同时实现这两方面，用以连接量子信息概念与强场光电子光谱。

### 研究方法（Methods）
实验：1030 nm、约 35 fs (FWHM)、100 kHz 商业飞秒激光经 300 µm BBO 倍频到 515 nm，清洁偏振并补偿 BBO/透射光学引入的 chirp，用 75 mm 焦距后向球面镜聚焦到冷 D₂ 气流（选 D₂ 以避免背景 H₂ 污染），置于 COLTRIMS 反应显微谱仪中作离子-电子符合测量；计数率限制在 <0.2 events/shot；强度由与 D₂⁺ 符合的光电子谱高能截止估计，四个强度从 I≈9×10¹³ W/cm²（U_P≈2.2 eV）到 I≈1.4×10¹⁴ W/cm²（U_P≈3.5 eV）；因背景 H₂ 电离与低能 D⁺ 重叠，数据限于 KER>0.5 eV。理论：非 Born-Oppenheimer 网格 TDSE 模型，含核（1D 键长 R）、束缚电子（1sσ_g/2pσ_u 两能级偶极耦合）、活性电子（2D）三部分，软核势参数按文献电离势拟合；网格 384×384×256（Δx=Δz=0.4 a.u., ΔR=0.05 a.u.），远区零填充至 1536×1536×1024，动量分辨率 Δp_x=Δp_z≈0.01 a.u.；发散方向关联 C=(N₊−N₋)/(N₊+N₋)，N₊ 取 θ<π/6、N₋ 取 θ>5π/6，实验侧先将离子限制在 θ_D⁺<π/8 或 >7π/8 再按 KER 分箱。

### 主要发现与核心结论（Main Results）
D₂ 的多光子解离电离产生两条由离子宇称区分的通道：路径 A（离子处于奇宇称 2pσ_u，光电子取相反宇称）与路径 B（离子处于偶宇称 1sσ_g），构成纠缠态 |ψ_(A+B)⟩ = α|e_u/g⟩|2pσ_u⟩ + βe^{iφ}|e_g/u⟩|1sσ_g⟩。TDSE 给出通道权重随 KER 变化：KER~1 eV 由路径 A 主导，KER~3 eV 由路径 B 主导，KER~2 eV 两者近乎等权（α≈β）。实测发射方向关联 C 在 KER>1.8 eV 处呈明显振荡且围绕零过零（TDSE 复现），C ≈ −2αβcosφ，是纠缠的直接证据；强度升高时 C 振荡幅度增大且相位平移，归因于激光诱导 Stark 效应扭曲 1sσ_g 与 2pσ_u 势能曲线。干涉图样方面：KER≈1.15 eV（几乎纯路径 A，α≈1，非纠缠可分离态）时光电子动量分布中全息干涉条纹清晰可见；选取 A、B 近乎等权的 KER 区间（纠缠态）时条纹被强烈压制，因为 D⁺ 发射方向提供了 which-way 信息（相当于隧穿出口侧别信息）；按离子宇称（gerade/ungerade）作后选可恢复干涉条纹。简单双缝模型取 d=10 a.u.、Δr=150 a.u.，路径 A 与 B 的全息图样互补（一个的极大与另一个的极小重合），非相干相加后完全抵消。

### 潜在研究方向（Future Directions）
本文的"擦除"仅在 TDSE 解中通过按离子宇称后选实现，实验上尚无法直接测量 D₂⁺ 的宇称，作者把用 XUV 强探测脉冲直接探测离子宇称列为"ambitious goal for future studies"。已知局限：TDSE 未做焦体积平均，且降维（活性电子 2D、不考虑转动与质心运动）导致计算 C 值大于实验；光电子 l/r 基的空间局域性并不完美，故即使 α=β=1/√2，C 仍小于 1；理论与实验峰值强度存在约 15% 偏差（TDSE 最优参数取 7.7×10¹³ W/cm²、52.5 fs sin² 包络，实验强度 5.6×10¹³–1×10¹⁴ W/cm²、35–70 fs）；TDSE 计算需数十万 CPU 小时、代码需作者授权方可使用。


## 研究方法（方法卡）

**方法**：强场多光子解离电离 D₂ 的离子-电子 Bell 纠缠/量子擦除实验（COLTRIMS 符合测量 + 非 Born-Oppenheimer 网格 TDSE）

**原理**：D₂ 强场多光子解离电离产生两条由离子宇称区分的通道：路径 A（离子奇宇称 2pσ_u、光电子相反宇称）与路径 B（离子偶宇称 1sσ_g），构成纠缠态 |ψ⟩ = α|e_u/g⟩|2pσ_u⟩ + βe^{iφ}|e_g/u⟩|1sσ_g⟩；实测发射方向关联 C=(N₊−N₋)/(N₊+N₋) ≈ −2αβcosφ（围绕零过零振荡）为纠缠直接证据；D⁺ 发射方向提供 which-way 信息压制光电子全息干涉条纹，按离子宇称（gerade/ungerade）后选可恢复条纹——分子体系量子擦除器；TDSE 给出通道权重随 KER 变化：KER~1 eV 路径 A 主导、~3 eV 路径 B 主导、~2 eV 近等权（α≈β）。
