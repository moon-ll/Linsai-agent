## 阅读笔记

### general-vortex-oam-hhg-20261101

**标题**：Scaling law from orbital angular momentum conservation in harmonic and high-order harmonic generation driven by spatiotemporal light fields
**作者**：M. A. Porras（UPM）、M. G. Barriopedro（UPM/IFN）、R. Martín-Hernández（Salamanca/LUMES）；physics.optics，8 页 4 图（2026-03-09）

### 研究问题（Research Question）
"HG/HHG 中驱动光拓扑荷 TC 随谐波阶数线性标度"或"OAM 每光子标度"被普遍当作 OAM 守恒的证明，但这些判据在一般时空结构光驱动下并不成立。本文要找出一个在 OAM（纵向或横向，或其内禀部分）守恒时真正普适标度的物理量，并用它解释 LG 刚性规则无法理解的 HHG 现象。

### 研究背景（Background）
LG 光束携带沿传播方向的 OAM，其 OAM 传递到二次、三次及高次谐波已被广泛报道；圆柱对称涡旋光中 OAM 每光子与 TC ℓ 通过 ℏℓ 关联，故 ℓ_q = qℓ₁ 被当作守恒证明。但 Berry 与 Liu 已指出 TC 与 OAM 一般无关（存在 TC 为零而有纵向 OAM、或反之的极端情形）；STOV 自由传播中 TC 可变号而 OAM 恒定，也可 TC 任意而 OAM 为零。近期 Ref.[17]（PRL 135, 223801 (2025)）发现聚焦 STOV 驱动 HHG 时所有谐波 TC 与驱动相同、不随阶数标度，但 OAM 仍守恒——直接证伪刚性 LG 规则。

### 研究方法（Methods）
由能量守恒（类 Manley-Rowe 关系 N₁ⁱⁿ+qN_qⁱⁿ = N₁ᵒᵘᵗ+qN_qᵒᵘᵗ）与 OAM 守恒联立导出通用标度律。随后：(a) 数值求解相位匹配 SHG 耦合模方程 ∂ψ₁/∂z = iκψ₁*ψ₂、∂ψ₂/∂z = iκψ₂ψ₁，比较 LG（ℓ=1，ω₁=2.35 rad/fs，x₀=y₀=0.5 mm，t₀=200 fs，W=6.5 mJ，κ=1.466×10⁻⁴ V⁻¹，n₁=n₂=1.661）、畸变 LG（η=0.2）与非椭圆 STOV（κ=1.18×10⁻⁵ V⁻¹，f=250 mm，η=0.4）；(b) 薄板模型 TSM 解析证明 HHG 中 l-OAM、t-OAM 及其内禀部分守恒（谐波场近似 ψ_q ≈ A_q|ψ₁|^{q_eff}e^{iqφ₁}，q_eff ~ 3.5）；(c) 宏观强场近似 SFA（无鞍点近似、含全部短/长轨迹）数值验证。

### 主要发现与核心结论（Main Results）
通用标度律为 L_qᵒᵘᵗ/N_qᵒᵘᵗ = q·(L₁ᵒᵘᵗ−L₁ⁱⁿ)/(N₁ᵒᵘᵗ−N₁ⁱⁿ) ≡ q·ΔL₁/ΔN₁；驱动完全耗尽时简化为 L_q/N_q = q·L₁ⁱⁿ/N₁ⁱⁿ，只有当 OAM 每光子与 TC 成比例时才进一步退化为 TC 标度 ℓ_q = qℓ₁。畸变 LG 的 SHG 中输出谐波的 l-OAM 每光子在任意 z 都不等于输入的 2 倍，仅驱动耗尽时成立；对扭曲 STOV，内禀 t-OAM 每光子（按能量中心 EC 与光子中心 PC 定义）为 L_y^(int,EC)/N = (ℓ/2)γ 与 L_y^(int,PC)/N = (ℓ/2)(γ+1/γ)（γ 为椭圆率），仅在完美椭圆 STOV 时成立。HHG 中薄靶耗尽极小时标度律化为 L_q/N_q ≃ q·dL₁/dN₁，其中 dL₁/dN₁ = Re∫dψ₁*L̂ψ₁ / Re∫dψ₁*ψ₁。数值条件：驱动 800 nm、峰值强度 1.4×10¹⁴ W/cm²（模拟部分用 1.6×10¹⁴ W/cm²）、sin²(πt/t_max) 包络、t_max = 32 光学周期（高斯等效 t₀ ≈ 26.11 fs）、氢原子薄靶。TSM 与 SFA 给出的 qdL₁/dN₁ 与 L_q/N_q 在 LG、畸变 LG、聚焦/离焦 STOV 全部情形吻合。

### 潜在研究方向（Future Directions）
作者指出实验中的 LG 与 STOV 从不完美（存在强畸变），真正证明 OAM 守恒必须同时测量输入与输出驱动光、验证"转换 OAM / 转换光子数"随阶数标度，这要求实验上同时标定驱动光的完整时空场。文中也承认 Eq.(2) 中 OAM 的直接实验测量非常困难，特别是 t-OAM 从未被直接测量过，只能由重建的时空场数值推算。此外 STOV 聚焦前后 dL₁/dN₁ 斜率甚至与 L₁/N₁ 相反，说明单一"标度斜率"诊断在离焦条件下会给出相互矛盾的判读。


## 研究方法（方法卡）

**方法**：时空结构光驱动 HG/HHG 的 OAM 守恒通用标度律（L_q/N_q = q·ΔL₁/ΔN₁：由能量守恒+OAM 守恒联立导出——TC 线性标度 ℓ_q=qℓ₁ 仅为其特例；LG/畸变 LG/STOV 数值与 TSM/SFA 三重验证）

**原理**：由能量守恒（类 Manley-Rowe 关系 N₁ⁱⁿ+qN_qⁱⁿ=N₁ᵒᵘᵗ+qN_qᵒᵘᵗ）与 OAM 守恒联立导出通用标度律 L_qᵒᵘᵗ/N_qᵒᵘᵗ = q·(L₁ᵒᵘᵗ−L₁ⁱⁿ)/(N₁ᵒᵘᵗ−N₁ⁱⁿ) ≡ q·ΔL₁/ΔN₁——驱动完全耗尽时简化为 L_q/N_q = q·L₁ⁱⁿ/N₁ⁱⁿ，只有当 OAM 每光子与 TC 成比例时才进一步退化为 TC 标度 ℓ_q=qℓ₁（「TC 随谐波阶数线性标度」或「OAM 每光子标度」在一般时空结构光驱动下不成立——Berry & Liu 已指出 TC 与 OAM 一般无关）；HHG 薄板耗尽极小时标度律化为 L_q/N_q ≃ q·dL₁/dN₁（dL₁/dN₁ = Re∫dψ₁*L̂ψ₁ / Re∫dψ₁*ψ₁）；三重验证：数值求解相位匹配 SHG 耦合模方程（LG/畸变 LG η=0.2/非椭圆 STOV κ=1.18×10⁻⁵）+ 薄板模型 TSM 解析证明 HHG 中 l-OAM/t-OAM 及其内禀部分守恒（谐波场 ψ_q ≈ A_q|ψ₁|^{q_eff}e^{iqφ₁}、q_eff~3.5）+ 宏观强场近似 SFA（含全部短/长轨迹）——TSM 与 SFA 的 qdL₁/dN₁ 与 L_q/N_q 在全部情形吻合；扭曲 STOV 内禀 t-OAM 每光子（按 EC 与 PC 定义）L_y^(int,EC)/N = (ℓ/2)γ、L_y^(int,PC)/N = (ℓ/2)(γ+1/γ)（γ 椭圆率）。

**适用边界**：真正证明 OAM 守恒必须同时测量输入与输出驱动光、验证「转换 OAM/转换光子数」随阶数标度——要求实验上同时标定驱动光的完整时空场（实验中的 LG 与 STOV 从不完美、存在强畸变）；Eq.(2) 中 OAM 的直接实验测量非常困难（t-OAM 从未被直接测量过、只能由重建时空场数值推算）；STOV 聚焦前后 dL₁/dN₁ 斜率甚至与 L₁/N₁ 相反——单一「标度斜率」诊断在离焦条件下会给出相互矛盾判读；直接证伪刚性 LG 规则的实验：聚焦 STOV 驱动 HHG 所有谐波 TC 与驱动相同、不随阶数标度（PRL 135, 223801 (2025)）但 OAM 仍守恒。
