## 阅读笔记

### general-ssh-weyl-20260920

**标题**：Topological central charge from Berry curvature: gravitational anomalies in trial wavefunctions for topological phases
**作者**：Barry Bradlyn, N. Read
**出处**：cond-mat.mes-hall, hep-th, cond-mat.str-el (2015)；PRB 91, 165306 (2015)

### 研究问题（Research Question）
能否仅从拓扑相的**体区基态波函数**（而非边缘理论）直接提取拓扑中心荷（topological central charge）c——具体做法是把空间度规（metric）绝热变化所产生的 Berry 曲率当作拓扑不变量来读出？由于已知热霍尔电导完全来自边缘、体区 Kubo 公式不足以给出 c，作者提出用体区的度规扰动 Berry 曲率来反推 c，并把霍尔电导率用同样的方式从 U(1) 规范反演中得到。

### 研究背景（Background）
Berry 相与低能有效作用之间的联系由来已久：量子霍尔电导可用 Kubo 公式写成 Berry 曲率；霍尔粘度（Hall viscosity）是流体质张量中的类比非耗散项，可写成环面上绝热改变长宽比/度规张量所产生的 Berry 曲率，并与球面上基态磁通数偏移（shift）相关；两者都对应有效作用中的 Chern-Simons 项（霍尔粘度对应第一 Wen-Zee 项）。但近期工作表明热霍尔电导完全来自边缘，这使得从体区访问中心荷需要 Kubo 公式之外的途径。作者强调本文方法给出的是一个**实数**的中心荷，而不像模 S 矩阵或动量极化那样只能确定到模 8 或模 24 的多重视。

### 研究方法（Methods）
综述 Berry 相与诱导作用的关系（绝热定理给出闭合路径上的相位 = 路径上的有效作用，Chern-Simons 项因含时间一阶导而直接贡献 Berry 相）。随后构造共形块（conformal block）试探波函数，并推广到同时含背景矢量势 δA 与度规扰动的情形；引入"全纯分解反常"（holomorphic factorization anomaly）概念——U(1) 规范场与度规扰动都会使 CFT 关联函数无法分解为纯/反纯函数。计算采用**广义屏蔽假设**（generalized screening）：局部算符关联随距离指数衰减，从而波函数范数平方与度规扰动无关（至少到 g 的二阶导数项），这允许只保留非纯项并只取 |μ|² 阶。用 Beltrami 微分 μ、$\bar{\mu}$ 描述度规扰动并固定 det g = 1（故 $e^\Phi = 1/(1-|\mu|^2)$），固定 $A^0_\mu = A_\mu + s\omega_\mu$，以功能导数定义 Berry 联络。

### 主要发现与核心结论（Main Results）
**主要结果一（Hall 电导）**：对环面上均匀矢量势扰动（等价于扭曲边界条件），Berry 联络 $A_{\delta A} = -iL^2/(8\pi)\,\delta\bar A$，Berry 曲率 $F_{\delta A,\delta\bar A} = iL^2/(4\pi)$，换算回物理量得 $F_{A_1,A_2} = -L^2\nu/(2\pi)$，除以面积后给出**霍尔电导率 $\sigma_H = \nu/(2\pi)$**，与从 U(1) Chern-Simons 项独立推出的 Berry 曲率完全一致。作者称这是首次直接从共形块波函数的分解行为推出霍尔电导率。**主要结果二（中心荷）**：度规扰动下的功能 Berry 曲率为 $F_{\bar\mu\mu} = -F_{\mu\bar\mu} = i\rho s\,\delta(z-z') + \frac{ic}{12\pi}\partial\bar\partial\delta(z-z')$——第一项给出霍尔粘度（等于第一 Wen-Zee 项系数），**第二项直接含有手征 CFT 的中心荷 c**，由此 c 等于构造波函数所用 CFT 的 c_CFT（这是两个主要结果）。**具体化**：取 $\mu = \mu_0 e^{ik_\nu x_\nu}$ 时 $F_{\bar\mu_0,\mu_0} = i(\rho s - c|k|^2/48\pi)L^2$，可见中心荷贡献 Hall粘度的 $O(|k|^2)$ 部分。无外磁场的 p-ip 配对态例子给出引力 Chern-Simons 项系数 $c = 1/2$，而霍尔粘度需用"Euler current"项描述。数值上：若先由霍尔电导率与霍尔粘度定出系数，则 Berry 曲率给出的是 $c - 12\nu\,\mathrm{var}\,s$（$\mathrm{var}\,s = \overline{s^2}-s^2$，轨道自旋方差）；若假设 $s^2 = \overline{s^2}$，则 c = c_CFT 成立。作者并指出 Ref. 18 在本文第一版后自行发现计算错误，修订结果（Ref. 47）与本文一致。

### 潜在研究方向（Future Directions）
**关键局限**：从体区 Berry 曲率原则上只能得到 $c - 12\nu\,\mathrm{var}\,s$，无法把 $\mathrm{var}\,s$ 与 c 分离——因为第二 Wen-Zee 项与引力 Chern-Simons 项在体区不可区分，必须靠边缘信息；作者的场论论证（边缘的重力反演要求引力 Chern-Simons 系数等于边缘 c，且无 Lorentz 对称时第二 Wen-Zee 项无对应反演）导出 $\mathrm{var}\,s = 0$，但这是间接论证。作者还批评 Wen-Zee 原文给出的准粒子自旋表达式含量子数线性项，违反自旋-统计定理（Laughlin 态与 WZ 直接冲突），并质疑其 $s^2$ 推导的可靠性。多组分推广已给出初步轮廓（Berry 曲率形式与单组分相同，霍尔粘度等于轨道自旋密度的一半，c = c_CFT），但完整诱导作用结构因额外 U(1)/非 Abelian 对称而更复杂，只作了勾勒。


## 研究方法（方法卡）

**方法**：拓扑中心荷的体区 Berry 曲率提取（度规扰动引力反常 + 共形块波函数，PRB 2015）

**原理**：把空间度规绝热变化产生的 Berry 曲率当拓扑不变量读出：共形块试探波函数 + 广义屏蔽假设（波函数范数与度规扰动无关至二阶）下，U(1) 规范扰动 Berry 曲率给出霍尔电导率 σ_H=ν/2π；度规扰动功能 Berry 曲率含 iρsδ 项（霍尔粘度=第一 Wen-Zee 项系数）与 ic∂∂̄δ/12π 项——后者直接含手征 CFT 中心荷 c。给出实数中心荷（相对模 S 矩阵只能定到 mod 8/24 的多重视）。

| 示例 | 无外磁场 p-ip 配对态引力 Chern-Simons 系数 c=1/2 | 主要发现与核心结论 |

**适用边界**：体区 Berry 曲率原则上只能得 c−12ν·var s，var s 与 c 无法分离（第二 Wen-Zee 项与引力 Chern-Simons 项在体区不可区分，需边缘信息）；var s=0 由场论论证间接导出非直接证明；多组分推广仅勾勒；作者批评 Wen-Zee 准粒子自旋表达式违反自旋-统计定理。
