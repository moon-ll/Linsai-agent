• # Empirical-Bayes Unfolding of γ-ray Spectra

  ## 林赛的理解

  这篇工作是核结构物理里"病态反问题正则化"的一个干净范本，但对我这样的强场超快 PI 来说，价值在于**方法学骨架的可迁移性**：我们处理阿秒 streaking 谱反演、强场光电子谱 unfolding、HHG 谱的仪器响应反卷积时，面对的是完全同构的数学结构——泊松计数 + 探测器响应矩阵（非负、病态、奇异值快速衰减）+ 背景扣除。作者给出的三个关键设计决策可以直接搬过来：① 把不确定性报告在**分辨率极限尺度**（η = Gγµ）而非原空间 µ，这一条直接回应了我们 HHG 谱反演中"亚分辨率振荡"的老问题；② 联合 ON/OFF 似然替代确定性背景扣除，避免低计数区出现负计数和非泊松差值（Skellam 分布问题）——这和我们在磁光谱仪上处理暗计数背景的场景一一对应；③ 经验贝叶斯先验（Richardson-Lucy 参考 + 自适应宽度）在"采样可靠"和"先验偏置"之间取平衡，对我们做谱反演的 prompt 级方法论设计有参考意义。数值上，四链 NUTS、每链 2000 warm-up + 2000 draws、单谱耗时约 1 分钟到半小时（多核笔记本 CPU），说明这条路在工程上是可负担的。

  ## 研究问题

  如何从经过探测器响应畸变的计数数据中，稳定反演出发射 γ 谱 µ，同时满足三个约束：保持泊松计数结构、强制非负性（µ ≥ 0）、并对反演不确定性给出可量化的置信带？具体地，这是在 Oslo 方法框架下，从（粒子望远镜 SiRi 定激发能 Ex + OSCAR 闪烁体阵列测 γ 能）符合测量得到的二维计数矩阵中，为每个固定 Ex bin 解一个一维病态泊松逆问题，替代现有 Richardson-Lucy 迭代和频率学派正则化最大似然（RMLE）框架，并获得贝叶斯意义下严格的非负不确定性量化。

  ## 研究背景

  - **物理动机**：核统计性质——核能级密度（NLD）和 γ 射线强度函数（γSF）——是核结构研究和天体物理 (n,γ) 反应率计算的核心输入，二者通过 Oslo 方法从初级 γ 谱经多步分析导出。
  - **问题本质**：探测器响应和有限能量分辨率把不同的非负发射谱映射成几乎不可区分的探测谱——离散化前向算子病态，奇异值快速衰减，小奇异值方向被泊松涨落按 1/σℓ 放大（Eq. 12），直接反演会强烈放大统计涨落（离散 Picard 条件刻画）。
  - **前人工作脉络**：高能自旋 γ 谱学早有响应修正（剥离程序，Ge 探测器响应函数，单谱/符合矩阵）；液闪探测器上有人用神经网络 unfolding 光子和中子谱；高能物理中 D'Agostini 迭代贝叶斯 unfolding 广泛使用，与 Richardson-Lucy 期望最大化算法族关系明确；近期核物理应用中最直接的基准是频率学派 RMLE 框架（非负约束 + 响应感知前向建模 + bootstrap 不确定性量化）。本工作即用贝叶斯层级框架与之正面对比。
  - **经典方法的两大痛点**：正则化强度 λ 或 RL 停止迭代的选择敏感、且随数据集变化；惩罚解或早停点估计周围的不确定性量化非平凡，高斯误差棒在非负边界和弱约束方向上系统性低估不确定性。

  ## 研究方法

  **方法密度中高——核心贡献是方法创新，以下按方法卡格式整理。**

  **1. 原理**

  经验贝叶斯层级泊松反演：对发射谱 µ 施加以数据驱动参考（RL 估计）为中心的软先验，保留泊松计数结构和非负性，用 NUTS 采样后验，并在分辨率极限尺度 η = Gγµ 上报告联合不确定性带。模型在 µ 空间指定（因为 Gγ 与 D 不对易，ν = GγDµ 的顺序对应物理探测序列），避免直接在 η 空间建模所需的病态逆映射。

  **2. 参数表（数值原样，出自原文）**

  - **前向模型**：H = Gγ M Gin（分辨率极限强度），V = Gγ D M Gin（期望探测信号），其中 Gγ 与 D 不对易，Rγ := GγD（Eq. 1-2）；算子归一化保证固定 Ex bin 下 Σⱼ Vⱼ,ₖ = Σⱼ Mⱼ,ₖ（Eq. 4）。
  - **似然**：Nⱼ,ₖ | V,B ~ Poisson(Vⱼ,ₖ + Bⱼ,ₖ)（ON），Noff ~ Poisson(B)（OFF），联合 ON/OFF 似然（Eq. 5, 6, 29），避免确定性背景扣除。
  - **背景构造（合成数据）**：b_true = (1−p)B sⱼ + p B/J，B = ρ Σⱼ νⱼ,true（Eq. 25-27），p=0 纯信号形背景，p>0 加均匀分量。
  - **活动域截断**：最小 Jact 使 Σ_{j=1}^{Jact} νⱼ,true ≥ (1−ϵ_tail) Σ_{j=1}^{Jfull} νⱼ,true（Eq. 24），边界记 Eγ^max。
  - **RL 参考**：背景感知更新 µ(t+1) = µ(t) ◦ [Rγᵀ (n / (Rγµ(t) + b_ref + ϵ))]；OFF 可用时 b_ref,ⱼ = (a₀ + n_off,ⱼ)/(b₀ + 1)（Gamma-Poisson 后验均值，Eq. 31-32）；迭代窗 w 内相对确定性变化 Δη(t;w) = ‖η(t)−η(t−w)‖₂/(‖η(t)‖₂+ϵ)（Eq. 33-34），与泊松重采样噪声水平 Nη 比较选半收敛停止点。
  - **采样**：NUTS via PyMC，4 链 × 2000 warm-up + 2000 后验 draws，单谱 wall-clock 约 1 分钟到约半小时（多核笔记本 CPU，取决于 Eγ bin 数、计数统计和采样后端）；每个 Ex bin 独立解一维问题（设 Gin = I）。
  - **合成数据**：RAINIER 模拟工具生成代表性 ¹²⁰Sn 级联数据集；响应矩阵用 OMpy（Oslo 方法 Python 实现）的 oscar2020 响应集（OCL 响应函数库，LaBr₃(Ce) 闪烁体，含全能量峰、康普顿连续谱、单/双逃逸峰）。
  - **病态性量化**：条件数 κ₂(Rγ) = σ₁/σ_J；减法估计量方差 Var(nⱼ − n_off,ⱼ) = νⱼ + 2bⱼ（等曝光 Skellam 情形，Eq. 18）；Fisher 信息 I(µ) = Rγᵀ diag(Rγµ + b)⁻¹ Rγ（Eq. 15）。
  - **Gin = I 近似的偏差控制**：∆V = Rγ M_true (Gin − I)（Eq. 30）；Ex bin 加宽到 ∆Ex ≈ 1.5 FWHM（相比 ∆Ex ≈ FWHM）时相邻 bin 正负偏差部分抵消，探测信号偏差显著减小。

  **3. 适用边界**

  - 一维独立 unfolding 忽略 Ex 方向涂抹（Gin = I），偏差大小取决于 Ex bin 宽度和谱沿 Ex 轴变化速率；高激发能准连续区变化更平滑、偏差更小。
  - 报告量 η 不消除问题本身的病态性，只是把后验、真值和不确定带放到探测器分辨率尺度上；µ 空间的高频结构本质上不可恢复。
  - RL 参考的先验设定不确定性不传播进后验——作者明确承认这是"必要近似"，并通过敏感性分析（Sec. IVB）量化其影响。
  - 完全贝叶斯超先验方案（对先验中心和宽度再设超先验）在本问题中采样不可靠（弱识别方向、强参数依赖、梯度采样器混合差），尤其对含类 δ 窄峰的谱。

  **4. 代表作**

  - 本文：Mjøs et al., arXiv:2606.24971 (2026)，Oslo 组经验贝叶斯 unfolding 框架。
  - 直接对比基准：RMLE 框架（原文 Ref. [14]）——非负约束 + 响应感知前向 + bootstrap 不确定性，核物理 γ 谱 unfolding 的频率学派现状。

  ## 主要发现与核心结论

  - 经验贝叶斯层级 unfolding 在保留泊松计数结构、强制非负、联合 ON/OFF 背景下完成 γ 谱反演，并用 NUTS 获得后验；后验摘要报告在分辨率极限谱 η = Gγµ 上，亚分辨率的 µ 空间高频振荡经 Gγ 映射后大幅衰减，η 上构造的同时性不确定带远更稳定（Fig. 3：µ 空间后验 draws 呈宽幅高频振荡曲线簇，同一批 draws 映到 η 空间后紧贴 η_true）。
  - 合成验证（RAINIER ¹²⁰Sn，已知真值）覆盖：先验→后验收缩、后验预测检验、经验贝叶斯构造敏感性、备选建模稳健性、低统计先验依赖。
  - 与频率学派 RMLE 的直接对比：在高统计和低统计代表性情形下，两种方法给出的 unfolded 谱**高度一致**（"highly consistent unfolded spectra"）。
  - 工程可行性：4 链 × 2000 warm-up + 2000 draws 配置下，基准谱单条 wall-clock 约 1 分钟至约半小时（多核笔记本 CPU）。
  - 背景处理：确定性 ON−OFF 减法在等曝光下是 Skellam 分布、可产生负值，方差 νⱼ + 2bⱼ 在信号弱于背景时相对不确定度 √ (νⱼ + 2bⱼ)/νⱼ 发散；联合似然在低计数区保持非负泊松结构。
  - Ex 涂抹近似：bin 宽度从 ∆Ex ≈ FWHM 加宽到 ∆Ex ≈ 1.5 FWHM 时，由 Gin = I 引起的期望探测信号偏差显著减小（Fig. 4）。

  ## 潜在研究方向

  - 二维联合 unfolding：本文逐 Ex bin 独立解一维问题、设 Gin = I 是显式近似，全 (E_x, E_γ) 矩阵的耦合二维反演（含 Ex 方向涂抹）尚未解决，是最自然的扩展方向。
  - 先验设定不确定性的传播：RL 参考的选择不确定性被刻意不传播，其系统性影响仅靠敏感性分析覆盖，缺乏严格量化。
  - 低统计区域的先验依赖：弱数据区后验由先验主导，经验贝叶斯宽度的自适应调谐规则还有打磨空间。
  - 窄类 δ 峰结构下的采样几何：更灵活的层级先验（非中心参数化、替代采样器）在被否决的完全贝叶斯方案上仍可能有更优表述。
  - 超物理迁移：框架声明"robust and extensible"，对非 Oslo 场景（如液闪中子谱、HEP unfolding）的推广未经实测；对含强相关结构响应（非因子化算子）的探测器是否成立需重新验证。

  ## 与林赛研究的关联

  - **谱反演的共同骨架**：HHG 光谱、streaking 光电子谱、时间分辨磁光克尔/交变磁信号的反演同样是"泊松/散粒噪声 + 仪器响应矩阵 + 非负约束"的病态逆问题。本文的联合 ON/OFF 似然可直接迁移到我们处理泵浦-探测暗计数背景的流程，替代减法估计量（Skellam 方差 ν + 2b 的教训值得写进我们的误差分析规范）。
  - **分辨率尺度报告范式**：把推断结果和不确定带统一放在探测器分辨率尺度（η = Gγµ）而非原空间，这一条对我们 HHG 谱峰位/产额拟合的方法学设计有直接借鉴意义——亚分辨率振荡不该进报告量，该进的是分辨率极限量。
  - **经验贝叶斯先验设计**：RL 参考 + 自适应宽度的"数据驱动先验中心 + 弱约束区保持宽先验"思路，与我们在 HHG 产额反演、对比度优化中"用低成本估计锚定、用似然主导强数据区"的哲学一致，可作为 prompt 级方法论素材进入 method 库。
  - **方法素材**：响应矩阵因子化（非对易算子顺序、归一化条件）、Fisher 信息刻画病态性、条件数 κ₂ 与有效数值秩的诊断流程，是课题方案写作中"判据/误差预算"一问的可复用素材，建议经 method_leads 沉淀进 methods 页。

## 研究方法（方法卡）
<!-- methods-backfill:v1 -->
**方法**：γ 射线谱的经验贝叶斯层级展开（联合 ON/OFF 似然 + RL 参考先验 + NUTS 采样 + 分辨率尺度报告）

**原理**：对探测器响应畸变的泊松计数数据做层级泊松反演：前向模型按物理探测序列指定算子顺序（H = G_γ·M·G_in，G_γ 与 D 不对易）；联合 ON/OFF 似然（ON: Poisson(V+B)、OFF: Poisson(B)）替代确定性背景扣除（避免 Skellam 分布负计数、等曝光方差 ν+2b 的发散）；对发射谱 µ 施加以数据驱动 RL（背景感知 Richardson-Lucy，半收敛停止）参考为中心的软先验（经验贝叶斯，自适应宽度），用 NUTS 采样后验；关键设计：不确定性报告在分辨率极限尺度 η = G_γ·µ 上（µ 空间亚分辨率高频振荡经 G_γ 映射后大幅衰减，η 上同时性不确定带稳定），µ 空间高频结构本质上不可恢复。
