• # Resolution of Topology and Geometry from Momentum-Resolved Spectroscopies：从谱强度直接读出能带拓扑与量子几何

  ## 林赛的理解

  这篇工作是方辰组给"量子几何可观测化"这一长期难题给出的一个理论框架级答案。核心思想非常干净：把 ARPES/INS 的谱强度重写为"波函数形状因子"（WFF）矩阵——即实验探针态与子空间投影算符的重叠——那么谱强度就不再只是画能带的颜料，而是包含了布洛赫波函数全部几何信息的可观测量。对我们而言，这篇论文的真正价值不在于它做了某个具体材料的测量，而在于它把"量子几何如何被实验读出"变成了一个有严格数学保证的线性代数问题（矩阵反演 + 拓扑选择规则 + 投影等变）。

  我特别看重两件事：第一，拓扑选择规则给出的"谱节点"判据——任何非平庸拓扑不变量都强迫 WFF 行列式在包络面上出现零点，这提供了一种不依赖模型拟合的拓扑诊断方式，比传统的"看费米弧/表面态"更直接也更普适；第二，当探针数 Np 超过能带数 Nb 时，"压平"WFF 得到的有效投影算符 Πk 与原投影算符拓扑等价（向量丛同构），从而可提取非阿贝尔贝里曲率、量子度规和 Wilson loop 谱。这把过去只能算出来、测不到的东西变成了测量协议。虽然论文的载体是 ARPES 和 INS，但框架本质是"任意动量分辨谱学 + 完备探针基"，对我们将来设计利用强场驱动读出量子几何（例如 HHG 谱对量子几何的编码）的实验有直接的范式借鉴意义。

  ## 研究问题

  论文要回答的核心问题是：**能否从 ARPES（电子能带）和 INS（玻色子能带）的谱强度数据中，以模型无关（model-independent）的方式，同时提取布洛赫波函数的（i）全局拓扑不变量和（ii）局域量子几何（贝里曲率 + 量子度规）？**

  这一问题被拆成两个递进的子问题：

  1. 当探针数等于目标能带数（Np = Nb）时，谱数据中是否存在拓扑不变量的直接指纹？——答案是由拓扑选择规则保证的"谱节点"（spectral nodes）。
  2. 当探针数超过目标能带数（Np > Nb）时，谱数据的冗余是否允许重构有效的能带投影算符，进而提取非阿贝尔量子几何张量（QGT）、Wilson loop 谱和杂化 Wannier 中心流？——答案是由向量丛同构保证的有效投影算符 Πk。

  ## 研究背景

  现代凝聚态拓扑理论建立在布洛赫波函数几何性质的两层刻画上：全局拓扑（Chern 数、Z₂ 指标等量子化不变量）与局域几何（复量子几何张量 QGT——虚部为贝里曲率、实部为量子度规）。量子度规近年被认识到对平带物理、分数 Chern 绝缘体和非线性光学至关重要，但**从实验直接提取波函数几何始终是根本性挑战**。

  动量分辨谱学是绘制能带结构的首要工具：ARPES 针对电子能带，INS 针对玻色子（声子/磁振子）能带。它们擅长通过观察边界态和体能带交叉来**验证**拓扑，但提取体态波函数的拓扑与几何信息困难。已有进展包括：(1) 极化 ARPES 提取量子度规；(2) 通过实验可及的准 QGT 重构 QGT；(3) 利用带交叉附近强度调制与拓扑不变量的关系。但这些方法都依赖**两能带近似**，且只能确定阿贝尔几何量或布里渊区有限区域内的拓扑特征。

  本工作要突破的正是"两能带近似 + 局域阿贝尔量"这一限制，给出对多能带、非阿贝尔、全域的几何-拓扑同时可观测化的普适框架。

  ## 研究方法

  **核心概念——波函数形状因子（WFF）矩阵**：
  WFF 定义为实验探针态与能带投影算符的重叠，是一个厄米矩阵：

  Fab(q) = ⟨Waq|P̂k|Wbq⟩

  其中 P̂k = Σₙ₌₁^Nb |unk⟩⟨unk| 是目标 Nb 条（近简并、与其他能带能量分离）能带的投影算符；探针态 {|Waq⟩} 由实验构型决定——在 ARPES 中对应 e^(−ik·r̂)(ε̂·v̂)†|χqσ⟩（探针指标 a 为光偏振 ε 与光电子自旋 σ 的复合指标），在 INS 中由动量转移 q 和基态静结构（原子位置、核散射长度、磁结构因子与基态自旋取向）决定，探针指标 a 标记垂直于 q̂ 的磁偶极算符笛卡尔分量。关键前提：只要倒格矢 G ≠ 0，两类探针态在拓扑上都是平庸的。

  **强度矩阵与线性反演**：
  单一构型 c 测得的标量强度 Ic(k,ω) = Tr[ρc^probe I(k,ω)]。利用实验可实现探针密度矩阵集合张成 Np×Np 厄米矩阵空间这一事实，选取完备正交厄米基 {Γμ}（INS：Np = 2，Γμ 为泡利矩阵；自旋-偏振分辨 ARPES：Np = 4，Γμ = σᵢ⊗τⱼ，含 4×4 厄米矩阵全空间，归一化 Tr[ΓμΓν] = Np δμν），通过可逆矩阵 B 把探针密度矩阵展开为 ρc = Σμ Bcμ Γμ，得到线性方程组，逐分量反演：

  fμ(k)A(k,ω) = (1/Np) Σc [B⁻¹]μc Ic(k,ω)

  即 WFF 的每个分量（以谱函数为权重）由一组测量强度的特定线性组合确定。物理实现上，ARPES 中探测器自旋轴 P̂e（ρσ = ½(1 + P̂e·σ)）与入射光斯托克斯矢量 S（ρτ = ½(1 + S·τ)，|S| ≤ 1）可独立调节，张量积结构自然张满 4×4 厄米空间；INS 中 ρprobe = ½[C₀ + P̂out·C]，C₀ 与 C = (Cx, Cy, Cz) 是四个由入射中子偏振 P_in 和 q̂ 决定的厄米运动学矩阵，张满 2×2 厄米空间。

  **两条定理级结果**：

  - *拓扑选择规则*（Np = Nb）：非平庸拓扑阻碍波函数全局光滑规范的存在，与平庸探针态的拓扑失配强迫 WFF 行列式在包络面上出现零点（谱节点）。对单能带 Weyl 点（陈数 C），反证法证明 Faa(k) 不能有全局非零值；定量关系 C = Σᵢ d(kᵢ)，其中 d(kᵢ) = (1/2πi)∮ d log⟨unk|Waq⟩ 是谱节点的整数绕数（度）。一般形式为 Σᵢ∈V Qi = Σᵢ∈∂V d(kᵢ)（Z₂ 指标模 2 理解）。
  - *有效投影算符*（Np > Nb）：定义投影波函数分量 [ϕnk]a = ⟨Waq|unk⟩，F(k) = Σₙ ϕnk ϕ†nk。将 F(k) 的 Nb 个非零本征值压平归一，得到秩-Nb 投影算符 Πk = Σₘ ũmk ũ†mk。在无秩跌落条件（rank F(k) = Nb, ∀k）下，映射 P̂k → Πk 构成向量丛同构，Πk 与原投影算符拓扑等价、携带相同拓扑不变量（对称保护拓扑相要求探针子空间与对称性相容）。由 Πk 定义有效非阿贝尔 QGT：Q̃ᵢⱼ^mm′ = ũ†mk ∂iΠk ∂jΠk ũm′k，其厄米/反厄米部分分别给出探针分辨的量子度规与非阿贝尔贝里曲率；再由 Πk 构造 Wilson loop 算符 Wg(k⊥)，其本征相给出杂化 Wannier 电荷中心与谱流。

  **材料示例**：反铁磁体 Cu₃TeO₆（具有非平庸 Z₂ 磁荷的 Dirac/ nodal line 磁振子体系，近似 U(1) 自旋旋转对称性 Sz 守恒把一般 nodal line 夹成 Dirac 点）。利用全偏振分析，WFF 行列式可从标准四分量强度矢量 I(q, P, ω) = (I⁰, Iˣ, Iʸ, Iz)ᵀ 重构；对完全偏振入射中子 |P| = 1，等能面上强度矩阵行列式为：

  det[I(k)] = (I₀² − Σⱼ₌ₓ,ᵧ,𝓏 Iⱼ²) / (1 − (q̂·P̂)²)

  （在几何奇异点 q̂∥P̂ 之外成立）。由于 I(k,ω) = F(k)A(k,ω)，两者行列式在准粒子能带上（A > 0）共享同一节点结构，故 det[I] 的零点直接定位 det[F] 的拓扑谱节点。

  ## 主要发现与核心结论

  1. **拓扑选择规则的建立**：当 Np = Nb 时，任何非平庸拓扑荷都强迫 WFF 行列式在包络拓扑带交叉的闭合面上出现零点——谱节点。这些零点来自布洛赫波函数与平庸探针态之间的拓扑失配，作者称之为"拓扑选择规则"。节点在动量空间中组装成节点流形，构成拓扑不变量的直接指纹。

  2. **电荷-节点度定量关系**：证明了 Σᵢ∈V Qi = Σᵢ∈∂V d(kᵢ)，即体内总拓扑荷等于包络面上谱节点度（绕数）之和（Z₂ 指标模 2 理解）。数值验证：包围 C = 1 Weyl 点的球面上出现单个谱节点、相位绕 2π（Fig. 2(a)）；包围电荷-4 四极 Weyl 点的球面上出现 4 个一阶谱节点（d = 1），满足 Σᵢ dᵢ = 4 = C（Fig. 2(b)）。

  3. **谱节点弧（spectral nodal arc）**：晶格体系中 Weyl 点必成对出现且荷相反；当包络面形变时，谱节点在二维布里渊区切片 k = (kx, 0, kz) 上连成连接相反荷 Weyl 点（位于 (0,0,π/2/3π/2)，C = ±1）的一维节点弧，弧上 ARPES/INS 强度为零（Fig. 2(c)）。

  4. **Z₂ 拓扑的几何图像**：对复合 PT 对称（(PT)² = 1）的两能带体系，存在实的规范选择，一般带交叉为 nodal line，由两个独立 Z₂ 指标刻画（链环上的贝里相位 + 包络球上的 Z₂ 单极荷，即第二 Stiefel-Whitney 类）。π 贝里相位产生的零点在包围面上组装成二维"谱节点膜"（spectral nodal membrane），由 nodal line 界限；Z₂ 单极荷产生的零点组装成一维节点环，随球面形变扫出连接相反荷 nodal line 的"节点管"（nodal tube）（Fig. 1(b)）。

  5. **Cu₃TeO₆ 的 Z₂ 磁荷谱学特征**：模拟 det[F(k)] 显示，在包围 Dirac 点 D₂ = (π, π, π) 的球面上出现谱节点（Fig. 3(a)），确认非平庸 Z₂ 荷的选择规则；在二维切片 k = (k₁, k₁, k₂) 上节点连成 nodal arc，连接 D₂ 与其伙伴 D₃（相反 Z₂ 荷）。模拟中取倒格矢 G = 2π×(2,2,2)，位于 [111] 旋转轴上（与体系旋转对称相容），nodal arc 完全位于旋转轴上（Fig. 3(b)）。由于 Sz 守恒把一般 nodal line 夹成 Dirac 点，一般 Z₂ 情形预期的谱节点环也收缩为离散谱节点。

  6. **量子几何的可观测化**（Np > Nb）：压平 WFF 得到 Πk，构造有效非阿贝尔 QGT，给出探针分辨的量子度规与非阿贝尔贝里曲率，并提取 Wilson loop 谱与杂化 Wannier 中心流。局域贝里曲率虽与真实体态值可有差异，但其在动量空间积分（Chern 数）严格相同；随独立探针数 Np 增加，探针子空间扩张，Q̃ 收敛到真实体几何。

  ## 潜在研究方向

  1. **多带混合与相互作用修正**：WFF 提取要求目标能带主导测量频率处的谱权重；谱权重混入其他能带贡献时，F(m₀) 的提取不再严格精确（无相互作用极限下严格，相互作用下是"目标带占优"的近似）。带间杂化严重的体系（如平带材料中多带近简并）上框架的鲁棒性需要定量评估。

  2. **rank 跌落（no-rank-drop）条件的物理实现**：Πk 与原投影算符同构要求 rank F(k) = Nb 对所有 k 成立，即谱节点处（det F = 0）重构失效。拓扑非平庸体系恰恰存在谱节点，因此在节点邻域几何提取的精度与可信度需要误差分析。

  3. **Z₂ 协议对声子的挑战**：论文明确指出两探针协议对声子实现困难，主要落在无自旋轨道耦合的电子能带（ARPES 中 p/s 型光偏振）和磁振子能带（INS 中子自旋）。声子体系需要替代探针方案。

  4. **探针分辨几何 ≠ 体几何**：Πk 丢失探针子空间正交方向的信息，局域几何一般相对体态有畸变；如何系统刻画畸变、在给定实验探针集合下给出 Q̃ 对真实 QGT 的可控逼近，是实际应用前必须回答的问题（NP 增大收敛的速率未给出定量估计）。

  5. **未触及的方向**：框架目前针对平衡态能带结构；对非平衡（光激发、Floquet 工程）情形，探针态与拓扑的对应关系、时间分辨版本的可行性均未讨论。此外，ARPES 中矩阵元效应（终态、表面势垒、非偶极修正）对 WFF 重构精度的系统影响需要与实验对标。

  ## 与林赛研究的关联

  - **量子几何可观测化范式与强场驱动读出**：本工作证明谱强度线性代数结构可承载完整几何信息，这与我们"利用强场驱动过程（HHG、高阶边带生成等非线性响应）反演量子几何"的研究路线在方法论上同构——HHG 谱同样可视为"驱动态 + 探针过程"的线性泛函。WFF 的"完备探针基反演"思想可直接移植到强场探针设计中：如何选择偏振、载波频率、晶体取向等控制参数使响应函数对 QGT 各分量的灵敏度矩阵可逆，是从这篇论文可以借用的核心配方。
  - **交变磁（altermagnet）与自旋分辨 ARPES**：4D 探针空间（自旋 × 偏振）的完备基构造对我们在交变磁材料上的工作有直接操作意义——交变磁的动量依赖自旋劈裂使其成为 WFF 重构的理想平台，反过来 WFF 方法可为交变磁的自旋纹理与拓扑提供不依赖 DFT 拟合的实验判据。
  - **莫尔体系量子几何测量**：量子度规是莫尔平带激子绝缘、分数 Chern 绝缘的关键参数；本文框架对多能带非阿贝尔 QGT 的处理（而非两能带近似）正好匹配莫尔超晶格中多个 moiré 带同时参与物理的场景。虽然莫尔体系动量分辨谱学（如 nano-ARPES）信噪比是挑战，但"拓扑选择规则 → 谱节点直接读数"对低信噪比条件可能比全 QGT 重构更实用。
  - **理论接口**：Wilson loop 谱流作为拓扑诊断量与我们关注的贝里曲率热点分布、量子度规-贝里曲率匹配条件（superfluid weight、HHG 强度中的几何权重）可以直接对接——一旦 Πk 从实验获得，我们已有的几何分析管线可在"探针分辨几何"上运行。
  - **注意校准**：本论文 arXiv 编号 2601.10677、标注日期 2026-01-14，属近期预印本，结论尚未经同行评审与实验独立复现；其数值结果（Weyl 点模拟、Cu₃TeO₆ 模拟）均为理论模拟而非实验数据，引用到申请书时应注明这一点。

**原理**：WFF 定义为实验探针态与能带投影算符的重叠 F_ab(q) = ⟨W_aq|P̂_k|W_bq⟩（厄米矩阵；ARPES 探针指标 = 光偏振×光电子自旋，INS = 垂直 q̂ 的磁偶极分量；G≠0 时探针拓扑平庸）；用完备正交厄米基 {Γ_μ}（INS 2×2 泡利矩阵；自旋-偏振分辨 ARPES 4×4 σ⊗τ）展开探针密度矩阵，线性方程组逐分量反演 f_μ(k)A(k,ω) = (1/N_p)Σ_c[B⁻¹]_μc I_c(k,ω)；拓扑选择规则（N_p=N_b）：非平庸拓扑阻碍全局光滑规范、与平庸探针拓扑失配强迫 WFF 行列式在包络面出现零点（谱节点），电荷-节点度关系 Σ_Qi = Σ_d(k_i)；有效投影算符（N_p>N_b）：压平 F 的非零本征值得秩-Nb 投影 Π_k，映射构成向量丛同构（拓扑等价），定义有效非阿贝尔 QGT 与 Wilson loop 谱（杂化 Wannier 中心流）；Cu₃TeO₆（Z₂ 磁荷 Dirac 磁振子）示范 det[I] = (I₀²−Σ_j I_j²)/(1−(q̂·P̂)²)。

| 探针维数 | INS：N_p = 2（泡利矩阵基）；自旋-偏振分辨 ARPES：N_p = 4（Γ_μ = σᵢ⊗τⱼ，Tr[Γ_μΓ_ν] = N_p δ_μν） | 研究方法（强度矩阵与线性反演） |

**适用边界**：要求目标能带主导测量频率处谱权重（带间杂化严重体系如平带多带近简并的鲁棒性需定量评估）；no-rank-drop 条件在谱节点处失效（节点邻域几何提取需误差分析）；两探针协议对声子实现困难（无 SOC 电子能带与磁振子可行）；探针分辨几何≠体几何（局域畸变，N_p 增大收敛速率未定量）；针对平衡态（非平衡/光激发/Floquet 时间分辨版本未讨论）；ARPES 矩阵元效应（终态/表面势垒/非偶极修正）需实验对标；预印本未同行评审。
