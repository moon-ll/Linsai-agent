# Does System Size Matter in Uncertainty Quantification for Machine Learning Interatomic Potentials?

## 林赛的理解

我是林赛，做强场超快光学的。这篇文章虽然不直接碰强场物理，但它戳中了我一直在意的一个问题：**机器学习势（MLIP）给出的不确定性估计，到底能不能信？**

在强场超快方向，我们用 MLIP 做分子动力学的情况越来越多——比如强激光场下分子解离、团簇电离后的动力学、乃至大体系含时演化的采样。MLIP 快是快，但它是数据驱动的：一旦模拟跑到训练集没覆盖的构型（OOD），能量和力的预测就可能悄悄失真。所以社区发展出各种不确定性量化（UQ）手段，期望用"不确定性分数"当警报器，把可疑构型筛出来回炉重算。

这篇文章的核心信息让我警惕：**UQ 的估计值本身随模拟体系尺寸变化**。换句话说，同一套不确定性判据，在小体系上标定好后搬到大体系（或反之），警报阈值就失准了。更麻烦的是，作者指出"尺寸无关"的判据在 OOD 构型筛选中存在局限——也就是说，光靠一个与体系大小解耦的标定并不足以可靠检出分布外构型，需要**尺寸感知的校准**。

这对我来说是个直接的警示：我们组用 MLIP 辅助强场 MD 时，如果体系从几十个原子扩到几百上千原子（团簇、界面、溶剂化体系都是这个方向），沿用旧的不确定性能阈值，很可能把真 OOD 构型漏掉，或者在正常构型上误报一片。尺寸效应不是边缘问题，是 UQ  pipeline 的系统性偏差源。

## 核心要点

- **核心发现**：MLIP 的不确定性估计随模拟体系尺寸变化，并非体系大小的不变量。
- **方法结论**：尺寸无关（size-independent）的 UQ 判据在 OOD 构型筛选中存在局限，不能跨体系尺寸直接迁移。
- **提出的方向**：需要尺寸感知的校准（size-aware calibration）才能可靠检测分布外构型。
- **实践含义**：在小体系上标定的不确定性阈值，搬到大体系后既可能漏检 OOD，也可能大量误报。

## 阅读笔记

### key-transient-quantum-phase-optical-20260726

标题：Does System Size Matter in Uncertainty Quantification for Machine Learning Interatomic Potentials?
作者：Chayaphol Lortaraprasert（MIT，工作完成于 Preferred Networks 实习）、Nontawat Charoenphakdee、Wenwen Li、Yong-Bin Zhuang、Yuta Tsuboi（Preferred Networks）。提交 2026-10-29，cs.LG; cond-mat.mtrl-sci。

### 研究问题
MLIP 的结构级不确定性打分在不同体系尺寸下是否仍然可比。通行做法是把逐原子不确定性按均值或最大值聚合后与固定阈值比较来标记 OOD 构型，这隐含假设了打分的尺寸无关性——本文正是对这一假设做系统检验。

### 研究背景
MLIP 普遍用不确定性估计标记分布外（OOD）构型并为主动学习挑选训练结构；随着在大型 DFT 数据库上训练的通用/基础势日益普及，跨元素周期表的大尺度原子模拟成为常规操作。但聚合不确定性的固定阈值判据在大体系下是否失效，此前未被系统考察。

### 研究方法
在多组分布内（ID）/OOD 数据对上，将均值聚合与最大值聚合两种逐原子不确定性聚合方式表征为原子数目的函数；用极值统计解释最大值聚合的增长行为；并设计重训练实验，对比“高不确定性大结构”与“构造的 OOD 结构”对模型改进的实际贡献。

### 主要发现与核心结论
均值聚合在均匀体系中保持尺寸无关，但对大胞中的缺陷失去敏感性；最大值聚合在 ID 体系中随体系尺寸增长，而在含缺陷体系中近似平坦，按极值统计规律收窄 ID–OOD 间隙。大结构中高不确定性原子虽可能指示新局域环境，但在这类结构上重训练几乎无改进，与在构造 OOD 结构上重训练形成对比。

### 潜在研究方向
结论揭示“尺寸无感知”不确定性判据的实用局限：大尺度原子模拟中固定阈值 OOD 检测可靠性下降。作者主张发展尺寸感知的校准方法；如何构造随原子数标定的判据、以及结论向其他聚合方式与体系的推广，是遗留的开放问题。


## 研究方法（方法卡）
<!-- methods-backfill:v1 -->
**方法**：MLIP 结构级不确定性的尺寸依赖性检验（均值/最大值聚合 × 原子数标度 + 极值统计 + 重训练对照）

**原理**：在多组 ID/OOD 数据对上系统检验逐原子不确定性聚合的尺寸无关性假设：均值聚合在均匀体系尺寸无关但对大胞中缺陷失去敏感性；最大值聚合在 ID 体系随尺寸增长、含缺陷体系近似平坦（极值统计规律收窄 ID-OOD 间隙）；重训练实验证明高不确定性大结构对模型改进几乎无贡献（与构造 OOD 结构上重训练形成对比）。

**适用边界**：大尺度原子模拟中固定阈值 OOD 检测可靠性下降；尺寸感知校准方法待发展；随原子数标定的判据构造、其它聚合方式与体系的推广为遗留开放问题。
