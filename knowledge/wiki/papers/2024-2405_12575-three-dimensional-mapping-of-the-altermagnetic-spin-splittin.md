• # CrSb 交变磁自旋劈裂的三维动量空间成像

  ## 林赛的理解

  这篇工作是我们的"交变磁强场驱动"方向必须吃透的一篇文献。CrSb 实现了迄今为止报道的最大交变磁能带劈裂（~1.0 eV），而且劈裂恰好位于费米面处、尼尔温度高达 705 K、自旋构型简单——这三点叠加使它不是一篇普通的材料确认论文，而是一张"器件级交变磁体"的入场券。对我们而言，最重要的启示有两层：第一，动量依赖的自旋劈裂意味着在圆偏振或线偏振强场驱动下，不同自旋通道的载流子能量尺度差异巨大（~1 eV），这为强场选择性驱动自旋通道提供了直接的能量学依据；第二，紧束缚模型揭示了劈裂源于 Sb 5p 轨道中介的第三近邻 Cr-Cr 跃迁，这把"如何调大/调小劈裂"从玄学变成了工程问题——压力、应变、以及化学替代 Sb 都可作为调控旋钮。我们在设计 HHG 探测方案时可以直接借鉴：用 mid-IR 场驱动，~1 eV 的自旋劈裂与典型 mid-IR 光子能量（0.12–0.5 eV）可比，自旋分辨的高次谐波发射强度不对称应当是可观测的。

  ## 研究问题

  论文要回答的核心问题有三个层次：

  1. **确认性**：CrSb 中的交变磁性（altermagnetism）是否能在三维动量空间中被直接谱学证实？此前仅有 (100) 取向薄膜的软 X 射线 ARPES 报道，缺乏 (001) 单晶的高分辨率三维 k 空间 mapping 和自旋分辨验证。
  2. **定量性**：交变磁劈裂随 k_z（离面动量）和 k_∥（面内动量）如何演化？劈裂的符号、节点平面位置、以及 g-wave 对称性是否与实际晶体结构一致？
  3. **机制性**：如此巨大的劈裂（~1 eV）从微观上由什么产生？Cr-Cr 间距很大，直接的 d-d 跃迁本应微弱，为什么实际劈裂反而比 MnTe（≲0.5 eV，位于远离 E_F 处）更大？

  ## 研究背景

  交变磁性是近年（2019–2022）理论上提出并被实验验证的一类共线磁体：实空间无净磁化，但倒空间电子能带发生动量依赖的自旋劈裂。MnTe 已作为 bulk-type g-wave 交变磁体被 ARPES 实验确认；RuO2 的实验证据虽有报道但磁性本质仍在争议中。按维度与对称性分类，交变磁体可分为 planar-type 与 bulk-type，后者按节点平面数分为 d-（2 个）、g-（4 个）、i-wave（6 个）对称性。由于劈裂幅度对自旋电子学应用（反常/非线性霍尔、巨磁阻、自旋矩、自旋卡洛效应）及奇异超导配对至关重要，寻找**费米面附近有大劈裂、磁有序温度远高于室温**的强交变磁体成为核心目标。

  CrSb 是巡游反铁磁体，尼尔温度高达 705 K，自旋群对称性允许 bulk-type g-wave 交变磁，但此前缺乏系统性的三维自旋分辨证据。

  ## 研究方法

  - **样品**：Sb 助熔剂法生长 (001) 取向 CrSb 单晶（Cr:Sb = 2:3 摩尔比，1150 °C 保温 20 小时后缓冷至 700 °C 离心除熔剂），晶体典型尺寸 1×1 mm²；XRD 确认晶格常数 a = b = 4.12 Å，c = 5.44 Å；EDX 与芯能级谱确认无杂质；PPMS 电阻测量显示 300 K–1.8 K 全温区金属行为、无相变。
  - **磁性结构**：中子散射确认磁空间群 P6₃'/m'm'c，Cr 磁矩沿 [001] 轴，六方层内平行、层间反平行——两个自旋子晶格由 [C2s‖Mz] 或 [C2s‖C̃6z] 自旋群对称操作连接，同时破缺 [C2s‖t⃗] 与 [T‖P]。
  - **自旋积分 ARPES**：瑞典 MAX IV 的 BLOCH 束线与中国上海光源 BL03U 束线；能量分辨率 ~20 meV，测量温度 ~20 K，光斑 ~15×15 µm²（BLOCH）/ ~50×50 µm²（BL03U），超高真空 < 5×10⁻¹¹ mbar，水平偏振光；通过光子能量扫描（68–105 eV）变换 k_z，内势 V₀ ~ 17 eV。
  - **自旋分辨 ARPES**：意大利 Elettra 的 APE-LE 束线，VESPA 系统（双 VLEED 散射腔，可同时测全部三个自旋分量）；能量/角分辨率 ~100 meV / ~1.5°，温度 ~15 K，Sherman 函数 0.3（以 Au(111) Rashba 表面态标定）。
  - **第一性计算**：VASP + PBE-GGA；测试不同 U 后取 U = 0（与实验符合最好）；能量截断 345 eV，11×1×9 Γ 中心 K 点，总能收敛至 1 meV/atom；对比 AM+SOC / NM+SOC / AM 无 SOC 三种情形分离交变磁与 SOC 贡献；Wannier 函数拟合 TB 模型。
  - **紧束缚模型**：以 Cr 的 Eg 表示（dxz, dyz, dxy, dx²−y² 在 Cr 位 D3d 点群下同属 Eg）构建八能带自旋群对称 TB 模型，保留至第三近邻（3NN）跃迁；通过 Wannier 计算分解直接跃迁（DH）与 Sb 中介跃迁（AH）的贡献。

  ## 主要发现与核心结论

  1. **迄今为止最大的交变磁能带劈裂**：CrSb 在费米面附近的交变磁劈裂高达 **~1.0 eV**，出现在面内 Γ̄−M̄ 方向、k_z ~ 0.25c* 处（介于 k_z = 0 与 0.5c* 两节点平面中点附近）。
  2. **kz 依赖验证 bulk-type g-wave 对称性**：80 eV 光子（k_z ~ 0.28c*）下观测到两套以 Γ̄ 为中心的空穴型能带、分裂达 **1.0 eV**；而 68 eV（k_z ~ 0）与 90 eV（k_z ~ 0.5c*）下仅见一套——劈裂在 k_z = 0 与 0.5c* 节点平面严格为零。kx-kz 图（E = −0.5 eV）显示 P–Q 方向"双弦"特征，劈裂随 k_z 从零增大至 k_z ~ 0.25c* 最大值再归零，与 DFT 定量一致。
  3. **面内 g-wave 对称性**：E = −0.65 eV、80 eV 下观测到六瓣花形空穴口袋（自旋分辨 contour 呈三重旋转对称，相反自旋相差 60°）；E_F 处 105 eV（k_z ~ 0.2c*）费米面直接显示六瓣花形。MDC 拟合（E = −0.6 eV，双高斯峰）提取动量劈裂 Δk(θ) 呈 **|sin(3θ)|** 函数形式，Γ̄−M̄ 方向有劈裂、Γ̄−K̄ 方向无。
  4. **自旋分辨直接证据**：在劈裂最大处（Γ̄−M̄、80 eV、k_z = 0.28c*）自旋分辨 MDC 显示自旋向上/向下谱峰明显移动，证明相反自旋带劈裂；实验极化率显著低于理想的近 100% 上-下-上-下图案，归因于双磁畴混合与动量展宽叠加。
  5. **交变磁 vs SOC 的角色分离**：对比计算表明带劈裂主要由交变磁序产生，SOC 影响微弱；E_F 附近 ⟨Sz⟩ ≈ ±1/2（自旋为好量子数），E ~ −2 eV 处 Sb 5p 贡献使 SOC 导致明显面内极化；k_z = 0 处微小劈裂属"弱交变磁"效应，实验中不可分辨。
  6. **微观机制（核心结论）**：TB 模型显示最近邻（NN）与次近邻（NNN）跃迁均保持 [C2s‖t⃗] 对称性、不产生劈裂；唯第三近邻项 f311(k)Γ311 与 f313(k)Γ313（正比于 **q2 + q3**）同时破缺 [T‖P] 与 [C2s‖t⃗]，产生交变磁劈裂。拟合参数：**q1 = −0.0184 eV，q2 + q3 = 0.1950 eV，q4 = 0.1942 eV**；Wannier 分解显示 q2 + q3 中直接跃迁仅 **21.4 meV**，而 Sb 中介跃迁达 **151.6 meV**（总计 173.0 meV，接近 TB 值）——Sb 5p 轨道作为桥梁大幅增强 3NN Cr 3d 跃迁，这是大劈裂的根源。3NN 跃迁幅度与 NNN 相当，违背 d 轨道局域直觉。
  7. **可调性**：∆E1（单套带内劈裂）近似正比于 q2 + q3，几乎不依赖 q1 + q4；∆E2（最接近 E_F 的反自旋带劈裂）在 q2 + q3 超过 ~0.1 eV 后依赖 q1 + q4（顶导带 crossing E_F 所致）。等比例增大 {qi}（模拟静水压）下劈裂单调增大——劈裂可通过压力/应变调控。
  8. **与同类体系对比**：MnTe 为半导体、U ~ 4.8 eV、劈裂 ≲ 0.5 eV 且远在 E_F 之下（主要来自 Te p 轨道）；VNb3S6 虽同属 g-wave 但 c = 12.17 Å、层间耦合弱，劈裂仅几十 meV。CrSb 的小 c 值（5.44 Å vs MnTe 的 6.75 Å）与强巡游性共同造就大劈裂。

  ## 潜在研究方向

  - **自旋极化率受损问题**：实测极化率远低于理论预期，磁畴混合与动量展宽是主因；如何实现单畴 CrSb 或厚层剥离样品以获得定量自旋极化数据仍未解决。
  - **弱交变磁/面内自旋分量**：k_z = 0 处的微小劈裂与面内 ⟨Sx⟩、⟨Sy⟩ 以及 E ~ −2 eV 处 SOC 诱导的面内极化值得更精细的自旋分辨研究。
  - **多轨道系统中的最优化问题**：∆E2 对 q1 + q4 的依赖表明，最大化 E_F 处自旋劈裂需要同时调多个带参数，材料设计空间尚未系统探索。
  - **超导近邻效应**：CrSb 的三维自旋简并节点平面使其平面与垂直 Josephson 结都可能出现有限动量配对与 0–π 振荡，且可通过界面取向切换——目前纯属理论展望，无实验。
  - **调控验证**：TB 模型预测压力/应变可调劈裂，但实验中尚无应变或高压下的 ARPES 验证；Sb 化学替代（p 轨道中介的其他离子）是否可进一步增强劈裂是开放问题。
  - **HHG/非线性光学响应**：论文未涉及强场驱动下的谐波、自旋注入或非线性光学响应——1 eV 自旋劈裂与自旋分辨谐波谱学的结合是明显的下一步空白。

  ## 与林赛研究的关联

  - **交变磁 + 强场驱动**：CrSb 提供"费米面处 1 eV 自旋劈裂 + 705 K 磁序 + 无净磁化"的理想平台。动量依赖的自旋劈裂意味着强激光场可空间选择性地驱动不同自旋通道（Γ̄−M̄ 与 Γ̄−K̄ 方向响应不同），线偏振取向即可作为自旋通道的选择旋钮——这正是我们交变磁强场驱动课题的核心物理。
  - **HHG 探针**：~1 eV 的带间能量尺度落在 mid-IR 强场驱动范围内，偶阶/奇阶谐波强度与圆偏振不对称性可直接读出 g-wave 对称性的 |sin(3θ)| 指纹；kz 依赖的节点平面应对应谐波谱的节点面。
  - **阿秒自旋动力学**：无净磁化 + 高 T_N 意味着超快退磁/自旋翻转的热容忍度高，Néel 矢量沿 c 轴避免了 MnTe 的多畴混杂问题，适合作为阿秒时间分辨自旋动力学的干净体系。
  - **量子几何/莫尔接口**：论文揭示的 Sb 中介跃迁机制（q2 + q3 = 0.195 eV）表明电子结构对晶格细节高度敏感；若把 CrSb 与莫尔超晶格/异质结结合，超晶格调制可直接改写 3NN 跃迁路径，为"量子几何 + 交变磁"交叉提供可操作的设计变量。

## 研究方法（方法卡）

**方法**：CrSb 交变磁自旋劈裂的三维动量空间测绘（多束线自旋积分/分辨 ARPES + 八能带自旋群 TB）

**原理**：Sb 助熔剂法 (001) CrSb 单晶（a=b=4.12 Å、c=5.44 Å，300 K–1.8 K 全金属行为）；中子散射确认磁空间群 P6₃'/m'm'c（Cr 磁矩沿 [001]，层内平行层间反平行，自旋群 [C2s‖Mz]/[C2s‖C̃6z] 连接两子晶格）；自旋积分 ARPES（MAX IV BLOCH + 上海光源 BL03U，20 K，hν 68–105 eV 扫 k_z，内势 V₀~17 eV）测劈裂带色散；自旋分辨 ARPES（Elettra APE-LE，VESPA 双 VLEED 同时测三分量，~15 K，Sherman 函数 0.3）定劈裂对称性；理论：VASP PBE（U=0 最合实验）对比 AM+SOC/NM+SOC/AM 无 SOC 三情形分离交变磁与 SOC 贡献；Cr 的 Eg 表示八能带自旋群对称 TB（保留至 3NN），Wannier 分解直接跃迁（DH）与 Sb 中介跃迁（AH）。

**参数表**：

| 参数 | 数值 | 出处 |
| --- | --- | --- |
| 样品生长 | Cr:Sb=2:3 摩尔比；1150 °C 保温 20 h 缓冷至 700 °C 离心；晶体 1×1 mm² | §样品 |
