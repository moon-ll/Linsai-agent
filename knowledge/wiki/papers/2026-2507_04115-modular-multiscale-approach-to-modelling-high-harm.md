• # Modular multiscale approach to modelling high-harmonic generation in gases

  ## 林赛的理解

  这篇工作对我们组最直接的含义是：它提供了一个可本地部署、可扩展的气体 HHG 全链路模拟管线。我们目前关心的 HHG、阿秒光源、强场驱动固体/莫尔体系等问题，都需要在"微观响应 → 宏观传播 → 远场信号"这条链路上做定量预测。该工具箱把 CUPRAD（IR 传播）、1D-TDSE（微观偶极）、衍射积分（XUV 远场）串成 HDF5 数据流，并且提供 Python 接口，这为我们提供了一个基准平台：既可以用来验证我们自己对气体 HHG 的直觉，也可以作为对比参照，理解固体 HHG 中缺失的宏观传播效应。尤其重要的是，它明确把"全反馈回路"（TDSE ↔ Maxwell）与"解耦管线"区分开来，后者用非线性光学响应 + 电子密度速率方程替代实时 TDSE 反馈，计算代价大幅降低，这对我们设计固体/莫尔体系的近似传播模型有方法论参考价值。

  ## 研究问题

  论文的核心问题是：如何建立一个模块化、用户友好、可在笔记本电脑到 HPC 集群上部署的模拟工具箱，以定量再现实验室条件下气体介质中的高次谐波产生过程。具体而言，该工具箱需要把三个尺度——宏观 IR 脉冲传播、单原子/分子微观量子响应、以及 XUV 辐射的远场相干叠加——整合为一条可重复执行的计算管线，同时保持各模块既能协同运行、又可独立使用。

  ## 研究背景

  气体 HHG 是强场超快光学中的核心光源技术，可产生相干的 XUV 辐射，并支撑阿秒科学。其微观机制由三步模型描述，并严格包含在含时薛定谔方程（TDSE）的解中。然而，IR 到 XUV 的转换效率仍然很低，限制了高亮度 XUV 脉冲在 XUV–XUV 泵浦-探测或非线性电离等应用中的推广。

  实验室中的 HHG 发生在宏观尺度（气室或气体喷流），驱动脉冲在传播过程中会经历等离子体散焦、克尔自聚焦、时空耦合等非线性动力学，从而在不同宏观位置改变 HHG 的局部驱动条件。与此同时，XUV 强度低，可近似为线性传播。因此，微观与宏观的耦合是 HHG 建模中的关键挑战。

  此前的数值方法大致分为两类：早期方法忽略宏观传播效应和驱动场形变；后续工作逐步引入自洽驱动场演化。在传播建模上，HHG 社群发展了标量包络模型和 UPPE 方法，而飞秒激光成丝社群则发展了复杂的包络传播代码。本文的工作正是这两个社群代码的整合产物，旨在提供一个统一的模块化工具箱，实现与实验条件的一对一对应。

  ## 研究方法

  论文提出"模块化多尺度方法"（Modular Multiscale Approach, MMA），将全反馈回路（图 1）解耦为三个顺序执行的模块，通过 HDF5 文件交换数据：

  1. **IR 传播模块（CUPRAD）**：在柱对称坐标 (ρ, z, t) 下求解扩展非线性薛定谔方程。采用复包络表示，支持 SVEA 的两种形式——标准形式（方程 36，忽略三阶时间导数、设 ˆT ≡ 1）和含高阶修正形式（方程 35，保留至三阶时间导数、使用 ˆT 算符）。线性部分包含衍射和色散，非线性部分包含瞬时/延迟克尔响应、光致电离、雪崩电离和自由电子电流。计算在 Fortran 90 + MPI 中实现，FFT 使用 FFTW3，纵向步长 Δz 自适应控制。当前版本限于线偏振和柱对称；未来版本将加入 UPPE 和矢量场。

  2. **微观响应模块（1D-TDSE）**：在长度规范下求解一维含时薛定谔方程，使用软核势 V_C = −1/√(x_m² + a²)，参数 a 通过基态能量 E_g 标定到目标原子。采用单电子近似、偶极近似和线偏振。偶极加速度源项由 ∂_t j_m(t) = ⟨ψ(t)|∂V_C/∂x_m + E(t)|ψ(t)⟩ 给出。该模块编译为 MPI 应用和动态库，可通过 Python 直接调用。

  3. **XUV 传播模块**：在 XUV 线性传播近似下，用衍射积分对全介质体积内的微观偶极源做相干叠加。柱对称使得角向积分解析完成，剩余径向和纵向积分；远场谱表示为方程（40），考虑气体密度不均匀时扩展为方程（41），其中波数 k 依赖局部密度，包含折射和吸收效应。

  数据流上，CUPRAD 输出整个宏观体积中的 IR 电场；1D-TDSE 在每个宏观网格点上求解微观响应；最后 Python 衍射积分模块计算远场 XUV 信号。模块间通过 HDF5 交换，保证单一文件内输入输出一致。

  ## 主要发现与核心结论

  论文主要呈现的是方法学与代码框架，而非针对某一具体物理体系的全新实验发现。其核心结论包括：

  - 气体 HHG 的全反馈建模（TDSE ↔ Maxwell）计算代价极高，但通过"光谱解耦"假设——即驱动 IR 与二次 XUV 辐射在频谱上可分离——可以将问题展开为顺序执行的 MMA 管线（图 2），在不引入过度限制假设的前提下大幅降低计算成本。

  - IR 传播模块 CUPRAD 实现了两种包络方程：标准 NLSE（方程 36）和包含空间-时间耦合、自陡峭等高阶效应的扩展方程（方程 35）。两者通过参数 `numerics_operators_t_t-1` 切换。当前版本限于 800 nm 量级、~100 fs 脉冲，可满足多数非少周期脉冲实验需求；对于未来少周期脉冲，需要 UPPE。

  - 微观模型采用一维软核势 TDSE，可在每个宏观网格点独立求解，宏观坐标作为参数进入 TDSE。论文明确当前实现限于线偏振、单电子、偶极近似，并指出正在开发外复标度、优化网格、三维 TDSE 等扩展。

  - XUV 远场通过衍射积分获得，方程（40）为均匀介质情形，方程（41）扩展至非均匀密度情形，其中局部色散通过 ∫k(ρ', z'', ω)dz'' 计入。该积分形式已用于高斯光束传播和 XUV 光束聚焦特性建模。

  - 代码设计上，各模块既可串联成完整 HHG 管线，也可独立运行：CUPRAD 单独模拟非线性成丝，1D-TDSE 通过 Python 接口用于单原子强场物理，衍射积分模块可接受任意用户定义的微观偶极。仓库提供 Jupyter notebook 教程、Docker 部署指南和 HPC 使用指南。

  文中给出的具体参数与数值示例包括：

  - 对于 800 nm 在空气中的三次谐波相位失配：∆k ≈ −5 cm⁻¹。
  - 延迟克尔响应中的特征延迟时间 τ_K 和共振频率 Ω 与 ~100 fs 脉冲相当。
  - 电子碰撞时间 τ_0 满足 1/(τ_0 ω_0) ≪ 1。
  - 临界等离子体密度定义为 ϱ_c = m_e ε_0 ω_0² / q_e²。
  - 非线性折射率条件：|n_2 I| ≪ n_b = n(ω_0)。
  - 电离能 U_i 作为能量守恒关系中的关键参数，链接光致电离电流 J_IL 与雪崩电离率 W_AI。
  - 泰勒展开中波数保留到三阶：k(ω) = k_0 + k'ω + (1/2)k''ω² + (1/6)k'''ω³ + …

  ## 潜在研究方向

  1. **维度与近似扩展**：当前版本为 1D-TDSE 和柱对称传播，未来需引入 3D-TDSE、矢量场、少周期脉冲 UPPE 描述，以覆盖椭圆/圆偏振、涡旋光束、非柱对称几何等实验配置。

  2. **全反馈回路的边界**：MMA 假设 IR 与 XUV 光谱解耦、且宏观传播可用非线性光学响应 + 电子密度速率方程替代实时 TDSE 反馈。当 XUV 强度足够高（如 XUV-XUV 泵浦-探测）或驱动场在亚波长尺度剧烈变化时，该解耦可能失效，需要重新评估。

  3. **固体与莫尔体系的迁移**：该工具箱针对气体原子气，其软核势 + 单电子近似无法直接迁移到周期性固体或莫尔超晶格。但 MMA 的"宏观传播 + 微观响应 + 远场积分"架构可以作为固体 HHG 模拟的方法论模板，微观模块需替换为半导体布洛赫方程或 Wannier 轨道模型。

  4. **多源学术检索与数据接口**：代码以 HDF5 为数据交换格式，未来可进一步与实验数据（光谱、空间模式、FROG/SPIDER 表征）直接对接，实现模型-实验闭环校准。

  5. **计算效率与 HPC 扩展**：虽然当前已实现 MPI 并行和 Python 接口，但随着 3D 化和更细网格需求，需要进一步优化负载均衡、检查点重启、以及与 GPU 加速 TDSE 求解器的集成。

  ## 与林赛研究的关联

  - **HHG / 阿秒光源**：本文直接面向气体 HHG 光源的全链路模拟，与我们组在固体 HHG、阿秒脉冲产生与表征方面的兴趣高度一致。其"宏观传播决定局部驱动场、微观 TDSE 决定局部偶极、远场积分决定可观测信号"的三层结构，是我们理解任何 HHG 平台（气体/固体/莫尔）的共同语言。

  - **强场驱动**：CUPRAD 中对克尔效应、等离子体散焦、电离损耗的建模，为我们分析强场驱动下固体/莫尔样品中激光传播效应（如自相位调制、载波包络相位演化）提供了气体中的基准参照。

  - **莫尔/量子几何**：虽然本文不涉及固体或莫尔体系，但其模块化思想可直接借鉴。莫尔体系中的微观响应可由紧束缚 + 量子几何量（量子度规、贝里曲率）描述，宏观传播可由非线性麦克斯韦方程描述，远场探测可由类似衍射积分或傅里叶光学描述。本文的 MMA 架构为这种跨尺度建模提供了工程模板。

  - **实验接口**：论文强调"与实验室条件的一对一对应"，这与我们组从实验设计（光路、气室/样品参数）出发反推可观测 HHG 光谱的目标一致。特别是 HDF5 数据流和 Python 接口，便于我们把自己的微观模型（如 BSV-driven HHG、moiré strong-field probe）插入类似管线，快速验证预测。

**方法**：HHG 的模块化多尺度方法 MMA（CUPRAD IR 传播 + 1D-TDSE 微观响应 + XUV 衍射传播，HDF5 串联）

**原理**：三模块 HDF5 串联：① CUPRAD IR 传播——柱对称扩展非线性薛定谔方程（衍射+色散+瞬时/延迟 Kerr+光致电离+雪崩+自由电子电流；SVEA 标准/高阶修正两种；Fortran 90+MPI+FFTW3，Δz 自适应）；② 1D-TDSE 微观响应——长度规范软核势（a 由 E_g 标定），偶极加速度源项 ∂_t j_m=⟨∂V_C/∂x_m+E⟩，编译为 MPI+Python 动态库；③ XUV 传播——衍射积分相干叠加（角向解析、径向纵向数值；方程 40/41 含密度不均匀折射+吸收）。

**适用边界**：当前版本限于线偏振+柱对称（未来加 UPPE+矢量场）；模块间 HDF5 交换无损但计算效率低于全耦合；页面提取限方法框架（结果在正文）。
