• # 对称性强制的手性声子：交变磁体中磁振子-声子耦合诱导的 CrSb g-波声子角动量纹理

  ## 林赛的理解

  这篇工作回答了一个我一直关心的问题：**在净磁化强度为零的补偿磁基态里，能否零磁场产生手性声子？** 传统共线反铁磁体被 PT 对称性锁死——声子角动量（PAM）在每个 k 点恒等于零、Berry 曲率在全布里渊区被禁。Rieger 等人证明交变磁体（altermagnet）打破了这一约束：CrSb 的磁点群 6′/m′mm′ 破坏 PT 但不破坏补偿性，相对论自旋-晶格耦合（SLC）把交变磁的 g 波对称性"印刻"到声子角动量分布上。这等于给晶格动力学造出了一个**声子版的交变磁性**——动量依赖的手性劈裂 + 全 BZ 精确抵消的总角动量。

  对我们的价值有三层：第一，这是一个清晰的**对称性分类判据**——判断任何候选材料能否零场支撑手性声子，只需查磁点群是否破坏 PT 且允许赝矢量在 k 空间取非零值；第二，11 meV 量级的磁振子-声子杂化能隙和 100 K 以上的热激活窗口，落在太赫兹-中红外泵浦可及的范围；第三，g 波 PAM 纹理本身是动量空间的奇宇称结构，与 Berry 曲率反常输运绑定，为"量子几何 → 晶格动力学"这条线提供了一个干净的理论范本。

  ## 研究问题

  核心问题：**零磁场下，如何在保持补偿（无净磁化）的共线磁基态中产生手性声子并驱动反常横向输运？** 具体分解为三个子问题：

  1. 交变磁体破坏 PT 对称性（产生自旋劈裂电子/磁振子能带的根源），这一破缺能否经由相对论 SLC 传递给晶格自由度，使声子获得有限角动量？
  2. 如果可以获得，PAM 在动量空间呈何种对称性纹理？是否继承交变磁相的非常规 g 波对称性？
  3. 杂化的磁振子-极化激元（magnon-polaron）是否携带有限 Berry 曲率，从而在无净磁化、无外加场、无结构手性的条件下驱动反常自旋/PAM Nernst 响应？

  中心论点：体相交变磁体是零场手性声子与手性声子输运的合适材料类别，且该机制与电子-声子耦合诱导 PAM 的机制（文献 [64, 65]）本质不同。

  ## 研究背景

  声子角动量作为可探测、可操控的自由度已有完整脉络：Zhang 与 Niu 的基础理论 [1, 2] 奠定 PAM 概念；随后在非中心对称体系中经圆二色性 [3]、X 射线 [4]、拉曼 [5, 6]、输运 [7, 8] 和扭矩测量 [9] 实验探测。手性声子（PAM 赝矢量与时间域传播方向对齐 [10]）联系着大 phonon 磁矩 [11–14]、超快退磁 [15, 16] 与声子 Barnett 效应的超快磁序反转 [17, 18]。稳态下 PAM 支撑热梯度下的反常横向输运：非相对论晶格中即可出现普适 PAM Hall 效应 [19]，结构手性激活手性声子自旋 Seebeck 效应 [8]。

  关键障碍在对称性：中心对称晶格中的裸声子是纯线性、非轴向振动 [20]，只有相对论 SLC 能解除这一约束。SLC 在破坏时间反演的磁环境中杂化自旋与晶格自由度，形成磁振子-极化激元 [21, 22] 并携带有限 PAM——近期已在铁磁体中预测 [24–26]，并伴随反常热 [26, 27] 与自旋 Nernst 效应 [24]。但**在常规共线反铁磁体中，PT 对称性使 PAM 与 Berry 曲率在零场下于全 BZ 恒等于零**——因 P 与 T 对每个 k 点的 PAM 施加相反符号，Berry 曲率在 PT 下为奇。

  交变磁体绕开了这一约束：保持补偿共线磁基态的同时破坏 PT，产生定义交变相的自旋劈裂电子 [28–32] 与磁振子 [33–35] 能带。CrSb 是原型 g 波交变磁体，其实验证据包括直接观测能带劈裂 [31]、大带劈裂 [36]、手性自旋劈裂磁振子 [37]、拓扑 Weyl 交变磁性 [38]、三维自旋劈裂测绘 [39] 及晶格对称性操控交变磁序 [40]。

  ## 研究方法

  - **原子级自旋-晶格耦合框架**：总哈密顿量（式 1）含谐振晶格动力学、磁交换（含各向同性交换、磁晶各向异性、反对称 DMI）与 SLC 项。SLC 张量 J^αβμ_in,jm,kl = ∂J^αβ_in,jm/∂u^μ_kl 由平衡坐标一阶泰勒展开得到，计入全晶体环境——包括中介非磁性配体原子位移对磁交换对的调制。
  - **第一性参数计算**：力常数（IFC）用 VASP [41] + phonopy [42, 43] 计算；磁参数全部用全相对论 KKR Green 函数方法 [46, 47] 从头算：交换耦合张量基于磁定理（LKAG 公式的相对论扩展 [48, 49]），SLC 张量用同源于力定理的高效方案 [50–52]，可给出任意阶的原子位移微扰 SLC 参数。
  - **玻色化与精确对角化**：Holstein-Primakoff 变换 [53] 将局域自旋映射为磁振子算符，得到多子格磁振子-声子哈密顿量（式 2），含正常交换 A_knm 与反铁磁特征的反常配对 B_knm；耦合顶点 c^±_qλn 把 SLC 张量的傅里叶变换投影到偏振矢量。用 Colpa 算法 [44, 57] 对耦合哈密顿量精确对角化，得本征态 |n_k⟩ 与能带 ε_kn。
  - **对称性分析**：针对磁点群 6′/m′mm′，群生成元 {P, C′_2y, C′_6z, m′_z, C_3z}，分析 PAM 分量 L_x/L_y/L_z、螺旋度 k·L、普通 Berry 曲率 Ω_xy 与 PAM Berry 曲率 Ω^Lz_xy 在各对称操作下的宇称（Table I）。
  - **输运计算**：推广纯磁振子 [34] 与纯声子 [19] 输运模型至杂化自旋-晶格 regime，用广义 Berry 曲率（式 4）与 Bose-Einstein 分布加权（c_1 函数，式 5）计算反常自旋与 PAM Nernst 系数，实线与虚线分别对应含/不含 SLC 的计算。

  ## 主要发现与核心结论

  1. **磁振子-极化激元形成**：沿 Γ–L 与 Γ–L′ 路径（Γ = (0,0,0)，L = (−π/a, −π/√3a, π/c)，L′ = (−2π/√3a, 0, π/c)），裸磁振子与声子支交叉处 SLC 通过避免交叉解除简并，打开能量隙**最大达 1.1 meV**，标志磁振子-极化激元形成 [58]。靠近 Γ 点群速度最高的支主要是磁振子性。

  2. **手性声子零场出现**：PAM 期待值 L_n,k = ⟨n_k|L̂|n_k⟩ 经与交变磁磁振子杂化后取有限值；投影到传播方向得声子螺旋度 h_n,k = k·L_n,k/|k|，非零即分类为手性声子 [10]。螺旋度高度各向异性，在 Γ–L 与 Γ–L′ 路径间反号——两路径相差绕量子化轴的 **60° 旋转**。

  3. **对称性强制的 g 波 PAM 纹理**：6′/m′mm′ 点群强制 PAM 呈 g 波图案，四个节平面交于 Γ 点。C′_2z（k_z → −k_z）强制 L_z 奇宇称 → k_z = 0 水平节平面；垂直镜 m_x（k_x → −k_x）→ k_x = 0 垂直节平面，C_3z 在 ±120° 复制；时间反演六重旋转 C′_6z 要求相邻扇区方位角 PAM 反号（L^z_n,C6zk = −L^z_n,k），严格反转声子螺旋度（h_n,k → −h_n,k）。磁振子最大交变磁劈裂的 BZ 平面（kz = 0 与 ±0.9π/c，c = 5.352 Å）上纹理最显著。

  4. **总 PAM 精确抵消**：尽管单个手性声子携带 PAM，零场总平衡 PAM 恒等于零（图 3）——L_z 因 m_x 与 C′_2z 下的奇变换在 BZ 内成对抵消，净面内 PAM（L_x, L_y）被 C_3z 严格禁戒。**动量依赖手性劈裂 + 总角动量精确抵消 = 交变磁性的直接声子类比**。沿 z 轴加外场破坏 m_x 与 C′_2z，磁点群降至 ¯3m′，产生有限零点 PAM L_z；高温下 L_z 渐近消失 [1, 24]。

  5. **反常 Nernst 输运**：杂化能隙从约 **11 meV** 起打开，T ≈ 0 时这些高 Berry 曲率区域未被占据；**100 K 以上**热能量跨过阈值，杂化态布居修改 PAM Nernst 输运——α^Lz_xy = −α^Lz_yx 增强，α^Lx_yz = −α^Ly_xz 相对非相对论背景减弱。**自旋 Nernst 系数无自旋轨道相互作用时恒等于零**，是完全由杂化激活的内禀磁驱动效应。零场反常热 Hall 效应消失（Ω_n(k) 在至少一个动量对称操作下为奇，BZ 积分精确抵消）。PAM Nernst 系数幅值**超过纯自旋 Nernst 效应两个数量级**，室温下相对论 SLC 贡献达总 PAM 信号的 **∼20%**。

  6. **线性响应的盲区**：宏观自旋/PAM 电流 J^O_μ ∝ ∇_νT 对温度梯度方向角的依赖周期至多为 π，g 波对称性在线性响应电流中不可见——需进入非线性输运 regime 才能分辨。

  7. **机制定位**：该体相定量框架区别于最小二维交变磁玩具模型 [56]（后者需破坏面外镜对称与界面 DMI 才能产生 d 波图案）；本文的声子诱导动态 DMI 型相互作用在中心对称晶格中保持有限，传统宏观磁弹性理论 [55] 因缺少此项而不足以描述。亦区别于电子-声子耦合诱导 PAM 的机制 [64, 65]。

  ## 潜在研究方向

  1. **实验探测缺口**：手性声子已由圆二色性 [3]、X 射线 [4]、拉曼 [5, 6] 探测，但交变磁体中 SLC 印刻的 g 波 PAM 纹理尚无实验验证；动量分辨（如非弹性 X 射线散射）对 ±120° 扇区反号的螺旋度是可行的对称性指纹。
  2. **非线性输运**：g 波 PAM 在线性响应中不可见（周期至多 π），需发展非线性 Nernst/热输运理论才能暴露动量空间手性纹理的宏观后果。
  3. **材料推广**：CrSb 是 g 波原型；其他交变磁候选（如 RuO₂）的磁点群是否同样允许有限 PAM 与 Berry 曲率、耦合强度如何随 d 波/i 波对称性变化，值得系统筛查 [20] 的目录可复用。
  4. **温度窗口限制**：杂化隙起始于 ~11 meV，输运修正仅在 100 K 以上显著；低温区间 SLC 信号微弱，限制热输运器件的工作温区。
  5. **动力学版本缺失**：本文处理平衡态与线性输运；超快（THz/红外泵浦）激发下磁振子-极化激元的相干动力学、以及对磁序反转的潜在通道（类比声子 Barnett 效应 [17, 18]）未涉及——而这恰是超快磁学最直接的接口。
  6. **总 PAM 抵消的利用**：零场总抵消意味着无宏观"声子磁矩"背景，动量选择性激发（定向 k 空间泵浦）可破缺抵消、产生可观测净 PAM——理论上可行但未讨论。

  ## 与林赛研究的关联

  - **交变磁 × 量子几何**：本文是"交变磁对称性 → 晶格动力学指纹"的范式案例，与我们 Berry 曲率/MnPS₃-Rashba 方向共享同一套对称性分析工具（磁点群对赝矢量与 Berry 曲率宇称的约束，Table I 的分析可直接移植到我们的候选材料筛查）。
  - **HHG/阿秒接口**：11 meV ≈ 2.7 THz 的磁振子-声子杂化隙完全落在强场 THz 泵浦可及范围；HHG 谱中声子边带（Raman/高阶边带）对声子螺旋度与动量纹理敏感，g 波反号的相邻扇区会在偏振依赖的 HHG 产率中留下可判读的对称性印记——这是"用强场光学读出手性声子纹理"的具体实验设计起点。
  - **强场驱动磁振子-极化激元**：耦合哈密顿量（式 2）+ 避免交叉结构（图 1）是强场驱动磁振子-声子杂化态的现成理论框架；Colpa 对角化的本征态可直接作为 Floquet/半经典强场计算的基。
  - **莫尔方向**：莫尔超晶格折叠 BZ 后可 engineered 磁点群与 k 空间纹理，把体相 g 波 PAM 印刻概念移植到可调莫尔体系（如转角磁性异质结）是自然的推广。
  - **课题直接挂靠**：本笔记服务于 `general-berry-mnps3-rashba-20260816`——SLC 张量的第一性计算流程（KKR + 力定理 [50–52]）与对称性分类判据可直接用于我们候选材料的"能否零场支撑手性声子/反常输运"预判。
