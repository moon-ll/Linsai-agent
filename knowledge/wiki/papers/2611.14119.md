# Physics-informed Bayesian optimization of high-order harmonic generation in gases

**arXiv**: [2611.14119](https://arxiv.org/abs/2611.14119) | **方向**: 气体HHG + 机器学习优化

## 深度解析

### 研究问题（Research Question）

Gap: 气体 HHG 转换效率 (CE) 的优化是典型的多尺度问题, 微观单原子响应与宏观相位匹配耦合, 参数空间维数灾难使穷举扫描在 4D 以上不可行 (100 点/维时 2D 需 1e4 次模拟, 4D 需 1e8 次). 标准 Bayesian optimization (BO) 用欧氏距离的高斯过程 (GP) 代理模型, 不利用已知的物理标度关系, 因此难以重构 CE 景观中的双曲脊结构. 已有 BO 在激光-物质相互作用的应用只追求找到最优点, 从不评估代理模型对整个景观的重构保真度. Contributions: (1) 提出物理知情 BO 框架, 把已知标度关系 (最优 CE 的压强-长度双曲线 pL ≈ const, 最优脉宽标度 CE_max ∝ τ^-1/2) 通过非线性坐标变换直接编码进搜索空间; (2) 用 2D 压强-长度空间的 100x100 直接网格扫描作基准, 严格区分'找到最优点'与'重构景观'两种能力 (NRMSE + SSIM 双指标); (3) 引入 Straddle 采集函数 (为本研究专门实现) 定位超过阈值 CE 的扩展高效率区域而非孤立点; (4) 扩展到 4D (p, L, I, τ), 用 1024 点 Sobol 序列独立参考集验证, 物理知情坐标 + 目标函数平方根变换使全局重构误差降低约 65%.

### 研究背景（Background）

(1) 与林赛气体 HHG 出身的直接对接: 这篇是 L'Huillier 组 (Lund) 与 Chalmers 的合作, 作者列表里有 Weissenbilder (2022 Nature Reviews Physics 的 pL 双曲线综述一作, 即本工作的物理基础之一) 和 Vabek (ELI Beamlines). 林赛博后出身 Krausz 组, 与这条 Lund-Munich 强场谱学线是同一学术家族; 该文引用的 Constant 1999 相位匹配经典, Heyl 2016 几何标度不变性, 都是林赛气体 HHG 时代的基础文献, 阅读成本极低. (2) 方法论对课题 A (固体 HHG 反演) 的同构迁移: 固体 HHG 的 CE/产率景观同样由微观 (带间极化 + 带内加速) 与宏观 (传播, 吸收, 相位匹配) 耦合决定, 且参数维数只多不少. 本工作的核心思想 — 把已知标度律编码为 BO 坐标 — 在固体版本里对应把椭圆率依赖, 场强-截止标度, 层厚-吸收平衡等写入坐标变换; 特别是 Straddle 采集函数找扩展高效率区的思路, 对固体 HHG 实验中寻找对厚度涨落和损伤不敏感的操作窗口有直接参考价值. (3) '找最优点 ≠ 重构景观'的方法论警示: 五种参数化最大 CE 几乎相同但景观保真度差 3.5 倍, 这条对林赛做任何基于代理模型的参数扫描 (包括神经网络拟合 HHG 谱) 都是提醒: 只报告最优值会系统性掩盖代理模型对参数依赖的误判, NRMSE + 结构指标的双评估协议值得直接搬用. (4) 与知识库条目的连接: 本工作依赖的 HarP 传播代码有独立论文 arXiv:2610.35440 (知识库收录范围内可关联); Weissenbilder 2022 NRP 的 p-L 双曲线和 Westerberg 2025 APL Photonics 的脉宽标度是两个物理输入, 若做固体版迁移, 需要先确认固体体系中是否存在同等可靠的标度律 — 这本身就是一个值得课题 A 回答的问题 (固体 HHG 的厚度-压强/厚度-场强是否存在类似双曲最优关系). (5) 拍赫兹电子学与波形优化的间接关联: 文中引用的 BO 在强场领域的应用 (Shalloo 2020 LWFA, Jalas 2021, Chu 2021 阿秒脉冲波形控制) 显示 BO 已是强场 waveform control 的标准工具; 林赛若推进量子光学驱动 HHG 的波形整形, 本框架 (坐标变换 + 阈值区域映射 + Sobol 验证集) 是现成的质量控制模板. (6) 07-24 职责边界: 只提炼物理与方法论, 不评论具体工程实现难度.

### 研究方法（Methods）

- 物理知情坐标变换的通用配方: 识别体系的已知标度关系 (本例: pL 双曲线来自相位匹配-吸收平衡, τ^-1/2 来自脉宽依赖), 把其乘积/比的对数作为 GP 坐标, 使平稳核 (Matérn) 的距离度量与物理结构对齐. 配方本身与 HHG 无关, 可移植到任何有已知标度律的昂贵模拟优化问题.
- Straddle 采集函数用于区域映射: Str(x) = β·σ(x) - |µ(x) - f_target|, 第一项推向高不确定区, 第二项贴着估计边界采样, 专门识别 CE(x) ≥ CE_target 的扩展区域. 相比 LogEI 只找孤立最优点, 该策略输出实验上更稳健的操作窗口 (对参数涨落有容忍度).
- 双指标景观评估协议: NRMSE 量化数值偏差, SSIM (图像结构相似度, 全局计算) 量化峰-脊-谷的结构保真, 区分'数值准'与'结构准'. 2D 用 100x100 网格参考, 4D 用 1024 点 scrambled Sobol 准随机参考集 (训练集与评估集严格分离).
- 目标函数变换作为独立优化维度: 对 CE 开平方压缩动态范围, 与坐标变换正交且可叠加, 在 4D 中单独贡献约 37% 的误差降低. 变换保持序关系, 故阈值在变换空间与物理空间一一对应.
- 非线性坐标下的边界处理: 采集函数直接优化会提出物理域外的点, 用随机候选 + 物理约束拒绝采样 (512 点池) 保证所有模拟点落在原始 (p, L, I, τ) 界内 — 这是使用非线性变换时容易被忽略的工程细节.
- 开源闭环工具链 HarP-BO: BoTorch/GPyTorch 优化器 + HarP 传播模拟器接口 + 全部运行数据与分析脚本, 构成可复现的仿真-优化闭环, 也为他人在其上扩展参数维度 (焦点位置, 气体密度剖面, 波长, 气种) 提供了底座.

### 主要发现与核心结论（Main Results）

- 2D 五种参数化系统对比: 在 (p, L) 线性坐标中 GP 完全无法重构双曲脊, 产生碎片化伪结构和竖直条带, NRMSE ≈ 0.14, SSIM ≈ 0.77; 单纯对数坐标 (log p, log L) 明显改善; 乘积-比坐标 (pL, p/L) 能捕捉双曲几何但产生多条伪脊; 只有组合变换 (log(pL), log(p/L)) 同时满足尺度压缩与物理结构对齐, 达到 NRMSE ≈ 0.04, SSIM ≈ 0.98. 结论: GP 重构精度同时需要合适的坐标缩放和对物理几何的对齐, 缺一不可.
- 找最优点不等于重构景观: 五种参数化在 60 次 BO 迭代内都收敛到相近的最大 CE (3.6-3.7e-6, 23 次谐波, Ar, 810 nm), 线性坐标和最佳物理知情坐标的最大 CE 仅差 3.67 vs 3.64e-6, 但景观保真度差 3.5 倍 (NRMSE 0.14 vs 0.04). 这意味着只报告最优值的 BO 研究可能掩盖代理模型对参数依赖关系的系统性误判.
- Straddle 阈值采集策略有效映射扩展高效率区: 以 β = 1.96 (95% 置信) 平衡探索与利用, 算法系统地把评估点集中到目标效率区域的边界上. 三个阈值 (0.75, 1.5, 2.7e-6) 下 60 次迭代后 NRMSE 均 < 0.08, 中高阈值 SSIM ≈ 0.98. 高阈值 (2.7e-6) 时算法在 19 次迭代内即达到 3.47e-6 (网格参考最大 3.56e-6), 说明边界采样策略同时高效锁定脊核.
- 4D 优化中脉宽标度与目标变换的独立增益: 保留原始 (p, L, I, τ) 的参考参数化 NRMSE_Sobol ≈ 0.126; 换成 (log(p/L), log(pL), I, 1/√τ) 降至更低; 再加 CE 平方根目标变换后达 NRMSE_Sobol ≈ 0.044, 相对参考降低约 65%. 目标函数变换本身在同坐标下贡献约 37% 的误差降低. 有趣的反转: 采样到的最高 CE (6.46e-6) 由不加 √CE 变换的物理知情参数化给出, 而景观重构最准的却是加了变换的版本 — 再次印证最大化与重构是两种不同的能力.
- 4D 预测最优点及其确认: GP 预测的最优参数为 L/zR = 0.0525, pzR = 300 mbar·cm (上界), I = 3.70e14 W/cm², τ = 11 fs (下界), 预测 CE = (6.81 +0.73/-0.69)e-6 (不对称误差来自非线性变换的回传), 独立 HarP 确认模拟给出 6.96e-6, 偏差仅 2%. 高效率区集中在短脉宽与 I ≈ 4e14 W/cm² 附近; 最优点落在压强上界和脉宽下界意味着真最优可能在所设域外.
- 传播模型与数值细节: HarP 框架求解傍轴 Helmholtz 方程 (圆柱对称, Crank-Nicolson), 驱动场包含线性色散/等离子体色散/Kerr 非线性 (Ar n2 = 9.8e-24 m²/W), 单原子响应来自预计算 3D TDSE 表 (SAE, 5 周期 ramp + 15 周期恒幅, 末 5 周期傅里叶提取), 吸收用 Henke 表. 固定 zR = 18.6 mm (w0 = 69.3 µm), 聚焦在介质中心. GP 用 Matérn 5/2 核 + ARD (每坐标独立长度尺度), 噪声固定 1e-5; Matérn 1/2 核 10 次迭代后拟合失败, 3/2, 5/2, RBF 收敛相近但 5/2 重构略优. 非线性坐标下采集函数优化会越出物理边界, 解法是拒绝采样 512 个有效候选点再取最大采集值.
- 可重复性纪律: 所有 2D/4D 结果用 5 个独立随机种子重复, 均值与标准差及全部数据集开源 (HarmonicPropagation GitHub + Zenodo), HarP 代码另有独立论文 (arXiv:2610.35440). 这种把 BO 收敛性从单次运气中剥离的做法在同领域文献中少见.

### 潜在研究方向（Future Directions）

- 参数维度扩展的自然路径已由作者列出: 激光焦点位置, 气体密度剖面 (现在固定为锐边均匀), 驱动波长, 气体种类. 其中密度剖面自由化最有可能打破 pL 双曲线的简单结构, 检验物理知情坐标在更复杂景观下的鲁棒性.
- 参数化未必最优, 替代变换 (例如基于传播物理的更精确标度) 值得探索; 一个潜在方向是把 GP 核本身做成物理知情 (非平稳核), 而非只变换坐标.
- Straddle 思路可推广到多目标: 同时映射多个阈值的等值面, 得到 CE 景观的分层拓扑, 对实验设计 (选择哪个参数最宽容) 有直接指导意义.
- 从仿真走向实验闭环: HarP 是确定性模拟器 (噪声固定 1e-5), 实验噪声与漂移下该框架的鲁棒性未验证; 在线 BO (每步是真实验而非模拟) 是显然的下一步, 领域内已有激光等离子体的先例.
- 对林赛课题的直接启示: 固体 HHG 的多维参数空间 (晶体取向 x 样品厚度 x 场强 x 脉宽 x 椭圆率 x 温度) 维数更高且每次传播模拟更贵, physics-informed BO 的框架可整体迁移; 固体体系同样有已知标度律可编码 (例如椭圆率依赖, 层厚-吸收平衡, 场强-截止标度).
- 警惕点: 4D 最优点落在参数域边界 (压强上界/脉宽下界) 提示域的选取本身影响结论; 采用此类框架时应先做边界敏感性检查或扩大域重跑, 避免把域边界误当物理最优.

## 研究方法（方法卡）

**方法**：气体 HHG 转换效率的物理知情贝叶斯优化（标度律编码坐标变换 + Straddle 阈值采集映射高效率区 + NRMSE/SSIM 双指标景观评估：4D 全局重构误差降 65%）

**原理**：气体 HHG 转换效率（CE）优化的多尺度问题（微观单原子响应×宏观相位匹配耦合，4D 穷举需 1e8 次模拟）：物理知情 BO 框架把已知标度关系（最优 CE 压强-长度双曲线 pL ≈ const、最优脉宽标度 CE_max ∝ τ^-1/2）经非线性坐标变换直接编码进搜索空间（log(pL)/log(p/L) 组合坐标使 GP 平稳核距离度量与物理结构对齐）；「找最优点 ≠ 重构景观」方法论警示：五种参数化最大 CE 几乎相同（3.6-3.7e-6）但景观保真度差 3.5 倍（NRMSE 0.14 vs 0.04）——只报告最优值会掩盖代理模型对参数依赖的系统性误判（NRMSE + SSIM 双评估协议值得直接搬用）；Straddle 采集函数 Str(x) = β·σ(x) − |µ(x) − f_target| 识别 CE ≥ 阈值的扩展高效率区（β = 1.96 即 95% 置信；三个阈值下 60 次迭代 NRMSE 均 < 0.08）；4D（p, L, I, τ）：组合坐标 + CE 平方根目标变换使全局重构误差降低约 65%（目标变换本身贡献约 37%）；GP 预测最优参数 L/zR = 0.0525、pzR = 300 mbar·cm、I = 3.70e14 W/cm²、τ = 11 fs——独立 HarP 确认模拟偏差仅 2%（预测 6.81e-6 vs 确认 6.96e-6）。
