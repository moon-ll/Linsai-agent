• # Noncollinear magnetic multipoles in collinear altermagnets

  ## 林赛的理解

  这篇工作是交变磁（altermagnetism）多极子序参量的第一篇系统的实空间、第一性原理量化研究，对我们组的意义非常直接：**它给了我们一把"实空间显微镜"，把交变磁序从倒空间能带劈裂的抽象概念落到可计算、可投影的局域磁多极子上**。此前讨论 d 波交变磁（如 MnF2）时几乎只谈八极子，这篇工作明确指出 32 极子（dotriacontapole）在实空间自旋密度和宏观响应中可以是主导项——这意味着我们在设计"交变磁 + 强场超快"探测方案时，选择对的序参量张量（响应张量）比选择对的磁结构更关键。另外，SOC 诱导的非共线自旋密度随 SOC 强度**线性**增长、而共线多极子只有**二次**修正——这一条对我们用 THz/强场光场"瞬时打开"或调控交变磁响应的实验设计有直接定量含义：非共线通道是 SOC 的一阶探针，灵敏度预期高一个阶次。KMnF3 中八面体旋转 ~6° 即可线性打开 32 极子的结果，还提示了一条"结构畸变旋钮"的实验路线：用超快声子/应变脉冲动态调谐交变磁态。

  ## 研究问题

  论文要回答的核心问题是：**在共线交变磁体（collinear altermagnets）的实空间中，原子尺度的磁多极子（magnetic multipoles）到底有哪些、哪些分量是晶胞内同相（in-phase）不抵消的、它们的大小能否从头算量化，以及自旋-轨道耦合（SOC）如何修正它们？** 具体分解为三个子问题：

  1. 典型共线交变磁体 MnF2（d 波）和 CrSb（g 波）中，哪些原子磁多极子被对称性允许，哪些在同相叠加后不抵消、构成宏观交变磁序参量？
  2. 在通常被认为"共线"的磁体中，SOC 诱导的非共线自旋密度（NSD）携带怎样的多极成分，其量级和对称性与共线分量有何本质区别？
  3. d 波交变磁体中常被忽略的 32 极子（dotriacontapole）对宏观响应（如压磁性）是否必须纳入讨论？

  此外以钙钛矿 KMnF3 为第三体系，回答结构自由度（氟八面体旋转）如何调控/诱导反铁磁—交变磁相变。

  ## 研究背景

  - 交变磁（AM）是 2022 年以来确立的独立于铁磁和传统反铁磁的磁相：其磁序自身破缺时间反演对称性 T，但保留 T 与某些非点式（non-symmorphic）晶体对称性的组合，保证净磁偶极矩抵消；由此在无 SOC 时就能使原本自旋简并的能带在大部分布里渊区劈裂，仅在特定节线/节面上保持简并，劈裂图样按角动量分类为 d 波（l=2）、g 波（l=4）等（类比非常规单态超导的节点结构）。
  - 这一节点—角动量联系催生了对交变磁多极子序参量的理论研究（cluster multipole、Landau 理论等）。实验上已有多极子探测提案：压磁性、二阶磁电效应、磁光 Kerr 效应等。理论侧，金属中多极子与 Pomeranchuk 失稳相联系，绝缘体中通过晶场+SOC 的原子 d/f 电子图像处理。
  - 但**真实材料实空间中从头算可视化和量化交变磁多极序参量的工作很少**（Bhowal & Spaldin 提出 MnF2 的铁八极序图像、Verbeek 等提出 α-Fe2O3 的铁 32 极序图像），且 SOC 对实空间多极子的影响从未被系统研究。
  - 本文动机即填补这一空白：发展"对称性判别允许多极子 → 预测同相/反相 → 从头算投影量化大小"的完整方法，并揭示 SOC 诱导的非共线多极子可能比共线分量更直接地展示交变磁性。

  ## 研究方法

  - **理论框架**：基于磁空间群（MSG）与磁 Wyckoof 位置确定每个原子位点的磁点群对称性，从而确定该位点允许的磁多极子；通过不可约表示（irrep）子群包含分析（subduction analysis，如 MnF2 中 mΓ2+ ↓ mmm.1′ → Ag− ⊕ B1g−）判定各多极子在晶胞内两磁离子之间是同相（IP）还是反相（OP）。判据核心：非点式对称操作（如 42 螺旋轴、63 螺旋轴、c 滑移面）交换两个磁离子且使其局域坐标系相对旋转 90° 或 60°，因此**在局域坐标反相的多极子若其轨道部分对相应旋转为奇函数，则全局坐标下同相**。
  - **多极子量化**：DFT 计算实空间自旋密度 m(r)，将原子球内 m(r) 各分量投影到 ℓ 阶立方（tesseral）谐波上，得到 ℓ+1 阶磁多极子的幅值，单位为 a₀^ℓ μB（a0 玻尔半径、μB 玻尔磁子）；八极子记 dxymz 型（∼∫xy·mz(r)dr），32 极子记 gmz 型（g 轨道样 l=4 节点图样）。此方法绕开了晶胞多极子因周期体系位置算符问题缺乏规范不变定义的困难。
  - **SOC 依赖分析**：通过扫描 SOC 强度参数 λSOC（0 = 关闭，1 = 真实值）计算各多极子的 λSOC 依赖；用微扰论解释：HSOC ∼ λSOC L·S 与 H0 的对易子在自旋和轨道空间均为非对角，故一阶波函数修正只含反向自旋成分 → 面内（非共线）自旋密度一阶出现，而非自旋翻转修正二阶才出现。
  - **压磁系数计算**：对晶胞施加应变、弛豫原子位置、自洽求解磁化强度，得到压磁张量 Λijk（Mk = Λijk εij）各分量与对应八极子的依赖关系。
  - **材料体系**：金红石 MnF2（MSG P42′/mnm′ #136.499，d 波）、六方金属 CrSb（MSG P63′/m′m′c，g 波）、钙钛矿 KMnF3（Pm3̄m → I4/mcm 结构相变，磁序 mR5−）。
  - **计算工具**：ABINIT 第一性原理代码（PAW 方法、Libxc 泛函库），数据存于明尼苏达大学数据仓库（ProDenCer）。

  ## 主要发现与核心结论

  1. **共线多极子的对称性分类与量化**：
     - MnF2 中允许的共线多极子（均属 mΓ2+ [B1g−]）：反相（OP）分量——偶极 smz、d z2mz、g z4mz、g x2y2mz；同相（IP）分量——八极 dxymz 与 32 极 g xyz2mz。偶极与所有 OP 多极抵消（补偿磁体），IP 八极与 32 极不抵消，与"金红石结构共线补偿磁体为 d 波交变磁、晶胞最低非零多极为八极"一致。
     - CrSb（g 波）中：OP 分量——smz、d z2mz、g z4mz；唯一的 IP 分量是 32 极 gyz(y2−3x2)mz。即偶极和八极全部抵消，**最低阶不抵消共线多极子是 32 极子**。
     - 单位晶胞内多极子的 IP/OP 行为由局域坐标系间的相对旋转（MnF2 为 C4z 90°，CrSb 为 6 重旋转+对角 {110} 镜面）下多极子轨道部分的奇偶性决定，DFT 结果与群论预测完全一致。

  2. **SOC 诱导的非共线自旋密度（NSD）是多极子更直接的载体**：
     - 即使在共线磁体中，一般等效位置 (x,y,z) 的局域自旋密度方向不受对称性约束，NSD 存在但原子球积分 ∫mx(r)dr = ∫my(r)dr = 0，故常被忽略；DFT 等值面图直接显示其存在。
     - **NSD 比共线分量小一个数量级以上**（"smaller than the collinear component by more than an order of magnitude"），但呈现清晰的节点结构，其多极行为比被偶极项主导的共线分量更直接地展示交变磁序。
     - MnF2（d 波）的 NSD 中出现不抵消的 32 极子——即使主序参量是八极，高阶面内多极在 NSD 中占主导并影响依赖面内磁矩的观测量。
     - **λSOC 依赖的阶次是核心定量结果**：非共线多极子随 λSOC **线性**出现（λSOC=0 时严格为零）；共线多极子仅被**二次（quadratically）**修正且幅度小到图中不可见。机制源于 HSOC 与 H0 对易子的自旋-轨道双非对角结构（一阶修正只含反向自旋 → 面内 NSD；非自旋翻转修正二阶才出现）。
     - MnF2 允许的非共线多极子：OP——dxzmx + dyzmy、g xz(x2−3y2)mx + gyz(3x2−y2)my；IP——dyzmx + dxzmy、gyz(y2−3x2)mx + gxz(x2−3y2)my（对 4 重旋转为奇者 IP）。
     - CrSb 允许的非共线多极子：OP——dyzmx + dxzmy、g yz3mx + gxz3my；IP——dxymx + dx2−y2my（八极）、gxyz2mx + g(x2−y2)z2my、gxy(x2−y2)mx + gx2y2my。**意外的是 CrSb 中最低阶 IP 非共线多极是 60° 旋转下为奇的对称性八极子**。

  3. **结构调控：KMnF3 中八面体旋转线性打开 32 极子**：
     - KMnF3 在 ~88 K 发生立方 Pm3̄m → 四方 I4/mcm 结构相变，G 型共线磁序（mR5−，zone-boundary 序，保持平移×时间反演联合对称）在相同或相近温度凝聚。
     - 四方相中氟八面体绕 c 轴旋转 **~6°**，晶胞加倍；八面体旋转序参量属 R5− 不可约表示，与磁序参量同一波矢，二者共同凝聚后反平移对称破缺 → 诱导交变磁性；交变磁劈裂正比于磁序参量与结构序参量之积。
     - DFT 显示：Mn 离子周围 mz(r) 等值面随八面体一同旋转且几乎无畸变，**积分偶极密度 smz 几乎不随旋转角变化，而最低阶 IP 多极子——32 极 gxy(x2−y2)mz——随八面体旋转角线性增长**。该 32 极按 Pm3̄m.1′ 的 mΓ1+ 变换，自由能三项耦合 F ∼ R5−(a,0,0)·mR5−(a,0,0)·mΓ4+ 解释其线性依赖。
     - 关联化合物 RbMnF3 的 Néel 温度与 KMnF3 相当但全温区保持立方结构，故部分 Rb 取代的 K1−xRbxMnF3 可望将结构相变温度压低到与磁相变分离，成为研究反铁磁—交变磁相变的模型体系。类似的旋转诱导交变磁相（菱方结构、同一旋转模式）在 BiFeO3 中也被研究过，说明这是磁性钙钛矿的共性特征。

  4. **与宏观响应张量的联系（五要素中的"所以什么"）**：
     - 多极子可与 Jahn 符号对应：磁八极 rirjmk 是轴矢量、磁性、秩 3、对 i↔j 对称，记 ae[V2]V；具净磁八极的系统必须允许 ae[V2]V 型响应张量非零元，如压磁性、二阶磁电效应。
     - MnF2 的 IP 共线分量 dxymz 对应压磁张量元 Λxyz（z 向磁化对 xy 剪切应变）。Λxyz 无 SOC 时对称性即允许、由大共线自旋分量诱导，但在零温能隙打开时被 **Luttinger 补偿**（自旋上下电子数相等）强制为零；而原子八极 dxymz 不受补偿影响、在所有 SOC 值下非零。值得注意：无 SOC 时 dxymz 非零而 Λxyz 在图示尺度内为零。
     - 无 SOC 时对称性不允许的 Λxzy（y 向磁化对 xz 剪切应变）在 SOC 小时**线性依赖**对应八极 dxzmy，仅在真实 λSOC 值处略有偏离线性；该分量不受 Luttinger 补偿影响，因其磁化来自局域原子矩的倾斜。
     - CrSb 只在非共线分量中呈 d 波，故应变只能沿 x、y 方向诱导线性磁化，且效应大小必须正比于 λSOC；与共线 32 极 gyz(y2−3x2)mz 线性相关的最低秩张量为秩 5 的 ae[V2][V2]V，包括二阶压磁性（磁化正比于两个不同应变分量之积，如 εyz·εxx）和二阶磁电效应的应变导数。

  5. **总结论**：即使表观共线自旋密度接近球对称，非共线分量也更能说明交变磁多极的存在与相对相位；**32 极子在 d 波交变磁中不可忽略，可对自旋密度乃至某些宏观性质给出主导贡献**；NSD、高阶多极、SOC 都是真实交变磁体预测宏观响应时必须纳入的要素；八面体旋转把交变磁性加入了钙钛矿中旋转诱导现象的清单。

  ## 潜在研究方向

  - 方法局限：投影量化只在原子球内进行，未计入晶胞总多极子的全部贡献（晶胞多极子因周期体系位置算符问题无规范不变定义）；多极子的符号与大小由对称性之外的物理决定，本文只量化幅值排序。
  - Luttinger 补偿对 Λxyz 的压制意味着"对称性允许 ≠ 可观测"——设计多极子探测实验时必须同时检查补偿约束，本文未给出补偿破缺（如激发载流子、升温越过能隙）下 Λxyz 的动态演化。
  - NSD 比共线分量小一个数量级以上，实验探测信噪比是开放问题；非共线多极子的谱学指纹（如共振 X 射线散射、非弹性中子散射的选择定则）尚未具体提出。
  - CrSb 中 Cr 轨道部分占据使 NSD 图样复杂化，多极分解的鲁棒性（对投影半径、泛函的依赖）在正文中未系统检验。
  - K1−xRbxMnF3 作为分离结构/磁相变的模型体系仅为预测，尚未实验验证；八面体旋转动态调谐交变磁（如用超快声子激发）是自然的延伸方向但本文未涉及。
  - 时间维度完全缺失：本文全部为准平衡静态计算，多极子对交变磁的**超快光致退磁/重取向动力学**的响应未讨论，而这恰是强场超快探测最能贡献的维度。

  ## 与林赛研究的关联

  - **交变磁 + 强场 HHG/阿秒读出**方向词高度契合：本文给出的"IP 多极子 ↔ 响应张量（ae[V2]V 压磁/二阶磁电、秩 5 ae[V2][V2]V）"映射，正是我们选择 THz 非线性磁电或偏振分辨 HHG 作为交变磁序读出通道时的张量选择依据——对 d 波体系（MnF2 类）应优先看八极通道，且注意 Luttinger 补偿对静水压磁通道的静态压制（动态激发下补偿可解除）。
  - **非共线分量 ∝ λSOC 一阶**：强场光场本身不直接调 λSOC，但非共线多极子是 SOC 的一阶探针——在强激光诱导的瞬态磁化/退磁过程中，面内磁矩通道的灵敏度预期比共线通道高一个微扰阶次，这对我们"用 HHG 偏振分量分离共线/非共线磁响应"的方案设计是定量输入。
  - **32 极子主导项的警示**：若用倒空间能带劈裂反推实空间序参量，d 波交变磁中 32 极的贡献可能主导某些面内观测量——我们 proposal 中的"序参量选择性读出"章节应引用此结论，避免把 MnF2 类体系简化为纯八极模型。
  - **结构旋钮接口**：KMnF3 的 ~6° 八面体旋转线性打开 32 极、以及 K1−xRbxMnF3 的结构—磁相变分离预测，为我们"应变/声子辅助的交变磁超快调控"提供了具体材料平台和定量标度（多极 ∝ 旋转角）。
  - 方法学上可直接复用：MSG → 磁 Wyckoof 位 → 允许多极子 → DFT 自旋密度投影到 tesseral 谐波的流程，可用于我们候选材料库（含莫尔/二维磁性体系）的序参量预判；对称性判据（局域坐标旋转角下多极子轨道部分的奇偶性）对分析莫尔超晶格中局域磁对称性同样适用。
