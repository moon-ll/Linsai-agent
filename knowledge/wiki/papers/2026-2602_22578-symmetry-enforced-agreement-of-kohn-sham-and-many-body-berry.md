• # 对称性强制一致：SSH–Hubbard 链上 Kohn–Sham 与多体 Berry 相的吻合

  ## 林赛的理解

  这篇工作对我最值钱的地方不是结论本身（γ=0 且在 U 全域不变，本质上是被对称性量化的平庸结果），而是它把一个方法论问题钉死在了一个可控模型里：**密度匹配的 KS 描述到底能不能复现相互作用体系的 Berry 几何？**答案是——在这个反演对称、半填充、密度平坦的特殊设定下能，但原因是 Z₂ 对称保护拓扑（SPT）类的"部门匹配"（sector matching），而不是密度真的编码了多体 Berry 联络。作者亲手构造了反例（U→U(θ) 使相互作用项也带通量依赖），说明密度约束本身并不结构性保护这种一致。

  这对我们课题的实际用处有三层：

  1. **为我们用 DFT/带结构语言讨论强关联拓扑提供了"何时合法"的判据**。我们写交变磁、莫尔体系方案时经常引用 DFT 算的 Wilson loop / Berry 相位，这篇论文给出了一条明确的警戒线：只有在对称性把 Berry 相量化到离散值（0 或 π）、且 KS 参考无对称破缺地与自由代表绝热连通时，DFT 的拓扑诊断才可信；一旦离开保护对称性或密度不再平坦，KS 几何可以全面失效（量子度量完全丢失而 Berry 相仍"碰巧"一致——这正是最危险的假象）。
  2. **量子度量 vs Berry 相的分离是一个可引用的概念框架**。强耦合极限下 g_θθ ∼ (t/U)² 被压制、而 Berry 相保持量化——"局域几何响应可以惰性化，全局拓扑荷仍然受保护"这个层级结构，与我们在强场驱动瞬态相探测中关心的"哪些可观测量对拓扑敏感、哪些不敏感"直接同构。
  3. **方法素材**：U(1) 通量插入 + DMRG 全扭曲循环 + 离散 Wilson loop 算多体 Berry 相的完整流程（含 wrap-link 伪影处理、unwrap 平均的量子度量估计器），是把"多体几何响应"做成数值实验的标准范式，可迁移到我们想验证强场诱导拓扑相的模型计算中。

  ## 研究问题

  核心问题：**一个仅匹配基态密度的 Kohn–Sham（KS）描述，能否在关联绝缘体中复现多体波函数的 Berry 相？** 尽管几何相位原则上只是波函数的泛函、而非密度的泛函——已有工作强调 Berry 相一般不能由单体期望值或密度唯一确定——但在某些模型中 KS 描述似乎又能给出相同相位。本文要在最小可控模型（一维 SSH–Hubbard 链）中把"何时能、为何能"的机制显式化：沿同一 U(1) 扭曲循环分别计算多体 Berry 相与密度匹配 KS 参考的 Berry 相，追踪二者的一致性（或不一致）如何随相互作用强度 U 从弱耦合演化到强耦合。

  ## 研究背景

  - **DFT/KS 框架的拓扑使用惯例**：非相互作用电子的 Berry 相与极化由占据 Bloch 带决定，可直接从能带结构读出；实际材料计算中这些能带来自 DFT 的 KS 构造，这是 DFT 工作流广泛用于带拓扑表征（Hasan & Kane 2010；Qi & Zhang 2011 式综述所代表）的基础。
  - **强关联下的理论张力**：相互作用增强后基态变为真正的多体态，极化与 Berry 相成为多体波函数的泛函；Resta、Vanderbilt 等人的工作（引文 [8–11]）明确指出这些相位一般不能由密度这类约化信息唯一确定。这就提出了 KS 描述可能无法重建相互作用依赖的全息（holonomy）的风险，尽管存在模型层面 KS 复现相同相位的个案（引文 [12]，Resta 2018 关于 KS-DFT 中极化的讨论）。
  - **选题动机**：SSH–Hubbard 链（一维二聚化 Fermi–Hubbard 模型，引文 [13, 14] 代表的相关模型研究）是最小的强关联拓扑设定，解析极限（U=0 自旋 SSH、U≫t 有效 Heisenberg 链、δ=0 Bethe ansatz 可解）可提供对照，使"密度约束约束了几何信息"这一问题的相关条件可以显式写出，而不被模型依赖的复杂性遮蔽。

  ## 研究方法

  方法密度中等偏高——本文核心贡献是数值方法学（DMRG 全扭曲循环 + 对称性约化的 KS 密度反演 + 离散 Wilson loop 几何诊断），装置/计算细节详尽。按方法卡整理：

  ### 方法卡：U(1) 通量插入 + DMRG 多体 Berry 相计算

  **原理**：在环上插入 U(1) 规范通量 θ（等价于 Peierls 相位），把 θ 视为哈密顿量空间中的绝热参数，基态 |Ψ₀(θ)⟩ 随 θ: 0→2π 构成希尔伯特空间中的几何轨迹；Berry 相由相邻态重叠的 Wilson loop 之积的辐角给出，即多体极化。通量在周期边界下不可规范去除，是 Berry 相的来源（Zak 相位/Resta 公式体系）。

  **参数表**（数值原样，出自原文 Sec. IV 及 Table I）：

  - 模型：SSH–Hubbard 哈密顿量，交错跃迁 t_i = t[1+(-1)^i δ]，在位排斥 U≥0，半填充 N_e = 2N，自旋非极化；t = 1 为能量单位
  - 二聚化参数：δ = 0.6（原文："yields a well-developed insulating regime"）
  - 边界条件：全程周期边界（PBC）；OBC 下拓扑区边缘零模使能隙指数收缩（L=12 时 Δ ~ 10⁻⁴），故弃用
  - 代表体系尺寸：L = 2N = 20（偶数 N）；尺寸扫描 L = 8, 12, 20, 30, 40, 50，L≥20 后物理观测量仅微小变化
  - 扭曲实现：均匀规范（uniform gauge），每条最近邻键均分相位 e^{-iθ/(2N)}，等价边界扭曲形式（Eq. 15）
  - 扭曲网格：θ_j = 2πj/N_θ，N_θ = 20（N_θ ≥ 20 后 L²⟨g_θθ⟩ 收敛到不可区分的单曲线）
  - DMRG 实现：基于 TenPy 库
  - 最大键维：m = 300（基态 GS）、m = 500（第一激发态 ES）
  - 截断误差：≤10⁻⁸（GS）、10⁻¹²（ES）、10⁻¹⁴（ES 精修）
  - 扫描次数：60（GS）、90（ES）、60（ES 精修）
  - 能量收敛阈值：10⁻⁸（GS 与 ES 同）
  - 收敛判据：L=20 下 |⟨ψ₀|ψ₁⟩| ≲ 5.0×10⁻⁷（对所有 U）；能量自洽 |E_eigen(θ) − ⟨ψ|Ĥ(θ)|ψ⟩| ≤ 10⁻¹⁰
  - ED 基准：L=2N=12 时 DMRG 与精确对角化基态能量偏差 < 10⁻¹³（L=6, 8, 10 同水平）
  - U 取值网格（多体，非均匀）：基线集 U = [0.0, 0.3, 0.5, 0.7, 1.0, 2.0, 3.0, 4.0, 6.0, 8.0, 10.0, 15.0, 20.0]，中间 U 区加密点 U = [0.6, 0.9, 1.2, 1.5, 1.8, 2.1, 2.4, 2.5, 2.7, 3.5, 4.5, 5.0]；KS 只算基线集
  - Berry 相离散公式：γ = −Im log ∏_j O_j，O_j = ⟨Ψ₀(θ_j)|Ψ₀(θ_{j+1})⟩
  - 量子度量估计器（链分辨）：g⁽ᵉˢᵗ⁾_θθ(θ_j, U) = −2/(Δθ)² · log|O_j(U)|，Δθ = 2π/N_θ；局域诊断用 unwrap 均值（剔除回绕链 θ_{Nθ−1}→θ_0），Berry 相用含回绕链的完整 Wilson loop

  **KS 密度反演的对称性约化**（方法学要点）：二聚化使体系具有二格点平移对称 [Ĥ, T̂₂] = 0，非简并基态（Wigner 定理）给出 ⟨n̂_{j+2}⟩ = ⟨n̂_j⟩，密度只剩两个不等价值 n_A、n_B 且 n_A + n_B = 2，独立自由度只有 δn = n_A − n_B；再施加反演对称，最一般单体势为 v_i = ±Δ_KS（A 格 +Δ_KS，B 格 −Δ_KS），多维密度反演问题严格约化为单变量求根 δn_KS(Δ_KS) = δn_MB。KS Bloch 哈密顿量 H_KS(k) 为 2×2，本征值 E_±(k) = ±√(Δ_KS² + t₁² + t₂² + 2t₁t₂ cos k)。

  **适用边界**：

  - Berry 相良定义的前提是基态在整个扭曲循环 θ∈[0, 2π] 上非简并且有有限能隙——本文对每个 U 验证 Δ_min^MB(U) = min_{θ_j} Δ_MB(θ_j, U) 有限（Fig. 1）
  - 量子度量估计器必须用 unwrap 链均值：回绕链的规范/分支匹配使 ⟨g_θθ⟩_all 出现非物理的 N_θ 依赖（Fig. 2 上下面板对比），而 unwrap 均值 N_θ≥20 后收敛
  - 本模型的对称性约化依赖 PBC + 半填充 + 反演对称 + 自旋非极化；离开这些前提，密度反演回到多维变分问题

  **代表作**：Watanabe 2026（本文，arXiv:2602.22578，DMRG 验证 KS–多体 Berry 相在 Z₂ SPT 类内一致）；方法学源头 Resta 1998（Resta 公式，Phys. Rev. Lett. 80, 1800）。

  ## 主要发现与核心结论

  1. **密度在整个 (θ, U) 参数面上平坦**：DMRG 显示半填充反演对称能隙区内，n_A、n_B 及各格点密度对 θ 和 U 无可分辨依赖，残差变化 ~10⁻⁹（最大偏差 ≲10⁻⁸），密度钉扎在 ⟨n̂_iσ⟩ ≃ 0.5。因此密度约束不提供任何非平凡信息，自然选择 Δ_KS = 0，KS 参考严格约化为 U=0 的二次型 SSH 自由费米子问题——KS 哈密顿量及 KS 几何完全与 U 无关。
  2. **多体波函数仍有真实的几何响应**：邻居重叠 |O_j| 偏离 1 表明态沿扭曲方向有非平凡形变；量子度量估计器 L²⟨g_θθ⟩_unwrap(U) 在中介 U 依赖 θ、随 U 增大被强烈压制。标度分析：强耦合下 ∂_θĤ = O(t)、中间态电荷激发能量 O(U)，给出 g_θθ ∼ t²/U²；大 U 下 ⟨g_θθ⟩_unwrap 单调下降，与能隙行为一致（∆_neutral ∼ t²/U 而 g⁽log⁾_θθ ∼ (t/U)²），物理解释为电荷涨落冻结。弱耦合下扭曲等效于 k → k + θ/L，几何响应由单粒子能带结构继承，θ 依赖增强（Fig. 3 热图，θ≈π 两侧近似对称，反映反演对称下 θ→2π−θ 对称性）。
  3. **KS 与多体 Berry 相在全 U 范围（弱到强耦合）一致，且 γ = 0 (mod 2π)**：Wilson loop 给出的 cos γ 对二者均贴合 y = 1（Fig. 5，MB 实心圆 / KS 空心方）。但机制是**对称性强制的 Z₂ 部门匹配**：一维反演对称能隙体系的 Resta 相位被量化到 0 或 π（mod 2π），属 Z₂ SPT 类；只要体能隙不关闭、保护对称性不破缺，同一绝热类内所有哈密顿量共享同一量化相位，且该类容许不破缺对称的自由（二次型）代表。KS 参考（Δ_KS=0 的 SSH）与该自由代表绝热连通，多体态也在同一 Z₂ 类，故相位相等是拓扑量化本身的强制，而非密度重建几何信息的结果。
  4. **密度约束不结构性保护几何一致（反例）**：若推广到相互作用项本身带通量依赖 U→U(θ) 的有效格点模型，通量共轭生成元 Ĵ(θ) = −∂_θĤ(θ) 含相互作用诱导项 (∂_θU)Σᵢ n̂_i↑n̂_i↓，它原则上可以抵消跳跃部门的局域电荷响应，使密度剖面沿循环严格 θ 无关而多体 holonomy 仍非平凡。即密度约束一般不决定全局 Berry 相几何。
  5. **结构性层级结论**：局域一点可观测量（密度）对拓扑不敏感；局域几何指标（量子度量）在大 U 下也会惰性化（g_θθ → 0）；而全局 Berry 相保持对称性保护——三者的分离确立了"局域几何响应 ≠ 全局拓扑 holonomy"的层级结构。

  ## 潜在研究方向

  作者明示的开放问题：

  1. **去掉保护对称性**：在没有反演对称（或相应保护对称）、Berry 相不再量化的区域，KS 构造即使精确复现密度，其 Berry 相能否保持稳定、还是一般地不受约束？这是检验"对称强制一致"机制普适性的第一刀。
  2. **其他相互作用拓扑分类**：类似的 KS–多体一致能否存在于其他相互作用保护分类（如 Z₈ 约化）的相中——那里对称保护以不同方式约束绝热类。
  3. **代表性 vs 巧合**：SSH–Hubbard 案例究竟是更广泛机制（对称强制部门匹配）的代表，还是绑定于特定对称性与密度平坦设定的例外巧合。
  4. 本文自身限制：密度平坦（δn 对 θ、U 不敏感）是本模型的特殊性质，KS 反演得以严格单参数化；一般关联体系中密度反演是多维优化，KS 几何是否/如何失败需要另行研究。所有计算限于一维、半填充、PBC、自旋非极化扇区；扭曲只通过跳跃部门进入（相互作用项 θ 无关），这一设定本身排除了反例类行为，向 U(θ) 类模型推广是自然的下一步。

  ## 与林赛研究的关联

  - **HHG / 强场驱动**：本文的 U(1) 通量插入 + 绝热 θ 循环在数学上与强场驱动下周期驱动体系的 Floquet/Fermi 面畸变分析同构；邻居重叠 Wilson loop 和量子度量估计器可平移到"光场驱动诱导的瞬态几何响应"的数值表征——特别是区分"局域几何量被压制 vs 全局拓扑量存活"这一层级，对我们判断**交变磁/拓扑体系在强场下的可观测信号该选哪个诊断量**有直接借鉴意义。
  - **莫尔与关联拓扑**：SSH–Hubbard 是关联拓扑的最小模型，其 Z₂ SPT 部门匹配机制对莫尔体系（平带、强关联、拓扑带并存）中"DFT 拓扑诊断何时可信"给出判据——莫尔方案写作中引用 DFT Wilson loop 时必须检查：对称性是否量化相位、KS 参考是否与自由代表绝热连通。
  - **量子几何**：量子度量 g_θθ ∼ (t/U)² 的强耦合压制标度，与我们在莫尔/关联体系中关心的"量子几何自由度何时冻结、何时可驱动"问题直接对应；unwrap/wrap 链的处理经验对我们做驱动体系几何诊断的数值实现有工程价值。
  - **可迁移方法素材**：通量插入 DMRG 全循环 + 离散 Wilson loop + 链分辨量子度量估计器，可作为我们验证"强场诱导瞬态量子相"模型计算的标准数值范式（已关联课题 key-transient-quantum-phase-optical-20260726）。
