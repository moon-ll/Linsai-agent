## 阅读笔记

### general-attosecond-streaking-20260822

**标题**：Reference Energies for Valence Ionizations and Satellite Transitions
**作者**：Antoine Marie, Pierre-François Loos（Laboratoire de Chimie et Physique Quantiques, UMR 5626, Université de Toulouse, CNRS, UPS, France）
**出处**：J. Chem. Theory Comput. (DOI 10.1021/acs.jctc.4c00216)；arXiv:2402.13877 [physics.chem-ph]，v1 2024-02-21、v2 2024-04-10，22 页3 图

### 研究问题（Research Question）
分子价层电离谱中的伴线（shake-up）能量此前缺乏可信的理论基准：现有 IP 基准集（如 GW100、24 个有机受体分子集、以及 Ranasinghe 等的 IP-EOM-CCSDTQ 集）都只针对主价 IP。本文的核心目标是建立首个分子伴线（satellite）能量基准集——以 FCI 品质给出 42 个伴线跃迁能与 58 个价层电离势——并以此检验耦合簇（CC）层级与多体 Green 函数类方法（G0W0、G0F(2)、G0T0、qsGW）对伴线的描述能力。

### 研究背景（Background）
价层电离发生在 10–40 eV 区间，10–20 eV 内尖锐强峰是单粒子（Koopmans 态）电离，稍高能量处出现更宽、更弱的伴线，对应"一个电子电离同时激发另一（些）电子"，本质上是含至少两电子一空穴的多体现象，等价于中性激发中的双激发。HF 等平均场形式几乎无法描述双激发，必须显式包含相关效应。学术界已知 CC 层级在双激发上的表现（如 Ranasinghe 等报告 IP-EOM-CCSDT 相对 CCSDTQ 的 MAE 仅 0.03 eV、IP-EOM-CCSD 为 0.2 eV），但伴线是"两空穴一粒子"态，相关性要求更严苛——论文明确指出"计算方法若要真正预测价层电离谱，必须同时准确定位外层/内层价 IP 与价层伴线的位置"，而强度基准化被明确排除在本文范围之外，留待后续。

### 研究方法（Methods）
沿用 QUEST 数据库协议（Véril et al., WIREs Comput. Mol. Sci. 2021, 11, e1517），用 CIPSI（configuration interaction using a perturbative selection made iteratively）方法计算参考能，构型空间逐级外推逼近 FCI；基组从 Pople 的 6-31+G* 到 Dunning 的 aug-cc-pVDZ/TZ/QZ（X = D, T, Q）。体系为 23 个小分子，分属 10 电子、12 电子、14 电子、18 电子系列及第三周期元素系列。对照方法包括 CC 层级（CC2、CCSD、CC3、CCSDT、CC4、CCSDTQ）、基于多体 Green 函数的 G0W0、qsGW、G0F(2)、G0T0，以及态专用 ΔSCF 型 ΔCCSD(T)（用于 23 个主价 IP 的参考）。统计指标为 MAE、MSE、RMSE、SDE 及极值误差，在 aug-cc-pVTZ 基组上对 58 个 IP 汇总。

### 主要发现与核心结论（Main Results）
共报告 42 个 FCI 伴线跃迁能与 58 个 FCI 价层 IP，为 QUEST 第十层参考值，也是首个含带电激发的参考层。IP 精度（Table VI，58 个 IP、aug-cc-pVTZ，MAE/MSE/eV）：CC2 0.769/−0.594、CCSD 0.175/0.097、CC3 0.070/0.001、CCSDT 0.041/−0.010、CC4 0.015/0.005、CCSDTQ 0.010/−0.005；G0W0 0.470/0.399、qsGW 0.391/0.268、G0F(2) 0.807/−0.550、G0T0 0.485/0.007；ΔCCSD(T) 0.021/0.016（仅 23 个主 IP）。化学精度（<0.043 eV）在 IP 上于 CCSDT 达到。伴线（Table VII）则严苛得多：CCSDTQ 的 MAE 为 0.039 eV（刚低于化学精度），CC4 及其近似四重激发为 0.093 eV，CCSDT 为 0.537 eV，CC3 为 0.787 eV——即含三重激发的方法（哪怕完全包含）用于伴线都需谨慎。G0W0 与 G0T0 的 MAE 接近（0.485 vs 0.470），均无法描述伴线。结论强调：CC3/CC4 是 CCSDT/CCSDTQ 在 IP 上的忠实近似，但伴线只有到 CCSDTQ 才达化学精度。

### 潜在研究方向（Future Directions）
论文明确列出若干开放方向：显式引入三体 Green 函数以对 IP 与伴线同等对待；用新基准检验 ADC 层级的收敛性；在这些小分子体系上评估凝聚态社区常用的 cumulant Green 函数方法（该工作已在进行）。最突出的缺口是过渡强度（transition intensities）的基准化——作者承认这是与实验谱直接比较的关键，且在 SCI 形式框架内计算强度并不直接但可行，已规划为后续工作。另需注意本文只处理垂直（vertical）IP，不涉及绝热（adiabatic）对应量。

## 研究方法（方法卡）
<!-- methods-backfill:v1 -->
**方法**：CIPSI 外推 FCI 的分子伴线能量基准集（QUEST 第十层：42 伴线 + 58 IP 检验 CC/GW 层级）

**原理**：CIPSI 迭代微扰选择构型空间逐级外推逼近 FCI，建立首个含带电激发（伴线/shake-up）的分子基准集：42 个伴线跃迁能 + 58 个价层 IP；以此检验 CC 层级与 Green 函数方法——IP 化学精度（<0.043 eV）在 CCSDT 达到，伴线须 CCSDTQ（MAE 0.039 eV）才达化学精度，含三重激发方法用于伴线均需谨慎，G0W0/G0T0 类均无法描述伴线（伴线本质为两空穴一粒子的双激发型多体态）。

**参数表**：

| 参数 | 数值 | 出处 |
| --- | --- | --- |
| IP 精度梯度 | CC2 0.769 / CCSD 0.175 / CC3 0.070 / CCSDT 0.041 / CC4 0.015 / CCSDTQ 0.010 eV（MAE，aug-cc-pVTZ） | 主要发现与核心结论 |
| 伴线精度 | CCSDTQ 0.039 eV；CC4 0.093；CCSDT 0.537；CC3 0.787 eV | 主要发现与核心结论 |
| Green 函数方法 | G0W0 0.470 / qsGW 0.391 / G0F(2) 0.807 / G0T0 0.485 eV——均无法描述伴线 | 主要发现与核心结论 |

**适用边界**：仅垂直 IP 不含绝热对应量；过渡强度基准化明确排除留后续（与实验谱直接比较的关键缺口）；仅小分子体系（10–18 电子系列）；ADC 层级收敛性、cumulant Green 函数检验、三体 Green 函数为开放方向。
