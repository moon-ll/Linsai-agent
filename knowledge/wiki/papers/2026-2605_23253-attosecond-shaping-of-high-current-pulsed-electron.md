• # 阿秒整形高电流脉冲电子束：自建37 keV电子束线中的亚光周期束团产生

  ## 林赛的理解

  这篇工作把"自由电子阿秒整形"从电子显微镜的高空间分辨率场景推向了高电流应用。核心突破在于：他们用一块倾斜20°的硅氮薄膜把大角度聚焦电子束的电子-光延迟差压到1 fs以内，从而在~2 electrons/pulse的高通量下获得了1.3 fs（FWHM）/0.5 fs（RMS）量级的电子微脉冲串。这对我们的意义很直接——如果我们想在未来把阿秒电子衍射或强场驱动光子产生推向有统计意义的信号强度，就必须解决"通量 vs. 时间相干性"的张力。文中对膜片几何、空间电荷展宽、能量啁啾与束团对比度的处理，提供了可量化的工程边界；其2.6 mm漂移段、双膜调制方案以及37 keV（v_e = 0.36c）的非相对论能量选择，都是我们设计HHG/阿秒泵浦-探测或交变磁/莫尔结构超快电子实验时可以对照的基准。

  ## 研究问题

  论文要回答的核心问题是：能否在**高电流（>2 electrons/pulse、最高~3 electrons/pulse且无明显空间电荷效应）**的非相对论电子束上实现阿秒尺度的光学整形，并在有大能量展宽（空间电荷导致）的束流中仍能观测到亚光周期调制？具体目标包括：(1) 在扩展束径和聚焦角度下保持电子-光相互作用的时间均匀性（延迟散布<1 fs）；(2) 产生并表征持续时间为亚光周期的电子微脉冲串；(3) 验证即使初始能量展宽达15 eV（FWHM），仅2 eV量级的光调制是否仍能诱导可分辨的阿秒结构。

  ## 研究背景

  自由电子束的光学调制已在电子显微镜、介电激光加速器和量子光子发射等场景取得显著进展，典型应用包括：Priebe等和Kozák等在超快透射电镜中实现阿秒电子脉冲串，Black等和Schönenberger等在硅介电激光加速器中观测到净加速/减速与阿秒微束团，Nabben等将阿秒电子显微术用于亚光周期光学动力学成像。然而，这些工作大多依赖截断束流以获得高空间分辨率，牺牲了通量。对于均匀样品电子衍射、宏观靶光子产生等不需要原子级空间分辨率但要求探测统计量的应用，**保持高平均电流**至关重要。高电流带来的新挑战是：光束聚焦角导致电子-光延迟在束截面上不再均匀；空间电荷效应会引入数eV至十余eV的能量展宽，可能破坏时间压缩。此前，Morimoto与Baum提出的双膜 ponderomotive 调制方案为在扩展几何中产生阿秒脉冲提供了理论基础，但将其扩展到>1 electron/pulse并量化空间电荷容忍度仍是开放问题。

  ## 研究方法

  **材料与光源**：实验使用自建37-keV电子束线，电子由钨<310>针尖通过双光子发射产生，针尖尖端放电修整至数微米；经静电场加速至37 keV（电子速度v_e = 0.36c），再经磁偏转器和磁透镜引导至调制区。驱动激光为中心波长1033 nm、脉宽190 fs、重复频率200 kHz的飞秒激光器，输出被分束后分别用于产生光电子脉冲和阿秒整形。

  **双膜调制几何**：两片20-nm厚SiN_x薄膜（Norcada）垂直于电子束与激光束正交布置。第一片膜（foil-1）施加可调的光学能量调制；电子自由传播2.6 mm后到达第二片膜（foil-2），此处完成束团化并用于阿秒条纹表征。foil-2处激光焦点设置在膜后，光斑尺寸140 μm（x）×300 μm（y，1/e²全宽），峰值场强9×10⁷ V/m（对应1×10⁹ W/cm²），诱导1.8 eV能量调制。电子束在foil-2的聚焦光斑为12 μm（y）×16 μm（x，1/e²全宽），对应聚焦半角|α_xz| = 0.3 mrad、|α_yz| = 2.3 mrad。

  **延迟补偿**：为把电子-光延迟散布压到<1 fs，作者在x-z平面将foil-1倾斜θ_xz = 20°，该角度满足tanθ_xz = v_e/c，对37-keV电子可补偿因聚焦角α_xz引起的传播距离差异；y-z平面则调整foil-1使其垂直于束流以最小化飞行时间散布。

  **诊断装置**：自制90°磁棱镜电子能谱仪，偏转半径100 mm，用八极透镜将色散电子投射到微通道探测器。foil-2前放置可移动狭缝（0.125 mm×1 mm，~9%透过率）以限制x方向聚焦角、提高能量分辨率。对37-keV束测得能量分辨率3.2 eV（FWHM，2 s曝光），对5-keV束为1.2 eV（FWHM）。阿秒条纹扫描中，延迟Δt在~7.5 fs范围内以0.23 fs步长扫描，数据为5–10次扫描平均。

  **理论模型**：采用一维经典点粒子模拟，预设1.2 eV（FWHM）带宽；电子受周期性加速/减速后经2.6 mm自由传播到达foil-2，到达时间加入高斯抖动（RMS宽度为σ_t + 2ℏ/ΔE），σ_t为唯一自由参数。另用高斯脉冲叠加恒定背景的简化模型估计束团宽度。

  ## 主要发现与核心结论

  1. **亚光周期脉冲串的成功产生**：在2 electrons/pulse（无狭缝）的束流下，观测到清晰的阿秒条纹谱图。能量分布质心（CoM）随延迟呈正弦振荡，周期T = 3.44 fs；在Δt = T/4、5T/4处出现净加速，在Δt = 3T/4、7T/4处出现净减速，在Δt = T/2、3T/2处出现单色化增强（谱强度最大），在Δt = 0、T处出现能量展宽。290-fs包络内形成84个微脉冲，间隔为一个光周期3.44 fs。

  2. **角度相关延迟补偿验证**：在α_yz = −1.5±0.25 mrad与0±0.25 mrad两角度下，CoM振荡存在~0.2 fs的时间偏移；小|α_yz|时偏移接近零，|α_yz|>1 mrad时显著增大。作者指出单靠y-z平面飞行时间差异（~0.05 fs at 2 mrad）不足以解释该偏移，推测源于膜片曲率，可能被激光加热放大。

  3. **束团持续时间估计**：通过比较实验CoM振幅与点粒子模拟，最佳拟合需要引入σ_t = 0.4 fs的到达时间抖动；σ_t = 0.6 fs会完全低估实验振幅。模拟显示σ_t = 0 fs时束团FWHM为0.5 fs，σ_t = 0.4 fs时为1.3 fs。综合点粒子模型与高斯+背景简化模型，在1.8–1.9 eV调制幅度下得到最短束团持续时间为**1.3±0.2 fs（FWHM）**和**0.5±0.1 fs（RMS）**。

  4. **调制幅度依赖性**：foil-1场强降至5×10⁷ V/m（1.0 eV调制）时仍可看到类似但振幅略弱的图样；即使低至2×10⁷ V/m（0.3 eV调制）仍有可分辨的阿秒调制。CoM振幅随调制增强而增大，反映的是脉冲对比度相对恒定背景的增强，而非单纯缩短脉宽。

  5. **空间电荷展宽束流的亚光周期调制**：提高电流至~10–16 electrons/pulse后，空间电荷导致能量展宽分别为9 eV（FWHM）和15 eV（FWHM）。尽管能量展宽远大于光诱导调制能量，仍观测到清晰CoM振荡，振幅分别为0.27 eV（9 eV展宽）和0.09 eV（15 eV展宽）。点粒子模拟（σ_t = 0.4 fs，假设无能量-时间啁啾）显示，当展宽超过10 eV（FWHM）时峰结构几乎消失，而实验振幅对应于模拟中8 eV和5 eV展宽的结果。作者推测差异来自束流啁啾：尽管整体能量展宽大，但在光周期时间尺度上的瞬时能量散布较窄，因此光学整形仍有效。

  6. **能量展宽容忍度**：在15 eV（FWHM）初始展宽、~16 electrons/pulse条件下，仅需2 eV量级的调制幅度即可塑造出可观测的亚光周期结构，说明该方法对高电流下的空间电荷展宽具有出人意料的鲁棒性。

  ## 潜在研究方向

  1. **啁啾与空间电荷的定量解耦**：实验显示大能量展宽束的CoM振幅显著高于无啁啾模拟，表明能量-时间关联（啁啾）是关键变量，但论文未直接测量啁啾。未来需要发展能同时分辨能量、时间和角度的四维相空间诊断，以定量区分空间电荷、加速场不均匀性和初始发射度贡献。

  2. **膜片热学与机械稳定性**：激光加热导致的膜片曲率变化被推测为角度相关延迟的主要来源之一。高重复频率或更高功率下，热膨胀、振动和像差/像散对束团对比度的影响需要系统建模与主动抑制。

  3. **更高电流与更多电子/微脉冲**：当前每个微脉冲仍接近单电子水平（2 electrons/pulse分布在84个微脉冲中）。要真正实现"含一个或多个电子的阿秒脉冲"，需要更长的光学周期（中红外或远红外驱动）或预聚束器/THz单色器，以在更大调制幅度下保持亚光周期压缩。

  4. **谱仪分辨率限制**：3.2 eV（FWHM）的谱仪分辨率不足以分辨光子阶边带，因此作者采用模型拟合间接推断脉宽。若能在不显著牺牲通量的前提下提升能量分辨率，将允许直接重构时间结构，降低模型依赖。

  5. **倾斜膜角度优化推广到其它能量**：θ_xz = 20°对应37-keV电子的v_e/c。若将该方案用于5 keV、100 keV或相对论能量，需要重新设计膜片倾斜角并考虑像差、相对论时间膨胀和同步辐射损失。

  6. **从束团化到应用**：下一步需将产生的阿秒电子脉冲串用于实际泵浦-探测（如超快电子衍射、原子尺度电荷运动成像、受控光子产生），并验证其对低对称材料、莫尔超晶格或交变磁结构动态响应的信噪比提升。

  ## 与林赛研究的关联

  - **HHG与强场驱动**：该双膜ponderomotive调制本质上是强场光学对自由电子波函数的相干操控，与我们在固体/纳米结构HHG中关心的电子非绝热动力学有共同的方法论基础。其37 keV、非相对论参数可作为设计强激光场驱动电子源（用于相干辐射或粒子加速器）的参考。
  - **阿秒泵浦-探测**：1.3 fs/0.5 RMS的电子微脉冲串可用于阿秒时间分辨电子衍射或成像。若结合我们关注的量子几何响应（如贝利曲率诱导的圆二色性、莫尔平带的超快退相干），高电流阿秒电子束能显著提升统计量。
  - **交变磁与莫尔**：交变磁序和莫尔超晶格的动态探测通常需要低剂量、高时间分辨的电子衍射；本工作展示的>2 electrons/pulse、可扩展至16 electrons/pulse的束流，为这类低对称体系的时间分辨结构因子测量提供了可能的技术路线。
  - **量子几何与自由电子-光耦合**：文中对扩展束径下电子-光相互作用相位一致性的处理，可直接映射到未来用结构化光场对自由电子进行横向/纵向量子态工程的研究，包括光子产生、自由电子量子光学和介电激光加速。

# Attosecond shaping of high-current pulsed electron beams in a home-built 37-keV beamline

**arXiv**: [2605.23253](https://arxiv.org/abs/2605.23253) | **方向**: 阿秒科学 / 强场超快光场

---

## 研究问题（Research Question）

Gap: 此前阿秒电子脉冲的演示(如 BaWa++ 等)都是亚相对论 30 keV 以下的紧凑型装置,受限于空间电荷效应(space-charge broadening)和电子-光延迟展宽两大瓶颈,要在 sample 端同时实现 >1 electron/pulse + sub-femtosecond 时间分辨率 + 高调制深度,一直是未解的难题。Contributions: 在 RIKEN 自建 37 keV 电子束线上(v_e = 0.36c,200 kHz femtosecond 激光器驱动钨 tip 两光子发射),用两片 20 nm 厚 Si-nitride membrane 间隔 2.6 mm 形成 sub-cycle 调制 + 自由空间传播脉冲压缩路径;通过优化膜的倾角(20° 满足 tanθ = v_e/c 关系)压缩电子-光延迟展宽到飞秒级;测得 1.3 fs (FWHM) / 0.5 fs (RMS) 的微波脉冲列,84 个 micropulse 串间距 3.44 fs(一个 1033 nm 光周期);在 2 electrons/pulse 低空间电荷条件下完成完整测量,首次证明可在 16 electrons/pulse + 15 eV 能量展宽的强空间电荷条件下仍观测到 2 eV 调制下的 sub-cycle 特征——这是迈向每个 micropulse 多个电子 + 阿秒时间分辨率的关键一步。

## 研究背景（Background）

直接命中林赛 PHz 电子学主线 + 强场超快光场 + 阿秒电子源三大领域。本装置的核心创新是让 sub-cycle 调制 + 自由空间压缩 在 37 keV / 2 electrons/pulse 这种高能量 + 高流强条件下工作——相比传统阿秒电子源(如 Baum, Morimoto 等的 30-200 keV 装置)流强提升了一个量级。

具体接口:

1) PHz 流强瓶颈:林赛 PHz 电子学方向目标的 每个样品脉冲 >2 个电子 + 可忽略空间电荷 + 亚飞秒时间分辨率 正是本文的核心实验条件。装置的设计要点(两段膜 + 自由空间压缩 + 20° 几何补偿)可直接迁移到林赛可能的 PHz 注入器设计。

2) 与 2606.31573 (Mizuno 交变磁体自旋电流 HHG) 的接口:2606.31573 探测的是 sub-cycle 自旋电流,需要 sub-cycle 时间分辨率的电子探针——本文的 1.3 fs FWHM 微波脉冲列正是这类探测的潜在载体。如果林赛想做探测 ZnO 中 sub-cycle 自旋极化,这种结构可作为探针侧的设计起点。

3) 与 2605.03794 (Picard-Lefschetz) 的接口:本文涉及到的自由空间传播相位空间混合本质上是一种鞍点求积——高能追赶低能形成垂直条纹(= caustic 几何),与 PL 框架中 thimble 沿 phase gradient 形变 一致。林赛未来若在 PHz 电子态量子控制中遇到 caustics/saddle-point 收敛问题,PL 框架可作为诊断工具。

4) 中红外长度选择:1033 nm 光周期 3.44 fs 接近本装置测得 1.3 fs 脉冲宽度的 3 倍——可用但不是最佳。林赛若用 mid-IR 拉长周期到 10-20 μm,每 micropulse 多电子 + 阿秒时间结构 这一目标才更容易达成,与林赛中红外供应链(断链风险已下降)一致。

5) 实际局限:实验条件是 sample 端 2 electrons/pulse,要达到 1 electron per sample pulse 的 PHz 探测器应用门槛已跨过;要达到 >10 electrons/pulse 仍需空间电荷抑制 + 预啁啾处理。

## 研究方法（Methods）

- 两片 Si-nitride membrane 的 调制 + 压缩 路径:膜-1 用 1.8 eV 周期能量调制产生 sub-cycle 微脉冲列,自由空间 2.6 mm 传播 = 时间透镜把不同能量的电子在空间上重新对齐形成 1.3 fs 微波脉冲,膜-2 提供时间结构的阿秒电子微分析。
- 电子-光延迟的几何补偿:x-z 平面放置膜的倾角 tanθ = v_e/c,使不同入射角的电子都看到相同的横向位移 + 相同的有效 interaction volume;y-z 平面则让膜-1 垂直于束斑消除飞行时间差异。整个设计使得阿秒分辨率独立于束斑聚焦位置。
- 高能量 37 keV 装置 + 200 kHz 重复频率 + 紧凑磁棱镜 (100 mm radius, 90° deflection) + 八极静电透镜 + MCP 检测器组合:给出 3.2 eV FWHM 能量分辨率 + 0.23 fs 延迟步长 + 2 s 曝光 + 5-10 次扫描平均的高灵敏度测量。
- Point-particle 1D 模拟 + σ_t 抖动参数化:把每种实验效应(光束像差、振动、热膨胀、能量抖动)作为 σ_t 整合,给出 0.4 fs 时与实验一致,0.6 fs 时严重低估——σ_t 比脉冲本身还长说明灵敏度刚好够抓住 1.3 fs FWHM。
- CoM 振荡振幅作为微脉冲含量度量:直接不对时间结构做反卷积(受能谱分辨率限制),用 CoM 振荡振幅作为 bump 强度的代理,振幅 → 1.3 fs 脉冲宽度通过 calibrated 模拟反推。

## 主要发现与核心结论（Main Results）

- 37 keV 装置 + 200 kHz 重复频率的双光子发射光电 tip(290 fs 电子脉冲 + 190 fs 激光脉冲)实现 2 electrons/pulse 稳定通过,无空间电荷展宽(<4 eV FWHM,能谱分辨率 3.2 eV FWHM @ 37 keV)。
- 拍赫兹电子调制 + 传播压缩路径:Si-nitride membrane-1 引入周期性能量调制(1.8 eV 调制),自由空间 2.6 mm 传播让高能电子追上低能电子形成微波脉冲列,membrane-2 验证子周期时间结构。2 段膜的电子透射率各 40%,总体 17%(实际可放在样品后方不损失)。
- 膜倾角优化:x-z 平面 tan(θ_xz) = v_e/c = 0.36 给出 20° 倾角,把不同束斑角度(α_xz = 0.1-0.3 mrad)的电子-光延迟差压缩到 <1 fs,从而支持阿秒分辨率。光束焦点设在膜后方 140 μm(x) × 300 μm(y) 避免 Gouy phase 污染。
- sub-cycle 特征:CoM 振荡显示 Δt = T/4, 5T/4 净加速、3T/4, 7T/4 净减速,T/2, 3T/2 单色化增强、0, T 增宽完整四相位子周期指纹。机制是相位空间动力学:在膜-1→膜-2 自由空间传播中高能追赶低能形成 vertical stripe 微波脉冲,膜-2 的能量调制与其 arrival time 匹配的相位差决定 ±sigma 加速/减速/单色化/增宽。
- 脉冲宽度估计(双模型交叉验证):point-particle 模型 + 1D 模拟(σ_t = 0.4 fs 抖动)给 1.3 fs FWHM + 0.5 fs RMS,与简单 Gaussian 模型吻合。σ_t = 0 fs 极限对应 0.5 fs RMS 微波脉冲。
- 核心突破:空间电荷效应下的 sub-cycle 调制:16 electrons/pulse + 15 eV FWHM 能量展宽 + 仅有 2 eV 调制幅时,仍观察到 CoM 振荡(0.09 eV 振幅),模拟要求瞬时能量展宽远小于 15 eV —— 意味着能量-时间啁啾(chirp)使得一个光周期之内的瞬时展宽足够窄,支持光学整形。
- 电流上限:无 slit 时直到 ~3 electrons/pulse 都没有显著能量展宽(Fig.1e)。最终系统演示 2 electrons/pulse 完整测量 + 16 electrons/pulse sub-cycle 特征。
- 未来工作:使用 mid-IR / far-IR 延长光周期 + 预啁啾 / 能量过滤器 / THz 单色化器(STEAM, ref 45-47)有望实现每个 micropulse 多个电子的阿秒脉冲。
- 100 mm radius 磁棱镜 90° 偏转 + 八极静电透镜 + MCP 检测器组合下,能量分辨率 3.2 eV FWHM @ 37 keV。

## 潜在研究方向（Future Directions）

- 用 mid-IR (e.g., 10-30 μm) 替代 1033 nm 拉长光周期,让 84 micropulses 在 290 fs 包络内进一步分立 / 减少邻近脉冲重叠,扩展至每 micropulse >1 electron。
- 通过预啁啾 (pre-buncher) 或 THz 能量过滤器(STEAM / ref 45-47)压缩 16 electrons/pulse 时的 15 eV 能量展宽到 sub-eV 级别,使光学整形更高效。
- 把系统耦合到商业 TEM / STEM + 把 slit 放在样品后方而非前方,最大通量至样品端。
- 贝叶斯反演 + 蒙特卡洛:在保持 sub-cycle 特征的同时,定量估计时间结构(直接重建)——目前的能谱分辨率(3.2 eV)看不到光子阶边带,必须靠模型+模拟;提升分辨率至 sub-eV 是路径。
- 把同样的膜结构用于 heavy-element 阴极(高 Z 降低空间电荷灵敏度)或加上更好的激光磁场(tens of MV/m)扩展到更深调制深度。
- 演示阿秒 microdiffraction / 四维成像:在样品后用同样的阿秒微脉冲列探针直接读出 atomic-scale dynamics(与 Yakovlev 2015, Yuan-Golubev 2025 路线一致)。
- 与其他 PHz 电子源方案(如 dielectric laser accelerator 黑硅加速 + 高次谐波调制)对照,建立统一的 multi-electron + attosecond 设计标准。



## 深度解析

### 研究问题（Research Question）

Gap: 此前阿秒电子脉冲的演示(如 BaWa++ 等)都是亚相对论 30 keV 以下的紧凑型装置,受限于空间电荷效应(space-charge broadening)和电子-光延迟展宽两大瓶颈,要在 sample 端同时实现 >1 electron/pulse + sub-femtosecond 时间分辨率 + 高调制深度,一直是未解的难题。Contributions: 在 RIKEN 自建 37 keV 电子束线上(v_e = 0.36c,200 kHz femtosecond 激光器驱动钨 tip 两光子发射),用两片 20 nm 厚 Si-nitride membrane 间隔 2.6 mm 形成 sub-cycle 调制 + 自由空间传播脉冲压缩路径;通过优化膜的倾角(20° 满足 tanθ = v_e/c 关系)压缩电子-光延迟展宽到飞秒级;测得 1.3 fs (FWHM) / 0.5 fs (RMS) 的微波脉冲列,84 个 micropulse 串间距 3.44 fs(一个 1033 nm 光周期);在 2 electrons/pulse 低空间电荷条件下完成完整测量,首次证明可在 16 electrons/pulse + 15 eV 能量展宽的强空间电荷条件下仍观测到 2 eV 调制下的 sub-cycle 特征——这是迈向每个 micropulse 多个电子 + 阿秒时间分辨率的关键一步。

### 研究背景（Background）

直接命中林赛 PHz 电子学主线 + 强场超快光场 + 阿秒电子源三大领域。本装置的核心创新是让 sub-cycle 调制 + 自由空间压缩 在 37 keV / 2 electrons/pulse 这种高能量 + 高流强条件下工作——相比传统阿秒电子源(如 Baum, Morimoto 等的 30-200 keV 装置)流强提升了一个量级。

具体接口:

1) PHz 流强瓶颈:林赛 PHz 电子学方向目标的 每个样品脉冲 >2 个电子 + 可忽略空间电荷 + 亚飞秒时间分辨率 正是本文的核心实验条件。装置的设计要点(两段膜 + 自由空间压缩 + 20° 几何补偿)可直接迁移到林赛可能的 PHz 注入器设计。

2) 与 2606.31573 (Mizuno 交变磁体自旋电流 HHG) 的接口:2606.31573 探测的是 sub-cycle 自旋电流,需要 sub-cycle 时间分辨率的电子探针——本文的 1.3 fs FWHM 微波脉冲列正是这类探测的潜在载体。如果林赛想做探测 ZnO 中 sub-cycle 自旋极化,这种结构可作为探针侧的设计起点。

3) 与 2605.03794 (Picard-Lefschetz) 的接口:本文涉及到的自由空间传播相位空间混合本质上是一种鞍点求积——高能追赶低能形成垂直条纹(= caustic 几何),与 PL 框架中 thimble 沿 phase gradient 形变 一致。林赛未来若在 PHz 电子态量子控制中遇到 caustics/saddle-point 收敛问题,PL 框架可作为诊断工具。

4) 中红外长度选择:1033 nm 光周期 3.44 fs 接近本装置测得 1.3 fs 脉冲宽度的 3 倍——可用但不是最佳。林赛若用 mid-IR 拉长周期到 10-20 μm,每 micropulse 多电子 + 阿秒时间结构 这一目标才更容易达成,与林赛中红外供应链(断链风险已下降)一致。

5) 实际局限:实验条件是 sample 端 2 electrons/pulse,要达到 1 electron per sample pulse 的 PHz 探测器应用门槛已跨过;要达到 >10 electrons/pulse 仍需空间电荷抑制 + 预啁啾处理。

### 研究方法（Methods）

- 两片 Si-nitride membrane 的 调制 + 压缩 路径:膜-1 用 1.8 eV 周期能量调制产生 sub-cycle 微脉冲列,自由空间 2.6 mm 传播 = 时间透镜把不同能量的电子在空间上重新对齐形成 1.3 fs 微波脉冲,膜-2 提供时间结构的阿秒电子微分析。
- 电子-光延迟的几何补偿:x-z 平面放置膜的倾角 tanθ = v_e/c,使不同入射角的电子都看到相同的横向位移 + 相同的有效 interaction volume;y-z 平面则让膜-1 垂直于束斑消除飞行时间差异。整个设计使得阿秒分辨率独立于束斑聚焦位置。
- 高能量 37 keV 装置 + 200 kHz 重复频率 + 紧凑磁棱镜 (100 mm radius, 90° deflection) + 八极静电透镜 + MCP 检测器组合:给出 3.2 eV FWHM 能量分辨率 + 0.23 fs 延迟步长 + 2 s 曝光 + 5-10 次扫描平均的高灵敏度测量。
- Point-particle 1D 模拟 + σ_t 抖动参数化:把每种实验效应(光束像差、振动、热膨胀、能量抖动)作为 σ_t 整合,给出 0.4 fs 时与实验一致,0.6 fs 时严重低估——σ_t 比脉冲本身还长说明灵敏度刚好够抓住 1.3 fs FWHM。
- CoM 振荡振幅作为微脉冲含量度量:直接不对时间结构做反卷积(受能谱分辨率限制),用 CoM 振荡振幅作为 bump 强度的代理,振幅 → 1.3 fs 脉冲宽度通过 calibrated 模拟反推。

**方法**：双 SiN 膜 ponderomotive 调制 + 自由传播压缩的高电流阿秒电子束团化

**原理**：foil-1 施加周期性能量调制，电子自由传播 2.6 mm 起时间透镜作用（高能追上低能形成亚光周期微脉冲串），foil-2 完成束团化并用于阿秒条纹表征；x-z 平面 foil-1 倾角取 tanθ_xz = v_e/c（37 keV 对应 20°）补偿聚焦角导致的电子-光延迟散布至 <1 fs；束团宽度用一维点粒子模拟 + 到达时间抖动 σ_t 标定，能量分布质心（CoM）振荡振幅作束团含量代理。

**参数表**：

| 参数 | 数值 | 出处 |
| --- | --- | --- |
| 电子束线 | 自建 37 keV（v_e = 0.36c）；钨 <310> 针尖双光子发射；重复频率 200 kHz | 研究方法 |
| 驱动激光 | 1033 nm、190 fs、200 kHz | 研究方法 |

| 能量调制 | foil-2 峰值场 9×10⁷ V/m（1.8 eV 调制）；最低 2×10⁷ V/m（0.3 eV）仍可分辨阿秒调制 | 研究方法 / 主要发现 |
