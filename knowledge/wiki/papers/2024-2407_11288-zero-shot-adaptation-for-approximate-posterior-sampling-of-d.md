• # Zero-Shot Adaptation for Approximate Posterior Sampling of Diffusion Models in Inverse Problems（ZAPS）

  ## 林赛的理解

  这是一篇图像逆问题（inverse problem）领域的机器学习论文，核心贡献是**用零样本（zero-shot）测试时训练自动学习扩散模型后验采样中的对数似然权重 {ζt}**，从而首次让"非规则噪声调度"（irregular noise schedule）在逆问题求解中变得可用。对我们的直接课题（HHG、阿秒、交变磁、莫尔）而言，这篇工作没有实验或物理内容，关联是**方法论层面的类比**：

  - 它解决的是"物理正向模型 + 数据先验"耦合反演中的**超参数手工调参痛点**。这与我们在强场超快数据分析中反复遇到的问题同构：阿秒条纹谱、光电子谱反演、HHG 光谱相位恢复都是典型的病态逆问题，我们目前依赖物理先验 + 手工正则化权重，权重调不好结果就发散或出伪影——ZAPS 给出的答案是"把权重变成可学习参数，用测量一致性损失在推理时自监督地微调"。
  - 它处理"观测 Fisher 信息矩阵（对数先验 Hessian）难以计算"的方式——**用正交离散小波变换近似对角化、只学习对角元**——是一个非常便宜的工程近似，值得记住这个思路：在无法精确计算二阶导算符时，找一个固定正交基做近似 Karhunen-Loève 对角化。
  - 作为跨领域方法素材入库：它证明了"固定少量采样步数 + 算法展开（algorithm unrolling）+ 物理一致性损失"这一组合可以把推理代价降一个量级。如果组内未来做谱反演或条纹谱重建的深度先验方法，这条路线可参考。

  ## 研究问题

  扩散模型作为生成先验求解含噪线性逆问题 y = Ax₀ + n 时，后验采样需要在每一步反向扩散中计算前向模型的对数似然项 ∇ₓₜ log p(y|xₜ)（式 1）。论文要回答的核心问题是：

  1. 现有方法（DPS、ΠGDM 等）对似然项引入逐步权重 {ζt}（式 4），但这些权重靠经验手工调节（empirical tuning），对不同的测量噪声水平 σy 和不同的前向算子 A 泛化性差；
  2. 图像生成领域已证明**非规则噪声调度**（在低噪声水平处密集采样，irregular jumps，如 Karras 等人的调度）能显著加速收敛并提升生成质量，但在逆问题中因"每个非规则时间步需要各自独立的 ζt、无法手工调"而无法应用；
  3. 能否在**不重新训练无条件扩散模型、不反向传播穿过 score 网络**的前提下，在推理阶段零样本地自动学习每个时间步的似然权重，使任意（含非规则）噪声调度下的后验采样既快又稳？

  论文目标：固定采样步数 S（~20–30），用零样本训练在少量 epoch 内学到各时间步的 ζt 和对角化近似矩阵，将采样步数从 1000 降至 ~20–30，同时达到或超过 SOTA 重建质量。

  ## 研究背景

  - **扩散模型反演脉络**：DDPM/Score-SDE 用预训练无条件扩散模型作 plug-and-play 先验，把前向物理模型嵌入反向采样。似然项的近似路线包括：投影到测量子空间（Score-SDE [5,8,35]、MCG [7]，但有边界伪影）；变分采样（RED-diff [26]）；球面高斯约束（DSG [44]）；谱域 SVD 方法（DDRM [21]，计算昂贵）；后验均值近似（DPS [6]，p(y|xₜ) ≈ p(y|x̂₀)，式 9/13/14）；高斯近似（ΠGDM [32]，式 3/15–17）。
  - **加速需求**：多数逆问题扩散方法沿用训练时的 1000 步采样，重建时间长。ΠGDM 用规则（线性跳跃）短调度加速，但更复杂的非规则调度在逆问题中无人使用，唯一障碍是 ζt 的经验调节不可行（每个非规则时间步一个权重）。
  - **零样本/测试时自监督脉络**：借鉴 test-time training [36,43] 与 physics-driven deep learning（作者组此前在 MRI 重建的工作 [15,22]）——这是本方法的直接思想来源：Akçakaya 组在压缩感知 MRI 中将算法展开与物理驱动深度学习结合的积累。
  - 作者的洞见：式 17 显示 DPS 与 ΠGDM 只差一个 (AᵀA + ηI)⁻¹ 项，两者更新相似，因此权重学习策略可迁移到任意后验采样扩散模型，不绑定 DPS。

  ## 研究方法

  方法密度：中等偏高（核心是方法创新，算法与超参数给得完整）。按方法卡格式整理。

  ### 方法卡：ZAPS（Zero-shot Approximate Posterior Sampling）

  **1. 原理**

  把后验采样的反向过程按算法展开（algorithm unrolling）固定为 S 步网络，交替执行 score model sampling（SMS，DDPM 无条件更新）与 likelihood guidance（LG，式 20 的似然项加权更新）。唯一可学习参数是各时间步的似然权重 {ζt} 与小波对角矩阵 {Dt}，用测量一致性损失 L(y, x₀) = ‖y − Ax₀‖₂² 在推理时对当前输入图像零样本微调若干 epoch，不触碰预训练 score 网络。对数先验 Hessian（观测 Fisher 信息矩阵，负值，见式 21）用固定正交 DWT 近似对角化（式 22），避免存储和反传穿过 score 网络的计算图。

  **2. 参数表（数值原样，出处为原文正文/Algorithm 1/§4.1）**

  | 类别 | 参数 | 取值 |
  |------|------|------|
  | 数据 | 数据集 | FFHQ、ImageNet，256 × 256 × 3，各采样 1000 张验证图像，归一化到 [0, 1] |
  | 模型 | 预训练扩散模型 | FFHQ 模型取自 [5]，ImageNet 模型取自 [11]，均不重新训练 |
  | 噪声 | 测量噪声 | 高斯噪声 σ = 0.05（所有评估统一） |
  | 小波 | 正交 DWT | Daubechies 4（db4）小波 |
  | 默认配置 | 采样步数 / 调度 | 30 步，调度 "15,10,5"（低噪声段密集） |
  | 默认配置 | 微调 epoch 数 | 10 epochs，总 NFE = 300 |
  | 消融配置 1 | 步数-epoch 组合 | S ∈ {20, 30, 60}，固定 NFE = 300，对应 {15, 10, 5} epochs |
  | 消融配置 2 | NFE 预算 | 100 NFE = 20 步 × 5 epoch（调度 "10,7,3"）；300 NFE = 30 步 × 10 epoch（"15,10,5"）；500 NFE = 50 步 × 10 epoch（"30,15,5"） |
  | 算子 | 高斯模糊核 | 61 × 61，标准差 σ = 3.0 |
  | 算子 | 修复（inpainting） | 随机遮罩 70%；或 128 × 128 方形区域，三通道统一 |
  | 算子 | 运动模糊 | 61 × 61 核、强度 0.5（代码库 LeviBorodenko/motionblur，同 [6]） |
  | 算子 | 超分辨 | bicubic 下采样（×4） |
  | 损失 | 微调目标 | L(y, x₀) = ‖y − Ax₀‖₂²（测量一致性，physics-guided loss） |
  | 指标 | 定量评估 | LPIPS↓、SSIM↑、PSNR↑ |
  | 计算代价 | NFE / 墙钟时间（Tab. 3） | DPS 1000 NFE / 47.25 s；MCG 1000 / 48.83 s；ΠGDM 100 / 4.53 s；DDRM 20 / 2.12 s；Score-SDE 1000 / 23.47 s；ZAPS 300 / 14.71 s |

  **3. 适用边界**

  - 权重与对角矩阵是**图像特异**的，每张测试图在推理时都要微调一次，故收益以"单次重建"为单位衡量，不摊销到数据分布上；
  - 零样本微调需固定噪声水平 σ 与算子 A，测量系统或噪声水平改变时需重新微调，且高 S 低 epoch 组合（如 60 步 × 5 epoch）对超参初始化更敏感、收敛更难；
  - 小波未必能完全去相关观测 Fisher 信息矩阵（作者自陈式 22 的近似局限）；
  - DPS 基线支持非线性算子，ΠGDM 不要求算子可微（只需伪逆式操作），ZAPS 的策略原则上可迁移，但本文实验仅在线性逆问题上验证；
  - 损失形似 DIP（deep image prior），作者指出其对应 p(y|x₀) 的似然而非逐步的 p(y|xₜ)，配合少量 epoch 可避免过拟合；更严格的防过拟合（data-splitting）未实施。

  **4. 代表作**

  - Chung et al., "Diffusion Posterior Sampling for General Noisy Inverse Problems"（DPS, ICLR 2023）——本文基线，ZAPS 的似然更新直接采用其式 18；
  - Song et al., "Pseudoinverse-Guided Diffusion Models for Inverse Problems"（ΠGDM, ICLR 2022）——不规则调度加速的先驱，其 Woodbury 简化式（本文式 17）揭示了与 DPS 的等价结构。

  ## 主要发现与核心结论

  在 FFHQ（含 ImageNet 验证）四类含噪线性逆问题上，ZAPS 的定量结果（Tab. 1/2，σ = 0.05，默认 30 步 "15,10,5" × 10 epoch = 300 NFE）：

  - **高斯模糊**：ZAPS LPIPS 0.121 / SSIM 0.757 / PSNR 26.06 dB，全面优于 DPS（0.128 / 0.718 / 25.20）、DDRM（0.183 / 0.702 / 24.42）、MCG（0.558 / 0.509 / 15.12）、Score-SDE（0.571 / 0.496 / 15.17）；ΠGDM 在模糊类任务上无法可靠实现，故缺项。
  - **随机修复（70%）**：ZAPS LPIPS 0.078 / SSIM 0.813 / PSNR 27.79 dB，优于 DPS（0.104 / 0.811 / 28.03，PSNR 略低但 LPIPS 明显更好）、ΠGDM（0.086 / 0.842 / 26.62）、DDRM、MCG、Score-SDE。
  - **运动模糊**：ZAPS 0.141 / 0.709 / 24.16，略优于 DPS（0.143 / 0.704 / 24.03）；其余方法显著更差。
  - **超分辨 ×4**：ZAPS 0.104 / 0.768 / 26.63 dB，明显优于 ΠGDM（0.131 / 0.760 / 24.48）、DDRM（0.175 / 0.711 / 24.55）、DPS（0.168 / 0.719 / 23.86）。
  - **计算代价（Tab. 3）**：ZAPS 总 NFE = 300、墙钟 14.71 s，对比 DPS 1000 NFE / 47.25 s——采样步数减少 ~33×，考虑微调 epoch 后整体加速约 3×；DDRM（20 NFE / 2.12 s）与 ΠGDM（100 NFE / 4.53 s）更快但定量指标均低于 ZAPS。
  - **消融（固定 NFE = 300，Fig. 5）**：S ∈ {20, 30, 60}（15/10/5 epochs）三组合重建质量相近，S 增大锐度略升但 epoch 数少、对初始化更敏感；最终选 S = 30 + 10 epochs。等 NFE 对比（Tab. 4/5）显示 ZAPS 非规则调度在 NFE = 100/300/500 下均优于 DPS 与 ΠGDM（如超分辨 NFE=500：ZAPS 非规则 0.095 LPIPS / 26.26 dB vs ΠGDM 0.123 / 24.25 dB；修复 NFE=500：ZAPS 0.071 / 28.11 dB vs ΠGDM 0.082 / 24.94 dB）；低预算（100 NFE）时非规则与均匀调度差别不大，300/500 NFE 时非规则调度优势显现。
  - **结论**：学习得到的似然权重使非规则噪声调度首次在扩散逆问题中可行，以 20–50× 更少的采样步数达到 SOTA 重建质量（作者自称 first attempt），相比 DPS 类方法整体加速约 3×，且权重自动适应图像与测量，免手工调参。

  ## 潜在研究方向

  - **非线性算子与更一般前向模型**：本文验证限于线性逆问题；DPS 基线本身支持非线性算子，ZAPS 在非线性场景（如相位恢复）的行为未验证。
  - **小波对角化近似的改进**：作者承认小波不能完备去相关 Fisher 信息矩阵；可学习正交变换或可学习小波基是自然的后续方向。
  - **过拟合防线**：微调损失形似 DIP，虽少量 epoch 下未出问题，但严格的 data-splitting 自监督策略 [3,23,27,42,43] 尚未纳入。
  - **超参数自适应**：epoch 数、步数-调度组合目前仍需预算内人工选择；探索不同测量噪声水平下自动选择 NFE 预算的策略可提升通用性。
  - **调度搜索成本**：更优的非规则调度存在但需要大量计算试错 [11]，自动调度选择是开放问题。

  ## 与林赛研究的关联

  - **逆问题反演的超参自动化**：HHG 光谱相位重建、阿秒条纹谱（attosecond streaking）谱图反演、光电子能谱退卷积都是病态逆问题，目前组内方案普遍含手工正则化权重与收敛判据。ZAPS 的"把逐步权重参数化 + 测量一致性损失 + 推理时零样本微调"范式可直接类比移植——尤其是权重随演化步自适应、免逐任务手调这一点，对我们写课题方案中"反演算法稳健性"一节有参照价值。
  - **可借鉴的廉价二阶近似**：式 22 用小波基近似对角化对数先验 Hessian 的技巧，可迁移到任何需要 Hessian/Fisher 信息但无法显式计算的迭代反演中；比完整自动微分反传便宜得多。
  - **算法展开 + 物理损失**是 physics-driven deep learning 的标准范式（作者组源于 MRI 重建），与我们强场驱动模拟中"物理模型嵌入网络"的思路同源，可作为方法学写作素材。
  - **距离警示**：本文是纯图像 ML 方法，无强场物理、无光谱学语境；其价值限于方法论类比与反演算法素材，不应在课题中作为物理依据引用。引用时严格限于"扩散模型/零样本微调求解逆问题"的算法学论断，数值不得脱离其图像任务语境升格。
