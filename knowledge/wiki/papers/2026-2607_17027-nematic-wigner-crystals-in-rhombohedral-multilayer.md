# Nematic Wigner crystals in rhombohedral multilayer graphene（arXiv:2607.17027）

## 林赛的理解

这是一篇纯理论平均场工作，但对我这个做强场超快的人来说信息量不小。菱方四层石墨烯加位移场，本质上是把载流子压进一个 Berry 曲率富集、谷自由度可寻址的平坦能带里，电子结晶成 Wigner 晶体之后还自发破缺 C3 对称性，形成向列相。这给了我两个直觉上的兴奋点：**其一，向列序意味着物理响应是各向异性的**，作者自己提出用方向依赖的 depinning 电压来探测，那么换成我的语言，这就是一个用角度分辨的强场太赫兹非线性输运/高次谐波去读出隐藏电子序的天然靶材；**其二，作者用的是 TDHF，但只做了线性局域稳定性分析**，也就是说，在强驱动、非微扰、含时大振幅扰动下这些 Wigner 晶体会怎么响应（滑移、动力学熔化、光致稳定、甚至时间晶体式的振荡），完全是空白，这正是我们组的方法栈能切入的地方。另外这篇已挂进 general-quantum-geometry-inversion 那个 proposal，菱方多层体系的层间量子几何与关联态的耦合值得顺着往下挖。谷极化加零 Chern 数的组合也提示圆二色/圆偏振泵浦可以做时间分辨的谷序探测。

## 核心要点

1. **体系与方法**：菱方四层石墨烯（rhombohedral tetralayer graphene），采用投影 Hartree-Fock（HF）找基态、含时 Hartree-Fock（TDHF）检验局域稳定性；初始构造为每个 Wigner 元胞一个电子。
2. **两类 Wigner 晶体**：
   - 向列相 Wigner 晶体（nWC）：自发破缺三重旋转对称性 C3；
   - C3 不变的 Wigner 晶体。
3. **相图结构**：nWC 出现在两个区域，大位移场 + 低电子密度的大区域，以及中等位移场 + 高密度的较小区域；位移场与密度是两个可调旋钮。
4. **拓扑与输运性质**：nWC 与 C3 不变 WC 均为**谷极化、零 Chern 数**态，HF 能带具有正的间接带隙（绝缘性）。
5. **TDHF 稳定性判据**：所有 C3 不变 WC 局域稳定；约一半 nWC 稳定；其余 nWC 不稳定，会流向每元胞两电子的 WC 或金属态。这是"HF 解 ≠ 真实亚稳态"的一个清醒示例。
6. **实验判据（作者提出）**：STM 下各向异性的实空间电荷分布；角度分辨输运中的方向依赖 depinning 电压。

### 方法亮点
- 投影 HF 限域在窄带子空间，直接在（位移场, 密度）二维参数空间扫描出竞争序的相图。
- 用 TDHF 做线性稳定性检验来筛掉 HF 的伪解——这种"静态解 + 动力学验证"的两步法，对我们处理强场下的平均场动力学（类似我们在含时布洛赫/含时密度响应中区分真实动力学与数值伪影）有直接的方法论参考价值。

## 实验/研究关联

- **与本组方向的接口**：
  - nWC 的各向异性 depinning 阈值 → 角度分辨强太赫兹驱动下的滑移动力学、非线性电导、乃至来自电荷序晶格的非线性辐射/高次谐波；向列序取向可作为可调的对称性破缺旋钮。
  - 谷极化 + 零 Chern 数 → 圆偏振泵浦的圆二色响应可作时间分辨谷序探针，与我们在能谷选择激发上的经验直接对接。
  - 超快熔化/重构：泵浦诱导的 WC 熔化与再结晶时序、电子-晶格序的恢复时间，是扫描探针和直流输运给不了的观测量。
  - TDHF 只到线性稳定性 → 强场驱动下的非线性动力学（光致 WC 稳定化、周期性驱动下的动力学有序）是公开空白，可作为 proposal 的理论延展点。
  - 与 general-quantum-geometry-inversion-20260726 的关联：菱方多层石墨烯的层间耦合带来强量子几何效应，Wigner 结晶发生在这种"几何修饰"的能带中，关联与几何的纠缠是我们关心的核心问题。
- **与领域实验的接口**：近期菱方石墨烯中已有 Wigner 晶体的实验证据报道；本文给出的 STM 各向异性电荷分布与方向依赖 depinning 是对实验家的明确可证伪预言。

## 开放问题

1. HF/TDHF 均为平均场层级：屏蔽、声子、温度、无序（钉扎势景貌）全部缺失；HF 间接带隙的数值在超越平均场后还能剩多少？
2. "一半 nWC 不稳定"暗示相图边界对动力学扰动敏感——真实的 nematic 区域边界在哪里？需要更大规模的精确对角化/DMFT 类交叉验证。
3. 零 Chern 数 + 谷极化的判定在有限尺寸/有限温度下是否被涨落改变（谷序 vs Chern 序的竞争，正是菱方石墨烯实验中争论的焦点）？
4. 强场极限完全未触及：周期驱动下的 WC 会滑移、熔化还是被光稳定？depinning 的本征时间尺度是多少？这决定超快实验的参数窗口。
5. 向列序的取向如何被应变/衬底/光场钉扎或切换？能否用超快脉冲写入并读出向列取向？
6. STM 与输运判据都是静态或准静态的；时间分辨的各向异性响应（瞬态二色性、角度分辨超快电导）作为第三类判据尚无人提出——潜在的首创空间。
