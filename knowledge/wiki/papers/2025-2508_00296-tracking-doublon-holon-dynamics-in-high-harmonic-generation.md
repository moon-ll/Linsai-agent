• # Tracking doublon-holon dynamics in high-harmonic generation from Mott insulators

  ## 林赛的理解

  这篇工作对我组的强场 HHG 研究是一条极其重要的方法论参照。传统固体 HHG 光谱学在弱关联、刚性带体系中提取的是**静态**信息——能带色散、Berry 曲率、跃迁偶极矩；而这篇工作示范了 HHG 光谱的另一种可能：读取**强关联体系在强场驱动下的逐周期（cycle-by-cycle）电子态重构**。对 1D Mott 绝缘体 Sr₂CuO₃，HH 峰的红移随载流子产生效率同步出现，这等于把"非平衡相变动力学"变成了一个 HH 光谱可以读出的可观测量。这直接呼应我们"强场驱动 + 量子几何"的研究主线：强场不仅探测几何相位，还会实时改造能带结构本身，观测信号与动力学过程不可分割。文中 tdDMFT + 窗口化傅里叶相位分析的技术路线（half-cycle 窗口分辨辐射相位），是我们做理论解释时可以整体搬用的分析框架。

  ## 研究问题

  论文的核心问题：**在强关联体系中，强场 HHG 能否、以及如何反映 Mott 绝缘体在非平衡驱动下的电子态动态变化（而非静态能带结构）？**

  具体中心论点：当 MIR 电场振幅超过阈值后，1D Mott 绝缘体 Sr₂CuO₃ 中通过量子隧穿产生 doublon-holon 对（载流子），Mott 绝缘态被熔化；这一逐周期演化的电子结构重构会在 HH 光谱上留下**红移（redshift）**指纹——HH 峰能量偏离驱动频率的奇数倍。论文主张：HH 光谱学有潜力成为探测强关联材料非平衡相变逐周期动力学的互补手段。

  ## 研究背景

  - HHG 起源于强场下非微扰的电荷动力学，最初在原子分子气体中观测，用于产生阿秒脉冲和探测阿秒尺度电子动力学，后扩展到半导体与半金属。弱关联刚性带体系中，HHG 与能带结构紧密相关，已能通过 HH 谱测量分析能带色散、Berry 曲率与偶极矩阵元。
  - 强关联体系中，电荷、自旋、轨道自由度的耦合形成多个竞争的关联相；捕捉相变过程中这些自由度的动力学是长期挑战。既有方案依赖泵浦-探测：用超带隙泵浦光激发载流子触发相变，再用探测光追踪其演化。近年 MIR 亚带隙强激发（通过非线性激发产生载流子并诱导相变）成为新工具，其伴随的 HHG 可能携带强关联体系元激发的动力学信息——这一点此前未解决。
  - 在 1D Mott 绝缘体中，大 Hubbard U 阻止单占据构型的电子运动；强亚带隙光场通过量子隧穿产生 doublon（双占据位）与 holon（空位），破坏电荷局域态、诱导 Mott 绝缘态熔化。由于 1D 大 U 体系的自旋-电荷分离，超过 Mott 带隙的光学跃迁谱权重必然转移到 Drude 分量。
  - 前人理论研究预言半满 Mott 绝缘体中 doublon-holon 三阶段动力学对 HHG 有大贡献，但"HHG 如何反映 Mott 熔化的动态电子态变化"此前无实验-理论闭环。本工作选取典型 1D Mott 绝缘体 Sr₂CuO₃ 系统研究 MIR 电场依赖的 HH 谱与载流子产生过程。

  ## 研究方法

  **材料体系**：1D 铜酸盐 Sr₂CuO₃。晶体由 CuO₄ 单元沿 b 轴共享两个对角氧原子形成 Cu 链；Cu 3d(x²−y²)-O 2p 组成的 d 带半满，但强库仑排斥 U_d 使其成为 Mott 绝缘体；O-2p 带位于上、下 Hubbard 带之间，体系实为电荷转移（CT）绝缘体。理论上可通过把 O-2p 带映射到下 Hubbard 带，用**单带 Hubbard 模型**有效描述。线性光谱中 1.76 eV 的尖锐峰对应 CT 隙能量（本文记为 ∆_Mott），其最低激发态为单光子允许激子，略上方为 doublon-holon 连续谱；隙以下无多余载流子结构，确认样品为干净的半满 Mott 绝缘体。单晶由激光二极管加热浮区法（travelling solvent 技术，SrO:CuO = 40 mol%:60 mol%，Ar 60 vol% + O₂ 40 vol%、100 cm³/min 气流，生长速率 1 mm/h）生长。

  **HH 光谱测量**：MIR 脉冲 ℏΩ = 0.263 eV（Ω/2π = 63.6 THz），最大振幅 |E_MIR| ≈ 4.0–12.3 MV/cm，沿 b 轴偏振，反射几何探测。激光源为 Ti:sapphire 再生放大器（1.55 eV、35 fs、7 mJ、1 kHz），经 OPA 差频在 1 mm z-cut GaSe 晶体中产生 MIR（脉宽 ~220 fs、谱宽 22 meV）。HH 测量用光纤光谱仪覆盖 0.70–1.5 eV（NIR）与 1.4–4.0 eV（VIS）两段，并用标准卤钨灯校正系统响应。

  **泵浦-探测反射谱**：同源于 RA 的 MIR 泵浦（0.264 eV）+ 可见探测（1.79 eV，55 fs / 55 meV；MIR 泵浦 ~170 fs / 24 meV），在 Mott 隙反射峰处测量 ∆R(t)/R。用两个 Lorentz 振子（奇宇称激子 + doublon-holon 连续谱）拟合 R 与 ε₂ 谱；据理论，这些光学跃迁的减弱约正比于载流子密度。载流子密度估计：n_c ≈ −∆I/2I（I 为两 Lorentz 振子强度之和）。

  **tdDMFT 模拟**：对半满单带 Hubbard 模型用时间依赖动力学平均场理论（tdDMFT，NCA 杂质求解器，基于开源库 Nessi）计算时间演化，参数贴合 Sr₂CuO₃：U = 2.6 eV、带宽 W = 2.08 eV、键长 b = 3.9 Å、温度 T = 260 K（此时 ∆_Mott ≈ 1.5 eV，反铁磁序发育）。Bethe 晶格上以高斯脉冲驱动：ℏΩ = 0.26 eV、σ₀ = 63.3 fs、φ_CEP = 0，模拟区间 −253.2 fs 至 +253.2 fs；HHG 谱由电流 J(t) 计算 I_HHG(ω) = |J̇(ω)|² = |ωJ(ω)|²，施加高斯窗口 σ′ = 101.3 fs。逐亚周期发射谱用 1.5 fs 窗口；半周期分辨的相位分析用半周期方窗；单粒子谱用 5.0 fs 窗口（对应光电子能谱泵浦脉冲），时间演化本征步长约 0.03 fs。辐射相位定义为 Arg[J̇(ω, t_p)]，参考时间 t_i = −73.2 fs。观测量的定义：doublon 密度 n_d 由上 Hubbard 带占据积分给出，n_c = 2n_d；反铁磁关联 m_AFM 定义为两个子格上自旋密度之差。

  ## 主要发现与核心结论

  1. **HH 观测**：Sr₂CuO₃ 具有空间反演对称性，只观测到奇次谐波。3rd–11th 阶在 |E_MIR| > 4.0 MV/cm 出现，13th 与 15th 分别在 > 5.0 MV/cm 和 > 8.5 MV/cm 出现。谐波强度从 3rd 到 7th 递减、7th–11th 几乎不变、13th 起再次递减，类似半导体的三阶段模型谱形。**当 |E_MIR| > 6.0 MV/cm 时，5th–13th 阶 HH 峰能量偏离 Ω 的奇数倍（红移），反映 Mott 绝缘态熔化。**

  2. **强度标度**：|E_MIR| < 4.0 MV/cm 时 I₃HG ∝ |E_MIR|⁶、I₅HG ∝ |E_MIR|¹⁰，符合多光子过程；更高场强下 I₃HG 显著增强（归因于 doublon-holon 产生后的瞬态电流，类似半导体内带电流），|E_MIR| > 7.0 MV/cm 时 I₃HG、I₅HG 趋于饱和。n = 7–13 的 I_nHG 在低场区不服从幂律，表明载流子产生过程持续参与 HHG。

  3. **载流子产生的阈值行为**：|E_MIR| ≤ 4.0 MV/cm 时 ∆R(t)/R 为以 t = 0 为中心的脉冲响应，−∆R(0 ps)/R ∝ |E_MIR|²，归属为激子 Floquet 态的相干三阶非线性响应。|E_MIR| > 4.0 MV/cm 出现有限衰减时间的载流子产生信号；相干响应在 t = 0.25 ps 完全消失，故用 −∆R(0.25 ps)/R 分析载流子产生，其 |E_MIR| 依赖呈阈值行为，可用 1D Mott 绝缘体 doublon-holon 产生概率 Γ ∝ exp(−πE_th/|E_MIR|)、E_th = ∆_Mott/(2eξ) 复现；取 E_th = 13.4 MV/cm、∆_Mott = 1.76 eV 得 doublon-holon 关联长度 ξ ≈ 6.57 Å（约 1.68 个格点）。|E_MIR| ≃ 12.0 MV/cm 时 −∆R(0.25 ps)/R 达 0.35，说明 Mott 绝缘态被载流子产生熔化；**估计的载流子密度 n_c 在 |E_MIR| = 12.0 MV/cm 时达 0.25（每格点）。**

  4. **红移的定量特征**：|E_MIR| ≤ 6.0 MV/cm 时各峰位于 nℏΩ；|E_MIR| > 6.0 MV/cm 时 3rd 阶峰保持 3ℏΩ，而 5th 及以上阶随 |E_MIR| 增大红移并在 ~12.0 MV/cm 饱和；红移量随阶次 n 增大，**11th 阶达 ~50 meV**。红移的 |E_MIR| 依赖与 ∆R(0.25 ps)/R 及 n_c 同步，指向 Mott 熔化中的连续电子态变化。非线性传播效应模拟确认远小于实验红移；带隙相近（1.42 eV）的常规半导体 GaAs 在 10 MV/cm、0.34 eV MIR 反射几何测量中无 HH 谱移动。

  5. **tdDMFT 微观机制**：|E_MIR| = 6.7 MV/cm 时 n_c、m_AFM 与单粒子谱几乎不随时间变化；|E_MIR| = 12.0 与 16.0 MV/cm 时，脉冲期间 n_c 上升、m_AFM 降至近零（体系转变为顺磁金属），单粒子谱逐周期变化——原 Mott 隙缩小、谱权重从下 Hubbard 带转移到上 Hubbard 带（对应 σ(ω) 中的 Drude 权重）。强场下辐射周期性被破坏、辐射权重前移，t ≈ 0 附近辐射被抑制（归因于 doublon-holon 动力学相干性的下降）。相位分析：在 ω = ω_peak_n（n ≥ 7）处辐射相位涨落更小、逐周期相长积累，产生峰移；16.0 MV/cm 时 ω = nΩ 处相位在 t > 0 近平坦，但因脉冲后半段载流子密度升高导致辐射退相干，峰移仍发生。**结论：HH 红移源于 Mott 绝缘态熔化过程，且在 Mott 隙未闭合的情况下发生。**

  6. **三特征 + 半定量图像**：n = 3 峰在 12 MV/cm 内不变；n ≥ 5 在 6 MV/cm 以上出现阈值式红移并随载流子产生效率变化、高场饱和；5th 阶红移小于 7th 及以上阶（居间特性）。三者均被 DMFT 半定量复现。相位补偿论证：Mott 隙缩小（∆ε < 0）→ doublon-holon 复合辐射附加相位 (Δε/ℏ)(t_r − t_c)（t_r − t_c ~ T_hp）→ 构造性干涉要求频率偏离补偿 → 红移 Δω_r < 0。该机制对 CEP 不敏感、不需要长散射时间，与此前 CEP 调控非整数次谐波（如 Bi₂Te₃）的机制本质不同。

  ## 潜在研究方向

  - 载流子密度的估计假设 Mott 隙光学吸收谱权重**全部**转移到载流子诱导的 Drude 响应，绝对值存在不确定性（阈值型起始行为本身稳健）。
  - 单带 Hubbard 模型无法精确描述远高于带隙（约两倍带隙以上）光能处的 HHG 过程；本文关注区间限于带隙两倍以内，有效描述成立但外推需谨慎。1D 真实体系的自旋-电荷分离、CT 激子等细节被平均场化处理。
  - Mott 隙缩小的定量提取需要详细的前向建模（forward modelling），本文仅给出量级一致的相位补偿估计；红移与 ∆ε 的一一对应关系未闭合。
  - 开放问题（作者明确提出）：在光诱导熔化电荷序、轨道序、磁有序或光诱导超导过程中，HH 光谱会出现什么指纹？这是后续强关联超快光子学功能化的直接入口。
  - 实验层面：机制在更高维 Mott 体系、其他关联相（如交变磁体）中是否普适；退相干与辐射抑制之间的竞争如何定量刻画，均需进一步工作。

  ## 与林赛研究的关联

  - **强场驱动 + 非平衡电子态重构**：本文示范"HHG 信号本身被强场实时改造的电子结构所调制"——HH 峰移不再是纯探测量，而是动力学过程的读出。这为我们"强场驱动"方向提供了核心范式：在分析本组 HHG 数据时必须区分"静态能带几何贡献"与"场致电子态重构贡献"，二者在 n ≥ 7（高于带隙）与 n = 3（带隙内）通道中可分离——这正是本文的谱学判据。
  - **HHG / 阿秒**：逐半周期窗口化傅里叶相位分析（Arg[J̇(ω, t_p)]、T_hp = π/Ω 窗口）是亚周期分辨 HHG 的直接工具，可迁移到我们阿秒尺度动力学反演的方法学工具箱。
  - **莫尔/低维关联体系**：1D Hubbard 链 + 强 U 的设置与莫尔体系中关联平带的物理同构（Mott 物理、Hubbard 带、关联长度 ξ ≈ 6.57 Å 的 doublon-holon 约束）。本文的 tdDMFT + NCA 计算框架（U = 2.6 eV、W = 2.08 eV、Bethe 晶格）可直接作为我们莫尔-强场课题的对照基准。
  - **量子几何接口**：红移机制本质是"复合辐射相位受瞬时电子结构调制"，与 Berry 曲率/量子度规调制 HH 强度的机制在形式上互补（一个调相位、一个调强度），两者在真实强关联体系中可能同时存在，是"强场 + 量子几何"申请书可论证的方法学增长点。
  - 实验对标数值：阈值场 ~6 MV/cm、红移 ~50 meV（11th 阶）、n_c ~ 0.25 @ 12 MV/cm，可作为我们实验可行性评估的定量锚点。

• # 中红外电场下 Mott 转变亚周期演化的高次谐波印记：1D 铜氧物 Sr₂CuO₃ 中 Mott 绝缘态超快熔化的 HHG 研究

  ## 林赛的理解

  这篇工作对我们组是一条"新赛道级"的示范：HHG 不再只是弱关联刚性能带体系的能带探针，而是可以直接读出强关联体系中**非平衡电子态演化的亚周期指纹**。在 1D Mott 绝缘体 Sr₂CuO₃ 中，作者把 MIR 电场同时当作"泵"（通过量子隧穿产生 doublon–holon 对熔化 Mott 态）和"探针"（HH 峰的红移直接映射载流子产生与能隙缩小的逐周期进程），并辅以 tdDMFT 模拟闭环验证物理机制。对我们强场驱动方向的启示非常具体：HH 峰的**阈值式红移**（~6 MV/cm 以上出现、随阶数增大、~12 MV/cm 饱和、11 阶达 ~50 meV）是一个可定量、可复现的可观测量，而 DMFT 给出的逐半周期相位分析框架（Arg[Ḣ(ω)] 在 ω=ω_peak 与 ω=nΩ 之间的分裂）是把实验信号反演为电子态重建的桥梁。这直接支撑我们"强场驱动莫尔/关联体系相位演化"课题：把同一个范式从 1D Mott 绝缘体平移到莫尔 moiré 体系，HHG 有望成为探测关联驱动绝缘体熔化的原位手段。

  ## 研究问题

  论文要回答的核心问题是：**在强关联体系中，强场 HHG 能否承载非平衡电子态转变（而非静态能带结构）的亚周期（cycle-by-cycle）动力学信息？**

  具体分解为三个子问题：

  1. 一维 Mott 绝缘体 Sr₂CuO₃ 在中红外（MIR）强场作用下熔化时，HH 谱会出现什么此前未解析的异常行为？
  2. HH 峰从 MIR 频率奇数倍频的偏离（红移）是否与载流子产生/Mott 绝缘态熔化的电场阈值及进程定量关联？
  3. 该红移是否源于逐周期电子结构重建对载流子复合辐射相位的调制——即 HHG 是否能在半周期（~T_hp = π/Ω）尺度上"看见" Mott 熔化的进行时？

  ## 研究背景

  - HHG 源于强场非微扰电荷动力学，最初在原子分子气体中实现，用于产生阿秒脉冲与探测阿秒尺度电子动力学；随后扩展到半导体、半金属。在**弱关联、刚性能带**体系中，HH 谱测量已可反演能带色散、Berry 曲率、偶极矩阵元。
  - 强关联体系中电荷/自旋/轨道自由度耦合，存在多种竞争有序相，捕捉相变中这些自由度的动力学是重要挑战。传统方案是 pump–probe：泵浦光子能量高于带隙产生载流子触发相变，探针检测其演化；近年来亚带隙 MIR 泵浦可通过非线性激发产生载流子并诱导相变，且强 MIR 泵浦本身产生 HHG。
  - 此前已有理论预言：在半满 Mott 绝缘体中，强场产生 doublon–holon 对的三步（three-step）动力学会显著贡献 HHG；也有工作将 HHG 用作关联体系相变的探针或使用亚周期探测技术。但"HHG 反映振荡电场下非平衡电子态动力学本身"这一层面仍未解决。
  - 1D Mott 绝缘体中，大在位库仑排斥 U 阻止单占据组态的电子运动，载流子（doublon/holon）经量子隧穿产生；由于 1D 大 U 下的自旋–电荷分离，Mott 隙以上光跃迁谱权重必然转移到 Drude 分量——这为通过光学谱权重转移反演载流子密度提供了物理基础。

  ## 研究方法

  **材料体系**：典型一维 Mott 绝缘体 Sr₂CuO₃。CuO₄ 单元沿 b 轴共边形成 CuO 链；Cu 3d_{x²−y²} 与 O p 轨道交叠形成的 d 带半满，因大 U_d 成为 Mott 绝缘体，O-2p 带位于上/下 Hubbard 带之间，体系为电荷转移（CT）绝缘体，原则上需双带 Hubbard 模型描述，但映射 O-2p 带后可用单带 Hubbard 模型有效讨论。偏振反射谱测得 CT 隙（本研究记为 Mott 隙）∆_Mott = 1.76 eV 处的尖锐激子峰。单晶由激光二极管浮区法 + 助溶剂技术生长（SrO:CuO = 40 mol%:60 mol%，Ar 60 vol% + O₂ 40 vol%，流速 100 cm³/min，生长速率 1 mm/h）。

  **HH 谱实验**：Ti:sapphire 再生放大器（1.55 eV、35 fs、7 mJ、1 kHz）→ OPA 产生信号/闲频光 → 1 mm 厚 z-cut GaSe 差频产生 MIR 脉冲（ℏΩ = 0.263 eV，Ω/2π = 63.6 THz，脉宽 ~220 fs，谱宽 22 meV）；|E_MIR| 由两片 MIR 线栅偏振器调节至 ~4.0–12.3 MV/cm，第三片保证 b 轴偏振；反射几何测量（ITO 镀膜玻璃作分束片），b 轴偏振 HHG，NIR/VIS 两台光纤光谱仪覆盖 0.70–1.5 eV 与 1.4–4.0 eV，用卤素钨灯标准源校正光谱响应。

  **pump–probe 反射测量**：MIR 泵浦（ℏΩ = 0.264 eV，~170 fs、24 meV）+ 可见探针（1.79 eV，55 fs、55 meV），平行 b 轴偏振，测 ∆R(t)/R；用两个 Lorentz 振子（奇宇称激子 + doublon–holon 连续谱）拟合 R 与 ε₂ 谱，基于谱权重 ∝ 载流子密度的近似反演载流子密度 n_c ≈ −∆I/2I。

  **理论模拟**：含时动力学平均场理论（tdDMFT），Bethe 格点上单带 Hubbard 模型 + Peierls 相位耦合电场，NCA 杂质求解器（开源库 Nessi）。拟合 Sr₂CuO₃ 的参数：U = 2.6 eV、带宽 W = 2.08 eV、b = 3.9 Å、T = 260 K（此时 ∆_Mott ~1.5 eV 且有反铁磁序）；高斯泵浦脉冲 ℏΩ = 0.26 eV、σ₀ = 63.3 fs、模拟窗口 ±253.2 fs。HHG 谱由 I_HHG(ω) = |Ḣ(ω)|² = |ωJ(ω)|² 计算；窗口化傅里叶变换分辨逐半周期辐射强度（窗口 σ_p = 1.5 fs）与相位（方波窗口覆盖 T_hp = π/Ω 半周期）；单粒子谱用 5 fs 高斯窗；载流子密度 n_c = 2n_d，反铁磁关联 m_AFM = n_↑A − n_↑B。

  ## 主要发现与核心结论

  1. **HH 峰红移及其阈值行为**：|E_MIR| > 6.0 MV/cm 时，5–13 阶 HH 峰从 Ω 奇数倍频红移，随 |E_MIR| 增大并在 ~12.0 MV/cm 饱和；红移幅度随阶数增大，11 阶达 ~50 meV；3 阶在 12 MV/cm 以内始终不变，5 阶介于中间。|E_MIR| ≤ 6.0 MV/cm 时各峰与 nℏΩ 重合。

  2. **强度标度**：|E_MIR| < 4.0 MV/cm 时 I₃HG ∝ |E_MIR|⁶、I₅HG ∝ |E_MIR|¹⁰（多光子行为）；>7.0 MV/cm 时 I₃HG、I₅HG 趋于饱和；n = 7–13 阶在低场区即偏离幂律，说明载流子产生过程持续参与 HHG。各阶强度行为分为三类：n = 3（带内电流主导，3ℏΩ < ∆_Mott = 1.76 eV）、n ≥ 7（nℏΩ > ∆_Mott，doublon–holon 对三步复合）、n = 5（二者混合，5ℏΩ 接近吸收边）。

  3. **载流子产生的阈值与密度**：pump–probe 显示 |E_MIR| ≤ 4.0 MV/cm 时为激子 Floquet 态的相干三阶非线性响应（−∆R(0 ps)/R ∝ |E_MIR|²，脉冲式）；>4.0 MV/cm 出现有限衰减时间的载流子响应，−∆R(0.25 ps)/R 呈阈值行为，可用 doublon–holon 隧穿概率 Γ ∝ exp(−πE_th/|E_MIR|) 拟合，E_th = 13.4 MV/cm、∆_Mott = 1.76 eV 得 doublon–holon 关联长度 ξ ~6.57 Å（~1.68 格点）；|E_MIR| ≃ 12.0 MV/cm 时 −∆R(0.25 ps)/R 达 0.35，反演得 n_c = 0.25（每格点），表明 Mott 绝缘态被载流子产生熔化。

  4. **DMFT 微观机制**：|E_MIR| = 6.7 MV/cm 时 n_c、m_AFM、单粒子谱几乎不随时间变化；12.0 与 16.0 MV/cm 时 n_c 上升、m_AFM 在脉冲期间降至近零（体系变为顺磁金属），单粒子谱逐周期变化——原 Mott 隙缩小、谱权重从下 Hubbard 带转移到上 Hubbard 带（对应 Drude 权重）。计算 HH 峰红移与 n_c 的 |E_MIR| 依赖半定量复现实验三大特征。

  5. **相位机制**：强场下辐射权重向脉冲前段移动，t = 0 附近辐射反而被抑制（归因于载流子产生导致 doublon–holon 动力学退相干）。逐半周期辐射相位分析（∆Arg[Ḣ(ω)]，参考时刻 t_i = −73.2 fs）表明：n ≥ 7 时 ω = nΩ 与 ω = ω_peak 的相位显著分裂，ω = ω_peak 处辐射相位涨落小、发生相长积累——红移源于 Mott 熔化过程中的电子结构重建，且**发生在 Mott 隙未闭合的情况下**。机制上，三步模型中 doublon–holon 复合辐射的附加相位 ~(Δε/ℏ)(t_r − t_c)，与频率偏离 Δω_r 补偿后，隙缩小（Δε < 0）导致红移（Δω_r < 0），观测红移与 |Δε|/ℏ 量级一致（t_r − t_c ~ T_hp）。

  6. **排除其他机制**：非线性传播效应（光载流子引起穿透深度与折射率变化）的模拟频移远小于观测值；带隙相当的常规半导体 GaAs（1.42 eV）在 0.34 eV MIR、10 MV/cm 反射几何下未见 HH 频移；该红移机制对载流子包络相位（CEP）不敏感、不需长散射时间，与此前 CEP 调控的非整数谐波机制（如 Bi₂Te₃）本质不同；在刚性能带体系中可忽略。

  ## 潜在研究方向

  - **载流子密度的绝对标定**：n_c 估计基于"Mott 隙光学吸收谱权重全部转移到 Drude 响应"的假设，绝对值有不确定性（n_c = 0.25 需打折扣看待），但阈值型起始行为被认为稳健。精确标定需要结合其他手段（如太赫兹谱、时角分辨光电子能谱）。
  - **定量反演缺口**：从 HH 红移定量提取隙缩小需详细正向建模；本文仅给出量级估计（|Δε|/ℏ 与 Δω_r 同量级）。
  - **模型适用范围**：单带 Hubbard 模型对 CT 绝缘体在远高于隙的光子能量处失效；本文仅覆盖至 ~2 倍隙。O-2p 自由度的显式作用、向 2D/3D 关联体系的推广、更复杂有序（电荷序/轨道序/磁序）熔化时的 HH 指纹尚属开放问题。
  - **实验拓展**：光诱导超导、磁序/轨道序熔化时 HH 谱会出现什么指纹？HH 谱学能否与常规 pump–probe 互补成为关联材料亚周期电子态演化的常规探针？CEP 不敏感的特性在少周期脉冲下是否仍成立需验证。
  - 1D 自旋–电荷分离这一特殊物理是否对红移有独立贡献，值得在 2D 体系中对照检验。

  ## 与林赛研究的关联

  - **HHG × 关联体系非平衡相变**：本工作给出了完整的方法论范式——"MIR 强场同时作泵与探针 + HH 峰移测量 + tdDMFT 相位分析"。我们"强场驱动莫尔体系探针"课题可直接复用：将 Sr₂CuO₃ 替换为莫尔 moiré 平带/关联绝缘体，HH 峰红移及其阈值可成为探测莫尔关联态光致熔化的定量指纹。
  - **亚周期分辨思想**：逐半周期 Arg[Ḣ(ω)] 分析框架（窗口 = T_hp = π/Ω）可直接移植到我们的模拟管线，用于从 HHG 信号反演强场驱动下电子结构的逐周期重建——这与我们"强场驱动 + 阿秒/亚周期时间分辨"的技术路线完全对口。
  - **三步动力学 → 量子几何**：本文将 n ≥ 7 阶 HHG 归因于 doublon–holon 对三步复合，其相位补偿条件 Δω_r ≈ −(Δε/ℏ)(t_r − t_c)/T_hp 实质是复合时间-能量关系的读出；在我们"量子几何反演"课题中，类似思路可把 HH 相位信息反演为驱动下的有效能带/隙重构。
  - **阈值标度可迁移**：Γ ∝ exp(−πE_th/|E|) 型阈值律与 ξ 的提取方式（由 E_th、∆ 反推关联长度 ~1.68 格点）为莫尔体系中的光掺杂阈值分析提供模板。
  - 实验参数（0.26 eV / 63.6 THz MIR、4–12 MV/cm 场强区间）处于我们现有强场装置可及范围，可作为方案设计的基准。
