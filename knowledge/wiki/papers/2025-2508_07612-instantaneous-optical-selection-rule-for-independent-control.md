• # Instantaneous optical selection rule for independent control of valley currents

  ## 林赛的理解

  这篇工作是陆培祥组的理论提案，把光学选择定则从"整个光周期的平均手性"推进到"亚周期瞬时手性"（IOC），这是我一直关注的"用波形设计做亚周期量子操控"方向的又一例证。对我来说最有价值的不是谷电子学应用本身，而是它的**方法学模板**：在半经典 SBE 框架内引入 ionization wavelet 概念，把亚周期激发写成一个解析的不等式 η_vp = −tanh[2c(t_i)ζ_g · Ē_g/g₀]，把"手性-谷耦合"变成可工程化的波形设计问题。这跟我们在"瞬态量子相"课题里想做的事——在强场驱动下实时读出/操控量子几何与拓扑信息——几乎是同一套思想：不追求长时间平均的稳态信号，而是直接在光学周期尺度上雕刻电子布居与电流。他们用共旋双圆场（CRBF）合成"chirality-separated field"的具体构造方案（两个相反螺旋度的基场线性叠加、零净手性、亚周期手性分离）可以直接借用到我们强场驱动 2D 材料的方案写作中：这是一套清晰的"双频共旋场合成 + Lissajous 图手性编码"的参数表。

  ## 研究问题

  能否超越传统光学谷选择定则（OVSR）的"周期平均手性"限制，实现对 K 和 K′ 两个能谷电流的**独立、同时**操控？传统方法中，两个谷的电子经历同一个非对称驱动波形，载流子只能沿同一方向流动——两个谷自由度被"同步锁定"，无法分别定向。核心问题是：能否构造单一激光场，使其在一个光周期内包含相反符号的瞬时光学手性（oppositely signed instantaneous optical chirality, IOC），从而让 K 谷电子和 K′ 谷电子"各听各的"，实现 (1) 完全谷电流分离（100% 纯度谷极化电流）和 (2) 零净电荷流的纯谷电流（pure valley current）。

  ## 研究背景

  - 在缺空间反演对称性的二维六角体系中，布洛赫区出现简并不等价的 K、K′ 谷，由于谷间散射被强抑制，谷指标可视为守恒的赝自旋，催生了谷电子学（valleytronics）。
  - 谷电流操控的两个典型目标：谷极化电流（单谷主导的总电流）和纯谷电流（零净电荷流但赝自旋有输运）。过去二十年主要靠两类方案：①刚性架构（固定电极强偏压、异质结构，时间尺度受器件本征限制，无法超快操控）；②线性偏振太赫兹偏压 + 共振激发脉冲的多泵浦方案（ps 到数百 fs）。
  - 近年可见光/中红外全光学方法把谷操控推进到光学周期量级，但都基于传统 OVSR：与光场**周期平均手性**（如圆偏振螺旋度）的选择性耦合。非零谷电流可利用非对称矢势获得，但两谷电子经历同一波形、同向流动（参考文献 22-29），两谷控制同步、谷自由度未被充分利用。
  - 陆组此前在双色场诱导高纯度谷极化电流（PRB 111, 115406 (2025)，即 Ref. 27）和阿秒瞬态吸收圆二色性测谷极化（arXiv:2412.19612，Ref. 9）上有直接积累。

  ## 研究方法

  方法密度高（核心贡献即理论框架 + 波形构造方案 + SBE 模拟验证），按方法卡整理。计算细节正文指明在 SM 的 Sec. I(C)/III。

  **方法卡一：瞬时光学谷选择定则的理论框架**

  - **原理**：CB 布居由带间跃迁的时间干涉决定，累积相位 S[k(t)] = ∫dt′{E_cv[k(t′)] + F(t′)·R_cv[k(t′)] + Im[ṅ(t′)·d_cv(k(t′))/(n(t′)·d_cv(k(t′)))]}（Eq. 1）。第三项含偏振方向的时间导数 ṅ(t)，捕获光场瞬时旋转方向（手性）与体系的耦合。定义瞬时光学手性 c(t) = n_y∂_t n_x − n_x∂_t n_y（Eq. 2，与文献定义差一个电场振幅因子，脚注 45）和体系手性 ζ(k) = Re[(d₊−d₋)/(d₊+d₋)]（Eq. 3），K 谷附近 ζ≈+1、K′ 谷附近 ζ≈−1，可经对称性严格证明。基于 t_i 时刻激发的 ionization wavelet（陆组 SBE-Huygens-Fresnel 图像，Refs. 46-47），给出解析不等式：
    η_vp = [N_c(K) − N_c(K′)]/[N_c(K) + N_c(K′)] = −tanh[2c(t_i)ζ_g · Ē_g/g₀]（Eq. 4，g₀ 为 ionization wavelet 宽度常数，Ē_g = E_cv[K + A(t_i)]，ζ_g = ζ[K + A(t_i)]）。
  - **适用边界**：两带二维六角体系、强场近似下的半经典加速定理 k(t) = k + A(t)；η_vp 形式在 Ē_g(K)≈Ē_g(K′)、ζ_g(K)≈−ζ_g(K′) 近似下成立。

  **方法卡二：手性分离光场（chirality-separated field）的构造**

  - **原理**：以两个相反螺旋度的**共旋双圆场**（co-rotating bicircular field, CRBF）为基：ε_co_± = ∓[e^{i(ωt∓φ_co/2)} + (1/2)e^{i(2ωt∓φ_co+ϕ_±)}]ê_±，ê_± = (ê_x ± iê_y)/√2（Eq. 5）。合成矢势 A_cs = f(t)Re[√I⁺_co ε_co_+ + √I⁻_co ε_co_−]（Eq. 6）。在 φ_co = φ − ϕ₋ + ϕ₊ 时两基场波形相同，取 I⁺_co = I⁻_co 得**非手性**合成场（整周期零净手性），但亚周期范围内有相反符号的非零 IOC。ϕ± 控制 ε_co_± 的非对称方向，θ₊ = π + ϕ、θ₋ = −ϕ。
  - **关键参数表（数值原样，出自正文）**：
    - 基频波长 **4000 nm**（ω），二次谐波波长 **2000 nm**（2ω，共旋，同手性）
    - 合成激光总强度 **5×10¹⁰ W/cm²**
    - 脉宽 **12 T₀** 梯形包络（**1 T₀** 上升沿 + **10 T₀** 平顶 + 1 T₀ 下降沿），T₀ = 2π/ω 为基频光周期
    - 基准算例：**φ = π，ϕ₊ = ϕ₋ = 0**（Eq. 4 验证）
    - 独立操控扫描：**φ = π 固定，ϕ₊ = ϕ₋ = ϕ 变化**（Lissajous 图呈双瓣结构，两瓣分别由红/蓝编码的正/负 IOC 主导，瓣偏置方向随 ϕ 旋转）
    - 完全分离算例：**ϕ = 0.4π 或 1.6π**（∆γ = γ_K′ − γ_K = (n+1/2)π，两谷电流正交）
    - 纯谷电流算例：**ϕ = 0 或 π**（∆γ = (2n+1)π，两谷电流等大反向）；强度扫描 1×10⁹ – 1×10¹² W/cm²
  - **计算设置**：半经典半导体布洛赫方程（SBE），两带二维六角体系，计算方法与全部参数见 SM Sec. I(C) 与 Sec. III（正文未列原文出处，保持标注）。

  **判据**：谷极化纯度 P = (|J_detect^K′| − |J_detect^K|)/(|J_detect^K′| + |J_detect^K|)；纯谷电流纯度 Q = (|J_valley| − |J_charge|)/(|J_valley| + |J_charge|)，J_valley = J_K − J_K′，J_charge = J_K + J_K′。Q = 1 表示纯谷电流，Q = −1 表示纯电荷电流。

  ## 主要发现与核心结论

  1. **瞬时光学谷选择定则成立**：Eq. (4) 给出解析的谷布居失衡。c(t_i) 的符号决定 t_i 时刻电离的 wavelet 偏好激发 K 还是 K′ 谷。SBE 模拟验证（φ = π 算例）：c(t₁) > 0 时 N_c(K′) > N_c(K)；c(t₃) < 0 时反转 N_c(K′) < N_c(K)；c(t₂) = 0 时两谷布居相同。
  2. **独立操控实现**：固定 φ = π、扫描 ϕ₊ = ϕ₋ = ϕ，K′ 谷电流方向 γ_K′ 随正 IOC 瓣**逆时针**旋转，K 谷电流方向 γ_K 随负 IOC 瓣**顺时针**旋转，两谷电流可独立指向任意方向。SM Sec. IV 还给出一谷方向固定、另一谷独立旋转的场景。
  3. **应用一：完全谷电流分离（ϕ = 0.4π / 1.6π）**：两谷电流沿互成正交的方向发射；P 的绝对值在探测角 (0.25+n/2)π（n∈Z）处达到最大 **1**，即 **100% 纯度谷极化电流**；P = ±1 点间隔 **π/2** 证实两谷电流正交。相比以往依赖激发不平衡的方案（无法达到 100% 选择性），纯度来自电流方向的完全分离。
  4. **应用二：纯谷电流（ϕ = 0 / π）**：两谷电流等大反向，净电荷流为零。场关于 x 轴镜像对称保证 J_charge,x = 0，J_K 与 J_K′ 的 y 分量因镜像对称恒为零。强度扫描 1×10⁹ 至 1×10¹² W/cm² 内，|J_charge| 保持可忽略，**Q 恒等于 1，精确到小数点后第四位**。对激光参数涨落鲁棒（对称性保证）。
  5. 一个细节性发现：ϕ = 0 与 ϕ = π 两种驱动场的矢势 Lissajous 图**完全相同**，但谷电流方向反转——凸显 IOC 而非几何路径本身起决定作用。

  ## 潜在研究方向

  - 全为理论与 SBE 模拟结果，尚无实验演示；实验实现需要 4 μm / 2 μm 中红外共旋双频场合成与亚周期波形稳定控制，实验可行性是开放问题。
  - 模型为理想化两带二维六角体系，未处理多谷材料（如 SnS 的多谷态）、激子效应、谷间散射（虽被抑制但非零）、以及真实动量弛豫对亚周期电流的侵蚀。
  - 纯谷电流的"探测"目前仅通过布居投影模拟（J_detect 投影），真实器件如何读出纯赝自旋输运未讨论。
  - CRBF 构造依赖 ω + 2ω 共旋双频，更一般的多频/少周期极限下 IOC 的刻画未展开。
  - 与拓扑相位/Chern 绝缘体 HHG 圆二色性的交叉（作者引 Chacón et al. PRB 102, 134115 (2020) 但未深入）：瞬时光学手性是否可作为强场 HHG 中谷/拓扑分辨的通用旋钮，值得探索。

  ## 与林赛研究的关联

  - **强场驱动 + 亚周期操控**：瞬时光学手性 c(t) 与本组"强场驱动超快读出瞬态量子相"的核心思路同构——都在光学周期尺度用波形雕刻电子动力学；Eq. (4) 的 η_vp 解析形式可直接作为我们方案中"信号可解释性"的论证模板（亚周期机制 → 解析判据 → SBE 验证）。
  - **HHG 接口**：两带 SBE + ionization wavelet 图像（陆组 HHG 互文工作 Refs. 46-47）正是固态 HHG 微观图像的同一套语言；手性分离场可作为固态 HHG 圆二色性实验中分离 K/K′ 谷贡献的新驱动方案，与 Chacón et al. 的 Chern 绝缘体 HHG 圆二色性工作（Ref. 38）直接衔接。
  - **量子几何/拓扑**：体系手性 ζ(k) 由跃迁偶极的圆分量比定义，与 shift vector R_cv、Berry 联络同属量子几何量；IOC × ζ 的耦合提示"光学手性场可读取偶极角动量结构（量子几何）"的新机制，支撑我们"量子几何超快读出"的立项逻辑。
  - **实验方法素材**：ω(4 μm) + 2ω 共旋双色场合成、12 T₀ 梯形包络、10¹⁰ W/cm² 量级的参数表可直接换算进我们 2D 材料强场实验方案；判据 P/Q 的定义可复用为谷纯度与赝自旋纯度的量化指标。
