• # 3R-MoS₂ 原子级锐利边缘超薄超构表面实现高效非线性纳米光子学（q-BIC 增强 SHG）

  ## 林赛的理解

  这篇工作对我们组的意义不只是"又一篇 MoS₂ 非线性论文"，而是一个可以直接嫁接到我们强场超快与莫尔/超构表面方向上的**方法学模板**：他们用 20–25 nm 厚的 3R-MoS₂——厚度只有 λ/13——通过"干法刻蚀 + 各向异性湿法刻蚀"的组合，做出了原子级锐利 zigzag 边缘的等边三角形纳米孔阵列，第一次在体相 χ⁽²⁾ 活跃的纯 TMD 平台上实现了正入射 q-BIC，SHG 增强实测 ~800 倍。核心启示有三条：

  1. **低对称性 + 高指数 + 大 χ⁽²⁾ 三者可以兼得**。3R 相 TMD 的体相非零 χ⁽²⁾（~10⁻¹⁰–10⁻⁹ m/V）让我们不必依赖单层材料，多层膜的 FP 干涉 + 超构表面共振可以叠加增强。这直接适用于我们想做的"量子几何 / 交变磁响应的光学读出"课题——量子几何效应往往微弱，共振增强是刚需。
  2. **湿法各向异性刻蚀是低损耗密钥**。三角孔的 SHG 增强（~800 倍）远超圆孔（~200 倍），原因不是模式更强，而是边缘锐利度直接把散射损耗压下去。这说明在超构表面设计中，**损耗工程（工艺路线）与共振设计同等重要**——我们的申请书里写"高 Q 共振"时必须给出可达的 Q 值及其工艺保证。
  3. **晶体轴与超构表面晶格轴的对齐是实验自由度**。χ⁽²⁾ 张量在 AC 方向最强，而共振跟晶格走；二者对齐/不对齐可以调节偏振分辨 SHG 图样（六重对称破缺成三对二重特征）。这是一个可控的偏振工程旋钮，与我们 HHG 偏振测量、超快开关的偏振设计都有接口。

  ## 研究问题

  能否用体相 χ⁽²⁾ 非零的高指数范德华材料（3R-MoS₂），通过一种既保证共振品质（原子级锐利边缘）又主动破缺面内对称性的纳米加工工艺，制造出支持 q-BIC 共振的全 TMD 超薄超构表面，并在 deeply subwavelength 厚度（20–25 nm，≤λ/13）下实现大幅 SHG 增强？换言之：把 BIC/q-BIC 的场增强概念与 TMD 的大二阶非线性结合，是否能绕开"单层 TMD 太薄导致转换效率低（η_SHG ∝ |χ⁽²⁾|²L²）"这一根本瓶颈，同时避免"单层贴合外来超构表面"带来的应变、激子位移与非线性阻尼问题？

  ## 研究背景

  - **TMD 单层的效率瓶颈**：非中心对称的 2H-TMD 单层（MoS₂ 等）|χ⁽²⁾| 高达 ~10⁻⁷ m/V（体等效单位），但纳米级厚度使传播长度 L 极小，SHG/SPDC 效率受限；体相匹配晶体的倍频效率可超 50%，单层远不能及。
  - **"单层 + 外来共振超构表面"路线的副作用**：将单层集成到 SiN 等共振结构上虽能放大非线性，但不解决体积问题，且剥离/转移过程引入界面应变，导致激子共振光谱移动与非线性响应阻尼。
  - **传统高 Q 非线性介质平台**：LiNbO₃、BaTiO₃、GaAs、GaP 等可承载 BIC/谐振腔/WGM 等高 Q 共振，SHG 转换效率已达 ~0.1%，SPDC 亦有报道，但 |χ⁽²⁾| 只有 ~10⁻¹¹–10⁻¹⁰ m/V，比单层 TMD 低几个量级。
  - **BIC/q-BIC 概念**：光学 BIC 理论上 Q 无限，但受限于工艺容差与材料损耗；q-BIC 通过轻微破缺对称性换取远场可激发性。q-BIC 已用于增强 SHG（~0.1%）、SPDC 甚至高次谐波产生。
  - **TMD 的多层优势与 2H 相缺陷**：多层 TMD 折射率高（n > 4）、光学各向异性强（Δn > 1.5），适合 BIC 概念；但常规 2H 相体晶体中心对称，体相 χ⁽²⁾=0。GaSe、NbOCl₂、3R-MoS₂、3R-WS₂ 等替代相体相即有可观 χ⁽²⁾（~10⁻¹⁰–10⁻⁹ m/V），但此前从未有基于这些材料的高指数超构表面报道。
  - 结合近期 3R 相范德华材料的晶圆级制备方法（文献 [69]），本工作补上"全 TMD 高 Q 非线性超构表面"这一空白。

  ## 研究方法

  本论文方法密度高：材料平台优化（厚度-波长二维扫描）+ 两套工艺路线对比（RIE 圆孔 vs. RIE+湿法三角孔）+ BFP 角分辨反射谱 + 偏振分辨 SHG + TMM/RCWA/COMSOL 三层模拟，每个环节数值完整。按方法卡格式整理：

  **方法卡 1：裸 3R-MoS₂ 薄片 SHG 平台优化（厚度-波长扫描）**

  - **原理**：在玻璃基底上测量未图案化 3R-MoS₂ 薄片 SHG 强度随泵浦波长（λ_pump 800–1040 nm，对应 ħω 1.2–1.55 eV）与厚度 h（至 ~400 nm）的二维分布，定位 FP 共振增强带，为超构表面选厚度。
  - **装置与序列**：可调谐飞秒激光经 40× / NA=0.95 物镜从玻璃基底侧聚焦到薄片表面，SHG 经同一透镜收集，雪崩光电二极管（APD）定量；光学成像定位薄片 → 单波长 SHG mapping → AFM 测厚度剖面（可同时对多个厚度取谱）。
  - **参数表**：
    - 泵浦范围：λ_pump = 800–1040 nm（ħω_pump = 1.2–1.55 eV），Fig. 2c
    - 典型共振截面波长：800 nm、910 nm（最共振）、1000 nm，Fig. 2d
    - 薄片厚度：AFM 测量，示例薄片 138 nm，Fig. 2b
    - 物镜：40×，NA = 0.95，Fig. 2a
    - 理论对照：glass/3R-MoS₂ 界面转移矩阵法（TMM），χ⁽²⁾ 张量取自文献 [67]，折射率取椭圆偏振测量 [54]
  - **适用边界**：FP 增强对 h 精确值极敏感（同一波长下可达三个量级差异）；计算值相对实验红移 ~0.1 eV（理论 χ⁽²⁾ 峰在 ~1.27 eV / ~975 nm）；高阶 FP 模因 SHG 波长（λ_SHG = λ_pump/2，400–500 nm）处 MoS₂ 介电函数虚部 >10 而饱和——体相极化存在但深处无法辐射。
  - **关键输出**：~20–25 nm 厚度是"单位材料 SHG 发射"最优（存在 ~100 nm 处第二个更大 FP 极大，但厚膜出耦与工艺精度都更差）。

  **方法卡 2：圆孔超构表面（EBL+RIE 基准工艺）**

  - **原理**：方格圆孔阵列支持对称保护 BIC（正入射），BFP 成像观察反射极小值在正入射角收敛/消失以确认 BIC 本性。
  - **参数表**（Fig. 3）：
    - 厚度 h = 27±1 nm（AFM）
    - 平均孔径 ⟨D⟩ = 278±8 nm；填充因子 ff = 0.25±0.02
    - 晶格常数 Λ_x = 493±7.4 nm，Λ_y = 488±8.3 nm
    - BFP 用油浸物镜，角度范围受限 sinθ ≈ 0.66（玻璃-空气全反射角 θ = arcsin(n_air/n_glass) ≈ 41.5°）
    - TE 模两个反射谷在 ħω ~1.4 eV 和 ~1.45 eV 处正入射消失 → 对称保护 BIC；TM 模 ~1.4–1.5 eV 为平带，非 BIC
    - RCWA 拟合参数：Λ = 500 nm，D = 262.5 nm，h = 23 nm
  - **适用边界**：圆孔样品存在形状缺陷与光刻胶残留（espacer 工艺），边壁粗糙抬升散射损耗，限制 Q；这也是其 SHG 增强偏低的直接原因。

  **方法卡 3：三角孔超构表面（RIE 预刻 + 各向异性湿法刻蚀，核心方法创新）**

  - **原理**：湿法刻蚀把圆孔自限制性地重构成等边三角形孔，孔边沿 3R-MoS₂ 的 zigzag 晶向；三角形元胞缺 C₂ 与 C₄ 面内对称 → 正入射可激发 q-BIC；同时边缘达原子级锐利，压低散射损耗。
  - **参数表**（Fig. 4）：
    - 刻蚀尺寸律（h = 24.5±1.5 nm 时）：a_tri = 2.14 D_hole + 72 nm（D 以 nm 计，线性拟合）
    - 成品几何：a_tri = 373±7.6 nm，ff = 0.24±0.02，Λ_x = 501±7.3 nm，Λ_y = 507±7.4 nm，h = 24.5±1.5 nm
    - 为匹配圆孔样品的填充因子，初始圆孔须更小（湿法消耗材料）
    - 关键工艺约束：三角孔边平行于晶胞轴要求预知 ZZ/AC 晶向；χ⁽²⁾ 峰沿 AC 方向，与超构表面晶格对齐有利于优化
    - 湿法刻蚀会暴露 3R-MoS₂ 多层中的堆垛层错（SI Fig. S5），层错样品排除出反射与 SHG 实验
    - RCWA 拟合参数：a_tri = 375 nm，Λ = 500 nm，h = 20 nm；qBIC 实验位于正入射 1.47 eV
  - **适用边界**：刻蚀自限制但对起始圆孔尺寸与晶向校准敏感；2H 相与 3R 相刻蚀行为不同（SI Fig. S4 对比）。

  **方法卡 4：SHG 增强测量与模拟**

  - **序列**：固定泵浦偏振沿 y 轴（三角孔高度方向/晶胞轴之一），无检偏器收集，扫描 λ_pump 得增强谱 SHG_meta/SHG_flake（Fig. 5a/b）；随后在最优波长做偏振分辨 SHG（旋转泵浦偏振角 φ，Fig. 5c/d）。
  - **参数与结果**：
    - 圆孔：共振 λ_pump = 850 nm（1.46 eV，对应 TM 模），实验增强 ~200 倍，计算 ~大一个量级
    - 三角孔：共振 λ_pump ≈ 810 nm（对应 BFP ~1.53 eV qBIC），实验增强 ~800 倍，计算 ~1400 倍
    - 理想无限阵列计算峰值二者相近（~1500 倍），实验差距归因于三角孔边缘锐利度与表面洁净度
    - 偏振分辨：宿主薄片六重对称；圆孔三角孔均呈三对二重特征，主方向 φ = 90°（AC 方向）；薄片 ZZ 方向理论上 SHG 为零处，计算给出最大增强（图 5c 计算值高达 8 个量级），实验因轴对齐偏差与模式 Q 限制远低
    - SHG 模拟：COMSOL（三角孔，同 Fig. 4e 参数）；宿主薄片对照计算取与超构表面相同厚度
  - **计算设置总览**：TMM（裸片 SHG）、RCWA（反射谱模式归属）、COMSOL（超构表面 SHG 增强与偏振图样）；χ⁽²⁾ 张量统一取文献 [67]，折射率取文献 [54] 椭圆偏振数据。

  ## 主要发现与核心结论

  - **首次实现体相 χ⁽²⁾ 活跃的全 TMD 超构表面支持 q-BIC 共振**：厚度 20–25 nm（≤λ/13）的 3R-MoS₂ 三角孔阵列，在正入射 1.47 eV 处观测到 qBIC（实验）/ 计算确认。
  - **SHG 大幅增强**：三角孔超构表面在 λ_pump ≈ 810 nm 处 SHG 增强 ~800 倍（实验）/ ~1400 倍（计算）；圆孔为 ~200 倍（实验）。论文摘要级口径"超构表面相比未图案化薄片增强超三个量级（特定波长与线偏振方向）"。
  - **湿法刻蚀的双重作用**：（i）原子级锐利 zigzag 边缘 + 更洁净表面 → 更低散射损耗（这是三角孔优于圆孔的直接机制，理想阵列计算峰值同为 ~1500 倍）；（ii）C₂/C₄ 面内对称破缺 → 远场可激发的 q-BIC。
  - **厚度优化结论**：~20–25 nm 是"单位材料 SHG 发射"最优厚度；~100 nm 处 FP 极大更强但出耦差、工艺难；高阶 FP 因 SHG 波长（400–500 nm）处介电函数虚部 >10 的吸收而饱和。
  - **FP 共振是 SHG 色散主因**，χ⁽²⁾ 张量沿各 FP 带调制光谱强度；实验 FP 增强相对离共振情形可达三个量级。
  - **偏振工程**：SHG 强度 = 场增强 × 材料非线性的乘积；φ = 90°（AC 方向）主导；在宿主薄片 SHG 理论上为零的 ZZ 方向，超构表面借助晶格共振提供大增益（计算达 8 个量级）——即超构表面能在材料本征非零响应之外"点亮"新偏振通道。
  - **对称保护 BIC 确认**：圆孔阵列 TE 模两个反射谷（~1.4 eV、~1.45 eV）在正入射消失；TM 平带非 BIC。

  ## 潜在研究方向

  - **实验与计算增强差距**：圆孔实验（~200 倍）比计算低近一个量级，源于表面/形状粗糙度；说明工艺-损耗定量关联仍是开放问题（SEM/AFM 形貌统计与 Q 值的定量映射未做）。
  - **qBIC 的 Q 值定量表征有限**：BFP 谱给出模式位置与对称性归属，但未给出 BIC/qBIC 的线宽/Q 随对称破缺参数的标度（如三角孔尺寸微调），留下设计空间。
  - **SHG 绝对转换效率未报告**：论文以增强倍数（meta/flake 比值）为指标，未给出绝对 η_SHG 与 q-BIC 平台文献 [45–47] 的 ~0.1% 直接对比——这是向 SPDC 等量子应用推进前必须补的。
  - **轴对齐误差**：偏振分辨实验中副峰弱于计算，可能源于晶轴与晶胞轴轻微失准；意味着实际器件中晶向校准工艺需要标准化。
  - **堆垛层错**：3R 多层中偶发层错需靠湿法刻蚀显影并手工剔除，大面积制备时的良率问题待解。
  - **未触及的动力学**：全文为稳态/准稳态 SHG 测量，未见泵浦功率依赖损伤阈值、超快时间分辨响应的报道——高 Q 共振下的非线性动力学与热效应是空白。
  - **向其他二阶过程与更强对称破缺扩展**：SFG/DFG、SPDC、以及把此平台用于更高阶非线性（q-BIC 高次谐波已有先例 [51,52]）均未在本工作中展开。

  ## 与林赛研究的关联

  - **HHG / 强场驱动**：q-BIC 的深亚波长场增强（高局域场 + 长光子寿命）正是强场驱动 HHG 需要的两个条件。本工作的"高指数 TMD + 原子级锐利边缘"工艺路线可直接平移到强场区（需注意 MoS₂ 在 400–500 nm 强吸收，泵浦应在近红外、谐波在近紫外内），为"超构表面上的固体 HHG"提供材料-工艺底座。其论文 [51,52]（q-BIC 高次谐波）是我们方案写作的直接引用锚点。
  - **阿秒 / 超快**：高 Q 共振的局域场增强可降低产生阿秒脉冲所需驱动强度；反之，超构表面共振的相位特性（FP/qBIC 的色散）对阿秒脉冲合成的群延迟色散管理提出新问题——这可以作为我们"超快读出"方向的理论接口。
  - **莫尔 / 超构表面**：本文示范了"晶格对称性（超构表面）× 晶体对称性（TMD χ⁽²⁾ 张量）"的耦合设计范式。莫尔超晶格正是同一范式的扭转角版本：把 3R-MoS₂ 换成莫尔体系，χ⁽²⁾ 或电极化响应受量子几何（贝里连接极化率）调制，超构表面共振负责读出放大。偏振分辨 SHG 图样（六重对称破缺成三对二重特征）就是量子几何指纹的光学读出模板。
  - **交变磁（altermagnetism）/ 量子几何读出**：量子几何效应通常信号微弱；本文证明 deeply subwavelength 高指数介质可以把弱非线性信号放大 2–3 个量级，这一"共振放大 + 偏振选择"的读出架构是交变磁或平带体系量子几何探测的现成方案。
  - **直接可复用素材**（供课题方案写作）：TMM/RCWA/COMSOL 三层模拟分工；BFP+油浸物镜角分辨反射表征协议（sinθ ≈ 0.66 上限）；湿法刻蚀尺寸律 a_tri = 2.14D + 72 nm；厚度-波长 SHG 优化扫描流程（40×/NA=0.95 背向收集 + AFM 联测）；偏振分辨 SHG 的"宿主薄片-超构表面对照"分析方法。

### 研究问题（Research Question）
能否通过**自上而下光刻 + 各向异性湿法刻蚀**在 3R-MoS₂ 中制备具有原子精度锯齿形（zigzag）边缘的等边三角形纳米孔超表面，从而在亚波长厚度（~20-25 nm）下实现 SHG 三数量级以上增强？核心问题：原子级锐利边缘 vs 粗糙边缘对 SHG 增强的贡献如何区分？

### 研究背景（Background）
介电超表面的非线性增强受材料 χ⁽²⁾ 与几何共振双重制约；常用材料（GaAs、GaP、LiNbO₃）存在加工损伤、缺陷散射。3R 相 MoS₂ 兼具高折射率、破缺反演对称（χ⁽²⁾ 非零）、且为层状 vdW 材料可定向刻蚀。本文由 Zograf、Shegai 团队（瑞典 Chalmers）发表，主打原子精度边缘控制作为非线性纳米光子学的关键工艺突破。

### 研究方法（Methods）
工艺：3R-MoS₂ 块体 → 电子束光刻定义三角形阵列 → 各向异性湿法刻蚀利用 MoS₂ 锯齿形边缘化学活性差异实现原子级锐利边界；表征：SEM/TEM 确认边缘粗糙度、SHG 偏振/波长依赖测量、对照实验比较粗糙边缘 vs 原子精度边缘的增强倍数；厚度 20-25 nm 的超表面满足 λ/13 深亚波长条件。

### 主要发现与核心结论
1) 在特定波长与偏振下 SHG 增强超过**三个数量级**（>1000 倍），相对原始薄膜与粗糙边缘样品均显著提升；2) 原子精度锯齿形边缘消除散射损耗，将米氏共振（Mie-type）与高 χ⁽²⁾ 有效耦合；3) 3R-MoS₂ 因其本征高折射率（约 4-5）与强 χ⁽²⁾ 优于传统介电材料，是超薄非线性超表面的新平台候选。

### 潜在研究方向（Future Directions）
当前工作集中在 SHG（χ⁽²⁾），三次谐波（χ⁽³⁾）与 HHG 还未涉及；刻蚀工艺是否可推广至其他 3R 相 TMD（WS₂、WSe₂）以及多层堆叠（双层扭转）尚需验证；大规模均匀性、wafer-scale 制备可行性、与波导/光纤集成的耦合效率仍为工程挑战；长时间运行下的激光损伤阈值与稳定性是实用化关键。
