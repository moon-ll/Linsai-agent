## 研究问题（Research Question）

本文的核心问题是：**当不使用经典的 Tikhonov 正则化（加惩罚项）时，能否用"加约束"的变分正则化方法——Ivanov 正则化（拟解法 / method of quasi solutions）与 Morozov 正则化（残差法 / method of the residuals）——在非线性、无限维 Banach 空间框架下建立良定性、收敛性与收敛率，并将其落到椭圆 PDE 的参数辨识问题中？**

作者特别聚焦于一个此前被忽视的缺口：文献中已知 Ivanov 正则化在**理想参数选择** ρ = R(x†)（即"恰好取真解的正则化泛函值"）下可证收敛与收敛率，但这要求事先知道 x† 的 R 值，实践中不可得。因此本文提出的具体子问题是：**当 R(x†) 未知时，能否用 discrepancy（差异原理）类型的规则来选取 ρ，并仍保持收敛与收敛率？**

第二个子问题是方法学上的正当性：Ivanov/Morozov 方法与 Tikhonov 是否等价？若能建立某种"惩罚参数 α 与约束半径 ρ 的对应关系"，则可大量借用 Tikhonov 的成熟理论。作者的答案是**否定的**——并给出一个无限维反例来证明这种等价性会因非凸性而失效，从而必须独立发展一套理论。

第三个子问题是：上述抽象结果在**实际的 PDE 参数辨识**（源项、势、扩散系数）中能否成立，且收敛率能否表述为物理上有意义的误差度量（如 W^{-1,p} 范数、BV* 范数）而非仅 Bregman 距离。

## 研究背景（Background）

经典 Tikhonov 正则化 min S(F(x), y^δ) + α·R(x) 无约束、形式简单，长期以来占据主导地位。但作者指出一个结构性劣势：它在**强凸性/非凸性**下参数 α 的选取行为复杂，且当数据本身携带物理先验（系数的逐点上下界、源项的非负性、仪器精度给出的噪声水平）时，Tikhonov 无法直接把这些先验作为约束利用。

Ivanov 正则化（Ivanov 1962, 1963；Dombrovskaja & Ivanov 1965；Ivanov-Vasin-Tanana 2002）与 Morozov 正则化（Morozov 1967）的共同点是**都产生不等式约束的极小化问题**：Ivanov 是"在 R(x) ≤ ρ 的球内最小化失配"，Morozov 是"在失配 ≤ τδ 的条件下最小化 R"。由于约束天然对应"已知系数有界""源项非负""噪声水平已知"这类物理信息，作者认为这类形式在应用中特别自然。发表版的引言明确点出这一动机：过去偏好无约束 Tikhonov，很可能正因为这两种方法带来约束极小化问题；但近几十年 PDE 控制/状态约束极小化方法（他们引用了 2016 年 Kaltenbacher–Rendl–Resmerita 用信赖域方法高效求解拟解的工作）的进展，已经为这些方法的实用铺平了道路。

前人工作版图：Seidman & Vogel (1989) 在 Hilbert 空间里建立了 Tikhonov/Ivanov/Morozov 三者的适定性与收敛性，但限于 Hilbert 空间与较粗的框架；Lorenz & Worliczek (2013) 给出三种方法的比较，并在有限维 R 上给出一个反例；Neubauer & Ramlau (2014) 在 Hilbert 尺度中给出了拟解的收敛率；Grasmair–Haltmeier–Scherzer (2011) 的残差法论文实际上已在更一般的框架下覆盖了 Morozov 的良定性。本文自身的增量在于**把 Ivanov 与 Morozov 放进同一个一般框架**，并把收敛率结果从 Bregman 距离推广到更贴近物理的误差泛函。

理论上还依赖 Banach 空间反问题正则化的既有成果：Hofmann–Kaltenbacher–Pöschl–Scherzer (2007) 给出的变分 source condition，以及 Bredies–Lorenz、Flemming、Grasmair、Hofmann–Mathé 关于广义 Bregman 距离与变分光滑性的系列工作。

作者也诚实地指出本文与 Grasmair 等 (2011) 的重叠："我们对 Morozov 正则化良定性与收敛性的结果实际上（在更一般的框架中）已被 [7] 覆盖"，但选择提供统一分析，因为命题 2.6/2.9 的框架——尤其**对 Ivanov（配合本文提出的 ρ 选择）与 Morozov 都新的收敛率结果**——是新的。

## 研究方法（Methods）

**理论框架（第 2 节）。** 设反问题 F(x) = y，F: D(F) ⊆ X → Y，X、Y 为拓扑空间 (X, T_X)、(Y, T_Y)，F 非连续可逆故病态；假设解 x† 存在。噪声水平已知：S(y, y^δ) ≤ δ。两种方法为：

- Morozov（残差法，式 (3)）：min_{x∈D(F)} R(x) s.t. S(F(x), y^δ) ≤ τδ，τ ≥ 1 为与 δ 无关的常数
- Ivanov（拟解法，式 (4)）：min_{x∈D(F)} S(F(x), y^δ) s.t. R(x) ≤ ρ，其中 x† ∈ X^ad(ρ) := {x : R(x) ≤ ρ}

三种 ρ 的选择：(6) 理想选择 ρ_*^I = R(x†)；(7) ρ_*^II := argmin{ρ ≥ 0 : 极小元 x^δ_ρ 存在且 S(F(x^δ_ρ), y^δ) ≤ τδ}；(8) 松弛且更易计算实现的 ρ_*^III：满足 δ < S(F(x^δ_ρ), y^δ) ≤ τδ。

核心假设 **Assumption 2.1** 六条：(i) F 关于 T_X–T_Y 顺序闭（sequential closed）；(ii) R 与 S(·, y^δ) 分别关于 T_X、T_Y 下半连续；(iii) R 的下水平集 {R ≤ C} 是 T_X-紧的；(iv) S 的下水平集是 T_Y-紧的；(v) 存在 x† 使 R(x†) < ∞；(vi) 存在 ρ₀ ≥ 0 使 x^δ_ρ₀ 的极小元存在且 δ < S(F(x^δ_ρ₀), y^δ)；若 ρ₀ < ρ_*^II 另需 (vi)a 存在从 X^ad(ρ) 到 X^ad(ρ+d_n) 的映射 φ_n 且 S(F(φ_n(x)), y^δ) → S(F(x), y^δ)，以及 (vi)b 极小元的唯一性。作者给出这些假设的可验证实例：R(x) = ‖x − x₀‖_p 时 φ_n(x) := x₀ + ((ρ+d_n)/ρ)^{1/p}(x − x₀)；若 R、S(·, y^δ) 凸且其一严格凸则唯一性成立；R 严格凸时即使 F 非凸，小半径 ρ 也足以补偿。

**反例构造（第 1 节 Example 1）。** 一维情形取 r(x)=|x|、s(x)=½|x|²、f(x) = (x−x₀)³ + y、y^δ = y + δ、x₀ > (2δ)^{1/3} > 0，则 x† = x₀ 同时是精确解、Ivanov 极小元（ρ = r(x†)）与 Morozov 极小元，但**对任意 α > 0，x^δ_α ≠ x₀**。随后提升到 X = L^∞(Ω)、Y = L²(Ω)、F(x)(t) = ∫_Ω Φ(t−s) f(x(s)) ds（Φ 为归一化非负核；若 Φ 弱奇异则 F 紧；若 Φ 是某微分算子 D 的 Green 函数，则 F(x)=y 等价于非线性反源问题 Dy = f(x)）。证明用一阶最优性条件：Ivanov 为 x(s) ∈ x₀·sign(p(s))，Tikhonov 为 x(s) ∈ (‖p‖_{L¹}/α)·sign(p(s))，其中 p(s) = −f′(x(s))∫∫ΦΦ(f(x(τ)) − y^δ)。利用 Φ 的归一化可证 p(s) ≥ 3(x(s)−x₀)²δ ≥ 0 且 p(s)=0 当且仅当 x(s)=x₀，故满足 Ivanov 条件的唯一可行点是常数函数 x†；同时验证 Ψ(x) = S(F(x), y^δ) 在 B^∞_{x₀}(0) 上凸（Ψ″(x)(h,h) ≥ 0，因 6(x(s)−x₀) 与 ((x(τ)−x₀)³−δ) 均非正、其余因子非负），于是 x† 满足 Ivanov 的 KKT 条件但**不**满足 Tikhonov 的条件（x†(t)=x₀ ∉ {0} = (‖0‖_{L¹}/α)sign(0)）。

**证明技术。** 良定性用变分法直接法（紧性 + 下半连续 + F 的闭性）；ρ_*^II 的适定性通过证明集合 Rad := {ρ : 极小元存在且 S ≤ τδ} 是右无界区间且含其左端点（用单调性 (15) 推得）；ρ_*^III 的适定性通过介值定理作用于 ψ(ρ) = S(F(x^δ_ρ), y^δ)（端点值 ψ(ρ₀) > τδ、ψ(ρ_*^II) ≤ τδ，连续性依赖 (vi)b 唯一性）。收敛用子列-子列论证 + Assumption 2.4（(i) S 的收敛合成律，(ii) S(ỹ,y)=0 ⇒ ỹ=y）。

**收敛率。** 用变分 source condition (23)：−⟨ξ†, x̃ − x†⟩ ≤ β·D_ξ†(x̃, x†) + φ(S(F(x̃), F(x†)))，β ∈ [0,1)，ξ† ∈ ∂R(x†)，φ 为指标函数；配合 Assumption 2.7 的广义三角不等式 S(y₁,y₃) ≤ C_S(S(y₁,y₂) + S(y₃,y₂))。

**PDE 应用（第 3 节）。** 统一在椭圆方程 ∇·(a∇u) + cu = b 下，分三种情形辨识空间变化的 a、b 或 c（其余两个已知）：(i) 源项 −Δu = b，前向算子 F: L^q(Ω) → L^p(Ω)，b ↦ (−Δ)^{-1}b（椭圆正则性给出 L^q → W^{2,p} 有界，p ≤ q）；(ii) 势 −Δu + cu = f，X = L^∞(Ω) = L¹(Ω)* 配弱* 拓扑，D(F) = {c ∈ L^∞ : c ≥ 0 a.e.}，Y = L^p(Ω)；(iii) 扩散系数 −∇(a∇u) = f，D(F) = {a ∈ X : γ̄ ≥ a ≥ γ > 0}，X = BV(Ω) 配弱* 拓扑（因为需要 X → L¹ 的嵌入和 D(F) 的 T_X 闭性，L^∞ 不可行，BV 可行），Y = L^p(Ω)，p 的取值范围由 (41) 给出（d=1 或 2 时 p ∈ [1,∞)；d ≥ 3 时 p ∈ [1, 2d/(d−2)]）。证明工具包括 Helmholtz 分解 + Poincaré–Friedrichs 不等式（Lemma 3.3 的 W^{1,p} 一致界）、弱形式测试与 Young 不等式（Lemma 3.4 的 F 弱序列闭性）、以及 Lemma 3.5 的对偶估计（由 {∇u†·∇φ} 在 Z 中稠密与 ‖∇(a∇φ)‖_V ≤ C‖∇u†·∇φ‖_Z 推出 ‖ã−a†‖_{Z*} ≤ C‖F(ã)−F(a†)‖_U）。误差泛函 E 的选取通过插值不等式 + Sobolev 引理确定。

## 主要发现与核心结论（Main Results）

**1. 与 Tikhonov 的非等价性得到严格证明。** Example 1 说明：在无限维 Banach 空间 X = L^∞(Ω)、Y = L²(Ω) 上，Ivanov (4) 与 Morozov (3) 都不等价于 Tikhonov min S(F(x), y^δ) + αR(x)，对任何 α > 0。这使得独立建立收敛理论成为必要，而非可选。

**2. 良定性与结构性不等式（Theorem 2.3）。** x^δ_Mo 与（对 ρ ≥ ρ_*^II 的）x^δ_ρ 均良定；ρ_*^II ≤ ρ_*^I = R(x†)；R(x^δ_Mo), R(x^δ_ρI*), R(x^δ_ρII*) ≤ R(x†)；S(F(x^δ_Mo), y^δ) ≤ τδ、S(F(x^δ_ρI*), y^δ) ≤ δ、S(F(x^δ_ρII*), y^δ) ≤ τδ；单调性 (15)：ρ₁ ≤ ρ₂ ⇒ S(F(x^δ_ρ₁), y^δ) ≥ S(F(x^δ_ρ₂), y^δ)。在附加 (vi) 后，ρ_*^III 良定且 ρ_*^III ≤ ρ_*^I = R(x†)、S(F(x^δ_ρIII*), y^δ) ≤ τδ。**关键点：ρ_*^II 与 ρ_*^III 这两个"不需知道 R(x†)"的 discrepancy 型选择同样满足 R(x̂^δ) ≤ R(x†) 与失配 ≤ τδ，这正是收敛率定理所需的 (24)(25)。**

**3. 闭合性（Proposition 2.2）。** Q_ρ = F(X^ad(ρ)) 是 T_X-闭的——在病态问题中 F 的值域通常非闭，这已表明 Ivanov 方法具有正则化性质。

**4. 收敛（Theorem 2.5, Corollary 2.6）。** 在 (19) R(x̂^δ) ≤ C 与 (20) S(F(x̂^δ), y^δ) → 0 下，得 T_X-子列收敛到 (1) 的解；若解唯一则全序列收敛。若 (19) 以 C = R(x†) 成立，则 R(x̂^δ) → R(x†)（式 (21)）；若 R 是满足 Kadets-Klee 性质的空间上的范数且 T_X 为弱拓扑，甚至得到（子列）范数收敛。Corollary 2.6 把结论落到 x^δ_Mo 与按 (6)(7) 选 ρ 的 x^δ_ρ（附加 (vi) 时含 (8)）。

**5. 收敛率（Theorem 2.8, Corollary 2.9）。** 在变分 source condition (23) 与 Assumption 2.7 下，D_ξ†(x̂^δ, x†) ≤ [1/(1−β)]·φ(C_S(τ+1)δ)。Remark 3 给出更一般的形式：对更一般的误差泛函 E，在 (28) E(x̃,x†) ≤ φ(S(F(x̃),F(x†)))（在 R(x̃) ≤ R(x†) 的受限集合上）下直接得到 **E(x̂^δ, x†) ≤ φ(C_S(τ+1)δ)**——这一形式不涉及 R 的次梯度，作者指出这特别适合 R 为 L¹ 或 L^∞ 范数（凸但不严格凸）的情形。

**6. 三个 PDE 参数辨识问题的定量结果。**
- **源项（Prop 3.1）**：X = L^q(Ω) 中的弱收敛（q = ∞ 时为弱*收敛）到 x† = −Δy，对 x^δ_Mo 与按 (6)(7)(8) 选 ρ 的 x^δ_ρ 均成立。速率：**‖x̂^δ − x†‖_{W^{-1,p}(Ω)} = O(√δ)**；**‖x̂^δ − x†‖_{BV(Ω)*} = O(δ^{(1−d/p−ε)/2})**，对任意 p > d、ε ∈ (0, 1 − d/p]，对应 φ(t) = C√t 与 φ(t) = C_ε t^{(1−d/p−ε)/2}。
- **势（Prop 3.2）**：X = L^∞(Ω) 中弱*子列收敛到 x†；在附加 f ∈ L^p(Ω)、g ∈ W^{2−1/p,p}(∂Ω) 且满足条件 (35)（u† ≥ u > 0，u† ∈ W^{1,q}，q 按 p* 与 d 的关系取 p* / (d,∞] / d）或 (36)（u† ∈ W^{1,p*} ∩ C(Ω)）时，速率同上：**W^{-1,p}: O(√δ)**，**BV*: O(δ^{(1−d/p−ε)/2})**。
- **扩散系数（Prop 3.6）**：X = BV(Ω) 中弱*子列收敛到 x†。在一维 Ω = (0,ℓ) 且满足 (48)（(u†)′ 有界远离零、1/(u†)′ ∈ C^{1−s}）时：**‖x̂^δ − x†‖_{W^{−σ,p}(Ω)} = O(δ^σ)**，σ ∈ [0, 1/p − 1)。此处常数 C = ‖a†‖_{BV}·‖1/(u†)′‖_{C^{1−s}}。

**7. 结论性论断（第 4 节）。** 论文主张："通过施加边界来正则化可以成为 Tikhonov 式'加惩罚项'正则化的一个有吸引力的替代方案"，且用适当的约束极小化算法可以实现非常高效的实现。

**方法**：Ivanov/Morozov 约束变分正则化的 Banach 空间收敛理论（含 PDE 参数辨识）

**原理**：在一般 Banach 空间统一建立 Ivanov（拟解法）与 Morozov（残差法）的良定性、收敛与收敛率：给出无限维反例严格证明二者与 Tikhonov 不等价（非凸性下失效），三种无需先验 R(x†) 的 discrepancy 型 ρ 选择规则均可保持收敛率；落到椭圆 PDE 源项/势/扩散系数辨识，速率以 W^{-1,p} 与 BV* 范数表述。

**参数表**：

| 参数 | 数值 | 出处 |
| --- | --- | --- |
| 源项/势辨识速率 | W^{-1,p}: O(√δ)；BV*: O(δ^{(1−d/p−ε)/2}) | 主要发现 |
| 扩散系数辨识速率 | 一维 W^{−σ,p}: O(δ^σ)，σ ∈ [0, 1/p−1) | 主要发现 |
