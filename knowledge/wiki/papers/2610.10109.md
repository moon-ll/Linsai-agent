## 阅读笔记

### general-floquet-20261107

**标题**：Gentle Floquet control of orbital Hall effect and orbital inverse Faraday effect
**作者**：Pei-Han Lin, Roderich Moessner, Egor I. Kiselev（cond-mat.mes-hall，v1 2026-10-07，v2 2026-10-08）

### 研究问题
能否在不增大驱动场强的前提下，通过选择"相空间受限"的体系，把共振 Floquet 驱动对轨道响应的相对影响放大？论文给出肯定答案并量化：关键判据是驱动强度只需与相空间宽度 ħΔk 相比（而非与 k0 或带宽相比），比值 eE0/(Ω0ħΔk) 即使在中等场强下也可观。

### 研究背景
Floquet 工程通常需接近微观电场才能重整电子能量：1 eV/1 Å 对应 E0 ~ 10^10 V/m；而 Floquet 拓扑绝缘体在 10^7–10^8 V/m 已可观测。作者提出绕过途径——若输运响应只由布里渊区中很小的"热区"主导，则驱动无需改动整个能带，只改动受约束的那一小块动量区域。轨道霍尔效应正属此类（常由相空间约束或局域强轨道 Berry 曲率主导），故特别适合相空间选择性 Floquet 工程；此前已有工作提出 Floquet 调控轨道霍尔效应的设想，但微观假设不同。轨道ronics/轨道 Edelstein 效应不需强 SOC，在 Cr、Si 等轻金属中也可显著。

### 研究方法
采用径向-切向（radial–tangential）两带模型（p_x、p_y 双轨道，C4 对称格点，m_ℓ = ±1）：色散 ε_±(k) = (1/m1 ± 1/m2)k²/2，聚焦 m2 > m1 > 0。零温冻结占据，Pauli 阻塞把带间相干限制在两条同心费米面之间的环带 k_F+ < k < k_F-，宽度 Δk = k_F- - k_F+。用 Peierls 替换构造 Floquet 哈密顿量（对 A0 保留一阶），一光子共振位置 k0 = m2Ω0/2，Floquet 准能 E_±(k) = ε_±(k) ± Ω0 ± Δ(k)/2；用量子几何张量（Fubini–Study 度规 g_ij = Re Q_ij，两带同度规，g_xx+g_yy = |Ω_+-|²）表达共振杂化；输运用密度矩阵的量子玻尔兹曼方程（碰撞无耗极限），并引入唯象弛豫时间 τ_f,0 正则化纵向响应。

### 主要发现与核心结论
(1) 未驱动本征轨道霍尔电导 σ^H_{L_z,(0)} = (m2 e²/4m1)·ln[(m2+m1)/(m2-m1)]，m1 ≈ m2 时趋于 e/(2ħ)；其值本身正比于相空间占比 Δk/k0（窄环带时 ln(k_F-/k_F+) ≈ Δk/k0），故对 q_A/Δk 尺度上的驱动格外敏感。(2) Floquet 能隙 Δ(k) = sqrt[(k-k0)²Ω0² + (2keA0/m2)²]，一阶 Floquet 混合由带间量子度规 g 决定。(3) 弱驱动下轨道霍尔电导相对变化 Δσ^H/σ^H_{(0)} ≈ -3q_A/(2Δk)，q_A = eA0/ħ；q_A ≈ Δk 即给出 O(1) 相对改变而 q_A/k0 ≪ 1（能带几乎未被扰动）。(4) m2 = 6m1 时，η = 0.60/0.70/0.80 三条曲线在 q_A/Δk = 3.42、2.67、2.33 处过零；取 ħΩ0 = 0.2 eV、Δk = 0.01 Å^-1，对应 E0 = 6.8×10^7、5.3×10^7、4.7×10^7 V/m（横轴 1 单位 = 2.0×10^7 V/m），与文献中 191 meV 光子、4.0×10^7 V/m 峰值场可比。(5) 逆轨道 Faraday 效应：m = μ_B χ_IFE E0² + O(E0³)，χ_IFE = (e²μ_B/4Ω0²)·[ln((k0²-k_F+²)/(k_F-²-k0²)) / ln((k_F-²-k_F+²)/k0²)]，随光学螺旋度反号；χ_IFE 随 η 增大下降并在 η = 0.410 处变号，k0 靠近任一费米面时出现对数发散（渐近展开失效，但精确积分保持有限）。

### 潜在研究方向
理论尚未纳入无序、有限温度、加热与散射（实验中必然存在），也未考虑 Floquet 带间占据重分布（计算中用冻结平衡占据）。作者指出"相空间约束放大 Floquet 效应"可推广到费米面更复杂、只要 Pauli 阻塞把带间相干限制在窄动量区的材料，但多带会引入额外共振并改变轨道纹理与量子几何；具有强轨道 Berry 曲率的热区也可能产生类似增强。应用方向：全光轨道流开关与阀。
