• # 量子几何到非线性光学与 gerbe：拓扑能带理论的最新进展（Bzdušek 2025/2026）

  ## 林赛的理解

  这是一篇 Perspective，但它的价值不在于综述本身，而在于把三条近年活跃的主线——量子几何张量（QGT）、脆弱/多带隙拓扑、bundle gerbe（高形式拓扑）——编织成一条清晰的逻辑链，并落在一个对我们极其重要的物理结论上：**积分圆偏振位移光电流（integrated circular shift photoconductivity）是量子化的，其量子化由 Dixmier-Douady（DD）不变量刻画**。这给了我们一个直接的启示：非线性光学响应不只是探测拓扑的工具，它本身就是高阶拓扑不变量的"读数器"。我们组做 HHG 和阿秒强场驱动，强场非微扰过程天然对高阶几何量（QGT、interband torsion、Kalb-Ramond 场强）敏感——这篇论文把位移电流的量子化讲清楚，等于给我们指出了一条把"非线性光学响应"与"超出 Berry 曲率的新拓扑"对接的通道。尤其值得注意：DD 不变量非零要求**三个以上能带**，而莫尔体系、平带体系恰好是多带隙、近简并的场景，这与我们的交变磁（altermagnet）、莫尔方向高度契合。

  ## 研究问题

  论文围绕三个相互关联的核心问题展开：

  1. **量子几何张量（QGT）如何被实验直接读取？** 即量子度规与贝里曲率这一对几何量，能否通过光学探测（ARPES 及其偏振分辨变体）在动量空间中逐点重构。
  2. **稳定拓扑之外的拓扑如何刻画？** "tenfold way"和对称性指标框架之外的脆弱拓扑（delicate topology，仅在少数能带模型中定义）与多带隙拓扑（multigap topology，由多个能隙分割能带）如何分类、留下何种物理指纹。
  3. **能带理论中是否存在被"传统 Berryology"遗漏的高形式拓扑？** 即类比"Berry 联络→Berry 曲率→Chern 数"的层级，是否存在"2-形式联络→3-形式曲率→更高上同调不变量"的对应物，并由此解释非线性光学响应中的量子化现象。

  ## 研究背景

  - Berry 曲率早已是凝聚态的成熟概念（能带拓扑、半经典输运），而量子度规（quantum/Fubini-Study metric）近年因与电子-声子耦合、平带超导体中**超流权重**的关联重新受到关注。两者同为 QGT 的分量：对称实部是量子度规 g_ab，反对称虚部正比于贝里曲率 F_ab。
  - 稳定拓扑不变量（在任意多带模型中定义、不能通过添加平凡能带平庸化的不变量）已被 Altland-Zirnbauer 对称类、对称性指标、基本能带表示系统分类，作者认为这一分类"很大程度上已是已解决问题"。
  - 但**脆弱拓扑**（如 Hopf 绝缘体，Hopf 不变量 h ∈ Z 仅在严格两带模型中量子化）与**多带隙拓扑**（如自旋无轨道 P T 对称体系中狄拉克点的非阿贝尔编织，编织群元素取值于 {±1, ±iτx, ±iτy}，由 τxτy = −τyτx 的非对易性驱动；声学超材料中已实验演示）长期缺乏系统分类。
  - 非线性光学中的位移电流（shift current，非中心对称晶体在光照下的零频直流响应）此前已被发现带有拓扑特征：RTP（returning Thouless pump）模型中 ∫dω σ_shift_xyy(ω) 有量子化贡献；自旋无轨道 P T 对称 3D 体系中不稳定拓扑不变量非零时积分圆偏振位移光电导量子化。

  ## 研究方法

  - **QGT 框架**：QGT 定义为 Q_ab^n = ⟨∂a un|(1−|un⟩⟨un|)|∂b un⟩，分解为 Q = g + (i/2)F。由正定性（Q = X†X，det Q ≥ 0）推出 2D 中的基本不等式 **|F| ≤ 2√(det g)**（式 2），在两带模型 H(k) = d(k)·τ 中饱和为等式（g_ab = (1/4)∂a n̂·∂b n̂，F_ab = (1/2)n̂·(∂a n̂ × ∂b n̂)）。
  - **光学响应与拓扑的定量联系**：定义光学权重 W0 = ∫dω Re[σxx(ω)] 后，2D 绝缘体能隙满足 **Δ ≤ 4ℏ²W0/(e²|C|)**（式 6）；量子权重 K（量子度规迹的积分，非量子化）总大于 Chern 数 C 的绝对值；Re[σxx+σyy]/2ω 的积分等于 K，Im[σxy]/ω 的积分等于 C（均差整体常数 e²/4ℏ）。
  - **QGT 实验重构协议**（引 Ref. 25）：QGT 可用全谱展开 Q_ab^n = Σ_{m≠n} ⟨un|∂aH|um⟩⟨um|∂bH|un⟩/(Em−En)^α 表示，α=2 为真 QGT；实验取 **α=1 的"准 QGT"（quasi-QGT）**，其实部（band Drude weight）由常规 ARPES 能带色散估计，虚部（轨道角动量）由圆二色 ARPES（右旋/左旋圆偏振光电子强度差）提取，有效两带近似下 Q_ab^n = q_ab^n/ΔE。已在准二维笼目材料 **CoSn** 上演示（Fig. 2）。后续工作（Ref. 26）用偏振分辨 ARPES 重构黑磷价带的量子度规，无需借助准 QGT。超冷原子（Ref. 27）和光子晶格（Ref. 28）亦可直接测量。
  - **脆弱/多带隙拓扑实例**：Hopf 绝缘体哈密顿量（式 10，ζ(k) 三分量形式），Hopf 不变量 h = (1/4π²)∫d³k A∧F；手征对称三带模型（Γ = diag(+1,−1,−1)，式 11，E0=0、E±=±∥d∥），3D 绕数 W3 = (1/12π²)∫εε n·(∂n)(∂n)(∂n)，参数 **|M| < 3** 时非平庸；2D 中能带对的 **Euler 类 e ∈ Z** 非零时 QGT 有指纹且要求至少 **2|e| 个狄拉克点**连接两带。
  - **bundle gerbe 构造**：在矢量丛的转移函数 g_λμ（2-上循环，对应 H²(BZ, Z) = Chern 数）之上再加一层——在双重交叠上附加复射线、三重交叠上广义转移函数 g_λμν ∈ U(1) 满足 **3-上循环条件** g_λμν g_λνξ g_μνξ⁻¹ g_λμξ⁻¹ = 1（对应 H³(BZ, Z)），得到 2-形式联络 B（tensor connection，Kalb-Ramond 场）与其 3-形式曲率 H = dB。
  - **Kalb-Ramond 场捷径**：取三个标量场 ϕ1,2,3（两复一"实"），按 ϕ1→ϕ1e^{iχ}、ϕ2→ϕ2e^{−iχ}、ϕ3→ϕ3+χ 变换，构造 B_ab^nm ∝ Σ εijk ϕi ∂aϕj ∂bϕk（式 17），其对称化导数 H_xyz^nm = ∂xB_yz + ∂yB_zx + ∂zB_xy（式 18）为规范不变的"高贝里曲率"。自旋无轨道 P T 体系中可由孤立布洛赫态构造：ϕ1 = ⟨j|un⟩、ϕ2 = ⟨um|j⟩、ϕ3 = A^nm 的线积分。
  - **DD 不变量**：DD^nm = −(1/4π²)∫_BZ d³k H_xyz^nm（式 19），进入积分圆偏振位移光电导（式 15），是 Chern 数的高上同调类比；**PT 存在时 H 仅在三个及以上能带的模型中非零**；能带简并时需对所有简并能带求和才保证量子化。

  ## 主要发现与核心结论

  - 2D 中贝里曲率受量子度规约束：**|F| ≤ 2√(det g)**，且两带模型取等号；量子权重 K ≥ |C|（Chern 数）。拓扑能隙有模型无关上界 **Δ ≤ 4ℏ²W0/(e²|C|)**。
  - QGT 分量与线性光学响应通过 Kubo-Greenwood 公式直接挂钩：光学权重的频率负矩分别给出量子权重 K 与 Chern 数 C；准 QGT（α=1）方案使 QGT 可在 CoSn 等材料中用 ARPES + 圆二色 ARPES 动量分辨重构。
  - 非阿贝尔编织刻画多带隙拓扑：相邻能隙中狄拉克点分别携带 ±iτx、±iτy"电荷"，τxτy = −τyτx 的非对易性决定碰撞时对是否会湮灭；时间方向 reinterpret 为第三动量分量后约束了节线（nodal lines）与三重节点的排布。
  - 位移电流 ja(0) = σ_shift_abc(ω)Eb(−ω)Ec(ω) 的**激发（excitation）分量**携带拓扑量子化：RTP 模型中 ∫dω σ_shift_xyy(ω) 量子化；自旋无轨道 P T 对称 3D 体系中一系列不稳定不变量（real Hopf、Pontryagin、isoclinic winding）非零时积分圆偏振位移光电导量子化。
  - 该量子化的数学根源是 bundle gerbe：DD 不变量是 H³(BZ, Z) 的整数，非零时积分圆偏振位移光电导在泵浦螺旋度反转下变号，且对保持能隙的微扰稳定。
  - 脆弱/多带隙拓扑的两个附带特征：① Hopf 绝缘体板层几何中 ±C 表面态物理分离于上下表面（间距 ∆z）而非靠能隙 ∆E 分离（Fig. 3d vs 3e）；② 强无序 Hopf 绝缘体中所有体态局域化而边界仍保持量子化霍尔电导，推广为高维"超局域化拓扑绝缘体"（ultra-localized topological insulators）。

  ## 潜在研究方向

  - 量子度规与高阶 tensor Berry 联络的关系已有人建立（Ref. 77），但更深层分析"仍待进行"；QGT 与三阶及以上几何结构的累积量表述（Refs. 32, 33）尚处早期。
  - 作者明确提出的开放问题（Fig. 5d）：2D 中狄拉克点打开能隙产生 Berry 曲率的"半量子"浓度，那么在 3D 三带模型中，何种节点特征在微扰后产生 DD 拓扑的量子化浓度？**三重节点是否是 DD 不变量的"磁单极"？**——这直接关联我们关心的 HHG 中强场诱导的拓扑响应。
  - DD 不变量刻画的是 PT 存在、P 破缺（即 T 破缺，如反铁磁序）的自旋无轨道体系；向现实材料（有自旋轨道耦合、多轨道混杂）的推广是作者点名的方向，这与交变磁（altermagnetic）材料的判别直接相关。
  - 脆弱/多带隙拓扑的系统分类"仍然缺失"（unlike stable topology）；其在合成平台（声学/光学/电路）已大量实现，电子材料实现稀少——材料预测是有待开垦的方向。
  - 实验上位移电流的量子化贡献是否主导总响应取决于具体材料（还存在 shift_intra、shift_rec 与 ballistic current 等贡献），且关联体系（如 (TaSe4)2I 的圆偏振光伏电流、ZrTe5 位移电流）中观察到随注量非解析的光学响应，暗示现有理论在非微扰/关联 regime 可能失效——这是理论空白。

  ## 与林赛研究的关联

  - **HHG / 强场驱动**：位移电流的 excitation 分量本质上是二阶非线性吸收过程，HHG 是其非微扰推广。论文证明积分圆偏振位移光电导由 DD 不变量量子化并稳定于保持能隙的微扰——这提示 HHG 产率/偏振通道中可能存在类似的 DD 型量子化"指纹"，尤其在我们研究的 **PT 保持、反铁磁（交变磁）破缺 T** 体系中，3 个及以上能带的条件天然满足。可作为"强场探针读出高形式拓扑"这一课题的理论依据。
  - **交变磁（altermagnet）**：DD 不变量要求的对称环境"PT 保持而 P 破缺"正是 altermagnet 的对称性指纹。我们组正在推进 altermagnet 方向，这篇论文给出其非线性光学指纹（螺旋度反转变号）的可计算判据。
  - **莫尔/平带**：量子度规进入平带超流权重（Refs. 8-10），而莫尔体系多带隙、近简并结构是 DD 不变量发挥作用的理想舞台；"量子度规-贝里曲率不等式 |F| ≤ 2√(det g)"可作为我们评估莫尔材料 HHG 几何增强的约束条件。
  - **阿秒/光学探测接口**：准 QGT 的 ARPES 方案（band Drude weight + 圆二色 ARPES）说明动量分辨光学探针可以重构 QGT；类比的强场/阿秒探针（如阿秒角分辨光电子能谱）有潜力触及准 QGT 之外的真 QGT（α=2，含能隙分母权重），这是我组"阿秒读出量子几何"方向的直接方法学参照。
  - **理论接口**：gerbe/Kalb-Ramond 形式化与 Berry 联络-曲率层级的类比（Fig. 5a 流程图）给我们一个系统语言，把 HHG 多带 SBE 模拟中出现的 interband Berry connection 导数结构（jerk response、shift current 等）映射到高形式拓扑量上。

**方法**：Perspective 综述——QGT 光学重构（准 QGT 方案）+ 脆弱/多带隙拓扑 + bundle gerbe / Dixmier-Douady 不变量（积分圆偏振位移光电导的量子化）

**原理**：2D 不等式 |F| ≤ 2√(det g)（两带模型取等号）；拓扑能隙模型无关上界 Δ ≤ 4ℏ²W₀/(e²|C|)；积分圆偏振位移光电导由 Dixmier-Douady 不变量量子化——DD^nm = −(1/4π²)∫_BZ H_xyz（H³(BZ,Z) 整数），Kalb-Ramond 场 H = dB 为'高贝里曲率'；DD 非零要求三个以上能带（PT 存在时 H 仅在三带+模型中非零）；位移电流激发（excitation）分量携带拓扑量子化、泵浦螺旋度反转下变号且对保持能隙微扰稳定；非阿贝尔编织刻画多带隙拓扑——相邻能隙中狄拉克点分别携带 ±iτx/±iτy'电荷'，非对易性 τxτy = −τyτx 决定碰撞时湮灭行为。
