• # Single Spatio-Temporal Mode Bright Twin-Beam Source Across the Near- and Mid-Infrared — 深度研究笔记

  ## 林赛的理解

  这篇工作对我最核心的价值在于：它第一次系统性地证明了**明亮的压缩真空（bright twin beams）可以在近变换极限泵浦下保持单空间-时间模式（K≈1），并且这个模式纯度可以用泵浦脉冲宽度（GDD）这一个旋钮连续调节**。这直接打通了"量子光驱动强场过程"这条线的实验闭环——我们组一直在关注 BSV 驱动 HHG 中光子统计如何印刻到强场响应上，此前这类实验都受限于模式数多、有效峰值量子场振幅被稀释的问题。本文给出的定量判据（泵浦时长须匹配相位匹配带宽的倒数 τ_p ~ 1/Δω_PM）是任何想把 BSV 当作强场驱动源的人都必须遵守的设计规范。此外，K→1 保证频率-时间一一映射，意味着可以在时域直接解析纠缠态的时间结构，这对阿秒尺度的量子涨落测量（他们引用的 XUV attosecond 方案）是关键使能条件。

  ## 研究问题

  如何构建一个同时满足**超快（~100 fs）、明亮（近单脉冲 10⁸–10¹⁰ 光子数）、近-中红外强非简并（1.37 µm / 4.0 µm）**且**近单空间-时间模式（K→1）**的双光束纠缠源？并进一步回答：模式纯度能否由泵浦脉宽连续调控？在高增益极限下，信号-闲频之间的纠缠资源如何在"模式（第一量子化）"与"占据数（第二量子化）"两类自由度之间分配？

  中心论点：泵浦脉冲时长是模式纯度的确定性控制参数——单模运行要求泵浦时长匹配相位匹配带宽的倒数；通过 GDD 拉伸泵浦可在单模与受控多模之间连续过渡；近单模（K≃1）使约 95–97% 的饱和纠缠资源集中于占据数自由度，可被宽带探测直接取用而无需模式分拣。

  ## 研究背景

  - 高增益 PDC 在简并情形下产生**明亮压缩真空（BSV）**，非简并情形产生**明亮双光束（BTB）**；宏观光子数下仍保持非经典关联，可支持亚散粒噪声测量。
  - 模式数的代价：高增益 SPDC 指数型增益会摊薄每个模式的压缩度，且多模态下若要取回全部量子关联必须做实验上困难且损耗大的模式分拣——早期 2500 photons per mode 的亮度纪录必须用只有 3 个模式的光纤源实现。
  - **BSV 作为强场/非线性过程驱动源**是近年热点：微扰谐波产生、固体 HHG、量子调控高次谐波边带发射、纳米结构多光子电子发射中，驱动场的非经典光子统计会印刻到强场响应上；理论预言了修正的截止定律、光子统计力、压缩谐波。反向地，HHG 过程本身也能辐射携带非经典统计（压缩、纠缠）的光，且 BSV 量子关联已被转移到 XUV 阿秒脉冲上，实现对光与物质量子涨落的阿秒分辨测量。单模运行使峰值量子场振幅最大化，对上述两个方向都是关键。
  - 强非简并源的另一动机：**解耦"相互作用波长"与"探测波长"**——闲频落在与分子振动共振的中红外，吸收信息印刻在近红外孪生光上，可用高量子效率、低噪声探测器读取（SU(1,1) 干涉仪、"未被探测光子"传感与成像的底层思想）。
  - 前人 BSV 强场实验多为 1 kHz 重复频率，统计采集慢。

  ## 研究方法

  - **光源**：type-0 SPDC，周期性极化铌酸锂（PPLN）晶体，2 mm 长度，极化周期 27.91 µm，选择该周期产生强非简并输出：信号 1.37 µm、闲频 4.0 µm，脉宽均 ~100 fs。
  - **泵浦**：Yb:KGW 激光器（Light Conversion Pharos），中心波长 1026 nm、脉宽 260 fs、单脉冲能量 5 µJ、重复频率最高 1 MHz（相比此前 1 kHz 的 BSV 实验是重大提升）；经反射型中性密度片衰减后，250 mm 焦距透镜（L1）聚焦入晶体；125 mm（图注中为 150 mm）凹面镜准直。
  - **折叠双晶体几何**：镜 M1 使泵浦二次通过晶体，提高参量增益，并通过抑制强衍射高阶模式的放大来减少空间模式数；PPLN 置于泵浦焦平面在第二次通过的位置。
  - **分光**：双色镜 DM1/DM2 分离泵浦与孪生光并分信号/闲频两臂；本文仅对信号臂做诊断，闲频臂未分析。
  - **两套独立模式诊断**：
    1. 光子数统计：可切换增益 InGaAs 光电二极管（Thorlabs PDA10CS）+ boxcar 积分器（Zurich Instruments UHFLI），逐脉冲记录 2,981,607 个事件，由 g⁽²⁾(0)=⟨N(N−1)⟩/⟨N⟩² 提取模式数（g⁽²⁾(0)=1+1/K 假设各 Schmidt 模为热统计分布）；
    2. 谱协方差：Ocean Optics NIRQuest 光谱仪逐发测量信号谱，重构约化谱密度矩阵 G⁽¹⁾(ω_s, ω_s′)，对其做奇异值（Schmidt）分解提取频率/时间模式数；不确定度由 60 个独立子集的 bootstrap 重采样估计（不含光谱仪入射狭缝空间滤波等系统误差）。
  - **模式调控**：固定泵浦光谱与脉冲能量，用 GDD 扫描改变泵浦脉宽，测量 S_mod^HG 随 GDD 的变化，并与啁啾泵浦理论联合谱振幅的 SVD 计算（单拟合参数：最小熵）对比。
  - **理论框架**：Schmidt 分解 ⟨N_n⟩=sinh²G_n；线性熵分解 S_lin ≃ (K−1)/K |S_eff_mod + 1/K |S_eff_occ（亮极限下饱和至 1）；要求保持在双线性（bilinear） regime（级联 χ⁽²⁾ 弱）。

  ## 主要发现与核心结论

  - **近单模运行的定量确认**：g⁽²⁾ 诊断给出 K_g2 = 1.05±0.03（对应线性模熵 S_mod^g2 = 0.05±0.03），谱 SVD 诊断给出 K_HG = 1.034±0.002（对应 S_mod^HG = 0.034±0.002；结论节记为 0.033±0.002），二者在不确定度内一致；g⁽²⁾ 略高是因为它对空间模敏感，而 G⁽¹⁾ 分析中被光谱仪狭缝滤除。
  - **纠缠资源分配**：按式 (7)，约 **95%（g⁽²⁾ 口径）至 97%（谱口径）** 的饱和双体纠缠资源分配在占据数自由度（occupational sector），即宽带探测无需模式分拣即可全量取用。
  - **亮度与增益标定**：增益 G≃7.6（⟨N_P⟩=4×10¹²）到 G≃14.5（⟨N_P⟩=1.6×10¹³）；实验数据与 sinh² 拟合在 ⟨N_P⟩ ≲ 1.4×10¹³ 内高度吻合，超过该阈值出现饱和（⟨N_S⟩ ≃ 10¹¹ 信号光子/脉冲、单模估计 G≃13.5），归因于泵浦耗尽、饱和效应等寄生过程。
  - **单模窗口宽度**：S_mod^g2 < 0.1 在**近三个数量级亮度范围内**（⟨N_S⟩ 从 ~10⁷ 到 ~10¹⁰ 光子/脉冲）维持，形成"最佳单模操作窗口"。在 ⟨N_S⟩ ≳ 10¹¹ 阴影区，g⁽²⁾↔K 映射失效；接近边界时 S_mod 的适度上升归因于寄生 χ⁽²⁾ 过程（泵浦或信号的 SHG）对 P(N) 高光子数尾的压平，而非真正的模式再占据。
  - **代表性数据点**：⟨N_P⟩=8×10¹² 处（未饱和增益 G∼10.4），测量 ⟨N_S⟩=1.296×10⁸ 光子/脉冲（正文记为 1.3×10⁸）、标准差 σ_NS = 1.265×10⁸，得 g⁽²⁾(0)=1.95±0.03（接近单模热态理论值 2），单发谱呈近完美热（负指数）分布。
  - **泵浦脉宽是确定性调控旋钮**：GDD=0（近变换极限 260 fs）时模纯度最优；随 GDD 增加 K_HG 单调上升，与啁啾泵浦理论 SVD 计算定性一致。物理图像：有效时间增益窗口 τ_eff 因①指数增益压缩（G_0≫1 时 τ_eff ~ τ_p/√G_0，G_0∼10 时窗口可接近相干时间 τ_c~1/Δω_PM）和②泵浦-信号与泵浦-闲频 GVM 反号（信号超前、闲频落后走离，限制三波重叠时间窗）两种机制共同被压缩；加 GDD 同时破坏两种机制，故单模→多模过渡被双重放大。依赖关系对 GDD 非严格对称，高阶色散（含 PPLN 自身）与非线性相移会修正有效相位匹配。
  - **单模的时间结构含义**：K_HG≃1 时每次脉冲填充同一谱形，啁啾可被被动色散元件完全补偿至变换极限，频率-时间一一映射成立；K>1 时各模相对相位随机导致脉冲包络等效于群延迟/GDD 的逐发随机涨落，任何静态补偿器无法消除，频率-时间映射变一对多。
  - **非简并的工程价值**：1.37 µm 信号落在高效低噪声探测波段，4.0 µm 闲频与分子振动指纹重叠，实现"中红外作用、近红外读出"的天然分离。

  ## 潜在研究方向

  - 本文只对信号臂做单臂表征；**中红外闲频臂的直接表征**以及跨越 NIR–MIR 光谱分野的孪生光束关联演示是明确的下一步。
  - 饱和阈值以上（⟨N_P⟩ > 1.4×10¹³）g⁽²⁾ 诊断失效，高阶强度统计而非模式结构主导表观 g⁽²⁾(0)；寄生级联 χ⁽²⁾ 过程（SHG）对统计的污染需要更深入建模与抑制。
  - K_HG 不确定度仅含 bootstrap 统计精度，未含光谱仪空间滤波等系统误差；闲频臂未分析意味着纠缠资源分配的间接性——式 (7) 的分配是从 K 推断而非独立测量（作者自己也强调了这一推断层级）。
  - 亮度纪录早期 2500 photons/mode 用 3 模光纤源实现，本工作在何种 photons/mode 指标上对比、以及增益进一步抬高时双线性 regime 的边界，值得定量核查。
  - 展望方向（作者列出）：非线性干涉测量、量子增强光谱传感、时域量子光学（频率-时间一一映射直接解析纠缠时间结构）；近红外信号臂的光子数条件投影可使中红外闲频落到纯 Fock 态（band-conditioned states），在该波段实现尚未展示过的非高斯量子态工程；受控 K>1 运行则面向多模 CV 复用协议。
  - 对本领域注意点：用此类源驱动强场过程时，必须工作在 ~10⁷–10¹⁰ 光子/脉冲的单模窗口内，否则统计解释会被寄生非线性污染。

  ## 与林赛研究的关联

  - **BSV 驱动 HHG 的直接实验接口**：本文给出 BSV 作为强场驱动源的设计规范（泵浦时长 ~ 1/Δω_PM、双晶体折叠几何、MHz 级重复频率），可直接移植到我们组"量子光驱动固体 HHG / 阿秒脉冲"方向——此前 1 kHz 的 BSV-HHG 实验受统计采集限制，1 MHz 源使逐发统计驱动强场过程成为可行路线。
  - **光子统计印刻强场响应**：K≈1 时 95–97% 纠缠资源在占据数自由度，意味着驱动场的量子涨落以最大峰值场振幅作用于强场相互作用，修正截止定律、光子统计力、压缩谐波等理论预言的实验检验窗口被打开。
  - **阿秒与 XUV 接口**：单模运行保证频率-时间一一映射，是 BSV 量子关联转移到 XUV 阿秒脉冲（attosecond-resolved quantum fluctuation measurement）类实验的使能条件，与我们"阿秒分辨强场动力学"方向直接对接。
  - **中红外强场窗口**：4.0 µm 闲频与分子振动共振、且处于中红外强场相互作用有利波段，"近红外探测、中红外作用"的解耦架构可为量子增强强场光谱（如量子增强 HHG 光谱学）提供新方案。
  - **量子几何/莫尔方向的间接价值**：高增益下模式纯度由泵浦-信号-闲频三波 GVM 匹配决定，这一时空体积放大图像与我们在莫尔体系中超快时空局域化调控的思路同构——晶体中群速度匹配作为"自然模式滤波器"的机制值得在强场驱动+量子光混合平台设计中借鉴。

## 研究方法（方法卡）
<!-- methods-backfill:v1 -->
**方法**：跨电信波段的单时空模亮孪生束源（折叠双 PPLN SPDC + 逐发 g⁽²⁾/谱协方差 Schmidt 双诊断）

**原理**：type-0 SPDC（2 mm PPLN，周期 27.91 µm）产强非简并孪生束（信号 1.37 µm/闲频 4.0 µm，~100 fs）；Yb:KGW 1026 nm/260 fs/5 µJ/最高 1 MHz 泵浦（较此前 1 kHz BSV 重大提升）；折叠双晶体几何：泵浦二次通过晶体提增益并抑制高阶空间模放大；双诊断：① 光子数统计（可切换增益 InGaAs+boxcar，2,981,607 事件，g⁽²⁾(0)=1+1/K 提模式数）；② 谱协方差（逐发光谱重构 G⁽¹⁾ 矩阵 SVD 提频率/时间模式数，bootstrap 60 子集估不确定度）；GDD 扫描调模式数，与啁啾泵浦理论 SVD（单拟合参数最小熵）对比；Schmidt 分解 ⟨N_n⟩=sinh²G_n、线性熵 S_lin≈(K−1)/K|S_eff_mod+1/K|S_eff_occ（亮极限饱和至 1）；保持双线性 regime（级联 χ⁽²⁾ 弱）。
