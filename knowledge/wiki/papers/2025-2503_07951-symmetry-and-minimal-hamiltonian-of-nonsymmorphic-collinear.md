• # Symmetry and Minimal Hamiltonian of Nonsymmorphic Collinear Antiferromagnet MnTe

  ## 林赛的理解

  这篇工作对我来说是一份"对称性账本"：Takahashi、Huang、Yu、Zang 四人把 α-MnTe 的两个价带顶（Γ 点和 A 点）的低能物理拆成了最小 k·p 哈密顿量，并且明确回答了一个对强场和自旋电子学都关键的问题——MnTe 的大自旋劈裂到底是谁的功劳。他们的答案非常直接：虽然 MnTe 常被当作 altermagnet 的范例，但在 Γ 点主导致输运的自旋劈裂**不是**非相对论性的 d/g/i-wave 机制，而是 Te 5p 轨道强 SOC（0.5 eV）的一阶微扰结果；无 SOC 时沿任意方向都是自旋简并的，"从输运意义上 MnTe 甚至不算狭义的 altermagnet"。这个澄清对我们做 MnTe 的强场超快光学至关重要：我们探测到的动量分辨自旋纹理、AHE 与非常规输运，其哈密顿量载体是价带的 p_z（Γ 点）和 p_x/p_y（A 点）子空间，模型参数他们已用 DFT + Wannier90 全部拟合出来，可以直接拿去算跃迁偶极矩、光电离矩阵元和阿秒级退相位过程，而不必自己从头重建。

  ## 研究问题

  论文要回答的核心问题是：α-MnTe 这一非对称（nonsymmorphic）共线反铁磁体在费米能级附近（Γ 点和 A 点价带顶）的**最小有效哈密顿量是什么**，以及由此产生几个必须厘清的问题：

  - 在布里渊区两个不同的价带顶区域（Γ 点，由 p_z 轨道主导；A 点，由 p_x/p_y 轨道主导），电子结构与输运如何定性不同？
  - 面内 Néel 矢量沿两个不等价方向 [11̄20]（x）和 [1̄100]（y）时，对称性和能带有何差异？
  - SOC 在 altermagnet 的自旋劈裂中究竟扮演什么角色——是可有可无的相对论修正，还是主导机制？

  ## 研究背景

  共线反铁磁体因满足 t₁/₂T 或 PT 组合对称性而长期被认为输运平庸（无内禀反常霍尔效应、无自旋转移矩）。Altermagnet 作为新型反铁磁体变体，具有零净磁化但破缺 t₁/₂T / PT 对称性，可同时兼得铁磁式自旋劈裂输运（内禀 AHE、自旋劈裂矩、TMR）与反铁磁式的磁稳定性、太赫兹级超快自旋动力学。传统观点认为 altermagnet 的自旋劈裂（d/g/i-wave 型）由非相对论的自旋群对称性唯一决定，SOC 不重要；但 SOC 在其他反铁磁体中对拓扑非平庸能带与 Néel 矢量探测/操控至关重要，且磁各向异性会改变原有的非相对论对称性，因此仅靠非相对论对称性分析不足以描述能带自旋劈裂的全貌。

  α-MnTe（NiAs 结构，空间群 P6₃/mmc，No. 194）兼具 altermagnetic 特征（破缺 t₁/₂T / PT）和源自 Te 原子的强 SOC，近年观测到大自旋劈裂、Kramers 简并解除、可控磁各向异性、大各向异性磁电阻与平面霍尔效应、内禀反常霍尔效应等，但这些自旋电子学现象与物理机制之间的联系不清楚——根本原因在于其布里渊区中 Γ 点与 A 点的价带行为截然不同且都紧贴 VBM，输运性质随条件完全不同。

  ## 研究方法

  - **第一性原理计算**：DFT + PAW 赝势（VASP），GGA-PBE 交换关联泛函；Mn(3d) 轨道采用 Liechtenstein 实现的双 Hubbard 参数 U = 4.0 eV、J = 0.9 eV；平面波截断能 600 eV；Γ 中心 12 × 12 × 8 k 网格；实验晶格常数 a = 4.171 Å、c = 6.686 Å；Néel 矢量沿 x、y 方向时包含 SOC。
  - **Wannier 紧束缚模型**：用 band disentanglement 方法将平面波基变换到局域 Wannier 函数基（Wannier90），仅投影 Te(5p) 轨道；验证 WF 哈密顿量在费米能级以下 0.5 eV 至 VBM 范围内与 DFT 本征值完全一致，确认 Mn 电子远离费米能级、只需考虑 Te p 轨道。
  - **群表示论**：对空间群、自旋群、磁群（商群 G/T ≅ D6h；无 SOC 反铁磁态自旋点群 26/m2m1m；Néel 矢量沿 x 时磁空间群退化为普通 Fedorov 群；沿 y 时为磁点群 m′m′m）构造不可约表示，利用"哈密顿量不变性 D(g)h(g⁻¹k)D⁻¹(g) = h(k)"只对小群生成元构造有效哈密顿量 h(k) = Σᵢ hᵢ fᵢ(k)。
  - **解析紧束缚 + Schrieffer-Wolff 变换**：H_k = H_Te-Te + H_Te-Mn + H_Mn-Mn + H_SOC；Te-Te 跳迁取至第三近邻（Slater-Koster 规则），Mn 只保留 d_z² 轨道（三重晶体场分裂下 dxz/dyz、dx²-y²/dxy 简并，d_z² 非简并），先对 d_z² 做 Schrieffer-Wolff 积分得到 p 电子有效哈密顿量，再对色散的 p 轨道做带矩阵形式 H′ᵏ 的第二次 Schrieffer-Wolff 展开（需保留高阶项以得到正确对称性）。
  - **参数拟合**：共轭梯度法，对 Γ 或 A 点周围布里渊区椭球区域内的 DFT 能带拟合全部系数；SOC 部分采用 kx → (1/a)sin(kx a)、ky → (1/a)sin(ky a) 变换；对不同 Néel 矢量分别拟合非 SOC 部分系数。

  ## 主要发现与核心结论

  **结构与基本电子结构**：α-MnTe 为 NiAs 型结构，A 型共线反铁磁序由 Mn 层间反平行磁矩构成，Néel 温度 TN ≈ 310 K，面内磁各向异性极小（< 0.05 meV/单胞），Néel 矢量可近似等概率取 [11̄20] 或 [1̄100] 方向。DFT 带隙约 0.7 eV，呈半导体性。

  **非 SOC 顺磁态**：Γ 点 VBM 由 p_z 轨道主导，A/B 赝自旋（σ）下生成元表示为 {3⁻₀₀₀₁|0} = σ₀、{2₀₀₀₁|1/2} = σ_x、{2₁₁̄₂₀|0} = −σ_x、I = −σ_x；σ_x 本征值 ±1 对应 S/A 对称化态，四重简并解除为二重自旋简并。A 点小群仍为 D6h，但非对称分数平移因子 e^(-ik·R′) 起作用，DOS 由 p_x/p_y 主导；A 点只有恒等表示 σ₀τ₀s₀，顺磁态下 8 条能带全部简并。

  **非 SOC 反铁磁态**：自旋点群 26/m2m1m ≅ D6h。Γ 点最小哈密顿量建于 |S↑⟩、|S↓⟩ 反键态二维子空间，HΓ_non-SOC = c₁(kₓ²+k_y²) + c₂k_z² + c₃(kₓ²+k_y²)² + c₄[4(kₓ²−k_y²)³ − 3(kₓ²−k_y²)(kₓ²+k_y²)²]，其中 c₄ 项即球坐标下 k⁶sin⁶θcos6ϕ，描述 Γ−K/M 线上非二次、非单调的能带（费米面可能切在远离 Γ 处）；这是**无自旋**哈密顿量，沿任意方向自旋简并——若把 altermagnet 狭义定义为无 SOC 的自旋劈裂，MnTe 从输运角度（Γ 点主导时）并不算 altermagnet。A 点最小哈密顿量 HA_non-SOC = c₁(kₓ²+k_y²) + c₂k_z² + c₃[(kₓ²−k_y²)τz + 2kₓk_yτx] + c₄ωz(k_yk_zτz + kₓk_zτx)，用新赝自旋 ω 标记 |S↑⟩ 与 |A↓⟩ 的二重简并（源于沿 [0001] 交替 Mn 自旋导致的子晶格-自旋混合）；A−Γ 线无劈裂，A−L₃、A−H₁ 线出现 p_x/p_y 劈裂但无自旋劈裂；体相 g-wave 自旋劈裂只出现在低对称区、且不显著推高能带位置，对输运影响不大。

  **SOC + Néel 沿 [11̄20]（x）**：此时 I 保持、C₃/C₆ 破缺，Γ 与 A 点小群均为 D2h ≅ D2 ⊗ Z2；关键结果是**没有任何组合包含时间反演 T**（磁空间群与 Fedorov 空间群相同），因此无磁场无净磁化下天然产生霍尔效应。Γ 点有效哈密顿量 HΓ_[11̄20] = HΓ_non-SOC + γ₁kₓk_y s_z + (δ₁kₓ³k_y + δ₂k_y³kₓ)s_z，价带在 II/IV 象限沿 +ẑ、I/III 象限沿 −ẑ 极化，形成四个镜像对称的空穴口袋，强各向异性；紧束缚表明 γ₁ 是 SOC **一阶**修正，Te 的 0.5 eV 大 SOC 解释了 Γ 点附近的大自旋劈裂。拟合参数：c₁/a² = 0.0306 eV、c₂/c₂ = −0.492 eV、c₃/a⁴ = −0.0497 eV、c₄/a⁶ = 0.0047 eV、γ₁/a² = 0.353 eV、δ₁/a⁴ = −0.381 eV、δ₂/a⁴ = 0.0870 eV。A 点出现 SOC 项打开的 p_x/p_y 能隙 2γ₀，但它是 SOC 二阶项，DFT 给出仅 3 meV，可忽略；拟合参数：c₁/a² = 1.089 eV、c₂/c₂ = −0.129 eV、c₃/a² = −0.615 eV、c₄/a² = −0.0035 eV、γ₀ = 0.0013 eV、γ₁/a² = −0.111 eV、γ₂/a² = 0.0141 eV、γ₃/a² = 0.0670 eV、γ₄/a² = 0.232 eV、γ₅/a² = 0.0070 eV。

  **SOC + Néel 沿 [1̄100]（y）**：磁点群变为 m′m′m = C2h ⊕ T(D2h − C2h)，生成元含 {2₁₁̄₂₀|0}T，哈密顿量不变性条件变为 D(g₀T)H*(−g₀⁻¹k)D⁻¹(g₀T) = H(k)（含复共轭）。Γ 点 SOC 项为 γ′₁(kₓ² − λ₁k_y²)s_z 型（含四次修正项），自旋仍沿 ±ẑ 极化。紧束缚给出 γ₁ = 2γ′₁、λ₁ = 1，即相对于 [11̄20] 情形能带旋转 π/4；但两组态群对称性不同，DFT 拟合给出 λ₁ = 1.31、λ₂ = 6.15（λ₁ ≠ 1、λ₂ ≠ λ₁），说明零自旋劈裂简并线不是直线 kₓ = ±k_y 而是沿 kₓ = 0、k_y = 0 镜像的弧线。拟合参数：c₁/a² = 0.0178 eV、c₂/c₂ = −0.513 eV、c₃/a⁴ = −0.0480 eV、c₄/a⁶ = 0.0045 eV、γ′₁/a² = 0.153 eV、δ′₁/a⁴ = 0.0571 eV、δ′₂/a⁴ = 0.0273 eV。A 点 γ₀ = γ′₀ 被紧束缚与 DFT 双重确认，γ₄ ≈ γ′₄ 表明 A 点 SOC 部分也近似服从 π/4 旋转；一阶系数 γ₂/γ′₂、γ₃/γ′₃ 与二阶 γ₅/γ′₅ 决定偏离 C₃ 的各向异性色散，其量级比 Γ 点对应系数小至少一个数量级，DFT 能带与拟合均显示仅 meV 量级的微小各向异性。

  **费米口袋**：MnTe 的 VBM 位于 Γ 还是 A 点极难判定——其相对能量差对应变、杂质、温度等外部环境高度敏感，计算位置也对交换关联泛函敏感。VBM 在 Γ 时，[11̄20] 与 [1̄100] 两种 Néel 方向下费米面形状显著不同（[11̄20] 情形有四个 VBM k 点）。

  **核心结论**：MnTe 在 Γ 与 A 点展现出定性不同的输运特征与 Néel 矢量取向依赖性；尽管普遍认为 SOC 对 altermagnet 不重要，本工作证明 SOC 在 MnTe 的价电子自旋劈裂中起主导作用（Γ 点大劈裂来自 Te 0.5 eV SOC 的一阶效应），为 altermagnet 输运研究建立了模型平台。

  ## 潜在研究方向

  - VBM 在 Γ 点与 A 点之间的归属对外部环境（应变、杂质、温度）和交换关联泛函敏感，实际样品中可能两者竞争，输运的解释需明确 VBM 位置前提。
  - A 点的 p_x/p_y 能隙仅 3 meV（SOC 二阶），高于二阶的项被略去；g-wave 体相自旋劈裂若要在更大能量尺度显现，需引入更高阶项，本模型未覆盖。
  - 高阶 k 修正（如 c₄）在 Γ−K/M 线上不依赖 Γ 点不可约表示，其对称性约束体系在远离高对称点的区域尚不完整。
  - 自洽场计算下不同 Néel 矢量的非 SOC 势略有差异，模型需分方向拟合，提示真实体系中磁序-电子结构反馈不可忽视。
  - 费米口袋与自旋纹理的实验验证（ARPES、输运）仍需在受控应变的单晶上完成；理论模型仅覆盖 Te(5p) 子空间，Mn d 电子若能级条件变化（如掺杂、压力）可能改变最小模型的适用性。

  ## 与林赛研究的关联

  - **强场驱动与 HHG**：本文给出的 Γ/A 点最小哈密顿量（含 SOC、含两套 Néel 方向的全部拟合系数）是计算 MnTe 强场激发、带间跃迁偶极矩与非线性光电流的直接输入。MnTe 是我们 moiré/强场 HHG 候选体系之一，0.7 eV 带隙处于中红外-太赫兹驱动可达范围，价带顶的 p_z/p_x/p_y 轨道成分决定了跃迁选择定则。
  - **交变磁与 Néel 矢量超快读出的理论接口**：本文澄清了 MnTe 的自旋劈裂由 SOC 主导而非非相对论 altermagnetic 机制，这对我们"交变磁序参量超快读出"课题是关键校正——光致自旋流与 THz 发射的理论预期必须建立在含 SOC 的 HΓ_[11̄20] / HΓ_[1̄100] 上，且 Néel 矢量在 [11̄20] 与 [1̄100] 之间的超快翻转会以 π/4 旋转的方式改写费米口袋与自旋纹理，可作为阿秒/飞秒时间分辨的光学指纹。
  - **莫尔与量子几何的延伸**：非对称空间群的分数平移相位 e^(-ik·R′) 在 A 点导致的子晶格-自旋混合（ω 赝自旋）提示，若将 MnTe 制成莫尔异质结构，moiré 折叠会进一步混合 Γ 与 A 谷，量子几何（Berry 曲率、量子度规）在 SOC 主导的自旋劈裂背景下的分布值得用此模型做 k·p 层级计算。
  - **阿秒退相位与自旋-动量锁定**：Γ 点 II/IV 与 I/III 象限相反的 ẑ 自旋极化提供了一个干净的"自旋-动量锁定"测试平台，可用于阿秒时间分辨光电离中自旋退相位与相干弛豫的理论建模。
  - 该模型全部参数已由 DFT + Wannier90 标定并给出解析形式，可直接迁移进我们 proposal（general-new-idea-20260822 及 HHG 相关课题）的 tight-binding + 含时驱动模拟，省去重建哈密顿量的工作量。

**方法**：非点式共线磁体的对称性与最小哈密顿量推导（MnTe：Te-p Wannier + 双重 Schrieffer-Wolff + 群表示论构造）

**原理**：DFT（VASP PAW/PBE，Mn-3d Liechtenstein 双参数 U=4.0/J=0.9 eV，600 eV，12×12×8，实验晶格 a=4.171/c=6.686 Å，含 SOC 的 Néel 矢沿 x/y 两取向）；Wannier90 band disentanglement 仅投影 Te(5p)（验证 E_F−0.5 eV 至 VBM 与 DFT 完全一致——Mn 电子远离费米面）；群表示论对空间群/自旋群/磁群（G/T≅D6h；无 SOC 自旋点群 26/m2m1m；Néel 沿 x 磁空间群退化为 Fedorov 群、沿 y 为磁点群 m′m′m）构造不可约表示，用不变性 D(g)h(g⁻¹k)D⁻¹(g)=h(k) 仅对小群生成元构造 h(k)=Σhᵢfᵢ(k)；解析 TB：H=H_Te-Te+H_Te-Mn+H_Mn-Mn+H_SOC，Te-Te 三近邻（Slater-Koster），Mn 保留非简并 d_z²（晶体场三重分裂），对 d_z² Schrieffer-Wolff 积分得 p 电子有效哈密顿量，再对色散 p 轨道做第二次带矩阵 SW 展开（需保高阶项得正确对称性）；共轭梯度拟合 Γ/A 点附近椭球区 DFT 能带，SOC 部分用 sin 变换。

**参数表**：

| --- | --- | --- |
| DFT 设置 | U=4.0 eV、J=0.9 eV（Liechtenstein）；600 eV；12×12×8 Γ 中心；a=4.171 Å、c=6.686 Å | §第一性原理计算 |
| Wannier 验证 | E_F−0.5 eV 至 VBM 与 DFT 本征值完全一致；仅 Te(5p) 投影 | §Wannier 紧束缚模型 |

**适用边界**：d_z² 单 Mn 轨道近似（其余 d 轨道远费米面假设）；二次 SW 展开需保高阶项（低阶截断破坏对称性）；拟合区限 Γ/A 椭球（全 BZ 外推未验）。
