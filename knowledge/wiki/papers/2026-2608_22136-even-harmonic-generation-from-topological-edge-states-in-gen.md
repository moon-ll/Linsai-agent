• # 扩展 SSH 模型与 Rice-Mele 模型中拓扑边缘态的偶次谐波产生

  ## 林赛的理解

  这篇工作对我们组的核心价值在于：它把"偶次谐波选择定则"从经验观察提升到了一个严格的对称性论证——**零能边缘态 + 粒子-空穴对称性 ⟹ 偶场宇称响应**，并用局域照明（local illumination）这一实验可操控的手段，把拓扑边缘态的信号从体带背景中分离出来。这正好命中我们"HHG 作为拓扑相全光学探针"的主线，而且方法极其轻量：一维紧束缚模型 + Crank-Nicolson 含时演化 + 分解分析，不需要 TDDFT 级别的算力，非常适合作为我们课题中快速筛选机制假说的理论沙盒。我在意的另一个点是他们揭示了一个反直觉结论：中隙态（MGS）提供的额外跃迁通道并不增强反而**破坏性地压制**总体 HHG 强度——这提醒我们在分析掺杂/缺陷体系的 HHG 时，不能简单地"态越多信号越强"。

  ## 研究问题

  论文围绕三个层层递进的问题展开：

  1. 在扩展 SSH（ESSH）模型和 Rice-Mele（RM）模型中，边缘态（ESs）与中隙态（MGSs）如何影响 HHG 光谱中的量子通道干涉，从而重塑谱形？
  2. 当照明从全局变为局域（只照亮拓扑绝缘体单侧边界）时，边缘态的 HHG 谱会呈现什么特征？局域照明能否作为一种"对称性操控旋钮"，选择性压制或增强偶次/奇次谐波？
  3. 局域照明下出现的偶次谐波，其对称性起源是什么——能否从零能边缘态的粒子-空穴对称性严格推导出来？

  中心论点：照明光斑的空间位置提供了一条调控体系对称性的途径，可在低维纳米结构中实现对偶次与奇次谐波的选择性抑制或增强；偶次谐波选择定则是零能边缘态特征与粒子-空穴对称性的直接后果。

  ## 研究背景

  - HHG 最初在气体原子分子中观测到，由半经典三步模型（隧穿电离—场驱动传播—回碰复合）成功描述；进入固体体系后需推广为包含带内与带间跃迁的固态三步模型。
  - HHG 作为拓扑相的全光学探针已有清晰脉络：Bauer 和 Hansen（PRL 120, 177401 (2018)）用 TDDFT 展示拓扑/平庸相在带隙区间的巨大谱差异；Jürß 和 Bauer 用 SSH 紧束缚模型复现类似特征，证明简单模型即可捕捉拓扑签名；Chuan Yu 用固态三步模型解释边缘态如何增强谐波发射及量子通道干涉机制。
  - HHG 对边缘态**数量**敏感：可区分 ESSH 模型中 0、2、4 个边缘态的相。Liu 和 Bian 进一步推广到 Aubry-André-Harper（AAH）模型，通过调制相位改变跳跃振幅，展示边缘态可通过带隙以下 HHG 增强被探测，且在周期与准周期体系中均稳健。
  - 对称破缺项方面：Ma 等人用 Lindblad 主方程处理开放边界 SSH 链的量子退相干，观测到单边缘态的偶次谐波发射，并用双通道干涉模型和动力学对称性分析奇偶结构；Nivas 等人在 AAH 模型中引入余弦形式在位势（可约化为交错势），发现其削弱带隙区谐波谱且强度强烈依赖在位势大小。
  - 本文动机：ESSH 与 RM 模型的扩展耦合丰富了能带结构、提供更多电子跃迁通道；边缘态与中隙态分别是两种模型的特征态，值得对比研究；局域照明下的结果可为轻掺杂半导体和局域杂质态研究提供参照。

  ## 研究方法

  - **模型体系**（原子单位，ℏ = |e| = mₑ = 4πε₀ = 1）：
    - SSH 模型：二聚化链，A/B 两个子格，胞内跃迁 v、胞间跃迁 w；|v|>|w| 为平庸绝缘体，|v|<|w| 为拓扑相（零能边缘态 + 整数绕数）。
    - ESSH 模型：SSH + 次近邻 A-B 子格长程跃迁 J，可承载更多零能边缘态。参数：ESSH-平庸相 v = −0.25, w = −0.20, J = −0.03；ESSH-拓扑相与 RM 模型 v = −0.10, w = −0.18, J = −0.2。
    - Rice-Mele 模型：ESSH + 交错在位势 H_U（幅度 U），破坏反演对称性，将四重简并零模劈裂为两组中隙态（分别移动 +U 和 −U）。
    - ESSH-拓扑相绕数为 2（对应 4 个边缘态）；三模型体带隙 E_gap ≈ 0.15（ESSH 平庸/拓扑）与 ≈ 0.16（RM），总谱宽 E_max ≈ 0.97（N = 2000）。
  - **驱动场**：长度规范，线偏振沿 x 轴，矢势 sin² 包络（5 个光周期，ncyc = 5），A₀ = 0.2 a.u.（对应峰值强度约 7.9 × 10¹⁰ W cm⁻²），基频 ω = 0.0075 a.u.，满足偶极近似。
  - **局域照明**：电场变为位置依赖形式 E(x,t) = E(t)cos²[(x−x₀)π/(2x_ℓ)]（|x−x₀|<x_ℓ 时，否则为 0），长度规范下势能以 ϵⱼ = dⱼE(t) 加入在位项。
  - **数值方法**：Crank-Nicolson 含时演化（半占据，最多 N/2 个本征态）；位置算符期望值 X(t) 对偶极加速度 ¨X(t) 取 FFT 模平方得谐波谱，Hanning 窗抑制谱泄漏。链参数 a = 2.0 a.u.，δ = 0.15 a.u.（ESSH-平庸）/ −0.15 a.u.（ESSH-拓扑与 RM）。
  - **分解分析**：将总偶极加速度分解为全部占据态（S_occ）、价带（S_VB）、边缘态（S_ESs）或中隙态（S_MGSs）三个分量，定位主要贡献来源。
  - **对称性分析**：对含时薛定谔方程做粒子-空穴变换 P，结合微扰论场振幅展开 X_M[E](t) = Σ X_M^(ℓ)[E](t)，利用场反演宇称 X_M^(ℓ)[E](t) = (−1)^ℓ X_M^(ℓ)[−E](t) 与零模条件 P|ψ₀⟩ ∝ |ψ₀⟩，严格推导偶次选择定则。

  ## 主要发现与核心结论

  1. **全局照明下拓扑相增强、中隙态反而压制**（图 3）：ESSH-拓扑相（含边缘态）HHG 强度强于平庸相——涉及边缘态的通道与其他通道发生**相长干涉**；而 Rice-Mele 模型虽通道更多，其强度在 20 次谐波以下（对应 E_gap/ω）反而弱于拓扑相，表明中隙态引起**破坏性干涉**。

  2. **分解分析揭示贡献者本质**（图 4）：ESSH-拓扑相中 S_VB 主导且与 S_occ 几乎重合，S_ESs 可忽略（对称的跃迁偶极矩导致边缘态相关通道破坏性干涉）；RM 模型中在谐波阶 [0, E_max/4ω] ≈ [0, 32] 区间 S_MGSs 与 S_VB 相当（中隙态活跃），但超过 ≈32 阶后 S_MGSs 迅速消失；且 S_VB ≈ S_MGSs > S_occ，说明 VB 与 MGS 偶极加速度间存在强破坏性干涉，净响应被压制。中间区 [32, 64] 由 VB 主导。

  3. **局域照明分辨边缘态信号**（图 5，N = 100）：脉冲照在链中心（x₀ = 0, x_ℓ = 10）时三模型谱形定性相似；照在边界（x₀ = 95）时带隙以下（≈20 阶）出现显著差异：ESSH-拓扑相在约 10 阶出现局域极大（对应体带隙一半，VB-ES 跃迁）；RM 模型在 15 阶（占据中隙态到导带底的 ∆E₂）；ESSH-平庸相在 20 阶（体带隙）。

  4. **照明位置扫描揭示偶次谐波起源**（图 6）：对 ESSH-拓扑相，照明中心靠近边界时出现偶次谐波，向链中心移动则逐渐消失——偶次谐波来自边缘态；ESSH-平庸相随位置无明显变化；RM 模型在 6 阶以下恒有偶次谐波（与照明位置无关）。

  5. **对称性论证（核心结论）**：局域照明破坏反演对称性，允许偶次谐波；而零能边缘态 + 粒子-空穴对称性强制边缘态响应具有偶场宇称，压制奇次场阶项（X₀^(ℓ)[E](t) = (−1)^ℓ X₀^(ℓ)[E](t)，奇 ℓ 项消失）。分解验证（图 7）：S_ESs 中偶次主导、S_VB 中奇偶并存；总谱 S_occ 中偶次被 VB-ES 破坏性干涉压制，照明窗口较小（x_ℓ = 10）时因边缘态指数衰减未完全捕获、偶次信号残留。高绕数 ESSH 每个边界有多个零模，但零能子空间内总可选出 P 不变的基，结论对每个零模成立。附录 A 确认普通 SSH 模型（v = −0.10, w = −0.18, δ = −0.15）有同样行为。

  6. **数值细节**：四个近简并边缘态本征值量级 10⁻¹⁸–10⁻¹⁶（有限尺寸非严格零能），为尊重反演对称性按能量排序交替赋予奇/偶宇称。

  ## 潜在研究方向

  - **实验实现性**：局域照明要求光斑尺寸 x_ℓ ≈ 10 a.u.（约 0.5 nm）量级，远小于当前远场光学衍射极限；需依赖近场、纳米天线或针尖增强方案，本文未讨论具体实验路径。
  - **模型局限**：一维紧束缚、半占据、零温、无退相干、无载流子弛豫；局域照明引入的空间非均匀势在长度规范下与规范选择相关的问题未深究；未考虑多体相互作用。
  - **RM 模型的未解之处**：RM 模型 6 阶以下与照明位置无关的偶次谐波的确切机制着墨较少，其来源（交错势 vs 中隙态的具体角色）可进一步拆解。
  - **可拓展方向**：轻掺杂半导体与杂质态体系（作者明示的动机）的直接对应实验；AAH 及其他准周期体系的局域照明对称性分析；时间分辨（泵浦-探测）下边缘态 HHG 的动力学；边缘态偶次谐波作为绕数/边缘态数量的诊断工具（对 4 边缘态 ESSH 是否可区分于 2 边缘态情形未做定量标定）。
  - 分解分析中 S_occ 对照明窗口尺寸的敏感性说明部分照明下信号解读需谨慎，残余偶次信号并不纯粹来自边缘态权重不足。

  ## 与林赛研究的关联

  - **HHG / 强场驱动**：直接同域。本文的轻量紧束缚 + Crank-Nicolson 框架可作为我们"强场驱动拓扑体系 HHG"课题的快速机制筛选工具，复现成本低、参数扫描灵活。
  - **拓扑边缘态探针**：与我们 BSV 驱动 HHG 课题（`general-bsv-driven-hhg-quantum-20260726`）高度相关——"局域照明操控对称性、选择性开关偶次/奇次谐波"为我们"照明几何作为对称性旋钮"的思路提供了严格的理论先例和选择定则模板；偶次谐波作为边缘态零模 + 粒子-空穴对称性的指纹，可迁移到我们体系中作为拓扑序诊断量。
  - **莫尔/二维推广**：一维链的局域照明思想可推广到莫尔体系的局域探测（如转角双层材料中特定畴区照明），莫尔超晶格中平带边缘/角态的 HHG 响应可借鉴其分解分析方法论。
  - **交变磁/量子几何**：中隙态破坏性压制的结论提示在分析交变磁体或掺杂莫尔体系的 HHG 时，需显式计算通道间干涉而非仅数态密度；跃迁偶极矩的对称性（量子几何在 HHG 中的角色）是决定边缘态贡献可否忽略的关键变量——这正是我们"量子几何因子调控 HHG 产率"方向的接口。
  - **量子几何关联**：文中"对称 TDM 导致破坏性干涉、破坏 TDM 对称性使 MGS 活跃"的机制，本质上就是量子几何（跃迁偶极矩结构）调控谐波发射的清晰一维范例，可作为我们推导中几何不变量表述的对照案例。

## 研究方法（方法卡）

**方法**：拓扑边缘态的偶次谐波产生：局域照明对称性破缺 + 零模粒子-空穴对称性选择定则（ESSH/Rice-Mele 紧束缚 + Crank-Nicolson）

**原理**：在 SSH、扩展 SSH（ESSH，含次近邻长程跃迁 J、绕数 2 → 4 个边缘态）与 Rice-Mele（RM，ESSH + 交错在位势，四重简并零模劈裂为中隙态）三种一维拓扑模型的局域照明 HHG 中建立偶次谐波选择定则：局域照明破坏空间反演对称性允许偶次谐波，而零能边缘态 + 粒子-空穴对称性强制边缘态响应具有偶场宇称（X₀^(ℓ)[E](t) = (−1)^ℓ X₀^(ℓ)[−E](t)）——压制奇次场阶项。分解分析（S_occ/S_VB/S_ESs 或 S_MGSs）揭示：ESSH-拓扑相中 S_VB 主导（边缘态跃迁偶极矩对称 → 破坏性干涉使 S_ESs 可忽略）；RM 模型中低阶 S_MGSs 活跃但与 S_VB 破坏性干涉压制净响应；照明位置扫描证明偶次谐波来源于边缘态（照明靠近边界出现、移向中心消失）。
