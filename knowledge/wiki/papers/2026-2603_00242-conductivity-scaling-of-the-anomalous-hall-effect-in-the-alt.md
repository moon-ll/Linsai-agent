• # α-MnTe 反常霍尔电导率的跳跃机制标度律：SrF₂(111) 衬底薄膜与块体单晶的统一图像

  ## 林赛的理解

  这篇工作对我们的价值在于"定量地钉死了一件事"：α-MnTe 的反常霍尔效应（AHE）是内禀的、由交变磁（altermagnetic）序参量 L 控制，而不是缺陷诱导的铁磁性。他们用 SrF₂(111) 衬底长出晶格几乎不受热应变（c/a = 1.618，与块体一致）的高质量薄膜，把文献中单晶、InP 衬底薄膜、本文薄膜三族数据的 σ_AHE–σ_xx 落到同一条标度线上，指数 n = 1.39 ± 0.08 明确落在跳跃机制区间（1.33 ≤ n ≤ 1.76）——样品间差异全部由电导率变化解释，不需要任何"缺陷铁磁"假设。这对我组做"序参量超快读出"课题是直接的判据支撑：如果用瞬态 AHE/MOKE 探测 Néel 矢量 L 的动力学，本工作给出了（i）衬底选择策略（SrF₂ 消除热应变，这对薄膜泵浦-探测实验的样品制备很关键）；（ii）背景磁化的检测下限（<10⁻⁴ μB/(u.c.)），即任何瞬态磁光信号若超过此量级才有意义；（iii）AHE 幅度与电导率纠缠的标度提醒——做时间分辨读出时不能用 σ_xx 漂移冒充 AHE 动力学。

  ## 研究问题

  α-MnTe 的反常霍尔效应究竟起源于何处？具体分解为三个子问题：

  1. 样品间（薄膜 vs 单晶、不同衬底、不同制备）AHE 幅度、场依赖、温度依赖的巨大差异，是内禀的还是缺陷诱导的铁磁所致（Chilcote 等 [24]、Watanabe 等 [30] 曾提出缺陷起源）？
  2. 在无净磁化的交变磁体中，σ_xy 的变化究竟由磁有序参量的样品间差异还是由纵向电导率变化主导？由于薄膜中自发磁化几乎不可测，仅靠 σ_xy 本身无法区分这两种贡献。
  3. α-MnTe 单位磁化对应的反常霍尔响应，与已知铁磁半导体相比处于什么量级？（这是判断"缺陷铁磁解释是否自洽"的检验。）

  ## 研究背景

  - 交变磁性（altermagnetism）是近期确立的新磁序类型：两个补偿磁亚晶格不能通过空间反演或平移互相映射，能带呈现纯交换诱导的动量依赖自旋劈裂；计入自旋轨道耦合后，尽管磁化近零仍可产生强反常霍尔与反常能斯特效应 [1–5]。半导体 MnTe 与金属 CrSb（NiAs 相）是最典型的交变磁体，其交换劈裂已在单晶和薄膜中观测 [14–20]。
  - α-MnTe 的 Mn 亚晶格位于不同层、反铁磁耦合，且不能由简单平移/反演互映，Néel 矢量 L 沿 <11̄00> 时，m'm'm 磁点群对称性允许自发 AHE [23,25–27]，已在薄膜和单晶中观测 [3,4,28,29]。但 AHE 幅度、场/温依赖与磁化的关系高度样品依赖 [3,4,21,24,27–30]，根源不明。
  - AHE 的标准诊断工具是电导率标度律 σ_xy = a·M·σ_xxⁿ [31]：绝缘/跳跃区（σ_xx < 10⁴ S/cm）磁半导体普适标度为 σ_AHE ∝ σ_xxⁿ，1.33 ≤ n ≤ 1.76，物理图像是杂质三站点（triad）间跳跃的干涉项破坏时间反演对称性，干涉项与 Berry 相位相连 [44]；金属区（10⁴ < σ_xx < 10⁶ S/cm）Berry 曲率机制给出 σ_AHE ∝ σ_xx⁰ [31]。此前 α-MnTe 缺一张把薄膜与单晶统一起来的标度图。

  ## 研究方法

  方法密度中等——核心是"应变工程衬底 + 多探针磁表征 + 标度律分析"的组合。按方法卡整理如下：

  ### 外延生长与结构表征
  - **样品制备**：分子束外延（MBE）在 SrF₂(111) 衬底、Te 富条件下生长；衬底温度 340 °C – 390 °C。三个样品：S1（145 nm）、S2（1080 nm）、S3（Hall bar，120 nm）。
  - **结构确认**：SrF₂(222) 布拉格峰附近的 XRD 确认 α 相（(0004) 峰出现，Cu-K 源未单色化）；(513) SrF₂ 与 (11̄26) MnTe 互易空间图谱（RSM，单色化 Cu-Kα 源，300 K）证明 145 nm 薄膜**非热应变**——区别于 III-V 衬底上的薄膜 [26,32,33]。
  - **晶格参数**（表 I，300 K）：S1 的 a = 4.146 Å、c = 6.713 Å；S2 的 a = 4.15 Å、c = 6.714 Å；S3 c = 6.711 Å；均得 c/a = 1.618，与块体单晶（a = 4.1486 Å、c = 6.7129 Å，厚度 3×10⁵ nm）一致。对照：InP 上 48 nm 薄膜 a = 4.1708 Å、c = 6.686 Å（明显受应变）。带结构与块体可比 [14–17]（补充材料 [34,35]）。

  ### 磁性表征（三套互补探针）
  | 探针 | 配置/参数 | 关键结果 |
  |---|---|---|
  | SQUID 磁强计 | 4 K，S2（1080 nm），扣除衬底抗磁背景 | 低场磁化 <10⁻⁴ μB/(u.c.)；ab 面自旋翻转（spin flop）转变在 0.8 T；5 T 下净磁矩 ≤ 0.007 μB/Mn；面外 <0.007 μB/Mn 至 5 T；面外弱 S 形信号 4–300 K 不变，判为外禀；剩磁 ~10⁻⁵ μB/Mn，与单晶一致 [3,28] |
  | 极化中子反射（PNR） | 77 nm MnTe/SrF₂（Te 盖帽），T = 50 K、B = 1 T；中子波长 0.2–0.8 nm；极化率 98.5–99% [36]；BL-4A MAGREF（SNS，IPTS-32732.1） | R± 无可分辨劈裂；自旋不对称度 SA = (R⁺−R⁻)/(R⁺+R⁻) 在 Q 高达 0.12 Å⁻¹ 处与零重合（误差内）；直接排除可测体磁化 |
  | X 射线磁圆二色（XMCD） | Mn L₃,₂ 边，DEIMOS 光束线（SOLEIL，Proposal 20241735）；T = 4 K；零场及 B ∥ c 轴；法向入射、全电子产额 | 零场 XMCD 与 α-MnTe/InP 一致，反映交变磁贡献 [38]；和规则求和（sum rules）[39–41]：若设各向异性磁偶极 <T_z> = 0，则 5 T 下 <S_z> ≈ 0.16 μB/Mn——比 SQUID 的 5 T 磁化 0.007 μB/Mn 大一个数量级以上；改用 <S_z>(H) = (m(H)−<L_z>)/2 重新评估 [42,43]，得 5 T 下 <T_z> ≈ 0.06 μB/Mn、<L_z> ≈ 0.03 μB/Mn（跨越自旋翻转转变），零场时 <T_z>、<L_z> ≈ 0，与多重度配位场理论一致 [42]。确认 m'm'm 磁点群 |

  ### 磁输运与标度分析
  - **测量量**：反对称化 Hall 电阻 ρ_xy(B)（以线性为主）；高场斜率扣除得 ρ_AHE；纵向 ρ_xx。变温测量（各样品温区因 AHE 温度依赖的样品差异而不同）。
  - **载流子参数**（表 II）：S1（2 K）：|p| = 6.44×10¹⁸ cm⁻³，μ = 27.4 cm²V⁻¹s⁻¹，ρ_xx = 353 μΩm，MR 不可测；S2（5 K）：9.75×10¹⁷ cm⁻³，30.9 cm²V⁻¹s⁻¹，2067 μΩm，MR <10⁻⁴ μB/u.c.；S3（6 K）：3.9×10¹⁸ cm⁻³，21 cm²V⁻¹s⁻¹，762 μΩm；InP 上（150 K）：4.9×10¹⁸ cm⁻³，29，554；块体（237 K）：4×10¹⁷，8.6，17851，MR 2.5×10⁻⁵；块体（200 K）：ρ_xx = 2644，MR 6×10⁻⁵。纵向电阻率跨一个数量级，这是构建标度图的基础。
  - **标度拟合**：σ_AHE = a·M·σ_xxⁿ，对数坐标线性拟合，数据涵盖本文三薄膜（标记 ND）+ 文献单晶（Warsaw [3]、Michigan [28]）+ InP 薄膜（Prague [4]）。薄膜的 σ_AHE/M 统一按探测下限 10⁻⁴ emu/(u.c.) 归一（图 1(b) 测量）。测量前饱和至 12 T 以造成时间反演畴失衡、激活 AHE [4,57]。
  - **对称性分析**：m'm'm 点群允许的反常 Hall 电导形式 σ_AHE ~ L_y(3L_x² − L_y²) [56]；三个等效 {11̄00} 畴给出同号 AHE [56]。

  ## 主要发现与核心结论

  1. **SrF₂(111) 衬底实现近块体质量薄膜**：c/a = 1.618 与单晶一致、无非热应变；XMCD 确认 m'm'm 磁点群——衬底选择本身是结果之一。
  2. **磁化与 AHE 完全脱钩**：S2 剩磁上限 <10⁻⁴ μB/(u.c.)（PNR 在 Q 至 0.12 Å⁻¹ 无信号），却在零场测得 ρ_AHE 达 1 μΩ·m；矫顽场与零场 ρ_AHE 均随温度升高衰减，最厚样品 S2 衰减最快（可能因其纵向电导率更低）。AHE 由 Néel 矢量 L 的场依赖驱动，而非缺陷磁化的场依赖。
  3. **XMCD 揭示各向异性磁偶极项 <T_z> 作为"无形磁化"**：5 T 下 <T_z> ≈ 0.06 μB/Mn、<L_z> ≈ 0.03 μB/Mn，零场时趋零——验证交变磁体零磁化 XMCD 来自自旋-轨道四极耦合的理论 [42,43]。
  4. **标度律 n = 1.39 ± 0.08**：覆盖薄膜+单晶全部数据，落在磁半导体跳跃机制区间 1.33 ≤ n ≤ 1.76 [44]（σ_xx < 10⁴ S/cm），表明 AHE 主要由跳跃机制主导，且薄膜/块体的表观差异可完全归因于电导率不同——无需缺陷铁磁假设 [24]。
  5. **巨量级（colossal）相对霍尔响应**：σ_AHE/M 标度图上，α-MnTe 超出 EuCd₂As₂、Ga₀.₉₄Mn₀.₀₆(As,P)、(Cu,Zn)Cr₂Se₄、Fe₃O₄、Co 掺杂 TiO₂ 等全部对比体系 2–4 个数量级。若强行归因于缺陷铁磁，则要求缺陷产生远超已知磁半导体的异常大 Berry 相位 [44]——不合理。结论：AHE 是内禀的、源于交变磁磁晶体对称性；M 只是次级序参量，σ_xy 由 L 方向控制 [56]。
  6. **高温端**：输运虽过渡到多声子辅助跳跃，但标度指数不变，因为横向响应受对称性与渗流网络拓扑控制，而非电子-声子耦合细节。

  ## 潜在研究方向

  - 标度分析止步于"指数落在跳跃区间"：三站点干涉模型的微观参数（跳跃距离分布、杂质三态密度）与 Berry 相位项的定量连接未在本文展开；n 在薄膜/块体间是否有系统性偏移，数据点尚不足以分辨。
  - 12 T 预饱和畴失衡的程度未定量——畴统计对 AHE 幅度的贡献（文中承认是次要因素）缺少直接测量（可参考纳米尺度交变磁成像 [27] 的工作做关联）。
  - 温度依赖的样品间差异（S2 衰减更快归因于其低电导率）目前是定性陈述，未做变温标度验证。
  - 面内 L 方向的电场/应变调控动力学未触及——m'm'm 对称性允许的 σ_AHE ~ L_y(3L_x² − L_y²) 是 L 矢量的非线性函数，意味着 90° L 切换应有可测的 AHE 符号/幅度变化，可作器件命题。
  - 本文聚焦平衡态与直流输运；交变磁序参量 L 的超快动力学（光致翻转时间尺度、与声子/磁振子的耦合）完全未研究。

  ## 与林赛研究的关联

  - **HHG / 强场驱动 / 阿秒读出**：α-MnTe 是 NSFC-强场超快方向下"序参量超快读出"课题（general-order-parameter-ultrafast-readout-20260727）的直接候选体系。本工作确立 L 控制 σ_xy 的内禀图像，为"用瞬态输运/磁光探测 Néel 矢量动力学"提供了基准：平衡态 AHE 幅度（零场 ρ_AHE ~ 1 μΩ·m）、磁化噪声底（<10⁻⁴ μB/(u.c.)）、以及必须剔除的 σ_xx(t) 纠缠（σ_AHE ∝ σ_xx^1.39）三项标定均来自本文。
  - **交变磁方向词**：这是交变磁 + 磁输运 + 对称性分析的组合范例，可作为课题立项依据中"交变磁体具有可测宏观输运响应"的关键引证（尤其 n = 1.39 ± 0.08 与 σ_AHE/M 超对比体系 2–4 个数量级两条硬数据）。
  - **样品制备接口**：SrF₂(111) 衬底消除热应变（c/a = 1.618）+ MBE 340–390 °C Te 富生长窗口，是可移植到我组薄膜制备与泵浦-探测实验的明确工艺参数；InP 对照组的应变数据（a = 4.1708 Å vs SrF₂ 4.146 Å）提示应变会改变带结构与 Berry 曲率，做应变调控读出实验时需谨慎分离应变效应与本征动力学。
  - **方法学接口**：PNR（Q 至 0.12 Å⁻¹ 无信号即排除体磁化）与 XMCD 和规则分离 <T_z>/<L_z>/<S_z> 的操作，是低磁化反铁磁体系磁表征的标准流程模板；XMCD 中 <T_z> 作为等效磁偶极携带 XMCD 但不带净磁化的机制 [42,43]，对理解我们磁光实验中"表观磁光响应 ≠ 磁化"的陷阱有直接借鉴意义。

### general-order-parameter-ultrafast-readout-20260727

标题：Conductivity scaling of the anomalous Hall effect in the altermagnetic semiconductor α-MnTe（Sara Bey, …, Xinyu Liu, Badih A. Assaf 等 24 人，2026-02-27 提交）
来源：[arXiv:2603.00242](https://arxiv.org/abs/2603.00242)

### 研究问题（Research Question）
论文聚焦 α-MnTe 巨大 AHE 的起源这一基础问题：不同样品间 AHE 幅度的显著差异是否暗示缺陷相关的（非本征）机制？中心论点是通过电导率标度分析给出判据。

### 研究背景（Background）
α-MnTe 是原型交变磁半导体，在磁化近乎为零时表现出强 AHE；近期样品间（尤其薄膜）AHE 幅度的变化引发了对缺陷相关起源的担忧，直接关系到把 AHE 用作交变磁序参量读出的可靠性。

### 研究方法（Methods）
研究生长在 SrF2 衬底上、具有体相预期晶体结构与 m'm'm 磁点群的 α-MnTe 薄膜；将本工作与文献报道的 AHE-电导率标度数据合并分析；用磁强计与极化中子反射（PNR）独立测定自发磁化，与 AHE 幅度对比；并与其它磁性半导体的 AHE 水平横向比较。

### 主要发现与核心结论（Main Results）
样品间 AHE 幅度差异可由一条与跳跃（hopping）输运机制一致的标度律很好地解释，无需引入样品特异机制。与其它磁性半导体相比，α-MnTe 的 AHE 相对其测得的自发磁化是“巨”（colossal）量级的，凸显 Berry 曲率（本征交变磁）贡献的主导性。这既回答了 AHE 起源问题，也支撑交变磁体作为自旋电子学材料的潜力。

### 潜在研究方向（Future Directions）
开放问题包括：跳跃标度律中缺陷态的具体角色、在更高品质/更低无序样品上验证标度外推、以及巨 AHE 与能带 Berry 曲率的定量对应。对读出课题的启示是：AHE 幅度受电导率（因而受缺陷与温度）调制，以霍尔信号做序参量读出时须对标度律导致的系统偏差建模。
