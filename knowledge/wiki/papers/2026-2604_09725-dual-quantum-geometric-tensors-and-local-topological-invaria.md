• # 对偶量子几何张量与局域拓扑不变量：Zeeman 量子几何的非厄米分解与局域 Dirac 节点拓扑的曲率-通量表示

  ## 林赛的理解

  这篇工作做了一件概念上很漂亮的事：把局域 Dirac 节点的 π₁ 缠绕拓扑（通常用绕数或 Berry 相位刻画）改写成一个**高斯型曲率-通量不变量**，而桥梁是非厄米的 Zeeman 量子几何张量（QGT）。核心洞察在于——厄米 QGT 的"实部=度规、虚部=Berry 曲率"的划分，在非厄米张量下不再成立；正确的分类标准是**指标交换对称性**，由此分出正常（normal）与反常（anomalous）两个度规-曲率扇区。反常 Zeeman 曲率 Ωᴬ 在二维 Dirac 系统中构成一个径向通量场，与切向缠绕场互为 Hodge 对偶。

  对我来说，价值有三层：第一，它给出了一套**对称性 + 低频标度**的"指纹协议"，用回旋电导率（gyrotropic conductivity）的张量结构把四个几何扇区逐一分离，并指出其倒易响应——动力学磁电效应（KME）——已有实验观测，这提供了一个从"几何量"到"可测信号"的完整链条。第二，它对磁点群的分类表（Table I）直接可移植到我们对**交变磁（altermagnetism）/共线磁体**输运与光响应的分析中。第三，Zeeman 耦合本身就是**磁偶极驱动**的耦合算符——这与强场驱动下自旋自由度参与的非线性动力学有潜在接口。这是纯理论工作，无实验装置参数，方法素材以理论构造与选择定则为主。

  ## 研究问题

  局域 Dirac 节点拓扑通常由绕数（winding number）或 Berry 相位描述（π₁ 型表征），而曲率-通量表述（如 Brillouin 区积分 Berry 曲率得 Chern 数）通常只与全局 π₂ 带拓扑关联。论文的核心问题是：**局域缠绕型拓扑能否也被改写成曲率-通量形式，使局域与全局拓扑描述可以在统一的几何语言下讨论？** 附带问题是：非厄米 Zeeman QGT 中超出常规度规-曲率对的几何内容是什么、如何测量？

  ## 研究背景

  - 带拓扑可从局域与全局两个视角理解：孤立带交叉附近的物理由动量空间受限区域内的几何量编码（二维 Dirac 节点由环绕奇点的闭合回路上的量子化 Berry 相位或绕数刻画，属 π₁ 表征）；全局拓扑则需在整个 Brillouin 区上积分几何量（Chern 数 = Berry 曲率的 BZ 积分，属 π₂ 表征）。
  - 常规厄米 QGT：实对称部分为量子度规，虚反对称部分为 Berry 曲率，二者共同支配绝热相位、轨道/电学响应、Bloch 带中的几何约束以及非线性霍尔效应。
  - 当耦合算符不是位置算符时，QGT 变为非厄米。典型例子是 Zeeman 耦合 **B·σ**（涉及自旋矩阵元而非电偶极耦合 E·r），其几何内容不再被单一的度规-曲率对所穷尽；Zeeman QGT 已被证明是驱动回旋磁电流（gyrotropic magnetic current）的底层几何对象。
  - 该工作受 NSFC 项目（No. 12404059、No. 12574054）支持；KME 效应已在文献 [40–42] 中有实验观测，为理论验证提供了现实路径。

  ## 研究方法

  本工作为纯理论推导，无实验装置。其核心方法链条如下（数值均出自原文）：

  **1. Zeeman QGT 的四重张量分解（方法卡：理论构造）**

  - 原理：Zeeman QGT 定义为 T^Z,ab_nm = r^a_nm σ^b_mn，其中 r^a_nm = ⟨u_n|i∂/∂k_a|u_m⟩ 为带间 Berry 联络，σ^b_mn = ⟨u_m|σ^b|u_n⟩ 为 Pauli 算符矩阵元。该张量不满足厄米共轭对称 T^ab = (T^ba)*，因此度规/曲率性须按**指标交换对称性**而非实虚性划分。
  - 参数表（定义式，原文 Eq. (3)）：
    - 正常 Zeeman 度规 g^N,ab_nm = (1/2)Re[r^a_nm σ^b_mn + σ^a_mn r^b_nm]（对称张量）
    - 反常 Zeeman 度规 g^A,ab_nm = (1/2)Im[r^a_nm σ^b_mn + σ^a_mn r^b_nm]（虚对称张量，常规 QGT 中不存在）
    - 反常 Zeeman 曲率 Ω^A 与正常曲率 Ω^N 由叉积定义：Ω^A/N_nm = −Re/Im(r_nm × σ_mn)，Ω^c = (1/2)ε^cab Ω^ab 为矢量表示
    - 退化校验：将 σ → r 代回，g^N、Ω^N 退化为常规量子度规与 Berry 曲率，g^A = Ω^A = 0（原文 Eq. (3) 后）

  **2. 通用两带恒等式（附录 A，装置=任意 H = d·σ 两带哈密顿量）**

  - 模型：H = d(k)·σ，本征值 ε± = ±E（E ≡ |d|），投影算符 P± = (1 ± d̂·σ)/2
  - 通用结果（原文 Eq. (4)–(7)）：
    - Ω^N_n = (n/2) ∇_k × d̂（依赖能带指标 n = ±）
    - g^A,ab_n = −(n/4)[∂_ka d̂_b + ∂_kb d̂_a]（依赖能带指标）
    - Ω^A_n = −(1/2)[d̂(∇_k·d̂) − (d̂·∇_k)d̂]（与能带指标无关，故 Σ_n Ω^N_n = 0 而 Σ_n Ω^A_n ≠ 0）
    - g^N,ab_n = (1/4)[(d̂×∂_ka d̂)_b + (d̂×∂_kb d̂)_a]（与能带指标无关）
  - 关键推导步骤：v^a,⊥ = E∂_ka d̂、d̂×v^a = E(d̂×∂_ka d̂)（原文 Eq. (59)），显式 E 相消使结果普适；多带推广以约化预解式 G′_n = Σ_{m≠n} P_m/(ε_m − ε_n) 替换 P_n̄/(ε_n̄ − ε_n)

  **3. 二维 Dirac 模型与通量不变量（基准体系）**

  - 模型：H = d·σ，d = (k_x, k_y, m)（原文 Eq. (8)），m → 0 为无质量极限
  - 计算设置：得 Ωᴬ = −(1/2)(k_x, k_y, 2m)/d²，∇_k·Ωᴬ = −m2/d4（d² = k_x² + k_y² + m²，原文式中指数为原文排版 m2/d4）
  - 无质量极限：∇_k·Ωᴬ = −(1/2)∇_k·(k/k²) = C δ⁽²⁾(k)，**通量 C = −π**（原文 Eq. (9)）

  **4. 线性响应理论与低频选择定则（附录 B）**

  - 微扰哈密顿量：H₁ = E_α(t)r_α − gµ_B B_α(t)σ_α（e = ℏ = 1），单频振荡场
  - 计算设置：量子 Liouville 方程 i∂_tρ = [H, ρ]，密度矩阵对外场作幂级数展开 ρ = ρ⁽⁰⁾ + ρ⁽¹⁾ + …，稳态解 ρ⁽¹⁾_mn ∝ e^(−iω_β t)，η 为正无穷小保证因果性；低频条件 ω_β ≪ ϵ_nm 下展开至 ω² 阶并略去更高阶
  - 输运量：时变磁场感应电荷电流 J^a = σ^ab B_b 定义回旋电导率；倒易响应 KME 为电场感应磁化 M^a = α^ab E_b（Onsager 倒易关系仅在频率相关部分成立，dc 贡献已移除）
  - 磁点群对称性约束由 Neumann 原理给出（Table I）

  **5. Spin QGT 推广（附录 C）**

  - 定义 (T^s)^ab,c_nm = v^a,c_nm v^b_mn/ϵ²_nm，自旋-速度算符 v^a,c = (1/4){v^a, σ^c}（原文 Eq. (20)–(21)）
  - 弛豫时间近似下分布函数修正 δf_n = τ E_b ∂_k_b f_n，自旋电流分解为内禀（intrinsic）与非平衡外禀（extrinsic）贡献，后者 ∝ τ
  - 适用边界：忽略 (1/2){∂_kb v^a, σ^c}_nn 项，该项对动量线性哈密顿量为零（原文附录 C 末段）

  ## 主要发现与核心结论

  1. **四重几何扇区**：Zeeman QGT 按指标交换对称性分解为正常（gᴺ, Ωᴺ）与反常（gᴬ, Ωᴬ）两对度规-曲率。正常扇区与常规厄米 QGT 结构相同；反常扇区含两个常规 QGT 中不存在的分量：虚对称的度规样张量 gᴬ 与实反对称的曲率样张量 Ωᴬ。四个量在晶体与磁对称性下变换不同（Table I 完整分类）。

  2. **局域 π₁ 拓扑的曲率-通量表示（核心结果）**：在二维 Dirac 系统中，反常 Zeeman 曲率构成径向通量场，与 Dirac 节点的切向缠绕场 Hodge 对偶。无质量极限下 ∇_k·Ωᴬ = C δ⁽²⁾(k)，**通量 C = −π**；归一化后定义高斯型拓扑指数
     Q = (1/C)∫∫_S ∇_k·Ωᴬ d²k = (1/C)∮_∂S Ωᴬ·n̂ dl = **1**（原文 Eq. (10)）
     与绕数 C_w = (1/2π)∮_Γ ∇_kθ_k·dl（w = ∇_kθ_k = (−k_y, k_x)/k²）给出同一拓扑荷。

  3. **Hodge 对偶的普适性**：对任意 d 矢量平面的两带哈密顿量 H = d·σ（d_z = 0），Ωᴬ = *w/2，对应关系 [∇_k×Ωᴬ]_z = (1/2)∇_k·w、∇_k·Ωᴬ = −(1/2)[∇_k×w]_z（原文 Eq. (12)）。对任意孤立二维缠绕缺陷，∮_Γ w·dl = 2πC_w 时取 Ωᴬ = (1/2)ẑ×w，得 ∮_Γ Ωᴬ·n̂dl = **−πC_w**——vortex-flux 对应是普适局域结构，非 Dirac 模型特有。

  4. **与 Berry 相位的关系**：常规 Berry 曲率 Ω_xy = −nm/[2(k_x²+k_y²+m²)^{3/2}]，m→0 极限 Ω_xy = **−nπ sgn(m) δ⁽²⁾(k)**。Ω_xy ≠ ∇_k·Ωᴬ 逐点成立，但环绕节点的任意圆盘上二者积分在 m→0 极限一致（差一个符号），捕获同一局域拓扑荷。

  5. **输运选择定则（gyrotropic conductivity，原文 Eq. (18)）**：
     - Imσ⁻(ω) ~ ω⟨Ωᴬ⟩（O(ω) 反称/Hall 通道 → 反常曲率）
     - Imσ⁺(ω) ~ ω⟨gᴺ⟩（O(ω) 对称通道 → 正常度规）
     - Reσ⁻(ω) ~ ω²⟨Ωᴺ⟩（次领头 O(ω²) Hall 通道 → 正常曲率）
     - Reσ⁺(ω) ~ ω²⟨gᴬ⟩（次领头 O(ω²) 对称通道 → 反常度规）
     即张量对称性 + 低频标度的组合可解纠缠正常与反常扇区。磁点群实例：Ωᴺ 相关的实 Hall 响应在**所有**磁点群允许；3m、4mm、6mm 额外允许 Ωᴬ 主导的 O(ω) Hall 响应并禁止 gᴺ、gᴬ 的对称横向响应；m′m′2、3m′、4m′m′、4′m′m、6m′m′ 则只允许 gᴺ 关联的对称横向响应。

  6. **倒易 KME 验证通道**：KME 已在文献 [40–42] 中实验观测，与回旋霍尔效应（GHE）由 Onsager 倒易关联，探测同一四个扇区但排列互补（原文 KME 选择定则）：
     - Imα⁻(ω) ~ ω⟨Ωᴺ⟩，Imα⁺(ω) ~ ω⟨gᴬ⟩
     - Reα⁻(ω) ~ ω²⟨Ωᴬ⟩，Reα⁺(ω) ~ ω²⟨gᴺ⟩
     GHE+KME 联合测量给出对称性-频率分辨的完整实验策略。

  7. **Spin QGT 平行结构**：自旋 QGT 同样四分解，反常扇区给出实的自旋涡量（spin-vorticity）型场，满足 Ω̄ᴬ,c_n = (1/2)∇_k×v^c_n（v^c_n 充当有效联络，原文 Eq. (27)）；自旋电流 J^c_n = ∫_k f_n[E×(Ω̄ᴺ,c_n + τΩ̄ᴬ,c_n) − 2(ḡᴬ,c_n + τḡᴺ,c_n)·E]（原文 Eq. (28)），反称通道由曲率扇区支配、对称通道由度规扇区支配，且内禀/外禀贡献有不同 τ 标度；手征对称体系中度规扇区的横向响应被抑制，留下纯 Hall 型自旋响应。

  ## 潜在研究方向

  - 论文限于二维 Dirac 系统与线性响应（低频 ω ≪ ϵ_nm 展开至 ω² 阶）；**非线性、有限频率（含共振区）乃至强场区**的几何响应未覆盖——高频段的选择定则是否仍然按扇区分离是开放问题。
  - GHE 的直接实验观测仍具挑战性，论文依赖倒易 KME 作为现实探针；反常曲率扇区 Ωᴬ 的直接输运指纹（Imσ⁻ ∝ ω⟨Ωᴬ⟩）尚待实验确证。
  - 拓扑保护/稳健性讨论较少：无序、相互作用对反常通量场的 π₁ 不变量鲁棒性如何，文中未展开。
  - 三维推广：文中明确指出反常 ZBC 在 3D 一般既非无散也非无旋，Hodge 对偶的 3D 对应结构未给出。
  - 与 Berry 曲率的逐点差异（Ω_xy ≠ ∇_k·Ωᴬ）提示 m≠0 或有质量情形下两个"同一拓扑荷"的描述可能分化，有限质量修正值得量化。
  - 具体材料平台未指定——哪些真实材料（交变磁体、拓扑半金属）的四扇区信号强度足以分辨，需要第一性计算与实验合作。

  - **交变磁方向**：Table I 的磁点群分类（含 4m′m′、6m′m′ 等共线反铁磁/altermagnet 常见群）可直接用于我们分析交变磁体回旋输运与磁光响应时判断哪些几何扇区被对称性放行。
  - **强场驱动接口（需延伸，本文未覆盖）**：Zeeman 耦合 B·σ 正是磁偶极驱动算符——我们强场驱动/交变磁课题中自旋自由度参与的动力学，其绝热几何端点即本文的 Zeeman 几何扇区；从直流-低频选择定则向**太赫兹-中红外强场驱动**的跨频推广是一个值得探索的桥梁，但需注意本文 ω ≪ ϵ_nm 的展开前提在强场下失效。
