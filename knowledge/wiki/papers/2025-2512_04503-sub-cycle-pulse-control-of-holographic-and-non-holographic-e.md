• # 亚周期脉冲调控全息与非全息电子干涉

  ## 林赛的理解

  这篇工作对我们是直接可用的工具箱论文。核心信息一句话：把驱动脉冲压到亚周期（FWHM < 1 个光周期），光电子全息的条纹间距就不再只是"靶+波长"的函数，而变成**脉冲时域形状的函数**——CEP 用来选模式（0° 出 FSH/BSH，90° 出 TDS），脉冲宽度通过内禀啁啾调条纹密度。这意味着全息重建若不在方案里锁定脉宽和 CEP，条纹密度本身就会漂移，成为我们课题里"瞬态量子相位光学读出"通道的系统性误差源。同时它也提供了一个反向机会：条纹间距对内禀啁啾的敏感性反过来可以用于亚周期脉冲的波形表征（pulse characterization），即用干涉结构本身标定驱动场。

  ## 研究问题

  亚周期（sub-cycle）激光脉冲如何影响强场光电子全息（SPH）与非全息的周内（intracycle）电子干涉结构？具体拆解为三个子问题：

  1. 当驱动脉冲从单周期（1.0T₀）缩短到半周期（0.5T₀）进入亚周期区间时，前向散射全息（FSH）、后向散射全息（BSH）和时间双缝（TDS）三类干涉结构的条纹密度/间距如何演化？
  2. 亚周期场的内禀啁啾（intrinsic chirp）与脉冲包络对干涉条纹的调控机制是什么？
  3. 能否通过脉冲宽度、载波包络相位（CEP）和时间包络的选择性组合，实现对这些干涉图样的精确时空调控？

  ## 研究背景

  - 隧穿电离后的电子在激光场中亚周期加速，回散射电子具有亚埃（sub-angstrom）空间分辨和阿秒（attosecond）时间灵敏度，构成强场光电子全息（SPH）的物理基础。
  - 光电子动量分布（PMD）中的干涉结构按周期归属分为周内（intracycle）与周间（intercycle）两类：周间干涉产生 ATI 同心圆环；周内干涉产生 FSH（蜘蛛腿状）、BSH（鱼骨状）全息结构，以及在适当场条件下出现的非全息时间双缝（TDS）条纹。
  - 多周期脉冲中全息结构常被强周间干涉掩盖，近单周期脉冲对隔离亚周期电子动力学、提升全息可见度至关重要；当前超快激光技术已能产生 FWHM 短于一个光周期的脉冲。
  - 亚周期场的关键特征：由时间局域化引起的内禀啁啾（类比空间聚焦光束的 Gouy 相），表现为瞬时频率蓝移，已在亚周期太赫兹脉冲中被实验观测；包络函数也会重塑驱动场并影响干涉轨迹间的相位积累。亚周期脉宽与包络形状已被证明强烈影响 HHG 发射及相关强场过程。
  - 由于全息结构源于电离时刻与返回时刻不同的电子轨迹的相干叠加，它们对这些时间畸变高度敏感，因此必须同时考虑内禀啁啾与包络诱导的波形重塑效应。

  ## 研究方法

  - **TDSE 模拟**：在单活性电子（SAE）近似下数值求解三维含时薛定谔方程（Qprop 程序包），速度规范偶极近似，含吸收势 V_abs(r)。束缚势参数 a₀ = 1.91，使 He 基态电离势匹配实验值 I_p = 0.90 a.u.，初始态由虚时传播获得。径向计算域 1000 a.u.，截断半径 R_co = 300 a.u.，通量捕获面 R_l = 800 a.u.，最大分波数 L_max = 100，径向网格 0.2 a.u.，时间步长 0.05 a.u.。
  - **经典轨迹模型（CTM）**：基于三步回散射模型，电子初位置 |z_i| = I_p/E₀，忽略库仑势；用经典作用量 S = ∫[½v²(t) + I_p]dt 计算轨迹相位，干涉图样由 cos²(ΔS/2) 给出，每条隧穿轨迹按 ADK 公式计算的瞬时隧穿电离概率加权。
  - **亚周期场模型（SCPB）**：采用亚周期脉冲束模型（由振荡偶极子模型经复源点方法导出，为麦克斯韦方程的精确解）。电场 E(t) = Re[A_d(t′)/|A_d(0)| f(t′) E₀ exp(iω₀t′ + iφ₀)]，其中 A_d(t′) = 1 − f̈/[ω₀²f(t′)] − 2iḟ/[ω₀f(t′)] 引入内禀啁啾；瞬时频率 ω(t′) = dφ(t′)/dt′。
  - **三种包络函数**（τ 为强度包络 |f(t′)|² 的 FWHM）：高斯 exp[−2ln2(t′/τ)²]、双曲正割 sech(1.76t′/τ)、洛伦兹 1/[1 + (1.29t′/τ)²]。
  - **驱动参数**：线偏振，波长 λ₀ = 800 nm（ω₀ = 0.057 a.u.），峰值强度 I₀ = 5×10¹⁴ W/cm²；Keldysh 参数 γ = ω₀√(2I_p)/E₀ < 1，确保隧穿电离机制。脉冲宽度扫描 τ = 0.5T₀–1.0T₀（T₀ = 2π/ω₀ 为一个光周期），CEP 对比 φ₀ = 0° 与 90°。

  ## 主要发现与核心结论

  - **CEP 选择性调控**：φ₀ = 0° 时电场关于脉冲峰值对称、矢势反对称，半周期脉冲清晰分离出 FSH（p∥>0 区蜘蛛腿状）与 BSH（p∥<0 区右弯条纹）结构——半周期脉冲把常被淹没的 BSH 单独隔离出来；φ₀ = 90° 时电场反对称、矢势对称，最有利于 TDS 干涉，p∥>0 侧呈鱼骨状结构（BSH 与 TDS 条纹位置/密度接近、难以分离，但因回散射截面小，TDS 占主导）。
  - **FSH 条纹密度随脉宽变化**：从 TDSE 提取 0.01 < p < 0.1 a.u. 区间的光电子动量角分布（PMAD，极角 0°<θ<90°），τ = 1.0T₀ 时条纹最密，随脉宽缩短逐渐变疏；平均峰宽（PW）在 τ = 0.5T₀ 最大、随脉宽增加而减小，TDSE 与 CTM 两种方法趋势一致。经典分析表明：直接轨迹（DT）的电离时刻对脉宽不敏感，散射轨迹（ST）电离时刻随 θ 延迟且随脉宽变化；再碰撞时间 ΔT = T_rec − T_ion 随 θ（即 p⊥）增大而增大，但随脉宽从 1.0T₀ 缩短到 0.5T₀ 而减小——**条纹密度主要由再碰撞时间决定：电离与回散射的时间差越大，条纹越密**。
  - **BSH 条纹间距同规律**：p⊥ = 0 a.u. 处的 BSH 线剖面显示 τ = 1.0T₀ 条纹最密，向 0.5T₀ 逐渐变宽；平均峰宽同样在 τ = 0.5T₀ 最大。后向散射存在短、长两类 ST（类似 HHG 的长短轨道），两者的再碰撞时间均以 τ = 0.5T₀ 最短、随脉宽增长。后向散射电子更接近离子实，对靶结构更敏感，适合动力学成像。
  - **TDS 条纹间距**：对 φ₀ = 90° 的 TDSE 谱按 θ 积分，脉宽从 τ = 1.0T₀ 减到 0.5T₀ 时相邻 ATI 峰间距增大。与多周期脉冲中周内调制与总周期数无关的结论相反，亚周期区间出现显著依赖。两条直接轨迹 DT1/DT2（电离时刻满足 A(t_i1) = A(t_i2)、电场反号 E(t_i1) = −E(t_i2)）的电离时间差 ΔT_ion 随 p∥ 增大而减小，且固定 p∥ 时短脉冲的 ΔT_ion 更小——**电离事件时间间隔越小，TDS 条纹间距越大**。
  - **内禀啁啾的因果链**：脉冲中心（t = 0）瞬时频率的相对蓝移 ω(0)/ω₀ 随脉宽从 1.0T₀ 进入亚周期区间而显著增大；对 FSH（固定 θ）、BSH（p∥ = −0.5 a.u.）、TDS（p∥ = 0.5 a.u.）三种结构，1/ΔT 随 τ 的依赖关系与中心频率蓝移趋势互为镜像——**更短脉冲的更强内禀啁啾产生更短的再碰撞时间，直接决定 FSH、BSH、TDS 的条纹间距**。
  - **包络效应**：即使 FWHM 固定，包络变化（高斯/sech/洛伦兹）也会通过改变电离时刻附近的瞬时频率与矢势斜率进一步重塑条纹间距；内禀啁啾对波形的压缩程度依赖包络函数的选择，从单周期到亚周期区间啁啾愈发显著。
  - 结论：亚周期脉冲（如 CEP 0°/90°）可选择性增强或抑制不同干涉特征、隔离全息图样并增强 BSH 条纹，为探测与操控阿秒电子动力学提供精确的时域控制手段。

  ## 潜在研究方向

  - 本文仅研究 He 原子（SAE 近似），分子体系与多电子效应下的亚周期全息调控未涉及；CTM 忽略库仑势，只能定性复现 TDSE 结果，条纹的绝对位置/密度定量预测仍需全量子处理。
  - BSH 在较长脉冲中被周内干涉淹没、无法从 TDSE 谱中提取干净线剖面，说明"脉宽—可见度"之间存在权衡，最优脉宽窗口依赖具体靶与强度参数。
  - φ₀ = 90° 下 BSH 与 TDS 条纹几乎重合难以解缠，如何进一步分离两种机制是开放问题。
  - 数值结果全部基于 SCPB 理想场模型；实验可实现脉冲（含色散残余、时空耦合、实际 CEP 稳定性）下的图样保真度有待实验验证。
  - 包络自由度（同 FWHM 下换包络）作为独立调控维度的系统性利用刚刚起步，其与波长、强度联合扫描的参数空间未探索。
  - 利用条纹间距对内禀啁啾的敏感性反演标定亚周期脉冲波形（自表征）是作者指向的应用方向，尚待实验演示。

  ## 与林赛研究的关联

  - **HHG/强场驱动接口**：本文的轨迹语言（短/长 ST、再碰撞时间 ΔT、作用量相位 ΔS）与 HHG 长短轨道分析完全同构；亚周期驱动下"啁啾缩短 ΔT → 条纹变疏"的机制同样会压缩 HHG 轨道的电离—返回时间差，是我们设计亚周期驱动 HHG 相位控制方案时必须纳入的修正项。
  - **阿秒电子动力学探测接口**：BSH 电子更贴近离子实、编码更强结构信息，半周期脉冲把 BSH 从周内干涉中干净分离出来——这正是我们"瞬态量子相位光学读出"课题想要的"干净探针"条件；CEP 0°/90° 切换相当于在同一束线上实现"全息通道/非全息通道"的模式选择器。
  - **量子几何/莫尔方向的间接接口**：若把光电子全息推广到周期性势（莫尔超晶格）中的强场电离，BSH 类近核散射轨迹对局域结构的敏感性正是探测实空间序参量（如莫尔势调制、交变磁序引起的电荷分布畸变）的候选通道；亚周期脉冲的时域纯净性对抑制超晶格多周期平均带来的相位模糊有价值。
  - **方法学可复用**：TDSE + CTM + ADK 加权 + PMAD 峰宽统计这条"定量指纹"分析流水线（含 Qprop 参数设置：L_max = 100、0.2 a.u. 网格、0.05 a.u. 步长、R_co = 300 a.u.）可直接作为我们组强场 PMD 模拟的基准配置；内禀啁啾项 A_d(t′) 的解析形式可直接搬进我们亚周期驱动方案的光线传播/场合成设计。
