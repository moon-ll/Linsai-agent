• # Structure- and laser-gauges for the semiconductor Bloch equations in high-harmonic generation in solids

  ## 林赛的理解

  这篇工作对我们组的固体 HHG 模拟方法论有直接价值。它把 SBE 计算中常被忽略、却决定结果物理正确性的两个规范问题——结构规范（structure gauge）和激光规范（laser gauge）——做了系统梳理，并给出了可操作的构造流程。特别重要的是，它用 h-BN 这个破缺反演对称的真实二维材料证明：在长度规范下省略 Berry 联络或跃迁偶极相位（TDP）会得到完全非物理的 HHG 谱（包括偏振对称性错误、谐波峰位错误）。这为我们后续用 SBE 模拟莫尔体系、交变磁体或低维量子材料的 HHG 提供了底线约束：只要用长度规范，就必须先做 PT/TPT 规范构造，必须同时保留 Berry 联络和 TDP。同时，它也指出了速度规范在“不要 dephasing、不要电流分解、只关注带隙以上高次谐波”时的效率优势，这对我们做大批量参数扫描有启发。

  ## 研究问题

  论文要回答的核心问题是：在基于半导体布洛赫方程（SBEs）的固体 HHG 模拟中，（1）如何为一般 D 维拓扑平庸体系构建光滑且布里渊区周期性的结构规范；（2）长度规范（LG）与速度规范（VG）两种激光规范各自的优缺点是什么、计算复杂度如何；（3）在破缺反演或时间反演对称性的体系中，忽略 Berry 联络和跃迁偶极相位（TDP）会带来什么后果。

  ## 研究背景

  固体 HHG 被视为产生紧凑阿秒光源和探测能带结构、Berry 曲率、拓扑相变的工具。理论框架主要包括含时密度泛函理论（TDDFT）、含时薛定谔方程和半导体布洛赫方程（SBEs）。SBEs 的优势在于能自然包含激子效应、退相位与粒子数衰减，并把总电流分解为带内电流和带间电流。然而，SBE 输入量（跃迁偶极、动量矩阵元、Berry 联络、Berry 曲率）都依赖于 Bloch 态的规范选择。由于商业软件通常对每个 k 点独立对角化，Bloch 相位随机且不连续，导致直接算出的跃迁偶极在 BZ 边界不光滑、不周期。已有文献中常见近似包括：用常数偶极耦合、忽略 Berry 联络、忽略 TDP，这些近似在破缺对称体系中的后果此前未充分探索。激光规范方面，长度规范在低阶非线性光学中有 band 收敛快、DC 极限无发散、便于处理 dephasing 和电流分解等优点，但其在 HHG 高阶谐波中的收敛性仍待研究。

  ## 研究方法

  1. **结构规范构造**：从随机相位的 Bloch 态出发，先构造平行输运规范（PT gauge），要求相邻 k 点态的 overlap 为严格正实数；再处理 BZ 边界积累的 Berry 相位，构造扭曲平行输运规范（TPT gauge），使 Bloch 函数满足周期条件 |φ_{k+b_d}^n⟩ = |φ_k^n⟩。方法适用于能带在整个 BZ 内非简并的拓扑平庸体系。

  2. **长度规范 SBEs**：在随矢势移动的晶格动量坐标 K 下求解密度矩阵 ρ^K_{mn}(t)，方程显式包含 Berry 联络 A^K_n = d^K_{nn} 和偶极耦合。电流分解为带间电流 j_ter 和带内电流 j_tra。

  3. **速度规范 SBEs**：不同 k 点解耦，密度矩阵为 g^k_{mn}(t)。为在 VG 中加入 dephasing 和电流分解，论文采用每 nδt 步将密度矩阵变换到 LG、施加衰减 ρ^k_{mn} → ρ^k_{mn} e^{-nδt δt/T_2}、计算电流后再变换回 VG 的方案。

  4. **计算复杂度分析**：给出 LG、VG 无 dephasing、VG 含 dephasing 三种情况下的标度公式，并在 1D ZnO Mathieu 模型和 2D 单层 h-BN 上做数值验证。1D 参数：Nk = 600, Nb = 5, NG = 10, nδt = 5 (δt = 0.2)；2D 参数：Nk = 200², Nb = 2, NG = 10²。

  5. **材料体系**：
     - 1D ZnO 模型：Mathieu 势 V(x) = -V_0[1 + cos(2πx/a_0)]，V_0 = 0.37，a_0 = 8。
     - 2D 单层 h-BN：赝势 Fourier 分量按 |G|²(a/2π)² = 0, 4/3, 3, 16/3 截断，对应 V^S_G = 0, 0.39634, 0.05409, 0.28664，V^{AS}_G = 0, 0.29425, 0, 0.13586；晶格常数 a = 4.7；最小带隙 E_b = 7.78 eV 位于 K 点。

  ## 主要发现与核心结论

  1. **结构规范的必要性**：长度规范 SBEs 要求光滑且 BZ 周期的结构规范；随机规范在 LG 下会给出完全错误的 HHG 谱。速度规范（无 dephasing、不求电流分解时）的结构规范无关性在 1D ZnO 模型中得到验证：PT gauge 与 random gauge 给出相同 HHG 谱。

  2. **激光规范效率对比**：
     - 1D ZnO：VG 与 LG 操作数之比 f_VG/f_LG ≈ 0.44（无 dephasing）；若加入 dephasing，f_VG,deph/f_LG ≈ 1.4。
     - 2D h-BN：f_VG,deph/f_LG ≈ 0.16，f_VG/f_LG ≈ 11。原因是 2D 中 Nb = 2 很小，VG 的优势更显著，但 VG 通常需要更多能带才能收敛。

  3. **ZnO 模型 HHG**：无 dephasing 时微扰区因相消干涉产额极低；加入 T_2 = 2 fs 退相位后恢复清晰谐波峰。LG 与 VG 结果在带隙上下均一致。

  4. **h-BN 能带与几何量**：TPT gauge 同时保证连续性和 BZ 周期性；Berry 联络在能带间不同且规范依赖，Berry 曲率在 K 点附近显著且满足 Ω^k_n = -Ω^{-k}_n。

  5. **h-BN HHG 的关键定量结果**：
     - 激光参数：A_0 = 0.35，ω_0 = 0.0285（λ = 1600 nm），τ = 29.4 fs。
     - 带内电流在所有谐波阶次上远小于带间电流。
     - Γ-K 方向线偏振：平行方向为奇次谐波，垂直方向为偶次谐波。
     - Γ-M 方向线偏振：只有平行于驱动方向的高次谐波。
     - 圆偏振驱动：20 次谐波以上出现 (22ω_0, 23ω_0) 和 (25ω_0, 26ω_0) 两对反向螺旋谐波峰，体现三重旋转对称性。
     - VG 收敛特性：带隙以上高次谐波用 10 个能带即可收敛，而带隙以下需要 30 个能带；即使 30 能带，带隙以下 LG 与 VG 仍有差异。

  6. **Berry 联络与 TDP 不可省略**：
     - 同时设 Ã^k_n ≡ 0 且 arg(d̃^k_mn) ≡ 0 时：Γ-K 平行方向大致可复现，但 Γ-K 垂直方向由正确结果的纯偶次谐波变为纯奇次谐波；Γ-M 垂直方向在全计算无产额时出现虚假产额；圆偏振下完全失真。
     - 只保留 TDP、设 Ã^k_n ≡ 0 时：所有方向均同时出现奇偶谐波，产额被严重高估。
     - 只忽略 Berry 联络、把跃迁偶极取为 K 点常数时：平行方向形状大致对但产额低估，垂直方向再次严重偏离；圆偏振下出现 6ω_0 间隔的虚假峰，错误暗示六重对称性。

  ## 潜在研究方向

  1. **简并能带与高维拓扑体系**：论文的规范构造目前仅处理 BZ 内完全非简并的能带流形。对于存在能带简并、拓扑非平庸（非零 Chern 数）或多带强耦合体系，需要推广到非阿贝尔 Berry 联络或 Wannier 规范方法。

  2. **带内-带间竞争体系**：h-BN 中带间电流占绝对主导，因此结论不能简单推广到带内、带间贡献相当的体系（例如某些低维或狄拉克材料）。需要系统性比较不同激光强度、偏振和材料参数下的规范收敛行为。

  3. **速度规范的带隙以下收敛**：h-BN 中 VG 在带隙以下需要远多于 LG 的能带，且 30 能带仍未完全收敛。这一“低速物理”机制与 DC 发散相关，值得进一步量化，并澄清是数值误差还是物理上需要更多能带。

  4. **含退相位的速度规范实现**：论文在 VG 中加入 dephasing 需要频繁 LG-VG 变换，计算量陡增。开发更高效的 VG dephasing 方案，或严格证明其规范不变性条件，是工程化模拟的需求。

  5. **圆偏振与旋转对称性**：圆偏振驱动下各种近似均严重失真，提示目前文献中基于常数偶极或忽略 TDP 的圆偏振 HHG 模拟需要重新审视。

  6. **实验验证**：论文预测了 h-BN 中特定偏振选择定则和 Berry 曲率相关的反常速度效应，可通过超快 HHG 偏振测量进行验证，并与阿秒探测、交变磁序的 HHG 信号做对比。

  ## 与林赛研究的关联

  这篇工作直接锚定我们组“强场驱动固体 HHG”的理论接口：我们若用 SBE 研究莫尔超晶格、交变磁材料或低维量子几何体系中的高次谐波，必须首先在长度规范下构造光滑周期规范并同时保留 Berry 联络与 TDP，否则谐波偏振选择定则和相对相位会被污染。这与我们正在推进的“量子几何/交变磁序的超快光学读出”方向高度相关——Berry 曲率和跃迁偶极相位本身就是我们希望通过 HHG 读出的对象。另一方面，速度规范在“只关心带隙以上高次谐波、无需电流分解”时的效率优势，可以用于 HHG 产额随激光参数扫描的预筛选。论文中 h-BN 的圆偏振 HHG 螺旋对结果，也可为我们设计利用圆偏或椭圆偏振阿秒光源探测低对称性材料的实验提供参考。最后，退相位时间 T_2 对谐波可见性的决定性作用，提示我们在与实验对比时必须把样品退相干时间作为独立拟合参数，而不是默认无限相干。

**原理**：解决 SBE 模拟中 Bloch 态规范随机性导致跃迁偶极在 BZ 边界不光滑不周期的问题：① 结构规范——先构造平行输运规范（PT gauge，相邻 k 点 overlap 严格正实数），再处理 BZ 边界积累的 Berry 相位构造扭曲平行输运规范（TPT gauge，满足 |φ_{k+b_d}^n⟩=|φ_k^n⟩），适用于 BZ 内非简并的拓扑平庸体系；② 激光规范对比——长度规范（LG）必须配 PT/TPT 规范且同时保留 Berry 联络与跃迁偶极相位 TDP，否则给出非物理谱（Γ-K 垂直方向纯偶次变纯奇次、圆偏振完全失真、虚假 6ω₀ 峰暗示错误六重对称）；速度规范（VG）对结构规范不敏感，在不要 dephasing/电流分解、只关注带隙以上谐波时效率更高（h-BN 下 f_VG/f_LG≈0.16），但带隙以下需 30 能带仍未收敛。退相位 T₂=2 fs 是微扰区谐波可见性的决定因素。
