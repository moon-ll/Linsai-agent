• # Nonlinear electron-phonon coupling drives light-induced symmetry switching in charge-density waves

  ## 林赛的理解

  这篇工作给强场超快领域提供了一个我一直在找的拼图：一个**能在含虚频软模的 CDW 晶体里做第一性原理超快晶格动力学**的理论框架。关键创新是把含四次非谐项的双势阱势能面做坐标平移（平移到 CDW 极小值），让虚频不稳定模变成正定频率的正则模，从而可以在 Heisenberg 图像下写出场量的二阶运动方程。对方法论的意义是：CDW 熔化的完整动力学——从 DECP 阻尼振荡、软模瞬时重整化到几皮秒内的 CDW 序恢复——全部可以由单胞高对称结构的 DFT 计算加 β（四次非谐系数）这一个额外参数决定。

  对我们最重要的洞察是：**线性电声耦合按对称性恒为零，光致对称切换由二阶（非线性）电声耦合 g^(2) 驱动**。这直接关联到"非线性电声耦合驱动"这一方向——Λ/Σ 形 CDW 的光致切换、拓扑物态的超快开关，本质上都是 g^(2) 在势能面上打开/闭合能垒 ΔE 的过程。单层 TiSe₂ 的数值——T_e^c ∼ 750 K 对应的吸收能 23 meV/uc、3.7 THz 软模频率、165 meV/uc 吸收能上限——可以直接作为我们设计超快调控实验的定量基准。

  ## 研究问题

  如何建立并第一性原理实现一个描述光致 CDW 序熔化（light-induced melting of CDW order）的理论框架？具体包括：如何正确处理 CDW 势能面上强烈非谐、含虚频的动力学不稳定模（harmonic 近似失效、二次量子化无法引入）；如何处理光激发载流子通过超越线性阶的电声耦合对势能面的瞬时重整化；并以单层 TiSe₂（原型 2×2 CDW 晶体）的超快熔化为例验证。中心论点：**非线性电声相互作用是 CDW 体系光致对称切换的首要机制，而普通的线性耦合按对称性恒为零**。

  ## 研究背景

  - 学术脉络：光激发可强烈修改固体势能面（PES），触发相干结构运动，进而诱导光致相变——包括瞬时的晶体对称性改变，可为超快操控拓扑、光学、输运、铁电、磁性等物性提供把手，应用指向传感、信息存储、全光电子。
  - 已有观测：光致结构相变的实验指纹包括对称破缺模振动频率的瞬时软化（TiSe₂ 等）、临界通量以上结构动力学呈现宽频谱、超临界通量下动力学变慢。Ginzburg-Landau 唯象模型（如时间依赖 GL 模型）已能复现若干关键特征，但缺材料特异性，无法识别相干结构运动的起源、耗散通道与电子-振动自由度耦合。
  - 缺口：现有第一性原理方法（TD-SCHA、机器学习势、约束 DFT、量子动力学方程、TDDFT、Heisenberg 图像相干声子动力学、非平衡 Green 函数等）均未能统一处理 CDW 晶格中"虚频不稳定模 + 光载流子非线性重整化势能面"这一对耦合挑战。
  - 前人工作：本文框架在概念上扩展了文献 [45] 的 Heisenberg 图像相干声子动力学与文献 [47, 49] 的声子自能阻尼形式；临界电子温度 T_e^c 与更早理论工作 [66, 67] 吻合良好。

  ## 研究方法

  - 理论框架三步走（核心结果为 Eq. 30–32 的晶格位移二阶微分运动方程，可对不稳定正则模 qν 用普通时间步进算法求解）：
    1. **坐标变换处理动力学不稳定**：将双势阱势能面 V = −|ω|²q²/2 + βq⁴/4 平移至极小值 q_min = ±|ω|/√β，使不稳定模获得正定频率 Ω² = −ω²/2（ω²<0），同时保留三次与四次非谐项 V^(a)；对称破缺模再分解为稳定子集 S（ω²≥0）与不稳定子集 U（ω²<0）。
    2. **电声耦合哈密顿量至二阶**：一阶 H^(1) 与二阶 H^(2) 电声耦合分别按 S/U 子集分解（H^(2) 细分为 SS、US、UU 三块），矩阵元 ĝ^(1)、ĝ^(2) 均在高对称结构的单胞内第一性原理计算。
    3. **Heisenberg 图像运动方程**：∂²_t Q + γ∂_t Q + Ω²Q = D(t)，其中 D(t) 含三次/四次非谐驱动项与含时耦合 ξ(t)Q 项；ξ(t) = (2N_p⁻¹Ω/ℏ)Σ_{nk} ĝ^{νν}_{nn}(k,q,−q)Δf_{nk}(t)，也可改写为 CDW 相一阶矩阵元形式（Eq. E5）以规避显式二阶矩阵元计算。半经典近似 ⟨Q̂ⁿ⟩ = Qⁿ，绝热近似忽略电子相干；不稳定模阻尼 γ 作唯象参数。
  - **验证体系**：单层 TiSe₂（2×2 CDW 重构的过渡金属硫族化合物）。势能面修正用约束电子占据的 Fermi-Dirac 分布模拟（T_e = 0, 460, 810, 1200 K，对应电子能量增加 ΔE = 0, 6, 23, 58 meV/uc，与实验可达激发条件兼容 [65]）；声子色散用 DFPT（原胞高对称相）；含时载流子分布 Δf_{nk}(t) 用 **TDBE**（time-dependent Boltzmann equation，显式含电声与电电相互作用）模拟，可用弛豫时间近似/双温模型作低成本替代。
  - 1D 双势阱玩具模型（Eq. 1–8）用于阐明机理：临界阈值 ξ_c = ω²/2 以下势能保持双势阱，以上变为单势阱；频率软化服从 ω̃(ξ)（Eq. 2），在 ξ_c 处归零，符合局域 Landau-Ginzburg 二级相变行为。

  ## 主要发现与核心结论

  - **对称性论证（核心结论）**：对对称破缺正则模（对称性异于高对称母结构 Ag 或 A1g），一阶电声耦合对结构动力学贡献为零（附录 D 的对称性分析），光致结构运动的最低阶贡献是二阶电声耦合——即 CDW 晶体的光致对称切换是**非线性相互作用**的体现。
  - **临界电子温度**：DFPT 声子色散显示 M 点虚频在电子温度超过 **T_e^c ∼ 750 K** 时变为正定的实频，标志 CDW→高对称相相变；T_e^c 不应与热平衡 CDW 相变温度 T_c 混淆（计入振动自由能贡献后 T_c < T_e^c）。M 点以外声子色散几乎不受电子温度影响。
  - **势能面重构**：βq² 双势阱被光激发修正项 ΔV = ξq² 逐步压平，ξ 随激发密度线性增大，超过 ξ_c 后双势阱变为 q = 0 单势阱；模型 PES 与显式 DFT 计算（2×2 超胞沿软模位移）吻合良好，残余偏差归因于六次及更高阶项。能垒随时间演化 ΔE(t) = β⁻¹[|ω|²/2 − ξ(t)]²θ(ξ_c − ξ(t))，归零即高对称态瞬时恢复。
  - **实时动力学三种 regime**（随吸收能增大）：低激发——DECP 式阻尼振荡局域在 CDW 极小（谐近似成立）；中等——非谐驱动核轨迹可切换至反号序参量的简并 CDW 相（opposite order parameter switching）；高激发——晶格绕高对称相振荡，即 CDW 熔化的主指纹，电子热化后数皮秒内 CDW 序恢复。
  - **定量光谱学特征**：低激发傅里叶谱峰位于 **ω = 3.7 THz**（与 CDW 相软模频率一致）；随激发增大峰向低频移动（结构不稳定附近特征软化行为）；吸收能谱在 **20 meV/uc 以下**为单一频率主导，**20 meV/uc 以上**变为宽频谱——与块体 TiSe₂ 通量依赖泵浦-探测实验 [19] 定性吻合；频谱呈现软化/硬化交替的能量域，对应弛豫后 CDW 凝聚到左/右不同极小（反号序参量），即通量依赖频谱可反推光激发后 CDW 凝聚的序参量符号。计算的吸收能上限达 **165 meV/uc**。

  ## 潜在研究方向

  - **方法学局限**：γ 对不稳定模作唯象参数（声子自能阻尼框架 [47, 49] 假设动力学稳定声子，不直接适用）；忽略电子相干（⟨c†c⟩ ≈ fδδ 近似）；半经典 ⟨Q̂ⁿ⟩ = Qⁿ 近似；1D 模型忽略非均匀性与长程关联的涌现。
  - **近似残差**：模型 PES 与 DFT 的偏差指向六次及以上基态势能项与更高阶电声耦合的贡献，当前四次非谐 + 二阶电声截断的定量边界未系统量化。
  - **未解决问题**：对称破缺模一阶耦合为零的结论严格依赖 Ag/A1g 对称性分类，对更复杂 CDW 重构（需复数正则坐标）和铁电体、多晶型钙钛矿等其他失稳体系的推广待验证；光致相变的微观耗散通道（载流子→晶格能量转移的模分辨路径）未在本文分解。
  - **开放接口**：TDBE 可用双温模型/弛豫时间近似替代以降低成本，但该降级的定量精度（尤其飞秒时间尺度）值得检验；时间分辨散射衍射信号与该动力学框架的直接对接尚未实现。

  ## 与林赛研究的关联

  - **CDW 超快调控 → 阿秒/强场驱动的直接接口**：本文给出 CDW 熔化的势能面-能垒语言（ΔE(t) 由 ξ(t) 实时开关），是我们研究光致序参量动力学（order-parameter ultrafast readout 课题）的理论锚点——HHG 或太赫兹发射对软模频率 3.7 THz 及其瞬时重整化的探测，可直接映射到本文的频谱演化图。
  - **非线性电声耦合（g^(2)）主线**：我们方向中"非线性电声耦合驱动"的机理在此得到第一性原理严格化——线性耦合按对称性为零、最低阶是二阶，这一判据可直接用于筛选候选材料（如 kagome 金属、单层 TMD 的 2×2×1/2×2×2 重构体系，文中明确列举）做超快对称切换。
  - **交变磁/量子几何的势能面视角**：光控晶体对称性可瞬时调制拓扑、磁性（文中列举 Weyl 半金属→平庸相变等），本文的双势阱-单势阱切换机制可作为交变磁材料光致磁态调控的动力学模板；四次非谐 β 与 Λ/Σ 形 CDW 能垒工程的关系值得在莫尔/平带体系中检验。
  - **实验设计基准**：单层 TiSe₂ 的定量参数（T_e^c ∼ 750 K ↔ 23 meV/uc、20 meV/uc 频谱展宽阈值、165 meV/uc 上限）可直接换算为我们的泵浦通量标定；频谱软化/硬化交替反映序参量符号的预测，为超快衍射 + 泵浦-探测联合读出提供了可证伪的实验设计。
  - **方法论可移植**：坐标平移处理虚频模 + Heisenberg 图像运动方程的套路，可迁移到我们自己做强场驱动晶格动力学的第一性原理模拟，特别是含失稳声子的体系。

**方法**：坐标平移处理虚频软模 + Heisenberg 图像二阶运动方程 + TDBE 载流子动力学——非线性电声耦合驱动的 CDW 光致对称切换第一性原理框架（单层 TiSe₂）

**原理**：三步走处理'虚频不稳定模 + 光载流子非线性重整化势能面'的耦合挑战：①将含四次非谐的双势阱势能面 V = −|ω|²q²/2 + βq⁴/4 平移至极小值，使不稳定模获得正定频率（对称破缺模分稳定 S/不稳定 U 子集）；②电声耦合哈密顿量展开至二阶（H⁽²⁾ 分 SS/US/UU 三块），矩阵元均在高对称单胞内 DFT 计算；③Heisenberg 图像得晶格位移二阶微分运动方程 ∂²_tQ + γ∂_tQ + Ω²Q = D(t)，含时耦合 ξ(t) 由光激发载流子分布驱动（TDBE 显式含电声/电电相互作用，可用双温模型降级）。核心对称性结论：对对称破缺正则模，一阶电声耦合按对称性恒为零——光致对称切换由二阶（非线性）电声耦合 g⁽²⁾ 驱动；1D 玩具模型给临界阈值 ξ_c = ω²/2（以下双势阱、以上单势阱），频率软化在 ξ_c 归零（二级相变行为）。
