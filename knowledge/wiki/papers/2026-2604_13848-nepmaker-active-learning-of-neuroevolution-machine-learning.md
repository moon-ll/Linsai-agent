# NEPMaker: Active learning of neuroevolution machine learning potential for large cells

## 林赛的理解

这篇论文解决的是机器学习势（MLP）领域一个我一直关注的痛点：势函数训练集与外推场景脱节。NEP 是 GPUMD 里的神经演化势，速度快，适合大体系，但传统流程是"先跑小体系采样 → 训练 → 再跑大体系"，大体系里出现的缺陷、界面、相变等局域环境往往不在训练集覆盖范围内，外推误差就是从这里来的。

NEPMaker 的思路是把主动学习嵌进 MD 运行过程本身：基于 D-最优性（D-optimality）实验设计准则，实时识别哪些原子环境属于外推区域，并用局部周期性结构标注把这些环境捕获下来，直接补充进训练集。这样大规模模拟不再是训练的"消费者"，而是训练集的"生产者"——模拟跑到哪，训练集就长到哪，外推误差被持续压低。

对我做强场超快光学的人来说，这个方向有直接的映射价值。我们关心的很多过程——强激光场驱动下的晶格动力学、光致相变、缺陷辅助的载流子动力学——本质上都是大体系、长时间、远离平衡态的 MD 问题，而训练数据恰恰最难从这些过程里采。一个能在模拟进行中自己发现"我没见过这种环境"并回头补训练的框架，理论上正是这类问题需要的工具链。

## 核心要点

- **D-最优性主动学习框架**：在 GPUMD/NEP 体系中实现，用实验设计中的 D-最优性准则来量化新环境与已有训练集的差异，作为"是否值得采样"的判据。
- **实时外推识别**：MD 运行过程中在线判断哪些原子环境处于外推区域，而不是事后分析轨迹再补采样。
- **局部周期性结构标注**：对识别出的外推环境做局域结构标记，使其可以被捕获并纳入训练集——这是把"大体系模拟"接入"训练集构建"的关键机制。
- **大规模模拟直接参与训练**：缺陷、界面、相变等大体系模拟场景不再是训练完成后的应用端，而是训练数据的直接来源，形成"模拟 → 发现外推 → 补充训练 → 降低外推误差"的闭环。
- **持续降低外推误差**：框架目标是迭代式收敛，而非一次性训练。

## 实验/研究关联

- 与我课题库中 `key-transient-quantum-phase-optical-20260726`（瞬态量子相的光学调控）相关：强场驱动下的超快晶格响应往往涉及大超胞和远离平衡的路径，如果要用 NEP 级别的机器学习势做这类模拟，主动学习框架几乎是必需品——否则训练集根本覆盖不到激光驱动访问的构型空间。
- 方法学层面可借鉴的点：**D-最优性作为采样判据**的思想不局限于 NEP。任何"高维空间选代表性样本"的问题（例如我们从强场 MD 轨迹中挑选代表性快照做 TDDFT/量子动力学计算）都面临同样的外推难题，这套"运行中识别 + 结构标注 + 回流训练"的闭环设计有移植潜力。
- 与知识库中方法学素材的衔接：GPUMD/NEP 是我们做大规模材料模拟的候选工具之一，NEPMaker 补上了它从"小体系采样"到"大体系自扩展训练"的关键一环，值得在方法手册中占一席。

## 批判性思考

- 摘要级信息只给出了框架设计，**没有给出定量基准**：D-最优性判据的阈值如何选取、外推误差随迭代轮次下降多快、与已有主动学习方案（如不确定性采样、 committee 模型分歧）相比精度与效率孰优，都需要读全文验证。
- **"实时"的代价存疑**：MD 运行中在线做 D-最优性计算和结构标注，开销多大？是否会显著拖慢大体系模拟的吞吐？摘要未提计算成本。
- **标注质量决定上限**：框架识别出外推环境只是第一步，对含缺陷/界面的复杂局域结构，标注是否准确、是否引入噪声标签，直接决定回流训练的效果。
- 对强场场景还有一个摘要未覆盖的隐患：我们的模拟对象是非平衡的激光驱动过程，而 NEP 类势通常面向平衡或近平衡势能面。主动学习降低的是构型空间的外推误差，但强场下的电子-声子耦合、激发态势能面本身是否在这类势函数的适用边界内，是另一个层面的问题，不能指望 NEPMaker 解决。

## 研究方法（方法卡）

**方法**：NEPMaker：大尺寸胞元主动学习神经进化机器学习势（GPUMD/NEP 框架内嵌 D-最优性外推环境实时识别 + 局部周期性结构标注闭环）

**原理**：把主动学习直接嵌入大尺度 MD 生产过程（非模拟后离线补采）：在 GPUMD/NEP 框架中依据 D-最优性识别当前 MD 轨迹里的外推原子环境，将构型及局部周期性结构信息加入训练集，持续扩充降低外推误差——「为了获得势而单独做模拟」转变为「生产模拟本身同时生成训练数据」的数据-模型迭代闭环（运行 MD → 识别外推环境 → 补充带结构标注样本 → 更新训练集）；区别于仅保存能量/力标量标签的设计：局部周期性结构标注嵌入训练集（大胞元中局部有序与全局缺陷/界面并存）；面向机器学习势最易失效的非理想局域环境（缺陷、界面、相变）。
