• # Self-consistent tensor network method for correlated super-moiré matter beyond one billion sites

  ## 林赛的理解

  这篇工作对我们组的价值不在于它直接研究了超快光学现象，而在于它提供了一套**能处理十亿原子位点级莫尔/超莫尔体系关联基态与局域谱函数**的数值引擎。我们课题中反复遇到的瓶颈是：实验上关注的关联电子体系（交变磁、莫尔、强关联绝缘体）往往需要处理数十万到上亿的位点，传统稀疏矩阵 KPM 或精确对角化完全不可行。这篇论文用 MPO + Chebyshev 核多项式 + quantics 张量交叉插值（QTCI）把"自洽平均场哈密顿量太大无法显式存储"的问题转化为线性标度的赝自旋多体问题，1D 中 2³⁰≳10⁹ 位点的体系在单核 i5 CPU 上只用 4×10⁴ 秒就解完，比此前稀疏矩阵方案快约四个数量级。这意味着我们可以用它来做关联莫尔体系的实空间局域态密度/谱函数计算，特别是未来叠加**光驱动（含时哈密顿量 + 时间演化）**后，有望直接模拟强场驱动下超莫尔体系的关联态响应——这正中我们 HHG/阿秒探针课题的理论接口。

  ## 研究问题

  如何在保留电子间相互作用的前提下，求解规模达到**十亿原子位点**级别的超莫尔（super-moiré）体系的关联基态与局域谱函数——即：当自洽平均场哈密顿量 H^MF 大到连稀疏矩阵形式都无法存储时，是否还能对其进行自洽求解并得到实空间的物理可观测量（局域谱函数、磁化分布、空间调制能隙）？论文的中心目标是为"关联超莫尔量子物质"提供一种可扩展到极端系统尺寸的求解方法论。

  ## 研究背景

  - 扭转莫尔材料已催生出非常规超导、拓扑态、关联绝缘体等一系列关联物相，其莫尔单胞含数千至数十万位点，已达传统原子级关联计算方法的极限；当两个及以上莫尔图案共存时形成超莫尔结构，所需位点数进一步推向百万至亿级，常规计算方法失效。
  - 张量网络（tensor network）以线性标度的变分张量积压缩 2^L 维 Hilbert 空间，在量子多体、机器学习、量子计算等领域已有成功应用；此前同组工作（文中 ref [59]）已尝试用张量网络处理超莫尔问题，但稀疏矩阵表示限制了体系规模。
  - 本文正是在该脉络下建立一套自洽张量网络算法，突破显式存储哈密顿量的瓶颈。

  ## 研究方法

  - **模型**：实空间哈密顿量 H = H₀ + H_V = Σ t_αβ c†_α c_β + Σ V_αβ c†_α c_α c†_β c_β（密度-密度相互作用），N = 2^L 位点；通过平均场解耦得自洽哈密顿量 H^MF_αβ = t_αβ + χ_αβ。
  - **核心映射**：把 2^L 位点的平均场哈密顿量重新诠释为 L 位点赝自旋链的多体算符，用矩阵乘积算符（MPO）表示 H^MF = Γ⁽¹⁾Γ⁽²⁾…Γ⁽ᴸ⁾，键维 m 可控。
  - **关键算法组合**：张量网络 Chebyshev 核多项式方法（KPM，谱重标定至 (-1,1)，密度矩阵 Ξ(H^MF)=Σ λ_n T_n(H^MF)）+ quantics 张量交叉插值（QTCI），后者把空间调制的跃迁幅 t(X_α) 压缩为 MPS，再转为对角 MPO 与移位算符 S 收缩构造完整哈密顿量。附录给出 1D 最近邻/次近邻及 2D 方格、三角、蜂窝格子的系统 MPO 构造方案（如 S^{2^N}=∏S¹、链间跃迁 S^{2^M} 移位）。
  - **演示体系**：1D 调制跃迁模型（t(X_α)=1+0.2cos(k₁X_α)+0.2cos(k₂X_α)，k₁=2π/(5√2)，k₂=8π/(229√3)，Hubbard U=2.7）；2D 超莫尔石墨烯与方格子（2³¹ 位点，形状 2¹⁶×2¹⁵，U=5.5t，t_ij 正弦双频调制）；含域壁的调制（δ=0.2/0.3，W=2³⁰/40、W=3000、W=819.2 等 tanh 剖面）；八重旋转对称调制 Hubbard 作用的准晶体系（U(r_i)=8+0.5{Σ cos(k₁n_i·r_i)+cos(k₂n_i·r_i)}，2³⁰=2¹⁵×2¹⁵ 位点）。
  - **基准测试**：固定 Chebyshev 多项式数 N_c=250、键维 χ=100，自洽收敛判据 ε<10⁻³（ε_n = max|ρⁿ − ρⁿ⁻¹|）。

  ## 主要发现与核心结论

  - **规模突破**：1D 中 2³⁰≳10⁹ 位点的超莫尔体系含相互作用局域谱函数计算，在 Intel i5 单核上耗时 4×10⁴ s，相比此前稀疏矩阵方法（ref [59] 路线）估计耗时加速约**四个数量级**，且原稀疏方法在实际上根本不可行。可处理体系规模提升超过三个数量级。
  - **复杂度标度**：在固定 χ 和 N_c 下，N=10 轮自洽迭代的总运行时间随位点数呈对数标度 O(log N)（随 L 指数线性），对比传统 KPM 的 O(N²)。
  - **物理结果**：1D 中 Hubbard 相互作用诱导出空间非均匀能隙——其空间变化由大莫尔尺度 k₂ 主导，在小莫尔尺度 k₁ 上近似均匀，原因是 U 与较小莫尔尺度同量级、相对较大莫尔尺度可忽略；域壁只对大莫尔尺度调制敏感，小莫尔尺度谱函数不受域壁影响（δ=0.2，W=2³⁰/40）。2D 中磁化 M_z=|ρ↑−ρ↓| 在所有尺度上精确跟随跃迁调制，能同时分辨超莫尔图案与域壁；八重对称准晶调制 U(r_i) 的局域磁化分布在大小尺度上均紧贴 U(r_i) 调制。
  - **谱重标定的简化**：单电子有效平均场哈密顿量的带宽与体系尺寸无关（1D W≈4t+U，2D 方格 W≈8t+U、蜂窝 W≈6t+U），谱函数无长尾，大幅简化 KPM 的 (-1,1) 重标定步骤。

  ## 潜在研究方向

  - **方法局限**：高度无序体系（每位点独立）无法用 QTCI 有效压缩为小键维张量网络；仅"稀疏无序"（稀杂质、扭转无序、域壁等可确定性函数表示的剖面）适用——文中 1D/2D 域壁结果即属此类。
  - **未拓展的方向**（即机会点）：① 目前仅做自洽平均场 + 静态谱函数，论文结尾明确指出该 MPO 框架天然兼容实时间演化张量网络算法，可扩展至超莫尔体系的动力学计算——这是通向含时/驱动问题的直接接口；② 可扩展到实空间密度泛函理论（DFT），进一步提升可处理体系尺寸；③ 多体微扰论与实空间线性响应的张量网络实现是作者点名的下一步。
  - 键维 χ 与 Chebyshev 阶数 N_c 的标度行为需要随问题重新标定，论文的对数标度结论是在固定 χ、N_c 前提下成立的。

  ## 与林赛研究的关联

  - **莫尔/超莫尔**：本组 `general-moire-strong-field-probe-20260726` 课题已直接挂靠此文。它解决了我们莫尔体系中"实验尺度 vs 计算尺度"错配的核心矛盾——十亿位点实空间关联计算使理论模拟首次能对标真实扭转角度（极小角、超大单胞）下的实验体系。
  - **强场驱动 / HHG / 阿秒**：方法的 MPO-KPM 内核与时间演化张量网络（TEBD/Time-dependent variational principle）天然兼容，下一步可将静态 H^MF 换成含光场驱动项 H(t)，计算强场驱动下关联莫尔/超莫尔体系的含时谱响应与交变磁态的高次谐波产生，这是我们 HHG-探针方向的关键理论工具链候选。
  - **交变磁 / 量子几何**：2D 演示中 M_z 磁化纹理对空间调制的忠实再现，说明该引擎可直接用于交变磁/反铁磁莫尔超结构的实空间磁态与关联谱预测，为阿秒磁动力学探针提供基态输入。
  - **实验接口**：文中提及 1D 体系可由光学量子模拟、多壁纳米管实现，2D 方格超莫尔可由光子晶格和扭转材料实现——与超快光学/光子学实验平台对接顺畅。

**方法**：MPO + Chebyshev 核多项式（KPM）+ quantics 张量交叉插值（QTCI）——十亿位点级关联超莫尔体系自洽张量网络方法：自洽平均场 + 局域谱函数的线性标度求解

**原理**：突破'自洽平均场哈密顿量 H^MF 太大无法显式存储'的瓶颈：把 2^L 位点的平均场哈密顿量重新诠释为 L 位点赝自旋链的多体算符，用矩阵乘积算符 MPO 表示 H^MF = Γ⁽¹⁾Γ⁽²⁾…Γ⁽ᴸ⁾（键维可控）；算法组合 = 张量网络 Chebyshev 核多项式（谱重标定至 (-1,1)，密度矩阵 Ξ = Σλ_n T_n(H^MF)）+ QTCI（把空间调制跃迁幅压缩为 MPS，转对角 MPO 与移位算符收缩构造完整哈密顿量）；附录给出 1D 最近邻/次近邻与 2D 方格/三角/蜂窝格子的系统 MPO 构造（S^{2^N} = ∏S¹、链间跃迁 S^{2^M} 移位）。谱重标定简化：单电子有效平均场哈密顿量带宽与体系尺寸无关（1D W≈4t+U、2D 方格 W≈8t+U、蜂窝 W≈6t+U），谱函数无长尾。
