• # Description of two-dimensional altermagnetism: Categorization using spin group theory

  ## 林赛的理解

  这篇工作对我们交变磁（altermagnet）方向的价值不在预测了哪几个新材料，而在**建立了二维交变磁体的群论描述框架**——二维情形此前没有公认的对称性语言，3D 用 10 个自旋 Laue 群（其中 5 个 plane 型被认为可用于 2D），他们证明实际存在**七个二维自旋层群**，比传统分类多出两类（`22/2mx` 与 `132m`，原本被归为 bulk 型）。这意味着我们之前按"plane 型五个群"做材料筛选时可能漏掉了相当一部分二维交变磁候选。对我们课题组而言，这篇论文直接提供了三个可用接口：一是**对称性判据**——不依赖 DFT 即可预言哪些 k 路径有自旋劈裂、哪些有自旋简并节线，这能显著降低我们做光学响应（如磁光 Kerr、偏振二次谐波）候选材料筛选的成本；二是**MnTeMoO6 和 VP2H8(NO4)2 两个新材料**，其中 MnTeMoO6 的交变磁基态能量比铁磁态低 8.5 meV/磁原子，基态判定相当可靠，值得列入强场光-物质耦合候选池；三是附录 B 的关键信息——SOC 引起的劈裂小于交变磁本征劈裂，说明在这些体系中用**非相对论极限下的自旋劈裂能带**描述光学/太赫兹响应是成立的，这为我们用强场驱动探测自旋-动量锁定电子结构提供了理论基础。

  ## 研究问题

  如何用一个严格的对称性群论框架描述和分类**二维交变磁性**（two-dimensional altermagnetism）？具体包括三个子问题：（1）3D 交变磁性已由 32 个非平凡自旋 Laue 群描述（其中 10 个对应交变磁），但二维材料的对称性描述此前未被解决——二维情形该用多少、哪些群来描述？（2）这些群的自旋-动量锁定特征（spin-momentum locking）如何决定能带的自旋简并线与自旋劈裂 k 路径？（3）基于该分类，能否在材料数据库中系统搜寻新的二维交变磁候选材料，并验证已报道的二维交变磁体？

  ## 研究背景

  - 交变磁性 2019 年已有理论提出，2022 年正式命名，是继铁磁、反铁磁之后的第三种磁态：实空间共线补偿磁序 + 倒空间时间反演对称性破缺。其判据是两个反向磁性子晶格由**旋转或镜面**对称连接（而非反铁磁的平移/反演对称连接），导致 PT 对称破缺。
  - 3D 交变磁体（RuO2、MnTe、MnF2 等）已观测到反常霍尔效应、Kerr 效应（文献 [14–17]）、ARPES 直接观测到 MnTe 的自旋劈裂电子结构 [18]；应用层面有 GMR/TMR [19] 与自旋劈裂矩 [20] 的预言与实验。
  - 但已知交变磁体绝大多数是 3D 的，二维报道很少：已知案例包括外场/ Janus 结构诱导的 MnP(S,Se)3 单层 [22]、理论预言的 V2Te2O [23] 与 RuF4 [24]；还有理论预言 2D 交变磁中可能出现磁振子媒介超导 [25]，但**没有任何具体材料被实验证实**。
  - 3D 情形已有自旋 Laue 群描述 [10]：5 个 plane 型自旋 Laue 群被认为同时适用于二维和三维晶体，5 个 bulk 型只出现于三维——但二维情形的正确描述此前没有解决。
  - 二维磁性还受 Mermin-Wagner 定理 [26] 约束：有限温度下 2D 材料的磁序必须依赖 SOC 提供的磁各向异性；已有工作指出 SOC 可能使 2D 交变磁体出现弱铁磁与 SOC 诱导劈裂 [27]。作者在主线计算中略去 SOC（交变磁源于非相对论对称性），但在附录 B 做了含/不含 SOC 的对比。

  ## 研究方法

  - **理论框架**：自旋群形式化（Litvin 记号），自旋群 = 自旋单群 ⊗ 非平凡自旋群 `[Ri||Rj]`（双竖线左侧只作用于自旋空间，右侧只作用于实空间）。对共线磁序，自旋单群含 `C∞`（绕共线自旋轴任意旋转，保证自旋是好量子数，能带严格分为自旋上/下通道）与 `[C2||T]`（`ε(s, k) = ε(s, −k)`，等价于倒空间反演）。
  - **选择层群而非点群作为实空间群**，理由有二：实际研究的是准二维材料而非严格二维；点群会引入歧义。将所有 80 个层群与空间反演群做直积得到全部倒空间对称群（属 Laue 群），列于 Table I（共 10 个倒空间群）。
  - **排除自旋简并保护对称性**：二维中共 4 个对称性保护全布里渊区自旋简并——`[C2||τ]`（等价于 `[C2||E]`）、`[C2||E]`（与 `[C2||T]` 组合给出 PT/Kramers 简并）、以及二维特有的 `[C2||mz]` 和 `[C2||C2z]`。凡实空间含 `{τ, mz, E, C2z}` 之一的对称性，在交变相必须配自旋空间恒等，因此不能连接两个子晶格。
  - **推导非平凡自旋层群**：由 `R3 = [E||H] + [C2||G − H]`（H 为层群 G 的减半子群）构造，对应零磁化 + 时间反演破缺 = 交变磁。最终得到 **7 个非平凡自旋层群**（Table II），用 Litvin 记号表示（上标 1 = 自旋空间恒等，2 = 自旋空间 C2）。
  - **材料搜寻**：在 Materials Project 数据库 [28] 中，按"含过渡金属 + 空间群对应该自旋层群 [32, 33] + vdW 结构 + AFM 磁构型"筛选候选，再逐个做对称性分析判定是否为交变磁。筛选手工完成，对每个群只找一个候选即停止。
  - **DFT 计算细节（附录 A）**：VASP + PAW，GGA-PBE 泛函 + Hubbard U 修正；平面波截断能 **500 eV**；原子力弛豫至 **< 0.01 eV/Å**；电子自洽能量收敛标准 **1 × 10⁻⁷ eV**；垂直材料平面真空层 **15 Å**；所有计算不含 SOC。所用 U 值与晶格常数（Table III）：RuF4 不加 U，a = 5.42 Å、b = 5.09 Å；Mn2P2S3Se3 不加 U，a = b = 6.22 Å；MnTeMoO6 取 U(Mn) = 3.9 eV、U(Mo) = 4.38 eV，a = 5.14 Å、b = 5.41 Å；VP2H8(NO4)2 取 U(V) = 3.25 eV，a = b = 8.46 Å。

  ## 主要发现与核心结论

  1. **建立 7 个二维自旋层群**，超越此前认为二维可用 5 个 plane 型自旋 Laue 群的分类。五个旧群全部包含在新分类内；新增的两类此前被归为 bulk 型：
     - `22/2mx`（`R3 = [E||{E, E}] + [C2||{C2x, mx}]`）：因保护全布里渊区简并的对称性 `[C2||mz]` 消失而进入二维分类，其自旋-动量锁定特征与已知的 `2m2m1m` 相同；材料代表为 **RuF4**（层群 No.18）。
     - `132m`：此前在 3D 分类中属 bulk 型，二维中因 `[C2||mz]` 与 `[C2||C2z]` 双双缺席而出现；由于倒空间中 `C+3z` 等价于 `C−6z`，其锁定特征与 `16/1m2m2m` 相同；材料代表为 Janus 结构 **Mn2P2S3Se3**（层群 No.70，Mn 两侧分别为 S 和 Se 面）。
  2. **预言两个新二维交变磁材料**（此前未见报道）：
     - **单层 MnTeMoO6**：vdW 材料，可从体相剥离；层群 No.21（含 C2z 二重旋转与两个螺旋轴）；自旋层群 `2m2m1m`。DFT 给出**交变磁态能量比铁磁态低 8.5 meV/磁原子**，故磁基态为交变磁态。自旋-动量锁定由 `[C2||C2x]`（`[C2||C2y]`）决定：kx = 0（ky = 0）处有自旋简并节线；Γ–X–S1–Y–Γ 路径全简并，而 S1–Γ–S2 路径自旋劈裂、Γ–S1 与 Γ–S2 自旋符号相反。
     - **VP2H8(NO4)2**：vdW 材料；层群 No.56（含 z 轴四重旋转、(110) 镜面及三个滑移面）；自旋层群 `14/1m2m2m`。**交变磁态能量比铁磁态低 0.47 meV/磁原子**，基态为交变磁态（注意该能量差很小）。锁定由 `[C2||{mx, my, m110, m̄110}]` 决定：kx = 0 与 ky = 0 处简并节线；Γ–X–M–Γ 全简并，X1–Γ–X2 劈裂且 Γ–X1 与 Γ–X2 自旋符号相反。
  3. **已报道二维交变磁体的归类**（Table II）：V2Se2O、V2Te2O、Cr2O2 属 `24/1m2m1m`——报道材料多数集中在这一群；RuF4 属 `22/2mx`，Mn2P2S3Se3 属 `132m`，验证了新分类。
  4. **7 个群中 2 个仍无材料候选**：`24/1m` 与 `16/1m2m2m`，作者推测因其对称性要求过高；但认为这两个群存在（它们也包含在自旋 Laue 群分类中）。
  5. **附录 B（含 SOC 对比）**：所有材料含 SOC 的带结构显示，**SOC 引起的自旋劈裂幅度小于交变磁本征劈裂**，交变磁是这些材料自旋劈裂的主导来源，故不含 SOC 的讨论成立。MnTeMoO6 中带交叉点（FIG.3(d)）在计入 SOC 后消失（FIG.5(f)），据此判定**这些点不是 Weyl 点**。
  6. 广义结论：对一切共线磁体（无论有无实空间反演对称性），非相对论能带在实空间反演操作下不变（`ε(s, k) = ε(s, −k)`），这一性质大幅简化了自旋层群推导。

  ## 潜在研究方向

  - **二维交变磁的重要性本身仍是开放问题**；需要含 SOC 的更严谨 DFT 与进一步讨论（主线计算略去 SOC 是近似，尽管附录 B 表明近似合理）。
  - **二维交变磁体完全缺乏实验探索**：目前所有 2D 候选均为理论预言，无 ARPES、磁输运或磁光实验验证——这既是缺口也是机会。
  - 交变磁中**非共线磁态是否区别于反铁磁中的非共线磁态**，值得深入探讨。
  - `24/1m` 与 `16/1m2m2m` 两个群尚未找到材料候选，高对称性要求的真实材料实现是空白。
  - 磁振子媒介超导 [25]（宣称可调化学势提高临界温度）仍未在任何具体材料上验证。
  - VP2H8(NO4)2 的交变磁-铁磁能量差仅 0.47 meV/磁原子，其基态判定对计算细节（U 值、泛函）敏感，需要更严格的能量学验证。
  - 作者的筛选为手工操作、每群只找一个候选即止，系统性高通量筛选（作者亦指出需要算法化）仍有空间。

  ## 与林赛研究的关联

  - **强场驱动 / HHG / 阿秒探测交变磁**：交变磁体倒空间 T 对称破缺 + 自旋-动量锁定能带是强场光学响应的天然舞台——7 个自旋层群各自给出确定的自旋简并节线位置与自旋劈裂 k 路径（Table II 第二列），等于**不跑 DFT 就能预言哪些动量路径会出现劈裂能带**，可直接用于设计强场驱动下的自旋分辨 HHG 或偏振磁光实验的候选材料清单。附录 B 证实 SOC 劈裂 < 交变磁本征劈裂，意味着用非相对论自旋劈裂能带做阿秒尺度自旋动力学建模是可控近似。
  - **交变磁方向直接接口**：本笔记已被课题 `general-berry-mnps3-rashba-20260816`（MnPS3 相关）引用。Janus Mn2P2S3Se3 的对称性分析（`132m`，三度旋转 + 垂直镜面连接反向子晶格）与我们 MnPS3 系的能带 Berry 几何研究直接相关；电场/Janus 结构破缺子晶格间反演对称即可诱导交变磁 [22]，这给我们已有的 MnPS3 Rashba/berry 课题提供了一个明确的**结构调控旋钮**。
  - **莫尔方向接口**：层群描述天然适配准二维 vdW 材料（MnTeMoO6、VP2H8(NO4)2 均为可剥离 vdW 体），层间堆叠与莫尔超晶格会进一步降低实空间对称性群，可在此框架下系统分析交变磁对称性在莫尔工程下的存活与破缺——这是本框架尚未触及但群论语言完全可承接的方向。
  - **量子几何与输运**：自旋劈裂能带 + 倒空间 T 破缺意味着反常霍尔/Kerr 响应的非零通道，对称性判据可直接用于筛选具有大相空间 Berry 曲率的 2D 交变磁候选，对接我们的强场超快输运读出设想。
  - **具体候选建议**：MnTeMoO6（8.5 meV/磁原子的稳健交变磁基态）优先列入强场光-物质耦合实验候选池；VP2H8(NO4)2 能量差过小（0.47 meV），建议先做能量学复核再投入。

## 研究方法（方法卡）
<!-- methods-backfill:v1 -->
**方法**：二维交变磁性的自旋层群描述与材料搜寻（Litvin 记号 + 层群直积 + 7 个非平凡自旋层群）

**原理**：自旋群形式化（Litvin 记号 [Ri||Rj]）：共线磁序的自旋单群含 C∞（保证能带严格自旋上/下分通道）与 [C2||T]（倒空间反演）；选层群而非点群作实空间群（准二维实际 + 避免歧义），80 个层群与空间反演群直积得 10 个倒空间群（Laue 群，Table I）；排除 4 个自旋简并保护对称性（[C2||τ]、[C2||E]、二维特有 [C2||mz]、[C2||C2z]——交变相须配自旋恒等故不能连接子晶格）；由 R₃=[E||H]+[C2||G−H] 构造得 7 个非平凡自旋层群（零磁化+时间反演破缺=交变磁）；Materials Project 按'含过渡金属+空间群对应+vdW+AFM'手工筛选，DFT（VASP PAW GGA-PBE+U，无 SOC）验证自旋劈裂。
