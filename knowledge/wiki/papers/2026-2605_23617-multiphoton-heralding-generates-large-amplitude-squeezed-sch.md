• # OPA 多光子预报生成大振幅压缩薛定谔猫态与宇称选择 Fock 叠加态

  ## 林赛的理解

  这篇工作对我们组的意义在于"资源态工程"这个角度：它展示了用一个参数（OPA 增益 g、输入压缩 r、m 光子注入、n 光子探测）系统调谐，就能在单台器件上实现等效 ≥3 阶光子相减、产出大振幅压缩猫态。对我们强场超快方向，直接的接口有二：

  1. **非高斯量子光源作为阿秒计量/超灵敏探测的探针态**。文中论证这些态在相位估计上超越海森堡极限，且光子损耗下相位空间复杂度 C 比 Wigner 负性衰减慢得多——这与我们关心的"强场测量在真实损耗环境下的可恢复信息量"是同一个问题框架。C 与 QFI 的正相关性（原文：high C correlates with large QFI）值得我们在设计超灵敏探测方案时借鉴。
  2. **器件级调优方法论**。猫态振幅 α≥2（e^{-2α²}≪1 保证容错纠错所需近正交性）这一"大振幅才是有用资源"的判据，可直接迁移为我们评估任何非经典光源实用价值的门槛函数。

  需要直说：这是纯理论协议论文（QuTiP 数值模拟），没有实验装置参数可采集，对 HHG/阿秒实验方案的直接方法素材贡献有限；其价值在概念层和资源判据层。

  ## 研究问题

  核心问题（原文明确）：**多光子输入与多光子探测能否在 OPA 中实现等效 k≥3 阶光子相减？**进而：并非所有满足 k=m+n 的 (m,n) 组合都能逼近压缩薛定谔猫态——哪些配置通过优化 OPA 增益 g 和输入压缩 r 能产生高保真目标态？以及这些非高斯态在相位估计中的量子计量优势和光子损耗下的韧性如何（后两方面为其前作 [24] 所未考虑）。

  子目标包括：
  - 给出一般性的宇称选择规则（m+n 奇偶决定输出态只含奇/偶 Fock 分量）；
  - 识别生成大振幅 SOSC 态的最优 (m,n) 组合，将猫态振幅推进到容错纠错所需的 α≥2 区间；
  - 提出 Wigner 负性 N 之外的互补度量——相位空间复杂度 C——刻画损耗下的结构保持。

  ## 研究背景

  连续变量量子信息中，压缩真空、相干态、热态等**高斯态**是主力（QKD、玻色采样等），但它们在相空间构成经典子流形，缺少非高斯资源时**无法实现通用 CV 量子计算或容错纠错**。非高斯态——薛定谔猫态、光子添加态、Fock 叠加态——通过实现通用门集 [10–12]、玻色编码纠错 [13–16]、量子计量超越标准量子极限 [18–21] 来突破此限制。

  标准制备路径是分束器上的条件测量（光子相减）：k 光子相减可实现振幅至多为 α~√k 的猫态。例如单光子相减产生 α≤1 的小振幅奇猫态（保真度 >0.99），但容错纠错需要 α≥2（e^{-2α²}≪1），这意味着至少探测 4 个光子，成功率随分束器反射率 R~0.02–0.05 按 R⁴ 标度，产率极低 [33]。广义光子相减 (GPS)、后选择弱测量、压缩蒸馏、量子光学催化 (QOC) 等虽有改进，但均为特定目标态定制、缺乏灵活性。

  OPA 的替代方案史：2019 年 Shringarpure 与 Franson 证明 OPA 可在无实际光子添加的情况下制备光子添加态 [44]；本组前作 [45] 将单光子注入+探测（(1,1) 配置）扩展到压缩真空输入，实现等效双光子相减、产出低阶偶猫态。近期 Erlick 等 [48] 在同一装置下只考察了真空 idler 输入 (m=0) 情形（此时 OPA 扮演"光子添加+衰减"角色）。**本文是首个系统性考察 m≥2 或 n≥2 多光子预报配置的工作。**

  ## 研究方法

  本论文为纯理论协议，无实验装置；方法密度中等，按方法卡格式整理其数值模拟协议与资源判据：

  **原理**
  通过双模压缩幺正 S(τ)=exp(τ*ab−τa†b†)（τ=ϱe^{iδ}，增益 g=coshϱ，G=tanhϱ=√(g²−1)/g）描述 OPA；idler 端注入 m 光子并对输出做光子数分辨探测（投影算符 Π_n=|n⟩⟨n|），在信号端预报非高斯态。对压缩真空输入 |ξ⟩（z=re^{iθ}，压缩水平 dB=−20 log₁₀(e^{−r})），通过调节 r、g、m、n 实现等效 k=m+n 阶光子相减。

  **计算设置（数值模拟协议）**
  - 模拟平台：QuTiP [46]（全文唯一数值工具）
  - 基准参数：r=1.0（≈8.69 dB）、θ=φ=0、g=1.5 用于 Wigner 函数全网格扫描（m=0–5 × n=0–4，Fig. 2）
  - 保真度扫描网格：r∈[0,3]，g∈(1,10]（各配置小节统一声明）
  - 目标态族：S(γ)|Cat⟩_{θ,α}（SOSC/SESC，归一化系数 N_θ=(2+2e^{−2α²}e^{2r}cosθ)^{−1/2}）；光子操作态 a²|Ψ_π⟩、a†²|Ψ_0⟩、a†a|Ψ_0⟩、a†²|Ψ_π⟩、a†³a|Ψ_π⟩、a†²a²|Ψ_π⟩ 等

  **两个资源度量（核心判据）**
  - Wigner 负性：N=∫|W(α|ρ)|d²α/π − 1 [50]——量子干涉资源指示
  - 相位空间复杂度：C(ρ)=e^{S_W(ρ)−1} I(ρ) [51]——由 Husimi Q 函数定义，Wehrl 熵 S_W 与 Fisher 信息 I 的构型权衡；C=1 为位移热态最小值；SV 态 C 大而 N=0。损耗下 C 衰减远慢于 N，是更具损耗韧性的结构度量，且与 QFI 正相关

  **装置概念图（无实验参数）**
  OPA 输入端口：idler 端 |m⟩（m 光子），信号端 |ϕ⟩（SV/相干态/小振幅猫态任选）；idler 输出经 PNRD 探测 n 光子，信号输出端即预报态 |Ψ⟩_{sv,m,n}。可行性讨论（Sec. VI）涉及成功概率与损耗，但全文截断部分未见具体数值。

  ## 主要发现与核心结论

  **一般性规则**
  - OPA 保持总宇称，预报态宇称为 (−1)^{m+n}：m+n 偶 → 只含偶 Fock 分量；m+n 奇 → 只含奇 Fock 分量。该规则对任意 (m,n) 普遍成立。
  - 随 g 增大，Wigner 负性 N 与复杂度 C 均增，且随 n 增大排序（n=4 > n=3 > n=2）；g 较小时 N 随 g 快速增长，之后趋于饱和。

  **(1,2) 配置 → 等效 3 光子相减 → 大振幅 SOSC**
  - r=1.0、g=1.5 时 F₁=0.992（目标 γ=0.803、α=2.0）
  - r=0.5 时最大保真度 F_max=0.999（α=1.191，γ_opt=0.378）
  - r=1.0 时 F_max=0.997（α=1.795，γ_opt=0.706）；F₁>0.99 的 α 范围为 1.565–2.029
  - 固定 r=0.74、α=1.732（≈√3）扫描 g=1.01–10：F₁≥0.993，g≥5.0 时饱和于 0.997（Table I：g=1.5, γ=0.668, F=0.993；g=2.0, γ=0.505, F=0.998；g=10, γ=0.329, F=0.997）
  - 目标态改为 a²|Ψ_π⟩：g=1.5 时 r=0.5 达 F=0.999（α=1.399），r=1.0 达 F=0.982（α=1.900）；r=0.5 下高保真区 F>0.99 覆盖 α=0.01–1.701
  - 单次试验成功概率 ~10⁻²（P_trial≈1.15%），对比传统 4 光子分束器相减的 R⁴~10⁻⁴（R~0.02–0.05）——产率提升约两个量级；装置只需单个 OPA，优于需两个压缩源+分束器的 GPS 方案

  **(1,3) 配置 → 偶宇称 Fock 叠加（|0⟩+|2⟩+|4⟩）**
  - 与理想 SESC 态保真度最高仅 0.914（远低于 (3,1) 配置的 0.970±0.010），不适合做 SESC
  - 与 a†²|Ψ_0⟩ 匹配极佳：r=0.5 时所有 g∈(1.5,10) 保真度达 0.999（α=0.473–0.612，γ_opt=0.250→0.073）；r=1.0 时 >0.998（α≈0.645–0.789）
  - 与 a†a|Ψ_0⟩ 亦可达 F≥0.999（r=0.5，α∈[1.063,1.324]）；r=1.0 时 F=0.990–0.996 但 α≈1.48–1.69 更大——按实验目标（保真度优先还是猫态尺寸优先）灵活选择

  **(1,4) 配置 → 奇宇称 Fock 叠加（|1⟩+|3⟩+|5⟩）**
  - 与 SOSC 态匹配差（最高仅 0.816），但与三个光子操作态都高度匹配：
  - a†²|Ψ_π⟩（|ψ₁⟩）：r=0.5 时全增益区间 F≥0.999（α=0.891–1.049）；r=1.0 时 F≥0.998（α=1.157–1.354）（Table III）
  - a†³a|Ψ_π⟩（|ψ₂⟩）：F 介于 0.983–0.999，α~0.74–0.79（保真度最优）
  - a†²a²|Ψ_π⟩（|ψ₃⟩）：F=0.998±0.001，g=10 时 α≈1.55（振幅最大）

  **(4,1) 配置 → 等效 5 光子相减 → α≈2.24（≈√5）**
  - 注入 4 光子、探测 1 光子即可得到等大振幅 SOSC（对比传统方案需探测 ≥5 光子），g=1.5 固定时全部 r 下保真度 >0.99（Table IV）

  **量子计量与损耗韧性**
  - 预报态相位估计超越海森堡极限（标准量子极限）
  - 光子损耗下 C 的衰减远慢于 N；N 消失后 C 仍显著高于最小值 1——状态保留非平凡相空间结构，指向损耗韧性资源，相关于容错纠错与计量

  ## 潜在研究方向

  - **光子损耗的定量边界**：Sec. VI 讨论实际限制（全文截断处未给出具体损耗阈值数值），N 消失的临界损耗率与 C 保留下来的结构资源之间的定量关系值得深挖——这是"损耗下多少结构仍可用"的关键工程参数
  - **成功概率的系统标度**：已给 (1,2) 的 P_trial≈1.15% 与 R⁴~10⁻⁴ 对比，但更大 m、n 配置的成功概率与探测效率要求的完整表格未见
  - **实验实现缺口**：纯理论协议；PNRD 对 m,n≥4 的当前探测效率、OPA 增益 g~1.5–10 与输入压缩 8.69 dB（r=1.0）的实际可行性需实验验证
  - **与 GKP 编码的直接对接**：文中仅指出猫态是 GKP qubit 的粗糙近似，压缩猫态到 GKP 态的精确转换路径未展开
  - **复杂度 C 作为通用资源度量的理论地位**：C 与 QFI 的相关性目前为数值观察，缺乏解析证明；C 在纠错码容量分析中的严格角色待建立

  ## 与林赛研究的关联

  - **HHG/阿秒计量的探针态设计**：文中"相位空间复杂度 C 与 QFI 正相关、且损耗下比 Wigner 负性更耐久"的发现，直接映射到强场超快测量场景——真实 HHG 实验中光子收集效率、探测效率总有损耗，评估非经典探针时应采用 C 类损耗韧性度量而非仅看 Wigner 负性。α≥2（e^{-2α²}≪1）的资源实用性判据可作为我们评估任何非经典光源的门槛函数
  - **量子几何方向（used_by_proposals: general-quantum-geometry-inversion-20260726）**：非高斯态的宇称选择规则本质是离散对称性（Z₂ 宇称）对输出结构的控制——与量子几何/拓扑不变量对响应函数的选择规则有同构的方法论结构；"用可调增益 g 作为连续旋钮在离散态族间切换"的思路对可重构量子几何探针设计有借鉴价值
  - **莫尔/交变磁**：无直接接口，本篇属连续变量量子光学，与凝聚态强场方向交叉点在"非经典资源+损耗韧性"概念层
  - **方法素材**：本文无实验装置参数，不提供装置/序列级方法卡素材；可复用的是资源判据（C、QFI 关联、α≥2 门槛）与保真度-产率权衡的数值优化流程范式
