• # Rothe 方法 + 解冻复高斯基组：TDHF/TDDFT 强场传播的无网格轨道表示

  ## 林赛的理解

  这篇工作解决的是我组做 HHG 理论模拟时绕不开的一个老问题：多电子体系（TDHF/TDDFT）在强场下传播，电子连续态怎么表示？实空间网格太贵，原子中心高斯基组抓不住 outgoing electrons，vMCG 那类变分高斯方法又被 Gramian 矩阵的奇异性折腾得 instability 频发。作者把 Rothe 方法——把含时演化重写为逐步优化问题——从单粒子 TDSE 推广到了**轨道层面的 TDHF/TDDFT**，用少量"解冻"（thawed，即宽度/位置/动量参数全部随时间演化）的复高斯就能描述电离连续区。对我们而言价值有两层：一是方法学上，如果解析积分版本的实现落地（作者明说当前网格评估只是 proof-of-principle 的临时方案），多电子强场动力学的计算成本有望大幅下降，这对我们把 TDDFT 级别的模拟推向更大分子体系、乃至与莫尔/二维材料相关的多电子问题有直接意义；二是思路上，"每步重新优化基组 + 误差可控地自适应加基函数"这一套，对我们设计 HHG 理论模拟的方案框架是一个可借鉴的范式。缺点是本文只做了 1D 模型体系（LiH 和 (LiH)2），3D 实现仍是开放问题。

  ## 研究问题

  如何用紧凑的、随时间自适应演化的高斯基组，在轨道层面的含时方法（TDHF 与 TDDFT）中表示强场诱导的电子连续区，从而避免使用实空间网格？

  具体分解为三个子问题：
  - Rothe 方法（将 TDSE/TDHF/TDDFT 传播重写为逐步最小化问题）能否从单体波函数推广到轨道方程（Fock 算符 / Kohn-Sham 哈密顿量的自洽场传播）？
  - 多少个解冻复高斯（thawed complex Gaussians）才够定性、定量地复现网格计算的偶极矩与 HHG 谱？
  - 基组大小能否随传播误差自适应地增长（加基函数/换基函数），使累计误差维持在预设容差以内？

  ## 研究背景

  - 强场过程（HHG 等）的 TDSE 求解随粒子数指数增长，标准出路是轨道方法：TDCI、MCTDHF（单组态极限即 TDHF）、TDCC，以及成本更低还能计入关联的 TDDFT（含时 Kohn-Sham）。
  - 这些方法的共同瓶颈是**基组必须能在所有时刻充分表示波函数**。为基态设计的各向同性原子中心高斯无法描述强场电离产生的 outgoing continuum 电子。
  - 已有连续区基组的缺陷：数值过完备、基组必须很大、往往需要启发式寿命模型（lifetime models）来避免反射和模拟电离。
  - 让高斯随时间演化（变宽度、位置、动量）的思路在振动动力学中由 vMCG 实现，但因隐式 ODE 中出现**不可逆 Gramian 矩阵**而数值不稳定；常用对策是冻结宽度参数（frozen Gaussians）+ 正则化，而正则化会使解严重偏离真实动力学，且已被证明不适用于强场中的原子体系。
  - 轨迹引导方法（如 CCS, coupled coherent states）可给出很好的强场动力学结果，但基组非自适应、不完备性问题突出，且需很大基组。
  - 网格/DVR/B 样条是另一路线，但计入关联后对粒子数标度极陡。
  - Rothe 方法近年被用于克服 vMCG 的数值问题：在每个时间点重新找一组最优高斯，把演化变成优化问题，回避刚性 ODE，且支持动态增减基函数。此前已证明 3D 氢原子强场波函数可用几十个高斯波包表示、显式关联高斯也能有效传播——但之前只对完整 TDSE 做了，未触及多体方法中的轨道方程。本文填补这一空白。

  ## 研究方法

  本文属**方法密度高的论文**（方法创新即核心贡献），按方法卡格式整理如下。

  ### 方法卡：Rothe 方法 + 解冻复高斯的 TDHF/TDDFT 传播

  **原理**：
  把含时轨道方程（TDHF 的 Fock 算符 / TDDFT 的 Kohn-Sham 传播算符）用 constant-mean-field（CMF）近似加 Crank–Nicolson 传播子半离散化，则"从 t_i 到 t_{i+1} 的演化"等价于一个最小化问题：找下一时刻的轨道使 Crank–Nicolson 残差（Rothe error）最小。轨道表示为复高斯的线性组合，线性系数用 Variable Projection（VarPro）解析消去，只对非线性参数（高斯宽度 a、b、位置 µ、动量 p）做优化。误差超过阈值时自适应增加高斯。传播关于高斯数 M 标度为**二次**（M²），远优于网格的指数标度。

  **参数表**（数值原样，出自原文；未注单位处为原子单位 a.u.）：

  - 时间步长：∆t = 0.05（全部模拟）；虚时传播优化初态也用 ∆t = 0.05（时间取 −i∆t）
  - 传播格式：CMF 积分器 + Crank–Nicolson，全局误差 O(∆t)（低阶但稳定性好）
  - 高斯形式：g(α) = d·exp(−(a²+ib)(x−µ)² + ip(x−µ))，归一化因子 d = (2a²/π)^(1/4)
  - 基函数数：定性正确只需少量全解冻高斯；定量复现网格需 **30–100 个高斯**；强度上限 **4×10^14 W/cm²**
  - 初始基组：冻结初态高斯 + 2 个 a=√(1/2)、b=p=0 的高斯置于分子两侧，共 4 个附加高斯；LiH 置于 µ ∈ {−7, −5, 5, 7}，(LiH)2 置于 µ ∈ {−15, −13, 13, 15}；初态高斯非线性参数全程冻结
  - Rothe 误差评估网格：中心区间 (−17, 17) 用 **239 点高斯求积**；外侧 [a,−17] 与 [17,b] 用梯形规则，均匀网格间距 **∆x = 0.4 a.u.**
  - 模拟盒子：E0 = 0.0534 a.u. 时 −a = b = **320**；E0 = 0.1068 a.u. 时 −a = b = **450**；(LiH)2 的 TDDFT 模拟用 −a = b = **500**（为避免反射）
  - 掩蔽函数（masking function）：cos^(1/4) 形吸收边界，起点 a_start = 0.85×a_min、b_start = 0.85×b_max；b_max = b − 5，a_min = a + 5；掩蔽后轨道需重新拟合回高斯线性组合
  - 高斯宽度限制：非基态高斯的 a ∈ [a_min, a_max] = **[0.1, 2]**；LiH TDHF、I0 = 4×10^14 W/cm² 高精度计算在 t = 219 a.u. 处放宽至 a_min = **0.04**（此限制被作者明确归因为底层网格而非 Rothe 方法本身）
  - 参数边界化优化：式(54)–(56)，s = **0.1**，宽度参数 q = **0.05**，b/µ/p 参数 q = **0.1**；近五时步内新增的高斯取 s = **0.5** 以便重新排布
  - 优化器：SciPy BFGS + 解析梯度，Hessian 逆初猜 H0⁻¹ = diag(|∇αr| + δ_num)⁻¹，δ_num = **10⁻¹⁴**；每时步最大迭代 **300** 次
  - 自适应加基：Rothe 误差（优化后）超过 ε∆t/N_T 时加一个高斯；候选参数由随机变分法（Stochastic Variational Method）从现行参数高斯分布中采样，候选数 **K = 500**，取使误差下降最多者为初猜再 BFGS 优化
  - 冗余基函数剔除：移除某高斯后误差增幅小于因子 **κ = 1.1** 即判定冗余，移除并以新采样高斯替换
  - 正交归一保持：每时步用 **Löwdin 对称正交化** + 重归一化（掩蔽前后各做一次；掩蔽造成的模损失予以尊重，不再强制归一）
  - VarPro 细节：线性系数 c(α) 解析求解；希尔伯特空间情形用 c = S⁻¹ρ（数值线性相关时 Tikhonov 正则化，S⁻¹ → (S+λI)⁻¹）；网格情形用 SVD + 伪逆 (WΦ)⁺Wf，最小奇异值截断防不稳定
  - 两类失效防护：高斯"碰撞"（重叠 ⟨g_k|g_l⟩ ≈ 1）与过完备——前者通过（网格实现下的）宽度下限规避，后者通过 SVD 截断与冗余剔除处理

  **计算设置（模型体系与泛函）**：

  - 体系：1D LiH（Z = {3, 1}，X = {−1.15, 1.15}）与 1D (LiH)2（Z = {3, 1, 3, 1}，X = {−4.05, −1.75, +1.75, +4.05}），参数沿用 Sato & Ishikawa（Ref. 38）
  - 软库仑势：W(x1, x2; Z, c) = Z/√((x1−x2)² + c)；阻尼参数 c = **0.5**（电子-核）、d = **1**（电子-电子）
  - 外场：E(t) = −E0 f(t) sin(ωt)，sin² 包络 f(t)，光学周期数 N_c = **3**，ω = **0.06075 a.u.**（λ = **750 nm**）
  - 场强：E0 = **0.0534 a.u.**（I0 = 10^14 W/cm²）与 E0 = **0.1068 a.u.**（I0 = **4×10^14 W/cm²**）
  - 1D LDA 交换泛函：ε_X^unif(ρ) 由 1D 均匀电子气导出，三次样条拟合，密度区间 ρ ∈ [10⁻¹², 10⁴] 内绝对误差 < **10⁻⁶**，区间外用渐近式
  - 1D LDA 关联泛函（Ref. 49 参数化，式47 参数表）：A = 18.40，B = 0.0，C = 7.501，D = 0.10185，E = 0.012827，α = 1.511，β = 0.258，m = 4.424
  - 实现：自旋限制（spin-restricted）闭壳层 HF 与 KS-DFT
  - 观测量：含时偶极矩 ⟨µ(t)⟩ = −∫ρ(x,t)xdx；HHG 谱取近似速度形式 S(ω) ∝ ω²|∫⟨µ(t)⟩e^{iωt}dt|²，离散傅里叶变换 + **Hann 窗**
  - 参考计算：1D 网格上的数值精确解（用作基准）

  **适用边界**：
  - 本文仅为 proof-of-principle：Rothe 误差在网格上评估是主要速度瓶颈（每时步数百次迭代、每点 M 个指数函数求值、网格上构建二维稠密 Fock 矩阵），限制了可用高斯数与场强；作者强调解析积分实现（全部矩阵元可解析计算，1D 与 3D 成本相当）下这不是方法本质缺陷
  - 需计算 Fock 算符平方的矩阵元 → **三体积分**是 Rothe 方法相对其他方法的固有瓶颈
  - 全局误差 O(∆t) 仅为一阶；正交归一性非自动保证，依赖每步 Löwdin 正交化
  - 1D 模型体系无法涵盖 3D 真实分子的全部物理；但基组收敛与传播稳定性等数值问题在 1D/3D 间可迁移
  - a_min 限制导致的"高斯碰撞"失稳是网格实现的人为产物
  - 备选方案（approach 2：直接传播单 Slater 行列式）因需存储 N 维函数且需三体广义 Slater-Condon 规则而未实现，仅在理论上讨论

  **代表作**：Schrader, Kristiansen, Pedersen, Kvaal（2025，本文，arXiv:2506.10701）；Rothe 方法用于强场 TDSE + 显式关联高斯的前作（Refs. 44–46，其中 Ref. 46 为 3D 氢原子强场传播演示）。

  ## 主要发现与核心结论

  - 首次将 Rothe 方法应用于轨道层面的含时方法（TDHF 与 TDDFT），证明了可高效传播解冻复高斯基组，实现无网格表示。
  - **少量全解冻高斯即可得到定性正确的结果**（对 TDHF 和 TDDFT 均成立），描述非束缚动力学。
  - **30–100 个高斯可在强度达 4×10^14 W/cm² 时定量复现网格计算**（对所研究的 1D 分子体系）。
  - 基组大小可经 Rothe 误差阈值（ε∆t/N_T）自适应增长，保证累计 Rothe 误差 ≤ ε∆t；Rothe 误差的平方根是单轨道单步演化误差（相对所选积分器）的上界。
  - 初态采用两步制备：先用网格算基态轨道再拟合高斯（BFGS + 解析梯度，VarPro 消去线性系数，体系相关的高斯数），再经 Rothe 虚时传播（∆t = 0.05）进一步优化——可同时降低能量、保证轨道正交归一、把初始 Rothe 误差压到最小，避免传播中的虚假振荡。
  - 单时步正交归一与正交性偏差极小，Löwdin 正交化 + 重归一化带来的额外误差可忽略；掩蔽造成的模损失被显式尊重（非幺正传播）。
  - 冗余高斯自动识别替换（κ = 1.1 判据）与随机变分法采样新增高斯（K = 500 候选）使基组在传播中保持紧凑与有效。

  ## 潜在研究方向

  - **3D 实现**是最直接的开放问题：本文全部结果为 1D 模型；需解析积分版本的实现来摆脱网格瓶颈（三体积分是主要成本障碍）。
  - 全局误差仅 O(∆t)（CMF + Crank–Nicolson 一阶格式），更高阶或自适应步长积分器值得探索；作者报告实际稳定性与定性行为"出奇地好"，但定量精度与收敛阶的关系未系统分析。
  - approach 2（直接以单 Slater 行列态为约束传播 TDSE，避免显式构造 Fock 算符）被讨论但未实现：需要 Ĥ² 的矩阵元与三体相互作用广义 Slater-Condon 规则，且存在"单行列式在精确哈密顿量下一般不保持为单行列式"的不可约误差——其相对 approach 1 的优劣未知。
  - 累计 Rothe 误差 r_tot 不是演化误差的显式上界（未计轨道间耦合），严格的误差可控性论证缺失。
  - 强场更高强度（> 4×10^14 W/cm²）与更多高斯的组合受网格评估瓶颈限制，未充分压力测试。
  - 推广到 MCTDHF / TDCC 等多组态方法（真正的强关联体系）未尝试——本文仅单行列式层级。
  - 与吸收边界（CAP）的等价关系只在一阶 ∆t 下建立；掩蔽后重拟合引入的额外误差未做系统收敛分析。

  ## 与林赛研究的关联

  - **HHG / 强场驱动理论模拟**：本文核心场景就是 HHG——观测量直接取偶极矩与 HHG 谱（速度形式 + Hann 窗）。我们组做固体/分子 HHG 理论方案时，多电子关联效应的处理（TDDFT vs TDHF vs 更高层级）是方法选型关键，本文提供了一个摆脱网格的候选路线。
  - **计算成本与体系规模**：Rothe + 高斯的 M² 标度对把强场 TDDFT 推向更大体系（包括我们关注的莫尔/低维材料多电子模型）有潜在吸引力；网格/DVR 路线在 3D 关联计算中成本爆炸，正是本文要替代的。
  - **方法学可迁移性**："误差阈值驱动的自适应基组增删 + 逐步优化替代 ODE 传播"的框架，对我们设计 HHG 模拟的数值方案（吸收边界、基组收敛判据、误差预算）有直接借鉴意义；操作五问中的"判据"与"参数表"可直接参照本文数值细节节。
  - **1D 模型体系传统**：1D 软库仑 LiH/(LiH)2 + 750 nm、10^14–4×10^14 W/cm² 的参数组合是 Sato & Ishikawa 一系的基准测试配置；若我们组需要快速验证新的强场传播算法，这套体系与网格基准是现成的对照（可复现性高）。
  - **阿秒视角**：连续区电子动力学的紧凑表示对阿秒 streaking/电离时间延迟等观测量模拟同样关键，本文的基组自适应思想不限于 HHG 谱。
  - 注意边界：本文为单行列式平均场层级 + 1D proof-of-concept，量子几何/莫尔物理所需的多体关联与二维真实结构模拟仍需 MCTDHF 层级或 3D 实现落地后才能对接。
