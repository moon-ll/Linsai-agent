# SALMON 2.3：分治密度泛函基态初始化实现大规模实时 TDDFT——论文精读笔记

## 林赛的理解

这篇文章解决的问题我在自己的模拟工作中深有体会：**基态准备比时间演化本身更贵**。实时 TDDFT 的时间传播部分（CT+ET 扩展 Taylor 展开）天然是局域操作，实空间网格上可扩展性很好；但基态 SCF 需要对角化整个 Kohn-Sham 哈密顿量，一旦体系超过几百个原子就成了瓶颈。我的课题组此前用 SALMON 做固体 HHG 时就卡在这一点——非晶、无序体系的超胞必须够大才能代表真实样品，但基态算不动。

Otobe 组（理研）这次在 SALMON 2.3 里把分治 DFT（DC-DFT）接进标准 RT-TDDFT 工作流，思路很务实：DC-DFT 的 SCF 是线性标度的，之后用一个后处理步骤把分治得到的局域轨道重构成**全局空间扩展的 Kohn-Sham 轨道**，直接喂给 SALMON 原有的时间传播模块。这样时间演化部分一行不用改，保留了 SALMON 已被大量验证的强场鲁棒性。这种"只换基态准备、不动传播器"的工程哲学，对我们这些要做上千原子非晶/液体强场模拟的人非常有吸引力。

对我们强场超快方向来说，两个测试体系选得很准：512 原子非晶 Si 和 4134 原子液态水。前者对应非晶材料 HHG（倒空间层析在无序体系失效，必须实空间大体系），后者正对着这两年液体水 HHG 实验的热潮——实验上液体喷射 HHG 已经做到很精细了，但理论侧一直缺能对得上的第一性原理模拟。deepxiv 评分只有 0.5，可能因为它是方法/实现类论文而非物理发现，但**工具能力本身对我们就是物理**——它直接决定了我们能模拟的实验对标体系的大小。

## 核心要点

1. **瓶颈定位**：大规模 RT-TDDFT 中，基态电子结构准备的代价超过后续时间传播，限制了数千原子级非平衡电子动力学模拟——对无序材料、液体、纳米结构、异质凝聚态体系尤其关键（这些恰是 HHG、光致相变等非线性强场现象需要显式实时处理的体系）。
2. **方法组合**：SALMON 2.3 实现分治 DFT（DC-DFT），SCF 过程对体系尺寸呈**线性标度**；随后用后处理方法重构整个体系的空间扩展 Kohn-Sham 轨道，作为标准实空间 RT-TDDFT 模块的初态。
3. **工作流设计**：高效 DC-DFT 基态准备 → 全局轨道重构 → 常规 RT-TDDFT 时间传播。时间传播模块保持原样，继承 SALMON 已验证的鲁棒性。
4. **平台与并行**：SALMON 本身是开源实空间网格光-物质相互作用程序，支持 MPI + OpenMP 或 GPU 加速的大规模并行；论文描述了计算流程、并行化策略和输入/输出设计。
5. **验证结果**：Fugaku 上 Si 超胞弱标度测试确认线性标度行为；精度验证包括 512 原子非晶 Si 和 4134 原子液态水，证明该工作流能支撑实际的大规模实时 TDDFT 模拟。

## 实验/研究关联

- **非晶/无序材料 HHG**：我们组关注强场下非晶体系的谐波响应。DC-DFT 工作流使 512 原子级非晶 Si 基态+实时演化成为常规计算，可系统研究无序度、缺陷态对 HHG 谱形与截止能量的影响，弥补晶体倒空间图像在无序体系的失效。
- **液体强场光学**：4134 原子液态水的演示直接对接当前液体喷射 HHG 实验浪潮。可作为我们解释液体/溶液高次谐波（与气相、固体对比）的模拟平台，检验液体中再散射与多重散射图像。
- **光致相变与非平衡动力学**：对光诱导相变、超快非热过程，初态（基态）质量决定后续动力学可信度；线性标度基态准备让大超胞下的相变模拟在计算上可行。
- **与我们现有计算栈的衔接**：SALMON 的实空间 RT-TDDFT 是我们强场模拟主力之一；升级到 2.3 后，此前受基态瓶颈限制的体系（非晶薄膜、液体盒、异质界面）可以直接纳入课题计划。Fugaku 弱标度数据也为我们申请国内超算机时提供性能参考。
- **提案方向**：可作为"千原子级强场电子动力学"类基金申请的方法学支撑——说明第一性原理模拟已能覆盖实验相关的真实尺度。

## 开放问题

1. **重构轨道的本征性**：DC-DFT 重构出的全局轨道是否是完整 Kohn-Sham 哈密顿量的严格本征态？若存在残余非正交性或非本征性，作为初态后是否会在时间演化早期引入伪动力学（如虚假的电荷振荡）？论文的精度测试在强场脉冲下表现如何，需要我们自查。
2. **电子结构质量**：线性标度 SCF 是否准确再现带隙、带边态、缺陷/局域态？这对非晶 Si 的 HHG 至关重要——局域带尾态可能主导低阶谐波行为。文中未讨论重构轨道能谱与常规对角化结果的逐态对比。
3. **强场相关物理的保留程度**：测试仅验证基态与流程可行性，尚未展示强场下的物理结果（如 HHG 谱）。绝热近似泛函、赝势质量、核动力耦合（Ehrenfest 是否可用）在超大体系下的表现都待确认。
4. **重构步骤本身的标度与开销**：DC-DFT 的 SCF 是线性标度，但全局轨道重构这一后处理步骤的计算代价和内存开销是否也随体系线性增长？在 GPU 上是否高效？
5. **与实验的直接对标**：液态水 HHG 模拟是否做了与实验谱的定量比较？液体的构型平均（多个 MD 快照）需要重复整套流程，DC-DFT 工作流的总体吞吐量是否支持构型平均？
6. **适用边界**：DC-DFT 对金属/小带隙体系（局域化假设减弱）和强杂化泛函的适用性如何？分治的分区大小参数如何影响精度-效率权衡？
