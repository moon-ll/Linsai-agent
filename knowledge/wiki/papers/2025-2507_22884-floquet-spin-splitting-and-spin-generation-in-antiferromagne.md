• # Floquet 自旋劈裂与反铁磁体中的自旋产生

  ## 林赛的理解

  这是一篇典型的"Floquet 工程 + 反铁磁自旋电子学"交叉理论工作，对我们组的意义不在于它提出的具体器件，而在于它示范了一套**用强场光驱动在 PT 对称反铁磁体中"凭空造出"自旋劈裂**的普适机制。核心信息有三条：其一，椭圆偏振光在 PT 对称反铁磁体（蜂窝格、Néel 序、MnPX3 类材料）中诱导的自旋劈裂可达原能带尺度，远超 SOC 劈裂；其二，劈裂是交换耦合与光场的**合作效应**——没有交换耦合就没有劈裂，这与我们关心的"强场驱动磁序"问题直接同构；其三，通过热浴工程（声子浴 vs 费米浴、左右电极对称性破缺）可以在**零 SOC** 条件下产生稳态纯自旋电流和净自旋积累（非相对论 Edelstein 效应），而且自旋输运的量级和方向可用光偏振角连续调控。这恰好为我们"强场超快驱动反铁磁/莫尔体系"的课题提供了一个可写入立项依据的理论支点：光诱导自旋劈裂 → 非平衡自旋输运 → 为超快自旋产生与磁矩操控提供无 SOC 的新通道。MnPS3 / MnPSe3 正是我们 knowledge 库里已有的课题关联材料（general-berry-mnps3-rashba），此文的 Floquet 视角可以与该课题的 Rashba 几何相位路线形成互补。

  ## 研究问题

  在具有 PT（宇称-时间联合）对称、本征自旋简并的共线反铁磁体中，能否不依赖自旋-轨道耦合（SOC）、也不用外加静磁场，就实现可观的自旋劈裂并进一步产生稳态自旋电流与净自旋积累？具体分解为三个子问题：

  1. 光场（椭圆/圆偏振）能否通过动力学破缺 PT 对称，在准能量能带中诱导出显著的自旋劈裂？
  2. 驱动系统耦合热浴达到非平衡稳态后，能否支持稳态纯自旋电流，以及线性响应下的纵向/横向自旋电流？
  3. 能否通过热浴工程（bath engineering）——特别是电极对称性破缺——在零 SOC 下实现净自旋积累（非相对论 Edelstein 效应）？

  ## 研究背景

  - 反铁磁自旋电子学因超快动力学、无杂散场而备受瞩目，但共线反铁磁体中电子能带常因反幺正有效时间反演对称（时间反演 × 空间反演或子格平移的组合）而保持自旋简并，这是利用自旋自由度的根本障碍。传统出路是 SOC（自旋产生、自旋霍尔效应、自旋轨道力矩等，[6,7]）。
  - 另一条新路线是交变磁体（altermagnet）：晶格对称性内禀破缺有效时间反演，产生非相对论自旋劈裂，且通常大于 SOC 劈裂，RuO2 中已观测自旋劈裂力矩与反常霍尔效应（[8-24]）。
  - 第三条路线是外磁场 Zeeman 劈裂显式破缺时间反演，但能标相对能带结构（~1 eV）可忽略——1 T 磁场仅给出 10⁻⁴~10⁻⁵ eV 量级劈裂。
  - 本文的切入点：用光场**动力学**破缺时间反演（Floquet 工程），在亚能隙驱动窗口内以非微扰方式提升自旋劈裂能标，且劈裂大小可与原始能带比拟、超过典型 SOC。

  ## 研究方法

  本工作为纯理论 Floquet 计算，方法密度中等偏上，核心方法链如下（数值均取自原文）：

  ### 模型与对称性分析

  - **体系**：蜂窝格共线反铁磁体（MnPX3, X=S, Se 类材料），基 (c_{kA,↑}, c_{kA,↓}, c_{kB,↑}, c_{kB,↓})，Hamiltonian 含跳跃项、交换耦合 λ（Néel 矢量 n∥ẑ 以保持自旋守恒）、内禀 SOC λ_SO（式(1)）。系统保持 PT 对称 → 全动量自旋简并。
  - **驱动**：偏振光矢势 **A** = A₀(sin ωt, sin(ωt+φ), 0)，A₀ = E₀/ω（e=ℏ=1）。椭圆/圆偏振（φ ≠ 0, π）显式破缺 PT；线偏振（φ = 0, π）下 PT 有效保持（A(−t) = −A(t) 等价于时间平移 π/ω）。
  - **耦合方式**：Peierls 替换 H(k) → H[k+A(t)]。
  - **驱动窗口**：亚能隙区 J_ex ≪ ℏω ≪ Δ_c（J_ex 为局域自旋间交换能，Δ_c 为电荷能隙；典型 J_ex ~ t_h²/U，Δ_c ~ U，t_h ≪ U）。取 ℏω ~ t 即落在窗口内：磁振子吸收被抑制，电荷激发加热仅发生在指数长时间尺度（~e^{U/ℏω}），并可由热浴进一步缓解。超快区（ℏω ≫ U ≫ t）反铁磁序也可存活但劈裂为微扰小量。

  ### Floquet 能带计算

  - Floquet 态 |ψₙ(t)⟩ = e^(−iεₙt/ℏ)|φₙ(t)⟩，|φₙ(t+T)⟩ = |φₙ(t)⟩，T = 2π/ω；Fourier 分量方程 (εₙ+mω)|φₙ⁽ᵐ⁾⟩ = Σ_{m′} H⁽ᵐ⁻ᵐ′⁾|φₙ⁽ᵐ′⁾⟩；准能量限于一阶 Floquet-Brillouin 区 −ω/2 ≤ εₙ < ω/2。
  - Fourier 化 Hamiltonian（式(2)）： hopping 与 SOC 通道均给出含 m 阶 Bessel 函数 J_m(ζᵢA₀a)、J_m(ζ̃ᵢA₀a) 的显式表达式；角度参数 θᵢ、ζᵢ 见原文表 I（N± = 1 ± √3/2·cosφ 等，数值原样见原文）。
  - 自旋为好量子数，可在自旋分辨子空间内分析输运。
  - 零 SOC 时存在**双重对称**（对偶对称）：τˣH↑[k+A(t)]τˣ = H↓[−k−A(t)]，源于空间反演 P 与绕 x 轴二重自旋旋转 C^spin_2x 的联合作用 → 准能量 ε↑_{u,d}(k) = ε↓_{u,d}(−k)。光场破缺三重旋转对称，故 K₃−Γ−K₂ 路径不适用对偶关系；非零 SOC 显式破缺该对称。

  ### 有效 Floquet Hamiltonian（微扰极限）

  - 远离共振（ω ≫ t）、弱驱动（A₀a ≪ 1），在谷 K₄(K₁) = (0, ∓4π/3√3) 附近：H_v(t) = v_F[τˣηᶻ(q_y+A_y) + τʸ(q_x+A_x)] + sλτᶻ，v_F = 3at/2，s = ±1 自旋指标，η 为谷 Pauli 矩阵。
  - 有效 Floquet Hamiltonian（至 O[(aA₀)⁴]，式(4)）：H^F_eff ≈ v_F(τˣηᶻq_y + τʸq_x) + sλτᶻ − Mτᶻηᶻ，其中 **M = (v_F A₀)²/ω · sinφ**。
  - 谷准能量 ε^s_{K₄(K₁)}(q) = ±√(v_F²q² + (sλ − χM)²)，χ = ±1 谷指标 → 各谷准能量自旋相关，劈裂由交换耦合与光驱动**合作**产生。计入 SOC 后 M → M − s·3√3 λ_SO，破缺 ε^s_{K₁} = ε^{−s}_{K₄} 对偶。

  ### 稳态与输运（声子浴，玻色浴）

  - 电子-声子耦合（式(5)）：H_ep = Σ g^λ_{ν′ν}(k−q,k) c†_{k−q,ν′}c_{k,ν}(b†_{qλ}+b_{−qλ})；声子 H_ph = Σ ℏω_{λk} b†b。
  - 稳态占据由动理学方程（式(6)）数值求解：∂tρ_{kα} = Σ [W_{kα,k′α′}(1−ρ_{k,α})ρ_{k′,α′} − W_{k′α′,kα}(1−ρ_{k′α′})ρ_{kα}]；散射率由电子-声子耦合与 Floquet 本征态决定（详见原文 [40,41] 及补充材料 §II：辐射复合过程 I_rec 与电子-声子散射 I_ph 两通道竞争）。
  - 计算参数：φ = π/2, A₀a = 1, ω = 1, t = 1, λ = 0.5, T_ph = 0.01t；SOC 取 λ_SO = 0, 0.05, 0.1。
  - 自旋电流（式(7)）：周期平均 j̄_s = j̄↑ − j̄↓，j̄_σ = Σₙ∫d²k/(2π)² ρ^σₙ(k) ∂_k ε^σ_{nk}。
  - 光学自旋电导（纵向 σ^s_xx、横向 σ^s_xy）由线性响应计算，外场频率 Ω 扫描 Ω/ω ∈ [0,5]（共振来自 Ω 与 Floquet 准能隙的共振）。

  ### 费米浴与自旋积累（Floquet-Keldysh）

  - 左右电极化学势 μ_L、μ_R，耦合强度 Γ_L、Γ_R；隧穿项 c†ᵢdⱼ 允许系统与引线间粒子交换 → 在自旋劈裂 Floquet 能带下等效自旋不守恒，产生净自旋积累（总自旋含引线守恒，自旋角动量由引线净流入驱动区 [44]）。
  - Floquet-Keldysh 形式体系 [36,41,46-48]。
  - 计算参数：t = 1, A₀a = 1, λ = 0.5, Γ_L = Γ_R = 0.1t, ω = 1, φ = π/2；纵向 10 个单胞；电压构型 μ_{L/R} = μ₀ ± V/2（μ₀ = 0.1, 0.2, 0.3）。

  ### 推广模型（End Matter / 补充材料 §V）

  - 非对称（nonsymmorphic）方格反铁磁体：H = H₀ + H′，H₀ = −2t cos(k_x/2)cos(k_y/2)τˣ − t′(cosk_x+cosk_y) + λτᶻσ·n，H′ = w sin(k_y/2)cos(k_x/2)τʸ（候选材料 SrMnPb、SrMnSn 等 [58]）；计算参数 φ=π/2, A₀a=2, ω=5, t=1, t′=0.2, w=0.6, λ=0.5。H′ 破缺反演对称，对自旋劈裂重要。
  - 四方 CuMnAs 最小模型：H = H₀ + α_R τᶻ(σ_y sink_x − σ_x sink_y)，计算参数 φ=π/2, A₀a=1, ω=5, t=1, t′=0.08, λ=0.6, α_R=0.8, n=(1,0,0)；此处 Kramers 简并存在但自旋不守恒 → 光驱动不仅去除简并还重塑自旋纹理，为 Néel 力矩工程提供机会。

  ## 主要发现与核心结论

  1. **光诱导自旋劈裂大而可控**：椭圆偏振光下准能量能带即使在零 SOC 时也自旋非简并（图 1）；自旋劈裂能标与原始能带尺度相当、超过典型 SOC，为高效接近自旋自由度提供途径。劈裂随偏振椭圆度（φ）出现/消失——线偏振下 PT 有效保持、无劈裂。
  2. **劈裂源于交换耦合与光场合作**：有效质量项 M = (v_F A₀)²/ω·sinφ 同时依赖交换 λ 与驱动；无交换则无自旋劈裂。
  3. **稳态纯自旋电流**：声子浴下稳态占据明显偏离 Fermi-Dirac——本全占据的下 Floquet 带部分耗空、空的上带获得有限占据（图 2），形成"有效金属"稳态（初始有能隙但出现有限电导，图 3(c)）。零 SOC 时双重对称保证 j̄↑ = −j̄↓ → 纯自旋流、零净电荷流；引入 SOC 后自旋流与电荷流共存。自旋电流量级与方向随偏振角高度可调（图 3(a,b)，单位 t/a ~ 10⁹ eV/m），并满足两条对称性：① j̄_s(2π−φ) = −j̄_s(φ)；② 在 [0,π] 内 j̄_s^x 关于 π/2 对称、j̄_s^y 关于 π/2 反对称。
  4. **线性响应自旋输运**：纵向与横向自旋电导 σ^s_xx、σ^s_xy 振荡行为源于外场频率 Ω 与 Floquet 准能隙共振；DC 极限两者均有限（尽管未驱动半填充系统是带绝缘体），证实驱动+声子弛豫形成有效金属稳态。线性光学自旋电导受双重对称约束、两自旋通道贡献相消，需非零 SOC 才有有限响应。
  5. **非相对论 Edelstein 效应（零 SOC 净自旋积累）**：自旋守恒的电子-声子耦合禁止净自旋积累；耦合费米浴（电极）后，自旋劈裂 Floquet 能带使自旋上/下粒子流入不平衡。若两电极对称（μ_L = μ_R），双重对称强制自旋积累为零，需 SOC（图 4(a)）；引入电极不对称（μ_{L/R} = μ₀ ± V/2）即破缺双重对称，产生随电压 V 线性响应的显著自旋积累，且自旋信号符号可反转（图 4(b)，量级 10⁻² ℏ/a²，e*V/t 扫描至 0.10）——自旋信号反号是 bath engineering 的标志。自旋局域守恒、自旋电流良定义，与 SOC 显式破缺局域自旋守恒的情形 [45] 形成鲜明对比。
  6. **实验可行性估算**（原文实验可行性一节）：取 ω = 1 eV（t = 1 eV）、A₀a = 1、a = 5 Å → 电场 E₀ = A₀ω/e = 2×10 MV/cm，对应激光强度 I ≃ 5×10¹¹ W/cm²，在实验可达范围内 [36,53]。输入功率 P_in ~ E₀|j̄_e| ~ 10⁸–10⁹ W/cm²；每自旋通道电流 j_e ~ e/ℏ·j_{↑/↓} ≈ 10⁻⁵~10⁻⁶ (e/ℏ)·eV/m。取声子浴：散射率 R ~ 2πg₀²D_ph/ℏ ~ 10¹³ s⁻¹（g₀ ≈ 0.05 eV，声子态密度 D_ph ~ 1 eV⁻¹）；耗散功率 P_diss ~ R(D_ph ΔE)n_ph/S_{u.c.}·ε_ph ~ 10⁷–10⁹ W/cm²（ΔE ≈ 0.1~1 ℏω 声子能量窗口，n_ph ~ 1 相关声子模数，S_{u.c.} ~ a² 单胞面积，ε_ph ≈ 0.1~1 ℏω）。功率平衡 P_in = P_diss 可行；外接储库/衬底/磁振子等额外耗散通道可进一步抑制加热。
  7. **普适性**：机制不限于蜂窝模型——非对称方格 AFM（图 5(a)，零 SOC 自旋劈裂）与四方 CuMnAs 最小模型（图 5(b)，去简并+重塑自旋纹理）同样成立。

  ## 潜在研究方向

  - **加热与退相干**：Floquet 驱动孤立体系趋向无限温态，本文靠热浴工程规避；实际材料中加热速率、磁序在驱动下的存活时间（亚能隙窗口论证依赖 J_ex ≪ ℏω ≪ Δ_c 的强层级）需实验检验。超快区（ℏω ≫ U）劈裂微扰小，实用窗口可能窄。
  - **Néel 力矩的光学工程**：CuMnAs 型模型中光驱动重塑自旋纹理，作者明确指向"optical engineering for magnetic torque"为未来方向。
  - **热浴工程维度**：通过调节热浴（电极不对称、储库类型）控制自旋相关输运是作者认为"非常有吸引力"的开放方向。
  - 与同期工作的部分重叠（作者 Note added 声明）：Huang et al.（arXiv:2507.20705，共线反铁磁中光诱导奇宇称磁性）与 Zhu et al.（arXiv:2508.02542，Floquet 奇宇称共线磁体）——引用时需注意结论归属。
  - 稳态占据对动理学散射率细节（电子-声子耦合矩阵、声子谱模型）敏感，定量预测依赖补充材料中的具体近似；τ-近似或不同浴谱下自旋电流定量值可能移动。

  ## 与林赛研究的关联

  - **强场驱动 + 反铁磁**：本文正是"强场超快光学驱动磁性"课题的理论范式样本——亚能隙 Floquet 驱动窗口（J_ex ≪ ℏω ≪ Δ_c）的判据可直接移植到我们 HHG 驱动反铁磁/莫尔体系（MnPS3、MnPSe3、MPX3 家族）的方案论证中，作为"驱动频率选择"与"加热控制"两问的现成答案。
  - **材料接口**：MnPX3 (X=S, Se) 与我们课题库中 general-berry-mnps3-rashba 课题同源；本文从 Floquet 自旋劈裂角度、该课题从 Rashba 几何相位角度切入同一材料家族，可在立项依据中互为支撑，并提示"光场调控自旋劈裂 → Berry 相位与量子几何响应"的交叉。
  - **可观测接口**：光诱导自旋劈裂的实验读出可对接我们方向中的超快光谱手段——时间分辨 Kerr/Faraday 旋转、TR-ARPES（Floquet 准能带已在 WSe2 中由 trARPES 圆二色性观测 [53]）、以及自旋积累的输运测量（非局域自旋阀构型）。
  - **与交变磁/莫尔方向的桥接**：交变磁体（altermagnet）与光诱导自旋劈裂共享"非相对论自旋劈裂"物理内核；莫尔体系中自旋-能谷耦合与可调 moiré 周期为 M = (v_F A₀)²/ω·sinφ 型 Floquet 质量项提供了可调费米速度 v_F 与对称性破缺的平台，值得在莫尔-强场课题中做机制迁移的可行性分析。
  - **定量锚点**：I ≃ 5×10¹¹ W/cm²、E₀ = 2×10 MV/cm、散射率 ~10¹³ s⁻¹、声子窗口 ΔE ≈ 0.1~1 ℏω 等数值可直接作为我们方案写作中"光参数量级-耗散预算"一节的参照标尺。

## 研究方法（方法卡）

**方法**：Floquet 能带 Bessel 展开微扰有效哈密顿量 + 声子浴动理学方程稳态 + Floquet-Keldysh 费米浴自旋积累（零 SOC 自旋产生）

**原理**：蜂窝格 PT 对称反铁磁（MnPX₃ 类）以椭圆偏振光 Peierls 驱动动力学破缺 PT（线偏振下 PT 有效保持无劈裂）；Fourier 化哈密顿量含 m 阶 Bessel 函数 J_m(ζA₀a)；谷 K₄/K₁ 附近有效 Floquet 哈密顿量至 O[(aA₀)⁴]：H^F = v_F(τˣηᶻq_y+τʸq_x)+sλτᶻ−Mτᶻηᶻ，光致质量 M = (v_F A₀)²/ω·sinφ——自旋劈裂由交换耦合与光场合作产生（无交换则无劈裂）；零 SOC 存在对偶对称 τˣH↑[k+A]τˣ = H↓[−k−A]（非零 SOC 显式破缺）；声子浴下动理学方程数值求解稳态占据（下 Floquet 带耗空/上带占据→有效金属稳态），对偶对称保证纯自旋流零净电荷流；Floquet-Keldysh 费米浴电极不对称（μ_L≠μ_R）破缺对偶对称产生非相对论 Edelstein 净自旋积累（符号可反转，bath engineering 标志）。

**适用边界**：加热靠热浴工程规避（实际材料加热速率与磁序在驱动下的存活时间需实验检验；亚能隙窗口论证依赖 J_ex ≪ ℏω ≪ Δ_c 强层级）；超快区（ℏω≫U）劈裂为微扰小量（实用窗口可能窄）；稳态占据对动理学散射率细节敏感（τ 近似/不同浴谱下定量值可移动）；与同期工作部分重叠（Huang arXiv:2507.20705、Zhu arXiv:2508.02542，引用注意归属）。
