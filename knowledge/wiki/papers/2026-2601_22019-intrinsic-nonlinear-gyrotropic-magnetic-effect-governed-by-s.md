• # Intrinsic Nonlinear Gyrotropic Magnetic Effect Governed by Spin-Rotation Quantum Geometry

  ## 林赛的理解

  这篇工作把我们的思考框架向前推了一步：过去我们关心电驱动非线性响应（Berry 曲率偶极、量子度规偶极、shift/injection current）作为探测布洛赫带量子几何的手段，而这篇文章系统回答了**"交变磁场驱动的二阶磁响应能探测什么"**这个问题。核心信息非常干净：**自旋转动量子几何张量（SRQGT）在线性响应中完全沉寂，只有在二阶旋磁响应中才首次登场**。这意味着如果我们在交变磁场下测量圆二色性/旋光功率的二阶谐波成分，我们得到的就是此前无法通过任何输运手段获取的纯几何量——SRQM（自旋转动量子度规）与 SRBC（自旋转动 Berry 曲率）。

  对我们的方法论有直接价值：(1) 它给出了一套**对称性选择定则表**（Table I/II），告诉我们什么对称性组合下位移流通道、传导流通道哪些分量存活——这正是我们在 MnPS₃/莫尔体系里设计"对称性工程探测量子几何"实验时需要的语言；(2) 它的密度矩阵微扰论 + 弛豫时间近似的推导框架可以平移到我们的强场含时驱动场景，作为"时间周期磁场"这一驱动通道的理论基线；(3) 所有 NGM 电导率都**不依赖散射时间 τ**（intrinsic），且结论还适用于多带体系（仅两处用了两带近似），这对真实材料预言很友好。

  值得注意的是：这是低频/静磁场展开的旋磁效应（gyrotropic magnetic effect）理论，非线性项是 B² 级，不是强场（非微扰）HHG 级数。但它确立的"对称性 → 几何量 → 可观测通道"映射，正是我们在申请书里论证"交变磁 + 量子几何 + 莫尔工程"可行性的理论锚点之一。CuMnAs 的 PT 对称反铁磁通道分析对我们交变磁方向的关联尤其直接。

  ## 研究问题

  核心问题：**在自旋-轨道耦合体系中，时间周期磁场驱动的二阶非线性旋磁响应由哪些量子几何量控制？特别是自旋转动量子几何张量（SRQGT）——这个在线性响应中完全沉寂的张量——如何、以及在什么对称性条件下进入非线性磁输运？**

  围绕这一核心，论文展开四个子问题：
  1. 如何从微观量子动理学出发，推导二阶旋磁电流（NGM current）的一般表达式，并将其分解为对角/非对角、传导（conduction）/位移（displacement）四类通道？
  2. 各通道分别由 ZQGT（Zeeman QGT）与 SRQGT 的哪些具体分量（量子度规、Berry 曲率、度规联络、辛联络）控制？
  3. 不同对称性破缺模式（破 P 保 T、破 T、PT 对称反铁磁等）如何选择性激活不同通道与不同张量分量？
  4. SRQGT 作为"非线性区独有"的几何量，能否通过 NGM 电导率这一实验可及观测量被分离出来？

  ## 研究背景

  **学术脉络**：非线性输运已成为探测布洛赫带隐藏几何与拓扑结构的有力工具——二次谐波产生、体光伏效应、非线性霍尔效应对空间/时间反演对称性破缺高度敏感，直接反映 Berry 曲率与量子度规等微观量子几何量。二维材料因维度降低、强自旋-轨道耦合与能谷自由度使信号显著增强，是访问量子几何张量（QGT）的理想平台。近年已证明：在特定对称性约束下，量子度规偶极乃至 QGT 高阶多极可超越 Berry 曲率偶极主导输运；TMD、极性半导体、少层拓扑绝缘体中已观测到巨大的非线性霍尔/shift 电流响应；转角双层石墨烯与交变磁（altermagnetic）异质结成为可调平台。

  **前人工作与缺口**：常规 QGT 只描述动量空间的平移几何。对自旋-轨道耦合能带，需推广为同时包含局域自旋转动的广义 QGT——引入 ZQGT（耦合位置算符矩阵元与带间自旋矩阵元）与 SRQGT。这些量有奇特的对称性：Zeeman Berry 曲率可在时间反演对称（TRS）下存活，Zeeman 量子度规反而是奇的——这在常规 QGT 中不允许。ZQGT 已成功被**线性**内禀旋磁电流（Zeeman 驱动的线性效应）探测到，但 **SRQGT 在线性区完全不活跃**，其对非线性输运的影响此前未被系统建立。

  **物理动机**：自然旋光性（natural gyrotropy）提供了天然载体——低频极限下干净金属中缓变磁场诱导电流可按 j_i = α_ij B_j + γ_ibc B_b B_c + … 展开。线性项来自内禀轨道/自旋磁矩与 Zeeman 量子几何；**二阶项由自旋转动量子几何决定**，是分离 SRQGT 的本质观测量。虚部对应圆二色性（微分吸收），实部对应旋光能力（optical rotation）。

  ## 研究方法

  **总体框架**：微观量子动理学（quantum kinetic theory）+ 密度矩阵形式微扰论，针对二维体系中时间依赖磁场 H_I = −gμ_B B(t)·σ（B(t)=B₀cos(ωt)）诱导的二阶非线性磁响应。

  **具体技术路线**：
  1. **广义量子几何定义**：对邻近周期性布洛赫态 |u^ζ_mk⟩ 同时施加动量平移 U_dk = e^{−idk·r̂} 与自旋转动 U_dθ = e^{−idθ·σ̂/2}（ℏ=1），量子距离 ds² 分解为常规 QGT（G）、SRQGT（S）、ZQGT（Z）三项；统一记号 z^ab_mp = x^a_mp y^b_pm（x,y ∈ {r,σ}），实部为度规、虚部为 Berry 曲率，涵盖 CQM/CBC、SRQM(R)/SRBC(Λ)、ZQM(F)/ZBC(Γ) 全套。
  2. **密度矩阵微扰求解**：从量子 Liouville 方程出发，弱无序极限 + 弛豫时间近似（dρ/dt + i/ℏ[(H₀+H_I),ρ] + (ρ−ρ⁽⁰⁾)/τ = 0），将 ρ 按磁场幂次展开，迭代求解一阶、二阶密度矩阵（式 6-8），二阶项分解为对角 ρ⁽²⁾_mm 与非对角 ρ⁽²⁾_mp 分量。
  3. **电流算符**：本征基下广义速度 ṽ^a_pm = ℏ⁻¹(δ_pm v^a_pm + i r^a_pm ϵ_pm)，二阶电流 j⁽²⁾ = j⁽d⁾ + j⁽od⁾，NGM 电导率 χ⁽²⁾_abc = j⁽²⁾_a/(B_b B_c)。
  4. **低频干净极限化简**：ℏω ≪ ϵ_mp 且 τ→∞ 下分解为传导（χ^C）与位移（χ^D）电导率四项（式 12），均不依赖 τ——定义为内禀 NGM 电导率；χ^C,od 形式类似 shift 电导率，χ^D,d 类似 injection 电导率。
  5. **对称性分析**：Table I 给出各几何量在 P̂、T̂、P̂T̂ 下的奇偶性；导出 χ^C,od/χ^D,d 对指标 b,c 反对称、χ^D,od/χ^C,d 对称等张量结构结论。
  6. **四个代表模型验证**：
     - 无质量 2D Dirac：H = v_F(k_x σ_y − k_y σ_x)，保 T、破 P 与 PT，有 M_x、M_y、C∞v；
     - 六角翘曲拓扑绝缘体表面态：H_HW = H(k) + λ/2(k₊³ + k₋³)σ_z，保 T、破 M_y 留 M_x，C3z 旋转对称；能谱 ϵ± = ±√(v²_F k² + λ²k⁶ cos3θ)，Fermi 面随 λ 增大由圆形变为雪花形；指认 Bi₂Te₃ [111] 表面态为该模型的现实材料平台；
     - 倾斜有质量 Dirac：H_TMD = H(k) + t k_y + Δσ_z，t 倾斜、Δ 质量隙，破 P、T、粒子-空穴对称；预言体系 α-(BEDT-TTF)₂I₃、WTe₂；TCI [001] 表面 SnTe 与 Pb₁₋ₓSnₓX（X=Se,Te）铁电相亦纳入（式 16，η=±1 能谷）；
     - PT 对称反铁磁 CuMnAs：双格子最小紧束缚模型（式 17，ϵ₀ = −t(cos k_x + cos k_y)，V_AB = −2t̃cos(k_x/2)cos(k_y/2)，h_B = −h_A 保证 PT，含 Rashba α_R、Dresselhaus α_D 与交错交换场 h_AFM）。

  **关键近似**：仅考虑两带体系（忽略 ρ⁽²⁾_mp 中涉及两个以上能带的过程）；忽略磁场对 Berry 曲率的微扰修正（据引文 [35,36]，该修正只重整化内禀旋磁电流，不改变几何贡献的对称性分类）。

  ## 主要发现与核心结论

  1. **几何分离律（核心结果）**：二阶 NGM 电导率呈现清晰的几何分工——
     - 对角通道整体由 SRQGT 控制（式 10）：其中传导贡献由**自旋转动量子度规 R^bc_mp** 决定，位移贡献由**自旋转动 Berry 曲率 Λ^ab_mp** 决定；
     - 非对角通道由两个新几何量控制（式 11）：传导由 **Zeeman 辛联络 L̃^abc_mp**（对 P、T 均奇）决定，位移由 **Zeeman 度规联络 L^abc_mp**（对 P 奇、对 T 偶）决定，二者满足 r^a_pm D^b_mp σ^c_mp = L^abc_mp − i L̃^abc_mp；
     - **SRQGT——线性响应中完全缺席——成为非线性磁输运的基本几何量**，这是全文的核心识别。

  2. **内禀性与鲁棒性**：干净极限下 χ^C、χ^D 四项均不依赖散射时间 τ，仅由布洛赫波函数性质决定，弱无序下依然鲁棒。χ^C,od 形式上类比 shift 电导率，χ^D,d 类比 injection 电导率。

  3. **无质量 2D Dirac**：TRS 下所有 NGM 电导率恒等于零——L 与 Λ 为零、传导通道被积函数对 k_x、k_y 为奇函数而积分相消。

  4. **六角翘曲 TI 表面态（Bi₂Te₃ [111]）**：TRS 使传导通道禁戒，但**位移通道有限**；M_x 镜像对称使含奇数个 x 指标的位移分量消失，存活三个独立分量 χ^xxy、χ^xyx、χ^yxx，且 χ^yyy = −χ^yxx；几何结构呈单极（L^xxy，图 1a）/偶极（Λ^xy，图 1b）/四极（R^xy，图 1c）特征；**所有分量在 Dirac 点 µ=0 处出现显著峰**（源于式 12 分母中 ϵ_mp），随 µ 偏离 Dirac 点两侧对称下降。计算参数：v_f = 1 eV、λ = 255 eV·Å³、T = 10 K、χ₀ = (gμ_B/2)² A m⁻¹ T⁻²。

  5. **倾斜有质量 Dirac**：t = 0 时传导与位移贡献**全部为零**；仅 t ≠ 0（粒子-空穴对称破缺）时出现有限响应。传导电导率三个独立分量 χ^xxy、χ^yxx、χ^xyx，位移两个独立分量 χ^xxx、χ^yxy；张量分量间满足 χ^C,d_xxy = χ^C,d_xyx、χ^C,d_yyy = χ^C,d_yxx、χ^C,od_xxy = −χ^C,od_yxx、χ^D,d_yxy = −χ^D,d_yyx、χ^D,od_yxy = χ^D,od_xxx 等关系（源于 Λ 的反对称、R 与 F 的对称、Γ^ab = −Γ^ab 及 R^yy = R^xx、F^xx = F^yy、Γ^xx = −Γ^yy 等性质）。µ 位于带隙内时 χ^C_xxy 与 χ^D_yxy 为零（无载流子），进入导带/价带后出现反对称峰，反映电子/空穴贡献反号。参数：v_f = 1 eV、Δ = 0.6 eV、t = 0.3 eV、χ₀ = (gμ_B/2)² A m⁻¹ T⁻²。TCI 双能谷情形：两个有质量 Dirac 锥由 TRS 联系，**传导 NGM 电导率在两能谷间完全相消**，但位移分量 χ^D,od_abc 在能谷交换下不变而存活。

  6. **PT 对称 CuMnAs**：SRBC Λ^ab_mp 恒等于零 → L̃^abc_mp 严格为零 → **位移电流贡献恒零**；而 SRQM 对 PT 为奇、L 对 PT 为偶，使**传导电流的对角与非对角分量均有限**——与 T 对称体系正好相反（那里传导禁戒、只有位移贡献）。存活三个独立分量 χ^xxy、χ^yyy、χ^yxx，满足 χ^C,d_xxy = χ^C,d_xyx、χ^C,od_yyy = χ^C,od_yxx。参数：t₀ = 1 eV、t̃ = 0.08 eV、h_A = [0.85, 0, 0] eV、t = 0.3 eV、α_R = 0.08 eV、α_D = 0.0 eV、χ₀ = (gμ_B/2)² A m⁻¹ T⁻²。

  7. **对称性设计原则总结**：质量less Dirac（T + M_x + M_y + C∞v）→ NGM 全零；六角翘曲（T + M_x + C3）→ 仅位移通道；倾斜有质量（破 P、T、PT）→ 传导 + 位移通道全开；CuMnAs（PT，破 P 与 T 各自）→ 仅传导通道。即"不同对称性破缺模式选择性激活不同输运通道"，为材料工程提供设计准则。

  8. **更广的结论**：ZQGT 与 SRQGT 控制的非线性旋磁输运在**常规 Berry 曲率驱动效应为零时仍然有限**，为探测多带体系隐藏的 spin-resolved 量子几何提供了实验可及的通道，可用于光电子与自旋电子器件中的定制非线性磁响应。

  ## 潜在研究方向

  1. **多带推广**：文中为简洁将 ρ⁽²⁾_mp 中涉及两个以上能带的过程忽略（两带限制）。真实关联材料（如 CuMnAs 全部 d 轨道、莫尔平带的多能带结构）中多带通道的贡献大小与符号尚未量化，是直接的推广方向。
  2. **磁场对 Berry 曲率的微扰修正**：文中明确未纳入（引 [35,36] 论证其只重整化内禀旋磁电流、不改对称性分类），但修正项是否影响 NGM 电导率的定量幅值与 µ 依赖形状，值得核实。
  3. **弛豫时间近似的松弛**：τ 取为动量无关常数；考虑动量依赖 τ 与不同散射通道（杂质、声子、电子-电子）后，内禀响应的"无 τ 依赖"结论是否严格保持，需要有限散射下的系统检验（尤其是 Dirac 点附近的增强峰，τ 可能引入展宽与饱和）。
  4. **温度效应**：计算中取 T = 10 K；µ 接近 Dirac 点时峰值的有限温度抑制、熵贡献对位移通道的影响未讨论。
  5. **非微扰强场区**：全文为 B² 微扰展开的低频旋磁效应；当交变磁场达到强场（与带间隙或费米能可比）时，非微扰动力学（含时 Floquet 混合、高阶谐波、磁致拓扑相变）如何修正或取代这一图景——这正是强场超快方向的自然延伸，原文未触及。
  6. **材料候选扩展**：Bi₂Te₃ [111]、α-(BEDT-TTF)₂I₃、WTe₂、SnTe/Pb₁₋ₓSnₓX、CuMnAs 之外的体系筛选（如交错磁体、转角莫尔体系中的蜂窝/三角晶格 Dirac 锥）缺乏系统性材料基因组式搜索。
  7. **实验方案具体化**：圆二色性/旋光功率的二阶谐波测量在 THz 磁场的实际信噪比、样品要求与背景（线性旋光、轨道磁矩贡献）分离策略，文中未展开。

  ## 与林赛研究的关联

  - **HHG/阿秒**：本文是 B² 微扰区理论，可作为我们强场（非微扰）HHG 理论的低频展开对照基线。其"几何量分工表"提示：在强场区，若驱动场同时含电场与磁场分量（如圆偏振光在磁化介质中），SRQGT 与 ZQGT 将混入 HHG 谱的通道选择定则——这为我们研究"磁分量在 HHG 中的角色"提供了几何语言。
  - **强场驱动**：时间周期磁场 H_I = −gμ_B B(t)·σ 是我们强场驱动哈密顿量的 Zeeman 部分；其密度矩阵逐级求解技术（式 5-8）与我们对含时密度矩阵做微扰/Floquet 展开的数学工具同源，可直接借鉴到交变磁场通道的二阶电流推导。
  - **交变磁**：CuMnAs 一节是本文与我们方向最直接的接口——PT 对称反铁磁中"传导 NGM 通道存活、位移通道禁戒"的选择定则，与我们在交变磁体中讨论的自旋劈裂与非常规动量依赖自旋织构共享同一套对称性语言；可迁移为我们论证"交变磁 + 量子几何"探测方案的引用锚点。
  - **量子几何**：SRQM/SRBC/Zeeman 联络这一套广义 QGT 是对我们"量子几何可观测化"方法论的直接扩充——我们关注的量子度规在非线性光吸收（shift 电流）中的角色，在这里有磁驱动类比（χ^C,od 类比 shift 电导率、χ^D,d 类比 injection 电导率的表述可引用）。
  - **莫尔**：莫尔工程调控对称性（破 P、保/破 T、控制镜面对称）正是本文 Table II"对称性 → 存活通道"映射的应用场景；莫尔 Dirac/平带体系可作为实现"六角翘曲型"或"倾斜有质量 Dirac"NGM 响应的可调平台候选。

**方法**：广义量子几何三分（QGT/SRQGT/ZQGT）+ 量子动理学密度矩阵微扰 + 弛豫时间近似 + 四代表模型对称性验证（非线性旋磁效应）

**原理**：对布洛赫态同时施加动量平移与自旋转动，量子距离分解为常规 QGT、SRQGT、ZQGT 三项（z^ab_mp = x^a_mp y^b_pm，实部度规/虚部 Berry 曲率，涵盖 CQM/CBC、SRQM/SRBC、ZQM/ZBC 全套）；量子 Liouville 方程在弱无序+弛豫时间近似下按磁场幂次展开迭代求解一/二阶密度矩阵（对角/非对角分解），低频干净极限化简为传导/位移电导率四项（均不依赖 τ——内禀 NGM 电导率）；核心几何分离律：对角通道由 SRQGT 控制（传导←自旋转动量子度规 R、位移←自旋转动 Berry 曲率 Λ），非对角通道由 Zeeman 辛联络 L̃（对 P、T 均奇）与 Zeeman 度规联络 L（P 奇 T 偶）控制——SRQGT 在线性响应完全缺席、是非线性磁输运的基本几何量；四个代表模型（无质量 2D Dirac/六角翘曲 TI 表面/倾斜有质量 Dirac/PT 对称 CuMnAs）验证对称性选择定则。
