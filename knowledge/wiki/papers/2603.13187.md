## 阅读笔记

### general-floquet-20261107

**标题**：Unified Theory of Spin and Orbital Inverse Faraday Effects in Rashba Metals
**作者**：Jaglul Hasan, Maxim Dzero, Chandan Setty（Iowa State/Ames National Lab, Kent State；cond-mat.mes-hall, physics.optics；v1 2026-03-13，v2 2026-11-04）

### 研究问题
在自旋-轨道耦合金属中，自旋逆 Faraday 效应（IFE）与轨道逆 Faraday 效应如何共存？两者在总光致磁化中的相对权重由什么决定？作者在无序 Rashba 二维电子气中建立统一微观理论，声称是首个同时给出自旋与轨道 IFE 的统一图示推导。

### 研究背景
实验上尚无单一机制能解释 SOC 金属中的 IFE：TGG 飞秒测量指向轨道磁化，而过渡金属 Kerr 测量（Cu、Au、Pd、Pt）显示的 Kerr 响应与 SOC 强度相关性很弱，且 Ta、W 的 Kerr 符号相反、结构相依赖性强。理论上 Edelstein 高频自旋 IFE 理论要求以耗散为前提；低频轨道→自旋转移理论（Taguchi–Tatara）不评估轨道磁化；Dzero (PRL 135, 116902 (2025)) 的 Rashba 动力学理论用非守恒近似、显式忽略碰撞积分反馈与部分相空间导数，其响应在无 SOC 时消失、可随频率反号、高频尾巴为 ω^-5，而普通金属轨道响应保号、衰减为 ω^-3。所有既有轨道处理都因"磁力远小于电力"而忽略光学磁场。

### 研究方法
量子动力学 + 图示法双轨：Keldysh 参数化 G^K = G^R∘ĥ - ĥ∘G^A，Wigner 卷积定义分布 ĥ，得到守恒的相空间动力学方程；线性与二次源项保留完整动量/能量导数 D_iĥ = ∂_{p_i}ĥ + ½{v_i, ∂_εĥ}，并首次纳入光的 Lorentz 力项 ½{(v̂×B̂)_i, ∂_{p_i}ĥ}。碰撞积分用 SCBA 完整散射入/出反馈（Σ^a = (Γ/2πν0)∫d²p/(2π)² G^a），保证电荷连续性并产生杂质顶点修正；光学顶点速度算符被杂质重整化为 V̂_i = p_i/m + α_so s(c×σ)_i，其中 w = Γ/z、u = Γz/(z²+Δ_R²)、v = (w+u)/2、s = (1-w)/(1-v)、z = Γ-iω。模型：无序 Rashba 2DEG，短程标量无序，Γ = τ^-1，SCBA 单粒子宽度 Γ/2；T = 0 固定化学势，Γ, ω, Δ_R ≪ ε_F、δ = α_so/v_F ≪ 1，保留任意 ωτ 与 Δ_Rτ。除解析式外做全动量数值积分（每曲线 81 个频率点，η/Γ = 0.0025，动能截止 4ε_F）。

### 主要发现与核心结论
(1) 轨道 IFE 与吸收线性光学电导直接相连：M_orb,z = [e/(mc0Γω)]·Re σ(ω)·H，且 M_E,z = M_B,z = ½M_orb,z——光学磁场（磁 Lorentz 力）贡献了轨道响应的另一半，是此前被忽略的机制。(2) 自旋 IFE 为色散型：M_spin,z = gμ_B e²ν0 C(ω)H，C(ω) = Im[s(2α_so²/z - Γ/p_F²)/(z²+Δ_R²)]；共振外 Γ ≪ ω 时 C(ω) ≈ Δ_R²/[2p_F²ω(Δ_R²-ω²)]，随频率穿越 Rashba 共振 Δ_R 反号；高频 max(Γ,Δ_R) ≪ ω ≪ ε_F 时 C(ω) ≈ -(Δ_R²+4Γ²)/(2p_F²ω³)。(3) 轨道 IFE 保号且主导：因 Re σ ≥ 0（无源金属），总磁化方向在展示区间内不随自旋反号翻转；SOC 自由极限下轨道响应连续并保留 ω^-3 尾巴。(4) 无 SOC 的 Drude 极限 M_orb,z^(0) = n0e³/(m²c0ω(Γ²+ω²))·H，低频按 ω^-1 标度。(5) 参数化（α_so p_F/ε_F = 0.13，ε_Fτ = 50/100/150，InAs m = 0.048m_e、n0 = 2.5×10^12 cm^-2 给 ε_F ≈ 125 meV、|E0| = 100 V/cm 时 M0/(n0μ_B) ≈ 4×10^-8）：自旋在 Rashba 跃迁窗口（宽度 4mα_so²，对应 0.24365 ≲ ω/ε_F ≲ 0.27745）内反号，轨道保持正值并占优。(6) 解析单分裂近似与全动量数值对比（r = 4mα_so²/Γ = 1.69/3.38/5.07）：自旋差异 40.1%/68.8%/83.5%，轨道差异 3.55%/30.8%/50.6%，电导一致性诊断 0.456%/0.906%/1.73%；更受控的 r = 0.08（β = 0.02, ε_Fτ = 100）下自旋最大差异 2.44%、轨道逐点相对差异 < 0.95%。

### 潜在研究方向
作者明确界定边界：单分裂金属公式在 r = 4mα_so²/Γ 不小时无法解析分辨径向跃迁展宽，需数值动量积分定峰形；尚未建立唯一的无库极限、定截止无关的固定密度连续极限，以及精确的未投影电磁分解，Eq.(S219) 的"电/磁各半"是所声明碰撞闭合下的解析结果而非数值证明。数值仍保留有限库与截止，导电性恒等式只是百分比量级的一致性诊断。多带体系中轨道响应本身可变号，故"总磁化必保号"限于本模型；Kerr 旋转到诱导磁化的换算依赖材料与探测频率。下一步需在真实强 SOC 材料与多带体系中检验。


## 研究方法（方法卡）

**方法**：Rashba 金属自旋与轨道逆 Faraday 效应的统一图示理论（Keldysh 相空间动力学 + SCBA 完整碰撞反馈 + 光学 Lorentz 力项：轨道 IFE 直接连吸收电导且保号主导）

**原理**：在无序 Rashba 2DEG 中统一微观推导自旋 IFE 与轨道 IFE：Keldysh 参数化 G^K = G^R∘ĥ − ĥ∘G^A（Wigner 卷积定义分布 ĥ）得到守恒相空间动力学方程，线性与二次源项保留完整动量/能量导数、首次纳入光的 Lorentz 力项 ½{(v̂×B̂)_i, ∂_{p_i}ĥ}；碰撞积分 SCBA 完整散射入/出反馈保证电荷连续性并产生杂质顶点修正（V̂_i = p_i/m + α_so s(c×σ)_i，w=Γ/z、u=Γz/(z²+Δ_R²)）；核心结论：(1) 轨道 IFE 与吸收线性光学电导直接相连 M_orb,z = [e/(mc0Γω)]·Re σ(ω)·H 且电/磁贡献各半（M_E,z = M_B,z = ½M_orb,z）——光学磁场是被此前忽略的另一半机制；(2) 自旋 IFE 为色散型、随频率穿越 Rashba 共振 Δ_R 反号；(3) 因 Re σ ≥ 0（无源金属）轨道 IFE 保号且主导——总磁化方向不随自旋反号翻转；SOC 自由极限保留 ω^-3 尾巴。
