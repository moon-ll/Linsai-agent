• # Two routes to quantum anomalous Hall states in altermagnets

  ## 林赛的理解

  这篇工作给我们提供了一个从**交变磁（altermagnet）**出发实现**量子反常霍尔态（QAHE）**的微观图像。对我们组的方向来说，关键启发在于：Rashba 型自旋-轨道耦合（SOC）与交变磁序的结合，可以在布里渊区边界诱导能带反转；随后通过**单轴应变**或**垂直磁场**这两种实验上可调的微扰把反转的能隙打开，得到具有不同陈数（C = 1 与 C = 2）的拓扑相。这让我立刻联想到我们可以用**强场超快光学/阿秒磁光光谱**去“读取”这些拓扑相的 Berry 曲率和自旋极化边缘态——这正是 HHG 与量子几何交叉的天然接口。 furthermore，磁滞回线中的亚稳态 C = 2 相是一个隐藏拓扑相，意味着**强场驱动**或许能在超快时间尺度上诱导或捕获这类态，为“交变磁序参量超快读出”与“莫尔/界面体系中的量子反常霍尔效应”两个课题都提供了具体的问题入口。

  ## 研究问题

  论文要回答的核心问题是：**如何在代表性交变磁材料中，从最小化的微观模型出发，实现量子反常霍尔效应？** 具体包括：
  - 交变磁的基态（无净磁化但具有宏观时间反演对称性破缺）能否通过实验可及的微扰转变为拓扑非平庸相？
  - 需要何种对称性破缺（晶格畸变 vs 磁场）来打开 Rashba 诱导的能带反转能隙？
  - 这些拓扑相具有怎样的量子化霍尔电导、陈数、边缘态自旋纹理，以及它们之间的本质区别是什么？

  ## 研究背景

  量子反常霍尔效应（QAHE）的特征是在无外磁场下出现量子化的霍尔电导，已在铁磁体、磁性掺杂拓扑绝缘体、非共面磁体以及莫尔异质结构中的轨道铁磁体等体系中被广泛讨论。这些体系的有限 Berry 曲率通常来源于自发磁化或标量自旋手性带来的等效磁场。

  近年来，**交变磁体**作为一类新的破缺时间反演对称性的共线反铁磁体受到关注：相反自旋的子晶格不是通过平移或反演对称性联系，而是通过旋转、镜面、滑移或螺旋等晶体对称性联系，因此即使在没有相对论 SOC 的情况下也会出现自旋劈裂的能带与多种非常规交叉关联效应（自旋流、反常霍尔效应、磁光效应、压磁效应、非常规超导等）。

  尽管已有若干理论 proposal 在 checkerboard、Lieb 晶格等理想几何或由所谓 Zeeman 型 SOC（忽略显式自旋混合）的模型中预言了交变磁的 QAHE，但这些设置往往过于理想化，且第一性原理演示多限于人工二维化合物。因此，**在真实代表性交变磁材料（钙钛矿/金红石型过渡金属化合物、有机导体等）中实现 QAHE 的微观路径仍不清楚**。本文正是从最小模型出发，用实验上可及的外场微扰填补这一空白。

  ## 研究方法

  研究采用**正方晶格单轨道 Hubbard 模型**，并引入反映交变磁子晶格交替局域环境的**反对称自旋-轨道耦合**：

  - 哈密顿量主体：$H_{\rm ALM} = -t \sum_{ij,\sigma} c^\dagger_{i\sigma} c_{j\sigma} + U \sum_i n_{i\uparrow} n_{i\downarrow} + \sum_{ij,\sigma\sigma'} \frac{i}{2}(\lambda^A_{ij}\cdot s)_{\sigma\sigma'} c^\dagger_{i\sigma} c_{j\sigma'}$，其中 $t$ 为最近邻跃迁积分，$U$ 为在位库仑相互作用，$\lambda^A_{ij}$ 为交变磁型反对称 SOC 矢量。
  - **Rashba 型 SOC** $H_R$：与 $\lambda^A_{ij}$ 相同形式的另一反对称 SOC 矢量 $\lambda^R_{ij}$，用于在反铁磁能隙处诱导能带反转。
  - 两种外微扰：
    - **交错势** $H_\Delta = \Delta\left(\sum_{i\in A} - \sum_{i\in B}\right) n_i$，可由沿 $\langle 110\rangle$ 方向的单轴压缩/拉伸应变产生，破坏联系 A/B 子晶格的对称性；
    - **垂直磁场** $H_Z = -h \sum_i s^z_i$，产生 Zeeman 劈裂。
  - 采用 **Hartree-Fock 自洽近似** 求解基态，A、B 位独立处理。
  - 霍尔电导通过 **Kubo 线性响应公式** 计算内禀贡献：
    $$\sigma_{\mu\nu} = \frac{\hbar}{iN}\sum_{klm} \frac{f(\epsilon_{kl})-f(\epsilon_{km})}{\epsilon_{kl}-\epsilon_{km}} \frac{[J^\mu(k)]_{ml}[J^\nu(k)]_{lm}}{\epsilon_{km}-\epsilon_{kl}+i\gamma}$$
  - 陈数采用 **Fukui-Hatsugai-Suzuki 方法的非阿贝尔推广** 在离散布里渊区上计算。
  - 边缘态计算采用**条带几何**：$x$ 方向开放边界，$y$ 方向周期边界，$N_x = 800$、$N_y = 400$；为固定反铁磁构型，将库仑项替换为反铁磁分子场 $-h^x_{\rm AF}\left(\sum_{i\in A} - \sum_{i\in B}\right) s^x_i$。
  - 参数取半填充，并设 $|\lambda^A_x| = |\lambda^A_y| \equiv \lambda^A$、$|\lambda^R_x| = |\lambda^R_y| \equiv \lambda^R$；主要展示结果取 $\lambda^A/t = \lambda^R/t = 0.1$。

  ## 主要发现与核心结论

  ### 无外场基态

  - 当 $U$ 较小时，体系为在 X、Y 点具有节点的**非磁性零能隙半金属**。
  - $U$ 超过临界值后，转变为**交变磁态**：反铁磁矩沿 $x$ 方向，同时出现沿 $z$ 方向的**弱铁磁矩**，$y$ 分量为零。
  - 以 $U/t = 1.5$、$\lambda^A/t = 0.1$ 为例：
    - $\lambda^R/t = 0.0$ 时，X–M、Y–M 等高对称路径上能隙完全打开，为绝缘性交变磁态；
    - $\lambda^R/t = 0.1$ 时，X–M 线附近发生能带反转，出现具有极小能隙的点；该极小能隙来源于自洽解中的弱铁磁矩 $\langle s^z\rangle$——若强制 $\langle s^z\rangle = 0$，则出现无能隙点节点。
    - 该态仍为**拓扑平庸**，陈数 $C = 0$。

  ### 路线一：交错势诱导的 QAHE（C = 1）

  - 在 $\lambda^A/t = \lambda^R/t = 0.1$ 的 $U$–$\Delta$ 相图中：
    - $\Delta/t = 0$ 时，小 $U$ 为 Rashba 把节点移开的非磁性零能隙半金属；增大 $U$ 进入拓扑平庸的交变磁绝缘体。
    - 有限 $\Delta/t$ 立即把非磁性半金属打开成**拓扑平庸非磁性绝缘体**。
    - $\Delta/t \gtrsim 0.003$ 时，在非磁性绝缘体与平庸交变磁绝缘体之间出现**拓扑交变磁绝缘体**相，且稳定区随 $\Delta$ 增大而扩展。
  - 沿 $\Delta/t = 0.01$ 的路径：
    - 自旋矩 $\langle s^x_{A,B}\rangle$、$\langle s^z_{A,B}\rangle$ 随 $U$ 平滑增加，在拓扑相变附近无异常。
    - 能隙 $\Delta_{\rm gap}$ 在 $U/t \simeq 1.45$ 处先关闭再打开，进入拓扑交变磁相；在 $U/t \simeq 1.48$ 处再次关闭，回到平庸交变磁相。
    - 在拓扑交变磁相内，霍尔电导 $\sigma_{xy}$ 量子化为 **$-e^2/h$**，对应 occupied 带的陈数 **$C = 1$**（图中以 $-C$ 表示，故 $-C = -1$）。
  - 下相边界（$U/t = 1.4475$）处能隙沿 $\Gamma$–Y 线关闭；上相边界（$U/t = 1.48$）处能隙沿 M–X 线在 $k_y < 0$ 区域关闭；X–M 线 $k_y > 0$ 区域始终保持有能隙。两个边界之间的有限能隙区即为 $C = 1$ 拓扑交变磁绝缘体。

  ### 路线二：垂直磁场诱导的 QAHE（C = 2）

  - 在 $U/t = 1.48$、$\lambda^A/t = \lambda^R/t = 0.1$ 下研究磁滞过程：
    - 正方符号代表基态解：正磁场下 A、B 子晶格反铁磁矩分别向下、向上，$\langle s^z\rangle > 0$；负磁场则相反。
    - 圆符号代表**亚稳态分支**：从 $h/t = 0.0$ 时具有负 $\langle s^z\rangle$ 的交变磁态出发，沿正磁场方向增加，$\langle s^z\rangle$ 逐渐减小但保持有限（反映弱铁磁性），在 $h/t \simeq 0.005$ 附近变号并随磁场方向增长；当 $h/t \gtrsim 0.012$ 时亚稳态消失，并入基态分支。
  - 基态分支：能隙随磁场单调增大，无能隙关闭，始终保持 $C = 0$、$\sigma_{xy} = 0$。
  - 亚稳态分支：
    - 能隙从基态值连续下降，在 $h/t \simeq 0.004$ 处关闭，随后重新打开，在 $h/t \simeq 0.012$ 处发生不连续跳跃。
    - 在能隙关闭点与亚稳态消失之间，霍尔电导量子化为 **$\pm 2e^2/h$**，陈数 **$C = \mp 2$**。
    - 这是**磁滞过程中出现的亚稳态拓扑交变磁相**。
  - 磁场诱导的相变在 X 点两侧同时发生能隙关闭（与交错势情形仅在一侧关闭不同），因为垂直磁场保留了连接最近邻键中点的二重旋转对称性，而交错势破坏了它。

  ### 边缘态

  - 采用条带几何（$x$ 开放、$y$ 周期），布里渊区边界 M–X–M 上的体能隙关闭决定了边缘态位置。
  - **C = 1 态**（交错势，$\Delta/t = 0.01$，$h^x_{\rm AF}/t = 0.2$，$\lambda^A/t = \lambda^R/t = 0.1$）：
    - 边缘态只在 $k_y < 0$ 区域穿越费米能级；
    - 一支强烈极化为正 $\langle s^z\rangle$，另一支为负 $\langle s^z\rangle$；
    - $\langle s^x\rangle$ 极化约为 $\langle s^z\rangle$ 的约 **五分之一**，$\langle s^y\rangle = 0$；
    - 正（负）$\langle s^z\rangle$ 分支具有正（负）群速度，分别局域在条带右（左）边界，形成**单支手性边缘通道**。
  - **C = 2 态**（磁场，$h/t = 0.01$，$h^x_{\rm AF}/t = 0.2$，$\lambda^A/t = \lambda^R/t = 0.1$）：
    - 边缘态在 $k_y < 0$ 和 $k_y > 0$ 区域均出现；
    - 每个区域有两支边缘态，共四支在体能隙内；
    - $k_y < 0$ 时自旋-传播方向关系与 C = 1 相同；$k_y > 0$ 时相反；
    - 每个边界承载**两支传播方向相同、自旋极化相反的手性边缘模**；
    - 边缘态局域化比 C = 1 态更弱，反映了该相体能隙更小。

  ## 潜在研究方向

  1. **实验实现平台**：作者建议优先探索具有破缺反演对称的交变磁薄膜、界面和异质结构，尤其是含 3d、4d、5d 过渡金属离子的氧化物界面，以及含重 5d 金属的有机-金属 $\pi$–$d$ 杂化分子导体（如金二硫烯类）。
  2. **压磁态/补偿亚铁磁薄膜**：交错势与压磁效应所需晶格畸变相同，因此补偿亚铁磁薄膜可能是不加应变即可实现 C = 1 量子化霍尔态的平台。
  3. **亚稳态拓扑相的操控**：C = 2 相作为磁滞回线中的隐藏拓扑相，其实验制备与超快操控值得研究——例如能否用**强场太赫兹脉冲或光磁化**在亚稳态窗口内诱导并读出该相。
  4. **强场/阿秒诊断**：用量子几何灵敏的 HHG 或阿秒磁光光谱直接探测 Berry 曲率分布、陈数跃迁以及自旋分辨的边缘态动力学，是与我们组最贴近的接口。
  5. **超越 Hartree-Fock**：有限温度、无序、动态关联和量子涨落对拓扑能隙与边缘态稳定性的影响需要进一步研究。
  6. **推广到其他晶格与 SOC**：本文采用最小正方晶格模型，其他交变磁晶格（如 rutile、钙钛矿结构）以及不同对称性的 SOC 可能给出更丰富的陈数相图。
  7. **莫尔异质结构**：将交变磁序与莫尔超晶格结合，可能通过莫尔势工程化地实现类似的交错势或等效磁场，从而调控量子反常霍尔响应。

  ## 与林赛研究的关联

  - **HHG 与量子几何**：QAHE 的本质是占据带的 Berry 曲率积分。强场驱动的 HHG 对 Berry 曲率、量子度规和拓扑不变量高度敏感，可以在不接触电极的情况下“光学读取”陈数跃迁。
  - **阿秒磁光与自旋极化边缘态**：C = 1 与 C = 2 态具有截然不同的自旋极化手性边缘通道，阿秒时间分辨的磁圆二色或自旋分辨 HHG 可作为非平衡拓扑相的指纹。
  - **强场驱动相变**：垂直磁场路线中的亚稳态 C = 2 相提示，超快磁场脉冲或光诱导自旋翻转可能在皮秒/飞秒尺度上捕获隐藏拓扑相，与我们的“强场驱动”方向直接对口。
  - **交变磁序参量读出**：论文中交错势与弱铁磁矩共同决定拓扑相，为“交变磁序参量超快读出”课题提供了明确的序参量-拓扑响应映射。
  - **莫尔平台**：莫尔异质结构中的轨道铁磁已被证实可产生 QAHE；将交变磁体（或压磁/补偿亚铁磁薄膜）与莫尔工程结合，是“莫尔”方向下新的材料设计思路。

**方法**：正方晶格 Hubbard 模型（反对称 SOC）Hartree-Fock 自洽 + Kubo 霍尔电导 + Fukui-Hatsugai-Suzuki 陈数 + 条带边缘态（交变磁 QAHE 双路线）

**原理**：单轨道 Hubbard 模型叠加交变磁型反对称 SOC λ^A，Rashba 型 λ^R 在反铁磁隙处诱导能带反转（极小能隙由自洽弱铁磁矩 ⟨s^z⟩ 维持）；两种实验可及微扰开隙得不同陈数拓扑相——路线一：交错势 H_Δ（⟨110⟩ 单轴应变产生，破 A/B 子格联系对称）诱导 C=1 QAHE；路线二：垂直磁场 H_Z 的磁滞过程中出现亚稳态 C=2 隐藏拓扑相；Hartree-Fock 自洽（A/B 位独立），Kubo 线性响应算内禀霍尔电导，FHS 方法非阿贝尔推广在离散 BZ 算陈数，条带几何（库仑替换为反铁磁分子场固定构型）算自旋分辨边缘态。
