## 深度解析

### 研究问题（Research Question）

高次谐波 OAM 上变换律 lq = q × l 一直被当作涡旋驱动 HHG 的铁律。本工作首次实验证明:当驱动脉冲短到 1.5 个光学周期时,少周期波形 CEP 成为额外自由度,可把探测窗口内的「整数」拓扑荷切换为相邻整数(lq=5 ↔ lq=6),甚至产生分数 TC 的谐波涡旋。机制依赖于反演对称破缺提供偶次谐波(缩短相邻谐波谱间隔至 n=1)与 CEP 敏感子周期电子动力学共同打开的「多模谱重叠窗口」。

### 研究背景（Background）

林赛的强场超快光学平台(800 nm Ti:Sa + OPA 出 3 µm 中红外 + 少周期压缩 + ZnO HHG)与本工作实验栈高度同构:(1) 中红外少周期涡旋驱动在 ZnO 中产生 TC 可调的谐波涡旋,直接对应林赛 2024 年起跑的 DFG 课题「少周期 CEP 控制固体 HHG」的可行性验证;(2) SBE 复偶极矩形式与林赛组已有的 SBE code(Dirac 组继承版本)完全兼容,只需把 d(k) 改成复数即可重现本工作 Fig. 9 的 CEP 谱预测——这是低成本理论迁移;(3) 浙大/上光所体系的 ZnO 单晶生长与 a-cut/c-cut 样品制备门槛不高,可与 Markus 组合作快速复现「偶次谐波 + CEP 切换 TC」的标志性结果;(4) 向 plateau 区延伸时,HHG 进入 EUV,需 3 µm 少周期 + 高通量 EUV 光谱仪(掠入射 + MCP + CCD),林赛现已在规划相应真空管线;(5) 与「能谷电子学」的连接:分数 TC 谐波涡旋对 TMD(如 WSe₂、MoS₂)天然适用,K/K' 谷间跃迁的偶极相位 Φ_K ≠ Φ_K',预期能直接读出谷间 Berry 相位差——这是林赛谷电子学方向的潜在突破口。最大不确定性是林赛实验室中红外 OPA 是否已达 1.5 cycle 级别(当前多在 17-25 fs),需要先做脉宽标定;如未达,需补一个 hollow-core fiber 或板条压缩级。

### 研究方法（Methods）

- 薄板模型(TSM)扩展到 CEP 依赖的两模干涉描述:在频域用带通滤波函数 W_BP(ω) 投影两个相邻谐波阶到同一探测频率,detected TC 等价于 winding number 取主导 OAM 模。给出闭式公式 ℓ = q×l 或 (q+n)×l 取决于 |aq|/|a_{q+n}| 的大小关系(式 17-22)。
- 复跃迁偶极矩 SBE 求解:把传统 1D 两带 SBE 改写为 pr + i pi 耦合形式(式 44),用 Φ(k)=φ0 sin(ka_x) 的现象学偶极相位代表 aZnO 反演破缺;该模型能在不破坏 SBEs 守恒律的前提下产生偶次谐波与 CEP 敏感发射,是少周期固体 HHG 的通用可迁移工具。
- CEP 稳定化与逐相位扫描:基于 Dazzler AOPDF + Fringeezz f-to-2f 干涉闭环,CEP 残余抖动 < 150 mrad RMS,扫描 31 步跨 -π 到 π,步长 0.2 rad。这是 ELI-ALPS MIR 实验室独有的标准化工作流,可直接迁移到其他 3-4 µm 涡旋驱动 HHG 实验。
- 倾斜 HG-lobe 模式转换法识别分数 TC:单柱面镜把涡旋转换为倾斜 HG 强度分布,lobe 间最小值数目等于整数 TC;分数 TC 表现为 lobe 不对称分布与 vortex 强度环破裂为「c 形」。比干涉法更紧凑,可分辨到 ±0.5 TC 变化。

### 主要发现与核心结论（Main Results）

- 实验观测到 TC 切换:用 ELI-ALPS MIR OPCPA(中心 3.2 µm, 100 kHz, 100 µJ/pulse)压缩至 16 fs(1.5 cycles)后经 SPP 形成 TC=1 的涡旋,聚焦在 a-cut ZnO(50 µm 和 200 µm 厚度)上;在 550±20 nm 带通窗口(位于第 5 与第 6 谐波之间)测得 TC 在 φ_CEP=0 时为 lq=6、φ_CEP=π 时为 lq=5,相邻整数间发生可逆切换。
- 反演对称破缺是必要条件:c-cut ZnO 在相同 1.5 cycle 条件下完全无 CEP 效应,lq 锁死;a-cut ZnO 旋转 90° 抑制偶次谐波后 TC 切换也消失。两组对照证明:偶次谐波 → 相邻阶间隔从 2ω 缩为 ω(n=1)→ 谱重叠进入 BPF 窗口是切换的前提。
- 脉冲长度是第二个开关:固定 aZnO(200 µm)情况下,4 mm CaF₂ 拉至 77.2 fs(semi-stretched,7.2 cycles)时呈现干净 lq=6 ↔ lq=5 整数切换;进一步拉伸到 186 fs(17.4 cycles)后 TC 完全不变,CEP 不再影响谐波;未压缩 4 cycle 直接输出时由于窗口内谱无重叠也不切换。说明「CEP 敏感的子周期动力学」与「谱重叠」必须同时满足。
- 多模干涉产额分数 TC:完全压缩脉冲下 HG 倾瓣呈非对称多瓣结构,对应 vortex 强度环破裂为「c 形」开口;数值模拟显示两模(l 和 l+1)等幅相干叠加给出 ⟨Lz⟩ = ℏ(l + 1/2) 的分数值。这是固体 HHG 中首次实验报告分数 TC 谐波涡旋。
- 理论框架:少周期下复跃迁偶极矩 dk = |dk|e^{iΦ(k)} 的相位项 Φ(k) 使 SBE 的相干项 pr + i pi 耦合不同;只有当 di≠0 时 HHG 谱呈现 CEP 依赖,且主要发生在相邻阶交叠区。detected TC 由两模相对振幅决定:|aq|·|Rql|^p 与 |a_{q+n}|·|R_{(q+n)l}|^p 谁大谁主导谐波的 lq;CEP 通过重排相邻阶的振幅比切换主导模。
- 晶厚影响:通过改变样品厚度(200 µm vs 50 µm)需用不同色散量达到最佳窗口匹配——50 µm 用 1 mm BaF₂(~68 fs),200 µm 用 4 mm CaF₂(77.2 fs)。这是相干长度与群速度失配的指纹,可在实验上用作微观相干长度的探针。

### 潜在研究方向（Future Directions）

- 向高次谐波(plateau 区)推进:相邻阶间距在 plateau 区同样会因谱增宽而趋零,作者预期 TC 控制可在 EUV 区实现。挑战是 EUV 谱仪与模式转换器的同步,需要新一带带通滤波结构。
- 双涡旋驱动(l_1, l_2 同时存在):两个 TC 的涡旋相干叠加天然给出分数 TC(⟨Lz⟩ = ℏ(a l_1 + b l_2)/(a+b)),可作为 CEP-TC 解耦控制的另一途径。
- 在拓扑材料(Bi₂Se₃、TIs)中测试:拓扑表面态的对称性与 Berry 偶极矩可改变 d(k) 的相位结构,预期能进一步操控 CEP-TC 耦合。
- 用 CEP-TC 切换作为固体中 Berry 连接相位 Φ(k) 的直接探针:测不同 φ_CEP 下多模干涉比,可反推 d(k) 复相位——这是把 HHG 升级为固体 Berry 相位测量的新路径。
- 拍赫兹电子学中的应用:CEP-locked OAM 谐波是天然可调谐的矢量束,可作为驱动近场扫描探针或编码高维量子比特的相干光源。

## 研究方法（方法卡）
<!-- methods-backfill:v1 -->
**方法**：复偶极矩 SBE（Complex-dipole Semiconductor Bloch Equations，含两模干涉 TC 判据）

**原理**：传统一维两带 SBE 把带间跃迁偶极取为实数，隐含反演对称，禁止偶次谐波且发射与 CEP 无关。该方法将带间相干项改写为 pr + i·pi 的耦合形式（式 44），引入复跃迁偶极 dk = |dk|e^{iΦ(k)}，其中现象学偶极相位 Φ(k)=φ0·sin(ka_x) 编码 a-cut ZnO 的反演对称破缺。虚部耦合使 pr 与 pi 的演化失同步，在不破坏 SBE 守恒律的前提下同时产生偶次谐波与 CEP 敏感发射：偶次阶出现把相邻谐波谱间隔从 2ω 压缩到 ω，使相邻阶进入带通滤波函数 W_BP(ω) 的探测窗口发生谱重叠；此时探测到的拓扑荷等价于 winding number 取主导 OAM 模，由 |aq|·|Rql|^p 与 |a_{q+n}|·|R_{(q+n)l}|^p 的相对大小决定（式 17-22 闭式公式），CEP 通过重排相邻阶振幅比即可在 ℓq=5 ↔ ℓq=6 间切换主导模；两模等幅相干叠加时给出 ⟨Lz⟩=ℏ(l+1/2) 的分数拓扑荷与 c 形强度环。

**林赛理解**：

林赛组已有的 Dirac 继承版 SBE code 与该形式完全兼容，只需把 d(k) 改成复数即可低成本复现本文 Fig. 9 的 CEP 谱预测，直接支撑 NSFC 强场超快项目「少周期 CEP 控制固体 HHG」课题的理论底座；把 Φ(k) 替换为 TMD 谷间偶极相位差（Φ_K ≠ Φ_K'），还可延伸到 WSe₂/MoS₂ 谷间 Berry 相位差的分数 TC 读出，成为能谷电子学方向的潜在突破口。需注意前提是林赛 OPA 脉宽须先压缩到 1.5 cycle 量级。

**适用边界**：仅适用于少周期（约 1.5-4 cycle）驱动、反演对称破缺晶体（a-cut ZnO 类）且相邻谐波阶在带通窗口内谱重叠的固体 HHG；中心对称取向（c-cut）或脉宽拉长至 ≳17 cycles 时偶次谐波消失或子周期动力学平均化，CEP 依赖与 TC 切换即失效。
