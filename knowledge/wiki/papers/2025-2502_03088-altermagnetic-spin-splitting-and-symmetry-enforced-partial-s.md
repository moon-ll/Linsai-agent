• # Altermagnetic spin splitting and symmetry-enforced partial spin degeneracy in hexagonal MnTe

  ## 林赛的理解

  这篇工作做了一件看似简单但此前没人系统做完的事：把六方 MnTe 的自旋劈裂与简并的"空间地图"完全钉死在磁空间群对称性上。我把它看作一份可以直接拿来用的**对称性字典**——不是又一篇宣称"发现了交变磁性"的论文，而是一份操作手册：哪些平面简并（kz=0、ky=0）、哪些平面劈裂、劈裂面内节点的精确位置由哪些反幺正操作强制保护，全部给出了 Seitz 符号级别的推导，还给了一个只有一项劈裂项 σz·kykz(3kx²−ky²) 的极简模型哈密顿量。对我们而言，这种"部分简并 + 节点线"的结构正是强场光电子谱学和超快磁学探测里最想要的目标：简并面与劈裂面共存意味着自旋相关的跃迁矩阵元在整个布里渊区内有巨大的、可被对称性预测的空间反差，这是设计强场驱动选择性激发、THz 频段手性磁振子激发以及自旋分辨光发射实验的天然路线图。

  ## 研究问题

  六方 MnTe 作为实验已确认的交变磁体（altermagnet），其核心问题是：**什么样的磁空间群对称性条件导致部分布里渊区发生自旋劈裂、同时在另一些区域保持自旋简并？** 具体分解为三个子问题：

  1. 在无自旋-轨道耦合（SOI）的非相对论框架下，MnTe 的磁空间群 P6̄′₃/m′mc′ 中哪些操作保护简并、哪些操作允许劈裂？节点线（nodal lines）的精确位置在哪里？
  2. 能否构造一个对称性适配的模型哈密顿量，在整个布里渊区定性复现 DFT 给出的劈裂/简并图案？
  3. 计入 SOI 后，实验报道的弱铁磁性与反常霍尔效应（MnTe 本应无净磁化）能否被对称性与 DFT 同时解释？

  ## 研究背景

  - 交变磁体是近期发现的零净磁化但破缺时间反演对称性的共线反铁磁体，兼具自旋劈裂能带，被认为可支撑自旋劈裂扭矩（spin-splitter torque）与线性色散的**手性磁振子**（chiral magnons）等应用 [1–3]。
  - 交变磁特征已在多种材料中被报道：六方 MnTe、正交 BiFeO₃ 与 CaMnO₃、四方 MnF₂ [4–8]；而著名的候选材料 RuO₂ 的直接谱学观测中自旋劈裂仍未被确认 [9]。交变磁体还可能承载磁多极、反常霍尔效应、晶体热霍尔效应与晶体能斯特效应 [10–16]。
  - 六方 MnTe 是少数实验确认的交变磁材料，且几乎展示全部特征 [4, 7, 11–23]：实验确认了破缺的 Kramers 简并与各向异性磁电阻 [19, 20]；非弹性中子散射确认了手性磁振子与 **g-wave 磁性** [19]。与铁磁来源磁振子的二次色散和 GHz 频率不同，交变磁手性磁振子可具有近线性色散和 **THz 频率** [3, 25]，对磁振子自旋电子学极具吸引力。
  - 悬而未决的问题：MnTe 中"某些 k 区劈裂、另一些 k 区简并"的对称性条件此前未被完整描述；SOI 常导致交变磁体出现微倾的磁矩、弱铁磁与反常霍尔效应 [5, 27–29]，MnTe 中实验上确实同时观测到反常霍尔效应与弱铁磁性 [14]，亟需厘清 SOI 的真实影响。
  - 该组的此前工作 [4]（Adv. Phys. Res. 3, 2300050 (2024)）发现六方 MnTe 的反铁磁自旋劈裂与"隐藏 Rashba-Dresselhaus 相互作用"，本工作是其对称性层面的深化。

  ## 研究方法

  - **材料体系**：块体六方 MnTe，空间群 P6₃/mmc，点群 D6h；Mn 与 Te 分别占据 2a 与 2c Wyckoff 位；A 型反铁磁序——局域磁矩在六方基面内平行、沿 a⃗₃ 方向反平行（Fig. 1）。空间群含 24 个幺正对称操作（Seitz 符号完整列出，Table I）。
  - **DFT 设置**：VASP 代码，PAW 势 + 平面波基组，截断能 **500 eV**；交换关联泛函采用 meta-GGA **SCAN** + **Hubbard-U 修正（U_eff = U − J = 3 eV，针对 Mn-3d）** + van der Waals 修正 **rVV10**（沿用该组先前的优化设置 [4]）；布里渊区积分用 **9×9×6** Γ 中心 k 点网格 + 校正四面体方法；原子位置与晶格矢量通过 Hellmann-Feynman 力优化至阈值 **10⁻² eV/Å**。
  - **对称性分析**：基于磁空间群（MSG）理论，分无 SOI（MSG P6̄′₃/m′mc′，含 12 幺正 + 12 反幺正操作，Table II）与含 SOI（自旋量子化方向 [11̄20]，MSG 降为 Cmcm，纯幺正，Table V）两种情况；对各类 kx-ky、ky-kz、kx-kz、v=常数平面逐一推导反幺正操作对 (u,v,w) 的不动点条件；附录给出倒空间对称操作矩阵推导 V=(U⁻¹)ᵀ 与六方倒格矢 ↔ 笛卡尔坐标变换的完整公式。
  - **模型哈密顿量**：Γ 点取两个 Mn 位高度局域化的自旋基态，对 MSG P6̄′₃/m′mc′ 的生成元 {3⁺₀₀₁|0}、{−1|0}、{21̄₁₀|0} 与反幺正 T{6⁺₀₀₁|001/2} 施加不变量约束，构造对称性允许的两能带有效哈密顿量。
  - **分析对象**：选取 Fig. 2 中加粗标记的一对自旋劈裂能带，绘制三维色散 ε(kx,ky,0)、ε(kx,0,kz)、ε(0,ky,kz) 及 E−EF = −0.58 eV（另取 −0.9 eV、−1.1 eV）的等能线，逐平面与对称性预言比对。

  ## 主要发现与核心结论

  1. **电子结构**：自旋极化 DFT 给出间接带隙 **~1.16 eV**（价带顶在 A 点、导带底在 K 点），与实验值 **1.27 eV** [42] 合理吻合（DFT 系统性低估）；每个 Mn 原子的投影磁矩 **4.54 µB**，与实验测得的每 Mn 位 **4.7–5 µB** [43] 相符。
  2. **简并面与劈裂面**（无 SOI）：自旋简并贯穿 **kz = 0** 与 **ky = 0** 整面；其余布里渊区普遍劈裂，除本文识别出的节点线外。Table III 汇总了全部平面的劈裂/节点图案：
     - kz = 0：不劈裂；kz = 常数 ≠ 0：劈裂，节点满足 **u = v、u = −2v、v = −2u**（kx-ky 面内六个对称强制简并点，DFT 等能线验证）；
     - ky = 0：不劈裂；ky = 常数 ≠ 0：劈裂，节点在 **kz = 0、kx = 0**；
     - kx = 0：劈裂，节点在 **kz = 0、ky = 0**；kx = 常数 ≠ 0：劈裂，节点同前；
     - v = 0：劈裂，节点在 **kz = 0、kx = 0**；v = 常数 ≠ 0：劈裂，节点在 **kz = 0、kx = −(π/a)v**。
     - 具体验证点：kz = **0.0553 Å⁻¹** 平面等能线仅在少数节点重合；kx = **0.0559 Å⁻¹** 平面节点位于 kz = 0 与 ky = 0；v = **0.037037** 平面节点位于 kx = (2π/a)u = −(π/a)v 与 kz = 0。
  3. **非对称劈裂线**：沿高对称线 **U → ∆** 与 **L̄(0, 1/2, −1/2) → Γ → L(0, 1/2, 1/2)** 出现显著自旋劈裂；反幺正操作 **T{2₀₀₁|001/2}** 使 kz = 0 面内任意 k 矢量不变、连接两个反平行磁亚格点，是 kz = 0 整面简并的保护操作。
  4. **模型哈密顿量**：Γ 点四阶不可约张量分析的唯一不变劈裂项为 **σz·kykz(3kx² − ky²)**，即
     H = H₀ + ασz·kykz(3kx² − ky²)，ε±(k⃗) = ε₀(k⃗) ± α·kykz(3kx² − ky²)。
     该项保持反演对称性（非相对论劈裂的特征），在附录 C 中取 H₀ 为自由电子动能后，其三维色散与等能线定性复现 DFT 的全部劈裂/简并图案（Table III）。
  5. **意外简并**：Fig. 5(b)(c)(e)(f) 与 Fig. 6(b)(c)(e)(f) 中额外出现的简并非对称保护，属偶然简并（accidental degeneracies）。
  6. **SOI 与弱铁磁**：含 SOI 后自旋量子化沿择优方向 **[11̄20]**，磁空间群降为 **Cmcm**（纯幺正，磁点群 mmm.1），仅允许磁矩分量 (mx, mx, 0)；镜像面 m1̄10 与 m001 翻转磁矩方向并强制反平行排列。DFT 证实 **[11̄20] 易轴上局域磁矩反平行相消，无弱铁磁分量**，即纯交变相。对实验报道 [14] 的弱铁磁与反常霍尔效应，论文讨论的解释路径：① Berry 曲率多极可在 Berry 曲率积分为零时仍维持反常霍尔电导 [47]；② Mazin 与 Belashchenko [48] 将其归因于 SOI 的**三阶效应**；③ 备选自旋量子化方向 **[1̄100]** 对应 MSG **Cm′c′m**，沿 a⃗₃ 产生弱铁磁与一阶反常霍尔效应 [45, 47]；④ **Cmcm 与 Cm′c′m 的混合相**也可能导致弱铁磁与一阶反常霍尔。
  7. **方法论结论**：P6₃/mmc 中的非对称螺旋操作 {2₀₀₁|001/2} 使结构在 a⃗₃/2 平移下不变但磁结构不变，T 与 PT 被破坏——**非对称螺旋对称是 MnTe 实现交变磁性的必要条件**；对电子能带的对称性分析同样适用于手性/非手性磁振子。

  ## 潜在研究方向

  - **Cm′c′m 混合相的微观证实**：论文提出的 Cmcm/Cm′c′m 混合机制目前只是合理推测，缺乏实验判据；需要能分辨局域自旋量子化方向（[11̄20] vs [1̄100]）空间分布的谱学或显微手段。
  - **弱铁磁的三阶 SOI 起源 vs 多极机制之争** [14, 47, 48] 未决：反常霍尔电导的动量空间分解（Berry 曲率分布）在 MnTe 中尚未被直接测量。
  - **模型哈密顿量的定量化**：附录 C 中 H₀ 仅取自由电子动能，带形与 DFT 差异明显；将该模型与紧束缚 H₀ 结合、提取 α 的实值并与等能线劈裂宽度定量拟合，是一个直接的后续工作。
  - **偶然简并的稳定性**：非对称保护的节点对微扰（应变、掺杂、SOI）是否稳定、是否演化为 Weyl/ nodal-line 半金属态，论文未讨论。
  - **关联强度敏感性**：仅测试了 U_eff = 3 eV；U 值对简并面位置、带隙（1.16 eV vs 实验 1.27 eV）及劈裂节点精确位置的系统影响未做扫描。
  - **表面/薄膜维度缩减**：全部结论针对块体六方结构；MnTe 薄膜或异质结中螺旋对称的破坏会如何改写这份"简并地图"，对器件应用至关重要但未涉及。

  ## 与林赛研究的关联

  - **强场驱动选择性激发**：Table III 的简并/劈裂地图直接给出强场激发设计的 k 空间模板——在劈裂区（如 kx = 0 面）两自旋支的带边能量差可达 eV 量级，强场驱动下可针对单一自旋支实现选择性布居；简并面（kz = 0、ky = 0）与劈裂面之间的边界节点线是强场谱学（如自旋分辨 trARPES）最敏感的特征信号。
  - **HHG / 阿秒探测**：σz·kykz(3kx²−ky²) 形式的动量依赖劈裂意味着自旋分辨的带间偶极矩在布里渊区内有 d 波（g 波）角结构，这将直接调制固体高次谐波产生的偏振与自旋依赖 HHG 谱——可作为我们**强场驱动 HHG 探测交变磁序**方向的定量化输入参数。
  - **THz 手性磁振子**：论文确认的 g-wave 磁性与近线性色散、THz 频率手性磁振子 [19] 与我们关注的**交变磁**方向词直接对接；对称性分析（对电子与磁振子等价适用）可迁移到超快 THz 激发-探测磁振子的实验设计中，预测哪些 k 区手性磁振子可激发、哪些禁戒。
  - **莫尔/平带接口**：六方 MnTe 的 D6h 对称性与常见莫尔体系（h-BN、TMD 六方晶格）兼容；若将 MnTe 作为莫尔异质结的功能层，其自旋劈裂的 d 波角动量结构与莫尔势叠加可产生可调谐的关联交变磁态，这与我们的**莫尔**方向存在潜在交叉。
  - **实验接口**：间接带隙 1.16 eV（实验 1.27 eV）、Mn 磁矩 4.54 µB（实验 4.7–5 µB）等基准数值可直接用于本组 DFT+U 计算流程（SCAN+rVV10+U=3 eV、500 eV 截断、9×9×6 网格）的交叉验证。

**方法**：交变磁自旋劈裂与对称性强制部分简并的 MSG 分析（MnTe：SCAN+U+rVV10 + 两能带对称哈密顿量）

**原理**：块体六方 MnTe（P6₃/mmc，D₆h，A 型 AFM）对称性逐平面推导：无 SOI 的 MSG P6̄′₃/m′mc′（12 幺正+12 反幺正）与含 SOI（量化轴 [11̄20]，降 Cmcm）两种情况，对 kx-ky/ky-kz/kx-kz/v=常数各平面逐一推导反幺正操作不动点条件（附录含 V=(U⁻¹)ᵀ 与倒格矢↔笛卡尔变换公式）；DFT：VASP PAW 截断 500 eV，meta-GGA SCAN + U_eff=3 eV（Mn-3d）+ rVV10 vdW，9×9×6 Γ 中心 + 校正四面体，力阈值 10⁻² eV/Å；Γ 点两能带对称性约束有效哈密顿量（对 MSG 生成元 {3⁺|0}、{−1|0}、{21̄₁₀|0}、反幺正 T{6⁺|001/2} 施加不变量）；分析自旋劈裂带的三维色散与 E−E_F=−0.58 eV（另 −0.9/−1.1 eV）等能线的对称性强制部分简并模式。
