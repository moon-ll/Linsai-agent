• # Wilson loops, symmetries, and selective bulk-boundary correspondence in higher-order topological insulators（高阶拓扑绝缘体中的 Wilson loop、对称性与选择性体-边对应）

  ## 林赛的理解

  这篇工作是纯理论的方法学文章，但它的价值恰好落在我们课题的一个软肋上：我目前的高阶拓扑/Floquet 课题（key-transient-quantum-phase-optical）里，判断"驱动后体系是不是高阶拓扑相"主要靠能量谱上数角态，缺乏一套动量空间的不变量诊断工具。这篇论文给出了一套可计算的、规范无关的 Wannier Hamiltonian 拓扑不变量（mirror-filtered 绕数 + 类比 Floquet 周期化 Wilson line 的 Wannier 隙不变量），并且诚实地指出了它们的适用边界——在非可分模型里，这些不变量给的是 Wilson loop 层面的体-边对应，而不是直接给角态计数。这正好是我们可以用 HHG/阿秒瞬态光学手段去补位的环节：谱学能看到角态和边界态，但动量分辨的非线性光学响应（HHG 的偏振结构、次谐波辐射的几何相位印记）有可能探测到 Wannier 带的拓扑跃迁。另一个直接可用的点：论文明确指出非可分模型（含对角跳跃项、长程跳跃）可以作为**周期驱动体系的 Floquet Hamiltonian** 自然出现——这把"静态高阶拓扑诊断"与"强场驱动诱导拓扑"两条线直接焊接起来了。

  ## 研究问题

  在具有**反对易镜像对称**的手征对称二维 Bloch Hamiltonian 族（推广了 π-flux 方格子/拓扑四极绝缘体）中：

  1. 哪些对称性保护、哪些不变量刻画**高阶体-边对应**（角态计数）？
  2. 对**非可分模型**（含对角/混合跳跃项），一维子系统手征绕数乘积 ν=ν₁ν₂ 失效后，如何在动量空间构造替代的拓扑诊断量？
  3. Wilson loop / Wannier Hamiltonian 的拓扑不变量与角态计数之间的对应关系在多大程度上成立？（"selective bulk-boundary correspondence"——对应是选择性的，不是普适的）

  中心论点：镜像滤波（mirror-filtered）绕数与 Wannier 隙不变量能刻画 Wannier 带拓扑，但在一般非可分模型中尚未找到它们到高阶体-边对应的简单映射。

  ## 研究背景

  - 高阶拓扑相自量化多极绝缘体理论 [1,2] 提出后已在多个平台实验实现 [3–11]。原型模型 π-flux 方格子 [12] 与 Kekulé 六角模型 [13] 等手征对称紧束缚模型早有研究，其涡旋束缚零能态的不变量与 Dirac 费米子-涡旋低能理论的指标定理一致 [14–19]。
  - 晶体对称性可保护余维数大于一的边界态（角/铰链模）[22–34]。早期用嵌套 Wilson loop 与 Wannier 带极化构造多极矩不变量 [35–41]，但多极矩之外存在更丰富的高阶拓扑结构。
  - 关键事实：π-flux 方格子中手征对称保护的是 **Z 值**不变量，而嵌套 Wilson loop 只给 **Z₂ 值**四极矩。体系同时具有 BDI 类离散对称与镜像/旋转对称，因此"谁保护、用什么刻画"是自然问题。
  - 可分模型的乘积不变量 ν=ν₁ν₂ 已被证明正确预言角态数 [42–47]；但非可分模型无法构造该量。[48] 用 Bott 指标在实空间定义了四极算符的 Z 不变量（可处理非可分模型），但实空间四极算符破坏周期边界条件，无法在 Bloch Hamiltonian 的动量空间 formulation。
  - 手征 Floquet 系统中已有周期化 Wilson line 不变量 [21,49]；本文将其适配到"动量依赖手征算符"的情形。

  **核心方法卡：Wilson line/loop 与 Wannier Hamiltonian**（原理：沿 BZ 内路径的子空间投影算符的路径有序乘积，其本征值谱 = Wannier 带，谱隙 ϱ₀、ϱ_π 对应胞内 Wannier 中心 ε/2π）：

  - Wilson line 算符 W^S_ℓ(k₀,k₁) = ∏ P^S(q) = Pexp[i∫_ℓ A(q)·dq]，A 为非阿贝尔 Berry 联络，[A]_{mn}=−i⟨u_m|∂_q u_n⟩（Eq. 10）；规范变换下算符不变、矩阵共轭变换（Eq. 11–12）。
  - Wannier Hamiltonian 在投影空间内定义：A^W_ℓ(k) = −iln W̃_ℓ(k)（Eq. 13）；关键点是投影算符非幺正，对数只能在投影空间定义。
  - 镜面对称约束下 MⱼWⱼ(k*_j)Mⱼ = [Wⱼ(k*_j)]†（Eq. 17，k*_j 为镜像不变动量）。

  **核心方法卡：mirror-filtered 不变量构造**（本文核心方法创新）：

  - **原理**：Wannier Hamiltonian 与投影镜像算符反对易，但该"手征对称"是动量依赖的投影对称；需构造规范无关的镜像滤波基再取反对角块的绕数。
  - **镜像滤波基**：用 Wilson line 平行输运 \|u^±_j(k)⟩ = e^{iζ±_j(k,k₀)}W̄_j(k,k₀)\|u^±_j(k₀)⟩，相位 ζ^±_j(k,k₀)=(1/2π)(k̄_j−k₀̄_j)λ^±_̄j 保证周期性；初态取镜像本征态投影 \|u^±_j(k₀)⟩ = P(k₀)\|m^±_j⟩/√⟨m^±_j\|P(k₀)\|m^±_j⟩，或取 Wilson loop 本征态；**数值取 k₀_j = −π**；基在镜像不变动量线上满足 M_j\|u^±⟩=±\|u^±⟩，光滑、规范无关、周期。
  - **不变量**：η_j = w_{ℓ̄_j}[A^W_j(k*_j), M^P_j(k*_j)]（Eq. 19），其中 M^P_j(k)=P(M_jk)M_jP(k)；在镜像滤波基中 M_j 对角、A^W_j 块反对角，η_j 即反对角块绕数。
  - **陷阱与判据**：简单延拓 W_j→W_j+1−P 不可行（未占据带 Wannier Hamiltonian 为零）；延拓 W_j+e^{iβ}CW_jC 要求 e^{iβ}=±1，但此时延拓 Wannier Hamiltonian 与 C 对易（至多差常数 β），由附录 Theorem 4 其绕数为零——占据/未占据 Wilson loop 的镜像绕数相消，**必须相减**（mirror 分级）才得非零值。
  - **Wannier 隙不变量**：将手征 Floquet 理论的周期化 Wilson line 适配到动量依赖手征算符情形，直接关联 ε=0 与 π 处 Wannier 隙；与 mirror-filtered 不变量通过与手征 Floquet 不变量相同的线性组合联系（Ref. [49] 的关系）。

  **适用边界**：所有 mirror-filtered 构造依赖镜像不变动量线 ℓ̄_j 与动量依赖手征算符的规范选择；η_j 刻画的是 Wilson loop 层面的体-边对应，不保证映射到角态计数（尤其对非可分模型）。手征绕数公式 w = (1/2π)(γ⁺−γ⁻) 要求手征本征态规范一致选取 \|a⁻⟩=H\|a⁺⟩（附录 Theorem 3），动量依赖手征算符情形有反例（附录警示）。

  **代表作**：Aich & Seradjeh 本工作（arXiv:2511.23471）；前作 [53]（C₄ 模型中 ν vs ν′ 对应的判定）。

  ## 主要发现与核心结论

  1. **谱隙对应关系**：在所有研究的情形中，沿 k̄_j 的边缘谱隙闭合总是伴随 Wannier 隙 ϱ^j_π 闭合；但体能隙闭合不伴随 Wannier 隙闭合，而是对应 Wannier 谱的扭结（kink）。Wannier 隙还可能出现异常小（Fig. 3、4 阴影区，"vanishingly small"）或与谱隙无关的扭结甚至闭合（Fig. 4(d) 虚线）。
  2. **可分模型**：ν=ν₁ν₂ 正确给出 4|ν| 个零能角态（每角 |ν| 个），只要手征对称保持且边缘能隙不闭合。
  3. **C₄ 对称模型的对应判定**（引自作者 [53]）：正确的体-边对应由 ν 而非 ν′ 提供；|ν|=|ν′|²；|ν| 个角态中只有 |ν′| 个具有相同对角镜像本征值，其余 ½|ν′|(|ν′|−1) 对具有相反本征值；所有 |ν| 个束缚态手征本征值相同。
  4. **Mirror-filtered 不变量**：给出了规范无关的 Wannier Hamiltonian 拓扑刻画（η_j），通过镜像滤波基 + 平行输运构造，绕数计算数值上在 k₀_j=−π 启动。
  5. **延拓方案失败与绕数相消**：完整 Hilbert 空间延拓 W_j+e^{iβ}CW_jC（e^{iβ}=±1）使延拓 Wannier Hamiltonian 与 C 对易（差常数 β），由附录 Theorem 4 绕数恒为零；手征算符把占据带中某镜像本征值子空间映射到未占据带相反本征值子空间，强制两绕数之和为零——故须"相减"（mirror 分级）定义非零 mirror-filtered 绕数。
  6. **Wilson loop 层面体-边对应成立，高阶对应选择性成立**：这套规范无关不变量给出 Wilson loop 的体-边对应，在若干情形也刻画高阶对应，但**未找到到高阶体-边对应的普适简单映射**——尤其一般非可分模型仍是开放问题。

  ## 潜在研究方向

  - **非可分模型的动量空间不变量**：核心开放问题——为含对角跳跃的一般非可分模型构造直接计数角态的动量空间不变量（实空间 Bott 指标 [48] 无法用 Bloch Hamiltonian 复现，因实空间四极算符破坏周期边界）。
  - **Wannier 隙的异常行为**：Wannier 隙可变得任意小或出现与体/边谱隙无关的扭结/闭合，其物理含义与可观测后果未澄清——提示用 Wilson 隙做拓扑诊断时存在"假阴/假阳性"风险。
  - **动量依赖手征算符的一般理论**：规范选择的系统性判据仅在镜像不变线上解决；一般动量依赖手征算符的绕数定义仍需小心（附录给出警示反例）。
  - **Floquet 方向**：非可分模型可由周期驱动体系的 Floquet Hamiltonian 产生 [50,51]；本文的周期化 Wilson line 适配已搭好桥，Floquet 高阶拓扑的动量空间诊断与手征 Floquet 不变量的关系值得深入。
  - **三维推广与实验可观测量**：本文限于二维；角态的可观测指纹（如局域光谱、非线性响应）未涉及。

  ## 与林赛研究的关联

  - **Floquet 高阶拓扑（直接接口）**：论文明确说非可分模型"可以作为周期驱动体系的 Floquet Hamiltonian 自然出现"（引 [50,51]）。这正是我们强场驱动/交变磁方向的核心场景——驱动把可分模型变成非可分模型，ν₁ν₂ 失效，而这篇论文诊断的正是这个失效区间里的拓扑。我们的"交变磁""强场驱动诱导瞬态量子相"课题可直接把 η_j 与 Wannier 隙不变量作为相变的算符级判据，替代目前仅靠实空间对角化数角态的做法。
  - **HHG/阿秒探测的几何相位接口**：HHG 光谱对 Berry 联络与量子几何敏感，而本文整套构造（非阿贝尔 Berry 联络、Wilson line 平行输运、Wannier 带谱隙 ϱ₀/ϱ_π）正是动量空间几何量的计算方案。Wannier 隙闭合（ϱ^j_π → 0）对应边缘拓扑转变——这类转变是否在我们的强场驱动莫尔/高阶拓扑体系的 HHG 偏振或强度谱中留下可识别印记，是一个可以立项的具体实验-理论接口。
  - **莫尔体系接口**：莫尔超晶格中的层间跳跃天然是"非可分、各向异性跳跃"的二维模型族，与本文 Eq. (8)(9) 的参数化形式同构；mirror-filtered 不变量可作为莫尔高阶拓扑候选体系的筛选工具。
  - **方法学资产**：镜像滤波基 + Wilson line 平行输运 + 分级绕数的构造流程（含 k₀=−π 的数值约定、占据/未占据绕数相消的判据）可直接写进我们课题的"拓扑诊断方法卡"，供方法页 methods_settle 融合。
