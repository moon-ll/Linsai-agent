• # 交变磁畴壁上自旋激发的传播与局域化：自旋劈裂元激发动力学理论

  ## 林赛的理解

  这项工作把交变磁（altermagnet，AℓM）的对称性诱导自旋劈裂引入到畴壁波导物理中，系统地预言了畴壁取向如何调控 bound states 的数目、色散、波前倾斜和局域长度。对我组而言，它提供了一个清晰的理论框架：AℓM 畴壁不仅是自旋波导，而且其 bound-state 色散具有强非线性、偏振不对称性和可电场/磁场调控的局域长度。这些特征正好可以与强场超快光学手段对接——THz 泵浦可以激发并探测这些 bound states 的非线性色散，而阿秒时间分辨可能捕捉 Neel 矢量进动的手性依赖动力学。特别是文中所预言的 "focusing" 效应（局域长度随频率趋于零）和磁场诱导的左右不对称局域，是可被 HHG 或超快磁光克尔信号读取的非平衡态拓扑缺陷特征。

  ## 研究问题

  论文要回答的核心问题是：在具有 d-wave 交变磁对称性的易轴 AℓM 中，180° 畴壁上传播的自旋本征激发（bound spin eigen-excitations）如何受畴壁相对晶格取向、交变磁参数强度以及沿易轴外磁场的调控？具体包括： bound states 是否存在额外的能隙局域模？其色散关系是否线性？不同手性（RH/LH）进动是否简并？局域化区域如何随本征频率变化？外磁场如何改变局域化区域并限制传播波矢？

  ## 研究背景

  畴壁（DW）作为一维拓扑孤子，是连接简并基态的边界，在铁磁和反铁磁体系中已有丰富研究，并被广泛视为自旋波导以实现自旋电子学器件。传统反铁磁畴壁只有一个无隙的平移 Goldstone 模，沿畴壁线性色散，群速度可达 ~10⁴ m/s，且无杂散场、动态在 THz 范围，具有能效优势。交变磁作为补偿磁体，兼具反铁磁的技术优点，但由于连接两个相反自旋子晶格的对称性更复杂，展现出更强的物理丰富性：静态 AℓM 畴壁会获得依赖取向的磁化，破坏 Néel 矢量拉格朗日的洛伦兹不变性，导致运动畴壁出现 Walker 极限式临界速度，并可激活反常霍尔效应。鉴于 AℓM 对畴壁静态和动态性质的强烈影响，作者预期其局域本征态物理也会被显著丰富，但此前缺乏系统理论分析。

  ## 研究方法

  研究基于 d-wave 交变磁的非线性 σ 模型拉格朗日量，采用连续介质近似，在交换近似下用单位 Néel 矢量场 **n**(T,**R**) = (**M**₁ − **M**₂)/(2M_s) 描述磁子系统。针对易轴 d-wave AℓM，使用如下拉格朗日量（含约束 |**n**| = 1）：

  L = (M_s / γ²B_ex) [ṅ + **n** × γ**B**]² − A_afm ∂_α**n**·∂^α**n** − K[**n** × **e**₃]² + (A_alt / γB_ex) [(ṅ + **n** × γ**B**) × **n**] · D̂_{X,Y}**n**

  其中 γ > 0 为电子旋磁比，A_afm 为反铁磁刚度，K > 0 为易轴各向异性系数，A_alt 控制 AℓM 效应强度，微分算符 D̂_{X,Y} = 2 cos 2φ₀ ∂²_XY − sin 2φ₀ (∂²_XX − ∂²_YY) 依赖于参考系相对晶格方向的转角 φ₀。

  方法要点包括：
  - 引入无量纲时空坐标 t = Ω_afm T，**r** = **R**/ℓ，其中 ℓ = √(A_afm/K) 为畴壁宽度，Ω_afm = γB_sf 为反铁磁共振频率，B_sf = √(B_ex K/M_s) 为自旋翻转场。
  - 采用经典 Holstein-Primakoff 表示将 Néel 矢量偏离编码为复函数 ψ。
  - 对静态畴壁背景 n_dw：θ_dw = 2 arctan e^{pX/ℓ}，ϕ_dw = const（p = ±1 为拓扑荷）做线性展开，得到关于 ψ 的二次拉格朗日量。
  - 对沿畴壁传播的波 ψ = Φ(x)e^{i(k_y y − ωt)}，将 Φ(x) = Ψ(x)e^{iqx} 分解，把振幅方程化为 Pöschl-Teller/Rosen-Morse 型 Schrödinger 方程，再用超几何函数 ₂F₁ 求解 bound states，并通过 κ+1/2 − √(u+1/4) = −n（n = 0,1,2,...）的量子化条件确定色散关系 ω(k_y)。
  - 对散射态，利用超几何解导出反射系数 R 和透射系数 T 的解析表达式。
  - 针对 B = 0 和沿易轴磁场 B = B**e**_z 两种情形，分别讨论 nodal 方向（φ₀ = 0, ±π/2, π）和最大 AℓM 劈裂方向（φ₀ = −π/4, 对应 [1̄10]；或 φ₀ = π/4, 对应 [110]）下的 bound states 与散射态。

  ## 主要发现与核心结论

  1. **Nodal 方向畴壁（φ₀ = 0 或 π/2，即 [100]/[010]）**：
     - AℓM 不改变 bound states 数目：仍存在 n = 0 的 bound state 和 n = 1 的 half-bound state。
     - n = 0 模的波函数为 Ψ₀(x) = C sech x，κ = 1；n = 1 为 Ψ₁(x) = C tanh x，κ = 0（half-bound）。
     - 但 AℓM 引入波前倾斜：q = −εωk_y，倾斜角 α_sl = arctan(q/k_y) = −arctan(εω)。
     - 色散被修正为非线性：bound state ω = ±|k_y|(1 + ε²k_y²)^{−1/2}；half-bound state ω = ±[(1 + k_y²)/(1 + ε²k_y²)]^{1/2}。
     - RH 与 LH 偏振保持简并。

  2. **最大 AℓM 劈裂方向畴壁（φ₀ = −π/4，即 [1̄10]）**：
     - 无波前倾斜（q = 0），但 AℓM 效应最强。
     - 对 k_y = 0 的均匀 bound states，n = 0 仍为 Goldstone 零模 ω ≡ 0，波函数 Ψ₀ = C sech x。
     - n = 1 的态在 ε ≠ 0 时从散射连续谱边缘分裂出来，形成局域态 Ψ₁ = C tanh x sech^κ x，在 x = 0 处有一个节点。
     - 对 n ≥ 1，仅当 |ε| ≥ ε_cr_n = (n² + n − 2)/(n² + n − 1/2) 时才出现局域解。具体阈值：ε_cr_1 = 0，ε_cr_2 = 8/11，ε_cr_3 = 20/23，…。
     - 当 ε = ±ε_cr_n 时，新的 half-bound state 在 ω = ∓1、κ = 0 处出现；当 |ε| > ε_cr_n 时，该态进入能隙 |ω| < 1 并局域化，波函数含 n 个节点。例如 Ψ₂ = [(3/2 + κ)/(1 + κ) tanh² x − 1] sech^κ x。
     - 在临界值附近 ε = ±(ε_cr_n + δε)（0 < δε ≪ 1），本征频率近似为 ω_n ≈ ±(1 − a_n δε²)，其中 a_n = 3/[8(1 − ε_cr_n)²(3 − ε_cr_n)]；局域尺寸 1/κ_n ≈ [(1 − ε_cr_n)/(2a_n)]^{1/2}/δε 发散。
     - 由于实际材料中 ε ≪ 1，n = 1 的 AℓM 诱导 bound state 最可能具有实际意义。

  3. **k_y ≠ 0 时最大劈裂方向的传播模**：
     - n = 0 平移模在长波极限 k_y ≪ ε^{−1} 下具有线性色散 ω ≈ ±|k_y|(1 + ε²/12)^{−1/2}。
     - 散射连续谱显著不对称：边界为 ω^±_bnd = ±[1 + k_y² + (1/4)ε²k_y⁴]^{1/2} − (ε/2)k_y²（对应 k_x = 0），以及 ω'_bnd = −1/ε（对应 k_x → ±∞）。
     - RH 模可存在于任意大 k_y，渐近趋近 ω^+_bnd；LH 模仅存在于 |k_y| < k_0 = (2 + ε²)/(4ε²)，在 |k_y| = k_0 处触及 ω'_bnd。
     - 当 n = 0 模接近 ω'_bnd 时，出现聚焦效应：局域尺寸 1/κ 收缩至零。n ≥ 1 模同样存在该聚焦效应。
     - LH 平移模还可在高能量区 ω < −4/ε、|k_y| > k'_0 = [(16 − ε²)/(5ε²)]^{1/2} 存在，具有较大局域面积且靠近 ω^−_bnd，可能因高群速度 v_g = ∂_{k_y}ω 而具应用价值。其余模在边缘频率 ω = −1/ε 附近达到最大群速度。

  4. **沿易轴磁场的影响（仅 nodal 取向）**：
     - 磁场下标准畴壁解 θ_dw = 2 arctan e^{pκx}，κ = √(1 − b²)，b = B/B_sf，仅对 φ₀ = 0, ±π/2, π 成立；一般取向会破坏该解。
     - 线性化后得到 Rosen-Morse 势的 Schrödinger 方程，参数为 α = 1 − [ω² − k_y²(1 − ε²(b² + ω²))]κ^{−2}，β = 2 − ε²b²k_y²κ^{−2}，γ = 2pbω(1 + ε²k_y²)κ^{−2}。
     - 束缚条件给出 κ_± = √(α ± γ)，n = 0 的解为 Ψ = C e^{−(1/2)(κ_+−κ_−)κx} / cosh^{(1/2)(κ_++κ_−)}(κx) · e^{iF(x)}，其中 F = qx − pbεk_yκ^{−1} ln cosh κx。
     - 磁场导致畴壁两侧局域区域不对称：对 RH 模，磁场与 Néel 矢量平行域的局域更大，反平行域更小；LH 模相反。
     - 磁场限制了传播波矢上限：AFM 极限下存在临界波矢 |k_y| < k_y^(cr) = κ/|b|。AℓM 使 k_y^(cr) 对磁场的依赖更陡峭，近似为 k_y^(cr) ≈ κ(1 − ε²/b²)^{1/2}/|b|（|ε| ≪ |b| ≪ 1）。
     - 当一侧发生退局域（1/κ_± → ∞）时，另一侧局域长度仍满足 1/κ_∓ ≳ 1/2，且 ε = 0 时等于 1/2。

  5. **散射态**：
     - 对 AℓM DW，一般 R ≠ 0，且 R 在 ε = 0 处不是解析函数。
     - Nodal 方向仍保持反射less：R = 0。
     - 最大劈裂方向（φ₀ = −π/4），k_y = 0 正入射时：
       - 小 k_x 极限（|k_x| ≪ |ε| ≪ 1）：R ≈ −(1 ± 2ik_xε^{−1})，T ≈ ±2ik_xε^{−1}（+ 对应 RH，− 对应 LH）。
       - 大 k_x 极限：R ≈ ±iε sin 2φ₀ / sinh(πk_x) · (π²/2)(1 − ik_x)/(1 + ik_x)√(1 + k_x² + k_y²)。
     - 出现 Levinson 定理的明显违反：RH 模相位移动满足 [δ(0) − δ(∞)]/π = 1/2 而非整数；LH 模 δ(∞) → ∞。这源于透射系数 T 在复半平面 Im(k_x) ≥ 0 上的非亚纯性，而根本原因是散射势振幅 u 依赖于能量（频率）。

  ## 潜在研究方向

  - **非 nodal 取向下磁场中的畴壁 profile**：文中仅处理了磁场下 nodal 取向的严格解；一般 φ₀ 下，θ_dw 和 ϕ_dw 均依赖坐标，AℓM 诱导的畴壁形变及其对 bound states 的影响尚待研究。
  - **实际材料的 ε 定量估计与实验验证**：现有 AℓM 中 ε ≪ 1，n = 1 态虽存在但能量接近连续谱边缘，如何通过非弹性中子散射、布里渊光散射或超快 THz 泵浦-探测分辨该 bound state 是开放问题。
  - **动态/非线性畴壁运动与自旋波的反作用**：文中仅考虑静态畴壁背景上的线性激发；当自旋波强度足够大时，其对畴壁的推进效应（propulsion）在 AℓM 中会比 AFM 更强，但非线性动力学和 Walker 极限的交叉尚需理论。
  - **Levinson 定理的推广**：AℓM 畴壁散射中透射系数的非亚纯性要求发展适用于能量依赖势的 Levinson 定理修正形式。
  - **多维/有限温效应**：连续介质模型在长波近似下成立，大 k 行为主要为数学自洽；有限尺寸、缺陷、温度导致的阻尼和线宽如何影响 bound states 的聚焦效应尚未讨论。
  - **偏振依赖的超快光学读取**：RH/LH 进动的不对称色散和局域长度提供手性选择通道，但如何通过 HHG 或磁光克尔实现高时间分辨、高空间分辨的实验读取仍需具体方案。

  ## 与林赛研究的关联

  - **强场驱动与 HHG**：AℓM 中 THz 频段自旋波与强场超快激光耦合，可驱动 Néel 矢量非平衡进动；畴壁 bound states 的非线性色散和聚焦效应会在 HHG 光谱中留下特征，例如手性依赖的谐波产额或偏振旋转。
  - **阿秒动力学**：RH/LH 进动模在最大劈裂方向失去简并，意味着超快退磁或光致自旋翻转过程可能存在可区分的阿秒时间尺度，可用阿秒磁光谱学追踪。
  - **交变磁与量子几何**：AℓM 的 d-wave 自旋劈裂根植于布洛赫态的量子几何和能带对称性；将本文的连续模型与第一性原理计算的贝里曲率、轨道磁化联系起来，可预测具体材料（如 RuO₂、MnTe 等）中畴壁 bound states 的能量位置。
  - **莫尔体系接口**：莫尔超晶格可人工构造低对称性的反铁磁/交变磁序并调控畴壁取向；本文预言的取向依赖 bound-state 色散可在扭转磁性双层或莫尔磁近晶格中通过栅压和扭转角加以工程化。
  - **量子几何与超快调控**：AℓM 中自旋波的非平庸散射（Levinson 违反、偏振依赖反射）提示存在与量子几何相关的非常规自旋-轨道耦合效应，可借助强场光场调控 AℓM 参数 ε 有效值，进而开关 bound states。
