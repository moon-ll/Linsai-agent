• # Electric and spin current vortices in altermagnets

  ## 林赛的理解
  这篇工作提出了一套在**有限几何、欧姆输运区**里用非均匀电场和自旋密度梯度“读取”交变磁体费米面自旋劈裂特征的新方案。对我们组而言，这意味着交变磁性不再只是 ARPES 或反常霍尔里的一个间接信号，而是可以通过**电流涡旋的空间纹理**被“成像”。我们的 HHG / 阿秒读出方向一直在寻找能把晶体序参量映射到可测量瞬态响应的接口：这里的电荷/自旋电流涡旋提供了一个清晰的 DC 输运基准。更进一步，如果用强场超快脉冲在非均匀场极限下驱动样品，涡旋图案可能转化为瞬态电流或退磁动力学，成为我们“强场驱动序参量读出”框架里的一个可嫁接模块。与莫尔、量子几何的接口在于：涡旋形态直接由动量依赖的自旋劈裂决定，而这种劈裂本质上是能带的量子几何量在自旋空间的投影。

  ## 研究问题
  论文的核心问题是：**如何在实验上明确探测交变磁体中动量依赖的自旋劈裂，并把它与界面、畴壁、自旋倾斜等非本征反常霍尔来源区分开？** 具体地，作者问：在有限尺寸样品中，利用点接触施加非均匀电势或自旋不平衡，能否诱导出依赖于交变磁体节面取向与样品边界相对几何的**电荷/自旋电流涡旋**？这些涡旋是否能作为一种新的、可由常规磁测量技术捕捉的交变磁签名？

  ## 研究背景
  交变磁体是一类具有**共线磁序、动量依赖自旋劈裂、净磁化消失**的磁性材料，同时保持空间反演对称性但破坏时间反演对称性。理论上已在 MnTe、RuO₂、Mn₅Si₃、MnF₂、V₂Se₂O、V₂Te₂O、CrO、CrSb、CoNb₄Se₈ 及 κ-型有机反铁磁体等材料中预言。实验上，角分辨光电子能谱（ARPES）和圆二色性已观测到自旋劈裂能带，但 ARPES 分辨率受限且高度依赖第一性原理计算对比。输运实验多聚焦于反常霍尔效应（AHE），但 AHE 可能源于界面低对称性、畴壁或自旋倾斜，因此不能单独作为交变磁性的确凿证据。自旋分离器效应（spin-splitter effect）提供了另一种替代方案，但迄今仅在 RuO₂ 中观测到自旋分离力矩，且其磁态仍有争议。此前电流涡旋的研究多集中在电子流体动力学区，需要强电子-电子相互作用或极纯样品。本文则提出：在更常见的**欧姆输运区、无序体系**中，交变磁体自身即可产生电流涡旋。

  ## 研究方法
  作者采用**连续介质模型 + 晶格非平衡格林函数**两条互补路径。

  1. **半经典玻尔兹曼方法**：低能有效哈密顿量为  
     H = t₀ k² + σ_z J(k) − μ̂，  
     其中 t₀ 为准粒子有效质量倒数，J(k) 为有效交换场，μ̂ = diag(μ₊, μ₋) 为自旋分辨化学势。假设非磁性弹性杂质散射，弛豫时间近似 I_col{f_λ} = −(f_λ − ⟨f_λ⟩)/τ，得到稳态方程  
     ∇_j(σ_ij ∇_i φ̄_λ) = 0，  
     电导率张量 σ_ij = 2eτ ρ_λ^(0)(t₀ δ_ij + λ T_λ,ij)。对 d-波交变磁体取  
     J(k) = t₁(k_x² − k_y²) + 2t₂ k_x k_y，  
     在矩形样品 L_x = L_y = L 上，边界条件为在 x = 0 和 x = L_x 的宽度 w 接触处固定电势或自旋化学势。数值求解使用 Wolfram Mathematica 的有限元法。

  2. **Keldysh 晶格方法**：d_xy 交变磁体的紧束缚哈密顿量为  
     H_S = Σ_{iσ} ε_i c†_{iσ} c_{iσ} + Σ_{ijσσ′} c†_{iσ} t_{σσ′}^{ij} c_{jσ′}，  
     最近邻跃迁 −t_I，自旋依赖对角跃迁 ±t_m σ_z。样品与金属引线连接，样品边缘除 10 个格点外设置 ε_edge = 10⁵ t 的高势垒以模拟收缩。无序通过 n_I = 0.2 的格点具有 ε_imp = 10 t_m 的点杂质实现，并对 100 种杂质构型取平均。晶格尺寸为 60 × 60，接触宽度 w = 10 a，参数取 t_m = 0.3 t，μ = −2.0 t，电压偏置 eV = 0.2 t。

  ## 主要发现与核心结论
  - **涡旋来源**：自旋分辨涡度方程  
    ∂_t ω_el,j + ω_el,j/τ = −2eρ^(0) ε_{jlm} T_{im} ∇_l∇_i φ̄_sp，  
    ∂_t ω_sp,j + ω_sp,j/τ = −2eρ^(0) ε_{jlm} T_{im} ∇_l∇_i φ̄_el。  
    涡旋来源于交变磁电导率张量中 (i) 非对角元 T_{λ,i≠m} 和 (ii) 对角各向异性 T_{λ,ii} ≠ T_{λ,mm}。前者在单方向电势变化下即可产生涡旋；后者需要非均匀电势，例如点接触边缘。

  - **电流分布（图 2）**：在施加电势偏置 eφ̄_{1,λ}/t₀ = −1、eφ̄_{2,λ}/t₀ = 1，且 ρ↑^(0) = ρ↓^(0) = ρ^(0)/2 时：  
    - 电荷电流 j_el = j↑ + j↓ 的流线几乎不受 t₁、t₂ 影响，呈典型欧姆输运分布。  
    - 自旋电流 j_sp = j↑ − j↓ 强烈依赖于交变磁参数：  
      * t₁ = t₀/2、t₂ = 0 时（图 2b），出现侧向涡旋；  
      * t₁ = 0、t₂ = t₀/2 时（图 2c），自旋电流形成从同一接触出发并回到该接触的环流；  
      * t₁ = t₂ = t₀/(2√2) 时（图 2d），呈现中心涡旋。  
    归一化电流 j₀ = 2eτ t₀ max{|ρ_λ^(0)(φ̄_{2,λ} − φ̄_{1,λ})|}/L。

  - **对偶性**：由于方程在自旋种类互换下对称，若在接触处施加自旋不平衡（例如通过自旋霍尔效应或自旋泵浦），则会得到形状与幅度均与上述自旋涡旋相同的**电荷电流涡旋**。

  - **量子方法验证**：Keldysh 晶格计算在无序区与半经典结果定性一致（对比图 2c 与图 4），中央涡旋形态相近；侧边涡旋因幅度较小而不易分辨。

  - **诱导磁场与材料估计**：对于施加自旋不平衡的情形，图 3 给出了 z = 0.1 L 处的感应磁场 B_z(r, z) 空间分布。作者给出标度律：  
    B₀[nT] = 73.9 √[1 − (t₁² + t₂²)/t₀²] μ[meV] τ[ps] δφ[mV] / L[μm]，  
    j₀[A/m] = 0.06 √[1 − (t₁² + t₂²)/t₀²] μ[meV] τ[ps] δφ[mV] / L[μm]。  
    取 L = 5 μm、τ = 1 ps、δφ = 1 mV：  
    - RuO₂：t₀ a⁻² = 2.5 eV，t₁/t₀ = t₂/t₀ = 0.2，μ = 0.4 eV → B₀ ≈ 6 μT，j₀ ≈ 24 μA/m；  
    - KRu₄O₈：t₁/t₀ = t₂/t₀ = 0.36，μ = 0.05 eV → B₀ ≈ 1 μT，j₀ = 3 μA/m。  
    这些值虽小，但已处于纳米线磁力显微、扫描 SQUID 磁强计及量子自旋磁强计可及范围。

  - **关键结论**：该涡旋效应**仅在交变磁体中出现，铁磁体中无涡旋**；它不需要流体动力学区或弹道区，完全在**欧姆输运区、局域响应**下发生，从而显著拓宽了可探测的材料平台。

  ## 潜在研究方向
  - 文中假设弱自旋翻转散射；虽然补充材料指出其只降低幅度而不改变电流分布的定性特征，但**强自旋-轨道耦合或磁性杂质**下的定量修正仍需系统研究。
  - RuO₂ 的体相磁性状态本身存在争议（近来有研究认为其非磁性），薄膜应变可能诱导交变磁性，因此实验材料选择需格外谨慎。
  - 所有估计基于 2D 模型，**三维几何与真实器件边界条件**（包括上下表面、厚度、电极形状）将改变涡旋形态。
  - 标度律显示信号随 L 增大而衰减；在 L = 5 μm 时仅为 μT 量级，**更高灵敏度磁传感器**或更小尺度器件将是实验实现的关键。
  - 文中仅考虑稳态线性响应；**交流/瞬态驱动、非线性输运、有限温度效应**以及更强无序下的行为尚未探索。
  - 补充材料提到 g-波、i-波交变磁体及弹道区涡旋，但弹道涡旋并非交变磁独有；如何提取**纯交变磁几何指纹**并与其他非均匀输运效应区分仍是开放问题。
  - 电流涡旋与**自旋-电荷转换效率、量子几何张量**之间的严格对应关系可进一步形式化，以便用于 HHG 等光学读出的反向设计。

  ## 与林赛研究的关联
  本工作与我们的 **NSFC-强场超快** 项目及 **general-order-parameter-ultrafast-readout** 课题直接相关：

  - **HHG 与交变磁序参量读出**：交变磁体中动量依赖的自旋劈裂是晶体序参量在动量空间的直接表现。我们正在探索的 HHG 高次谐波谱对能带 Berry 曲率、量子度规等量子几何量高度敏感；本文给出了同一序参量在 DC 输运中的几何指纹，可作为光学读出的交叉验证基准。
  - **强场驱动的非均匀场**：点接触产生的非均匀电势与聚焦飞秒激光在样品内产生的强非均匀电场在概念上相通。我们可借鉴本文的涡旋图像，研究 **强场激光泵浦下交变磁体中的超快自旋/电荷涡旋动力学**，并比较瞬态电流与谐波产额之间的关联。
  - **阿秒磁学接口**：文中估计的 μT 级感应磁场处于量子自旋磁强计可及范围；类似地，我们可用 **阿秒时间分辨的磁光或磁化动力学** 来探测泵浦诱导的涡旋出现与衰减时间，从而把空间纹理读出推广到时间域。
  - **莫尔与量子几何**：莫尔超晶格能工程化地产生可调的共线磁序与动量依赖自旋劈裂。把本文的连续模型中的有效交换场 J(k) 替换为莫尔微带的量子几何量，可研究莫尔交变磁体中的涡旋输运，并连接到我们关注的 **莫尔-强场-量子几何** 交叉方向。
