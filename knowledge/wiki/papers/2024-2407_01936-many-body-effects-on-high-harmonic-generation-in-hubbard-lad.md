• # Many-body effects on high-harmonic generation in Hubbard ladders

  ## 林赛的理解

  这篇工作是 Murakami 组对 Mott 绝缘体 HHG 理论的系统性推进，核心信息是：**HHG 不只是电荷动力学的探针，在强关联体系中它直接"看见"自旋背景的动力学**。两腿梯子模型给出的物理图景分三段：ty=0 时 doublon-holon 对因自旋-电荷分离而长相干；中等 ty 下链间跳跃诱发 spin-string 使 DH 对退相干，谱中出现清晰奇次谐波；大 ty 下出现 spin-polaron 主导的新平台甚至"双极化子+磁振子"三体 HHG 过程。对我们而言最有价值的两点：其一，HHG 谱中"额外的平台/鼓包"在关联体系里可以被赋予明确的元激发指认（polaron、spin-bag、三体通道），这为"用 HHG 反演多体激发谱"提供了理论先例；其二，subcycle 分辨 + 三步模型拟合的方法论可以直接移植到我们强场驱动关联体系的课题中。实验上 SrCu2O3 可用化学/物理压力调 ty/tx，非线性声子学可做更大调制——这给出了可检验的实验路线。

  ## 研究问题

  背景自旋动力学所伴随的多体效应如何控制 Mott 绝缘体中的高次谐波产生（HHG）？具体而言：

  - 链间跳跃 ty 如何改变 doublon-holon（DH）对的相干性，进而改变 HHG 谱特征？
  - 自旋-电荷耦合除了已知的能量耦合通道（Ref. 46）之外，是否存在其他控制相干时间的机制？
  - 自旋极化子（spin-polaron）、spin-string、磁振子（magnon）等新元激发是否会在 HHG 谱中留下可辨识的指纹（如额外平台）？
  - 大 ty 极限下是否会出现涉及两个以上元激发的非传统 HHG 过程？

  ## 研究背景

  - HHG 研究已从气体扩展到固体，此前固体 HHG 多聚焦半导体/半金属，可用独立电子运动学描述；近年扩展到关联材料，独立电子图像失效。
  - 已有工作揭示：Mott 绝缘体中的 HHG 可关联到 doublon（双占据位）与 holon（空位）多体元激发的相干动力学（Ref. 35, 39）；强自旋-电荷耦合可致 HHG 有趣的温度依赖（Ref. 45, 46）。
  - 但 spin-string 的形成、新元激发的涌现、与磁振子的散射等效应尚未被讨论，自旋-电荷耦合对 HHG 作用的根本理解仍然缺失。
  - 已有研究局限于 1D 链（Ref. 34, 39, 44）与无穷维极限（Ref. 35, 46），两腿梯子介于其间，其几何结构允许讨论超出这两极限的物理，且结论应可推广至一般 2D/3D 体系。
  - 实验动机来自两腿铜氧化物 SrCu2O3 被中红外激光激发的场景。

  ## 研究方法

  - **模型**：半填充两腿梯子 Hubbard 模型，哈密顿量含链内跳跃 tx（电场沿 x，经 Peierls 相位 Ax(t) 耦合）、链间跳跃 ty、在位库仑作用 U。取 tx 为能量单位，U = 8（Mott 绝缘相），Ω = 0.5、t0 = 60、σ0 = 15 的高斯脉冲；能量单位约对应 0.5 eV。电场沿 x 方向。
  - **动力学模拟**：infinite time-evolving block decimation（iTEBD），基于 MPS 表示直接处理热力学极限；四阶 Trotter-Suzuki 分解 + swap 算符处理次近邻项；实时间演化另用四阶 commutator-free matrix exponentials。代码基于 ITensor 开源库。单链（ty=0）基态虚时演化截断维数 D = 1000，实时演化 D = 3000、时间步长 dt = 0.04（并加微小交错磁场 hz = 0.001 降截断）。
  - **HHG 谱**：I_HHG(ω) = |ωJx(ω)|²，Jx(ω) 为 x 方向电流的傅里叶分量；谱计算用高斯窗 FG（σ = 20）。
  - **Subcycle 分析**：加窗傅里叶变换 Jx(ω, tp)，提取 tp 附近的瞬时辐射谱 I(ω, tp)，时间分辨窗口 σp = 0.8；用半经典三步模型（DH 对色散 Eg(kx) = U − 4tx cos(kx)）做对照拟合。
  - **有效模型**：Schrieffer-Wolff 变换（tx,y/U 展开）得到有效哈密顿量（DH 跳跃项 + 自旋交换项 Jex,x = 4tx²/U、Jex,y = 4ty²/U + 光激发算符 Px），通过开关 ty、Jex,x、Jex,y 四组对比计算分离不同物理过程的贡献。
  - **单粒子谱**：含时 DMRG 计算动量分辨单粒子谱 A(kx, ky, ω)（x 方向 80 个格点），用于指认 ty = 1 与 ty = 2 下的元激发；大 ty 极限用强 rung 耦合微扰论对照。

  ## 主要发现与核心结论

  - **ty = 0（两链解耦）**：HHG 不出现清晰奇次谐波峰，出现非奇整数谐波信号——因 DH 对自旋-电荷分离导致长相干时间，体系在短脉冲下未达完全时间周期态，谱对载波-包络相位敏感（Ref. 32, 39）。
  - **中等 ty（0.5 → 1）**：奇次谐波峰逐渐清晰；ty = 1（对应铜氧化物）在 ω ≈ 6.5 出现新鼓包，形成两个类平台结构：4.5 ≲ ω ≲ 6.5 与 6.5 ≲ ω ≲ 10.5。鼓包位置随场强增大而移动（见 SM），说明它不源于特定激发模式。
  - **退相干机制（Case 2 对比 Case 1）**：DH 沿 y 跳跃本身（不经自旋交换能量 Jex,y = 0.125 的通道）即显著缩短 DH 对寿命，权重移向周期早期；根源是 spin-string——DH 对链间跳跃后在自旋背景留下扰动串，返回相邻位点时无法复合，不贡献 ⟨ΨGS|Ĵx|δΨex⟩。此过程在 Jex = 0 极限仍存在，半导体中不存在。退相干同时使体系快速进入时间周期态，解释奇次谐波峰的锐化。
  - **ty = 1 的极化子平台**：DMRG 单粒子谱显示低能色散带 2.5 ≲ |ω| ≲ 3.5，对应 spin-polaron（被自旋云修饰的电荷）。两个极化子复合发光范围 5 ≲ ω_emit ≲ 7，与第一个平台吻合——即 HHG 同时捕获 DH 动力学与极化子动力学两重通道。
  - **ty = 2（强 rung 极限）**：出现 ω < 0 的相干带（ky = 0 的空穴极化子 hPolaron）与 2.5 ≲ ω ≲ 7.5 的连续谱（ky = π 的电子极化子 ePolaron + ky = π 的磁振子）；连续谱底部有高强度的弱束缚复合体 spin-bag。Subcycle 谱对照支持**场景 1：三体过程——两个极化子加一个磁振子**（总动量守恒由无电荷的磁振子平衡，并提供其产生能的能量移动），优于场景 2（hPolaron + spin-bag 两体）。信号相干性的恢复源于强 rung 极限下相干极化子的涌现。
  - **HHG 与单粒子谱关系非平庸**：A(kx, ky, ω) 中 ω > 0 部分呈非相干，ePolaron 信息被隐藏，与半导体情形相反；HHG 直接探测的是带非零电荷的元激发的运动学。
  - 这些定性特征（随 ty 的剧烈变化）在常规半导体中不出现，根植于强关联性。

  ## 潜在研究方向

  - 模型为 1D 梯子极限，真实 2D/3D 体系中 spin-string 与 spin-polaron 对 HHG 的效应需验证（作者预期高度相关但未计算）。
  - 涉及多个元激发的 HHG 过程在关联体系中的普遍性有待系统研究。
  - 三体 HHG 场景的指认依赖强 rung 微扰论与 subcycle 拟合，更严格的定量验证（如直接计算三体关联）缺失。
  - 温度效应、无序、更真实的多轨道/长程相互作用未纳入。
  - HHG 与单粒子谱之间的非平庸关系意味着用 HHG 反演激发谱需要新的理论框架。
  - 实验验证路径已指出但未实施：SrCu2O3 中经化学/物理压力调 ty/tx，非线性声子学实现更大跳跃调制；subcycle 动力学需时域电场观测、阿秒瞬态吸收、多维光谱等超快手段提取。

  ## 与林赛研究的关联

  - **HHG 作为多体元激发探针**：本文示范了"HHG 额外平台/鼓包 → spin-polaron / spin-bag / 三体通道"的指认链条，直接支撑我们"用强场 HHG 反演关联体系激发谱"的理论路线；其"HHG 与单粒子谱关系非平庸"的警告对我们设计反演方案是必须面对的约束。
  - **强场驱动 + 交变磁**：三体过程（双极化子 + 磁振子）表明强场可以在关联绝缘体中相干激发磁振子并让其参与发光，这为"强场驱动诱导/调控交变磁性序"提供微观机制素材。
  - **方法论可移植**：subcycle 加窗傅里叶 + 半经典三步模型对照 + Schrieffer-Wolff 有效模型开关变量分离机制，这套组合拳可用于我们手头的强场驱动关联体系模拟。
  - **实验接口**：SrCu2O3 体系 + 中红外强场 + 压力/非线性声子学调控跳跃比，是一个低门槛的实验检验平台，与我们 HHG 实验方向（强场驱动、阿秒诊断）直接对接。
  - **莫尔/量子几何维度**：两腿梯子是研究低维关联与维度交叉的最小模型，其结论向 2D 的推广逻辑与莫尔体系中关联平带 + 可调 hopping 的设计思路同构，可作为莫尔强场探针课题（general-moire-strong-field-probe）的理论参照。

**方法**：半填充两腿梯子 Hubbard iTEBD（MPS 热力学极限）+ Schrieffer-Wolff 有效模型 + subcycle 加窗傅里叶 + 含时 DMRG 单粒子谱（多体效应对 HHG 的影响）

**原理**：三段物理图景：ty=0 两链解耦——DH 对自旋-电荷分离导致长相干时间、非奇整数谐波信号（载波-包络相位敏感）；中等 ty——链间跳跃诱发 spin-string（DH 对链间跳跃后在自旋背景留下扰动串、返回相邻位点无法复合），显著缩短 DH 对寿命、使体系快速进入时间周期态解释奇次谐波峰锐化（此过程在 Jex=0 极限仍存在、半导体中不存在）；ty=1 出现极化子平台——spin-polaron（被自旋云修饰的电荷）复合发光范围与第一个平台吻合（HHG 同时捕获 DH 动力学与极化子动力学两重通道）；ty=2 强 rung 极限出现三体过程——两个极化子加一个磁振子（总动量守恒由无电荷磁振子平衡并提供产生能的能量移动），优于 hPolaron+spin-bag 两体场景；HHG 直接探测带非零电荷的元激发运动学（单粒子谱 ω>0 部分非相干、ePolaron 信息被隐藏——与半导体情形相反）。
