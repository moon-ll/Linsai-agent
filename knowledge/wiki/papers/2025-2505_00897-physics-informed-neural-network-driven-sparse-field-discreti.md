• # PINN 驱动的稀疏场离散化近场声学全息方法（PINN-SFD）

  ## 林赛的理解
  （第一人称：这篇工作对我们的研究意味着什么、可以怎么用）

  这篇论文跟我们做的强场超快光学没有直接的物理重叠——它解决的是声学里的逆问题（从近场声压反演振源表面速度场）。但它的**方法论骨架对我们高度可迁移**：物理约束神经网络（PINN）+ 稀疏先验 + 中间虚拟平面的"场离散化"约束，本质上是**把一个病态、欠定的波动逆问题改造成"单次样本、无监督、对正则化参数不敏感"的自洽求解框架**。我们组关心的量子几何反演（从可测量反演交变磁、量子几何张量等隐藏自由度）面临完全同构的困境：测量点少于待反演自由度、逆问题病态、传统 Tikhonov/压缩感知对正则化参数极度敏感。PINN-SFD 给出的三条工程经验——①物理残差直接进 loss 而非数据驱动监督、②在测量面与源面之间加中间约束面增加传播路径约束、③ℓ1 稀疏罚只激活少数等效源——每一条都可以平移到我们的反演管线里。它已经被 `general-quantum-geometry-inversion-20260726` 课题引用，值得作为"逆问题求解器设计"的方法素材沉淀，而非声学知识条目。

  ## 研究问题

  论文要回答的核心问题是：**能否设计一个不需要大规模训练数据集、单次样本即可求解的近场声学全息（NAH）逆问题方法，使其在重建精度与对正则化参数的鲁棒性上同时超过传统的压缩等效源法（C-ESM）？**

  具体分解为三个子问题：
  - 现有深度学习方法（CV-KHCNN、3D-CNN 等 PGNN 路线）依赖监督训练，泛化性被训练数据分布锁死，且 NAH 领域缺乏覆盖各种声源的大型数据集——如何摆脱数据依赖？
  - 传统 C-ESM 求解欠定病态系统时严重依赖正则化参数的人工调优（通常需要相对噪声水平的先验知识），如何降低这种敏感性？
  - 能否通过在更靠近真实源面的位置施加额外物理约束（场离散化 + 虚拟平面），提升复杂振动模式的重建精度，尤其是高频细结构？

  ## 研究背景

  - NAH 是声源识别与可视化的标准技术：从近场全息面（hologram plane）麦克风阵列测得的声压，反演振源表面法向速度场，广泛应用于噪声控制与乐器（如小提琴面板）等精密/轻质对象的振动分析，避免了加速度计接触损伤与附加质量。
  - 逆问题的数学本质是反演 Kirchhoff-Helmholtz（KH）积分。由于近场包含倏逝波成分，自由场格林函数随距离衰减导致逆过程高度病态，且测量点数 M 通常小于源面网格点数 N2（欠定），解空间非唯一，必须正则化。
  - 方法谱系：Fourier NAH、平面/球面波展开（HELS、统计优化 NAH）、逆边界元、等效源法（ESM，基于 Huygens-Fresnel 原理，用源面内侧一层虚拟单极子等效辐射）。经典求解用 Tikhonov（ℓ2）正则化；压缩感知（CS）引入后用 ℓ1 范数促进稀疏解，形成 C-ESM，常用 CVX 内点法求解。
  - 深度学习路线分两类：PGNN（监督、数据驱动，构建全息声压→源速度场的代理映射，如复值 UNet 架构 CV-KHCNN、3D CNN）与 PINN（以控制方程残差为弱约束 loss、自监督）。已有的 KHCNN/CV-KHCNN 属于 PGNN 与 PINN 的混合体，仍需训练数据；纯 PINN 路线此前未在 NAH 上系统验证。
  - 研究动机：监督方法只对训练数据相似的声源有效，而跨领域大规模数据集不存在，因此需要"单样本、自监督、物理约束"的新范式。

  ## 研究方法

  方法密度高，按方法卡格式详述（数值均为原文原值）。

  **原理**：在 ESM 框架内，用复值 CNN 作为可微分求解器，把 KH 积分离散化算子嵌入网络前向传播，通过物理约束 loss 直接优化等效源速度场。关键创新是**场离散化（Field Discretization）**：在等效源面 E 与全息面 H 之间、靠近真实源面 S 的位置设置 Nv 个虚拟平面（VPs），等效源先传播到 VP 重建出中间速度/压力场，再作为次级源传播到 H，形成额外传播路径约束；同时对等效源速度施加 ℓ1 稀疏罚，使少数等效源激活。优化是"single-instant"（单样本、无训练集）+ 自监督（无 ground truth，仅物理正则驱动）。

  **装置/几何配置与测量序列（§IV-A1，原文数值）**：
  - 平面几何（z 轴坐标）：真实源面 S 在 zS = 0；全息面 H 在 zH = 3.12 cm；等效源面 E 在 zE = −5.0 cm（源面内侧）
  - 虚拟平面 3 个（Nv = 3）：zV1 = zS = 0，zV2 = −0.10 cm，zV3 = 0.10 cm；对照模型 Nv = 0
  - 网格点数：E、Vi、S 面相同，N1 = N2 = N3 = 16 × 64；全息面 M = 8 × 8（上采样重建，N2 > M）
  - 正则化参数：PINN-SFD 固定 λ = 1 × 10⁻⁶（Nv=0 与 Nv=3 均固定）；C-ESM 用 CVX 内点法，5 个正则化参数在区间内均匀取点——小提琴数据集 [0.001, 0.1]、矩形板数据集 [0.005, 0.1]，按全息声压重建 MAE 最小选最优
  - 空气密度 ρ ≈ 1.225 kg/m³（20 °C）

  **计算设置（网络与训练超参，§IV-A3，原文数值）**：
  - 网络：改造版复值 U-Net（encoder–bottleneck–decoder），复数卷积/转置卷积/最大池化/批归一化，复数激活函数 Cardioid；框架 PyTorch + complexPyTorch 库
  - Loss（式 18）：L = (1/M)(∥pH − p̂H^E∥1 + Σᵢ∥pH − p̂H^Vi∥1) + λ∥v̂E∥1——直接路径与 VP 附加路径用 MAE（ℓ1 偏好），稀疏罚 ℓ1
  - 归一化因子 α = 1%，β = α·max|pH|；输入归一化 pH/β，输出反归一化 β·v̂E
  - 优化器 Adam，初始学习率 0.01，200 个 epoch 无改进则 ×0.1，下限 0.001；早停：50 个 epoch loss 无改进即停；网络参数默认初始化
  - 数据增强：每样本加性噪声，SNR 从 [10, 60] dB 均匀分布采样

  **数据集（§IV-A2，原文数值）**：特征频率限于 [0, 2000] Hz。小提琴面板 10 块、覆盖 1–53 模式共 471 样本；矩形板按模式抽样（每模式 10 样本，高模式略少）——固支（clamped）模式 1–14 共 139 样本、自由（free）模式 1–30 共 299 样本、简支（simply supported）模式 1–20 共 183 样本。每个样本独立训练（single-instant）。

  **指标**：NMSE（dB，式 20）与 NCC（式 21），复数列向量计算；小提琴不规则表面用二值 mask 选取网格点。

  **适用边界**：VP 对高频复杂模式有效提升细结构，但低频模式使用 VP 可能出现源速度"回弹效应"（rebound effect）；对过简单模式（如 1 阶模式）PINN-SFD 反而不如 C-ESM（可能过拟合）；Nv=3 不总是优于 Nv=0——NMSE 改善但 NCC 可能下降。

  **代表作**：Luan, Pezzoli, Antonacci, Sarti (2025) arXiv:2505.00897（本方法）；对照基线 C-ESM 见 [9], [11] 及 CVX 工具链。

  ## 主要发现与核心结论

  1. **整体精度优于 C-ESM**（Table II，均值）：小提琴数据集——C-ESM NMSE −2.54 dB / NCC 65.46%，PINN-SFD (Nv=0) −2.01 dB / 67.69%，PINN-SFD (Nv=3) −2.79 dB / 70.83%；矩形板固支——C-ESM −2.63 / 73.51%，Nv=0 −4.27 / 89.93%，Nv=3 −5.07 / 84.04%；矩形板自由——C-ESM −1.63 / 59.61%，Nv=0 −1.84 / 68.53%，Nv=3 −2.35 / 68.23%；矩形板简支——C-ESM −4.17 / 76.72%，Nv=0 −4.50 / 90.00%，Nv=3 −5.05 / 84.07%。两种 PINN-SFD 配置的 NMSE 与 NCC 均值均优于 C-ESM。
  2. **典型样例**（Fig. 4/5）：小提琴面板模式 23（985.30 Hz）——C-ESM NMSE −4.04 / NCC 79.27%，Nv=0 −3.70 / 84.47%，Nv=3 −5.60 / 86.41%；固支矩形板模式 14（1964.02 Hz）——C-ESM NMSE 0.16 / NCC 58.50%，Nv=0 −3.98 / 86.84%，Nv=3 −6.28 / 88.26%。相位重建上 PINN-SFD 优势更明显。
  3. **对正则化参数不敏感**：PINN-SFD 固定 λ = 1 × 10⁻⁶ 效果稳定；C-ESM 结果显著依赖参数选择（5 参数中按全息声压 MAE 选优仍不稳定），且最优参数与振型复杂度强相关、需相对噪声水平先验。
  4. **VP 的作用与回弹效应**：VP 对复杂振型（小提琴模式 2–30、自由矩形板 15–30）一致改善；对极复杂模式（小提琴 31–48），Nv=3 总体优于 C-ESM 而 Nv=0 总体不如 C-ESM；但低频模式用 VP 时实际源速度随训练 epoch 可能出现精度回弹；Nv=3 不恒优于 Nv=0（NMSE 改善但 NCC 可能降低）。
  5. **模式复杂度规律**：小提琴（不规则形状+正交各向异性木材）振型复杂，精度到约 30 阶保持较高、40 阶附近降至低点后回升；矩形板低阶精度反而低于高阶；所有数据集的 1 阶模式 PINN-SFD 均差于 C-ESM（作者归因于过拟合）。15 阶以前 C-ESM 波动剧烈且精度远低于两种 PINN-SFD。

  ## 潜在研究方向

  - **回弹效应机理**：低频模式使用 VP 时源速度精度随 epoch 回弹，需从优化动力学/约束竞争角度解释与抑制。
  - **简单模式的过拟合**：1 阶等简单模式 PINN-SFD 不如 C-ESM，说明单一架构对"复杂度谱"两端适配不足；可能需要自适应 VP 数量或按复杂度切换策略。
  - **NMSE–NCC 权衡**：VP 降低误差却不保证模式相似度提升，损失函数层面如何同时约束幅度与空间结构是开放问题。
  - **计算成本**：单次样本独立训练 + 早停机制的单样本成本未与 C-ESM 做系统对比；向实时/瞬态 NAH 与工业实时应用扩展（论文提及的 transient NAH 方向）需效率优化。
  - **超参数敏感性转移**：论文宣称对 λ 不敏感，但学习率、早停窗口、网络结构等 NN 超参的影响未做消融；低频回弹是否由学习率调度触发值得排查。
  - 数据合规声明：本次蒸馏基于提供的全文（末尾在讨论 C-ESM 最优参数与振型复杂度关系处被截断），结论以上述可见部分为准。

  ## 与林赛研究的关联

  - **逆问题求解范式迁移（核心接口，对接 quantum-geometry-inversion 课题）**：该课题的量子几何反演（从 HHG/输运等可测量反演交变磁、量子几何张量）同为欠定病态波动逆问题。PINN-SFD 的三件套可直接借鉴——①把物理控制方程残差作为 loss（自监督、免训练集，解决我们标注数据稀缺的问题）；②在"测量面—源面"之间插入中间虚拟平面构造多路径传播约束（可类比为在我们的反演链路中引入中间可观测量/中间面的自洽约束）；③ℓ1 稀疏罚使少数等效源激活（对应强场驱动体系中稀疏的跃迁通道/主导轨道的先验）。
  - **对正则化参数鲁棒性**：我们以往反演管线的痛点之一是 Tikhonov/CS 参数敏感；论文证明 PINN 优化器（Adam + 物理 loss）可显著降低这种敏感性，这对我们 HHG 谱反演与莫尔体系参数提取的可重复性有直接价值。
  - **复杂度自适应的警示**：VP 在复杂模式有效、简单模式反而过拟合——提醒我们强场 HHG 反演中也应对"简单谱（少通道）"与"复杂谱（多通道干涉）"采用不同的约束强度，一刀切的多约束可能损伤简单情形。
  - **方法素材**：复值 U-Net + Cardioid 激活 + 物理嵌入前向传播的架构设计，以及"全息面约束选优失效"的对照结论，可作为我们构建强场逆问题网络求解器的方法页素材（装置/序列/参数/判据/时间预算五问中"计算设置"与"判据"两问的参考）。
