# High-harmonic Transient Grating Spectroscopy of NO₂ Electronic Relaxation

## 林赛的理解

这篇工作将高次谐波产生（HHG）与瞬态光栅（Transient Grating）技术结合，首次在实验上验证了 NO₂ 分子锥形交叉（conical intersection）驱动的百飞秒振动动力学。其核心价值在于：HHG 过程本身编码了分子轨道对称性信息，而瞬态光栅几何将激发 grating 的空间调制转化为远场衍射信号，实现背景-free 探测。对我们的研究方向而言，这是将 HHG 拓展至非辐射跃迁分子动力学的重要方法论示范——尤其是它能提取振动波包在激发态势能面上的运动相位信息（通过 ΔIpτ 累积相位）。

## 研究问题（Research Question）
NO₂ 分子在 ~3 eV 处存在 ²B₂ ← ²A₁ 电子激发，由于 C₂ᵥ → Cₛ 对称性降低，两个态发生强烈振动耦合（vibronic coupling），形成高密度锥形交叉区域（0.754 levels/cm⁻¹），导致传统光谱技术难以解析其弛豫动力学路径。本工作要回答的核心问题是：

**HHG 瞬态光栅光谱能否编码并提取 NO₂ 电子弛豫中百飞秒振动时间尺度的动力学信息？如果能，定量一致性如何？**

具体分解为：
1. 实验观测到的 ~100 fs 振荡是否对应 ²B₂–²A₁ 振动耦合的基元过程？
2. 激发态 diabatic surface 2 上的 bending motion 如何影响 HHG 的幅值、相位和衍射效率？
3. 锥形交叉的两次穿越（~10 fs 和 ~60–100 fs）如何在信号中留下可区分的印记？

## 研究背景（Background）
### 学术脉络

NO₂ 长期被视为分子物理学的"地狱圣杯"（hellish grail）——它是一个稳定的小分子，但锥形交叉导致电子态与振动态高度混杂，使得时间分辨实验难以归属观测到的信号。前人工作可分为几类：

- **时间分辨光电离/光电子谱**：观察到 ~500 fs 的规则振荡（400 nm 泵浦），但一直未能归属。
- **高次谐波光谱**（此前工作，Nature Physics 2012）：用 ~400 nm 泵浦观察到少数 ~100 fs 振荡，归属于 ²B₂–²A₁ 振动耦合，与理论预测（Trajectory Surface Hopping）定性一致。
- **量子含时（QTD）与表面 hopping（TSH）理论**：在总能量 ~13000–28000 cm⁻¹ 范围内，预测规则再现的周期在 50–100 fs 范围，且随能量增加而增长。QTD 与 TSH 结果一致性良好，说明半经典方法对此系统可靠。

### 研究动机

前人的 HHG 实验只进行了定性比较，且存在若干未解问题：
1. 衍射效率的绝对数值未经验证；
2. 泵浦强度、波长、转动温度对信号的影响未系统研究；
3. 理论预测的锥形交叉两次穿越（~10 fs 初遇、~60 fs 主要转移、~100 fs 回调）是否都能在信号中观测到，尚不清楚。

本研究由此出发：结合 Aurore 1 kHz Ti:Sa 激光系统，系统改变实验参数，并将 TSH 计算直接与实验数据定量对比。

## 研究方法（Methods）
### 实验体系

| 参数 | 数值 |
|------|------|
| 激光源 | CELIA Aurore Ti:Sa, 7 mJ, 27 fs, 800 nm, 1 kHz |
| 泵浦波长 | 400 nm（SH-BBO 200 µm，7 nm 带宽，~35 fs） |
| 泵浦能量 | 10–35 µJ/pulse/arm（可调） |
| 探针波长 | 800 nm |
| 探针强度 | ~1.2×10¹⁴ W/cm² |
| 气体靶 | 纯 NO₂，780 mbar，背压，80°C（抑制 N₂O₄ <10%） |
| 喷嘴 | 100 µm General Valve，100 Hz（或 Even-Lavie 1 kHz 对比） |
| 探测 | 微通道板 + 磷屏 + CCD |
| 谐波阶次 | H15–H21 |

### 瞬态光栅几何

- 两束平行泵浦光垂直偏振、竖直间距 16 mm，经 50-50 分束器产生
- 干涉条纹间距 **9.4 µm**
- 探针光置于两泵浦光中间，三束在 750 mm 球面银镜处聚焦
- 激发 grating 水平→衍射峰在谐波主束上下两侧
- 通过第一阶衍射效率 η = I₁/(I₀ + I₋₁ + I₁) 表征

### 理论计算：Trajectory Surface Hopping (TSH)

- **势能面**：Kurkal-Fleurat-Lessard-Schinke (KFS) 模型，基于 MRCI + QZ 基组构建，同时提供 adiabatic 和 diabatic 表示
- **电子耦合**：通过 $V_{12}^2 = \frac{1}{4}[(E_A - E_X)^2 - (E_2 - E_1)^2]$ 从 diabatic/adiabatic 能量提取；V₁₂ ∝ Q⁻（反对称伸缩坐标）
- **初态**：Wigner 函数 × 一光子共振滤波（Eq. 3），随机启动时间分布 $e^{-2\alpha t^2}$
- **轨迹数**：1×10⁴（收敛检验：2×10³ 和 5×10³ 无明显差异）
- **泵浦脉冲**：30 fs FWHM 高斯，中心 400 nm（计算中也试了 395 nm 和 392 nm，无显著差异）

### 信号模型

基于三步模型（tunnel ionization → propagation → recombination），推导了 undiracted 和第一阶衍射信号：

$$I_0(t) \propto \left| \int [(1-r)d_g + rW_1(\theta,t)d_1(\theta) + rW_2(\theta,t)d_2(\theta)] d\theta \right|^2$$

$$I_1(t) \propto \frac{1}{4} \left| \int [rW_1(\theta,t)(d_1(\theta)-d_g) + rW_2(\theta,t)(d_2(\theta)-d_g)] d\theta \right|^2$$

其中 $d_g$ 和 $d_j(\theta)$ 分别为基态和第 j 表面发射的复偶极矩，由 Kurkal 等人的 1D bent angle 计算插值得到。传播相位 $\phi = \Delta I_p \tau$，$\tau$ ≈ 1.2 fs（H17）。

## 主要发现与核心结论

### 定量实验结果

| 物理量 | 数值 |
|--------|------|
| 第一阶衍射效率峰值位置 | **20 fs**（最大值），**58–60 fs**（最小值），**120 fs**（宽峰） |
| HHG 总信号行为 | t<20 fs 快速衰减；65 fs 峰；130 fs 谷；随后缓慢增加（解离） |
| 解离时间 | **1.8 ± 0.3 ps** |
| 400 nm 激发后高于解离限的分子比例 | **25%** |
| 离子信号增幅 | t=−60 fs → t=60 fs 增加因子 **1.3**，之后稳定 |
| 最佳泵浦-探针偏振配置 | **垂直偏振** |
| 第二阶衍射出现泵浦能量阈值 | **~25 µJ/arm**（饱和效应） |
| 波包 bending angle 范围（基态，PES 1） | **120°–142°** |
| 波包 bending angle 范围（激发态，PES 2） | **90°–110°** |
| ΔI_pτ 变化范围（基态） | **−0.4π ~ +0.4π** |
| ΔI_pτ 变化范围（激发态） | **+0.2π ~ +0.8π** |
| 电子传播时间 τ（H17） | **1.2 fs** |
| 态密度 | **0.754 levels/cm⁻¹** |
| D₀（理论/实验） | **3.00 eV / 3.11 eV** |
| Tₑ（理论/实验） | **1.31 eV / 1.21 eV** |
| TSH 预测的锥形交叉时间节点 | **~10 fs**（首次穿越）、**30–60 fs**（主要电子转移）、**~100 fs**（第一回复）、**~170 fs**（第二回复） |

### 核心结论

1. **实验与 TSH 定量一致**：在 20% 激发分子比例（r=0.2）的假设下，计算得到的衍射效率时间演化与实验在对比度（contrast）和快动力学时间尺度上**惊人地一致**（Fig. 10c）。第一峰位置略有时移，但整体趋势正确。

2. **信号由 diabatic surface 2 的 bending motion 主导**：通过归一化population（消除population转移影响）和单独计算各表面贡献，确认第一阶衍射效率的振荡主要源于**激发态（PES 2）**上的 bending 运动——尽管 PES 1 上的 bending 幅度实际上更大。原因在于 PES 2 上的 ΔI_pτ 变化范围（0.2π~0.8π）远大于 PES 1（−0.4π~+0.4π），导致更强的相位调制和衍射信号。

3. **锥形交叉第二次穿越（~60–100 fs）是第二振荡峰的物理起源**：关闭电子耦合（只保留 PES 2）计算显示第一峰（~20 fs）几乎不变——第一次穿越锥形交叉（~10 fs）对波包结构影响甚微。但第二峰（~120 fs）在有无耦合时**完全不同**——这正是从基态到激发态的第二次穿越（~100 fs）在信号中的直接印记。

4. **第二阶衍射来自饱和而非双光子吸收**：2B₂ ← 2A₁ 吸收截面 ~6×10⁻¹⁹ cm²，泵浦腰直径 ~60 µm，饱和在 ~25 µJ/arm 即出现。第二阶衍射动力学与第一阶相同，证明其来源于饱和诱导的 grating 非谐性，而非双光子激发。

5. **信号对外部参数（泵浦强度、波长、转动温度）稳健**：泵浦能量 10–35 µJ、波长 392–400 nm、两种不同气体源（高温/低温 beam）均未改变第一阶衍射信号的时间行为。这说明观测到的是 NO₂ 本身的本征动力学，而非实验条件引入的假象。

6. **HHG 瞬态光栅光谱编码振动动力学**：由于 HHG 信号的相干性，幅值平方依赖于 population，传播相位 ΔI_pτ 依赖于分子几何，该技术天然地将电子弛豫的振动相位信息映射到 XUV 辐射的时空特性中。

## 潜在研究方向（Future Directions）
### 局限性

1. **1D 模型近似**：计算只考虑了 bending 坐标，将 stretching 坐标积分掉。波包在 stretching 方向的扩散（尤其在 t>100 fs 后）是导致实验第二峰比计算更宽的主要原因（计算给出 100 fs 峰加 170 fs、240 fs 弱复制，实验融合为单一宽峰）。

2. **KFS 势能面不完整性**：diabatic 表示缺少显式的 electronic coupling 和 nonadiabatic derivative coupling（通过 Eq. 1 从 adiabatic 能量反推，符号由对称性确定），这在某些 Q⁻ 区域可能引人误差。

3. **纯光学探测的固有局限**：HHG 探测的是 tunnel ionization 概率和 recombination dipole，对某些量子态的灵敏度可能存在盲区（如 conical intersection 附近 derivative coupling 主导的区域）。

4. **转动温度效应未完全厘清**：两种气体源对比显示第一峰/第二峰高度比有差异，但论文未能给出定量归属——可能是激光条件差异而非转动温度本身。

### 未解决/开放问题

1. **波包在 stretching 坐标的完整三维演化**：当前的 1D bent-angle 模型无法描述 60 fs 后波包的横向扩散，这是计算与实验在长延迟处偏差的唯一来源。

2. **高阶衍射（>2）的潜在信息量**：文章只系统研究了第一、第二阶，第二阶以上是否携带更多相位/构型信息未探讨。

3. **与光电离实验 ~500 fs 振荡的关系**：前人光电离实验报道的 ~500 fs 振荡（400 nm 泵浦）在本文未被观测到——这是两种探测技术的本质差异，还是 NO₂ 在不同激发条件下的不同动力学通道？

4. **更大分子的推广可行性**：TSH 方法的优势在于可推广至多原子分子，但本文尚未在真正的大型系统上验证 HHG-TG 的灵敏度。

5. **Recombination dipole 相位的精确角色**：文章指出 recombination dipole 的额外相位可能会使表面 1 的动力学主导信号——这一效应在当前计算中未包含，值得进一步研究。

## 与林赛研究的关联

作为强场超快光学 PI，本工作对林赛研究的直接接口在于：

- **HHG 作为探测手段**：本文展示了 HHG 可以作为分子动力学的时间分辨探针，其固有阿秒时间分辨率（electronic propagation ~1.2 fs）远超振动周期。对林赛组正在发展的 HHG 光谱，这是一个可靠的方法论验证。

- **瞬态光栅实现背景-free 探测**：光学干涉产生 excitation grating → HHG 从此 grating 衍射，这一几何将激发态信号从基态背景中几何隔离。这对林赛组研究弱激发态信号（如 Mahan 和 Wilg 难以直接测量的态）具有直接借鉴意义。

- **相位 ΔI_pτ 作为构型传感器**：本文的核心物理——电子传播累积相位随分子几何变化（ΔI_pτ）——揭示了 HHG 信号对 ionization potential 变化的敏感度。这与林赛组的**交变磁、莫尔、量子几何**研究方向潜在相关：莫尔超晶格中载流子局域化会导致局域 ionization potential 分布，HHG-TG 也许能探测这种空间调制。

- **对 NO₂ 本身**：作为林赛强场驱动研究的一个可能靶分子，NO₂ 的高密度锥形交叉（0.754 levels/cm⁻¹）提供了一个理想的三原子 benchmark 系统，用于验证强场驱动的非绝热动力学理论（TSH vs. QTD）。

- **技术迁移**：1 kHz、7 mJ、27 fs 的激光系统与林赛组设备在量级上可比；本文的 pump-probe 延迟扫描（10 fs 步长、6250 shots/delay）可作为设计类似实验的参数参考。

**方法**：HHG 瞬态光栅（Transient Grating）+ TSH 定量对比：NO₂ 锥形交叉驱动的百 fs 振动动力学分辨
