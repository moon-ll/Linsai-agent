• # 交变磁体中磁振子驱动的反常霍尔效应（Magnon-Driven Anomalous Hall Effect in Altermagnets）

  ## 林赛的理解

  这篇工作给了我们一把全新的钥匙：反常霍尔效应不再必须依赖平衡态的宏观磁性序，而可以由一个**动力学手性方向**——Néel 矢量的进动——来驱动。对我来说最兴奋的有两点。第一，它揭示了一种新的"拓扑输运—磁激发"耦合通道：Berry 曲率响应过去总是绑定在平衡序上，现在有了"非平衡序驱动"的版本，而且其对称性约束与平衡版本**本质不同**——在 CrSb 这种 g 波交变磁体中静态 AHE 被对称性完全禁戒，但磁振子驱动的 AHE 却存活。第二，这是一篇纯理论 + 最小模型的对称性分析工作，落点在"探测磁振子手性、用磁振子操控电子手性"，恰好落在自旋电子学与超快磁动力学的交叉点上。我们组做超快光学，这篇工作直接暗示了一个实验方案：用 THz 脉冲相干激发 Néel 矢量进动（这正是我们所长的），再读出直流反常霍尔电压——把"磁振子手性"变成一个可电学读取的观测量，或者反过来用受控进动去"写入"电子手性输运。

  ## 研究问题

  论文回答两个相互关联的核心问题：

  1. **手性磁振子模式能否与电子耦合、产生独特的输运行为？** 此前手性声子-磁振子耦合（混合模手性行为）与手性声子-电子耦合（谷激子受手性声子深刻影响）已被深入研究，但"手性磁振子→电子"这条通道基本未被触及。
  2. **反常霍尔效应能否由动力学手性方向（Néel 序进动方向）直接诱导，而非仅由平衡态宏观手性方向（如铁磁序）携带？**

  论文的核心命题：交变磁体中相干激发的手性磁振子可以与手性电子运动耦合，产生一种**磁振子驱动的反常霍尔效应**，其霍尔电导仅由 Néel 序进动的手性决定，而非由 Néel 矢量本身决定。由此它拥有与平衡自旋序诱导的反常霍尔效应**不同的对称性要求**，甚至可以在后者被对称性禁戒时仍然存在。

  ## 研究背景

  - **手性是现代凝聚态的核心概念**：电子、声子、磁振子的圆运动（手性）在激子形成、磁动力学、热霍尔效应等量子现象中起重要作用，驱动自旋电子学、声子学、磁光功能等应用方向。不同手性模式之间的耦合（产生与探测手性）是中心研究主题。
  - **反常霍尔效应是电子手性最突出的体现**：微观上由平衡基态的 Berry 曲率刻画，必然与晶体中的宏观手性方向（如铁磁自旋序）绑定，翻转自旋序即翻转反常霍尔响应。
  - **磁振子/自旋进动提供了另一个手性方向——进动方向**。于是"反常霍尔效应能否由动力学手性方向诱导"成为一个自然但未被回答的问题。
  - **为何选交变磁体（altermagnet）**：① 其低能激发同时含**两种手性**的磁振子模式（与铁磁体单一手性相反）；② 两种手性磁振子在能量上**分离**（与 PT 或 Tτ 对称反铁磁体中的简并磁振子相反）。RuO₂、MnTe、CrSb 等体系中手性劈裂磁振子已被观测或理论预言。
  - **物理图像**（论文图 1(b)）：平衡时，相反局域自旋序关联的 Berry 曲率也相反，对 AHE 相消贡献；但相反局域自旋序以**相同方式进动**，共享同一进动方向，于是对磁振子驱动 AHE **相长贡献**。物理原点即"交变磁体中存在两个手性方向：Néel 序与其进动方向"。

  ## 研究方法

  - **微观理论——密度矩阵微扰论**：在同时含静态电场与动力学 Néel 矢量变化的哈密顿量 `Ĥ = Ĥ₀ + eE·r̂ + F̂ᵢN̂ᵢ(t)`（F̂ᵢ ≡ ∂Ĥ₀/∂N̂ᵢ 为 Néel 偏差的线性耦合，忽略 N̂ᵢ 的高阶项，因其对 N̂ 对称、不贡献响应）下，通过动力学方程 `iℏ dρ̂/dt = [Ĥ, ρ̂] − iℏ/τ₀ (ρ̂ − ρ̂⁽⁰⁾)`（τ₀ 为弛豫时间近似下的唯象弛豫时间）求解至三阶得 δρ̂⁽³⁾，由 `jᵢ = −eTr(δρ̂⁽³⁾ v̂ᵢ)` 得到稳态电流响应。
  - **响应张量结构**：一般响应对电场 E 与两个进动频率分量反对称化（磁振子为圆偏振，取 ωα + ωβ = 0），将四阶张量 χᵢⱼₖℓ 约化为二阶张量 χ̃ᵃᵇ(ω)，电流写为 `jᵢ = εᵢⱼₐ χ̃ᵃᵇ(ω) Eⱼ [iN̂(ω) × N̂*(ω)]ᵦ`。磁振子动量不直接影响电流，但决定磁振子手性（正反动量手性相反）。磁振子驱动 AHE 对应响应中时间反演偶的部分，即 χ̃ᵃᵇ(−N̂₀) = χ̃ᵃᵇ(N̂₀)。
  - **对称性分析**：对 χ̃ᵃᵇ，时间反演等价于恒等操作（由 Onsager 倒易关系出发），故 χ̃ᵃᵇ 受"磁点群把 T 认同为恒等"的导出群约束；反演操作也使 χ̃ᵃᵇ 不变，因此 Cₙ 与 ICₙ 等价（统一记作 C̃ₙ，C̃₂ 含镜面操作）。利用**自旋群（spin group）**区分自旋坐标系与晶格坐标系，定义 χ̃sep_ab（第一指标随晶格系、第二指标随自旋系变换），将自旋轨道耦合作微扰、对自旋轨道矢量 ℓⱼᵐ 展开：由于交变磁体的纯自旋对称性由 T Cs₂ₓ 与 Cs∞z 生成，Cs₂ₓ 使 χ̃sep_az 变号，禁戒零阶项，得一阶结果 `χ̃sep_iz = αᵢⱼℓⱼᶻ = αᵢⱼN̂ⱼ`（αᵢⱼ 为自旋轨道耦合一阶强度）。对比平衡反常霍尔电导 `σᴴᵢ = βᵢⱼℓⱼᶻ`：α 与 β 在纯自旋群下变换相同，但在非平凡自旋群操作 Cs₂⊥ 下 **β 变号而 α 不变**——这是磁振子驱动 AHE 稳健性的对称性根源。
  - **最小晶格模型**：取与交变磁体 CrSb 同对称性的共线反铁磁模型，哈密顿量 `H = ε₀,k + tx,kτx + tz,kτz + τyλ·σ + τzJ·σ`（τ 作用子格、σ 作用自旋；ε₀,k、t_x,k、t_z,k、λ_x,k、λ_y,k、λ_z,k 均为动量依赖系数，含 f_x = sin kx + sin(kx/2)cos(√3ky/2)、f_y = √3cos(kx/2)sin(√3ky/2) 等结构因子），晶格常数取 1，晶体点群 D₆ₕ，自旋点群由 {Cs₂⊥|C₆zᴸ}、{Cs₂⊥|σxyᴸ}、{Eₛ|C₂xᴸ} 生成，与 CrSb 自旋结构一致。

  ## 主要发现与核心结论

  1. **磁振子驱动反常霍尔效应存在且机制清晰**：霍尔电导仅由 Néel 序进动方向的手性决定，响应系数 χ̃ᵃᵇ 对平衡 Néel 矢量 N̂₀ 为偶——**翻转 Néel 序不影响响应系数**，与图 1(b) 的相长贡献图像一致。这与平衡自旋序诱导的 AHE（对 N̂₀ 为奇、翻序即翻转响应）形成鲜明对比。
  2. **对称性要求本质不同，稳健性更强**（Table I 的完整约束）：
     - 对角分量 χ̃xx、χ̃yy、χ̃zz 在任意转动对称性下均被允许——只要交变磁体中有磁振子模式的自旋进动，垂直于进动方向的平面内总有霍尔型响应；
     - 若存在单一转动轴 C̃ₙz（n ≥ 2），χ̃xy、χ̃yx 也允许；
     - χ̃xz、χ̃yz、χ̃zx、χ̃zy 仅在"None"（母点群无广义转动操作）时允许，有 C̃ₙz 或 C̃ₙ'⊥（n, n' ≥ 2）时禁戒；
     - **out-of-plane 构型**：若晶体磁点群含 CₙT（n ≥ 2），自旋序诱导的 AHE 其霍尔偏转平面不能垂直于转动轴（禁止 out-of-plane 构型），但磁振子驱动 AHE 仍允许——此时自旋进动方向、自旋序方向、霍尔电导矢量三者共沿转动轴。
  3. **具体材料例证**：
     - **FeSe₂**（d 波交变磁体，Néel 矢量沿 y，对称性 T C₂y）：自旋序的霍尔电导矢量 σᴴ 不能沿 y 方向，但当自旋序绕 y 轴进动时可诱导有限的 σᴴ_y；
     - **CrSb**（g 波交变磁体，Néel 矢量沿 z，对称性 T C₆z）：自旋序的 σᴴ 恒等于零（被对称性禁戒），但可被磁振子诱导。
  4. **最小模型数值结果**（模型参数 t₂/t₁ = 1.0，t₃/t₁ = 0.5，µ/t₁ = 0.5，λ/t₁ = 0.004，J/t₁ = 0.45；磁振子频率 ω/t₁ = 0.1；图 2(f) 中 Fermi 能固定 EF/t₁ = 0；响应系数以 c₀ S/cm 为单位，c₀ = τ₀/ℏ）：
     - 无自旋轨道耦合时能带已明显自旋劈裂（净磁矩完全补偿但自旋劈裂，体现交变磁性本质）；自旋上/下 Fermi 面在动量空间分离，符合 CrSb 的 g 波特性；
     - k 分辨的 Berry 曲率 Ωz(k) 在方位角方向正负交替（自旋上/下带反号），整体相消；而 k 分辨响应系数 χ̃₃₃(k) 对自旋上、下带分布**完全相同**、方位角方向不变号——直接证明磁振子驱动 AHE 由磁振子手性而非局域自旋序支配；
     - **χ̃zz 非零**（Néel 矢量沿 z 时），且随 Fermi 能灵敏变化、可在能带交叉点变号；静态 AHE 在该模型中被磁点群禁戒，而磁振子驱动 AHE 存活；
     - **角依赖呈偶极结构**：Néel 矢量从 z 轴转向 x 轴转过角度 θ 时，`χ̃sep_xz = αxx sin θ`，`χ̃sep_zz = αzz cos θ`（非零元素仅 αxx = αyy 与 αzz，由非平凡自旋群轨道部分 C₆zᴸ、σxyᴸ、C₂xᴸ 决定）；CrSb 中当 Néel 矢量偏离 z 轴时，自旋序诱导的霍尔电导矢量在 Néel 矢量的**三次方阶**（即自旋轨道耦合强度三次方）才开始，而磁振子驱动 AHE 从**线性阶**就开始——对比印证对称性分析，图 2(f) 曲线与式 (11) 吻合良好。
  5. **普适性**：该效应同样可产生于 PT 对称或 Tτ 对称的共线反铁磁体——这两类体系中反铁磁自旋序本不支持 AHE，但只要通过（例如）自旋流注入激发固定手性的磁振子，即可由 χ̃ᵃᵇ 产生非零反常霍尔效应。效应普遍在 Néel 矢量空间具有偶极结构。
  6. **应用指向**：揭示了手性磁振子模式与手性电子运动的紧密耦合，提供了将磁振子信号转换为电子响应的路径——通过输运测量探测磁振子手性，为用磁振子操控电子手性开辟道路。

  ## 潜在研究方向

  - **实验实现未被本文处理**：如何相干激发"固定手性"的磁振子（自旋流注入之外，THz 脉冲、圆偏振光泵浦等超快手段是自然候选）及其激发效率、弛豫时间 τ₀ 对信号强度的实际影响，均需实验标定；文中 c₀ = τ₀/ℏ 的单位设定暗示信号大小直接受限于电子弛豫时间。
  - **模型为最小模型**：仅含三参数跃迁与两个对称性关键项，未做 CrSb 的 first-principles 定量计算；χ̃ 的绝对量级、温度依赖（magnon 占据数）、无序与多带效应有待真实材料计算与测量。
  - **与自旋轨道耦合的微妙关系**：αᵢⱼ 本身是一阶自旋轨道耦合强度——意味着在自旋轨道极弱的体系中信号可能过弱，需权衡"对称性允许"与"强度可观"两个条件。
  - **未讨论时间分辨动力学**：χ̃(ω) 的频率依赖仅取单频进动，宽带/脉冲激发下的瞬态响应、磁振子-电子能量交换的 back-action 未涉及。
  - **与 PT/Tτ 对称反铁磁体中简并磁振子的耦合**只给了定性展望，简并模式下手性选择的具体实现方式仍是开放问题。

  ## 与林赛研究的关联

  - **强场驱动 / THz 磁振子激发**：本文要求的"相干激发手性磁振子（Néel 序圆偏振进动）"正是强场超快光学的看家本领——THz 脉冲可共振驱动反铁磁 Néel 矢量进动（对应其 ω/t₁ = 0.1 量级的低频模）。我们可直接提出实验构型：THz 泵浦 CrSb 激发手性进动 → 直流探测反常霍尔电压 → 改变泵浦手性（圆偏振 helicity）切换霍尔信号符号。这是把"超快磁动力学"读出为"电子输运"的干净接口。
  - **交变磁方向**：本文与 general-order-parameter-ultrafast-readout 课题直接相关——它示范了"序参量的动力学分量（而非平衡值）作为独立输运驱动源"的范式。这为我们"超快读出序参量"的立项逻辑提供了理论先例：观测对象可以从序参量本身扩展到序参量的进动手性。
  - **HHG / 阿秒关联**：磁振子手性是一种低频（meV-THz）手性驱动源，而 HHG 中电子波包的手性运动由 Berry 曲率规范场支配——两者共享"手性电子运动"语言。可探索：交变磁体中磁振子驱动 AHE 的 χ̃(ω) 与强场非线性光学响应（如圆偏振依赖的 HHG 产率、注入电流）之间的张量结构类比，把对称性分析框架（时间反演偶的响应、自旋群导出群）移植到非线性光学响应分类中。
  - **莫尔 / 量子几何接口**：χ̃ᵃᵇ 的微观表达为动量空间 Berry 曲率型响应的反对称化组合，与量子几何张量同属能带几何量；莫尔超晶格中可工程化的反铁磁关联与平带 Berry 曲率热点，可能是实现/放大此类"动力学手性输运"的可调平台。

## 研究问题（Research Question）

本文的核心问题是：**能否在交变磁体（altermagnet）中通过非平衡的手性磁振子（chiral magnons）激发一种反常霍尔效应（anomalous Hall effect, AHE），即使当静态Néel 矢量本身由于磁性点群对称性禁止产生任何AHE？** 作者将该问题进一步拆为两个子目标：第一，建立从相干磁振子与手性电子运动耦合出发的微观响应理论；第二，利用自旋群（spin group）对称性分析，阐明该效应的允许张量结构，并寻找它与"平衡态Néel 序产生的传统AHE"在对称性上的本质差异，从而在最有利于发现的体系（如 CrSb 这类g-wave 因磁体）中进行具体验证。

## 研究背景（Background）

手性（chirality）作为电子、声子、磁振子等多种准粒子的圆周运动属性，在激子形成、磁动力学、热霍尔效应等领域扮演核心角色，是当代自旋电子学和磁光功能应用的关键自由度。已有研究集中于"手性声子-磁振子耦合"与"手性声子-电子耦合"两类耦合模式，例如混合磁振子-声子模式已被证明可以显示出独特的手性特征。然而，在交变磁体这一近两年才被确立的具有g-wave/d-wave 等非平庸自旋劈裂的磁有序相中，**手性磁振子与手性电子运动的直接耦合尚未被系统地研究**。传统的AHE由平衡磁序的对称性决定，并在CrSb 这类因磁体（其磁点群因含 n 重旋转轴与时间反演联合对称而禁止AHE）中受到严格限制，这正是本工作所聚焦并试图逾越的对称性障碍。

## 研究方法（Methods）

论文采用三步互补的方法学路线：（1）**密度矩阵微扰理论（density-matrix perturbation theory）**：在电子哈密顿量  $\hat{H} = \hat{H}_0 + e\mathbf{E}\cdot\hat{\mathbf{r}} + \hat{F}_i\hat{N}_i(t)$ 下求解包含恒定电场与 Néel 矢量动态进动的三阶密度矩阵响应 $\delta\hat{\rho}^{(3)}$，并通过 $j_i = -e\,\text{Tr}(\delta\hat{\rho}^{(3)}\hat{v}_i)$ 给出稳态电流，其中 $\hat{v}_i$ 为速度算符，$\tau_0$ 为唯象弛豫时间。（2）**自旋群对称性分析（symmetry analysis）**：对 $\tilde{\chi}_{ab}$ 实施磁性点群操作、并将时间反演 T 识别为恒等操作后，导出"广义旋转群"$\tilde{C}_n$（包含 I·C_n 与纯 C_n），由此构造对称性约束表（Table I），证明对角分量 $\chi_{xx}, \chi_{yy}, \chi_{zz}$ 在任意 $\tilde{C}_n$（n≥2）下都被允许。（3）**最小晶格模型验证**：对CrSb 构建具有 D_6h 晶格点群与 $\{C_{2\perp}^s|C_{6z}^L\}, \{C_{2\perp}^s|\sigma_{xy}^L\}, \{E^s|C_{2x}^L\}$ 自旋点群的紧束缚模型（式 (10)，包含子格间跃迁 $t_{x,k}, t_{z,k}$、自旋-轨道型耦合 $\tau_y\boldsymbol{\lambda}\cdot\boldsymbol{\sigma}$ 与反铁磁交换 $\tau_z\mathbf{J}\cdot\boldsymbol{\sigma}$），数值计算 Berry 曲率与 $\tilde{\chi}_{33}$ 在动量空间的分布，并在 Néel 矢量旋转下验证 $\tilde{\chi}_{xz}^{sep}=\alpha_{xx}\sin\theta$、$\tilde{\chi}_{zz}^{sep}=\alpha_{zz}\cos\theta$ 的角依赖关系（式 (11)）。

## 主要发现与核心结论（Main Results）

（1）**微观响应系数与物理图景**：作者证明由非平衡磁振子驱动的霍尔电导率张量 $\tilde{\chi}_{ab}$ 完全由 Néel 序进动的**手性**（chiralithy） $\propto [i\hat{\mathbf{N}}(\omega)\times\hat{\mathbf{N}}^*(\omega)]_b$ 决定，并满足 $\tilde{\chi}_{ab}(-\hat{\mathbf{N}}_0)=\tilde{\chi}_{ab}(\hat{\mathbf{N}}_0)$——即它是 Néel 矢量偶函数但对磁振子进动方向敏感；这意味着翻转 Néel 矢量不影响响应系数，但左右手磁振子产生反号贡献（Fig. 1(b)）。（2）**对称性容许性（Table I）**：对角分量 $\tilde{\chi}_{xx},\tilde{\chi}_{yy},\tilde{\chi}_{zz}$ 在所有旋转对称性下均被允许，且在同时存在 $\tilde{C}_{nz}$ 与 $\tilde{C}_{n'\perp}$ 时额外允许 $\tilde{\chi}_{xy},\tilde{\chi}_{yx}$；当体系没有 C_2 轴沿旋转轴并垂直于霍尔偏转平面时，"自旋序AHE"被禁止，但"磁振子驱动的AHE"在该方向（沿旋转轴）仍可存在——这是对传统AHE 在CrSb 类因磁体中被对称性禁戒的彻底逾越。（3）**CrSb 数值验证**：在所建格点上，g-wave 自旋劈裂的费米面被清晰复现，Berry 曲率在方位角方向变号并在自旋上下能带间相消，导致静态AHE 为零；与此相反，$\tilde{\chi}_{33}$ 在自旋上下能带上具有**相同**分布且不在方位角方向变号（图2(c)–2(d)），证实响应完全由磁振子手性而非局部自旋序决定。（4）**费米能与角度依赖**：$\tilde{\chi}_{zz}$ 随费米能敏感变化并可在能带交叉点改变符号（Fig. 2(e)）；将 Néel 矢量从 z 轴转向 x 轴时，$\tilde{\chi}_{xz}^{sep}$ 与 $\tilde{\chi}_{zz}^{sep}$ 完美遵循 $\sin\theta$ 与 $\cos\theta$ 规律（Fig. 2(f)），与对称性预言相符。（5）**SOC 角色**：在自旋框架中 $\tilde{\chi}_{iz}^{sep}=\alpha_{ij}\hat{N}_j$，其中 $\alpha_{ij}$ 一阶依赖于自旋-轨道耦合强度，但与非平庸自旋群操作 $C_{2\perp}^s$ 无关，这正是该效应相比传统AHE $\sigma_H^i = \beta_{ij}\ell_z^j$ 更为鲁棒的对称性根源。

## 潜在研究方向（Future Directions）

（1）**实验可观测性**：CrSb 等典型因磁体的 Néel 温度高达约 705 K，但其低能磁振子能否在实验室被相干激发（特别是以可控制手性的方式，如自旋电流注入或圆极化微波）尚未被验证——需要发展亚 THz 量级的磁振子手性选择激发技术；（2）**强关联与材料拓展**：当前推导基于单粒子密度矩阵响应，忽略了电子-电子相互作用与多体散射，应进一步扩展至含 Hubbard-U 的情形，并考虑更多 g-wave/d-wave 因磁材料（如 MnTe、MnTe 类体系）的具体响应幅度与频率色散；（3）**时间分辨探测**：磁振子驱动AHE 本质是亚皮秒的非平衡响应，应借助时间分辨的 pump-probe（如 TR-MOKE、自旋极化 STM）来实时观察霍尔信号随磁振子进动相位的变化；（4）**自旋电子学应用**：作者明确指出该效应提供了一条将磁振子信号转换为电学响应的通道，未来可探索以此机制为基础的磁振子-电子换能器、磁振子手性探测器乃至低功耗逻辑器件；（6）**理论限制**：模型采用了最低阶 $\hat{N}_i$ 耦合与弛豫时间近似，对高阶非线性（多个磁振子同时激发）以及非平庸自旋-声子耦合通道的影响尚未触及，值得在讨论部分作为开放问题加以阐明。

## 研究方法（方法卡）
<!-- methods-backfill:v1 -->
**方法**：密度矩阵三阶微扰响应 + 自旋群对称性分析 + CrSb 对称最小晶格模型（磁振子驱动反常霍尔效应）

**原理**：在 H = H₀ + eE·r̂ + F̂ᵢN̂ᵢ(t) 下求解含弛豫项密度矩阵方程至三阶 δρ⁽³⁾，j = −eTr(δρ⁽³⁾v) 得稳态电流；对电场与两进动频率分量反对称化把四阶张量约化为二阶 χ̃ᵃᵇ(ω)，电流 j = εχ̃E[iN̂×N̂*]——霍尔电导仅由 Néel 序进动手性决定、对平衡 N̂₀ 为偶（翻 Néel 序不影响响应，与平衡 AHE 翻序即翻转响应本质不同）；自旋群分析（Onsager 下时间反演等效恒等，Cₙ 与 ICₙ 统一记 C̃ₙ），SOC 微扰展开中 Cs₂ₓ 禁戒零阶得一阶 χ̃_iz = α_ij N̂_j，非平凡操作 Cs₂⊥ 下平衡系数 β 变号而 α 不变——稳健性对称性根源；CrSb 对称 D₆h 最小模型数值验证：Berry 曲率方位角反号相消（静态 AHE 禁戒）而 χ̃₃₃ 自旋上下带同分布不变号。

**适用边界**：实验实现未处理（固定手性磁振子的相干激发——自旋流注入/THz/圆偏泵浦——待验证）；最小模型无 first-principles 定量（χ̃ 绝对量级、温度依赖、无序、多带未含）；α_ij 一阶依赖 SOC（SOC 极弱体系信号过弱）；仅单频进动（宽带/脉冲瞬态响应、磁振子-电子 back-action 未涉及）；N̂ᵢ 线性耦合（多磁振子同时激发的高阶非线性未触及）。
