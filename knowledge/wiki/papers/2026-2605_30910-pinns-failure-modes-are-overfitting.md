• # PINNs 失败模式本质为过拟合：残差直接可视化与双重反向传播正则化

  ## 林赛的理解

  这篇工作对做 PINN 解 PDE 的人是个"认知纠偏"：过去四年 PINNs 社区把 failure mode 归咎于损失景观（谱偏置、局部极小值），最近又有人主张"FP64 是全部所需"，本质是优化困难。本文作者的诊断干净利落——把 PDE 残差画出来，发现失败模式里损失确实被压到了 ~10⁻¹ 的近全局最小值，但残差只是在配点（collocation points）上被压平，配点之间残差巨大。这就是教科书意义上的**过拟合**：训练/测试损失发散是判据。对我们来说这意味着两件事：① 如果我们用 PINN 求解强场 Maxwell-Bloch 或含时薛定谔方程这类含陡梯度的方程，失败与否不看损失数值看**测试损失分叉**；② 处方极廉价——加 L2 或双重反向传播（double PINN），普通 MLP + FP64 就能在四个基准方程上超越 PINNsFormer / PINNMamba 一个数量级以上，且配点从 ~10000+ 降到 144-800 个。我的结论：这是 2026 年 PINN 训练的默认基线配置，写方法学时直接引用。

  ## 研究问题

  PINNs 在某些简单 PDE（对流方程、波动方程等）上收敛到错误解（"failure mode"）——损失接近零却解完全错误——其根本原因究竟是什么？既有解释为损失景观中存在不可逾越的损失壁垒（局部极小值）[12]，或数值精度不足（FP32）阻碍优化 [20]。本文要回答的核心问题是：**failure mode 是"优化没做好"还是"优化做好了但过拟合到了配点上"？** 以及基于正确诊断，能否用标准正则化手段（而非新架构）以 vanilla 网络达到 SOTA？

  ## 研究背景

  - PINNs（Raissi et al. 2019 [11]）通过最小化 PDE 残差 + 边界/初值损失训练网络直接逼近解，形式简单、应用广泛，但在低维简单问题上会塌缩到错误解（failure mode，Krishnapriyan et al. 2021 [12] 系统刻画）。
  - 既有诊断归因于：谱偏置与域/边界损失失衡 [13, 14]、初值向域内传播失败 [15–17]、损失景观复杂 [18–20]。处方包括损失重加权、自适应采样、新优化器、新架构，以及 FP32→FP64 精度升级 [13, 14, 16–20]。
  - Xu et al. [20]（NeurIPS 2025，"FP64 is all you need"）主张失败源于精度不足导致的优化失败，其 FP64 方法仍有较高误差，且本文指出它在大配点网格（101×101=10201 点）上仍能失败——暗示高精度方法部分依赖"过定问题"来规避失败。
  - 正则化（L1/L2、double backpropagation [23]、Sobolev training [37]）是深度学习标准工具，但极少应用于纯 PINNs；梯度正则化只在域目标上用过、未针对 failure mode [39, 40]。
  - 神经算子（FNO [6]、DeepONet [10]）是求解算子的并行路线，非本文焦点。

  ## 研究方法

  方法密度中等偏高：核心贡献是**诊断方法（残差可视化）+ 正则化处方（double PINN）**，实验设置标准化。按方法卡整理：

  **网络与训练配置（§3，数值原样）**
  - 网络：4 个隐藏层 × 128 神经元，tanh 激活，Glorot normal 初始化 [41]（vanilla 架构，无特殊结构）
  - 优化器：L-BFGS（全内存版本） [42]，训练 10⁶ 次迭代（Allen-Cahn 提前停）
  - 精度：FP32 实验在 Nvidia Titan RTX 上跑，FP64 实验在 Nvidia A100 GPU 上跑
  - 实现：JAX 库 [43]
  - 配点：域内网格配点 + 边界/初值线性等距配点（对标 failure mode 文献 [20]）；另设一组**远大于训练集的随机配点作测试集**（含更密的边界/初值），这是诊断过拟合的关键设计
  - 损失权重：λ_F = λ_B = λ_I = 1（沿用原始 PINNs [11]）

  **诊断方法（§4.1）**
  - 直接可视化 PDE 残差（将残差沿配点时间切片逐 x 画出，配点位置用竖线标出）；判据为**训练损失与测试损失是否分叉**——分叉即过拟合型 failure mode，同步不叉即优化困难（如 Allen-Cahn）。
  - 精度消融：波动方程在 10201 点（101×101）网格 vs 144 点（12×12）网格上分别跑 FP32 与 FP64。

  **核心处方：double PINN（Eq. 5，Eq. 5 数值原样）**
  - 将 Drucker & Le Cun 的 double backpropagation [23] 推广到 PINNs 全部损失项：对残差关于网络**输入**（x, t）取梯度并加入损失：
    L = L_F + (λ_r/2)‖∇_{x,t}F‖² + Σ_j (L_Bj + (λ_r/2)‖∇_t B_j‖²) + Σ_j (L_Ij + (λ_r/2)‖∇_x I_j‖²)
  - 机制：把残差"压平"（flatten），惩罚网络"在配点处压低损失、牺牲邻域"的行为——直接针对过拟合机制，不限制权重本身，故不损失表达力（对比 L1 稀疏化）。
  - 对照正则化：L2（L_θ = L_0 + (λ_r/2)‖w‖²₂）、L1（L_θ = L_0 + λ_r‖w‖₁），均在 β=50 对流方程 FP32 上对比（Fig. 6）。

  **基准方程与配点预算（§4.3，数值原样）**
  - 四个基准：Convection（β=50）、Reaction、Wave、Allen-Cahn
  - 域内配点数分别为 400、256、144、4096；边界/初值配点：Convection 每项 200 点，其余三项每项 100 点（Allen-Cahn 用 4096 点网格以分辨锐界面）
  - 基线：vanilla FP64 PINN [20]、PINNsFormer [21]、PINNMamba [22]（后者均在 10201 点密集网格上）
  - 指标：最终损失、rMAE（相对平均绝对误差）、rRMSE（相对均方根误差）

  **计算成本注记**
  - 双重反向传播理论上使计算成本翻倍（需对输入再求梯度），但收敛更快（Fig. 6 中 double PINN 约 5000+ 次迭代即收敛，对照组需 25000 次）且配点大幅减少，实际总成本更低。

  ## 主要发现与核心结论

  1. **失败模式 = 过拟合，非优化失败。** 直接可视化残差显示：失败模式下损失被平滑优化到 ~10⁻¹ 的近全局最小（Fig. 1d），训练/测试损失显著分叉——这是 PINNs failure mode 的标志性特征，在所有测试方程上一致出现。残差在配点处被压平、配点之间残差巨大（Fig. 3c），即网络"记住"了训练配点而非学会解。
  2. **FP64 既非必要也非充分。** 波动方程上 FP64 在 10201 点网格成功 [20]，但降到 144 点网格即失败（Fig. 3b）；加正则化后同一 144 点训练成功（Fig. 3d）。作者论证：FP64 方法部分依赖过定配点来压制记忆化，代价是训练成本。
  3. **正则化使 failure mode 在 FP32 下消失。** L2 与 double PINN 均使测试损失重新跟踪训练损失、残差无配点关联；L1 也消除过拟合但难优化、误差大（作者归因于稀疏化过度限制表达力）。
  4. **double PINN + FP64 达到 SOTA，误差优于现有方法至少一个数量级**（Table 1 数值原样，N 为总配点数）：
     - Convection（N=800，vs 基线 N=10403）：double PINN rMAE 4.9e-6±4.4e-6，最优基线 PINN_FP64 为 5.9e-3±1.3e-3（约 3 个数量级提升）；PINNsFormer rMAE 3.3e-2，PINNMamba 1.8e-2
     - Reaction（N=456）：double PINN rMAE 1.1e-5±2.3e-6、rRMSE 2.9e-5±8.0e-6；最优基线 PINNMamba rMAE 9.2e-3±1.7e-3
     - Wave（N=444）：double PINN rMAE 3.8e-4±1.0e-4；最优基线 PINNMamba 1.9e-2±3.3e-3
     - Allen-Cahn（N=4396，需更多点分辨锐界面）：double PINN rMAE 9.6e-5±2.0e-5；最优基线 PINN_FP64 1.6e-2±3.6e-3
     - 配点减少约 23×（摘要口径 up to 23× fewer collocation points；如 Wave 10504→444）
  5. **Allen-Cahn 被重新归类**：其 FP32 训练失败时训练/测试损失同步、不分叉，属刚性（stiff）方程的优化困难而非 failure mode；FP64 可解，但后期测试损失回升表明学到解后继续优化仍会发生记忆化——即使无 failure mode，正则化也有益（Fig. 4d 得最佳结果）。
  6. **double PINN 综合最优**（Fig. 6，β=50 对流方程 FP32）：收敛最快（约 5000+ 次 L-BFGS 迭代，未正则化对照需 ~25000 次迭代仍失败）、最终损失最低；归因于其只作用于残差、不限制权重表达力。

  ## 潜在研究方向

  - **高维与复杂 PDE 的泛化待验证**：作者预期收益在复杂/高维 PDE，但本文仅测试 1D+时间 的四个基准方程；多维、多物理耦合（如含激波、多尺度界面）情形下的表现与 λ_r 调参未系统展开。
  - **λ_r 超参敏感性**：正则化强度 λ_r 的选择策略文中未给出系统扫描；不同方程/精度下是否需要不同的 λ_r 是开放问题。
  - **理论解释缺口**：梯度正则化 PINNs 为何有效的理论分析此前被留作 open question [39]，本文给出过拟合机制层面的解释但未提供收敛性证明。
  - **与自适应采样/因果训练的关系**：double PINN 与 R³ sampling [16]、causal training [17] 等正交手段的叠加效果未测试。
  - **计算成本的理论翻倍 vs 实际收益**依赖收敛加速，对更复杂损失景观是否仍成立需验证。

  ## 与林赛研究的关联

  - **PINN 求解含时薛定谔方程 / Maxwell-Bloch 的可靠性判据**：本组若用 PINN 做强场驱动下的波包演化或 HHG 谱模拟，失败诊断可直接照搬——画残差 + 比较训练/测试损失分叉，而不是盯损失绝对值。
  - **陡梯度方程接口**：Allen-Cahn 的锐界面行为对标本组的强场问题中波函数局域化、势垒隧穿等陡结构；其"需 4096 点 + 正则化 + FP64"的配置是可直接复用的参数起点。
  - **计算成本口径**：配点从 ~10000 降至 144-800（约 23×），L-BFGS 迭代从 25000 降至 ~5000——写课题方案"时间预算"一节时的具体数字素材。
  - **量子几何反演课题（general-quantum-geometry-inversion-20260726）**：该课题已引用本笔记；double PINN 的输入梯度正则化思想对反问题中防止解向测量点过拟合有直接借鉴价值。
  - 方法论上，"把残差画出来"这一诊断范式（可视化算符残差的空间结构）同样适用于检验任何神经求解器在莫尔体系、交变磁模型中的物理合理性。

**方法**：PINNs 失败模式诊断（残差可视化 + 训练/测试损失分叉判据）与 double PINN 输入梯度正则化处方

**原理**：诊断：直接可视化 PDE 残差沿配点的空间结构，判据为训练损失与测试损失（远大于训练集的随机配点集）是否分叉——分叉即过拟合型 failure mode（残差在配点处被压平、配点间残差巨大），同步不分叉属刚性方程优化困难。处方：把 Drucker-Le Cun double backpropagation 推广到 PINNs 全部损失项，对残差关于网络输入 (x,t) 取梯度加入损失 L = L_F + (λ_r/2)‖∇_{x,t}F‖² + …，压平残差、惩罚'配点处压低损失牺牲邻域'的记忆化行为；普通 MLP + L-BFGS 即可，无需新架构。
