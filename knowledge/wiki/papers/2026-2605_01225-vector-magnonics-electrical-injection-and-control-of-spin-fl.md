• # Vector Magnonics：交变磁体中磁振子自旋流的电学注入与矢量操控

  ## 林赛的理解

  这篇工作把我们一直在追的交变磁（ATM）真正拉到了"可输运、可判定"的层面。之前 ATM 的实验判据基本靠能带（ARPES/XMCD），那测的是电子结构，是静态指纹；而这篇论文给的是一个**输运判据**——电学注入产生纵向+横向的"矢量"磁振子自旋流，横纵比在 ATM 中比同对称性 AFM 大两个数量级。对我们而言有三层用处：第一，这是 ATM 材料鉴定的新维度，可直接写进立项依据的"实验可行性"论证；第二，横向自旋流的空间符号反转、由两个手性劈裂模干涉与不等衰减产生——这与我们强场/超快驱动的"双模干涉"物理图像同源，是可以借用的理论语言；第三，Néel 矢量方向作为总开关（θ=π/2 时注入完全淬灭），提示"超快光拨动 Néel 矢量 → 瞬态打开/关闭矢量磁振子流"是一个自然的超快扩展，可作为我们 HHG/阿秒调控交变磁的交叉接口。

  ## 研究问题

  交变磁体（ATM）承载手性劈裂磁振子（chirally split magnons），被寄望于低耗散自旋输运与信息处理，但其**独特的输运特征——实验上识别和操控 ATM 所必需的指纹——仍然缺失**。论文要回答的核心问题是：能否通过重金属界面的电学自旋注入，在 ATM 中产生具有独特对称性和量级的磁振子自旋流输运信号，并以此提供一个可将 ATM 与传统反铁磁（AFM）明确区分的实验判据？

  ## 研究背景

  - ATM 是结合了 AFM 高频动力学与铁磁强自旋响应的新磁相，其晶体-自旋旋转对称性的特殊交织破坏了全局 Kramers 简并，产生非相对论性的电子能带自旋劈裂（已由 XMCD、ARPES 观测，如 MnTe、CrSb、α-Fe₂O₃、RuO₂）。
  - ATM 中预言并观测到**手性劈裂磁振子**（Smejkal 等 PRL 2023；MnTe、hematite 的中子与 RIXS 实验），其本征地绕开了传统 AFM 因磁化补偿导致的磁振子输运低效（后者需大磁场或强自旋轨道耦合才能驱动）。
  - 已有 ATM 磁振子输运效应（如自旋 Nernst 效应）多由温度梯度驱动；而**重金属电学注入**是已在 FM/亚铁磁/AFM 中验证的高效产生纵向磁振子自旋流的方法，其在 ATM 中的行为此前是空白。本文即填补这一空白，提出"Vector Magnonics"概念。

  ## 研究方法

  - **模型体系**：最小正方格子 ATM 模型（晶格常数 a，Néel 矢量 n 与扩散轴 ẑ 成可调夹角 θ）。自旋哈密顿量含：亚格子间反铁磁交换 J₁ > 0（对角近邻）、亚格子内交换 J₂ 与 J′₂（沿晶轴两个方向，二者不等即 J₂ ≠ J′₂ 才产生手性劈裂，J₂ = J′₂ 退化为 AFM）、单轴各向异性 K < 0、外场 H₀ 沿 n。
  - **磁振子谱**：两模手性劈裂，沿 n 携带 ∓ℏ / ±ℏ 自旋，劈裂项 ∝ S(J₂ − J′₂)(γ₁ − γ₂)。
  - **微观量子动理学**：建立含注入、相干演化和弛豫项的磁振子密度矩阵量子动理学方程（∂ₜρ_q = ∂ₜρ|inj + ∂ₜρ|coh + ∂ₜρ|rex），电子-磁振子通过界面 s-d 交换耦合（NM 厚 d），散射振幅矩阵显式依赖 Néel 矢量取向 θ：θ=0 时仅自旋翻转过程；θ=π/2 时自旋守恒与自旋翻转等幅干涉，注入淬灭；任意 θ 时干涉不平衡 → 矢量自旋流。弛豫用 relaxation-time 近似，特征时间 τ_m 对两模取同值。
  - **扩散输运**：注入磁振子沿 ẑ 扩散，解含 v_∥ 依赖的衰减方程，自旋流密度 Jᵢᵅ = Σ_η S_ηᵅ ⊗ v_ηⁱ ρ_ηη。
  - **对称性分析**：用四阶响应张量 Γᵅᵝᵢⱼ（Jᵢᵅ = Γᵅᵝᵢⱼ δμᵝⱼ）对 n 做偶阶展开，结合 M_x、M_z 镜面对称操作约束各分量形式。
  - **材料参数**（取 Cr₂I₂O、Cr₂Br₂O 可实现值）：J₁ = 1 meV，J₂ = −0.15 meV，J′₂ = 0.5 meV，K = −0.02 meV，S = 3/2，a = 1 nm，NM 厚 d = 20 nm；Δμ = 0.4 meV，τ_m = 1 ns，界面交换 J = 15 meV。其他候选材料：LuFeO₃、MnTe。

  ## 主要发现与核心结论

  1. **矢量磁振子自旋流**：重金属电荷电流 I x̂ 经自旋霍尔效应产生 z 极化自旋积累，在 ATM 中注入同时含纵向（沿 ẑ）与可观横向（沿 x̂）分量的磁振子自旋流。
  2. **横向流的空间符号反转**：横向自旋流 Jᶻ⊥ 在有限传播距离处发生符号反转（如 θ = π/6 时），源于两模不等衰减率——模 1 起始小但衰减慢，模 2 起始大但衰减快。这是源于双模干涉与不等衰减的关键量子特征。
  3. **Néel 矢量开关效应**：θ = π/2（n ⊥ ẑ）时两模注入均因完全干涉相消而为零；θ = 0（n ∥ ẑ）时横向速度相消、横向流为零；横向流还在 θ = {π/4, 3π/4, 5π/4, 7π/4} 因两模贡献精确抵消而为零。纵向分量 Jᶻ∥、Jˣ∥ 呈二重与四重对称，横向分量呈双四重对称。即横向流可通过转动 Néel 矢量电学开关。
  4. **ATM 对比 AFM 的巨增强（核心判据）**：横向流在 AFM 中并不被对称性禁戒（n 倾斜时色散各向异性使群速度分布畸变即可产生），但 AFM 中两模横向速度几乎抵消；ATM 中破缺 PT 对称导致的磁振子自旋劈裂造成两模强不对称。响应张量展开系数定量给出：纵系数 ATM 与 AFM 几乎相同（A₁ ≈ A₂，B₁ ≈ B₂），而**横系数 ATM 比 AFM 大近两个数量级（C₁ ≈ 40C₂，D₁ ≈ 40D₂，E₁ ≈ 30E₂）**。因此**横向/纵向自旋流之比在 ATM 中比同对称性 AFM 大两个数量级**，构成区分 ATM 与 AFM 的决定性输运指纹。
  5. **无磁场纵向注入**：不同于温度梯度在无外场 AFM 中驱动不出磁振子流（磁化补偿），电学注入通过吸收模 1、注入模 2 的不对称，可在 AFM（J₂ = J′₂）于 n ∥ ẑ、零磁场下产生纵向自旋流；ATM 中两模群速度差异进一步增强之。
  6. **磁场调控**：沿 Néel 矢量的外场 H₀ 高效调控——纵分量关于 H₀ = 0 近对称，横分量不对称；源于两模频率反向移动（H₀ 增大上移模 1 频率减少吸收、下移模 2 频率增强产生），故 J⊥ = J⊥(v⊥₁) − J⊥(v⊥₂) 对磁场呈反对称响应。
  7. 电学注入的对称性与温度梯度驱动（纵流 A₃cos²θ + B₃sin²θ、横流 sinθcosθ）明显不同，可实验区分驱动机制。

  ## 潜在研究方向

  - 本文横向增强机制依赖最小正方格子模型的 J₂ ≠ J′₂；**真实 ATM 候选材料（Cr₂I₂O、Cr₂Br₂O、LuFeO₃、MnTe）中声子、磁振on-磁振on 散射及 Landau 阻尼的空间各向异性**（如 altermagnet 中巨空间各向异性 Landau 阻尼的已有预言）对两个数量级判据的鲁棒性需逐材料检验。
  - τ_m 对两模取同值是简化假设；若两模寿命差异显著，空间符号反转距离与判据比值都会移动。
  - 判据基于扩散输运近源区（z ≳ 0）；实验上横向信号在微米尺度的可测性、与自旋流探测（逆自旋霍尔等）接口的信噪比未评估。
  - 未涉及时间分辨：Néel 矢量翻转动力学下矢量自旋流的瞬态响应、以及与超快激发（THz/光）耦合的可能性完全开放。
  - 自旋流多向传播可横向连接芯片上不同自旋电子单元——器件级布局与串扰是后续工程问题。

  ## 与林赛研究的关联

  - **交变磁（方向核心）**：本文给 ATM 提供了首个输运层面的定量判据（横纵比大两个数量级，系数比 C₁/C₂ ≈ D₁/D₂ ≈ 40、E₁/E₂ ≈ 30），可直接支撑我们课题中 ATM 材料鉴定与"非相对论自旋劈裂的输运后果"论证。
  - **强场驱动 / HHG**：横向流由两个手性劈裂磁振子模的干涉与不等衰减决定，J⊥ = J⊥(v⊥₁) − J⊥(v⊥₂) 的图像与强场过程中多轨道/多支路干涉的物理语言同源；Néel 矢量作为总开关（θ 转动即开关流），暗示**超快光场拨动 Néel 矢量 → 泵浦-探测读出矢量磁振子流开启/关断**是一条自然的超快扩展路线。
  - **莫尔 / 量子几何**：本文对称性分析范式（响应张量对磁序方向的偶阶展开 + 镜面对称约束，TensorSymmetry 工具链）可直接移植到莫尔体系磁振子/激子输运的对称性分类；J₂ ≠ J′₂ 的各向异性交换劈裂机制与莫尔超晶格中各向异性耦合调控磁振子谱的思路呼应。
  - **阿秒 / 时间分辨**：横向自旋流的符号反转距离由两模衰减率差设定，提供了一个内禀的"相位-传播"标尺，未来可做时间分辨输运实验（含反演破坏 PT 对称体系）的方法学参照。

**原理**：重金属界面电学自旋注入（电荷电流经自旋霍尔效应产生 z 极化自旋积累）在交变磁体（ATM）中产生同时含纵向与可观横向分量的矢量磁振子自旋流——填补'ATM 磁振子输运指纹缺失'的空白；微观机制：界面 s-d 交换散射振幅显式依赖 Néel 矢量取向 θ（θ=0 仅自旋翻转、θ=π/2 自旋守恒与翻转等幅干涉淬灭注入），横向流空间符号反转源于两个手性劈裂磁振子模的不等衰减（模 1 起始小衰减慢、模 2 起始大衰减快）；核心判据：响应张量展开给出纵系数 ATM 与 AFM 几乎相同而横系数大近两个数量级（C₁ ≈ 40C₂、D₁ ≈ 40D₂、E₁ ≈ 30E₂）——横向/纵向自旋流之比在 ATM 中比同对称性 AFM 大两个数量级，构成区分 ATM 与 AFM 的决定性输运指纹；Néel 矢量为总开关（θ=π/2 注入完全淬灭；θ={π/4, 3π/4, 5π/4, 7π/4} 横向流精确抵消）；沿 Néel 矢量的外场对横分量呈反对称响应（两模频率反向移动）。
