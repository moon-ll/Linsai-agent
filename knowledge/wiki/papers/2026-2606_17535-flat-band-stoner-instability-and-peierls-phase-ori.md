• # Flat-Band Stoner Instability and Peierls-Phase Origin of the Transdimensional Anomalous Hall Effect in Rhombohedral Graphite

  ## 林赛的理解

  这篇工作把最近在九层菱方石墨（nine-layer rhombohedral graphite）里观测到的“跨维度反常霍尔效应”（TDAHE）锚定到了两个非常明确的微观机制上：一个是平带 Stoner 不稳定性导致的自旋-能谷锁定铁磁序，另一个是层间跃迁 Peierls 相给出的面内轨道 Zeeman 耦合。对我来说，这意味着 TDAHE 并不需要假设某种全新的拓扑序或外场对称性破缺；它是一个强关联平带体系里，由相互作用自发产生能谷极化、再由量子几何（Berry 曲率）把面内磁场耦合进输运的“自然结果”。特别值得注意的是，面内和面外霍尔响应共享同一个序参量 η(T)，因此它们必须在同一个 T_c 消失——这是一个可以定量检验的强预言。文中大量数值（g_orb、Uρ、R_xy、T_c 等）都和实验在同一量级，说明这个理论框架是可操作的。对我组正在探索的强场驱动、莫尔与量子几何方向而言，它提供了一个把“相互作用自发破缺”与“Berry 曲率输运”直接对接的范例。

  ## 研究问题

  论文要回答的核心问题是：九层菱方石墨中同时受面外磁场（B⊥）和面内磁场（B∥）驱动、且具有共同居里温度 T_c ≈ 1.6 K 的跨维度反常霍尔效应（TDAHE）的微观起源是什么？具体而言，为什么两种几何构型完全不同的磁场能在同一材料里产生滞后霍尔信号？为什么它们的 T_c、载流子浓度依赖和门电压依赖完全一致？一个完整的理论必须同时解释：(i) 时间反演对称性的自发破缺来源，(ii) 面内磁场耦合到霍尔响应的微观通道，(iii) 层数阈值与相窗口，(iv) 为什么两种响应的比值与相互作用强度无关。

  ## 研究背景

  反常霍尔效应（AHE）通常被理解为二维现象：Berry 曲率位于电子运动平面，因此只与面外轨道磁化耦合。然而，Li 等人在九层菱方石墨器件中观测到 TDAHE——面内磁场也能产生滞后霍尔电阻，且面内矫顽场（160–500 mT）比面外矫顽场（~3 mT）大两个数量级，却共享同一 T_c 与门依赖。此前工作存在明显缺口：Li 等人的 Hartree-Fock 计算给出了月牙形 Fermi 面和 ~2.2 μ_B/electron 的面内轨道磁化，但没有定量理论；Zheng 等人证明了层间相干可通过 Berry 连接磁化率产生本征平面霍尔效应，但他们的非相互作用框架是“手动”破缺对称性，没有序参量、没有自发相变、无法解释 T_c、层数阈值和门调控的起始行为；DMFT 工作则排除了通过准粒子权重 Z 的 1/Z² 增强来解释 AHE 的可能性。本文正是在这一背景下，提出一个同时包含自发对称性破缺与面内场耦合的微观理论。

  ## 研究方法

  研究采用多尺度理论方法，核心材料体系为 N 层 ABC 堆叠菱方石墨（rhombohedral graphite），以 Slater-Koster 紧束缚模型为出发点：

  - **哈密顿量**：H(k) = H_intra(k) + H_inter + H_D，其中 γ0 = 3.16 eV 为层内跃迁，γ1 = 0.39 eV 为主导层间跃迁，γ3 = 0.315 eV 为三角翘曲，γ4 = 0.044 eV；位移场 D 产生能隙 m = eDd0/2，d0 = 0.335 nm。
  - **低能有效模型**：在 K 点附近投影到 A1、B_N 两个表面格点，得到两带模型 H_eff = mσ_z + v_eff P^N σ_+ + v_eff^* P^{*N} σ_-，其中 v_eff = (γ0 a√3/2)^N / γ1^{N-1}，P = ξp_x - i p_y。
  - **Berry 曲率与本征 AHC**：由 Kubo 公式得到 Ω(p) = N² m v_eff² p^{2N-2} / [2(m² + v_eff² p^{2N})^{3/2}]，进而 σ_int_xy = (e²/h)·N m/(2ε_F)（每个能谷每个自旋）。
  - **相互作用与 Stoner 不稳定性**：Hubbard U 满足广义 Stoner 判据 U ρ(ε_F) > 1，驱动自旋-能谷锁定铁磁序；同时引入 intervalley 交换 V_iv/U ≈ 1（constrained-RPA 值），决定能谷极化是否出现。
  - **面内场耦合**：通过 Peierls 替代 k_y^{(l)} = k_y + (eB_x d0/ℏ)(l - (N-1)/2)，推导出有效能隙移动 δm = g_orb B∥，g_orb = e d0 v_F (N-1)/2。
  - **自洽计算**：完整 2N 带 Hartree-Fock 计算 valley 极化 η(T)、T_MF_c 和 R_xy；并用 DMFT 验证本征 AHC 与 Z 无关；用 2D Ising 临界涨落解释 T_c 从 2.2 K 压低到 1.6 K。

  ## 主要发现与核心结论

  1. **单一序参量框架**：TDAHE 由能谷极化 η ∈ [0,1] 统一描述。总 AHC 为 σ_tot_xy = η·g_s·σ_int_xy，其中 g_s = 2；面内场诱导的平面霍尔电导率为 σ_PHE_xy = η g_s (e²/h)·N g_orb B∥/(2ε_F)。由于两者都正比于 η(T)，它们在 η→0 的同一个温度 T_c 消失，解释了实验上两种霍尔信号共享 T_c ≈ 1.6 K。

  2. **层数阈值与饱和**：完整 2N 带 Hartree-Fock 计算显示，能谷极化在 N ≥ 8 时突然出现（N = 7 时 η = 0，N = 8 时 η → 1），与实验的九层器件一致。具体数值：
     - N = 3：g_orb = 0.34 meV/T，Uρ = 0.55，η = 0
     - N = 5：g_orb = 0.69 meV/T，Uρ = 7.31，η = 0
     - N = 7：g_orb = 1.03 meV/T，Uρ = 8.90，η = 0
     - N = 8：g_orb = 1.20 meV/T，Uρ = 8.88，η = 1.00，σ_tot = 8.0 e²/h，R_xy = 1.6 kΩ
     - N = 9：g_orb = 1.37 meV/T，Uρ = 8.89，η = 1.00，σ_tot = 9.0 e²/h，R_xy = 1.6 kΩ
     - N = 11：g_orb = 1.71 meV/T，Uρ = 8.88，η = 1.00，σ_tot = 11.0 e²/h，R_xy = 1.5 kΩ

  3. **关键能量与温度尺度**：N = 9、D = 0.85 V/nm 时，位移场能隙 m = 142 meV；平均场转变温度 T_MF_c ≈ 2.2 K；考虑 2D Ising 临界涨落后压低为 T_c ≈ 1.6 K，与实验一致；每个自旋-能谷通道的 Stoner 乘积 Uρ ≈ 2.2。

  4. **面内场耦合强度**：N = 9 时 g_orb = 1.37 meV/T，g_orb/μ_B ≈ 24，比通常自旋 g 因子大约一个量级。在 B∥ = 0.3 T、m = 142 meV 时，能隙移动 δm = 0.41 meV，σ_PHE_xy/σ_tot_xy = g_orb B∥/m ≈ 0.3%。该比值独立于 η、U 和温度，是一个纯单粒子预言。

  5. **Intervalley 交换的作用**：V_iv/U ≈ 1 时体系处于自旋-能谷锁定铁磁态（SVM）；V_iv/U ≲ 0.65 时能谷极化消失。但 T_c 对 V_iv/U 不敏感：当 V_iv/U ≳ 0.75 时 T_MF_c 饱和在 ≈ 2.2 K，因此无论是 constrained-RPA（≈1）还是常规屏蔽（≈0.3）值，N = 9 都处于相同有序相。

  6. **密度依赖与电切换**：D = 0.9 V/nm、T = 0.5 K 时，η 在 n ≲ 1.8×10¹² cm⁻² 饱和到 1；在 n ≈ 1.83×10¹² cm⁻² 出现 ΔR_xy 符号反转，对应两个简并 SVM 解 ±η 之间的 K ↔ K′ 能谷味切换；实验上滞后回线在 n ≈ 2.0×10¹² cm⁻² 处急剧坍缩进入 quarter-metal 相。

  7. **DMFT 验证**：Hubbard-I DMFT 计算确认 σ_int_xy(Z)/σ_int_xy(bare) = 1 在 10⁻⁸ 精度内成立（U = 0.5–5.0 eV），排除了关联增强 AHE 的 1/Z² 图像。

  8. **月牙形 Fermi 面的对称性选择**：在 m = 1 角向通道引入 C3 破缺自能 Σ_A1(k) = Δ cos θ_k，可在 V_1 > V_1c ≈ 1.7 eV（解析）/≈2.8 eV（数值）时得到月牙形 Fermi 面；对称性选择 m = 1 通道（对角交换线性耦合），而 m = 2 仅给出椭圆。重要的是，月牙形与环形 Fermi 面之间的 σ_xy 仅变化 1.6%（0.495 vs 0.487 e²/h 每个能谷/自旋），说明霍尔电导对 Fermi 面几何不敏感。

  9. **临界涨落与 2D Ising 普适类**：平带刚度 c_v 极小，关联长度 ξ0 ≈ 0.35 nm ≪ N d0 = 3.0 nm，因此转变是二维的并受 2D Ising 临界涨落支配；Monte Carlo 给出 T_c ∈ [1.34, 2.05] K（中间作用范围 ≈1.9 K），实验 1.6 K 落在此区间下半部分。

  ## 潜在研究方向

  1. **层数 N = 8 的边界测试**：理论预言能谷极化在 N = 7→8 之间出现跳变，N = 8 是测试这一阈值的关键样品。同时预言 σ_tot ∝ N、g_orb ∝ (N-1)，可通过系统改变层数验证。

  2. **面内场角度各向同性**：理论预言 TDAHE 幅度与面内场在样品平面内的方向无关，因为 M_z 始终垂直于层面。可用旋转面内磁场实验直接检验。

  3. **莫尔增强**：在莫尔菱方石墨中， miniband DOS 增强约 a²_moire/a² ~ 10²，预言 T_c 升高、TDAHE 窗口扩大，值得实验探索。

  4. **非平衡与外场驱动**：文中所有结果均为平衡/线性响应。强场驱动下（例如阿秒脉冲或 THz 驱动）是否能瞬时调控 η、 Berry 曲率分布以及 TDAHE 滞后，是一个开放问题。

  5. **八层菱方石墨中的面内场诱导 Chern 数反转**：实验报道 N = 8 中在 ~0.4 T 出现 Chern 数反转，但本文两带模型预言 B_rev ~ m/g_orb ≈ 118 T，表明莫尔超晶格在该体系中可能引入了完全不同的机制（自旋-轨道辅助能带翻转或相互作用驱动的能级交叉），需未来研究。

  6. **动量依赖 intervalley 交换的 sign-free QMC**：作者指出，最小均匀相互作用格点上的 two-valley Hubbard 模型在平均场能标上未发展出长程能谷序；实现动量依赖 intervalley 交换的无符号量子蒙特卡洛是下一步。

  7. **精确测量 σ_PHE_xy/σ_tot_xy 比值**：该比值 ≈0.3%（B∥ = 0.3 T）是纯单粒子预言，不依赖 η 或 U。如果能以更高精度测量其温度与掺杂依赖，将直接检验理论的核心结构。

  8. **动态与超快响应**：将 Stoner 序参量 η 的动力学与超快光学探针（如 HHG、瞬态磁光克尔）结合，可望直接观测 η 的熔解与恢复时间尺度。

  ## 与林赛研究的关联

  这项工作与本组方向的接口非常具体：

  - **量子几何与 Berry 曲率**：σ_int_xy 完全由两带模型的 Berry 曲率积分给出，N² 因子来自速度算符 v_x,y ∝ N P^{N-1}。我们研究强场驱动下的量子几何响应时，可以直接借用这套低能有效模型和 Berry 曲率公式。
  - **强场驱动与非平衡**：文中 g_orb B∥/m ≈ 0.3% 是一个静态、线性响应的结果。若用强 THz 或近红外脉冲驱动 N 层菱方石墨，Peierls 相可能被周期性调制，从而在超快时间尺度上产生可分辨的 σ_PHE_xy 动态；这与我们“强场驱动量子物态”的方向天然衔接。
  - **莫尔体系**：作者明确提到莫尔菱方石墨中 miniband DOS 增强 ~10² 会提升 T_c 并扩展 TDAHE 窗口。我组对莫尔材料中的量子几何和关联效应感兴趣，可把该预言作为莫尔-强场交叉实验的设计依据。
  - **阿秒与超快磁性**：自旋-能谷锁定铁磁序的 η(T) 是一个可以用阿秒磁光谱或高次谐波产生（HHG）探测的序参量；特别是 η→0 时的临界慢化和涨落，对超快探针高度敏感。
  - **交变磁（altermagnetism）与自旋-能谷锁定**：虽然文中未使用交变磁术语，但 K/K′ 能谷味作为 Z₂ 序参量、其空间分布与自旋锁定，与交变磁中 d 波自旋密度波的某些特征有概念重叠，可作为类比和理论迁移的素材。
