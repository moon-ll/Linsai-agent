• # Revealing the anisotropic charge-density-wave order of TiSe2 through high harmonic generation

  ## 林赛的理解

  这篇工作对我的价值非常直接：它证明了**HHG 偏振依赖谱可以作为序参量的"指纹读出器"**——TiSe2 低温 CDW 相中三个 CDW 序参量之间仅 **0.1 meV**（∆Q1=0.1148 eV vs ∆Q2=0.1147 eV vs ∆Q3=0.1146 eV）的微弱各向异性，就能在 H5 的偏振角依赖曲线上放大成"左峰高于右峰"的强不对称。这正是我们"序参量超快读出"课题（general-order-parameter-ultrafast-readout-20260727）最需要的范式例证：宏观对称性信息通过非微扰高次谐波被放大读出，且是非平衡探测、本征的超快。更关键的是，它示范了一条**实验现象 → 现象学平均场模型 → 反演序参量对称性**的完整方法论链——他们没有做 DFT 级的严格计算，而是用一个 2D 双带（Se 4p 价带 + Ti 3d 导带）tight-binding + 自洽 CDW 平均场模型就复现了实验的 H3/H5/H7 全部偏振行为（单峰/双峰/单峰）+ 峰间不对称 + 质心移动。这告诉我们：把 HHG 当作序参量探针时，"模型要够简单才能反演"，而非越精确越好。

  实操层面有三个可移植的结论：①几何效应必须剔除——正常入射几何下 HHG 谱呈六重对称，而 45° 入射（实验几何）投影后场振幅随偏振角变化，才把 H3/H7 压成单峰、把 H5 劈成双峰；**解释实验时必须先把激光几何建模进去**，否则会把几何变形误读成材料对称性。②峰劈裂（H5）只能在"ΓK 方向为谷"的本征谱上出现，单峰无法区分本征峰与本征谷——这是偏振扫描测量的信息论分辨力。③小的晶体轴向偏置 α（实验测 7° ± 2°，模拟取 5°）足以解释高温相的弱不对称，但低温相的强不对称**必须**来自序参量本身的各向异性——两相的不对称来源可以分离，这是温度分辨测量的额外收益。

  ## 研究问题

  为实验观测到的 TiSe2 高次谐波（HHG）谱的偏振依赖行为提供理论解释：为何 H3 和 H7 随偏振角呈单峰、而 H5 劈裂为双峰；为何低温 CDW 相出现远强于高温半金属相的 H5 双峰间不对称。更深层的中心问题是：**HHG 谱对 CDW 序参量（尤其是其各向异性）的敏感性能否用来反演 CDW 序的本质**。

  ## 研究背景

  - TiSe2 是过渡金属硫族化合物，高温半金属/半导体相（晶格常数 a = 3.54 Å）在 Tc ≈ 200 K 转变为 2×2×2 公度 CDW 态。其 CDW 机制存在持续争论：电子-声子耦合（Jahn-Teller 效应）vs 激子凝聚 [49-53]；铜插层、加压或载流子掺杂可使 CDW 熔融并诱发超导 [43-48]。澄清 CDW 序的性质对该材料意义重大。
  - HHG 从原子/分子气体扩展到固体后，已成为探测材料电子动力学、能带性质与对称性的超快光学手段 [5-14]；在强关联体系（Mott 绝缘体 [33-38]、Kitaev 自旋液体 [39]、高温超导 [40]）中，HHG 谱可作为量子相变的光学探针。
  - 直接前驱实验 [I. Tyulnev et al., Commun. Mater. 6, 152 (2025)]（即 Ref. [54]）测量了 TiSe2 的 HHG 谱，发现其对 CDW 序高度敏感，且随入射光偏振角呈现明显不对称行为，为研究 CDW 相变提供了新视角。本文即为该实验的理论解释。

  ## 研究方法

  - **模型**：二维现象学平均场模型。因 TiSe2 层间为范德华间隙、激光主要与表面层相互作用，取单层 2D 哈密顿量。最小模型只含最高占据价带（Se 4p，Γ 点空穴口袋）与最低未占据导带（Ti 3d，M 点三个电子口袋），两带小重叠形成半金属。CDW 以平均场序参量 ∆(±Q1,2,3)（|Q1|=|Q2|=|Q3|=ΓM，三重-Q）耦合价带空穴口袋与导带电子口袋，折叠布里渊区后在约化布里渊区重写为 8×8 动量依赖哈密顿量（基矢含 ak, bk, ak+Q1…等 8 个分量）。
  - **能带**：价带/导带色散取自 Ref. [57] 的 tight-binding 模型（附录 A 给出全部 Slater-Koster 参数，如 εdε = 0.2 eV、εdγ − εdε = 1.112 eV、t(pdσ) = −1.422 eV 等 12 个参数）。
  - **序参量温度依赖**：∆(T) = ∆0 √(1 − (T/Tc)²)，∆0 = 115 meV。
  - **HHG 计算**：最小耦合 k → k + eA(t)/ℏ，在 Bloch 基下对密度矩阵解含时薛定谔方程 iℏ dρ/dt = [H(k+eA(t)/ℏ; {∆Qi(t)}), ρ]，其中 ∆Qi(t) = (UQi/V) Σk Tr[ρ a†k+Qi bk] 随时间自洽演化，UQi 为现象学温度依赖参数。引入唯象退相干：每步 δt 后变换到瞬时哈密顿量对角化基，非对角元乘 e^(−δt/τ)。
  - **激光参数**：ℏω = 0.4 eV、ncyc = 8、A0 = 1.2 ℏ/ea（对应 E0 = A0ω ≈ 0.14 V/Å；实验为 100 fs、中心波长 3.2 µm、E0 ≈ 0.08 V/Å）。比较两种几何：①正常入射（本征材料谱）；②实验实际的 45° 入射（矢量势投影到材料平面，面内振幅随偏振角变化），并引入晶体轴向偏置角 α。
  - 谐波强度由速度期望值沿激光方向分量的傅里叶变换给出：P(ω) = ω²|FT[v·nA]|²。

  ## 主要发现与核心结论

  1. **正常入射几何（300 K 半金属相，∆Qi = 0）**：HHG 谱关于偏振角对称，每阶谐波在 60° 间隔处有三个峰，反映 TiSe2 六重晶体对称；主要来自 Γ 点空穴口袋沿价带的运动，反映 ΓK 与 ΓM 方向色散非线性的差异。此行为与实验不符。
  2. **45° 入射几何（高温相）**：投影导致面内场强在 θ = 90°（p 偏振）最大、θ = 0° 最小，使 H3、H7 变成 θ ≈ 90° 附近的**单峰**，H5 劈裂为 θ = 30° 和 θ = 120°（间隔 60°）的**对称双峰**，与实验 [54]（黑线）吻合。特别地，H5 的双峰劈裂唯一地表明本征正常入射谱在 θ = 90° 处为谷——单峰情形无法区分本征峰与本征谷。
  3. **高温相的弱不对称**：实验激光相对晶体轴有约 7° ± 2° 的偏置；模拟中取 α = 5° 后拟合良好，H5 左峰低于右峰，质心移动也被复现。说明高温相不对称可由晶体轴偏置单独解释。作者还论证激光椭圆率太小不足以产生可见差异；无序、残余应变、表面不均匀性导致的有效不对称能带也不是必需的。
  4. **低温 CDW 相（14 K）**：各向同性三重-Q 序参量 ∆Q1 = ∆Q2 = ∆Q3 = 0.1147 eV（UQ1 = UQ2 = UQ3 = −1.80935 eV）+ α = 5° 只能给出"左峰低于右峰"，与实验（左峰高于右峰，黑线）**相反**。只有引入序参量各向异性——∆Q1 = 0.1148 eV、∆Q2 = 0.1147 eV、∆Q3 = 0.1146 eV，对应 UQ1 = −1.80965 eV、UQ2 = −1.80935 eV、UQ3 = −1.80905 eV——才复现实验的 H5 左峰高于右峰，同时复现 H5、H7 质心左移与 H3 质心右移（略高估）。选择 ∆Q1 > ∆Q3（Q1、Q3 关于 θ = 90° 对称）使 θ < 90° 区域带隙更大，增强 H5、H7 等高阶、抑制 H3 等低阶。**结论：低温相的强 HHG 不对称由 CDW 序参量的微弱各向异性主导，压倒晶体轴偏置效应**；该各向异性可能源于低温下应变/无序导致的三个 Ti-Se 位移方向不同的畸变。
  5. **稳定性检验**：等向序参量下，激光频率 ℏω = 0.35/0.40/0.45 eV 与振幅 A0 = 1.1/1.2/1.3 ℏ/ea 范围内峰行为稳健；固定偏置 α = 5° 下，三组不同各向异性强度（如 (∆Q1,∆Q2,∆Q3) = (0.1151, 0.1147, 0.1144) eV，对应 U = (−1.81035, −1.80935, −1.80835) eV）下不对称行为均保持稳健（Fig. 6，展示 40° ≤ θ ≤ 120° 区间）。

  ## 潜在研究方向

  - **模型层面的局限**（作者自陈）：tight-binding 能带只抓住 DFT 能带的主要特征，可能在某些偏振角高估或低估 HHG 强度；多轨道、多带效应被忽略，可能对 HHG 谱有非平凡影响。模拟的 H3/H5 强度随偏振角的变化不如实验显著，可能源于模型局限或实验实际入射角与 45° 略有偏差。
  - **CDW 各向异性的微观起源未解**：序参量各向异性被归结为"可能的应变/无序"，但实验上各向异性的确切来源（应变 onset 与 CDW 相变的关联）需要独立验证；本文是现象学拟合，未从微观机制推导各向异性。
  - **CDW 机制之争未决**：Jahn-Teller（电子-声子耦合）vs 激子凝聚的争论本文悬置——模型刻意忽略微观机制，只研究 HHG 响应。HHG 是否能区分这两种 CDW 起源是开放问题。
  - **各向异性符号与大小的定量反演**：本文展示的是"定性/半定量"复现；如何从 HHG 谱定量提取三个 ∆Qi 的相对大小（而不仅是序）是下一步；中心质心移动的略高估说明模型仍需精化。
  - **推广方向**：HHG 偏振谱学作为读出 CDW 序各向异性的一般工具，可推广到其它多-Q 序体系；时间分辨版本（泵浦-探测 HHG 偏振谱）可能追踪 CDW 熔化动力学，是自然的延伸。

  ## 与林赛研究的关联

  - **序参量超快读出课题（general-order-parameter-ultrafast-readout-20260727）的直接方法论样板**：HHG 偏振扫描 = 序参量对称性的非平衡光学读出。0.1 meV 级序参量各向异性 → H5 双峰不对称的可测放大，这是"HHG 作为序参量探针"灵敏度的一个量化锚点。
  - **强场驱动 + HHG**：全文基于半导体 Bloch/密度矩阵形式的含时薛定谔方程，与我们组的强场驱动数值框架同构；其退相干处理（瞬时绝热基 + e^(−δt/τ) 衰减）可直接移植。
  - **交变磁/莫尔方向的接口**：多-Q 序参量（三重-Q）与单个序参量的 HHG 响应区分，对研究具有多波矢序的体系（包括莫尔超晶格中多个重建波矢、交变磁体的多-Q 磁序）是现成模板；8×8 折叠布里渊区哈密顿量的构造方式可复用于莫尔 miniband 的 HHG 建模。
  - **实验几何学警示**：45° 入射投影效应是解释一切偏振依赖数据的第一道工序——我们在设计自己的偏振分辨 HHG 实验（HHG、阿秒、强场驱动方向）时必须先把入射几何的振幅调制建模进去，否则对称性指认会出错。
  - **温度分辨测量的两相分解**：高温相不对称由晶体轴偏置解释、低温相由序参量各向异性解释——说明温度依赖的偏振不对称谱可以把"外因（几何）"与"内因（序）"分离，这一判据可直接写进我们课题的实验设计。
