# HHK：面向硬件的跨部位 PPG 密钥生成架构（BAN 会话密钥）精读笔记

## 林赛的理解

先说实话：这篇论文是被我们的导入流水线误投进来的——原始卡片上标着“HHG光谱学”，但 HHK 是 Hardware-oriented PPG Key generation 的缩写，和高次谐波生成没有任何关系，多半是 hermes 的关键词匹配把 HHK 当成了 HHG。我在这里先纠正归类，避免它污染 HHG 方向的知识图谱。deepxiv 0.33 的评分也说明它对我们主线价值有限。

不过既然读了，从我的视角看它仍有两点方法论上的共鸣。第一，“从两个观测同一物理过程、但各自带有独立噪声的信道中提取共享密钥”，本质上就是 QKD 后处理里信息协调（reconciliation）的物理层版本——用极化码做 fuzzy commitment，正是我们看 QKD 实验论文时熟悉的套路，只不过这里的“信道”是人体脉搏波的传导，而非光纤中的光子。第二，跨部位心跳时间戳对齐，处理的是头部、手腕、脚踝之间脉搏传导时间差异加上运动伪影下的时间对准问题——这与我们每天面对的时钟恢复、时序抖动稳定、跨仪器互相关对齐在数学结构上是同一类问题。此外，“无乘法器、无 BRAM 的 RTL 数据通路”这种设计约束，对我们自己搭建高重复频率系统的实时采集板卡是有参考价值的工程模式。

结论：留作外围方法学参考，不进入 HHG 主线的 proposal 素材。

## 核心要点

- **问题定义**：体域网（BAN）中的可穿戴节点计算与能量预算极度受限，传统公钥交换开销过大，需要超轻量级的会话密钥建立机制。
- **信号链路**：在多个身体部位（头、腕、踝）用绿光 PPG 提取心搏间期（IBI）→ 跨部位心跳时间戳对齐 → Gray 编码的等频量化 → 码率 1/3 的极化码模糊承诺（N=128, K=42）协调残余时序失配。
- **硬件实现**：Xilinx XC7Z020 上综合后占用 18,760 LUT / 20,971 FF，**不用任何乘法器和片上存储**；单次密钥生成 48 µJ，120 秒采集窗口内平均功耗 0.4 µW。
- **实验验证**：16 名被试、216 小时真实日常活动数据（头/腕/踝三部位），原始 IBI 位一致率 86.0–90.1%，最终密钥一致率仅 51.3–69.8%。
- **宣称的贡献**：首个在真实日常活动数据上跨多身体部位验证的可综合 RTL 密钥生成架构。

## 实验/研究关联

- **与 QKD 后处理的同构性**：量化 + 纠错码协调 + fuzzy commitment 的流水线，与 QKD 中的 sifting→reconciliation→privacy amplification 高度同构。值得注意的是本文似乎止步于 fuzzy commitment，未见隐私放大和熵估计环节（待核对原文）——这对我们理解“物理信道密钥”的安全边界是反面教材式的有用。
- **跨部位时间对齐 ↔ 我们的时序问题**：脉搏传导时间在头-踝间可达上百毫秒量级且随运动漂移，beat 时间戳对齐本质上是在低信噪比、非平稳时延下做时钟恢复——与我们做 attosecond streaking 轨迹对齐、dual-comb 互相关校正面临的是同类的“对齐容差 vs 信息保留”权衡。
- **无乘法器 RTL 设计模式**：纯 LUT/FF、避免 DSP 和 BRAM 的数据通路设计，对我们组里高重复频率系统的实时频谱分箱、boxcar 时序固件是一个可借鉴的资源约束思路。
- **对本组实际相关性**低。若未来涉足 comb-based 密钥分发或物理熵源随机数（激光噪声 RNG 之类），这篇可作为“量化 + 极化码协调”的工程化模板引用。已在知识库中标记为误归类，建议重打标签并降低优先级。

## 开放问题

- **熵的根本性问题**：心率是高度可预测的生理量（约 60–100 bpm），每个心搏的 IBI 到底携带多少最小熵？全文若没有熵估计和隐私放大，仅靠 fuzzy commitment，密钥可能对知道心率统计的攻击者可猜测。
- **攻击者模型薄弱**：远程 rPPG（摄像头提取心率）或攻击者自带 PPG/ECG 传感器贴近受害者，能否以足够精度重建 IBI 序列？文中未见讨论。
- **51–70% 的密钥一致率在实用层面偏低**：失败重试在 120 秒窗口上的代价是什么？有效密钥生成速率到底多少？
- **运动伪影鲁棒性**：日常活动中跨部位对齐的失效模式、脉冲传导时间的个体差异与动态变化如何处理？16 名被试的样本量偏小。
- **跨领域迁移**：同一“量化 + 协调”框架能否用于我们场景中相关的物理信道——例如同一台激光器驱动的两个探测站之间由共同噪声（泵浦涨落、CEP 涨落）承载的共享熵？
- **文献核查**：arXiv 编号 2605.24991 与“2026 年单作者短文”的组合需要核实来源可靠性，进口卡片可能有元数据错误。
