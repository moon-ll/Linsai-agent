# K壳层电子碰撞电离截面实验汇编（Limandri et al., 2025）

## 林赛的理解

第一眼看到这篇会觉得它"和我们组的方向没什么关系"——原子物理基础数据嘛，和超快光学有什么关系？但我读完之后判断，这篇工作对我们这条线其实有"被低估"的价值，原因有三：

第一，内壳层电离在我们组的几个主线里其实是**隐藏的瓶颈**。attosecond streaking 我们主要靠 K 壳层（或 L 壳层）的瞬态布居变化来反推电场波形；高次谐波里近阈谐波及 inner-shell HHG 也越来越受关注；固体高谐波里 K 壳层空穴的退激过程直接影响谐波相位。这些环节中，**K 壳层电离的速率/截面**是决定时序与能谱的最底层输入参数。

第二，电子碰撞电离截面与光子（X 射线）碰撞电离截面**共享相同的物理图像**（一阶微扰、Born 近似、Eikonal 近似等都通用）。换句话说，这批 2509 个实验点本质上也是在**约束内壳层原子结构**——这正是我们做 TDDFT 模拟、含时 Hartree-Fock、强场 S-matrix 计算时最缺的基准。

第三，这种数据集真正的"用法"不是直接拿来画图，而是把它作为**校验工具**——当我们提出一个内壳层超快过程的新机制时，能不能用实验截面反推出的跃迁偶极矩/振子强度来定量自洽？这是我带学生时反复强调的："先回到经典基准再谈新现象"。

所以这篇我倾向把它放进组里的"数据基础"档案，而不是当冷门文献跳过。

## 核心要点

- **数据规模**：汇编了 **H 到 U 共 2509 个 K 壳层电子碰撞电离截面实验数据点**，时间跨度 **1930 年至今约 95 年**的 publications，是该领域迄今最系统化的实验数据库。
- **物理过程**：入射电子与靶原子 K 壳层电子发生非弹性碰撞，使 K 壳层电子被电离。这是**最简单、最干净的内壳层电离通道**，没有共振激发、Auger 等干扰（尽管 Auger 退激在后续很重要）。
- **数据可用性**：这种大规模汇编工作真正的价值在于**统一了不同年代、不同实验室、不同方法的截面定义与归一化**，使得跨文献比较成为可能。
- **典型应用场景**：X 射线荧光产额校正、PIXE（粒子诱发 X 射线发射）定量分析、内壳层电离理论模型（BEB、ECPSSR、IAEA 等）基准测试。
- **方法学**：需要追溯原始文献，逐一审核实验条件、归一化方式、靶厚度修正、检测立体角修正等，把不同来源的数据放在同一标度上——这是数据汇编工作的核心技术难点。

## 实验/研究关联

**对我们组的直接关联点**：

1. **Attosecond streaking 中的 K 壳层空穴产生**
   - 在强场电离的极端条件下（I > 10¹⁷ W/cm²），K 壳层电子也能被直接拉出，产生瞬态空穴。这个过程的"速率"我们目前只能用 TDDFT 估算，缺少干净实验基准。这篇汇编的截面数据可以通过 Bethe-Born 近似转化为**广义振子强度 (GOS)**，进而约束我们的原子响应函数。

2. **固体高谐波中的内壳层贡献**
   - 最近 Ghimire 等人的工作表明中高 Z 材料的 K 壳层对高次谐波有显著贡献。我们模拟时需要可靠的 K 壳层极化率，这可以从汇编的电子碰撞数据中提取。

3. **XUV/软 X 射线阿秒光源的反演**
   - 我们做 attosecond transient absorption 时，K 边附近的吸收边是**直接给出 K 壳层空穴动力学**的探针。但吸收边的强度绝对定标需要理论振子强度，而电子碰撞数据正是该振子强度的独立实验检验。

4. **作为我们 code 的基准模块**
   - 建议把我们组用的 few-level 模型（特别是含 K 壳层的版本）用这批截面数据做一次系统校验。Limandri 等人的数据可以直接作为**输入比较文件**。

## 开放问题

读这篇时我想追问的几个问题（部分可能要回到原文/补充材料里去看）：

1. **电子 vs 光子截面的换算可靠性**：
   - 论文里是否给出了与**光子碰撞截面**（也就是我们常用的光电离截面）的定量比较？Bethe 理论下两者通过广义振子强度有解析关系，但**高 Z、低入射能区**的非偶极与相对论修正到什么程度？这一点对我们把电子数据外推到 X 射线情形很关键。

2. **1930–1970 老数据的权重问题**：
   - 95 年的数据汇编里，老数据的相对论修正、靶厚度修正、检测效率校正的标准和现代实验差别很大。Limandri 等人采用什么样的**权重策略**？是等权、按不确定度加权、还是按发表期刊加权？这直接影响我们用这批数据做拟合时的可信区间。

3. **近阈值区域的数据密度**：
   - 强场超快里我们特别关心**近阈值**（几倍阈值能量以下）行为，因为这里是隧穿-碰撞连续过渡区。这篇汇编在 K 壳层电离阈值附近（典型几百 eV 到几 keV）的数据密度如何？如果近阈值点偏少，对我们做内壳层隧穿理论验证是个限制。

4. **分子与固体靶的缺失**：
   - 汇编只覆盖原子（H 到 U），但我们组的研究对象很多是**分子和固体**。分子环境下的 K 壳层截面与孤立原子有多大差别？论文是否讨论了这种外推的不确定性？如果没有，是个值得我们自己补的"暗物质"。

5. **与最新机器学习原子数据库（FAIR 原则）的兼容性**：
   - 这批数据是否以可机读格式发布？是否带有 DOI 与元数据？我们组的 code 如果要自动调用，需要的是 API 或标准格式，而不是 PDF 表格——这是我读任何"汇编类"工作的第一个问题。
