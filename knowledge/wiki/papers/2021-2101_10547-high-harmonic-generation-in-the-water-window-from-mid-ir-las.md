• # High-Harmonic Generation in the Water Window from mid-IR Laser Sources

  ## 林赛的理解

  这篇工作对我们在固体和原子体系中推进强场超快阿秒光源具有重要的方法学参照意义。作者用 RMT 这一全电子从头算方法把水窗 HHG 计算推进到 3000 nm 中红外波段，明确验证了：三步骤模型的截止规律定性成立，但转换效率的绝对数值对模型细节极度敏感。我们的 HHG / 阿秒研究方向长期依赖 SAE 或 SFA 模型做快速预测；Finger 等人的结果提醒我们，当把驱动波长拉长到 mid-IR 以触及水窗（282–533 eV）时，多电子关联、规范选择、窗口函数和磁量子数处理都会显著改变定量结论。这尤其关系到我们评估“以 mid-IR 驱动固体/莫尔体系产生软 X 射线”是否可行、如何标定效率，以及在实验设计中是否应该把 SAE 预测当作保守估计还是乐观上限。

  ## 研究问题

  论文要回答的核心问题是：在中红外波段（2000–3000 nm）驱动氖原子产生高次谐波时，全电子、从头算的 R-Matrix with Time-dependence（RMT）方法能否生成进入水窗区域（碳 K 边 282 eV 至氧 K 边 533 eV）的软 X 射线谐波，并且与单活性电子（SAE）模型及三步骤模型相比，多电子关联、模型参数和数值处理如何影响谐波谱的定性形状与定量转换效率？

  ## 研究背景

  水窗是 282 eV（碳 K 吸收边）到 533 eV（氧 K 吸收边）之间的软 X 射线区域，水在此波段近乎透明而含碳有机物吸收强烈，因此被视为活细胞、生物分子时间分辨成像的理想光源。传统水窗光源主要依赖同步辐射或自由电子激光，但瞬时功率低，难以对活体细胞进行飞秒时间分辨成像。高次谐波（HHG）利用少周期中红外激光产生相干软 X 射线，是替代同步辐射的桌面化方案。

  HHG 的经典图像是 Corkum 三步骤模型：隧穿电离 → 电场加速 → 回撞辐射，截止能量为 Ec = Ip + 3.17Up，其中 Up ∝ I0λ²。理论上提高强度或波长即可把水窗谐波推得更高，但实验上提高强度会导致靶材耗尽，提高波长则使转换效率按 λ⁻⁵ 甚至 λ⁻⁶ 下降。因此水窗 HHG 通常依赖 mid-IR 驱动，但效率问题突出。近年来已有 nJ 量级水窗 HHG 源的报道。

  计算上，全量子力学处理需要极大的角动量展开和构型空间，常用简化包括强场近似（SFA）和单活性电子（SAE）模型，它们都忽略多电子效应。但多电子效应已被证明会显著改变谐波截止和谐波强度，例如氙中的巨共振、He 和 Be 中的 HHG。RMT 方法通过高性能计算代码纳入多电子效应，此前已用于 1800 nm 的 HHG 计算，本工作将其扩展到 3000 nm。

  ## 研究方法

  **研究对象**：氖（Ne）原子基态，外层 2p 电子。

  **激光参数**：6 周期、线偏振中红外脉冲，中心波长 2000–3000 nm，峰值强度 1.0×10¹⁴ W/cm² 至 2.0×10¹⁴ W/cm²；包络采用 3 周期 sin²  ramp-on/off 以近似高斯包络；使用“cosine pulse”并选择载波包络相位使 ∫₀ᵀ A(t)dt = 0。

  **计算平台**：Stampede2、Frontera（德州高级计算中心）和 Bridges-2（匹兹堡超算中心）。每次 RMT 计算约需 500 核运行 8–10 小时；SAE 计算在单节点多核 OpenMP 上耗时最多数小时。

  **SAE 模型**：求解含时薛定谔方程，活性电子初始处于 2p 轨道；采用 Tong–Lin 模型势；有限差分径向网格最小步长 0.01、最大步长 0.05；时间步长 0.005 a.u.；长度规范；包含角动量至 ℓ = 300。通过数值微分由诱导偶极矩得到加速度、速度，再按 S(ω) = (2/3πc³)|ã(ω)|² = (2/3πc³)ω²|ṽ(ω)|² = (2/3πc³)ω⁴|z̃(ω)|² 计算谱密度，最终换算为转换效率 C = ∫S(ω)dω / ∫E²(t)dt。对六个 2p 电子按 m = 0 和 m = ±1 加权（分别为 4 和 16 倍），实际发现 m = 0 占主导。

  **RMT 方法**：全电子、从头算，基于 R-matrix 范式把位形空间分为内区（半径 20 a.u.）和外区（最长 65,000 a.u.）；外区有限差分网格步长 0.08，时间步长 0.005（最高截止能量算例用 0.003）；长度规范传播。靶态用 Burke–Taylor 轨道及 RMATRX-II 生成，测试了四种耦合/组态级别：
  - 1st-1cf：仅离子基态 (2s²2p⁵)²P，仅主导组态；
  - 1st-7cf：离子基态，含 7 个组态；
  - 2st-13cf：2 态模型（含 (2s2p⁶)²S），13 个组态；
  - 2st-23cf：2 态模型，23 个组态。

  包含 2s²2p⁵εℓ 和 2s2p⁶εℓ 通道至最大总轨道角动量 Lmax = 240（多数算例用 60 个 13 阶 B 样条；最高能量算例用 64 个样条）。谱由偶极算符含时期望值的傅里叶变换得到，并在长度、速度、加速度三种形式下交叉验证。

  **窗口处理**：讨论了 RMT 中用于限制偶极矩积分区域的高斯窗，以及后处理中常用的 Blackman 窗。发现 Blackman 窗虽能改善谱图外观，却会改变 plateau 区域 1 个量级以上的绝对强度，因此定量转换效率计算弃用 Blackman 窗。

  ## 主要发现与核心结论

  1. **规范不变性与收敛性验证**：对 2000 nm、2.0×10¹⁴ W/cm² 算例，RMT 在长度规范和速度规范直接计算的谱高度一致；由长度形式偶极矩数值微分得到的速度、加速度结果也彼此吻合。Lmax = 200 与 Lmax = 240 的结果相近，而 Lmax = 160 仍存在可见差异，证明 Lmax = 240 已达到收敛。

  2. **SAE 与 RMT 的定性一致、定量分歧**：在 2000 nm、2.0×10¹⁴ W/cm² 下，SAE（m = 0，权重 4 倍）与 RMT-1st-1cf 的 plateau 均延伸至约 260 eV，与三步骤模型预测的 258 eV 截止吻合。但谱密度绝对值在对数尺度上差异显著，说明多电子关联和靶态描述会改变定量预测。

  3. **磁量子数贡献**：SAE 中 m = ±1 的贡献（权重 16 倍）相对于 m = 0 可忽略。

  4. **模型细节对转换效率的敏感依赖**：在 2000 nm、2.0×10¹⁴ W/cm² 下，不同模型给出的 plateau 转换效率 Cp 相差约 5 倍（2st-13cf 的 5.50×10⁻³ 到 1st-1cf 的 2.65×10⁻²）。全谱转换效率 Ct 的变化相对较小，因为低频主导峰对模型不敏感。具体数值见下表：

  5. **强度与波长的标度规律**：在 2000 nm 下，截止能量随强度近似线性增加，从 1.0×10¹⁴ W/cm² 的约 140 eV 增至 2.0×10¹⁴ W/cm² 的约 260 eV；RMT 与三步骤模型最大偏差约 5 eV。在 1.0×10¹⁴ W/cm² 下，波长从 2600 nm 增至 3000 nm 使截止从约 220 eV 升至约 290 eV，符合 Up ∝ λ² 的近似二次关系。

  6. **进入水窗的参数窗口**：在 3000 nm、1.5×10¹⁴ W/cm² 下，RMT 给出截止约 420 eV，首次将水窗 HHG 推进到水窗内部。

  7. **波长对转换效率的影响**：在 2.0×10¹⁴ W/cm² 下，波长从 2600 nm 增至 3000 nm 使总转换效率 Ct 下降近 2 倍，符合近似 λ⁻⁵ 依赖；但 plateau 转换效率 Cp 在 3000 nm 仍约为 2600 nm 的 70%，暗示 plateau 区域效率随波长下降更缓。

  8. **窗口函数导致定量失真**：Blackman 窗在 plateau 起始段（约 20–50 eV）可把谱密度压低一个量级以上，对短脉冲尤为严重，因此不适合用于绝对转换效率的定量研究。

  ## 潜在研究方向

  1. **RMT 与 BSR 代码接口**：作者计划将 RMT 与 Zatsarinny 的 B-spline R-matrix（BSR）代码结合，使用非正交、项相关靶轨道，以改善内区描述，尤其针对更复杂原子/分子靶。这能进一步检验多电子关联和靶态组态收敛性对水窗 HHG 的影响。

  2. **与实验直接对比**：当前工作缺乏实验对照。未来需要在相近激光参数（3000 nm、1.0–1.5×10¹⁴ W/cm²）下测量氖的谐波谱和绝对转换效率，以验证 RMT 预测的可靠性并校准不同理论模型。

  3. **载波包络相位平均**：本文使用单一 CEP 并选择使 ∫A(t)dt = 0 的相位。更贴近实验的处理应设置矢量势并做 CEP 平均，但当前计算资源不足。CEP 平均对 plateau 和转换效率的影响仍是开放问题。

  4. **长波长下最佳规范与收敛策略**：文中指出长度规范收敛更快但需要更多角动量。针对 mid-IR 长波长，系统比较长度规范与速度规范、优化 Lmax 和 B 样条数目，可显著降低计算成本并提高定量精度。

  5. **多电子效应向分子和凝聚相扩展**：RMT 目前主要用于原子。将其方法学推广到分子、团簇乃至固体/莫尔体系，研究多电子关联、屏蔽效应和激子效应对 HHG 的影响，是连接原子物理与材料科学的关键桥梁。

  6. **定量转换效率的“误差预算”**：本文揭示 Cp 在不同 RMT 模型间可相差数倍。未来需要建立模型不确定度的系统评估框架，明确在实验设计阶段应使用哪个理论数值作为效率预期。

  7. **窗口函数与后处理标准**：本文警示 Blackman 窗对定量结果的影响。需要为水窗 HHG 的理论谱建立统一的后处理规范，避免不同研究因窗口选择而给出不可比较的效率。

  ## 与林赛研究的关联

  - **HHG 与阿秒光源**：我们的工作围绕强场驱动下固体、莫尔体系和低维材料产生 HHG 与阿秒脉冲。本文对氖原子 mid-IR HHG 效率的系统计算，为我们评估“将驱动波长延伸至中红外以获得更高光子能量”提供了原子尺度的基准和效率上限参考。
  - **强场驱动与量子几何**：在固体 HHG 中，驱动波长、强度和能带结构共同决定截止和谐波产额。本文强调的 Up ∝ I0λ² 标度、多电子关联和靶态细节，与我们在莫尔/转角体系中关注的层间耦合、贝里曲率和量子几何对 HHG 的调控形成类比。
  - **交变磁（altermagnetism）与自旋分辨**：虽然我们主要研究关联电子材料，但本文中对 m = 0 与 m = ±1 磁量子数贡献的分析，提示我们在具有自旋-轨道耦合或自旋极化靶的 HHG 研究中，磁量子数权重和选择规则可能带来类似的定量修正。
  - **实验-理论接口**：本文呼吁理论与实验合作标定绝对转换效率，这与我们课题组在固体 HHG 实验中迫切需要可靠的理论产额预测高度一致；也提示我们在撰写申请书或设计实验时，应明确区分 SAE 的定性预测与 RMT/多电子方法的定量预测。

**原理**：R-Matrix with Time-dependence（RMT）全电子方法把水窗 HHG 计算推进到 3000 nm：位形空间分内区（20 a.u.，Burke-Taylor 轨道+RMATRX-II 靶态，通道含 2s²2p⁵εℓ 与 2s2p⁶εℓ，Lmax=240 收敛）与外区（最长 65000 a.u. 有限差分），长度规范传播；与 SAE（Tong-Lin 模型势、ℓ=300、m=0/±1 加权 4/16 倍）及三步模型（Ec=Ip+3.17Up）三方对比。核心结论：① 截止位置定性一致（RMT 与三步模型最大偏差约 5 eV），但转换效率绝对值对模型细节极敏感——同条件下四种 RMT 耦合级别的 plateau 效率 Cp 相差约 5 倍（2st-13cf 5.50×10⁻³ 到 1st-1cf 2.65×10⁻²）；② 长度/速度规范+偶极矩三种形式交叉验证一致；③ m=±1 贡献相对 m=0 可忽略；④ Blackman 窗虽改善谱观感却改变 plateau 绝对强度一个量级以上——定量转换效率计算必须弃用；⑤ 3000 nm、1.5×10¹⁴ W/cm² 下截止约 420 eV，首次把 HHG 推进水窗内部。
