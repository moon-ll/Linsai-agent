• # Valley polarization in 2D tetragonal altermagnetism

  ## 林赛的理解
  这项工作提示了一个被我此前“强场驱动—莫尔—量子几何”视角长期忽略的入口：**二维四方交变磁体中的能谷极化可以通过面内磁化方向被开关，并伴随自旋极化同步翻转**。这与主流的六方铁磁/反铁磁谷电子学范式（需面外磁化、谷位于 -K/K）形成鲜明对照。对我组正在推进的“Berry 曲率工程”和“强场超快调控”课题而言，交变磁体提供了零净磁矩却拥有自旋劈裂的晶格平台，意味着可以用超快磁化方向切换（而非大的外磁场翻转）来控制谷极化，从而可能实现**低功耗、超快的谷自由度光学读写**。特别是文中提到的 90 meV 大谷劈裂候选体系，值得作为强场超快光谱与阿秒探测的后续目标。

  ## 研究问题
  论文的核心问题是：**能否在二维四方交变磁体中，通过调控磁化方向实现可翻转的能谷极化？** 具体而言，作者要验证：当面内磁化方向从 x 轴转到 y 轴时，布里渊区中 Γ-Y（Y₁）与 Γ-X（X₁）两个等效能谷的能量简并能否被打破并被反向，以及这种谷极化是否伴随自旋极化。

  ## 研究背景
  - **能谷电子学**：能谷作为电子能带的极值点，是低功耗信息处理的新自由度；实现自发谷极化是谷电子器件的前提。
  - **六方磁体系的主流范式**：此前自发谷极化多研究二维六方铁磁或反铁磁材料（如 CrSi₂N₄、FeClBr、NbX₂ 等），谷位于 -K/K 点，依赖自旋-轨道耦合（SOC）和面外磁化共同作用；自旋劈裂公式通常写作 ΔE_VS = 4α cosθ，θ=0° 为面外磁化，θ=90° 为面内磁化。
  - **反铁磁的优势与局限**：反铁磁材料零净磁矩、抗外磁扰动、动力学超快，但六方反铁磁中缺少自旋劈裂，限制了更丰富的物理。
  - **交变磁体的出现**：altermagnetism 作为第三类共线磁序，兼具反铁磁的零磁矩和铁磁的自旋劈裂特征，由旋转/镜面而非平移/反演对称性驱动。
  - **四方交变磁的谷机会**：已有工作通过单轴应变或扭转双层在四方体系中诱导谷极化；本文则提出**通过面内磁化方向直接实现并翻转**谷极化的新路径。

  ## 研究方法
  - **理论框架**：基于密度泛函理论（DFT），使用 VASP 软件包，采用投影缀加波（PAW）方法，交换关联势选取 PBE-GGA。
  - **计算参数**：平面波截断能 500 eV，总能收敛判据 10⁻⁸ eV，原子力收敛判据 0.0001 eV·Å⁻¹；真空层厚度大于 16 Å；电子结构计算使用 12×12×1 的 Monkhorst-Pack k 点网格。
  - **关联处理**：对 Fe 的 3d 轨道采用 Dudarev 等提出的旋转不变 GGA+U 方法，主要使用 U=2.5 eV；对 Ru 体系因 U<3.5 eV 收敛到非磁解，改用 U=4 eV 以获得磁解。
  - **稳定性验证**：利用 Phonopy 基于有限位移法计算声子谱（4×4×1 超胞）；采用 NVT 系综进行 ab-initio 分子动力学（AIMD）模拟，时间步长 1 fs，总时长超过 8000 fs；通过应变-应力关系计算弹性常数，并按 C²ᴰᵢⱼ = L_z C³ᴰᵢⱼ 进行二维归一化。
  - **材料体系**：
    - 主要原型：Janus 四方交变磁单层 Fe₂MoS₂Se₂。
    - 放大验证：理想化的 Ru₂MoS₂Se₂，以展示更大的 SOC 效应。
    - 扩展验证：四方铁磁单层 Fe₂I₂。

  ## 主要发现与核心结论
  - **对称性机制**：对于二维四方交变磁体，无 SOC 时 C₄z 旋转对称性使 Y₁、X₁ 两谷等效；引入 SOC 后，当面外磁化时磁点群 C₄zT 仍禁止谷极化；当面内磁化沿 x 或 y 方向时，C₄zT 被破坏，**谷极化与自旋极化同时出现，且方向可随磁化方向在 x 与 y 之间切换而反转**。
  - **一般磁化方向的消光条件**：当 θ=0°、180° 或 ϕ=45°、135°、225°、315° 时，谷极化消失；谷劈裂 ΔE_VS = E_Y₁ − E_X₁ 随 ϕ 以 90° 为周期振荡。
  - **Fe₂MoS₂Se₂ 基态与稳定性**：
    - 晶格常数 a=b=5.576 Å（GGA+U，U=2.5 eV）。
    - AFM1 为磁基态，能量比 FM/AFM2 分别低 96 meV 和 23 meV。
    - 磁各向异性能 MAE = 129/249 μeV/Fe，易轴为面外。
    - 弹性常数 C₁₁=48.67 Nm⁻¹、C₁₂=3.88 Nm⁻¹、C₆₆=6.35 Nm⁻¹，满足 Born 稳定性判据 C₁₁>0、C₆₆>0、C₁₁−C₁₂>0。
    - 声子谱无虚频，300 K AIMD 能量涨落小，表明具有良好的动力学与热稳定性。
  - **Fe₂MoS₂Se₂ 电子结构**：
    - Janus 结构产生约 0.84 V·Å⁻¹ 的内建电场。
    - 无 SOC 时能带在 X、Y 点形成谷，呈现 d 波交变磁性，两个 Fe 原子磁矩分别为 2.94 μB 和 −2.94 μB，总磁矩严格为 0.00 μB。
    - 当 U 从 0 eV 增至 4 eV 时，晶格常数 a 增加约 0.12 Å；U<3.7 eV 时保持 AFM1 基态与交变磁性，U>3.7 eV 时 AFM2 成为基态并失去交变磁性。
    - Fe₂MoS₂Se₂ 为直接带隙半导体，带隙为 34 meV（U=0 eV 或 2.5 eV 下的 DFT+U 结果）。
    - 面内 x 方向磁化时，导带底 Y 与 X 谷之间的**谷劈裂约为 1.6 meV**；磁化方向从 x 转到 y 时，谷极化反转；沿 xy（45°）方向磁化时无谷劈裂，与对称性分析一致。
  - **Ru₂MoS₂Se₂ 的放大效应**：作为理想化的重原子体系验证，面内 x 磁化时 Y₁ 与 X₁ 谷之间的**谷劈裂达到 90 meV**；磁化方向在 x 与 y 之间切换同样导致谷极化反转。
  - **向铁磁体系的扩展**：该机制可推广到二维四方铁磁材料。以 Fe₂I₂（空间群 P4/nmm，No.129，a=b=3.863 Å，U=2.5 eV）为例，面内 x 或 y 磁化均产生谷劈裂，并可被磁化方向切换反转。

  ## 潜在研究方向
  - **实验实现挑战**：Fe₂MoS₂Se₂ 的谷劈裂仅 1.6 meV，在低温、应变或杂质展宽下易被抹平；如何在真实样品中稳定磁化方向并光学读出谷极化仍是开放问题。
  - **重原子体系的材料搜索**：作者明确指出 3d 磁性原子导致 SOC 弱、谷劈裂小，需系统搜索基于 4d 或 5d 元素的四方交变磁体，以获得可与六方谷材料竞争的大谷劈裂。
  - **面外易轴与面内磁化的张力**：Fe₂MoS₂Se₂ 的 MAE 显示易轴为面外，而谷极化需要面内磁化；如何通过应力、电场、界面工程或超快场将磁化稳定或瞬态驱动到面内，是器件化的关键。
  - **超快翻转动力学**：磁化方向在 x 与 y 之间以 90° 切换即可反转谷极化，为超快自旋-谷光电子学提供了可能，但相应的超快退磁/再磁化路径、相干时间尚未研究。
  - **拓扑与输运的后续**：Fe₂I₂ 原本以量子反常霍尔效应著称，本文主要讨论谷劈裂，但二者在同一材料中的竞争或共存值得深入；此外，谷霍尔电导、圆偏振光吸收选择定则等光电响应尚未计算。
  - **DFT+U 的可靠性**：U 值对磁基态（U>3.7 eV 失去交变磁性）和 Ru 体系的磁性解有显著影响，需要更严格的杂化泛函或动力学关联方法验证。

  ## 与林赛研究的关联
  - **强场驱动与阿秒读出**：谷劈裂 1.6 meV 对应约 0.39 THz 的能量尺度，远小于光学光子能量，适合用强场太赫兹或近红外脉冲驱动谷间相干，并通过高次谐波（HHG）光谱探测谷自由度的超快演化；90 meV 的 Ru₂MoS₂Se₂ 体系更易在室温下实现阿秒时间分辨的光电流或二次谐旋光探测。
  - **交变磁与莫尔工程的结合**：本文的四方晶格与莫尔超晶格存在天然接口——莫尔势可进一步破缺 C₄ 对称性并调制 Y/X 谷权重，为“莫尔 + 交变磁”双自由度调控提供了材料候选；我们可借鉴文中对称性分析，设计莫尔周期与四方交变磁胞格匹配的异质结。
  - **量子几何与 Berry 曲率**：谷极化体系通常伴随非零 Berry 曲率，可产生谷霍尔效应；强场驱动下，Berry 曲率偶极子将贡献高阶谐波的非微扰通道，是连接本文电子结构与 HHG 理论的关键桥梁。
  - **量子几何材料数据库接口**：Fe₂MoS₂Se₂ 这类 Janus 交变磁体可作为“低对称性、可磁控谷极化”的代表性体系，纳入我们针对强场超快光学筛选的材料清单，与 MnPS₃/Rashba 方向的课题形成互补。
