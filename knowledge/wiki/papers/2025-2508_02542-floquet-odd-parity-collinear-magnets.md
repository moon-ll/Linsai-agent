• # Floquet 奇宇称共线磁体（Floquet odd-parity collinear magnets）

  ## 林赛的理解

  这篇文章做了一件概念上很干净的事：把"奇宇称自旋劈裂"（p 波、f 波磁体）从非共线磁体的复杂世界里"搬"进了共线反铁磁体，而搬运工是圆偏振光（CPL）+ Floquet 工程。对称性逻辑只有一句话——CPL 破坏保自旋的赝时间反演对称 `[C2T||E]`、但保留翻自旋的反演对称 `[C2||P]`，于是共线 AFM 的 PT 双重简并被解除，费米面从平庸变成 p 波、f 波奇宇称形态。

  对我们的直接价值有三个层次。第一，**材料正好是单层 MnPSe₃**——这正是我们 Berry-MnPS₃-Rashba 课题的核心材料家族（MPX₃），论文给出了 RCPL（Ã = 0.2 Å⁻¹、ℏω = 5 eV）驱动下的能带、自旋劈裂（最大 40 meV）、反常霍尔电导（≈6e²/h）全套第一性原理数据，这是我们课题"强场驱动/光诱导磁态"叙事最现成的支撑文献。第二，它给了一个**可操作的对称性判据**：哪些共线 AFM 在 CPL 下会出 f 波、如何通过单轴应变把 f 波降成 p 波——这相当于一份"光诱导奇宇称磁态"的材料筛选清单。第三，f 波磁体里的 **|C| = 2 反铁磁 Chern 绝缘态**（带隙闭合-再打开，每个 Dirac 锥 C 变 −1）把拓扑、奇宇称劈裂和非线性自旋输运统一在同一平台，且论文明确说该态支持二阶纯自旋流——这是 Floquet 拓扑相在磁性体系中非常清晰的理论预言。

  要注意的边界：所有结果都是高频离共振近似下的有效静态哈密顿量 + 基态 DFT/Floquet 能带，**没有动力学演化、没有考虑光致加热与退相干**，40 meV 劈裂是在 Ã = 0.2 Å⁻¹ 这一相当强的光场下算出的。作为方案写作的素材很好，作为实验预期要打折。

  ## 研究问题

  共线磁体中能否实现奇宇称（p 波、f 波）自旋劈裂？既有认知是：交错磁体（altermagnet, AM）虽在动量空间有铁磁式自旋劈裂，但皆为偶宇称（d、g、i 波）；奇宇称磁体此前只在**非共线**磁体中被提出，而复杂磁结构对外场敏感、自旋电子学应用受限。本文的核心问题是：能否用**外场（特别是 CPL）对常规共线反铁磁体做对称性工程**，在保持共线磁结构的前提下诱导出奇宇称自旋劈裂，并实现与之共生的新奇量子态（如高 Chern 数拓扑绝缘态）？

  ## 研究背景

  - 非常规磁体（超出铁磁/反铁磁二分）是凝聚态热点，altermagnet 在实空间呈净磁化强度为零的共线交错磁矩、动量空间呈偶宇称自旋劈裂（d-/g-/i-波费米面），已有大量理论预言与部分实验证实（CrSb、RuO₂、MnTe 等）。
  - 奇宇称磁体（p-/f-波）此前仅在非共线磁体中提出（Brekke et al. 2024；Yu et al. 2025；Song et al. 2025 的 p 波磁体电学开关等），磁结构复杂、抗外场能力弱。
  - Floquet 工程（时间周期光场调控电子/磁结构）已有一系列成功范例：CPL 破缺时间反演对称导致拓扑绝缘体表面态开隙、光致反常霍尔效应、Floquet-Bloch 态观测等。
  - 本文的关键洞察：在可忽略 SOC 的 PT 对称 AFM 中，自旋简并由两条自旋群对称共同保护——`[C2||P]`（给出 ε(s,k)=ε(−s,−k)）与 `[C2T||E]`（给出 ε(s,k)=ε(s,−k)），二者合成 PT。只需选择性破坏后者而保留前者，简并即被解除且费米面呈奇宇称。**CPL 恰好满足这一对称性要求**：在 SOC 可忽略体系中光不直接耦合自旋、且在空间反演下不变，因而破 `[C2T||E]` 而保 `[C2||P]`。

  ## 研究方法

  本文属理论方法密度高的工作，核心是"对称性分析 + Floquet 有效模型 + 第一性原理 Floquet 计算"三线并行。以下按方法卡整理（参数均出自原文，图号与公式号为出处）。

  ### 方法卡 1：对称性判据（理论框架）

  - **原理**：在自旋群对称 `[S||R]`（S 作用于自旋空间、R 作用于实空间）语言下，共线 PT 对称 AFM 的能带双重简并由 `[C2||P]` 与 `[C2T||E]` 联合保证；破 `[C2T||E]` 保 `[C2||P]` → p 波；p 波磁体若额外具有三重旋转对称 → f 波。
  - **适用边界**：要求体系 SOC 可忽略（光场不直接耦合自旋的前提）；CPL 传播方向需与对称性分析设定自洽。

  ### 方法卡 2：二维 AFM 格点模型 + Floquet 高频展开

  - **原理**：时间周期哈密顿量经 Peierls 替换 k → k + eA(t)/ℏ 引入光场，用 Floquet 理论映射为有效静态哈密顿量；离共振（高频）极限取一阶 Van Vleck 展开：
    Heff(k) = H0(k) + M(k)，M(k) = Σ_{n≥1} [H_{−n}, H_n]/(nω) + O(1/ω²)（原文 Eq. 2）
  - **参数表**（原文 Fig. 2，量纲均取无量纲单位）：
    - 菱形（低对称）格点：A 子格 (0,0)、B 子格 (0.5, 0.8)（分数坐标）；基矢 a₁ = a(√3/2, 1/2)、a₂ = a(√3/2, −1/2)；A–B 最近邻三跳迁 t₁、t₂、t₃；交错交换场 h_z（χ_m = +1(−1) 对应 A(B) 子格）
    - p 波计算：t₁ = 3、t₂ = 2、t₃ = 0.7、h_z = 0.2、Ãa = 2.6、ℏω = 6；自旋分辨费米面取 E = −2.8（Fig. 2b,c）
    - 蜂窝格点（恢复 C₃，三跳迁等价记为 t = 1）：一阶质量项 M(k) = 4ηλ(cos(√3 k_x a/2) − cos(k_y a/2))·sin(k_y a/2)·σ_z，λ = −√3 t² J₁(Ãa/√3)²/ω（原文 Eq. 3，J₁ 为一阶 Bessel 函数）
    - 实空间有效哈密顿量：H_F = iλ Σ_{⟨⟨m,n⟩⟩} ν_mn c†_m c_n，ν_mn = sgn[(d₁×d₂)·z]——即 Haldane 型虚跳迁项（原文 Eq. 4），自旋无关、保 `[C2||P]` 与 `[E||C3]`、反演奇于 TR
    - f 波计算：Ãa = 2.6、ℏω = 6；费米面取 E = −0.75（正文 Fig. 2e,f 标注 E = −2 处亦确认 f 波特征——以原文两处表述并存为准）
  - **CPL 规范约定**：A(t) = A₀[cos(ωt), η sin(ωt)]，η = ±1 对应右旋/左旋（RCPL/LCPL）；定义 Ã = eA₀/ℏ（波矢量纲）。

  ### 方法卡 3：f 波磁体中的拓扑相分析

  - **K/K′ 谷低能有效哈密顿量**（原文 Eq. 5，至动量线性阶）：
    Heff(K+q) = v(q_x σ_y + q_y σ_x) + (s h_z − ηλ′)σ_z
    Heff(K′+q) = v(−q_x σ_y + q_y σ_x) + (s h_z + ηλ′)σ_z
    其中 v = √3 a t J₀(Ãa/√3)/2，λ′ = 3√3 λ = −9 t² J₁(Ãa/√3)²/ω，s = +1(−1) 对应 ↑ (↓)。
  - **拓扑相变判据**：每个自旋极化 Dirac 锥的 Chern 数为 ±1/2；|λ′| = |h_z| 时 K 谷自旋上、K′ 谷自旋下两锥同时闭合再开隙，各伴随 ΔC = −1 → 总 C = −2（RCPL 高强度区；LCPL 得 C = +2）；低强度区（|λ′| < |h_z|）两价带 Chern 数相消、总 C = 0。
  - **验证**：Ãa = 1.73、ℏω = 5 下计算表面态，带隙中出现两条手性边缘态（Fig. 3c）；完整相图以光振幅与频率为轴（Fig. 3d）。

  ### 方法卡 4：第一性原理 Floquet 计算（MnPSe₃）

  - **材料体系**：单层 MnPSe₃，基态为 Néel 型 AFM（Chittari et al. 2016）；Mn 原子成蜂窝格点、相邻 Mn 磁矩反平行，具 `[C2||3̄001]` 对称（绕 z 轴三重旋转接反演）。
  - **计算管线**：VASP（PAW 赝势，GGA-PBE 泛函）+ Wannier90 构造 Wannier 函数 + Floquet 处理光场；具体 k 网格/截断能在补充材料（原文引文 [75]–[87]，正文未列数值，不虚构）。
  - **计算设置**：RCPL，振幅 Ã = 0.2 Å⁻¹、频率 ℏω = 5 eV（Fig. 4b,d）；扫描频率 ℏω = 3、5、7 eV 下最大自旋劈裂随光振幅的变化（Fig. 4f）。
  - **单轴应变的对称性降阶**：破 3̄001 对称可进一步由 Floquet 工程诱导 p 波劈裂（补充材料）。

  ## 主要发现与核心结论

  1. **新磁态类别**：提出 Floquet 奇宇称共线磁体——CPL 辐照常规共线 AFM 可诱导 p 波与 f 波磁体。对称性机制为破 `[C2T||E]`、保 `[C2||P]`；该机制在所有共线磁体中普适成立（`[C2T||E]` 存在于一切共线磁体）。
  2. **f 波磁体中的反铁磁 Chern 绝缘态**：高强度 RCPL 下（|λ′| > |h_z|）实现 C = −2（LCPL 下 C = +2）；相变点 |λ′| = |h_z| 处两谷双锥同步闭合-再开隙；Ãa = 1.73、ℏω = 5 时带隙中观察到两条手性边缘态；该量子反常霍尔效应由 CPL 诱导且与自旋自由度无关。f 波 Chern 态还呈现二阶纯自旋流（Edelstein 效应 + 欧姆定律组合，均线性于电场）。
  3. **MnPSe₃ 第一性原理证实**：RCPL（Ã = 0.2 Å⁻¹、ℏω = 5 eV）下能带解除简并、E = 0 eV 处费米面呈 f 波自旋极化；PT 破缺后出现可观的反常霍尔电导，费米能调至约 −0.1 eV 时达 ≈6e²/h；动量分辨自旋劈裂（最高自旋上与自旋下价带能量差）**最大约 40 meV**；劈裂大小随光振幅与频率（ℏω = 3、5、7 eV 扫描）可广泛调控；单轴应变破 3̄001 对称可进一步诱导 p 波劈裂。
  4. **理论定位**：蜂窝格点模型的虚跳迁项即 Haldane 模型的自旋无关版本，本文模型可视为"带局域磁矩的修正 Haldane 模型"；与常规 Floquet Chern 绝缘体（Kitagawa et al. 2011）的区别见补充材料。
  5. 作者声明存在两篇独立同期工作（Huang et al., arXiv:2507.20705；Li et al., arXiv:2507.22884）结论部分重叠。

  ## 潜在研究方向

  - **动力学与耗散缺失**：全部结果基于离共振高频展开的静态有效哈密顿量与基态 Floquet 能带，未处理光致加热、退相干、真实脉冲包络与共振区物理；实验观测窗口（ pulse 宽度 vs Floquet 态寿命）是开放问题。
  - **实验判据待落地**：文中提到奇宇称劈裂可用 pump-probe（tr-ARPES，引文 [84]–[87] 理论支撑）探测，但无具体实验参数；40 meV 劈裂所需 Ã = 0.2 Å⁻¹ 对应的光强强度在文中未换算为实验可执行的通量/损伤阈值。
  - **SOC 可忽略假设**：判据的前提是弱 SOC；对含重元素或本身有显著 SOC/Rashba 的 AFM（如我们关心的 Rashba 体系），`[C2T||E]`/`[C2||P]` 的分析框架需扩展，p/f 波劈裂与固有 Rashba 劈裂如何区分未讨论。
  - **并发竞争**：两篇同期 arXiv 工作（2507.20705、2507.22884）覆盖部分结论，新颖性窗口正在被压缩，引用时需注意归属。
  - **磁性稳定性**：CPL 诱导的交换场重正整、磁有序在强驱动下的热稳定性未涉及；f 波 Chern 态的二阶自旋流的可观测材料平台与输运判据有待提出。

  ## 与林赛研究的关联

  - **直接材料接口：MnPSe₃ = 本组 Berry-MnPS₃-Rashba 课题（general-berry-mnps3-rashba-20260816）的同族体系**。MPX₃ 家族是本组"量子几何/反常霍尔输运"叙事的载体，本文给出该材料在 CPL 下的自旋劈裂（40 meV）、反常霍尔电导（≈6e²/h @ E_f ≈ −0.1 eV）、|C| = 2 Chern 相全套数据，可直接作为课题"光场调控量子几何响应"立论的第一性原理先例。
  - **强场驱动/Floquet 工程接口**：本文的哈密顿量构建（Peierls 替换 + Van Vleck 一阶展开 + Haldane 型虚跳迁）是我们 HHG/强场驱动理论计算的同构工具链，其对称性判据（破 `[C2T||E]` 保 `[C2||P]`）可直接移植到"强激光诱导非常规磁态"的方案设计中，作为选题的 symmetry-based 筛选规则。
  - **交变磁/莫尔接口**：Floquet 奇宇称磁体是 altermagnet 的奇宇称推广；本组莫尔-强场方向中，CPL 驱动莫尔异质结（含磁性衬底或磁性转角体系）的对称性工程是自然的延伸——特别是"莫尔超晶格降对称 → p 波取代 f 波"与本文"单轴应变破 3̄001 → p 波"完全同构，可借其分析模板。
  - **探测接口**：pump-probe/tr-ARPES 作为奇宇称劈裂的判据，与本组阿秒-超快探测能力对接；40 meV 能标处于中红外-近红外光泵范围，与 HHG 泵浦-探测平台的参数区相容。
  - **竞争窗口**：两篇同期工作重叠，本组若引用需以本文（MnPSe₃ 具体材料实现 + |C| = 2 拓扑态）为差异化锚点。
