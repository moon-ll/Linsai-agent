• # 手性波导QED非线性光学：动量反关联光子对的产生

  ## 林赛的理解

  这项工作展示了一个非常干净的量子光学平台：超导transmon手性耦合到一维波导，在弱相干驱动下可以把"普通"相干光转换成非经典光场，而且两个transmon又能把相干光"还回来"。从我们的强场超快光学视角看，它的核心价值在于提供了一个**受控的非线性量子光源**——单个人工原子把两个独立光子转化为动量反关联的光子对，g^(2)(0)可以从0调到约2.5×10^7。这和我们关心的HHG、阿秒物理、强场驱动量子材料在底层逻辑上是相通的：都是研究强（或弱但非线性）光-物质相互作用如何把入射光场的量子统计或相空间分布改写。虽然这个平台是微波波导、弱驱动，但"手性耦合+非线性散射+光子统计工程"的思想可以直接嫁接到我们思考的光学频率或强场方案中。特别是动量反关联光子对的产生机制——两个入射光子→一个(k0+δ, k0−δ)光子对——和参量下转换、HHG中的相位匹配、甚至莫尔系统中波矢守恒的物理图像有可比性。

  ## 研究问题

  论文要回答的核心问题是：**当transmon链手性耦合到一维波导时，透射光中的非相干分量从何而来？它为什么会在单transmon处导致"相干性的丧失"，而又能被第二个transmon恢复？** 进一步地，作者想利用波导驱动和局域驱动的干涉，实现对透射光光子统计（二阶关联函数g^(2)(0)）的宽范围调控，包括反聚束、相干、聚束和超强聚束态。

  ## 研究背景

  手性量子光学是近年来活跃的方向，其核心是量子发射体与一维光子连续态的单向耦合，使发射体-光子相互作用依赖于光子传播方向。实现途径包括自旋-动量锁定、两能级系统的量子非线性干涉、以及两个量子发射体对称耦合到波导引起的方向性集体干涉等。实验平台涵盖中性原子、量子点、纳米颗粒、等离子体表面以及超导量子比特。

  超导transmon作为人工原子，与一维波导的耦合效率可达99.9%，且可实现对每个量子比特的独立控制，使其成为研究手性相互作用的理想平台。已有工作利用手性发射体链产生位移Fock态混合、光子束缚态，以及通过共振荧光产生关联光子态。然而，手性对光场本身的非经典统计特性、特别是"相干性丧失与恢复"的微观机制，仍缺乏完整理解。本文正是聚焦这一缺口，结合半经典和全量子方法，揭示单transmon引入的非相干透射光的起源。

  ## 研究方法

  **体系**：N个transmon作为两能级系统手性耦合到一维色散less波导，只与向右传播的光子相互作用。设ℏ=1，且所有transmon完美耦合到波导（波导耦合效率为1）。

  **半经典模拟**：将光子部分视为相干态，采用Born-Markov近似，对transmon写出主方程：
  d/dt ρ̂ = −i[H, ρ̂] + L[ρ̂]
  其中H = H_l + H_wg，H_l为相干驱动（含旋转波近似），H_wg描述通过波导的手性交换相互作用，L[ρ̂]为Lindblad耗散超算符。总Rabi频率Ω = Ω_wg + Ω_d，其中Ω_wg来自波导驱动、相位由transmon位置x_n和入射模式波数k决定，Ω_d为来自旁端口的局域驱动，振幅和相位可独立调节。通过输入-输出理论计算相干透射振幅t_coh = ⟨α̂⟩和相干透射概率T_coh = |⟨α̂⟩|²，非相干透射T_inc = T_tot − T_coh。

  **全量子计算**：显式包含光子波函数，考虑长度为L的波导、周期边界条件，动量取k_m = m·2π/L。系统波函数|Ψ(t)⟩包含双transmon激发、单transmon+单光子、双光子三种分量，由薛定谔方程i d/dt|Ψ⟩ = H|Ψ⟩驱动。初始态为两个以x_c(0) = −L/4为中心、宽度∆x = L/24的高斯波包，中心动量k0 = ω_a/v_g。耦合强度g = √(Γ v_g/L)。时间积分至t_f = (L/2)/v_g，此时波包中心位于x_c(t_f) = L/4。通过正交化|Ψ_inc⟩ = |Ψ⟩ − |Ψ_0⟩⟨Ψ_0|Ψ⟩提取非相干分量，计算功率谱密度S(k)、二阶关联函数g^(2)(τ)和单光子Wigner函数W(x,k)。

  ## 主要发现与核心结论

  1. **单transmon导致相干性丧失**：在共振驱动下，非相干透射概率T_inc随归一化Rabi频率Ω/(√2 Γ)先增大，在Ω = 0.5√2 Γ处达到T_inc = 1，此时t_coh = 0，透射光完全不能与入射光干涉。对应的功率谱密度展宽（图3），二阶关联函数在Ω = 0.5√2 Γ时g^(2)(0) = 5 > 1，表现为聚束。解析表达式为T_inc = Ω²/(2Γ²)·(∆² + Ω²/2 + Γ²/4)^(-2)。

  2. **双transmon恢复相干性**：在Ω/√2Γ = 0.5时，单transmon后T_inc = 1，但双transmon后T_inc = 0。两个transmon形成纯暗态"dimer"，有效退耦于波导场，从而把非相干光恢复为相干光。

  3. **非相干光主要来自双光子过程**：全量子计算显示，在弱驱动Ω = 0.01Γ下，非相干分量的功率谱密度和g^(2)(τ)随输入波包宽度∆x增大而趋近于半经典结果（∆x分别取1σ、2σ、4σ、8σ，σ = 20 v_g/(3Γ)）。弱相干驱动光子流约为10^(-4) Γ，N_ph > 2的成分不显著贡献。非相干透射概率在弱驱动下∝ Ω²，透射光功率∝ Ω²，因此非相干光功率∝ Ω^4，说明其主要是双光子过程。单光子过程因能量守恒应保持高斯型功率谱，而实测功率谱明显非高斯，故被排除。

  4. **动量反关联光子对的产生**：双光子概率密度|Ψ_inc^sym(k,k′,t_f)|²主要集中在k − k0 = −(k′ − k0)的直线上，表明一个transmon把两个独立光子转化为动量相反移动的光子对。 traced-out单光子Wigner函数在相空间中心出现负值，证明该光场是非经典的。

  5. **第二个transmon抑制光子对**：第二个transmon使|Ψ_inc^sym|²/|Ψ^sym|² ∼ 1/∆x^β，其中β = 3，即把部分非相干分量转化回Ψ_0，与半经典"相干性恢复"一致。

  6. **局域驱动实现光子统计工程**：仅波导驱动时（Ω_wg = 0.01Γ, Ω_d = 0），g^(2)(0) = 9，强聚束；仅局域驱动时（Ω_wg = 0, Ω_d = 0.01Γ），g^(2)(0) = 0，反聚束；两者叠加使相干透射≈0时（Ω_wg = 0.02Γ, Ω_d = −0.01Γ），g^(2)(0) ≈ 2.5 × 10^7，超强聚束。解析式g^(2)(0) = [Ω²/2 + Γ²/4 + Γ²(4Ω²/Ω_wg² − 2Ω/Ω_wg)] / [Ω²/2 + Γ²/4 + Γ²(Ω²/Ω_wg² − Ω/Ω_wg)]²表明，g^(2)(0)可通过Ω和Ω/Ω_wg从0调到∞。若Ω_d = −Ω_wg使总Rabi频率Ω = 0，则透射光即为入射相干光，g^(2)(0) = 1。

  7. **全量子与半经典自洽**：在弱驱动极限下，全量子结果（激发概率<10^(-16)）与半经典预测收敛，验证了双光子机制的正确性。

  ## 潜在研究方向

  1. **强驱动区域的机制**：全量子计算目前只模拟了弱驱动情形，此时N_ph > 2的多光子过程不重要。但文中提到强驱动下N_ph > 2的过程也会贡献非相干光，却仍能被第二个transmon恢复，这需要发展新方法（如多体散射理论或矩阵乘积态）来研究。

  2. **有限耦合效率与非理想性**：实际transmon-波导耦合效率虽可达99.9%，但非完美耦合、退相干、噪声会如何改变T_inc、g^(2)(0)和Wigner函数负值？这对实验实现和量子信息应用至关重要。

  3. **transmon作为多能级系统的修正**：本文把transmon近似为两能级系统。实际transmon具有弱非谐性，高激发态可能在较强驱动下参与，带来额外的非线性通道和泄漏。

  4. **光子对的量子态层析与纠缠验证**：文中通过Wigner函数负值论证非经典性，但未做完整的双光子纠缠见证。下一步可量化动量反关联光子对的纠缠熵、Hong-Ou-Mandel类干涉或Bell不等式违背。

  5. **局域-波导驱动的高维参数空间**：文中只讨论了一个transmon、三种典型驱动组合。多transmon、不同相位ϕ_n,d、非均匀失谐、时变驱动等将开启更丰富的光子统计工程和量子态制备。

  6. **与量子网络/量子计算的接口**：手性波导QED平台天然适合作为量子节点之间的确定性态传输和非经典光源。需要研究该非相干光/动量反关联光子对作为飞行量子比特或纠缠分发资源的保真度和可扩展性。

  ## 与林赛研究的关联

  这项工作与我们组的方向有几个具体接口：

  - **强场驱动与非线性光学**：transmon在这里扮演的是一个单原子非线性介质，把相干驱动光转换为非经典光。这与我们在HHG和阿秒物理中研究的"强场驱动下介质非线性响应导致高次谐波和超连续谱产生"在概念上一致——都是利用光-物质非线性相互作用重塑光子状态。不同之处在于能量尺度和非线性阶数：这里是微波波导中的弱驱动双光子过程，而HHG是光学强场下的多光子/隧穿电离过程。

  - **量子几何与莫尔材料**：论文中动量反关联光子对的形成依赖于波导中动量守恒和两光子散射的相空间约束。在莫尔超晶格或拓扑材料中，类似的波矢选择定则、能带几何和贝里曲率也会调控光-物质散射。我们可以借鉴"把两个光子转化为具有相反动量移动的光子对"这一图像，思考在莫尔体系中通过强场驱动产生携带相反赝自旋或谷指标的电子-空穴对或极化激元对。

  - **交变磁（altermagnetism）与手性**：手性波导QED中的单向耦合和自旋-动量锁定与交变磁材料中的自旋劈裂、手性磁振子模式有概念亲缘性。两者都涉及传播方向依赖的光-物质耦合，未来可探索把交变磁薄膜或自旋波波导作为微波/光学频段的手性非线性介质。

  - **阿秒与量子统计**：文中对g^(2)(τ)和Wigner函数的研究方法（关联函数、相空间分布）与我们在超快光谱和阿秒计量中使用的二阶/高阶关联、Wigner分布分析工具相通。可以思考如何把这类全量子波函数方法迁移到描述强场HHG光子的统计特性或阿秒脉冲的量子涨落。

**方法**：半经典主方程（Born-Markov + Lindblad）+ 全量子波函数计算 + 输入-输出理论（手性波导 QED 动量反关联光子对产生）

**原理**：N 个 transmon 两能级系统手性耦合一维无色散波导（仅与右传光子作用，耦合效率 1）；半经典路线——光子作相干态 + Born-Markov 主方程 dρ/dt = −i[H,ρ] + L[ρ]，总 Rabi 频率 Ω = Ω_wg + Ω_d（波导驱动与局域旁端口驱动，振幅相位独立可调），输入-输出理论分离相干/非相干透射；全量子路线——显式光子波函数 |Ψ(t)⟩ 含双 transmon 激发/单+单光子/双光子三分量，正交化提取非相干分量；机制链——单 transmon 导致相干性丧失（Ω=0.5√2Γ 时 t_coh=0）；非相干光主要来自双光子过程（弱驱动非相干功率 ∝ Ω⁴：透射功率 ∝ Ω² × 非相干比 ∝ Ω²；单光子过程因能量守恒应保持高斯谱而实测非高斯排除）；动量反关联光子对 k−k₀ = −(k′−k₀)（单 transmon 把两个独立光子转化为动量相反移动的光子对）；双 transmon 纯暗态 dimer 有效退耦波导、恢复相干性。
