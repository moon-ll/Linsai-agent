# High Harmonic Spin-Orbit Angular Momentum Generation in Crystalline Solids Preserving Multiscale Dynamical Symmetry

## 林赛的理解

这篇工作对我们林赛研究组具有重要的直接价值。它首次在固体HHG中实验证明了自旋-轨道角动量（SOI）的守恒规则，为我们利用圆二色HHG读出 Rashba/Moire 系统中的自旋轨道能带拓扑提供了可行的实验路线。核心发现是：总角动量 $J_m = mJ_1 + nQ$ 在强场非线性区域依然成立，这打破了以往认为自旋和轨道角动量在固体中独立守恒的认知。实验中观察到多阶OAM模式（$l = 0, \pm2, \pm4, \pm6, \pm8, \pm10$），且其分布与晶体三维旋转对称性（$n=3$, GaSe）直接相关。这意味着我们可以在强场驱动下，通过控制圆偏振和晶体取向来实现对HHG产物自旋-轨道结构的主动调控。

## 研究问题（Research Question）
本论文要回答的核心问题是：**在具有各向异性晶体对称性的固体中，自旋-轨道相互作用（SOI）如何影响高次谐波产生（HHG）中的角动量守恒规则？** 具体而言，研究者希望验证多尺度动力学对称性（multiscale dynamical symmetry）是否能够在强场非微扰区域维持总角动量守恒，并探索利用晶体对称性实现对结构光（structured light）自旋和轨道角动量的协同控制。

## 研究背景（Background）
高次谐波产生（HHG）和阿秒脉冲产生的 overarching framework 是时空对称性——动力学对称性（dynamical symmetry, DS）。DS 算符 $\hat{G}$ 作用于电子系统与外加周期光场的 Floquet 系统，满足 $\hat{G} \hat{H}(\vec{r}, t)\hat{G}^{-1} = \hat{H}(\hat{\gamma}_G \vec{r}, \hat{\delta}_{\hat{G}} t) = \hat{H}(\vec{r}, t)$，其独特之处在于同时在空间和时间维度上操作。DS 已被广泛应用于微扰和非微扰光-物质相互作用的普适规则预测，包括 HHG 偏振选择规则、分子对称性传感、以及光致对称性破缺现象。

然而，既有研究仅在气相原子（具有球对称性）和微扰 regime 下验证了 DS。对于固体系统，尽管其各向异性晶体对称性为结构光设计提供了更丰富的可能性，但复杂的多体效应（隧穿、带间加速、自相位调制、级联过程、再吸收等）使得理论框架的发展一直停留在理论层面。本研究首次将 DS 扩展到多尺度空间结构（自旋+轨道角动量）并通过固体系统实验验证。

## 研究方法（Methods）
**材料体系：** GaSe 晶体，禁带宽度 $E_g = 2.2$ eV，具有面内三重旋转对称性（$n=3$），厚度 2 mm。选择 GaSe 的原因是其显著的单轴各向异性（$n_e = 2.41$, $n_o = 2.74$ at 0.51 eV），是研究 SOI 的理想平台。

**驱动光源：** 红外脉冲，光子能量 0.51 eV，中心波长约 2.4 μm，脉冲宽度 80 fs（傅里叶极限），重复率 3 kHz。由 BBO 基光学参量放大器（TOPAS-prime）泵浦 Ti:sapphire 放大器产生。

**关键技术：**
1. **紧聚焦配置（tight focus）：** 使用焦距 6 mm 的非球面镜，将外发散角设为 402 mrad，确保光束以大角度斜入射进入晶体，从而激发强烈的 SOI。相比之下，松聚焦配置（外发散角 12.7 mrad）作为对照实验。
2. **自旋-轨道角动量层析（spin-orbit tomography）：** 使用空间光调制器（SLM, SLM-200, Santec）对谐波施加额外方位相位因子 $\exp(i\Delta l \phi)$，通过透镜傅里叶变换后在相机上成像，当 $\Delta l = -l_m$ 时中心亮斑出现，从而识别各阶谐波的 OAM 成分。
3. **圆偏振分辨光谱测量：** 使用消色差四分之一波片和线栅偏振器分析谐波的 RCP/LCP 成分。
4. **Laguerre-Gaussian 模式拟合：** 对空间图像进行二维拟合，验证六重结构源于间隔为 6 的不同 OAM 模式之间的干涉。

## 主要发现与核心结论

**核心发现：紧聚焦条件下，圆偏振高斯光束（$s_1=1$, $l_1=0$）入射 GaSe 晶体后，产生了包含多个 OAM 模式的结构化谐波，且总角动量守恒规则 $J_m = mJ_1 + nQ$（其中 $J_m = l_m + s_m$, $n=3$）依然成立。**

1. **SOI 效应显著：** 在紧聚焦（402 mrad）条件下，谐波出现 RCP 和 LCP 两类成分，且空间分布呈现六重对称性（与 GaSe 的 $n=3$ 对应）。在松聚焦（12.7 mrad）条件下，仅有 RCP 四阶和 LCP 五阶谐波，符合自旋角动量守恒规则，SOI 效应被抑制。

2. **OAM 模式识别：** 通过 SLM 层析成像，确认了从二阶到六阶谐波中包含的 OAM 模式：
   - 四阶 RCP：$l = 0, 6$
   - 四阶 LCP：$l = 2, 8$
   - 五阶 RCP：$l = -2, 4, 10$
   - 所有 $l_m$ 均为偶数（与方程（5）一致：$l_m = ml_1 + 2Q'$，其中 $l_1=0$）

3. **功率依赖关系：** 在脉冲能量 0.1 μJ（对应聚焦强度 0.15 TW cm$^{-2}$）的极端非线性区域，所有阶次的谐波强度均偏离微扰理论的幂律关系，证实了非微扰强场效应。

4. **晶体取向关联：** 旋转 GaSe 晶体绕光轴时，谐波的空间结构随之旋转，证明了非线性光学与 SOI 的结合使得宏观光学响应与微观光-物质相互作用通过晶体对称性联系起来。

5. **级联过程的关键作用：** 负 OAM 成分（如 $(3; -1, -2)$）的观测表明，HHG 过程涉及谐波产生与 SOI 的复杂级联转换，即使对于带隙以上非微扰谐波也是如此。

**核心结论：** 多尺度动力学对称性在固体 HHG 中作为光与固体的联合对称性有效运作，总角动量守恒规则即使在复杂的非线性过程和传播效应存在下依然成立。这为基于电子结构设计结构光（如通过 Floquet 工程）提供了可靠的理论框架。

## 潜在研究方向（Future Directions）
1. **Rashba/Moiré 系统中的圆二色 HHG 读出：** 本工作验证了利用晶体对称性读取自旋-轨道角动量的可行性，下一步可将类似方法应用于具有强自旋-轨道耦合的二维材料（如 MoS$_2$、WSe$_2$）或 Moiré 超晶格，系统研究自旋-轨道能带拓扑对 HHG 圆二色性的响应。

2. **Floquet 工程与动态调制：** 利用强场脉冲动态调制 Floquet 态，实现对矢量结构光的超快时间整形（ultrafast temporal shaping），这为阿秒脉冲产生中的自旋-轨道量子态工程提供了新途径。

3. **向极紫外区域延伸：** 当前实验在红外区域驱动，产生的谐波在极紫外区域。将该方法扩展到更高光子能量范围，可用于探测拓扑材料中的自旋-轨道效应。

4. **与元表面/光子晶体集成：** 将晶体对称性与元表面、光子晶体或光电装置的周期性结构同步，可能实现固体非线性光子学的功能扩展。

5. **理论框架的进一步完善：** 当前 DS 算符（方程（2）和（3））仅考虑基频光与晶体的相互作用。实际过程中存在复杂的级联效应和传播效应，需发展更完整的理论来描述这些多过程耦合。

6. **其他晶体对称性：** GaSe 具有 $n=3$ 对称性，不同的晶体点群（如 $n=4, 6$）可能产生不同的 OAM 模式选择规则，值得系统研究。

## 与林赛研究的关联

- **HHG 与阿秒：** 本工作直接相关于我们利用 HHG 产生阿秒脉冲的研究。固体 HHG 在强场驱动下产生的 OAM 结构化谐波，可作为自旋-轨道量子态的新型探针，为阿秒时间尺度研究自旋-轨道动力学提供了可能。

- **Rashba 物理：** GaSe 本身是具有非线性光学响应的半导体。本工作的多尺度 DS 框架可推广至具有 Rashba 自旋劈裂的系统，通过圆二色 HHG 谱读取自旋-轨道能带拓扑结构随动量空间的分布。

- **Moiré 系统：** Moiré 工程是当前强关联物理的热点。本工作证明晶体对称性可以通过 SOI 与 HHG 产物耦合，为利用 Moiré 超晶格的对称性实现 OAM 结构化谐波提供了理论依据。

- **强场驱动与量子几何：** 非微扰强场（0.15 TW cm$^{-2}$）与物质的相互作用涉及复杂的量子几何效应（如贝里曲率、量子度规）。本工作中观测到的总角动量守恒规则在强场区域依然成立，这为探索量子几何对 HHG 的影响提供了重要的实验依据。

- **交变磁：** 若将交变磁（alternating magnetic fields）引入系统，可能进一步调控自旋-轨道耦合强度，从而实现对 HHG 产物自旋-轨道结构的超快磁控制。

**方法**：固体 HHG 自旋-轨道角动量产生（多尺度动力学对称性：紧聚焦 GaSe 中 J_m=mJ₁+nQ 守恒 + SLM 层析识别 OAM 模式 l=0,±2,4,6,8,10）

**原理**：把动力学对称性（DS）框架扩展到多尺度空间结构（自旋+轨道角动量）并在固体中实验验证：总角动量守恒 J_m=mJ₁+nQ（J_m=l_m+s_m，n=3 为 GaSe 三重旋转对称性）在强场非微扰区依然成立——打破'自旋与轨道角动量在固体中独立守恒'的旧认知。关键技术：紧聚焦配置（f=6 mm 非球面镜、外发散角 402 mrad）使光束大角度斜入射激发强 SOI（对照：松聚焦 12.7 mrad 仅 RCP 四阶/LCP 五阶、SOI 被抑制）；自旋-轨道层析——SLM 对谐波施加方位相位 exp(iΔlφ)，透镜傅里叶变换成像，Δl=−l_m 时中心亮斑出现识别各阶 OAM 成分；圆偏振分辨（消色差 QWP+线栅偏振器）；Laguerre-Gaussian 二维拟合验证六重空间结构源于间隔 6 的 OAM 模式干涉。结果：紧聚焦下二至六阶谐波含多 OAM 模式——四阶 RCP l=0,6、四阶 LCP l=2,8、五阶 RCP l=−2,4,10（均为偶数，符合 l_m=ml₁+2Q′）；0.1 µJ（0.15 TW/cm²）极端非线性区全阶偏离微扰幂律；晶体旋转带动谐波空间结构旋转（宏观响应-微观相互作用经晶体对称性联系）；负 OAM 成分（如 (3;−1,−2)）证明谐波产生与 SOI 的级联转换（带隙以上非微扰谐波亦然）。
