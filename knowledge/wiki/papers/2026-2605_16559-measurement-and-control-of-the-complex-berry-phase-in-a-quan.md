• # Measurement and Control of the Complex Berry Phase in a Quantum System —— 复 Berry 相位的实验测量与非幺正几何操控

  ## 林赛的理解

  这篇工作对我们"瞬态量子相位光学读出"课题（key-transient-quantum-phase-optical-20260726）的价值不在于实验平台（超导比特），而在于它给出了一套**可移植的"几何相位提取协议"**：如何用干涉学手段把复几何相位拆成实部（态间干涉 → 量子态层析）与虚部（存活概率比值 → 衰减的几何调制）分别读出，并用正反向回路之比严格消除动力学相位。这正是强场/超快光学里"如何把几何相位从动力学相位背景中剥离"这一老大难问题的同构解法——我们在 HHG/阿秒泵浦探测里面对的正是同一个结构：演化相位 = 动力学相位 + 几何相位 + 耗散诱导的非幺正因子。文中"虚部几何相位正比于反厄米哈密顿量期望值、源于实际轨迹对理想绝热轨迹的滞后"这一物理解像（App. C），可以直接借用来解释强场驱动开放体系中的几何衰减调制。另外，"几何滤波"（geometric filtering）选择性放大/衰减本征分支的思路，与我们在莫尔体系里用驱动路径工程量子几何响应的思路高度同构，值得写进方案的"可迁移方法学"一节。

  ## 研究问题

  论文要回答的核心问题是：**能否在完全量子（而非经典模拟平台）的体系中，同时测量复 Berry 相位的实部与虚部，并利用虚部实现确定性的非幺正量子操控？**

  具体分解为三个子问题：
  1. 非厄米（NH）体系中绝热演化获得的复几何相位 θ = θ⁽ʳ⁾ + iθ⁽ⁱᵐ⁾，其实部（对应厄米 Berry 相位）与虚部（对应态依赖的放大/衰减）能否被实验独立分离并定量读出？
  2. 虚部几何相位是否具有路径依赖性（回路方向 η = ± 的符号翻转），且服从规范不变的标度行为（开放回路线性缩减）？
  3. 虚部引起的本征分支增益/损耗能否构成一个"几何非幺正门"，即仅由参数空间路径几何决定的、对 Bloch 球的非线性概率偏置映射？

  ## 研究背景

  - Berry 相位是绝热量子演化绕参数空间闭合回路获得的几何相位，是几何量子门（对控制误差具有内禀鲁棒性）[1–3]、测量诱导相位现象 [4,5]、以及凝聚态平台（石墨烯量子霍尔 [6]、相位磁力计 [7]、超冷原子合成规范场 [8]）中的基础概念。
  - 非厄米哈密顿量最初为描述开放量子动力学而发展，现已成为描述多种经典与量子平台有效演化的有力框架 [9–16]。NH 体系具有闭系中没有的复谱与本征态性质：exceptional point（EP）简并、非正交本征右矢、手征态转移；其绝热演化获得**复 Berry 相位**——实部是厄米 Berry 相位的推广，虚部编码哈密顿量反厄米部分引起的态依赖放大/衰减。
  - 此前复 Berry 相位仅在经典平台被观测：反馈耦合振子 [17]、光机械系统 [18]；理论工作预言了 NH 多体体系中复 Berry 相位的对称保护量子化行为 [19]。**在真正的量子体系中同时读出虚实两部并用于控制，是本文填补的空白。**

  ## 研究方法

  **方法卡 1：耗散工程实现有效非厄米比特（装置配置）**

  - **原理**：在 transmon 电路的子空间中实现有效 NH 演化。利用 {|g⟩,|e⟩,|f⟩} 三能级结构，工程化耗散环境使 |f⟩ 弛豫率 γ_f 远小于 |e⟩ 弛豫率 γ_e；对 |e⟩→|g⟩ 量子跳跃做后选择（postselection，无跳跃轨迹），{|e⟩,|f⟩} 流形内的条件动力学由有效 NH 哈密顿量 H = [[∆−iΓ, Je^{iϕ}], [Je^{−iϕ}, 0]] 描述（式 1）。
  - **参数表**（数值原样，出处见正文）：
    - 差分衰减速率 Γ ≡ (γ_e − γ_f)/2 = **0.426 μs⁻¹**（Sec. 3A）
    - 失谐 ∆ ≡ ω_d − ω_q（驱动频率减比特频率）
    - 有效耦合 J e^{iϕ} = J_x + iJ_y，驱动相位 ϕ(t) 在 0→2π 调谐构成闭合回路
    - 实验用失谐 ∆/2π = **3 MHz、1.34 MHz、0.81 MHz**（Fig. 2）；门操控演示用 ∆/2π = **1.05 MHz、0.51 MHz**（Fig. 5b）
    - 器件：MIT Lincoln Laboratory SQUILL 铸造厂制造；|e⟩ 布居经参数化 SWAP 转移到邻近比特实现高保真单次读出 [22]
    - 读出后对仍停留在 {|e⟩,|f⟩} 流形的实验试次做后选择
  - **适用边界**：|f⟩→|e⟩ 残余弛豫（不被式 1 捕获）对观测动力学造成小扰动 [21]；这是后续与理论偏差的主要来源之一。
  - **代表作**：Chen et al., PRL 127, 140504 (2021)（同一平台的 NH 动力学量子跳跃）[21]；Erdamar et al., PRX Quantum 7, 010337 (2026)（NH 比特黎曼面拓扑 + 绝热捷径）[27]。

  **方法卡 2：实部几何相位的干涉学测量（测量序列）**

  - **原理**：实部几何相位调制两个瞬时本征态之间的干涉，用四步干涉协议 [23] 读出。
  - **序列**（四步，Sec. 3B）：
    1. 绝热演化沿 C₊：初态 1/√2(|R₊⟩+|R₋⟩)，因 θ₋,C₊ = 2π−θ₊,C₊，两分量获得相反几何相位；
    2. 本征态交换：沿本征基 y 轴加共振 π 脉冲，交换 |R₊⟩↔|R₋⟩（e^{−iπ/2}Ŝ），消除动力学相位贡献；
    3. 沿反向回路 C₋ 再绝热演化：末态相对相位为 4θ₊,C₊，分解为旋转 4θ⁽ʳ⁾ 与相对标度 e^{−4θ⁽ⁱᵐ⁾}；
    4. 后选择量子态层析：定义可观测量 Ŝx、Ŝy，由 x = ⟨ψ₃|Ŝx|ψ₃⟩、y = ⟨ψ₃|Ŝy|ψ₃⟩ 得 **θ⁽ʳ⁾₊,C₊ = (1/4) arctan(y/x)**。
  - **参数表**：
    - 单回路时长 **T = 3 μs**
    - 相位主分支在 J = 0 处固定，随耦合增大按 π/2 模数解析延拓
    - 对相同回路重复（η′ = η），几何相位与动力学相位完全相消，作为零相位基准
  - **适用边界**：要求近绝热演化；同一方向双回路构型给出恒零相位，可用于系统校验。

  **方法卡 3：虚部几何相位的存活概率比值法（测量序列）**

  - **原理**：虚部几何相位改变态范数，直接体现在 {|e⟩,|f⟩} 流形内的瞬态存活概率上：∥Ĉ₊|R₋⟩∥²/⟨R₋|R₋⟩ = e^{−2(λ⁽ⁱᵐ⁾₋+θ⁽ⁱᵐ⁾₋,C₊)} ≡ P(C₊)₋（式 9）。注意与经典驱动耗散谐振器的绝对稳态增益不同，此处测量的是**上界为 1 的瞬态存活概率**，且 |θ⁽ⁱᵐ⁾₋,Cη| < |λ⁽ⁱᵐ⁾₋|，几何放大严格从属于主导的动力学耗散（App. C）。
  - **序列**：正反向回路取范数比值消除虚部动力学相位——∥Ĉ₊|R₋⟩∥²/∥Ĉ₋|R₋⟩∥² = e^{−4θ⁽ⁱᵐ⁾₋,C₊} = P(C₊)₋/P(C₋)₋（式 10），即两个回路方向的后选择成功概率之比 p±,Cη 直接给出虚部相位。
  - **参数表**：
    - 回路时长 **T = 3 μs**；开放回路取 ϕ: 0→2π/n，总时长固定 **T = 3 μs**
    - 绝热增强的相位速度包络：余弦半 ramp **750 ns** + 平台相位速度段 **1500 ns**，末端对称 ramp 至零（Sec. 3C）
    - 实测绝热因子 |a±| **< 0.3**（Fig. 7，近似绝热）；从 |R₊⟩（最强阻尼本征态）出发仅为准绝热
  - **适用边界**：从 |R₋⟩（阻尼最弱、受正几何相位相对放大）出发数据噪声更低、与理论符合更好；从 |R₊⟩ 出发受非绝热过渡惩罚。

  **方法卡 4：几何非幺正门（非幺正控制演示）**

  - **原理**：在虚实两部测量序列末端再加一个 π 旋转，抵消态依赖动力学相位；净作用为本征基对角映射 U_eff ∝ diag(e^{+i2θ}, e^{−i2θ})，同时含幺正旋转 θ⁽ʳ⁾ 与非幺正增益/损耗因子 θ⁽ⁱᵐ⁾；归一化后对 Bloch 球起非线性映射，把布居按 θ⁽ⁱᵐ⁾ 符号重新分配。输出概率 P₋⁽η′,η⁾ = |β|²e^{+4θ⁽ⁱᵐ⁾} / (|β|²e^{+4θ⁽ⁱᵐ⁾} + |α|²e^{−4θ⁽ⁱᵐ⁾})（式 12）。
  - **参数表**：
    - 演示用虚部相位幅值 |θ⁽ⁱᵐ⁾| = **0.17**（J = 2.17 rad/μs，∆/2π = 0.51 MHz）与 |θ⁽ⁱᵐ⁾| = **0.08**（J = 4.78 rad/μs，∆/2π = 1.05 MHz）
    - 相位速度包络：单余弦脉冲，全周期 **1.8 μs**（Fig. 5c）与 **2.7 μs**（Fig. 5d）
    - 模拟：Lindblad 主方程计入 |f⟩→|e⟩ 非相干弛豫与非绝热性，与实验数据极好符合
  - **适用边界**：大 J 与大 |∆| 处虚部被抑制（近似厄米本征态绝热跟随）；J、∆ 接近 EP 时非幺正贡献显著；长时间相互作用下 |f⟩→|e⟩ 弛豫降低门保真度。

  **理论框架（计算设置）**：
  - 复本征值 E± = (ε±δ)/2，ε = ∆−iΓ，δ/2 = √(J² + (ε/2)²)，主分支取值；双正交基右/左本征矢 |R±⟩、⟨L±|（式 2）。
  - Berry 联络 A±(ϕ) = i⟨L±|∂ϕ|R±⟩/⟨L±|R±⟩ = (1 ∓ ε/δ)/2（式 3）；闭合回路几何相位 θ±,Cη = πη(1 ∓ ε/δ)（式 4）；η = ± 标记回路方向，± 标记初态本征支。
  - 厄米极限（Γ→0）共振点（∆ = 0）退化为 θ±,Cη = πη，即熟知的 ±π Berry 相位；NH 情形下复比值 ε/δ 引入偏离厄米基线的附加几何分量。
  - 动力学相位 λ± = −∫₀ᵀE±(t)dt，其中 λ⁽ʳ⁾± = −T(∆±δr)/2，λ⁽ⁱᵐ⁾± = T(Γ±δi)/2。
  - NH 绝热判据 a_nm = |⟨Ln|∂tRm⟩|/|En−Em| · e^{−Inm(t)} ≪ 1（式 A1），含相对增益/损耗因子；本文情形 a±(t) = Jϕ̇/|δ|² · e^{±Im(δ)t}——指数因子使 a₋ 消失、a₊ 发散，体现 NH 绝热定理的失效不对称性。
  - 全局规范：复混合角 α = αr + iαi（式 B1–B3），扩展参数空间 M = {(ϕ, αr, αi)} 为物理参数空间的双覆盖，NH Berry 曲率由厄米情形（Γ = 0）经混合角复值解析延拓得到（App. B）。

  ## 主要发现与核心结论

  1. **实部几何相位测量**：在 T = 3 μs、∆/2π = 3 MHz 下层析测量 ⟨Ŝx⟩、⟨Ŝy⟩，对 ∆/2π = 3、1.34、0.81 MHz 三个失谐提取 θ⁽ʳ⁾₊,η；实验与理论（实/虚线）极好符合。相反回路方向（C₊ 与 C₋）导致相位符号反转；相同回路加中间 SWAP（η′ = η）时几何相位与动力学相位完全相消，全驱动幅值范围恒为零。
  2. **虚部几何相位测量**：单回路存活概率 p±,Cη（T = 3 μs）含虚实两部贡献，经正反回路比值（式 10）消去动力学相位后提取 θ⁽ⁱᵐ⁾。三个失谐（0.81、1.34、3.00 MHz）下与式 (4) 理论值符合良好：从 |R₋⟩ 出发（圆点）积累**正相位**且噪声更低（受正几何相位相对放大），从 |R₊⟩ 出发（方点）积累**负相位**且仅为准绝热、噪声更高。开放回路（ϕ: 0→2π/n，T = 3 μs）中 θ⁽ⁱᵐ⁾ 随回路比例**线性缩减**，是规范不变性的体现。
  3. **时间分辨动力学**（Fig. 4）：相对空闲情形的指数衰减，控制回路 C± 调制瞬时衰减率——初态 |R₋⟩ 时 C₋ 降低衰减率、C₊ 增强之，|R₊⟩ 时反转；回路方向依赖性印证几何起源。Bloch 球轨迹显示：C₋（C₊）回路采样更低（更高）耗散区域，即与损耗更小（更大）的 |f⟩（|e⟩）更大重叠。
  4. **虚部起源的物理图像**：瞬时态偏离理想绝热轨迹的滞后——滞后向阻尼最弱本征态时相对放大，向阻尼最强本征态时衰减增强；形式化为虚部几何相位正比于反厄米哈密顿量期望值（实际轨迹与理想绝热演化之差，App. C）。
  5. **几何非幺正门**：输入输出关系（式 12）呈非线性概率偏置；|θ⁽ⁱᵐ⁾| 越大偏置越强——实测 |θ⁽ⁱᵐ⁾| = 0.17 比 0.08 的偏置效应更强，Lindblad 模拟（含 |f⟩→|e⟩ 跳跃与非绝热性）与实验极好符合。C₊C₋ 序列放大 |R₋⟩，C₋C₊ 衰减 |R₋⟩，C₊C₊ 不产生几何相位（直线响应）。
  6. **参数相图**（Fig. 6）：J、∆ 相图上实验/Lindblad 模拟相互符合但与裸理论（式 4）仅边际符合，偏差归因于 |f⟩→|e⟩ 弛豫与非绝热跃迁；实验数据涟漪归因于非绝热演化。大 J、大 |∆| 处虚部抑制，近 EP 处非幺正贡献显著（注意 ∆ = 0 且 |J| < Γ/2 时，尽管近 EP，虚部消失但实部仍贡献非幺正项 [26]）。
  7. **绝热性定量**：|a±| < 0.3（Fig. 7），a₊ 在所有情形更大（|R₊⟩ 为最强阻尼态，只能准绝热）；实验中加 cosine ramp（750 ns 半周期 + 1500 ns 平台）增强绝热性。
  8. **概念性结论**：复几何相位是"保持几何特性、引入可控增益/损耗"的路径依赖幅度调制；实部与虚部可被独立测量并分别用于量子控制，确立了两者之间的清晰几何区分，并实验确认了 NH 体系独特的绝热行为。

  ## 潜在研究方向

  1. **几何滤波（geometric filtering）**：虚部几何相位可构造选择性放大/衰减特定本征态的非幺正门，纯由控制路径几何决定；有望增强量子态制备协议，并实现"利用而非对抗环境耗散"的更高效误差抑制。
  2. **量子虚时演化的几何实现**：虚时演化算法 e^{−Ht} 需变分优化的幺正操作序列，计算昂贵；本文的本征分支放大 |ψ⟩ = Σc_n|n⟩ → Σc_n e^{−θ⁽ⁱᵐ⁾_n}|n⟩ 天然模拟虚时演化结构——几何相位能否减少或消除变分近似需求，是量子模拟的开放方向。
  3. **绕过后选择指数代价**：NH 物理中的拓扑边缘态、EP 物理在量子体系中受后选择指数代价限制；用参数路径工程最小化不利虚部相位，可扩展 postselected NH 演化的实用区间。
  4. **连续变量体系与量子噪声**：复 Berry 相位应同样出现于微波谐振腔等连续变量体系，但几何相位与量子噪声的相互作用基本未被探索——或产生量子放大、压缩与传感、通信新工具。
  5. **本文自身局限**：|f⟩→|e⟩ 非相干弛豫与非绝热跃迁在长时间相互作用下降低保真度（Fig. 6 理论-实验偏差）；从 |R₊⟩ 出发仅能准绝热；虚部测量受主导动力学耗压制（|θ⁽ⁱᵐ⁾| < |λ⁽ⁱᵐ⁾|），信噪比受限。

  ## 与林赛研究的关联

  - **HHG/强场驱动**：强场驱动固体或原子中的绝热/非绝热演化同样积累几何相位 + 耗散相位。本文"正反驱动循环取比值消动力学相位"的协议（式 10）可直接移植到 HHG 泵浦-探测与阿秒 streaking 的相位提取设计中——特别是区分辐射相位的几何贡献与动力学贡献。
  - **量子几何**：复混合角 α = αr + iαi 与"Berry 曲率由厄米情形经复值混合角解析延拓"的全局构造（App. B），为我们在莫尔/拓扑体系中处理复化量子几何（含耗散的量子度规与曲率）提供了严格的数学模板。
  - **交变磁/莫尔**：开放莫尔体系（耗散、驱动）中量子几何响应的复相位分解（实部 → 带内几何相位；虚部 → 态依赖放大/衰减）是本文核心信息，与我们"超快读出量子几何/序参量"的方案中"几何 vs 动力学贡献分离"这一关键方法论需求直接对应。
  - **瞬态相位读出课题（key-transient-quantum-phase-optical-20260726）接口**：课题方案写作时可引用本文三点方法学资产——① 干涉学实部测量协议（四步序列 + 本征态 SWAP 消动力学相位）；② 存活概率比值法虚部测量（数值忠实基准：T = 3 μs、cosine ramp 750 ns/1500 ns）；③ 非幺正门偏置律（式 12，输入 P₋⁽⁰⁾ → 输出 P₋⁽η′,η⁾ 的非线性映射）作为"路径工程控制瞬态响应"的概念先例。

## 研究方法（方法卡）
<!-- methods-backfill:v1 -->
**方法**：超导比特复 Berry 相位干涉学测量与几何非幺正门

**原理**：在 transmon {|g⟩,|e⟩,|f⟩} 子空间经耗散工程实现有效非厄米两能级演化（对 |e⟩→|g⟩ 量子跳跃做后选择）。实部几何相位用四步干涉协议（双回路 + 本征态 SWAP 消动力学相位）从态层析读出 θ(r)=(1/4)arctan(y/x)；虚部用正反回路存活概率比值 P(C₊)/P(C₋)=e^{−4θ(im)} 提取；进一步构成由参数路径几何决定的非线性概率偏置'几何非幺正门' U_eff ∝ diag(e^{+i2θ}, e^{−i2θ})。

**参数表**：
