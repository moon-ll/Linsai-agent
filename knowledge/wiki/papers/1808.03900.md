## 研究问题（Research Question）

本文提出并回答两个核心问题。第一，Weyl 半金属（WFM）中由手征异常（chiral anomaly）诱导的正纵向磁电导（longitudinal magnetoconductance, LMC）能否用一套**统一的解析理论**描述，即同时覆盖经典极限（|E_F| ≫ ℏω_c，Δσ ∝ B²）与超量子极限（|E_F| ≪ ℏω_c，Δσ ∝ B）之间此前空缺的中间区域？作者明确指出"理论 investigation of the anomalous LMC in the intermediate regime… is still absent"，即要补上 Landau 量子化与手征异常相互作用的中间区空白。

第二个、也是更"卖点"的问题：能否找到一个**基于输运测量的、无歧义的 WSM 判据**？作者的动机在于现有两条鉴定路径都不够干净——ARPES 直接看 Weyl 节点受"spectroscopic resolutions"限制；而正 LMC（即负磁阻）"only a necessary condition for identifying the WSM phase, but not a sufficient condition"，尤其因为实验中弱反局域化（weak anti-localization, WAL）贡献的负磁电导常常同时存在，使二次/线性场依赖的理论比对变得 equivocal。

作者的破局点是一个此前理论未披露的信号：**叠加在正 LMC 之上的、以 1/B 为周期的量子振荡**。核心论点是：不同于会叠加在正 LMC 上从而被 WAL 的负磁电导掩盖的场依赖标度，量子振荡这一特征不会被 WAL 掩盖，因此它的观测可作为 WSM 手征异常的**充分条件**（sufficient condition）指纹。

## 研究背景（Background）

Weyl 半金属的低能激发是带电的 Weyl 费米子，低能谱在简并的能带交点附近形成非简并的三维 Dirac 锥，即 Weyl 点。Weyl 点必须成对出现、手征性相反，扮演动量空间中 Berry 曲率的源与汇，其出现要求打破空间反演或时间反演对称性。WSM 态于 2015 年首先在 TaAs 中被实验实现（TaAs、TaP、NbP、NbAs 等系列随后跟进）。

手征异常（Adler-Bell-Jackiw 异常）指不同手征性 Weyl 费米子的分别人数守恒律被破坏：平行电场与磁场可在相反手征的谷之间泵浦 Weyl 费米子，建立谷间载流子数不平衡，从而产生正 LMC（或等价地，负磁阻）。Weyl 半金属还展示出其他手征异常诱导的异常输运性质：光学旋光性（optical gyrotropy）、面内霍尔效应（planar Hall effect）、以及费米弧表面态的**非局域**量子振荡。

理论上此前的状态是"两个极端各自成熟、中间缺失"：Son & Spivak (PRB 88, 104412 (2013)) 与 Burkov (PRB 91, 245157 (2015)) 在经典极限 |E_F| ≫ ℏω_c 给出 Δσ(B) ∝ (B/E_F)²；而 Xiao, Law & Lee (PRB 96, 165101 (2017)) 独立地在超量子极限 |E_F| ≪ ℏω_c 给出 Δσ(B) ∝ B。实验上，TaAs 族的正 LMC 还面临 current jetting（电流喷流）伪影问题——高迁移率半金属在 B∥I 时会因磁致电导各向异性导致电流分布不均匀，产生表观负 LMR；另有工作（如 Nat. Commun. 7, 11615 (2016) 关于 TaP 的工作）指出即使手征性未良好定义（费米面口袋包含成对 Weyl 节点、总 Berry 通量为 0）仍能观测到大的负磁阻，说明"负 LMR ⇒ 拓扑非平凡"这一推论并不成立。作者此前的 PRB 96, 155141 (2017) 也已讨论过 Dirac 与 Weyl 情形在输运中的区分问题。

## 研究方法（Methods）

**理论框架**：Landau 量子化 + 线性化 Boltzmann 方程。模型为一个含两个相反手征 Weyl 点的3D WSM，取 **B = (B, 0, 0)** 沿 x方向，**E = (E, 0, 0)** 沿 x 方向（即 E ∥ B 的反常构型）。连续低能哈密顿量取 H_χ(k) = χ·υ_F·(ℏk + eA)·σ，电子电荷取 −e。

**Landau 能谱（精确求解，Eq. 2）**：ε_n^χ(k_x) = −χℏυ_F k_x（n = 0 手征 LL）；sgn(n)·√(2|n|(ℏω_c)² + (ℏυ_F k_x)²)（n ≠ 0）。磁长度 ℓ_B = √(ℏ/eB)，回旋频率 ω_c = υ_F/ℓ_B，每条 LL 简并度 Ω_n = 1/(2πℓ_B²)。纵向群速度 v_x,n = ∂ε_n/∂(ℏk_x)：n = 0 时为 −χυ_F（常数，手征性体现），n ≠ 0 时为 ℏυ_F²k_x/ε_n。

**态密度与振荡因子**：单谷 DOS ρ(E_F) = ρ_0·Θ，其中 ρ_0 = 1/(2πℓ_B²ℏυ_F)，Θ = 1 + 2Σ_{n=1}^{n_c} λ_n，λ_n = √(1 − 2|n|(ℏω_c/E_F)²)，n_c = sgn(E_F)·int(E²_F/2(ℏω_c)²)。Θ 随 E_F 强烈振荡，在 E_F = sgn(n)√(2|n|)ℏω_c 处因 van Hove 奇异性而周期性发散。

**输运计算**：线性响应稳态分布函数 f_n^χ(k_x) = f_0(ε_n^χ) − f_0′(ε_n^χ)·g_n^χ(k_x)。线性化 Boltzmann 方程 e·v_x,n·E = −g_n^χ − g^χ/τ_intra − g^χ/τ_inter，弛豫时间分为谷内（intravalley）与谷间（intervalley）两个，且假设 **τ_inter ≫ τ_intra**（因 Weyl 点在布里渊区相距较远，谷间散射弱）。对费米面态求平均 ⟨·⟩_χ 后自洽求解得到 g^χ = −⟨v_x,n⟩_χ·eE·τ_inter。

**手征异常的显式提取**：⟨v_x,n⟩_χ = ΔN_ch^χ·h/ρ(E_F)（正比于 1/DOS），其中 ΔN_ch^χ = (1/2πℓ_B²)Σ{sgn(v_x,n)}，定义在 χ谷中费米面处右行与左行通道数之差。由于非手征的 n ≠ 0 LL 的左右行波总是成对出现、贡献相消，ΔN_ch^χ 仅由 n = 0 手征 LL 决定，等于 −χ/(2πℓ_B²)。由此得到 g^χ = χ·Δμ，Δμ = eEℓ_e/Θ，ℓ_e = υ_F τ_inter——这正是**非平衡手征化学势**，两谷局域化学势相对 E_F 等量反向偏移 Δμ（图 1 蓝色虚线）。

**电流与电导分离**：j_x = −(e/2πℓ_B²)Σ_{χ,n}∫v_x,n g_n^χ(−f_0′)dk_x/2π。分离为 σ(B) = σ_D + Δσ(B)，零场 Drude 电导 σ_D = n_e e²/(ℏk_F·υ_F·τ_intra)，k_F = |E_F|/ℏυ_F，n_e = k_F³/(3π²)。在 τ_intra/τ_inter ≪ 1 的领头阶，Δσ(B) = (n_e/h)(ΔN_ch⁻ − ΔN_ch⁺)Δμ，即反常 LMC 源于手征化学势 Δμ 在 n = 0 手征通道上驱动额外电流。

**数值**：全部为解析式 + 参数化数值作图，无第一性原理计算（未用真实能带结构，也未含倾斜/type-II Weyl 锥）。

## 主要发现与核心结论（Main Results）

**（1）统一量子公式（Eq. 15，全文核心结果）**

Δσ(B) = (e²/h)·[eB·υ_F·τ_inter/ℏ]·(1/Θ)

统一了经典与超量子两个极限。经典极限 |E_F| ≫ ℏω_c 时把 Θ 的求和换成积分得 Θ ≃ 2(ℏω_c/E_F)²，Eq.(15) 化为 Eq.(16)：Δσ(B) = (e²/4π²ℏ)·(eB)²υ_F²/E_F²·υ_F τ_inter，恢复 Son-Spivak/Burkov 的经典公式（图中 Fig. 2(c) 红色虚线），且经典公式与量子公式的包络在 |E_F| ≫ ℏω_c 时近似一致。超量子极限 |E_F| < √2ℏω_c（费米面只跨 n = 0 LL，n_c = 0，Θ = 1）时化为 Eq.(17)：Δσ(B) = (e²/2π²ℏ)(eBυ_F τ_inter/ℏ)，与 Xiao/Law/Lee 结果一致（差别仅在后者多一个 1/2 前因子）。强场区两式显著偏离，这正是统一公式相对两极限外推的价值所在。

**（2）LMC 呈现以 1/B 为周期的量子振荡**

由于 Δμ ∝ 1/Θ，而 Θ 随 E_F 强烈振荡，且 Δσ ∝ Δμ，两者同步振荡：在 E_F = sgn(n)√(2|n|)ℏω_c（n ≠ 0）处 DOS 发散、Δμ 周期性归零。振荡的物理来源被明确归结为**非平衡手征化学势的振荡**，而非普通朗道量子振荡（后者出现在横向电导、E ⊥ B）。Fig. 3(a)(b) 给出 Δμ 与 Δσ(B) 随 B 的变化，Fig. 3(c) 将 Δσ 重绘为 B⁻²Δσ/σ₀ 随 1/B 的函数，确认等间距周期性。

**（3）定量周期公式（Eq. 18）**

Δ(1/B) = 2eℏ(υ_F/E_F)²

Fig. 3 所用参数为 E_F = 2ℏω_c|_{B=1T} = 2υ_F√(eℏ[B=1T])，给出 Δ(1/B) = 0.5/T，图中实测周期与之一致。同时指出 Δσ(B) 的包络在小1/B（大 B）区明显偏离经典公式预言的 B² 依赖。

**（4）振荡被认定为 WSM 手征异常的指纹**

论文明确宣称："The quantum oscillations superposed on the positive LMC are a sufficient condition for identifying a WSM material."论证要点有三：其一，振荡叠加在正 LMC 之上，不会被 WAL造成的负磁电导掩盖（而二次/线性场依赖会被掩盖）；其二，出现在纵向上，是"quite different from the usual SdH oscillations"；其三，作者指出这类振荡**此前已在多篇实验中被观测到**——Ref.[21] = Li et al., Nat. Commun. 6, 10137 (2015)（Cd₃As₂ 纳米线的负磁阻，Figs. 3(a,b)）；Ref.[26] = Zhang et al., Nat. Commun. 7, 10735 (2016)（Fig. 2(d)）；Ref.[29] = Du et al., Sci. China Phys. Mech. Astron. 59, 657406 (2016)（Fig. 3(d)）。即本文是**对已有数据的重新诠释**，而非预言新现象。

**（5）LMC 正比于谷间弛豫时间 τ_inter**

因非平衡手征化学势只能通过谷间散射弛豫，Δσ ∝ τ_inter，这使 τ_inter 成为直接决定 LMC 幅值的材料参数。

**（6）三幅图的结构**：Fig. 1(a)(b) 为 χ = +/− 两谷的 LL 图（n = 0 斜率相反，蓝色虚线示意手征异常导致的局域化学势反向偏移）；Fig. 1(c) 为 DOS 随 E_F/ℏω_c 的强振荡；Fig. 2(a)(b)(c) 分别为 Δμ、σ_D、Δσ(B) 随 E_F/ℏω_c 的变化（τ_inter = 5τ_intra，B = 1T，σ₀ = (2e²/h)[B=1T]υ_F τ_intra/h 为电导单位）。

## 潜在研究方向（Future Directions）

**方法与理论上的局限**

论文做了若干明确的理想化假设，直接限定了结论的适用范围。模型只含**一对** Weyl 点、单一锥、各向同性线性色散，**未包含 type-II 倾斜 Weyl 锥、multi-Weyl 点、多谷结构或实际材料能带**；τ_inter 视为与磁场无关的常数；只处理线性响应与稳态直流情形；E ∥ B 严格平行、且未考虑电极/接触电阻与电流分布（current jetting）问题。真实材料中若 E_F 离 Weyl 点太远，LL 会趋于半连续，"impurity scattering may obscure the quantum oscillations, especially at low fields"——作者承认高质量 WSM 中需在足够强磁场、低温下才能显现。

**最重要的一点：作者自己随后削弱了本文的唯一性主张。** 在同组的后续工作 PRB 100, 235105 (2019)（"Positive longitudinal spin magnetoconductivity in Z₂ topological Dirac semimetals"）中，作者明确写道："it is further demonstrated that the quadratic or linear field dependence of the positive LMC is not unique to the chiral anomaly"，并把 1/B 振荡这一机制推广到拓扑 Dirac 半金属的 Z₂ 异常（LSMC）中——即同样的振荡指纹也出现在**并非 Weyl**的体系里。这说明"1/B 周期性振荡"作为 WSM 专属指纹的排他性是有限的。

**领域内的直接争议**

关于"正 LMC / 负 LMR 是手征异常的证据"这一前提本身存在实质性反驳。arXiv:1911.04775（PRMaterials 4, 034201 (2020)）在 TaP、NbP、NbAs、TaAs 全部四种材料上，通过确保电流均匀性来排除 current jetting，发现 TaP/NbP/NbAs 沿 c 方向的正 LMR 在 4 T 以上饱和，且可**完全由纯轨道效应（基于 Fermi 面几何）解释**，与 Weyl 节点到费米面的距离无关；沿 a 方向的非单调行为可用**弱反局域化**解释，"the longitudinal transport in the TaAs family can therefore be explained without including any chiral or topological effects"。该文还列举了负 LMR 的多种非手征起源：WAL、磁性杂质、费米面的负高斯曲率（TaAs 族"香蕉形"费米面有大量负曲率区域）、以及 current jetting，并直言"the implication used occasionally that a negative LMR proves a material to be topologically nontrivial is wrong"。另一篇 Nat. Commun. 7, 11615 (2016) 对 TaP 的研究则表明手征性未良好定义时仍出现大负 MR。

**值得注意的辨别力与后续延伸**

尽管有上述争议，本文提出的振荡与普通 SdH 振荡在频率来源上确有本质差别：普通 SdH 频率由费米面截面积决定（F = (Φ₀/2π²)A，可用 Onsager 关系标定），而本文的 Δ(1/B) = 2eℏ(υ_F/E_F)² 依赖费米速度与费米能量，这一差别提供了一个可实验区分的判据。相关的后续扩展已经展开：PRB 103, 115208 (2021)（Huang, Geng & Sheng）引入**磁场依赖的谷间弛豫时间 τ_a(B)**（短程杂质散射、任意磁场强度），发现考虑该依赖后振荡被**增强**，并解释了 WSM 中 LMC 幅值的反常行为；PRB 103, 104434 (2021)（Qi, Deng, Luo, Geng, Sheng 等）研究纵/横向磁电导之间的 **π 振荡相移**；EPL 130, 47004 (2020)（Yu, Sheng & Xing）处理 ac 电场下的 LMC，发现低角频率行为与 dc 相同，而角频率超过临界值（等于谷间弛豫时间的倒数）时 LMC 迅速降为零；PRB 107, L081107 (2023)（Zeng, Nandy, Liu, Tewari & Yao）则把量子振荡推广到**非线性响应**，主张其为手征异常的稳健指纹。

**其他开放问题**

本文的 LMC 是准经典（Landau 量子化 + Boltzmann）产物，在真正的超量子极限下纯量子（Landau 能级占据数严格量子化、无碰撞或含碰撞的量子输运框架）是否给出相同的振荡结构与行为，仍需更完整的量子输运处理；在多谷体系中手征化学势的分配方式、不同谷间弛豫通道的相对权重如何影响振荡的幅度与相位，是尚未厘清的。此外，用 1/B 振荡反推 E_F 与 υ_F 的实验可行性、对界面/表面粗糙散射（谷内）主导体系的稳健性、以及在 type-II 或倾斜 Weyl 锥（TaP、WTe₂）中该指纹是否仍然存在且形式如何改写，都是有待检验的问题。
