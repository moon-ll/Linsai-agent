• # Switchable and unswitchable bulk photovoltaic effect in two-dimensional interlayer-sliding ferroelectrics

  ## 林赛的理解

  这篇工作把二维层间滑移铁电体做成一个可工程化的体光伏效应（BPVE）平台，而且揭示了一个反直觉的对称性后果：面内光电流对铁电极化翻转“免疫”，面外光电流却可以随极化同步翻转。对我这组来说，这意味着少层堆叠方式本身就可以成为一种调控非线性光电响应和量子几何张量的旋钮。我们已经在用强场超快激光去“读”材料的 Berry 相位和量子几何（HHG、阿秒、THz 发射），而滑移铁电体恰好提供了一个两态可切换、但面内响应稳定的体系，把“极化态的光学读出”和“非线性光电流的几何起源”直接挂钩。未来可以让少周期中红外或 THz 脉冲驱动这类样品，通过 HHG 偏振、相位或光电流方向反推畴结构，甚至用强场诱导层间滑移实现超快光电开关。

  ## 研究问题

  论文要回答的核心问题是：在二维层间滑移铁电材料中，体光伏效应是否必然与铁电极化同步翻转？具体而言，可切换的层间滑移铁电极化态会导致所有 BPVE 张量元都变号，还是只影响其中一部分？如果不同分量表现出不同的切换行为，其深层的对称性根源是什么？

  ## 研究背景

  体光伏效应（BPVE）和铁电性都源于反演对称破缺，因此传统铁电体通常被看作天然的 BPVE 材料。在 BiFeO₃、CuInP₂S₆、SnTe 单层等体系中，铁电极化翻转会带动 BPVE 光电流反向，这一思路已被广泛用于设计可切换光电器件。然而，铁电极化是极矢量，而 BPVE 系数是三阶张量，二者遵循不同的对称性变换规则。特别地，垂直于极化方向的镜面反射可以反转极化，却未必能反转 BPVE 的所有张量分量。

  近年来，二维范德华材料中的层间滑移铁电性在实验上被不断发现，包括 bilayer WTe₂、BN、InSe、MoS₂ 等。与传统铁电体中由原子在面内相对位移实现的极化翻转不同，层间滑移保持每层单层的晶体结构不变，+P 与 −P 态由水平镜面 M_xy 联系，而非反演操作。这为探索 BPVE 与铁电序之间更微妙的关系提供了新平台。

  ## 研究方法

  作者首先用抽象双层晶体模型对最常见的四种堆叠构型做对称性分类：

  - Case 1a（单层有反演、无水平镜面；A/A 堆叠）：体系始终保持反演对称，无铁电性。
  - Case 1b（单层有反演、无水平镜面；A/B 堆叠）：可实现层间滑移铁电性，+P/−P 由 M_xy 联系。
  - Case 2a（单层无反演、有水平镜面；A/A 堆叠）：可实现层间滑移铁电性，+P/−P 由 M_xy 联系。
  - Case 2b（单层无反演、有水平镜面；A/B 堆叠）：体系始终保持反演对称，无铁电性。

  随后选取 Case 2a 的代表双层 MoS₂ 和 Case 1b 的代表双层 WTe₂ 进行第一性原理计算。计算采用 VASP 软件包，GGA-PBE 泛函，平面波截断能 400 eV，k 点网格为 MoS₂ 的 12×12×1 和 WTe₂ 的 12×8×1，真空层厚度约 15 Å，并考虑 DFT-D2 范德华修正与自旋-轨道耦合。DFT 布洛赫波函数通过 Wannier90 转化为最大局域化 Wannier 函数（MoS₂ 用 Mo-d 与 S-p 轨道，WTe₂ 用 W-d 与 Te-p 轨道），再基于紧束缚哈密顿量用自主程序 WNLOP 计算 BPVE 系数。

  面内 BPVE 采用标准二阶 Kubo 公式计算；面外 BPVE 采用修正二阶 Kubo 公式，将速度算符替换为 z 方向位置算符。收敛测试后，BPVE 计算采用 k 网格 500×500×1（MoS₂）和 600×300×1（WTe₂），展宽参数 δ = 0.02 eV。最终通过公式

  σ₃ᴰ = (L_active / L_slab) σ_slab

  将计算得到的 slab 系数换算为等效三维系数。

  ## 主要发现与核心结论

  1. **对称性规则**：当 +P 与 −P 由水平镜面 M_xy 联系时，M_xy 只反转 z 方向矢量而保持 x、y 方向不变，因此面内 BPVE 张量元满足 σₐᵦc(+P) = σₐᵦc(−P)（a,b,c ∈ {x,y}），而面外 BPVE 张量元满足 σ'ᵦc(+P) = −σ'ᵦc(−P)。这与传统铁电体中由反演联系 +P/−P、所有 BPVE 分量都反号形成鲜明对比。

  2. **双层 MoS₂（Case 2a，C₃ᵥ 对称性）**：
     - 能带结构在 +P 与 −P 态下完全相同。
     - 面内 BPVE 系数在两种极化态下相等，且满足 σˣʸʸ = σʸˣˣ = −σˣˣˣ = −σʸʸʸ，σˣˣʸ = σʸˣʸ = 0。
     - 面外 BPVE 满足 σ'ᶻᶻˣˣ = σ'ᶻᶻʸʸ，σ'ᶻᶻˣʸ = σ'ᶻᶻʸˣ = 0，且 +P 与 −P 态符号相反。
     - 面内光电流的数值大小与光偏振方向无关，面外光致极化各向同性。

  3. **双层 WTe₂（Case 1b，C₁ᵥ 对称性）**：
     - 价带与导带发生重叠（半金属/半导体重叠特征）。
     - 面内 BPVE 有三个独立张量元 σˣʸʸ、σʸˣˣ、σʸʸʸ，在 +P 与 −P 态下数值相等：σˣʸʸ(+P) = σˣʸʸ(−P)，σʸˣˣ(+P) = σʸˣˣ(−P)，σʸʸʸ(+P) = σʸʸʸ(−P)。
     - 三个面内张量元的相对大小为 σˣʸʸ : σʸˣˣ : σʸʸʸ = 1 : (−0.7) : 1.6。
     - 面外 BPVE 系数随极化翻转而反号：σ'ᶻᶻˣˣ(+P) = −σ'ᶻᶻˣˣ(−P)，σ'ᶻᶻʸʸ(+P) = −σ'ᶻᶻʸʸ(−P)，且 σ'ᶻᶻˣˣ ≠ σ'ᶻᶻʸʸ，相对大小为 σ'ᶻᶻˣˣ : σ'ᶻᶻʸʸ = 1 : (−0.6)。
     - 面内光电流大小随光偏振方向变化，面外光致极化也呈现各向异性。

  4. **定量对比与实验可达性**：计算得到的双层 MoS₂ 和双层 WTe₂ 的面内 BPVE 系数与已报道的 SnTe 单层以及 BiFeO₃、BiTiO₃、PbTiO₃ 等三维传统铁电体相当；面外 BPVE 系数与转角双层石墨烯的报道值相当，均处于实验可探测范围。

  5. **器件物理含义**：在含有多种铁电畴的真实样品中，面内 BPVE 光电流在不同畴之间同向叠加而非相互抵消，有利于构建大面积、对畴结构不敏感的光电器件；面外 BPVE 则随畴极化反向而反向，可用于可切换光电功能单元。

  ## 潜在研究方向

  1. **动态翻转与畴壁动力学**：目前工作主要讨论静态 +P/−P 态的 BPVE，层间滑移的翻转势垒、畴壁处 BPVE 的空间分布以及电场/光场驱动的畴壁运动尚待直接模拟与实验表征。

  2. **强场超快非平衡响应**：二阶 Kubo 公式描述的是线性光学区内的稳态 BPVE。在少周期强场驱动下，非谐、相干载流子动力学、高阶非线性项以及退相干时间对 BPVE 的影响需要超快光谱和含时模拟来填补。

  3. **与转角/莫尔体系的交叉**：滑移铁电与莫尔超晶格共享“堆叠工程”这一调控维度，转角引入的低能平带和拓扑非平庸能带会进一步改变 Berry 曲率分布，从而影响 BPVE 与 HHG 响应。

  4. **铁电金属与拓扑半金属的推广**：双层 WTe₂ 属于 C₁ᵥ 对称性，具有半金属特征；类似地，滑移铁电的 ZrI₂ 以及其它铁电金属中的 BPVE 与反常霍尔、非线性霍尔效应的耦合值得探索。

  5. **有限温度、缺陷与衬底效应**：实验样品通常通过“撕贴法”制备，存在应变、扭转、杂质和衬底屏蔽，这些因素对 BPVE 张量元的定量修正需要进一步研究。

  6. **从 BPVE 到高次谐波/THz 发射**：BPVE 本质上是二阶非线性光电导，与强场 HHG、光致电流辐射的 THz 发射共享相同的带间-带内跃迁通道，可在同一类少周期实验中同时读出极化态与量子几何信息。

  ## 与林赛研究的关联

  这项研究与我们组聚焦的强场超快光学方向有多个具体接口：

  - **HHG 与量子几何读出**：少周期中红外激光驱动的 HHG 对 Berry 连接、Berry 曲率和带间偶极矩高度敏感。滑移铁电体中 +P/−P 态具有相同的能带但不同的几何张量元，正是用 HHG 做“几何态读出”的理想体系。
  - **阿秒极化动力学**：面外可切换 BPVE 对应 z 方向极化电荷的超快积累，可用阿秒瞬态吸收或光电子能谱追踪层间电荷重心的亚周期运动。
  - **强场驱动与畴结构成像**：面内 BPVE 不随极化翻转而变号，意味着畴壁两侧的光电流方向一致，无法直接用面内光电流区分畴；但面外 BPVE 会反号，因此结合面内/面外光电流或 HHG 偏振可实现畴极化的全光学映射。
  - **莫尔与交变磁材料**：将层间滑移铁电推广到转角莫尔超晶格或具有交变磁序的二维体系，可研究铁电-磁-拓扑序耦合下的非线性光响应，包括磁化诱导的 BPVE 切换。
  - **太赫兹发射与光电流光谱**：用 THz 脉冲驱动层间滑移并探测其后瞬态光电流，可直接验证层间滑移势垒与 BPVE 张量的强场非线性修正。

**方法**：DFT+Wannier90+WNLOP 计算层间滑移铁电体 BPVE 系数

**原理**：计算二维层间滑移铁电体的体光伏效应（BPVE）二阶光电导张量。先用第一性原理得到布洛赫波函数，经 Wannier90 转化为最大局域化 Wannier 函数构建紧束缚哈密顿量，再用自主程序 WNLOP 基于修正二阶 Kubo 公式计算 BPVE 系数（面内用标准二阶 Kubo 公式，面外用 z 方向位置算符替换速度算符的修正公式），并通过对称性分类预测 +P/−P 态下张量元的变号行为。
