• # Low-frequency and Moiré Floquet engineering: a review

  ## 林赛的理解

  这篇综述把我们的两条主线——**强场超快光驱动**与**莫尔量子材料**——直接接在一起了。它系统梳理了从高频到低频（THz）各种 Floquet 有效哈密顿量的推导路径，并把我们最感兴趣的低频区单独拿出来讲。对我们组而言，最重要的价值在于：它提供了一个理论词典，让我们能把实验上用的强场/THz 脉冲、阿秒探测和莫尔体系的能带工程统一描述。特别是低频区与声子共振、vdW 磁体、拓扑相变这些关键词，都和我们正在构思的 HHG-莫尔、交变磁、量子几何探测等课题有明确接口。不过需要指出，用户提供的全文在 2.3.2 节处被截断，第 3 章的具体应用细节（TBG/TDBG/TTMD 的定量结果、波导中的具体能带演化、声子驱动磁体的数值）未能完整读到，因此下面的笔记以理论框架和已可读到的结论为主。

  ## 研究问题

  1. 在周期性光驱动下，如何在高频、中频和**低频**三个区间系统地推导有效的 Floquet 哈密顿量，并比较各方法的优劣与适用范围？
  2. 当驱动频率 Ω 不再远大于体系的局域能量尺度 h 时（即中频/低频区），传统的逆频率展开失效，需要什么样的非微扰或自洽方法？
  3. 将低频 Floquet 工程应用于**莫尔超晶格**（如扭转双层石墨烯 TBG、扭转双双层石墨烯 TDBG、扭转过渡金属硫族化合物 TTMD）时，准能谱与稳态如何被光场（自由空间或波导中的线偏振/圆偏振）改变，能否诱导拓扑相变？
  4. 当 THz 脉冲与 vdW 磁性材料中的声子共振时，声子动力学如何在 Floquet 图像下驱动磁相变？
  5. 低频莫尔-Floquet 工程有哪些新的发展方向与技术应用前景？

  ## 研究背景

  量子材料的核心特征是宏观层面呈现量子效应，如磁性、超导、拓扑态等，这些有序态来源于电子自旋、轨道、晶格振动等内部自由度之间的相互作用。传统调控手段包括温度、压力、掺杂、化学成分和电磁场。近年在低维体系中，**层间扭转角**成为新的调控维度：错配产生的莫尔超晶格能够显著改变能带结构，例如 hBN 上的双层石墨烯出现分数量子霍尔效应，TBG 在特定载流子浓度下出现超导/绝缘/铁磁态，TDBG 呈现自旋极化关联相，TTMD 异质结中观测到莫尔激子。

  另一方面，**Floquet 工程**利用周期性光驱动把平衡体系拓展到非平衡周期体系，已在拓扑绝缘体中观测到 Floquet-Bloch 态、在石墨烯中实现光致反常霍尔效应、在 TMD 中实现谷选择性激子调控、在 1T-TaS₂ 中实现亚稳电荷密度波等。驱动频率 Ω 相对于材料局域能量尺度 h 的大小把问题分为三个区间：高频区（Ω ≫ h）可用逆频率展开和旋转波近似；**中频区**和**低频区**（Ω 与 h 可比或更小）理论更复杂，但对固态体系更现实，并且当驱动偏离电子共振时有助于抑制加热。当频率进入 THz 范围并与声子共振时，出现**非线性声子学**机制，可用于瞬态增强超导、亚稳金属相、铁电相以及有效磁场调控等。

  本综述旨在整合低频 Floquet 理论与莫尔超晶格这两个方向，形成所谓 **Moiré-Floquet engineering**。

  ## 研究方法

  ### 两种 Floquet 理论视角

  1. **时间演化算符视角**：从 Schrödinger 方程 `i∂ₜU(t) = H(t)U(t)` 出发，周期驱动下 `U(nT) = U(T)ⁿ`，定义 Floquet 哈密顿量  
     `H_F := i log(U(T))/T`。  
     它决定 stroboscopic 时刻 `t = nT` 的动力学，当 `T` 足够小时可平滑化为 `U(t) ≈ e^{-iH_F t}`。挑战在于计算时间序指数和矩阵对数。

  2. **准能量算符视角**：将时间依赖 Schrödinger 方程 `i∂ₜψ = H(t)ψ` 在扩展希尔伯特空间 `F = H ⊗ I` 中写成准能量本征方程  
     `ε u(t) = (H(t) − i∂ₜ)u(t) = Q̂ u(t)`，  
     其中 `u(t+T) = u(t)`。引入扩展空间内积  
     `⟨⟨u, v⟩⟩ = ∫₀^T dt ⟨u(t), v(t)⟩`  
     后，可用傅里叶基 `|n⟩ = e^{inωt}/√T` 把 `Q̂` 写成无限维块三对角矩阵，块为 `H_n = (1/T)∫₀^T dt e^{-inωt} H(t)`，对角块平移 `nω`。该视角不依赖初始条件，适合数值截断。

  ### 高频近似（Ω ≫ h）

  - **Floquet-Magnus 展开**：令 `U(t) = e^{Ω(t)}`，`H_F = ∑ₙ H_F^{(n)}`，`H_F^{(n)} ∝ ω^{-n}`。前两项为  
    `Ω₁(t) = −i∫₀^t dt₁ H(t₁)`，  
    `Ω₂(t) = −∫₀^t dt₁∫₀^{t₁} dt₂ [H(t₁), H(t₂)]`。  
    用傅里叶分量写出  
    `H_F^{(0)} = H₀`，  
    `H_F^{(1)} = ∑_{n≠0} [H_{-n} − 2H₀, H_n]/(2ωn)`。  
    展开显含初始时间 t₀（Floquet 规范）。

  - **Van Vleck 展开**：在扩展空间中对角化 `Q̂`，通过反厄米生成元 `G`（`U = e^G`）块对角化，得到有效哈密顿量不依赖 t₀，且保持对称性。前几阶为  
    `H_vV^{(1)} = H₀`，  
    `H_vV^{(2)} = ∑_{m≠0} H_m H_{-m}/(mω)`，  
    三阶含 `1/(2m²ω²)` 和 `1/(3mm'ω²)` 项。

  - **Brillouin-Wigner 展开**：在零光子子空间投影，定义波算符 `Ω̂`，有效哈密顿量  
    `H_eff = P Q̂ Ω̂ P`。  
    大 ω 展开前几阶为  
    `H_BW^{(0)} = H₀₀`，  
    `H_BW^{(1)} = ∑_{n≠0} H₀ₙ Hₙ₀/(nω)`，  
    二阶含 `1/(n₁n₂ω²)` 项。优点是高阶表达式更紧凑，缺点是不以嵌套对易子表示，易出现非局域项。

  - **微扰旋转坐标系**：通过 `Q(t) = e^{Ω̂(t)}` 将哈密顿量变换到旋转系，使 `H_eff` 时间无关。生成元按 `Ω̂_n = O(ω^{-n})`、时间导数 `∂ₜΩ̂_n = O(ω^{-n+1})` 逐阶消去含时部分，最终 `H_eff = ∑ₙ (1/T)∫ dt G_n`。

  ### 中频近似

  - **Replica 近似**：适用于分段常数驱动  
    `H(t) = H₀`（`nT < t < nT + t₀`），`H(t) = H₁`（`nT + t₀ < t < (n+1)T`），其中 `t₁ = T − t₀`。  
    Floquet 算符 `U = e^{-iH₀t₀} e^{-iH₁t₁}`。当 `t₀`、`t₁` 较小时可用 Magnus/BCH 展开；当只有 `t₁` 较小时，可用 replica 技巧  
    `log(U) = lim_{ρ→0} (1/ρ)(U^ρ − 1)`  
    对 `t₁` 展开。该方法有清晰展开参数，可估计预热带寿命，但只适用于特定驱动波形且计算繁琐。

  - **非微扰旋转坐标系**：选择幺正变换 `Q(t)` 使得变换后含时部分更小，即 `||V_eff(t)|| < ||V(t)||`，并要求 `Q(T) = 1`。典型选择  
    `Q(t) = e^{-i∫₀^t dt V(t)}`，  
    近似 Floquet 哈密顿量为 `H_F ≈ (1/T)∫₀^T dt H_eff(t)`。该方法可超越高频展开，但缺乏统一展开参数。

  ### 低频近似

  低频区要求处理驱动频率与体系能量尺度可比甚至更小的情形，此时逆频率展开发散，必须采用：
  - Floquet 微扰理论；
  - **自洽低频方法**：有效哈密顿量显式依赖准能量 ε，需自洽求解，这是捕捉低频区非解析能隙打开的关键；
  - 实时流方程方法；
  - 扩展空间流方程方法。

  ### 应用对象（绪论/摘要中提出，具体数值细节因全文截断未完整可读）

  - 自由空间与波导中受光照的 TBG、TDBG、TTMD；
  - 与声子共振的 THz 脉冲驱动的 vdW 磁体。

  ## 主要发现与核心结论

  1. **Floquet 描述存在两种等价但互补的框架**：时间演化算符框架便于理解 stroboscopic 动力学和预热带行为，但依赖初始条件且涉及矩阵对数；准能量算符框架在扩展空间中不依赖初始条件，更适合数值对角化，但需要定义包含时间积分的内积。

  2. **高频展开具有渐近性**：Magnus、Van Vleck、Brillouin-Wigner 等展开在 `Ω ≫ h` 时有效，但都是渐近级数，存在最优截断阶 `n* ∝ ω`。随着频率降低，必须转向中频/低频方法。

  3. **Floquet-Magnus 展开显含 Floquet 规范**：一阶有效哈密顿量 `H_F^{(1)}` 通过 `e^{-inωt₀}` 依赖初始时间 `t₀`；Van Vleck 展开通过块对角化消除了这种规范依赖，同时显式保持对称性。

  4. **中频区需要非微扰旋转框架或 Replica 技巧**：传统高频展开在 `v ≪ ω` 或 `h₀ ≪ ω` 条件不满足时失效。非微扰旋转框架通过 `Q(t) = e^{-i∫₀^t dt V(t)}` 可降低含时部分，并要求 `Q(T) = 1` 保证与原框架的 Floquet 哈密顿量等价。

  5. **低频区必须自洽处理**：Brillouin-Wigner 形式中有效哈密顿量 `H_eff = P Q̂ Ω̂ P` 显式含准能量 ε，这种自洽条件在低频区非但不能忽略，反而是捕捉准能谱非解析能隙打开的必要条件。

  6. **莫尔 + Floquet 工程提供多维可调控平台**：莫尔超晶格的扭转角敏感性赋予能带结构（平带、范霍夫奇点、拓扑非平庸区）以高度可调性；光场的频率、振幅、偏振、波形提供额外旋钮，二者结合可实现按需设计的非平衡物态。

  7. **THz 声子驱动可诱导磁相变**：在 vdW 磁性材料中，低频光脉冲与声子共振时，非线性声子相互作用可有效调控晶格结构，并通过电子-声子/自旋-声子耦合进一步诱导磁有序的转变，为超快磁调控提供 Floquet 视角。

  ## 潜在研究方向

  1. **截断材料的限制**：由于提供的全文在 2.3.2 节处截断，TBG、TDBG、TTMD 在自由空间与波导中的具体能带演化、稳态分布、拓扑不变量变化以及声子驱动 vdW 磁体的定量相图均未完整呈现，需要获取全文第 3–4 章以补充。

  2. **实验验证低频莫尔-Floquet 拓扑相变**：理论预言的准能隙打开与拓扑转变需要在 THz 泵浦-探测、ARPES 或输运实验中被直接观测，尤其是在 TBG 魔角附近的平带区域。

  3. **抑制加热与实现长寿命 Floquet 态**：低频驱动容易耦合到连续谱或声子 bath，如何设计驱动参数（频率、偏振、波形）以延长预热带寿命仍是开放问题。

  4. **强关联效应**：现有方法多基于单粒子或弱关联图像，莫尔体系中的强关联（关联绝缘、超导）与 Floquet 驱动的交叉需要更多非平衡多体方法。

  5. **非线性声子学与交变磁/超快磁调控的接口**：将 THz 声子驱动从 vdW 磁体推广到具有交错磁化或自旋-轨道耦合的体系，探索光诱导磁各向异性、磁畴翻转和亚稳磁相。

  6. **量子几何量的 Floquet 调控**：Berry 曲率、量子度规、陈数等在周期性驱动下的重正化规律，以及如何通过 HHG/反常霍尔/光电导等探针读取这些变化。

  7. **波导约束下的光-物质耦合**：把莫尔样品置于波导中以增强光场约束和模式选择，可能产生自由空间无法实现的 Floquet 耦合形式，需要进一步发展腔/波导量子电动力学与 Floquet 理论的结合。

  ## 与林赛研究的关联

  - **HHG 与强场驱动**：我们组的高次谐波产生（HHG）光源正好覆盖 THz 到低频红外区间，与本文的低频 Floquet 工程处于同一能量窗口。用 HHG 泵浦莫尔体系时，可借用本文的旋转坐标系、自洽低频等方法解释强场下的有效能带重构。

  - **阿秒探测**：Floquet 准能量是 stroboscopic 概念，而阿秒脉冲具有足够时间分辨率，可以在亚周期尺度上“看”到微运动（micromotion）和准能态之间的相干演化，为验证本文的理论框架提供天然探针。

  - **莫尔体系**：TBG、TDBG、TTMD 等扭转角平台具有平带、Berry 曲率热点和拓扑非平庸区，是我们研究强场-物质相互作用和量子几何效应的理想载体。光场可进一步调制其能带和拓扑。

  - **交变磁（altermagnetism）**：本文讨论的声子驱动 vdW 磁体与超快磁相变，可直接对接我们对交变磁材料中超快自旋动力学和光诱导磁有序转换的兴趣。

  - **量子几何**：Floquet 工程本质上是对能带和波函数的几何性质进行时间平均重正化。量子几何量（Berry 曲率、量子度规、陈数）在驱动下的变化，将直接决定 HHG 产率、反常霍尔响应和各向异性光电导，是我们理论与实验设计的核心接口。

## 研究方法（方法卡）

**方法**：Van Vleck 高频 Floquet 展开

**原理**：在扩展希尔伯特空间 F = H ⊗ I 中把准能量算符 Q̂ = H(t) − i∂ₜ 用傅里叶基写成无限维块三对角矩阵（对角块平移 nω），再通过反厄米生成元 G（U = e^G）将其块对角化，得到有效 Floquet 哈密顿量。与 Floquet-Magnus 展开不同，结果不显含初始时间 t₀（不依赖 Floquet 规范），且显式保持对称性。

**参数表**：

| 参数 | 数值 | 出处 |
| --- | --- | --- |
| 一阶有效哈密顿量 | H_vV^(1) = H_0 | 研究方法-高频近似-Van Vleck 展开 |
| 二阶有效哈密顿量 | H_vV^(2) = Σ_{m≠0} H_m H_{-m}/(mω) | 研究方法-高频近似-Van Vleck 展开 |
| 三阶项结构 | 含 1/(2m²ω²) 和 1/(3mm'ω²) 项 | 研究方法-高频近似-Van Vleck 展开 |
| 展开参数标度 | H_F^(n) ∝ ω^{-n}，最优截断阶 n* ∝ ω | 主要发现-高频展开具有渐近性 |

**适用边界**：仅适用于高频区 Ω ≫ h，且为渐近级数存在最优截断；频率降低（中频/低频区）时失效，需改用 Replica、非微扰旋转坐标系或自洽低频方法。
