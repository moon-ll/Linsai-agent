## 研究问题（Research Question）

本文的核心问题是：**在集合卡尔曼反演（EKI）中，Tikhonov 正则化参数 λ 应当如何随迭代自适应地学习，而不是被固定在某个先验选定的值上？** 论文把这一问题拆成两条腿同时推进。

第一条是理论腿。已有工作（Chada, Schillings, Tong 的 TEKI）只证明了固定 λ 下 EKI 连续时间极限的适定性与收敛性，且大多建立在**无噪声观测**假设或**确定性 EKI 更新**假设上。作者明确指出这两个假设在实践中都不成立：一旦引入观测噪声，原始 EKI 的性能会显著恶化甚至发散；而一旦引入自适应学习，噪声项就必然进入迭代，因此必须用**随机（stochastic）EKI 公式**来分析。所以本文要回答的是：在含噪、且噪声协方差与正则协方差都随时间变化的条件下，TEKI 还能不能收敛，收敛速率是多少。

第二条是算法腿。即使理论成立，"怎么在线选 λ"仍是悬空的：论文要给出三种可操作的自适应正则方案，并证明/验证它们比固定正则的 TEKI 和不带正则的原始 EKI 都好。作者的核心论点是：**自适应学习正则参数能显著改善对底层未知量的恢复，尤其在含噪数据下能同时避免"过拟合数据"和"过度平滑"这两个相反的失效模式。**

方法论上的第三个隐含问题：EKI 的初始集合本身就携带了先验信息（协方差 C(u)），而 EKI 又把正则项解释为高斯先验假设——这两者之间存在冗余/张力，如何把"先验强度"作为超参数来学习，是本文要厘清的。

## 研究背景（Background）

逆问题 y = G(u) + η，η ~ N(0, Γ) 的经典解法是最小化 I(u;y) = ½||y − G(u)||²_Γ + S_λ(u)。EKI 自被提出为无导数优化器（受 EnKF 启发）以来，发展迅速：它把滤波方法（尤其是 EnKF）应用于逆问题，通过样本均值与样本协方差更新一组粒子 u⁽ʲ⁾，主要吸引力是 **derivative-free**，在 PDE 约束的高维问题中能大幅降低计算成本。

但作者梳理文献时指出了三条明显的裂缝。第一，**后验一致性**：EKI 在线性高斯假设下能逼近后验，但对非线性前向映射**与后验分布不一致**（[21]）；为此人们从平均场极限与 Fokker–Planck 方程角度分析 EKI，并用各种贝叶斯修正（[19,25,28,44]）或层次方法（[11,13]）去逼近真后验。第二，**正则化的正则参数几乎都是固定的**：文献中引入的盒约束、Tikhonov 正则、迭代正则等（[14,15,16,30,36,47]），绝大多数都取固定的 λ>0；少数考虑自适应选择与收敛的工作（[29,43]）针对的是迭代正则而非 EKI 的 Tikhonov 形式。第三，**含噪 EKI 几乎没被认真分析过**：直接忽略扩散项的确定性 EKI 已被证明是预条件梯度流 du/dt = −C(u)∇_uΦ，但这是无噪结论；针对含噪情形，[46] 引入了一个 discrepancy principle 作为停止准则 ||G(u) − y_*||² ≤ τ√(Trace Γ)，能防爆但问题远未解决。

作者的动机定位很清楚：**把 Tikhonov 正则引入 EKI 来化解噪声导致的不稳定性（沿用 [15] 的推导），并首次系统地把"正则参数的自适应学习"与"含噪随机 EKI 的收敛性证明"两件事放在一起做。** 论文也指出这一路线与数据驱动正则（神经网络、投影、字典学习，[3,4,38,41]）的近期热潮相契合——EKI 的 prediction step 天然产生训练数据，这正是其自适应方案的技术根基。

## 研究方法（Methods）

**理论路线：连续时间极限 + 耦合随机微分方程。** 作者把离散 EKI 的协方差按 Σ = h⁻¹Σ 重标度，取 h → 0 得到形如 du⁽ʲ⁾ = B^up(u)Σ⁻¹(z − F(u⁽ʲ⁾))dt + B^up(u)Σ⁻¹ᐟ² dW⁽ʲ⁾ 的耦合 SDE 系统（离散到连续的严格推导引用 [7]）。TEKI 的实现方式很有巧思：把 Tikhonov 正则**嵌入观测模型**——扩充为 y = G(u) + η₁ 与 0 = u + η₂，η₂ ~ N(0, λ⁻¹C₀)，从而 Σ = blkdiag(Γ, λ⁻¹C₀)，前向映射变为 F(u) = [G(u); u]。这样参数空间的正则化就与观测空间的噪声同构，EKI 的更新公式几乎不用改。对应的损失函数即 I(u;y) = ½||y − Au||²_Γ + ½||u||²_{C₀}。

**分析工具链。** 在线性前向映射 G(·) = A· 下，作者用样本协方差 C(u) 的矩阵值 Ornstein–Uhlenbeck 型结构，写出残差动力学 d r̃⁽ʲ⁾ = −C(r̃⁽ʲ⁾)r̃⁽ʲ⁾dt + C(r̃⁽ʲ⁾)dW⁽ʲ⁾，其中 r̃ = Σ⁻¹ᐟ²F(u_t − u*) 且 u* = (AᵀΓ⁻¹A + C₀⁻¹)⁻¹AᵀΓ⁻¹y。由 ∇I(u*, y) = 0 得到的梯度结构保证残差单调递减（引用 [9] 的 Prop 5.1 与 Thm 5.2）。

**方差膨胀（variance inflation）。** 为保证正则损失真正收敛，作者在漂移项前置了随时间衰减的膨胀项 (C(u_t) + B/(t^α + c))，α ∈ (0,1)、c > 0、B 正定。数值实验中取 α = 1/2、R = 1。

**时变推广的关键假设（Assumption 2.5）。** 令 Ψ_t = dΣ_t⁻¹/dt，要求 Σ_t⁻¹ ⪰ σ_min I、−(t^β+R)⁻¹Σ_t⁻¹ ⪯ Ψ_t ⪯ (t^β+R)⁻¹Σ_t⁻¹（β > 1）、∫₀ᵗ||Ψ_t||dt ≤ κ₁，且 B̃_t = Σ_t⁻¹ᐟ²FBFᵀΣ_t⁻¹ᐟ² 的最小特征值一致下界。物理含义是"学习过程不能突变 Σ_t"，实践中可通过合适的优化步长满足。

**三种自适应正则方案（Section 3）。**

*Algorithm 1 — 双层优化 / 参数自助法（bilevel + parametric bootstrap）。* 把 prediction step 视作生成训练数据：y⁽ʲ⁾_{n+1} = G(u⁽ʲ⁾_n) + η⁽ʲ⁾_{n+1}，其中 (u⁽ʲ⁾) 是当前粒子的经验分布 μ_n = (1/J)Σδ_{u⁽ʲ⁾_n} 视作先验。然后定义误差 v⁽ʲ⁾_{n+1}(λ) = T_λ(y⁽ʲ⁾_{n+1}) − u⁽ʲ⁾_n（当前粒子与 Tikhonov 极小解之差），损失 f_{n+1}(λ) = (1/J)Σ½||v⁽ʲ⁾||²，对 λ 做梯度下降。关键解析导数为 dv/dλ = −(AᵀΓ⁻¹A + λC₀⁻¹)⁻¹C₀⁻¹(AᵀΓ⁻¹A + λC₀⁻¹)⁻¹AᵀΓ⁻¹y^{(j)}，更新 λ_{n+1} = λ_n − γ_n f′(λ_n)，步长按 Armijo 规则以保证下降方向正确。非线性情形下因 T_λ 无闭式解，作者在每次迭代对前向映射做线性化 G(u) ≈ G(ū_n) + DG(ū_n)(u − ū_n)，令 A_apprx = DG(ū_n)、a_apprx = G(ū_n) − DG(ū_n)ū_n。**关键设计取舍（Remark 3.2）：线性化只用于选 λ，TEKI 的粒子更新仍在完整非线性空间进行。**

*Algorithm 2 — MAP 公式。* 取 λ ~ U[0,M] 的先验，对 (u, λ) 联合 MAP 给出 argmin ½||G(u)−y||²_Γ + (λ/2)||u||²_{C₀} − (d_u/2)log λ。当 u 给定时 λ 有解析临界点 λ* = ((1/d_u)||u||²_{C₀})⁻¹，于是 λ_{n+1} = P_{[0,M]}( ((1/(J d_u))Σ_j ||u⁽ʲ⁾_n||²_{C₀})⁻¹ )，投影算子保证 λ 留在可行集。

*Algorithm 3 — 层次贝叶斯 / 协方差学习。* 把先验协方差 C₀(θ) 的超参数 θ 与 u 一起视为两层优化问题，第二层对 θ 做梯度下降：θ⁽ʲ⁾_{n+1} = θ⁽ʲ⁾_n − ∇_θ(½||u⁽ʲ⁾_n||²_{C₀(θ)}) − ∇_θ(½ log det C₀(θ))。进一步通过特征分解 C₀ = U D(θ)Uᵀ（不妨设 C₀ 对角）、D(θ) = diag(1/θ₁, …, 1/θ_{d_u})，**学习整张先验协方差的特征值**，即学习各维度的权重，更新式为 (θ_{n+1})_k = (θ_n)_k − ½(v̄_n)_k² + ½(1/(θ_n)_k)，其中 v_n = Uᵀu_n 是特征基下的坐标。作者明确指出 Algorithm 3 相对 Algorithm 2 在概念上是推广，但在数值稳定性上用梯度下降优于直接解 MAP 的稳定点。

**数值设置。** 线性算例：1D 椭圆型 PDE d²p/dx² + p = u，x ∈ (0,π)，p = 0 on ∂D；分片有限元 h = 2⁻⁴；K = 8 个等距点观测；噪声 Γ = γ²I，γ = 0.1；先验 C₀ := λ†·10·(−Δ)⁻¹，而真值 u† ~ N(0, (1/λ†)C₀)，**故意让先验与真值失配**；方差膨胀 α = 1/2、R = 1；固定正则对照 λ = 1；λ† ∈ {50, 0.04}；Q = 100 条路径、J = 50 个粒子、t 至 1000。非线性算例：Darcy 流 −∇·(κ∇p) = f，f ≡ 1，κ = exp(u)；先验 C₀ := σ²(τ·I − Δ_u)^(−ν)，ν > d/2；Karhunen–Loève 展开 u_ξ = Σ_j √(1/λ†) σ_j ξ_j φ_j，φ_j = √(2/π)sin(2πx)，截断到 d 维，未知量取 ξ ∈ R^d；λ† = 20、τ = 0、σ = 1、ν = 1；Q = 10 条路径、J = 50；噪声 N(0, γ²I)，γ = 0.01；K = 16 个观测点；D = [0,1]、网格 i/64；固定正则 λ = 0.1，且此处**不使用**方差膨胀，用离散版 (2.3) 实现。评价指标三项：数据失配 E[(1/J)Σ_j|Au⁽ʲ⁾ − y|²]、Tikhonov 正则损失 E[(1/J)Σ_j I(u⁽ʲ⁾, λ)]、残差 E[(1/J)Σ_j|e_r⁽ʲ⁾|²]。

## 主要发现与核心结论（Main Results）

**理论结果（线性前向映射 + 变分膨胀 + 时变 Σ_t）。** Proposition 2.2 证明耦合 SDE 系统的强解存在唯一（要求初始集合几乎处处线性无关），由 F = [A; I] 为有界线性映射加 [9] 的 Theorem 3.4 得到。Proposition 2.3 给出集合坍缩的定量速率：E[(1/J)Σ_j|Σ⁻¹ᐟ²F(e_t⁽ʲ⁾)|²] ≤ 1/(C₀⁻¹ + ((J+1)/J²)t)，且 E[(1/J)Σ_j|e_t⁽ʲ⁾|²] = O(t⁻¹)。**Proposition 2.4 是本文相对前作最关键的推进**：在 y = Au† + η† 含噪情形下，E[(1/J)Σ_j|r̃_t⁽ʲ⁾|²] 严格单调递减——作者明确对比指出，对原始 EKI 应用 [9] 的 Prop 5.1 只在**无噪数据**下才有单调性，而 Tikhonov 正则的引入带来了**对含噪数据的稳定性**。加入方差膨胀后，收敛速率提升为 O(t^-(1-α))，收敛到 I(u,y) 的极小解（线性 + C₀ 正定时 I 强凸，Hessian = AᵀΓ⁻¹A + C₀⁻¹ > 0，最小特征值 κ_min > 0）。

**Theorem 2.6（自适应情形的主定理）。** 在 Assumption 2.5 成立、观测含噪、初始矩有界的条件下，对任意 α > 0 有 E[min_{s≤t} (1/J)Σ_j|r̃_s⁽ʲ⁾|²] ∈ O(t^-(1-α))。这一步的意义在于：它把"固定 λ 的收敛性"平移到了"λ_t 与 Γ_t 随时间学习"的情形，**只要学习进程足够快**（Ψ_t 的衰减速率受控、总变差有界）。证明在附录 A，通过链式法则处理 d(Σ_t⁻¹ᐟ²r̃_t)/dt 中 Σ_t 的时变项，并用 du*_t/dt = (AᵀΓ_t⁻¹A + C_t⁻¹)⁻¹AᵀΨ_t^Γ 追踪极小解本身的漂移。

**数值结论（线性 PDE）。** 三种自适应方案在 λ† = 50 与 λ† = 0.04 两个算例中**一致优于**无正则 EKI 与固定正则 TEKI。无正则 EKI 最差（重建方差最大），原因是数据失配权重过大导致**过拟合数据**；固定正则次之，在 λ† = 50 时正则不足（仍过拟合），在 λ† = 0.04 时正则过强导致**过度平滑**。三种自适应法同时避免了这两个失效模式。学到的 λ 在 λ† = 50 时升到 10² 数量级（图 6），作者用图 4 的"残差-vs-λ 曲线在 λ 较大区间平坦"来论证这种大 λ 是合理的而非发散。定量上：残差从 10⁰ 量级降至 10⁻³（图 6/9），数据失配从 10⁰ 降至 10⁻¹、Tikhonov 正则损失从 10⁻¹ 降至 10⁻⁶ 量级（图 7/10）。

**数值结论（非线性 Darcy 流）。** 趋势与线性算例一致：自适应法显著降低数据失配、加大正则权重（图 11、13），学到的 λ 达 ~40 量级（远大于固定值 0.1，图 12）。**Algorithm 3 表现最好**：图 14 显示所学习正则协方差的**最小特征值下降幅度远小于最大特征值**（最小从 0 降到 ~0.08，最大从 0 升到 ~20），这正是 KL 展开中不同系数需要不同权重的结果，因而比单一标量 λ 更精细；其残差也低于 Algorithm 1 与 2（图 12 右）。

**作者对三方案的预期（Sec 3.4）。** Algorithm 1 有既有理论支撑（源自 [12,17]），**在线性情形预期表现最好**；非线性下因 T_λ 无闭式解、只能用粗糙线性化选参，预期收益会打折。Algorithm 3 可视为 Algorithm 2 的推广，预期同样表现良好，且能扩展到学习完整协方差结构。整体结论：**自适应正则方案在含噪数据下显著优于固定正则**。

## 潜在研究方向（Future Directions）

**作者自述的局限与方向（Section 5）。** 第一，**理论只覆盖线性前向映射**——非线性情形的理论是明确的空白，作者建议借助 [16,7] 的工具并将其适配到连续时间设定。第二，**可引入其他正则形式**，如 L₁；作者指出非自适应版本已被研究过（[36,47]），自适应版本是自然的延伸。第三，**自适应方案可迁移到其他迭代正则方法**，如 Landweber 或 Levenberg–Marquardt 正则。第四，**时变前向映射的完整分析**是"合著者正在进行的工作"（作者原话），这可能带来时变 PDE 的更优反演建模，即 time-dependent EKI。

**需要读者注意的注意事项与假设边界。** Assumption 2.5 要求的 Σ_t⁻¹ ⪰ σ_min I 与 B̃_t 特征值一致下界是**非平凡的条件**，在算法实现中若 λ_t 逼近 0 可能被破坏；∫₀ᵗ||Ψ_t||dt ≤ κ₁ 的总变差约束实际上把可用的步长策略限制在较窄的范围。三种方案的**理论保证并不一致**：Algorithm 1 有既有理论但该理论不直接适用于非线性，Algorithm 2/3 主要是数值验证，Algorithm 3 的梯度下降形式是出于数值稳定性的工程选择而非理论最优。数值算例规模相当小（线性 J = 50 粒子、Q = 100 路径、d_u 与 K 都很小；非线性 d_u = 未知系数维数、d = 截断维数未在文本中给出明确数值），且**只测试了一个非线性模型（Darcy 流）**；线性算例中"真值由 λ† 生成"这一构造使先验与真值的关系是已知且人为设定的，与真实反问题中先验误设的情形可能仍有差距。另外要注意的是，"学到的 λ 数量级与 λ† 相当"这一观察是**间接**的——λ† 是先验方差的缩放，而 C₀ 还含因子 10·(−Δ)⁻¹，二者并非同一标度，不能直接等同。

**方法**：随机 EKI 的自适应 Tikhonov 正则（双层优化/MAP/层次贝叶斯三方案）

**原理**：把 Tikhonov 正则嵌入 EKI 观测模型（扩充 F(u)=[G(u);u]），首次系统地把'正则参数自适应学习'与'含噪随机 EKI 收敛证明'结合：Prop 2.4 证明正则化带来含噪数据下的残差单调递减（原始 EKI 仅无噪成立）；三种在线选参方案——双层优化参数自助法、MAP 解析临界点、层次贝叶斯学习完整先验协方差特征值——含噪数据下一致优于固定正则与无正则。

**参数表**：

| 参数 | 数值 | 出处 |
| --- | --- | --- |
| 集合坍缩速率 | E[(1/J)Σ|e_t|²] = O(t⁻¹)；方差膨胀后 O(t^{-(1-α)}) 收敛到 Tikhonov 泛函极小 | 主要发现 |
| 自适应主定理 | E[min_{s≤t}(1/J)Σ|r̃_s|²] ∈ O(t^{-(1-α)})（学习进程受 Assumption 2.5 约束） | 主要发现 |
| 学到的正则参数 | 线性算例 λ 升至 10² 量级；Darcy 流学得 λ~40（远大于固定 0.1） | 主要发现 |

**适用边界**：理论仅覆盖线性前向映射（非线性空白）；Assumption 2.5 的 Σ_t 一致下界与总变差约束非平凡（限制步长策略）；三方案理论保证不一致（Alg.2/3 主要是数值验证）；数值规模小且仅一个非线性模型（Darcy）。
**代表作**：Weissmann, Chada, Schillings, Tong, Adaptive Tikhonov strategies for stochastic ensemble Kalman inversion, Inverse Problems 38, 045009 (2022)
