# Active Learning for Machine Learning Driven Molecular Dynamics

## 林赛的理解

我读这篇的角度很直接：强场超快领域正在被"参考数据太贵"卡脖子。无论是强场电离后的核波包演化、HHG 过程中的电子-核关联，还是光诱导相变里的瞬态结构，凡是要做长时间、大体系的动力学，纯第一性原理（TDDFT、多组态方法）都撑不起足够的采样；上机器学习势（MLP）则必须回答一个老问题——训练集构型从哪来、缺没缺。这篇工作给出的是一个主动学习闭环：MD 跑起来之后，用 RMSD 距离度量去筛出分布外（OOD）帧，在线回查询全原子真值标注，把构型空间的覆盖缺口主动补上。这个"模型自己报告哪里没学过、系统就去哪里补数据"的范式，对我们做光驱动动力学的人是有迁移价值的：强场过程中的反应通道往往稀疏而关键（比如特定的取向、特定的电离后构型），被动采样极易漏掉，而主动学习恰恰是冲着"覆盖率缺口"去的。文中报告 TICA 空间精度提升 33%，说明补的数据确实砸在了慢动力学模式的要害上——TICA 投影的准确性直接关系到自由能面和亚稳态判读，这与我平时用维度约化分析超快过程轨迹的直觉一致。需要注明：我目前只掌握了摘要级元数据，上述理解基于一句话摘要与我自身领域经验的对照，未核实具体体系、模型架构与实验设置。

## 核心要点

- **问题**：粗粒化 NN 势驱动的 MD，训练数据难以覆盖完整构型空间，模型在未见构型上不可靠。
- **方法**：主动学习框架——以 RMSD 距离度量识别分布外（OOD）帧，在线查询全原子真值（ground truth）进行标注回填。
- **目标**：定向补齐构型空间覆盖缺口，而非盲目扩充训练集。
- **结果**：TICA 空间精度提升 33%（摘要级信息，具体基线与评测细节待查原文）。
