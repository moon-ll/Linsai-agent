• # 用原子单电子晶体管成像亚莫尔超晶格势场

  ## 林赛的理解

  这篇工作是 Ilani 组把 QTM（量子扭转显微镜）平台升级为**原子级静电势成像工具**的标志性成果。核心思想非常直接：不用微加工的 SET 岛，而是直接拿 vdW 材料里天然存在的单原子缺陷当量子点用——缺陷探测的是它所在位置的局域电势，扫描就得到势场图。空间分辨率从传统扫描 SET 的 >100 nm 提到 **~1 nm**，电势灵敏度 **6 µV/√Hz**，两个数量级的提升。

  对我们的研究，这篇有三层意义：

  1. **方法论层面**：缺陷即传感器（defect-as-sensor）的思路对"如何把超灵敏局域探针做到亚纳米尺度"是一个范式参考。我们在思考莫尔体系的强场超快读出时，一直面临"探针分辨率和灵敏度不可兼得"的张力，Atomic SET 用"倒置几何"（样品上针尖、传感器固定）绕开了这个问题——可以从大量天然缺陷里挑一个最优的。这个"平台固定 + 被测物扫描"的架构值得借鉴。
  2. **物理层面**：G/hBN 的莫尔势实测 **55–63 mV**、近似 C6 对称、几乎不随载流子密度变化（~10%），而理论只有一半。这个"理论漏掉一倍"的事实对所有依赖 G/hBN 界面的体系（包括菱形五层石墨烯的 FQAHE）都是警示——莫尔势的"已知"其实是半知的。
  3. **定量接口**：势随离界面距离快速衰减——0.8 nm 到 1.5 nm 衰减 ~60%，一个莫尔周期距离处只剩 ~10%。这告诉我们任何探测莫尔势的探针（包括未来可能的超快光学/太赫兹读出）都必须工作在极近界面的几何下。

  ## 研究问题

  能否直接成像 vdW 异质结构界面（特别是石墨烯/hBN 对齐界面）的静电莫尔势场，而不是像过去那样只能依赖输运和光学手段间接推断？具体子问题包括：莫尔势的空间对称性是什么、幅度多大、对载流子密度依赖多强、现有理论模型能否定量复现实验？

  ## 研究背景

  - 固体中电子性质由其所处的周期势场决定；莫尔工程把可调控周期势推到纳米尺度。G/hBN 是最经典的莫尔界面，催生了 Hofstadter 蝴蝶、Brown-Zak 振荡等一系列发现，近来还在魔角双层石墨烯铁磁（Sharpe 2019；Serlin 2020）、双层石墨烯非常规铁电（Zheng 2020）、菱形五层石墨烯分数量子反常霍尔效应（Lu 2024）中起稳定作用。
  - 但该界面的莫尔势此前只能从输运（Lee 2016；Yankowitz 2018）和光学（Shi 2014；Ni 2015）测量间接推断。TMD 中带边可作势场直接标记（Shabani 2021），G/hBN 则没有这种天然标记，需要新的成像技术。
  - 最灵敏的静电势成像工具是扫描单电子晶体管（SET，Yoo 1997；Honig 2013；Xie 2021），但微加工岛尺寸限制其分辨率 >100 nm，无法分辨单个莫尔晶胞内的势。STM 加石墨烯传感层（26）只有中等分辨率。直接可视化 vdW 异质结构内的莫尔势此前未被实现。

  ## 研究方法

  方法密度高，按方法卡格式整理。

  **原理**：利用 TMD 层中天然原子缺陷在低温下形成量子点（QD），处于库仑阻塞态。缺陷电势 φ_d = αφ_t + (1−α)φ_b，α = d_b/(d_t + d_b) 为几何杠杆因子（d_t、d_b 为缺陷到上、下层的距离）。扫描携带被测体系的 QTM 针尖经过固定缺陷时，缺陷处局域电势变化调制 QD 共振条件，追踪零偏压库仑峰的栅压位置 V_tg^peak(x) = K·φ(x) + Kμ，即可直接提取空间电势 φ(x)。倒置几何（样品在针尖上、缺陷固定）允许从大量天然缺陷中筛选最优者。同时通过库仑钻石边界的弯曲可测局域电子压缩率（compressibility）。

  **参数表（装置配置）**：
  - 平台：量子扭转显微镜（QTM，Inbar et al., Nature 614, 682–687, 2023），可在 vdW 异质结构中形成 pristine、可扫描的 2D 界面
  - 传感端：少层 TMD（室温成像用三层 WSe₂；主数据用双层 WSe₂ 势垒）+ 石墨烯底电极；传感器件含 61 nm 厚 hBN 层 + 金属底栅
  - 针尖端：对齐 G/hBN 莫尔界面 + 24 nm 厚 hBN + 石墨顶栅
  - 工作温度：T = 0.2 K（主数据）；室温下也可成像
  - 偏压选择：主成像用 V_b = −0.35 V（单层缺陷、近零背景隧穿）；对比测量用 V_b = −1.25 V、−0.9 V、−0.7 V
  - 磁场：对比测量用 B = 5 T，用于标定上下石墨烯层的朗道能级（顶层 ν = ±2, ±6；底层 ν = ±2）
  - 结区控制电压：顶栅 V_tg、底栅 V_bg、偏压 V_b 三路
  - 关键器件特征：接触非线性阈值 |V_b| < V_th ≈ 65 mV 区间内偏压主要降在接触上（器件特异，SI Section 10）

  **测量序列**：
  1. 先做大偏压扫描成像定位缺陷：高偏压下大量缺陷成像为"肺形"针尖接触区复制品；逐步降偏压缩小可及缺陷能窗，直至扫描窗内只剩单个低能缺陷
  2. "off-defect" 标定结区静电学：测 dI/dV 对 V_tg、V_b 的依赖，拟合上下层电中性点（CNP）曲线，建立三电压→双层密度的完整标定
  3. "on-defect" 库仑钻石测量：提取库仑峰位置对 V_tg 的响应系数 K，并通过 CNP 偏折点与 5 T 下朗道能级台阶验证压缩率响应
  4. 成像序列：固定 V_b（D1 缺陷零偏压；D2 缺陷 V_b = −0.21 V），在每个空间点扫 V_tg 测零偏压 dI/dV，提取 V_tg^peak(x,y)，经 K 换算得 2D 势场 φ(x,y)；对多个莫尔位点平均
  5. 距离依赖：用距界面 0.8 nm（D2）和 1.5 nm（D1）的两个缺陷分别测势，标定衰减

  **计算设置**：自洽 Hartree 计算（SI Section 14），载流子密度对应 ν = 4；屏蔽按 RPA 介电常数 ε = 1 + 4α_g ≈ 2.0 处理，α_g = e²/(κℏv_F) 为石墨烯精细结构常数，κ = 3.5 取 hBN 介电常数；势分解为三项：层间堆垛赝势（对应单位矩阵）、形变赝势（形变势，源自面内弛豫对 C-C 键的拉伸压缩）、赝磁场项（对应 σ_x、σ_y 子晶格泡利矩阵）。

  **适用边界**：
  - 分辨率 ~1 nm（由缺陷成像边缘锐度确定，SI Section 6）；灵敏度 6 µV/√Hz，相当于在 1 nm 距离上分辨单电子电势的百万分之几
  - 探针必须极近界面：一个莫尔周期距离处只剩 ~10% 信号（正文公式 + Extended Data Fig. 1，0.8→1.5 nm 已衰减 ~60%）
  - 势场测量在零（或小）偏压下进行以避免热电子/声子注入干扰热力学基态
  - 莫尔异质应变很小（典型 < ±0.3%，SI Section 7），转移到针尖未显著扭曲莫尔结构
  - 填充因子误差源于调 QD 共振所需的栅压掺杂（ν = 0 ± 0.15、1.3 ± 0.2、4 ± 1）

  **代表作**：Klein, Zondiner et al., 2024（本文，1 nm / 6 µV/√Hz）；Inbar et al., Nature 614, 682–687 (2023)（QTM 平台）。

  ## 主要发现与核心结论

  1. **首次直接成像 G/hBN 莫尔静电势**。势的峰-峰幅度很大：55–63 mV；在零载流子密度下仍达约 63 mV。
  2. **对称性近似 C6**：莫尔晶胞中心（CN 堆垛点）为势极大值；周围两个极小值（CB 与 AA 堆垛点）相隔 60°，两者势差仅 ΔV_C6 ≈ 4 mV，相对总幅度是小量——存在微弱的 C2 成分但整体接近 C6。
  3. **对载流子密度依赖极弱**：ν = 0 ± 0.15、1.3 ± 0.2、4 ± 1 三个填充下幅度仅变化 ~10%。
  4. **理论定量失配**：自洽 Hartree 理论能复现近似 C6 对称性（堆垛赝势与形变赝势各自 C2 对称但相互补偿），但预测幅度只有实验值的一半。单调增大应变会给出 C2 对称势，与实验矛盾——说明即使对 G/hBN 这样"最被充分研究"的莫尔界面，理论理解仍有实质缺口，对依赖该界面设计新物态（如五层石墨烯 FQAHE）的实验有直接后果。
  5. **屏蔽的作用**：载流子屏蔽保持赝势形状但幅度减小约 2.2 倍，与 RPA 介电常数 ε ≈ 2.0 一致；赝磁场项被屏蔽转化为一个小的、随 ν 线性且 ν=0 时恒为零的静电势，因观测到密度依赖很弱而可忽略。
  6. **工具性能**：1 nm 空间分辨率（比现有 SET 好两个数量级，低于许多体系的费米波长、磁长和莫尔尺度）；6 µV/√Hz 灵敏度。针尖上莫尔异质应变典型 < ±0.3%。
  7. **势的空间衰减**：0.8 nm → 1.5 nm 衰减约 60%；推断在一个莫尔周期（λ_m ≈ 14 nm，本实验样品）处只剩 ~10%。薄层体系中（如五层石墨烯）最远离界面的石墨烯层仍可感受数十 mV 的莫尔势。

  ## 潜在研究方向

  - 实验势幅度（55–63 mV）约为自洽理论的两倍，且不能通过简单增大应变解释（应变会把对称性推向 C2）——理论缺失的物理机制未解决（候选：被低估的界面应变及其分布、超越 Hartree/RPA 的关联效应、赝势与形变势的幅度标定）。
  - 赝磁场项与质量项在 ν≠0 时线性出现，本文因密度依赖弱而未展开；高密度或低对称体系（转角更大、更强弛豫）中这些项可能不可忽略。
  - 接触非线性阈值 V_th ≈ 65 mV 以下的偏压降落在接触上，是器件特异效应——器件工程上如何消除或利用这一点未讨论。
  - 势随距界面距离快速衰减（亚纳米即衰减大半），意味着厚样品深处的莫尔物理难以用此技术探测；需要解决"探测深度"问题。
  - 缺陷化学身份未鉴定（多种缺陷空间结构相同暗示同一起源）；不同缺陷能级、不同 TMD 势垒（三层 vs 双层 WSe₂）对测量带宽/灵敏度的系统比较未做。
  - 展望中列出但未实现的应用：Wigner 晶体、拓扑边缘态、涡旋电荷、对称破缺相、分数电荷准粒子的成像；电子压缩率与熵的定量测量仅在原理上展示。

  ## 与林赛研究的关联

  - **莫尔 + 量子几何**：本文给出的 G/hBN 莫尔势实测幅度（55–63 mV，ν≈0）和 C6 对称性是任何"莫尔体系强场驱动/超快读出"课题必须面对的基态势场事实——我们的"莫尔强场探针"课题（general-moire-strong-field-probe-20260726）在估计局域场增强、载流子布居与布洛赫振荡条件时，应以此实测值为基准而非理论半值。赝磁场项的存在（虽在 G/hBN 中因屏蔽转小）与"量子几何/贝里曲率工程"方向直接相关。
  - **强场驱动接口**：局域静电势的亚纳米分辨成像意味着可以实验验证"外场 + 内建莫尔势"叠加下的真实局域能带结构，这对我们设计强场作用下莫尔体系的极端非平衡响应实验（隧穿/太赫兹谱/超快电流读出）是重要的诊断工具候选。
  - **方法学借鉴**：倒置几何（固定传感器、扫描样品）+"从天然缺陷池中选优"的模式，对任何需要在亚纳米尺度同时获得高灵敏度的读出探针（包括我们设想的超快光学-电学混合读出）有架构层面的参考价值；其零偏压库仑峰追踪读出方式也可类比到超快泵浦下库仑峰瞬态位移（singlet-triplet / 态占据瞬态读出）的设想。
  - **注意边界**：势在距界面 1.5 nm 处已衰减 ~60%，我们的任何界面敏感探测（HHG/阿秒 streaking 类）若在多层体系上，只有最邻近界面的一两层真正"感受"完整莫尔势。

## 阅读笔记

### general-moire-strong-field-probe-20260726

### 研究问题（Research Question）
本文核心问题是：能否在实空间直接成像石墨烯/hBN对齐体系中的亚莫尔（sub-moiré）静电势？作者发明"原子单电子晶体管（Atomic SET）"扫描探针，针对最典型莫尔界面给出第一张实空间电势图，并测试既有理论的预测能力。

### 研究背景（Background）
莫尔超晶格已成为调控纳米尺度周期势的平台，催生了关联绝缘、超导、量子反常霍尔等新物态。然而受限于空间分辨率与电荷灵敏度，直接电势成像长期缺位。前人工作主要借助STM隧穿电流或近场光学，但灵敏度不足。量子扭转显微镜（QTM）此前提供了一种原位扫描vdW异质结的范德华界面方法，但缺乏原子级势成像传感器。

### 研究方法（Methods）
技术核心：利用vdW材料中的单原子缺陷构造Atomic SET，作为QTM平台下的超灵敏势成像探针，具备1 nm空间分辨率与对约百万分之一电子电荷的灵敏度。实验中扫描石墨烯/hBN莫尔界面，记录不同载流子密度下的静电势分布，并与理论模型对比对称性来源。

### 主要发现与核心结论（Main Results）
首次给出石墨烯/hBN莫尔界面实空间电势图，势近似C6对称，对载流子密度依赖微弱，且在无载流子条件下仍具有约60 mV的显著幅度。势的对称性只能通过多种竞争对称机制的精细平衡解释，而其幅度显著高于现有理论预测，意味着对莫尔起源的理解仍不完整。

### 潜在研究方向（Future Directions）
局限在于扫描速度与采样面积仍受限，目前难以覆盖大面积器件；未来可拓展到对称破缺相、量子晶体、涡旋电荷、分数量子准粒子等更复杂物态的成像。开放问题包括：在HHG强场超快探测中，若莫尔势随光场重塑，Atomic SET能否追踪其飞秒动力学？这与课题"moiré强场探测"目标直接相关。
