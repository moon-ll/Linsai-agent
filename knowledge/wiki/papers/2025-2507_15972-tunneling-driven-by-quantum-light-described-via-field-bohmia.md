# 用Bohmian场轨迹描述BSV驱动隧穿

## 林赛的理解

这篇工作为量子光驱动的强场物理提供了优雅的半经典理论框架。核心贡献在于：将量子光（BSV）分解为经典场的集合（通过Bohmian轨迹），使每个场的隧穿事件可独立处理，量子统计特性最终体现在测量电流中。对林赛而言，这解决了BSV驱动HHG实验中一个关键理论需求——如何在不做正P分布近似的情况下描述量子光-隧穿耦合。框架可直接移植到我们的交变磁莫尔体系：量子光场 → Bohmian轨迹束 → 电子隧穿（或HHG）响应。特别值得注意，定量结果中Keldysh参数γpeak的分类依然有效，这意味着经典强场图像在量子驱动下仍有结构基础。

## 研究问题（Research Question）
如何建立描述量子光（如亮压缩真空，BSV）驱动隧穿的严谨理论框架？具体问题包括：
1. 如何在不假设正P分布、不忽略量子涨落的条件下处理BSV与物质的相互作用？
2. 如何将已知的经典场非绝热隧穿理论（quasiclassical non-adiabatic tunneling theory）推广到量子光驱动情形？
3. 量子光驱动隧穿是否存在类似经典Keldysh参数的分类标准？

## 研究背景（Background）
**学术脉络：**

HHG是强场物理的标志性现象，三步模型（隧穿→经典运动→复合）成功描述了原子HHG的频率平台与截止区。但光场处理始终为经典半经典近似——量子光源的相干场可忽略量子修正。

**量子光进展：**

近年出现亮度超过10¹³光子/少周期脉冲的BSV光源突破（Spasibko et al. 2017; Manceau et al. 2019），打开了量子光强场物理的新领域。理论上出现基于相干态展开研究非经典光驱动HHG和自由电子动力学的工作，但预测结果与经典场解释惊人一致，表明需要更深的理论洞察。

**Bohmian力学应用：**

Bohmian力学（量子流体力学形式）已在强场电子动力学中用于研究离子化区间转变、隧穿时间与出口位置定义等问题，但此前均处理经典光场，电子用Bohmian轨迹描述。本文反过来：用Bohmian轨迹描述量子光场，电子用实经典轨迹描述，形成一致的半经典图像。

**研究动机：**

现有理论在处理量子光时需假设正P分布并忽略涉及相干态幅度的量子涨落，本文旨在突破这一近似限制，建立更完整的量子图景。

## 研究方法（Methods）
**材料体系：**

金针尖-表面系统，隧穿势垒ΔU = 5 eV，间隙约几纳米。选择此几何构型是为了限定隧穿方向，仅收集从针尖到表面的单向电子输运。

**关键方法——Bohmian场轨迹：**

单频模式（中心频率ω），线性偏振固定。哈密顿量Ĥ = ℏω(â†â + 1/2) = ℏω(·P² + ·X²)/2。压缩真空态|ψ(t)⟩ = |ze⁻²iωt; 0⟩由压缩算符Ŝ(z) = exp(½zâ†² − ½z*â²)作用于真空态得到，z = re^(iϕ)。

波函数在X表象中为：

ψ(X) = ψ(0) exp(−c₋/c₊ · ½X²)

其中c± = cosh r ± e^(iϕ) sinh r。

概率分布ρ(X, t) = |ψ(X, t)|²满足连续性方程，概率流（概率通量）J(X, t) = ωIm[ψ*(X, t)∂Xψ(X, t)]，定义Bohmian速度：

Ẋ(t) = v(X, t) ≡ J(X, t)/ρ(X, t) = ωIm[∂Xψ(X, t)/ψ(X, t)]

对于压缩真空，P(t)（正交电场）给定为：

P(t) = −c(t)X(tᵢ)e^(−ω∫ₜᵢᵗ c(t′)dt′)

c(t) = [−sin(ϕ − 2ωt)sinh(2r)] / [cos(ϕ − 2ωt)sinh(2r) + cosh(2r)]

初始分布ρ(X, tᵢ) = |⟨X|z·e⁻²iωtᵢ; 0⟩|²为高斯分布。

**关键参数：**

ω = 0.0285 a.u.（对应0.775 eV），√(ℏω/ε₀V) = √2 × 10⁻⁸ a.u.（与实验观测真空涨落相关）。

**隧穿理论——非绝热准经典方法：**

采用修正的WKB（虚时间法），区别于原始方法可处理不对称场轮廓。电子准经典波函数 ψ_el(x, t) ∝ e^(i/ℏ S(x,t))，作用量 S(x,t) = ∫ₜ₀ᵗ L(x′, ẋ′, t′)dt′ − Et₀。势垒区域为常数静态势 U(x′) = −ΔUΘ(−x′)。

边界条件：x′(t′ = t₀) = 0, x′(t′ = t) = x；且 ḋ′(t = t₀) = i√(2ΔU/m)。

额外条件：∂_t Im S(x, t) = 0 → Im[mẋ′(t′ = t)] = 0（类空区域）。

隧穿概率（指数精度）：P = e^(−2/ℏ Im S_opt)。

**轨迹平均：**

总隧穿概率需对所有场实现的隧穿概率P(Xᵢ)按初始分布ρ(Xᵢ)加权平均：

P_tot = ∫₀⁻∞ P(Xᵢ)ρ(Xᵢ) dXᵢ

仅取X < 0的实现（X > 0的场将电子拉回针尖）。

**有效Keldysh参数：**

γ_peak = ω√(2mΔU) / (eE_peak)

## 主要发现与核心结论

**1. 量子光Bohmian轨迹束**

BSV被分解为一束经典场实现，每束由确定的Bohmian轨迹X(t)表征。概率分布ρ(X, t)在相空间中展示非谐振荡特性：X不变号但存在符号相反的对应实现，P quadrature呈现围绕零的非谐振荡（r越大非谐性越强）。两种quadrature在任何时刻的平均值均为零，这是纯量子光的本质特征。

**2. 锯齿场实现**

随r增大，场的时间轮廓呈现锯齿状，在满足 ωtₙ/2π = (2n+1)/4 的时刻附近出现突变。这是压缩真空的特有性质。

**3. 最优隧穿时刻**

电子在实时间 τ₀ = Re t₀ 时刻从势垒中出现，τ₀非常接近电场时间轮廓的垂直边缘（而非峰值点，向节点方向偏移）：

τ₀ = (2π/ω)[1/4 + ε + n/2], n ∈ Z

其中 0 < ε ≪ 1。由于几何不对称性，仅考虑将电子从针尖推向表面的场实现（X < 0），X > 0的实现将电子拉回。

**4. P_tot(γ_peak)平滑过渡**

总隧穿概率P_tot随有效Keldysh参数γ_peak的变化平滑地从多光子区（γ_peak ≫ 1）过渡到直接隧穿区（γ_peak �ll 1），表明基于Keldysh参数的分类可推广到量子光驱动情形。

**5. 核心结论**

将量子光表示为确定性Bohmian场轨迹束，为处理光-物质相互作用中的量子光问题提供了严谨框架。该方法与非绝热准经典隧穿理论完美结合，推广了经典光驱动情形下的相应描述。特别适用于非对称几何（隧穿显微镜、非对称纳米天线），理论可作为任意量子态光驱动光致隧穿实验的平台，并可桥接半经典理论（如含经典驱动的含时薛定谔方程或其Bohmian对应）与全量子类比。

## 潜在研究方向（Future Directions）
1. **多模量子光驱动**：框架可扩展到多模BSV，研究模式间量子关联对隧穿/HHG的影响
2. **光-物质纠缠生成**：利用量子光驱动产生光与物质之间的量子纠缠态
3. **Fock态驱动**：相比BSV（相干态叠加），研究光子数确定态（如Fock态）驱动的隧穿动力学
4. **返回电子与复合过程**：本文聚焦隧穿阶段，后续可加入三步模型的返回与复合环节，完善HHG全链条描述
5. **固体系统推广**：从金针尖-表面拓展到固体HHG（块体晶体、莫尔超晶格），量子光驱动的量子几何响应
6. **背作用近似验证**：本文忽略电子对场的反作用（无backaction），可进一步研究强耦合极限下的修正效应
7. **实验验证**：与2024年BSV驱动HHG实验（Rasputnyi et al. 2024）对比，检验理论预言的隧穿概率与量子统计效应

## 与林赛研究的关联

- **HHG**：框架直接描述BSV驱动下的隧穿事件，是HHG三步模型的第一步。量子光Bohmian轨迹束提供比经典场更丰富的统计结构，可能在HHG平台与截止区产生可测量的量子光学效应（纠缠光子对、Schrödinger猫态等）
- **阿秒**：隧穿延迟时间τ₀的精确确定（接近电场节点而非峰值）涉及阿秒时间分辨率的物理，对理解隧穿时间本质有直接意义
- **强场驱动**：γ_peak的分类有效性表明，经典强场图像在量子驱动下仍有结构基础；但量子涨落（压缩参数r）可显著改变场轮廓（锯齿化），这在极高强度下可能改变电离机制
- **交变磁**：金针尖-表面体系的隧穿输运与莫尔超晶格中二维电子气的隧穿动力学有几何相似性；量子光Bohmian方法可推广到层间隧穿与层间谷间输运
- **量子几何**：BSV的量子涨落结构（不同于相干态的确定性振幅）可能在隧穿电流中留下特征印记，类似于量子几何（Berry曲率、量子度规）对输运的修饰效应
