**Entanglement Chern Number for an Extensive Partition of a Topological Ground State**
Takahiro Fukui (Ibaraki Univ.), Yasuhiro Hatsugai (Univ. Tsukuba)
arXiv:1408.3471 [cond-mat.mes-hall; hep-th] → J. Phys. Soc. Jpn. **83**, 113705 (2014). DOI: 10.7566/JPSJ.83.113705（开放获取，4 页 2 图）

## 研究问题（Research Question）

核心问题：能否**仅凭纠缠哈密顿量的波函数**、**不依赖体系对称性保护**，构造一个良定义、可计算、能刻画**体相**拓扑性质的不变量？具体而言，若二维体系的**广延（extended）分划**产生的约化密度矩阵具有**有隙纠缠谱**，则由对应纠缠本征态的 Berry 曲率积分定义**纠缠陈纳数**（entanglement Chern number）。

三重具体诉求：(1) 为时间反演对称体系（常规 c = c↑+c↓ = 0 平凡）提供 Z₂ 之外的**替代方案**；(2) 为**无对称性保护**的超晶格弱拓扑相提供**新的**不变量；(3) 在方法论上把**体-边对应**实现在"实空间纠缠描述"中。

## 研究背景（Background）

Chern 数自 Thouless 等 (1982) 起即决定整数量子霍尔电导，经 Altland-Zirnbauer/Schnyder 的十重分类 (1996–2009) 成为最通用工具；Fukui-Hatsugai-Suzuki (JPSJ 74, 1674) 的 link & plaquette 方法使其可稳定数值计算——本文直接复用。纠缠谱自 Li-Haldane (PRL 101, 010504) 起成为拓扑绝缘体标准工具，经 Prodan-Hughes-Bernevig、Alexandradinata 等的 trace index/spectral flow、Huang-Arovas 的 Hofstadter 纠缠谱工作发展至成熟。

**直接出发点**是 Hsieh & Fu (arXiv:1305.1949) 与其与 Qi 合作的 arXiv:1407.0994 提出的"**体纠缠谱**"：通过广延且平移不变的分划，证明拓扑基态内在隐藏一次相变。本文在此框架下追问能否提取体相拓扑不变量。

**动机张力**：Kane-Mele 模型中 Rashba 破坏自旋守恒（c_σ 不可定义）；自旋陈纳数（Sheng 等 2006）虽可用却**必须在实空间计算**；Fu-Kane Z₂ 需 Kramers 对间的**特定规范固定**。而超晶格模型（Fukui-Imura-Hatsugai, JPSJ 82, 073708；Yoshimura 等, PRB 90, 155443）虽有反射对称性保护的弱拓扑相，但模型本身仅具粒子-空对称性、不提供保护，非平凡 c = 0 相难以表征。

## 研究方法（Methods）

**理论框架**：ρ_A = (1/Z)e^{−H_A} = tr_B|Ψ⟩⟨Ψ| (Eq.1)；引入关联矩阵 C_ij = ⟨c_i†c_j⟩ (Eq.2)；据 Peschel (J. Phys. A 36, L205)，ℋ_A^T = ln(1−C_A)/C_A (Eq.3)，故 **C_A 与 ℋ_A 共本征**。取广延平移对称分划后，傅里叶变换给出 **C_A(k) = P_A P₋(k) P_A** (Eq.4)。

因投影 P_A 存在，ξ_n **不限于 0 与 1**，而是形成**围绕 0 与围绕 1 的两组带**；假设组间有隙，取上半带 (ξ_n ≲ 1) 定义 Berry 连接与曲率，得 **c̃_A = (i/2π)∫F̃₁₂ d²k** (Eq.6)。数值上用 link & plaquette 变量在离散化布里渊区计算，且**不依赖纠缠波函数规范**（含 TR 对称体系亦然）。

**模型一（Kane-Mele）**：A = 自旋↑、B = 自旋↓；Rashba=0 时 H_KM = diag(H↑,H↓)，H_σ 等价无自旋 Haldane 模型。
**模型二（超晶格 Wilson-Dirac）**：H = (−it/2)Σ(c_i†σ_μc_{i+μ̂}−h.c.) + Σm_i c_i†σ₃c_i + (b/2)Σ(c_i†σ₃c_{i+μ̂}+h.c.−2c_i†σ₃c_i) (Eq.7)。均匀质量时 0<m<2b 给 c=1，2b<m<4b 给 c=−1。超晶格沿一维**交替**取 m₊(蓝线)/m₋(红线)，条纹周期 **2 个格距**（仅一个晶胞的平移对称性）。以**迹掉质量为 m∓ 的费米子**定义 c̃_±。

## 主要发现与核心结论（Main Results）

**1) 定义与规范不变性**：c̃_A 良定义、整数量子化、不依赖纠缠波函数规范；物理上即 H_A = Const. − ln ρ_A 的基态 Chern 数。

**2) Kane-Mele**：QSHE 相 **(c̃↑, c̃↓) = (−1, 1)**，平庸相 **(0, 0)**——能区分 c = 0 的 TR 对称类中的两相。Rashba=0 时与扭边界条件的自旋陈纳数**显式等价**，但**自旋不守恒时仍可在布里渊区定义**（这是相对 Z₂ 与自旋陈纳数的核心优势）。

**3) 数值奇异性与成本（关键定量结果）**：相变点处**纠缠谱能隙闭合极难在离散网格上观察**；更强地，**ξ_n(k) 与纠缠熵在相变点两侧（甚至紧邻相变点）都相似**，与"有边界分划"展现边缘态谱流的常规行为截然不同——反证所研究的确实是**无边界体纠缠谱**。作者**推测**（原文用 "we guess"）能隙以 **δ 函数型奇异方式**在少数几点闭合。**定量后果：纠缠陈纳数需约 100×100 网格，Z₂ 仅需约 10×10（~100 倍成本差）。**

**4) 超晶格弱拓扑相——新不变量**：相图 t=1, b=2，横轴 m₊ (0→4)，纵轴 m₋ (≈3.8→6.5)。**非平凡相 A** 位于中央、坐落 c=±1 相区重叠处，总 c = 0 但沿特定边界有边缘态，其 **c(c̃₊, c̃₋) = 0(1, −1)**——两个分量分别非平凡，与所有其它 c = 0 相的 0(0,0) **明显可区分**。其余相取"自然"值：c=0→0(0,0)，c=1→1(1,0)，c=−1→−1(0,−1)。

**5) 判别性检验（相 B）**：相 B 同为 c = 0 且有非平凡半隙态，但这些态**可绝热形变为一维解耦极限 m₋ → ∞ 的平带**，故与纠缠无关，纠缠陈纳数为**平凡 0(0,0)**——说明该不变量能区分"真拓扑"与"可形变为平带的假拓扑"。

**6) 失效判据（作者明确承认）**：m₊ = m₋ = m 时退化为均匀质量 Wilson-Dirac 模型，纠缠谱**无隙**（Hsieh-Fu 已证），无法定义纠缠陈纳数。机制在于均匀情形具**格距级精确平移对称性**，而 m₊ ≠ m₋ 时仅具**两格距（一个晶胞）**平移对称性——正是平移对称性降级使非均匀情形的纠缠谱可有隙。作者坦承"也存在纠缠陈纳数 plays no role 的案例"。

**7) 相互作用展望（仅原理性论证，无数据）**：Z₂ 无法直接用于相互作用体系；而 H_A = Const. − ln ρ_A 可由**有限体系精确对角化**获得，即使含相互作用；只要纠缠谱有隙，纠缠陈纳数与相应拓扑相对**有限但小的相互作用保持拓扑稳定**。

**总结论**：纠缠熵/谱用于澄清分划**边界**上的边缘态，纠缠陈纳数则通过**无边界**广延分划揭示**体相**拓扑性质——即"拓扑相在纠缠描述下的体-边对应"。

## 潜在研究方向（Future Directions）

**论文明示**：① 验证纠缠陈纳数能否在**含相互作用**的拓扑绝缘体中真正替代 Z₂（仅有稳定性论证，**未做任何相互作用数值计算**）；② **两类分划（边界型 vs 广延型）之间的关系**——原文明确称"研究两类分划之间的关系将是很有意思的"；③ 普适适用条件（何时存在有隙的广延平移不变分划）。

**已实现的后续工作**：Araki, Fukui & Hatsugai, PRB **96**, 165139 (2017), arXiv:1708.03722——三维 **section entanglement Chern number** 作为 TR 截面 Z₂ 的连续插值，发现纠缠谱中出现**两个 Weyl 点**，其**数目奇偶性区分 STI（奇）与 WTI（偶）**；Fukui & Hatsugai, JPSJ **85**, 083703 (2016), arXiv:1605.04015（自旋泵）；Fukui, JPSJ **84**, 043703 (2015), arXiv:1501.07031（纠缠混合态的解纠缠拓扑数）。

**技术性局限**：① 计算成本高且**能隙闭合在离散网格上原则上不可观测**，δ 函数机制仅为**作者推测**而非证明；② 适用性条件性依赖"广延+平移不变分划"与"该分划下纠缠谱有隙"，二者不自动满足；③ **纠缠陈纳数为 0 不能一般性地断言体系平庸**（相 B 案例）；④ 弱拓扑性的刻画是**方向选择性的**（边缘态对边缘相对超晶格的方向敏感），非各向同性；⑤ 全文限于**非交互单粒子**模型，实空间数值实现的规范处理细节未展开。

## 研究方法（方法卡）
<!-- methods-backfill:v1 -->
**方法**：纠缠陈纳数：广延分划纠缠谱 Berry 曲率积分的体相拓扑不变量（Kane-Mele 与超晶格弱拓扑应用）

**原理**：广延平移不变分划下约化密度矩阵的关联矩阵 C_A(k)=P_A P₋(k) P_A 与纠缠哈密顿量 ℋ_A=ln(1−C)/C 共本征；假设纠缠谱有隙，取上半带 (ξ≲1) 定义 Berry 曲率积分 c̃_A=(i/2π)∫F d²k——良定义、整数量子化、不依赖纠缠波函数规范（TR 对称体系亦然）。Kane-Mele QSHE 相 (c̃↑,c̃↓)=(−1,1) 区分 c=0 两相（Rashba 破坏自旋守恒时仍可定义——相对 Z₂ 与自旋陈纳数的核心优势）；超晶格模型区分「真拓扑」0(1,−1) 与「可形变为平带的假拓扑」0(0,0)。

**参数表**：

| 参数 | 数值 | 出处 |
| --- | --- | --- |
| 计算成本对比 | 纠缠陈纳数需 ~100×100 网格，Z₂ 仅 ~10×10（约 100 倍成本差）；相变点能隙闭合为 δ 函数型奇异的作者推测 | 主要发现与核心结论 |
| 失效判据 | m₊=m₋=m 均匀质量模型纠缠谱无隙（格距级精确平移对称）无法定义——m₊≠m₋ 的两格距平移降级使纠缠谱可有隙 | 主要发现与核心结论 |

**适用边界**：纠缠陈纳数为 0 不能一般性断言平庸（相 B 案例）；弱拓扑刻画是方向选择性的非各向同性；限于非交互单粒子模型，相互作用体系仅有原理性稳定性论证（有限体系精确对角化可得 ℋ_A）未做数值；适用性条件性依赖广延平移不变分划与纠缠谱有隙；两类分划（边界型 vs 广延型）关系为作者明示的开放方向。
