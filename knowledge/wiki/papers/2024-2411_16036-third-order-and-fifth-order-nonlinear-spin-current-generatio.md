• # Third-order and fifth-order nonlinear spin-current generation in g-wave and i-wave altermagnets, and perfectly nonreciprocal spin-current in f-wave magnets

  ## 林赛的理解

  这篇 Ezawa 的工作给出一套非常干净的**对称性选择定则**：高阶波对称磁体中，费米面节点数 = ℓ + 1 的体系只产生 ℓ 阶非线性自旋-Drude 电导（∝ E^ℓ），其余所有阶全部禁戒。对做交变磁（altermagnet）与强场超快读出方向的我来说，价值有三层：

  1. **交变磁自旋输运的"谱学指纹"库**——d 波（线性）、f 波（纯二阶）、g 波（纯三阶）、i 波（纯五阶），每个体系的自旋电流阶数是唯一标签。这直接服务于我们"序参量超快读出"课题：非线性自旋电流的阶数本身携带磁对称性的信息，可作为序参量身份的电学判据。
  2. **f 波磁体的完美非互易自旋电流**——只有二阶项存在，意味着电流方向与电场方向无关，是"整流型"自旋流的极限情况。这与我们关注的强场驱动下的非互易/整流响应是同一物理家族，提示把直流电场语言平移到 THz/强场驱动语言的可能。
  3. **无自旋轨道耦合的长相干自旋流**——整套机制不依赖 SOC，自旋流相干长度比自旋霍尔机制更长，这是把 altermagnet 作为"自旋电子学功能层"的核心理由，也是评审中必须答上的"为什么不用传统自旋霍尔效应"。

  需要注意：这是一篇纯理论解析工作（两带模型 + 半经典玻尔兹曼方程），不涉及任何实验测量序列或装置参数，因此"研究方法"节按理论方法整理，不虚构实验方法卡。

  ## 研究问题

  高波对称磁体（s、p、d、f、g、i 波）中，线性与非线性自旋电流的生成规律是什么？具体而言：

  - 各种高波对称（由费米面节点数标记：s 波 0 节点、p 波 1、d 波 2、f 波 3、g 波 4、i 波 6）磁体能产生哪些阶数 ℓ 的自旋-Drude 电导 σ^(ℓ)_spin？
  - d 波交变磁中已知的纯自旋电流现象能否推广到 g 波、i 波等更高波对称的交变磁？
  - f 波磁体是否存在特殊的非互易自旋电流行为？

  中心论点：当费米面节点数为 ℓ + 1 时，体系**只**产生 ℓ 阶非线性横向自旋电流（∝ E^ℓ）——线性自旋电流对应 ℓ = 1 的特例。

  ## 研究背景

  - 纯自旋流（有自旋流无电荷流）是自旋电子学的基础概念，传统上由自旋轨道耦合（SOC）诱导的自旋霍尔效应产生[Dyakonov-Perel 1971；Sinova et al., RMP 87, 1213 (2015)]。但 SOC 会旋转自旋方向、缩短自旋流相干长度，限制应用。
  - 近期发现 d 波交变磁体可在**无 SOC** 的情况下借助自旋劈裂能带结构产生自旋流（Naka et al., Nat. Com. 10, 4305 (2019)；Gonzalez-Hernandez et al., PRL 126, 127701 (2021)；Naka, Motome, Seo, PRB 103, 125114 (2021)；Bose et al., Nature Electronics 5, 267 (2022)），相干长度可能更长。
  - 对称性分类上存在 s、p、d、f、g、i 波磁体（Šmejkal, Sinova, Jungwirth, PRX 12, 031042 (2022)；PRX 12, 040501 (2022)；Hellenes et al. 提出 p 波磁体；Hayami et al. 提出动量依赖自旋劈裂）。其中 d、g、i 波破坏时间反演对称性，称为交变磁（altermagnet）。
  - 除 d 波交变磁外，其余高波对称磁体的自旋电流生成问题尚未解决。二阶非线性电导已被广泛研究（Sodemann-Fu 量子非线性霍尔效应等），但高阶非线性自旋电导的系统研究缺失。
  - 注意不存在 h 波磁体，因为五重旋转对称性与晶格对称性不相容。

  ## 研究方法

  理论方法（解析 + 紧束缚数值验证），无实验装置。

  **模型框架**：
  - 两带哈密顿量 H_total = H_0 + H_wave，H_0 为自由费米子动能（2D：ℏ²(k_x²+k_y²)/2m · σ₀；3D 同理加 k_z²），H_wave 为各波对称磁项（交换耦合 J，σ_z 为自旋好量子数 s = ±1）：
    - 2D：H_s = Jσ_z；H_p = Jk_xσ_z；H_d = Jk_xk_yσ_z；H_f = Jk_x(k_x²−3k_y²)σ_z；H_g = Jk_xk_y(k_x²−k_y²)σ_z；H_i = Jk_xk_y(3k_x²−k_y²)(k_x²−3k_y²)σ_z
    - 3D：H_d = Jk_z(k_x+k_y)σ_z；H_f = Jk_xk_yk_zσ_z；H_g = Jk_zk_x(k_x²−3k_y²)σ_z；H_i = J(k_x²−k_y²)(k_y²−k_z²)(k_z²−k_x²)σ_z
    - 紧束缚表示由替换 k_j → sin(ak_j)、k_j² → 2(1−cos(ak_j)) 构造（a 为晶格常数），定义在四方晶格/立方晶格/层状三角晶格上。
  - 由于哈密顿量对自旋对角（本质单带），Berry 曲率 Ω = 0，量子度规与 Berry 曲率偶极子对非线性电导无贡献——所有结果来自 Drude 机制。

  **核心公式**（ℓ 阶非线性 Drude 电导，非静态、任意阶）：
  - 玻尔兹曼方程：∂_t f − (eE/ℏ)·∇_k f = −(f − f⁽⁰⁾)/τ，τ 为弛豫时间，f⁽⁰⁾ = 1/(exp(ε−µ)+1)。
  - 递归解给出 ℓ₁+ℓ₂ 阶分布函数 f⁽ℓ₁+ℓ₂⁾ = (e/ℏ/(iω+1/τ))^(ℓ₁+ℓ₂) · ∂^(ℓ₁+ℓ₂)f⁽⁰⁾/∂k_x^ℓ₁∂k_y^ℓ₂ · E_x^ℓ₁ E_y^ℓ₂。
  - ℓ 阶自旋分辨电导：σ^(ℓ)_s = (−e/ℏ)^(ℓ+1)/(iω+1/τ)^ℓ ∫d^D k f⁽⁰⁾_s ∂^(ℓ+1)ε_s/(∂k…∂k_b)。
  - 非零判据（关键选择定则）：∂^(ℓ₁+ℓ₂+1)ε_s/(∂k_x^ℓ₁∂k_y^ℓ₂∂k_b) ≠ 0；磁项为 k 的 ℓ+1 次多项式 ⇒ 只存在 ℓ 阶非线性自旋电导。
  - 自旋电导定义：σ_spin = (σ_↑ − σ_↓)/2；电荷电导 σ_charge = σ_↑ + σ_↓。

  **计算设置**：
  - 解析：连续模型求费米面 k_F(φ, θ)、费米体积 V_F 及各阶电导（对小 J 做级数展开，2D d 波取到 J 二阶、3D d 波取到 J 四阶）。
  - 数值：紧束缚模型计算自旋-Drude 电导与费米体积，与解析结果对比；作图统一取 ℏ²/(ma²) = ε₀/4、J = 0.1ε₀、µ = 0.1ε₀。
  - 验证结果：连续模型与紧束缚模型在带底 µ = 0 附近吻合很好（Fig.2 各面板青色/品红线）。

  **关键量级估算**（原文 XV 节）：
  - 特征电场尺度 ℏk/(eτ) = 6.6 × 10⁵ [kgm/As³]，采用 τ = 3.4 × 10⁻¹² s、k = 0.35 Å⁻¹。
  - 实验可达电场 E = 1 [V/µm] = 10⁶ [kgm/As³]；更强电场 E = 10 [V/µm] 可满足 E/(ℏk/eτ) > 1，此时高阶非线性电导显著——E > 6.6 × 10⁵ [kgm/As³] 时高阶自旋流高效产生。

  ## 主要发现与核心结论

  **总选择定则：节点数 = ℓ + 1 ⇒ 只存在 ℓ 阶非线性自旋-Drude 电导**（线性自旋电流为 ℓ = 1 特例）。与通常体系多种高阶贡献并存形成鲜明对比。汇总表（2D/3D）：

  | 体系 | 节点数 | 存在的自旋电导 |
  |------|--------|----------------|
  | s 波（铁磁体） | 0 | 无纯自旋流（σ_x;x^spin = eℏ/m·(V_F^↑−V_F^↓)/2，伴随电荷流的自旋极化电流） |
  | p 波 | 1 | 无任何阶自旋电导（ℓ ≥ 0 全部为零）；有线性电荷电导 σ_x;x^charge = (4eπ/ℏ)(µ + mJ²/2ℏ²)，含 J 依赖 |
  | d 波交变磁 | 2 | 仅线性横向自旋电导 σ_y;x^spin = (e²/ℏ²)/(iω+1/τ) · V_F J |
  | f 波磁体 | 3 | 仅二阶非线性自旋电导 |
  | g 波交变磁 | 4 | 仅三阶非线性自旋电导 |
  | i 波交变磁 | 6 | 仅五阶非线性自旋电导 |

  **分体系定量结果**：
  - 2D d 波：费米体积 V_F = 2πmµ/(ℏ²√(1−J²m²))（|Jm|<1 条件）；σ_y;x^spin = σ_x;y^spin = (e²/ℏ²)/(iω+1/τ)·V_F J。3D d 波：V_F = 8√2π(mµ)^{3/2}/(3ℏ³√(1−2J²m²))；σ_z;x^spin = σ_x;z^spin = σ_z;y^spin = σ_y;z^spin = (e²/ℏ²)/(iω+1/τ)·V_F J。
  - 2D f 波（关键结果——完美非互易）：V_F = (2πmµ/ℏ²)(1 + µm³J²)（至 J 二阶）；只有 ∂³ε/∂k_x∂k_y² 与 ∂³ε/∂k_x³ 项非零贡献，得 σ_yy;x^spin = σ_xy;y^spin = 6(e/ℏ)³/(iω+1/τ)²·V_F J，σ_xx;x^spin = −6(e/ℏ)³/(iω+1/τ)²·V_F J。二阶非线性 ⇒ 电流方向与电场方向无关 ⇒ **完美非互易自旋电流**（非互易是完美的是因为只存在二阶项）。σ_yy;x 在很宽 J 范围内对 J 线性；小 J 时费米体积几乎无 J 依赖。
  - 3D f 波：σ_zy;x^spin = −(e/ℏ)³/(iω+1/τ)²·V_F J。
  - 2D g 波：V_F = (2πmµ/ℏ²)(1 + µ²m⁴J²)；仅 ∂⁴ε/∂k_y³∂k_x = −6sJ 与 ∂⁴ε/∂k_x³∂k_y = 6sJ 贡献；σ_yyy;x^spin = σ_xyy;y^spin = −6(e/ℏ)⁴/(iω+1/τ)³·V_F J，σ_xxx;y^spin = σ_xxy;x^spin = 6(e/ℏ)⁴/(iω+1/τ)³·V_F J。σ_yyy;x^spin 在很宽 J 范围对 J 线性，解析式适用区间宽。
  - 3D g 波：∂⁴ε/∂k_x³∂k_z = −∂⁴ε/∂k_x∂k_y²∂k_z = 6sJ ⇒ σ_xxx;z^spin = 6(e/ℏ)⁴/(iω+1/τ)³·V_F J；V_F = 8√2π(mµ)^{3/2}/(3ℏ³) + 128√2π m^{11/2}µ^{7/2}J²/(35ℏ³)。
  - 2D i 波：V_F = (2πmµ/ℏ²)(1 + µ⁴m⁶J²/2)；仅 ℓ = 5 存在：∂⁶ε/∂k_y⁵∂k_x = −∂⁶ε/∂k_y³∂k_x³ = ∂⁶ε/∂k_y∂k_x⁵ = 360sJ；σ_yyyyy;x^spin = σ_xxxxx;y^spin = −σ_xxxyy;y^spin = 360(e/ℏ)⁶/(iω+1/τ)⁵·V_F J。σ_yyyyy;x^spin 在很宽 J 范围对 J 线性。
  - 3D i 波：∂⁶ε/∂k_x²∂k_y⁴ = ∂⁶ε/∂k_y²∂k_z⁴ = ∂⁶ε/∂k_z²∂k_x⁴ = −∂⁶ε/∂k_x⁴∂k_y² = −∂⁶ε/∂k_y⁴∂k_z² = −∂⁶ε/∂k_z⁴∂k_x² = 48sJ ⇒ σ_yyyyx;x^spin = 48(e/ℏ)⁶/(iω+1/τ)⁵·V_F J；V_F = 8√2π(mµ)^{3/2}/(3ℏ³) + 16384√2π m^{15/2}µ^{11/2}J²/(15015ℏ³)。
  - p 波的微妙点：费米面在 k 空间对相反自旋反向平移（Fig.1(b2)），直觉上应有 ℓ = 0 持续自旋流，但费米子不是自由费米子——速度 v_x = ℏk_x/m + sJ/ℏ（公式 (49)），两项相消，无持续自旋流；自旋电导对所有 ℓ ≥ 0 为零。

  **材料实现**（原文 Discussion 列举）：2D d 波——有机材料、钙钛矿、扭转磁性范德华双层；3D d 波——RuO₂、Mn₅Si₃、FeSb₂；g 波——扭转磁性范德华双层，3D g 波费米面劈裂在 MnTe 与 CrSb 中实验观测到；2D i 波——扭转磁性范德华双层；CeNiAsO 被理论预言为 p 波磁体。

  ## 潜在研究方向

  - 本文用两带模型、假自旋（pseudospin）自由度缺席、哈密顿量对角；涉及假自旋且哈密顿量非对角的体系未研究，是未来问题（多带效应、量子度规/Berry 曲率偶极子贡献可能重新进入）。
  - 级数展开的适用性：2D d 波解析结果仅 |Jm| < 1 有效（3D 为 |Jm| < 1/√2），需 J 高阶展开改善拟合——大 J 极限的严格处理未做。
  - 材料搜索：f 波、g 波、i 波磁体的实际材料实现尚少（除扭转双层与 MnTe/CrSb 的 g 波劈裂观测外），本文结果可激励更高波对称磁体的材料寻找。
  - 实验验证非线性阶数谱：需要 E > 6.6 × 10⁵ [kgm/As³] 量级的强电场（10 V/µm 可达）才能显著激发高阶项；如何在器件中实现并分辨 ℓ 阶贡献是开放问题。
  - 未处理无序、相互作用（库仑/磁振子）对高阶自旋电导的修正；有限温度效应未讨论。

  ## 与林赛研究的关联

  - **交变磁 × 强场超快**：本文的非线性自旋电导 σ^(ℓ) ∝ E^ℓ/(iω+1/τ)^ℓ 是频率依赖的——把直流 E 换成 THz/强场驱动场，同一选择定则给出"只有特定谐波/特定阶的非线性自旋响应"，这正是**序参量超快读出**（general-order-parameter-ultrafast-readout-20260727 课题）需要的读出机制候选：g 波/i 波交变磁中若观测到纯三阶/纯五阶自旋响应，即是对磁对称性的电学指纹鉴定。
  - **HHG 语言对接**：强场驱动固体中的非线性电流展开 j = Σσ^(ℓ)E^ℓ 与 HHG 的密度矩阵微扰展开同构；本文"节点数锁定阶数"的动量空间对称性论证，可平移到强场条件下布洛赫电子的非互易/整流响应分析。f 波磁体的"完美非互易"（电流方向与电场方向无关）是强场整流响应的理想极限参照。
  - **莫尔体系接口**：文中多次提到扭转磁性范德华双层可实现 g 波、i 波对称——这与本组莫尔/量子几何方向直接重叠：莫尔超晶格可人工构造高节点数费米面，为高阶非线性自旋流的"量子工程"提供平台；量子几何（度规/曲率）在本文单带极限下被禁戒，但多带推广中将成为主角。
  - **数值素材**：各波对称磁项的紧束缚哈密顿量（公式 (53)-(124)，含晶格类型与 sin/cos 替换规则）可直接搬进我们强场模拟的初始哈密顿量库；特征电场尺度 ℏk/(eτ) = 6.6 × 10⁵ [kgm/As³]（τ = 3.4 × 10⁻¹² s、k = 0.35 Å⁻¹）是估算强场非线性自旋实验可达性的基准数字。
  - 注意挂靠准确：d 波自旋流的实验支持来自 Bose et al.（RuO₂ 倾斜自旋流，Nature Electronics 5, 267 (2022)）与 Naka et al.（有机/钙钛矿），g 波劈裂观测在 MnTe 与 CrSb——引用时勿与本文理论预测混淆。

**方法**：高阶非线性自旋电流产生的 Drude 理论（波对称磁项 TB + 递归 Boltzmann + 阶数选择定则）

**原理**：两带哈密顿量 H=H₀+H_wave：H₀ 自由费米子动能，H_wave 各波对称磁项（s/p/d/f/g/i 波，交换耦合 J，2D/3D 多项式形式；TB 表示经 k_j→sin(ak_j)、k_j²→2(1−cos(ak_j)) 替换构造）；自旋对角 → Berry 曲率为零、量子度规与 BCD 无贡献，全部非线性来自 Drude 机制；递归解 Boltzmann 方程得 ℓ 阶自旋分辨电导 σ^(ℓ)_s=(−e/ℏ)^(ℓ+1)/(iω+1/τ)^ℓ ∫f⁰∂^(ℓ+1)ε；关键选择定则：非零要求 ∂^(ℓ₁+ℓ₂+1)ε/∂k^(ℓ₁+ℓ₂+1)≠0，磁项为 k 的 ℓ+1 次多项式 ⇒ 恰存在 ℓ 阶非线性自旋电导（三阶/五阶等）。

**参数表**：

| 参数 | 数值 | 出处 |
| --- | --- | --- |
| 晶格实现 | 四方/立方/层状三角晶格；替换 k_j→sin(ak_j)、k_j²→2(1−cos(ak_j)) | §模型框架 |

**适用边界**：弛豫时间恒定近似；自旋对角假设排除 SOC 混合（真实材料 Berry 项可修正）；非静态有限频率响应（ω→0 静态极限发散需处理）。
