• # Momentum-resolved spectral functions of super-moiré systems using tensor networks

  ## 林赛的理解

  这篇工作把张量网络技术从“解超大实空间紧束缚模型”推进到了“算动量分辨谱函数”，对咱们组的方向意义不小。它给出了一条不依赖周期性的数值通路，可以直接模拟量子扭转显微镜（QTM）这类局域、动量分辨的实验。对我手头的“莫尔强场探针”课题来说，这意味着：未来可以把强场驱动下的超莫尔电子结构、阿秒尺度响应与这种实空间/动量空间双分辨的谱函数方法对接，尤其适用于非均匀应变、准晶超莫尔这类没有平移对称性的体系。它更像一个数值探针平台，而不是单一结果论文。

  ## 研究问题

  论文要解决的核心问题是：如何在非周期、原子尺度的超莫尔（super-moiré）体系中计算动量分辨谱函数 A(k,ω)？具体来说，这类体系的特征长度远超普通莫尔系统，真实空间模型动辄百万甚至十亿量级的格点，传统稠密矩阵方法无法处理；同时实验上 QTM 和 ARPES 已经可以在局域区域测量动量分辨谱函数。因此，作者要建立一种能同时处理超大体系、非周期性、相互作用、非均匀应变和准晶结构的统一数值方法，直接输出可与 QTM/ARPES 对比的谱函数。

  ## 研究背景

  范德华材料堆叠形成的莫尔超晶格为关联电子态提供了丰富平台（Geim & Grigorieva, 2013；Andrei 等, 2021）。现有理论主要分为两支：连续介质模型能低成本处理均匀莫尔体系，但难以容纳杂质、畴壁和非均匀应变；真实空间紧束缚模型可以处理缺陷和非均匀性，但所需体系尺寸很快达到数十万乃至百万格点，常规方法难以承受。近年来出现的“用量子多体求解器解指数级大单粒子问题”的策略，通过张量网络加张量交叉插值（TCI/QTCI）把十亿量级的实空间紧束缚问题编码为辅助多体问题，已在拓扑准晶马赛克和自洽平均场超莫尔体系中得到验证（Moustaj 等先前工作 [46–48]）。但这些方法本质上是实空间的，不能直接给出动量分辨谱函数，限制了与 QTM、ARPES 实验的直接比较。量子扭转显微镜（QTM）通过纳米尺度扭转界面实现相干隧穿，能在局域区域动量分辨地测量谱函数，这进一步催生了本工作对动量空间方法的迫切需求。

  ## 研究方法

  ### 核心思想
  将实空间紧束缚哈密顿量通过赝自旋编码（pseudo-spin encoding）映射为一个多体问题：N = 2^L 个格点变成 L 个赝自旋，H_αβ 变成 L 个赝自旋基下的多体哈密顿量，并以矩阵乘积算符（MPO）表示。 hopping 振幅和空间调制函数通过 Quantics 张量交叉插值（QTCI）构建为对角 MPO。

  ### 单粒子与相互作用哈密顿量
  非相互作用哈密顿量一般写成：
  Ĥ = Σ_n T̂^(n) K̂^n + h.c.
  其中 K̂ 是移位算符，T̂^(n) 是空间调制的第 n 近邻 hopping 对角矩阵。

  相互作用采用局域 Hubbard 模型：
  Ĥ_int = Σ_α U_α (n̂_α↑ − 1/2)(n̂_α↓ − 1/2)
  通过自洽平均场（SCMF）解耦为：
  Ĥ_int,α/U_α ≈ (n̂_α↑ − 1/2)(⟨n̂_α↓⟩ − 1/2) + (⟨n̂_α↑⟩ − 1/2)(n̂_α↓ − 1/2)
  密度期望值 ⟨n̂_ασ⟩ 通过对平均场哈密顿量的谱函数积分得到，迭代至收敛。

  ### 谱函数与核多项式方法（KPM）
  谱函数由 Dirac δ 算符展开：
  δ(ω − Ĥ) = (1/π√(1−ω²)) [1 + 2 Σ_{n=1}^∞ μ̂_n T_n(ω)]
  Chebyshev 矩 μ_n = T_n(Ĥ) 用 MPO 递推计算；实际保留 N_μ 项，结合 Jackson 核，有效能量展宽约为 1/N_μ。

  ### 量子傅里叶变换（QFT）
  关键步骤是用张量网络实现离散傅里叶变换。QFT 在赝自旋基下由 Hadamard 门和受控二分有理相位门 C R̂_κ 构成：
  Ĥ = (1/√2)[[1,1],[1,−1]],  R̂_κ = [[1,0],[0,e^{2πi 2^{-κ}}]]
  QFT 计算复杂度为 O(L²) = O((log₂ N)²)，远低于 FFT 的 O(N log N)。谱函数定义为：
  A(k,ω) = ⟨k| F̂ δ(ω−Ĥ) F̂^{-1} |k⟩

  ### 局域投影谱函数
  为模拟 QTM 的局域测量，引入实空间投影算符 P̂_R，投影到位置 R 附近 N_R 个格点：
  A_P(R,k,ω) = ⟨k| F̂ P̂_R δ(ω−Ĥ_MF) P̂_R F̂^{-1} |k⟩

  ### 计算平台
  所有基准计算在 NVIDIA H200 GPU 集群上完成。

  ## 主要发现与核心结论

  ### 一维非均匀应变超莫尔
  体系尺寸 N = 2^24，投影区域尺寸 N_X ≈ N/16。Nearest-neighbor hopping 被两个不可公度波长调制：
  t_{i,i+1} = t(x_i) [1 + (1/5) Σ_{l=1}^2 cos(k̃_l(x̃_i) x̃_i)]
  其中 x̃_i = (x_i + x_{i+1})/2，k̃_l(x̃) = 2π/λ_l(x̃)。原子尺度波长 λ₁(x) = √5/2 保持恒定；莫尔波长线性增长 λ₂(x) = √3 N / 15 (1 + x/N)；整体幅度调制 t(x) = t₀(1 + 3x/4N)；相互作用强度 U = 3.2t。

  结果（图 2）：
  - LDOS ρ(x,ω) 清楚跟随大尺度调制，反映频率和幅度递增。
  - 总谱函数 A(k,ω) 因不同区域谱权重混合而展宽。
  - 投影谱函数 A_P(X,k,ω) 在两个区域呈现明显差异：图 2(d) 区域的 hopping 调制波长是图 2(c) 区域的 2 倍，幅度大 75%，因而 miniband 间隙更加显著。

  ### 二维八重旋转准晶超莫尔
  非相互作用二维方格模型，hopping 受八重旋转对称准晶势调制：
  t(r) = t₀ [1 + Σ_{n=1}^4 (Δ_α cos(α k_n · r̃) + Δ_β cos(β k_n · r̃))]
  其中 Δ_α = 0.25 控制原子尺度调制强度，Δ_β = 0.1 控制更大尺度调制强度；k_n = R_n(π/4)[2π,0]^T；调制尺度 α = 1/(10√2)，β = 16/(√3 N_x)。体系尺寸 N = 2^24 ≈ 10^7，N_x = N_y = 2^12。投影区域线性尺寸 N_R ≈ N_x/16 = N_y/16。

  结果（图 3）：
  - 实空间 hopping 函数在中央区呈现不同尺度的八重对称图案。
  - 总谱函数沿 k_x = k_y 线显示出准晶图案导致的莫尔能隙。
  - LDOS ρ(r,ω=0) 的空间图案与 hopping 调制高度一致。
  - 投影谱函数 A_P(R,k,ω) 在中央 hopping 最大区域与右下角 hopping 最小区域之间差异明显：半填充时态的局域化最强处并不在图案中心；能带底部在中央区域有显著更高的谱权重。
  - 二维准晶的 nesting 条件比一维更复杂，导致谱重构更丰富。

  ### 方法通用性与拓扑可能性
  作者强调框架对真实材料模型完全通用：任何可压缩的紧束缚哈密顿量（Wannier 化从头算结果或实验拟参）都可编码为 MPO；KPM 和 QFT 步骤与模型无关。文中示例的相互作用仅打开关联能隙、拓扑平庸，但方法本身可处理拓扑相；例如可在拓扑/平庸畴壁处用局域投影器捕捉 in-gap 边缘模。

  ### 数值基准（图 4）
  - 最大键维数 χ_max = 100 在约 50 个 Chebyshev 矩后达到，且与体系尺寸无关。
  - 相对 RMS 误差 ε(χ) 随 χ 增大呈次指数衰减，ε(χ≈150) ≈ 10^{-4}；误差几乎不依赖体系尺寸，由截断键维数控制。
  - 计算 Chebyshev 矩的总墙时随 L = log₂(N) 线性增长。
  - GPU 内存消耗约为 3 GB 到 5 GB，随矩数 N_μ 和体系尺寸增长都很缓慢。
  - 对 N = 2^24 的非相互作用二维体系，80 个 k 点和 100 个 ω 点的完整计算约需 2 小时（不做块平均）。
  - 采样通常在 100×100 网格上进行，N_samp ~ 10^4，采样阶段耗时与矩数无关，随采样点数线性增长。

  ## 潜在研究方向

  1. **超越平均场的关联效应**：目前相互作用仅处理到自洽平均场（SCMF）水平。强关联、量子涨落、分数化激发（如 FCI、量子自旋液体候选）尚未纳入，这是本方法下一步自然延伸。
  2. **有限温度与非平衡动力学**：当前方法面向零温谱函数。有限温度谱函数、非平衡响应（如强场驱动后的含时谱演化）需要扩展。
  3. **拓扑边缘态的直接演示**：作者提到方法原则上可处理拓扑相，但正文中未给出具体算例；带畴壁的 Chern 绝缘体、in-gap 边缘模的 A_P(R,k,ω) 计算值得期待。
  4. **与实验的更紧密耦合**：QTM 数据的空间分辨率、能量分辨率、隧穿矩阵元等实验细节如何映射到理论投影器 P̂_R，需要进一步建模。
  5. **强场/阿秒探针接口**：谱函数 A(k,ω) 是理解 HHG、光电子发射等强场过程的输入；将本方法产生的超莫尔电子结构与含时强场驱动耦合，可预测局域 HHG 产率和阿秒电流响应。
  6. **更高效的采样与 GPU 优化**：采样阶段是主要耗时瓶颈（O(N_samp)），发展自适应采样、压缩感知或更精细的块平均策略可进一步加速。
  7. **三维与自旋-轨道耦合**：当前演示限于一维和二维；扩展到三维、非共线磁序、自旋-轨道耦合体系，需要相应扩展 QFT 和 MPO 构建。
  8. **噪声、无序与缺陷**：方法可处理非均匀应变，但点缺陷、边界、层间无序对谱函数的影响值得专门研究。

  ## 与林赛研究的关联

  最直接接口是咱们 NSFC-强场超快课题下的“莫尔强场探针”方向：

  - **HHG 与超莫尔能带结构**：本方法给出的 A(k,ω) 可作为强场 HHG 计算中电子态和偶极跃迁矩阵的输入，把非均匀应变、准晶超莫尔的局域能带特征转化为强场光谱预测。
  - **阿秒时间分辨与交变磁**：超快 pump 诱导的临时对称性破缺、交变磁性或赝自旋织构变化，可通过时间依赖的 A(k,ω;t) 来追踪；本方法若扩展到含时哈密顿量，将直接服务于阿秒泵浦-探测设计。
  - **莫尔/超莫尔量子几何**：准晶和超莫尔中 Berry 曲率、量子度规的动量分布可通过本方法的 MPO 框架进一步提取，为理解非线性光响应（shift current、HHG 偏振依赖）提供基础。
  - **非均匀应变与局域探针**：QTM 式的局域投影谱函数与我们的强场局域探针思路高度契合——都想把“全局平均”拆解为“空间分辨”，从而揭示应变工程莫尔中位置依赖的电子态。
  - **方法论借鉴**：论文中 QTCI + KPM + QFT 的组合思路，对咱们处理大尺度、非周期强场模型也有启发，可以考虑将类似的张量网络编码引入强场含时薛定谔方程或半导体布洛赫方程的实空间求解。

## 研究问题（Research Question）

论文要解决的核心问题是：**如何在超大、非周期性的 super-moiré 系统中计算动量分辨的光谱函数**。Super-moiré 系统由多层二维材料以不同转角堆叠形成，其超胞尺寸可远大于原始晶格周期，导致传统紧束缚方法面临指数级增长的计算复杂度。具体而言，论文提出一个 open problem：对于极大尺度的非周期性 super-moiré 系统，如何在原子级别精度上获得其动量分辨的光谱函数（即准粒子谱 / spectral function），从而直接模拟量子扭转显微镜（quantum twisting microscope, QTM）实验。

---

## 研究背景（Background）

Moiré 超晶格自石墨烯"魔角"发现以来，已成为研究强关联电子态和量子物态的核心平台。在光子学/光学领域，moiré 超晶格的 flatband 特性（零群速度）已被用于增强谐波产生效率（见我之前的笔记 2512.18397 相关工作）。然而，在电子结构层面，super-moiré 系统（即由 moiré 系统再叠加转角形成的层级结构）的光谱计算面临根本困难：随着层数和转角组合增加，系统原胞可包含数百至数千个原子，常规对角化方法（如直接数值对角化紧束缚矩阵）的计算量随系统规模指数增长，无法处理。

现有方法（如 kernel polynomial method, KPM）虽可计算态密度，但无法给出动量分辨的光谱函数。量子扭转显微镜作为一种新兴实验手段，能够直接在动量空间探测层级 moiré 系统的电子结构，但其数据解释需要理论工具来计算动量分辨光谱。该工具的缺失是领域内的一个关键瓶颈。

---

## 研究方法（Methods）

论文的核心方法论是**将指数级大的紧束缚问题编码为辅助量子多体问题，然后利用多体 tensor network 算法求解**。具体技术路线包括以下几个关键步骤：

**（1）问题映射：** 将大规模紧束缚哈密顿量的 spectral function 计算，映射为一个辅助量子多体系统的计算问题。这使得原本随系统规模指数增长的维度，可以通过 tensor network 的压缩表示来有效处理。

**（2）多体 kernel polynomial tensor network 算法：** 结合 kernel polynomial method（KPM）和 tensor network 收缩技术，用于计算非相互作用和相互作用系统（相互作用在平均场层面处理）的 spectral function。

**（3）量子傅里叶变换 tensor network：** 用于在动量空间重构光谱函数，实现从实空间 tensor network 表示到动量空间的可控转换。

**验证场景：** 方法在以下体系进行了验证：（i）一维和二维 super-moiré 系统；（ii）含非均匀应变的 super-moiré；（iii）平均场处理的相互作用系统；（iv）准晶体 super-moiré 图案。

---

## 主要发现与核心结论（Main Results）

论文的核心成果是**建立了一套可实际计算超大 super-moiré 系统动量分辨光谱函数的 tensor network 方法论**，主要结论包括：

1. **方法验证：** 该方法能够在原子级别精度上计算非周期 super-moiré 系统的 spectral function，计算规模远超传统直接对角化方法的极限。

2. **空间选择性成像能力：** 该方法允许计算限定在 super-moiré 系统特定区域内的动量分辨光谱函数，从而可直接成像（direct imaging）非均匀应变系统中的位置依赖电子结构以及 minigaps。

3. **多体系适用性：** 方法对非相互作用系统、平均场相互作用系统、含非均匀应变的系统以及准晶体 super-moiré 图案均适用，展示了广泛的应用范围。

4. **与实验的直接联系：** 该方法为量子扭转显微镜实验提供了直接的理论工具，能够模拟 QTM 在扭转范德瓦尔斯异质结中的测量结果，为实验数据提供可解释的理论框架。

---

## 潜在研究方向（Future Directions）

1. **方法的局限性：** 论文在平均场层面处理相互作用，更高阶的关联效应（如真正的多体相互作用、杂化泛函中的自能修正）尚未纳入。向 full CI 或 post-MFT 的关联处理扩展是自然的下一步。

2. **计算规模化：** 虽然 tensor network 解决了指数墙问题，但在极大规模（真正实验级系统，含数千原子）下的计算效率仍需验证和优化，尤其三维效应或多层堆叠体系的适用性。

3. **与实验的深度结合：** 论文建立了方法论框架，但尚未与具体 QTM 实验数据进行对照。开展与现有石墨烯 moiré 或 TMDC moiré 体系的 QTM 实验的对比研究，将是验证方法的重要方向。

4. **开放科学问题：** 如何利用该工具从 spectral function 中提取量子几何（Berry curvature, quantum metric）信息，以及能否结合动力学平均场理论（DMFT）处理更真实的强关联效应，均为值得探索的方向。

## 研究方法（方法卡）

**方法**：超莫尔体系动量分辨谱函数的张量网络方法（赝自旋编码 MPO + QTCI 对角势 + Hubbard 相互作用）

**原理**：赝自旋编码：N=2^L 格点映射为 L 个赝自旋，H_αβ 变为赝自旋基多体哈密顿量（MPO 表示）；hopping 与空间调制经 Quantics 张量交叉插值（QTCI）构造成对角 MPO；非相互作用 Ĥ=ΣT̂⁽ⁿ⁾K̂ⁿ+h.c.（K̂ 移位算符+空间调制对角矩阵），相互作用取局域 Hubbard 模型——超莫尔体系动量分辨谱函数的大规模张量网络计算。

**适用边界**：页面提取限方法框架开头（谱函数算法与体系规模在后续）；MPO 键维压缩效率依赖低秩性。
