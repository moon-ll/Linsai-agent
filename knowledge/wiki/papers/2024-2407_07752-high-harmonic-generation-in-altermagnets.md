• # High harmonic generation in altermagnets

  ## 林赛的理解

  这是一篇把强场超快光学伸向交变磁金属的开拓性理论工作。对我们而言，它的直接价值在于：HHG 不再只是探测半导体能带或原子电离的工具，而是可以把自旋纹理、能带拓扑与超快非线性响应耦合起来，成为一种针对量子材料的时域光谱探针。文中给出的几个定量结论——低次谐波对磁场符号的 d-wave 响应、SOC 诱导的带间平台、以及无磁场时 altermagnet+SOC 的非线性横向电流和圆二色——都可以无缝嫁接到我们围绕 HHG、阿秒、强场驱动、交变磁和量子几何的研究设想中。特别是它用一个极简的两能带模型就把“自旋劈裂—轨道耦合—拓扑—HHG”的关系讲清楚了，为我们的实验设计和对称性分析提供了可计算的基准。

  ## 研究问题

  论文要回答的核心问题是：交变磁（altermagnet）金属的能带结构，尤其是其 d-wave 型自旋劈裂以及自旋轨道耦合（SOC），如何在强场驱动的高次谐波产生（HHG）光谱中留下可识别的指纹？进一步地，能否通过 HHG 对磁场、偏振、圆偏二色的依赖，来诊断交变磁性，并将其与单纯的 SOC 效应或普通金属区分开？

  ## 研究背景

  HHG 作为非线性光学过程，已在原子气体、液体、半导体和强关联材料中被广泛研究。在固体中，HHG 通常用三步模型的变体理解：电子-空穴产生、能带内加速、复合发光，因此能带结构的信息会直接反映在谐波谱中。近年来，交变磁体作为一类新的共线磁体进入视野：它们净磁化为零，但具有自旋劈裂的能带和 d-wave 型自旋劈裂费米面。这种自旋劈裂会导致自旋极化电流甚至纯自旋电流，并引发丰富的非线性输运效应。然而，交变磁金属在强场超快光学下的响应，尤其是 HHG 中自旋劈裂与 SOC 的各自角色，此前缺乏系统研究。本文正是在这一空白中建立了一个可解析的二维模型，连接能带结构对称性与超快非线性光谱。

  ## 研究方法

  研究采用二维非相互作用电子模型，哈密顿量为：

  \[
  H(t)=\sum_k \Psi_k^\dagger h_k(t) \Psi_k,\quad \Psi_k^\dagger=(c_{k\uparrow}^\dagger, c_{k\downarrow}^\dagger)
  \]

  其中 \(h_k=h_k^{\text{alter}}+h_k^{\text{SOC}}\)。

  交变磁项：

  \[
  h_k^{\text{alter}}(t)=\left(t_0[2-\cos k_x(t)-\cos k_y(t)]-\mu\right)\sigma_0
  +2t_a[\cos k_x(t)-\cos k_y(t)]\sigma_3+b\sigma_3
  \]

  Rashba SOC 项：

  \[
  h_k^{\text{SOC}}(t)=-\alpha\sin k_y(t)\sigma_1+\alpha\sin k_x(t)\sigma_2
  \]

  参数取值为 \(t_0=1\)（能量单位），\(t_a=0.25\)（自旋劈裂强度），\(\mu=0.5\)（化学势），\(\alpha\) 为 SOC 强度，\(b\) 为 Zeeman 场。电场采用纯矢势规范，脉冲形式为：

  \[
  E_i(t)=E_{0,i}\sin\left(\Omega(t-t_{\text{avg}}+\phi_i)\right)\cos^8\left(\frac{\Omega(t-t_{\text{avg}})}{2M}\right),\quad 0<t<MT
  \]

  含 \(M=20\) 个周期，中心位于 \(t_{\text{avg}}=MT/2\)，频率 \(\Omega=0.1\)。无外磁场时取线性偏振，研究 SOC 时加入圆偏振，相位取 \(\phi_x=0,\phi_y=\pm\pi/2\)。

  时间演化通过 Von-Neumann 方程求解密度矩阵：

  \[
  \frac{d}{dt}\rho(k,t)=-i[h_k(t),\rho(k,t)]
  \]

  使用 commutator-free expansion 方法。电荷流定义为：

  \[
  J_i(t)=-\frac{1}{N_k}\sum_k \text{Tr}[\rho(k,t)v_i(k,t)],\quad v_i(k,t)=\frac{\partial h_k(t)}{\partial k_i}
  \]

  自旋流定义为：

  \[
  J_{ij}(t)=-\frac{1}{N_k}\sum_k \text{Tr}[\rho(k,t)v_{ij}(k,t)],\quad v_{ij}(k,t)=\frac12[\sigma_i v_j(k,t)+v_j(k,t)\sigma_i]
  \]

  HHG 谱计算为 \(|\omega J_i(\omega)|^2\)，自旋流 HHG 谱为 \(|\omega J_{ij}(\omega)|^2\)。无 SOC 计算使用 \(200\times200\) 动量网格，含 SOC 计算使用 \(500\times500\) 网格，并已用 \(2000\times2000\) 验证收敛；傅里叶变换时施加窗函数 \(f(t)=\cos^8(\Omega(t-t_{\text{avg}})/2M)\) 抑制高频振荡。初始温度设为 \(T=1/30\)。

  ## 主要发现与核心结论

  ### 1. 纯交变磁模型（\(\alpha=0\)）：带内动力学主导的 HHG

  - 参数 \(t_a=0.25,\mu=0.5\) 时，自旋向上费米面沿 \(k_x\) 拉长，自旋向下费米面沿 \(k_y\) 拉长；沿对角线 \(k_x=k_y\) 两自旋能带简并。
  - 弱场下，低次奇次谐波 \(\omega=n\Omega\,(n=1,3,5,\dots)\) 的振幅按 \(E_0^{2n}\) 缩放，与非线性电流 \(j^{(n)}\propto E_0^n\) 的预期一致。
  - 强场下沿 \(x\) 偏振出现平台，截止能量约为 \(\omega_{\text{cut}}\approx E_0\)。
  - 对角线偏振时截止能量约为 \(x\) 或 \(y\) 偏振的 \(1/\sqrt{2}\)，因为对角线投影使单近邻跃迁能量增益降低。
  - 对 \(t_a=0.25\)，沿 \(x\) 偏振时自旋向下电子产生的 HHG 谱强度是自旋向上的 14 倍。
  - 当 \(t_a=0.375\) 时，费米面拓扑由闭合变为开放（1D 型），自旋向下贡献完全主导 \(x\) 方向电流。

  ### 2. Zeeman 场的 d-wave 特征

  - 小磁场 \(b=0.01\) 下，\(\omega_c=b\ll\Omega=0.1\)，忽略 Lorentz 力。
  - 差分谱 \(\Delta_{\text{HHG}}=\text{HHG}(b)-\text{HHG}(-b)\) 在 \(x\) 方向为正，在 \(y\) 方向为负，对角线方向为零，呈现 d-wave 结构。
  - 该符号可由能带移动理解：沿 \(k_x\)，\(b>0\) 使宽带自旋向下能带下移、窄带自旋向上能带上移，从而增强 \(x\) 方向电流；沿 \(k_y\) 则相反。

  ### 3. 自旋流 HHG

  - 定义 \(J_{zr}=\cos\theta J_{zx}+\sin\theta J_{zy}\) 为沿 \(\hat r\) 方向的自旋流。由于对称性，对角线方向自旋流为零。
  - 沿 \(x,y\) 方向自旋流振幅与截止能量最大；垂直分量 \(J_{z\perp}=\cos(\theta+\pi/2)J_{zx}+\sin(\theta+\pi/2)J_{zy}\) 在对角线偏振时最大，但截止能量较低。

  ### 4. 含 SOC 模型（\(\alpha=1\)，\(t_a=0.25\)）：带间跃迁与拓扑效应

  - SOC 打开能带杂化，出现新的高能峰和平台结构，最大能量由能带劈裂决定。
  - 沿 \(x\) 偏振、\(E_0=3\) 时，可识别多个截止：低能截止来自交变磁带内动力学；第二截止随 \(\alpha\) 线性增加，源于 SOC 增强的带间劈裂。
  - 对 \(\alpha=2,E_0=3\)，出现 \(\omega_{\text{cut}}\approx4.13\) 的场无关截止，对应 \(k_y=0\) 处最大能隙；以及 \(\omega_{\text{cut}}\approx4.13+(1,3,5)E_0\) 的组合带内-带间截止，且仅出现奇数倍 \(E_0\)。
  - 高能特征对动量离散敏感，使用 \(500\times500\) 网格并验证 \(2000\times2000\) 收敛。

  ### 5. 横向电流与圆二色（CD）

  各模型的横向电流与 HHG 圆二色总结如下：

  | 模型 | 横向电流 | HHG 圆二色 |
  |---|---|---|
  | 交变磁 | 无 | 无 |
  | 交变磁+\(b_z\) | 无 | 无 |
  | 交变磁+\(b_x\) | 无 | 无 |
  | SOC | 无 | 无 |
  | SOC+\(b_z\) | 有 | 有 |
  | SOC+\(b_x\) | 有 | 有 |
  | 交变磁+SOC | 有（非线性） | 有 |
  | 交变磁+SOC+\(b_z\) | 有 | 有 |
  | 交变磁+SOC+\(b_x\) | 有 | 有 |

  - 在有磁场的拓扑相中，横向电流在弱场下线性地正比于 \(E_0\)，且相对于纵向电流有 \(\pi/2\) 相位差。
  - 关键发现：即使没有磁场，交变磁+SOC 模型也存在非线性横向电流，\(j_t\propto E_0^3\)，并伴随 HHG 圆二色；而纯交变磁或纯 SOC 模型均无此效应。因此，在 SOC 不可忽略的材料中，HHG 圆二色可作为交变磁性的诊断信号。

  ## 潜在研究方向

  1. **相互作用与无序效应**：论文明确假设非相互作用电子、无杂质散射、无阻尼。实际材料中电子-电子关联、杂质、声子散射会如何改变谐波平台、截止能量和 d-wave 磁场响应，是下一步必须回答的问题。
  2. **Lorentz 力的角色**：模型中假设 Zeeman 项主导磁场效应，\(\omega_c=b\ll\Omega\)。当磁场增强或低频驱动时，回旋运动不可忽略，其对 HHG 和自旋流的贡献需要重新评估。
  3. **真实材料与多轨道效应**：极简两能带模型只能给出对称性层面的启示；真实交变磁金属通常包含多轨道、能带交叉、关联效应，需要更紧致的模型或第一性原理计算。
  4. **自旋流的可测量性**：文中自旋流 HHG 谱是理论构造量，实验上如何通过自旋泵浦、逆自旋霍尔效应或自旋分辨光电子谱将其读出，仍是开放问题。
  5. **圆二色作为拓扑探针的特异性**：圆二色在含 SOC 和磁场的拓扑相中出现，但如何与寻常手性、表面态或缺陷态贡献区分，需要更系统的偏振依赖实验和对称性分析。
  6. **温度与掺杂依赖**：文中仅取 \(T=1/30,\mu=0.5\)。化学势和温度会改变费米面拓扑及自旋通道权重，系统研究可预测可调控的 HHG 响应。
  7. **时间分辨与少周期脉冲**：文中用 20 周期脉冲。更短脉冲可能揭示载流子动力学、退相干和 Berry phase 效应，连接阿秒科学。

  ## 与林赛研究的关联

  - **HHG 与阿秒探针**：本文为将 HHG 拓展到交变磁金属提供了理论蓝图，直接服务于我们“用强场超快光学读取量子材料隐藏序”的研究主线。
  - **强场驱动与非线性电流**：交变磁+SOC 中无磁场即可产生 \(E_0^3\) 非线性横向电流，这为我们设计“强场驱动自旋流”实验提供了新机制；可通过偏振调控在中红外-太赫兹强场下产生纯自旋流。
  - **交变磁与莫尔体系**：文中的 d-wave 自旋劈裂和费米面各向异性，与莫尔超晶格中可工程化的能带拓扑和关联磁性存在接口；我们可以探讨莫尔平带中交变磁序如何调制 HHG 响应。
  - **量子几何与 Berry phase**：SOC 开启带间跃迁后，谐波平台与能带劈裂、动量依赖自旋纹理紧密相关；这与我们关注的量子几何量（Berry curvature、quantum metric）在强场动力学中的角色高度一致，可进一步研究 Berry curvature 对圆二色和谐波相位的贡献。
  - **实验设计启示**：测量 \(\Delta_{\text{HHG}}(b)\) 的偏振依赖可作为无接触、超快识别交变磁序的实验协议；结合圆二色测量，可在单一 HHG 实验中区分自旋劈裂、SOC 和拓扑效应。
