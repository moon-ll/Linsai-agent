## 阅读笔记

### general-ssh-weyl-20260920

Square lattice model with staggered magnetic fluxes: zero Chern number topological states and topological flat bands — Chen, Guan, Qi, Zhang, Han, He（扬州大学，cond-mat.str-el，2025-03-06，10页9图）

### 研究问题
交错磁通（SMF）不借助晶格二聚化能否诱导零陈数拓扑绝缘体（ZCNTI）与高阶拓扑绝缘体（HOTI）；同一正方格子模型能否进一步承载拓扑平带（TFB）并在玻色子填充下给出分数量子霍尔（FCI）态。

### 研究背景
Haldane 模型开创的 SMF 方案已在多种晶格、准晶与非晶体系推广出 CI 与 TFB，但正方格子上的 TFB 模型极少。另一脉络：2D SSH 模型显示二聚化可给出由量子化极化表征的 ZCNTI，BBH/Kekulé 模型给出由量子化四极矩表征的 HOTI，红宝石格中 SMF 可不经二聚化直接产生 HOTI。SMF 能否诱导一阶（极化型）拓扑态、以及正方格上能否兼得 TFB/FCI，是本文填补的空缺。

### 研究方法
四原子元胞正方格子紧束缚模型：胞内 NN 跃迁 t1 携带 SMF ϕ1、胞内 NNN 跃迁 t2、胞间 NN 跃迁 t11 携带 SMF ϕ2（全晶格总磁通为零），后加胞间 NNN 跃迁 t21、t22；取 t=1.0 为单位。陈数由 Berry 曲率全 BZ 积分；利用反演对称性，由高对称点 Γ、X(Y) 宇称计算极化 Pi 与四极矩 Qxy；柱几何/开边界对角化检验边缘态与角态。FCI 用 hard-core 玻色子实空间精确对角化（不做带投影，环面几何按动量扇区 (2πkx/Nx, 2πky/Ny) 分解）；并给出超导电路实现方案（四个传输线谐振腔经 SQUID 调制耦合，等效 Heff=Je^{iθ}a†b+H.c.，复相位由 SQUID 提供）。

### 主要发现与核心结论
仅加胞内 SMF（如 ϕ1=0.4π，t2=−0.5）时，1/4 填充出现 ZCNTI：Px=Py=1/2（宇称 η1(Γ)=+1、η1(X)=η1(Y)=−1），有无能隙边缘态但无角态，Qxy=1/4，与 2D SSH 拓扑态同类但由 SMF 而非二聚化诱导，且因时间反演破缺其 Berry 曲率处处非零；相图中 t2>−0.8 为 ZCNTI，t2 接近 −1 时转为 |C1|=2 的 CI。半填充下再引入二聚化与胞间 SMF（t11=1.5、ϕ1=0.5π、ϕ2=0.33π）得 HOTI：Px=Py=0、Qxy=1/2、边缘态有隙、角上出现四重简并态；HOTI 需二聚化与 ϕ2 缺一不可。加入胞间 NNN 后在大参数区找到平坦比 ∆/W≈38 的 TFB（参数 {t11,t2,t21,t22,ϕ1,ϕ2}={−0.75, 0.8, −0.65, −0.4, −0.67π, 0}；正文给 C=1，图 5 图注标 C=−1，原文内部不一致）；填充 hard-core 玻色子得 ν=1/2 FCI（Nb=5,6,7 于 40/48/56 格点，两重准简并基态位于动量扇区 (0,0) 与 (0,2)）与 ν=2/3 FCI（Nb=6,8 于 36/48 格点，三重准简并），简并态随边界相演化交叉且与大隙分离。

### 潜在研究方向
FCI 判据止步于 ED 尺寸（≤56 格点）上的简并度、谱隙与边界相演化，缺分数陈数/纠缠谱等进一步佐证；TFB 对无序与参数漂移的稳健性未评估。实现方案落在超导电路（含稳态拓扑探测），冷原子等其它平台、费米子填充、更分数化填充因子以及 ZCNTI↔CI↔HOTI 相变的动力学均留待后续研究。


## 研究方法（方法卡）

**方法**：正方格子交错磁通模型：SMF 无二聚化诱导 ZCNTI/HOTI + 拓扑平带承载玻色 FCI（四原子元胞紧束缚 + 宇称极化/四极矩 + hard-core 玻色子精确对角化）

**原理**：交错磁通（SMF）不借助晶格二聚化在正方格子诱导拓扑态：四原子元胞紧束缚模型（胞内 NN t1 携带 SMF ϕ1、胞内 NNN t2、胞间 NN t11 携带 ϕ2、全晶格总磁通为零）；仅加胞内 SMF（ϕ1 = 0.4π、t2 = −0.5）时 1/4 填充出现零陈数拓扑绝缘体（ZCNTI）：Px = Py = 1/2（宇称 η1(Γ) = +1、η1(X) = η1(Y) = −1）、无能隙边缘态无角态、Qxy = 1/4——与 2D SSH 拓扑态同类但由 SMF 而非二聚化诱导、因时间反演破缺 Berry 曲率处处非零（相图 t2 > −0.8 为 ZCNTI、t2 接近 −1 转 |C1| = 2 CI）；半填充再引入二聚化与胞间 SMF（t11 = 1.5、ϕ1 = 0.5π、ϕ2 = 0.33π）得高阶拓扑绝缘体（HOTI）：Px = Py = 0、Qxy = 1/2、边缘态有隙、角上四重简并态（二聚化与 ϕ2 缺一不可）；加胞间 NNN 后大参数区找到平坦比 Δ/W ≈ 38 的拓扑平带（TFB）——填充 hard-core 玻色子得 ν = 1/2 FCI（两重准简并基态于动量扇区 (0,0) 与 (0,2)）与 ν = 2/3 FCI（三重准简并）。
