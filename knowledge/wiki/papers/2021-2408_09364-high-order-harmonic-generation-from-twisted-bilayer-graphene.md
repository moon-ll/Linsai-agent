• # Birth-Death Processes are Time-Changed Feller's Brownian Motions（李平，2025）

  ## 林赛的理解

  **先指出一个必须记录的问题**：本条目的 frontmatter 写的是 "High-order harmonic generation from twisted bilayer graphene driven by a midinfrared laser field"（Chen et al., Phys. Rev. A 104, 033113, 2021），但随附全文实际是李平的概率论论文（arXiv:2408.09364v2 [math.PR]，2025-07-25）——元数据与全文不匹配，疑似 PDF 抓取/索引错位。**本笔记蒸馏的是实际收到的全文**，frontmatter 中的 HHG 题名无法核实，保持原样标注，不填充。

  就实际这篇数学论文本身而言：它建立了 Feller 布朗运动（连续状态 [0,∞) 上、在边界 0 有 kill/reflect/sojourn/jump 四种行为的强 Markov 过程）与生灭过程（离散状态 ℕ 上只跳最近邻的连续时间 Markov 链）之间的**双向时间变换等价**——任何 Feller 布朗运动经唯一时间变换变为某生灭过程，反之亦然，参数对应关系为 γ = p₁、β = 2p₂、ν 由 p₄ 按权重分配得到。这是纯概率论成果，**对本组 HHG/莫尔/强场方向没有直接实验或理论接口**，唯一沾边的概念是"时间变换 = 换时钟"这一思想，以及生灭链作为随机动力学模型的通用性。入库意义：作为 `general-moire-strong-field-probe-20260726` 课题挂接的条目，需要人工核实是否应重新抓取 Chen 2021 的正文（该文献才是我们真正需要的扭转双层石墨烯中红外 HHG 计算文献），本篇数学笔记不应用作该课题的方法素材。

  ## 研究问题

  论文要回答的核心问题是：**Feller 布朗运动与生灭过程这两类历史上平行发展、边界条件结构惊人相似（式 1.1 vs 式 1.2）的经典 Markov 过程模型，是否存在比"研究方法互借"更深层的构造性联系？** 具体目标：

  1. 证明任何满足边界条件 p₁f(0) − p₂f′(0) + (p₃/2)f″(0) + ∫₍₀,∞₎(f(0)−f(x))p₄(dx) = 0（式 1.1）的 Feller 布朗运动 Y，都可以通过一个由正连续可加泛函（PCAF）诱导的唯一时间变换，变成某个生灭过程；
  2. 给出时间变换后生灭过程参数 (γ, β, ν) 与原参数 (p₁, p₂, p₃, p₄) 的显式对应关系（γ = p₁，β = 2p₂，νₙ = pₙ）；
  3. 反向构造：任何生灭过程都可由某 Feller 布朗运动时间变换得到，从而**为所有生灭过程提供一条路径级（pathwise）构造方案**——这是对现有文献（Yang 的预解式解析构造、Wang 的 Doob 过程逼近构造）都未能给出的概率直觉补全。

  ## 研究背景

  - **两条平行的经典脉络**。第一条：Feller 从转移半群理论出发研究半直线 (0,∞) 上布朗运动在边界 0 的一切可能行为且保持强 Markov 性，Itô 与 McKean 在 [11] 中完成了全部此类过程的路径级构造，命名为 Feller 布朗运动；解析上由边界条件式 1.1 中四参数 (p₁, p₂, p₃, p₄) 刻画，概率上对应 killing、reflecting、sojourn、jumping 四种边界行为。
  - 第二条：生灭过程是连续时间 Markov 链的基本模型，Q 矩阵（式 2.1）只允许向左右最近邻跳跃，类比布朗运动轨迹的连续性；因过程可在有限时间到达 ∞，其在 ∞ 及到达后行为是理论基本问题。Feller 在 [7] 中观察到生灭过程在 ∞ 的边界行为与 Feller 布朗运动在 0 的行为有内在相似性，给出边界条件式 1.2；Yang（1965，见 [27] 第 7 章）用预解式方法完成了全部生灭过程的解析构造；Wang（1958 博士论文，见 [27] 第 6 章）给出概率构造，但用的是 Doob 过程逼近而非路径构造，导致 (γ, β, ν) 的概率直觉难以理解。
  - **对称情形已知、非对称情形模糊**。对称情形（同时满足 Kolmogorov 向前/向后方程）下边界退化为经典 Dirichlet/Neumann/Robin 边界，两类过程都是更一般的 **quasidiffusion**（广义扩散/gap diffusion，源于 Kac–Krein 的广义二阶微分算子谱理论 [13]）的特例；且已知对称生灭过程是对称 Feller 布朗运动的时间变换（最小生灭过程对应 killed Brownian 的时间变换，(Q,1)-过程对应 reflecting Brownian 的时间变换）。但**非对称情形**——尤其 Feller 称之为"病态"的 p₄ 或 ν 为无穷测度情形——两类过程的关联在平行发展中只剩方法互借，几乎无人讨论边界条件 1.1 与 1.2 所暗示的拟合。
  - 作者前期工作 [19] 已证明所有（非 Doob）生灭过程满足 Feller 的边界条件 1.2，本文在此基础上补上缺失的桥。

  ## 研究方法

  数学论文，无实验/计算装置；其"方法"是工具组合，按方法卡四要素整理如下（数值均出自原文公式）：

  **原理**：时间变换（time change）——用一个由正连续可加泛函 Aₜ 定义的"新时钟"Aₜ⁻¹ 重新参数化原过程 Y，使 Y_{Aₜ⁻¹} 在另一状态空间上表现为目标过程；本文的核心机制是通过空间变换（scale function 对齐 + 边界反射）先把生灭过程的 ∞ 映到 0，再用由**局部时（local time）对速度测度积分**给出的 PCAF（式 4.4）做时间变换，把 Feller 布朗运动的连续轨迹"压"成只取离散点集 E = {ĉₙ : n ∈ ℕ} ∪ {0} 的跳跃轨迹。

  **参数表（关键构造与公式，原文数值原样）**：

  - 生灭 Q 矩阵（式 2.1）：qₖ = aₖ + bₖ，aₖ > 0 (k≥1)，bₖ > 0，a₀ = 0。
  - 尺度函数（式 2.2）：c₀ = 0，c₁ = 1/(2b₀)，cₖ = 1/(2b₀) + Σ_{i=2}^{k} a₁a₂⋯a_{i−1}/(2b₀b₁⋯b_{i−1})（k ≥ 2）。
  - 速度测度（式 2.3）：µ({0}) = µ₀ = 1，µ({k}) = µₖ = b₀b₁⋯b_{k−1}/(a₁a₂⋯aₖ)（k ≥ 1）。
  - 边界分类辅助量：R = Σ_{k=0}^{∞}(c_{k+1}−cₖ)·Σ_{i=0}^{k}µᵢ，S = Σ_{k=0}^{∞}cₖµₖ；∞ 为 regular 当 R<∞ 且 S<∞，为 exit 当 R<∞ 且 S=∞；c∞ := lim_{k→∞}cₖ < ∞ 等价于最小 Q 过程的暂态性。
  - Feller 布朗运动预解式关键要素（式 3.7）：Eₓe^{−ατ₀} = e^{−√(2α)x}；u₋(x) = sinh(√(2α)x)，u₊(x) = e^{−√(2α)x}，Wronskian W = √(2α)/2。
  - Gₐh(0) 的显式表达式（式 3.9）：分子 2p₂∫e^{−√(2α)x}h(x)dx + p₃h(0) + ∫G⁰ₐh(x)p₄(dx)，分母 p₁ + √(2α)p₂ + αp₃ + ∫(1−e^{−√(2α)x})p₄(dx)。
  - Itô–McKean 路径构造用的 subordinator（式 3.20）：Laplace 变换 Ee^{−xZ(t)} = exp(−t(p₂x + ∫₍₀,∞₎(1−e^{−xy})p₄(dy)))；路径公式 Y¹ₜ := Z(Z⁻¹(ℓₜ)) − ℓₜ + W⁺ₜ（式 3.22），其中 ℓₜ 为 reflecting Brownian 在 0 的局部时，Revuz 测度为 δ₀/2；sojourn 经 f(t) := t + p₃ℓ^{Y¹}ₜ 时间变换加入（式 3.24），killing 经乘性泛函 Mₜ := e^{−p₁ℓ^{Y¹}_{f⁻¹(t)}} 的子过程加入（式 3.25）。
  - 反射布朗运动的局部时定义（式 3.21）：ℓₜ = lim_{ε↓0} (1/(2ε))∫₀ᵗ 1{W⁺ₛ<ε} ds。

  **计算/理论设置（工具组合）**：
  - 对称情形：Dirichlet 型理论（Fukushima [3, 9]），对称 Feller 布朗运动的 Dirichlet 型为 E(f,g) = (1/2)∫₀^∞ f′g′dx + (p₁/(2p₂))f(0)g(0)，对称测度 m(dx) = (p₃/(2p₂))δ₀(dx) + 1₍₀,∞₎(x)dx（式 3.15、3.16；p₃/(2p₂) = m({0}) 即 0 点的速度测度质量）。
  - 非对称有限跳测度（|p₄|<∞）情形：在 Dirichlet 型基础上做 **Ikeda–Nagasawa–Watanabe piecing out 变换**（[10]），在死亡时刻按分布 λ（式 3.19：λ|(0,∞) = p₄/(p₁+|p₄|)，λ({∂}) = p₁/(p₁+|p₄|)）拼接复活路径。
  - 无穷跳测度（|p₄|=∞）情形：piecing out 失效，改用 **Wang 逼近思想**——为 Feller 布朗运动构造 Doob 布朗运动逼近序列（§7），其边界行为简单，可与对应生灭过程的逼近序列对接，分 p₃=0 与 p₃>0 两情形（§8.2、§8.3）最终建立参数关系。
  - 预解式表征：全部非最小 Q 过程的预解式由 (Q, γ, β, ν)-预解式矩阵（式 2.7）给出，存在唯一（至多差正常数倍）；honest ⟺ γ=0，Doob 过程 ⟺ 0<|ν|<∞ 且 β=0（定理 2.1）。
  - Ray-Knight 紧化给出每个 Q 过程的 càdlàg 修正；Doob 过程的紧化非正规，其余 Q 过程在 ℕ∪{∞} 上为 Feller 过程（[19] 推论 5.2）。

  **适用边界**：时间变换保持的参数映射中 **p₃ 不出现**——因为目标生灭过程按定义在 ∞ 无 sojourn（指标集为 ℕ），时间变换实质上"绕过"了原过程的 sojourn 段（§8.3）；要保留 sojourn 须改用指标集 ℕ∪{∞} 上的广义生灭过程（[7]）。映射成立的归一化前提为 p₁+p₂+p₃+∫(x∧1)p₄(dx) = 1 且 p₂=p₃=0 时 |p₄|=+∞（式 3.3、3.4）。

  **代表作**：Itô & McKean, *Diffusion Processes and their Sample Paths*（[11]，路径构造原始文献）；Li（李平）, [19]（生灭过程边界条件与构造理论前期工作，本文直接基石）。

  ## 主要发现与核心结论

  1. **主定理（定理 4.2 与 5.1）**：满足边界条件式 1.1 的 Feller 布朗运动 Y，总能经时间变换变为 E = {ĉₙ}∪{0} 上对应边界条件 γF̂(0) − (β/2)F̂⁺(0) + Σ(F̂(0)−F̂(ĉₖ))νₖ = 0（式 1.3）的生灭过程，参数对应为 **γ = p₁，β = 2p₂，νₙ = pₙ（n ∈ ℕ）**，其中 {pₙ} 是由测度 p₄ 按式 5.1 与 5.2 的方式分配权重得到的序列。
  2. **唯一性（定理 4.4）**：该时间变换由式 4.4 给出的 PCAF 唯一确定——该 PCAF 是 Y 的局部时对由 Q 矩阵决定的速度测度 µ 的积分。
  3. **sojourn 参数的缺席**：p₃ 不出现在参数映射中，原因是所得生灭过程在边界 0 不停留，时间变换"绕过"了 Y 的 sojourn 部分（§8.3 详述）。
  4. **反向构造（推论 5.2）**：由参数关系可进一步推出 E 上每个生灭过程都可由某 Feller 布朗运动时间变换得到。
  5. **路径级构造方案（§5.2）**：由此给出全部生灭过程的一条路径级构造——X̂ 的轨迹就是对应 Feller 布朗运动在 E 上的迹（trace），填补了文献中"生灭过程缺少类似 Itô–McKean 路径构造"的空白。
  6. **对称性判别（推论 3.5）**：Feller 布朗运动对称当且仅当 p₂ > 0 且 |p₄| = 0，此时对称测度必为 m(dx) = (p₃/(2p₂))δ₀(dx) + 1₍₀,∞₎(x)dx（至多差常数倍）。
  7. **勘误性说明**：作者指出 [19] 定理 6.3 推导边界条件时把 β/2 误写为 β（因 [19] 所用尺度函数是 [7] 中尺度函数的一半，引用时漏乘 2），本文按 β/2 的正确形式使用。

  ## 潜在研究方向

  1. **sojourn 的保留**：参数映射丢失 p₃；如何在时间变换框架内保留边界 sojourn（即与广义生灭过程对应）是自然的推广方向，文中仅以"绕过"处理并指向 [7] 的广义生灭过程。
  2. **Doob 过程与非正规紧化**：Doob 过程的 Ray-Knight 紧化不是正规过程，不在本文"Feller 布朗运动 ⟷ 生灭过程"主对应之内；Doob 型（对应式 3.1 的 Doob 布朗运动）一侧的完整对应关系未展开。
  3. **无穷测热情形的逼近收敛**：|p₄|=∞ 情形依赖逼近序列交换极限，逼近误差与收敛速率未量化。
  4. **离散↔连续对应的具体化**：ν 与 p₄ 之间的权重分配公式（式 5.1、5.2）在 |p₄|=∞ 时的构造较复杂，是否存在更直接的显式表达未讨论。
