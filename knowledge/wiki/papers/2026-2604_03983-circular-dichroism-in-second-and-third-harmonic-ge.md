# Circular dichroism in second- and third-harmonic generation in chiral topological semimetal CoSi

## 林赛的理解

这篇 Ominato & Mochizuki (2026) 的理论工作是 HHG/非线性光学与手性拓扑材料交界处的一份"机制说明型"工作——不是新现象的首报，而是把已有现象（SHG-CD、THG-CD of order unity）拆解到底层相位结构，给出一个**统一图像**：SHG-CD 与 THG-CD 都源于非线性电流相位结构 ⟨J_i,n(k,ω)⟩ 的干涉，但二者出现的非线性阶次不同，导致对耗散/展宽 γ 的鲁棒性出现质的差别。这一论点对**强场超快光学**组有可操作的迁移价值——在 HHG 实验里，"相位"常常是难以直接测的"虚部信号"，但 Ominato 等人用 L_n = ∫|J_x,n| dωd k 验证"电流幅度本身不携带 dichroism 信号"，从而把 dichroism 完全归到相位/干涉。这与我组正在做的**相位分辨 HHG**（attoclock、streaking、二维光谱相位恢复）方法学高度同构——尤其是 THG-CD 的"leading-order 鲁棒性"提示我们：**高阶谐波里相位鲁棒的不对称响应，是探测电子相干/拓扑结构的理想通道**，比低阶（SHG）更抗退相干。

可直接借鉴到课题里的点：
- **方法学素材**：四带紧束缚 + Floquet-Keldysh + Peierls 替换是 HHG 理论的标准三件套，可直接套到我们的 WSM/MoTe₂/Co₃Sn₂S₂ 等材料做 HHG-CD 计算
- **判据**：gCD_n ~ O(1) 是"非中心对称 + 手性"的明确指纹，可以作为我们 HHG-CD 实验数据的材料归属判据
- **γ 鲁棒性差异**：提示我们在实验设计 HHG 圆二色谱时，**优先选择三阶而非二阶**，因为三阶信号抗退相干

## 研究问题

论文要回答的核心问题是：**在非中心对称的手性拓扑半金属 CoSi 中，SHG 与 THG 的圆二色谱（circular dichroism in nonlinear response）是否都表现出 order-unity 的强信号？它们对谱展宽/耗散的鲁棒性为什么不同？差异的微观机制是什么？**

具体子问题：
1. SHG-CD 和 THG-CD 的频率依赖、场强依赖、温度/化学势依赖如何？
2. CD 是 chirality-odd 还是 chirality-even？能否反映 CoSi 的"手性"本身？
3. 谐波辐射对偏振态（线/椭/圆）和晶体学取向的依赖？
4. CD 的物理起源：非线性电流的幅度还是相位结构？
5. 谱展宽 γ 如何影响 CD（耗散鲁棒性）？

## 研究背景

- **线性 CD**：左旋/右旋圆偏光响应的差异，是探测分子/表面/固体手性的基本探针 [1-3]，反映晶格手性和电子态对称性
- **非线性 CD**：可远强于线性 CD，提供能带结构与相干性微观信息 [9-11]；SHG 与 THG 是固体中最基本的非线性响应 [12,13]
- **SHG/THG-CD 文献积累**：金属表面单层 [14,15]、手性超材料 [16-22]、单斜晶格超表面 [22]，近年来扩展到固体中的高次谐波
- **手性拓扑半金属作为平台**：B20 型手性晶体（空间群 198）缺乏反转与镜面对称，是手性 chiroptical 响应的理想平台
- **CoSi 的特殊性**：
  - 空间群 198（P2₁3）
  - Γ 点 spin-1 chiral fermion（spin-1 Weyl）
  - R 点 double Weyl fermion
  - Γ 与 R 携带反号拓扑荷
  - 已有 SHG 实验 [Lu et al., PRL 2022] 与线性 CD 计算 [Multunas 2023, Urru 2025]
- **动机**：理论上尚未澄清**真实非中心对称晶体**中 SHG-CD 与 THG-CD 的微观起源，特别是它们对耗散/相位相干的依赖

## 研究方法

这是一篇**高方法密度**的理论计算工作，方法创新 + 计算细节是核心贡献之一，按方法卡四要素详述。

### 方法卡 1：四带紧束缚模型（CoSi）

**原理**：用一个 4×4 矩阵 h(k) 描述 CoSi 费米能级附近的电子结构，矩阵元按空间群 198 的不可约表示构造，sublattice 标记 A/B/C/D 对应单胞中四个原子位 (0,0,0), (a/2,a/2,0), (a/2,0,a/2), (0,a/2,a/2)。模型在 Γ 点给出 spin-1 chiral fermion，在 R 点给出 double Weyl fermion，与 DFT 一致。

**参数表**（数值原样保留）：
| 参数 | 数值 | 出处/单位 |
|------|------|-----------|
| 晶格常数 a | 0.44 nm | Eq.(3)-(5) 上下文 |
| 跳跃积分 t₁ | 0.34 eV | DFT 拟合 [25,42] |
| 跳跃积分 tc | 0.14 eV | DFT 拟合，**打破反转/镜面对称**，手性来源 |
| 跳跃积分 t₂ | 0.13 eV | DFT 拟合 |
| 能量偏移 ε₀ | 0.60 eV | DFT 拟合 |
| 矩阵结构 | μ⊗τ 直积空间 (Pauli-like) | Eq.(6) 给出六个独立 μᵢτⱼ 矩阵 |

**对称性**：
- 三个非相交二重螺旋旋转 s₂,x, s₂,y, s₂,z
- 三重旋转 C₃,[111]（绕 [111] 轴 2π/3）
- 矩阵表示见 Eq.(7)
- 手性翻转规则：tc → -tc 时，Γ 与 R 的拓扑荷反号，手性-奇量反号

**适用边界**：低能有效模型，仅描述费米能级附近能带结构；不包含 SOC 完整细节（但通过对称性嵌入）；不可直接外推到高能 (ℏΩ > 0.6 eV) 区。

**代表作**：Tang, Zhou, Zhang PRL 119, 206402 (2017); Chang et al. PRL 119, 206401 (2017)。

### 方法卡 2：Peierls 替换 + Floquet 展开

**原理**：光场用矢势 A(t) 描述，通过 Peierls 替换 k → k + (e/ℏ)A(t) 引入光-物质耦合；由于哈密顿量时间周期，可用 Floquet 定理在 Sambe 空间展开，时间周期函数用 Bessel 函数 Fourier 分解。

**参数表**：
| 项目 | 设置 | 出处 |
|------|------|------|
| 矢势形式 | A(t) = (E/Ω)[sin(Ωt) e_x' + sin(Ωt+φ) e_y'] | Eq.(10) |
| 偏振控制相位 φ | φ=0 线偏，φ=±π/2 圆偏，中间值椭圆 | Fig.1(b) |
| 旋转轴 | [1̄10] 轴旋转角 θ，坐标 (x',y',z') | Eq.(11)-(12) |
| Floquet Fourier 阶数 | \|m\| ≤ 6 | 数值收敛保证 |
| Bessel 函数 | J_n(A)，A = (eEa/ℏΩ)wᵢ 等无量纲组合 | Eq.(23)-(28) |

**适用边界**：Floquet 适用于周期驱动；不直接处理瞬态/非周期驱动；Bessel 展开在小参数 (eEa/ℏΩ ≪ 1) 下收敛快，强场区收敛慢但可加更多阶。

### 方法卡 3：Floquet-Keldysh 形式计算电流

**原理**：用 Floquet 表示的非平衡格林函数（Dyson 方程 in Keldysh contour）描述驱动+耗散系统。Retarded/Advanced 自能取唯象形式 Σ^R = -iγI，γ 是谱展宽参数（散射率/退相干率）；Keldysh 分量由涨落-耗散定理给出 tanh(β(ℏω+mℏΩ-μ)/2) 因子。最终通过 lesser Green function G^< = G^R Σ^< G^A 计算电流。

**参数表**（数值原样保留）：
| 参数 | 数值 | 出处/说明 |
|------|------|-----------|
| 谱展宽 γ | 0.05, 0.10, 0.20 eV | 三档，描述耗散强度 |
| 场强 E | 2.0 MV/cm | 主图参数 |
| 温度 β⁻¹ | 0.03 eV | 逆温度 |
| 化学势 μ | 0 eV (主文)；±0.2 eV (Appendix) | μ=0 与无掺杂 |
| 光子能量 ℏΩ | 0.2–0.6 eV (扫描)；0.45 eV (特定) | 中红外驱动 |
| k-ω 网格 | 60³ × 40 | 数值积分网格 |
| 强度单位 I₀ | ≃ 6×10⁶ A²/(μm⁴·ps²) | 来自 (2e³V²/(16π⁴ℏ²a²))² |

**电流计算公式**：
- ⟨J_i(t)⟩ = Σ_n e^(-inΩt) ⟨J_i,n⟩
- ⟨J_i,n⟩ = Σ_k ∫(dω/2π) J_i,n(k,ω)
- J_i,n(k,ω) = (2ieℏ) Σ_{m,l} tr[v_{i,m+n-l}(k) G^<_{lm}(k,ω)]
- 前因子 2 来自自旋简并

**HG 强度分解**：
- I_n = I_∥,n + I_⊥,n（平行/垂直于驱动电场振荡面）
- I_∥,n = (nΩ)²(|⟨J_x',n⟩|² + |⟨J_y',n⟩|²)
- I_⊥,n = (nΩ)²|⟨J_z',n⟩|²

**CD 判据（gCD 因子）**：
- gCD_n = (I_n^L - I_n^R) / [½(I_n^L + I_n^R)]
- I_n^L 对应 φ=-π/2（左旋），I_n^R 对应 φ=+π/2（右旋）

**适用边界**：唯象耗散（常数 γ）无法区分弹性/非弹性散射；不直接给出实验可观测的退相干时间 t₂*；不包含电子-电子/电子-声子散射的具体微观机制。

**代表作**：Floquet-Keldysh 在固体 HHG 中的标准应用，见 Refs.[38-41]。

### 方法卡 4：选择定则（HHG selection rules）

**原理**：由空间群 198 对称性（C₃,[111] + 三个 s₂）导出的非线性响应张量选择定则，决定 SHG/THG 在特定几何下的出射分量。

**关键结论**：
- 在 (111) 面圆偏振下：**SHG 只有面内分量**（I_∥,2 ≠ 0, I_⊥,2 = 0）；**THG 只有面外分量**（I_∥,3 = 0, I_⊥,3 ≠ 0）
- 当驱动面偏离 (111)（θ ≠ 0）时，I_∥ 与 I_⊥ 同时出现
- θ → -θ 对应手性翻转（左右互换）

## 主要发现与核心结论

### 1. CD 量级

**SHG-CD 与 THG-CD 均为 order unity**（gCD_n ~ 1–2）。这是核心数值结果：
- 见图 3(a)(b)：在 0.2–0.6 eV 全频段，gCD₂ 与 gCD₃ 在 O(1) 量级振荡
- 这意味着 CoSi 的 SHG 与 THG 在左右旋下强度可比，是强 CD 材料

### 2. γ 鲁棒性的"质"差异（核心结论）

| 谐波 | γ=0.05 eV | γ=0.10 eV | γ=0.20 eV | 行为 |
|------|------------|------------|------------|------|
| SHG (I₂) | 0.05–0.30 (I₀) | 0.02–0.10 (I₀) | 0.0005–0.0020 (I₀) | **CD 显著被抑制**，gCD₂ 整体下降 |
| THG (I₃) | 0.005–0.025 (I₀) | 0.002–0.010 (I₀) | 0.0005–0.0020 (I₀) | **CD 几乎不变**，gCD₃ 维持 order unity |

THG 强度约比 SHG **小一个量级**（在当前参数下），但 CD 信号更鲁棒。

### 3. 微观起源：相位 vs 幅度

- **幅度 L_n = Σ_k ∫(dω/2π) |J_x,n(k,ω)| 不携带 CD**：左右旋曲线重合，且 L_n 随 ℏΩ 单调变化，与 I_n 的非单调行为（SHG 在 ℏΩ~0.5 eV、THG 在 ℏΩ~0.35 eV 出现局部极值/谷）不一致
- **CD 来源：非线性电流的相位结构 ϑ_{i,n}(k,ω)**，反映 Floquet 态间的相干/微运动

### 4. 非线性阶次差异（最关键的论断）

- **SHG-CD**：在弱场区，I₂ ∝ E⁴；左右旋差异在 E⁴ 拟合区**可忽略**，只在更高 E 出现 → CD 来自**亚主导（subleading）非线性干涉**
- **THG-CD**：在弱场区，I₃ ∝ E⁶；左右旋差异**已存在**于 E⁶ 拟合区 → CD 已存在于**主导非线性阶次**

这是 SHG-CD vs THG-CD γ 鲁棒性差异的根本原因：**主导阶次的相位相干更鲁棒**，亚主导干涉被耗散快速擦除。

### 5. 化学势依赖（Appendix A）

- μ = -0.2, 0, +0.2 eV 三档对比
- THG-CD 定性保持，左旋始终大于右旋
- SHG-CD 在 μ = -0.2 eV 低频区**反号**，gCD₂ 变负（重要反常）

### 6. 偏振态与晶体学取向依赖

- 偏振 φ 在 -π 到 π 扫描：SHG 始终 I_∥,2 主导；THG 在 φ=±π/2 附近 I_⊥,3 主导，偏离后转为 I_∥,3 主导
- 取向 θ 扫描（驱动面绕 [1̄10] 旋转）：
  - θ = 0 与 θ = ±π/2 时 CD 消失
  - θ = ±θ₀（θ₀ 为 z' 与 [111] 重合角度）时：SHG 的 I_⊥,2 被禁止；THG 的 I_∥,3 被禁止
  - θ → -θ 映射左右旋（对称性要求）

### 7. Chirality-even vs chirality-odd（重要警示）

- **gCD_n 与 I_n 都是 chirality-even 量**：tc → -tc 下不变，因此**不能直接探测 CoSi 的"手性"，只反映非中心对称性**
- **电流 Fourier 分量 ⟨J_i,n⟩ 是 chirality-odd**（在 n 为偶数时反号，n 为奇数时不变；n=0 直流光电流反号，与既有理论 [57-59] 一致）
- 含义：要测手性本身，需要**相位敏感的测量**（实时电流动力学），而不是积分强度

### 8. THG 强度在 ℏΩ ≈ 0.35 eV 的 dip

- 来源：带间跃迁，反映底层电子结构
- γ 增大时被抑制

## 潜在研究方向

### 1. 局限性

- **模型局限**：四带紧束缚不包含完整 SOC 与高能带；外推到 ℏΩ > 0.6 eV 不可靠
- **唯象耗散**：常数 γ 不区分弹性与非弹性散射；不含具体电子-声子/电子-电子耦合
- **零温近似附近的 T 效应**：β⁻¹ = 0.03 eV，作者声称改变一个量级结论不变，但未系统扫描
- **无相位敏感观测量**：只算了强度 gCD_n，没有直接输出 ⟨J_i,n⟩ 的相位或实时电流
- **材料单一**：仅 CoSi；未推广到 RhSi、AlPt、CoGe 等同结构家族

### 2. 开放问题

- **chirality-odd 观测量的实验实现**：如何直接测 ⟨J_i,n⟩ 的相位/手性反号？attoclock 或 sub-cycle 电流探测？
- **高阶谐波（> 3 次）的 CD**：是否 THG-CD 的鲁棒性能推广到 HHG 的高阶 plateau？
- **手性拓扑费米子（spin-1 Weyl, double Weyl）的指纹**：THG-CD 频谱中的 dip（0.35 eV）是否对应 spin-1 chiral fermion 的带间跃迁？需要 DFT 能带精确比较
- **强场非微扰区**：E > 2.0 MV/cm 下 Floquet-Bessel 展开需要更多光子；非微扰区是否出现 plateau-like CD 行为？
- **时间分辨**：Floquet 框架本质是稳态周期驱动；如何衔接 pump-probe 的瞬态 chiroptical 动力学？
- **反常化学势效应**：μ = -0.2 eV 时 SHG-CD 反号的微观机制？是否对应某个特定费米面拓扑口袋？

### 3. 实验落地挑战

- CoSi 薄膜 (111) 取向制备与表征
- 中红外 (ℏΩ ~ 0.2-0.6 eV, λ ~ 2-6 μm) 圆偏振驱动
- 区分 in-plane vs out-of-plane 谐波（角度分辨探测）
- 抗 γ 退相干：需要低温降低 γ

## 与林赛研究的关联

**HHG 光谱学**方向的具体接口：

1. **方法迁移**：四带紧束缚 + Floquet-Keldysh + Peierls 三件套可直接套到我们正在研究的**交磁材料**（如 Co₃Sn₂S₂, Mn₃Sn）的 HHG-CD 计算。只需把对称性从空间群 198 换成对应的 magnetic space group，floquet 引擎本身不用改。

2. **判据迁移**：gCD_n ~ O(1) 是非中心对称 + 手性的明确指纹。我们实验组在 HHG-CD 实验中可以用**三阶信号**作为"是否存在手性贡献"的诊断，比 SHG-CD 更可靠（鲁棒）。

3. **γ 鲁棒性 → 实验设计**：若我们要用 HHG-CD 探测**莫尔超晶格**或**量子几何（Berry curvature, quantum metric）**，室温下 γ 较大，应优先选择 THG 甚至更高阶，而非 SHG。这一点是直接的方案写作指南。

4. **相位分辨 HHG**：作者明确指出 ⟨J_i,n⟩ 是 chirality-odd 而强度 I_n 是 chirality-even——这强烈支持我们正在探索的**相位分辨 HHG**方向（attoclock / 2D ESHHG）：**要看到材料"手性"本身，必须测量相位敏感的观测量，不能只看强度谱**。

5. **HHG selection rules 与 out-of-plane 探测**：作者明确给出 (111) 面圆偏振下 SHG 只有面内、THG 只有面外分量。这意味着我们可以设计**角度分辨的 HHG-CD 探测**：THG-CD 信号出现在面外方向，SHG-CD 在面内。这一几何选择性在我们的实验台上可以通过偏振+角度扫描直接验证。

6. **与"强场驱动"的耦合**：Floquet 形式天然适用于周期性驱动，作者将 θ 和 φ 作为连续参数扫描，相当于在 "驱动场几何空间" 中绘制 CD map。这与**强场驱动的相干控制**（coherent control of HHG）有共同语言：CD 可以作为驱动场几何的敏感探针。

7. **反常化学势效应（μ = -0.2 eV）**：提示在 doping-tuned HHG-CD 实验中，可能在某个特定 doping 下观测到 SHG-CD 反号，可作为**拓扑口袋填充的 fingerprint**。

# Circular dichroism in second- and third-harmonic generation in chiral topological semimetal CoSi

**arXiv**: [2604.03983](https://arxiv.org/abs/2604.03983) | **方向**: 手性拓扑半金属 CoSi 中圆二色性、二次/三次谐波生成与相位分辨固体高次谐波电子动力学

---

## 研究问题（Research Question）

此前非线性圆二色性常被作为强度差异或对称性现象讨论，尚未清楚回答 SHG 与 THG 的二色性为何对耗散/谱展宽表现完全不同，也难以从强度本身判断响应究竟编码了晶体手性还是更一般的非中心对称性。本文在空间群 198 的手性拓扑半金属 CoSi 上，用四带紧束缚模型、Peierls 光-物质耦合、Floquet 理论和 Floquet–Keldysh 非平衡 Green 函数统一计算谐波电流及其偏振分量，揭示具体机制：SHG-CD 只有在超出 E⁴ 主导项的高阶路径干涉中出现，因而被退相干抹平；THG-CD 已存在于 E⁶ 的首个非线性项，因相位结构而对谱展宽更稳健。该机制把谐波强度的非单调频率依赖与 Floquet 态微动相位联系起来，同时明确指出强度型 SHG/THG-CD 在反转手性参数 t_c 时是手性偶的，真正判定左/右晶体手性必须测量电流相位或其他手性奇观测量。

## 研究背景（Background）

这篇工作把固体 HHG 的核心问题从“谐波强度有多大”推进到“非平衡电流路径的相位如何编码对称性”，与林赛的强场超快光学、阿秒科学和拍赫兹电子学直接相连。实验上可在 800 nm Ti:Sa 优先条件下做 CoSi 的偏振/晶向分辨 HHG，但必须用多能带模型处理 1.55 eV 光子能量；相位敏感 HHG 或电子束/电光电流采样尤其适合提取论文指出的手性奇 Fourier 分量。CoSi 可作为手性拓扑参照，ZnO 可作为核心非中心对称固体 HHG 材料，MoS₂/WSe₂ 则把 SHG/THG-CD 连接到 K/K′ 能谷选择、TMD Berry 曲率和超快能谷操控。

## 研究方法（Methods）

- - 手性四带紧束缚模型：用空间群 198 的四个子晶格和 a=0.44 nm 建立 h(k)，以 t₁、t_c、t₂、ε₀ 参数拟合 DFT；显式利用 t_c→−t_c 区分手性偶强度与手性奇电流，并保留 Γ spin-1 与 R double-Weyl 拓扑节点。
- - 任意椭圆/圆偏振和晶向的 Floquet 建模：以 A(t)=E[sin(Ωt)e_x′+sin(Ωt+φ)e_y′]/Ω 表示光场，绕 [̄110] 轴旋转 θ；用 Peierls 替换 k→k+eA/ℏ、Sambe 空间 Floquet 矩阵、Bessel Fourier 展开处理 (111) 面及倾转几何。
- - Floquet–Keldysh 非平衡 Green 函数：用 Σ^R=−iγ、Σ^A=+iγ 的 reservoir 自能表示谱展宽，通过 Keldysh/lesser Green 函数 G^< =G^RΣ^<G^A 得到耗散稳态；在 |m|≤6 的光子截断和 603×40 的 k–ω 网格下收敛计算。
- - 相位分辨谐波诊断：从速度算符与 G^< 的 Fourier 分量构造 J_i,n，分解平行/垂直驱动面强度 I_n=(nΩ)²|J_n|²，并定义 g_n^CD=(I_n^left−I_n^right)/[ (I_n^left+I_n^right)/2 ]；同时积分 |J_x,n(k,ω)| 得 L_n，借此把“谱模长”与“路径相位干涉”分离。

## 主要发现与核心结论（Main Results）

- - 在晶格常数 a=0.44 nm、t₁=0.34 eV、t_c=0.14 eV、t₂=0.13 eV、ε₀=0.60 eV 的四带 CoSi 模型中，t_c 同时破坏反演/镜面对称并决定手性；模型保留 Γ 点 spin-1 chiral fermion 与 R 点 double-Weyl crossing。对 (111) 面、E=2.0 MV cm⁻¹、μ=0、β⁻¹=0.03 eV 的圆偏振驱动，SHG 与 THG 都出现数量级为 1 的圆二色性。
- - SHG-CD 对耗散极其敏感：在 γ=0.05、0.10、0.20 eV 的谱展宽下，SHG 总强度和左右旋差异随 γ 增大而下降；SHG 强度在 ℏΩ 略低于 0.5 eV 附近有左旋峰，右旋则有多个局部峰并在约 0.5 eV 有浅谷，显示带间跃迁和路径相位干涉而非简单单调共振。
- - THG-CD 在宽频段保持数量级为 1，并除约 ℏΩ=0.35 eV 的带间跃迁谷附近外对 γ=0.05–0.20 eV 不敏感，甚至二色性幅度随 γ 增大趋于增强；THG 总强度约为 SHG 的十分之一，增大 γ 会压低强度并抹平 0.35 eV 谷，但不消除左右旋差异。
- - 弱场标度直接定位了机制：在 ℏΩ=0.45 eV，SHG 服从 I₂∝E⁴，且左右旋差在首个 E⁴ 项中几乎为零，只在更高阶非线性贡献出现；THG 服从 I₃∝E⁶，左右旋差从首个 E⁶ 项就存在，所以对谱展宽更具鲁棒性。这对应 SHG 的 subleading interference 与 THG 的 leading-order CD。
- - 相位而非电流谱模长控制二色性：左右旋的积分谱模长 L₂、L₃ 几乎相同且随 ℏΩ 单调变化，但实际 SHG/THG 强度非单调并有明显 CD，说明 Floquet lesser Green 函数携带的 Floquet 态相干/微动相位改变了路径干涉。偏振离开圆偏振后，SHG 始终以面内分量为主，THG 从圆偏振附近的面外主导转为面内主导；晶向 θ=0、±π/2 时 CD 消失，并在 θ→−θ 下交换左右旋。
- - 强度 CD 并非直接的晶体手性判据：反转 t_c 后谐波强度不变，而电流 Fourier 分量对偶次 n 变号、奇次 n 不变，dc 分量尤其是手性奇的；因此相位敏感电流或实时电流测量才可提取 CoSi 左右手性。化学势 μ=−0.2 eV 时低频 SHG-CD 可反号且减弱，而 THG-CD 的总体趋势在 μ=−0.2、0、0.2 eV 保持。

## 潜在研究方向（Future Directions）

- 1. 在 800 nm Ti:Sa（ℏω≈1.55 eV）平台上做 CoSi 的偏振分辨固体 HHG：论文扫描的是 0.2–0.6 eV 中红外，800 nm 已超出该四带低能模型的适用窗口，需先扩展到含远离费米能级能带的第一性原理/Wannier 模型，再比较 2ω、3ω 与更高次谐波的 CD，避免把模型外推当作结论。
- 2. 建立真正相位敏感的手性测量：用干涉型 HHG、外差/自外差电光采样或实时电流重构测 J_n 的相位，在 CoSi 左右手性晶体或等效 t_c 符号反转样品间验证偶次电流分量变号、奇次不变，从而把“非中心对称 CD”与“晶体手性”实验区分开。
- 3. 将常数 γ 的耗散替换为动量、能量和温度依赖的电子-声子/电子-电子自能，并把激子、远程能带、实际掺杂和表面态纳入 Floquet–Keldysh；尤其检验 0.35 eV THG 谷以及 μ=−0.2 eV 低频 SHG-CD 反号在真实散射中的稳定性。
- 4. 系统扫描 θ、φ、场强和入射晶向，测量 SHG 面内/面外、THG 面内/面外的联合偏振图，结合发射方向性和时间分辨 HHG，提取拓扑节点、晶体对称性与相干微动的可辨识指纹。
- 5. 把机制移植到林赛的核心材料：在 ZnO 中检验非中心对称晶格、Berry 几何和固体 HHG 相位是否产生同类 leading-order THG-CD；在 MoS₂/WSe₂ 中用 800 nm 共振/多光子驱动，将 SHG/THG 圆二色性与 K/K′ 选择、能谷极化和超快退相干联合测量，形成 TMD 能谷电子学与拍赫兹电子学的桥接。

## 研究方法（方法卡）
<!-- methods-backfill:v1 -->
**方法**：CoSi 谐波圆二色性的相位机制分析（E⁴/E⁶ 领头阶定位 + 手性奇电流分量）

**原理**：与四带 Floquet-Keldysh 主计算（另页）互补的机制分析：弱场标度定位 CD 来源——SHG 服从 I₂∝E⁴ 且左右旋差在首个 E⁴ 项中几乎为零（subleading 高阶路径干涉，故被退相干抹平），THG 服从 I₃∝E⁶ 且左右旋差从首个 E⁶ 项即存在（leading-order CD，故对谱展宽鲁棒）；以积分谱模长 L_n=∫|J_x,n(k,ω)| 分离'谱模长'与'路径相位干涉'——左右旋 L₂/L₃ 几乎相同而强度非单调有 CD，证明是 Floquet 态微动相位控制二色性；t_c→−t_c 下谐波强度不变而电流 Fourier 分量偶次 n 变号、奇次不变（dc 分量尤其手性奇），故判定晶体左右手性必须测电流相位。
