• # Giant X-ray circular dichroism in a time-reversal invariant altermagnet

  ## 林赛的理解
  这篇工作把“结构手性 + 共线反铁磁序”这两种本不该产生强磁圆二色性的因素耦合在一起，在 Ni₃TeO₆ 中得到了可与铁磁 XMCD 相比的 XNCD 信号。对我组来说，这意味着**交变磁（altermagnet）的量子几何响应可以不依赖外磁场、不破坏时间反演对称性而被光谱直接读取**。HHG 和阿秒探测一直苦于如何在反铁磁体系中无磁化地读取自旋/轨道序；这篇文章给出的思路是：利用材料本身的手性晶格把圆偏振光场等效为磁化场，进而诱导轨道磁矩和自旋极化。换句话说，它为“强场超快光驱动的交变磁序成像”提供了一个元素敏感、手性可分辨的光谱接口，尤其适合我们关注的 Berry 曲率、量子几何与非平衡磁化动力学交叉方向。

  ## 研究问题
  论文要回答的核心问题是：**为什么一个具有有效时间反演对称性的共线反铁磁体（交变磁体）Ni₃TeO₆ 会在 Ni L₃ 边产生巨大的 X 射线圆二色性？** 具体包括：
  - 这种强 XNCD 的来源是传统的 E1–E2 干涉，还是新的与磁序和手性晶格耦合的机制？
  - 在没有外磁场、没有净磁化的情况下，圆二色信号如何随反铁磁相变出现、为何在 T_N 附近增强、又为何在左右手性畴之间反号？
  - 这一现象能否把 Ni₃TeO₆ 归类为新型“时间反演不变但可观测圆二色性”的磁性材料，并为交变磁性提供光谱学证据？

  ## 研究背景
  - **圆二色性的两种传统来源**：在时间反演对称但中心反演破缺的晶体中，E1–E2 干涉产生 X 射线自然圆二色性（XNCD），通常比 3d 金属 L 边的磁圆二色性（XMCD）弱几个数量级；在铁磁/亚铁磁等破坏时间反演对称的材料中，XMCD 可直接探测自旋和轨道磁矩。
  - **反铁磁中的非常规 XMCD**：传统认为共线反铁磁净自旋为零、无 XMCD，但近年发现非共面/手性自旋结构的反铁磁可产生 XMCD；随后“交变磁体”（altermagnet）概念提出，共线反铁磁自旋完全抵消，却因自旋群对称性可表现出类似铁磁的输运/光学响应。
  - **晶体手性与自旋选择效应**：手性晶体或分子可通过自旋-轨道耦合在电流中产生显著自旋极化（CISS）；Ni₃TeO₆ 本身是极性、手性的改良刚玉结构，且为共线反铁磁，是研究“手性晶格 + 交变磁性”耦合的理想平台。

  ## 研究方法
  - **样品**：采用助熔剂法生长 Ni₃TeO₆ 单晶；DC 磁化率测量使用 µ₀H = 0.2 T 的外场，分别平行和垂直于 c 轴。
  - **同步辐射实验**：在台湾光源 TPS 41A 光束线进行 Ni L 边软 X 射线光谱与散射实验，能量分辨率 0.3 eV，入射光通过毛细管光学聚焦到样品处约 1 µm 的光斑；散射 X 射线与荧光分别由光电二极管和 CCD 探测器接收。
  - **测量模式**：
    - 全荧光产额（TFY）用于 XAS 与圆二色，经过自吸收修正；
    - 部分荧光产额（PFY）用于 X 射线线二色（XLD），入射光斑 50 µm（竖直）× 60 µm（水平），入射角 θ = 20° 偏离 a 轴；
    - 共振 X 射线磁散射（RXMS）扫描倒空间 (0, 0, L)，使用 RCP 光在 ω_RT + 0.3 eV 处测得 (0, 0, 1.5) 反铁磁衍射峰；
    - XCD 在 90×90 µm² 区域内分别对 A、B 两个手性畴进行 RCP/LCP 吸收谱测量，入射角约 θ ∼ 53° 偏离 a 轴。
  - **数据归一化**：TFY-XAS 在 L₃ 边以下 8 eV 和 L₂ 边以上 8 eV 归一化；PFY-XAS 为 5 eV；RXMS 以扫描前后平均入射光强归一化；XCD 误差按 L₃ 峰强度 ±2% 估算，XAS/RXMS 强度误差 ±1%。
  - **理论分析**：建立现象学模型，把圆偏振 X 射线在手性晶格中的传播等效为磁化场；证明 L 边 XCD 截面正比于固定能量下动量空间 Berry 曲率的积分，从而把观测到的圆二色性与材料的量子几何性质联系起来。DFT 交换参数引用 Wu 等的 GGA+U（U = 2.5 eV）结果：J₁ = −0.94 meV，J₂ = −4.55 meV，J₃ = 3.70 meV，J₄ = 6.41 meV，J₅ = 1.48 meV。

  ## 主要发现与核心结论
  - **反铁磁相变**：Ni₃TeO₆ 在 T_N = 52–62 K 进入共线反铁磁态；本样品的 Néel 温度为 **T_N = 62 K**，磁化率平行 c 轴分量 χ∥ 在 T_N 处出现尖锐峰刺，RXMS 的 (0, 0, 1.5) 峰在 T_N 以下出现并随降温增强。
  - **巨大的自然圆二色性**：在零外场、无剩余磁化下，Ni L₃ 边观测到显著的 XCD，最大幅度约为 Ni L₃ 边 XAS 峰强度的 **~20%**，远大于此前报道的 **2%**；该信号在 A、B 两个相反手性畴之间反号。
  - **谱峰能量与线形**：室温 XAS 主峰位于 **ω_RT = 853 eV**；降温至 T_N 附近，XAS 峰增强并向高能移动约 **~0.3 eV**；畴 A 的 XCD 正峰位于 **ω_RT + 0.3 eV**，畴 B 的负峰位于 **ω_RT + 0.7 eV**；RXMS 能量扫描也显示畴 A 峰在 ω_RT + 0.3 eV，畴 B 峰在 ω_RT + 0.7 eV。
  - **强度随温度的非单调行为**：XCD 强度在 T_N 附近最强，室温下几乎不可见；T_N 以下呈现类似反铁磁态的峰刺特征，T_N 以上仍有有限磁化率贡献。
  - **非线性光强依赖**：在 **26 K** 将入射 X 射线强度降至 **60%** 时，归一化 XCD 强度下降至约 **~1/2**，表明信号并非简单的线性吸收过程，可能涉及光诱导的声子/磁振子激发。
  - **手性-磁序耦合机制**：作者提出，圆偏振 X 射线在手性晶格中传播时，其 Poynting 矢量对应的等效磁场可诱导轨道磁矩，并通过自旋-轨道耦合进一步产生自旋极化；该机制是互易的（k → −k 时 B → −B，磁化反向），因此属于 XNCD 而非 XMCD。形式上，L 边 XCD 截面正比于 Berry 曲率在动量空间的积分，说明**非零 Berry 曲率源于反演对称性破缺，而非时间反演对称性破缺**。
  - **交变磁性归类**：Ni₃TeO₆ 的磁点群为 **31′**，属于 type-III 交变磁体：具有破缺的 PT 对称性，不表现出奇数阶反常霍尔效应，但在守恒 PT 对称的外微扰（如传播光子）下可呈现类铁磁行为。观测到的温度依赖 XNCD 即为这种交变磁响应的光谱证据。
  - **角度依赖**：XCD 强度在入射角 **θ ∼ 53°** 时最大，可能与 X 射线入射方向（倾向于 c 方向）和 Ni₃TeO₆ 磁各向异性（倾向于 ab 面）之间的竞争有关。
  - **临界场与自旋翻转**：对于 H ∥ c，当外场超过临界场 **H_c ∼ 6–9 T** 时，Ni 自旋从 c 轴翻转到 ab 面，形成非公度螺旋结构。

  ## 潜在研究方向
  - **微观定量理论**：目前模型为现象学对称分析，尚未从第一性原理计算 XNCD 的绝对强度；需建立包含 Berry 曲率、自旋-轨道耦合和光场非线性驱动的完整微观理论。
  - **时间分辨与超快调控**：用飞秒/阿秒脉冲追踪 XNCD 在光泵浦后的超快演化，可直接测量交变磁序、手性声子和磁振子角动量的非平衡动力学。
  - **推广至其他交变磁材料**：验证 type-III 交变磁体是否普遍存在“光子等效磁化场”诱导的圆二色性，并探索极性/手性耦合对信号强度的调控。
  - **热 CISS 与非平衡效应**：区分光诱导声子/磁振子角动量、热流与 Berry 曲率各自对 XNCD 的贡献，特别是在有限温区 T_N 以上仍存在的信号。
  - **畴工程与器件接口**：利用手性畴的符号可辨特性，把 XNCD 发展为无磁场、元素敏感的手性/磁畴成像工具，并与自旋电子学器件对接。
  - **强场下的非线性响应**：论文已观测到 XCD 对 X 射线强度的非线性依赖；在强场超快激光驱动下，可能产生更高阶的非线性圆二色或高次谐波中的手性信号。

  ## 与林赛研究的关联
  - **HHG 与阿秒探测接口**：Ni₃TeO₆ 这类手性交变磁体具有由 Berry 曲率支配的光学响应，正是 HHG 探测量子几何（Berry 相位/曲率）的理想体系；可设计圆偏振强场激光诱导高次谐波，观察谐波中的圆二色或手性依赖。
  - **强场驱动交变磁**：论文把“传播光子等效为磁化场”的图像可自然推广到强红外/THz 场——交变磁体或许能在无外磁场条件下被超快光场诱导出瞬态轨道磁矩和自旋极化，为我们“强场驱动交变磁序”的立项提供参考材料与候选体系。
  - **莫尔与量子几何**：Ni₃TeO₆ 的手性晶格和反演破缺带来的非零 Berry 曲率，与我们在莫尔/低维体系中关注的量子几何量（Berry 曲率、量子度规）有共同语言；可借鉴其 XNCD–Berry 曲率关系，发展适用于莫尔超晶格的圆二色探针。
  - **非平衡磁化动力学**：光诱导声子/磁振子角动量对 XNCD 的贡献提示，超快时间分辨圆二色可作为追踪“光-晶格-自旋-轨道”耦合的新窗口，直接服务于本组阿秒磁学方向。
