• # Spin-orbit magnetism in altermagnets（交变磁体中的自旋-轨道磁性）

  ## 林赛的理解

  这篇工作给了一个我非常看重的东西：一个**对称性语言的"解耦定理"**——把 SOC 诱导的净磁化拆解为自旋（M_S）和轨道（M_O）两部分，并证明在特定对称性下两者对 SOC 呈现不同阶的微扰依赖。这意味着**反常霍尔（AHE）信号和杂散磁矩在原理上可以独立优化**：type III 交变磁体中 M_O 是一阶、M_S 被压到二阶，于是可以"大 AHE + 近零净磁矩"兼得。对我的团队而言，这有两层直接价值：其一，KV2Se2O 的"共轴霍尔效应"（M_O ∥ M_S ∥ Néel 矢量）给出了弱场确定性 180° 翻转 Néel 序的路径，这是交变磁体器件化的关键瓶颈之一；其二，文章把 SOC 写成 3×3 张量 χ(θ,φ) 并做定向自旋群（oriented spin space group）分类的整套技术，可以直接搬到我们的强场/超快问题里——光场本质上是时间依赖的对称性破缺源，同一个张量展开框架可以用来分析强场诱导磁化（包括光致 Floquet 磁化）中轨道与自旋成分的阶数差异。另外注意这是 SUSTech 刘奇航组的活，正是国内做交变磁性的主力之一，值得持续跟踪。

  ## 研究问题

  论文要回答的核心问题是：**为什么交变磁体（altermagnet）在净磁化近乎为零（甚至小到 10⁻⁶–10⁻² µB）的情况下仍能产生显著的反常霍尔响应？** 具体分解为三个子问题：

  1. SOC 诱导的净磁化（spin-orbit magnetism, SOM）中，**自旋磁化 M_S 与轨道磁化 M_O 各自对 SOC 强度是几阶微扰依赖？** 二者能否解耦？
  2. 这种依赖关系如何由**连接反自旋子格的空间旋转轴次**（二重/四重/六重）决定？
  3. 如何据此找到**"大 AHE + 极小净磁矩"** 兼得的候选材料，并实现 Néel 序的可控翻转？

  中心论点：只有当反自旋子格通过**四重旋转**连接时，M_O 与 M_S 才呈现不同的微扰阶数（一阶 vs 二阶），从而产生"轨道霍尔主导、自旋磁矩可忽略"的共轴霍尔效应（coaxial Hall effect）。

  ## 研究背景

  - 非常规磁体（unconventional magnets）兼具补偿磁化与类铁磁物理性质，被视为下一代自旋电子学平台，分为两支：反常霍尔反铁磁体（如 Mn3Sn）和自旋劈裂反铁磁体。
  - 交变磁体（altermagnet）是后者的原型：无 SOC 时即具有动量依赖的自旋劈裂（d/g/i 波自旋织构），最初被认为 AHE 是其输运指纹。
  - 近期认识修正：反铁磁中的 AHE 对应一种独立磁相——**自旋-轨道磁性（SOM）**，净磁化完全由 SOC 通过其对称性破缺路径诱导产生，包括自旋与轨道两部分。
  - 悬而未决的矛盾：交变磁体净磁化在不同体系中跨 **10⁻⁶ 到 10⁻² µB** 数个量级变化（FeS、Mn5Si3、MnTe 等实验值仅 10⁻⁵–10⁻⁴ µB），而 AHE 却可相当可观，两者间的定量关系一直没有建立。
  - 方法学脉络：传统磁空间群分析把磁有序与 SOC 的贡献纠缠在一起（Brinkman-Elliott 自旋空间群、Litvin 自旋点群以来的老问题）；近期自旋空间群理论（Chen/Ren 与 Liu 组的枚举工作，PRX 14, 031038/031037/031039, 2024）允许分离无 SOC 物理。此前张量展开方法已解释了铁磁体和共面反铁磁 Mn3Sn 中 M_O 与 M_S 的不同阶数，但**系统覆盖交变磁体、并量化其对 Néel 矢量取向依赖的完整框架缺失**——本文填补的正是这个空白。

  ## 研究方法

  1. **理论框架：定向自旋空间群（oriented spin space group, OSG）**——统一自旋空间群与磁空间群框架（源自 Liu et al., Nature 652, 869 (2026)），将共线磁体的自旋-晶格关系由 SO(3) 自由度缩减为 SO(2)（由 Néel 矢量的极角 θ 和方位角 φ 描述）。
  2. **SOC 张量展开**：把 SOC 哈密顿量重写为 3×3 张量形式 Ĥ_SOC = λ Σ_ij χ_ij L̂_i σ̂_j，其中 χ(θ,φ) 由 Néel 取向参数化（式 2 给出显式旋转矩阵）。对 M_O 和 M_S 做 χ 的幂级数微扰展开（式 3），ω^(n) 为 (2n+1) 阶对称适配张量。
  3. **对称性分类**：自旋磁化按 D(U) 变换、轨道磁化按 det(U)det(R)D(R) 变换；反演与分数平移不改变两者，因此约束完全由 **10 个自旋 Laue 群**决定，进一步推广为**定向自旋 Laue 群（OSLG）**。对 OSLG 退化为"允许净磁化的磁 Laue 群（MLG）"的方向，评估 ω^(n) 的最低非零阶。
  4. **第一性原理计算**：DFT（VASP，PAW，GGA-PBE 泛函，部分体系含 DFT+U 处理 Mott 绝缘体，如 LiFe2F6 参考文献引用 Anisimov 方法），Wannier90/WannierTools/Wannsymm 计算 Berry 曲率与反常霍尔电导率。
  5. **高通量筛选**：对 **MAGNDATA 数据库**中全部交变磁体结构筛查具备关键 {−1∥4} 对称性的候选，得到 7 个 SOM 候选材料，其中 5 个为大能隙绝缘体、2 个为金属。

  材料体系：LiFe2F6（三金红石结构，type III 验证平台）与 KV2Se2O（室温以上金属性 d 波交变磁体，Nat. Phys. 21, 754 (2025) 已报道，本文预测其为共轴霍尔效应的理想载体）。

  ## 主要发现与核心结论

  **1. 三类 OSLG 的分类定理**（核心结果，见原文 TABLE I）：

  - **Type I**（反自旋子格仅由**二重旋转**连接）：M_O 和 M_S 均为**一阶** SOC 微扰 → 净磁矩大，如 RuF4 理论预言 ~10⁻¹ µB。
  - **Type II**（由**六重或多重高次旋转**连接）：M_O 和 M_S 均为**三阶**微扰 → 净磁矩极小，与 FeS、Mn5Si3、MnTe 实验观测的 **10⁻⁵–10⁻⁴ µB** 一致。
  - **Type III**（由**四重旋转**连接）：**M_O 保持一阶而 M_S 被压至二阶**——阶数差异仅在此类出现，这是"大 AHE + 可忽略净磁矩"的微观对称性基石。

  **2. 阶数差异的对称性起源**：源于自旋群 ∞m1 与操作 {−1∥(2l)} 的联合约束。无自旋群时 {−1∥(2l)} 使 M_O、M_S 分别出现在 (l−1) 阶和 l 阶；当 l 为奇数（type I/II）时，共线自旋群把 M_O 从 (l−1) 阶推到 l 阶，消除差异；当 l 为偶数（type III，l=2）时差异保留。

  **3. 共轴霍尔效应（coaxial Hall effect）**：type III 中（特别是 −14/1m−1m1m∞m1），当 Néel 矢量沿 [110] 方向时，M_O ∥ M_S ∥ N，三者共轴。机制是 SOC 消除了交换子格的操作后，剩余对称性强制净磁化与 N 平行。与共线关系消除了多态简并与翻转势垒竞争，**弱磁场即可实现 Néel 矢量的确定性 180° 翻转**，类铁磁操作。

  **4. 定向输运规律**：
  - N 沿纯晶格旋转轴 {1∥R} 时，SOM 消失（MLG 禁止净磁化）。
  - 1−3/−1m∞m1 群中即使 N 沿 [100] 高对称方向，M_O,z 仍被限制到高阶，σ_xy 源于高阶 SOC 效应，**输运测量应聚焦更显著的 σ_xz 或 σ_yz 分量**。
  - 低对称取向下，{−1∥4⁺_001} 或 {1∥R_001} 与 {−1∥m_100} 的联合对称使 M_O,z 分量恒为零。

  **5. LiFe2F6 定量验证**（N ∥ [100]，OSG 为 P−142/1m−1n1m∞100m1，SOC 下退化为 m′mm′，允许 [010] 方向净磁化）：DFT 确认 **M_O ∝ λ（一阶）、M_S ∝ λ²（二阶）**。尽管全由轻元素组成，反常霍尔电导率高达 **40 S/cm**。

  **6. KV2Se2O 的共轴霍尔效应预测**（OSG 为 P−14/1m1m−1m∞010m1，因晶体学设定有 **45°** 偏移，N 沿 [100] 或 [010] 均可实现）：
  - 无 SOC 时 Γ-X 路径巨动量依赖自旋劈裂 **超过 1 eV**，典型 d 波自旋织构；
  - SOC 引入后带结构几乎不变，但在能带交叉处产生显著 Berry 曲率；
  - 费米面附近反常霍尔电导率 **~100 S/cm**，而净磁化**小于 10⁻³ µB**；
  - 器件学差异：普通交变磁体 V ∝ cosψ（ψ 为 N 与电场 E 夹角），共轴霍尔效应为 **V ∝ sinψ**——E ∥ N 时横向霍尔响应严格为零，E ⊥ N 时最大，Hall 信号沿与 E 和 N 都正交的轴向。

  **7. 推广性**：框架可推广到非共线磁体，"M_O 与 M_S 的 SOC 阶数至多差一阶"的规则仍成立；张量方法可望用于磁各向异性、电极化、量子输运（如自旋/轨道电流分离）。

  ## 潜在研究方向

  1. **实验验证缺口**：type III 中最著名的候选 RuO2 磁结构本身有争议（中子、µSR 有非磁基态的相反结论，见 PRL 132, 166702 (2024) 等），**其他 type III 体系的 AHE 实验验证仍然缺乏**——KV2Se2O 的共轴霍尔效应亟待输运实验确认。
  2. **动力学维度完全未触及**：本文全部是静态平衡性质。SOC 诱导磁化的**超快光致翻转动力学**、Néel 矢量的弛豫时间尺度、光场对 χ(θ,φ) 张量的时间调制效应，都是开放问题。
  3. **二维极限与层间耦合**：KV2Se2O 是金属性体材料，二维 type III 交变磁体是否存在、共轴霍尔效应在少层极限下是否保留，未讨论。
  4. **温度效应**：分类基于零温对称性，有限温度下自旋涨落对阶数差异和共轴构型的稳定性影响未知。
  5. **与非常规霍尔家族的接口**：共轴霍尔效应（sinψ 依赖）与已报道的 spontaneous Hall、bending Hall 等的关系，以及与自旋霍尔/轨道霍尔电流的分离测量，作者明确列为展望但无具体方案。
  6. **动力学/输运系数**：本文给出 σ_xy 等静态电导，对自旋-电荷转换效率、THz 发射等器件相关量的定量预测缺失。
  7. 共线条件的依赖：共轴效应要求 N 严格沿 [110]（或经 45° 设定偏移后的 [100]/[010]），**偏离高对称方向时共轴性如何退化**、磁各向异性能否把 N 钉扎在所需方向，需要材料级评估。

  ## 与林赛研究的关联

  - **交变磁 / 量子几何接口**：本文的核心量是 SOC 张量 χ(θ,φ) 与 Berry 曲率诱导的 M_O。我们组关注的量子几何（Berry 曲率/量子度规）在交变磁体中的角色，可以借用其 OSLG 分类来预言哪些磁空间群允许**动量依赖的 Berry 曲率热点**（KV2Se2O 中"能带交叉处产生显著 Berry 曲率"正是这类机制），这直接关联我们的量子几何读出方向。
  - **强场驱动 / 光致磁化**：SOC 微扰展开的语言可平移到光场——把 Ĥ_SOC 换成含时矢势耦合，Floquet 诱导磁化的自旋/轨道成分也可做阶数展开。type III 中"M_O 一阶、M_S 二阶"的结论提示：**圆偏振强场可能在净磁矩极小的情况下诱导可观的轨道磁化与横向输运响应**，这对我们"强场诱导交变磁体非常规响应"的设想是一个可检验的对称性预言。
  - **莫尔体系**：莫尔超晶格破缺晶格旋转对称性，type I/II/III 的旋转轴次判据在莫尔平带磁体中需要重新表述——SOC 张量展开 + 莫尔对称群（层群）的结合可能预言莫尔磁性中轨道/自旋磁化的新层次结构，与本组"莫尔强场探测"方向直接相关。
  - **阿秒 / 超快翻转**：共轴霍尔效应的弱场确定性 180° 翻转机制（消除简并与势垒竞争）提示一条路径：**用阿秒/飞秒脉冲实现对 Néel 序的超快确定性翻转并用电读出（sinψ 依赖的霍尔信号即为内置的读出头）**——器件读出与超快操控在此材料概念中天然一体化。
  - **HHG 角度**：交变磁体的 d 波自旋劈裂（>1 eV）提供了强动量依赖的带间跃迁通道，SOC 诱导的 Berry 曲率热点可能增强特定谐波阶的带间 HHG 产率；type III 体系"净磁矩近零但轨道响应强"恰好规避了磁偶极贡献的干扰，是干净的 HHG 量子几何探针候选。
  - 国内同行动态：刘奇航组（SUSTech）在自旋空间群方向的系列工作（含 Nature 652, 869 (2026)）正快速成为该领域范式，建议列入本组 NSFC 申请书相关工作引用的重点跟踪对象。
