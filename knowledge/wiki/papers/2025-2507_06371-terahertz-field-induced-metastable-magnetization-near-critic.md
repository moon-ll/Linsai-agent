• # 太赫兹场诱导 FePS₃ 临界区亚稳磁化

  ## 林赛的理解

  这篇工作是"光诱导隐藏磁相"方向里我目前读到的最完整的一篇：它把一个看似简单的现象——THz 脉冲打完以后磁信号不回去——用实验（磁光探测 + 圆二色直接证明净磁化）+ 第一性原理（自旋-声子耦合）+ Monte Carlo + 自旋动力学 + Ginzburg-Landau 理论 + 临界指数拟合，全链条闭环地解释了机制：不是热效应，不是载流子，是 Ω₂ = 3.27 THz 声子非线性驱动导致交换耦合重新平衡。对我们组来说，它的方法论意义大于现象本身——它给出了一个可复制的"找亚稳隐藏态"的配方：**去相变临界区，那里序参量涨落既放大光诱导序的幅度，又通过临界慢化延长它的寿命**（M ∼ √χ_zz，τ ∼ |T−T_N|^(−νz)）。这个思路可以直接移植到我们关注的强场超快调控问题上，尤其是 HHG 与自旋/晶格自由度纠缠的场景。

  ## 研究问题

  核心问题：能否利用强 THz 脉冲，通过**非热通道**（选择性激发低能集体模）在层状反铁磁体中诱导出一个**寿命足够长（亚稳）的隐藏磁相**，并理解其微观机制与稳定条件？

  具体拆解为三个子问题：
  - 在 FePS₃ 这种强自旋-晶格耦合的范德华反铁磁体中，共振驱动低能磁振子-声子模能否产生有限净磁化？
  - 该非平衡磁化的寿命有多长，为何能超过常规光诱导相（ps–ns 量级）？
  - 为什么磁化幅度和寿命都在 Néel 温度 T_N 附近发散？

  ## 研究背景

  - 光诱导功能相（超导、铁电、磁性、电荷密度波）是量子材料调控前沿，但绝大多数光诱导相在撤光后 ps–ns 内即回到平衡（如 [1,3,5,7,14]），亚稳案例极少（[2,4,15,16]），且高能光脉冲沉积大量热，破坏确定性控制。
  - THz 脉冲光子能量低，可在不激发电子跃迁的情况下把集体模驱动到大振幅，是干净的非热调控手段。
  - 涨落（热、量子、序参量）在相变点附近最强：欠掺杂铜酸盐赝能隙被认为源于反铁磁涨落 [8,9,10]；SrTiO₃ 中量子涨落阻止铁电长程序 [11]。这提示临界区可能是稳定非平衡态的"助推器"。
  - FePS₃ 属于 MPS₃ 蜂窝晶格范德华反铁磁家族，其两个突出特性使本研究可行：① Fe²⁺ 未淬灭轨道矩导致强单离子各向异性，加上最近邻铁磁 + 第三近邻反铁磁交换，形成 T_N = 118 K 以下的 zig-zag AFM 基态，磁矩沿面外方向；② 异常强的自旋-晶格耦合，低能磁振子与声子显著杂化 [37–40]，改变晶格即可操控磁性。

  ## 研究方法

  **实验体系与样品**
  - 化学气相输运法生长 FePS₃ 单晶（铁 99.99%、磷 99.99%、硫 99.998% 纯度，额外加 5 wt% 硫补偿蒸气压），SEM-EDX 与 XRD 确认化学计量；样品厚 20–60 µm，在高真空（∼10⁻⁷ torr）下解理。
  - Ti:sapphire 放大器：35 fs、800 nm、1 kHz；泵浦经 OPA（1300 nm）在有机晶体中光学整流产生 THz。
  - 共振激发"THz1"：宽带谱 0.2–6 THz，峰值场 ∼300 kV/cm；非共振"THz2"：谱集中在 <2 THz，峰值场 ∼600 kV/cm（LiNbO₃ 倾斜波前技术）。THz 光斑 180±10 µm FWHM，800 nm 探测光斑 54±2 µm。
  - 探测：800 nm 弱探测光测量透射偏振态的偏振旋转 Δθ 与椭偏率改变 Δη（分别探测复折射率实部/虚部各向异性），并用圆偏振探测光（σ⁺/σ⁻）直接测圆二色（CD），作为净磁化的直接证据；THz 光学整流致 Kerr 效应标记时间零点。

  **计算与理论**
  - 第一性原理（abinit，LDA+PAW，平面波截断 20 Ha、PAW 部分 40 Ha，Fe-d 轨道 Hubbard U = 2.7 eV（ACBN0 自洽确定），8×6×8 Γ 中心 k 网格；Wannier90 映射 + tb2j 磁力定理计算交换参数）。冻结声子近似计算自旋-声子耦合 α_ij，发现 α_ij 随原子间距快速衰减，仅最近邻显著。
  - 有效模型：H = Σ J_ij S_i·S_j − ΔΣ S_iz²（Heisenberg + Ising 型单离子各向异性）；声子位移 Q 线性调制交换 J_ij(Q) ≈ J_ij − α_ij Q。粗粒化到宏观变量 L（AFM 序参量）与 M（FM 序参量），只有 Ω₂ = 3.27 THz 声子通过 H_m-ph = gLM Q²² 耦合产生有限磁化。
  - Monte Carlo 模拟退火验证第一性原理交换参数；自旋动力学模拟验证声子位移诱导磁化积累。
  - Ginzburg-Landau 自由能 F = a_L/2 L² + b_L/4 L⁴ + a_M/2 M² + b_M/4 M⁴ + Ω₂/2 Q²² + gLM Q²，用随机/确定性动力学方程解释幅度发散与寿命。
  - 亚稳态寿命提取：利用泵浦间隔（τ_pump = 2 ms / 5 ms）与探测延迟（τ_probe = 1–4 ms）下泵浦关区信号累积模型拟合；临界指数幂律拟合 M(T)、τ_rise(T)、τ_decay(T)。

  ## 主要发现与核心结论

  **1. 太赫兹诱导亚稳净磁化，寿命超 2.5 ms**
  - 在 T_N = 118 K 处，THz 脉冲诱导的 Δθ(t) 与 Δη(t) 到 t = 175 ps 仍在增长且无饱和迹象（测量窗口上限 ∼175 ps）。
  - 泵浦前（pre-time zero）信号的出现表明弛豫时间与泵浦脉冲间隔（1 ms / 2 ms）可比；将 τ_pump 延长至 5 ms、τ_probe 扫描 1–4 ms 拟合得 **τ_decay ∼ 2.5 ms**（118 K），为迄今为止光诱导磁相中极长的寿命。

  **2. 磁化幅度与寿命都在 T_N 附近发散**
  - Δθ₀(T) 与 Δη₀(T)（t = 175 ps 处最大值）均在 T_N 达到峰值：Δθ₀(T) 跨 T_N 不对称，Δη₀(T) 对称。
  - 椭圆率通道的积分响应与静态信号显著偏离，证明存在**非热贡献**；而偏振旋转通道积分后与静态信号几乎重合，主要是 AFM 序参量的热弱化。Δθ₀ 与 Δη₀ 在 T_N 的尖锐发散表明 THz 场只造成无限小的自旋温升（显著热沉积会产生远离 T_N 的宽峰，如文献 [42] 的带隙上激发）。
  - 净磁化的直接证据：σ⁺/σ⁻ 圆偏振透射出现显著圆二色，温漂行为与椭圆率一致，说明光诱导态具有面外净磁化，且与虽被弱化但仍占主导的 zig-zag AFM 序共存。

  **3. 机制：Ω₂ = 3.27 THz 声子的非线性驱动**
  - 载流子激发被排除：THz 光子能量 < 25 meV 与带隙 ∼1.6 eV 相差 2–3 个数量级，多光子吸收被强烈抑制；隧道电离路径用非共振 600 kV/cm THz2 检验，未产生任何长寿命信号（Extended Data Fig. 6b）。
  - 场强依赖：Ω₁ = 2.64 THz 声子与磁振子 Ω_m = 3.69 THz 线性依赖场强（磁振子由 THz 磁场分量直接激发）；Ω₃ = 4.80 THz、Ω₄ = 7.51 THz 声子二次方依赖；**Ω₂ = 3.27 THz 声子呈线性+二次方叠加行为**，是唯一通过 H_m-ph = gLM Q²² 产生有限 M 的模式。
  - Ω₂ 声子实时空间运动改变 Fe–Fe 键长，增强一条 FM 链内交换、削弱相邻链内交换，从而诱导 M ≠ 0。Monte Carlo 模拟与 Ginzburg-Landau 极小化（L 恒定时）均给出非零 M 与 Q₂ 的全局极小。
  - 非线性激发的物理路径：纯光子过程因能量匹配约束不太可能；2D THz 光谱（Fig. S5）揭示 3.27 THz 模与 4.8 THz 红外活性声子的耦合，支持**红外活性声子介导的整流过程**。
  - 磁化符号由 Q₂L 的符号决定，与磁畴无关、外磁场也不能翻转 M——这与平衡铁磁体的直觉相反，且 FePS₃ 磁点群 2/m1′ 禁止压磁效应，故机制明确区别于动态压磁效应 [5,55]。

  **4. 临界涨落放大幅度并延长寿命**
  - Ginzburg-Landau 分析给出 M ∼ √⟨L²⟩ ∼ √χ_zz，即 **M(T) ∼ |T − T_N|^(−γ/2)**。实验拟合 ∆η₀(T)：T > T_N 侧 γ/2 = 0.53 ± 0.05，T < T_N 侧 γ/2 = 0.56 ± 0.05，与 3D Ising 期望值 γ/2 = 0.62 [53] 吻合良好。
  - 亚稳性来源：自由能存在 ±(M, Q₂) 简并对浅极小（图 4e 上），平衡涨落阻止净磁化积累（类比 SrTiO₃）；THz 诱导有限 Q₂ 位移后，涨落的 L 与 M 被稳定并迁移到由 Q₂L 符号选定的极小中（图 4e 中、下）。
  - 寿命由主导序参量的临界慢化决定：δL(t) ∼ e^(−t/τ)，τ(T) ∼ |T − T_N|^(−νz)。磁化 M(t) ≈ g/√(Ωb_M) δL(t) 继承同一临界动力学。拟合结果：上升时间临界指数 νz = 1.07 ± 0.27（T < T_N）、νz = 0.44 ± 0.07（T > T_N）；衰减时间 νz = 0.72（低温侧）、νz = 0.56（高温侧），低温侧接近 3D Ising 期望值 νz = 1.27。
  - 第一性原理计算四个声子模频率 Ω₁ = 2.67 THz、Ω₂ = 3.27 THz、Ω₃ = 4.77 THz、Ω₄ = 7.48 THz，与实验 THz 及拉曼数据高度一致；所得交换参数与近期中子散射数据 [35] 吻合良好。

  ## 潜在研究方向

  - **直接磁结构证据缺失**：偏振旋转、椭圆率、CD 足以表征非平衡态，但仍缺时间分辨 X 射线衍射或 XMCD [56–58] 的微观磁结构直接确认。
  - **Ω₂ 声子的独立实验确认**不足：间接通过场强依赖与 2D THz 光谱推断，需要更直接的模识别实验。
  - **简并极小验证**：Ginzburg-Landau 预言的 ±(M, Q₂) 双简并极小及其平衡涨落行为（Q₂ 与 L 符号关联）尚待实验验证（Supplementary Note 13 的机制细节）。
  - **寿命 > 2 ms 意味着可用常规输运探针**（如霍尔电阻）测量——作者自己指出这是走向自旋电子学应用的关键一步，但本文未做。
  - **普适性问题**：该机制（自旋-声子耦合驱动的交换重平衡 + 临界慢化稳定）是否适用于其他强自旋-声子耦合磁性材料 [51,52]（含非 MPS₃ 体系、含金属体系）值得系统检验；对 MPS₃ 家族其他成员（NiPS₃、MnPS₃ 交换符号不同）的预期行为是开放的。
  - **2 ms 的弛豫仍是宏观可测的"慢"态**：其退相干/衰减是否受缺陷、畴壁、层间耦合的微观限制，临界慢化解释的适用范围（离 T_N 多远仍成立）需要更系统的温度-场强相图。

  ## 与林赛研究的关联

  - **强场驱动与 HHG**：本文是"用强场非热通道改写基态"的范式案例。我们组 HHG 恰恰依赖强场把晶体电子态驱离平衡；THz 驱动声子改交换的套路提示：在 HHG 反演对称破缺体系中，声子驱动的交换重平衡可能是 HHG 强度各向异性随泵浦变化的微观来源之一，可作为 HHG 相位/偏振调控的新旋钮。
  - **莫尔体系接口**：莫尔范德华磁体（如转角 CrI₃、MnPS₃ 异质结）天然把"层间交换 + 应变可调"放在一起，本文的"特定声子改键长 → 改交换"机制在莫尔超晶格中因应变场空间结构化而可能有空间图案化的磁化写入——这是"莫尔 + 强场驱动"交叉点上值得试探的方向。
  - **阿秒/超快时间分辨**：本文用的是 175 ps 窗口 + 泵浦累积模型来外推 ms 寿命，时间分辨上很粗糙；我们若把阿秒抽运探测或太赫兹发射谱接入此类临界区磁化动力学，可以测到 M 建立过程的 fs–ps 细节，直接检验"涨落辅助弛豫进选定极小"的动力学图像。
  - **量子几何/交变磁接口**：FePS₃ 的 zig-zag 序、强自旋-轨道耦合（未淬灭 Fe 轨道矩）与其大自旋-声子耦合同源 [67]；交变磁（altermagnet）与量子几何性质对交换网络的对称性极敏感，声子动态改写交换键强弱差（一条链增强、相邻链削弱）本质上是在时间域调制反铁磁的键各向异性——这为"用光把交变磁体切换到暂稳铁磁样态"提供了具体的微观通道，可与我们已有的一般性 HHG 交错磁探测提案（general-berry-mnps3-rashba 等）对接。
  - **方法论直接可移植**：临界区 + 选择性模驱动 + 序参量涨落放大的配方，不局限于磁性——对我们评估任何"相变附近的光诱导隐藏态"设想（含电荷密度波、铁电、激子绝缘体）都是一个可写进申请书的方法论框架。

## 研究问题（Research Question）

论文的核心问题是：**能否在层状范德华反铁磁体 FePS₃ 中，通过太赫兹（THz）光场的非热驱动，将原本反铁磁（AFM）的基态诱导到一个具有有限磁化强度的亚稳态，并使其寿命远超常规的超快时间尺度（达到毫秒量级）？**

更具体的科学问题包括：(1) 单一特定声子模式的相干位移能否有效调制磁交换耦合，从而在奈尔温度（T_N）附近产生具有有限磁化强度的非平衡基态？(2) 反铁磁序的临界涨落（即接近 T_N 时序参量的增强涨落）是否能够放大并稳定这一光致亚稳磁化态？作者的中心论点是：在反铁磁相变临界点附近，光致亚稳相既具有增强的磁化幅值，又具有异常长的寿命（>2.5 ms），这是临界涨落放大非线性响应的直接体现。

## 研究背景（Background）

研究背景建立在"光致相（photo-induced phase）"这一凝聚态前沿领域之上：在超导、铁电、磁性、电荷密度波等体系中已观察到光致新相，但大多数光致相在光关闭后会在超快时间尺度（皮秒到纳秒）内弛豫回平衡态，这严重限制了实际应用。本文的科学动机正是突破这一寿命瓶颈。

材料背景聚焦于 MPS₃（M = Fe, Ni, Mn）家族——一类蜂窝格子范德华反铁磁体，其反铁磁序可稳定到原子层极限。选择 FePS₃ 的两个关键物理依据：(1) Fe²⁺ 离子由于未淬灭的轨道矩，存在显著的单离子各向异性（来自自旋-轨道耦合）；(2) FePS₃ 具有特别强的自旋-晶格相互作用，表现为低能磁振子与声子模式的强杂化（magnon-phonon hybridization），这已被 magneto-Raman 实验证实。

前人工作中已用 THz 驱动观察到 FePS₃ 中 4.8 THz 红外活性声子，并通过应变工程诱导出反铁磁-铁磁转变。但本文与这些"高于带隙（above-gap）光激发"工作有本质不同——THz 光子能量（<25 meV）远小于带隙（~1.6 eV），多光子吸收被抑制 2-3 个数量级，因此是真正的非热驱动路径。

## 研究方法（Methods）

本文采用**实验 + 多尺度理论计算**的协同路线：

**实验方面：** 用强场单周期 THz 脉冲泵浦 FePS₃ 样品（THz 焦点尺寸 180±10 μm FWHM），然后用 magneto-optical（磁光）探针测量时间分辨磁化响应。THz 场的磁场分量直接驱动磁振子模式（线性依赖关系表明是直接磁激发而非热效应），并通过监测磁圆二色性变化提取磁化强度 Δη(t) 的时间演化。通过对比"时间零点前"与"时间零点后"的信号比值拟合出 τ_decay。

**理论方面：** 采用三层次理论框架：(1) 第一性原理计算（DFT+U）描述 3.27 THz 特定声子模式（Ω₂）的位移模式及其对 Fe-Fe 交换耦合 J 的调制；(2) 经典蒙特卡洛模拟（基于 Heisenberg 自旋哈密顿量 H_m-ph = gLMQ₂）求解有限温度下的平衡磁化；(3) 随机 Ginzburg-Landau 方程（stochastic GL）和确定性 GL 解析解共同描述接近 T_N 时序参量的临界涨落行为。从粗粒化理论（coarse-grained theory）中证明只有 Ω₂ = 3.27 THz 声子模式能通过 L·Q₂ 形式的耦合产生有限磁化。

## 主要发现与核心结论（Main Results）

**核心定量发现：**

1. **THz 诱导亚稳磁化寿命超过 2.5 毫秒**——比典型光致相寿命（皮秒-纳秒）长 6-9 个数量级，是该类非热光致磁相的最长记录之一。

2. **温度依赖性呈现临界增强：** 随着温度接近 T_N，亚稳态的磁化幅值 Δη 和寿命 τ_decay 均呈现临界发散行为（critical divergence），拟合为 M(t) ∝ (T_N - T)^(-α) 的幂律形式。这一现象强烈支持"临界涨落放大"机制。

3. **关键声子模式：Ω₂ = 3.27 THz**——从粗粒化理论对所有声子模式的扫描中发现只有该模式通过 H_m-ph = gLMQ₂ 形式的耦合能产生有限磁化。该模式的位移 Q₂ 的符号与轨道序参量 L 的符号绑定，使得 Q₂·L 的乘积只由材料本征参数决定，从而解释了 THz 驱动的高效性。

4. **机制图景：** THz 磁分量直接线性激发磁振子；THz 电场驱动 3.27 THz 声子位移 → 调制交换耦合 J → 在 T_N 附近产生有利于"有限磁化基态"的新自由能极小 → 临界涨落放大该极小值的捕获效率和稳定时间。

5. **定性发现：** THz 驱动与之前高于带隙的光激发工作有本质区别——多光子吸收被 1.6 eV vs <25 meV 的能量失配抑制 2-3 个数量级，因此这是真正的非热路径操控磁基态。

## 潜在研究方向（Future Directions）

**研究局限性与注意事项：**

1. **单一材料验证：** 结论在 FePS₃ 上得到验证，但 H_m-ph = gLMQ₂ 这种动态调制交换耦合的机制是否在其他 MPS₃ 家族成员（NiPS₃, MnPS₃）或其他具有强自旋-声子杂化的层状磁体中普适，仍未明确。本文指出该机制"可推广"到其他强自旋-声子耦合材料，但缺乏跨材料验证。

2. **THz 场强的标定与可重复性：** THz 焦点尺寸和场强对实验结果影响显著，但 180 μm 焦点下样品均匀性、可能的热效应（尽管已通过与 above-gap 实验对比排除主要热贡献，但局部光热无法完全忽略）等细节需要更多实验复现。

3. **未解决的开放问题：**
   - 临界点附近的毫秒级寿命上限在哪里？是否存在类似的动力学瓶颈？
   - 亚稳磁化态的空间分布（是否均匀，还是形成畴结构）？
   - 该机制能否应用于更快的 THz 脉冲（如周期量级）以及更高谐波阶次的相干控制？
   - 该亚稳态与"光致隐藏量子态（hidden quantum states）"之间是否存在更系统的联系？
   - 在 T_N 以下的整个温度范围内，临界发散的具体指数 α 与 Heisenberg 模型的普适类关系如何？

4. **应用前景：** 论文建立了"临界点附近序参量涨落增强区"作为寻找亚稳隐藏量子态的新搜索策略，这一原则性思路可推广到其他相变附近的量子材料（如电荷密度波、超导、铁电）的非热光控研究。

## 研究方法（方法卡）

**方法**：临界点附近 THz 场致亚稳磁化（FePS₃ 强 THz + tr-MOKE/CD + 冻结声子电声耦合 DMFT 链）

**原理**：CVT 生长 FePS₃（+5 wt% S 补偿蒸气压）单晶 20–60 µm；两路强 THz：宽带 THz1（0.2–6 THz，~300 kV/cm）与非共振 THz2（<2 THz，~600 kV/cm，LiNbO₃ 倾斜波前）；探测 800 nm 偏振旋转 Δθ 与椭偏率 Δη（复折射率实/虚部各向异性）+ 圆偏振探测直接测圆二色作净磁化证据；理论：abinit LDA+PAW（U=2.7 eV ACBN0 自洽）+ Wannier90/tb2j 磁力定理，冻结声子近似算自旋-声子耦合 α_ij（仅最近邻显著）；有效模型 Heisenberg+Ising（J_ij(Q)≈J_ij−α_ij Q）粗粒化到 L/M 变量——仅 Ω₂=3.27 THz 声子经 H_m-ph=gLM Q² 耦合产生有限磁化（THz 场致亚稳磁化机制）。
