## 阅读笔记

### general-berry-berry-20261107

Direct Observation of Chirality-Dependent Berry Curvature Dipole via Cross-Axial Nonlinear Hall Effect in Trigonal Te — Jaehyun Lee, Junhee Shin, Daryll J. C. Dalayoan, Miju Park, Changhee Sohn, Gang Qiu, Noejung Park, Binghai Yan, Tony Low, Hosub Jin, Seon Namgung (UNIST / Univ. Minnesota / Penn State), arXiv 2026-10-09, cond-mat.mes-hall, 41 页。

### 研究问题（Research Question）
核心问题是：能否通过**交叉轴向（cross-axial）非线性霍尔效应**直接探测三角相碲（trigonal Te）的 Berry curvature dipole，因为先前报道的 Te NHE 测量都在面内构型进行、而**面内构型中内禀 BCD 贡献因对称性为零**，故并未真正触及 BCD。作者追问的是：Te 中是否存在随晶体手性（左右手）反号的 BCD，以及该 BCD 的微观来源是什么。

### 研究背景（Background）
Berry曲率与量子度规决定材料的物理与拓扑性质：线性响应霍尔电导由布里渊区 Berry 曲率积分决定，shift current 由 shift vector 决定，而量子度规张量已用偏振分辨 ARPES 测得，shift current 已在铁电半导体的太赫兹电磁谱中直接观测。NHE 因不需要外磁场或磁有序、只需破坏反演对称性，成为探测 BCD 的有力手段，并可用于探测铁电/反铁电相变、高场高压等常规 SHG 不适用的极端条件。三角 Te 是非磁性手性半导体，已有手性相关输运、非互易输运、负磁阻、Weyl 电子性质与手性诱导自旋选择性（CISS）等丰富研究；Te存在两个不可约对映体（手性空间群 P3₁2₁ 对应 RH，P3₂2₁ 对应 LH），提供了天然的对称性旋钮。

### 研究方法（Methods）
器件：水热法合成 Te 纳米片（105 mg Na₂TeO₃ + 550 mg PVP + 3.65 mL25% NH₄OH + 1.94 mL 80% 水合肼，30 mL Milli-Q 水，180 °C 密封 30 h，3500 rpm 离心 5 min，洗三次）；干法转移 h-BN 与 Te 叠层，EBL 制蜘蛛网底电极，h-BN 仅露出 1 μm × 1 μm 金属接触区以便测量沿面外 ŷ 方向的二阶横向电压；STEM判定对映体。测量：注入 77.7 Hz 交流电流 I_ω（θ 为电流方向与 c 轴夹角），按 V⊥,out₂ω/(I_ω)² = 2 R_xx R_yy R_zz /(L_x² A_y) χ_yxz sinθcosθ 拟合，并从线性霍尔用单带模型提取迁移率进而得散射时间。理论：第一性原理 DFT 计算 Berry 曲率与 BCD，并用电阻率标度 V⊥,out₂ω/(I_ω)² = β + γρ_l + δρ_l² 区分内禀/外禀机制。

### 主要发现与核心结论（Main Results）
对称性分析是全文关键：Te 的 BCD 为对角张量 **D_xx = D_yy = −D_zz/2**、非对角元全零，由于 ε_abc 在两指标相同时为零，内禀 BCD 只对 **χ_yxz** 有贡献，而 **χ_xxx 完全不含内禀 BCD**——故交叉轴向测量是直接探测 BCD 的必要手段。实验上 LH-Te 与 RH-Te 的 **|χ_yxz|/|χ_xxx| = 2.28 与 2.81**，两者符号相反、幅度相近，NHE 电压在所有角度均与 (I_ω)² 线性，确证二阶起源。DFT 显示 H 点附近存在拓扑非平凡的**刺猬（hedgehog）型 Berry 曲率纹理**，RH 对映体变为 anti-hedgehog；(∂ₓΩₓ, ∂_yΩ_y, ∂_zΩ_z) 在 LH 沿 (−,−,+) 方向、RH 沿 (+,+,−)；时间反演伙伴 H 与 H′ 保持相同纹理 Ω(H+q) = −Ω(−H−q) = −Ω(H′−q)。由实验反推 BCD 得 **D_xx = −0.0676（RH）、+0.0616（LH）**，散射时间 τ = **294 fs（RH）、308 fs（LH）**，有效质量 m* = **0.150 m₀**，落在理论计算范围内。电阻率标度给出：cross-axial 构型下 γ 与 δ 同号（若 side-jump 或 skew 主导则应反号），故**内禀 BCD 主导**；而面内构型 γ、δ 反号、由 side-jump 主导。

### 潜在研究方向（Future Directions）
论文自陈的边界是"精确量化各机制贡献仍然困难"，本工作用 cross-axial 与 in-plane 的标度符号差异作间接判据而非直接分离；电阻率标度拟合依赖残余电阻率 ρ_l0 与各系数 C 的联合拟合，参数存在简并性。作者指出应用前景包括基于对映体的相反向整流器、以及对映体界面拓扑转变研究。此外 CH 偏置与接触几何的有限尺寸效应、以及 DFT 与实验 BCD 数值仍存在可辨差异（虽落在同一量级），均留待进一步改进。

## 研究方法（方法卡）

**方法**：三角碲手性依赖 Berry curvature dipole 的交叉轴向非线性霍尔直接观测（对称性张量分析 + 面外二阶横向电压 + 电阻率标度内禀/外禀判别 + DFT hedgehog 纹理）

**原理**：先前 Te NHE 测量均在面内构型——而面内构型中内禀 BCD 贡献因对称性为零、并未真正触及 BCD；对称性分析为全文关键：Te 的 BCD 为对角张量 D_xx=D_yy=−D_zz/2、非对角元全零，ε_abc 在两指标相同时为零——内禀 BCD 只对 χ_yxz 有贡献、χ_xxx 完全不含内禀 BCD，交叉轴向（沿 c 轴注入电流 + 测面外 ŷ 二阶横向电压）是直接探测 BCD 的必要手段；实验 LH/RH 对映体 |χ_yxz|/|χ_xxx| = 2.28 与 2.81、符号相反幅度相近、NHE 电压与 (I_ω)² 线性确证二阶起源；DFT 显示 H 点附近拓扑非平凡刺猬（hedgehog）型 Berry 曲率纹理（RH 对映体为 anti-hedgehog；∂ 纹理 LH 沿 (−,−,+)、RH 沿 (+,+,−)；时间反演伙伴保持相同纹理）；电阻率标度 V⊥,out₂ω/(I_ω)² = β + γρ_l + δρ_l²：cross-axial 构型 γ 与 δ 同号（side-jump/skew 主导则应反号）→ 内禀 BCD 主导，面内构型 γ、δ 反号、由 side-jump 主导。
