• # Lattice-mismatch Moiré laser with strong flatband coupling

  ## 林赛的理解
  这项工作把 Moiré 光子学从“转角”拓展到“晶格失配”维度，给我最直观的启发是：晶格失配 Moiré 腔提供了一种**频率鲁棒、Q 增强显著、且可通过单元胞尺寸独立调控耦合强度**的纳米激光平台。对我们组而言，它解决了一个长期困扰——转角 Moiré 的平带频率随转角剧烈漂移（数十 THz），而晶格失配方案能把漂移压到约 2 THz 以内，同时 Q/Q_single 可提升约两个数量级。这意味着，如果我们想利用 Moiré 平带做**强场驱动、阿秒产生或交变磁/量子几何探针**，晶格失配腔可能是更稳定、更可批量重复的光学载体。中心孔工程进一步把六极模从简并偶极模中“剥离”出来，实现单模低阈值激光，这为我们将来把 Moiré 腔作为**非线性频率转换器或量子发射体耦合腔**提供了可直接借鉴的模式选择策略。

  ## 研究问题
  1. 能否在光子体系中实验实现**晶格失配 Moiré 腔**的强平带耦合，而不仅仅停留在转角 Moiré 框架内？
  2. 与转角 Moiré 腔相比，晶格失配 Moiré 腔的平带频率、Q 因子和模式耦合强度如何随单元胞尺寸变化？
  3. 如何通过结构工程（如中心孔尺寸）在保持强胞间耦合的同时，实现**单模低阈值平带激光**？

  ## 研究背景
  Moiré 超晶格由两个周期性晶格以微小错位叠加形成，可产生超周期性与平带，已在凝聚态中催生超导、关联绝缘体、量子反常霍尔效应等涌现现象。在光子学中，Moire 结构同样被预言和观测到具有平带特征，可增强光-物质相互作用，实现高 Q、小模式体积纳米腔。然而，过去光子学器件几乎 exclusively 采用**转角 Moiré** 构型，**晶格失配 Moiré** 尚未被实验探索。同时，平带的强胞间耦合不能仅由能带测量推断，需要细胞分辨光谱等直接证据；此外，将平带精确调至目标频率并嵌入光子带隙，对实际激光应用至关重要。

  ## 研究方法
  - **仿真**：采用 COMSOL Multiphysics Wave Optics Module 进行三维有限元法（FEM）计算，使用 Floquet 周期边界条件计算能带，散射边界条件计算单胞模式。InGaAsP 平板折射率设为 3.33，空气为 1.0。
  - **结构设计**：比较转角 Moiré（δθ = 3.48°, 4.41°, 6.01°）与晶格失配 Moiré（δa = 30, 40, 60, 102, 120 nm）。平板厚度 h = 257 nm，孔直径 d = 212 nm（仿真）或 216/255 nm（实验）。
  - **制备**：在含 257 nm InGaAsP 多量子阱外延片（中心发射波长 ~1.5 μm）上，通过电子束光刻（30 keV）定义孔图案，ICP-RIE 刻蚀，再用 3:1 HCl:H₂O 选择性湿法刻蚀 InP 牺牲层，得到悬空光子晶体平板。
  - **光学测量**：980 nm 脉冲激光二极管泵浦，重复频率 1 MHz，占空比 1%，光斑直径 ~29.2 μm。使用 ×50（N.A. = 0.42）和 ×100（N.A. = 0.85）物镜收集光致发光（PL）；能带测量在傅里叶面用垂直狭缝空间滤波后送入光谱仪，单次可测 k 范围分别为 2.63 μm⁻¹ 和 5.44 μm⁻¹，光谱分辨率 ~0.4 nm。

  ## 主要发现与核心结论
  - **转角 vs 晶格失配的对比**：转角 Moiré 中，随 δθ 增大，平带频率偏移 Δf 最大达 **26.67 THz**，而 Q/Q_single 最大仅约 **26.72**。晶格失配 Moiré 中，δa 变化时 Δf 仅 **1.89 THz**，Q/Q_single 可达约 **300**。
  - **平带演化**：在晶格失配 Moiré 中，随 δa 从 30 nm 增至 60 nm，平带从与色散带重叠，到接触带边，最终形成完全嵌入光子带隙的带内平带。
  - **模式特征**：δa = 60 nm 的晶格失配腔存在三个平带模式——一个六极模（hexapole）和一对简并偶极模（px、py），可用紧束缚模型理解。
  - **能带测量验证**：单元胞尺寸 **2.40 μm**（δa = 120 nm，晶格常数 480 nm 与 600 nm）的样品中，PL 能带测量在 kx ≈ 0 处观察到三个平带，频率约 **193.8 THz**；第一布里渊区约 **3.02 μm⁻¹**，与计算高度吻合。
  - **细胞分辨光谱验证强耦合**：
    - **3.06 μm** 单元腔（δa = 102 nm，晶格常数 510 nm 与 612 nm，孔径 d = 255 nm）：七个单元胞中一致出现三个峰，波长分别为 **1572.8 nm**（hexapole）、**1574.6 nm**（px）、**1576.4 nm**（py）。
    - **4.32 μm** 单元腔（δa = 60 nm）：主导峰在单元胞间变化范围宽达 **1478.0 nm 至 1497.1 nm**，表明耦合较弱。
  - **中心孔工程实现模式选择**：将中心孔从 1.0 缩至 0.3 时，hexapole 频率稳定在 ~**193.2 THz**，px/py 频率从 **193.8 THz** 降至 **179.0 THz**；hexapole Q 维持在约 **1.5 × 10⁴**，而 px/py Q 从 **3180** 降至 **445**。
  - **实验光谱与模式分离**：0.6 d 腔测得尖锐峰 **1449.6 nm** 与宽峰 ~**1550.5 nm**，间距 **Δλ = 100.9 nm**；0.8 d 腔间距 **Δλ = 55.5 nm**。
  - **单模激光演示**：
    - 0 d 腔单峰 **1467.5 nm**；
    - 0.4 d 腔单峰 **1464.7 nm**；
    - 0.6 d 腔尖锐峰 **1471.6 nm** + 宽峰 ~**1563.5 nm**；
    - 0.8 d 腔尖锐峰 **1474.6 nm** + 宽峰 ~**1527.8 nm**。
  - **激光阈值与线宽**：所有四种腔的阈值约为 **1–2 kW cm⁻²**，线宽受光谱仪分辨率限制约为 **0.4 nm**。

  ## 潜在研究方向
  - **耦合强度的尺寸阈值**：4.32 μm 单元腔的实验耦合弱于仿真预期，说明实际实现强胞间耦合所需单元胞尺寸可能比理论预测更小，需进一步量化缺陷、有限阵列尺寸和辐射损耗的影响。
  - **转角-晶格失配联合参数空间**：文章仅分别讨论了两种极限，若同时引入 δθ 与 δa，可能开启新的平带工程自由度。
  - **连续波与电泵浦**：当前为光脉冲泵浦，未来可探索电注入、连续波操作及热稳定性。
  - **与量子发射体集成**：平带腔的强局域与大 Q 可用于 Purcell 增强与 cavity QED，需验证单量子点与晶格失配 Moiré 腔的耦合。
  - **非线性光学扩展**：平带增强的光-物质相互作用可推动二次谐波、高次谐波等非线性过程。
  - **拓扑与量子几何**：晶格失配 Moiré 的布洛赫波函数几何性质、Berry 曲率与平带之间的关系尚待研究。
  - **规模化与均匀性**：细胞分辨光谱显示单元胞间仍有强度涨落，大面积阵列的可重复性需要工艺优化。

  ## 与林赛研究的关联
  - **强场驱动与 HHG/阿秒**：晶格失配 Moiré 腔的平带增强光-物质相互作用和高 Q，可为固体高次谐波产生提供一种可控的周期性驱动平台；强场脉冲泵浦下，平带电子态的非线性响应对应着丰富的阿秒动力学。
  - **莫尔与量子几何**：Moire 平带附近的布洛赫波函数几何（Berry 曲率、量子度规）可能影响强场跃迁选择定则，这与我们关注的“量子几何响应”方向直接相关。
  - **交变磁/关联物态探针**：高 Q Moiré 腔可作为局域电磁场增强器，用于探测低维关联体系或交变磁材料的超快光学响应。
  - **实验接口**：腔模频率位于 1.4–1.6 μm 电信波段，与我们常用的近红外强场激光系统兼容，便于开展泵浦-探测或谐波产额实验。

**方法**：晶格失配莫尔激光器（COMSOL FEM + InGaAsP 悬空光子晶体平板 + EBL/ICP-RIE + 980 nm 泵浦 PL/傅里叶面测量）
