• # 交变磁中非线性热霍尔效应的对称性选择定则：量子度规与 C₂ 旋转对称性的作用

  ## 林赛的理解

  这篇工作给我的是一把"筛子"——它把非线性热霍尔响应是否需要做实验，压缩成一个可以一眼判别的对称性问题：**κ_xyy 非零 ⟺ 非平庸量子度规 ∧ M_x 破缺 ∧ C₂ 破缺**。这不是数值上的优化建议，而是硬性的存在性判据。对我们"强场超快读出交变磁序参量"这条线，这篇论文的价值在三个层面：其一，它证明了量子度规（而非仅贝里曲率偶极）是交变磁中可观测的几何可观测量，且与 C₂ 对称性直接挂钩——这正是我们超快探测想要读出的"序参量与对称性的对应关系"的理论版本；其二，Mn₅Si₃ 作为 d 波平台被论文点名，这个体系恰是我们方法素材库中 MNLHE（磁非线性霍尔效应）的实验载体，热响应可作为电学 MNLHE 的交叉验证通道；其三，它的选择定则反过来为"超快手段在交变磁中发现对称性破缺"提供了可证伪的靶子——如果超快瞬态测量让 κ_xyy 类型响应从闭合到打开，那就是 C₂ 破缺的直接时域证据。方法上，论文的紧束缚构造、分部积分正则化、自适应子网格数值方案都是可以搬进我们计算工作流的标准零件。

  ## 研究问题

  论文要回答的核心问题是：**在交变磁体（altermagnets）中，由量子度规主导的内禀二阶非线性热霍尔效应（nonlinear thermal Hall effect），其非零响应需要满足怎样的对称性选择定则？** 具体而言，为何同为交变磁的 d 波体系（如 Mn₅Si₃）能给出非零 κ_xyy，而高对称的 g 波体系（如 CrSb、NiS）中该响应严格为零？围绕这个中心问题，论文给出三个子问题：

  1. 两能级有效哈密顿量中，量子度规 g_ab 非零的代数条件是什么（为何必须有轨道杂化/自旋轨道耦合）？
  2. 镜像对称 M_x 与二重旋转对称 C₂ 各自如何约束三阶输运张量 κ_abc（允许哪些分量、禁止哪些分量）？
  3. d 波与 g 波交变磁在 C₂ 对称性上的本质差异（宇称混合轨道杂化 vs 纯奇宇称 gx）如何决定 κ_xyy 的存在与否？

  ## 研究背景

  - **交变磁相的定义与现状**：交变磁是近年确认的新磁相——共线反铁磁序 + 动量依赖的强自旋劈裂，但宏观不破坏时间反演对称 [1–7]。与常规反铁磁的全局 Kramers 简并不同，其自旋劈裂具有按偶次谐波分类的角动量结构：d 波（l=2）、g 波（l=4）、i 波（l=6）[2,8]。ARPES 已在多个候选材料中直接观测到巨自旋劈裂：MnTe [9–11]、CrSb [12]、Mn₅Si₃ [13]。
  - **线性输运已被广泛研究**：反常霍尔效应 [3,14,15,17]、自旋劈裂效应（spin-splitter）[18–20]、新奇磁电阻行为 [21–23] 均已有理论与实验报道。
  - **非线性输运的几何本源**：电学二阶非线性霍尔效应的两个内禀几何驱动量——贝里曲率偶极（BCD）[24–27]与贝里联络极化率（BCP）[28–32]——已被系统研究；在 PT 联合对称（贝里曲率为零）体系中，BCP 是主导内禀贡献 [29,30,33]，而 BCP 与量子度规内禀关联 [45,46]。
  - **交变磁中的关键实验动机**：d 波交变磁 Mn₅Si₃ 中发现的大磁非线性霍尔效应（MNLHE）[16]证明非线性电输运是交变磁对称性破缺的灵敏实验指纹 [34–36]。
  - **明确的空白**：尽管电学领域进展迅速，**内禀非线性霍尔物理向热学域的拓展尚属空白**；交变磁的线性热霍尔已有理论研究 [37–39]，但二阶非线性热霍尔的几何起源需要系统澄清，且 Luttinger 形式框架 [40–44] 下交变磁的显式对称约束从未被完整给出。本文正是填补这一空白：建立 C₂ 作为宏观几何热输运"守门员"（gatekeeper）的选择定则。

  ## 研究方法

  本文为理论方法密集型工作（紧束缚模型 + 对称性证明 + 数值验证），按方法卡格式整理：

  **原理**：用两能级赝自旋哈密顿量 H(k) = g(k)·σ 构造 d 波与 g 波交变磁模型，计算量子度规 g_ab 与非线性热霍尔电导 κ_xyy；通过张量对称性分析与幺正算符证明，确立 κ_xyy 非零的充分必要条件。

  **模型与参数表**（数值原样，出自原文式 (1)–(9) 与 Fig. 1–4）：

  - 通用哈密顿量：H(k) = g_x(k)σ_x + g_z(k)σ_z（设 g_y = 0），能带 ε_±(k) = ±G(k)，G = √(g_x² + g_z²）（式 1）
  - **d 波模型**（动机：Mn₅Si₃ 正交相 [15]）：
    - g_z(k) = Δ(cos k_x − cos k_y)（式 7）
    - g_x(k) = 2t₁ sin k_x sin k_y + λ sin k_y（式 8）——含宇称偶轨道混合项 2t₁ sin k_x sin k_y（C₂ 破缺来源）+ 宇称奇 SOC 项 λ sin k_y（M_x 破缺来源）
    - 节点线沿 k_x = ±k_y
  - **严格二维 g 波模型**：
    - g_z(k) = Δ sin k_x sin k_y (cos k_x − cos k_y)（式 9）
    - g_x(k) = λ sin k_y
    - Γ 点 Taylor 展开：g_z ≈ −(1/8)Δk⁴ sin 4θ，领先项严格 O(k⁴)、四重角向依赖、偶函数 g_z(−k) = g_z(k)（式 10–13）；节点为复杂的八重结构
  - **量子度规代数推导**：从通式 g_ab = [G²(∂_a g·∂_b g) − (g·∂_a g)(g·∂_b g)] / 4G⁴（式 2）逐项展开相消，得紧凑形式 g_ab = (g_z∂_a g_x − g_x∂_a g_z)(g_z∂_b g_x − g_x∂_b g_z) / 4(g_x² + g_z²)²（式 6）；结论：g_ab ≠ 0 严格需要轨道混合或 SOC 驱动的带间耦合
  - **热输运形式体系**：Luttinger 代换 eE → ((ε−μ)/T)∇T，将电学 BCP G_xy^(n) = n·g_xy/(2G) [28,40] 映射为热学对应量；原始积分 κ_xyy = (1/ℏT²)∫_BZ d²k/(2π)² Σ_n W(ε_n) ∂_{k_y} G_xy^(n)，热权重 W(ε) = (ε−μ)²f₀(ε)（式 16）；节点附近 G_xy ∝ 1/G³、导数 ∝ 1/G⁴ 的发散经**分部积分**正则化，链式法则 ∂_{k_y} = ℏv_y ∂_ε，W'(ε) = 2(ε−μ)f₀(ε) + (ε−μ)²f₀'(ε)（式 17–18），得无发散稳健公式 κ_xyy = −(1/ℏT²)∫ d²k/(2π)² Σ_n G_xy^(n) W'_n(ε) v_{y,n}（式 19）
  - **对称性证明工具**：M_x 反射下 κ_abc → (−1)^{n_x} κ_abc，迫使 κ_xxy = κ_yxx = κ_yyy = 0，仅 κ_xxx、κ_xyy、κ_yxy 允许；C₂ 旋转下 κ_abc → −κ_abc，若 C₂ 守恒则 κ_abc ≡ 0；用 U = σ_z 赝自旋幺正算符验证 σ_z H(k) σ_z = −g_x(k)σ_x + g_z(k)σ_z（式 14–15），对 g 波模型证得 σ_z H(k) σ_z = H(−k)（C₂ 严格守恒 → κ_xyy = 0），d 波因 g_x(−k) ≠ ±g_x(k) 而 C₂ 破缺、κ_xyy 存活
  - **数值计算设置**：自适应子网格修补（adaptive sub-grid patching）分辨节点奇点；参数 Δ = 1.0，t₁ = 0.5，μ = −0.5，T = 0.05，展宽 η = 0.005（能量单位），g 波破缺对照用偶宇称参数 λ_even 扫描 0.0–0.5（Fig. 4）

  **适用边界**：Luttinger 型对应关系在线性区由 Luttinger [40] 与 Qin–Niu–Shi [41] 严格建立，非线性区的电学 BCP 公式已有实验验证 [33]，但**纳入磁化电流修正 [41,42] 与二阶位置偏移（positional shifts）的严格非线性量子动理学仍是开放问题**——本文只处理主导对称性保护输运边界的领先阶几何贡献。C₂ 选择定则是点群对称对三阶张量的作用结果，晶格无关（对六角晶格的 CrSb、NiS 等实际 g 波体系同样成立），但具体材料是否破缺 C₂ 取决于 SOC 微观细节，须逐材料第一性原理判定。

  **代表作**：Luttinger, Phys. Rev. 135, A1505 (1964) [40]；Qin, Niu & Shi, Phys. Rev. Lett. 107, 236601 (2011) [41]；Provost & Vallee 量子度规通式 [45]。

  ## 主要发现与核心结论

  1. **三条件选择定则**：非零内禀非线性热霍尔电导 κ_xyy 需要同时满足——(i) 非平庸量子度规；(ii) M_x 破缺；(iii) C₂ 破缺。其中 **C₂ 是宏观几何响应的"守门员"**。
  2. **代数层面**：量子度规非零严格要求带间耦合（轨道混合或 SOC），由式 (6) 的紧凑形式直接可见。
  3. **d 波 vs g 波的本质对比**：d 波模型的宇称偶项 2t₁ sin k_x sin k_y 使 g_x(−k) ≠ ±g_x(k)，幺正等价 σ_z H(k) σ_z = H(−k) 被破坏，C₂ 破缺，κ_xyy 存活；g 波模型 g_z(−k) = g_z(k)、g_x(−k) = −g_x(k)，C₂ 严格守恒，σ_z H(k) σ_z = H(−k) 精确成立（式 14–15），**κ_xyy 被数学上强制为零**。
  4. **解析标度律**：d 波模型中 φ_xφ_y ≈ F(k)·(λΔt₁)，F(k) 为动量偶函数，BZ 积分不抵消，得 **κ_xyy ∝ λΔt₁**（对破缺参数 λ 线性）。
  5. **数值验证**（Δ = 1.0，μ = −0.5，T = 0.05，η = 0.005，d 波 t₁ = 0.5）：
     - d 波：κ_xyy 随 λ 单调线性增长（Fig. 4a），与解析标度一致；
     - g 波：C₂ 守恒时（λ_even = 0）κ_xyy 锁定在数值零（**∼10⁻¹⁹**）；引入偶宇称 C₂ 破缺项（λ_even ≠ 0）后信号急剧恢复，单调增长至与 d 波响应同量级（Fig. 4b）。
  6. **几何热点图像**：量子度规迹 Tr(g_ab) 在节点线附近形成对数标度下的奇点结构，是宏观输运的源（Fig. 2）；BCP G_xy 的纹理对称性直接可视化 C₂ 保护——d 波非对称（破缺），g 波完美点反对称（点对称结构强制全积分为零，Fig. 3）。
  7. **材料预测与实验判据**（论文强调晶格无关的一般性）：
     - **RuO₂**：若理想金红石结构保持 C₂，内禀非线性热霍尔效应必须为零 [2]；观测到有限信号即证明隐藏对称性破缺（自旋倾斜或缺陷诱导应变）；
     - **Mn₅Si₃**：d 波交变磁中的最优观测平台，Néel 温度以下正交畸变天然破缺 C₂ [15,16]；
     - **CrSb、NiS** 等实际 g 波交变磁（六角结构）同样受 C₂ 定则约束。

  ## 潜在研究方向

  - **非线性量子动理学不完善**：纳入磁化电流修正 [41,42] 与二阶位置偏移的严格理论仍是开放挑战，本文结论仅覆盖领先阶几何贡献。
  - **逐材料第一性原理判定**：C₂ 是否破缺依赖 SOC 微观细节，需对每个候选材料做第一性原理计算——这是本文框架的直接后续工作量。
  - **维度推广**：模型为二维紧束缚；三维实际材料中节点线的几何与热输运积分行为是否改变标度律，未讨论。
  - **实验可行性**：热学二阶响应的测量信噪比、温度窗口（模型中 T = 0.05 为约化单位）与真实 Mn₅Si₃ 参数的对应关系，论文未给出换算。
  - **扩展到其他对称性通道**：本文锁定 κ_xyy，其他允许分量（κ_xxx、κ_yxy）及更高阶谐波（i 波，l=6）体系的选择定则尚未系统给出。
  - **与超快手段的结合是本文未触及的方向**：对称性破缺的选择定则天然适合用瞬态手段做时域验证，这正是我们的切入点（见下节）。

  ## 与林赛研究的关联

  - **交变磁 + 量子几何 + 序参量读出**：本组方向词中的交变磁、量子几何在此交汇。论文给出"几何响应 ↔ C₂ 对称性"的严格对应，为我们的"交变磁序参量超快读出"课题提供理论判据：κ_xyy 类型响应的开关即 C₂ 破缺的读出。超快泵浦若能在时域上诱导/解除 C₂ 破缺（如光致晶格畸变），非线性热霍尔/非线性霍尔响应即可作为序参量的时域探针——这与"order parameter ultrafast readout"课题的核心逻辑直接对接。
  - **Mn₅Si₃ 双通道交叉验证**：d 波平台 Mn₅Si₃ 同时是本论文的热霍尔推荐平台与已观测 MNLHE（arXiv:2502.04920 [16]）的电学平台。电学 BCP 通道与热学 BCP 通道（Luttinger 对应）在同一几何量 g_xy 上汇合，构成同一量子度规观测量在两个热力学力（电场/温度梯度）下的交叉验证方案——可作为 proposal 中"多通道读出同一几何序参量"的论证素材。
  - **MnPS₃ / Berry + Rashba 线**：本论文被 `general-berry-mnps3-rashba-20260816` 课题引用。该课题的贝里曲率/量子几何分析可借鉴本文的紧束缚构造套路：两能级 g(k)·σ 形式、量子度规通式 (2)→紧凑式 (6) 的代数化简、分部积分去奇点的数值方案（G ∝ 1/G³ 奇点在 MnPS₃ 类节点结构中同样会出现）。
  - **方法学沉淀**：自适应子网格修补 + 分部积分正则化的组合是处理几何量节点奇点的标准做法，可写入我们计算方法库；Luttinger 代换 eE → ((ε−μ)/T)∇T 是电学几何量转热学响应的通用桥梁。
  - **强场/阿秒接口（延伸）**：非线性响应（二阶谐波产生类逻辑）对破缺对称性的灵敏度与 HHG 中的对称性选择定则思想同源——C₂ 破缺允许偶次谐波、非线性霍尔允许 κ_xyy，两者的张量对称性分析可互相借用；若做超快强场驱动下的交变磁高次谐波，本文的点群分析是现成的对称性底账。
