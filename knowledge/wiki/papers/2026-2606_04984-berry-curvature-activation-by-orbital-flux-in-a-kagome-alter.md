• # Berry-Curvature Activation by Loop-Current Order in a Kagome Altermagnet（kagome 交变磁体中轨道通量激活贝里曲率）

  ## 林赛的理解

  这篇工作解决了一个对我们非常实际的问题：**kagome 交变磁体（altermagnet）有强动量依赖自旋劈裂，却不一定有贝里曲率**——隐藏的 $TC_{2z}$ 反幺正对称性把 Berry 曲率精确压为零。我们的 HHG/阿秒探测方案若要声称"用光读出量子几何/贝里曲率"，必须先知道目标体系里这个对称性有没有被破缺、被谁破缺。本文给出的答案是清晰的层级结构：

  - 共面 120° 磁织构 + SOC → 自旋劈裂大但贝里曲率严格为零（"Hall-silent"态）；
  - 加入时间反演奇的 loop-current（虚键序 $\chi$）→ 立即破缺 $TC_{2z}$，非相对论极限下就激发出有限贝里曲率和可观的反常霍尔响应；
  - $\chi$ 与 SOC 足够强时，在 $n_e = 3$ 填充处打开全局能隙，霍尔电导趋近 $2e^2/h$（占据带 Chern 数大小为 2）。

  对我们的课题这意味着两件事：其一，**探测轨道流序（orbital-current order）本身就是一种可做的实验**——时间反演对称破缺的光学/输运信号是这类材料拓扑激活的直接指纹；其二，强场驱动本身可以扮演 $\chi$ 的角色——交变电场在键上诱导的电流/虚跃迁，正是破缺 $TC_{2z}$ 的动力学通道，这给我们"强场超快读出交变磁体隐藏拓扑"的方向提供了一个干净的理论对照组：基态无曲率 → 驱动中瞬时曲率 → 高次谐波/霍尔型信号。这是把"kagome + 交变磁 + 贝里曲率"三个方向词焊在一起的桥接文献。

  ## 研究问题

  核心问题：在**零净磁化、共面 120° 磁织构、无标量自旋手性（$\kappa_{ijk}=0$）**的 kagome 交变磁体中，能否产生动量依赖的自旋极化与有限贝里曲率/反常霍尔响应？具体分解为三个子问题：

  1. 纯共面非共线交换场（无 SOC）能产生多大的动量依赖自旋劈裂与自旋极化费米面？
  2. 加入本征 SOC 后，为什么（在什么对称性保护下）贝里曲率仍然严格为零？
  3. 用一个时间反演奇的 loop-current 序 $\chi$（虚键序/轨道通量）破缺隐藏反幺正对称性后，能否在非相对论极限激活有限贝里曲率与反常霍尔电导，甚至打开拓扑能隙？

  作者的定位是：提供一个"最小、解析透明"的紧束缚模型，把**磁性织构、轨道（orbital）、相对论（SOC）三种机制**的贡献解耦，回答"轨道流序是否是激活拓扑的独立通道"。

  ## 研究背景

  - 交变磁体（altermagnet）是近年新确立的磁量子物态类别：零净磁化与动量依赖的非相对论自旋劈裂共存（正文引文 1–15）；其时间反演破缺与反常霍尔效应来自共线部分，相对论极限下允许自旋倾斜（antisymmetric exchange，引文 17–19）。
  - 近期定义被扩展到**非共线交变磁体**：非相对论极限下破缺时间反演、由晶体对称性保护零磁化的材料（引文 20–23）。kagome 晶格处于核心位置：几何阻挫、平带、Dirac 锥、强量子干涉天然增强贝里曲率效应与量子几何响应（引文 35–42），已在反常霍尔输运、Chern 磁性、非常规超导、关联拓扑相、巨隧穿磁阻等方向成为前沿（引文 37–40, 43–45）。
  - 动机缺口：已有理论要么聚焦共线交变磁体（对称性分析直接），要么聚焦重元素 kagome 金属（效应主要来自 SOC 而非磁织构本身）。**共面 120° 序 + 弱 SOC + 子格不对称**协同产生自旋选择带几何的区间关注很少（引文 52）。
  - 实验驱动：Mn 基 kagome 化合物、巡游 120° 反铁磁体、轨道通量驱动 kagome 体系中观测到的大贝里曲率响应，无法用常规自旋手性或相对论机制解释（引文 54, 55）；$AV_3Sb_5$ 中的时间反演破缺也催生了 loop-current 描述（引文 58）。

  ## 研究方法

  本文是**理论方法密集型**工作（紧束缚模型 + 对称性分析 + Kubo 响应），无实验装置。按方法卡整理：

  ### 方法卡：kagome 交变磁体最小紧束缚模型 + 贝里曲率/霍尔电导计算

  **原理**：在 kagome 晶格上构造 6 分量 Bloch 哈密顿量（3 子格 × 2 自旋），逐项加入非共线交换、本征 SOC、次近邻跃迁与虚键序（loop-current），通过对称性分类判断隐藏反幺正对称性，用 Kubo 公式计算贝里曲率与内禀反常霍尔电导，追踪各机制对拓扑响应的贡献。

  **计算/分析序列**：
  1. 基线：$J = \lambda = \chi = 0$，验证纯 NN kagome 谱（Dirac 点 + $E = 2t$ 平带）自旋简并；
  2. 交换场单独作用（$t_2 = \lambda = \chi = 0$，$J = 0.2 / 0.5$）：$\langle S_x\rangle$ 投影能带、第三带自旋织构、自旋着色费米面；
  3. 交换 + SOC（$\chi = 0$）：验证贝里曲率恒为零、$\langle S_z\rangle = 0$；
  4. 交换 + loop-current（$\lambda = 0$）：$\Gamma$–$K$–$M$–$\Gamma$ 路径逐带贝里曲率，随 $\chi$ 演化；
  5. 参数空间与填充依赖的霍尔电导计算，含长程跃迁稳健性检验。

  **适用边界**：
  - $\chi$ 是唯象对称破缺场，作者**未自洽计算 loop-current 序的形成**（明确声明）；$\chi$ 不应解释为外施均匀磁通。
  - 反幺正保护 $TC_{2z}$ 只在**严格共面**磁织构下成立；任何自旋倾斜/非共面性（$\kappa_{ijk} \neq 0$）都会破缺它并直接产生贝里曲率热点。
  - 模型为最小紧束缚（仅 NN + NNN），真实材料的轨道成分、多带效应未包含；霍尔响应对填充强依赖。
  - 反对易关系 $[H_J, H_\chi(k)] \neq 0$ 是贝里曲率产生的关键机制——交换场先提升简并，轨道通量再诱导复数子格相干。

  **代表作**：Bagheri Tagani & Autieri, arXiv:2606.04984 (2026)；非共线交变磁体对称性分类参照引文 52。

  ## 主要发现与核心结论

  1. **无 SOC 的强自旋劈裂**：共面 120° 交换场单独作用即可在整个布里渊区大部分区域解除自旋简并，产生强动量依赖自旋劈裂与自旋极化费米面；$J$ 从 0.2 增至 0.5 时劈裂显著放大，平带演化为两支强自旋极化色散带，$\langle S_x\rangle$ 接近饱和值 $\pm 1$；$M$ 与 $M'$ 等对称相关区域自旋极化反号——这是交变磁（而非铁磁型）动量各向异性劈裂的标志性特征。

  2. **隐藏反幺正对称性导致"拓扑沉默"**：即使加入本征 SOC（$\lambda = 0.1$），只要 $\chi = 0$ 且磁织构严格共面，复合反幺正操作 $S = TC_{2z}$ 保持哈密顿量不变（$S^2 = +1$，无 Kramers 简并），数学上强制 $\Omega_z(k) = -\Omega_z(k)$，即**贝里曲率在整个布里渊区恒等于零**。几何上对应标量自旋手性 $\kappa_{ijk} = S_i \cdot (S_j \times S_k) = 0$。同时 $S$ 迫使 $\langle S_z(k)\rangle = 0$——SOC 不产生面外自旋倾斜。体系是"对称性保护的交变磁金属"：巨非相对论自旋劈裂 + 完全无贝里曲率。

  3. **loop-current 独立激活拓扑**：虚键序 $H_\chi$ 在时间反演下变号（$T H_\chi T^{-1} = -H_\chi$）且不被 $C_{2z}$ 抵消（$S H_\chi S^{-1} \neq H_\chi$），明确破缺 $TC_{2z}$。结果在**完全非相对论极限**（$\lambda = 0$、$\kappa_{ijk} = 0$）就产生贯穿动量空间的显著贝里曲率热点（集中在 $K$ 谷附近，随 $\chi$ 增大热点幅度与宽度显著演化），贝里曲率对 $\chi$ 线性响应（$\Omega^n_z(k) \propto \chi$，领头阶）。元胞三角上积累几何相位 $\Phi_\triangle \approx \frac{\chi}{t}$（领头阶），等效于 kagome 上的 Haldane 型轨道规范场。

  4. **填充依赖的霍尔响应与量子化拓扑相**：有限贝里曲率转化为可观、强填充依赖的反常霍尔电导。当 loop-current 与 SOC 足够强时，在 $n_e = 3$ 填充处打开**全局能隙**，霍尔电导趋近 $2e^2/h$，与占据带 Chern 数大小为 2 一致。

  5. **稳健性**：霍尔活性区在交换耦合、SOC、化学势的宽广参数范围内存在，且对保持对称性的长程跃迁稳健——即该机制不是微调出来的偶然效应。

  6. 总结论：轨道流序是把"Hall 沉默"的 kagome 交变磁体转变为反常霍尔金属或带隙拓扑相的**独立通道**，无需净磁化、非共线自旋序或标量自旋手性。

  ## 潜在研究方向

  - **$\chi$ 的微观自洽起源未解决**：本文将 loop-current 作唯象外生场处理；非局域库仑相互作用（特别是 van Hove 填充附近）如何自洽稳定该序、与 120° 磁序竞争还是共生，是开放问题（引文 57 的 extended-Hubbard 方向值得接）。
  - **填充依赖是双刃剑**：霍尔响应强依赖化学势，实际材料中落在霍尔活性窗口需要能带工程/栅压，材料实现路径不明。
  - **动力学层面完全未触及**：论文只讨论基态与线性响应。loop-current 序的涨落、在外场下的瞬态响应、强场驱动下 $TC_{2z}$ 的动力学破缺与贝里曲率的实时演化，都是本文框架的自然延伸且直接对接超快实验。
  - **最小模型的现实化**：未包含真实轨道成分、多带效应、电子关联动力学；与具体材料（Mn 基 kagome、$AV_3Sb_5$ 类）的对照需要第一性原理或多轨道模型。
  - **探测问题**：共面磁织构下 $\langle S_z\rangle = 0$、净磁化为零，实验上如何确凿指认 loop-current 序（而非自旋倾斜）是拓扑激活的来源，需要对称性分辨的光谱/散射判据。

  ## 与林赛研究的关联

  - **HHG / 强场驱动接口（最直接）**：本文的基态是"贝里曲率严格为零"的交变磁金属，而 $\chi$ 通道证明破缺 $TC_{2z}$ 即可瞬时激活曲率。交变强场本身在键上诱导电流与虚跃迁，是动力学版本的 $\chi$——因此"强场驱动 kagome 交变磁体、通过高次谐波读出隐藏拓扑/贝里曲率"有干净的理论起点：无驱动时 Hall 沉默，驱动窗口内瞬时霍尔型响应。这与我们 general-berry-mnps3-rashba-20260816 课题的"贝里曲率超快读出"主线直接咬合（该课题已引用本笔记）。
  - **交变磁（altermagnet）方向词**：本文系统给出了非共线交变磁体的对称性分类（S 型、磁点群 $6'/m'm'm$）与动量各向异性自旋劈裂的判据（$M/M'$ 反号、$\langle S_x\rangle \to \pm 1$），是我们写立项依据"交变磁体中非常规自旋劈裂"段落可直接引用的理论框架。
  - **莫尔 / 量子几何**：kagome 平带 + Dirac 锥 + 贝里曲率热点的组合与莫尔体系的量子几何响应同源；本文"轨道规范场激活拓扑"的机制（$\Phi_\triangle \approx \chi/t$）与莫尔/超晶格中的通量工程思想一致，可作为量子几何方向的方法类比。
  - **阿秒 / 超快磁学**：时间反演奇的轨道序意味着存在纯轨道通道的时间反演破缺指纹——这类信号对超快光学探测（法拉第/克尔旋转、THz 发射）是天然靶标，面外自旋分量为零反而有利于把信号归因于轨道通道。
