• # Large Scale Finite-Temperature Real-time Time Dependent Density Functional Theory Calculation with Hybrid Functional on ARM and GPU Systems

  ## 林赛的理解
  这项工作把有限温度、含杂化泛函的实时含时密度泛函理论（rt-TDDFT）真正推到了千原子量级，并且是在 ARM 与 GPU 两种异构超算架构上同时实现的。对我组来说，它的直接价值在于：我们终于有机会把强场超快驱动下的大规模电子动力学——特别是涉及热载流子、分数占据、非绝热跃迁的过程——用杂化泛函的精度来算，而不必被“只能跑几十原子”的限制卡住。PT-IM 方法把平行输运规范从 0 K 带隙系统推广到有限温度金属/半导体混合态，再叠加上 occupation 矩阵对角化、ACE 算子、环形异步通信和共享内存优化，相当于把计算墙从“方法学不可行”推到了“工程可扩展”。这对 HHG、阿秒探测、强场驱动相变以及莫尔体系中光诱导非平衡输运的研究，都是一个可以落地的工具入口。

  ## 研究问题
  论文要回答的核心问题是：**能否在 ARM/GPU 等大型异构并行系统上，高效、可扩展地实现有限温度、含杂化泛函的 rt-TDDFT 计算，从而模拟包含数千原子的真实材料体系？** 具体分解为三个子问题：
  1. 现有的平行输运 Crank-Nicolson（PT-CN）方案只能处理 0 K 带隙体系，如何将平行输运规范推广到分数占据的有限温度/金属体系？
  2. 有限温度下 occupation 矩阵 σ 的引入使 Fock 交换算子复杂度从 O(N²) 跃升至 O(N³) 乃至 O(N⁴)，如何在算法层面把成本降下来？
  3. 在 ARM 与 GPU 平台上，如何通过通信-计算重叠、共享内存等手段，把 PT-IM 的基线实现扩展到 960 节点/768 A100 GPU 的规模？

  ## 研究背景
  rt-TDDFT 是模拟激光诱导非平衡电子动力学的标准工具，已用于离子碰撞、光吸收谱、激光退磁、电荷转移、激发载流子动力学等。近年来实验上越来越多的超快现象——如激光诱导结构相变、电荷密度波激发、催化中的非绝热路径——要求电子激发模拟必须超出基态 DFT。  
  然而，rt-TDDFT 面临双重瓶颈：**精度-稳定性瓶颈**要求时间步长在亚阿秒量级，常用显式 RK4 积分器效率虽高但步长受限；平行输运规范能找到最慢振荡的轨道，使隐式积分器可用约 50 as 的步长并保持与 RK4 相当的精度，但原 PT-CN 方案仅适用于 0 K 带隙体系，无法处理金属或有限温度下的分数占据。**精度瓶颈**则来自半局域泛函（LDA/GGA）对激发态和带隙描述不足，会引入非物理激子；杂化泛函通过混入 Fock 交换积分可改善电子结构与光学吸收，但与平面波 rt-TDDFT 结合后计算量极大，此前真实材料的杂化泛函 rt-TDDFT 文献极少，遑论千原子体系。  
  An 等人近期提出了有限温度 rt-TDDFT 的平行输运形式，并在一维问题上展示了可突破 RK4 步长限制。本文在此基础上，把 PT-IM 方案真正落到了三维真实材料的平面波程序中，并面向 ARM/GPU 做了系统优化。

  ## 研究方法
  作者在自研平面波程序 **PWDFT** 中实现了 **PT-IM（parallel transport-implicit midpoint）** 方法，并分别在 ARM 平台（OpenMP）与 GPU 平台（CUDA）上优化。研究体系为硅超胞，原子数从 48 到 3072，对应 1×1×3 到 6×8×8 的单胞扩展；每个单胞 8 个 Si 原子，晶格常数 5.43 Å。计算设置统一采用 SG15 ONCV 赝势与 HSE06 杂化泛函，动能截断 10 Hartree，温度 8000 K，外场为波长 380 nm 的激光脉冲，总模拟时长 30 fs，PT-IM 与 PT-IM-ACE 的时间步长均为 50 as，电子密度与交换能收敛阈值设为 1.0×10⁻⁶，最大 Anderson mixing 维度为 20。精度测试中额外轨道数取 Natom，其余测试取 1/2 Natom。

  **基线实现**采用带指标/格点两种并行策略，通过 MPI_Alltoallv 转置；Fock 交换算子在混合态下按三重循环实现，需 N³ 次 FFT，复杂度 O(Ng log Ng · N³)。在 GPU 上采用 batch size=16 的多批次 FFT/广播策略以提高带宽利用率并降低 CPU-GPU 启动延迟。

  **算法优化**包括：
  1. **Occupation 矩阵对角化**：利用 σ 是厄米矩阵的性质，σ = QDQ*，将密度矩阵写成 P(r,r′)=Σ_i φ_i(r)d_iφ_i*(r′)。此举把 Fock 交换算子中的 FFT 次数从 O(N³) 降到 O(N²)，电荷密度计算从 O(N²) 降到 O(N)，整体复杂度从 O(N⁴) 降到 O(N³)。
  2. **ACE（Adaptively Compressed Exchange）**：由于 Fock 交换在 384 原子硅体系中仍占总时间 90%，作者在 PT-IM 中引入双层 SCF：外层构建 tn 与 tn+1/2 两个 ACE 算子，内层用 ACE 算子把双电子积分替换为 Ng×N 的矩阵乘法。原本每个时间步平均需 25 次 Fock 交换算子计算，引入 ACE 后约需 5 次外层迭代×每次 13 次内层迭代，Fock 交换算子实际计算次数减少 20 次，即降低 80%。

  **系统优化**包括：
  1. **环形点对点通信**：用 ring-based p2p 替代 MPI_Bcast 传输波函数，每步只需相邻进程通信，降低网络拥塞与延迟。
  2. **异步环形通信**：在环形基础上用非阻塞收发重叠通信与计算。
  3. **共享内存机制**：利用 MPI SHM 扩展，将 σ、Φ*Φ、Φ*HΦ 等同节点内进程共享，内存占用降至原来的 1/p；虽然 NUMA 远程访问带来一定性能损失，但显著扩大了可算体系规模。

  测试平台一为 **Fugaku**（ARM），理论峰值 537.21 PFLOPS，158,976 节点，6D-torus 网络，每节点 1 颗 A64FX CPU（4 CMG，每 CMG 12 计算核 + 8 GB HBM2，节点共 32 GB HBM2），512-bit SVE，单 CPU 峰值 3.38 TFLOPS，内存带宽 1024 GB/s。平台二为 **A100 GPU 集群**，每节点 1 颗 128 核 Kunpeng-920 CPU、256 GB DDR4、4 块 NVIDIA A100 GPU；A100 峰值 9.7 TFLOPS（Tensor Core 19.5 TFLOPS），40 GB HBM2，带宽 1.5 TB/s，CPU-GPU 通过双向 64 GB/s 的 PCIe 互联。

  ## 主要发现与核心结论
  1. **精度**：在 8 原子硅体系、380 nm 激光脉冲下，PT-IM-ACE 用 50 as 时间步得到的结果与 RK4 用 100 倍更小步长（0.5 as）的结果在 x 方向电偶极矩和总能量上完全吻合；局部放大图显示即使在最后 100 步（25–30 fs）仍保持良好一致性，且纯态与混合态均适用。
  2. **有限温度电子动力学**：8000 K 下，电子在模拟初始时刻就已出现分数占据。图 8 显示 occupation 矩阵的非对角元 σ_t(0,2) 随时间呈现随机涨落，体现电子运动的随机性；对角元 σ_t(22,22) 在外场增强阶段（10–15 fs）明显上升，表明激光场越强电子激发越活跃。
  3. **性能加速**：在 384 原子硅体系上，优化后的代码在 ARM 平台相对基线加速 **55.15 倍**，在 GPU 平台加速 **41.44 倍**。
  4. **可扩展性**：在 Fugaku 上可扩展到 **960 节点（46,080 ARM 核）** 模拟 **1536 原子** 的硅体系；在 GPU 集群上可在 **192 计算节点（768 块 A100 GPU）** 上实现 **3072 原子（12,288 电子）** 的有限温度杂化泛函 rt-TDDFT 模拟，单时间步求解时间为 **429.3 s**，相对基线加速 **41.4 倍**。
  5. **资源细节**：对 1536 原子体系，波函数格点数为 Ng = 60×90×120 = 648,000，电荷密度格点为 120×180×240，轨道数 N = 1536×2 + 1/2×1536 = 3840。

  ## 潜在研究方向
  1. **材料普适性**：目前全部物理与性能验证均基于硅体系，该方法能否直接迁移到金属、强关联体系、低维材料或莫尔超晶格仍需系统测试。
  2. **更强场强与 HHG  regime**：本文外场为 380 nm 激光，强度远未达到产生高次谐波的非微扰区；将 PT-IM-ACE 推广到强场 HHG、阿秒脉冲驱动以及含时矢势框架是下一步。
  3. **更长时间与更大体系**：即使优化后 3072 原子仍需每步 429.3 s，若要模拟数百飞秒乃至皮秒量级的动力学，总耗时仍巨大，需要进一步的时间步长与外推策略。
  4. **ACE 近似边界**：ACE 在相对温和的非平衡占据下有效，但在强激发、occupation 剧烈变化时其低秩近似精度需要更严格的误差分析。
  5. **k 点并行与自旋-轨道耦合**：本文仅采用 Γ 点，适用于大超胞；对小元胞、拓扑体系或含重元素体系，需要 k 点采样、自旋-轨道耦合与非共线自旋支持。
  6. **NUMA 与内存布局**：共享内存机制在 NUMA 系统上存在远程访问惩罚，优化共享矩阵的 NUMA 放置可进一步提升 ARM 平台性能。
  7. **与实验观测量对接**：目前主要报告电偶极矩与总能量，下一步应系统输出 HHG 谱、瞬态吸收、阿秒条纹谱等可直接与实验比较的观测量。

  ## 与林赛研究的关联
  这项工作的工具链可以直接接到我组的多个核心方向：
  - **HHG 与阿秒产生**：杂化泛函 rt-TDDFT 能更准确地描述带隙与激发态，正是模拟固体高次谐波、材料阿秒发射以及强场驱动载流子动力学的关键精度升级；PT-IM 的 50 as 步长对捕捉阿秒尺度的电子运动已经足够粗粒度友好。
  - **强场驱动相变与莫尔体系**：我组关注强场下莫尔超晶格（如转角 TMD、扭曲石墨烯）中的光诱导电荷转移与相变。有限温度混合态的描述能力，使我们能把热载流子分布、光场泵浦后的非平衡占据一起纳入计算，而不是假设 0 K 纯态。
  - **量子几何与非线性光学**：occupation 矩阵的非对角动力学与能带间相干直接相关，而相干演化又受量子几何（Berry 曲率、量子度规）支配；PT-IM 方法保存了完整的 σ 矩阵演化，为研究量子几何对超快非线性光学响应的影响提供了数据基础。
  - **NSFC-强场超快项目接口**：该论文的算法与代码实现，可作为“general-moire-strong-field-probe-20260726”等课题在理论模拟端的潜在工具，用来支撑“强场驱动 + 莫尔 + 量子几何”交叉方向的大尺度电子动力学计算。

## 研究方法（方法卡）

**方法**：大规模有限温实时 TDDFT 的 PT-IM 方法与 HPC 优化（PWDFT + ACE + Fugaku/A100）

**原理**：自研平面波程序 PWDFT 实现 PT-IM（parallel transport-implicit midpoint）混合泛函实时演化；三大优化：① occupation 矩阵对角化（σ=QDQ* 把密度矩阵写成 P=Σφdφ*）使 Fock 交换 FFT 从 O(N³)→O(N²)、总复杂度 O(N⁴)→O(N³)；② ACE（Adaptively Compressed Exchange）双层 SCF 把每步 25 次交换算子计算降到 ~5×13 结构（降 80%）；③ 系统层：环形点对点通信替代 MPI_Bcast、异步非阻塞重叠、MPI SHM 共享 σ/Φ*Φ（内存降至 1/p）。测试：硅超胞 48–3072 原子（HSE06/SG15，T=8000 K，380 nm 激光 30 fs，步长 50 as），Fugaku（ARM/A64FX）与 A100 GPU 集群双平台。
