• # C-BerryANC：基于第一性原理直接计算任意材料 Berry 曲率反常 Nernst 电导率的 C++ 代码

  ## 林赛的理解

  这是一篇方法学论文，本身不产出新物理，但它解决了一个很实际的问题：**Wannier 插值在纠缠能带/复杂能带交叉体系里会失效，而反常 Nernst 电导（ANC）偏偏最敏感于费米面附近的 Berry 曲率精细结构**。C-BerryANC 的做法是绕开 Wannier 化，直接从 FP-LAPW 全电子计算的动量矩阵元和本征值用 Kubo 公式暴力积 Ω，再用 OpenMP 并行 + 二进制存储 band-resolved Ω 把代价压下来——Ω 算一次，任意温度/化学势窗口的后处理几乎免费。

  对我们组的价值在两条线上。第一，"费米面附近 Berry 曲率分布"是反常霍尔/反常 Nernst/Weyl 相表征的核心观测量，这篇文章给出的 k 点收敛数据（Fe₃Al 需 ≥350×350×350 才收敛到 -1.83 A K⁻¹ m⁻¹）是非常具体的方法学数字，写方案时可以作为"第一性原理输运计算需要多密 k 网格"的直接依据。第二，它的工程思路——**重活（Ω）与扫描活（T、μ）解耦、一次计算多次后处理**——和我们超快泵浦-探测里"一次强场演化、多次观测量投影"的批处理哲学是同一个范式，可以借鉴到强场驱动含时布居/Berry 曲率演化后处理代码的设计里。

  ## 研究问题

  如何在不依赖 Wannier 插值的前提下，从第一性原理电子结构直接、高效、准确地计算任意材料的 Berry 曲率依赖反常 Nernst 电导（ANC）？具体痛点是：Wannier90 的 MLWF 构造对能量窗口、轨道选择高度参数敏感，在金属性强、能带高度色散且纠缠（如磁性金属、复杂能带交叉体系）时"几乎无解"（原文："hopeless task"），而已有代码家族中缺少直接第一性原理实现 ANC 的工具。

  ## 研究背景

  - 反常 Nernst 效应（ANE）：铁磁材料在无外磁场时，温度梯度与磁化（等效内建场）垂直方向产生横向电压，源于电子能带 Berry 曲率 Ω 对载流子的类洛伦兹横向加速。ANE/ANC 只破缺时间反演对称的材料才有非零值。
  - 应用动机很强：纳米器件中 ANE 已实现约 13 ± 2 W/cm³ 的功率密度（热回收），可用于热流传感、自旋量热电子学（spin-caloritronics）、依赖温度梯度的磁成像显微术；与反常霍尔效应（AHE）一起用于磁性 Weyl 半金属的拓扑表征。
  - 与 AHC 的关键区别：**AHC 依赖全部占据能带的整体积分，ANC 只由费米能附近的能带贡献**——这使 ANE 测量成为探测费米面附近 Ω 分布、验证 Weyl 相的灵敏工具，也意味着 ANC 对电子结构细节（本征值与动量矩阵元的精度）极其敏感。
  - 现有主流路线是 Wannier 插值（wannier90），但因 Bloch 相位不定导致 Wannier 函数非唯一、需要人为选取 disentangled 能量窗口、对高色散纠缠能带失效；且此前 ANC 文献值（Fe₃Al 的 2.7–3.0 A K⁻¹ m⁻¹、Noky 高通量数据）多来自 Wannier 化紧束缚模型，缺一个直接 FP 参照工具。Xiao 等人的 Kubo 公式（Eq.1）形式下，ANC 需在 400×400×400 或更密的全 BZ k 网格上积分 Ω，计算量大，要求代码在内存与速度上做专门设计。

  ## 研究方法

  方法密度高（代码论文，计算细节详尽），按方法卡整理：

  **原理**
  ANC（α_ij）由费米面附近 Berry 曲率 Ω 对"能量-熵核"的 BZ 积分给出（Xiao 公式）：
  α_ij = -(1/T)(e/ℏ) Σ_n ∫d³k/(2π)³ Ωⁿ_ij(k) [(Eₙ-E_F)fₙ(k) + k_BT ln(1+exp((Eₙ-E_F)/(-k_BT)))]
  Ωⁿ_ij(k) 由 Kubo 型公式从动量矩阵元与本征值直接计算：
  Ωⁿ_ij(k) = -(ℏ²/m²) Σ_{n'≠n} 2 Im⟨ψ_nk|p_i|ψ_n'k⟩⟨ψ_n'k|p_j|ψ_nk⟩ / (Eₙ-E_n')²
  SOC 必须计入（否则积分为零，代码内建 SOC）。

  **计算设置与参数表（数值原样，出处 = 原文 Table III/IV/V 及正文）**

  | 项目 | 参数 |
  |------|------|
  | DFT 引擎 | WIEN2k（全电子 FP-LAPW），SOC 自洽计入，磁化沿 z 轴 |
  | 自洽收敛判据 | 10⁻⁴ Rydberg/单胞 |
  | 自洽 k 网格（IBZ） | 10×10×10（三个体系均如此） |
  | 交换关联泛函 | Pd：PBE；Fe₃Al、Co₂FeAl：PBESol |
  | Pd 晶格 | Fm-3m，a=b=c=3.89 Å，α=β=γ=90°，Pd 在 (0,0,0) |
  | Fe₃Al 晶格 | Fm-3m，a=b=5.77 Å；Fe(I)=(0,0,0.50)，Fe(II)=(0.75,0.25,0.75)，Al=(0,0,0) |
  | Co₂FeAl 晶格 | Fm-3m，a=b=c=5.70 Å；Co=(0.25,0.25,0.25)，Fe=(0.50,0.50,0.50)，Al=(0,0,0) |
  | ANC 积分 k 网格 | 400×400×400（全 BZ），shifted 网格避开高对称点 |
  | μ 扫描窗口 | E_F ± 200 meV，40 等分（emin=-200，emax=200，estep=10 meV） |
  | 温度扫描 | T = 25–300 K（Tmin=25，Tmax=300，Tstep=25 K），μ = E_F |
  | 化学势设定 | Pd 0.5153375149 Ry / Fe₃Al 0.6017577882 Ry / Co₂FeAl 0.6276267143 Ry |
  | 计算资源 | 64 GB RAM，NUM_THREADS=28，num_kp_at_once=5000 |
  | 输出分量 | α_xz、α_yz、α_xy |

  **工作流程**：modify_calc_window 模块改写 case.in1/case.inso/case.inop 的能量窗口 → klist_gen_div 生成 dense case.klist（含 k 网格平移选项）→ 按线程数切分 k 点 → 各线程子目录批量（num_kp_at_once 个一批）调用 WIEN2k 算本征值与动量矩阵元（OPTIC 模块提取）→ energy_pmat_read 算 band-resolved Ω 并存入二进制 data.bin（显著降低内存）→ alphaANC 模块对任意 (T, μ) 窗口做后处理积分，结果写入 ANC.txt，计时写入 time.dat。Ω 计算（重活）与 (T, μ) 扫描（轻活）解耦：data.bin 生成后可改输入文件重新后处理而无需重算 Ω；后处理须用与 Ω 计算相同的线程数。

  **适用边界**
  - 目前仅对接 WIEN2k；作者称可扩展到 Elk、Quantum ESPRESSO。
  - 计算值与实验值可能大幅偏离，原因归结为样品缺陷/杂质、多晶相引入的散射机制——对比实验时需注意。
  - 内存随 case.klist 中 k 点数增长，超大网格需靠 num_kp_at_once 分批。
  - 网格收敛要求：Fe₃Al 的 α_xy 在 350×350×350 之后才收敛（50³ 时为 -1.58 → 350³/400³ 均为 -1.83 A K⁻¹ m⁻¹）。

  **代表作（方法卡）**
  - Pandey & Pandey, 2025（本文，arXiv:2505.19280）
  - 理论框架：Xiao, Chang & Niu, Rev. Mod. Phys. 82, 1959 (2010)

  ## 主要发现与核心结论

  - **代码基准验证三体系（均为 FCC 铁磁体），与文献吻合**：
    - **Pd**：300 K 时 α_xy = -0.86 A K⁻¹ m⁻¹（Guo 等报道 -0.72 A K⁻¹ m⁻¹）；μ 依赖上，μ 在 E_F 下 200 meV 处 α_xy 最大约 +1.5 A K⁻¹ m⁻¹，在 E_F 上约 30 meV 处取最小约 -0.94 A K⁻¹ m⁻¹；25–300 K 温度扫描见下表。
    - **Fe₃Al**：300 K、μ=E_F 时 α_xy = -1.83 A K⁻¹ m⁻¹；μ 扫描在 E_F 下 60 meV 处取最小 -2.84 A K⁻¹ m⁻¹；T ≤ 500 K 时最大量级 2.83 A K⁻¹ m⁻¹（Sakai 高通量 2.7、Koepernik 等 3.0 A K⁻¹ m⁻¹——后两者基于 Wannier 化紧束缚模型）。
    - **Co₂FeAl**：300 K 时 α_xy ≈ +0.11 A K⁻¹ m⁻¹（Noky 高通量 Wannier 计算 0.06 A K⁻¹ m⁻¹）；μ 扫描在 E_F 处取极大 ≈ +0.11，在 E_F 上 160 meV 处取极小 ≈ -0.08 A K⁻¹ m⁻¹。
  - **温度依赖（μ = E_F，原文 Table VI）**：三者 |α_xy| 均随温度升高而增大。Pd：25 K 时 -0.06 → 300 K 时 -0.86 A K⁻¹ m⁻¹；Fe₃Al：-0.05 → -1.83；Co₂FeAl：0.01 → +0.11。
  - **k 网格收敛（Fe₃Al，300 K）**：50³：-1.58；100³：-1.87；150³：-1.76；200³：-1.84；250³：-1.80；300³：-1.79；350³：-1.83；400³：-1.83 A K⁻¹ m⁻¹。≥350³ 收敛，故全部正式计算用 400³。
  - 工程结论：C++ 编译为机器码 + OpenMP（优于 Python multiprocessing）+ band-resolved Ω 二进制存储 + 一次 Ω 计算多次 (T, μ) 后处理，使"高通量材料筛选中人工调 Wannier 函数不可行"的场景下直接 FP 计算 ANC 成为现实。

  ## 潜在研究方向

  - 仅对接 WIEN2k：对 Elk/Quantum ESPRESSO 的接口移植是明确的开放工程问题（对习惯平面波/PAW 的社区不友好）。
  - 计算-实验偏差的来源仅定性讨论（缺陷、杂质、多晶散射），未做定量无序/有限寿命（如常数弛豫时间近似之外的自能修正）处理。
  - ANC 对 μ 的强依赖（几 meV–几十 meV 即变号、变幅）意味着化学势标定误差会直接转化为定量误差；本文未讨论这一系统不确定度。
  - 未触及强关联体系（如含 U 的 DFT+U/动力学平均场）——磁性拓扑材料的强关联修正下该框架是否可靠未验证。
  - 对时间反演对称破缺但磁结构复杂（非共线、自旋 frustrated）体系的推广未讨论（当前框架为共线自旋极化设定）。
  - 对非平衡输运（光电导、强场驱动布居）的 Berry 曲率响应，本文的"平衡 (T, μ) 扫描"范式无法直接覆盖，需要含时推广。

  ## 与林赛研究的关联

  - **Berry 曲率是共同语言**：本文的核心观测量 Ω(k) 在费米面附近的分布，与我们关心的强场驱动下布洛赫电子的量子几何响应（HHG 中 Berry 曲率/量子度规对非线性电流的贡献、阿秒时间分辨的拓扑输运读出）是同一张图的两个侧面。其"band-resolved Ω 先算后扫描"的数据结构，可直接迁移为强场含时演化后处理中"先演化、多观测量投影"的批处理模板。
  - **k 网格收敛数字可直接引用**：400×400×400（全 BZ）、IBZ 收敛阈值 350³ 这类定量收敛数据，是我们写第一性原理支撑部分（费米面附近 Berry 曲率计算的计算代价与精度论证）时可援引的硬数据；特别是它证明 ANC 类观测量对 k 网格的敏感度远高于常规能带计算。
  - **"量子几何读出"课题接口**：本笔记被 `key-transient-quantum-phase-optical-20260726` 课题使用——瞬态量子相的光学读出需要把 Berry 曲率的平衡参照（此类代码可算）与强场诱导的瞬态修正对比，C-BerryANC 类工具提供平衡基线的可重复来源。
  - **方法论警示**：Wannier 插值在纠缠/高色散能带（正是强场驱动常涉及的金属性、近简并体系）中的失效，提醒我们组内任何依赖 Wannier 化的强场响应计算都要先做带交叉/纠缠诊断；本文的"直接 FP 暴力积分 + 并行 + 后处理解耦"是绕开这一陷阱的可行范式。
  - **交变磁/莫尔方向**：ANC 要求破缺时间反演对称——交变磁体（altermagnet，动量依赖自旋劈裂但零净磁矩）能否产生反常 Nernst 响应、其 Ω 分布特征，可用此类直接计算工具系统筛查；莫尔体系的 miniband Berry 曲率热点同样适用"先算 Ω、后扫参量"的流程。
