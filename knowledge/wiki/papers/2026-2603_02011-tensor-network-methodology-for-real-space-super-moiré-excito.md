• # 超摩尔激子的实空间张量网络方法学（Tensor-network methodology for real-space super-moiré excitons）

  ## 林赛的理解

  这篇工作的核心价值不在具体的物理结果（两个理想化玩具模型），而在**方法学**：它把 Bethe-Salpeter 方程（BSE）搬进了张量网络（TN）框架，使激子谱计算从"百万格点都难以为继"跳到"十亿格点以上"，哈密顿量维度达 10^18 量级。对我们做**莫尔体系强场超快探测**的课题，这是两件直接可用的东西：其一，准周期/非公度超摩尔体系的激子 LDOS 可以实空间直接算，不需要周期超胞近似——这为"莫尔势如何重构激子能级、进而调制 HHG/非线性响应"提供了理论计算工具；其二，文中"非周期势场中激子谱权重按势场极小值局域化、形成 miniband 分裂"的物理图像，正是我们设想中强场驱动下激子-载流子动力学调控的微观图景。方法密度高，研究方法节按方法卡格式整理。

  ## 研究问题

  如何在非公度、超摩尔（super-moiré）尺度（特征长度比常规莫尔体系大几个数量级、有效晶格达百万乃至十亿格点）的体系中，直接计算束缚激子的实空间谱函数（局域态密度 LDOS）？具体而言：

  - 常规 BSE 求解器在动量空间、截断价带/导带基组中工作，无法处理非公度调制与非周期几何；
  - 实空间直接处理双粒子 BSE 的时间复杂度为 O(N^6)、内存 O(N^4)（稀疏方法最好也只能 O(N^2) 内存），对超摩尔体系完全不可行；
  - 论文要回答：**能否用张量网络把完整的实空间双粒子 BSE 哈密顿量压缩并提取谱信息，同时跨越大不相同的尺度分辨原子级与介观级结构？**

  ## 研究背景

  - 二维范德华材料因增强的库仑相互作用成为激子物质工程平台，激子特征在室温下仍稳定（引用文献 [1–3]），双层 TMD 中转角与晶格失配控制实现了莫尔激子（[10–16]），产生周期约束、激子 miniband，以及可编程量子发射器阵列与人工量子模拟器（[10, 16, 17]）。
  - 微观上激子现象由 BSE 描述（[18–25]）。现有 tight-binding BSE 软件包：Xatu [26]、WanTiBEXOS [27]、WannierBSE [28]，基组大小为 N_k·N_v·N_c，只保留动量空间截断基组，不保留完整实空间电子-空穴基组；QNANO [29] 用 configuration interaction 超出单电子-空穴 sector，但多体 Hilbert 空间组合爆炸。
  - 单粒子实空间方法已有利用稀疏矩阵线性标度的成熟工作（[36–41]），单粒子谱的稠密对角化为 O(N^3) 时间/O(N^2) 内存。但激子是双粒子问题，Hilbert 空间随格点数二次增长，超摩尔体系有效晶格达百万到十亿格点（[42, 43]），暴力方法不可行。
  - TN 多体求解器已能处理指数大的哈密顿量，内存标度 O(log N)（[44–49]），配合 tensor cross interpolation（[62–68]）；此前 TN 已用于准周期拓扑 Chern 态马赛克 [46]、十亿格点以上自洽相互作用超摩尔体系 [45]、大非周期体系空间分辨动量谱函数 [47]。本工作把这一思路推广到**双粒子激子问题**。

  ## 研究方法

  本文是方法创新为核心贡献的论文，按方法卡整理。

  ### 原理

  用张量网络编码完整实空间 BSE 双粒子哈密顿量（不做基组截断），配合 Chebyshev 核多项式算法（KPM）直接计算束缚激子实空间 LDOS ρ(r, ω) = ⟨r,r|δ(ω − Ĥ)|r,r⟩。关键编码技巧：把 2^L 个实空间格点映射为 L 个 pseudospin 指标，用 quantics tensor cross interpolation（QTCI）把空间变化的哈密顿量表示为 MPO；电子-空穴双粒子空间采用**交错排序（interleaved ordering）**避免两链接口处 bond dimension 指数增长，使相互作用算符的 bond dimension 与体系尺寸无关。

  ### 参数表（数值原样，含出处）

  **模型设置（正文 §II, Eq. 1–2）**
  - 两带 Wannier 哈密顿量 Ĥ = Ĥ_c + Ĥ_v + Ĥ_U，无自旋（spinless）近似；局域屏蔽电子-空穴相互作用 U_l；BSE 激子哈密顿量 Ĥ_X = T̂_c ⊗ 1 − 1 ⊗ T̂_v − Û，其中相互作用矩阵元 U_klmn = U_k·δ_kl·δ_mn·δ_ln，**不可写成乘积算符**（Appendix A 推导）
  - pseudospin 编码：2^L 实空间格点 → L 个 pseudospin；双粒子体系总长 2L；相互作用 Û = ⊗_r (1/2)[1_r⊗1_{r+L} + 2σ_z,r σ_z,r+L]

  **谱计算（Chebyshev KPM，正文 §II）**
  - 标准 Jackson 核：能量分辨率 ~1/N_μ，谱加宽 ΔE ≈ πa/N_μ
  - 高阶 delta-Chebyshev（HODC）核：m 阶有理逼近 δ(ω−E)，精度 O(η^m)，Chebyshev 展开阶数 N_ν ~ O(1/η)，点收敛率 O(N_μ^{−m})（对比 Jackson 核的二阶 O(N_μ^{−2})）；m < 8 时权重 w_l 可算到双精度；系数 ν_k 经 DCT 快速获得
  - HODC 缺点：不保证正定性（正文 §IV.B 论证负值是正则化数值伪迹，非物理负谱权重）

  **1D 非公度超摩尔算例（正文 §III.A, Eq. 10）**
  - 势场 V_i = V_0[1 + 0.1·cos(2πx_i/b_1) + 0.1·cos(2πx_i/b_2)]，b_1 = 3√5/2、b_2 = √3N/10（两调制互为非公度）
  - 参数：最近邻跳跃 t = −1，电子-空穴相互作用 U = 6，势幅 V_0 = 3（|t| 为单位）
  - 体系尺寸 N = 2^30；谱半宽 a ≃ 5.6；Jackson 核 N_μ = 150 → ΔE ≃ πa/N_μ ≃ 0.12
  - TN 参数：χ_max = 200，SVD 截断容差 tol = 10^−10

  **2D 八重准周期超摩尔算例（正文 §III.B, Eq. 11）**
  - 势场 V(r) = V_0[1 + Σ_{n=1..4}(Δ_α cos(αk_n·r) + Δ_β cos(βk_n·r))]，k_n = R_n(π/4)[2π, 0]^T（四波矢叠加成八重对称，对应 45° 转角双层 GeX/SnX 类体系 [94]）
  - 参数：Δ_α = 0.15（原子尺度调制幅），Δ_β = 0.05（超摩尔调制幅）；摩尔尺度 α = 2/(5√5)，β = 16/(√3N_x)；t = −0.5，V_0 = 6，U_0 = 10
  - 体系尺寸 N_x = N_y = 2^15，即超过 10 亿格点；束缚激子能量 E_X = −1 处取 LDOS
  - 谱半宽 a ≃ 14.4；HODC 核 m = 3，N_μ = 40，η = 0.03 → 物理能量加宽 ΔE = aη ≃ 0.43；同 N_μ 下 Jackson 核 ΔE ≈ πa/N_μ ≈ 1.13（两倍多宽，故 bond-dimension 受限情形必须选 HODC）
  - TN 参数：χ_max = 400，tol = 10^−11

  **基准测试（正文 §IV）**
  - 1D：χ_test = 200、χ_ref = 500、tol = 10^−10；测试递推在 N_μ ≈ 180 附近触及 χ 上限，即 1D 在关注范围内非 bond-dimension 受限；相对 RMS 误差 ε(χ)（Eq. 12 定义）在 χ ≲ 90 已落到数值地板
  - 2D：χ_test = 400、χ_ref = 800、tol = 10^−11；χ_max 在 N_μ ≈ 65 饱和测试上限，N_μ = 100 时参考递推也逼近 χ_ref，即 2D 可用 Chebyshev 矩数内在地限制在约 N_μ ≈ 65（当前架构）；ε(χ) 要到 χ ~ 400 才到地板
  - HODC 验证：SSH 链 N = 20000 站点，随机迹 KPM 稀疏矩阵-矢量传播，N_μ = 500、η = 0.003、m = 4；2D 激子 LDOS 在 L_x = L_y = 4 小体系上与稀疏矩阵算法对照，空间峰位与相对权重高度相关
  - 误差定义：ε(χ) = sqrt(Σ_ij |ρ_ij(χ) − ρ_ij(χ_ref)|² / Σ_ij |ρ_ij(χ_ref)|²)

  ### 适用边界

  - 1D 体系 bond dimension 增长温和，χ ≲ 90 即收敛；2D 体系 χ 随 Chebyshev 矩数快速增长，当前架构实际可用矩数约 N_μ ≈ 40–65，处于可压缩性阈值边缘
  - SVD 截断容差必须保守选取并随体系尺寸收紧：容差不够紧会选择性压低束缚态谱权重（附录 C 基准）
  - HODC 核不保证 LDOS 非负，在 van Hove 奇异点附近出现小幅负振荡（数值伪迹，可忽略）
  - 本文仅含局域电子-空穴相互作用、无自旋、最小两带模型；长程库仑、交换项、更复杂晶格几何尚未实现（作者指出可能加速 bond dimension 增长）

  ### 代表作

  - Moustaj, Sun, Antão, Eek, Lado（2026，本文，arXiv:2603.02011）：实空间 BSE 的 TN 方法，10^18 维哈密顿量、十亿格点以上激子 LDOS
  - （方法基石）QTCI 与超摩尔单粒子 TN 工作：Lado 组此前十亿格点自洽相互作用超摩尔求解 [45]、大非周期体系空间分辨谱函数 [47]

  ## 主要发现与核心结论

  1. **方法层面**：TN + Chebyshev KPM（HODC 核）组合可在 1D 和 2D 上求解超过十亿格点的实空间 BSE，哈密顿量维度达 10^18，比常规 BSE 求解器（Xatu、WannierBSE 等）的能力高出数个数量级；内存标度 O(log N)，避免显式存储双粒子哈密顿量。
  2. **交错排序是关键实现技巧**：电子-空穴两链顺序排列时接口处 bond dimension 随体系尺寸指数增长；交错排序使相互作用算符 bond dimension 与体系尺寸无关。
  3. **1D 结果**：N = 2^30 非公度链上，束缚激子谱带实空间轮廓紧密跟随 onsite 调制势；原子尺度（中心 ℓ = 64 区域）与介观尺度同时分辨；非公度小尺度调制产生 miniband 分裂，在两个尺度上都可见——局域电子-空穴环境改变移动局域激子能，不同局域环境杂化形成 miniband 式分裂。
  4. **2D 结果**：N_x = N_y = 2^15（十亿格点以上）八重准周期势中，E_X = −1 处激子 LDOS 谱权重峰值位于势极小值处，呈八重旋转对称约束图样；原子尺度（中心 128×128 区域）呈现同样的八重对称约束——束缚激子在非周期势景观中被约束于势极小值。
  5. **HODC 核在 bond-dimension 受限 regime 的必要性**：2D 中 χ 在 N_μ ≈ 65 饱和，无法用大矩数；m = 3、N_μ = 40、η = 0.03 给出 ΔE ≈ 0.43，而同参数 Jackson 核为 ΔE ≈ 1.13，宽两倍多。
  6. **物理主结论**：非公度空间结构重新分配并分裂激子谱权重；超摩尔与原子两个分离尺度上的谱权重均跟随势场调制，证明束缚激子在势极小值处的约束——此类约束预期出现在非公度堆叠范德华异质结中。

  ## 潜在研究方向

  - 2D 体系 Chebyshev 矩数被 bond dimension 增长限制在约 N_μ ≈ 65，tree tensor network 等替代架构或更适合处理 2D 关联、进一步提升性能。
  - 长程库仑相互作用与交换项尚未纳入；纳入后可能加速 bond dimension 增长，需配套新 TN 架构。这是走向真实莫尔异质结构定量建模的必经扩展。
  - SVD 容差对束缚态信号的敏感性要求随体系尺寸收紧容差，大体系计算成本与精度权衡需系统研究。
  - 方法可推广至其他双粒子关联问题：莫尔体系中的双极化子（bipolaron）态 [98–100]、莫尔磁性绝缘体中的双磁振子束缚态（bimagnon）[101–106]——这些体系的双粒子 Hilbert 空间同样在大尺寸下不可直接处理。
  - 当前仅无自旋最小模型；自旋-谷物理（TMD 中真实激子的自旋-轨道与谷选择定则）与真实材料参数（介电屏蔽、带结构）的接入尚待完成。

  ## 与林赛研究的关联

  - **莫尔 + 强场接口**：本文给出超摩尔体系中激子能级结构（miniband、局域化、能级分裂）的实空间计算手段。我们课题（general-moire-strong-field-probe）关心莫尔势如何调制强场驱动的载流子动力学与 HHG 谱——本文的 LDOS 分辨出的局域激子态与 miniband 正是强场电离/复合通道的初始态结构，可作为 HHG 通道分析的输入。
  - **交变磁/莫尔磁性的远亲接口**：文中明确展望 bimagnon 束缚态的双粒子 TN 计算（[101–106]），与我们交变磁（altermagnet）方向的磁激发动力学有方法层面的共通性。
  - **量子几何与非周期体系**：非公度势无平移对称性，动量空间 BSE 失效，实空间 TN 是研究其量子几何效应（如实空间分布的 Berry 曲率、激子 Hopfield 系数）的潜在工具。
  - **方法论借鉴**：HODC 核"以低 Chebyshev 阶数换高分辨率"的策略，以及交错排序抑制 bond dimension 的技巧，对我们若开展 DMRG/TN 类强场动力学模拟（如 t-DMRG 处理强场驱动晶格模型）有直接参考价值。
  - **注意边界**：本文是理论方法 + 玩具模型演示，未触及任何超快/强场过程；用于我们课题时须自行扩展含时驱动项，且真实 TMD 参数（屏蔽库仑、自旋-谷结构）的接入是其未完成的扩展方向。
