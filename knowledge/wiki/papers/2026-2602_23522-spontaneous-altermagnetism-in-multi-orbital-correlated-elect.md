• # 自发交变磁性：多轨道关联电子系统中的新机制与手性磁振子

  ## 林赛的理解

  这篇工作解决了一个我组"交变磁超快读出"课题线上的根本性问题：**自发交变磁（spontaneous altermagnet）是否只是两轨道玩具模型里的数学可能性，还是能在真实材料中稳定存在？** 答案是肯定的——三轨道 t2g 体系里，不参与交变相轨道序的第三个半填充轨道提供了额外的反铁磁超交换，使 AFM+AFO（反铁磁+反演铁磁轨道序）态绕过 Goodenough-Kanamori 规则稳定下来，LaVO3 等立方钒酸盐立刻成为实验目标。更让我感兴趣的是两个"超快可及"的预言：① 手性劈裂磁振子的劈裂量 Δχ 服从 **1/U³ 标度**（由四阶过程产生），这直接告诉我们超快磁光/NIS 实验中预期能看到多大劈裂、随关联强度怎么调；② 弱面内磁场 + 弱原子 SOC 能混合出**手性磁振子-轨道子杂化模**，具有有限轨道极化、在温度梯度下产生纵向和横向轨道电流——这是一个全新的"轨道电流"实验通道，而且与超快光泵浦天然兼容。对我们"交变磁 + HHG/阿秒读出"的技术路线，这篇给出了材料候选（准二维 LaVO3 类、2 电子/V³⁺）、可观测窗口（Neel 温度 20-60 K，可达 120-150 K）和具体的序参量诊断工具。

  ## 研究问题

  论文的核心问题有三个层层递进：

  1. **现实性问题**：在双轨道模型中，自发交变磁所必需的 AFM+AFO 序违反 GK 第二规则（要求正交占据轨道间为铁磁交换）。那么真实材料中是否存在更现实的实现路径，使 AFM+AFO 态在不违反基本磁学规则的前提下稳定？
  2. **稳定性问题**：这种 GK 规则被"绕开"而非"违反"的自发交变磁 Mott 绝缘态，是否能在量子涨落（DMRG）和热涨落（蒙特卡洛）下存活？稳定判据是什么？
  3. **动力学问题**：晶体学交变磁中预言并被非弹性中子散射证实的手性劈裂磁振子，在没有晶体对称性破缺的自发交变磁中是否仍存在、其微观起源是什么？能否找到轨道子（orbiton）的实验可观测通道？

  ## 研究背景

  - **交变磁研究脉络**：交变磁（altermagnetism）是零净磁化但电子能带具有强非相对论自旋劈裂的共线交错磁态，近年因自旋电子学/磁振子学应用备受关注。MnTe、CrSb、KV₂Se₂O、Rb₁₋δV₂Te₂O 等材料已被角分辨光电子能谱和中子散射实验证实为**晶体学交变磁**——其自旋劈裂来自非磁原子提供的低对称晶体环境（交错磁原子位置由 Cn 旋转而非平移/反演联系）。
  - **自发交变磁的提出与困境**：已有理论在关联双轨道模型中预言了**自发交变磁**（交错轨道序与交错磁序自发破缺完全对称晶格的平移反演对称性，产生 d 波交变磁），但该模型所需的 AFM 交换 + AFO 交换违反 GK 规则（GK 规则要求正交轨道间铁磁交换以配合 Hund 耦合），其现实性存疑。目前自发交变磁**无任何实验证据**。
  - **多轨道关联体系中的轨道-磁序共存**：eg 钙钛矿 LaMnO₃、KCuF₃、K₂CuF₄ 等中 AFO 序总伴随面内 FM 序（符合 GK 规则）。有趣的是，**LaVO₃**（立方钒酸盐，V³⁺ 的 t2g 轨道含 2 个电子）早在交变磁概念提出之前就表现出 AFO+AFM 序（主要归因于超交换），立方钒酸盐因此在交变磁语境下重新受到关注。
  - **关键物理图像**：双轨道体系四分之一填充时 FM+AFO 与 AFM+FO 态能量最低；加入半填充第三轨道后，其 Anderson 超交换增强净 AFM 交换（同时 Hund 耦合维持原子内自旋平行），把 AFM+AFO（交变磁）态压到基态——如图 1(d) 所示的能谱排序。

  ## 研究方法

  - **模型**：二维方格三轨道 Hubbard 模型，每个格点含 xy、xz、yz 三个 t2g 轨道，2 电子/格点；跃迁矩阵 t̂x、ŷ 取对角形式且 xz↔yz 对称变换、无轨道间跃迁，取 tz = 1.0 为能量单位、tx = ty 为自由参数；多轨道 Hubbard 相互作用含 U、U′ = U − 2JH 与 Hund 耦合 JH。
  - **平均场**：非限制 Hartree-Fock 求解 12×12 体系，固定 JH/U = 0.2，绘制 U-Δ、U-tx 相图，以 (π,π) 自旋/赝自旋结构因子 S(π,π)、τz(π,π) 表征磁与轨道序。
  - **大 U 极限有效模型**：二阶微扰论推导 S=1、L=1 局域空间的自旋-轨道（S-L）哈密顿量（含自旋-轨道四极/偶极耦合项 H^SQ、H^SL 与轨道四极-四极、偶极-偶极项 H^Q、H^L）；对 Δ<0 进一步约化为 Kugel-Khomskii 型自旋-赝自旋（S-τ）模型，交换参数 J^S、J^Sτ₁、J^Sτ₂、J^τ 为 tx、tz、U、JH/U 的函数。用 2 格点精确对角化能谱对比验证了有效模型。
  - **DMRG**：用 ITensor 库对 S-L 模型在 8×4 圆柱几何（x 周期、y 开放边界）做密度矩阵重整化群计算，键维数达 **2500**，固定 Δ = −1.5、tx = 1.0、U = 20，检验量子涨落下 AFM+AFO 稳定性。
  - **热涨落**：CP2 表示 + 经典蒙特卡洛（半经典、纠缠自由直积态近似）计算 12×12 体系的比热 Cv、S(π,π)、τz(π,π)，扫描 JH/U 构建温度-相图。
  - **自旋激发**：线性化含时 Hartree-Fock（等价 RPA，64×64 体系）计算动力学自旋结构因子 S(q,ω) 与手性度量 Mχ(q,ω) = S⁺⁻(q,ω) − S⁻⁺(q,ω)；原子 SOC 项 HSOC = λ Σ⟨α|Li|α′⟩·⟨σ|Si|σ′⟩c†c 计入 HF+RPA；大 U 下用 SU(3)/SU(2) Schwinger 玻色子做线性自旋-轨道波理论（LSOWT），并通过对称性分析（自旋 SU(2)、C4v 点群、时间反演）纳入四阶微扰论才会出现的项（Jχ = 0.005、K = 0.0056 等）。

  ## 主要发现与核心结论

  - **相图与稳定区**：Hartree-Fock 相图（tx/tz = 0.7）显示，在四方压缩晶场（**Δ < 0**，即 xy 轨道近半填充）区域、较大 U/tz 下稳定出现 AFM+AFO 的交变磁 Mott 绝缘态，单粒子能带呈 dx²₋ᵧ₂ 波型非相对论自旋劈裂且在化学势附近有能隙；Δ > 0（四方伸长）区域则为无轨道序的 AFM+OD 绝缘态。U 与 |Δ| 协同稳定 ALM 态：**|Δ| 越大，实现 ALM 所需 U 越小**。增大 tx/tz 会把 ALM 推向符合 GK 规则的 FM+AFO 态——说明强的 xy-xy 轨道内跃迁对"绕开"GK 规则至关重要。
  - **量子涨落下稳定**：DMRG（8×4，键维数 2500，Δ = −1.5、tx = 1.0、U = 20）确认，在宽范围的弱到中等 JH/U 内 AFM+AFO 稳定；仅当 Hund 耦合很强时才转为 FM+AFO 或 FM+OD。能量判据：J^S > J^Sτ₁/4 且 J^τ > J^Sτ₁ 保证 AFM+AFO 优于 FM+AFO 与 AFM+FO；增大 JH/U 会减小 J^S、增大 J^τ 与 J^Sτ₁，最终破坏 ALM。半填充 xy 轨道的 t²z/U 项是稳定 AFM 的关键，t²x/y/U 项因内部反号项相互抵消而弱得多。
  - **温度相图与序温度**：比热 Cv/kBT 呈三峰结构——最高温峰（kBT ≈ 0.3）对应赝自旋熔化；中间峰（JH/U = 0.2 时 kBT ≈ 0.02）对应自旋关联建立温度 T^c_SO；最低温峰对应 AFO 序（Ising 对称破缺）建立，临界温度 T_OO ≈ 0.008/kB。JH/U = 0.275 时 AFM 与 AFO 转变次序反转——Hund 耦合决定相变次序。临界温度随 JH/U 反向变化，形成**穹顶状交变磁区**：参数 (tx, U) = (0.7, 20)tz 下最高交变磁临界温度 T_ALM ≈ 0.018/kB；取典型跃迁幅度 0.1-0.3 eV，对应约 **20-60 K**；对较温和的相关强度 U/tz ≈ 8-10，T_ALM 可达 **120-150 K**。这些转变纯由库仑关联驱动，**不需要 Jahn-Teller 效应和晶格畸变**。（二维 S-L 模型中 T^c_SO 是关联长度指数增长的特征温度；真实材料中四方晶场 + 原子 SOC 引起的 Ising 各向异性可赋予真正的二维长程序。）
  - **手性劈裂磁振子（首次发现）**：RPA 计算（U = 8.0tz、JH/U = 0.20、tx = 0.7tz）显示无能隙 Goldstone 模从 q = M 点出发，沿 M-X-Γ 与 M-Y-Γ 路径劈裂为两支（Γ-M 直线路径不劈裂）；Mχ(q,ω) 在两支间符号反转且满足 Mχ(C4q, ω) = −Mχ(q, ω)，证实 d 波型手性劈裂。劈裂量 Δχ（由 q = (π, π/2) 两处极点位置差量化）呈 **1/U³ 标度**，即由**四阶过程**产生的自旋交换驱动（而磁振子能量本身随 1/U 下降，对应二阶过程）；q = M/2 处磁振子能量低于 X(Y) 点，归因于高阶环交换项。S-τ 模型的二阶形式不含劈裂，需四阶项（LSOWT 中 Jχ = 0.005 等对称性允许项复现了 RPA 结果）。中等关联强度的真实材料中可预期中等劈裂，可在非弹性中子散射中观测。
  - **弱 SOC 效应**：λ = 0.04tz 时 AFM+AFO 基态保持，局域自旋锁定 ±z Ising 方向，赝自旋相对 Ising z 轴倾斜小角度 ϕ（自旋沿 +(−)z 的子晶格向 +(−)y 方向倾斜），仍保持共线 AFO；自旋激发在 q = M、X 点出现能隙——该能隙在有限温度下稳定二维交变相。
  - **磁振子-轨道子杂化与轨道电流（新预言）**：弱原子 SOC 存在下施加小的面内磁场，可实现磁振子与轨道子的杂化，使轨道子能直接在非弹性中子散射中被探测（绕开此前只有共振非弹性 X 射线散射能看到的限制）；出现具有**有限轨道极化**的手性磁振子-轨道子杂化模，在温度梯度下产生有限的纵向与横向轨道电导（图 5(f) 给出自旋电导随角度 η 的函数，温区 T ≈ 0.5 T_OO、T_OO < T_SO）。
  - **实验建议**：ALM→纯 AFO 或纯 AFM 的热致转变可在共振 X 射线衍射和中子衍射中观测；对 t2g 填充、关联较弱的材料，沿 z 方向加压增强四方压缩有助于稳定交变磁序；合成立方钒酸盐的准二维对应物是二维交变磁的方向。

  ## 潜在研究方向

  - **实验空白**：自发交变磁目前无任何实验证据——LaVO3 类材料（含其准二维对应物）的 ARPES/中子散射/共振 X 射线验证是首要开放问题。本文也指出 LaVO3 的 ab 面参数下已有变分团簇计算得到类似的自旋劈裂单粒子激发，支持平均场结论，但需系统检验。
  - **截断部分未及展开的问题**（正文在此截断）：四阶微扰论严格推导 LSOWT 中 Jχ、K 等项的微观系数；磁振子-轨道子杂化模的完整谱学与电导定量预测（文中仅给出 LSOWT 谱与自旋电导示意）；轨道极化与轨道电流的实验读出方案细节。
  - **模型局限**：热力学研究用半经典直积态近似（忽略纠缠），依赖 DMRG 显示的"量子涨落温和"这一前提；二维长程序依赖 SOC 诱导的 Ising 各向异性（论文自陈 Mermin-Wagner 限制）；S-L/S-τ 有效模型仅在大 U 极限严格。
  - **未解问题**：手性劈裂 Δχ 的 1/U³ 标度意味着在强关联极限劈裂极小——真实材料（中等 U）中劈裂的可观测性需逐案评估；ALM 态向超导/拓扑态的耦合（晶体学交变磁中已讨论的方向）在自发交变磁中完全未探索。

  ## 与林赛研究的关联

  - **交变磁 + 强场超快读出**：本组"order-parameter-ultrafast-readout"和"moiré strong-field probe"方向的直接理论输入。自发交变磁的电子能带自旋劈裂（dx²₋ᵧ₂ 波型）正是 HHG/阿秒瞬态吸收可读的序参量；T_ALM ≈ 20-60 K（可达 120-150 K）给出实验温区，磁光超快测量需要低温但可达的条件。
  - **手性磁振子作为超快探针**：1/U³ 标度的手性劈裂是一个可调的谱学窗口——通过压强/掺杂调节 U 即可调控劈裂量，THz 泵浦-磁振子激发或 NIS（核非弹性散射）实验可直接对标图 5 的 S(q,ω)。
  - **轨道电流通道**：面内磁场 + 弱 SOC 诱导的轨道极化杂化模与"轨道角动量输运"直接相关——超快光泵浦产生温度梯度（瞬态加热）后探测轨道电流/轨道霍尔信号，是把本论文预言接到超快实验台的具体接口，也为"交变磁超快读出"提供了区别于电荷/自旋的第三通道。
  - **材料接口**：LaVO3 及准二维钒酸盐、2 电子 t2g 体系；四方压缩（压应力/衬底应变）作为稳定 ALM 的旋钮——与莫尔/范德华异质结的应变工程天然兼容，可探索莫尔超晶格中交变磁与强场驱动的交叉。
  - **HHG/阿秒**：交变磁 Mott 绝缘体的 d 波自旋劈裂能带对强场驱动的亚周期磁动力学响应（自旋劈裂带间的阿秒相干操控）是"HHG + 交变磁"课题的候选体系。
