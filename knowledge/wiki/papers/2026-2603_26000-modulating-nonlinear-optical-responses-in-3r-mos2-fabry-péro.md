• # 3R-MoS₂ Fabry–Pérot 微腔中非线性光学响应的调制

  ## 林赛的理解

  这篇工作的核心价值不在于又测到了多大的谐波增强，而在于给出了一套**自洽的"几何腔效应 vs 本征材料性质"解耦框架**：用宽谱反射率做原位光学定标（绕开厚层 AFM 的形貌误差），再用 TMM + 电磁格林函数一路从线性反射谱算到 SHG/THG，把每个谐波级次里"基频 FP 共振、谐波 FP 模式、本征吸收"三者的贡献拆开。

  对我最直接的三点启示：

  1. **吸收是调控非线性的隐藏旋钮**。亚带隙谐波（700–800 nm）由基频+谐波双 FP 模式协同调制，谱形复杂；带隙以上谐波（466–533 nm）因强吸收把谐波腔模式阻尼掉，退化为"只受基频 FP 调制"的吸收限制区。这意味着同一个微腔，换泵浦波长就能在"双模式干涉调制"和"单模式吸收限制"两种物理 regime 之间切换——这是可设计的，不是缺陷。
  2. **SHG 调制深度做到 99 倍（约两个量级）**，且完全无需图案化加工，单片未加工 3R-MoS₂ 靠 n≈4 的折射率反差天然成腔。对我们做强场超快、追求片上紧凑非线性光源的方向，这是"零加工成本"的增强路径。
  3. **方法论可直接迁移**：反射率定标厚度 → TMM 定基频场 → 格林函数卷积非线性极化这套流程，对任何高折射率 vdW 材料（包括我们关心的莫尔体系、3R 堆叠体系）的谐波谱建模都适用，且他们诚实承认了 χ⁽²⁾ 色散未完全参数化导致的绝对强度包络偏差——提醒我们建模时共振峰位可信、强度包络需谨慎。

  ## 研究问题

  如何在**未图案化的单片 3R-MoS₂** 中严格追踪多个谐波场（SHG、THG）的演化，并把**几何 FP 腔增强**与**本征材料非线性性质**解耦？具体而言：3R-MoS₂ 因 n≈4（近红外）与周围介质（空气/SiO₂ 衬底）的巨大介电反差天然形成 FP 微腔，这一波长尺度的内禀腔效应如何调制各阶非线性发射？基频 FP 共振、谐波频率 FP 模式、材料本征吸收三者在不同谐波级次、不同光子能量区间各自扮演什么角色？

  ## 研究背景

  - TMDC 是高非线性极化率平台，但主流的 2H 相反演对称性完好，偶数阶非线性需靠单层或人为破缺反演。3R 相无论层数均保持反演对称性破缺，可实现远超单层极限的可扩展谐波产生。
  - 既往提升转换效率的努力依赖复杂人工结构：周期极化准相位匹配、垂直组装扭角相位匹配、图案化超表面的局域/共振模式激发等——工艺复杂且会遮蔽本征光学行为。
  - 3R-MoS₂ 一个被低估的特性是 n≈4（近红外，文献 25–29）的高折射率：厚层 regime 下与环境介质的巨大介电反差使**未加工单片薄片天然成为高效 FP 微腔**。内禀 FP 模式显著约束并重塑局域光场，深刻影响线性与非线性过程。因此严格解耦几何腔增强与本征材料性质，是准确评估和充分利用 vdW 微腔非线性潜力的前提。

  ## 研究方法

  - **样品**：机械剥离 3R-MoS₂（HQ Graphene 体单晶）至熔融石英（SiO₂）衬底（真空等离子清洗 SUNJUNE PLASMA VPR3 预处理），AFM（Bruker nanoIR3s）表征厚度。
  - **原位光学定标协议**：宽谱卤素灯反射率测量（600–1570 nm），可见段（600–965 nm）用 20× Nikon 物镜（NA=0.45）+ 光栅光谱仪（HRS-300SS-NI）+ PyLoN CCD；红外段（985–1570 nm）用 40× 反射物镜（LMM40X-P01，NA=0.5）+ PyLoN-IR CCD（965–985 nm 为探测器灵敏度交叠区数据缺口）。用 TMM 反射率模型（含材料本征色散）拟合提取每片精确厚度，取代厚层不可靠的 AFM。
  - **非线性测量**：可调谐飞秒激光（Levante IR fs, APE GmbH）经 5× Mitutoyo 物镜（NA=0.14）聚焦，背向收集 SHG/THG，带通滤波 + 同一光谱仪探测。SHG 激发谱 1400–1600 nm、10 nm 步进；THG 在 1400/1420/1440 nm 及 1500–1600 nm（10 nm 步进）测量，1450–1490 nm 因激光器该波段输出功率不足而剔除。恒定入射功率。
  - **理论**：线性反射谱用 TMM（计及多界面反射与相位积累）；非线性响应用电磁格林函数方法，观测点置于上界面（空气/3R-MoS₂）以对应背向收集，非线性场强 I_NL ∝ |E_NL|² ∝ |∫G·P_NL dz|²，源项 P²ω = χ⁽²⁾(E_ω)²、P³ω = χ⁽³⁾(E_ω)³；介电常数波长依赖取自文献（MoS₂ 引文献 25，SiO₂ 引文献 39）。

  ## 主要发现与核心结论

  - **FP 调制深度巨大**：SHG 强度比 Ratio = max[I_SHG(λ)]/min[I_SHG(λ)] 最高达 **99**，出现在 **1089.8 nm** 厚薄片，由 1480 nm 处强共振峰与 1440 nm 处深极小值形成；说明腔对非线性响应施加了显著的频率选择性。
  - **过程纯度验证**：SHG 双对数功率定标斜率 **2.01±0.01**；THG 为 **2.98±0.01**，分别确认为纯二阶/三阶过程。
  - **两种调制 regime 的分野由谐波光子能量相对带隙的位置决定**：
    - 泵浦 1400–1600 nm 时，SHG 光子 700–800 nm，**低于** 3R-MoS₂ 光学带隙，吸收弱 → 谱形复杂，由**基频与谐波双 FP 模式协同**调制，厚片（微米级）出现主共振峰之外的附加峰；理论 2D 图呈现纠缠的共振分支拓扑。
    - THG 光子 466–533 nm，**远高于**带隙，强本征吸收**重阻尼谐波腔模式** → THG 退化为**吸收限制 regime**，谱形简化为单一清晰峰，几乎只受基频 FP 共振调制；THG 与 SHG 2D 图振荡周期整体相似，印证共同驱动力是基频局域场增强，但 THG 图中缺少 SHG 的附加共振分支。
  - **可预测性验证**：预测用更短泵浦波长 1030 nm 时，SHG（∼515 nm）被推入带隙以上强吸收区，其谱形调制应平行于 THG 的吸收限制行为——补测实验（SI Sec. 5）证实了这一预测。
  - **激子特征**：反射谱中 A、B 激子共振增强峰约 **681 nm 和 631 nm**，与几何厚度无关，区别于色散的 FP 条纹，被 TMM 框架准确捕获。
  - **定标精度**：六个代表厚度（126.4 / 344.2 / 617.0 / 1089.8 / 1422.3 / 1821.4 nm）的逐谱对比中，理论与实验在峰位、振荡周期、谱线上均高度吻合；样本厚度跨度至 ∼3210 nm，线性反射 2D 图覆盖 600–1570 nm。
  - **模型边界**：共振峰位精确复现，但绝对强度包络有轻微偏差，归因于 χ⁽²⁾ 的波长依赖（色散）未在当前模型中完全参数化。
  - Discussion 中总结：内禀共振诱导的 SHG 增强**超过两个数量级**；非线性发射由三个因素一致支配——本征材料吸收、基频 FP 效应、谐波频率 FP 效应。

  ## 潜在研究方向

  - χ⁽²⁾/χ⁽³⁾ 的精确波长依赖未纳入模型，绝对强度包络拟合存在系统偏差——需要非线性极化率色散的独立测量与自洽参数化。
  - 全工作于**环境条件**、连续/准连续扫描的稳态-like 非线性响应；飞秒脉冲下的瞬态效应（激子、热、载流子动力学对 FP 腔的反馈）未涉及。
  - 未涉及泵浦强度进一步升高后的高阶非线性、饱和与损伤阈值。
  - 腔内局域场分布本身（而非仅背向收集谱）未被直接成像或时域分辨——与时空分辨非线性成像（如文献 16）结合是自然的下一步。
  - 扭角/莫尔堆叠引入的额外相位匹配与对称性自由度未与本征 FP 腔效应联动研究。
  - 带隙附近（谐波光子能量 ≈ 带隙）的过渡区行为（双模→吸收限制的 crossover 细节）值得精细扫谱。

  ## 与林赛研究的关联

  - **HHG/强场驱动**：本文是低阶（SHG/THG）非线性微腔物理，但"基频腔共振→局域场增强→非线性产额放大"的机制链条与高次谐波完全一致。把泵浦推向强场 regime，同一 FP 腔的基频场增强可直接用于 boosting HHG 产额；且他们演示的"泵浦波长切换调制 regime"在 HHG 中意味着可通过波长选择操控谐波谱的选择性——对阿秒光源的谱工程有借鉴意义。
  - **3R 堆叠 / 莫尔 / 量子几何**：3R 相的反演对称性破缺与层数无关，是量子几何（贝里联络极化率等）驱动非线性的载体；本文的解耦框架（腔效应 vs 本征非线性）正是从实测谐波谱中**萃取本征 χ⁽ⁿ⁾** 的必经步骤——对我们从莫尔/3R 体系谐波信号反演量子几何贡献至关重要，否则腔增强会被误读为材料本征。
  - **交变磁 / 磁性 vdW**：3R-MoS₂ 本身非磁性，但该"高折射率天然 FP 腔 + 反射率定标 + TMM/Green 函数"方法论可直接移植到磁性 vdW 薄片（如 MnPS₃、FePS₃ 等候选交变磁体），为交变磁诱导的奇次谐波（如 THG 作为 d-wave 交变磁序探针）提供腔增强与定量建模工具。
  - **实验接口**：反射率定标厚度的流程（600–1570 nm 宽谱 + TMM 拟合）可立即并入我们现有微区光谱 setups，作为 vdW 厚层样品的非破坏性厚度与腔模预表征标准步骤。
