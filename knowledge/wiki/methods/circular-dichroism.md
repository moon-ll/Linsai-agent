## 原理

圆二色/偏振分辨探测通过左右旋圆偏振光响应差异读出结构手性畴占据比、元素选择磁序与磁畴实空间成像（XMCD/磁圆二色监测奈尔矢量演化；纳米聚焦扫描透射 nano-XMCD 显微可在 200 nm 厚体相样品中以数十纳米空间分辨率直接成像交变磁畴与纳米纹理、确立其体相起源）、磁振子手性及其子晶格来源（CD-RIXS 以左右圆偏 RIXS 谱之差直接分辨磁振子手性与子晶格来源、给出确定性的奈尔矢读出信号；2025-2508.04388 的 CD-RIXS 理论进一步把磁群对称性结论转化为可测量谱学方案——经方位角与偏振扫描甄别共线磁序及其畴，将圆二色 RIXS 读出从磁振子手性/子晶格分辨扩展到对称性设计的共线磁序与磁畴判别通道）、声子手性/声子角动量与偶极矩旋转方向（红外圆二色 ICD 谱学以左右圆偏振红外光的差分吸收直接读出声子手性与偶极矩旋转方向；红外磁圆二色 MCD 谱学经磁光响应被理论论证为探测 Γ 点声子手性的灵敏手段、可分辨极小的圆偏振声子劈裂；CD-RIXS 在氧 K 边以左右圆偏振 X 射线散射强度差直接、元素特定地读出声子角动量的符号与大小，动量分辨 CD 对比度随声子动量 q 的变化进而映射布里渊区中声子角动量的分布——与零场 ICD、红外 MCD 互补，把圆二色声子读出从红外光学通道拓展到 X 射线共振散射通道，共同构成声子自旋/角动量的谱学探测手段）、晶体对称性与带间跃迁几何（螺旋度分辨 CD-HHG 以左右旋圆偏驱动光的谐波产率对比把圆二色从线性响应推广到强场非线性平台区，2024 拓扑高次谐波谱学方案进一步经左右旋驱动下的谐波响应对比提取与陈数符号锁定的手性信号，但左右旋驱动谐波谱与偏振对比研究提示其二色性信号依赖带间跃迁几何细节而非拓扑数，故应作为经对称性对照设计的陈数符号/跃迁几何探针而非普适拓扑不变量判据；HG-CD 普适对称性公式；纳米有限尺度偶极跃迁 CD 编码陈数符号）、谷自由度（Weyl 半金属 CPGE、圆偏驱动谷选择谐波）及 Bloch 电子量子几何（光二色可写成 QGT 解析函数：线偏跃迁由量子度规、圆偏跃迁由 Berry 曲率与轨道磁矩支配，已在 SnSe 中结合 tr-ARPES 与实时从头算演示螺旋度依赖谷布居失衡、亚皮秒电子-声子衰减谷极化与螺旋度可逆瞬态光电流）；强场非微扰区手性光场与手性电子结构耦合可产生显著超出电偶极近似的对映敏感信号（PECD 光电子圆二色与 HHG 圆二色），其中阿秒时间分辨 PECD 通过边带前后向发射不对称性的振荡相位提取手性分子二色性电离时间延迟，把圆二色从强度衬比测量拓展为手性敏感的阿秒计时计量；在超表面平台上左右旋向分辨的谐波强度不对称（HHG-CD）是定量判定“手性 HHG”成立的关键判据；自旋-动量锁定/圆二色表征可经自旋选择激发与谐波偏振-方向测量验证倍频光对泵浦拓扑自旋纹理的继承。

## 适用边界

除 2610.30930 的泵浦/探针参数、2502.18597 的纳米成像参数与 2603.06144 的氧 K 边共振边标定外，其余证据（含 HG-CD 公式、超表面 HHG-CD、阿秒 PECD、扭转双层圆偏谐波与倍频拓扑继承、2401.01100 陈数符号锁定方案、CD-RIXS 子晶格来源分辨、ICD 声子手性读出、红外 MCD 探测 Γ 点声子手性，以及 2508.04388 共线磁序/畴甄别的方位角-偏振扫描 CD-RIXS 方案）仍为摘要卡级定性描述，未提供 CD 衬比度、灵敏度、磁场范围、CD-HHG 平台区谐波阶次与驱动场强、陈数锁定信号幅度、HG-CD 公式具体形式及适用 (N, l, q) 范围、超表面谐波阶次与泵浦偏振条件、CD-RIXS 子晶格分辨条件、2603.06144 的 CD 对比度幅度与动量 q 覆盖范围/声子分支指认、二色性电离延迟数值与边带阶次、ICD 红外频率范围/声子模式与 CD 幅度、红外 MCD 可分辨圆偏振声子劈裂下限与磁光配置条件、2508.04388 的方位角/偏振扫描配置与共线磁序/畴甄别判据具体形式等可核数值，须回原文核实；2023-2303.17300 表明 CD-HHG 二色性信号依赖带间跃迁几何细节而非拓扑数、2024-2401.01100 主张经左右旋驱动对比可提取陈数符号锁定信号——以新证据为准，陈数符号锁定应理解为需对称性匹配设计与对照的方案级拓扑读出通道，裸 CD 不对称仍最易被带不对称等平凡机制与跃迁几何细节混淆，须与独立拓扑测量交叉验证；光学波段实空间畴读出受衍射极限与 CD 信号强度限制，nano-XMCD 虽以数十纳米分辨率突破该极限并确立交变磁纳米纹理体相起源，但依赖约 200 nm 量级薄样品透射几何与纳米聚焦圆偏 X 射线束线（同步辐射/XFEL），成本高；XMCD 信号幅度可能来自缺陷等非本征来源（高品质 MnTe 单晶中 XMCD 信号亦显著减小），纳米纹理体相起源与缺陷敏感磁信号判读须在高品质样品上做元素选择交叉验证；量子几何 CD 判读需动量分辨探测（tr-ARPES/XUV）与从头算实时模拟交叉验证，且谷选择激发与螺旋度依赖光电流并非必然并存（单层 MX2 的 D3h 水平镜面在近单位谷 CD 下仍禁戒面内螺旋度光电流）；谐波对泵浦自旋纹理的‘继承’判读须以自旋选择激发对照与谐波偏振-方向测量交叉验证并排除平凡自旋转移来源；HG-CD 提示非手性结构借结构光亦能诱导 CD，须区分光场结构诱导与材料本征手性；超表面 HHG-CD 判据须先排除样品各向异性、非手性背景与螺旋度依赖相位匹配等平凡不对称来源；CD-RIXS 依赖共振边选择与圆偏 X 射线束线、成本高，其子晶格分辨与‘确定性奈尔矢读出’判读依赖共振边与偏振配置的原文级核对，2508.04388 的共线磁序/畴方位角-偏振扫描甄别方案同为简报级线索、其磁群对称性判据形式、扫描/畴分辨配置与 CD 衬比幅度须回原文核实，且 2603.06144 的声子角动量读出（氧 K 边）目前为简报级线索，同样依赖圆偏软 X 射线束线与动量分辨散射几何，其动量分辨 CD 对比度映射受有限 q 覆盖与声子分支交叠限制，声子角动量判读须与磁振子 CD-RIXS 信号及结构不对称背景区分，CD 对比度随 q 变化的具体数值须回原文核实；偶极跃迁 CD—陈数判据限于有限尺度体系分立跃迁，外推体相连续谱需查原文核实；强场 PECD/HHG 圆二色的对映敏感信号本质超出电偶极近似、依赖非微扰强场区并须正确纳入磁偶极/电四极等高阶多极贡献，不能由电偶极层面对称性分析外推或替代，阿秒 PECD 二色性延迟提取还依赖边带前后向发射不对称性振荡相位的稳定干涉测量且须与不含手性信息的平凡平均电离延迟背景区分；ICD 声子手性读出依赖左右圆偏红外光对声子共振模式的差分吸收测量，其声子自旋与偶极矩旋转方向的判读细节及适用光谱范围目前仅为简报级线索，具体声子模式与衬比幅度须回原文核实；红外 MCD（2506.11258）读出 Γ 点声子手性目前为理论论证级简报线索，可分辨劈裂下限、所需磁场/磁光配置与红外频率范围等数值未见，其手性声子磁光信号判读须与零场 ICD 差分吸收及磁场诱导的平凡磁光背景区分，须回原文核实。
