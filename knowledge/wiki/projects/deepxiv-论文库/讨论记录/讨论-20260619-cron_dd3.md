## Trigger Conditions
- User asks for daily/regular research updates in their field
- User wants to track research trends and hot topics
- User requests research summary or newsletter

## Tool Priority: DeepXiv First

**IMPORTANT**: Web search engines return mostly news/journalism, not papers. Do NOT use web search as the primary paper discovery tool — results are biased toward older indexed content and polluted with non-academic hits.

**Correct priority order**:
1. **DeepXiv** — primary arXiv search CLI. Fast, clean JSON output. Use `execute_code` with subprocess (see DeepXiv section below). Run 3-5 parallel queries with different angle keywords, limit 5 each.
2. **arXiv direct** — browse https://arxiv.org/list/physics.optics/recent if DeepXiv is unavailable
3. **Google Scholar alerts** — set up once, get email notifications automatically
4. **Journal TOCs** — Nature Physics, PRL, Science Advances for curated recent highlights
