## 触发 Skill：research-daily-briefing

> 用户在多次 cron 会话中均触发 `research-daily-briefing` skill，要求按其规范生成学术领域的日常研究简报。

**Skill 名称**：`research-daily-briefing`  
**类别**：research  
**功能**：通过检索最新论文并汇编结构化报告，为特定学术领域生成日常研究简报。

### 触发条件

- 用户请求所在领域的日常/定期研究更新
- 用户希望跟踪研究趋势和热点
- 用户请求研究摘要或新闻通讯

### 工具优先级：DeepXiv 优先

**重要**：Web 搜索引擎返回的多是新闻/媒体报道，而非论文。不应将 Web 搜索作为主要论文发现工具——其结果偏向旧索引内容且混杂非学术结果。

**正确优先级**：

1. **DeepXiv** — 主要的 arXiv 搜索 CLI。快速、JSON 输出干净。使用 `execute_code` 与 subprocess 调用（见下方 DeepXiv 章节）。运行 3–5 个并行查询，每个查询使用不同角度关键词，限制 5 篇。
2. **arXiv 直接访问** — 若 DeepXiv 不可用，浏览 https://arxiv.org/list/physics.optics/recent
3. **Google Scholar 提醒** — 设置一次，自动接收邮件通知
4. **期刊 TOC** — Nature Physics、PRL、Science Advances 以获取精选近期高亮

### DeepXiv 子进程调用模式（终端管道被阻止）

```python
import subprocess, json
result = subprocess.run(
    ['deepxiv', 'search', 'YOUR QUERY', '--limit', '5', '--format', 'json'],
    capture_output=True, text=True
)
data = json.loads(result.stdout)
# iterate data['result'] for papers

# ️ CRITICAL: Paper dict keys to know:
#   arxiv_id  — deduplicate with THIS field (NOT 'id')
#   title     — paper title
#   tldr      — one-sentence summary (use this, not abstract for briefing)
#   authors   — list of dicts with name/affiliation
```
