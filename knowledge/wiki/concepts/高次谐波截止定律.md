# 高次谐波截止定律

## 林赛的理解

高次谐波截止定律（Cutoff law）是 HHG 最著名的特征之一。

对于原子 HHG，截止频率对应于电子在电场中获得的 maximum return energy：

E_cutoff ≈ I_p + 3.17·U_p

其中 I_p 是电离势，U_p = e²E²/(4mω²) 是ponderomotive potential（电子在激光场中晃动的平均动能）。

超过截止频率的谐波不存在——这是量子力学而非经典物理的结果，反映的是电离电子在返回母离子过程中能交换的能量上限。

固体 HHG 的截止定律比原子 HHG 更复杂，因为需要考虑能带色散和非抛物线性。
