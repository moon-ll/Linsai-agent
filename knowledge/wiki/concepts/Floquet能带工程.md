# Floquet能带工程

## 定义定位

Floquet能带工程（Floquet Band Engineering）指利用周期性外场（最典型为激光、圆偏振光）对固体电子能带进行非破坏性修饰与重构的方法体系。其理论根基是 Floquet 定理：时间周期驱动的量子系统可用准能量（quasi-energy）本征态描述，形成与平衡态 Bloch 能带对应的“Floquet 准能带”。区别于化学掺杂、静电门控、应变等静态调控手段，它通过光子–电子耦合在动量空间**选择性**地打开能隙、翻转能带序或重整化有效耦合项，实现“不更换材料、仅靠外场重写能带”的动态调控范式。在本知识库中属于方法类核心概念，是两篇驱动调控样本文献的公共理论底座。

## 物理内涵/技术原理

核心框架是 Floquet–Bloch 联合本征问题：对含时哈密顿量 H(t)=H(t+T)，在包含时间周期的扩展 Hilbert 空间（Sambe 空间）中求解 (H(t) − iħ∂ₜ)·φ_α(t) = ε_α·φ_α(t)。准能量仅在区间 (−ħω/2, ħω/2] 内有定义，具有与倒空间重复布里渊区相似的折叠结构。

按驱动参数可分为三个技术层次：

1. **高频繁区**（ħω ≫ 带宽）：对 Magnus/van Vleck 展开截断得到有效静态哈密顿量 H_eff ≈ H₀ + Σₙ [H₋ₙ, Hₙ]/(nħω)。圆偏振光下，矢量势 A(t) 的周期平均产生类似 Haldane 次近邻复跃迁项，破坏时间反演对称性，在 Dirac 点打开拓扑非平庸质量隙——这是光致拓扑相变的标准机制。
2. **共振区**（ħω ≈ 能隙）：出现光子副本带（replica bands）的杂交与 Floquet 侧带隙，需双简并微扰或非平衡 Green 函数处理；双色/双频驱动在该区可实现对不同能谷的不同阶共振。
3. **低频强场区**：出现 subharmonic 响应、动力学局域化与加热问题，须引入耗散或预热化图像。

物理效应层面包括：能隙开合与符号翻转（Lifshitz 转变）、有效 Zeeman 场与自旋–轨道耦合的重整化、Berry 曲率与 Chern 数的光致修改，以及由角动量守恒决定的手性选择定则（σ⁺ 光优先耦合 K 谷、σ⁻ 光优先耦合 K′ 谷）——这正是双样本（双色圆偏光谷极化、赝自旋选择性能带重构）共享的机制内核。

## 与现有方法/概念的关联

- 与 [[Floquet理论]]：本概念是 Floquet 理论在能带调控层面的工程化落地，前者管定理、后者管“怎么用”。
- 与 [[圆偏振光调控]] 与 [[时间反演对称性破缺]]：圆偏振光是本概念最常用驱动源，其手性直接提供破缺 TRS 的操作算符。
- 与 [[谷电子学]]、[[赝自旋]]：样本 2026-260803242（双色圆偏光驱动谷极化）将 Floquet 能带工程落到谷自由度的频率–手性联合选择上；样本 2023-2302_00604 则演示赝自旋通道分离的能带重构。
- 与 [[Haldane模型]]、[[光致拓扑相变]]：高频展开二阶项等价于动态 Haldane 质量项，即“用光实现 Haldane 模型”。
- 与 [[高频率展开]]、[[非平衡Green函数]]：分别对应弱驱动解析区与强驱动数值区的标准计算工具。

## 林赛理解

在本项目（光驱动低维体系的谷/赝自旋调控）中，Floquet 能带工程是把“外部驱动”翻译成“可计算能带语言”的中间层：一切“光致谷极化”“光致拓扑相变”“光调控有效质量”的论断，最终都要落到写出 H_eff、分析能隙位置与符号、追踪 Berry 曲率再分布这三步上。两篇样本恰好覆盖其两个应用切面——双色驱动对谷极化的联合选择，与赝自旋通道的选择性能带重写。做文献笔记时，应把每篇驱动类论文按“驱动参数 → H_eff 修正项 → 能隙/Berry 曲率变化 → 可观测效应”的链条归档到本概念之下，使其成为驱动调控类文献的索引枢纽与校验模板。
