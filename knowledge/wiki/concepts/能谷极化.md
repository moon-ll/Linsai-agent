# 能谷极化

## 定义定位

能谷极化（valley polarization）指固体能带结构中若干**不等价能谷**之间载流子布居出现不平衡的状态，典型对象是过渡金属硫族化合物（TMD）单层中位于布里渊区角点的 K 与 K′ 谷。时间反演对称性保证 K/K′ 谷严格简并、净谷极化为零；一旦体系破缺时间反演，或通过选择性激发、选择性输运在非平衡上注入布居差，即形成能谷极化，定量上用 P_v = (n_K − n_K′)/(n_K + n_K′) 描述。它是能谷电子学（valleytronics）的核心操作对象，也是判定二维磁体与莫尔体系中自发时间反演破缺的“序参量式”实验证据，可通过圆二色性、圆偏振发光、克尔旋转与反常霍尔信号读出。

## 物理内涵/技术原理

能谷是能带在动量空间中的局部极值，谷指标构成一个可类比自旋的内部自由度，其手性（贝里曲率与轨道磁矩的符号）在时间反演下相反。产生谷极化的物理途径主要有四类：

1. **光学选择性激发**：单层 TMD 中价带巨自旋-轨道劈裂使 K 与 K′ 谷分别与 σ⁺、σ⁻ 圆偏振光强耦合（能谷选择定则），圆偏振泵浦可直接注入谷布居不平衡。
2. **磁场与交换场**：谷轨道磁矩带来能谷塞曼效应；磁性近邻（如 CrI₃、EuS）或本征二维铁磁的交换场等效地在两谷引入相反的能量位移，诱导**平衡态**谷极化。
3. **相互作用驱动的自发极化**：在莫尔平带或窄带体系中，高态密度使某一谷味（valley flavor）优先占据，形成自发能谷极化——这正是 Stoner 型铁磁转变在谷指标上的投影，超越平均场的涨落会显著修正其临界行为与畴结构。
4. **应变与电场调控**：应变通过符号相反的伪规范场（“伪磁场”）作用于两谷；垂直位移场可调双层/莫尔体系的层间杂化与谷劈裂，实现电学开关式的谷极化调控。

探测层面：圆二色性/圆偏振 PL 给出激发-弛豫动力学，克尔/法拉第旋转给出磁性响应，反常霍尔效应是输运指纹（源于贝里曲率）。谷极化寿命由谷间散射（声子、缺陷、边缘）决定，是谷存储与谷逻辑的瓶颈参量。

## 与现有方法/概念的关联

- 与 [[贝里曲率]]：谷极化的反常霍尔响应与轨道磁矩均来自贝里曲率在谷处的集中分布，二者互为读出通道。
- 与 [[能谷霍尔效应]]：电场下贝里曲率使两谷横向分离，提供**无需破缺时间反演**的非平衡谷极化姊妹方案。
- 与 [[时间反演对称性破缺]]、[[Stoner 转变]]：相互作用驱动的自发能谷极化是二维/莫尔体系中 Stoner 铁磁的谷味版本，项目样本 2026-2607_13675 的超越平均场分析正关注其涨落修正。
- 与 [[应变工程]]、[[位移场调控]]、[[莫尔平带]]：样本 2026-260619954 展示应变+电场双 knob 调控谷极化；莫尔平带则为相互作用诱导极化提供高态密度平台。
