# 固体HHG机制

## 定义定位

固体HHG机制指强激光场与晶体（半导体、绝缘体等周期性固体）相互作用时产生高次谐波的微观物理通道，是气相 HHG（基于原子隧穿电离与电子再碰撞）在凝聚态体系中的对应与延展。与气体中主要由单原子响应主导不同，固体 HHG 的发射源包括两类通道——带内电流（intraband current）与带间极化（interband polarization），二者的相对权重由材料带隙、能带色散、驱动场强与偏振共同决定。该机制既是强场凝聚态物理的核心研究对象，也为能带结构、带隙、贝里曲率等电子结构参量的全光学测量提供了物理基础。

## 物理内涵/技术原理

**带内通道**：载流子（本征存在或先被激发到导带）在激光场作用下沿能带加速。由于能带色散 ε(k) 偏离抛物线，带内电流 J(t) = −e∫v(k)ρ(k)dk 呈非线性时间依赖，其傅里叶分解直接给出奇次（特定对称性下含偶次）谐波。极限情形下电子在布里渊区内往返运动，即 [[Bloch振荡]] 图像，谐波阶次可达驱动频率数十倍；带内截止对波长依赖较弱，随场强大致线性增长。

**带间通道（半导体再碰撞模型）**：结构上继承气体三步模型——(1) 强场 Zener 隧穿在带隙中产生电子–空穴对（固体版的“电离”）；(2) 电子与空穴在各自能带中被场加速、沿实空间分离并积累相对相位；(3) 场换向使波包重新交叠并复合，以光子形式释放复合能加动能。截止能量近似随 E² 增长，但受带间退相干时间与相位匹配截断。相邻半周期发射的干涉在谱上形成准分立的线状增强，可反演能带色散（全光能带重构）。两通道相干叠加，加上传播效应，共同决定宏观谐波谱。近年亚周期时间分辨实验（arXiv:2502.07390）开始在时域直接分辨带间极化的建立与衰减，验证了“复合集中在场过零附近”等关键预言。

## 与现有方法/概念的关联

- 与 [[三步模型]] / [[气体HHG]]：带间通道是三步框架（电离—加速—复合）在能带语言中的移植，“复合能”换成带隙加动能，退相干取代连续态寿命成为截止瓶颈。
- 与 [[Bloch振荡]]、[[贝里曲率]]：带内通道的准经典极限；反常速度与不对称能带引入反常电流与偶次谐波，是拓扑相关谐波诊断的基础。
- 与 [[阿秒瞬态吸收光谱]]：亚周期分辨带间极化的主要实验手段，见 [[2025-2502_07390-subcycle-observation-of-interband-polarizati]]。
- 机制源头文献：[[2015-1412_0141-linking-high-harmonics-from-gases-and-solids]]。
- 应用延伸：[[全光能带重构]]、[[隧穿电离]]（Zener 击穿的气相对应）。
