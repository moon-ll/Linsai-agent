# 高次谐波产生 (High Harmonic Generation, HHG)

## 定义定位

高次谐波产生（HHG）是一类强场非线性光学过程：当飞秒强激光（通常为红外波段，强度约 10¹³–10¹⁵ W/cm²）聚焦到原子或分子气体靶时，介质会辐射出驱动频率奇数倍（可达数百乃至上千阶）的相干光，频谱延伸至极紫外（XUV）乃至软 X 射线波段。HHG 是目前实验室台式相干短波光源与阿秒脉冲的主流产生方案，也是强场物理与阿秒科学的核心研究对象。

## 物理内涵/技术原理

主流物理图像是 Corkum 提出的“三步模型”（半经典描述）：

1. **隧穿电离**：强激光场使库仑势垒弯曲变薄，基态电子以隧穿方式脱离母体离子；
2. **加速**：自由电子在光场振荡中获得动能，有质动力能 Up ∝ I·λ²；
3. **回复复合**：光场反向后电子被推回母体离子，复合并以高能光子释放多余能量。

由此产生若干标志性特征：截止定律 E_cut = Ip + 3.17Up 决定最高光子能量；频谱呈“平台区 + 截止区”结构，平台内各阶谐波强度可比拟；气体介质中心对称，故仅出现奇次谐波；辐射具有优良的时间相干性与准直光束质量，平台区谐波相干叠加可形成阿秒脉冲串乃至孤立阿秒脉冲。量子层面，Lewenstein 强场近似（SFA）理论表明谐波由短/长量子轨道的干涉叠加构成，谐波相位携带复合瞬间电子波包与离子残余态的信息——这使 HHG 不只是光源，更是对母体离子电子结构的“内窥探针”（分子轨道层析成像的物理基础）。此外，采用双色/多色驱动场可打破空间反演对称性（允许偶次谐波）、精确调控电离与回复时刻，并将截止能量推向软 X 射线区（对应样本 arXiv:2501.12576 的双色场方案）。

## 与现有方法/概念的关联

- HHG 的“电离—回复”循环与 [[强场隧穿电离]]、[[阿秒脉冲产生]] 直接相关：截止区附近谐波的相干叠加形成阿秒时间尺度脉冲；
- 与 [[非序贯双电离]]（NSDI）共享同一强场电子回复物理，二者常作为伴生过程分析；
- 回复电子携带的振幅与相位信息支撑 [[分子轨道层析成像]] 及阿秒时间分辨测量；
- 样本 arXiv:2604.06707 将回复复合视为电子–离子 [[量子纠缠]] 的资源，把 HHG 从“光源”扩展为“量子传感/光谱过程”；
- 作为台式相干 X 射线源，与大型装置上的 [[自由电子激光]]（XFEL）形成互补关系。

## 林赛理解

在本项目的阿秒/强场文献网络中，HHG 是枢纽性支撑节点：它既是两个样本论文（纠缠阿秒量子光谱、双色场软 X 射线 HHG）共同的技术底座，也是理解“电子回复作为量子测量过程”的物理载体。我在后续阅读中重点关注两点：其一，双色场波形整形对谐波截止能量与量子轨道选择的调控能力，即光场波形的可编程性；其二，回复复合中电子–离子纠缠度如何被写入谐波场的振幅与相位，从而支撑量子增强型光谱方案。该概念当前引用频次仅 2、优先级 low，本页按支撑节点维护，待 [[阿秒脉冲]]、[[强场电离]] 等上游概念页成熟后再回填交叉链接。
