# 有限尺寸效应

## 定义定位

有限尺寸效应指当系统的空间尺度 L 不足以远大于其内禀特征长度（如边缘态局域化长度 ξ、载流子相干长度、波包尺寸或激发光波长）时，系统的可观测量——能谱、态密度、输运系数、光学响应——系统性地偏离热力学极限（L→∞）行为的现象。其物理来源主要有三：边界/表面占比随 L 增大以约 1/L 衰减；连续能带退化为间距约 1/L 的分立能级；动量空间退化为离散网格。在凝聚态数值模拟与固态高次谐波计算中，它既是必须评估的基本误差源，也是可以主动利用的物理探针。

## 物理内涵/技术原理

**（1）能谱离散化。** 有限体系中体态能级间距 ΔE 随尺寸增大而收窄（一维链上 ΔE ∝ 1/N），带隙内的拓扑边缘能级则近似不随 N 移动——这恰好使小尺寸体系中“体带—带隙—边缘态”的结构在能谱上清晰可辨，是数值上指认 [[边缘态]] 的常用手段。

**（2）边缘贡献的标度分离。** 边缘态局域于链两端，其布居与电流贡献近似与 N 无关，而体贡献近似 ∝ N。因此谐波产率的归一化方式（按总信号还是按每原子归一）决定了边缘谐波通道占比随 N 以 1/N 衰减还是趋于常数。通过扫描链长并将产率分解为体项 + 边缘常数项，可以把有限链的数值结果外推到宏观样品，这是尺寸收敛性测试的核心逻辑。

**（3）边界条件选择。** 周期性边界条件消除边界、恢复平移对称，但抹除拓扑边缘态；开放边界条件保留边缘态却引入有限尺寸伪影。二者交叉验证是 [[紧束缚模型]] 动力学模拟的标准做法。

**（4）有限尺寸标度（finite-size scaling）。** 在相变点附近关联长度发散，任何有限 L 都将其截断。标准处理是假设标度形式 A(L, t) = L^(−β/ν) f(t·L^(1/ν))，或用 A(L) ≈ A(∞) + c/L^ω 外推，提取热力学极限量与临界指数。这套方法论可迁移到拓扑相变（如通过边缘态能隙随 N 的闭合判定陈数改变）的分析中。

**（5）对固态 HHG 模拟的具体影响。** 有限链使带间共振条件被分立能级调制，谐波谱中出现尺寸依赖的峰位漂移与干涉结构；小尺寸下边缘贡献被系统性高估，若不做收敛性检验，容易把有限尺寸伪影误读为拓扑信号。

## 与现有方法/概念的关联

- 与 [[边缘态]] / [[体边对应关系]]：体拓扑不变量不依赖尺寸，边缘态数目受其保护，但边缘能级位置、展宽与可分辨性由比值 ξ/L 决定。
- 与 [[高次谐波产生]]：固态 HHG 的紧束缚与 TDDFT 模拟普遍采用有限超胞/有限链，尺寸收敛测试是区分体相通道与边缘通道、并把结论外推到实验样品的前提。
- 与 [[紧捆绑模型]]（[[紧束缚模型]]）：一维 SSH 链是最常用的有限尺寸研究平台，N 从几十到数百即可观察边缘能级收敛。
- 与周期性边界条件方法（PBC/k 点采样）互补：前者控制边界伪影，后者控制动量离散化伪影。

## 林赛理解

在本项目“拓扑边缘态对高次谐波贡献”的主线上，有限尺寸效应具有双重身份：一方面它是需要控制的伪影——小链中边缘贡献被放大、能谱分立化改变共振条件，直接引用原始谱形可能误导物理解释；另一方面它是信号放大器——有限链让带隙内的边缘能级与体带分离，便于在谐波谱上指认边缘通道。我的工程判据是：对 N ≈ 50–400 的链做谐波谱随 N 的标度，把产率分解为 ∝ N 的体项与近似常数的边缘项，再外推到热力学极限。该概念目前引用频次 2、优先级 low，属于支撑性概念，主要活跃在两篇样本论文的收敛性讨论部分，暂不单独立研究线。
