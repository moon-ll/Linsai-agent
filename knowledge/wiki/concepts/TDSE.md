• # TDSE（含时薛定谔方程）

  ## 定义定位

  TDSE（Time-Dependent Schrödinger Equation，含时薛定谔方程）是量子力学中描述量子态随时间演化的基本动力学方程，标准形式为 $i\hbar\,\partial_t|\psi(t)\rangle = \hat{H}(t)|\psi(t)\rangle$。它与定态薛定谔方程（TISE，本征值问题）相对：TDSE 是**初值问题**——给定初始波函数与哈密顿量，即可唯一确定系统后续的全部演化，扮演量子动力学"运动方程"的角色。在本项目语料中，TDSE 出现于两类语境：其一，共振 X 射线散射理论中，电子波函数在芯空穴势与 X 射线外场共同作用下的演化求解；其二，物理先验驱动的时间序列分析中，作为可嵌入学习模型的物理约束方程（PDE 先验）。

  ## 物理内涵/技术原理

  - **形式与结构**：$i\hbar\,\partial\psi(\mathbf{r},t)/\partial t = \hat{H}(t)\,\psi(\mathbf{r},t)$，其中 $\hat{H} = \hat{T} + \hat{V}(t)$ 为哈密顿量（动能 + 势能，可含时变外场）。方程对时间为一阶，保证初态决定整条演化轨迹。
  - **幺正性与守恒律**：演化算符 $U(t)=\exp(-i\hat{H}t/\hbar)$ 是幺正的，因此波函数范数（总概率）守恒；当 $\hat{H}$ 不显含时间时能量亦守恒。幺正性是量子演化可逆、无信息耗散的根源，也严格约束了数值格式的选择。
  - **与定态问题的关系**：当 $\hat{H}$ 不含时，分离变量 $\psi(\mathbf{r},t)=\phi(\mathbf{r})e^{-iEt/\hbar}$ 将 TDSE 化为 TISE 本征值问题；一般含时解可按本征态展开，各分量仅 accumulating 相位因子。
  - **微扰极限与散射**：一阶时间相关微扰展开导出费米黄金规则，是 X 射线吸收/散射截面计算的常用出发点；但在强场或超短脉冲（femtosecond/attosecond）条件下，Rabi 振荡等非微扰效应显著，必须直接数值求解 TDSE。
  - **数值方法谱系**：空间离散（有限差分/格点/有限元）+ 时间推进。典型格式包括 Crank–Nicolson（隐式、保幺正）、劈裂算符-傅里叶法（split-operator，谱精度）、Runge–Kutta 与 Krylov 子空间法（如短迭代 Lanczos，适合大稀疏 $\hat{H}$）。显式欧拉因破坏幺正性一般不可用。
  - **数据驱动侧**：TDSE 可作为 PDE 残差软约束写入 PINN 类损失函数，或以其演化算符/传播子形式充当时序模型的物理归纳偏置，用少量物理先验换取数据效率与外推稳定性。

  ## 与现有方法/概念的关联

  - **TDSE vs [[薛定谔方程]]（TISE）**：初值问题视角 vs 本征值视角；TISE 是 $\hat{H}$ 不含时下 TDSE 分离变量的特例，二者共享哈密顿量结构但用途迥异。
  - **微扰极限 → [[费米黄金规则]]**：弱场下由 TDSE 一阶微扰导出，连接到散射截面与跃迁速率的计算。
  - **多电子近似 → [[TDDFT]]**：多电子体系直接解 TDSE 不可行（维度灾难），含时密度泛函理论以含时密度替代波函数作近似。
  - **机器学习侧 → [[PINN]]**：样本 arXiv:2509.18483 将物理方程作为时序分析的先验约束，TDSE 是此类"物理信息"范式中的典型算例。
  - **应用侧 → [[共振X射线散射]]**：样本 arXiv:2406.1962 中，散射振幅由电子在芯激发与 X 射线场下的 TDSE 演化波函数给出，非微扰求解是理论核心。
  - **数值实现 → [[TDSE求解器]]**：TDSE 的数值求解已沉淀为独立的 A 级完整方法页，覆盖具体求解器实现。

  ## 林赛理解

  在我的项目研究版图中，TDSE 是连接"第一性原理量子动力学"与"数据驱动建模"两个世界的桥梁。共振 X 射线散射那份样本表明：超短脉冲下的电子动力学必须非微扰地解 TDSE 才能得到正确的散射信号，这为量子体系的真实时间演化提供了基准真值（ground truth）；而 physics-informed 时序分析那份样本则把 TDSE 这类方程降格为模型中的软约束，用物理先验换取数据效率。二者合流提示了一条互补方法论：**小体系精确解 TDSE 做验证 + 大体系用物理约束学习做外推**。本概念当前引用频次仅 2、优先级 low，属于背景级概念——暂不深挖数值实现细节。
