# 高次谐波光谱学

## 定义定位

高次谐波光谱学（High Harmonic Generation Spectroscopy，HHG 光谱学）是以强场激光与物质非线性相互作用辐射出的高次谐波（频率为驱动场整数倍、可延伸至极紫外的相干光）作为“读出信号”的超快光谱技术。与把 HHG 当作桌面极紫外/阿秒光源的用法不同，它把谐波谱的强度分布、截止阶次、相位、偏振与螺旋度视为介质内部电子与晶格动力学的指纹，借助正演建模与反演分析，从谐波信号中提取能带结构、拓扑不变量、对称性破缺及原子级动力学信息，兼具亚周期（阿秒量级）时间分辨与动量/实空间信息编码能力，是强场物理与凝聚态光谱的交叉枢纽。

## 物理内涵/技术原理

其物理核心可由“三步模型”概括：强场隧穿电离产生电子波包 → 波包在激光场中被加速并积累动能 → 回核复合时以高次谐波光子形式释放能量，谐波阶次与截止能量由再碰撞动能决定。固体中的机制则分为两条通道：**带间极化**（对应再碰撞图像，复合偶极矩阵元携带布洛赫波函数与动量信息）与**带内电流**（布洛赫振荡、反常电流），二者相干叠加决定谱形。

光谱学信息主要体现在四个层面：

1. **对称性判据**：中心反演对称破缺由偶次谐波出现来判定，晶格/电子对称性直接调制谐波偏振；
2. **拓扑与几何结构**：圆偏驱动下谐波的螺旋度与圆二色响应编码贝里曲率与自旋-轨道耦合，可用于拓扑相变的全光学判定；
3. **实空间动力学**：谐波发射时刻锁定于驱动场相位，对核位移高度敏感，可反演声子振动与结构相变的实空间轨迹；
4. **非平衡动力学**：谐波在单个光学周期内产生，天然具备亚周期时间分辨，可跟踪载流子散射与退相干过程。

定量反演依赖正向模型（半导体布洛赫方程、含时密度泛函理论、Wannier-Stark 展开）对谱特征的拟合与参数化提取。

## 与现有方法/概念的关联

- 与 [[强场物理]]、[[阿秒科学]]：共享隧穿电离与再碰撞的语言体系，是气相 HHG 向固体推广的桥梁；
- 与 [[贝里曲率]]、[[拓扑物相]]：谐波的圆二色与偏振旋转充当拓扑量的全光学探针，弥补输运测量在非平衡/光驱动情形下的失效；
- 与 [[半导体布洛赫方程]]：作为最常用的正演模型，把微观带间/带内电流映射为可观测谱；
- 与角分辨光电子能谱（ARPES）互补：ARPES 直接读占据态动量分布但表面敏感，HHG 光谱为体敏感、全光学，代价是需要反演建模。

## 林赛理解

在本项目中，高次谐波光谱学是连接“光驱动非平衡动力学理论”与“实验可观测量”的主测量通道。三条样本文献恰好覆盖其三类典型应用：拓扑相的全光学检测（2305.02025）、光驱动动力学的谐波读出（PRB 105, 155140）、晶格动力学的实/倒空间探测（2605.20631）。对本项目的操作含义是：任何光致相变或 Floquet 工程方案，最终都要回答“谐波谱上可分辨什么”——因此建模管线（SBE/TDDFT）的输出必须落到谱特征（偏振、螺旋度、截止阶次、奇偶次分布）上与文献对比。该概念当前引用频次仅 3 但横跨拓扑、自旋与晶格三个子方向，适合作为综述叙事的串联线索与跨方向术语锚点。

## 学习路径/参考

**学习路径：**
1. 先掌握气相三步模型与截止定律，建立谐波-再碰撞的物理图像；
2. 进入固态 HHG：带间/带内通道、Wannier-Stark 态与布洛赫振荡；
3. 攻读偏振/螺旋度读出方向：圆二色、贝里曲率响应与拓扑判定；
4. 上手半导体布洛赫方程正演代码，复现样本文献的谐波谱特征。
