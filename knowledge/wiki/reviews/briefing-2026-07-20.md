### 2. Hermes 默认 gateway 诊断（11:49 "hermes好像挂掉了"）
- **现象**：用户感觉 hermes 无响应
- **诊断**：
  - linsai gateway（PID 90910）**没挂**，10:18 已重连飞书，正在回这条消息
  - 真挂的是**默认 profile gateway**（PID 90726）：循环重试飞书连接 22+ 次，每次报 `TypeError: Client.__init__() got an unexpected keyword argument 'extra_ua_tags'`
- **根因**：
  - 10:16 默认 gateway 启动时加载的是旧版 lark_oapi（不支持 `extra_ua_tags`）
  - 10:17 lark_oapi 被升级到 1.6.8（adapter.py:4749 调用的 `extra_ua_tags=["channel"]` 在新版已支持）
  - 但默认 gateway 进程没重启，**内存里还是老版镜像** → 永远循环报错
  - linsai gateway 10:18 启动 → 加载新版 → 连接成功 ✓（这就是两个 gateway 表现不同的原因）
- **处置**：
  - 无法在 linsai gateway 内 kickstart 默认 gateway（会自杀）
  - 给用户命令让其在**外部 shell** 跑：`launchctl kickstart -k gui/$(id -u)/ai.hermes.gateway`
  - 备选建议：若默认 profile 已不再使用，可 `launchctl bootout` 彻底停掉避免循环重连浪费资源
