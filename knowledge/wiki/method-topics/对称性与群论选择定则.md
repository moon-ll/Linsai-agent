# 对称性与群论选择定则（磁空间群 / 自旋空间群 / EFT 幂次计数）

> **专题定位**：从晶体对称性推导 HHG 允许通道与选择定则的完整工作流——
> 磁空间群/自旋空间群分类、对称性允许的谐波阶与偏振通道、以及 EFT 幂次计数
> 作为「选择定则的解析引擎」。本页同时是 `methods/磁性空间群群论对称性分析`
> 与 `methods/自旋空间群对称性分析` 两个工作页的方法学归宿。

## 一、基本理论原理

**1.1 对称性 → 允许通道的映射。** 晶体的（磁）空间群决定极化张量允许的谐波阶与偏振组合：中心对称体系压灭偶阶（电偶极近似下）；磁序引入时间反演破缺通道（磁场依赖的谐波各向异性）；交变磁体的 d 波/g 波自旋劈裂在动量空间各向异性分布，直接映射到谐波谱的磁场方向依赖与偏振通道（Werner 等的 altermagnet HHG 理论[2]：3ω ~15%、5ω ~30% 的各向异性是 d 波劈裂的谱签名）。自旋空间群（SPG）框架把「晶格旋转 + 自旋旋转」的联合对称性分类，是 altermagnet 谱学分类的现代表述（框架综述见库内 NSFC-T1 Q3/Q6[3]）。

**1.2 EFT 幂次计数：选择定则的解析引擎。** 对称性分析传统上给「允许/禁止」的二值结论；EFT 分层 Hamilton 族把它升级为**定量标度**[1]：以 λ 参数化对称破缺算符强度，谷奇谐波产量 ∝λ（一阶允许）、谷偶谐波 ∝λ²（二阶允许）——幂次计数直接读出「哪个谐波阶对哪个破缺算符最敏感」。λ=0 对称极限构成**严格空检验**：选择定则禁止的信号在此必须严格为零，任何非零即非物理结果或数值伪象。

**1.3 谷-螺旋度锁定实例。** ω-2ω 反旋圆极化场下，H4/H5 领头修正算符旋转方向相反、由相反能谷发射——对称性分析不仅给「有没有」，还给「哪个谷发什么旋向」（详见 [[材料体系HHG方法]] 的 EFT 应用[1]）。

## 二、核心算法实现（可参照复现）

**2.1 对称性工作流（四步）。**
① 群识别：确定体系的 MSG/SPG 编号与生成元（磁结构解 / 自旋构型分类；工具链：文献群表 + 库内 NSFC-T1 框架[3]）；
② 规则推导：对目标响应（偶/奇阶谐波、CD、线二色）做不变量分析——极化张量的对称允许分量表，得到「哪些通道为零、哪些一阶允许」；
③ 最小模型：构建尊重目标对称性的最小 TB（约束：对称极限下禁阻通道系数严格为零）；
④ EFT 标度与空检验：引入 λ 扫描破缺强度，验证 ∝λⁿ 标度律与 λ=0 零点，再校核真实材料强度（λ=1）处的领头阶精度（H4 对真实石墨烯谷对比 10% 以内的经验线[1]）。

**2.2 参数表（复现锚点）**：

| 量 | 内容 | 出处 |
|---|---|---|
| 分层族 | H_λ(k)=\|t/λ\|[f(K_τ+λq)σ₊+h.c.]，λ∈[0,1] | [1] |
| 谷奇/谷偶标度 | 谷奇 ∝λ，谷偶 ∝λ² | [1] |
| 领头阶有效性 | x=λa_cc·A₀ ≤ 0.5；H4 场强上限 ≤10¹¹ W/cm² | [1] |
| 交磁谱签名 | 3ω ~15%、5ω ~30% 磁场依赖各向异性 | [2] |
| 空检验 | λ=0 下 P_N 严格为零（选择定则） | [1] |

**2.3 验证清单。** ① 对称极限零点检验（必过）；② 群分类交叉验证（MSG/SPG 编号与文献磁结构一致）；③ 标度指数与幂次计数一致；④ 真实材料参数（λ=1）下领头阶 vs 全算的偏差 ≤10% 量级[1]。

**2.4 适用边界。** ✅ 选择定则推导、非物理信号过滤、对称破缺强度的定量反演（与 [[HHG反演方法学]] 的解析先验衔接）。❌ 对称性分析不给出绝对产额（需动力学引擎）；磁畴/无序引起的对称性平均需显式建模；SPG 框架对复杂非共线磁构型的完备分类仍在发展中（库内 NSFC-T1[3] 的竞争格局节）。

### 扩展 A：分类计数谱系（2024 SSG 完备化，联网检索）

磁对称分类的三级层级与计数：**122 磁点群**（有限群）→ **1,651 磁空间群 MSG**（Shubnikov 黑白群）→ **自旋空间群 SSG**（2024 全分类）：**1,421 共线 + 9,542 共面 + 56,512 非共面**。SSG 解耦自旋与空间旋转，是交磁体（d/g 波劈裂）、_altermagnet_ 谱学选择定则的完备语言；工具链 **FindSpinGroup**（磁结构 → 取向 SSG + 自旋劈裂性质自动识别）。

### 扩展 B：不变量分析实例（两个标准例子）

**例 1（反演对称 + 镜面）**：中心对称晶体（含反演 i）→ 电偶极 χ⁽²⁾ = 0 → 偶阶谐波在电偶极近似下禁阻；磁序引入 i·T 组合（黑白群反操作）可部分解禁——「偶阶出现」即磁序/界面破缺的指纹。
**例 2（三重旋转 + 手性）**：三重轴 C₃ 体系 → 各阶谐波偏振受 C₃ 不变量约束——ω-2ω 反旋构型下谷对比度 P_N 在 warping→0 极限严格为零（λ=0 空检验，EFT[1]）。

### 扩展 C：工作流工具链

① 群识别：FindSpinGroup（SSG）/ ISOTROPY（MSG）；② 规则推导：极化张量不变量表；③ 最小模型：对称约束 TB（λ 扫描）；④ 空检验 + 幂次计数。与 [[材料体系HHG方法]] 的模型栈、[[多变量光场设计]] 的扫描协议直接衔接。

## 三、典型应用案例

**案例 1（严格空检验过滤非物理结果）**：EFT 框架在谷对比反演中的应用[1]——λ=0 极限下任何非零谷对比直接归因 warping/tilt/mass 算符，把「数值是否可信」变成对称性命题。

**案例 2（交磁体谱签名预言）**：Werner 等[2]的 3ω/5ω 磁场依赖各向异性预言——SPG/d-wave 对称性 → 谐波通道的定量映射模板（实验设计直接引用）。

**案例 3（Kagome 模型的对称通道）**：2508.15631 的三模型对比[4]中，breathing Kagome 的 HOTI 通道与 Haldane/Kane-Mele 的对比展示了「同一框架、不同对称类」的系统扫描方法。

**案例 4（国内竞争格局定位）**：Liu & Si 的国内 altermagnet HHG 计算首例（PRB 112, L081105, 2025，见库内 NSFC-T1 Q6[3]）——对称性框架用于文献定位与空白识别（偶子格国内空白、奇子格待补）。
