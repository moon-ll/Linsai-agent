# 强场电离量子轨道方法（SFA / CQSFA / Q-CCSFA）

> **专题定位**：强场电离与再碰撞过程的半经典量子轨道方法谱系——从 Keldysh 理论到
> Coulomb 修正再到量子光场扩展的完整演进，含鞍点方程数值流程与可复现要点。
> 服务于电离端课题设计、BSV/量子光方向、以及与固体 SBE 框架的对应关系建立。

## 一、基本理论原理

**1.1 Keldysh 理论与电离区间。** Keldysh 参数 γ = ω√(2I_p)/F 划分电离区间：γ≫1 为多光子区，γ≪1 为隧穿区[1]。强场物理的主要工作区（10^13–10^15 W/cm²，光学至中红外波长）多为 γ≲1 的隧穿区，此时电离可视为「在复时间平面上穿越被场压低的势垒」，电离幅由穿越作用量控制——这一复时间/作用量语言是全部量子轨道方法的公共基础。

**1.2 SFA（强场近似）。** Lewenstein 等建立了 HHG 的完全量子表述[2]：电离幅对 Volkov 态（激光场中自由电子态）展开，忽略束缚势在连续态中的残留影响。由此电离-传播-复合被组织为对量子轨道（鞍点解）的相干求和：每条轨道由复电离时刻 t_i、复合时刻 t_r 与复动量 p 标记，其相位 = 作用量 S 沿轨道的积分。短轨道与长轨道族在谱上干涉，给出平台结构与截止位置；椭圆极化推广见 Antoine 等[2]所引谱系。

**1.3 CQSFA（Coulomb 修正 SFA）。** 纯 SFA 丢弃末态 Coulomb 势，导致低能结构缺失与绝对产额偏差。Popruzhenko–Bauer 谱系引入 Coulomb 修正：对作用量与波函数幅度加末态散射相位与轨迹偏折修正[3]；Popruzhenko、Paulus 与 Bauer 进一步给出 Coulomb 修正量子轨道的系统构造，使轨迹在原点附近无奇点且可数值传播[4]。修正后的 CQSFA 在任意激光频率下与 TDSE 符合良好[3]。

**1.4 Q-CCSFA（量子光扩展）。** 库内方法卡（2610.16077）确立的「最小量子化修改」路线：把经典场近似中的全部经典场量替换为量子光场的期望值/量子取样——零均值 BSV 场作为量子微扰与相干态驱动场相位相关混合。亚周期隧穿波包的发射时刻与初动量仍由鞍点方程决定，但对瞬时场正交分量相位敏感，因而相敏电子动量 ⟨p_z⟩(φ_rel, I_α) 成为光场正交分量的读出探针。对 BSV 量子统计（光子数/Wigner 分布）做系综平均后可定量重现混合场的 PMD、计数统计与能谱。

**1.5 与固体框架的对应。** 气体 saddle-point + action phase 提取迁移到固体的标准路径：SBE 半经典近似下的带间轨道 + 带内加速（课题 A 推导 Step 1.3，记号锁定后 saddle-point 从 SBE 相位中提取 φ_coh^solid）；系综平均引入 dephasing 与 SBE 显式退相干项构成两种对照方案（见 [[固体HHG数值计算方法体系]] §2.3）。迁移时必须保留机制检验：液体/气体再碰撞 vs 固体带内加速机制不同。

## 二、核心算法实现（可参照复现）

**2.1 鞍点方程与数值流程（五步）。**
① 场定义：A(t) 与 E(t)，工作波长/强度定 γ；② 鞍点求解：∂S/∂t_i=0（电离时刻）、∂S/∂t_r=0（复合时刻）、∂S/∂p=0（动量），在复时间平面上以 Newton–Raphson 迭代求解，初值取稳相近似 p≈A(t_r)；③ 轨道分类：按 ∓π 相位差与轨迹时长分短/长轨道族（气体 HHG 中 P₁–P₄ 类发射通道在 BSV 场下被推到不同最优压强，即 σ₃=−σ₁、σ₄=−σ₂ 的四通道结构）；④ 幅度与相位：每条轨道贡献 e^{iS}×预因子（van Vleck 因子 + 电离率 W(t_i)），电离率用 Popruzhenko 任意频率 Coulomb 修正公式[3]；⑤ 谱合成：对轨道求和做傅里叶分析，系综问题叠加量子统计平均。

**2.2 Q-CCSFA 复现要点**（2610.16077 方法卡）：
- 场构型：800 nm 线偏振相干态驱动 + 1600 nm 零均值 BSV 量子微扰，相位相关混合；
- 相敏量：⟨p_z⟩ 对相对相位 φ_rel 与 BSV 强度切片 I_α 的二维扫描；
- 系综：对 BSV 光子数分布采样（SPDC 源 ~10⁴ 光子/模量级），逐样本算 PMD 后平均；
- 反演：连续 φ_rel 扫描 + shot-resolved 强度切片，在 Husimi Q ≈ Wigner 的宏观场近似下重构 BSV Wigner 函数（压缩正交方向 δ 锐化、反压缩方向有限宽）；
- 实验端依赖：高重频 BSV 源、相位锁定、COLTRIMS 单发动量记录——复现前先评估源可达性。

**2.3 验证清单。** γ→0 极限复现 Landau 隧穿率（Popruzhenko 修正公式的标准检验[3]）；关闭 Coulomb 修正退化回 SFA 复现短/长轨道干涉图样；TDSE 对照（原子体系用库内 1407.6613 的 3D TDSE 传播栈作基准[9]）。

**2.4 适用边界。** ✅ 隧穿区电离谱、HHG 轨道分辨解释、量子光场读出。❌ 多电子关联缺失（对照 RPAE/TDSE，见 [[B-spline_TDDFT_计算场自由_EWS_时延]]）；Coulomb 修正沿末态单散射近似，深束缚/低能区仍有偏差；固体问题不可直接套用气体公式（需 SBE/Bloch 加速重表述）。

### 扩展 A：PPT/ADK 定量框架

隧穿区电离率的解析谱系：**PPT 理论**（Perelomov–Popov–Terent'ev 1966）给出任意频率准静态近似下的电离率（含库仑尾修正）；其 γ→0 极限即 **ADK**（Ammosov–Delone–Krainov）公式：

W_ADK ∝ |C_{n*l*}|² · F/(κ²) · (2κ³/F)^{2n*−|m|−1} · exp[−2κ³/(3F)]

（κ=√(2I_p)，n*=Z/κ）——指数因子即「穿越作用量」的 WKB 面积。Popruzhenko 2008 的任意频率 Coulomb 修正把该公式推广到 εω ~ I_p 区（修正因子乘入指数）[3]。
数值实践：ADK 作初值/权重，CQSFA 轨道作动力学，TDSE 作基准——三层精度栈。

### 扩展 B：鞍点求解的数值细节

- **复时间平面**：t_i, t_r ∈ ℂ；Newton–Raphson 初值取稳相近似（p ≈ A(t_r)）
- **Stokes 现象**：鞍点对的 Stokes 线 crossing 处轨道贡献突变——轨道计数随场强变化，是「轨道突然出现/消失」的数学根源
- **支切割**：√(k²+κ²) 的分支选择决定电离 vs 复合通道一致性
- **轨道滤波**：短轨道保留（phase matching 窗口）、长轨道压制（实验几何）

### 扩展 C：BSV 四通道的 σ 结构细节

Wang 等[8]的通道结构：σ₃ = −σ₁、σ₄ = −σ₂（两对镜对称副驱动相位），压强扫描下四通道的最优压强两两分离——这使「通道分辨的光子统计测量」成为可能：在单一通道最优压强下测 g⁽²⁾，避免通道混叠污染（详见 [[量子光驱动HHG方法]] §2.1）。

## 三、典型应用案例

**案例 1（量子光场读出）**：Q-CCSFA 把强场电离升级为 BSV 光场 Wigner 函数的相敏反演仪[5]——「量子光场→强场过程→量子光场可读出」闭环的电离端实现，与 HHG 端（2604.06707）构成双向验证。

**案例 2（BSV 三部曲）**：库内理论三角把 BSV-HHG 组织为输入态表征（2608.16027）→ 输入态-动力学解析连接（2604.09284）→ 输出态（2410.15503）闭环，电离端 Q-CCSFA 与谐波端 2604.06707/2604.06703 共用本文的鞍点方法栈[5][6][7]。

**案例 3（相位分解迁移）**：Wang 等的气相 action phase 分解[8]——σ 扰动把四条发射通道推到不同最优压强——正是 SFA 量子轨道语言的应用实例；其向固体的迁移（σ_solid 三分解）构成课题 A 的核心命题。

**案例 4（TDSE 对照基准）**：1407.6613 的 HF+RPAE+3D TDSE 栈为 SFA/CQSFA 精度校核提供基准数据（Ne 2p-2s 相对时延理论值 4.82/8.19 as 对照实验 21±5 as 的分歧即方法敏感性实例，详见 [[阿秒计量方法体系]]）[9]。
