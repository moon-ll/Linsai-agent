# 量子光驱动 HHG 方法（BSV / 压缩光 / 输出态层析）

> **专题定位**：以非经典光场（亮压缩真空 BSV、压缩态）驱动的 HHG——谐波光的
> 量子态（光子统计/纠缠/压缩）如何被驱动场量子态塑形、如何表征、如何反演，
> 完整输入态-动力学-输出态闭环。电离端读出见 [[强场电离量子轨道方法]]。

## 一、基本理论原理

**1.1 HHG 的量子光学本质。** HHG 产生的辐射不是经典相干态：谐波模式呈双模压缩、高斯纠缠（Rivera-Dean 等[1]）；光子探测过程本身把谐波模式纠缠化（Stammer[2]），光场模式间的纠缠与压缩已被实验确认（Stammer 等 PRL 2024[3]）。这意味着谐波输出是可设计的量子资源——驱动场的量子统计（而非仅其经典包络）决定输出态。

**1.2 BSV 驱动的输入-动力学-输出闭环。** 库内理论三角给出方法组织：输入态表征（[[2608.16027]]，BSV 光子统计/Wigner 函数）→ 输入态-电子动力学解析连接（[[2604.09284]]）→ 输出态（[[2410.15503]]，谐波光子统计/纠缠）。BSV 的零均值、强涨落（SPDC 源 ~10⁴ 光子/模）使驱动力成为对经典三步模型的量子微扰：谐波产额对光场正交分量相位敏感，输出光子统计偏离 Poisson（超 Poisson 保持问题——传播中的非耗散条件见 [[宏观传播与相位匹配工程]] 的 ∇σ 传播指纹）。

**1.3 action phase 语境。** Wang 等把 BSV 副驱动的贡献归结为 σ 相位项（φ_act = φ_coh + σ）[9]：σ 的四通道结构（σ₃=−σ₁、σ₄=−σ₂）使各发射通道在压强维度可分离。该分解是连接「驱动场量子统计 → 谱指纹」的解析桥梁，其向固体的迁移（σ_solid）是课题 A 的核心命题。

## 二、核心算法实现（可参照复现）

**2.1 BSV-HHG 全流程（五步）。**
① 输入态制备与表征：SPDC 产生 BSV，光子数分布/正交分量统计表征（[[2608.16027]] 方法栈）；
② 场量子化替换：经典场量 → 量子期望值/取样（[[2610.16077]] 的最小量子化修改路线，电离端 Q-CCSFA）；
③ 鞍点动力学：发射时刻/动量由 saddle-point 方程决定，对瞬时场正交分量相位敏感；
④ 系综演化：对 BSV 光子数分布采样，逐样本算 HHG 谱，按量子统计平均——复现要点：50 级系综规模与压缩参数（r 值）扫描的收敛检查；谐波光子统计（g⁽²⁾、Mandel Q）与纠缠度量（模式的压缩谱）作为输出读出[1][3]；
⑤ 态层析：原位四缝干涉量子态层析 + shot-resolved 强度切片（[[2511.18362]]），重构输出模式的 Wigner 函数。

**2.2 参数表（复现锚点）**：

| 量 | 数值/要点 | 出处 |
|---|---|---|
| 驱动构型 | 800 nm 相干态 + 1600 nm 零均值 BSV 混合 | [[2610.16077]] |
| BSV 源强度 | SPDC ~10⁴ 光子/模（高增益） | [[2610.16077]] |
| 相敏读出 | ⟨p_z⟩(φ_rel, I_α) 二维扫描（电离端） | [[2610.16077]] |
| 通道分离 | 四通道（P₁–P₄）最优压强分离，σ₃=−σ₁、σ₄=−σ₂ | [9] |
| 输出态层析 | 原位四缝干涉 + 单发光子统计 | [8] |
| 理论基线 | 谐波双模压缩/纠缠（理论预言→实验确认） | [1][3] |

**2.3 验证清单。** ① 经典极限（BSV→相干态）退化回标准 HHG；② 光子统计守恒检查：无耗散传播中超 Poisson 保持（传播端 [[宏观传播与相位匹配工程]]）；③ 层析重构的正性检验；④ 电离端与谐波端的双向一致性（同一驱动态分别从电子与光子读出）。

**2.4 适用边界。** ✅ 量子态传递（压缩态上转换）、谐波纠缠源、量子光驱动强场过程。❌ 高增益近似在少光子极限失效；固体语境需 SBE 重表述（课题 A σ_solid，尚待完成）；BSV 源可达性是实验复现的第一道门。

### 扩展 A：量子化 HHG 的扰动层级

按驱动场量子化程度的三层：① **经典驱动**（相干态，标准 HHG）；② **压缩态/BSV 驱动**（场统计非经典，平均场动力学仍适用，输出光子统计非 Poisson）；③ **单光子级量子驱动**（微扰量子化处理，发射光子与驱动场纠缠结构显著）。层级决定理论工具：② 用「经典轨迹+量子统计系综平均」（[[强场电离量子轨道方法]] Q-CCSFA 路线），③ 需全量子化模型。

### 扩展 B：BSV 源生成参数

BSV（亮压缩真空）由高增益 SPDC 产生：非线性晶体（BBO/PPKTP）+ 超短泵浦，单模光子数 ~10⁴ 量级（高增益区），压缩度由泵浦强度控制；驱动构型用 1600 nm BSV（量子微扰）+ 800 nm 相干态（主驱动）相位相关混合——「量子微扰叠加经典主驱动」是可控实验设计的核心（纯 BSV 驱动尚不可行，强度不足）。

### 扩展 C：g⁽²⁾ 与 Mandel Q 的预言-测量对照

输出谐波的光子统计读出：g⁽²⁾(0) 偏离 1 的幅度与 Mandel Q 参数随驱动压缩度 r 的标度——BSV 驱动下谐波呈超 Poisson（Q>0）；传播端（[[宏观传播与相位匹配工程]]）的超 Poisson 保持条件（无耗散）使「统计传递」可检验。这是输出态层析之外的轻量诊断（单探测器即可），适合作为实验第一目标。

## 三、典型应用案例

**案例 1（理论奠基）**：Rivera-Dean 等证明 HHG 辐射的非经典性（双模压缩+高斯纠缠）[1]——本专题全部方法的理论出发点。

**案例 2（输出态实验确认）**：Stammer 等的光场模式纠缠与压缩测量[3]——输出态层析（§2.1 步骤⑤）的实验级实现。

**案例 3（BSV 三角与四缝层析）**：库内三角三篇（输入/连接/输出[4][5][6]）+ 隧穿涨落阿秒分辨的单发统计测量[8]——闭环从静态统计推进到亚周期时间分辨。

**案例 4（压强维通道纯化）**：σ 的传播指纹使四通道在压强维度可分离[9]——输出态层析前的通道纯化手段，避免通道混叠污染统计。
