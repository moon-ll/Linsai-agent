  # 瞬态多体相的全光读-写-控（HHG 指纹库）

  ## 林赛的理解

  我把这个框架看作我课题的"北极星"：强关联体系（Mott、CDW、光致超导）的麻烦在于多体参数——Hubbard U、doublon-holon 产生率、电声耦合 g——藏在谱学信号的背后，传统手段（ARPES、中子散射）要么测不到超快时间尺度，要么需要互易空间分辨的庞然大物。HHG 的独特性在于：它天然是亚周期时间分辨的探针，而且谐波谱的每个特征频率都被电子结构和对称性"指纹化"。我的直觉是：如果能证明谐波红移量 Δω/ω₀ 与 ΔU/U₀ 之间有干净的标度关系，HHG 就从"现象展示"升级成"多体参数的定量读出器"。但我在申请书里给自己划了红线：反演多解性（争论 1）是真实风险，我不承诺数学唯一解，而是用偏振 + 温度 + 双色场三重约束把解空间压到可接受的工程精度（< 15%）——这是方法论上的诚实，也是和审稿人谈判的筹码。

  ## 核心要点

  - **"读"（核心目标 1）**：建立 HHG 谱 → 多体参数（U, Γ_dh, g_mn^λ）的定量反演
    - 三重交叉验证方法学：tdDMFT（1D/2D Hubbard 严格解）+ TDDFT+U（实际材料）+ 声子耦合 HHG
    - 谐波红移 Δω/ω₀ 与 ΔU/U₀ 的标度关系，精度目标 < 15%（现有水平约 30%）
    - 非整数谐波强度比 I_{n+0.5}/I_n 与 U/t₀ 呈指数衰减关系，拟合优度 R² > 0.90
    - 3 参数联合反演为首发；与 ARPES 对比误差 < 20%
  - **"写"（验证目标 2）**：单周期 MIR 强场（3–5 μm, 0.1–1.0 MV/cm）在三类相间切换
    - 可逆性已被实验确认（Eckstein 2016：Mott 10–20 fs 恢复；Dean 2016：Sr₂IrO₄ Néel ~ps 恢复），故降级为验证目标而非首创目标
    - 指标体系：切换成功率 > 70%（以 HHG 谱恢复判定）+ 切换时间 < 1 光学周期（约 3.3 fs @ 3 μm）
    - 重点产出：光场参数 → 切换路径的**设计规则**（频率/场强/CEP/偏振四参数扫描）
  - **"控"（核心目标 3）**：双色场（MIR 驱动 + NIR 弱调控场，800 nm, 0.05–0.2 MV/cm）主动调控
    - 调制深度 M = ΔI_HH / I_HH^(0) > 10%；延迟扫描步长 0.1 fs（亚周期精度）
    - 退相干时间 T₂ > 50 fs；U 值动态调制 ΔU/U₀ > 20%
    - 样品锚点：MoS₂（声子选择性激发）+ Sr₂CuO₃（U 值调制）
  - **三大支柱与优先级（v0.2 拍板）**：Mott 50% / CDW 30% / 光致超导 20%
  - **四个差异化壁垒**：定量精度 < 15%、切换 > 70%、调制 > 10%、T₂ > 50 fs
  - **范式定位**：从"单色场被动观测"转向"主动调控 + 定量读出"的研究范式转变

  ## 实验/研究关联

  - **支柱证据链**：
    - Mott：Silva 2018 NP（Hubbard 模型定性 HHG）→ Prajapati 2410.01424（RNiO₃ THz HHG）→ Ikeda 2508.00296（Sr₂CuO₃ tdDMFT doublon-holon 红移，半定量）
    - CDW：Nakano PRL 2024（Pr-CMO 电荷序主导）、Tyulnev 2409.04216（TiSe₂ 偏振分辨）、EuTe₄ 室温全光切换 2310.10293
    - 光致超导：Cavalleri 组 K₃C₆₀ 系列（NP 2021/2023）、Eckhardt 2024 NC（声子-电子吸引机制）、η-pairing 2606.05092、Demler/Sentef 2024 NC（异质结验证平台）
  - **样品清单（9 个，4 类 + 校准）**：Sr₂CuO₃（1D Mott 主验证）、NiO（3D Mott 拓展）、1T-TiSe₂ 与 Pr₀.₆Ca₀.₄MnO₃（CDW 双体系）、K₃C₆₀（光致超导探索）、MoS₂（声子耦合）、ZnO + Au（校准样品）
  - **实验装置**：MIR-OPCPA（3–5 μm, > 10 μJ）+ Ti:sapphire NIR 调控臂 + 亚周期延迟线（步长 < 0.1 fs, 范围 > 1 ps），第 3 年搭建，ZnO/Au 校准后先在 TiSe₂ 上复现 Tyulnev 基线
  - **5 年时间线**：基态计算（ACBN0 自洽 U + Wannier 投影）→ 含时模拟与标度关系 → 装置搭建 → 指纹库建立（第 4 年核心产出）→ 切换验证 + 闭环
  - **方法学外溢**：指纹库 + 切换协议是后续候选课题（HHG-QGT、莫尔强场）的方法学基础

  ## 开放问题

  - **反演多解性**：HHG 谱 → 多体参数的映射是否病态？多维约束（偏振 + 温度 + 双色场）能否把精度压到 < 15%，还是必须接受"工程唯一性"而非数学唯一性？
  - **三类相指纹区分度**：若 Mott/CDW/光致超导的 HHG 特征频率重叠度过高，指纹库框架是否失效？需要多少维度的辅助依赖（偏振角扫描、温度 10–300 K）才能拉开区分度？
  - **η-pairing 缺直接证据**：光致超导支柱目前只能靠"探索 HHG 指纹"的保守表述，是否存在不依赖 η-pairing 探测的替代物理图像来支撑该支柱？
  - **TDDFT+U 的激发态关联缺失**：强场区（0.1–1.0 MV/cm）单粒子 + U 修正框架是否足够？与 tdDMFT 的偏差在多大幅值场强下开始失控？
  - **双色场同步稳定性**：0.1 fs 步长的延迟线对机械/热漂移的容忍度，主动反馈能否长期维持调控精度？
  - **Sr₂CuO₃ 与铜氧化物样品制备**：MBE/PLD 合作组产能是否支撑 5 年路线图的逐年样品需求？
