  # HHG光谱多维反演——凝聚态参数读出的公共方法学

  ## 林赛的理解

  这份 v0.2 汇总里我最看重的不是某个单一方向，而是 T5 的定位判断：把 HHG 光谱反演做成一个**公共方法学平台**，让 T1-T4 四份申请书各自引用、共享同一条"谱 → 参数"的技术路线。我做强场超快光学这些年有个反复被验证的经验：HHG 谱里编码的信息远超"第几阶有多强"——偏振、椭圆度、载波包络相位、涡旋拓扑荷、晶体取向、温度、外场，每一个实验旋钮都是谱空间的一个独立维度。单维度测量只能给出定性指纹，多维约束联立才能把反演问题从"欠定"拉回到"可解"。这正是 2015 年 Vampa 用 HHG 反演能带以来这条谱系（Berry 曲率偏振反演 → 量子度规反演 → shift vector 反演 → 多维 NN 反演）持续推进的主线，也是我认为国内目前最该抢占的位置——汇总里 T3 标注"完全空白"、T4"几乎完全空白"，空白点恰恰在方法学落地而非概念本身。我倾向选项 C 的判断也源于此：方法学独立成册风险高（没有自己的材料体系），拆进各申请书又会重复建设，作为公共平台被四方引用才是最省也最扎实的结构。

  ## 核心要点

  - **定义**：HHG 光谱多维反演是指以高次谐波谱（含强度、偏振、相位、阶次依赖）为观测量，通过正演模型 + 优化/学习算法，反推凝聚态体系的多维微观参数——能带结构、Berry 曲率 Ω(k)、量子度规 g(k)、谷极化率 η、Floquet 准能带 E_Floquet(k)、瞬态能隙 Δ_gap(t)、以及激子/超导/磁/CDW 四类序参量。
  - **物理直觉**：强场驱动下电子在 k 空间经历非绝热加速，HHG 发射的振幅与相位记录了整个布洛赫振荡历史；不同实验旋钮（偏振几何、双色场、CEP、涡旋相位、外场/温度）分别对不同微观自由度"敏感"，构成互补的测量通道。
  - **数学表达（示意）**：反演可写成约束优化问题
    P\* = argmin_P Σ_ν || S_exp(ν) − S_fwd(ν; P) ||² + λ·R(P)，
    其中 ν 遍历多维实验旋钮（偏振角、椭圆度、CEP、取向等），S_fwd 由 SBE / Floquet-Bloch / TDDFT-BSE 等正演模型生成，P 为待反演参数向量，R(P) 为先验约束（如 8-9 维约束、对称性限制）。求解器用贝叶斯推断（量化不确定度）+ 神经网络（加速正演）组合。
  - **四方向反演路径**（T5 核心，详见原始材料表格）：T1 量子几何（紧束缚 + k·p + SBE → Ω(k), g(k), C）；T2 谷极化（k·p + TDDFT → η(k,T)）；T3 Floquet（Floquet-Bloch + SBE → 准能带、瞬态能隙）；T4 序参量（BCS/平均场/GW-BSE → 序参量幅值与动力学）。
  - **谱系关键节点**：2015 Vampa（HHG 反演能带奠基）→ 2018 Luu/Wörner（Berry 曲率偏振反演）→ 2022 Liu/Fu/Kais 与陆瑞锋 PRX（量子度规、shift vector 反演，后者为国内首次）→ 2024 Hu/Zhao/Meng PNAS（国内顶刊多维反演）→ 2024-2025 Jensen/Rubio、Puviani、Sala（激子反演、序参量涨落三次谐波、3D TI 量子度规磁阻首次实验验证）。
  - **关键争论**：HHG 反演的唯一性——单一谱维度的反演解不唯一，需多维约束 + 神经网络 + 贝叶斯不确定性量化联立解决。

  ## 实验/研究关联

  - **正演模型分层**：SBE（半导体布洛赫方程）用于能带/量子几何类反演；Floquet-Bloch + SBE 用于周期驱动体系的瞬态能带；TDDFT / GW-BSE 用于激子与关联效应；BCS/平均场用于序参量。
  - **验证闭环**：反演结果需独立实验交叉验证——tr-ARPES（Floquet、能带）、量子度规磁阻（Sala 2025）、PL/SHG（谷极化）、XRD/STM/ARPES/输运（序参量）。
  - **五方向协同结构**：T1-T4 各自产出物理目标，T5 提供共享的反演算法栈（贝叶斯、NN、5 维约束解耦）；样品池跨方向复用（Bi₂Se₃ 同时进 T1/T3、CrI₃ 同时进 T3/T4、CrSb/MnTe 同时进 T1/T4）。
  - **合作布局**：国内以孟胜组为 T5 核心合作（5 方向全覆盖），国际对标 Wörner/Bauer/Puviani/Biegert 集团。

  ## 开放问题

  - 反演唯一性的严格判据：多维旋钮之间的敏感矩阵何时满秩、何种对称性简并仍不可破？
  - NN 加速正演的泛化性：训练分布外的材料体系（如 altermagnet、关联材料）外推是否可靠？
  - 贝叶斯后验在高维参数空间（8-9 维以上）的采样成本如何控制？
  - 4 份申请书各自引用 T5 时，方法学的"工作量归属"如何在评审语境下表述而不被认定为重复？
  - 国内 T3/T4 空白窗口的持续时间——国际组（Huber/Sentef/Biegert）推进速度是否会压缩布局空间？
