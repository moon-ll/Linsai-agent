  # 凝聚态高次谐波产生的工具级方法学

  ## 林赛的理解

  我做强场超快光学这些年，越来越确信一件事：**高次谐波产生（HHG）不该只是"在固体里也能产生谐波"的现象学注脚，而应该升级为一类凝聚态光谱学工具**。这份调研索引所承载的项目——"强场超快 HHG 凝聚态工具级方法学"——正是我这一判断的系统化落地：四个科学方向（量子几何、能谷、能带动力学、序参量）加一条反演方法学协同平台，目标是把 HHG 从"看见一个信号"推进到"反演出一份能带结构"。

  我的直觉很直接：原子 HHG 的三步模型之所以伟大，是因为它给了我们一个能解读的强场过程；固体里多了布洛赫振荡、带间极化和晶体对称性这些自由度，复杂度上去了，但**可提取的信息量也成倍增加**——谐波谱里的每一个特征都可能对应一条真实的能带信息。工具级方法学的难点不在"产生"，而在"解码"：信号 → 物理解这一环，靠的是 T5 那样的反演方法（PINN、贝叶斯、Transformer 等）与实验测量学的协同。

  ## 核心要点

  - **项目骨架（4+1 结构）**：T1 量子几何、T2 能谷、T3 能带动力学、T4 序参量四个科学方向，各配立项报告与展板；T5 为反演方法学协同平台，是整个体系的"解码器"。
  - **T1 量子几何**：用 HHG 信号中的 Berry 相位/量子几何相关特征读取晶体动量空间的波函数几何信息；跨方向协同点包括 altermagnet 体系的自旋纹理 HHG 与圆二色性 RABBITT（CD-RPED）类测量。
  - **T2 能谷电子学**：HHG 作为能谷选择性探针，方向涵盖转角范德华体系、反铁磁能谷（如 NiPS₃、MnSe、CrCl₃ 磁振子强耦合）、莫尔非线性霍尔效应关联体系。
  - **T3 能带动力学**：HHG 谱直接反映带内布洛赫振荡与带间跃迁动力学，含载波包络相位（CEP）依赖测量、涡旋光 HHG、Floquet-Bloch 工程化能带等子方向。
  - **T4 序参量**：把 HHG 用作凝聚态序的对称性读出——超导体 Higgs 模（H₃S 等）、电荷密度波（CDW）的完整反演链、altermagnet 的 HHG"蓝海"方向（国内已出现计算首例）。
  - **T5 反演方法学**：以机器学习反演（PINN 系、贝叶斯反演、Transformer+HHG）把谐波谱反解为能带/动力学信息，是方法学闭环的枢纽。
  - **知识基座**：索引覆盖了 1992–2026 年约 34 年时间跨度的 98 篇精读，且已识别出 6 组跨方向协同核心发现与 30+ 国内合作契机（估算 60+ 个具体研究组）。

  ## 实验/研究关联

  - **测量学关联**：trARPES（周树云组等）、自旋/磁光 MOKE（altermagnet 域成像）、STM（kagome/CDW 体系）与 HHG 测量互为印证；CEP 稳定测量（魏志义组方向）是把 HHG 推向定量反演的前提。
  - **理论/计算关联**：Floquet TDDFT（孟胜组等）、2D 半导体 TDDFT、altermagnet HHG 第一性计算构成"信号 ↔ 机制"双向往返验证。
  - **方法学闭环**：实验 HHG 谱 → 反演方法（T5）→ 能带/序参量结论 → 指回 T1–T4 的科学问题。国内已出现围绕 T5 的反演方法核心团队（陕西师大–吉大系列）与国际上 NOC/Bayesian、CELIA Transformer+HHG 等路线。

  ## 开放问题

  - 四个科学方向（几何/能谷/能带/序参量）的信号在同一谐波谱中如何**无歧义地分离**？这是工具化的第一性问题。
  - altermagnet HHG 作为"蓝海"方向，实验上从计算预言走向可复现测量的关键障碍是什么（样品、信噪比还是泵浦条件）？
  - 反演方法（T5）的适定性边界在哪里——哪些物理参数从谱中可唯一反演、哪些天然欠定？（索引显示已有多团队并行探索，尚无统一基准。）
  - CEP 依赖、涡旋光、偏振控制等操控自由度之间能否组合出"多旋钮"反演协议，以提高 T5 的解唯一性？
