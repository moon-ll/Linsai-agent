# Extraction of the self energy and Eliashberg function from angle resolved photoemission spectroscopy using the xARPES code

提出从 ARPES 谱函数一致提取自能 ΔΣ(ω)（电声子/电电子/电杂质贡献）的系统性方法：将最大熵法推广到 curved dispersion 体系的 Eliashberg 函数提取并引入贝叶斯推断联合优化，摆脱线性化能带与手工赋值的旧局限；在 SrTiO3 二维电子液和锂掺杂石墨烯两组高质量实验数据上验证，两套独立数据提取的 Eliashberg 函数达到前所未有的一致性。是 ΔΣ(ω) 重构精度方法论的最直接支撑，已发表于 npj Comput. Mater. 12, 172 (2026)。
