# Single Best Fits Can Be Misleading: Resolving Common Trapping Signatures across FA–Cs Perovskites

荧光强度依赖的时间分辨 PL + 完整 Shockley-Read-Hall 建模 + 贝叶斯后验推断，横跨 FA1-xCsxPbI3 组分系列。核心结论：单一最优拟合会误导，因为弱占据陷阱态存在『电子捕获系数—陷阱密度』简并，而陷阱填充可解除该简并——这正是『缺陷密度作为可调参数 + 多判据份额分解』的方法论范式。识别出跨组分普适的非简并陷阱特征 Tβ（βp/βn 捕获系数比强不对称），表明陷阱填充是钙钛矿载流子动力学的普遍特征。
