# BayesHHG: Bayesian Inference for High Harmonic Generation Spectroscopy

Introduces BayesHHG, a Bayesian inference framework using Gaussian process emulators to perform parameter estimation and uncertainty quantification for high harmonic generation spectroscopy, enabling surrogate-assisted parameter scans with full error bars instead of single point estimates.
