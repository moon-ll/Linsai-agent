# Limitations of an approximative phase-space description in strong-field quantum optics

理论分析强场量子光学中常用的近似正P表象(APP)的局限性：证明在缺乏偶极关联的电子系统中，APP表象无法描述任何低于真空波动的正交压缩或亚泊松光子统计，为量子光驱动HHG计算的可信度提供了误差标定，与Lange组BSV驱动HHG课题直接相关。
