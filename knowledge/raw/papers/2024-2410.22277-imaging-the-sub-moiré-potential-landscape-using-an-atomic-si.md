# Imaging the Sub-Moiré Potential Landscape using an Atomic Single Electron Transistor

基于量子扭曲显微镜(QTM)的原子单电子晶体管首次直接成像石墨烯/hBN范德华异质结莫尔势，测得振幅约60 mV呈近C6对称性，且幅值约为理论预测两倍，揭示现有理论不完备。
