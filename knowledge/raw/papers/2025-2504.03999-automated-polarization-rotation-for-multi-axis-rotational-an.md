# Automated Polarization Rotation for Multi-Axis Rotational-Anisotropy Second Harmonic Generation Experiments

为旋转各向异性二次谐波（RA-SHG）设计低成本高保真自动偏振旋转器（导电滑环+微型步进电机），消除手动旋转偏振片的劳动约束与低频噪声引起的不确定度；在 GaAs 时间分辨 RA-SHG 中演示多轴测量，支持更长时间数据平均，显著提升偏振分辨非线性光学测量的精度与吞吐。发表于 Rev. Sci. Instrum. 96, 043002 (2025)。
