# Manipulation of the altermagnetic order in CrSb via crystal symmetry

通过晶体对称性工程(Dzyaloshinskii-Moriya矢量锁定磁空间对称)实现CrSb薄膜中交变磁序的重构，从共线Néel矢量到倾斜矢量，在交变磁体中产生室温自发反常霍尔效应。
