# Signatures of Green's function zeros and their topology using impurity spectroscopy

通过 1D Hubbard 模型+杂质+塞曼场的精确对角化证明格林函数零点（GFZ）在单位散射极限下表现为带隙内谱权重（zeron 激发），可作为检测莫特拓扑的实验探针。
