# HarP: a simulation tool for high-order harmonic generation and propagation in gases

开源 Python工具 HarP，用预计算偶极表求解驱动激光与生成谐波的波动方程，连接微观单原子量子动力学与宏观强场传播。通过表格化非线性极化密度实现准确微观模型直接积分并避免传播中的昂贵计算，可用于精确预测 HHG 光谱——为谱匹配/光谱保真度分析提供基准工具。
