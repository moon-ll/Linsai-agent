# Strong-Field Control of Stacking Order in 2D Materials via Coherent Phonon Excitation

Demonstrates that mid-infrared strong-field pulses can coherently drive interlayer shear modes to selectively switch rhombohedral-to-hexagonal stacking in transition metal dichalcogenides, achieving deterministic control of the stacking phase on femtosecond timescales.
