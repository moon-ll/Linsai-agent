# Large-scale array of squeezed light and synchronization using atomic vapor

实验演示单原子气室通过原子相干增强非线性光学过程产生大规模偏振压缩光阵列：实现30光束阵列、2.03 dB压缩，各通道经集体基态相干实现同步，阵列增大时压缩纯度与抗扰动能力提升，为可扩展量子光源提供新路径。
