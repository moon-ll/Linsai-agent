# Chiral Vector Beams for Topological Enantio-Sensitive Nonlinear Spectroscopy

将矢量光束转化为分子手性的高效探针：紧聚焦径向偏振基频+方位偏振二倍频构造局部手性的'手性矢量光束'，在随机取向手性分子（蒎酮类）中产生强对映敏的和频响应，两对映体发出拓扑环结构不同的 3ω 光，可直接由环半径读出分子手性。
