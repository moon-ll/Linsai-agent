## 节 1：科学意义与研究价值（申请书级深度）

### 1.1 量子几何：凝聚态物理的新维度

**量子几何（Quantum Geometry）** 是描述电子布洛赫波函数在动量空间几何性质的核心框架，主要由两部分构成：

| 几何量 | 物理意义 | 关键效应 |
|--------|----------|----------|
| **Berry 曲率** Ωₙ(k) | 电子在动量空间获得的"磁场" | 量子反常霍尔、自旋霍尔、谷霍尔、光学 SHG/THG |
| **量子度规** gₙ(k) | 电子波函数的"长度"结构 | 超流刚度、介电常数、轨道磁性、非线性磁阻 |
| **拓扑数**（Chern、Z₂、缠绕数） | Berry 曲率的全局积分 | 边缘态、量子化输运、对缺陷的鲁棒性 |

**关键范式转变**：2010 年后拓扑材料（拓扑绝缘体、Dirac/Weyl 半金属、莫尔超晶格、**altermagnet**）成为凝聚态物理核心前沿。2024 年新磁相——**altermagnet**（如 CrSb、MnTe）——结合反铁磁序 + 动量依赖自旋劈裂，**打开量子几何新维度**。

### 1.2 HHG 探测量子几何的不可替代性（4 重优势 + 1 重挑战）

**为什么必须是 HHG**？现有方法各有局限：

| 维度 | ARPES | STM/STS | 输运（霍尔） | tr-ARPES | **HHG（本项目）** |
|------|-------|---------|-------------|---------|------------------|
| **体相 vs 表面** | 仅表面 ~1 nm | 仅表面 | 体相平均 | 仅表面 | **体相 10-100 nm** |
| **时间分辨** | 静态 | 静态 | 静态 | 30-100 fs | **亚周期 100 as - 几 fs** |
| **多维光场** | 无 | 无 | 间接 | 1 维（偏振） | **5+ 维**（偏振/相位/CEP/涡旋/晶体取向） |
| **强场非线性放大** | 无 | 无 | 无 | 弱 | **14 数量级**（Bauer 2018） |
| **单发 vs 累积** | 累积（多次扫描） | 累积 | 累积 | 累积 | **单发** |
| **全光学** | 需紫外源 | 需超高真空 | 需低温磁场 | 需紫外源 | **全光学**（实验室可达） |

**HHG 的 4 重不可替代优势**：
1. **全光 + 体相**：HHG 激光穿透深度 10-100 μm，可探测体相 Berry 曲率（避免表面态/污染干扰）
2. **亚周期时间分辨**：HHG 本身在亚光学周期内发射（100 as - 几 fs），可实时追踪 Berry 曲率在强场下的瞬态演化（**Floquet 拓扑瞬态相变**）
3. **多维光场联合**：圆偏振/椭圆/线偏振 + 二色场相位 + 涡旋光 OAM + CEP + 晶体取向 = **5+ 维探测自由度**
4. **强场非线性放大**：HHG 是非微扰过程，拓扑相变可导致 HHG 差异达 **14 个数量级**（Bauer & Hansen PRL 2018）

**HHG 的 1 重挑战**：反演多解性（HHG 谱受多参数耦合调控，需多维约束破除）→ 4.3 节详述。

### 1.3 5 个具体科学发现机会

**H1：Floquet 拓扑瞬态相变的 HHG 指纹**
- 强光场诱导瞬时拓扑相变（C 从 0 → ±1，Z₂ 从 0 → 1），HHG 谱即时响应
- **预期信号**：拓扑相变点附近 HHG 峰位突然移动、偏振反转、非整数谐波出现
- **国际空白**：理论预言（Oka & Aoki 2009、Jürß & Bauer 2020），实验**完全空白**
- **国内空白**：**完全空白**

**H2：altermagnet HHG 的磁化方向依赖**
- 2024 年新磁相 altermagnet（CrSb、MnTe、Mn₅Si₃）有动量依赖自旋劈裂
- Werner 2024 PRB 预言：altermagnet 的 HHG 谱显示**磁场依赖的低阶谐波各向异性**
- **国内空白**：**完全空白**（2024 全新方向）

**H3：3D 拓扑绝缘体量子度规的直接反演**
- 量子度规 g(k) 是量子几何张量对称部分，决定非线性磁阻
- Sala 2025 arXiv:2509.17135 在 Sb₂Te₃ 测量**量子度规诱导磁阻**（**首次实验**）
- HHG 偏振依赖 → 量子度规直接反演：**方法学突破**
- **国内空白**：**完全空白**

**H4：多体关联拓扑材料的 HHG 探测**
- 强关联拓扑（重费米子、Kondo 拓扑、莫尔超晶格关联绝缘态）HHG 未探索
- **国际空白**：理论**几乎空白**（仅 Oka 等 Mott HHG 探索）
- **国内空白**：**完全空白**

**H5：HHG 偏振门控的空间分辨拓扑探测**
- 利用偏振门控/涡旋光实现 < 10 nm 空间分辨（远低于 200 nm 衍射极限）
- **应用**：拓扑边缘态/畴壁的局域探测、空间不均匀拓扑相
- **国际空白**：方法学**几乎空白**（Pisanty 2019 理论）

### 1.4 科学意义（申请书 4 维度）

1. **填补方法论空白**：首次实现全光 + 体相 + 亚周期分辨的 Berry 曲率/量子度规/拓扑数直接测量
2. **捕捉 Floquet 拓扑瞬态**：亚周期时间分辨是现有方法无法实现的
3. **解决反演多解性争论**：通过多维约束（偏振+相位+涡旋光+CEP+取向）为争论 1 提供解决路径
4. **推动拓扑材料应用**：快速筛选候选材料，为拓扑量子计算、低功耗电子器件提供材料基础

## 节 3：关键科学问题凝练（申请书级深度）

### 3.1 核心科学问题

**主问题**：HHG 的多维光场依赖（偏振 + 椭圆度 + 相位 + CEP + 涡旋 OAM + 晶体取向）如何直接映射到凝聚态材料的 Berry 曲率 Ω(k)、量子度规 g(k)、拓扑数 C/Z₂，并捕捉**强场诱导的瞬态拓扑相变**？

### 3.2 4 个子问题

#### 3.2.1 子问题 1：Berry 曲率在 HHG 中的反演（深耕 + 国际对标）

**物理图像**：
- Berry 曲率 Ωₙ(k) 决定**异常速度** v_ano = (e/ħ) E × Ωₙ(k)
- 进入非线性极化电流 J(t) = ∫ d³k [pₙ(k,t) + A(t) × Ωₙ(k)] nₙ(k,t)
- 圆偏振 HHG 的椭圆度依赖直接反映 Ω(k) 积分

**关键科学问题**：
1. **解析表达式**：Ωₙ(k) 在 HHG 偶极 d(t) 中的**严格解析表达式**是什么？（半经典 vs 全量子）
2. **动量空间反演**：Ω(k) 的**空间分布**（整个 BZ）能否从 HHG 反演？
3. **多能带解耦**：多能带系统中不同能带 Berry 曲率贡献如何分离？
4. **跨材料普适性**：不同对称性（中心/非中心对称）、不同维度（2D/3D）的 HHG 反演方法如何统一？

**v0.2 新增实验设计**：
- **Bi₂Se₃ / Bi₂Te₃**（拓扑绝缘体，3D 强拓扑）：Huber/Baykusheva 已有实验基础
- **Na₃Bi / Cd₃As₂**（Dirac 半金属）：3D Dirac 锥的 Berry 曲率集中在锥附近
- **CrSb / MnTe**（altermagnet）：Werner 2024 预言的磁场依赖各向异性
- **温度依赖扫描**：跨越 T_c（拓扑相变点）观察 HHG 谱的跳变

#### 3.2.2 子问题 2：量子度规从 HHG 提取（**方法学突破**）

**物理图像**：
- 量子度规 gₙ(k) = Re[⟨∂ₖuₙ|∂ₖuₙ⟩ - |⟨uₙ|∂ₖuₙ⟩|²] 是量子几何张量对称部分
- 决定超流刚度、介电常数、轨道磁性
- **涡旋光 OAM** 耦合到 g(k)：涡旋光场 E(φ) = E₀ e^{iℓφ} 中 ℓ（OAM）映射到布洛赫波函数相位

**关键科学问题**：
1. **涡旋光 OAM-度规耦合机制**：OAM ℓ 如何直接进入 g(k) 的 HHG 谱？耦合系数是什么？
2. **圆偏振 HHG 多解性**：不同 (Ω(k), g(k)) 组合可能产生相似圆偏振 HHG 谱
3. **联合反演 (Ω, g)**：是否可行？需要多少独立约束？
4. **实验实现**：涡旋光 HHG 需稳定空间相位调制（SLM + q-plate），实验难度如何？

**v0.2 新增关键论文**：
- **Sala arXiv:2509.17135 (2025-09)**：首次实验测量 3D TI（Sb₂Te₃）**量子度规诱导非线性磁阻**——打开**实验观测量子度规**的先河！
- **Liu, Fu, Kais PRR 2022**：圆偏振 HHG 提取 g(k) 理论

**国内空白**：**完全空白**（除陆瑞锋组 shift vector 单参数反演）

#### 3.2.3 子问题 3：拓扑数的 HHG 指纹（**蓝海突破**）

**物理图像**：
- 拓扑数 C = (1/2π) ∫ d²k · Ω(k)（Chern 数），Z₂（时间反演不变）
- 不同 C 对应不同 Berry 曲率**全局积分**
- HHG 对 Ω(k) 的非线性依赖 → 不同 C 谱特征不同

**关键科学问题**：
1. **不同拓扑数的谱特征**：C = 0, ±1, ±2 在 HHG 谱中如何区分？
2. **拓扑相变点的 HHG 行为**：C 跳变时 HHG 是否突变？是否伴随新谐波出现？
3. **Z₂ 拓扑**：时间反演不变拓扑绝缘体的 HHG 特征？
4. **altermagnet 的"拓扑数"**（d-wave、g-wave、i-wave）：HHG 能否区分？

**v0.2 新增实验**：
- **CrSb（altermagnet d-wave）+ Cr₂O₃（反铁磁）+ Bi₂Se₃（TI）**：3 种"拓扑数"类型对比

- **磁场依赖**：altermagnet 的 HHG 各向异性（Werner 2024 预言）

#### 3.2.4 子问题 4：Floquet 拓扑瞬态相变的 HHG 探测（**最大蓝海**）

**物理图像**：
- 周期性强光场诱导能带重整化（Floquet 态）
- 拓扑数在 Floquet 驱动下发生**瞬时变化**（平庸 → 拓扑，或 C 跳变）
- HHG 是亚周期过程（100 as - 几 fs），可捕捉瞬态相变

**关键科学问题**：
1. **HHG 谱的瞬态响应**：Floquet 准能带重整化 → HHG 谱的**实时**变化？
2. **拓扑相变点的特征信号**：HHG 峰位突变 / 偏振反转 / 非整数谐波？
3. **多体 Floquet 拓扑**：电子-电子关联 + Floquet 驱动 → 关联拓扑相变？
4. **实验实现**：需要 few-cycle 10-15 fs 脉冲 + 二色场 + CEP 锁定

### 4.3 澄清有争议的原理：Berry 曲率反演的多解性

**争论 1 核心**（来自 scientific_debates_2026-06-09.md）：
- HHG 谱受能带色散、跃迁矩阵元、退相位时间多参数耦合调控
- **无严格唯一性证明**：不同参数组合可能产生相似 HHG 谱

**本项目多维约束解决方案**：

| 约束维度 | 提供信息 | 对多解性贡献 |
|----------|----------|--------------|
| **偏振分辨** | Berry 曲率矢量方向 | 约束 Ω(k) 符号 |
| **椭圆度依赖** | Ω(k) 非线性响应 | 约束 Ω(k) 幅度 |
| **涡旋光 OAM** | 量子度规 g(k) | 约束 g(k) 张量 |
| **相位分辨** | Shift vector（Berry 相位梯度） | 约束拓扑数全局信息 |
| **时间分辨** | Floquet 态演化 | 约束能带与拓扑动态耦合 |
| **晶体取向** | 群论选择定则 | 约束对称性 |
| **温度依赖** | 拓扑相变 | 约束相变点 |
| **磁场依赖** | altermagnet 各向异性 | 约束 d-wave 特征 |

**v0.2 新增**：8 维约束 vs v0.1 的 5 维约束 → **约束数翻倍**，多解性显著降低

**物理原理**：不同拓扑材料的 HHG 响应在多个维度上**同时不同**，单一维度可能多解，但**多维度联合**可唯一确定（类比 CT 成像：单一投影多解，多角度投影唯一）

**机器学习辅助**：
- 用 SBE/TDDFT 计算生成训练数据集（HHG 谱 → Ω/g/C）
- 训练神经网络建立非线性映射
- 用多维约束数据作为输入，提高反演鲁棒性

**HHG 谱 → 量子几何多维参数反演路径**：

```
输入：HHG 谱
├─ 偏振依赖（圆/椭圆/线）

├─ 二色场相位扫描
├─ CEP 依赖
├─ 涡旋光 OAM 依赖
├─ 晶体取向依赖
└─ 温度依赖
    ↓
物理模型：紧束缚 + k·p + 半导体布洛赫方程（SBE）
    ├─ 单电子：紧束缚（拓扑绝缘体）+ k·p（Dirac 半金属）+ 拓扑能带
    └─ 多体：TDDFT（孟胜组 IOP CAS 合作）
    ↓
反演算法：
├─ 贝叶斯反演（多解性概率量化）
├─ 神经网络（多维非线性映射）
├─ 约束优化（多维约束 + 对称性 + 物理常数）
└─ 群论选择定则（晶体对称性）
    ↓
输出：
├─ Berry 曲率 Ωₙ(k) 动量空间分布
├─ 量子度规 gₙ(k) 张量
├─ Chern 数 C / Z₂ 拓扑数
├─ 反演误差（95% 置信区间）
└─ 多解性概率（贝叶斯后验）
    ↓
验证：与 ARPES / tr-ARPES / 输运 / Sala 2025 量子度规磁阻独立对比
```
