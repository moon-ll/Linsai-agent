# 全文逻辑骨架
## ① 主线论证链
扭转 MoS₂/WSe₂ 异质结把直接带隙、强激子共振、II 型能带对齐与可调莫尔周期势纳入同一测量对象。方向一分离激子基线与扭转角基线并在 1—4 层样品上标定 η(N)；方向二在同一异质结中测量协同放大系数 α_syn；方向三将谐波观测量反演为 Ω(k) 并用 ARPES、独立 TDDFT 与阿秒 streaking 三套独立基准标定空间与时间精度。核心指标为 R² ≥ 0.90、R² ≥ 0.85、α_syn ≥ 0.15、r ≥ 0.8、σ_Ω ≤ 0.15 和 Δt ≤ 100 as。

## ② 章节衔接点
立项依据从固体 HHG 的发展收窄至三项缺口：扭转角与选择定则映射（§2.3 点群归属与适用条件）、激子—莫尔势协同（§1 物理图像）、HHG 反演精度（§2.4 反演双维度）。研究内容将三项缺口组织为方向一→二→三与四问 → 七条目标（目标一激子基线、目标二选择定则映射、目标三层数累积、目标四协同放大、目标五—七反演三阈值），并由 §2.6 边界条件统一降级规则。

研究方案以方向一输出作为方向二输入、方向一电子结构与方向二协同数据共同作为方向三输入。Δt 装置分辨级联降级（≥100 as / 100—170 as / 170—300 as / <300 as）由研究方案 §3.3.1 给出，立项依据 §2.4 与研究内容 §2.6 按该表述指代引用。RMS 残差 16%→σ_Ω ≤ 0.15 的归一化映射由方案章 §4 三步映射给出（Ω_max 归一化分母 → 实数残差映射 → k 点对齐）。研究内容承担问题与目标表述，研究方案承担参数级流程。

## ③ 跨章节统一标准表

| 指标或术语 | 唯一表述 |
|---|---|
| 选择定则拟合 | ε(ξ) 与点群理论预测拟合，R² ≥ 0.90；R² 介于 0.85—0.90 时接受映射并报告适用区间，不强行外推；R² < 0.85 时按 C₃、C₃v、D₃d 逐段重拟合并报告适用边界 |
| 协同放大 | α_syn=(N_cutoff_syn−max(N_cutoff_ex,N_cutoff_tw))/max(N_cutoff_ex,N_cutoff_tw)，N_cutoff 为谱包络截止拐点插值的连续取值，阈值 ≥0.15；两基线相对差异超 30% 时分母切换为几何平均 √(N_ex·N_tw) 并重新报告 |
| 协同统计置信度 | σ_α ≈ √2·δ·max(N_ex, N_tw)/denom，denom 取二者中较大者；δ≤5% 时 α_syn ≥ 0.15 对应约 2.1σ；δ≈10% 时判据上调至 α_syn ≥ 0.30（保持约 2.1σ） |
