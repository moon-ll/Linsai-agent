## 一、科学问题清晰度（0.78）

**核心结论：核心问题"从谐波频谱到磁结构参数如何建立定量反演通道"一句话可判定、可证伪；不是方向名词堆砌；但摘要文件因骨架压缩丢失了"两层递进问题"的显式声明,需借 `proposal-brief.md` 才能还原完整问题链。**

### 优点

- **核心问题可一句话判定**：proposal-brief L9 写明"g 波节点面几何如何通过带间-带内双通道干涉写入谐波偏振各向异性图样,从谐波频谱到磁结构参数如何建立定量反演通道"——机制层 + 应用层两问,各自可独立证伪,无方向名词堆砌。
- **物理入口量级论证健全**：0.3–0.8 eV 自旋劈裂与 0.41 eV 光子能量同量级 + 三光子 1.23 eV 落在 MnTe 间接带隙 1.3 eV 近带边——这是可行性层面的"匹配条件",非空喊。
- **题目与问题对齐**：标题"基于高次谐波产生对称性指纹的交变磁体磁结构定量谱学"——三个关键词（HHG 对称性指纹 / 交变磁体 / 定量谱学）逐一对应到三段问题链,可对照阅读。

### 具体问题

1. **摘要文件本身不承载问题句,需指针化（P1）**：`00_research_idea.md` §2"研究背景与动机"是一段 200 字的综述,**没有"拟解决的关键科学问题"显式节**。读者读骨架只能获得"知识簇综合"叙述,核心问题要跳到 `proposal-brief.md` 或 rationale §3 去找。这与 idea 文件作为"快速看懂课题"的产品定位略偏。
2. **机制层问题三靶并列遗留（P1，与 r1 一致）**：proposal-brief L9 仍把"自旋极化、偏振对称性、阶次结构"三靶并列未指明主攻量。r1 P1.3 已指出,本轮骨架未改善。
3. **"MnTe 演示[3]"的引用现状已修复,但骨架中"研究空白或瓶颈"节空白**：§3 当前仅写"Lee 等人用 MBE 生长 MnTe 薄膜并原位 ARPES 观测到 37"——一句被截断的句子,**没有显式的空白声明与对账**。r2 panel 已确认 r1 的"空白#1 事实性错误"已修复（rationale §1 时限限定 + §2 显式对账 2024–2026 反例），但骨架摘要没有把"修复后空白收窄到何处"的结论带过来,造成骨架与详尽章节的口径错位（骨架像停在 r1 阶段）。
4. **"共振窗口"表述松散（P1,与 r1 一致）**：摘要未触及此,但 rationale L35"近带边多光子干涉"的措辞仍是同源问题。骨架若承担"快速判断可不可做"的功能,这一物理入口条件应在骨架显式落地。

## 四、方向一致性（0.85）

**核心结论：课题与现有课题边界清晰（主体系 MnTe、对照 CrSb/MoS₂、理论正演 + 实验测量 + 贝叶斯反演三层定位）、无换皮嫌疑、增量可指——是四个维度中最好的一项。**

### 优点

- **与 r1 时代的换皮嫌疑已完全消除**：v1 用 CrI₃/FePS₃ 的旧设想已彻底替换为 MnTe + CrSb + MoS₂ 三体系,主体系单一化后方向感显著增强（与 r1 评审报告 P0.4 同源问题的修复结果）。
- **三层主线无跑题嫌疑**：理论正演 → 实验验证 → 定量反演三层递进,各层有独立交付物且与上层有"产出-输入"接口（proposal-brief §3）。
- **与现有课题边界清晰**：从 memory 看到 `general-quantum-geometry-inversion-20260726` 走的是 ZnO 反演路径、`general-ssh-weyl-20260920` 走的是 SSH/Weyl 拓扑路径、`general-attosecond-streaking-20260822` 走的是阿秒时间分辨路径——本课题是"交变磁体 + HHG 谱学"交叉,**不与上述任何课题在主线上重叠**。
- **"检索截至 2026 年 8 月"时限限定全文一致**：rationale L13/L71、scheme L115/L121、content 同步出现,体现"与现有文献边界"的纪律。
- **方法学增量可指**：相比 ZnO 反演（Vampa 2015 Nature Physics）路径,本课题的增量是"① g 波节点面几何指纹,非 Berry 曲率 dipole；② 自旋-偏振通道分离测量；③ 跨反铁磁相变扫描"三点具体差异化（proposal-brief L13）,可逐项判读。

### 具体问题

1. **与 `general-quantum-geometry-inversion-20260726` 在"反演方法学"层面有底层共用（P1,fineness 上同源）**：两个课题都用到 Fisher 信息矩阵 + 贝叶斯 MCMC 反演 + κ 条件数 + Gelman-Rubin 诊断,这是方法学层面的"工具复用",不构成换皮,但评审需确认"工具复用"与"问题复用"区分清晰。从 proposal-brief §3 看,反演的对象不同（前者是 Berry 曲率 / 后者是磁结构参数）+ 观测量不同（前者是 HHG 频谱的色散 / 后者是偏振方位角周期）,可以判定为"工具复用"非"问题复用",但骨架摘要没有显式做出这一区分。
2. **与 `general-moire-strong-field-probe-20260726` 在"二维材料 HHG"路径上的差异化未声明（P1）**：两者都涉及 HHG 在新材料体系中的应用,但本课题主线是 3D 块体交变磁体,莫尔课题主线是 2D 莫尔超晶格——这区分是显然的,但骨架摘要没有显式做出"3D vs 2D 体相 vs 表面对比"的边界声明。
3. **"MnTe + CrSb 对照"的边界声明在骨架层不可见（P2）**：proposal-brief §3 提了 CrSb 作为"波型对照体系",但骨架摘要完全没有"主体系 + 对照体系"的明示——评审员读 53 行骨架,只能看到一个"α-MnTe（主）"而不知 CrSb 角色。
