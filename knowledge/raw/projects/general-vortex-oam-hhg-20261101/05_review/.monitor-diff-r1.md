+## 三、跨章节统一表述
+
+连续破缺量 l̄_q 全文写作 Σ_l l·P(l) / Σ_l P(l)，基线值取多周期区实测结果而不预设为 q·l₀，贯穿研究内容的概述、总述、分方向一与研究目标各节；整数拓扑荷偏离 l_q − q·l₀ 与它严格分列，全文不作混用。破缺量的定义是 l̄_q 与同一驱动条件下基线值之差，三通道分解写作 l̄_q = A_sym + A_CEP + A_nd，破缺阈值周期数记作 N*，即破缺量首次超出读出门限的最小周期数，这三项的定义在研究内容与研究方案中逐字一致。
+
+无量纲非偶极参数 η = k_⊥·r_peak，其中 k_⊥ = 2π/w₀，r_peak = eE₀/(m_e ω²)·k_⊥，进入可测非偶极区的门限取 η ≥ 0.1。读出门限统一为 l̄_q 单次读出 ≤ 3%、三次重复平均后 ≤ 2%，整数计数判定门限 ±0.5，对应偏离分辨能力 ±1。仲裁的判据统一为 95% 置信、ν = 2、χ²_ν < 5.99 配合残差小于合成不确定度。破缺阈值定律的偏差上限为 N* 标度相对偏差 ≤ 20%，A_nd 幂指数偏差 ≤ 15%，二者由同一批束腰标定数据判定，验收时不重复计为两项独立通过条件。
+
+层析探针库统一取 Δℓ = 0、±1、±2、±3 共七个驱动。层析判据分两层，主判据取角谐分量阶数与材料旋转对称性相符，手性符号判据在主判据成立且驱动场手性背景扣除之后才执行。材料与几何的对应关系全文固定为 ZnO/GaSe/MgO 透射、Si 与单层 WSe₂ 反射，两者不构成全交叉，G1 判据相应表述为"各材料可用几何下"。周期数取点全域为 1.5、2、2.5、3、4、5、7、10 八点，少周期区取 1.5 至 4，多周期区取 5、7、10。空时耦合的扣除在破缺量构造之前完成，按谐波阶次缩放基频时空啁啾后从角向分布中减去。
+
+采样与机时按材料与几何的既定配对核算，总计 2819 个采样点，其中主网格 2240 点、束腰系列 480 点、仲裁扫描 36 点、层析扫描 63 点，合计约 156 小时，年均约 39 小时。阿秒结构的判据为螺旋相位与理论波前偏差小于 λ/10，阿秒串时间间隔与门控设置一致。各分方向的定位为分方向一是前提层，分方向二是核心层，也是唯一可能得出"分解不成立"结论者，分方向三为应用层，探索方向挂在破缺窗口之上。
