## （三）研究方案

### §3.1 总体方案与技术路线

本项目的研究按"归因—框架—材料实现"三段推进，每一段的输出是下一段的输入。先建立光驱动效应的通道分解框架并给出两通道贡献比的解析表达，再把该分解嵌入自旋点群判据的求取过程以构造统一判据表。最后以判据表限定的候选劈裂形式为输入，完成 MnPSe₃ 电子侧、单层 MnPS₃ 磁振子侧与破缺 [C₂⊥||ℳ_z] 的 AB′ 堆垛 CrI₃ 双层平台的计算，输出定量预言与实验判据。

选择这一路线的理由在于物理上的依赖顺序。逆法拉第通道与纯 Floquet 通道的区别体现为对驱动频率的不同依赖，而驱动频率既决定有效哈密顿量的截断阶数，也决定磁振子劈裂的色散形式，两者在数学上并非相互独立。若先做材料计算再回头讨论归因，计算中已经混入的准静态项无法从结果中剥离。通道分解因而必须先于材料计算完成，并把分解结果作为参数带入后续计算。

三段之间传递的具体对象是明确的。第一段向第二段传递的是劈裂算符的对称性允许分量集合，其中已按通道标注哪些分量在纯 Floquet 通道下非零。第二段向第三段传递的是一张筛选后的对照表，表中只保留自旋点群与驱动条件可在实验上实现的组合，以及每个组合下需要计算的少数几个候选劈裂形式。第三段不重复前两段的推导，只做代入与检验。这样的分工把计算量集中在真正需要数值精度的环节，而把可以由对称性直接判定的部分交给群论处理。

### §3.2 方案一：两通道分解与判据建立

第一阶段处理光驱动对有效时间反演对称性的破缺机制。计算对象为 MnPSe₃ 与单层 MnPS₃ 的电子哈密顿量，由第一性原理给出不含自旋轨道耦合极限与含自旋轨道耦合极限两套能带。

把通道分解放在最前面，而不是作为计算后的解释环节，有两个具体理由。其一，两条通道对驱动频率的依赖形式不同：逆法拉第通道是准静态过程，其贡献在低频端随 ω 线性趋零、在 ω ≈ τ⁻¹ 处达极大，此后随频率升高按三次幂衰减，并在 Rashba 共振区被放大；纯 Floquet 通道来自高阶光子缀饰，其贡献按频率的一次幂衰减。频率既是实验上最直接可调的参量，也是区分两者的判据所在，频率依赖关系须在计算设计之初就明确。其二，两条通道对材料参数的敏感性不同，逆法拉第通道依赖自旋轨道耦合强度与费米面附近的态密度，纯 Floquet 通道依赖带间跃迁矩阵元与能带色散，两套极限的能带必须都算出来，作为分离的参照系。只算含自旋轨道耦合的一套，无法判断贡献来自哪一侧。

圆偏振光的驱动哈密顿量是整条路线的起点。取光场沿面内方向垂直于磁化轴入射，使有效时间反演破缺来源于特定的电偶极跃迁通道而非几何偏振效应。这一几何选择是必要的：若光场几何允许额外通道参与，逆法拉第项与 Floquet 项的分离将依赖具体的跃迁矩阵元细节，而非可以普适化的对称性论证。

几何选择同时决定了两条通道各自进入哪个可观测量。对面外 Néel 序的共线磁体，Yarmohammadi [36] 给出的双频光力矩分析表明，逆法拉第场沿 Néel 矢量方向，因而只对子晶格自旋施加沿磁化轴的作用而不产生横向力矩。该文的单频极限与精确 Floquet 响应在此方向上与高频有效场描述相符。逆法拉第通道随之表现为沿磁化轴的准静态均匀场，纯 Floquet 通道给出的则是动量依赖的自旋分裂算符。前者进入磁化，后者进入劈裂，两者的观测对象本就不同。本项目据此把劈裂幅度取作归因判据的主要观测量，而不是以磁化或偏振旋转作为主判据。

有效哈密顿量按光子谐波阶展开。Zhu 等人 [11] 在高频非共振区给出的展开为

H_eff(k) = H₀(k) + M(k)，M(k) = Σ_{n≥1} [H₋ₙ, Hₙ]/(nω) + O(1/ω²)，

其中 Hₙ 为驱动哈密顿量的第 n 阶傅里叶分量。式中须区分两个阶数：求和指标 n 是光子谐波阶，决定取哪一对傅里叶分量参与对易子；而分母上的 nω 因子则给出该阶对频率的幂次贡献。本项目取 n = 1 与 n = −1 这一对，即一阶光子缀饰所产生的二阶对易子 [H₋₁, H₁] 作为主导非微扰项，n ≥ 2 的谐波对因远离 Floquet 共振条件而其贡献被计入 O(1/ω²) 余项。二阶谐波项是否可忽略，取决于驱动频率与体系带宽之比，这一点决定了后文选择高频非共振工作区的原因。

该二阶对易子在蜂窝晶格上给出显式解，

M(k) = 4ηλ(cos(√3k_xa/2) − cos(k_ya/2)) sin(k_ya/2) σ_z，

其中 λ = −√3 t² J₁(Ãa/√3)²/ω，Ã = eA₀/ℏ 为归一化光场幅度，J₁ 为一阶贝塞尔函数。由于 J₁(x) ≈ x/2，λ 对光场幅度呈二次依赖、对驱动频率呈一次幂衰减，即纯 Floquet 通道的主项 ∝ 光强²/频率¹。这一标度形式是后续判据的数值支点，不作为待验证的假设处理。

逆法拉第贡献的分离紧随其后。该通道的物理内容是光场在体系中产生的准静态有效场，可通过两种途径得到：以光场在时间反演不变点附近产生的自旋响应计算有效场，或直接由第一性原理求解含光场与不含光场两种情形下的磁化之差。后者给出的是总效应，需与纯 Floquet 项比较后才能分离。对 Mott 绝缘体，Banerjee 等人 [37] 用 Floquet 理论处理逆法拉第效应，给出有效磁场依体系是否具备反演对称性而与近邻自旋作铁磁或反铁磁耦合，为绝缘体平台上以磁化差分折算等效场提供了可对照的处理方式。
