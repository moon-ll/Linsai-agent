## 一、物理链条总述

主问题（problem.md §一）：**在强关联固体的宽带隙能带体系中，是否存在"两个价带电子被顺序激发到导带后、在同一时刻同步复合回各自空穴"的 HHG 通道；若存在，它的存在条件由带间跃迁偶极与双电子关联强度的比值还是由别的量控制，以及该通道产生的谐波截止能服从"标度式"还是"内禀多体尺度钉死"式？**

三个子问是同一问题的三个判别面：存在性 → 存在条件 → 截止形式。因此本方案不按"理论/实验"切分，而按**判别链**切分七步，每一步产出一个可被下一步消费的量，任一步的否定结论都直接改写主问题答案。

链条的物理支点是三条已核实的事实，它们直接决定步骤顺序：

第一，原子侧的 NSDR 标度来自**显式施加同步复合条件**。arXiv:2606.24765 的鞍点分析给出两族轨迹 τ − τ′ ≃ π（Case I）与 τ − τ′ ≃ 2π（Case II），无量纲振幅函数 A(τ,τ′) 的极大值为 **4.646U_p** 与 **5.498U_p**，与经典 simple-man 的 4.7U_p / 5.5U_p 定量吻合，对比单电子 3.17U_p（[ref:1]，全文核实）。这把"4.7/5.5"从一个经验标度变成一个**可移植的条件集合**：两电子各自满足位移回零条件 + 二重数值积分。这意味着固体版不必重新发明机制，只需回答"能带中的位移回零条件长什么样、能否同时满足"。

第二，固体侧的两篇代表性多体 HHG 工作在全文中出现 "two-electron""multi-particle""sequential""cascade" 的次数为**零**（[ref:4]、[ref:6]，全文核实），发射能量分别是单对总能量 `ℏω_emit = |E_g[p(t_r)]|` 与 UHB–ZRS 间距上限。也就是说，固体侧现有全部零件都是**单对**的，双电子同步复合的能带对应物尚未建立——这正是 S1 的任务。

第三，固体侧的"同步"约束比原子侧更脆。Bloch 振荡要求 doublon–holon 越过布里渊区边缘（p = 3π/2）后群速度反转，长轨迹变混沌振荡、复合被压制（[ref:4]，全文核实）。单电子轨迹的周期回归一旦被破坏，两电子同时回归的同步条件自动失效。**这是固体版 NSDR 独有的存在性上界，原子侧没有对应物**，必须在 S2 中先行处理，否则 S3 之后的所有结论都悬空。

链条的输出不是一个"截止能量数值"，而是一份**可判定报告**：通道是否存在（肯定/否定）、存在条件由什么量控制（函数形式 + 临界点）、截止服从哪种形式（标度式 / 内禀式 / 两者都不服从）、以及每个结论的适用维度。

## 二、步骤分解 S1–S7

### S1 双电子同步复合的能带判据定义：D⁽²⁾ 与固体版鞍点条件

**方法**：本步是全链条的定义层，必须先把"同步复合"在固体中变成可计算的量，否则后面每一步都在测量一个未定义的对象。分三个子动作。

（a）从单电子电流–电流涨落关联函数推广出**双电子电流–电流关联** D⁽²⁾μν(t,t′)。参照 [ref:10] 的 D_μν(t,t′)，该张量"encodes key quantum geometric and topological properties"，SSH 对偶体系中拓扑相因增强的量子度规张量而电流更强（[ref:10]，全文核实）。D⁽²⁾ 的定义取二阶密度矩阵的对角双电子跃迁项（两电子同时在导带、一对空穴同时在价带），其傅里叶变换给出双电子通道的谐波源项。**关键边界**：D_μν 是一体的两时两流关联，不是双电子关联；[ref:10] 的弱关联展开参数 β²₀ = N^(3/2)g²₀ < 1 是硬边界，在强驱动、强关联固体中可能失效——因此 D⁽²⁾ 的推导必须在"超出弱关联展开"这一前提下自洽，并如实标注该前提。

（b）**不能用单粒子双空穴布居 D(t) 定义同步复合**。[ref:5] 明确指出"带内动力学并不严格守恒双空穴"（LHB 最低能区本征态已具非零双空穴数），故 D(t) 不是守恒量，只能作诊断量，不能作同步判据。本步据此规定：同步复合的判据取**双电子复合算符的期望值与其关联函数的联合条件**，D(t) 仅保留为对照诊断量（这与 [ref:5] 把 D(t) 用作区分带内自旋波型激发与带间双空穴–空穴对激发的用法一致，但用途不同，须在报告中分开陈述）。

（c）**能带版鞍点条件**。把 [ref:1] 的双电子鞍点条件（两电子各自满足 `x₁(t) − x₁(t′) = 0` 与 `x₂(t) − x₂(t′′) = 0`）平移到能带图像：单电子的位移回零条件改为 Bloch 轨迹的实空间回归条件 `x_n(t_r) = x_n(t_{i,n})`（带内位移 + 倒空间群速度积分）。三通道展开（基态 |0⟩ + 单电子连续态 |p⟩ + 双电子连续态 |p,p′⟩）的矩阵元结构保持不变，但因子化近似 `d(p,p′) = d₀(p)d₀(p′)`（[ref:1]，全文核实，领头阶）在固体中被替换为**带间偶极矩阵元的双线性形式** `d(p,p′) ≈ d_cv(p)·d_cv(p′)`（d_cv 为价带–导带跃迁偶极），这正是"偶极 vs 关联竞争"进入模型的形式化位置。

**输入**：[ref:1]（TAE-SFA 三通道展开、鞍点条件、A(τ,τ′) 极大值）、[ref:17]（分子体系 NSDR 前作：截止对核间距存在内禀依赖，源于 NSDR 过程中的强电子关联改变了经典允许的回归能量；核间距 R ≳ 8–9 a.u. 时信号性质改变、R ≳ 13 a.u. 时出现第一电子发射点的清晰特征——这是"几何位置调制 NSDR 截止"的分子版先例，为 S5 的能带几何调制提供类比锚）；[ref:2]（相位斜率解析式 `α₂ₑ(Ω) = [(t₂ᵢ − t₁ᵢ) + 2(t_r − t₂ᵢ)]`）、[ref:10]（D_μν 定义与 SSH 对偶比较法）、[ref:5]（双空穴布居 D(t) 投影与带内/带间电流分解）、[ref:4]（Bethe ansatz 上下 Hubbard 带色散、半经典 doublon–holon 轨迹、复合判据 `|x(t_r)| = a`）。

**输出**：（i）D⁽²⁾μν(t,t′) 的显式定义式及其与 D_μν 的差异表；（ii）固体版双电子鞍点方程组（每电子一条实空间回归条件 + 能量守恒 + 同步时刻相等条件）；（iii）无量纲双电子振幅函数 Ā(τ,τ′) 的固体版定义（能带色散取代原子势）；（iv）同步复合的**可判定存在条件**：给定能带与关联强度，双电子鞍点方程是否有实解。

**判据**（可复算）：
- **J0-a（定义自洽）**：D⁽²⁾ 在极限情形下退化为已知结果——令两电子之一不参与（关联强度 → 0），D⁽²⁾ 的谐波源项须收敛到单电子带间源项；令关联强度 → ∞（双电子刚性对），源项须收敛到双对复合项。两条极限须在数值上同时通过。
- **J0-b（同步判据与 D(t) 的分离）**：在 [ref:5] 的半满 U/t₀ = 10、50 MV/cm 条件下（同一模型、同一参数），双电子同步复合判据给出的"同步事件计数"须与 D(t) 的行为**定性不同**（D(t) 在带内动力学下已非守恒）。若两者给出相同结论，则说明同步判据被退化回单粒子量，本步作废重做。
- **J0-c（相位结构自洽）**：固体版相位斜率表达式须在双电子同步条件满足时退化为 [ref:2] 的形式（差一个能带色散因子），即 `α₂ₑ` 的解析结构（两项飞行时间组合）在能带版中保持。这是 D⁽²⁾ 定义正确性的独立交叉检验。
- **J3B 前置**：双电子 attochirp 须在理论计算中给出，量级对照 [ref:2] 的 0.85 / 0.88 as/eV（长/短轨迹，约 1000 eV 处）与 [ref:4] 的固体单电子 0.19 fs/eV，判据阈值按 J3B。

**预计工作量**：D⁽²⁾ 定义推导与极限检验（1.5 周）；能带版鞍点方程组推导（2 周）；与 D(t) 的分离性数值检验（1.5 周，代码量小但需 [ref:5] 的 ED 骨架）。合计约 5 周，依赖 S3 的代码骨架前置。

**失败处理**：若 D⁽²⁾ 的两极限无法同时通过，退回以**两体关联函数**（而非电流关联）定义同步复合——即直接定义双电子复合算符的复合矩 `⟨Ĉ₂⁺(t)Ĉ₂(t′)⟩`，绕开 D⁽²⁾ 的电磁学外壳；若 J0-b 失败，判定"同步复合在单粒子可观测层面不可分辨"，把主问题转为"同步条件是否可由谱形间接判别"，并在报告中如实记录该否定分支。

### S2 半经典双电子轨迹与同步条件的可解性（含 Bloch 振荡上界）

**方法**：本步回答"同步条件在固体中能不能成立"。采用 [ref:4] 的三层计算链——精确可解模型的主阶物理（Bethe ansatz 一维 Hubbard 上下 Hubbard 带色散）+ 半经典运动学轨迹 + 微扰相位积累——在**双电子版本**上重建轨迹求解器。

具体地：（a）两电子各自的相干输运方程 `dx/dt = dE_g/dp`、`p(t) = p(t_b) − A(t) + A(t_b)`，各自初动量取 Mott 隙最小处（[ref:4] 取 p = π/2）；（b）同步条件取为**两电子在同刻 t_r 各自回到各自空穴**——即同时满足 `|x₁(t_r) − x₁(t_{i,1})| = a` 与 `|x₂(t_r) − x₂(t_{i,2})| = a`（a 为晶格常数），并额外要求 t_r 一致；（c）发射光子能量取两电子在 t_r 时刻的**总能量**（原子侧为两电子动能之和 + I₀，固体侧对应为两个复合体各自释放的能量之和），这与 [ref:4]、[ref:6] 的单对总能量 `ℏω_emit = |E_g[p(t_r)]|` 形成结构性对照；（d）**Bloch 振荡上界**：追踪 doublon–holon 越过 p = 3π/2 后群速度反转的时刻，给出同步条件失效的场强阈值。

**输入**：[ref:19]（Murakami 等，一维 Hubbard HHG：doublon-holon 复合起源、截止频率对外部场的**线性**依赖、Schrieffer-Wolff 展开对带内/带间/自旋交换三过程的分解——本步轨迹方法与截止标度锚的理论母体）；[ref:4] 的 Bethe ansatz 色散构造（t_h = 0.3 eV、U = 2.1 eV、a = 3.9 Å、U/t_h = 10、初始动量 p = π/2、驱动 3.5 µm、脉冲 77.5 fs、峰值场 0.21 V/Å；低场对照 0.0525 V/Å 下长短轨迹均良好定义）；[ref:4] 的复合判据 `|x(t_r)| = a` 与发射能量 `ℏω_emit = |E_g[p(t_r)]|`；[ref:6] 的 UHB–ZRS 间距上限表述。

**输出**：（i）双电子同步轨迹族的存在性图（哪些场强/双电子初始动量配对下存在同步解）；（ii）同步事件的发射能量面 E_emit(t_r) 与截止能 E_cut vs 场强曲线；（iii）Bloch 振荡导致的同步失效场强阈值 E_Bloch；（iv）双电子 attochirp：∂E_emit/∂t_r 的能量导数，给出 J3B 的固体侧数值。

**判据**（可复算）：
- **J0-d（同步解存在性）**：在 [ref:4] 的参数点（t_h = 0.3 eV、U = 2.1 eV、a = 3.9 Å）下，必须能找到同步双电子轨迹族；若在全部场强扫描中无同步解，主问题的"存在性"分支直接判否（这是主问题的否定答案，不是本步失败）。
- **J0-e（Bloch 上界定量）**：给出同步条件失效的临界场强 E_Bloch，并在其上给出同步事件数目的下降曲线；与 [ref:4] 的 0.21 V/Å（Bloch 振荡出现）与 0.0525 V/Å（轨迹良好定义）作对照，检验本模型是否复现该量级关系。
- **J3B（attochirp 差异）**：双电子 attochirp 须 ≤ 0.1 as/eV 且比同区间单电子通道低 ≥ 1 个数量级；若不满足，报告实际值并判定固体版双电子通道**不具备**低啁啾特征，J3B 判否（这将直接限制 J5 的亚阿秒可行性）。
- **J3A 前置（候选形式初判）**：由 E_cut vs 场强曲线初判偏向标度式还是内禀式；此处只作初判，S4 数值定案。

**预计工作量**：双电子轨迹求解器（从 [ref:4] 单电子版扩展，约 2 周）；同步解搜索（场强 × 双电子初动量配对网格，约 1.5 周）；Bloch 振荡阈值扫描与 attochirp 提取（约 1.5 周）。合计约 5 周。

**失败处理**：若双电子同步解在全部参数网格中不存在（可能是"同步条件在固体中恒不成立"的真实结论），转入**软同步**版本——允许两电子复合时刻相差 Δt 并扫描 Δt，求"相干累加仍有效"的容差窗口；该容差本身即为有价值的判据输出（它定义了固体内 NSDR 的时间同步要求有多严格），并直接服务于 J3E 的通道分离设计。

### S3 一维 Hubbard 精确对角化 + 含时密度矩阵传播：存在性与存在条件

**方法**：本步给出主问题存在性与存在条件的**数值裁决**。采用 [ref:5] 的完整数值原型并做两处必要改动：（i）把电流分解从"带内/带间"两级扩展为"**带内 / 单对带间 / 双电子同步带间**"三级投影分解——三级划分的物理依据取 [ref:19] 的 Schrieffer-Wolff 强耦合展开结论（在偶极规范下把 Hubbard 模型的 HHG 分解为 doublon/holon 带内动力学、带间偶极激发与自旋交换三过程，且关联跳跃项基本决定谱形）；（ii）把诊断量从单粒子双空穴布居 D(t) 扩展为双电子联合诊断量（双电子复合算符的期望与二阶关联）。

模型：周期边界一维 Hubbard 链，`Ĥ(t) = −t₀Σ_σ,j(e^{−iϕ(t)}ĉ†_{j,σ}ĉ_{j+1,σ} + H.c.) + UΣ_j n̂_{j↑}n̂_{j↓}`；精确对角化 + 含时密度矩阵传播；Lindblad 型纯退相干项 `ρ̇_mn(t) = −i[Ĥ̃(t), ρ(t)]_mn − (1−δ_mn)/T₂ · ρ_mn(t)`（非对角元以 T₂ 指数衰减、对角元守恒）；四阶 Runge–Kutta 时间步长 Δt = 0.1 a.u.；把本征态按双空穴权重投影到有效能带后严格分解电流。

扫描网格：填充因子 n = (N↑+N↓)/(2L)×100% 取 5% / 25% / 50%（对应 L = 20 / 8 / 10，与 [ref:5] 同）；U/t₀ 取 5 与 10 两档作基线，并加密扫描 U/t₀ = 5, 6, 7, 8, 9, 10 以找 J2a 的临界点；驱动取线偏振 sin² 包络、总持续 10 光学周期、载波 9.11 µm，峰值场强取 10 MV/cm 与 50 MV/cm（[ref:5] 的两档），并按 J3A 要求**新增场强跨度 ≥ 3 倍的扫描**（如 50 → 150 MV/cm 三档）专用于截止形式裁决；T₂ 扫描取多档以找 J2c 的内极大。

**输入**：[ref:5] 的模型与全部数值参数；[ref:21]（光致非平衡态在 Mott 绝缘体中的行为综述，作为非平衡背景相寿命与相干性的背景约束）；[ref:20]（Mott 绝缘体 HHG 的异常温度依赖：反铁磁关联下 HHG 随降温显著增强——温度作为关联强度代理变量的依据）；[ref:1]、[ref:2] 的双电子鞍点条件（作为三级分解中"双电子同步带间"分量的定义依据）；S1 的 D⁽²⁾ 定义与同步判据。

**输出**：（i）三级电流分解 J_intra / J_pair / J_double 的时域与频域结果；（ii）次级平台相对产额 vs U/t₀ 曲线（J2b）；（iii）次级平台 vs T₂ 曲线（J2c）；（iv）E_cut vs 场强曲线（供 S4 裁决 J3A）；（v）双电子通道在光谱中的形状（平台边缘是否可辨、双空穴特征是否可分辨）。

**判据**（可复算）：
- **复现门槛（先于本课题判据）**：在 [ref:5] 的原始参数点（半满、U/t₀ = 10、50 MV/cm、9.11 µm、10 cyc）上须先复现其定性结论（带内动力学不严格守恒双空穴；U 从 5t₀→10t₀ 系统性抑制带间贡献；50% 填充出现平台与截止）。复现不通过则不得进入本课题判据判定，先修代码。
- **J1（存在性）**：双电子通道截止能超过单对上限 ≥ 15%（单对上限取法见口径表 J1）。
- **J2a（相变）**：存在临界 U/t₀，低于无次级平台、高于出现。
- **J2b（单调性）**：次级平台相对产额随 U/t₀ 单调上升。注意这与 [ref:5] 的"U↑抑制单对带间"方向相反——本判据要求区分"抑制单对带间"与"提升双电子通道"，二者若在同一 U 扫描中同时成立，则说明两个通道由不同物理量控制，这本身是可报告的结构性结论。
- **J2c（退相干符号）**：次级平台产额对 T₂ 呈非单调（内极大）。[ref:5] 已给出关键反直觉事实：纯退相干使**总**双空穴布居上升，而同步复合要求两电子相干存活——这正是内极大的预期来源。
- **J6（维度声明）**：本步输出 E_cut vs 场强三点以上的曲线，S4 据此裁决。**维度依赖的对照取 [ref:7]**：准一维 SrCuO₂ 呈现稳健平台型谱且弱温度依赖，准二维 Pr₂CuO₄ 谐波产额单调下降且高阶热抑制显著，微观起源为自旋–电荷耦合支配的维度依赖 doublon–holon 退相干——故本步的一维链结论不可直接外推到二维，S3 的任何定量结论须标注适用维度。

**预计工作量**：ED + 密度矩阵传播代码重建（含退相干项与带投影，约 3 周）；三级投影分解的改造（约 1.5 周）；参数扫描（U/t₀ 6 档 × 填充 3 档 × 场强 3 档 × T₂ 5 档，约 4 周，含算力等待）；复现门槛检验（约 1 周）。合计约 9.5 周。

**资源估算**：ED 的 Hilbert 空间随 L 与电子数组合式增长，L = 10/8/20 属可直接精确对角化规模；密度矩阵传播为 O(N²) 存储（对角化后本征基中 N 为多体本征态数），L = 10 半满约 10⁴ 量级本征态，单条轨迹内存可控；单次参数点传播（10 光周期 @ 9.11 µm、Δt = 0.1 a.u.）约需 10⁴–10⁵ 时间步，单点机时量级为分钟至小时（首月以实测校准）。全网格总机时**待标定**（首月用单点实测外推）。

**失败处理**：若 L = 10 无法承载双电子同步事件所需的电子数（半满 + 两个额外空穴即超出），降级为 L = 6/8/10 的有限尺寸族并做有限尺寸外推（[ref:5] 自己也把有限尺寸稳健性列为待办），同时把"双电子事件在有限链中的统计权重"作为显式限制写入结论；若三级投影分解在数值上不稳定（近简并本征态导致投影病态），退回到以双电子复合算符的**直接期望值**作为通道指示量，并如实说明分解的模型依赖性。

### S4 截止形式的裁决：标度式 vs 内禀多体尺度钉死式

**方法**：本步单独存在，因为它是主问题三个子问中最容易被既有结论"污染"的一个。[ref:8] 确立固体截止能由"复合时刻遇到的最大带隙"决定并随场强**线性**标度（键长压缩 7.5% 使截止从 10.2 eV 提至 13.8 eV，与材料无关，[ref:8]，摘要核实）；[ref:6] 则在 La₂CuO₄ 中观测到约 **4 eV 且与驱动场强无关**的截止，机制被明确归于 UHB 顶–ZRS 底的间距（"the maximum energy for doublon-holon recombination is bounded by the separation between the ZRS bottom and the UHB top — a scale established at ∼4 eV in cuprates"，[ref:6]，全文核实），且在峰值场强低于约 18 MV/cm 时截止阶次随场强线性标度，接近 4 eV 阈值后再增场强也无法延展。

两条结论从未被放在同一判据下比较（problem.md §2.3 第 2 条）。本步的做法是**把两个候选写成同一组可观测量**，并在同一模型、同一场强网格上同时计算：

- 候选 A（标度式）：`E_cut − E₀ = c·U_p`，c 为待定系数（原子侧 4.7 / 5.5 为参照，非固体预设值），随场强线性移动；
- 候选 B（内禀多体尺度钉死式）：`E_cut = Δ(UHB, ZRS)` 一类不随场强移动的常数。

裁决方法：取 S3 输出的 E_cut vs 场强曲线，按 J3A 的口径（跨度 ≥ 3 倍场强；移动量 > 2 U_p 增量 → 支持 A，< 0.5 U_p 增量 → 支持 B），并辅以**双候选同时拟合的残差比较**——把实测 E_cut(场强) 同时用 `E₀ + c·U_p` 与 `max(E₀ + c·U_p, Δ_多体)` 两种模型拟合，比较残差，并报告哪个候选的参数更少（简约性）而不仅是残差更小。

同时处理 [ref:9] 报告的中间情形：MgO 中 50 eV 纪录（100 μm 厚 (001) 样品、780 nm / 30 fs、峰值强度 0.8–10 TW/cm²）同时报告"谐波截止随场强呈**非平凡**行为，偏离此前预期的平方根依赖"（[ref:9]，摘要核实；其 arXiv ID 经 B2 实测为错误，本条仅以 DOI 10.1364/OL.547945 溯源）。这提示**两候选都不够**的第三种可能，故本步必须报告"两者皆不合"的分支，不能强行二分。

**输入**：S3 的 E_cut vs 场强曲线；S2 的双电子截止能面；[ref:19] 的独立固体线性标度锚（一维 Mott 绝缘体中截止频率与外部场呈线性依赖，与 [ref:8] 在半导体中的结论方向一致，构成候选 A 的双来源支撑）；[ref:8] 的线性标度锚（Si 10.2 eV → 压缩 7.5% 得 13.8 eV，拉伸 7.5% 约 9 eV）；[ref:6] 的 4 eV 恒定截止与 18 MV/cm 阈值；[ref:9] 的 50 eV 纪录与非平凡强度标度。

**输出**：（i）固体版双电子截止的候选形式裁决结论（A / B / 皆不合），附拟合残差与简约性比较；（ii）若为 A，则给出固体修正系数 c 与原子侧 4.7 / 5.5 的偏离幅度及其与带隙/有效质量的关联；（iii）若为 B，则给出该内禀多体尺度在材料间的可外推性判据（能否写成 f(U, t)）；（iv）"两者皆不合"分支下的第三形式候选。

**判据**（可复算）：严格按 J3A 的倍数阈值执行；场强扫描跨度不足 3 倍则本步判定为"数据不足"而非"结论为 A"；拟合须报告参数、置信区间与残差，不以单点匹配作结论。

**预计工作量**：候选形式化与拟合（1.5 周）；与 [ref:8]、[ref:6] 的外部锚点对照与材料无关性检验（1 周）；[ref:9] 中间情形的复现尝试（2 周，含 rt-TDDFT 设置借用 [ref:8] 的 PWMAT 参数：平面波截断 50 Ry、能带 k 网格 12³、电流 k 网格 28³、3000 nm / 20 fs / 1.0 TW/cm²、[111] 偏振）。合计约 4.5 周。

**失败处理**：若两候选残差相当且无法区分（简约性不决），如实报告"在现有场强窗口内不可区分"，并把判决推向 J3E 的双色延时通道分离（用独立的 Δt 依赖性判据替代场强依赖性判据），同时说明该替代判据的可行性前提。

### S5 量子几何调制：双电子电流关联与 Peierls 一致的量子度规

**方法**：本步按 problem.md §2.4 的技术澄清执行——**量子几何进入响应的位置是电流，不是能量**。[ref:10] 证明辐射场量子统计由电流–电流涨落关联函数 D_μν(t,t′) 决定，该张量"encodes key quantum geometric and topological properties"，拓扑相因增强的量子度规张量而电流更强（[ref:10]，全文核实）。因此本课题的量子几何落点是：量子几何通过调制双电子复合的**振幅与相干性**（进而调制谐波产额与相位）来起作用，**不直接改变释放的能量标度**。故 S5 的可观测量是产额与相位，不是截止能。

具体动作：（a）在 S1 的 D⁽²⁾ 定义中显式插入量子几何张量项；（b）量子度规的计算约定必须按 [ref:16] 的**含完整位置算符的协变导数**形式，该形式与由 **Peierls 替换**导出的微观电流唯一强制，且 [ref:16] 指出标准 k·p 有效理论在**键序隙**体系存在领头阶失效（[ref:16]，摘要核实）——固体 NSDR 的双电子复合电流与相位都要走 Peierls 替换，约定不一致则调制量本身不可信；（c）调制旋钮取应变扫描（[ref:11] 的范式：单层 WS₂ 第一性原理模拟，拉伸应变使垂直偏振谐波分量放大约一倍，机制为应变改变带色散增强带内电流 + 显著重塑贝里曲率从而增大带间响应的反常速度贡献，[ref:11]，摘要核实）。因为应变同时改变色散与贝里曲率，两者必须靠**偏振分辨**（垂直分量）把反常速度项单独隔离；（d）把 [ref:12] 的贝里相位直接分辨范式移植为"双电子复合相位 vs 单电子贝里相位的可分辨性"判据——[ref:12] 用双色干涉仪分辨动力学复贝里相位的实部（对应相干带内动力学）与虚部（对应隧穿）（[ref:12]，全文核实）；（e）预筛对称性必要条件：若材料保持时间反演对称且自旋纹理不破坏二重旋转对称性，则双电子通道中需非平凡贝里曲率才可能出现（[ref:13]，摘要核实）。

**输入**：[ref:23]（半经典波包动力学的标准形式：群速度加反常速度项 `ṙ = (1/ħ)∂ε_n/∂k − ḱ×Ω_n(k)`、加速度定理 `ħḱ = −eE − eṙ×B`，适用条件为波包尺寸远大于晶格且带间跃迁弱）；[ref:10] 的 D_μν 框架与 SSH 对偶比较法（J₂/J₁ = J 与 1/J）；[ref:16] 的物理 QGT 协变导数约定；[ref:11] 的应变 + 偏振分辨范式；[ref:12] 的复贝里相位实虚部分辨；[ref:13] 的选择定则；S1 的 D⁽²⁾ 定义。

**输出**：（i）含量子几何项的 D⁽²⁾ 表达式；（ii）应变扫描下的贝里曲率与量子度规张量演化（k 空间计算）；（iii）双电子平台产额的垂直/平行偏振分量比 vs 应变曲线；（iv）双电子复合相位的几何贡献项（与单电子贝里相位的可分辨性判据）。

**判据**（可复算）：
- **J4（主判据）**：同一应变扫描下，垂直偏振的倍频双电子平台分量变化 ≥ 2 倍（相对平行分量），或双电子平台的 attochirp 变化 ≥ 30%。
- **J4-b（计算约定硬要求）**：量子度规须用 [ref:16] 的协变导数形式计算；本步须附带**约定敏感性检验**——用标准 k·p 形式重算一遍并报告两者的差异幅度。若两者差异大，则报告中"量子几何调制量"的绝对数值须标注约定依赖，不得作为定量结论。
- **J4-c（对称性预筛）**：给出所选材料在时间反演/二重旋转对称性下的允许性判定，明确"双电子通道是否存在几何调制"的前提条件。
- **J3B 交叉**：几何调制若改变复合相位，须一并报告 attochirp 变化，并接受 J3B 的 ≤ 0.1 as/eV 约束的重新核验。

**预计工作量**：QGT 协变导数实现与 k 空间计算（2 周）；应变扫描（DFT 设置可借 [ref:11] 与 [ref:8] 的第一性原理设置，键长扫描 ±10% 内、弛豫收敛 10⁻³ eV/Å 量级；[ref:8] 的键长扫描在 ±5% 外已见饱和与反向，故本步的应变窗口收在 ±5%，2 周）；D⁽²⁾ 插入与产额/相位计算（2 周）。合计约 6 周。

**失败处理**：若 [ref:16] 的协变导数约定在所用计算框架中难以实现（完整位置算符的晶胞内轨道位置需从 Wannier 函数显式构造），退回到**只用 Berry 曲率**（[ref:11] 已建立的量）做定性调制判断，并如实声明"量子度规的调制量未按 Peierls 一致约定计算，故不报定量值"——这比用不一致约定给出错误数值更可接受。

### S6 实验方案：先标定、后搜索 keV 平台

**方法**：本步按 problem.md §七 交接项 3 执行——**判据 3E（两通道分离）与判据 5（水窗可行性）都标为 [D]，因为固体中双电子发射时间分布宽度与宏观相干累加长度目前完全未知，因此标定必须单列为第一个实验，而不是直接进入 keV 平台搜索。** 分四个实验段。

**S6-a 标定实验（前置，最高优先级）**：测量现有强关联材料的次周期谐波发射时间分布宽度与相干退化长度，为 J3E 的可分性提供分辨率依据，并标定双色场相位锁定的抖动。测量范式直接采用 [ref:4] 的双色 HHG attochirp 计量（该方案所引用的直接方法前作是 [ref:22] 的双色 HHG 反演对称性破缺测量，以偶次谐波的约四分之一周期调制为核心判据）：3.5 µm 基频（0.35 eV、0.6 TW/cm²、沿 Cu–O 链线偏振）+ 1.75 µm 二倍频（仅 20 MW/cm²，弱约 30 倍，只破缺对称性与编码相位、不独立产生谐波），AGS 晶体倍频后入 Mach–Zehnder 干涉仪控相位，反射几何收集第 4–12 阶谐波；调制周期约为基频的 1/4 周期。退相干标定量取强度加权时间 skewness（[ref:4]：H4 为 0.0045 → H12 为 0.2613 单调上升；12 阶比 4 阶早约 22 fs 达峰；相邻偶阶轨迹最大分离差 0.62a / 0.45a / 0.40a，给出退相干特征长度约 0.5 晶格位点的量级估计）。样品：Ca₀.₄Sr₀.₆CuO₂ 单晶（电荷转移隙 2.1 eV，Tauc 法 2.13 eV），同构替代 SrCuO₂（压强调控备选）。

**S6-b 次级平台搜索**：在标定给出的分辨率窗口内，按 J1、J3A、J3C、J3D 的判据设计对照矩阵。核心对照逻辑继承 [ref:3] 的两条已核实存在条件——扩展只在**过驱动**高强度下出现（[ref:3] 中强度 > 2×10¹⁵ W/cm² 才出现扩展；400 nm / 28 fs / ≤2.8 mJ / 1 kHz），且 He / Ar / Ne 均无扩展（Ar 因 Ar²⁺ 呈**主平台位移**而非延伸）；且波混频通常在**优化通量**下出现而非过驱动区（[ref:3]，全文核实）。固体侧的对照轴由"元素种类"替换为"**关联强度/带宽隙比**"（判据 2 的控制变量选择），因为固体侧不存在"同种原子、不同元素的干净对照"这一原子侧便利条件。

**S6-c 偏振与排除性对照**：椭圆度扫描测双电子平台与单对平台的消失点之差（J3C，≤ 5%）；过驱动 vs 优化通量区的对比用于排除波混频（J3D）；同时沿用 [ref:12] 的复贝里相位分辨范式检查双电子复合相位是否携带可分辨的几何信息。

**S6-d 双色延时通道分离**：Mach–Zehnder + AGS 二倍频范式扫 Δt，测次级平台截止对 Δt 的依赖，尝试分辨 4.7U_p 与 5.5U_p 两条线（Δt ≈ π/ω₀ 与 2π/ω₀）。原子侧这两条线由半经典轨迹分析给出（[ref:3] Fig. 3a,b；[ref:1] 的 Case I/II），固体侧尚无。**本段在 S6-a 标定完成前不得启动**（J3E 为 [D]）。

**输入**：S3 的双电子通道预期谱形与截止位置；S4 的截止形式裁决结果（决定扫场强的窗口）；S1 的 attochirp 预期值（决定双色相位扫描的分辨要求）；[ref:3]、[ref:4] 的实验范式与参数。

**输出**：次级平台的谱形与截止位置；场强扫描下的 E_cut 移动量（J3A 实测）；椭圆度消失点差（J3C）；双电子平台的实测 attochirp（J3B）；双空穴指纹的可分辨性（通过与 S3 理论诊断量的联合拟合间接推断——固体中双空穴产额**不是守恒量**，[ref:5]，故只能作诊断对照而非直接测量）。

**判据**（可复算）：严格按口径表 J1、J3A–J3E 执行；每条判据须同时报告"通过/不通过/数据不足"三态与失败原因，不以"部分符合"作结论；S6-b 的每个对照点须有同场次、同材料、同几何的基线谱，不跨日比较绝对产额。

**预计工作量**：S6-a 标定约 4 周（含样品制备与表征排期）；S6-b 平台搜索约 6 周（场强 3 倍跨度扫描 + 材料系列）；S6-c 偏振与排除性对照约 3 周；S6-d 通道分离约 4 周。合计约 17 周（可与 S1–S5 并行，见 §四 里程碑）。

**失败处理**：若 S6-a 标定给出的发射时间分布宽度过大（例如宽到 4.7U_p 与 5.5U_p 两条线在现有能量分辨率下不可分），则 J3E 判定为"数据不足"并停止 S6-d；此时改以**理论侧的统计区分**为主（用 S3 的双电子事件时间分布做后验投影，判断两条线在噪声水平下的可分性），实验侧转而执行 J3A/J3C/J3D 三条已可执行的判据。

### S7 水窗区桌面积亚阿秒源的可行性评估

**方法**：本步评估的不是"能否实现"，而是**在什么条件下能实现、差多少**。三重约束必须同时计入，缺一则结论无效。

（a）**截止可达性**：双电子通道截止能 ≥ 284 eV（水窗下沿；水窗范围 284–543 eV，[ref:1]，全文核实）。

（b）**相干带宽与合成**：在 ≥ 284 eV 的连续区间内，双电子通道的相位斜率须支持 FWHM ≤ 1 as 的合成脉冲。**这里必须用 [ref:2] 的真实相位而非 [ref:1] 的平谱相位假设**——[ref:1] 的 0.62 as 建立在平谱相位假设上，真实双电子 attochirp 由 [ref:2] 修正为约 1000 eV 处长/短轨迹 0.85 / 0.88 as/eV（[ref:2]，全文核实）。本课题的合成须走 [ref:2] 的路径：取复振幅显式选短轨迹分支做 Fourier 合成 `E_atto(t) = Re[Σ_{|r(Nω₀)|^(1/2) e^{−iNω₀ t}}]`，不使用平谱相位近似。

（c）**产额约束**：这是最硬的一条。原子侧 DER/SER 平台产额比在实验中约 **4 个数量级**，而在单原子 TDSE 中近 **10 个数量级**（[ref:3]，全文核实）；固体中双电子通道产额只会更低。因此 J5 的可达性**必须由相干累加（多原子/多胞元）回答，不能由单胞元产额回答**。本步须建立宏观相干累加模型：计算带间极化相干长度、再吸收长度与损伤阈值构成的三重约束下，可累积的有效相干体积与总通量。

对标基线：气体路线的已验证标杆为 3.9 µm 中红外 + 约 35 atm He 空心波导，谱延伸到 > 1.6 keV，1 keV 处 1% 带宽内约 10⁵ photons/shot，相位匹配截止标度 `hν_PM cutoff ∝ λ_L^{1.5–1.7}`，压缩后理论上支持 2.5 as 脉冲（[ref:14]，全文核实）。固体在相位匹配/传播上有气体所没有的可调自由度（厚度、晶向、相位匹配几何），这是本课题可能的增量——但须用同一口径与气体基线对比，不能只报固体自身数字。相位匹配口径取 Δk = q·k_q − k_ω，四个贡献项（中性色散、等离子体色散、Gouy 几何相位、吸收），吸收极限谐波阶 q_abs ≈ L_med / L_abs（KB 方法页 [[相位匹配]]）。

**输入**：S4 的截止形式裁决（决定是标度式可达水窗还是被内禀多体尺度钉死）；S1/S2 的 attochirp 与相位结构；S3 的单胞元产额比；[ref:3] 的 4 vs 10 数量级约束；[ref:14] 的气体基线；[[相位匹配]] 方法页的口径。

**输出**：（i）可达性判定（达到 / 未达到 / 差多少数量级）；（ii）若未达到，缺口分解为"截止能缺口"与"相干累加长度缺口"两项，分别给出所需条件；（iii）固体版相位匹配几何的可调自由度清单与最优晶向/厚度建议；（iv）与气体基线（[ref:14]）的同口径对比表。

**判据**（可复算）：严格按口径表 J5 的双阈值（a）≥ 284 eV、（b）FWHM ≤ 1 as 执行，且**必须附产额约束说明**——产额比结论若基于单胞元计算而未经相干累加建模，则 (b) 判定为"数据不足"；合成脉冲的 FWHM 须由含完整相位的 Fourier 合成给出，不得引用平谱相位估计；气体对比须同口径（同一通量定义、同一带宽定义）。

**预计工作量**：宏观相干累加与相位匹配建模（3 周）；含相位的脉冲合成实现（1.5 周）；与气体基线的同口径对比（1 周）；缺口分解报告（1 周）。合计约 6.5 周。

**失败处理**：若相干累加模型给出的通量远低于气体基线（< 10³ photons/shot 量级），判定"固体版水窗桌面积亚阿秒源在现有约束下不可行"，并把结论收缩为**科学可行性而非工程可行性**——即明确报告"固体 NSDR 通道存在且可判别，但水窗源不可行，理由是相干累加长度而非机制本身"，同时指出放宽哪一项约束（晶向自由度 / 厚度 / 材料选择）可回到可行区间。这与 [ref:2] 自陈的宏观传播缺口（宏观传播需要 Antoine/L'Huillier (1996) 式的相位匹配才能定量预言发射波形）一致。

## 六、风险与备选路线

每个关键步骤一条 fallback，失效条件尽量写成可监测的量。

- **S1（定义层）**：D⁽²⁾ 的两条极限检验不能同时通过 → 退回到以**双电子复合算符的复合矩** `⟨Ĉ₂⁺(t)Ĉ₂(t′)⟩` 定义同步复合（去掉电磁学外壳、保留多体关联内核）；若 J0-b 显示同步判据与 D(t) 不可分辨 → 承认"同步复合在单粒子观测层面不可分辨"，把主问题转为"同步条件能否由谱形间接判别"，并把 S6 的实验重心从双空穴指纹移至截止形式（J3A）。
- **S2（轨迹层）**：在 [ref:4] 参数点下**不存在**双电子同步轨迹族 → 这本身是主问题存在性分支的否定答案，必须如实报告而非调参硬凑；此时转入**软同步**版本，扫描两电子复合时刻差 Δt 给出相干累加有效的容差窗口，把该窗口作为固体内 NSDR 时间同步要求严苛程度的定量输出（直接支撑 J3E 的 Δt 扫描设计）。
- **S3（ED 数值）**：复现门槛不通过 → 在修好 [ref:5] 复现之前，不做任何本课题判据判定（纪律硬约束）；L = 10 装不下双电子同步事件 → 降级为 L = 6/8/10 有限尺寸族并显式声明有限尺寸效应未外推；三级投影近简并病态 → 改用双电子复合算符直接期望值作通道指示量，并声明分解的模型依赖性。
- **S4（截止裁决）**：两候选残差相当、简约性无法裁决 → 如实报告"现有场强窗口内不可区分"，转用 J3E 的双色延时依赖性作独立判据，并声明该替代路径的前置条件（S6-a 标定必须先完成）；[ref:9] 的"非平凡强度标度"型第三分支成立 → 明确产出第三形式候选（标度 + 内禀上限的混合式 `max(E₀ + c·U_p, Δ_多体)`），并把该混合形式写成独立候选而非事后解释。
- **S5（量子几何）**：[ref:16] 的协变导数约定在所用框架中难以实现（需显式构造含胞内轨道位置的 Wannier 函数）→ 退回只用 Berry 曲率做定性调制判断，**不报量子度规调制量的定量值**，并在报告中声明"因未按 Peierls 一致约定计算，调制量的绝对数值不可信"；应变扫描超 ±5% 出现饱和与反向（[ref:8] 观察到键长变化超过约 ±5% 后截止能饱和甚至反向）→ 收窄应变窗口至 ±5% 并在结论中声明该窗口限制。
- **S6（实验）**：S6-a 标定显示发射时间分布过宽，两条截止线不可分 → J3E 判定"数据不足"并停止 S6-d，改以 S3 理论事件时间分布做后验投影的可分性分析，实验侧只执行 J3A/J3C/J3D；材料侧标定平台缺失（强关联材料损伤阈值低于过驱动所需场强）→ 转入宽带隙绝缘体支（如 MgO 的 7.8 eV 带隙，[ref:12]，全文核实），但须声明该支不含 Mott 关联，故只检验"双电子通道"部分，不检验"关联竞争"部分（J2 系列在宽带隙支无效，结论须按维度/体系分别陈述，见 J6）；波混频无法排除 → 按 [ref:3] 的纪律逐个排除替代通道（波混频、带间三阶非线性混合、双光子吸收），未能排除者如实报告为未排除。
- **S7（可行性）**：相干累加模型给出的通量远低于气体基线 → 判定"固体版水窗桌面积亚阿秒源在现有约束下不可行"，把结论收缩为科学可行性而非工程可行性，明确指出瓶颈是相干累加长度而非 NSDR 机制本身，并列出可放宽的约束项（晶向、厚度、材料选择）；相干累加模型依赖的带间极化相干长度无实验值 → 标"待标定"并把 J5 的 (b) 判定为"数据不足"，不以模型输出充当实测输入。
