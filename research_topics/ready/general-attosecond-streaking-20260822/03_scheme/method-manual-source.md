## M1：TDSE 双通道耦合数值模拟

### 物理模型与算法依据

气体靶多通道效应表现为不同电离阈的贡献叠加而非能带结构效应。TDSE 在单电子近似下严格处理双通道耦合势项 $V_{ij}(t) = \langle\psi_i|\mathbf{r}\cdot\mathbf{E}(t)|\psi_j\rangle$，使通道间相位关系以数值方式自洽体现；解析少带模型在能带结构场景下有优势，但在原子气体多电离阈叠加场景下通道耦合由连续态与不同束缚末态的叠加决定，必须在足够大的箱体边界与足够细的空间网格下做数值自洽求解。该选择决定 M1 模拟端只产出气体靶条纹信号，不外推至固体 HHG 体系。TDSE 在阿秒条纹场景下亦可作为基准生成真值时延已知的合成条纹谱数据，使各系统误差可被逐项定量分离（[[methods/TDSE求解器]]）。

TDSE 形式（原子单位）：

$$i\frac{\partial}{\partial t}\Psi(\mathbf{r},t) = \left[ -\frac{1}{2}\nabla^2 + V(\mathbf{r}) + \mathbf{r}\cdot\mathbf{E}(t) \right]\Psi(\mathbf{r},t)$$

$V(\mathbf{r})$ 为原子库仑势，$\mathbf{E}(t) = \mathbf{E}_{\mathrm{XUV}}(t) + \mathbf{E}_{\mathrm{IR}}(t)$ 为 XUV 与 IR 联合电场。波函数按本征态分波展开 $|\Psi(t)\rangle = \sum_n c_n(t)|n\rangle e^{-iE_n t}$。末态动量取 $\vec{k}+\vec{A}(t)$（$\vec{A}(t)=-\int\vec{E}(t)\,\mathrm{d}t$），展开至矢势二次项：

$$E_{\mathrm{final}} = E_{\mathrm{kin}} + U_{\mathrm{p}}\left[1 - \cos 2(\omega t + \phi_{\mathrm{CEP}})\right] + \vec{A}(t) \cdot \vec{k}$$

$E_{\mathrm{kin}}$ 为无场光电子动能；$U_{\mathrm{p}} = E_0^2/4\omega^2 = A_0^2/4$，$U_{\mathrm{p}}[1-\cos 2(\omega t+\phi_{\mathrm{CEP}})]$ 即 $A^2/2$ 的等价表述。展开精确至二次项，无更高阶矢势项；弱场近似所省略的是库仑末态修正与相对论修正（不在本手册范围）。单通道条件下该式严格成立；多通道叠加下动量空间出现重叠，通道间相位干涉项 $\Delta\phi_{ij}$ 须显式引入——即 M2 处理对象。

### 两级建模层级

建模分基准级与验证级两级，承担不同物理对象与方法学角色。

**基准级（双通道 TDSE）**：单电子近似下的两能级干涉模型，以通道间相位干涉项 $\Delta\phi_{ij}$ 为核心。输出直接进入 M2 代价函数的光谱拟合与通道强度比 $R = I_2/I_1$ 提取。适用条件（两判据同时满足）：(a) 通道间能量差 $\Delta E \geq 0.5$ eV，保证通道波函数在能量域可分离，混合可作微扰处理；(b) 通道重叠宽度 0.5–2 eV，物理上受 XUV 脉冲相干宽度与探测器能量分辨率共同约束。$\Delta E < 0.5$ eV 时（如 CO₂/N₂/Ne 2s2p 高能点约 0.3 eV），双通道近似退化，解析修正项失效，触发备选路径 A。C K 边（C 1s → 2π*，~284 eV）与 N K 边（N 1s → 2π*，~409.7 eV）通道能量差均满足判据 (a)。CH₄ 的 shake-up 通道能量以 Köppe 等 [31] 1996 年高分辨 C 1s 光电子能谱实测为准：C 1s 电离阈 290.7 eV，shake-up 卫星阈位于 303 eV 与 311 eV 附近，即电离阈之上 12–20 eV，通道间能量差远超判据 (a) 的 0.5 eV 门限；伴峰具体能量以第一阶段模拟端扫描结果为准（见「分阶段模拟执行计划」），覆盖水窗低段典型多通道场景，不预设无文献支撑的伴峰数值。

**验证级（R 矩阵 TD，外部检验）**：针对 shake-up 残离子关联通道，核算对象限定为氦原子，即 He⁺ 残离子的 2s/2p 关联激发终态。氦原子的残离子激发通道可由有限基组展开，且已有六维含时薛定谔方程从头计算作为对照，是本层级唯一可核算的对象。分子靶（CH₄、N₂ 等）的残离子激发终态不进入本项目的建模层级：其关联通道仅可展开有限子空间，不适用于多电子同时出射的连续耦合终态，目前无先例支撑其核算，故列为第二阶段拓展方向；分子靶关联通道的可展开子空间与失效边界由研究内容一 K1 界定，本手册不重述该论证。SAE-TDSE 在 shake-up 等剩余离子关联动力学中失效，须采用 R 矩阵含时理论单独核算。验证级定位：**(i)** 不参与参数标定，输出不进入 M2 形式标定，与基准级形成方法学互补；**(ii)** 以 R 矩阵的 shake-up 振幅因子 $f_{\mathrm{shake}}(E)$ 为输入复现光电子能谱贡献，与基准级修正项在残离子终态维度的预测值比对，偏差 < 10% 视为核验通过；**(iii)** R1 阶段只覆盖氦原子的 5–10 个参数点，不展开为全参数扫描。

验证级的物理支撑与参数基线取自 Shi 与 Thumm [14] 的六维含时薛定谔方程计算：该工作给出氦原子角度分辨条纹 shake-up 电离中的光电子–残离子相互作用，残离子–光电子–IR 场的三重耦合在相位层面引入随发射方向与动能变化的相干修正，其时延分解为 $t_{\mathrm{s}} = t_{\mathrm{EWS}} + t_{\mathrm{CLC}} + t_{\mathrm{DLC}}$ 三项之和，其中偶极–激光耦合项 $t_{\mathrm{DLC}}(k) \approx d_z^{(n)}(k)/(k\cos\theta)$ 携带 $1/\cos\theta$ 的角度放大因子，为验证级「方向依赖相干修正」这一命题给出可直接对标的解析形式与参数取值（[[papers/2024-2409_03622-photoelectronresidual-ion-entanglement-in-streaked-shake-up]]）。其可迁移到本层级的参数基线为：IR 条纹脉冲 FWHM 3 fs、峰值强度 $4\times10^{11}$ W/cm²；XUV 光子能量 90 eV（另算 100/110/120 eV）、FWHM 200 as、峰值强度 $10^{12}$ W/cm²；延迟采样 40 个等间距点覆盖 2 个 IR 周期，且在 IR 强度 $10^{8}$–$10^{12}$ W/cm² 区间内 streaking 时延及其拟合精度基本不依赖探针强度；末态通道数按 $2n(n-1)+1$ 计（n=2 shake-up 为 5 通道、n=3 为 13 通道）；Stark 态投影时刻取 XUV 脉冲中心后 $t_{\ast} = 5.5$ fs，$t_{\mathrm{DLC}}$ 近似在 $\gamma < 1.6^\circ$ 可忽略、且以 $t_{\mathrm{DLC}}$ 小于 IR 周期 5% 为适用条件。R 矩阵核算须沿用同一组几何与脉冲参数，使验证级输出与该基线在同一条件下可比；相位展开与投影时序的实现细节见 §验证级 R 矩阵含时理论——5 步骨架。

上述参数基线同时界定了本层级的失效边界：$t_{\mathrm{DLC}}$ 的偶极近似在小角度与慢 IR 外失效，M=0 磁量子数守恒限制了圆偏与非共线几何的推广，自适应 FE-DVR 网格与分波收敛成本随通道数上升；相应处置为验证级固定在线偏振、几何与基线一致，偏离基线的构型不纳入核验通过判据（[[methods/TDSE求解器]] 给出 SAE 近似下"物理精确"的适用前提与多电子关联须由双电子全关联 TDSE 或 RMT 多体 TDSE 承担的分工，以及 He 体系双电子全关联 TDSE 与含时 R-matrix 内外区耦合推进至多体体系的既有实现路径，作为本层级方法选择的依据）。

### 验证级 R 矩阵含时理论——5 步骨架

R 矩阵以内区/外区划分为核心：内区含 N-1 电子束缚态与靶极化，外区只含一个出射电子的库仑势。

```
输入：靶离子哈密顿 H_{N-1}、通道数 N_ch、shake-up 末态标记
输出：含 shake-up 残离子关联通道的光电子能谱 S(E, τ)

# 步骤 1：内区基组与 R 矩阵构造
#   求解 (N-1) 电子靶离子本征方程 H_{N-1} φ_α = E_α φ_α
#   得 {φ_α}（含 shake-up 源）；在 r=a 处构造 (N-1) 电子径向基组 {u_{nl}}
#   （Dirichlet 边界）；构造 N+1 电子反对称化乘积态；求 (E-H)Ψ=0
#   边界值问题，得 R 矩阵 R_{kl}=(1/u_k)·du_k/dr|_{r=a}

# 步骤 2：外区库仑传播得 S 矩阵
#   外区每通道为单电子库仑问题；r=a 用 Buttle 修正延拓 R 矩阵至渐近区；
#   库仑波函数传播至 r→∞，得 K 矩阵与 S 矩阵

# 步骤 3：shake-up 通道标记
#   分离单激发 shake-up 末态（CH₄ 的 C 1s⁻¹2π*¹⁰ 等）；
#   通道 α 总能量修正 E_α^shake = E_α^基 + ΔE^shake（CH₄ ~5–15 eV）；
#   通道 α 电离振幅中乘以 shake-up 振幅因子 f_shake(E)

# 步骤 4：含时演化（与基准级同 RK4，Δt ≤ 0.2 as）
#   步骤 2 S 矩阵构造 t=0 散射态初态；XUV+IR 联合场下 RK4 演化

# 步骤 5：输出 S(E, τ)，含 shake-up 残离子关联通道贡献
```

关键参数：内区半径 $a$ = 15–25 a.u.；通道数 $N_{\mathrm{ch}}$ = 10–30（CH₄ 约 12、N₂ 约 10）；(N-1) 电子基组 50–200 个组态；外区径向网格 50–5000 a.u.（对数网格 1000–2000 点）；Buttle 修正阶数 1–6；角动量截断 $\ell_{\max}$ = 5–8。

### 算法伪代码（基准级）

```
输入：靶材能级 {E_n}，通道数 N_ch，场参数 (E_XUV, E_IR, τ)
输出：条纹信号 S(E, τ)

# 步骤 1：初态制备
c(t=0) ← [1, 0, ..., 0]  # 选择性布居初始通道

# 步骤 2：预计算原子本征态矩阵元
for i,j in range(N_ch): d_ij ← ⟨ψ_i| r | ψ_j⟩

# 步骤 3：时间演化（RK4，dt ≤ 0.2 as）
t ← 0
while t < t_final:
    k1 ← -i·H(t)@c(t)
    k2 ← -i·H(t+dt/2)@(c+dt/2·k1)
    k3 ← -i·H(t+dt/2)@(c+dt/2·k2)
    k4 ← -i·H(t+dt)@(c+dt·k3)
    c ← c + dt/6·(k1+2k2+2k3+k4)
    # 每步 PML 衰减因子

# 步骤 4：谱计算
S(E) ← |FT{c(t_final)}|²

# 步骤 5：延迟扫描
for τ in [−5000:100:5000] as:  # ±5 fs、步长 100 as，101 点
    重复步骤 3-4，得 S(E, τ)
```

### 执行层操作细节

**初态制备**：靶材初始电子态，通道数 2–3，通道能量差 ΔE ≥ 0.5 eV。

**场构型**：XUV 中心光子能量 284–410 eV（水窗低段），脉冲宽度 100–300 as，高斯或双曲正割型。IR 条纹场的波长、峰值强度、$U_{\mathrm{p}}$ 与 γ 档位见 §IR 条纹场共用档位（两套平台统一，方案 §3.1 沿用）。两场共线共焦点，IR 延迟通过压电陶瓷扫描。

**时间积分**：RK4 积分耦合 ODE 组。柱坐标 $(r,\theta)$，$r$ 方向 512–1024 点、$r_{\max}=50$–100 a.u.，PML 吸收边界。守恒性以总概率 $\sum_n|c_n(t)|^2$ 守恒至 6 位有效数字确认。

**谱计算**：对 $c_n(t_{\mathrm{final}})$ 做傅里叶变换得 $S(E)$。延迟 $\tau$ 扫描 ±2–5 fs、步长 ≤100 as、≥100 点，得 $S(E,\tau)$。

**干涉特征提取**：对每个能量点 $E$ 在延迟方向 FFT 并做多谐波拟合（窗内 ≥20 个延迟点），提取峰值频率相位即 $\Delta\phi(E)$ 与 $R(E) = I_2(E)/I_1(E)$。若通道重叠宽度 ≥ 0.5 eV 修正项生效（与失效边界 < 0.5 eV 衔接）。

### 通道混合度 η 的计算与映射

$\eta$ 用于量化双通道间强耦合程度，是触发备选路径 A 的判定量。

1. 对 TDSE 输出 $S(E)$ 做多高斯拟合（通道数 2 或 3）：$S(E) = \sum_i A_i \exp[-(E-E_i)^2/(2\sigma_i^2)]$。
2. 提取峰面积 $A_i\sqrt{2\pi}\sigma_i$，计算 $\eta = A_2/(A_1+A_2)$；三通道时以主通道为分母，$\eta = (A_2+A_3)/(A_1+A_2+A_3)$。
3. 不确定度：典型计数 $N_1,N_2\geq10^4$ 下 $\delta A_i = \sqrt{N_i}$，传播至 $\eta$ 的相对不确定度 < 10%，满足 30% 触发条件判定可靠性（信噪比 > 3σ）。

实验端对测得能谱做相同多高斯拟合提取 $A_i$ 计算 $\eta$ 作为代理量。

$\eta$ 与研究方案 §2.1/R3 §3.3 中"多通道贡献占总截面百分比"（M2 中 8%–50%、15%–30% 区间所对应物理量）的差异：$\eta = A_2/(A_1+A_2)$ 由条纹谱多高斯峰面积比提取，含通道间干涉项与脉冲包络卷积效应；多通道贡献为去卷积后的次通道截面占比（不含干涉项）。映射的非平凡性正来自干涉项与卷积修正。该映射为 R1 阶段待标定的占位关系（预期：30% → ~40%），由模拟端对照 Verner–Yakovlev 分壳层截面拟合（截面源口径见 M3 靶材配置表）与已发表多通道截面曲线标定后固化；Peschel 等 [6]（2022）数据是否含可直接复用 $\eta$–$R_{\mathrm{ch}}$ 散点须在 R1 阶段调取原文复核。

| 通道混合度 η | 多通道贡献百分比（占位值） | 在三层口径中的位置 |
|----------------|---------------|------------------|
| 5% | ~7% | 可行性论证层下界（8%）附近 |
| 10% | ~14% | 可行性论证层内（锚点约 10%） |
| 15% | ~22% | 实验验证层下界附近 |
| 30% | ~40% | 备选路径 A 触发线（先于失效边界 50% 约 10 个百分点） |
| 50% | ~60% | 失效边界外 |

物理意义：备选路径 A 触发线（30%）先于失效边界（50%）约 10 个百分点，给出从解析修正降级到神经网络再到完全失效的渐进路径。M6 双变量图谱横轴沿用"多通道贡献百分比"，纵轴采用 η 时需先经该映射换算。

### 验证方式

**解析基准验证**：单通道极限（去除 $V_{ij}(t)$）下 TDSE 与少带模型解析结果相对偏差 < 1%。

**文献复现验证**：氖原子 2s/2p 双通道体系（能量差约 4 eV），复现文献已知光电子能谱结构。

**收敛性测试**：网格密度（512/1024/2048 点）与时间步长（0.4/0.2/0.1 as）下 < 1% 变化内收敛。

**守恒律验证**：$\sum_n|c_n(t)|^2$ 演化全程守恒至 6 位有效数字。

**重构误差验证**：TDSE 模拟信号输入传统 FROG-CRAB；多通道贡献 > 15% 时误差跳升至 > 20%（模拟端预期值，作为 R1 终止判据"目标降幅 ≥ 4 倍"的依据；修正前基准误差以第一步氦靶实测为准）。

**预期产出**：完成 284–409.7 eV 能区三参数点基准数据库，解析修正项适用参数区间明确标定。

### 失效边界与风险缓解

**失效边界**：通道间能量差 < 0.5 eV 时双通道近似波函数可分离性丧失，TDSE 结果失去物理意义。

**风险缓解**：在 0.5–1 eV 区间做参数扫描，确认修正项适用性随能量差增大单调恢复。通道混合度 η > 30% 触发备选路径 A（神经网络学习通道干涉模式）。


## M2：通道间相位干涉解析修正项

### 数学基础

总光电子能谱含两通道干涉项：

$$S(E) = S_1(E) + S_2(E) + 2\sqrt{S_1(E)S_2(E)}\cos[\Delta\phi(E)]$$

其中干涉项的相位 $\Delta\phi(E)$ 与通道强度比 $R(E) = S_2(E)/S_1(E)$ 为待提取参量。

修正项的物理来源：传统 FROG-CRAB（[[methods/FROG]]，以广义投影迭代同时反演脉冲强度与相位）假设条纹信号是脉冲电场的二阶非线性响应，该假设在多通道叠加条件下因通道间相位干涉而失效。KB FROG 方法页登记的适用边界与该失效同向：标准 FROG-CRAB 反演在通道混合、脉冲啁啾与库仑-激光耦合（CLC）下提取的时延/相位相对真值存在系统性偏差（arXiv:2312.14174）。修正项在代价函数中引入通道干涉约束，使相位检索过程显式利用干涉相位信息。

### 算法步骤

**步骤 1：干涉特征提取**

从 TDSE 模拟或实验的条纹能谱 $S(E,\tau)$ 中，对每个能量点 $E$ 在延迟方向做全窗口傅里叶变换并做多谐波拟合（延迟采样 ≥100 点、步长 ≤100 as；原 200 as 短时傅里叶窗在 100 as 步长下仅 2 点，不足以支撑时频分析，已废弃），提取干涉项的相位 $\Delta\phi(E)$ 与强度比 $R(E)$。

**步骤 2：修正项构造**

以 $\Delta\phi$ 与 $R$ 为参量，修正项取以下形式：

$$\Phi_{\mathrm{corr}}(\omega) = \alpha \cdot \Delta\phi \cdot S_{\mathrm{interference}}(\omega)$$

其中 $\alpha$ 为通道强度相关加权系数（量纲为一），由 TDSE 模拟标定；$S_{\mathrm{interference}}(\omega)$ 为干涉项的光谱分布，从条纹迹中提取。

修正项有效性的数值判据：重构脉冲与真实脉冲的均方根相位误差以 2π 归一后 $\delta\phi_{\mathrm{RMS}}/2\pi\times100\% < 5\%$。

**步骤 3：嵌入代价函数**

将修正项嵌入 FROG-CRAB 代价函数：

$$C(\varphi) = C_{\mathrm{FROG-CRAB}}(\varphi) + \lambda \cdot \mathrm{Penalty}(\Delta\phi)$$

$C_{\mathrm{FROG-CRAB}}$ 为传统 FROG-CRAB 代价函数，$\lambda$ 为正则化系数，$\mathrm{Penalty}$ 为通道干涉约束项（惩罚量取检索相位推算的干涉相位估计与从条纹迹中提取的干涉相位之间的二范数）。$\lambda$ 取值通过 L-curve 法在预处理阶段确定，扫描范围 $\lambda \in [10^{-4}, 10^{0}]$，在对数坐标下寻找 $\chi^2$ 与惩罚项的 L 形拐点。终止判据为重构脉冲与 TDSE 输入真值的均方根相位误差以 2π 归一后小于 5%（模拟验证层面的可量化指标）。

L-curve 法选取 $\lambda$ 的具体步骤：在对数坐标下扫描 $\lambda \in [10^{-4}, 10^{0}]$，计算对应解的 $\|\chi^2\|$ 与惩罚项 $\|\mathrm{Penalty}\|^2$，在双对数图上通常呈现 L 形拐点，选取拐点处 $\lambda$ 值作为最优正则化参数。该步骤独立于主迭代，在预处理阶段完成。

**步骤 4：迭代检索**

使用共轭梯度法（CG）或主成分分析法（PCG）求解修正后的代价函数。CG 迭代公式：

$$\mathbf{p}_{k+1} = \mathbf{r}_k + \beta_k \mathbf{p}_k$$

$$\beta_k = \frac{\mathbf{r}_k^T \mathbf{r}_k}{\mathbf{r}_{k-1}^T \mathbf{r}_{k-1}}$$

其中 $\mathbf{r}_k = \nabla \chi^2(\Phi_k)$ 为残差梯度，$\mathbf{p}_k$ 为搜索方向。迭代终止条件：相邻两步 $\chi^2$ 变化 $< 10^{-4}$ 或达到 200 次迭代上限。

**步骤 5：误差评估**

以重构脉冲与真实脉冲的均方根相位误差为判据：

$$\delta\phi_{\mathrm{RMS}} = \sqrt{\frac{1}{N}\sum_{k=1}^{N}\left|\Phi_{\mathrm{retrieved}}(\omega_k) - \Phi_{\mathrm{true}}(\omega_k)\right|^2}$$

修正有效的阈值：$\delta\phi_{\mathrm{RMS}}/2\pi\times100\% < 5\%$（以 2π 归一）。

| 加权系数 $\alpha$ | 由 TDSE 模拟确定（典型值 0.5–1.5） | 通道强度相关 |
| 束线时间预算（分段口径） | 六组纯采集 208 h ≈ 9 天；M3 三组 104 h ≈ 3 周；M4 四组 83 h ≈ 3 周；三段合计纯采集 396 h ≈ 17 天；总占用典型 12–14 周，最坏约 24 周 | 按研究方案 §3.3 分段口径，单延迟点积分时间为唯一输入；推算链见下方"束线预算推算链"段 |

**束线预算推算链**：单延迟点积分时间按方案 §3.1 的算式 $t = 10^3/(\Phi_{\mathrm{pulse}}\cdot f_{\mathrm{rep}}\cdot N)$ 核算，其中 $\Phi_{\mathrm{pulse}}$ 为单脉冲光子数、$f_{\mathrm{rep}} = 1$ kHz、$N$ 为单光子计数产额。取标称组合（$\Phi_{\mathrm{pulse}} = 10^4$ 每脉冲、$N = 2.0\times10^{-6}$）得每延迟点 50 s。取通量下沿与产额下沿组合（$\Phi_{\mathrm{pulse}} = 10^3$、$N = 1.8\times10^{-7}$）得 5.6×10³ s ≈ 93 min，为单延迟点耗时最长的情形。计数产额链 $N = R_{\mathrm{mirror}}\cdot f_{\mathrm{abs}}\cdot(\Omega/4\pi)\cdot\eta_{\mathrm{det}}$ 的四因子取值与光子通量区间见 M3 §两套实验平台分工与硬件配置。水窗段光子通量的实验上界由 [[papers/2020-2003_06755-energy-scaling-of-water-window-high-order-harmonic-generatio]] 给出（He 靶水窗区光子通量 $(7.12\pm0.30)\times10^{8}$/s、较此前提升约 100 倍），该文为本项目通量上沿估计的参照。

单组采集时间为 $t\times$ 延迟点数 $\times$ 重复次数。标称 50 s 下，500 延迟点、5 次重复时单组 34.7 h，100 延迟点时 6.9 h，300 延迟点、5 次重复时单组 20.8 h。按方案 §3.3 的分组口径累加：M6 跨能区标定六组（每组 500 延迟点）纯采集 208 h ≈ 9 天；M3 多通道失效修正三组（每组 500 延迟点，氦气基准测量复用 M3 已建测量、不占新增束线）纯采集 104 h ≈ 3 周；M4 偶极相位角积分解耦四组（每组 300 延迟点）纯采集 83 h ≈ 3 周。三段合计纯采集 396 h ≈ 17 天，计入束路切换、通道效率标定与能区门控检验后，总束线占用典型 12–14 周。

低截面能点的最坏情形按 93 min/延迟点核算。维持 500 延迟点与 5 次重复时单组 161 天，六组全落入该情形将超出四年周期内可承受的实验窗口。压缩措施为两项：重复次数由 5 次降至 2 次，延迟点取 100 个子集。两项同时施加后单组采集时间降至 12.9 天；六组中若仅 3 个低截面能点组落入最坏情形，则最坏合计约 39 天，实际组数超出 3 个时按比例上调。该"3 组"为方案设计假设值，非实测统计。三段全部测量组均落入最坏情形时，压缩措施下的总占用上限约 24 周，较典型值增加约 10 周，仍可安排在第 2 至第 4 年的实验窗口内。条纹测量的延迟扫描与相位提取要求见 [[methods/阿秒条纹相机]]：XUV/IR 延迟扫描为重建条纹谱并提取相位的必要条件，单发条纹相位精度约 20%。

**失效模式与替代方案**：单延迟点耗时超出 93 min 的最坏情形（产额低于 $1.8\times10^{-7}$）按上述两项压缩措施处置。若压缩后信噪比仍不足，替代路径是以 §关键取值溯源表所列的判据降级运行——延迟点取 100 点下限、重复 2 次下限，此时单组 12.9 天为采集端上限。相应地缩小单组覆盖的靶材组数，并在误差图谱中按插值权重下调该点的支撑度，不以延长束线时间补足统计量。束线占用与年度计划的对应关系见研究方案 §3.3。

### 验证方式

**自洽性验证**：用修正后的脉冲相位重新计算条纹信号 $S_{\mathrm{model}}(E,\tau)$，与原始输入信号做二维相关，要求相关系数 > 0.95。

**参数敏感性验证**：在 $\alpha \pm 20\%$ 范围内扫描，确认 $\delta\phi_{\mathrm{RMS}}$ 变化 < 1%，以验证修正项对参数取值不敏感。

**通道数普适性验证**：分别用 2 通道和 3 通道 TDSE 数据测试，确认修正项形式不变，仅 $\alpha$ 系数需随通道数轻微调整。

**外部数据验证**：以 Cousin 等（Phys Rev X 7, 041030, 2017）的公开数据集作为外部基准，以氦靶单通道实测基准为参照，确认修正算法将多通道条件下的重构误差压低至 < 5%（修正前基准误差以氦靶实测为准，"20%" 为模拟端预期值、非文献引用值）。

### 三层口径与 10% 锚点

"多通道贡献百分比"在 M2 中按三层口径使用，三层之间是**嵌套**关系（实验验证 ⊂ 算法适用；可行性论证 ⊂ 算法适用 ⊂ 实验验证的扩展），而非并列口径：

| 层级 | 多通道贡献区间 | 用途 | 验证锚点 |
|------|-------------|------|---------|
| 算法适用层 | 8%–50% | 解析修正项可拟合的完整区间 | 修正项形式在该区间均成立 |
| 实验验证层 | 15%–30% | 对应 CH₄、N₂ 等水窗典型靶材的自然落点 | M3 三步验证流程 |
| 可行性论证层 | 8%–15% | 与 rACE 方法[7]单通道假设边界形成交叉验证 | 10% 锚点（rACE 边界处，区间内代表点） |

10% 锚点为本方案设定口径，由 R1 模拟端对照标定：修正项的解析形式可与 rACE 单通道假设下的解析形式独立比对，二者重构误差之差即为可行性判据。该交叉验证属已有方法学对照，无原理性障碍。

三层口径在本手册 M2/M3/M6 与申请书研究内容 §2.2、可行性分析 §4.1 完全对齐。任何阶段引用"多通道贡献"区间时须明确所属层级，避免区间错配。

### 失效边界与风险缓解

**失效边界**：通道重叠宽度 < 0.5 eV 时，双通道近似的可分离性丧失，修正项不再适用。

**风险缓解**：触发条件为 TDSE 模拟中通道混合度（以通道投影算子衡量）> 30%。此时切换至备选路径 A（神经网络学习通道干涉模式，详见 §M5/M2 失效处置）。

### 两套实验平台分工与硬件配置

研究方案 §1 与 §3.1 给出两套实验平台的总体分工与共用硬件清单：极紫外平台用于单通道极限场景的方法学验证（中心能量 100 eV、脉冲宽度 < 300 as），覆盖 50–150 eV 极紫外能区；软 X 射线平台承担多通道失效场景复现（中心能量 284–543 eV），覆盖水窗低段 284–409.7 eV 与水窗高段 409.7–543 eV 全区间。两套平台共用 1 kHz Ti:sapphire 泵浦源、HHG 靶室与 16 通道角分立 TOF 阵列；软 X 射线平台在此基础上加装中红外驱动级（1850 nm OPA/OPCPA 等）经空心芯光纤压缩至亚周期量级，配幅度门/偏振门选通孤立阿秒辐射，并以高气压（50 mbar 量级）气体靶配 Cr/Sc 多层膜（C K 边增强构型）提升水窗段转换效率。

**两套平台能区匹配（M8 方法条目）**：

| 平台 | 用途 | 中心能量 | 脉冲宽度 | 适用能区 | 适用研究内容 |
|------|------|---------|---------|---------|------------|

**软 X 射线平台驱动级选型**：首选 1850 nm OPA/OPCPA（与 Cousin 等[2]同源，次 2 周波驱动、谱覆盖至水窗低段 350 eV、孤立脉冲上限 322 as），备选 1.6 μm BIBO-OPCPA（Ishii 等[12] 2014 年演示水窗 CEP 依赖 HHG，谱截止约 325 eV），备选 2.1 μm OPCPA（Pupeikis 等[28] 2020 年以 2.2 μm（邻近 2.1 μm 设计值）、100 kHz、25 W 平均功率的少周期中红外 OPCPA 驱动氦气高次谐波产生，100 kHz 重频下谱延伸至 0.6 keV 以上、覆盖水窗全段；能量色散方式演示水窗软 X 射线衍射）。截止判据按 $E_{\mathrm{cut}} = I_p + 3.17\,U_p$（与 λ² 成正比）：

| 驱动级 | λ | 5×10¹⁴ W/cm² 截止能量 | 覆盖区间 | 选型定位 |
|--------|---|----------------------|---------|---------|
| 1850 nm OPA/OPCPA（首选） | 1850 nm | ≥ 531 eV | 水窗低段与高段全区间 | 与 Cousin 等[2]同源 |

**水窗孤立阿秒脉冲选通方案**：30 fs 驱动脉冲经空心芯光纤光谱展宽与色散管理压缩至少周期量级后，以幅度门/偏振门在单一半周期内选通孤立阿秒辐射（Ishii 等[12] 已演示少周期红外驱动在水窗能区实现 CEP 依赖 HHG）。执行细节：(1) 空心芯光纤展宽光谱至倍频程以上，啁啾镜对（典型 −40 fs²/bounce）补偿色散，压缩后脉冲 < 5 fs；(2) 幅度门利用 CEP 稳定的少周期脉冲在时域上"切出"半个光学周期内的辐射，隔离孤立阿秒脉冲；CEP 稳定保证逐发次电场波形可复现，是孤立阿秒脉冲产生与阿秒条纹测量的共同前提（[[methods/波形控制]]，arXiv:2409.16392），水窗 19.2 as 孤立脉冲先例将 CEP 漂移由慢反馈压至 88.8 mrad rms，本方案取该值为幅度门 CEP 稳定度设计指标；(3) 偏振门用椭圆偏振旋转门（80% 线偏 + 20% 椭圆偏振合成）作偏振依赖选通，仅圆偏振附近半周期内产生有效 HHG；(4) 选通后的孤立阿秒脉冲经 Cr/Sc 多层膜反射镜（设计工作能区 284–400 eV，与水窗低段匹配；Mo/Si 标称工作能区 13.5 nm ≈ 92 eV、Zr/Si 上限 ~300 eV 均不覆盖水窗低段全段，不采用）滤波后送入条纹光路，设计反射率取 0.3–0.5（与效率链估算一致）；各膜层能点与反射率设计值在光机设计文档中按滤波能点选定后给出。选通孤立性的在位判据采用 CEP 扫描下 HHG 谱的连续-调制切换（CEP-tagged 谱学门控判据，arXiv:1310.7008，出处 [[methods/波形控制]]），与后续条纹重构的直接时域表征互为交叉验证。

**先例 A（Jarecki 等 2024, arXiv:2407.05964）**

实验步骤：高平均功率 MIR OPCPA（10 kHz / 2.1 μm / 27 fs FWHM / CEP 稳定）经 15 m 跨实验室传输送入 He 45 bar 气相相位匹配靶室，以能散式（energy-dispersive）衍射几何同时采集宽能谱 HHG 在倒易空间的大面积切片；首次在 HHG 源上完成水窗时间分辨衍射（500 eV 附近 Mo/Si 超晶格激光致应变动力学示范）。

关键参数：驱动中心波长 2.1 μm / 重频 10 kHz / 脉宽 27 fs（FWHM）；水窗 HHG 谱覆盖 200–600 eV（C K 边 284 eV–O K 边 531 eV 与该谱包络一致）；1/0.1% 带宽光子通量 10⁸–10⁹ 光子/s/mm² 量级（参 Pupeikis 等 Optica 7, 168, 2020 综述级数据，非本实验直接报告）。

验证方式：Mo/Si 超晶格 1 级 Bragg 峰位随时间延迟的位移作为晶格应变动力学直接探针；通过软 X 射线散射模拟提取应变速率。

风险与替代：能散式几何回避单色化造成的光子损失但牺牲动量空间分辨率；需更高角分辨时改用光栅单色器+zone-plate 聚焦；单能峰弱化时备选直接对接 16 通道 TOF 阵列作时间分辨光电子能谱。

**先例 B（Fu 等 2020, Nat. Commun. Phys. 3, 92；综述层 Nishimiya & Takahashi 2025, Adv. Phys. X 2528351）**

实验步骤：TW 级中红外 DC-OPA（dual-chirped optical parametric amplification, 1.55 μm / 45 fs / 80 mJ @ 10 Hz）经 f = 2 m CaF₂ 透镜松聚焦作用于 He 气相靶（约 1 atm），配合"松聚焦+高气压相位匹配"几何把水窗软 X 射线谐波转换效率较先前报道提升 100 倍以上；首次在水窗区演示 nJ 级单脉冲能量并完成 NEXAFS（近边 X 射线吸收精细结构）吸收谱。

关键参数：驱动中心波长 1.55 μm / 脉宽 45 fs / 脉冲能量 80 mJ / 松聚焦 f = 2 m / He 靶压力约 1 atm；水窗软 X 射线单脉冲能量 3.53 ± 0.12 nJ（@ 284–380 eV）；总转换效率 (7.20 ± 0.24) × 10⁻⁸；光子通量 7.12 × 10⁸ s⁻¹（@ 284–380 eV 积分）；水窗强度较先前文献提升 ≥100 倍；束发散角 1/e² 约 3 mrad。

验证方式：NEXAFS 在 C K 边与 L 边取得清晰可辨的精细吸收结构；测量时间从小时级压缩到秒级；与松聚焦协同把单脉冲能量与转换效率同步提升。

风险与替代：TW 级驱动需 1 J 级 Ti:sapphire CPA 泵浦，对泵浦能量与 OPCPA 损伤阈值要求高；若项目预算或空间受限，备选 100 kHz 体制（Pupeikis 等 2020, 2.2 μm）以中等峰值功率 + 高重频换同等平均通量。

**先例 C（Utrio Lanfaloni 等 2025, Nat. Photon. 20, 79–86; 在线发表 2025-11-13, DOI 10.1038/s41566-025-01802-1）**

实验步骤：白光种子 OPA（1800 nm / 38 fs / 2.7 mJ / 1 kHz Ti:sapphire 泵浦）耦合进充气空芯光纤（HCF, 长 2.5 m 量级），通过气体非线性与反常色散平衡实现孤子自压缩（soliton self-compression），无需 post-compression；气压扫描下脉宽由 38 fs 压至 2.5 fs（强度包络 FWHM）。相位稳定由 OPCPA 源 CEP 稳定 + CRIME 原位场分辨测量在阿秒束线完成；驱动光瞬态同时作为 HHG 驱动源与 ATAS 泵浦/探测，光路采用 in-line 几何+干涉式劈裂环形镜精确控制延迟。

关键参数：OPA 中心波长 1800 nm / 入射脉宽 38 fs / 脉冲能量 2.7 mJ；自压缩脉宽 2.5 ± 0.2 fs（强度包络 FWHM, 对应 1800 nm 中心波长下 1/2 光学周期）；自压缩气压 1.1 bar（脉宽约 11 fs, 2 周期）→ 2 bar（脉宽 2.5 fs, 亚周期）；水窗 ATAS 演示 250 eV；CEP 在 ATAS 测量中非主动稳定，由 CEP 扫描 250 个相移值的模拟覆盖。

验证方式：CRIME + TIPTOE 组合做束线内原位场-相位分辨表征，强度包络 FWHM 与波形相位偏移均被反演；ATAS 在 250 eV 处取得清晰水窗吸收谱，作为深度亚周期水窗时间分辨能力的直接证据。

风险与替代：自压缩最终脉宽与气压强相关（2.5 fs 取得窗口约 2 bar ± 小量），对输入脉冲能量/波形稳定性敏感；输入条件偏离时退回到 pre-soliton regime（11.6 fs 量级, HH 强度约降 4 倍）。备选传统两级 HCF + chirped mirror post-compression 链路，代价是相位噪声累积与系统复杂度上升。

**XUV 单脉冲光子通量设计值与计数产额链（C K 边与 N K 边附近，方案 §3.1 软 X 射线平台口径）**：

方案 §3.1 给出两套平台统一判据：水窗 HHG 在 TW 级驱动方案下软 X 射线单脉冲能量达 nJ 级、相对常规方案光子通量提升约 100 倍；与之衔接，本节给出与之等价的计数链核算。

(a) **单脉冲光子通量设计值**：C K 边与 N K 边附近按水窗 HHG 典型转换效率估算为每脉冲 10³–10⁵ 光子（设计估算值，装置建成后以 XUV 光电二极管实测标定），1 kHz 重复频率下对应 10⁶–10⁸ 光子/秒。实测标定流程：XUV 光电二极管（Si 或 GaAs，量子效率已校准）置于多层膜反射镜后焦点处测单脉冲电荷量，对照 NIST 标准光电二极管响应度（典型不确定度 < 5%）做绝对定标。

(b) **单光子计数产额链 N = R_mirror · f_abs · (Ω/4π) · η_det**（设计值口径，按 16 通道角分立 TOF 阵列几何核算）：

| 因子 | 物理含义 | 设计取值 |
|------|----------|----------|
| R_mirror | 多层膜反射镜（Cr/Sc，水窗低段 284–400 eV）反射率 | 0.3–0.5 |
| f_abs | 靶气体吸收分数（高气压 50 mbar 量级） | 0.05–0.2 |
| Ω/4π | 16 通道 TOF 立体角占比（每通道覆盖 22.5°，2π 立体角均匀采样） | 约 4×10⁻⁵ |
| η_det | MCP + 阳极探测器量子效率 | 0.3–0.5 |

按上表全区间组合核算得单光子计数产额 N ≈ **1.8×10⁻⁷–2.0×10⁻⁶**（R_mirror 与 f_abs 取下沿、η_det 取下沿给出下沿 1.8×10⁻⁷；R_mirror 与 η_det 取上沿给出上沿约 2.0×10⁻⁶）。该口径替代先前较宽的 10⁻⁷–10⁻⁵ 估算，作为单能峰 10³ 计数需求的输入。原先 10⁻⁷–10⁻⁵ 表述未对 R_mirror 与 f_abs 取值做分层核算，给出的可操作裕度过宽，与 16 通道立体角实测几何不匹配；本节以四因子取值表替换之。

(c) **积分时间量级**：10³ 计数除以计数产额得单能峰所需入射光子数；按 10³ 光子/脉冲 × 10⁶–10⁸ 光子/秒 × 1.8×10⁻⁷–2.0×10⁻⁶ 产额核算，单能峰累积时间典型端分钟量级、最坏端小时量级（多通道靶材截面较低的能点以延长积分时间补偿）。该量级与原估算一致，未因计数产额口径收紧而改变。

**XUV–IR 条纹场几何构型**：采用非共线构型，IR 条纹场与 XUV 光束在空间上分离约 1 mrad 夹角（两束在靶室出口合束），延迟通过 IR 臂的压电陶瓷（PZT）扫描控制，扫描范围 ±5 fs（对应光程 ±1.5 µm），步长 ≤100 as（≥100 个延迟点），PZT 分辨率 0.1 nm（对应 0.67 as）。延迟稳定性：亚 100 as RMS（通过主动稳定环路的载波包络相位监测器实时反馈校正 PZT 电压）。

**驱动激光 timing jitter**：Timing jitter 是指激光脉冲到达时间相对于参考时钟的起伏，会叠加在条纹迹的延迟轴上。Ti:sapphire 放大器的 timing jitter 通常优于 10 fs RMS（载波包络相位稳定环路），该值远大于阿秒条纹所需的 100 as 级延迟分辨率——因此需要主动延迟稳定环路压制至 100 as RMS 以下。技术方案采用 Huppert 等（Rev Sci Instrum 86, 123106, 2015）的 He-Ne 激光联合白光干涉仪方案，在 XUV 与 IR 空间分离的几何构型中实现 26 as rms 延迟稳定。

**备选方案对比（磁瓶式谱仪排除理由）**：磁瓶式谱仪虽可达更高能量分辨率（典型 ΔE < 0.1 eV @ 100 eV），但以牺牲角分辨为代价（全立体角收集），与本方案"角积分/角分辨联合测量"的刚性需求不兼容——磁瓶式谱仪无法在角向通道间做独立触发与能量-角度联合提取。静电分析器则牺牲立体角换取高能量分辨率（1 eV 量级），适用于精细结构测量的扩展方案，不作为主探测器。

### IR 条纹场共用档位（两套平台统一，方案 §3.1 沿用）

本节是全册 IR 条纹场强、质动力势与 Keldysh 参数的唯一权威表述，M1 参数表、M1 §执行层操作细节、M3 §驱动级截止判据、M3 §失效边界与风险缓解、§关键取值溯源与口径对照各处的 IR 场档位均以本节为准，本节不再在别处重复给出档位数值。标题所称"两套平台统一"指统一采用同一套弱场判据（γ ≥ 100、$U_p < 1$ eV）与同一套有质动力势公式，而非两平台取同一场强数值——两平台的场强上限按各自条纹场波长分别反推，见下段档位表。档位口径与申请书 §1 总体技术路线、§3.1 实验方案一致，取值顺序（γ 区间按低场强端—高场强端升序给出）与 §1 口径表一致。

**物理模型与判据公式**：条纹场对光电子能谱的作用须保持为动量空间的小幅刚性平移，即条纹场矢势幅度远小于光电子中心动量、条纹展宽远小于能谱宽度。该图像成立的弱场条件由 Keldysh 参数给出（[[methods/keldysh]]，该页给出 γ≲1 隧穿极限、γ≈1 隧穿—多光子过渡区的判据来源）：γ 明显大于 1 后隧穿极限图像失效，故本方案取 γ ≥ 100 的弱场判据，使条纹场只作刚性平移而不参与电离。质动力势与 Keldysh 参数按

$$U_p[\mathrm{eV}] = 9.33 \times 10^{-14} \cdot I[\mathrm{W/cm^2}] \cdot \lambda^2[\mu\mathrm{m}^2]$$

$$\gamma = \sqrt{I_p / (2 U_p)}$$

计算，电离能取氩的第一电离能 $I_p = 15.76$ eV（氩为极紫外平台 Ar/Kr 主测靶材与水窗段 2p/2s 芯态通道的共同基准靶材，取氩可覆盖全靶材集的保守上限）。条纹场强度的量纲归一至 eV 时按上式系数折算，$\lambda$ 以 μm 代入；该系数与申请书 §1 总体技术路线、水窗高段谱覆盖核算的截止能量公式 $E_{cut} = I_p + 3.17\,U_p$ 共用同一常数，两处取同一值以保证档位反推与截止判据自洽。

**档位分设与算例**：两套平台的条纹场波长由各自的驱动级决定，故场强上限由弱场判据反推、并非沿用同一数值：

| 平台 | 条纹场波长 | 场强区间 | $U_p$ 区间 | $\gamma$ 区间 | 档位设定依据 |
|------|-----------|---------|-----------|-----------|------------|
| 极紫外平台 | 800 nm | $10^{9}$–$10^{10}$ W/cm² | 6.0×10⁻⁵–6.0×10⁻⁴ eV | 115–363 | 上限取 10¹⁰ 而非更高一档，为弱场条纹近似与中心动量近似同时保留适用余量 |
| 水窗平台 | 1850 nm | $10^{9}$–2×10⁹ W/cm² | 3.2×10⁻⁴–6.4×10⁻⁴ eV | 111–157 | 上限由 γ ≥ 100 判据反推，见下段 |

算例（$I_p = 15.76$ eV、系数 9.33×10⁻¹⁴）：800 nm 端 $10^{9}$ W/cm² 处 $U_p = 5.97\times10^{-5}$ eV、$\gamma = 363$，$10^{10}$ W/cm² 处 $U_p = 5.97\times10^{-4}$ eV、$\gamma = 115$；1850 nm 端 $10^{9}$ W/cm² 处 $U_p = 3.19\times10^{-4}$ eV、$\gamma = 157$，2×10⁹ W/cm² 处 $U_p = 6.39\times10^{-4}$ eV、$\gamma = 111$。两端 $U_p$ 均远小于 1 eV，靶气体无 IR 直接电离本底；档位表的区间端值为按上式复算后取两位有效数字所得，与算例末位差异仅为舍入。

**水窗端上限低于极紫外端的理由**：条纹场波长由驱动级决定，同一场强下 $U_p \propto \lambda^2$，故维持 γ ≥ 100 所许用的场强随 $\lambda^2$ 下降。水窗端 1850 nm 的 $\lambda^2$ 因子为极紫外端 800 nm 的 5.35 倍，反推即得水窗端上限 2×10⁹ W/cm² 低于极紫外端 10¹⁰ W/cm² 的结果。两端档位下的最大条纹能量位移量级相当，能量分辨能力不因波长切换而下降；位移量的取值能点与数值以申请书 §1 总体技术路线段为准。

**验证方式**：(1) 场强标定——以条纹臂末端功率计（分光取样）标定条纹臂功率，结合弱聚焦束腰（3–7 mm）测量得到靶点处实际峰值强度，与上表档位比对，偏差 > 20% 时重新对焦或调整分束比；(2) 弱场条件自洽校验——由标定场强反算 $\gamma$ 与 $U_p$，确认 $\gamma \ge 100$、$U_p < 1$ eV 两项同时成立，并确认条纹可见度随场强单调上升、无 IR 直接电离本底导致的本底抬升；(3) 刚性平移图像校验——在单通道极限靶材（氦气）上，比较加/不加 IR 前的能谱形貌，确认条纹仅使能谱整体平移而不改变展宽与结构，这是条纹场档位未侵入强场区的直接证据；(4) 场强稳定性判据——IR 强度 ±20% 变化引起的条纹相位变化约 10%、单发条纹相位精度约 20%（[[methods/阿秒条纹相机]] 参数表，arXiv:2202.06147），故场强标定不确定度须优于 ±20%，该量级直接约束单延迟点积分时间预算。

**失效模式与替代方案**：

- 失效边界——γ ≈ 1 对应 IR 场直接电离通道开启、违反弱场条纹假设。以氩 $I_p = 15.76$ eV、系数 9.33×10⁻¹⁴ 计，γ ≈ 1 条件为 $U_p = I_p/2 = 7.88$ eV，800 nm 下对应 $I \approx 1.32\times10^{14}$ W/cm²，1850 nm 下对应 $I \approx 2.47\times10^{13}$ W/cm²，分别远离本方案 10¹⁰ 与 2×10⁹ W/cm² 上限约 1.3×10⁴ 倍与 1.2×10⁴ 倍，本档位保有充分安全裕度。
- 失效模式——实测出现 IR 直接电离本底（γ 趋近 1 的本底抬升信号）时，立即下调场强一档、保留 5×10⁸–5×10⁹ W/cm² 作为备用档（$U_p$ 区间 3.0×10⁻⁵–1.6×10⁻³ eV：800 nm 端 3.0×10⁻⁵–3.0×10⁻⁴ eV、1850 nm 端 1.6×10⁻⁴–1.6×10⁻³ eV，两端均远小于 1 eV 阈值；相应 γ 区间 70–514，800 nm 端 5×10⁸ W/cm² 处 γ ≈ 514 为区间上端、1850 nm 端 5×10⁹ W/cm² 处 γ ≈ 70 略低于 100，该端若启用须按 §验证方式 (2) 复核），代价是条纹可见度下降约 3–10 倍、需更长积分时间补偿。
- 替代方案——若 16 通道 TOF 阵列在 10⁹ W/cm² 档位下条纹可见度不足（统计误差 > 2% 残余阈值要求的检测下限），备选方案为切换至偏振门 + 单光子计数的能量-角度联合提取（去掉角积分步骤、改走 M4 第二级按光电子动能的角分辨修正全程路径，绕过角积分压制效率瓶颈），代价是数据采集时间与算法复杂度显著上升。
- 强度相关的反演边界——条纹场作为刚性平移的前提是中心动量近似（CMA）成立；FROG-CRAB 类相位检索在通道混合、啁啾与库仑-激光耦合（CLC）下提取的时延/相位相对真值存在系统性偏差，宽带/快变谱相位下迭代重构病态、仅给带宽平均延迟（[[methods/FROG]] 适用边界，arXiv:2312.14174）。本方案的通道混合由 M2 解析修正项处理、CLC 项不在建模范围内，二者的分工见 M1 §末态能量展开与 M2 §适用边界。

### R1 三步验证流程

对应申请书 §3.1 实验流程三步。测量端为阿秒条纹重构（[[methods/阿秒条纹相机]]）：以 IR 矢势为阿秒时钟，扫描 XUV–IR 延迟、由条纹能移随延迟的变化重构 XUV 时域相位；KB 方法页登记该技术的适用范围已由 XUV 拓展至 K 边/水窗软 X 射线并在 K 边直接测得孤立脉冲宽度（arXiv:2407.05937）。反演算法端为 FROG-CRAB 二维相位检索（[[methods/FROG]]），其适用边界——通道混合、啁啾与库仑-激光耦合（CLC）下提取的时延/相位相对真值存在系统性偏差、宽带快变谱相位下迭代重构病态仅给带宽平均延迟（arXiv:2312.14174）——正是本节第二步失效现象与第三步修正对象的方法学来源。该流程是 M2 修正项的闭环验证，靶材按多通道贡献梯度选取：

研究方案 §3.1 给出三步流程的定量判据：第一步（氦气单通道极限）实测误差 < 5% 作为零阶基准；第二步切换至多通道靶材（甲烷 18%–24%、氮气 16%–26%，均落在 15%–30% 主检验区），传统 FROG-CRAB 误差跳升至 > 20%（此为模拟端预期值，依据为通道间相位干涉项 2√(S₁S₂)·cos(Δφ) 引入相位依赖边带结构、破坏二阶非线性响应基础，与 Cousin 等[2]摘要对水窗多壳层条件下检索保真度的定性警示一致；修正前基准误差以第一步氦靶实测为准，"20%" 不作为文献引用值）；第三步嵌入 M2 解析修正项后重构误差恢复至 < 5%，目标降幅不小于 4 倍。该判据值与本手册 M2 §关键参数表中"误差目标 δφ_RMS/2π×100% < 5%"一致：第三步的"< 5%"即 δφ_RMS/2π×100% < 5%，"降幅不小于 4 倍"取自第二步 > 20% 与第三步 < 5% 之间的比值下界，是同一判据在修正前/后两个数据端点上的读数，不是独立的第二个判据。

Cousin 等[2]对 FROG-CRAB 在水窗多壳层条件下的检索保真度提出定性警示（摘要明确"several shells of target gases are accessed simultaneously"并警示检索保真度须审慎检验），但未给出解析形式的通道间相位干涉项与定量误差水平；"误差超过 20%"数字在其公开文本中未见出处（经 arXiv:1710.02208 全文检索核实），不得作为其观测结果引用。修正前基准误差由本项目第一步氦靶单通道基准实测确定，模拟端预期多通道贡献超过 15% 时误差跳升至 20% 以上，目标降幅不小于 4 倍。本方案在复现其实验条件的场景下检验解析修正项的定量有效性。

**靶材选取与多通道贡献梯度的对应**：氦气（He，Z=2，单一 1s 通道，电离势 24.6 eV）对应单通道极限基准；氖气（Ne，Z=10，2s 电离阈 48.5 eV，水窗段 2s/2p 双壳层开放）对应线性响应区验证点（多通道贡献约 8%–15%，指极紫外段档位）；甲烷（CH₄，C 1s 电离阈 290.7 eV，覆盖 C K 边以上约 291–410 eV，设计估值 18%–24%）、氮气（N₂，N K 边 409.7 eV 附近，设计估值 16%–26%）覆盖水窗典型 K 边能区，对应多通道贡献 15%–30% 主检验区。该对应关系与研究内容 §2.2 的口径一致；两靶设计估值的来源与交叉标定路径见研究内容一，分档归属与逐靶数值的权威表述见本节下方 M3 §靶材配置表（该表以"多通道主测靶材"行给出 15%–30%（设计估值 18%–24%／16%–26%）的逐靶数值），本节不重复该表的档位定义。

**触发时序逻辑**：16 通道 TOF 的共同触发信号来自 Ti:sapphire 激光器的同步输出（1 kHz TTL，上升沿 < 5 ns）。触发信号经延迟单元（分辨率 1 ns，可调范围 0–1 ms）分配至各通道的时域分析窗口，确保所有通道在相同激光脉冲事件下同步积分。触发路径：激光器 TTL → 触发分配器 → 16 通道独立延迟单元 → 各 TOF 通道门控信号。各通道的延迟偏移在实验前做系统校准，以消除电子学通道间触发时间差（< 100 ps）。

**通道-角度映射**：16 通道沿环形阵列等角距排列，每通道对应 $\theta_i = i \times 22.5°$（$i = 0\ldots15$），以 XUV 传播方向为法线，取第一通道指向右侧水平方向为 $\theta_0 = 0°$。角度标定在实验前使用准直电子源（微型电子枪，发射极细电子束）完成，通过旋转电子源方位角记录各通道响应峰位，确认通道-角度映射关系，偏差 < ±1°。

**靶材本底与多通道原子响应（Kr/Xe 芯态段的失效模式与替代）**：氪 3d 内壳层电离的价轨道光电子与内壳层光电子在 30–100 eV 电子能量区间重叠，30–60 eV 能区 Auger 电子产额与 3d 光电子相当并落在脉冲检索窗口内，若不作为独立通道纳入原子响应模型，将直接污染水窗高段的相位检索结果（[[papers/2025-2510_17949-comment-on-brilliant-source-of-192-attosecond-soft-x-ray-pul]]）。据此，水窗高段靶材的判据增列两条：(1) 低能谐波（< 150 eV）贡献须以金属滤片/多层膜截断并在同一实验批次内测量滤片透过谱，使价轨道电离与内壳层电离在能谱上可分离；(2) Auger 电子须按独立通道并入总产额与能量分布模型，并以 TOF 能量刻度的 Auger 峰作内标（不作为背景扣除）。上述两条为水窗高段靶材启用条件，不改变本表极紫外与水窗低段的档位取值；氖气、氩气在本项目所涉能区无 K 边芯态通道与 Auger 重叠问题。

**多壳层同时电离对本表档位取值的约束**：氖、氩、氙等多壳层靶材中，条纹图样为多壳层同时电离信号的叠加，壳层间条纹延迟差异与光电子—剩余离子纠缠会系统性影响单通道相位提取的精度与解释（[[methods/阿秒条纹相机]]、[[papers/2024-2409_03622-photoelectronresidual-ion-entanglement-in-streaked-shake-up]]）。氖 2s–2p 轨道相对条纹光电发射时间延迟实测为 21±5 as（该 KB 方法页登记值），故氖气的"线性响应区验证点"定位针对的是通道间相位关系而非绝对条纹时标；该延迟量级小于本项目条纹场相位分辨目标，不改变本表档位取值，但作为 M2 通道间相位差 Δφ 的初值约束纳入模拟端基准数据库。

**验证方式**：本表每档靶材的档位归属以"模拟端截面核算 + 实验端条纹迹拟合"双路验证。(1) 模拟端：以 TDSE 双通道模型在对应靶材（He/Ne/Ar/Kr/N₂/CH₄）上计算通道产额比，给出各档设计估值与通道占比随入射能量的演化曲线，模拟端基准数据库随 R1 定版；(2) 实验端：在各靶材上采集条纹迹，以多高斯峰面积比提取通道占比，与本表档位区间比对，偏差超出档位边界时以实测值更新档位并回写本表与 M1/M6 三处；(3) 通道开放性验证：以"加/不加 IR 条纹场"的能谱对比确认目标壳层在给定光子能量下确有光电子产出，避免仅凭阈值数值判定通道存在（He 靶单通道基准即承担该验证）；(4) 能量刻度自检：以 Auger 峰与已知壳层阈位置对 TOF 能量轴标定，确认水窗段 2p 通道开启能点与其阈值的对应关系。

**失效模式与替代方案**：(1) 氖气水窗段 5%–8% 过渡带档位若第一阶段实测标定结果落在 5% 以下，则并入 He 单通道极限档处理（≤5%），该档位作为修正项趋零的等价性校验点而非主检验点，替代方案是改以甲烷/氮气承担该档位功能；(2) 若标定结果高于 8%，则该靶材升入线性响应档 8%–15%，此时须同步修改 M6 四档表中氖气的能区归属与 M1 η 映射段的标定区间，替代方案是保持靶材不变而按实测值重新标定 η–R_ch 映射；(3) 氩 2p 双阈（248.4/250.78 eV）间 2.38 eV 分裂若在实测中被分辨为两个可分离通道，则本项目由"双通道"升级为"三通道"处理，备选路径按 M5 CNN 抗噪相位检索方案扩展；(4) 氪/氙芯态段的 Auger 重叠按上述两条启用条件处理，条件不满足时该能区仅作失效边界验证、不进入主检验区。

### 实验步骤

**步骤 1：通道效率标定**

在均匀光电子源（微通道板平场源，注：或用低密度氦气靶的单色光电子）下，测量各通道对同一能量的响应，获取相对效率因子 $k_i$（$i=1\ldots16$）。标定重复 3 次取平均，统计误差 < 0.5%。标定在每次实验前后各执行一次，确认无显著漂移（< 1%）。

**通道效率标定的操作细节**：标定时使用低密度氦气靶（气压 ~0.1 mbar），XUV 脉冲单独电离（不加 IR 条纹场），确保光电子来自单色过程。各通道的 TOF 谱中同一能量峰位的计数比值即为 $k_i$。若某通道的 $k_i$ 与平均值偏差 > 5%，该通道触发硬件检查（检查高压馈通、TOF 入口狭缝对准）。

**步骤 2：数据采集**

在设定靶材下采集条纹迹。各通道独立记录能量谱 $S_i(E,\tau)$，延迟 $\tau$ 扫描范围 ±2–5 fs，步长 ≤100 as。每组实验至少采集 5 次重复，以评估统计误差。

**数据采集的触发时序**：16 通道 TOF 的共同触发信号来自 Ti:sapphire 激光器的同步输出（1 kHz TTL）。触发信号经延迟单元（分辨率 1 ns，可调范围 0–1 ms）分配至各通道的时域分析窗口，确保所有通道在相同激光脉冲事件下同步积分。

**步骤 3：效率修正**

对每通道数据乘以修正因子 $1/k_i$，消除通道间灵敏度差异：

$$S_i^{\mathrm{corr}}(E,\tau) = S_i(E,\tau)/k_i$$

**步骤 4：角向求和（等效角积分）**

修正后各通道能谱做角向求和：

$$S_{\mathrm{int}}(E,\tau) = \sum_{i=1}^{16} S_i^{\mathrm{corr}}(E,\tau)$$

角积分过程中同时保留各通道的独立数据，以供 M4 第二级（按光电子动能分辨）使用。

**步骤 5：角分辨数据导出**

从 16 通道 TOF 数据中提取 $(E,\theta)$ 二维动能-角度分布，其中 $\theta$ 为光电子发射角（每个通道对应 $\theta_i = i\times22.5°$）。用于第二级解耦。

### 验证方式

**均匀性验证**：以单通道极限靶材（氦气，单一 1s 通道）为检验源，确认角积分谱的信噪比优于单通道谱 3 倍以上。

**偶极相位压制效率验证（与方案 K2 一致）**：在氩气靶上对比角积分前后偶极相位贡献的占比，确认角积分对偶极相位的压制效率达到设计阈值水平（< 2% 残余贡献）。该阈值与方案 §3.2 R2 二级触发逻辑、K2 关键科学问题中的"第一级角积分残余偶极相位贡献须小于 2%（设计阈值，待 R2 实测标定）"口径一致：残余 > 2% 即启用第二级按光电子动能的角分辨修正（详见 M4 §偶极相位二级解耦重构算法），残余 ≤ 2% 视为第一级角积分独立提取脉冲包络能力合格、脉冲包络信息可被独立提取。该阈值是本项目设定口径，物理依据为角积分量子力学对称性压制效率的量级估计（典型气相靶材偶极相位残余范围 0.5%–3%，无单点普适文献值），其是否成立由 R2 实验实测标定。

**通道响应一致性验证**：以双通道靶材（氮气）重复采集 5 次，确认各通道效率因子 $k_i$ 的长期稳定性（漂移 < 1%）。

**延迟稳定性验证**：以相同脉冲条件下的两次独立测量比对，确认延迟模块的 < 100 as RMS 稳定度要求被满足。

### 失效边界与风险缓解

**失效边界**：探测器各通道灵敏度差异若 > 5%，角积分结果的准确性将受严重影响。IR 条纹场档位的失效边界（γ ≈ 1 对应的阈值场强、失效模式与替代方案）见 §IR 条纹场共用档位（两套平台统一，方案 §3.1 沿用）。

**风险缓解**：每次实验前后均进行效率标定；数据处理中对通道响应做归一化修正，并估算修正引入的系统误差（< 1%）。若标定发现通道漂移 > 5%，该通道数据在后续处理中被剔除。IR 条纹场端的风险缓解（场强档位的弱场近似余量、IR 直接电离本底出现时的下调处置与备用档）见 §IR 条纹场共用档位（两套平台统一，方案 §3.1 沿用）。

**IR 条纹场档位的替代方案**：条纹可见度不足时的偏振门 + 单光子计数能量-角度联合提取路径及其代价，见 §IR 条纹场共用档位（两套平台统一，方案 §3.1 沿用）的失效模式与替代方案条。

**部分通道异常的稳健性依据**：Meier 等的机器学习重构研究表明，16 通道 TOF 构型中个别探测通道失效与高噪声可由通道间冗余信息补偿——即使 2–3 个通道失效或噪声显著偏离，剩余通道仍可重构角向分布。该先例支撑了本方案在部分通道异常时的数据稳健性：剔除通道数 ≤ 3 时（占总通道 18.75%），角积分重构结果的不确定度增量 < 5%，不影响 R2 的 2% 偶极相位压制判据。

## M4：偶极相位二级解耦重构算法

### 物理背景

角积分过程对不同磁量子数 $m$ 的偶极矩阵元做平均，使与角动量相关的偶极相位贡献被天然压制（Pabst 与 Dahlström[3]的量子拍方案论证了该压制原理）。压制到何种程度依赖靶材与能区条件，无普适文献值；2% 为本方案设计阈值（待 R2 实测标定）。条纹重构端（[[methods/阿秒条纹相机]]）的 KB 适用边界提供独立佐证：多通道情形下光电子与剩余离子的纠缠、通道间条纹延迟差异会系统性影响单通道相位提取的精度与解释（arXiv:2409.03622），第二级角分辨修正所分离的正是这类靶材依赖的系统性分量。

物理论证与适用条件说明：对常规 s 初态的单通道电离，连续态 Wigner 相移与 $m$ 无关，$m$ 求和不会使其相消；角积分压制的是不同分波（如 p→s 与 p→d 连续通道）间的相位差贡献，其量级由 Ar/Kr 的分波偶极相位差决定。R1 模拟端将给出 Ar 3p 与 Kr 4p 光电离的 s/d 分波相移差量级估计，作为 2% 设计阈值的物理支撑；若估计值显著偏离 2%，按 M4 失效边界启用备选路径 B。

本方法利用这一压制效应，建立二级解耦策略：

- **第一级**：角积分提取脉冲包络，假设偶极相位已被压制至可忽略水平
- **第二级**：按光电子动能分辨，分离脉冲固有啁啾与残余偶极相位

### 算法步骤

**第一级（角积分提取脉冲包络）**

1. 将角积分能谱 $S_{\mathrm{int}}(E,\tau)$ 代入 FROG-CRAB 代价函数，检索脉冲包络 $I(t)$ 与光谱相位 $\Phi_{\mathrm{pulse}}(\omega)$：

$$\chi^2_1 = \sum_{i,j}\left|S_{\mathrm{int}}(E_i,\tau_j) - S_{\mathrm{model}}(E_i,\tau_j; I,\Phi_{\mathrm{pulse}})\right|^2$$

2. 以 $\chi^2_1$ 最小化为目标，采用主成分分析法（PCG）或共轭梯度法（CG），得到脉冲固有啁啾信息。

3. 评估偶极相位残余贡献：$\eta_{\mathrm{dip}} = |\Phi_{\mathrm{dip}}|/|\Phi_{\mathrm{total}}|$。若 $\eta_{\mathrm{dip}} < 2\%$ 则第一级成功，可进入第二级。若 $\eta_{\mathrm{dip}} \geq 5\%$ 则触发备选路径 B（CNN 端到端检索）。

**第一级的操作细节**：步骤 1 中代价函数使用 L-curve 法确定正则化参数 $\lambda_1$，扫描范围 $\lambda_1 \in [10^{-4}, 10^{0}]$。PCG 迭代的初始猜测取为平坦相位（$\Phi(\omega) = 0$），以避免陷入局部极小。

步骤 3 中 $\eta_{\mathrm{dip}}$ 的频域计算步骤如下：

1. 从重构结果中提取总光谱相位 $\Phi_{\mathrm{total}}(\omega)$，计算瞬时频率调谐 $\partial\Phi_{\mathrm{total}}/\partial\omega$。

2. 对 $\partial\Phi_{\mathrm{total}}/\partial\omega$ 做低通滤波分离慢变与快变分量。滤波器采用 8 阶巴特沃斯低通，**截止频率 5 THz** 的选取依据：阿秒脉冲固有啁啾的典型频率调谐在 0.1–3 THz 区间（对应 100–300 as 脉冲宽度的二阶相位展开），偶极相位残余的特征快变分量集中在 5–15 THz，与原子里德堡序列高 n 相邻能级间隔量级一致——如 Ar 3p⁵nd（n≳12）相邻能级间隔约 20 meV ≈ 5 THz（Ar 3p→4s 本征激发能约 11.6 eV ≈ 2.8 PHz，不在此列，原"3p→4s 间隔约 20 meV"表述有误，已修正）；截止频率的最终依据为分波偶极相移的特征能量尺度，由 R1 模拟端的分波相移差估计定量标定。

3. 低通滤波后的慢变分量对应脉冲固有啁啾 $\Phi_{\mathrm{pulse}}$，快变分量为偶极相位残余 $\Phi_{\mathrm{dip}}$。计算 $\eta_{\mathrm{dip}} = \|\Phi_{\mathrm{dip}}\|_{\mathrm{RMS}} / \|\Phi_{\mathrm{total}}\|_{\mathrm{RMS}}$。

若 $\eta_{\mathrm{dip}} < 2\%$ 则第一级成功，可进入第二级。$\eta_{\mathrm{dip}}$ 落入 2%–5% 区间时以加权正则化修正为主路径（详见 M4 §失效边界、风险缓解与触发验证 第二档处置，主路径失败后启用 CNN 兜底）；$\eta_{\mathrm{dip}} \geq 5\%$ 时直接升级切换至备选路径 B（CNN 端到端检索）。

### 偶极相位压制效率的物理估算

Pabst 和 Dahlström[3]在量子拍实验中验证了角积分对偶极相位的压制效应，本方案的推广对象是常规靶材（Ar、Kr）而非特定波包制备条件。角积分过程对不同磁量子数 $m$ 的偶极矩阵元做平均，使与角动量相关的偶极相位贡献被压制。

压制阈值的物理依据：角积分后偶极相位残余以相位加权求和的形式估算，其中各磁量子数分量的强度权重与其偶极相位乘积的求和使主导相位贡献相消。残余量级由靶材的非对称散射振幅决定，落入典型气相靶材偶极相位残余范围 0.5%–3%（无单点普适文献值）。本方案以 2% 为设计阈值（作为二级修正的触发判据），其是否成立由 R2 实验实测标定。实测达到该阈值后，脉冲包络信息方可被独立提取。

**角积分残余偶极相位的加权求和公式**：对各磁量子数分量 $m$（对单 s 初态电离，$m = -1, 0, +1$ 三个通道分别对应 $\sigma^-$、$\pi$、$\sigma^+$ 光子偏振），连续态电子的偶极相位 $\phi_m(E)$ 在角积分后被压制为：

$$\eta_{\mathrm{dip}}(E) = \frac{\left|\sum_{m} w_m(E) \cdot e^{i\phi_m(E)}\right|}{\sum_{m} w_m(E)}$$

其中 $w_m(E) = |d_m(E)|^2$ 为各磁量子数分量的偶极矩阵元模方（光电离强度权重）。当 $\phi_m$ 在 $m$ 求和范围内近似均匀分布（各分量相位差 $\Delta\phi_m \sim \pi$ 量级）时，分子复矢量和的模远小于分母标量和，残余比例 $\eta_{\mathrm{dip}}$ 自然下降到 0.5%–3% 区间。该公式中"主导相位贡献相消"的物理含义即上式中复矢量的对称分布使总长度压制。

**2% 设计阈值的物理依据**：对 Ar 3p 与 Kr 4p 光电离，分波偶极相位差（s/d 分波 Wigner 相移差 $\delta_\ell^{\mathrm{Wigner}}(E)$ 随光电子动能 $E$ 的演化）在 50–500 eV 动能区间典型量级 0.05–0.3 rad。当 $\delta_\ell^{\mathrm{Wigner}}(E) < 0.1$ rad 时，$\eta_{\mathrm{dip}}$ 量级 1%–2%；当 $\delta_\ell^{\mathrm{Wigner}}(E) > 0.2$ rad 时，$\eta_{\mathrm{dip}}$ 上升至 3%–5%。2% 设计阈值对应 $\delta_\ell^{\mathrm{Wigner}}(E) \approx 0.1$–$0.15$ rad 的相移差范围，对应 Ar/Kr 在 100–300 eV 动能区间的典型值。该阈值由 R1 模拟端的分波偶极相位差量级估计给出、待 R2 实测标定。

### 二级解耦 100–140 eV 触发阈值（双端落定）

第一级角积分独立提取脉冲包络的能力受光电子动能主导。光电子动能跨越触发线后偶极相位-动能依赖增大，第一级角积分的独立提取能力随之失效，须叠加第二级修正。触发线按驱动端双端落定：800 nm 极紫外端取 100 eV 设计值，1850 nm 水窗端上移至 140 eV 量级。本阈值与下节"残余分档处置表"为 R2 偶极相位解耦模块的两条独立判据：100–140 eV 为动能触发线（基于分波相移-动能尺度的物理依据），残余分档为触发后处置路径（基于角积分压制效率的实测残余水平）。

**100 eV 阈值的依据**：该阈值为本方案设计值（无直接文献依据），由 R1 模拟端的分波偶极相位差量级估计给出，精确阈值待 R2 实测标定（原挂靠 Hutcheson 等的"偶极相移随动能演化关系"经核实为延迟域 ATAS 研究、无动能依赖表述，该依据已删除）。

**100 eV 的物理依据（IR 半周期累积偶极相移 ≈ 1 rad 的典型动能上限）**：偶极相位斜率取 Ar 3s3p 价壳层典型值约 0.005 rad/eV，$0.005\ \mathrm{rad/eV} \times 200\ \mathrm{eV} \approx 1\ \mathrm{rad}$ 的累积相位偏离对应动能上限约 200 eV；计入 800 nm 与 1850 nm 两端的偶极相位斜率差异，阈值在 100–140 eV 区间内落定——800 nm 极紫外端取 100 eV 设计值，1850 nm 水窗端上移至 140 eV 量级，区间内取值由模拟端标定。在中心动量近似下，光电子末态在 IR 半周期内的相位累积量可由分波偶极相移 $\delta_\ell^{\mathrm{Wigner}}(E)$ 随动能 $E$ 的导数量级给出。对 Ar 3p、Kr 4p 等典型气相靶材，在 50–500 eV 动能区间的 s/d 分波相移差 $\delta_\ell^{\mathrm{Wigner}}(E)$ 量级 0.05–0.3 rad（详见 M4 §偶极相位压制效率的物理估算）；当动能跨越约 100 eV 时，分波相移差进入 0.1–0.3 rad 的非线性增长区，对应 IR 半周期（800 nm 驱动 T/2 ≈ 1.33 fs）内光电子累积偶极相移约 1 rad 的动能尺度。该尺度基准由 R1 模拟端的分波相移-动能依赖估计给出初值，由 R2 实验实测在第二年完成复核——若实测拐点偏移至 70 eV 以下，水窗能区的验证能区上移至 380 eV（对应 Ar 2s 通道区），靶材-能区组合同步调整（降级路径与可行性论证见 scheme §4.1 末尾设计值降级路径汇总）。该物理图为 R1 模拟端的分波相移估计与 R2 实测共同验证的尺度基准，不作为单一文献引用的结论。

**R2 验证能区据此明确为两段**：

| 能区 | 靶材与条件 | 二级修正需求 |
|------|----------|------------|
| 极紫外端（800 nm 驱动，阈值 100 eV） | Ar 光电子动能 < 100 eV | 第一级独立提取足够，无需第二级 |
| 水窗能区（1850 nm 驱动，阈值 140 eV） | Ar、Kr 光电子动能 ~270–395 eV | 全程处于二级修正区，需两级串联 |

**与 R1 失效边界的时间序对比**：N₂ 分子电离势约 15.58 eV，100 eV 动能对应约 115.6 eV 光子能量（仍处于极紫外能区）。该换算表明 R2 二级修正的触发远早于 R1 的失效边界（N K 边 409.7 eV），与研究内容 K2 的口径一致。

**触发逻辑**：若第一级角积分残余 > 2%，触发 R2 第二级按光电子动能的角分辨修正。Zhu 等[8]的 CNN 网络以含偶极相位残差的条纹迹作为训练集的一部分，将高偶极相位残余的条纹迹作为噪声模型的一个分量，通过端到端学习方式恢复脉冲相位信息（备选方案触发条件与详细路径见 M5）。

**第二级（按光电子动能分辨修正偶极相位）**

4. 以第一级得到的 $\Phi_{\mathrm{pulse}}(\omega)$ 为已知量，从角分辨数据中提取偶极相位：

$$\Phi_{\mathrm{dip}}(E,\theta) = \arg\left[\tilde{S}(E,\theta)\right] - \Phi_{\mathrm{pulse}}(\omega_E)$$

其中 $\theta$ 为光电子发射角，$\omega_E$ 为光电子动能 $E$ 对应的光学频率。

5. 构建二维动能-角度相位图 $(E,\theta)$，分离脉冲固有啁啾（与 $E$ 强相关，与 $\theta$ 弱相关）与靶材偶极相位（与 $\theta$ 强相关，与 $E$ 弱相关）的空间分布特征。

6. 跨靶材（Ar、Kr）比对二级解耦结果的可比性误差 $\delta_{\mathrm{cross}}$：

$$\delta_{\mathrm{cross}} = \frac{\left\|\Phi_{\mathrm{pulse}}^{(\mathrm{Ar})} - \Phi_{\mathrm{pulse}}^{(\mathrm{Kr})}\right\|}{\left\|\Phi_{\mathrm{pulse}}\right\|}$$

目标：$\delta_{\mathrm{cross}} < 5\%$（以相位范数归一，与申请书 content §2.3/G2 度量口径一致）。

### 关键参数表

| 参数 | 取值 | 说明 |
|------|------|------|
| 第一级正则化参数 $\lambda_1$ | $10^{-4}$–$10^{0}$（L-curve 法于扫描区间内定值） | 控制偶极相位惩罚强度 |
| 迭代收敛阈值 | $\Delta\chi^2 < 10^{-4}$ | 第一级重构终止判据 |
| 偶极相位压制目标 | < 2%（第一级残余贡献） | 本方案设计阈值（无普适文献值，待 R2 实测） |
| 跨靶材可比性误差目标 | < 5% | 第二级终止判据 |
| 角向求和权重 | $w_i = 1/k_i$（通道效率修正因子） | 数据处理参数 |
| $\eta_{\mathrm{dip}}$ 触发阈值 | < 2%（正常），> 5%（触发备选） | 第一级判据 |
| 动能-角度相位图网格 | 16×能量 bins（每通道一个 $\theta$） | $(E,\theta)$ 分辨率 |

### 验证方式

**分解自洽性验证**：以第二级提取的 $\Phi_{\mathrm{dip}}$ 叠加第一级重构的 $\Phi_{\mathrm{pulse}}$，重新计算条纹迹，与原始测量数据比对，相关性应 > 0.95。

**跨靶材一致性验证**：在氩气与氪气靶上分别执行完整二级流程，确认 $\Phi_{\mathrm{pulse}}$ 提取结果一致（误差 < 5%），而 $\Phi_{\mathrm{dip}}$ 反映各自靶材特征。

**氦气对照组验证**：在无偶极相位复杂结构的氦气靶（Z=2）上执行流程，确认第二级提取的 $\Phi_{\mathrm{dip}}$ 接近零，验证方案的固有上限标定。

**重构误差独立验证**：以标准 FROG-CRAB 对单通道氦气数据重构为基准，比较 M4 与标准方法的 $\delta\phi_{\mathrm{RMS}}$，差异应 < 1%。

### 失效边界、风险缓解与触发验证（含备选路径 B 入口）

本节是 R2 失效边界处置与备选路径 B 触发的统一入口，承担 M4 §失效边界、M5 原触发条件与验证段、备选路径 B 行三处语义的合并表述。下方三档处置给出分阶段判定与对应执行路径；备选路径 B 的 CNN 验证方式、网络选型依据与 sim-to-real 风险缓解同节列出，避免在 M5 重复触发条件。

**失效边界**：第一级角积分无法将偶极相位压制至 < 5% 时，二级解耦策略整体失效。该判据与 R1 模拟端通道混合度 η 的标定（详见 M1 §通道混合度与多通道贡献的映射）相互独立——偶极相位残余由分波相移差决定，多通道贡献由通道强度比决定，两类残余在 Ar/Kr 等芯态靶材上同时出现但来源不同。

**触发条件分三档处置**（与研究方案 §6 备选路径 B 的残余分档表完全对齐，三档独立于本节 100 eV 动能触发阈值；100 eV 为进入第二级的动能触发线，本表为第二级内部按残余水平的处置路径）：

1. **< 2%**：第一级直通，无需第二级修正。
2. **2%–5%**：以加权正则化修正为主路径——在第二级修正的代价函数中提高偶极相位约束项权重 $\lambda_2$（相对第一级 $\lambda_1$ 提至 5–10 倍量级），以补偿压制效率下降；该档可继续沿用 M4 二级解耦架构。主路径失败后（实测 $\delta_{\mathrm{cross}}$ 仍 $\geq 5\%$ 或重构相位 RMS 偏差恶化）启用 CNN 作为兜底路径。
3. **≥ 5%**：直接升级切换至备选路径 B（CNN 端到端相位检索，详见 M5 §架构 与 M5 §训练数据生成），绕过加权正则化主路径。

**备选路径 B 触发后的验证方式**：在相同实验数据上对比 CNN 与 M4 的重构结果，确认 CNN 的 $\delta\phi_{\mathrm{RMS}}$ 不劣于 M4（允许 10% 的性能差距，以换取方法稳健性）。Meier 等的机器学习先例支撑 16 通道冗余稳健性；微调后验证集损失下降 > 30% 即为降级运行通过判据，与 M5 §局限性 微调有效性判据一致。

**网络选型依据**：Zhu 等[8]（Chin. Phys. B 35, 054204, 2026）以自相关图作为卷积网络输入，规避条纹迹在低计数下的泊松噪声敏感性。该工作为 M5 当前 U-Net（属 CNN 家族）选型提供直接参照——条纹迹-相位映射的端到端回归任务以卷积骨干为主，U-Net 的编码器-解码器共享该骨干。在 M5 训练数据生成阶段，可将 [8] 的自相关注噪预处理口径作为网络输入敏感性分析的输入；该敏感性切换不改变 M5 的整体方法链，仅调整 U-Net 编码器-解码器中的通道数与跳跃连接数量。

**sim-to-real 风险缓解**：仿真训练数据中的噪声模型可能不完全匹配实际实验条件。风险缓解采用物理启发的损失函数（加入先验约束，如脉冲相位平滑性、光谱支持约束），减少对仿真数据分布的依赖；在真实数据上做微调（fine-tuning），逐步缩小领域差距。微调后验证集损失下降 > 30% 即为微调有效。

## M5：CNN 抗噪相位检索备选方案

### 架构

M5 以端到端卷积回归替代 FROG-CRAB（[[methods/FROG]]）的广义投影迭代反演：后者在条纹迹采样不足或低信噪比时存在相位恢复多解与收敛风险（KB FROG 方法页适用边界），端到端学习的噪声鲁棒性由训练集注噪分布直接覆盖。网络采用 U-Net 型编码器-解码器结构（参照 Zhu 等[8]，Chin. Phys. B 35, 054204, 2026）。编码器部分采用 4 级下采样（每级 2 卷积层 + MaxPool），提取条纹迹的多尺度特征；解码器部分对应 4 级上采样，输出脉冲光谱相位 $\Phi(\omega)$ 的 2D 分布图（与输入条纹迹分辨率相同）。

**U-Net 架构参数**：

| 层 | 卷积核 | 通道数 | 输出尺寸 |
|----|--------|--------|---------|
| 输入 | — | 1 | H×W（条纹迹） |
| Enc1 | 3×3, ReLU | 64 | H/2 × W/2 |
| Enc2 | 3×3, ReLU | 128 | H/4 × W/4 |
| Enc3 | 3×3, ReLU | 256 | H/8 × W/8 |
| Enc4 | 3×3, ReLU | 512 | H/16 × W/16 |
| Bottleneck | 3×3, ReLU | 1024 | H/16 × W/16 |
| Dec4 | 3×3, ReLU + 上采样 | 512 | H/8 × W/8 |
| Dec3 | 3×3, ReLU + 上采样 | 256 | H/4 × W/4 |
| Dec2 | 3×3, ReLU + 上采样 | 128 | H/2 × W/2 |
| Dec1 | 3×3, ReLU + 上采样 | 64 | H × W |
| 输出 | 1×1 卷积 | 1 | H×W（相位图） |

跳跃连接将 Enc2/3/4 的特征图与对应 Dec 层拼接，以保留高分辨率细节。输入为单通道条纹迹图像 $S(E,\tau)$，输出为对应的脉冲光谱相位图 $\Phi(\omega)$。

### 训练数据生成

从 TDSE 模拟产生大量成对数据 $(\mathbf{S}_{\mathrm{noise}},\mathbf{S}_{\mathrm{clean}})$，其中 $\mathbf{S}_{\mathrm{noise}}$ 注入泊松噪声（模拟实际计数统计噪声），信噪比范围 10–40 dB。

**信噪比注噪的具体操作**：对干净条纹迹 $\mathbf{S}_{\mathrm{clean}}$，按以下方式注入泊松噪声：

$$\mathbf{S}_{\mathrm{noise}} = \frac{1}{N_{\mathrm{ph}}} \mathrm{Poisson}(N_{\mathrm{ph}} \cdot \mathbf{S}_{\mathrm{clean}})$$

其中 $N_{\mathrm{ph}}$ 为归一化因子，控制平均光子计数（$N_{\mathrm{ph}} = 10$–$10^4$ 对应 SNR ≈ 10–40 dB，换算式 SNR(dB) = 10·log₁₀N；原"5–30 dB"换算有误，N=10 对应 10 dB、N=10⁴ 对应 40 dB，已废弃）。Poisson 采样对每个像素独立执行。

训练损失函数：

$$\mathcal{L} = \frac{1}{N}\sum_{k=1}^{N}\left|\Phi_{\mathrm{retrieved}}(\omega_k) - \Phi_{\mathrm{true}}(\omega_k)\right|^2 + \beta\cdot\mathrm{TV}(\Phi_{\mathrm{retrieved}})$$

其中 $\beta$ 为全变差正则化系数，典型值 **0.01**。$\beta$ 的选取通过验证集扫描确定：扫描范围 $\beta \in [0.001, 0.1]$，以验证集相位误差最小且 TV 项不过压制相位细节为双目标，取帕累托最优解。TV 项定义：

$$\mathrm{TV}(\Phi) = \sum_k |\Phi(\omega_{k+1}) - \Phi(\omega_k)|$$

**推理硬件要求**：推理速度 < 50 ms/pulse，需 NVIDIA A100 或同级 GPU（约 20 TFLOPS FP32 或 312 TFLOPS FP16 TensorCore），显存 ≥ 20 GB（模型参数约 $2\times10^6$，中间激活图约 8 GB）。若仅做相位检索（不训练），可在消费级 GPU（NVIDIA RTX 3090/4090，24 GB 显存）上运行，推理速度约 100–200 ms/pulse，仍可满足离线批处理需求。

**端到端微调策略**：实验数据微调（FROG-CRAB 已提取真实脉冲相位作为监督信号）使用 20–50 个实验条纹迹，每条含 5 次重复平均。微调时冻结编码器参数，仅微调解码器（12 层，约 $2\times10^6$ 参数），使用 AdamW 优化器，学习率 $10^{-5}$（预训练学习率的 1/10），余弦退火至 $10^{-6}$，训练 50 个 epoch。微调有效性判据：验证集损失下降 > 30%。

### 触发条件与验证

**触发条件与三档处置**：角积分方案在特定靶材上压制效率低于预期（偶极相位残余贡献 > 5%）即升级至本备选方案。三档处置全貌（< 2% 第一级直通 / 2%–5% 加权正则化 / ≥ 5% 切换 CNN）、sim-to-real 风险缓解详见 M4 §失效边界、风险缓解与触发验证，本节不再重复。

### 局限性

**sim-to-real 差距**：仿真训练数据中的噪声模型可能不完全匹配实际实验条件。物理启发的损失函数与真实数据微调见 M4 §失效边界、风险缓解与触发验证 的 sim-to-real 风险缓解段。

## 备选路径 A/B/C 总览

研究方案 §3.1/§3.2/§3.3 三处分别触发备选路径 A/B/C，本节集中索引触发条件、对应方法、失效后的执行流程，作为各方法条目内"失效边界与风险缓解"段的合并索引。详细触发条件与具体降级路径分散在各方法条目（M2、M4、M6），本节不重复，仅做总览。**备选路径 C 的触发条件以本节表述为唯一权威口径**。该行按研究方案 §6 的三条件合取写法给出；M6 §失效边界与风险缓解段中出现的一组离散阈值描述（光子能量 409.7 eV 与通道重叠度 50% 单列）按本节的合取逻辑读取。二者指向同一组条件，不构成两套判据。

| 路径 | 触发条件 | 触发来源 | 对应方法 | 失效后的执行流程 | 与主路径的关系 |
|------|---------|---------|---------|----------------|---------------|
| **备选路径 A** | 通道混合度 $\eta$ > 30% 或通道重叠宽度 < 0.5 eV 或通道间能量差 < 0.5 eV | R1（研究方案 §3.1）：模拟端通道混合度先于失效边界触发 | M5（CNN）作为降级工具；M1 三阶段模拟执行计划作为底层支撑 | 切换至神经网络学习通道干涉模式：以 TDSE 双通道扫描点为训练集（含通道混合度 30%–60% 的极端点），U-Net 输出通道间干涉相位 $\Delta\phi$ 与强度比 $R$ 的代理量；推理后嵌入修正代价函数。CNN 输出与 M2 解析修正项的预期偏差 < 10% 视为降级运行通过 | 主路径：M1 → M2 解析修正项；降级路径：神经网络 $\to$ M2 备选实现（功能等价） |
| **备选路径 B** | 第一级角积分残余偶极相位 > 5%（$\eta_{\mathrm{dip}} \geq 5\%$）或二级解耦跨靶材可比性误差 $\delta_{\mathrm{cross}} \geq 5\%$ | R2（研究方案 §3.2）：角积分压制效率低于预期 | M5（CNN，U-Net 端到端相位检索） | 触发条件三档处置（< 2% / 2%–5% 加权正则化 / ≥ 5% 切换 CNN）、CNN 验证方式、网络选型依据、sim-to-real 风险缓解详见 M4 §失效边界、风险缓解与触发验证；降级运行以微调验证集损失下降 > 30% 为通过判据 | 主路径：M3 角积分 → M4 二级解耦；降级路径：CNN 端到端检索（绕过角积分压制） |
| **备选路径 C** | **主支（能区支，三条件合取，三项同时成立才触发）**：(i) 对真值基准的重构偏差 $\epsilon > 10\%$；(ii) 经参数重标定后无改善；(iii) 光子能量 $E_{\mathrm{ph}} > 409.7$ eV（N K 边电离阈上能区，水窗高段 409.7–543 eV）——三项缺一不触发。**另支（通道支，任一能区均可触发）**：多通道贡献 > 50% | R3（研究方案 §3.3 与 §6）：软 X 射线能区预判为失效边界候选 | M6 双变量图谱的阴影标注（不切换其他方法） | 在双变量图谱中以阴影形式标注失效区间，不强求修正；边界方程的拟合残差持续 > 0.1 时该段以未标定区呈现，禁止外推；图谱纵轴的误差阈上/下分区内不做方法学兜底，仅以实测点覆盖域为限 | 主路径：M6 双变量图谱（双线性回归边界方程）；降级路径：阴影标注 + 禁止外推（边界终止，无方法学降级） |

**备选路径 C 的触发判据展开（合取口径）**：主支的三项条件须同时成立，才判定该能区为方法学失效边界。单独的 $\epsilon > 10\%$ 只表明修正尚未收敛；单独的光子能量超过 409.7 eV 只表明进入了软 X 射线能区，尚不足以判定修正框架失效。两项任一缺失而先行触发，即属于过早宣告失效。第三步"经参数重标定后无改善"是排除性条件：须在 $\epsilon > 10\%$ 的能点上重跑边界方程的参量重标定（双线性回归系数与阈值项）。重标定后 $\epsilon$ 仍高于 10% 方可确认触发；重标定后回落至 5%–10% 区间者按合格区处理，并以实测点续补图谱。通道支独立成立：多通道贡献超过 50% 时，任何能区（含极紫外与水窗低段）的修正框架近似假设均不再成立。该项不与主支的三项条件捆绑。

**主支与通道支的覆盖关系**：主支的能区条件以 $E_{\mathrm{th}} = 409.7$ eV 为分界。该阈值落在水窗低段（284–409.7 eV）与水窗高段（409.7–543 eV）两档之间，两档中点能量分别位于该阈值的下方与上方（346.85 eV 与 476.35 eV）。故合取条件在图谱上表现为水窗高段内一块由 $\epsilon$ 等高线与 $E_{\mathrm{th}}$ 竖线共同圈定的区域，而非整段高段。通道支沿纵轴（多通道贡献百分比 $R_{\mathrm{ch}}$）在 50% 处划出横贯全图的失效带；两支在双变量空间中相交于（水窗高段，> 50%）区段。两支的处置一致：均以阴影标注 + 禁止外推结束，不引入方法学降级。

**判据的物理来源与不可外推的范围**：修正框架的近似假设在多通道叠加与宽带快变相位下同时失效。传统 FROG-CRAB 相位检索在通道混合、脉冲啁啾与库仑-激光耦合（CLC）下提取的时延与相位相对真值存在系统性偏差（[[methods/FROG]] 适用边界，arXiv:2312.14174）。同一 KB 方法页登记该反演依赖中心动量近似与迭代收敛性，条纹迹采样不足时相位恢复存在多解风险；故本节的 $\epsilon > 10\%$ 判据须在采样充分的条件下判定（[[methods/FROG]]）。条纹测量端的噪声底同样规定判据的分辨率下限：单发条纹相位精度约 20%，故 $\epsilon$ 的判定必须在多发平均后的数据上进行（[[methods/阿秒条纹相机]] 参数表，arXiv:2202.06147）。KB 条纹方法页另登记多通道情形下光电子与剩余离子的纠缠、通道间条纹延迟差异会系统性影响单通道相位提取的精度与解释。该系统性分量由 M2 解析修正项处理，CLC 项不在建模范围内；故本节的三条件合取不覆盖 CLC 与残离子纠缠导致的误差，二者的分工见 M1 §末态能量展开与 M2 §适用边界。上述来源给出的是失效的物理方向，不给出 $\epsilon$、$E_{\mathrm{th}}$、50% 三个数值的文献实测值。三者均为本方案设计值，须由第一阶段实测与 TDSE 模拟端标定后定版。

**备选路径间的耦合关系**：路径 A 与路径 B 共享 M5（CNN）作为底层工具，但触发条件与应用阶段不同——路径 A 在 R1 模拟端先于解析修正项失效触发，路径 B 在 R2 实验端先于二级解耦失效触发。两条路径的 CNN 训练集不同（路径 A 强调通道混合度参数空间覆盖，路径 B 强调 SNR 与偶极相位残余覆盖），二者可在同一 U-Net 模型上做联合微调。路径 C 是边界终止型，不依赖 M5。

**触发顺序**：R1 阶段模拟端先判定是否触发路径 A；A 通过后进入 R2 实验端判定是否触发路径 B；B 通过后进入 R3 跨能区标定，由路径 C 标定失效边界。三条路径按 R1 → R2 → R3 顺序串联触发，不允许跨阶段前向触发。

**回到主路径的条件**：路径 A 触发后，模拟端给出通道混合度参数空间的标定（30%–60% 区间），即可重新启用 M2 解析修正项（修正形式不变，仅参数区间扩展）。路径 B 触发后，CNN 在真实数据微调通过（验证集损失下降 > 30%），即可替代 M4 二级解耦作为新的"标准方法"——后续 R3 标定以 CNN 为参照。路径 C 触发后无回退机制，失效边界以阴影标注结束。其中主支在重标定后 $\epsilon$ 回落至 5%–10% 区间的区段不算触发，可按合格区处理，并以实测点续补图谱。

## M6：双变量误差依赖图谱标定

### 实验设计

以光子能量区间（$E_{\mathrm{ph}}$）与通道重叠度（$R_{\mathrm{ch}}$，以多通道贡献占总截面的百分比表征）为自变量，以修正算法的重构误差 $\epsilon$ 为因变量。$\epsilon$ 定义为重构结果对真值基准的偏差：模拟端以 TDSE 注入相位为真值；实验端以已知人工相位调制回注为真值基准，并以 rACE 锚点交叉定标（原"修正算法与传统 FROG-CRAB 的结果偏差"口径存在判据自毁——修正越有效该偏差越大，已废弃）。

三能区 × 两种靶材配置（共 6 组独立测量）：

| 能区 | 光子能量范围 | 靶材 | 多通道贡献 $R_{\mathrm{ch}}$ | 预期修正效果 |
|------|------------|------|---------------------------|-------------|
| 极紫外 | 50–150 eV | He（单通道基准）、Ne/Ar（线性响应区） | He ≤5%（单通道极限档）、Ne/Ar ~8%–15% | 修正项自动退化为零（基准验证） |
| 水窗低段 | 284–409.7 eV | N₂、CH₄ | 15%–30%（设计估值：CH₄ 18%–24%、N₂ 16%–26%） | 修正项显著有效（核心验证区） |
| 水窗高段（软 X 射线段） | 409.7–543 eV | Kr、Xe | > 30%（芯态通道预期明显） | 接近或超出失效边界 |

**靶材选取的 Z 依赖与边界对照**：

- **极紫外能区**：He（Z=2，单一 1s 通道）承担单通道极限基准，修正项应自动退化为传统 FROG-CRAB，结果偏差 < 1%（修正算法的可约性验证）；Ne（Z=10）与 Ar（Z=18）多通道贡献约 8%–15%（Ne 2s 阈 48.5 eV、Ar 3s 阈 29.24 eV 在该能区开放），处于线性响应区，兼作修正项低贡献端验证点。
- **水窗低段**：CH₄（C 1s 电离阈 290.7 eV，覆盖 C K 边以上约 291–410 eV）与 N₂（对应 N K 边 409.7 eV）。多通道贡献 15%–30%，对应实验验证子区间。
- **水窗高段（软 X 射线段，409.7–543 eV）**：Kr（Z=36，3d 芯态）与 Xe（Z=54，4d 芯态），为 N K 边电离阈上能区。芯态通道（Xe 4d、Kr 3d）与价通道的截面占比随光子能量演化，具体数值无单点文献值，以 Verner–Yakovlev 分壳层截面拟合（截面源口径见 M3 靶材配置表）与实测交叉标定为准。该能区预判为修正框架的失效边界候选（对应备选路径 C），用于界定图谱的失效区间阴影标注，而非修正算法的主检验区。

**图谱横轴的三档能区中点取值**：图谱横轴以能区类别为离散档位，每档以该能区的中点能量取值——极紫外 100 eV、水窗低段 346.85 eV、水窗高段 476.35 eV，纵轴为多通道贡献百分比（$R_{\mathrm{ch}}$）。三档中点由各自能区跨度取算：极紫外 (50+150)/2 = 100 eV；水窗低段 (284+409.7)/2 = 346.85 eV；水窗高段 (409.7+543)/2 = 476.35 eV。中点能量同时承担时间域等价量的换算基准。同一相位误差按 $\delta t = (\delta\phi/2\pi)\cdot T$、$T = h/E$ 折算，$\delta\phi$ 取相位均方根偏差。5% 相位误差在 346.85 eV 对应 0.60 as、100 eV 对应 2.07 as、476.35 eV 对应 0.43 as。三档的时间域验收线因此按能区分列，不设跨能区统一数值（口径见研究内容 G1/G3）。三档中点亦用于边界方程的分段阈值衔接：$E_{\mathrm{th}} = 409.7$ eV 落在水窗低段与高段两档之间，两档中点能量分别位于该阈值的下方与上方。

**两条按能区锁定的合格线判据**：图谱的合格性判定由两组按能区锁定的差值判据承担，二者分别承担"验证修正模块有效"与"标定失效边界运行状态"两项功能，取值口径与研究内容 G3 一致。

差值定义为 $\Delta\epsilon = \epsilon_{\mathrm{FROG\text{-}CRAB}} - \epsilon_{\mathrm{corr}}$，取同一能点、同一靶材、同一真值基准下的重构误差百分数之差。两端算法分别为传统 FROG-CRAB 与修正算法，修正算法含多通道解析修正项与偶极相位角积分解耦，即 G3 合取判定中的两套修正算法。

| 能区（横轴中点） | $R_{\mathrm{ch}}$ 区间 | 差值判据 | 功能定位 | 通过含义 |
|---|---|---|---|---|
| 水窗低段（346.85 eV） | 15%–30%（主检验档） | $\Delta\epsilon \geq 5$ 个百分点 | 修正模块有效性验证 | 修正项把传统 FROG-CRAB 的重构误差压低至少 5 个百分点，主检验区通过 |
| 水窗高段（476.35 eV） | 30%–50%（失效边界档） | $\Delta\epsilon \leq 2$ 个百分点 | 失效边界运行状态标定 | 两套算法的重构误差相差不超过 2 个百分点，差值收窄表明该能区已逼近修正框架失效边界 |

水窗低段的判据方向为"差值越大越好"，与修正项有效性同向；水窗高段的判据方向为"差值收窄"，其物理来源是该能区接近失效边界、修正项趋于饱和或失效，此时两套算法输出趋于一致而非修正项失效为灾难性事件。单通道极限档（$R_{\mathrm{ch}} \leq 5\%$）另设等价性旁证：两种算法相互偏差 < 1%，验证修正项幅度趋零时二者收敛到同一结果，与上述两条差值判据在物理含义上区分（前者验证可约性，后者验证修正效果与边界状态）。

差值判据的测量协议：每组测量同步运行传统 FROG-CRAB 与修正算法重构，误差量取重构结果对真值基准的偏差，模拟端与实验端按 G1 的两端定义分列度量、不共用数值（模拟端真值为 TDSE 注入相位，实验端真值为已知人工相位调制回注基准）。每组测量重复次数 ≥ 5 次，$\Delta\epsilon$ 取该组重复的均值后与阈值比较；两组判据按能区各自独立判定，不做跨能区合并统计。实验端回注基准的传递方式见 M7 的 TDSE→FROG 门控自洽性校准。其中 $\Delta\phi$ 与通道强度比 $R(E)$ 作为共同参量由模拟端与 FROG 端独立提取，用于消除场参数偏差与靶材模型偏差对差值判据的污染。共同参量选取与提取步骤见 M7 §算法步骤。

**图谱判据的用法**：图谱以 $(E_{\mathrm{ph}}, R_{\mathrm{ch}})$ 双变量平面呈现。横向三档中点（100 / 346.85 / 476.35 eV）承载能区定位，纵向按 $R_{\mathrm{ch}}$ 四档（≤5%、8%–15%、15%–30%、30%–50%）承载通道重叠度分档。判据用法为逐单元判定。水窗低段（346.85 eV）× 15%–30% 主检验档所覆盖的笛卡尔积单元内，逐单元核验 $\Delta\epsilon \geq 5$ 个百分点；水窗高段（476.35 eV）× 30%–50% 失效边界档单元内，逐单元核验 $\Delta\epsilon \leq 2$ 个百分点。两组单元在双变量平面上互不重叠，前者承担有效性验证、后者承担边界标定；等高线图上以 $\epsilon = 5\%$（合格线）与 $\epsilon = 10\%$（失效线）分层。主检验档单元的等高线须落在合格区内，失效边界档单元的等高线须贴近或越过失效线，越界即备选路径 C 的阴影标注区。G3 的 5% 合格阈值按两项判据合取判定。多通道修正单独 5% 与偶极相位解耦单独 5% 须在双变量平面内逐点同时通过，方计为合格。合取口径见研究内容 G3，等高线层级与填充色参数见本节 §算法步骤步骤 2、步骤 3。

**关键参数的验证方式**：以修正算法与传统 FROG-CRAB 的差值而非绝对误差作为判据量，同一真值基准下的两项重构误差共享该基准的估计不确定度，在作差时相消，消除了真值基准不确定度对 5% 阈值判定的直接影响。合格线与失效线的绝对阈值（5% / 10%）仍作用于 $\epsilon$ 本身，其真值基准不确定度由 G1 两端定义分离承担，模拟端与实验端不共用数值。

**失效模式与替代方案**：水窗高段（476.35 eV）差值判据的不通过有两种可能原因，须在图谱上分开呈现：一是修正项在该能区确实趋于饱和或失效（预期结果，与备选路径 C 的阴影标注一致）；二是修正项仍有效但真值基准在该能区的传递出现系统偏差（异常结果，指向 M7 门控校准未收敛）。二者区分依据是 $\epsilon$ 的绝对量级与参数重标定后的改善幅度：$\epsilon > 10\%$ 且经参数重标定后无改善者判为失效边界（备选路径 C）；参数重标定后 $\epsilon$ 下降而 $\Delta\epsilon$ 仍不满足者判为真值基准传递问题，退回 M7 校准环节重新标定共同参量后复测，不作为图谱结论。水窗低段（346.85 eV）差值判据不通过时，按备选路径 A 的触发条件检查通道混合度与通道重叠宽度：通道间能量差 < 0.5 eV 或通道重叠宽度 < 0.5 eV 时转入神经网络降级路径，否则回到 M2 解析修正项的参数重标定。相关判据的算法侧口径见本节 §算法步骤步骤 0 与 §失效边界与风险缓解。

**方法学来源**：传统 FROG-CRAB 相位检索在通道混合、脉冲啁啾与库仑-激光耦合（CLC）下提取的时延/相位相对真值存在系统性偏差，宽带快变谱相位下迭代重构病态、仅给带宽平均延迟（[[methods/FROG]]，arXiv:2312.14174）。这是两套算法在同一真值基准下产生可测差值的物理前提。条纹重构端按 XUV–IR 延迟扫描逐步提取条纹相位的协议，与单发条纹相位精度约 20% 的噪声底见 [[methods/阿秒条纹相机]]（arXiv:2202.06147），后者规定了差值判据的统计分辨率下限。水窗段条纹谱的多通道通道重叠与 FROG-CRAB 在极端带宽下的表征极限见 [[papers/2017-1710_02208-attosecond-streaking-in-the-water-window-a-new-regime-of-att]]。
### 算法步骤

**步骤 0：四档通道重叠度阈值划分（研究方案 §3.3 表格的复刻）**

研究方案 §3.3 给出通道重叠度四档划分，对应不同的处理路径。该表与本手册 M6 §关键参数表中"通道重叠度分级"的差异在于：参数表以三档（低/中/高）做梯度覆盖，四档表以处理路径做精细映射（含过渡带归类与备选路径触发点）。两表互补，不重复。

| 通道重叠度档位 | 多通道贡献区间 | 处理路径 |
|---|---|---|
| 单通道极限档 | ≤5%（5%–8% 过渡带归入此档，修正项不激活） | 传统 FROG-CRAB，修正项自动退化 |
| 线性响应档 | 8%–15% | 修正项生效，rACE 锚点交叉验证（约 10%） |
| 主检验档 | 15%–30% | 修正项核心验证区 |
| 失效边界档 | 30%–50% | 约 40%（多通道贡献 40%）触发备选路径 A，40%–50% 降级运行 |

**步骤 1：误差提取**

对每组测量，计算修正算法重构结果对真值基准的偏差：

$$\epsilon = |\Phi_{\mathrm{corr}} - \Phi_{\mathrm{true}}|_{\mathrm{RMS}}$$

模拟端 $\Phi_{\mathrm{true}}$ 取 TDSE 注入相位；实验端 $\Phi_{\mathrm{true}}$ 取已知人工相位调制回注基准。每组测量重复次数 ≥ 5 次，以评估统计误差。

**步骤 2：二维插值**

在 $(E_{\mathrm{ph}}, R_{\mathrm{ch}})$ 参数空间（极紫外/水窗/软X射线 × < 5%/15%–30%/> 30%）做双线性插值，构建 50×50 的误差网格。实测点集的扩充规则（统计功效要求）：实测 6 组（每能区 2 组靶材）不足以支撑 50×50 网格插值与 3 参数边界方程的统计功效，须以模拟端扫描点扩充——每能区至少 3 个能量点 × 重叠度 4 档（≤5%/8%–15%/15%–30%/30%–50%），扩充后点集不少于 12 点；模拟点承担插值骨架，实测点承担绝对标定。边界方程拟合与外推约束见步骤 4。

**双线性插值的具体操作**：设扩充后的实测点集 $(E_i, R_i, \epsilon_i)$，$i=1\ldots N$（$N \geq 12$，含 6 个实验实测点与模拟端扫描点），首先生成规则的 50×50 参数网格（50 个能量采样点 × 50 个重叠度采样点）。双线性插值按以下顺序执行：

1. 对每个 $R$ 固定值（行方向），在能量方向上对相邻两实测点做线性插值，得到中间值 $\epsilon(E_{\mathrm{interp}}, R)$。

2. 对每个 $E$ 固定值（列方向），在重叠度方向上对中间值做线性插值，得到网格每个点的 $\epsilon$ 估计。

若相邻实测点间存在非单调关系（如软 X 射线能区的非单调误差依赖），则在对应区间改用三次样条插值替代线性插值，以保证插值函数连续且导数光滑。

**留一交叉验证（LOOCV）的操作步骤**：

1. 剔除第 $i$ 个实测点（$i=1\ldots N$，$N \geq 12$），用剩余点重新执行双线性插值，得到预测值 $\hat{\epsilon}_i$。

2. 计算相对误差 $\delta_i = |\hat{\epsilon}_i - \epsilon_i| / \epsilon_i$。

3. 重复步骤 1–2 共 $N$ 次（$N \geq 12$），得到留一误差集 $\{\delta_1, \ldots, \delta_N\}$。

4. 取最大相对误差 $\max(\delta_i)$，若 < 10% 则插值通过验证。若不通过，检查 $\epsilon_i$ 异常的实测点，排除靶材系统误差后重新验证。

**等高线绘制参数**：使用 matplotlib `contour` 函数绘制等高线，等高线层级设置为 [0.02, 0.05, 0.08, 0.10]（对应 2%/5%/8%/10% 四级），其中 5% 为主等高线（线宽加粗），合格区（$\epsilon < 5\%$）用浅绿（`#90EE90`）填充，失效区（$\epsilon > 10\%$）用浅灰（`#D3D3D3`）填充，中间过渡区（$5\% < \epsilon < 10\%$）不填充仅标等高线。

**步骤 3：等高线绘制**

以 $\epsilon = 5\%$（对真值基准）为合格线阈值，绘制等高线图，标注修正模块的适用区间与失效边界。以 $\epsilon = 10\%$（对真值基准）为失效线，高于此值定义为方法学失效。单通道极限下修正算法与传统 FROG-CRAB 的相互偏差 < 1% 作为可约性旁证（区别于误差量 $\epsilon$）。

等高线绘制使用 matplotlib 的 `contour` 和 `contourf` 函数，合格区（$\epsilon < 5\%$）填充浅绿色，失效区（$\epsilon > 10\%$）填充浅灰色，中间过渡区（$5\% < \epsilon < 10\%$）不填充仅标等高线。

**步骤 4：边界方程拟合**

对 < 5% 合格区间边界做曲线拟合，给出解析边界方程 $R_{\mathrm{ch}}^{\mathrm{max}}(E_{\mathrm{ph}})$，用于预测新能区的适用性。

**边界方程拟合的具体操作**：采用双线性回归模型。设合格边界在 $(E_{\mathrm{ph}}, R_{\mathrm{ch}})$ 平面内近似为分段线性曲面：

$$R_{\mathrm{ch}}^{\mathrm{max}}(E_{\mathrm{ph}}) = \beta_0 + \beta_1 \cdot E_{\mathrm{ph}} + \beta_2 \cdot E_{\mathrm{ph}} \cdot \mathbb{1}[E_{\mathrm{ph}} > E_{\mathrm{th}}]$$

$E_{\mathrm{th}} = 409.7$ eV 为分段阈值（对应 N K 边电离阈上能区起始）。$\beta_0$、$\beta_1$、$\beta_2$ 为回归系数，由扩充后的实测点集（$\geq 12$ 点，见步骤 2）的边界估计通过最小二乘法确定。拟合残差 < 0.05 为通过。拟合结果以方程形式给出，并附带 95% 置信区间；实测点覆盖域之外禁止外推，边界方程仅在实测点集覆盖的能量-重叠度范围内给出预测，域外区域以阴影标注为未标定区。参数化形式与终止判据（合格阈值 5%）的对应关系：$\beta_0 + \beta_1 E_{\mathrm{ph}}$ 描述水窗及以下能区的合格边界；$\beta_2$ 项描述软 X 射线能区的边界跃迁（如适用）。

**水窗高段 409.7–543 eV 的模拟能点归属**：M1 的参数扫描止于 409.7 eV——其第二阶段的能量范围为 284–409.7 eV、通道数 2–3、重叠度 0.5–2 eV，第三阶段的极端点亦在该能量域内选取（见 M1 §分阶段模拟执行计划）。水窗高段 409.7–543 eV 不在 M1 扫描范围内，故该档在图谱上以实测单列：Kr（3d 芯态）与 Xe（4d 芯态）能点归入 M6 的实测点集，不占 M1 的模拟扫描点预算，也不计入 M1 三阶段核时估算。由此，本节「模拟端扫描点扩充至 ≥12 点」的扩充在 284–409.7 eV 与 50–150 eV 两档成立，水窗高段的插值骨架由该档实测点自身承担；该档的 $R_{\mathrm{ch}} > 30\%$ 区间属备选路径 C 的失效边界候选区（见 §备选路径 A/B/C 总览），其覆盖不足按 §失效边界与风险缓解段的阴影标注与禁止外推规则处置，不以补充模拟扫描点填补。

**水窗高段靶材的能区条件与参数溯源**：该档的 HHG 源由中红外长波长驱动级承担——$U_p \propto I\lambda^2$ 的截止标度使中红外驱动把 HHG 截止推入水窗/软 X 射线波段，结合少周期驱动或振幅门控可得孤立水窗阿秒脉冲（[[methods/高次谐波产生]]）；该页亦登记气体 HHG 与固体 HHG 分属不同机制分支，气体靶三步模型不可直接套用于固体体系，故本档靶材一律取气体靶。Kr/Xe 芯态通道与价通道的截面占比随光子能量演化，无单点文献值，以 Verner–Yakovlev 分壳层截面拟合与实测交叉标定为准（截面源口径见 M3 靶材配置表），该档 $R_{\mathrm{ch}}$ 档位归属为设计估值、待第一阶段实测标定。

### 验证方式

**单通道极限验证**：在极紫外能区（Ne、Ar），修正算法应自动退化为传统 FROG-CRAB，两者偏差 < 1%。若偏差显著 > 1%，说明修正项存在非物理的残余贡献。

**误差对称性验证**：水窗能区 N₂ 和 CH₄ 应给出相近的 $\epsilon$ 值（相同 $R_{\mathrm{ch}}$ 区间），若偏差 > 5%，提示实验系统误差未被充分控制。

**插值连续性验证**：扩充后实测点集（≥12 点）的插值误差估计应 < 10%（通过留一交叉验证确定）。

### 失效边界与风险缓解

**失效边界**：当光子能量超过 409.7 eV（N K 边电离阈上能区）或通道重叠度超过 50% 时，修正框架的近似假设不再成立。失效判据：对真值基准的重构偏差 $\epsilon > 10\%$ 且不随参数优化改善。

**风险缓解**：三能区实验并行安排以节省总实验周期；失效区域在图谱中以阴影区域标注，不再强求修正。该标注对应 M6 实验设计的"水窗高段失效边界候选"段，触发条件为边界方程在 $E_{\mathrm{ph}} > 409.7$ eV 段拟合残差持续 > 0.1。

### 外部参照：宽带反演与本方案修正的并行技术路径

Ardana-Lamas 等[21]以再分析方法处理 Cousin 等[2]的 2017 年氪条纹数据，采用 VTGNA 类变分投影算法，得到 19.2 as、谱中心 243 eV、谱上沿约 390 eV 的孤立脉冲。该结果覆盖 243–390 eV，与本方案水窗低段 284–409.7 eV 部分相邻，但不进入 409.7–543 eV 高段；其约 150 eV 谱宽亦明显宽于本方案 M3 设计谱宽约 5 eV（284 eV 处）。因此，该工作用于校准宽带反演的适用尺度，不作为本方案脉冲宽度的直接目标。

Gao 等的工业级 CEP 稳定 Yb 激光驱动氦气 HHG 工作，经多滤膜啁啾补偿后报告 25±2 as、50–320 eV 光谱和约 10¹² 光子/秒通量，后续发表版本报告 18 as。其变分反演处理宽带条纹反演的收敛性；本方案 M2 解析修正处理通道间相位干涉造成的物理建模偏差。两者解决不同误差源：反演迭代陷入局部极小且传统 FROG-CRAB 多次初值仍不能稳定时，采用变分算法；反演可收敛但多通道干涉主导残差时，采用 M2 修正。VTGNA 结果可作为 M5 训练集的附加相位标签，不替代 TDSE 真值；仅当独立样本的相位误差满足 5% 判据时纳入。

Han 等对 Ardana-Lamas 报告提出反演归因质疑，Biegert 组后续答辩涉及实验体制、啁啾补偿、条纹迹残差及时间门控等系统项。该争议不作为本方案的物理边界依据，但提示水窗反演结果须由独立实验标定。M6 在 CH₄/N₂（284–409.7 eV）上执行模拟扫描与实验回注交叉验证，按能量和通道重叠度拟合边界方程，不从外部报告直接移植阈值。

Reinhard 等展示了水窗相干层析对脉冲谱相位精度提出的应用需求。本项目不据此单独设定阈值，而沿用 M6 的统一判据：重构均方根相位误差小于 5% 为合格，超过 10% 且参数优化不能改善即进入失效边界；边界拟合残差目标小于 0.05。

**验证与降级路径**：先在极紫外 He 单通道数据上确认修正项与传统 FROG-CRAB 的可约性偏差小于 1%，再在水窗低段验证误差小于 5%；若变分反演不稳定，固定多初值、延拓谱相位并采用投影正则化，保留原始条纹迹进行残差复核；若残差仍集中于边带结构，转入 M2 通道干涉修正。E_ph 超过 409.7 eV 或通道重叠度超过 50% 时，不强求修正，按 M6 图谱阴影区报告未标定边界。

## M7：TDSE→FROG 门控自洽性校准流程

### 功能定位

M7 不产生独立物理输出，确保 R1 阶段 TDSE 模拟标定的修正项参数（通道间相位差 Δφ、通道强度比 R、修正项系数 α）在 R2 实验条件下仍成立。该校准对应申请书 §4.3 方法学自洽性中"具体校准流程"。

### 校准逻辑

TDSE 模拟与 FROG 实验之间存在两类系统偏差：**场参数偏差**（XUV 脉冲中心能量/脉宽的理论假设与实验真值的不确定度）与**靶材模型偏差**（原子能级/振子强度取自理论数据库，与真实靶气体的细微差异）。两类偏差若不消除，R1 标定的修正项参数直接套用 R2 会引入额外误差、导致门控判据失真。

### 算法步骤

**步骤 1：共同参量选取**

从 TDSE 模拟与 FROG 实验中提取一组**共同参量**作为校准锚点，须满足：同时可从两类数据源独立提取，且对两类系统偏差的一阶导数趋零。优先选用通道间能量差 ΔE₁₂ 与通道强度比 R(E)——两者对场参数不确定度的敏感度低于干涉相位 Δφ。共同参量适用性：

| 共同参量 | TDSE 可提取 | FROG 可提取 | 对场参数敏感 | 对靶材模型敏感 |
|------------|--------------|--------------|--------------|----------------|
| 通道间能量差 ΔE₁₂ | ✓（能级差已知） | ✓（能谱峰位提取） | 低 | 中 |
| 通道强度比 R(E) | ✓（谱强度比） | ✓（需去脉冲包络） | 中 | 低 |
| 干涉相位 Δφ(E) | ✓（直接计算） | ✓（FFT 提取） | 高 | 低 |

FROG 端提取操作：

1. **ΔE₁₂**：对光电子能谱 S(E) 做 2–3 高斯拟合，提取各分量峰位 E_i，相邻峰位之差即为 ΔE₁₂ = |E₂−E₁|。N ≥ 10⁴ 时峰位精度约 0.1 eV（多高斯拟合显著优于单峰分辨率 4 eV @ 400 eV），满足 ΔE₁₂ ≥ 0.5 eV 的 M1 适用条件。
2. **R(E)**：取高斯分量峰面积 A_i，去脉冲包络卷积（S_{chan,i}(E) = S_i(E)/I_XUV(E)，以单通道 He 数据为脉冲强度参考）后用去卷积谱面积计算 R(E) = A₂/A₁。

**步骤 2：偏差评估**

对每种靶材，分别从 TDSE 与 FROG 提取共同参量，计算：

$$\delta_{\mathrm{calib}} = \left| R_{\mathrm{TDSE}}(E) - R_{\mathrm{FROG}}(E) \right| / R_{\mathrm{TDSE}}(E)$$

三档处置：δ_calib < 5% 校准通过，修正项参数直接用于 R2；5% ≤ δ_calib < 10% 进入步骤 3 线性重标定；δ_calib ≥ 10% 修正项整体失效，触发备选路径 A（神经网络）。

**步骤 3：参数重标定（5% ≤ δ_calib < 10% 档）**

以 FROG 提取的共同参量为真值做线性重标定：

$$\alpha_{\mathrm{recal}} = \alpha_{\mathrm{TDSE}} \times \frac{R_{\mathrm{FROG}}}{R_{\mathrm{TDSE}}}$$

假设偏差源于靶材振子强度的系统性缩放（不改变修正项函数形式）。重标定后回步骤 2 验证 δ_calib 收敛至 < 5%。

**步骤 4：独立验证**

以 CO₂（C 1s→2π* ~290 eV，与 CH₄ C K 边 284 eV 相近但分子结构不同——线形 CO₂ vs. 四面体 CH₄，振子强度分布差异显著）为独立验证靶材。该靶常温常压下为气体，与 CH₄/N₂ 靶材形态一致，无需改造真空系统。在该验证集上运行校准后修正算法，确认重构误差 < 5%；若 > 5% 回步骤 1 重校。

### 关键参数表

| 参数 | 取值 | 说明 |
|------|------|------|
| 校准通过阈值 | δ_calib < 5% | 修正项参数直接应用 |
| 重标定阈值 | 5% ≤ δ_calib < 10% | 线性重标定程序 |
| 失效阈值 | δ_calib ≥ 10% | 触发备选路径 A |
| 验证靶材 | CO₂（C 1s→2π* ~290 eV） | 独立验证校准结果 |
| 每靶材重复测量次数 | ≥ 5 次 | 统计误差评估 |
| 峰位提取精度 | ~0.1 eV @ N ≥ 10⁴ | 多高斯拟合显著优于单峰分辨率 |

### 时间节点

R1 模拟（第 1–12 月）与 R2 实验准备（光源调试、探测器标定）并行；R1 完成修正项参数输出后立即启动 M7 校准（约 1 月）；R2 正式实验在 M7 校准通过后（第 13 月起）开始。相比串行方案节省约 12 月。

## 三能区靶材递进逻辑与门控关系

### 递进设计原理

三能区（极紫外、水窗低段、水窗高段）的靶材选取不是平行对照，而是遵循**单通道极限→线性响应→多通道典型→多通道失效边缘**的递进逻辑，每一阶段的结论决定下一阶段的实验参数：

```
极紫外能区（He 单通道基准 + Ne/Ar 线性响应区 8%–15%）
  → 目的：验证修正算法在单通道极限下可约至传统 FROG-CRAB，
     并在线性响应区与 rACE 锚点交叉验证
  → 预期结果：修正项贡献趋于零（由干涉谱因子自然实现），偏差 < 1%
  → 门控输出：若偏差 > 1%，说明修正项存在非物理残余贡献，
     需重新检查 M2 的修正项构造逻辑，不进入下一阶段
  ↓ 通过门控 G5（单通道可约性）后进入

水窗低段能区（N₂/CH₄，15%–30% 多通道贡献）
  → 目的：标定修正模块的核心适用区间（申请书 §3.3 R3 核心验证区）
  → 预期结果：修正项显著有效，修正前基准由第一步实测确定，
     模拟端预期偏差跳升至 20% 以上、修正后降至 < 5%（目标降幅 ≥4 倍）
  → 门控输出：若偏差未降至 < 5%，检查通道干涉相位提取是否正确；
     若通道重叠宽度超出 2 eV，修正项参数需重新标定
  ↓ 通过门控 G5（多通道有效性）后进入

水窗高段能区（Kr/Xe，> 30% 多通道贡献）
  → 目的：界定修正框架的失效边界（申请书 §3.3 失效条件触发区）
  → 预期结果：偏差接近或超过 10%，需通过参数重标定尝试恢复
  → 门控输出：若参数重标定后对真值基准偏差仍 > 10%，该区域标注为失效边界，
     不再强求修正（M6 以阴影区标注）
```

### 门控信号与决策矩阵

| 能区转换 | 通过条件 | 未通过处置 |
|---------|---------|---------|
| 极紫外→水窗低段 | 单通道可约性验证：修正项贡献范数（修正项加权之和占脉冲谱强度的百分比）< 1%，偏差 < 1% | 进入水窗低段能区 | 修正项构造逻辑回溯检查 |
| 水窗低段→水窗高段 | 多通道有效性验证：修正后偏差 < 5% | 进入水窗高段能区 | 参数重标定（通道重叠度重扫） |
| 水窗高段区段内 | 失效边界确认：对真值基准偏差 > 10% 且不随参数优化改善 | 标注失效边界 | 以阴影区域标注，不外推 |
