# 应变石墨烯中的 Floquet 二阶拓扑绝缘体（corner mode 理论预言）

- 课题 ID: general-ssh-weyl-20260920
- 五维笔记（literature-reading skill 标准）
- 出处：arXiv:2605.07190（2026-05），摘要级蒸馏（KB 蒸馏页 digest_level: abstract）
- 与本课题的关系：**高阶拓扑支柱的 Floquet 实现路线**——corner mode 的 HHG 指纹是本课题可挖的待验证方向。

## 研究问题（Research Question）

单轴应变（打破 C₃ 对称性）与斜入射圆偏振光（Floquet 周期驱动）耦合，能否在石墨烯这种无能隙 Dirac 体系中实现二阶拓扑绝缘体（SOTI）并预言 corner mode？

## 研究背景（Background）

二阶拓扑绝缘体的标志是 0 维角态出现在二维体的「角」上。单自由度（纯应变或纯光）通常不足以同时实现能带反转与边界条件重构；石墨烯 Dirac 锥清晰、C₃ 高对称，是几何+光场双自由度耦合的理想载体。

## 研究方法（Methods）

紧束缚模型 + Peierls 替换（光场矢势以 exp(i∫A·dl) 引入跃迁相位）——比 k·p 连续模型更忠实于原子尺度边界条件，对 corner 这类原子级局域态更可靠。单轴应变负责打破 C₃ + 能带工程；斜入射圆偏振光负责 Floquet 驱动（斜入射破坏 z→−z 对称、对上下子格不等价耦合——正入射只能产生 Haldane-like 质量项）。

## 主要发现与核心结论（Main Results）

- 紧束缚+Peierls 模型预言 **corner mode 出现**——SOTI 的标志性证据。
- 应变与光双自由度解耦又互补：应变管对称破缺与边界条件、光管拓扑相变。

## 潜在研究方向（Future Directions）

纯理论预言（无实验/STM 对应）；Floquet 展开阶数与实验可达光强未给（KB 页作者经验估计约 10 MV/cm 量级，非论文数据）；corner mode 对边界无序与热涨落的鲁棒性未评估；应变 vs 光对拓扑相图的主导边界未给参数扫描；**corner mode 在 HHG 中如何表现（对称性破缺+二阶拓扑是否给出可区分的谐波信号）为待验证方向**。
