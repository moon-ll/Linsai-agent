# 课题设想

**最后更新**：2026-11-10

## 标题

强场高次谐波谱学中的拓扑量子数探测与增强机制分解：以高阶拓扑绝缘体、SSH 边界态与 Weyl 半金属为对象的统一多带强场动力学框架

## 研究背景与动机

知识簇综合：该方向以固体高次谐波产生（HHG）为核心，将其拓展为兼具阿秒分辨与量子光物态探测能力的统一平台。多项研究显示：HHG 圆二色性光谱可有效区分低阶与高阶拓扑绝缘体，而高阶拓扑量子数在 HHG 过程中是否留下可观测印记仍属开放问题，紧束缚拓扑相谐波产额增强上限达两个数量级；SSH 模型中边界态导致带隙频率处谐波压缩，且拓扑相与平凡相压缩度不同，可作为拓扑相判据；Weyl 半金属 TaP 中 Weyl 费米子驱动太赫兹三次谐波产生，呈立方功率律并支持偏振调谐与拍赫兹电子学应用；ZnO 中强场 HHG 与激子光致发光存在竞争，呈现各向异性光谱及强度切换机制。理论层面，多带模型、Berry 相位、等离激元-半导体混合纳米结构与量子光场效应正被整合为统一框架，实现阿秒级谐波相位控制与非经典光生成，勾勒出拓扑量子光学 HHG 的前沿图景。

## 现存研究空白或瓶颈

四条空白沿"现象—机制—对照"次序依次浮现。第一，高阶拓扑相的 HHG 信号是否留下可观测印记尚未厘清，高阶 CD 与对称破缺诱导边带信号的联合探针设计仍属空白。第二，SSH 边界态诱导的带隙谐波压缩结论多基于一维紧束缚数值，推广至三维真实材料时体-边重叠、shift vector 与 Berry 曲率三类贡献的耦合形式尚未被独立建立。第三，Weyl 半金属 HHG 的量级增强究竟来自 Weyl 节点色散、Berry 曲率分布还是非平衡载流子散射，至今尚无定量分解。第四，拓扑 HHG 探针的判别边界缺少非拓扑对照标定，拓扑体系与 ZnO 在相同驱动条件下的 HHG 行为对比未被定量建立。上述空白依据截至 2026 年 11 月对公开文献的检索作出。国内在多带 SBE 数值积分与 Berry 曲率反演方法上已有积累，但上述四类问题尚无独立工作系统处理。

## 拟开展研究内容和方案

四个方向按递进依赖展开，每一方向的产出是下一方向的输入。

方向一以四带 BHZ 推广构造的模型级 HOTI（铰链态）为计算原型，Bi₂Se₃ 家族仅承担一阶 TI 实验参照，多层 SSH 与 Qi-Wu-Zhang 模型作算法验证。构造含高阶拓扑量子数的紧束缚哈密顿量并接入多带含时演化引擎，把高阶 CD 的角度依赖与对称破缺诱导边带信号联合提取，在 CD 角度谱与边带频率二维空间中形成对高阶拓扑量子数的双变量印记。产出 R_HOTI ≥ 10、S_edge ≥ 0.2、δ_FP < 5% 三项指标，终止判据取双类平衡样本（各类 400 个、总计 800 个）上判别成功率 G1 的单侧 95% 置信下界 ≥ 90%，800 样本的 1σ 约 ±0.77 个百分点、真值 95% 时 Wilson 单侧下界 93.6%。三项自定标阈值在只含平庸/低阶相的 null 样本集上标定，判定域一次性固定后度量阶段不再拟合。

方向二把 SSH 边界态诱导的谐波压缩机制向三维 Weyl/TI/HOTI 推广。沿拓扑相变点附近扫描谐波压缩度、CD 与边带信号，把边界态谐波压缩、体相拓扑不变量、shift vector 与 Berry 曲率矩阵元修正三类贡献在二维空间中组织为对相变点位置的指纹，并借 ESSH 偶/奇宇称定则与半填充反幺正对称性关断横向通道的机制，把边界态参与、耗散定态破缺与对称性显式破缺三条通道分开甄别。产出 Δκ ≥ 20%、η_SF ≥ 95%、Δt ≤ 10 fs 三项指标。

方向三在 TaP/TaAs 上把已公开报告的 HHG 增强分解为 Weyl 节点、Berry 曲率分布与非平衡载流子散射三类因素的归一化贡献。散射贡献须同时以标度与谱形两条线索纳入：带内与带间贡献的相干叠加本身即可抑制高次谐波，退相干增强解除该破坏性干涉后被抑制的谐波重新进入，故开关差分提取的是周内项主导的谱形差异，周期间调制由基准谱在归一化时扣除。节点分型作为前置判断：type-I 族（TaP/TaAs 节点近于水平）与 type-II 族（β-WP₂ 节点倾斜）的色散结构不同，节点项取舍与高阶抛物修正幅度按族分别标定，分解先在 type-I 族完成后再移至 type-II 族。以 TaP 严格立方功率律界定散射贡献 Z 的占比下限、以 Cd₃As₂ 裸膜幂指数 2.3 界定其上限，微腔近场放大的外场增益不计入本征非线性。产出 X + Y + Z ≥ 95%、σ_dec ≤ 5 个百分点、R² ≥ 0.9 三项指标。

方向四以 ZnO 与 MgO 承担非拓扑对照，标定前三方向所产判据的判别边界。ZnO 承担多通道竞争区的标定，MgO 承担纯对称性各向异性的扣除；在 800 nm 与 1800 nm 双基线下按通道切换、强度残余、符号偏离的次序给出 ΔI_rev ≥ 0.5 × I_threshold、δ_CD ≥ T 两项阈值，以及分两层的 ΔI_gap 阈值——全量层 ΔI_gap^full ≥ R（R = 2，对应紧束缚拓扑相增强上限两个数量级的常用对数），残余层 ΔI_gap^res ≥ R_res（扣除带隙、偶极矩与非拓扑差后由残余分布回填）。

## 拟采用技术路线

以紧束缚模型为基底搭建含拓扑量子数的多带 TDSE/SBE 计算引擎，覆盖一维 SSH（含 ESSH 与 Rice-Mele）、二维 Qi-Wu-Zhang 与 Haldane、三维 BHZ 推广 HOTI 与 TaAs/TaP Weyl 半金属、ZnO 与 MgO 五类体系。引擎在相干项中按方向激活两类扩展：Berry 曲率诱导反常速度项支撑 Weyl 分解，激子-连续态耦合项支撑 ZnO 通道建模。

Weyl 三因素反演框架以三个开关控制节点线性色散与高阶抛物修正、Berry 曲率修正项、散射时间与带内阻尼，按"全开—单关—双关—全关"嵌套差分归一化，以 σ₀/σ_full < 0.05 作为弱耦合近似成立的前置条件。分解按 Weyl 节点分型分两步推进，先在 type-I 族完成并以 TaP 立方律校核，再移至 type-II 族；若 type-II 族的节点项无法与散射项分离，其结论按适用边界单独标注而不并入 type-I 族的百分比。ZnO 耦合模型以 SBE 加激子-连续态耦合项实现双通道强度切换曲线的复现。拓扑与非拓扑对照框架在双基线下扫描驱动强度、偏振与晶体取向三个参数维度，标定阈值 R、T 与 R_res 并检验其跨基线一致性。SBE 引擎的演化方程含带间跃迁、带内加速项、布居 T₁ 与极化 T₂ 四项：布居方程取 $(2/\hbar)\mathbf{E}\cdot\sum\mathrm{Im}[\mathbf{d}_{nm}\rho_{mn}]$，右端为实数，与 $\rho_{nn}$ 的实数性自洽；极化方程的带内项取 $-\mathbf{F}\cdot\nabla_{\mathbf{k}}\rho_{mn}$，与谐振项共同保证规范不变性；相干电流的带间项取 $\sum\mathrm{Im}[\rho_{nm}\mathbf{d}_{mn}]$，两项各只含一次密度矩阵元。时间步长由 CFL 条件约束，适用条件按中红外/近红外主窗、太赫兹弱场校核窗、强场太赫兹三类通道分别给出。退相干时间按体系分档：强场主窗 SSH 3 fs、Qi-Wu-Zhang/Haldane 2 fs、HOTI 与 Weyl 各 1.5 fs；弱场太赫兹校核窗另立一档，取 T₂ 在 5–25 fs 区间扫描，并要求 R² ≥ 0.9 的达成在该区间内对 T₂ 不敏感。TaP 立方律的标度拟合区间取 $10^{6}$–$10^{11}$ W/cm²，下限与实验施加的 $10^{6}$–$10^{7}$ W/cm² 区间重合，上延段用于检验立方律在高场下的保持情况。退相干项的建模边界由实验与第一性原理两侧的工作共同划定：超纯硅的温度依赖测量以随机晶格位移模拟非相干声子涨落，定量复现谐波产额随降温上升的退相干图像，说明非相干声子足以在实验条件下主导退相干；第一性原理工作则指出固体的退相干主要由布居动力学主导，而弛豫时间近似在强激光下失效，强场通道因此改用含时密度泛函理论。统一理论框架把上述产出抽象为含拓扑项 SBE 的通用形式与多带跃迁矩阵元的统一表达。

## 创新点

（1）针对高阶拓扑量子数在 HHG 谱中信号消失的方法学瓶颈，提出高阶 CD 与对称破缺诱导边带信号联合的二维参数空间探针。该探针不依赖低阶 CD 的间接推断，而是在体态、边态、角态通道分辨的框架下把高阶性印记单独提取，边带信号按高阶边带偏振矢量的显式公式反演为可比较量。判据设计先区分两类产生奇偶阶次差异的机制——选择定则被显式破缺，与对称性分析不足导致的通道误判，因而以多重指纹联合判定而非依赖单一通道特征。R_HOTI ≥ 10 使"高阶拓扑量在 HHG 谱中不可观测"由断言转为可量化检验的命题。

（2）把 SSH 一维边界态谐波压缩结论推广为三维拓扑相变与边界态动力学的可工程化判据集。判据集沿拓扑相变点扫描压缩度、CD 与边带信号三类可观测量，并借 ESSH 偶/奇宇称定则与耗散定态路径的对照甄别边界态参与的机制来源；Δκ ≥ 20%、η_SF ≥ 95%、Δt ≤ 10 fs 三项指标使判据集由现象学归纳转为可标定的工程量。

（3）把 Weyl 半金属 HHG 的量级增强分解为 Weyl 节点、Berry 曲率分布与非平衡载流子散射三类因素的归一化百分比贡献，这一三因素分解在现有公开工作中尚无定量结果。以 TaP 严格立方律与 Cd₃As₂ 裸膜幂指数构成方向相反的两条约束，外场增益与材料本征非线性被分开计入；分解按 type-I 与 type-II 节点分型分别标定而非跨型套用；X + Y + Z ≥ 95% 的闭合条件使分解结果具备自洽性检验。

（4）以 ZnO 与 MgO 两套非拓扑参照在双驱动基线下标定拓扑 HHG 探针的判别边界。ZnO 提供多通道竞争区的数据，MgO 提供纯对称性各向异性的扣除基准，两者在同一扫描协议下并行给出；阈值 R 与 T 在 800 nm 与 1800 nm 双基线下偏差均须小于 10%，双基线一致构成阈值有效的必要条件。
