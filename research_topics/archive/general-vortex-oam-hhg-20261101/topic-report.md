## 一、问题一句话陈述

一句话问题：在少周期 CEP 锁定涡旋驱动下，谐波拓扑荷偏离整数守恒律 l_q = q·l₀ 的连续量 l̄_q，其出现条件是由晶体反演对称性破缺决定、由 CEP 敏感的时间不对称决定，还是由非偶极展宽独立决定？

这是一道三择一的互斥归因题，而非开放式提问。判定设计为两条正交扫描线的交叉实验：固定材料、只扫 CEP，得 l̄_q(CEP) 的振幅 A_CEP；固定 CEP、只扫材料点群，得 l̄_q 的选择定则分量 A_sym。两者是否满足"同一 l̄_q 的可加分解"即为判据。该分解写作 l̄_q = A_sym + A_CEP + A_nd，其中 A_nd 为非偶极项，由束腰与强度两条杠杆组成的标定系列独立标定。分解成立且残差小于合成不确定度，则三通道份额可判；分解不成立，即三者不可分离，本课题如实报告为"主导项不可判"。

破缺量的可观测量定义是判据可测性的前提。拓扑荷 l_q 是整数，其偏离 l_q − q·l₀ 同样离散，无法连续振荡，因此整数表述下的"破缺随 CEP 呈 π 周期振荡"不可执行。改用角向强度分布的一阶角谐分量也不可行：理想拉盖尔-高斯涡旋的角向强度分布严格轴对称，一阶角谐分量为零、相位无定义；该分量度量的是谐波环偏离圆对称的椭圆化程度，与整数拓扑荷偏离并非同一物理量。

破缺量的定义还需先划定一处边界。Porras 等人（arXiv:2603.08263）指出，对一般时空光场，拓扑荷随谐波级次的标度并不等同于轨道角动量守恒，真正普适守恒的是换算光子数比例下的角动量（纵向、横向与内禀）。这意味着 l_q 与 l̄_q 的基线值并不必然为 q·l₀，而须由所驱动光场的时空结构确定。本课题把这一限定纳入破缺量的操作定义：基线值取理想基线处的实测 l̄_q，不作预设；破缺量是 l̄_q 与该基线之差。标度律的偏离与角动量守恒的偏离由此在定义层面被区分开。

本课题改以有限谱窗内占优拓扑荷通道的连续期望值 l̄_q 作为破缺量的操作定义。把第 q 阶谐波环的角向强度分布 I_q(φ) 作角谐傅里叶展开，取各拓扑荷通道的角谐权重 P(l)，定义 l̄_q = Σ_l l·P(l) / Σ_l P(l)。该量在理想基线处的取值与 q·l₀ 相符，可连续振荡，且与 arXiv:2607.23652 观测的"有限谱窗内主导拓扑荷通道"在物理内涵上直接对应。整数拓扑荷 l_q 仍由 astigmatic 变换后的亮瓣计数给出，作为独立于连续量的第二条通道，二者的一致性即交叉校验。全文以 l̄_q 指连续操作量，以 l_q − q·l₀ 指整数偏离量，二者不混用。

"时间破缺"在本课题中专指驱动场在时间维度上偏离严格周期对称，即少周期极限下包络的时间不对称使发射窗的相位不再以半周期为周期，从而让整数拓扑荷约束松动的现象。它不等同于偏振态的时间演化，

## 二、背景调研摘要（迁移自 rationale/文献链）

## （一）立项依据

### §1.1 研究意义：角动量作为独立自由度的转移规律

强场高次谐波产生（high-harmonic generation, HHG）是光与物质相互作用中高阶、非微扰的响应过程，谐波辐射的强度、相位与偏振携带了远快于光学周期的电子动力学信息。气体 HHG 领域自 2003 年 Niikura 等人[1]以关联波包对在阿秒尺度追踪分子核运动以来，已发展出以谐波谱为探针的飞秒与阿秒超快测量方法，涵盖原子价电子运动的实时观测与电子波函数的相干重构[2,3]。这些工作把时间分辨率推进到 100 as 量级，使"在单个光学周期内追踪电子"从理论推演变为实验事实。

2011 年 Ghimire 等人[4]用中红外激光驱动 ZnO 晶体，观测到非微扰的高次谐波辐射。此后固体 HHG 在 ZnO、GaAs、SrTiO₃ 等氧化物与 III-V 族半导体中被逐一建立，谐波谱呈现超出带隙的截止平台，产额随强度的标度偏离微扰理论预期，各向异性与偏振取向的依赖在块状晶体中被独立测量[26]。

为把这种复杂度转化为可控的探针，一组数值方法被建立起来。Ndabashimiye 等人给出固体中超越原子极限的谐波产生[5]，Wu 等人建立了基于布洛赫电子的半导体布洛赫方程模型[7]，Ghimire 与 Reis 的综述则勾勒了这一领域的整体图景[6]。

Vampa 等人提出的带间再碰撞半经典模型[8]、Li 等人的倒空间轨迹模型[27]与 Yue 与 Gaarde 的非理想再碰撞分析[28]进一步把电子动力学从波函数还原为可解释的轨迹物理。这些模型使固体 HHG 从"能否产生"的问题转变为"如何从中读出特定物性"的问题。

同一测量平台已支撑驱动光下的多带能带结构观测[29]与电子空穴相干性的探测[38]，应用一侧的拓展以涡旋谐波束的叠层成像为代表：Wang 等人[39]用携带轨道角动量的高次谐波对周期结构作高保真叠层成像，把谐波涡旋从待表征对象转为成像探针。本项目的选题位置即由这一图景界定：角动量作为独立自由度的转移规律，在气体侧已被确立，在固体侧刚被建立，尚未进入份额分配阶段。

轨道角动量（orbital angular momentum, OAM）为这一读出问题提供了新的可控维度。Allen 等人[9]于 1992 年指出，具有螺旋相位 Φ = lφ 的光场每个光子携带 lħ 的外禀角动量，与自旋角动量相互独立。OAM 与频率、偏振构成光的三个相互独立的自由度，可编码在单个光子或单个谐波光子上，使"同一个频率、同一个偏振、仅角动量不同"的两束光以内禀模式正交性原理上可无限区分。这一自由度在高次谐波中格外有意义：谐波频率由能带与驱动场共同决定，无法自由调谐，而拓扑荷 l 由非线性过程的角动量分配决定，原则上可以被整形与读取。

气体 HHG 中的 OAM 转移遵循简洁的标度律 l_q = q·l₀，即 q 阶谐波继承驱动场拓扑荷的 q 倍。

Hernández-García 与 Picón 等人[10]以数值方法证明携带拓扑荷的红外场驱动的高次谐波在传播后仍保有螺旋相位结构，给出该标度律的首个理论预言。Rego 等人[11]指出气体谐波中这一标度律在微扰区并不成立，须由再碰撞轨迹的非微扰扭量修正方能给出正确结果。Pisanty 等人[12]从环面纽结（torus-knot）角动量守恒出发给出理论解释，指出在旋转不变的原子势与偶极响应近似下，谐波发射轨迹在动量空间的缠绕数决定了拓扑荷传递关系，由此确立整条标度律的半经典选择定则。

## 标题

涡旋光束驱动的固体高次谐波：轨道角动量转移标度律的时间破缺与晶体对称性的角动量分辨层析

## 研究背景与动机

轨道角动量（OAM）是光场除频率、偏振之外的第三个独立自由度。气体高次谐波产生（HHG）中涡旋驱动满足简洁的守恒律 l_q = q·l₀，即 q 阶谐波继承驱动场拓扑荷的 q 倍，其成立依赖偶极近似——电子 excursion 远小于束腰。固体 HHG 中晶体各向异性、界面、缺陷与强自旋-轨道耦合原则上都为 OAM 重分布提供通道，守恒律是否成立长期悬置。气体侧的奠基工作是 Pisanty 等给出的环面纽结（torus-knot）角动量守恒理论，其结论建立在旋转不变的原子势与偶极响应之上（Phys. Rev. Lett. 122, 203201 (2019)）。

2026 年这一格局被三组工作改写。其一，"Twisting harmonics"（arXiv:2601.12743）在 ELI-ALPS 用螺旋相位板把飞秒高斯束转为中红外拉盖尔-高斯涡旋。所用参数为束腰约 65 μm、脉宽约 47 fs、单脉冲约 20 μJ、峰值强度约 6.4×10¹¹ W/cm²、重频 100 kHz。该工作在 ZnO、GaSe、MgO、Si 与单层 WSe₂ 的透射与反射两种几何中都验证了严格的 l_q = q·l₀，标度律对晶体对称性、带隙与强自旋-轨道耦合表现出极强鲁棒性。驱动端的可行性已有先例：Granados 等（arXiv:2512.19412）以静态空间整形策略在 3.2 μm 波段生成少周期 Bessel-Gauss 涡旋与完美光学涡旋，在 ZnO 与 GaSe 中驱动强场高次谐波，验证谐波继承驱动光结构并满足 l_q = q·l₀ 的放大关系，证明少周期中红外涡旋与固态强场驱动可在同一光路下共存。

其二，Granados 等（arXiv:2607.23652）证明守恒律并非铁律：约 1.5 光周期的少周期涡旋驱动 3.2 μm ZnO 时，l_q = q·l₀ 被载波包络相位（CEP）重新洗牌。该文报告拓扑荷在相邻整数值间随 CEP 切换，且切换只在反演对称性破缺且谐波发射本身对 CEP 敏感的条件下出现；其数值分析把成因归于 CEP 控制的谱权重在谱窗内重叠谐波阶次间的再分配。其三，Albar 与 Rubio 组（arXiv:2503.14982）用完整最小耦合处理发现，涡旋几何会主动放大磁偶极与电四极等非偶极修正，非线性偶极动力学在正交于偏振与传播的方向上长出分量，且该对称性破缺在偶次谐波中尤为明显。

## （三）研究方案、特色与创新、预期研究成果

### §三.1 总体技术路线

研究方案由一条自洽的时序链构成：先把少周期 CEP 锁定涡旋源的输出标定到可追溯的参数点，再把材料矩阵上的谐波环读数转换为可连续采样的破缺量，随后用两条正交扫描线加一条束腰系列完成三通道份额的仲裁，最后把已分离的对称性分量转成层析协议。四个环节的产出依次是前一个环节的输入，任何一环的产出不确定，后续环节的判据便失去可执行性。

理论正演置于链条首位。含最小耦合修正的 SBE–传播统一模拟在实验相图启动前完成计算，输出两件事：破缺相图的预言基准，以及非偶极项 A_nd 的误差预算来源。这一位置安排不是流程偏好，而是由判据结构决定的。A_nd 之所以能够被独立标定，前提是它的量级与不确定度在实验投入之前已经给出。若理论正演滞后于数据采集，非偶极通道就只能作为事后解释项被引入，三通道仲裁随之失去统计基础。

驱动端采用少周期 CEP 锁定中红外涡旋源。选这一路线的理由有两层。Granados 等人[30]以静态空间整形策略在 3.2 μm 波段生成少周期 Bessel-Gauss 涡旋与完美光学涡旋，并在 ZnO 与 GaSe 中驱动强场高次谐波，谐波继承驱动光结构并满足 l_q = q·l₀ 的放大关系。装置层面没有待验证的环节。周期数少于 2.5 之后包络不再以半周期为周期重复，发射窗相位随 CEP 平移，CEP 通道才有可观测的物理来源。在 3.2 μm 这一中红外波段，样品在强场下的载流子散射与损伤累积被短脉冲时长压制，谐波发射仍以非微扰的场驱动电子动力学为主导。

测量端采用拓扑荷与角向分辨并行的读出方案。整数拓扑荷由 astigmatic 变换后的亮瓣强度极小值计数给出，连续破缺量由谐波环角向强度分布的角谐傅里叶展开给出，两条通道在同一帧数据上一并提取。选择 astigmatic 变换而非干涉、轴锥或旋转多普勒等方案，是因为它无需参考光束，把方位相位结构映射为强度条纹，因而可以在谐波波段直接成像，且不引入额外的干涉可见度标定环节。Flores-Cova 等人[34]给出的闭式分析进一步把这一方法从 Laguerre-Gaussian 光束推广到 Bessel-Gauss 与完美光学涡旋。其结论给出极小值计数与拓扑荷之间的普适对应：变换后条纹的相位累积扫过 ℓπ，故极小值数 N_min ≈ ℓ，与整数拓扑荷一一对应。该工作另指出一项限制：像散变换只能给出中心模及其拓扑荷，无法分辨振幅不等的模式叠加，这正是本项目必须保留连续量 l̄_q 的原因：角谐权重 P(l) 的角向分布能给出各通道的相对份额，而变换图只给出占优通道。

样品矩阵沿两条正交轴展开：材料轴取 ZnO 与 GaSe 为非中心对称、MgO 为中心对称、单层 WSe₂ 为强自旋-轨道耦合的低维情形；几何轴取透射与反射两种。ZnO 与 GaSe 均在透射几何下测量，其 A_sym 符号一致性的检验因而不含几何自由度；Si 与单层 WSe₂ 在反射几何下测量，前者因谐波体内自吸收强，后者因穿透深度过浅，均不适配透射几何。Si 为非晶短程有序材料，无晶体点群可供对称性判据引用，不进入判据链；其带隙 1.6 eV，三阶与四阶光子（1.16、1.55 eV）落在带隙内，主网格七个阶次单元按产额与鲁棒性记录计入，[18] 已在反射几何对 Si 实测谐波并验证标度律。MgO 因而是唯一的晶态中心对称材料，单独承担 A_sym = 0 的对照，与 Si 的角色分工在数据表中分列。WSe₂ 的自旋-轨道劈裂 513(10) meV 检验极端情形下标度律的鲁棒性，该数值不作为判据输入，只作为极限情形的说明。
