# 内测系统（影子用户）

## 触发条件
用户输入包含以下关键词任一：
内测、测试、回归测试、运行测试、self-test、self_test、test、影子用户、健康检查、冒烟测试、验证一下、测一下、跑测试

## 上下文注入
你掌握 LinSai-CoPilot 的轻量化内测系统。当用户要求运行测试或验证系统状态时，按以下规则响应：

### 系统能力
- **全量回归测试**：`python3 scripts/self_test.py`
- **分维度测试**：
  - `--module`：仅核心模块（会话、知识库、技能、任务、记忆、上下文）
  - `--scenario`：仅场景剧本（5 类影子用户端到端交互）
  - `--persona`：仅人格一致性抽检（静态检查人格注入文件）
- **JSON 输出**：`--json` 用于程序化解析
- **程序化调用**：`from self_test import run_tests; result = run_tests()`

### 关键特性
- **零污染**：所有测试在临时隔离目录运行，结束后自动清理，不触碰真实会话/任务/记忆
- **零成本**：不调用任何 LLM API，纯本地代码逻辑验证
- **速度快**：全量 85 个检查点通常在 0.05-0.1 秒内完成
- **自动发现**：在 `scripts/tests/` 下新增 `test_*.py` 文件即可自动纳入回归

### 测试覆盖（当前 85 个检查点）
| 维度 | 数量 | 内容 |
|------|------|------|
| 核心模块 | 31 | 会话 CRUD、知识库搜索/别名/触发、技能匹配、任务流转、记忆更新、上下文预算 |
| 场景剧本 | 16 | 并肩工作（HHG 实验）、深度对话（PRL 拒稿）、快速验证（量纲检查）、任务驱动（DFG 截止提醒）、主动感知（压力检测） |
| 人格一致性 | 38 | 身份锚点、章节结构、表达 DNA、AI 协作哲学、价值层级、能力边界、反模式清单 |

### 适用边界
- ✅ 适用：每次修改核心模块后快速验证"没坏东西"
- ✅ 适用：重构后确认接口兼容性
- ⚠️ 局限：不测 LLM 输出质量（人格风格、表达自然度）
- ⚠️ 局限：不测 Web UI 前端交互
- ⚠️ 局限：不测长会话性能（>50 条消息）

## 工作流
1. **确认范围**：询问用户是全量测试还是针对某一维度（模块/场景/人格）
2. **执行测试**：调用 `scripts/self_test.py`（或对应过滤参数），获取结构化结果
3. **汇报结果**：给出通过/失败总数、各套件耗时、失败项详情
4. **给出建议**：如有失败，指出最可能的代码位置；如全过，确认系统状态健康
