### C. 研究方案（scheme.md）

| ID | 意见 |

| [R1-04\|critical] §1 + references｜Liu 2017 复现基频口径存疑｜**问题**：原文写"MoS₂ 上复现 Liu 等人[3]已发表的 HHG 阶次结构（基频 0.30 eV、谱窗第 6–13 阶）"。Liu 等[3] Nat. Phys. 2017 报告的 MoS₂ HHG 实验使用 ~1.7 μm OPA（单光子能量约 0.73 eV），与"基频 0.30 eV、谱窗 6–13 阶"在数值上不一致。如确为 0.30 eV 基频则谐波光子能量落在 6×0.30=1.80–13×0.30=3.90 eV，与 MnTe 直接带隙 1.3 eV 不在同一窗口，机制层论证的物理关联需重新论证。｜**建议**：检索核实 Liu 等[3] 报道的 MoS₂ HHG 实测基频与谱窗上限，按实测值重写"基频 = ? eV、谱窗第 ?–? 阶"；如基频确为 0.30 eV，则应在 §2 物理入口处明确三光子能量 ~0.90 eV 与 MoS₂ 带隙的关系，不应沿用 MnTe 主体系的 1.23 eV 论述。 |
| [R1-05\|major] §5.4 SOC 取值与综合区间表述歧义｜**问题**：原文写"g 波自旋劈裂综合取值 0.3–0.8 eV"，但 §5.4 同时报告沿 Γ–K 节点面内 SOC 能隙约 0.3 eV、节点面外一般动量点 g 波劈裂最大 0.8 eV。综合区间下限 0.3 eV 实际来自 SOC 而非 g 波劈裂最小值，下限口径混入两类物理量；表中也以"综合取值 0.3–0.8 eV"统一表述，会令读者把 0.3 eV 误读为纯 g 波劈裂量级。｜**建议**：将 SOC 与 g 波劈裂两套数值拆分列表——"SOC 能隙（Γ–K 节点面内）≈ 0.3 eV" 与 "g 波劈裂（节点面外最大）≈ 0.8 eV"；"综合取值 0.3–0.8 eV"仅作为 SOC/劈裂比计算引用基础，不应作为统一物理量。 |
| [R1-06\|major] §5.4 SOC/劈裂比 = 1.0 边界归属｜**问题**：原文写"比值上端 = 0.3/0.3 = 1.0...上端触及与 SOC 主导区的边界（1.0）"，但未明确比值 = 1.0 的 MnTe 实验观测点落入过渡区还是 SOC 主导区。分档判据 < 0.3 / 0.3–1.0 / > 1.0 在边界处会出现判据冲突（同一比值归入何档未规定）。｜**建议**：明确 0.9 < 比值 < 1.0 区间采用双模型交叉验证（过渡区一阶 SOC + 主导区相对论紧束缚），并在 §1 数据处理 SOP 中加一条"边界处两模型偏差 > 5% 则取平均值，否则按主导判据归类"。 |
| [R1-07\|major] §1 Fisher 阈值缺乏统计依据｜**问题**：原文写"三重独立观测约束下预期条件数 κ < 10²"，未给出 κ < 10² 与可辨识性之间的统计联系。一般 Fisher 信息反演的可辨识性条件由 Cramér-Rao 下界给出 σ ≥ 1/√I，与 κ 阈值无直接换算关系。10² 阈值的物理意义需明确。｜**建议**：补充 κ < 10² 阈值的推导：建议以单参数 1-σ 反演精度的 Cramér-Rao 下界为锚，κ < 10² 时联合反演后验标准差小于单参数独立反演后验标准差的 1.5 倍；引用 Vehtari 等[arXiv:1903.08008] 的层级判据给出具体数值边界。 |
| [R1-08\|major] §5.1 MoS₂ 对照体系 valley 各向异性未扣除｜**问题**：原文写 MoS₂ 对照体系承担"零磁畴 + 零自旋 + 强可分辨带间结构"三重角色，但单层 MoS₂ 在 K/K' 谷具有显著 valley-各向异性（贝里曲率符号相反、激子谷选择定则差异显著）。HHG 在单层 MoS₂ 中已实测到 valley-各向异性响应，"零非磁各向异性"假设不严格成立。｜**建议**：在对照测量中明确增加 MoS₂ valley-各向异性本底测量（基态 + 顺磁相处本底），把 valley-各向异性作为第二本底与 g 波对比区分开；或选择 MoS₂ 体相（块体 2H 相，谷效应被对称性平均）作为对照，并相应调整判据。 |
| [R1-09\|major] §3 MnTe 单畴 SHG 实时筛选口径过紧｜**问题**：原文要求"解理后 30 分钟内完成 SHG 实时成像筛选单畴区域。机械解理获得原子级平整表面（尺寸 ≥ 500 μm × 500 μm），解理面晶向以 X 射线劳厄背反射标定"。500 μm 范围内 SHG 实时成像的空间扫描 + 劳厄背反射标定的时间成本未核算；30 分钟限制不明确是真空下还是大气下；MnTe 解理面空气氧化的动力学速率需检索核实。｜**建议**：把 30 分钟约束改为可操作版本（如"真空转移链下不超过 4 小时"），并以原位 SHG 像素密度（如 5 μm/像素）反算全 500 μm × 500 μm 扫描时间，或限定扫描区域（如 200 μm × 200 μm 单畴筛区）以匹配时间预算。 |
| [R1-10\|minor] §3 反铁磁自旋翻转场公式口径｜**问题**：原文写"H_SF ≈ (2H_E·H_A)^(1/2)...
