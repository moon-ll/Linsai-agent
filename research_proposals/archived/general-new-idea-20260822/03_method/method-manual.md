## 方法 1：紧束缚 + Houston 基自旋分辨 HHG 正演

### 1.1 算法步骤

**Step 1：能带构造** 8 带（4V+4C）紧束缚模型，k 点默认 20³、收敛 30³。能带参数取自 ARPES（Krempaský 2024；Osumi 2024），与 §0 判据表一致。通用 TB 构造见 `knowledge/wiki/methods/tight-binding-model.md`。

**Step 2：g 波自旋劈裂项 H_alt(k)** MnTe（α 相、NiAs 型六方）属 P6₃/mmc 空间群：

```
H_alt(k) = Δ(k) · σ_z ⊗ f(k)
```

- Δ(k)：0.3–0.8 eV（§0 判据表）。
- f(k)：满足六方对称的解析函数，**三重方位角依赖**（θ → θ + 2π/3 周期性，与 Y₄⁻³ 型四组节点面结构一致，节点面处变号）。
- θ 反演目标 0°–360° 连续变量。

零阶模型不显式纳入 SOC 哈密顿量。SOC 项构造与带内/原子双口径见 §1.6。

**Step 3：Houston 基含时演化** 覆盖 2–3 个光学周期，步长 5 as（收敛 2.5 as）。二阶劈裂算符 U_I(t+Δt,t)。计算量级：8 带 / 20³ / 5 as ≈ 1 CPU·h（单节点数十核数分钟至 1 小时）。

**Step 4：谐波提取** 合成频谱 I(Ω) = |P(Ω) + J(Ω)/Ω|²（P 带间极化、J 带内电流）。自旋通道分别统计 I_↑/I_↓；CD = [I_LCP - I_RCP]/[I_LCP + I_RCP]；椭圆率 ε = arcsin(S₃/S₀)。

### 1.3 收敛性测试流程（双重硬门控）

**程序内部数值精度测试（先于 MoS₂ 复现通过）：**

1. 时间步长 10 → 5 → 2.5 as 三档，低阶奇次（3/5/7 阶）相对强度变化 < 2%。
2. k 点密度 15³ → 20³ → 30³，谐波总产额变化 < 5%。
3. 能带数 6V+6C vs 8V+8C，低阶奇次差异 < 3%。
4. **MnTe 顺磁相自旋简并基准（第二道硬门控）**：Δ=0 极限下偶次谐波 < 1%。不通过 → Hamiltonian 对称性审查，不进入 SOC 扫描。

**MoS₂ 文献复现（第一道硬门控，执行 §4.3）：** 0.30 eV 基频复现 Liu 等（2017）6–13 阶谱窗，偏差 ≤ 10%；切换至 3 μm 验证装置系统响应。两步均通过 → 进入 MnTe。

两道门控逻辑独立：MoS₂ 复现失败 → 装置或算法问题；MnTe 顺磁基准失败 → Hamiltonian 构造问题。

### 1.4 模型验证与对标

- **MoS₂ 对照体系**（§4）：能带参数替换为 Liu 2017 / Kang 2021 数据集；6–13 阶偏差 ≤ 10%；切换 3 μm 验证装置系统响应。
- **MnTe 顺磁相自旋简并基线**：Δ=0 极限下偶次谐波 < 1%；若 > 1% → Hamiltonian 对称性不满足 P6₃/mmc 空间群要求。

### 1.5 风险评估与替代方案

| 风险 | 触发判据 | 替代方案 |
|------|----------|----------|
| SOC 不可忽略 | ξ_SOC_in-band/Δ > 0.3（§1.6） | 一阶 SOC 修正或 Hamiltonian 扩展；带内 SOC 上端触发 3→5 μm 切换 |

### 1.6 SOC 边界判据与扩展条件

**两套 SOC 取值评估框架：**

| 取值 | 来源 | 量级 | ξ/Δ | 适用角色 |
|------|------|------|------|----------|
| 原子 SOC | Te 5p | 0.4–0.5 eV | 0.5–1.7 | 强场外推校验对照 |
| 带内有效 SOC | Osumi 2024 Γ–K 方向能隙 | ~0.3 eV | 0.375–1.0（全区间） | **主模型锚定** |

物理来源：原子 SOC 在不参与节点面对称性的轨道分量上被部分抑制，进入带内动力学后表现为约 0.3 eV 有效能隙。零阶 + 一阶修正框架在过渡区 0.3 ≤ ξ/Δ ≤ 1.0 内可适用。

**全区间比值计算（带内 SOC = 0.3 eV 固定）：** Δ = 0.8 eV（下端）→ 0.375；Δ = 0.3 eV（上端）→ 1.0；坐标方向与 Δ 相反。Γ–K 方向窄化口径并存：节点面内非相对论劈裂 = 0，SOC 能隙 ≈ 0.3 eV。R1 灵敏度分析扫描空间用全区间比值。

**判据规则（按 ξ_SOC_in-band/Δ）：**
1. **零阶区**（< 0.3）：SOC 视为微扰，直接用 §1.1 Step 1–4。
2. **过渡区**（0.3 ≤ ≤ 1.0）：g 波偏振各向异性图样被部分修正，需加一阶修正 H_SOC = ξ_L·L·σ（仅保留 Te 5p L_z 与 σ 耦合）；0.7–1.0 子区间按一阶 + 相对论性紧束缚双计算交叉验证。
3. **SOC 主导区**（> 1.0）：节点面结构被破坏，必须使用相对论性紧束缚（含完整 λ_L·σ·L 项），节点面重定位。

实际预期落入过渡区，R1 灵敏度分析须将 ξ_in-band 作为扫描参数（0–0.6 eV、步长 0.1 eV）。

**双工作点切换（§7 一致）：** SOC 0.2–0.3 eV（下端）→ 3 μm；SOC 0.3–0.6 eV（上端）→ 5 μm。3 μm 调制深度 < 可分辨窗口下沿（差分目标值 1% 的 50% = 0.5%）→ 启动 5 μm 预计算 → 5 μm 调制深度 > 3 μm 时切换。

**SOC 扩展 Hamilton 构造步骤：**（1）基函数扩展为含 L_z 的轨道角动量基（Te 5p: m_L = -1, 0, +1）；（2）构造 SOC 矩阵元 ξ_L·⟨L·S⟩·δ·δ；（3）对角化扩展 Hamiltonian；（4）重求 H_alt(k) 有效节点面；（5）重复 Step 3–4 含时演化；（6）零阶与扩展模型差异 < 5% 视为零阶可用。

## 方法 2：MnTe 自旋/偏振分辨 HHG 实验

### 2.1 样品准备 SOP

1. 机械解理（氮气手套箱内 Scotch tape），解理面积 ≥ 500 × 500 μm；AFM 抽检台阶 < 5 nm、暴露空气 < 30 s。
2. Laue 背反射确认 (001) 面，与晶轴夹角 < 2°。
3. SQUID FC/ZFC 确认 T_N ≈ 310 K（转变宽度 < 5 K）。
4. SHG 确认磁点群对称性、筛除多畴区域。
5. 解理后 30 min 内完成 SHG 实时成像（超 30 min 表面氧化层 ~1–2 nm 破坏磁畴衬度）；单畴区域 ≥ 200 μm 量级覆盖焦斑（典型 50–100 μm）。
6. 安装：镀金铜样品托、EpoTek H20E 银胶点固 4 角、Al wire 键合 3 点；T_N 附近用 LakeShore CX-1050 校准热电偶，偏差 < 1 K。

**块体 MnTe 磁畴尺寸预研实测（§5.1 难点一动作）：** 薄膜（Amin 等 PEEM，30 nm α-MnTe(0001)/InP(111)A）畴尺寸 100 nm 至 10 μm，不可外推至块体。预研动作：解理后 30 min 窗口内对 ≥ 3 解理面做 SHG 成像，每区域 ≥ 500 × 500 μm；同步 Laue 晶向 + 10/300 K 各扫一组。若典型畴 < 50 μm → 触发 SHG 实时选区测量；若 ≥ 100 μm → 焦斑直接落入单畴。

### 2.2 驱动激光与光路

| 参数 | 目标值 | 容许范围 |
|------|--------|----------|
| 中心波长 λ | 3 μm | ±50 nm |
| 脉冲宽度 τ | < 25 fs | < 30 fs 上限（FROG/SPIDER） |
| 峰值强度 I | 1 TW/cm² | 0.5–2 TW/cm² |
| 重复频率 | 1 kHz | — |
| 焦斑直径 w₀ | 50 μm | ±5 μm（CCD 诊断） |
| 时间抖动 | < 30 fs | < 50 fs |

光路：激光 → 能量衰减（半波片+偏振片）→ 分束监测（98/2）→ 延迟线 → 偏振调制（零级 1/2 + 1/4 波片）→ 超导磁体入口窗 → 样品室 → 偏振分析器（消光比 > 10⁴）→ 光谱仪（0–20 eV）→ ICCD/PMT。

**单脉冲能量估算：** 按高斯焦斑 1/e² 半径下有效面积 A_eff = πw²/2、τ ≤ 30 fs 上限口径，按焦斑直径 w 取 50 µm（下沿）与 100 µm（上沿）双界分解：

- w = 50 µm：0.5–2 TW/cm² → 单脉冲能量约 0.15 µJ（下沿）。
- w = 100 µm：0.5–2 TW/cm² → 单脉冲能量约 2.4 µJ（上沿）。

合并 0.5–2 TW/cm² 强度窗口 × w=50–100 µm 焦斑窗口，单脉冲能量工作区间为 0.15–2.4 µJ，与申请书 §3 驱动激光端口径一致。该口径基于 1/e² 强度半径下的有效面积，与按全峰斑（2w）面积换算的数值不同，特此声明，避免与 §2.4 产额 A 级估算按全峰斑口径串扰；1 kHz 重频下平均功率为 0.15–2.4 mW 量级（毫瓦量级）。

**圆二色性副检验：** 1/4 波片快轴 ±45° 切换，左右圆各 100 个脉冲差分。纯交变磁极限下 CD_n = 0（Werner 2024 选择规则）；SOC 参与时按 Werner 等预期非零。R2 测 |CD_n| < 1% 视为自洽性通过；> 1% 触发 SOC 区间重扫描。

### 2.3 信号提取（磁场反转差分主信号维度）

#### 2.3.1 磁场反转差分流程

1. +7 T 驻留 5 min（2 min 磁化稳定 + 3 min 采集），采集 0–20 eV 谱（步长 0.1 eV），积分 30 s，重复 5 次。
2. 切换顺序随机化：+7 → -7 → +7 → -7 ... 每 4 对为一组随机排列；慢漂移在差分中抵消到一阶。
3. -7 T 重复驻留 + 采集。
4. ΔI = I(+7T) - I(-7T)；相对差分 |ΔI|/I_avg（I_avg = [I(+7T)+I(-7T)]/2）。
5. 反铁磁相（10–290 K）相对差分 ≥ R1 预计算目标值 + SNR_diff ≥ 3:1。

**B-线性偶次通道的物理前提：**
- 奇数阶 ±B 谱形不变，偶数阶 ±B 相位反向，差分信号与 B 成正比。
- 共线反铁磁奈尔矢量受晶格钉扎，H_SF ≈ √(2H_E H_A) ~ 10 T 量级（H_E ~ 10² T、H_A ~ 1 T），高于 ±7 T 工作磁场，奈尔矢量至多小幅倾斜。
- 目标值不确定传递：SOC 区间 0–0.6 eV 扫描 → 目标值在 0.5%–5% 波动；R2 验收取最稳健温度点（10 K 或 50 K）与 R1 中位数对比，偏差 > 50% 触发 §1.6 重扫描。

#### 2.3.2 差分采集驻留与统计基线（本轮新增）

超导磁体 ±7 T 间切换受失超保护限制为分钟级（典型 60–120 s），不依赖秒级快速切换。差分采用双态驻留采集：每磁场态驻留 ~5 min（含 2 min 磁化平衡 + 3 min 采集）；正负场对为一个差分基本单元；交替顺序随机化以扣除慢漂移；探测端 ICCD / 单光子计数（暗计数 < 0.1 counts/s）。

**产额标定基准阶与统计基线（以第 11 阶为产额标定基准阶，与 §2.4 A 级下限对齐）：**

驻留估算取第 11 阶作为产额标定基准阶，与 §2.4 谐波产额外推基准统一（ZnO 第 11 阶 10²–10³ counts/s @ 3.25 μm / ~1 TW/cm²，Ghimire 2011；MoS₂ 第 11 阶 10³–10⁴ counts/s @ 3 μm / ~1 TW/cm²，Liu 2017）。MnTe 预期第 11 阶产额落入 §2.4 A 级区间 10²–10⁴ counts/s，对应 §0 判据表 R2 产额 A 级口径；R2 差分目标 ≥ 1%（暂用，10 K 测，§5.3 预计算）即在该基准阶上读取差分相对强度。驻留估算的计数率下限 10² counts/s 与 §2.4 A 级下限直接对齐：低于该下限即触发 §2.4 B 级三层微调预案，不进入 R2 差分采集链。

**驻留与重复次数的统计估算（第 11 阶基准、计数率下限 10² counts/s、差分目标 ≥ 1%）：**
- 单次 60 s 积分：~6×10³ 光子、泊松涨落 ~1.3% → 单谱对差分 SNR ≈ 0.5。
- 累计 30 次谱平均（~6 个差分单元）越过 §0 SNR ≥ 3:1 阈值。
- 计数率升至 10³–10⁴ counts/s 时，所需平均次数按 √N 律降至个位数，单点差分采集压缩到 10 min 量级。

**输出格式：** ΔI_q(B)/I_avg,q(T) 差分相对强度谱；顺磁相（320–340 K）差分基线在数据处理中扣除，反铁磁相各温度点差分值与其对照即磁敏感信号。

#### 2.3.3 自旋通道分离

四分之一波片快轴 α = 0°/45°/90°/135° 各采一谱，四组谱联合解算各阶谐波的 Stokes 参数 (S₀, S₁, S₂, S₃)，每方位角积分 30–60 s、重复 10–30 次，10² counts/s 计数率下单阶统计涨落降至百分之几，足以分辨百分量级的偏振调制（与 §2.7 消光比 > 10⁴ 同链路验收）。

**Stokes 解算约定（与 §2.7 偏振分析器方位角标定同链路）**：
- S₀ = I(0°) + I(90°)，S₁ = I(0°) − I(90°)，S₂ = I(45°) − I(135°)，S₃ = I(σ⁺) − I(σ⁻)。
- 四组方位角 I(α) 取同一波片旋转序列的脉冲平均计数率；σ⁺/σ⁻ 由 α = ±45° 测得（同一波片快轴 ±45° 即等效圆偏振基矢）。
- 椭圆率角 ε_q 与螺旋度 h_q 并列提取，与申请书 §3 信号提取端「椭圆率角 ε_q + 螺旋度 h_q 阶次序列」表述对齐：
  - 椭圆率角 ε_q ≡ arcsin(S₃/S₀)，单位 rad；取值范围 [−π/4, π/4]，±π/4 对应纯圆偏振、0 对应线偏振。
  - 螺旋度 h_q ≡ sign(S₃) = ±1，按发射光场旋转方向区分左/右手性；与 ε_q 同号即同旋转方向，区别在于 ε_q 量化偏振态偏离线偏的程度、h_q 仅给符号。
  - 偏振度 P_q = √(S₁² + S₂² + S₃²)/S₀ ∈ [0, 1]，作为偏振态纯度的辅助量；P_q → 1 即完全偏振，P_q ≪ 1 触发 §2.3.4 SNR_diff < 3:1 边界。
- 各 q 阶输出 (ε_q, h_q) 二元序列；该序列是 §1 自旋纹理 → 偏振图样映射的唯一可观测量，序列跨 T_N 的变号是自旋极化翻转的直接读出。
- 椭圆率 ε_q 连续可读、h_q 仅取 ±1，两者在 SOC 关闭极限下应给出 h_q = 0（对称性禁戒，见 §2.2 副检验），SOC 参与时按 Werner 等[16]选择规则非零。

**关键参数（带单位）**：
- 波片快轴方位角序列：{0°, 45°, 90°, 135°}，机械重复性 ±0.5°。
- 偏振分析器消光比：> 10⁴（§2.7 验收）。
- 单方位角积分：30–60 s；重复 10–30 次；单方位角总积分 ≤ 30 min。
- 计数率下限：10² counts/s（单阶）；统计涨落 < 5% 所需单方位角最小积分 t_min = 100/(rate·P_q²) s。
- (ε_q, h_q) 阶次序列输出格式：CSV，列为 q, ε_q [rad], σ_ε_q, h_q, P_q, σ_P_q。

**验证方式**：
- 已知偏振态标定：实验前以线偏振入射做方位角扫描，按 §2.7 余弦平方拟合验证 ε_q ≈ 0、h_q 与椭圆率旋转方向一致；偏差 > 5% 触发波片延迟校准。
- 顺磁相内参基准：320–340 K 顺磁相 5 点（§2.5）应给出 h_q = 0 的对称性基线（自旋简并下 CD-HHG 禁戒），与 §2.2 副检验一致；非零 h_q > 0.5 触发装置偏振效率核查。
- 跨 T_N 翻转判据：280 K / 310 K / 330 K 三点 ε_q 序列符号变化（h_q 翻号）即磁有序敏感性的直接读出，与 §2.5 跨 T_N 谱形变化共同构成可辨识性证据。

**风险与替代方案**：
- 风险 1：四方位角序列对慢漂移（温漂、激光功率起伏）敏感 → 替代：每 4 个方位角循环内插时间戳，扣除线性漂移；漂移 > 5% 触发 §2.7 重校准。
- 风险 2：P_q ≪ 1（消光比不足或多畴平均）→ 替代：偏振度降级为辅助通道，主分析只取 h_q 序列；不达 → §2.3.4 SNR 边界界定。
- 风险 3：单方位角 30 min 内计数不足 → 替代：跨方位角共享同一参考谱（如 0° 重复测量），用相对变化代替绝对值；触发 §2.4 B 级微调（延长积分 / 提驱动 / 改低温工作点）。
- 替代方法（信号物理量保持不变）：绕开 Stokes 四参数解算，以左/右圆直接差分 CD_q ≡ 2(I_σ⁺ − I_σ⁻)/(I_σ⁺ + I_σ⁻) 给出与 h_q 等价的符号信息；该路径是 §2.2 圆二色副检验主通道，本小节保留 Stokes 全解算以便 ε_q 连续可读。

**方法页溯源**：圆二色/偏振分辨 HHG 作为对称性、valley 选择定则与 Berry 曲率选择性探针，CD-HHG 按发射螺旋度分解构造谱学特征（参数依据 `knowledge/wiki/methods/circular-dichroism.md` 原理段与代表作 1807.01616）。

#### 2.3.4 SNR 评估方法

- **差分 SNR**（项目主判据）：SNR_diff = |ΔI_signal|/σ_diff，σ_diff 为差分谱谐波峰两侧 3 像素标准差。
- **峰值 SNR**（辅助）：SNR_peak = I_peak/σ_bg；SNR_peak ≥ 10 是 SNR_diff ≥ 3 的必要条件。
- 若 SNR_diff < 3:1 → 触发边界界定，不进入反演。

### 2.4 谐波产额量级外推与 A/B/C/D 分级触发

**外推基准：** ZnO 3.3 eV / 3.25 μm / ~1 TW/cm² 第 11 阶 10²–10³ counts/s（Ghimire 2011）；MoS₂ 1.3 eV / 3 μm / ~1 TW/cm² 第 11 阶 10³–10⁴ counts/s（Liu 2017）；MnTe 预期 10²–10⁴ counts/s。按 1 kHz 折算单脉冲约 0.1–10 光子。定量缩放尚无直接文献，以预研实测标定。

**预研标定分级触发：**

| 级别 | 实测产额 | 触发动作 |
|------|----------|----------|
| **A 级** | 10²–10⁴ counts/s | SNR ≥ 3:1 路径成立，进入 R3 反演 |
| **B 级** | 10 ≤ < 10² counts/s | 三层微调（见下） |
| **C 级** | < 10² 经微调仍不达标 | No-Go，不投入 R3 资源 |
| **D 级** | < 10 counts/s | 极端情形，界定探测能力上限 |

**B 级三层微调预案：**（1）提驱动强度至 2 TW/cm² 上限（同步测功率定标曲线，给出烧蚀阈值安全余量）；（2）延长积分时间至 60 s/磁场态；（3）改用低温工作点 10–50 K。任一项使产额回到 A 级即进入 R3；前后同时采集 I_HHG(I_drive) 与 I_HHG(T) 两条标度曲线，鉴别产额偏低物理来源。

**功率定标曲线测量细则：** 驱动强度 0.5–2 TW/cm²、步长 0.25 TW/cm²（5 点）；温度 10–340 K 按 §2.5 协议 24 点。

### 2.5 温度扫描协议

| 区间 | 步长 | 点数 | 物理目的 |
|------|------|------|----------|
| 10–290 K | 20 K | 15 | 反铁磁有序相（强磁有序） |
| 300–320 K | 5 K | 5 | 跨 T_N ≈ 310 K 加密 |
| 320–340 K | 5 K | 4 | 顺磁相自旋简并基线 |
| **合计** | — | **≥ 24** | **顺磁相 ≥ 5 点** |

每个温度点等待 ~5 min 热平衡（±0.5 K 后起算），依次完成谐波谱 + 偏振序列 + 磁场差分，单点 0.5–3 h；一轮温度扫描累计约 2–9 工作日，计入日检与复测裕量按 1–2 周机时预算。

**跨 T_N 谱形变化作为磁有序敏感性的直接读出：** 跨 T_N 谱形变化曲线 ΔI_n(T)/I_n(T>T_N) = [I_n(T<T_N) - I_n(T>T_N)]/I_n(T>T_N) 直接对应 g 波自旋劈裂的磁有序敏感性，是自旋极化符号翻转阶次序列的提取基础。

**预期数据形态与内参基准定位：**
- **温度-阶次二维谐波强度谱 I_q(T)：** 阶次 q 覆盖奇偶至截止阶次（按 3 μm 驱动 0.41 eV 基频估算截止约第 13 阶），温度 T 为表 1 所列 24 点网格（10–290 K 步长 20 K 共 15 点、300–320 K 步长 5 K 共 5 点、320–340 K 步长 5 K 共 4 点）。该谱是磁相变区间阶次结构重排的直接观测载体：反铁磁相 I_q(T<T_N) 与顺磁相 I_q(T>T_N) 列向对比即可读出偶次谐波萌发与奇偶强度比反转。
- **椭圆率角序列 ε_q(T)：** 由 §2.7 Stokes 解算给出的各阶椭圆率角 ε_q = arcsin(S₃/S₀)，对每个 T 点取一条阶次序列。预期形态：顺磁相全阶次 ε_q ≈ 0（自旋简并下偏振各向同性）；反铁磁相偶次阶 ε_q ≠ 0、奇次阶保持近零，与 g 波自旋纹理对偏振通道的对称性选择一致。
- **螺旋度序列 h_q(T)：** 与 ε_q 同步解算的螺旋度阶次序列。预期形态：顺磁相 h_q = 0（CD-HHG 禁戒于自旋简并极限），反铁磁相按 Werner 等[16]选择规则出现非零 h_q 且奇偶交替。三组数据 I_q(T)、ε_q(T)、h_q(T) 共轴同采于同一温度扫描协议，无附加机时开销。
- **顺磁相内参基准定位（315–340 K 自旋简并窗口）：** 表 1 中 320–340 K 共 4 点；为满足"≥ 5 点"判据，将跨 T_N 加密段 300–320 K 中 315 K、320 K 两点同时纳入顺磁相基线窗口（自旋关联长度在 T ≳ 1.2 T_N 已低于磁畴耦合尺度，315 K 点可作为补充简并参考），合计 ≥ 5 点。该窗口的 ε_q ≈ 0、h_q = 0 基线作为内参基准，用于：① 扣除装置偏振分析效率非理想残差；② 反铁磁相 ε_q、h_q 非零值的归一化分母；③ 与 §2.2 圆二色通道独立交叉验证自旋简并下圆二色通道对称性禁戒。
- **跨 T_N 谱形变化 ΔI_n(T)/I_n(T>T_N) 的双重用途：** 该曲线既作为 g 波自旋劈裂磁有序敏感性的直接读出（见上一段），亦作为内参基准的延伸应用——T > T_N 段 I_n(T>T_N) 取顺磁相 5 点平均，分母的统计涨落较单点降为 1/√5 ≈ 0.45 倍，使 ΔI_n 的探测灵敏度对低产额偶次阶仍可分辨至百分量级。

### 2.6 带隙温漂与三光子共振补偿（本轮新增）

半导体带隙在 10–340 K 全温区漂移可达 0.1 eV 量级；三光子近带边干涉的共振条件随之移动。
- 三光子过程对波长的灵敏度 dE/dλ ≈ 0.41 eV/μm（3 μm 中心）。
- 按线性近似补偿 0.1 eV 漂移需调谐约 ±0.25 μm。
- **路径 A（装置调谐）**：OPCPA 小范围波长调谐 3 μm 附近 ±0.25 μm。
- **路径 B（数据处理）**：若调谐裕量不足，正演模型在窗口核算中引入温度相关带隙参数，把三光子能量重映射到对应带边位置、保留温度依赖项的拟合自由。
- 两路径共同保证跨 T_N 扫描期间三光子能量始终处于近带边窗口内。

### 2.7 装置校准与性能验证

- **偏振分析器**（每次实验前）：余弦平方拟合 I(θ) = I₀ cos²(θ-θ₀) 提取消光比，验收 > 10⁴；不达 → 清洁或更换。
- **光谱仪能量轴**（每周/换激光后）：Hg 灯 1.0/1.5/2.0 eV 特征线，偏移容许 ±0.05 eV；分辨率 FWHM ≤ 0.1 eV。
- **SNR 基线**（每温度点前）：暗噪声 < 0.1 counts/s（PMT）或 ICCD < 10 counts/pixel/s；背景谐波 < 真实信号 5%。

### 2.8 风险评估与替代方案

| 风险 | 触发 | 替代 |
|------|------|------|
| 样品表面退化 | 暴露 > 30 s 或 SHG 降 > 30% | 重解理并立即安装 |
| 脉宽 > 30 fs / 温漂 > 2 K / 谐波饱和 | §2.7 校准超限 | 压缩 / 延长等待 / 衰减片降场强 |
| 消光比 < 10³ | 校准失败 | 清洁/更换；降级"总偏振度" |

| MoS₂ 偏差 > 10% | §4.4 | 排查装置→模型 |

## 方法 3：贝叶斯 MCMC 频谱-磁结构参数反演

通用贝叶斯框架见 `knowledge/wiki/methods/bayesian-inference.md`。本方法仅保留本课题特化内容。

### 3.1 反演目标与参数定义

| 参数 | 符号 | 先验分布 | 目标精度（σ_post） |
|------|------|----------|--------------------|
| g 波劈裂幅度 | Δ | Uniform(0.1, 1.0) eV | ±0.05 eV |
| 奈尔矢量方位角 | θ | Uniform(0°, 360°) | ±10° |
| 奈尔温度 | T_N | Normal(310, 10) K | 层级 A ≤ ±10 K / 层级 B ≤ ±3 K |

**T_N 反演精度的双层级：**
- **层级 A（R3 跨 T_N 联调门控）**：σ_post(T_N) ≤ ±10 K = 先验宽度 50%。未达标不进入跨 T_N 联调，触发 No-Go。
- **层级 B（可发表指标）**：反演输出与 SQUID 独立测定（±2 K）的差 ≤ ±3 K = SQUID 不确定度的 1.5 倍。
- 两层级共用同一 σ_post 量化载体，但语义不同：层级 A 是流程门控（不达标停止资源投入），层级 B 是论文指标（不达标改"上限估计"）。

### 3.2 算法步骤

**Step 1–3：似然构造** 输入 R2 实验谱 I_exp(Ω)（各 T_i、B_j、P_k）→ 观测量特征向量（各阶产额比 n = 2/3/5/7、偶次相对强度、CD_n、椭圆率 ε_n、跨 T_N 谱形变化，维度 D ≈ 5–10）→ 调用 R1 正演模型计算 y_theo(x) → 高斯对数似然，σ_d 由 R2 SNR 标定：SNR ≥ 10:1 → 0.1|y|；SNR = 3:1 → 0.33|y|；SNR < 3:1 → 不进入反演。

**Step 4：MCMC 采样** Metropolis-Hastings，3 维参数空间；提议步长 Δ 0.1 eV、θ 20°、T_N 5 K；4 条独立链各 10⁴ 步，burn-in 前 2×10³ 步舍去。收敛 Gelman-Rubin R̂ < 1.2；R̂ > 1.2 延长至 2×10⁴；R̂ > 1.5 触发模型审查。

**Step 4.5：R1 灵敏度分析（MCMC 启动前的可辨识性预评估，本轮强化）**

三重独立观测约束：
- 差分偶次谐波 ΔI_even/I_avg：主约束 Δ，对 θ 弱敏感（通过偏振选择规则间接进入）。
- 偏振方位角周期结构 S₁(α)/S₀、S₂(α)/S₀：主约束 θ，对 Δ 与 T_N 中度敏感。
- 跨 T_N 谱形变化 ΔI_n(T)/I_n(T>T_N)：主约束 T_N（通过临界标度律），对 Δ 弱敏感。

Fisher 信息矩阵数值计算：
- 基准点 **x* = (0.55 eV, 180°, 310 K)**（与 §1.2 Δ 默认值、T_N 中位、θ 中心对齐）。
- 中心差分步长 **ε_i = 0.01 × |x_i*|**。
- 三类观测各 10 个采样点 → 总 N_obs = 30。
- F_ij = Σ_d (1/σ_d²)·[∂y_d(x*;x_i)/∂x_i]·[∂y_d(x*;x_j)/∂x_j]。
- 参数空间范围对齐申请书 §1：Δ 0.1–1.0 eV、θ 0°–360°、T_N 310 ± 20 K。

退化方向诊断：对 F 做特征值分解 λ_max → λ_min，若最大特征向量指向某 (Δ, θ, T_N) 的特定线性组合，标记为简并方向，用于 §3.4 降维反演的"识别简并方向"步骤。常见简并：(Δ, θ) 难解耦、(Δ, T_N) 共敏感、(θ, T_N) 罕见。

**Step 5：Fisher 条件数分区**

| κ 区间 | 可辨识性 | 动作 |
|--------|----------|------|
| < 10² | 三参数联合可辨识 | 执行完整 3 维 MCMC |
| 10² ≤ κ < 10⁴ | 边缘可辨识（弱简并） | 触发降维反演（§3.4） |
| ≥ 10⁴ | 强简并，不可联合辨识 | 触发 No-Go（§3.5） |

**Step 6：后验分布与精度评估** 去除 burn-in 后每 10 步取 1 点抽取后验样本；输出边缘后验 p(Δ|y)、p(θ|y)、p(T_N|y)；与 §3.1 目标精度对比，不达标触发边界界定。

### 3.3 降维反演预案（κ ∈ [10², 10⁴) 触发）

1. 识别简并方向：F 特征向量对应最弱约束方向。
2. 边缘化最弱参数：对难解耦对，先验分布退化为 Dirac δ（用外部独立测量强约束），再对剩余参数做 1/2 维 MCMC。
3. 报告约束来源：标注哪些参数由外部测量约束（SQUID 给 T_N、ARPES 给 Δ 中位数）、哪些由 HHG 反演独立给出。

精度目标放宽规则：完整 3 维按 §3.1 目标精度；降维 2 维放宽 50%（Δ ±0.075 eV、θ ±15° 或 T_N σ ≤ ±15 K）；降维 1 维放宽 100%。降维后 σ_post 仍须满足层级 A，否则触发 No-Go。

### 3.4 No-Go 判据与边界界定

触发条件（任一）：κ ≥ 10⁴ / SNR < 3:1 / σ_post(T_N) > ±10 K（层级 A 门控不达；Δ/θ 等效判据 σ_post(Δ) ≥ 0.05 eV、σ_post(θ) ≥ 10°）。

输出规范：参数探测上限（95% CI）、可辨识性报告（所有 (参数对) 的 Fisher 条件数 + 简并方向）、探测能力总结、改进路径建议。

No-Go 与失败的区分：No-Go 是反演完整执行后判定不可行（属正常科学输出）；失败是流程未完成即中断（MCMC 不收敛、模型崩溃），需先修复流程。

### 3.5 泵浦-探测动力学测量（目标 4 扩展）

承接 §2.3 静态磁场反转差分主信号维度，本节扩展延时维度：在同源 3 μm 中红外输出上加机械延迟线把单一驱动脉冲分劈为泵浦与探测两路，采集延时-谐波强度二维网格 I_q(τ, T)，兑现申请书"目标 4：捕获磁相变动力学的谐波谱瞬态响应曲线"。该任务的时间尺度匹配反铁磁自旋进动皮秒量级（0.3–3 THz 反铁磁共振频区），与目标 2 的跨 T_N 谱形变化曲线构成时-频两轴上的互补提取维度。通用泵浦-探测架构与适用边界见 `knowledge/wiki/methods/pump-probe.md`（参数溯源：原理段、参数表、代表作 r50–r59 / r69）。

#### 3.5.1 实验步骤

**光路分劈。** 1 kHz 中红外 OPA 输出经 50/50 分束为两路：透射为泵浦（高功率）、反射为探测（经机械延迟线）。两路以偏振合束器共线导入超导磁体入口窗，到达样品时空间重合（焦斑同心，§2.2 同 50 μm 焦斑参数）。延迟线行程 ≥ 10 ps，对应最大延时 ≥ 10 ps，机械重复性 ≤ 1 μm（折算 ≤ 6.7 fs）。

**延时扫描协议。** 0–10 ps 延时范围、步长 δτ ≤ 100 fs，对应 ≥ 100 个延时点。步长上限由目标时间分辨率 100 fs 决定（脉宽 + 抖动卷积给出，详见 §3.5.2 关键参数表）。单延时点积分 10–30 s；网格重复扫描 3 遍取中位数，单个温度点约 1–2 h 完成。

**温度序列与跨 T_N 采样。** 跨 T_N 温度点的选取复用 §2.5 表 1 协议：310 K 上下各含 ≥ 1 个反铁磁相点与 ≥ 1 个顺磁相点，合计 ≥ 3 个跨 T_N 温度点（T_N 以样品 SQUID 独立测定为准，§0 R3 层级 B）。3 个跨 T_N 温度点合计约 1 工作日机时，计入温区重建与复测裕量后不超过 1 周，与申请书 §8 第四年"约 1 周"机时预算一致。

**背景与内参基准。** 每温度点前采集暗谱、无样品背景谱与驱动关断本底（§2.7 同链路），背景份额 < 5%。顺磁相（320–340 K 共 4 点 + 跨 T_N 加密段 315 K 纳入，§2.5 顺磁相内参基准窗口 ≥ 5 点）作为内参基准：自旋简并极限下 I_q(τ, T > T_N) 应给出无延时依赖的平稳基线，扣除该基线即磁敏感瞬态信号。

**泵浦-探测功率定标。** 泵浦注量在 0.1–1 mJ/cm² 微扰区间，避免激发磁相变（与申请书 §3 信号提取端"微扰方式激发自旋进动、探测磁相变临界动力学"对齐；与目标 4"临界慢化"匹配）。烧蚀阈值 0.5 安全系数给出 F_pump 上限 ~ 2 TW/cm² × 30 fs × 2 / 面积上限 ≈ 1.2 mJ/cm² 区间，微扰上限取 1 mJ/cm²。注量扫描 0.1–1 mJ/cm² 区间 5 点，验证瞬态响应幅度随 F_pump 单调变化且不出现饱和；出现饱和触发烧蚀阈值核查。

#### 3.5.3 数据产出与验证方式

**数据产出格式。** 延时-谐波强度二维网格 I_q(τ, T)，列为 τ [fs], q, I_q [counts/s], σ_I, 温度 [K] 为多个文件；与 §2.3 静态网格 I_q(±B, T) 合并即得三维 I_q(τ, ±B, T) 数据集。

**验证方式：**

- *时间零点定位。* 跨零信号（如非晶硅电流瞬态、二次谐波互相关相关峰）单次标定，给出 τ = 0 参考点的不确定度 ≤ 50 fs。
- *单点步长内插校验。* 短延时窗口（τ < 500 fs）内插步长减半测试，I_q(τ) 连续平滑、无假频结构，则 δτ ≤ 100 fs 步长设定可分辨奈尔矢量瞬态响应。
- *顺磁相自旋简并基准。* T > T_N 顺磁相 ≥ 5 点的 I_q(τ, T > T_N) 应给出无延时依赖的平稳基线（自旋简并极限下光激发对瞬态信号零贡献），与 §2.5 内参基准一致；非平稳偏差 > 测量噪声 3σ 触发装置漂移核查。
- *跨 T_N 谱形变化双重用途。* ΔI_q(τ, T) ≡ [I_q(τ, T) - I_q(τ, T > T_N)] / I_q(τ, T > T_N) 提取磁相变临界慢化特征时标 τ_onset(T)；dτ_onset/dT 反映磁相变临界慢化对谐波发射时窗的改写幅度，与目标 2 跨 T_N 谱形变化曲线构成时-频互补。
- *SNR 验收。* 累计平均后 SNR_diff ≥ 3:1（§0 R2 同口径，§2.3.4 链路）。

#### 3.5.4 风险与替代方案

| 风险 | 触发判据 | 替代方案 |
|------|----------|----------|
| 注量烧蚀样品 | 表面 SHG 降 > 30% 或反射率降 > 10% | F_pump 降至 0.1 mJ/cm² 下沿；延长积分补偿 |
| 时间分辨率不足 | 互相关 FWHM > 100 fs | 压缩脉宽至 §2.2 上限 < 25 fs；触发主动稳定延迟线 |

#### 3.5.5 适用边界

方法页 `knowledge/wiki/methods/pump-probe.md` 指出：飞秒泵浦-探测的时间分辨本领受泵浦/探测脉宽与时间抖动限制（受限于此 30 fs 脉宽上限 + 30 fs 抖动）。阿秒/XUV 波段须依赖亚飞秒级延迟轴标定与色散管理才能获得 fs 级时延定量不确定度，本节 3 μm 中红外波段不涉及；序参量成像、非平衡拓扑读取须样品/器件具有与目标量耦合的可测瞬态信号且光激发动力学可重复，本节对 MnTe 交变磁体满足此边界。微扰区间 0.1–1 mJ/cm² 不属于激发磁相变范畴（与 R1-07 一致），与目标 4"临界慢化"读出匹配。

## 方法 4：MoS₂ 对照体系验证

### 4.1 验证目的与角色

三重作用：装置偏振分析效率标定、正演模型算法验证、失败切换判据触发源。

### 4.2 样品制备与验收

1. Scotch tape 机械解理 2H 相块体单晶至 SiO₂/Si 衬底。
2. 光学 50× 确认单层（衬底对比度 ~10%）。
3. PL/Raman：A₁g - E²g 峰位差 ~19 cm⁻¹（2H 相特征）；SHG 确认 D₃h 非中心对称。
4. 单层均匀性 AFM < 1 nm；PL 半高全宽 ≤ 50 meV。
5. 单层区域 ≥ 100 × 100 μm；氮气手套箱保存，安装前暴露空气 < 30 s。

### 4.3 测量流程与判据

**对照指标（Liu 等，Nat. Phys. 13, 262 (2017)）：** 基频 0.30 eV（约 4.1 μm）；6–13 阶相对强度偏差 ≤ 10%；偶次谐波（2/4 阶）< 5% 基线噪声。

**驱动条件两步走：**（1）0.30 eV 基频（4.1 μm）驱动 → 算法验证（与 Liu 2017 完全相同）；（2）切换至 3 μm 驱动 → 验证装置系统响应（光谱仪能量轴、偏振分析器消光比、ICCD/PMT 灵敏度温度稳定性）。

### 4.4 验证通过与失败切换

**通过：** 6–13 阶偏差 ≤ 10% + 偶次谐波 < 5% + 偏振消光比 > 10⁴。

**失败切换流程：**（1）排查装置（消光比 → 光谱仪校准 → 脉宽 → 光斑）；（2）装置无问题则排查模型（MoS₂ 能带参数 → 基函数 → 收敛性）；（3）仍不通过 → 重标定模型或触发装置大修；（4）连续 3 次失败 → 暂停项目，触发顶层复盘。

### 4.5 风险与替代

| 风险 | 触发 | 替代 |
|------|------|------|
| MoS₂ 氧化 | 暴露 > 30 s 或 PL 漂移 | 重解理；手套箱全流程 |
| 文献系统偏差 > 10% | 实测 | 切换 ZnO 对照；或双对照交叉验证 |
| 消光比 < 10⁴ | 实测 | 清洁/更换；降级"总偏振度" |
| 产额异常 SNR < 1:1 | 实测 | 检查功率稳定性；提驱动（仍 < MoS₂ 损伤阈值） |

### 4.6 与申请书对应条目

§3（§4 可行性分析）→ 方法 4；§4 失败切换判据 → §4.4；§2.2 R1 内容一 → 方法 4 作为 R1→R2 放行依据。

## 方法 5：含 SOC 磁点群正演预计算（R1 → R2 接口产物）

### 5.1 预计算目的与角色

R1 主模型输出 HHG 全谱用于反演拟合；R1 预计算专门服务 R2 验收阈值定标——输出 B-线性偶次通道相对强度目标值与 SOC 强度依赖。

### 5.2 含 SOC 磁点群 Hamiltonian

```
H_total(k) = H_TB(k) + H_alt(k) + H_SOC(k)
```

- **H_TB(k)**：MnTe 8 带紧束缚（沿用 §1.1 Step 1）。
- **H_alt(k)**：g 波自旋劈裂项，零阶模型（§1.1 Step 2）。
- **H_SOC(k)**：Te 5p L_z 与自旋 Pauli 矩阵耦合，ξ_L = 0.4–0.5 eV（原子 SOC）。

**磁点群对称性约束（本轮新增——六方母群 + 反幺正复合操作的初判框架）：**
- 顺磁相空间群 P6₃/mmc（NiAs 型、点群 6/mmm）。
- 反铁磁相合成磁对称操作：六重螺旋旋转 + c/2 磁平移与时间反演 T 的复合（{C₆T|c/2} 类，Krempaský 2024 确认相反自旋子格由六重螺旋旋转 + c/2 平移联系）。
- SOC 项在该磁对称群操作下保持不变，对称性筛选使部分 m_L 通道被筛除，进入带内动力学的有效投影 ~0.3 eV。
- B-线性偶次通道的允许性由立项阶段群论初判确认（与 §5.3 Step 1 联动）。

### 5.3 B-线性偶次通道预计算流程

**Step 1：磁对称群对称性初判（零计算成本）** 外磁场 B 作为时间奇赝矢量在 {C₆T|c/2} 反幺正操作下反号；偶次项是否存留由磁点群操作与奈尔矢量取向的组合决定，群论初判给出定论（预期允许非零；若对称禁戒则按申请书降级预案执行）。

**Step 2：B-线性偶次通道幅度数值计算** ±B 下分别对角化 H_total(k) → 本征态 |n,k,±B⟩；每个 ±B 态独立执行 §1.1 Step 3 含时演化；§1.1 Step 4 提取各阶谐波；ΔI_even = I_even(+B) - I_even(-B)；相对差分 |ΔI_even|/I_avg。

**Step 3：SOC 强度扫描** 沿用 §1.6：带内 SOC = 0–0.6 eV、步长 0.1 eV；立项 ≥ 1% 为保守下限；R2 验收按预计算目标值 50% 作为可分辨窗口下沿。

### 5.4 共线交变磁序奈尔矢量钉扎确认

**物理前提：** 共线反铁磁的奈尔矢量受晶格各向异性钉扎，抑制翻转的是 H_SF ≈ √(2H_E H_A)（非铁磁翻转场 2K_u/(μ₀M_s) 公式）。以 T_N ≈ 310 K 对应 H_E ~ 10² T、H_A ~ 1 T（K_u ~ 10⁵ J/m³）估算，H_SF ~ 10 T 量级，高于 ±7 T 工作磁场。

**预计算确认：** ±7 T 下对角化 H_total(k)，±B 下 |n,k⟩ 本征态差异 < 1% → 奈尔矢量未翻转。若预研实测 H_SF < 7 T → 降工作磁场至 H_SF/2 以下再执行差分。

### 5.5 预计算输出交付物

| 输出量 | 格式 | R2 用途 |
|--------|------|---------|
| B-线性偶次通道目标值 | CSV，SOC 强度网格 | R2 验收阈值定标 |
| 偏振各向异性图样调制深度 | 数值表（α = 0°–360°） | 3/5 μm 切换判据 |
| 临界翻转场 H_SF 估算 | 数值 | 磁场反转差分前提确认 |
| ±B 本征态差异 | CSV | 奈尔矢量钉扎确认 |

### 5.6 风险与替代

| 风险 | 触发 | 替代 |
|------|------|------|
| 预计算目标值显著偏离实测 | 偏差 > 50% | §1.6 SOC 重扫描 |
| 奈尔矢量翻转 | H_SF < 7 T | 降外加磁场至 H_SF/2；或换更高 H_SF 样品 |
| 磁对称群误判 | B-线性通道被误禁戒 | 重检磁点群对称性；引入子群破缺修正 |

### 5.7 与申请书对应条目

§1 R1 输出 → 方法 5 B-线性偶次通道目标值；§3 信号提取端 → §5.3 主体；§3.4 可行性分析第一层 → §5.4 奈尔矢量钉扎；§5.4 两套 SOC 取值 → §5.2 含 SOC 磁点群 Hamiltonian。通用磁点群/自旋群对称性分析见 `knowledge/wiki/methods/磁点群自旋群对称性分析.md`。

## 方法 6：验证层方法

验证层以四类独立表征作为 R3 反演输出的对照基准。每类对照给出"独立测量 → R3 反演输出 → 一致性判据"三段闭环（汇总表见 §3 / §0）。

### 6.1 MoS₂ 装置偏振分析效率标定

3 μm、0.5–2 TW/cm² 驱动下采集 MoS₂ HHG 谱；偏振分析器旋转 α = 0°–180°（步长 10°）提取消光比；偶次谐波（2/4 阶）< 5% → 装置偏振分析效率合格；6–13 阶相对强度偏差 ≤ 10% → 复现通过（§4.3）。

### 6.2 SQUID 磁测量独立 T_N

样品与 HHG 同批次 MnTe（3 × 3 × 1 mm 小块）。FC/ZFC：10 → 340 K，T_N 附近步长 2 K、其余 5 K；H = 100 Oe；测 M(T)。T_N 提取：dM/dT 极值点（精度 ±2 K，MPMS 3 商用典型）。触发：T_N 偏离文献 > 5 K → 批次质量审查；ΔT > 5 K → 多畴或非均匀性。

### 6.3 XRD 磁 Bragg 峰温依赖

Cu Kα（1.5418 Å）单色器，测角仪 ±0.001°；变温台 10–340 K，精度 ±0.5 K；扫描 2θ = 30°–80°，步长 0.01°。MnTe (101) 磁 Bragg 峰 ~34°（Cu Kα），T < T_N 存在、T > T_N 消失；位移 ~0.1°/K。T_N 提取：峰强 → 0 的温度（精度 ±10 K）。触发：磁 Bragg 峰位移 > 0.1°/K → 结构相变审查；提取失败 → 中子衍射或加密温变步长。

### 6.4 反常 Hall 效应（AHE）符号

器件：MnTe 薄片（< 100 μm）+ 电子束光刻 + Ti/Au 5/50 nm Hall bar；电极间距 ~200 μm、宽度 ~50 μm。变温 10–340 K，±7 T；测 R_xy(H, T)。AHE 提取：σ_xy^A = ρ_xy^A / (ρ_xx² + ρ_xy^A²)；扣除常规 Hall 线性项。符号对照：AHE 符号由 g 波磁点群对称性破缺决定；θ = 0° 对应正、θ = 90° 对应负（具体对应由 R1 预计算给出）。触发：符号不一致 → θ 值审查（可能源：多畴平均或模型对称性破缺方向有误）。

### 6.5 风险与替代

| 风险 | 触发 | 替代 |
|------|------|------|
| MoS₂ 标定偏差 > 10% | §6.1 | 切换 ZnO 对照或双对照 |
| SQUID T_N 偏差 > 5 K | §6.2 | 重解理新批次；检查设备校准 |
| XRD 失败 | §6.3 | 中子衍射；放宽至 ±15 K |
| AHE 异常 | §6.4 | 检查欧姆接触；改用磁阻各向异性 |

### 6.6 与申请书对应条目

§1 验证层 → 方法 6 主体；§1（MoS₂ 标定 / SQUID / XRD / AHE）→ §6.1-§6.4。通用输运张量对称性细节见 `knowledge/wiki/methods/磁性点群输运张量对称性分析.md`；自发反常霍尔测量细节见 `knowledge/wiki/methods/自发反常霍尔效应测量.md`。

## 方法 7：5 μm 备用驱动光路与切换标定

### 7.1 切换背景与物理依据

带内 SOC 强度在 0.3–0.6 eV 上端区间时，3 μm 调制深度落入可分辨窗口下沿以下，切换至 5 μm 以维持 g 波节点面特征可区分度。5 μm 物理入口：光子能量 0.25 eV，三光子能量 0.75 eV 远低于 MnTe 间接带隙 1.3 eV，切换到带内多光子干涉。

### 7.2 装置差异参数表

| 元件 | 3 μm | 5 μm | 切换难度 |
|------|------|------|----------|
| 驱动激光 | OPCPA 3 μm 输出 | OPCPA 5 μm 输出 | 调谐（非破坏，1–2 h） |
| 偏振调制单元 | 零级 1/2 + 1/4 波片 | 复用 | ZnSe/IR 级透明 |
| 偏振分析器 | 消光比 > 10⁴ | 复用 | ZnSe Rochon 棱镜 5 μm 透明 |
| 光谱仪 | 0–20 eV 谱窗 | 0–15 eV（截止能量更低） | 调光栅与探测器 |
| ICCD/PMT | 0–20 eV | 0–15 eV | 调门宽 |
| 超导磁体入口窗 / 样品室 | ZnSe 窗 | 复用 | — |
| 功率定标曲线 | 3 μm 烧蚀阈值定标 | 5 μm 重标定（吸收长度变化） | 预研独立标定 |

### 7.3 切换判据的执行标准

- 触发：R1 含 SOC 磁点群预计算在 3 μm 下偏振各向异性图样调制深度 < 可分辨窗口下沿（差分目标值 1% 的 50% = 0.5%）。
- 5 μm 预计算执行：保持 MnTe 能带参数不变，仅替换 ℏω = 0.25 eV。
- 切换决策：5 μm 调制深度 > 3 μm → 切换；反之保留 3 μm。

### 7.4 切换后标定流程

沿用 §2.4 A/B/C/D 四级触发规则；5 μm 工作点需在预研阶段单独标定产额与 SNR。5 μm 截止阶次 ~10 阶（0.25 eV × 10 = 2.5 eV），较 3 μm 的 ~15 阶（6.15 eV）压缩；单阶产额可能更高（带内多光子干涉集中）。无直接文献，预期 10²–10⁴ counts/s。

### 7.5 双工作点并存期内部一致性

5 μm 启用后 3 μm 数据不立即作废，两套驱动条件下采集的同一温度点构成内部一致性验证：
- 劈裂幅度：3 μm 与 5 μm 反演 Δ 的 95% CI 重叠 → 一致；不重叠 → 模型审查。
- 方位角：3 μm 与 5 μm 反演 θ 在 ±20° 内一致。
- T_N：跨 T_N 反演 T_N 在 ±5 K 内一致。

### 7.6 风险与替代

| 风险 | 触发 | 替代 |
|------|------|------|
| 5 μm 输出功率 < 3 μm 50% | 实测 | 调泵浦参数；或降重复频率提单脉冲能量 |
| 5 μm 消光比 < 10³ | 实测 | 切换 ZnSe Rochon；降级"总偏振度" |
| 5 μm 截止阶次 < 5 | 实测 | 提驱动强度；或切 7 μm 备用 |
| 5 μm MoS₂ 复现失败 | 偏差 > 10% | 排查 ZnSe 表面；保留 3 μm 主测数据并标注"5 μm 切换未执行" |

### 7.7 与申请书对应条目

§1（5 μm 备用启用条件）→ §7.3；§3 驱动端（5 μm 切换标定）→ §7.2、§7.4；§5.4 双工作点切换 → 方法 7 主体。

## 方法 1+2+3+4+5+6+7 串联接口规范

### 判据门控总览

| 环节 | 前置判据 | 触发动作 |
|------|----------|----------|
| M4 MoS₂ 验证 → R1 MnTe 计算 | 6–13 阶偏差 ≤ 10% | > 10% 排查装置→模型；连续 3 次失败暂停项目 |
| R1 顺磁基准 → R1 SOC 扫描 | 顺磁相偶次谐波 < 1% | > 1% Hamiltonian 对称性审查 |
| R1 SOC 扫描 → R2 实验设计 | 偏振各向异性图样演化序列 | 选调制最强工作点；带内 SOC 上端触发 3→5 μm 切换 |
| R2 产额实测 → R3 资源投入 | A 级 10²–10⁴ counts/s 或 B 级微调达标 | < 10² 且微调失败 → 不投入 R3 |
| R2 数据采集 → R3 反演 | 关键温度点（280/310/330 K）SNR_diff ≥ 3:1 | < 3:1 触发 No-Go |
| R3 κ 预评估 → MCMC 启动 | κ < 10² | 10²–10⁴ 触发降维；≥ 10⁴ 触发 No-Go |
| R3 后验 → 验证层 | σ_post(T_N) ≤ ±10 K（层级 A）+ R̂ < 1.2 | 任一不达标 → No-Go 或重采 |

### R1 → R2 接口

R1 须提供：各阶谐波产额比（Δ/θ/T_N 三维 CSV）、偏振方位角周期结构（极坐标图）、圆二色性系数 CD_n（数值表）、MoS₂ 验证报告（偏差 ≤ 10%，PDF 签名确认）。

### R2 → R3 接口

数据包目录：

```
experiment_data_package/
├── harmonic_spectra/MnTe_T{10-340}_B{+7T,-7T}_pol{lin,circ}_{raw,proc}.csv
├── polarization_data/{Stokes_parameters_T*.csv, CD_coefficients_allsamples.csv}
├── metadata/{SNR_assessment.csv, temperature_calibration.log, polarimeter_calibration.log}

```

R3 接收后执行 SNR 复核：关键温度点（280/310/330 K）任一 SNR < 3:1 → 触发边界界定，不执行 MCMC。

### R3 → 验证层接口

R3 须交付：后验分布 MCMC 链（HDF5，4 链 × 8000 步）、参数后验中位数 + 95% CI（JSON）、Fisher 条件数 κ + 特征值分解（JSON）、边界界定触发记录（JSON）。
