# 研究内容

## 研究目标

本项目旨在建立"量子度规—Berry联络—固体高次谐波偏振特性"的完整理论框架，从Bloch电子态的几何性质出发，揭示量子度规张量与Berry联络调制固体HHG偏振态（椭偏率、螺旋度、椭圆旋转方向）的微观物理机制；定量预测不同驱动场条件、不同材料体系下高次谐波的偏振可观测量，阐明量子几何量与能带拓扑结构对HHG偏振的协同调控效应，为通过能带工程主动设计HHG偏振态提供理论依据。[CITE:xxx]

## 研究内容

### （一）量子度规与Berry联络的固体HHG理论建模

**目标：** 在半导体Bloch方程框架下，建立包含量子度规张量 $g_{mn}(\mathbf{k})$ 与Berry联络 $A_m(\mathbf{k})$ 的统一HHG理论，奠定后续机制分析的数学基础。[CITE:xxx]

**方法要点：**
- 基于k·p微扰理论或第一性原理计算，从Bloch波函数中提取全动量空间内的 $g_{mn}(\mathbf{k})$ 与 $A_m(\mathbf{k})$；
- 将量子几何量作为额外源项嵌入含时密度矩阵方程，引入与 $g_{mn}$ 耦合的相干演化项 [CITE:xxx]；
- 分别在二能带（Dirac型）与多能带（多轨道）模型中数值求解时域Bloch方程，输出完整的HHG电场 $E_{\text{HHG}}(t)$。

### （二）量子度规主导的HHG偏振调控机制

**目标：** 阐明量子度规张量的各向异性与非对角分量如何决定高次谐波偏振态，区分度规贡献与Berry曲率贡献。[CITE:xxx]

**方法要点：**
- 将HHG电流分解为 $j(t)=j_{\text{intra}}+j_{\text{inter}}$，提取与 $g_{mn}$ 直接耦合的interband电流贡献 [CITE:xxx]；
- 定量建立椭圆驱动场下度规非对角分量 $g_{xy}(\mathbf{k})$ 与 $n$ 阶谐波椭偏率 $\varepsilon_n$ 的解析关系；
- 对比具有相似能带色散但度规分布显著不同的材料（如hBN与MoS$_2$、石墨烯与过渡金属硫族化合物），通过差分分析剥离度规的独立效应。

### （三）Berry联络与非平庸拓扑的协同调制效应

**目标：** 揭示Berry联络 $A_m$ 通过反常速度、Airy型非对称跃迁等通道与量子度规协同调制HHG偏振，并阐明拓扑相变点附近的特征信号。[CITE:xxx]

**方法要点：**
- 比较拓扑平庸（Si、MgO）与拓扑非平庸（拓扑绝缘体、Weyl半金属）体系中 $A_m$ 对偏振谐波的差异化贡献；
- 引入非Abelian Berry联络，分析多带间量子几何干涉对谐波螺旋度 $h_n$ 的影响；
- 探究能带拓扑相变点附近 $g_{mn}$、$A_m$ 的奇异结构在HHG偏振谱中形成的特征指纹。

### （四）实验可观测量的定量预测与方案设计

**目标：** 将理论结果转化为可直接测量的偏振物理量，并提出可分离量子度规与Berry曲率贡献的实验判据。[CITE:xxx]

**方法要点：**
- 预测椭偏率依赖的谐波产率 $Y_n(\varepsilon_{\text{drive}})$、谐波螺旋度 $h_n$ 与偏振分辨的HHG角分布；
- 设计双色场、圆偏振基频场等实验方案，通过扫描驱动场椭偏率在偏振谱中分离 $g_{mn}$ 与 $A_m$ 的独立印记 [CITE:xxx]；
- 与现有固体HHG实验数据（MgO、Si、MoS$_2$等）系统对比，验证理论框架的普适性与可检验性。

## 各子内容之间的逻辑关系

四个研究内容构成"建模—机制—协同—验证"的递进闭环。内容（一）奠定统一的量子几何理论基底，为（二）（三）提供共同的几何描述语言；内容（二）聚焦量子度规对偏振的独立贡献，内容（三）拓展至Berry联络与拓扑序的协同调制，二者形成"单一几何量—多几何量耦合"的层次递进；内容（四）将前三部分的理论预言转化为可测量的偏振信号与具体实验方案，与（一）中的理论形成首尾呼应，构成完整的"理论建模—机制分析—协同效应—实验检验"研究链条。[CITE:xxx]
