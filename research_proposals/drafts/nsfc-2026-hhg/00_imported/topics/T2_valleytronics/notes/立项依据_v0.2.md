## 节 1：科学意义与研究价值（申请书级深度）

### 1.1 谷自由度：超越电荷/自旋的新量子信息载体

**谷电子学（Valleytronics）** 利用二维六角晶格材料中布里渊区 K 和 K' 两个不等价谷的离散自由度作为信息载体。**与自旋的根本区别**：

| 自由度 | 退相干时间 | 操控速度 | 室温稳定性 | 信息维度 |
|--------|-----------|----------|-----------|----------|
| 电荷 | ps | fs | 优 | 1（连续）|
| 自旋 | μs-ms | fs | 中（需磁场）| 1（±1/2）|
| **谷** | **ns-μs** | **亚 fs** | **优**（时间反演保护）| **2（K/K'）** |

**v0.2 关键补充**：
- 谷极化态由**时间反演对称性**保护（K 与 K' 谷 Berry 曲率符号相反）
- **自旋-谷锁定**：强自旋-轨道耦合使谷态与自旋态锁在一起（MoS₂、WS₂ 等 TMDCs）→ **2 维 + 1 维 = 3 维信息编码**
- 2024-2026 新材料涌现：**反铁valley（antiferrovalley）**（MnSe 单层，自发谷极化 + 反铁磁序，Wang 2024 J. Materiomics）打开**电-磁-谷三重调控**新维度

### 1.2 HHG 谷操控相比现有方法的不可替代性（4 重优势 + 1 重挑战）

**为什么必须是 HHG**？对比圆二色光致发光（主流方法）：

| 维度 | 圆二色光致发光 | **HHG 圆偏振/涡旋光** | 提升倍数 |
|------|--------------|-------------------|---------|
| **产生效率** | 10⁻⁶（发射截面 ~10⁻¹⁶ cm²）| **10⁻³ - 10⁻²**（非微扰）| **10³-10⁴×** |
| **时间分辨率** | 10-50 fs（泵浦-探测）| **亚周期 < 500 as**（HHG 内禀）| **10²×** |
| **空间分辨率** | 200-300 nm（衍射极限）| **理论 < 10 nm**（偏振门控 / 涡旋光中心空位）| **20-30×** |
| **单次测量** | 需平均 10³-10⁴ 次激光 | **单发**（HHG 单脉冲即可）| **无需平均** |
| **多维信息** | 仅强度 | **强度+偏振+相位+频谱+OAM** | **5 维** |

**HHG 的 4 重不可替代优势**：
1. **效率 10³-10⁴×**：HHG 是非微扰过程（E_n ∝ E₀ⁿ，n 阶谐波），弱谷信号被指数放大
2. **时间分辨率 100×**：HHG 本身在亚光学周期（100 as - 几 fs）发射，可捕捉谷间瞬态动力学
3. **空间分辨率 20-30×**：偏振门控 / 涡旋光中心空位 / 近场增强实现亚波长（< 10 nm）谷态成像
4. **单发 + 多维**：单脉冲完整 HHG 谱（含 5 维信息），适合不可逆谷相变/单次事件探测

**HHG 的 1 重挑战**：**反演多解性**（HHG 谱受多参数耦合）→ 4.3 节详述 T5 多维约束解决方案。

### 1.3 5 个具体科学发现机会

**H1：莫尔超晶格 HHG 全光学表征（魔角双层石墨烯）**
- Molinero 2024 Optica 11, 171：HHG 谱直接反映**魔角双层石墨烯**的能带结构，**HHG 信号在魔角处急剧下降**（平带 → 群速度 → 0）
- **应用**：莫尔扭转角（0.5°-3°）**全光、无接触**测量
- **科学价值**：替代 STM/AFM 扭转角测量，**全光集成**可能
- **国际对标**：Molinero 2024 理论，**实验完全空白**
- **国内空白**：**完全空白**

**H2：拓扑涡旋场在体相 MoS₂ 中非共振谷极化（Tyulnev Nature 2024 验证）**
- Tyulnev 2024 Nature 628, 746：trefoil 脉冲（拓扑荷 ℓ=3）可在**体相 MoS₂（无 Berry 曲率）**中诱导谷极化
- 关键机制：**瞬态破缺时间 + 空间反演对称性** → 谷极化（vs 单层需要 Berry 曲率）
- **应用**：**体相/多层材料谷电子学**（vs 主流单层）
- **国内空白**：**完全空白**

**H3：2D TMDC 单层 HHG 椭圆度依赖反演 2D Berry 曲率（PRJ 549545 2024）**
- 单层 MoS₂ HHG 偶次谐波**垂直分量**在有限椭圆度处增强（**异常**）
- 2D Berry 曲率分布操控**亚周期**电子动力学
- **科学价值**：首次实验提供**全 Brillouin 区 Berry 曲率**的实验方法（vs 之前 1D 测量）
- **国内空白**：**完全空白**

**H4：多体增强 HHG 在 MoS₂ 中的反常垂直响应（Nature Comm 2024）**
- GW 准粒子 + 激子 + Berry 曲率共同决定 MoS₂ HHG 谱（**非微扰 GW** ab initio 理论）
- 垂直响应分量显示**激子-BC 复杂耦合**特征
- **科学价值**：**首次** ab initio GW 描述 MoS₂ HHG（含多体），实验吻合
- **国内空白**：**完全空白**（GW HHG 反演方法学）

**H5：阿秒谷开关 + 拍赫兹谷极化反转（CPL 2026 ⭐）**
- 反向旋转双色圆偏振场（counter-rotating two-color circular）→ 2D 半导体布洛赫方程模拟 monolayer MoS₂
- 可调谐单手性高次谐波，**谷干涉**实现
- **科学价值**：**拍赫兹速度**谷极化开关（< 1 fs），比现有泵浦-探测快 10²×
- **国内空白**：**完全空白**（**2026 最新**）

### 1.4 科学意义（4 维度）

1. **方法论突破**：HHG 作为**全光 + 体相 + 亚周期分辨**的谷自由度探测与操控平台，补充现有圆二色光致发光的局限
2. **材料维度拓展**：从单层 → 体相（Tyulnev 2024）、从 2D TMDC → 莫尔超晶格（Molinero 2024）、从铁磁 → 反铁valley（MnSe Wang 2024）
3. **物理新维度**：涡旋光 OAM 守恒、谷干涉、阿秒谷开关、HHG 反演 Berry 曲率 2D 分布
4. **应用基础**：谷电子学器件（量子比特、低功耗逻辑、量子通信）核心物理基础

## 节 3：关键科学问题凝练（申请书级深度）

### 3.1 核心科学问题

**主问题**：HHG 的圆偏振 / 涡旋光 OAM / OTC 相位 / CEP / 晶体取向多维依赖如何直接映射到**谷极化率 η、Berry 曲率 Ω(k)、谷间相干寿命 τ_v**，并捕捉**莫尔超晶格 / 反铁valley / 多体关联**等复杂体系的谷动力学？

### 3.2 4 个子问题

#### 3.2.1 子问题 1：HHG 圆偏振/椭圆依赖 → 谷极化率（深耕 + 国际对标）

**物理图像**：
- TMDC 单层（MoS₂/WS₂）K 谷仅耦合 LCP，K' 谷仅耦合 RCP（**谷光学选择定则**）
- HHG 圆偏振依赖：LCP HHG 谱 vs RCP HHG 谱差异 = 谷选择性指纹

**关键科学问题**：
1. **谷极化率定量提取**：Q = (I_K - I_K') / (I_K + I_K') = f(强度, 椭圆度, OTC 相位, OAM)

3. **多能带效应**：导带+价带+高能带 → 多带 HHG 谷选择规则扩展
4. **温度依赖**：跨越 T_N（反铁valley 转变点）HHG 谱跳变

**v0.2 新增实验**：
- MoS₂ 单层（CVD）：最成熟

- CrI₃（与 T4 序参量协同）

#### 3.2.2 子问题 2：涡旋光 OAM → 谷轨道角动量（**方法学突破**）

**物理图像**：
- 涡旋光场 E(φ) = E₀ exp(iℓφ)，OAM = ℓℏ
- HHG 中 OAM 守恒律：ℓ_driver + ℓ_v = ℓ_HHG（**Pisanty 2019 理论**）

**关键科学问题**：

### 4.3 澄清有争议的原理：HHG 反演多解性

**争论 1 核心**（HHG 反演多解性）：
- HHG 谱受能带色散、跃迁矩阵元、退相位时间、Berry 曲率、激子浓度、OAM、CEP 多参数耦合
- **唯一性证明缺失** → 反演多解性

**本项目多维约束解决方案（9 维 vs v0.1 的 5 维）**：

| 约束维度 | 提供信息 | 对多解性贡献 |
|----------|----------|--------------|
| **偏振分辨**（LCP/RCP） | 谷极化率 η | 约束 η |
| **椭圆度扫描** | Berry 曲率 Ω(k) | 约束 Ω(k) |
| **涡旋光 OAM** | 谷轨道角动量 | 约束 ℓ_v |
| **OTC 相位** | 谷开关 | 约束谷干涉 |
| **CEP 依赖** | 谷相干寿命 τ_v | 约束 τ_v |
| **晶体取向** | 群论选择定则 | 约束对称性 |
| **温度依赖** | 激子解离、相变 | 约束多体 |
| **掺杂依赖** | 载流子浓度 | 约束 Drude 贡献 |
| **扭转角依赖**（莫尔） | 莫尔平带 | 约束莫尔势 |

**v0.2 新增 4 维约束**（OAM+CEP+温度+扭转角），总约束数从 5 维升到 **9 维**，多解性显著降低

**机器学习辅助**：
- 用 TDDFT/GW HHG 计算生成训练数据集（HHG 谱 → η, Ω, τ_v, 激子浓度, OAM）
- 训练神经网络建立非线性映射
- 多维约束数据作为输入，提高反演鲁棒性

**HHG 谱 → 谷动力学参数反演路径**：

```
输入：HHG 谱
├─ 圆偏振依赖（LCP/RCP）

├─ 掺杂依赖（载流子浓度）
└─ 扭转角依赖（莫尔）
    ↓
物理模型：
├─ 单粒子：k·p + 紧束缚 + 半导体布洛赫方程（SBE）
└─ 多体：TDDFT / GW（孟胜组 IOP CAS 合作）
    ↓
反演算法：
├─ 贝叶斯反演（多解性概率量化）
├─ 神经网络（多维非线性映射）
├─ 群论选择定则（晶体对称性）
└─ 拓扑场论（Berry 曲率 + OAM 守恒）
    ↓
输出：
├─ 谷极化率 η(k, T)
├─ Berry 曲率 Ω(k)
├─ 谷间相干寿命 τ_v
├─ 谷轨道角动量 ℓ_v
├─ 激子浓度 n_ex
├─ 莫尔势 V_M
├─ 反演误差（95% 置信区间）
└─ 多解性概率
    ↓
验证：与 tr-ARPES、SHG、PL 独立对比
```
