**红队质询**：

✅ **修复确认**：相比第 1 轮"两个独立科学问题拼盘"，本节通过"工具-靶标-方法"递进闭环论证，结构性不匹配问题已解决。R1→R4 正向模型依赖论证、R1→R2→R3 信噪比论证、R3→R4 真实数据闭环论证，三段论证链条清晰。

🟠 **[high] logic_gap — R1→R4 依赖链过度宣称，弱→中关联外推可信度未论证**

- **位置**：第 109 行"R1 建立的 BSV-SBE 是唯一兼顾物理保真度与计算效率的正向模型——这正是 R4 的方法学根基"
- **问题**：该论断声称 BSV-SBE"唯一兼顾物理保真度与计算效率"——但 BSV-SBE 本质上是 BSV 驱动的单电子（mean-field + Volkov 修饰）理论，**并不显式包含多体效应**。第 159 行 §2.4 又说 R3 旨在检验"BSV-SBE 理论在何种关联强度下开始偏离单电子图像"——这与第 109 行"R4 方法学根基"形成内部张力：**R1 正向模型本身不包含多体物理，又如何作为 R4 的多体反演正向模型使用？** 这一矛盾是 §2.1 与 §2.4 跨段冲突的红线。
- **风险**：评审一眼可见：R1 既被定位为"含多体效应的正向模型"（§2.1），又被定位为"在 CDW 中开始偏离"（§2.4）。两段同时存在意味着：(a) §2.1 论证过度，(b) §2.4 R1 边界检验的必要性被推翻，(c) R4 多体反演缺乏真正多体正向模型，依赖 R1 是循环论证。
- **建议**（action: **rewrite**）：
  1. §2.1 第 109 行明确承认 BSV-SBE 是"含显式光子数涨落但不含完整多体相互作用"的近似正向模型，定位为 R4 的"弱关联域锚点 + 物理保真度参照"。
  2. 同时引入 R3 的 tdDMFT 数据作为"多体域训练源"，明确 R4 的双源训练分工（R1 SBE 仅负责弱关联预训练+大批量粗筛，tdDMFT 负责中等关联微调），化解跨段矛盾。
  3. 在 §2.5 R4 范围说明中显式声明"BSV-SBE + tdDMFT 联合正向模型"而非仅 §2.1 声称的"唯一正向模型"。

🟡 **[medium] logic_gap — R3→R4 论证中"PINN 缺乏对实验系统误差的鲁棒性"过于抽象**

- **位置**：第 111 行"R3 的实验 CDW 谱为 R4 提供带测量噪声的测试集与不确定性校准基准，纯模拟训练得到的 PINN 缺乏对实验系统误差（样品不均匀性、热漂移）的鲁棒性检验"

🟠 **[high] method_weakness — g⁽²⁾(0) 截止公式推导的物理假设未明示**

- **位置**：第 121 行"推导 N_cutoff(r, I_p, m_r) 的解析形式，量化 squeeze 参数 r 对高阶谐波通道的增强因子 α(r)"
- **问题**：(a) Ghalgaoui 2023 的原子体系截止增强基于**强场近似（KFR 势垒电离 + 三步模型）**，而固体的能带结构（带隙、带内跃迁、跃迁矩阵元 k-依赖）会显著改变截止位置。申请书将"原子三步公式"形式（α(0)=3.17，α(1.0)≈4.5）直接搬到 §3.1 第 191 行"α(1.0)≈4.5"——**但未交代公式如何处理色散、非抛物带、多能带间的 Landé-Zener 跃迁等固体特异性**。(b) 参数 m_r 在 N_cutoff(r, I_p, m_r) 中的角色未阐明：是平均有效质量？带边有效质量？这关系到 N_cutoff 的解析形式是否对窄带隙半导体（如 Bi₂Te₃，E_g ≈ 0.15 eV）依然适用。
- **风险**：评审若追问"R1 的解析截止公式到底在何种能带模型下推导"，作者若无清晰答复，将直接判定"理论推导不严谨"。Ghalgaoui 2023 用的原子势是库仑势，固体的周期性势需要引入 Bloch 加速定理（Houston 或加速 Bloch 态），这绝非纯数值加权就能完成。
- **建议**（action: **rewrite + research**）：
  1. §2.2 任务 1 明确假设的能带模型：是否限制在"两带紧束缚模型 + 抛物带近似"？是否包含自旋轨道耦合（对 Bi₂Te₃ 必需）？
  2. 显式提到需要采用 **accelerated Bloch states / Houston 展开** 而非简单 Volkov 相位加权（这是固体 HHG 与原子 HHG 的本质区别）。
  3. m_r 给出明确定义，建议改为 N_cutoff(r, I_p, m*, E_g) 包含 4 个参数，避免 m_r 含义不清。
  4. 在方法学手册 §2A.3 给出完整推导主线（申请书说不展开即可）。

🟠 **[high] concept_inconsistency — "BSV 双模压缩真空态"与实际实验光源的对接存在概念落差**

- **位置**：第 123 行"经典 SBE 中的 Volkov 修饰项为经典场 E(t) 的函数。在量子光驱动下，需将电场算符化...使方程对任意光子数态 |n⟩ 的叠加均成立"
- **问题**：§3.1 第 201 行说实验阶段通过 BBO 退相匹配产生非简并光子对（signal/idler），"通过空间滤波和单模光纤耦合提取单时空模式 BSV 场"——但双模压缩真空（类型 BSV）经单模光纤耦合后是**单模 BSV** 而非双模。这里 BSV 理论端用双模算符 S(ξ)|0,0⟩（ξ = re^{iϕ}），实验端却提取单模，二者之间的概念跳跃未做解释。
- **风险**：双模算符的"信号-闲置（signal/idler）光子对"框架在 2023–2024 年文献中确实用于量子光 HHG（参见 arXiv 2309.14435 Rivera-Dean 等），但需要明确：(a) 算符化处理的是双模（用于纠缠/压缩验证），还是单模（仅压缩态）？(b) HHG 输出与"闲置模"的关系如何处理？(c) 单时空模式 BSV 实际是单模。这会让评审对理论-实验衔接产生疑虑。
- **建议**（action: **rewrite**）：
  1. §2.2 第 123 行明确区分理论端的"双模压缩算符 S(ξ)"与实验端的"单时空模式 BSV 场"，并说明 HHG 的非线性转换会涉及闲置模（idler 模）与谐波模的耦合或解耦。
  2. 引用 Rivera-Dean et al. arXiv:2309.14435 作为理论基础。
  3. §3.1 第 201 行补充说明理论-实验对接的具体假设（"本项目采用单模近似，因 HHG 高阶谐波的相位匹配条件天然过滤闲置模"或类似描述）。

- **建议**（action: **add**）：补充 L_GF 的迭代实现："L_GF 在 PINN 训练中通过外循环重算（frequency-domain penalty）：每个 epoch 末，根据当前反演的 U 值重新计算 Σ(ω)，并以新 Σ 更新 L_GF 的正则化目标。训练 / 推理阶段分别耗时增加 15% / 8%（详见方法学手册 §3D.2）。"

🟡 **[medium] verification_weakness — "f-sum rule 偏差 < 5%" 与 "Hubbard-U 偏差 < 15%" 的互洽性未论证**

- **位置**：§3.4 第 248 行"反演 Ω(k)/g(k) 是否满足 f-sum rule（偏差 < 5%）；Hubbard-U 反演值与 ACBN0 自洽计算偏差 < 15%"
- **问题**：f-sum rule 与 Hubbard-U 是两个独立的物理约束。在弱关联域（ZnO），f-sum rule 应严格满足（< 5% 是合理）；但在中等关联域（CDW），f-sum rule 会被多体修正（重整化）打破——5% 的偏差界限是否依然可达？申请书未讨论这一过渡。
- **建议**（action: **rewrite**）：明确 f-sum rule 的检查仅在"弱关联域"内做硬约束；中等关联域用"f-sum rule deviation ~ U/W 的标度律"做软约束，避免单一阈值跨越关联强度。
