# 课题设想

**最后更新**：2026-08-03

## 标题
莫尔超晶格的强场量子调控——非线性光学探针与主动调控

## 研究背景与动机
莫尔超晶格（moiré superlattice）的关联量子态（关联绝缘态、flat band 拓扑态）的"读出"与"改写"传统依赖电学/输运手段，受限于皮秒时间分辨与接触式扰动；强场超快激光驱动的固体高次谐波产生（HHG）提供亚周期、全光、非接触探针，为莫尔量子态的超快主动操控提供物理平台。核心科学问题：在莫尔势、扭转角与关联态调控下，能否通过 HHG 谱学反演与光 Floquet 工程建立"读出—改写"全光闭环。

首选材料：TMDC 莫尔异质结（tMoS₂ / tWSe₂，~1–3°），带隙可调 ~1–2 eV，避免石墨烯零带隙强场损伤；对比验证：魔角 TBG（~1.1°），flat-band 极限。

## 现存研究空白或瓶颈
1. 理论空白：大原胞莫尔体系（>10⁴ 原子）全原胞 TDDFT 不可承受（>10⁸ 核时），单一紧束缚难以刻画多体关联修正，缺少降阶耦合框架与误差传递量化。
2. 反演空白：单一 HHG 谱反演莫尔势是欠定逆问题（解不唯一），扭转角与莫尔势耦合需多观测解耦，物理先验未被系统形式化。
3. 调控空白：光 Floquet 工程在均匀 2D 体系已验证（黑磷/MoS₂），但在莫尔关联态上的实验验证尚未见报道，缺乏定量预言与可测靶标。

## 拟开展研究内容和方案
3 项递进研究内容构成"读出—改写"闭环：
- R1（理论建模）：TDDFT 标定参数 → 连续莫尔紧束缚 + SBE → 张量网络关联修正的三段式降阶框架，计算量从 >10⁸ 降至 ~2×10⁴ 核时。
- R2（谱学探针）：HHG 谱 + 椭偏依赖 + ATAS 三类观测量联合反演莫尔势与扭转角，三层正则化（物理先验 + 多观测联合 + Tikhonov），SNR=50 下误差棒 < 15%、扭转角 ±0.05°。
- R3（主动调控）：光 Floquet 工程调控莫尔能带，两个可测靶标——关联绝缘态光致熔化（HHG 跳变 > 20%）与 flat band 带宽调制（谐波标度 Δα > 0.2）。

## 拟采用技术路线
探针/调控双模式共用平台：通过驱动场参数切换（强度 + 椭偏 + CEP）实现读出与改写。Y1 TDDFT 标定 + SBE 迁移 + Floquet 理论；Y2 R2 三类观测量接入 + R1 正向模型 + R3 临界强度预言；Y3 反演验证 + 靶标 A/B 实验验证 + TBG 对比；Y4 闭环校准 + 误差棒量化 + 论文产出。

## 创新点
3 个创新点（方法学 2 + 理论+假说 1），与 §三.5 严格 1:1 对应：
1. 莫尔强场响应的降阶有效模型构建方法（方法学）——首次将多体张量网络修正纳入莫尔 HHG 正向模型。
2. 莫尔势/扭转角的多观测联合反演算法（方法学）——针对莫尔自由度定制正则化约束，误差从 >30% 降至 < 15%。
3. 光 Floquet 工程调控莫尔能带的理论框架与可测预言（理论+假说）——3 条可证伪假设 + No-Go 条件。
