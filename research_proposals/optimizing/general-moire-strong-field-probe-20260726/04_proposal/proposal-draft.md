### 3.1 总体技术路线

本项目构建"理论建模 ↔ 谱学探针 ↔ 主动调控"三路闭环，核心架构如下：

```
            ┌─────────────────────────────────────────────┐
            │              R1 有效理论模型                  │
            │  TDDFT(小原胞标定) → 连续莫尔紧束缚 + SBE      │
            │         → 张量网络(关联子空间修正)             │
            └──────────────┬──────────────────┬────────────┘
                    正向模型│                  │ 调控预言
                           ▼                  ▼
┌──────────────────────┐         ┌──────────────────────────┐
│   R2 谱学探针         │ 数据流  │   R3 主动调控             │
│ 莫尔 HHG 平台         │←──────→│  光 Floquet 工程          │
│ (谱 + 椭偏 + ATAS)    │ 反馈    │  (周期场重构莫尔能带)      │
│ 多观测联合反演        │         │  可测靶标：关联绝缘态熔化  │
│ → 莫尔势/扭转角       │         │                            │
└──────────────────────┘         └──────────────────────────┘
```

**三路闭环的数据流**：实验谱 → 反演莫尔势/扭转角 → 反馈调控参数（驱动场强度/椭偏/CEP）→ 改写莫尔量子态 → 再次读出 HHG 指纹验证。闭环的关键是 R1 正向模型同时服务于"反演"（R2 的逆问题求解）和"调控预言"（R3 的靶标预测），避免理论与实验脱节。

**探针与调控的共用平台切换**：R2（探针）与 R3（调控）共用同一套中红外 HHG 平台，通过驱动场参数切换工作模式——探针模式采用弱场（I < 10¹¹ W/cm²，线性响应区边缘）读取指纹；调控模式采用强场（I ~ 10¹¹–10¹² W/cm²，Floquet 重构区）改写能带。两模式共享光路、样品与检测系统，仅驱动场强度与椭偏配置不同，确保探针读出的指纹与调控改写的态对应同一体系。详细的强度窗口划分与切换协议见方法学手册 §3F。

### 3.2 R1：莫尔体系强场响应的有效理论模型

**问题起点（回应评审 C2）**：候选方法路线写"TDDFT + 张量网络 + 莫尔势能反演"，但三者存在尺度与范式的不可直接耦合——TDDFT 适用于百–千原子尺度、Kohn-Sham 单粒子框架；张量网络(DMRG/MPS)受限于小 Hilbert 空间/准一维；而 magic-angle TBG 的莫尔原胞含 >10⁴ 个原子，标准 TDDFT 计算量不可承受。本项目不回避这一硬伤，而是给出明确的降阶策略与桥接界面。

**降阶策略（三段式耦合）**：

1. **TDDFT 参数标定（最小原胞）**。仅在均匀极限（单层原胞，~10² 原子）下用 TDDFT 计算单层能带、跃迁偶极矩与有效质量，标定下游紧束缚模型的跃迁参数 t、 onsite 能量 ε、以及 SBE 所需的偶极矩阵元 d_nm(k)。此步计算量在团队现有资源内（详见计算资源账本，方法学手册 §3B.3）。

2. **连续莫尔紧束缚模型 + SBE（莫尔尺度）**。将标定参数注入连续莫尔哈密顿量 H_Moiré(θ)（θ 为扭转角），在莫尔布里渊区用 SBE 求解强场电子动力学。该步避免了全原胞 TDDFT 的 >10⁴ 原子灾难，计算尺度为莫尔 mini-布里渊区（~10²–10³ k 点），是本项目理论计算的主力。SBE 框架已由团队在 ZnO/MgO 体系中验证（偶次谐波偏振旋转角复现偏差 < 6%，见前期工作基础），迁移到莫尔体系属增量开发。

3. **张量网络关联修正（强关联子空间）**。仅在 flat band / 关联绝缘态等强关联子空间（Hilbert 维度可控，~10⁴–10⁵）启用 DMRG/MPS 修正，计算 Hubbard-U 引发的多体修正 ΔΣ(ω)，再以自能修正项形式反馈回 SBE。这一耦合界面的误差传递通过对照基准量化（方法学手册 §3B.4）。

**莫尔势能反演的正则化（回应评审 H3）**。从 HHG 谱反演莫尔势能是欠定逆问题，解不唯一。本项目采用三层正则化保证稳定性与唯一性：
- **物理先验约束**：扭转角 θ 已知范围（样品制备精度 ±0.05°）、莫尔势的 C₃ 对称性、平移对称性作为硬约束，大幅压缩解空间。
- **多观测联合**：单一 HHG 谱欠定，本项目联合 HHG 谱 + 椭偏依赖 + 瞬态吸收（ATAS）三类观测量，分别编码莫尔势的不同分量，联合反演显著提升条件数（方法学手册 §3C 给出条件数改善的数值验证）。
- **Tikhonov 正则化 + 合成数据误差棒**：对反演结果给出置信区间，并通过合成数据（已知莫尔势的正问题模拟谱）反演验证误差棒 < 15%。

### 3.3 R2：莫尔 HHG 谱学探针与势能反演

**材料聚焦（回应评审 M2、H2）**。候选方向原列 4 类材料（magic-angle TBG / TMDC 异质结 / graphene-hBN / 铁谷莫尔），过宽，违背面上"小切口深挖掘"。本项目收敛至 **1 主 + 1 对比**：
- **首选：TMDC 莫尔异质结（tMoS₂ / tWSe₂，小角度 ~1–3°）**。理由：TMDC 莫尔体系带隙可调（~1–2 eV）、flat 程度可调（通过角度与层间耦合）、且存在带隙避免了石墨烯零带隙导致的强场损伤与信噪比问题。小角度非 magic 的 TMDC 异质结兼具 flat-band 物理与可接受 HHG 产额，是平衡"物理丰富性"与"信号可测性"的最优切口。
- **对比验证：magic-angle TBG（~1.1°）**。作为 flat-band 极限的对比，验证 R1 理论在最强 flat-band 极限的适用边界。
- graphene-hBN 与铁谷莫尔列为后续重点项目延伸，不在本期 4 年计划内。

**flat-band HHG 产额物理张力处理（回应评审 H2）**。flat band 群速度低，传统图像下 HHG 产额依赖载流子类弹道加速度，故 flat-band 体系 HHG 效率偏低。本项目的应对：
- (a) **量级估算**：基于 R1 的 SBE 模型，对 tMoS₂（带隙 ~1.5 eV，扭转角 2°）预估 HHG 截止阶次 ~7–11 阶、信号强度相对体相 ZnO 低 ~10–50 倍（仍可探测，详见方法学手册 §3E 产额估算）。关键依据是 TMDC 莫尔体系虽 flat，但仍保留带隙与带间跃迁偶极矩，HHG 通道未被完全淬灭。
- (b) **备选体系**：若 tMoS₂ 产额不足，退守至角度更大（~3–5°）的 TMDC 异质结，flat 程度降低但 HHG 产额提升，通过角度扫描寻找"物理丰富性 vs 信号可测性"的最佳工作点。
- (c) **既有支撑**：莫尔体系 HHG 已有理论与实验先例——Mrudul 等 2023 已演示扭转角的 HHG 读出 [CITE:mrudul_2023_moire]，证明 HHG 对莫尔自由度敏感；本项目在此基础上从"读出"升级为"反演+调控"。

**实验关键参数（回应评审 H4，完整参数表见方法学手册 §3D）**：
- 驱动光源：中红外 OPA/OPCPA，λ = 1.3–4.5 μm（可调谐，匹配 TMDC 带隙），脉冲能量 > 5 μJ，脉宽 < 50 fs，重频 1–100 kHz（高重频提升信噪比，因莫尔样品微米级且产额低）。
- 探测方案：积分测量（目标谐波阶次 3–11 阶），椭偏分辨（偏振扫描 0–360°，精度 < 2°），泵浦-探测时序（ATAS 模式，时间分辨率 < 50 fs）。
- 损伤阈值余量：TMDC 莫尔样品损伤阈值估算 ~10¹² W/cm²，工作强度 10¹¹–5×10¹¹ W/cm²，余量 > 2 倍（方法学手册 §3D.2）。

### 3.4 R3：强场主动调控莫尔量子态

**调控机制的具体化（回应评审 H1）**。"主动调控"是本项目相对 Mrudul 2023（仅读出）的核心差异化，必须落到可测机制。本项目选定 **光 Floquet 工程** 作为主调控机制：

- **物理机制**：周期性强场（频率 ω，强度 I）通过 ac-Stark 效应重构莫尔能带，等效哈密顿量 H_eff = H_Moiré(θ) + H_Floquet(I, ω, ε)。驱动场强度与椭偏作为两个连续可调参数，可在亚周期时间尺度改变 flat band 的带宽、关联绝缘态的能隙，甚至诱导拓扑转变。
- **可观测靶标**：聚焦两个可证伪、可测量的靶标——
  - **靶标 A：相关绝缘态的光致熔化**。TMDC 莫尔异质结在半填充附近存在关联绝缘态（ν = 1），强场可在飞秒尺度破坏电荷序，HHG 谐波强度与椭偏应在熔化阈值处出现特征跳变（理论预言跳变幅度 > 20%，方法学手册 §3G）。
  - **靶标 B：flat band 带宽的光致调制**。Floquet 重构改变 flat band 带宽，HHG 截止阶次与谐波标度（I_n ∝ I^α）应在 Floquet 参数空间呈现可分辨变化。

**可证伪假设（回应评审 H5）**。本项目给出 3 个定量、可证伪的预测，与 R1 理论计算直接对接：
- **假设1（R2 对应）**：TMDC 莫尔异质结扭转角每变化 0.1°，HHG 椭偏依赖将产生 > 5% 的可分辨变化。该假设可由角度依赖的 HHG 椭偏扫描直接证伪。
- **假设2（R1 对应）**：flat-band 体系（magic-angle TBG）在驱动强度 ~3×10¹¹ W/cm² 下出现谐波饱和特征（高阶谐波强度不再随光强增长），饱和阶次由 flat band 带宽决定。该假设可由光强扫描的谐波标度测量直接证伪。
- **假设3（R3 对应）**：光 Floquet 调控可使 TMDC 莫尔关联绝缘态在强度阈值 I_c 处发生光致熔化，HHG 谐波在 I_c 处出现 > 20% 的强度跳变。该假设可由强度扫描的直接观测证伪，熔化阈值 I_c 由 R1 理论定量预言。

**风险与对策**：

### 3.5 方法学创新

本项目提炼 3 个方法学贡献，与 Mrudul 2023 [CITE:mrudul_2023_moire] 及候选1（QGT 反演）明确划界：

1. **莫尔体系强场响应的降阶有效模型构建方法**。针对 magic-angle 原胞 >10⁴ 原子的 TDDFT 不可承受问题，建立"TDDFT 标定 → 连续莫尔紧束缚 + SBE → 张量网络关联修正"的三段式降阶框架，给出可量化的耦合界面与误差传递协议。该方法可推广至任意大原胞莫尔/超晶格体系的强场响应计算，超越 Mrudul 2023 仅用紧束缚而无多体修正的处理。

2. **莫尔势/扭转角的多观测联合反演算法**。针对 HHG 谱反演莫尔势的病态性，建立"物理先验硬约束 + HHG/椭偏/ATAS 三类观测量联合 + Tikhonov 正则化"的反演框架，给出唯一性的数值论证与误差棒。相比候选1（QGT 反演依赖多频场+椭偏+ATAS），本方法针对莫尔自由度（扭转角、莫尔势）定制，是莫尔体系的首个系统反演方案。

3. **"光控+光读"闭环协议**。首次将强场非线性光学同时用于莫尔态的读出（R2）与改写（R3），通过驱动场参数切换实现探针/调控双模式共用平台。该闭环协议可推广至其他莫尔量子态（超导涨落、拓扑边界态）的主动操控，形成"强场探针 × 莫尔物理"的通用方法学。
