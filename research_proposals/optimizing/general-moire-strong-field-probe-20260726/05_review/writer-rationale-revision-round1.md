## 三、口径纠偏（独立核验，未按指令回改）

writer prompt 内跨章口径表载 1.3 μm 端 I_c 为 `2.7×10¹⁰ / 1.1×10¹¹–4.3×10¹¹ / 1.1×10¹² W/cm²`。经核，该组值是 **r4 之前**的旧基线（λ = 3 μm 基准 `5×10⁹–2×10¹¹` × (3/1.3)² = 5.325）：

- `05_review/critic-round-4-method_manual.md` L116–L122 明确将四章旧值 `2.7×10¹⁰ / 4.3×10¹¹ / 1.1×10¹²` 统一改为现行值，并复核"命中 **0**"；
- 方法手册 §3F.0/L629 现行 λ = 3 μm 基准为**联合包络 7×10⁹–2.3×10¹¹**（典型 2×10¹⁰–8×10¹⁰）。按 (3/1.3)² = 5.325 复算：7×10⁹ → 3.73×10¹⁰、2×10¹⁰ → 1.07×10¹¹、8×10¹⁰ → 4.26×10¹¹、2.3×10¹¹ → 1.225×10¹²，与磁盘现行值 `3.7×10¹⁰ / 1.1×10¹¹–4.4×10¹¹ / 1.2×10¹²` 逐项闭合，与旧基线不自洽。

故本轮**保留现行值不动**，未按口径表回改。理由：现行值与方法手册（单一真相源）算术闭合，旧值在磁盘上已被显式作废（round-4 复核命中 0）。若口径表为最新口径，应先更新方法手册 §3F.0，再同步三章。
