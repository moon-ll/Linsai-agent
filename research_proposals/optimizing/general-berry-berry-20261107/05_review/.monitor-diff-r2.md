+理论环节建立统一非平衡量子输运框架，输出三类几何机制的共同响应函数、标度交叉场强阈值表达式与对称性选择定则。第一性原理环节以 Wannier 插值把框架所需的能带几何参数化，输出各候选材料的量子几何量随外场参数的演化，以及手性太赫兹增益阈值与干涉项符号翻转条件。实验环节以无自由参数的形式检验前两个环节的联合预言，输出横向光电流标度行为、螺旋度依赖与门压符号翻转的实测结果，并据此判断三类机制的共存与竞争关系。
+
+三个环节的技术选择各有明确理由。弛豫时间近似足以刻画 Berry 曲率密度极值点附近的非平衡占据，而本项目的核心正是几何量与分布函数的耦合关系，所需参数亦可由第一性原理直接给出，因此不必动用更严格的多体方法。Berry 曲率与量子度规需要对整个费米面做动量空间积分，实空间方法的局域性在此处构成限制，Wannier 插值由此成为参数化手段。干涉项的有无由两类通道的螺旋度变换行为共同决定，单一偏振的强度测量无法把干涉贡献与各通道自贡献分离，螺旋度分辨测量由此成为提取手段。
+
+框架的适用范围与失效边界随上述选择一并确定。弱场端的判据取 k_E = eEτ₀/ℏ 与 Berry 曲率密度极值点到费米面的动量距离 k_BC 之比。ε = k_E/k_BC ≪ 1 时解析展开成立，二次幂标度可复现。ε ≳ 1 的强场区由准线性标度占据，标度指数不再由 Berry 曲率偶极单独决定，此处亦正是弛豫时间近似开始失稳的位置。当偏置场继续升高使 k_E 超过费米面动量尺度 k_F 时，费米面本身被重构，弛豫时间近似与 Berry 曲率偶极计算的可靠性同时失效，该区间的处理须转入非平衡稳态格林函数方法[27]。本项目的定量结论因而限定在 k_BC ≲ k_E ≲ k_F 的区间内。螺旋度分辨的横向光电流测量在偏置场低于 2.1×10⁴ V/m 时仍处于弱场区，其干涉项提取不受这一边界的影响。
+
+技术路线可分解为三个步骤。步骤一建立统一非平衡量子输运框架，把强场完全非平衡载流子分布、光抽运带边粒子数反转、偏置场重整跃迁偶极与带内速度导致的场致 Berry 曲率修正、光致 Berry 曲率纳入同一响应函数。解析导出 Hall 电流标度的交叉场强阈值、手性太赫兹增益条件，以及场致与光致 Berry 曲率干涉项的表达式和对称性选择定则。步骤二对候选材料完成第一性原理参数化与定量预言，沿研究内容设定的三个扫描自由度逐点计算，输出研究内容所要求的阈值载流子密度、量子效率与最优材料平台判据。步骤三设计实验判据并在器件上完成验证。
+
+### 3.2 分方案一：统一非平衡量子输运框架的构建
+
+#### 3.2.1 载流子分布的动力学方程
+
+非平衡分布函数由弛豫时间近似的动力学方程确定。方程的碰撞项记为杂质弹性散射导致的弛豫时间，其表达式依赖于被扰动后的分布函数，方程在 k 空间与分布函数之间由此构成自洽耦合，这一耦合正是强场区标度行为的来源。
+
+方案上分两步推进。第一步在直流偏置条件下求解，引入无量纲化的动量尺度 k_E = eEτ₀/ℏ 与 Berry 曲率密度极值点到费米面的距离 k_BC，以 ε = k_E/k_BC 作为区分弱场与强场的判据。在 ε ≪ 1 区间验证解析展开可复现二次幂标度，在 ε ≳ 1 区间观察准线性标度的出现并定位交叉位置。第二步加入交变偏置场，把方程转为含时形式，求解周期稳态分布函数后作傅里叶分解得到各 nω 谐波。
+
+直流条件先行有其物理上的便利。直流情形下分布函数与弛豫时间的耦合是定常的，标度指数与交叉场强可作解析展开并读出系数；交流情形下该耦合随时间演化，直接求解虽可行，但各项贡献的来源难以分辨。
+
+#### 3.2.2 几何通道的纳入与耦合求解
+
+几何量的处理需要在跃迁矩阵元层面完成，而非在输运系数层面外加。偏置电场对带间跃迁偶极矩的重整通过位移算符作用在初末态上实现，对带内速度的重整通过能带色散的场致偏移实现，对跃迁能量的重整通过 shift vector 与偏置场的耦合实现。光致 Berry 曲率则以 Floquet 重整进入跃迁矩阵元，与上述三条场致通道共用同一套量子几何极化率张量与 shift tensor。
+
+方案上把跃迁矩阵元的场依赖与分布函数的自洽求解合并进行，即每次迭代中依据当前分布函数重算占据态相关的跃迁矩阵元，再据此更新响应函数。这一处理方式与 Murotani 等人建立的光伏霍尔统一框架在跃迁矩阵元层面同源，差别在于本项目的占据态来自被直流偏置场强烈驱动的非平衡分布，而非光致态。
+
+保留干涉项的做法是：在响应函数中不按通道分别计算后再叠加，而是把各通道的横向电流贡献写为同一响应核下的不同算符形式，使交叉项由算符非对易性自然给出。由此可直接读出干涉项在何种对称性条件下非零。两通道算符在相应对称性操作下的变换行为一致时交叉项不消失，否则因对称性而抵消。
+
+#### 3.2.3 解析结果的输出
+
+框架输出三类可直接检验的结果，各自以闭式表达式给出，便于逐项与实验数据比对。Hall 电流标度指数的交叉场强阈值，由弛豫时间 τ₀、Berry 曲率偶极分量大小与费米面几何共同决定。手性太赫兹增益条件，给出横向光电导实部取负所需的偏置场强、载流子密度与抽运频率的组合关系。干涉项表达式，给出场致与光致 Berry 曲率交叉贡献随门压、抽运光相位与螺旋度的依赖形式。
+
+这三条闭式结果并非终点，其数值走向由第一性原理扫描独立给出，两条路径构成互相校验的关系。交叉场强阈值由解析式对 τ₀ 求得，而 τ₀ 在预言中作可扫描参数，同一解析式按第一性原理扫描读出的 Berry 曲率密度分布逐点评估，给出一条交叉场强随 τ₀ 变化的曲线。第一性原理扫描则从同一几何量出发，由 Berry 曲率密度极值点位置 k_BC 与费米面动量尺度 k_F 定出 ε = 1 所对应的场强。二者对同一材料给出同一物理量的两个独立数值，两值的相对偏差用作框架内部一致性检验。按研究内容给定的定义，统一框架对至少两类候选材料给出的交叉场强预测相对偏差不超过 30%，两类材料同时满足方判定该一致性成立。这一判据不含实验测量环节，比较的是理论内部的两条计算路径，其 30% 的容差与标度判据 20%、门压判据 15% 分属不同性质的分辨能力，不相互借用。
+
+不通过时区分两种情形并各有排查路径。框架未给出标度过渡者，回到本节检查 k_E 是否已越过 k_F，即分布函数边缘是否已抵达 Berry 曲率热点；过渡位置超出容差者，回到第一性原理环节检查 Berry 曲率密度极值点位置 k_BC 的计算精度。
+
+### 3.3 分方案二：候选材料的第一性原理参数化
+
+#### 3.3.1 能带与几何量的计算
+
+第一性原理计算采用 DFT 结合 Wannier 插值。流程为先自洽计算得到电荷密度与能带，选取适当窗函数构造 Wannier 函数以确保关键能带的解析性与时间反演对称性，随后在均匀动量网格上计算 Berry 曲率、量子度规与 Berry 曲率偶极张量分量。
+
+Berry 曲率偶极是 Berry 曲率密度对动量的加权积分，权重随费米面位置改变。实验关心的是这一积分量随门压与应变的演化，Wannier 插值允许在同一套 Wannier 函数上改变费米能并重复计算，既避免了重复的自洽计算开销，也保证了不同费米能下的几何量出自同一套布洛赫态，这正是从头计算直接输出所不能提供的。
+
+几何量的场致修正以两类方式纳入。跃迁偶极矩的场致重整在能带层面计算，即对含场的哈密顿量重新构造 Wannier 函数并提取跃迁矩阵元的场依赖。带内速度的场致偏移由能带色散在偏置场下的偏移给出。
+
+#### 3.3.2 参数扫描与判据输出
+
+扫描沿研究内容设定的三个自由度展开，每个采样点输出 Berry 曲率偶极张量分量、量子度规分量、横向光电导的场致项与光致项，以及两者的干涉项。
+
+计算输出三类判据结果。手性太赫兹增益判据给出各材料平台的阈值载流子密度与达到给定增益所需的偏置场强，并结合碲一类材料已知的介电函数共振结构，给出可激光频段与所需偏置场的组合。干涉项符号翻转判据给出在所选材料平台上实现翻转所需的门压区间与抽运光相位窗口。标度交叉场强判据给出由 Berry 曲率密度分布的极值点位置算得的 k_BC 与 k_F 之比，以及对应于目标弛豫时间的交叉场强范围。
+
+材料平台排序按研究内容给定的三项指标分别列出，不合成单一评分。以碲为例，其 Berry 曲率偶极张量分量在以 ħ/e 为单位的约定下取 D_B = −8.99×10⁻³，为无量纲量，与载流子浓度 0.784×10¹⁶ cm⁻³ 一并给出明确的增益阈值参照，可作为本项目排序结果的标定点。这一量的量纲自洽性由回旋频率关系确认：Berry 曲率偶极进入 ω_c = τe³D_B E₀/(ε₀ℏ²) 时，ω_c 量纲为频率，τ 与 ε₀ℏ² 给出其余各量所需的组合，故 D_B 只能是无量纲量。
+
+阈值场强的取值区间由增益条件与器件耐压共同限定。已有计算给出的三方碲增益阈值覆盖 2.1×10⁴ 至 4×10⁵ V/m 的偏置场范围，具体的几何配置与频带对应关系在立项依据中给出[14]。本项目的增益判据以这一区间为有效范围，超出该区间的偏置场需要另行评估器件击穿与载流子注入带来的非几何机制。
+
+### 3.4 分方案三：实验判据设计与器件验证
+
+#### 3.4.1 脉冲偏置场标度测量
+
+测量在门控可调的二维或块体器件上进行。偏置场以脉冲形式施加，以避免稳态加热把标度行为推离几何机制主导的区间；横向电流由四端配置读取，纵向电流与偏置场同步记录。
+
+时序设计的关键在于把热电子效应与几何响应在时间上分开。脉冲宽度选在远短于晶格热弛豫时间而长于载流子散射时间的区间，热电子积累尚未达到热平衡即被读取，此区间的响应携带的是分布函数非平衡而非晶格加热的信息。标度指数由横向电流对纵向电场的幂律拟合给出，交叉场强由指数随场强的转折点确定。
+
+直流偏置方案不具备这一分离能力。直流条件下热电子与晶格温度在测量窗口内充分建立，几何机制与非平衡热效应在标度上完全混合。脉冲方案把区分两者的判据从标度指数转移到时间尺度，一次测量即可兼取两类信息。
+
+脉冲宽度的取值参照超快非线性霍尔效应的既有时间尺度确定，取的是文献报道的时标参照值而非本项目自身的指标。在中心对称黑磷中用飞秒脉冲动力学破缺对称性实现的超快非线性霍尔效应，其横向电流仅在泵浦偏振沿扶手椅高对称方向时出现，并持续超过 300 fs[28]。谷间布居不对称因子由初始约 60% 经约 200 fs 衰减到稳定值约 23%，该结果以预印本形式报道。这一结果表明，几何响应在对称性恢复之前已经完成，而布居不平衡在数百飞秒内弛豫。本项目的脉冲宽度取 100 fs 量级，短于该弛豫时间窗而长于载流子散射时间，落在热电子积累尚未充分建立而几何响应已形成的区间内。
+
+标度判据的读数方式在这一环节确定。交叉场强取横向电流标度指数随场强的转折点，因过渡带内位置只能定位到约两成的区间，该读数按置信带而非单点记录，与第一性原理算得的 Berry 曲率分布预测对照后按统一容差判定。
+
+#### 3.4.2 螺旋度分辨的横向光电流与太赫兹发射测量
+
+光路以可调相位板与线偏振片组合实现抽运光的螺旋度与相位可控切换，在器件表面以斜入射几何提供沿晶轴方向的偏置场分量与沿晶面方向的传播波矢。场致与光致 Berry 曲率在这一几何下均不为零，且可分别调制。
+
+测量分两路。横向光电流由器件电极直接读取，其中螺旋度奇分量的幅度给出干涉项的强度，其随偏置场、门压与相位的符号变化给出符号翻转位置。太赫兹发射由电光采样或时域太赫兹探测读出，螺旋度分辨的发射谱给出手性增益的频带宽度与偏振选择性，可与第一性原理计算的增益频带对照。太赫兹驱动下二阶横向输运的门压可调性已在二维碲烯中给出实测：非线性霍尔、非线性纵向与非线性对角三种贡献被逐项分离，且均可由门压调控[29,33]。这为本项目的门压扫描提供了直接的器件级参照。
+
+光电流与太赫兹发射一并纳入测量的理由是，两者对干涉项的敏感度不同。光电流直接给出电流核的符号信息，太赫兹发射给出电流核在频域的分布，两者结合可以把干涉项与单通道自贡献在频率维度上分开，这比单一测量的唯一性更高。
+
+抽运光波长按带间激发条件选取。块体碲在斜入射近红外光（λ = 0.780 μm）带间激发下给出零偏光电流，其平行于螺旋轴的分量呈现圆偏光生伏特效应，本征旋光光电导张量分量 β 为数至数十 nA/W，且带间激发所得 β 可能大于带内激发[32]。取 0.780 μm 的依据在于该波段已给出可比的旋光光电导量级，可直接作为本项目横向光电流幅度的参照基准，而不必另行引入量纲换算。偏置场强度扫描窗口取 10⁴–10⁵ V/m，覆盖弱场标度区与几何重整起效区。
+
+#### 3.4.3 器件实现与验证
+
+器件选型以已有文献验证过的材料平台为优先，并按判据对材料性质的要求锁定主选载体。载体选择的具体依据见研究内容所述，本节只补充其在器件实现层面的条件：三方晶轴取向须在样品制备中保留，背栅门控须给出连续的费米能穿越，制备路线须与文献已验证的碲烯工艺一致。
+
+偏置场扫描窗口的下界由器件承受能力与信号量级共同确定。上界 10⁵ V/m 低于碲平台增益阈值场窗的上限 4×10⁵ V/m，留出足够的器件耐压裕量。下界 10⁴ V/m 对应场致 Berry 曲率重整量级过小、干涉项淹没于散粒噪声的区间，取值需靠近增益阈值场窗下限 2.1×10⁴ V/m 一侧加密，以换取足够的信噪比。该下界低于增益阈值场窗下限并不与器件能力冲突：太赫兹场驱动的非线性输运实验在碲烯器件上于远低于击穿场的场强下即可读出二阶响应，场强本身不构成器件耐压的约束，真正的约束来自增益阈值所要求的场致重整量级。增益阈值场窗的下限同时是螺旋度分辨测量中干涉项提取不受影响的场强界。
+
+器件制备沿用二维碲烯的制备路线，作为参数窗口的实测依据。水热法合成的碲薄片经干法转移与 h-BN 叠层，电子束光刻制 Hall bar 底电极，溅射蒸镀金属接触形成欧姆接触，背栅氧化层作为门控介质。同一路线已支撑门压可达 ±20 V、对应载流子浓度约 5×10¹² cm⁻² 的二维碲烯器件，室温迁移率空穴约 430 cm²/Vs、电子约 170 cm²/Vs[33]。这一组参数给出本项目门压判据的可实现范围，符号翻转所需的门压区间只有落在这一范围之内，门压扫描才能给出连续可调的费米能穿越。
+

+### 3.5 可行性分析
+
+#### 3.5.1 理论方案的可行性
+
+统一框架所需的三个要素在既有文献中均已各自成立。强场非平衡分布的处理有 Sur 等人基于弛豫时间近似玻尔兹曼方程的推导，其 k_E 与 k_BC 的标度判据与准线性标度的出现已被确认[6]。光抽运与场致几何重整的统一处理有 Murotani 等人建立在长度规范密度矩阵上的推导，其跃迁偶极矩、跃迁能量与带内速度三条重整通道的划分与对称性选择定则已经给出[15]。手性太赫兹增益的阈值与频带有 Eslami 等人对碲的定量计算作为参照，其给出的掺杂浓度、Berry 曲率偶极与阈值偏置场可作为本项目结果的标定点[14]。
+
+本项目的增量在于把三者置于同一响应函数并保留交叉项。这一做法在技术上是可行的，因为三条路径在跃迁矩阵元层面共享同一套占据态表述：场致重整作用于跃迁矩阵元，光致重整同样作用于跃迁矩阵元，而非平衡分布决定占据态。三者的耦合在矩阵元层面自然闭合，而不需要额外的唯象假设。

+#### 3.5.2 第一性原理方案的可行性
+
+计算方案所需的能力均已具备。Berry 曲率与量子度规的动量空间积分是标准流程，Wannier 插值在拓扑材料计算中已有成体系的实施流程，且相关方法已在 WTe₂、TaIrTe₄ 与碲等体系上产出过与实验一致的 Berry 曲率偶极数值。

+#### 3.5.3 实验方案的可行性
