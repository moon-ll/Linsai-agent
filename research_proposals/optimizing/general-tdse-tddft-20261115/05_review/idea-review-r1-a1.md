## 二、可检验性（validation 模块给出判据、对照与独立交叉验证路径）

### 核查结果：这是本设想最强的一维，但对照组的设置有实质漏洞

**判据层：优秀。** `00_idea-dossier.md` 路线 4 给出五组带数值的判据：
- 长时稳定性：‖U†U−I‖ 谱范数 < 1e-3，范数漂移 < 0.1%，>100 光学周期，且误差标度指数不劣于 Crank-Nicolson
- 外推校准：波长外推至训练上限 1.5–2 倍时预测区间保持 85–95% 经验覆盖率
- 反演精度：强度平均相对误差 ≤ 3%（对照原位定标 ~20%）
- 闭环增益：同等精度下仿真调用数下降 ≥ 一个量级
- 迁移有效性：TDSE 预训练 + 少量 TDDFT 微调优于等数据量纯 TDDFT 训练

判据可计算、可比较、含明确阈值，符合"判据 + 对照 + 交叉验证"的完整形态。

**替代解释排除：形式上完整，但有一处失效。** dossier 路线 5 列出七类替代解释并给出排除方法（OOD 划分强制外推、CEP 平移对称性测试、特征置换消融、误差累积标度分析、等预算网格/随机基线、等数据量消融、留出实验条件覆盖率检验）。这是本领域少见的自觉，予以肯定。

**失效点 1（重要）："闭环增益 ≥ 一个量级"这一判据的对照不成立。** dossier 自己写明闭环机制是"以贝叶斯实验设计/主动学习把步骤一代理作为在线仿真器、步骤二反演器作为观测算子"。但在这种设计下，代理既是"被评估的省时对象"又是"闭环的采样来源"——**闭环增益测量的是"用代理替代真 TDSE 做模拟采样"的加速比，其基线必须是同样使用主动学习但以真 TDSE 为仿真器的版本**。dossier 路线 5 写的是"与同预算网格/随机基线严格对照"，网格/随机基线是**非主动学习**的被动基线。与被动基线比出"一个量级"，很可能只是主动学习本身相对被动采样的收益，而非"代理加速"的贡献。

修改建议：增设**双基线**，并明确把两个增益分离报告——
- 基线 ①：主动学习 + 真 TDSE 仿真器（隔离"代理加速"的净效应）
- 基线 ②：网格/随机采样 + 真 TDSE（隔离"主动学习"的净效应）
把"仿真调用数下降"拆成两段归因：主动学习节省多少、代理替代真 TDSE 节省多少。当前设计会把两者混为一谈，导致最响亮的那个数字（"一个量级"）无法归因。

**失效点 2（重要）："反演精度 ≤ 3%"未排除"参数可辨识性"这一前提。** 四参数联合反演（强度/脉宽/啁啾/CEP）的可行性依赖参数在谱中的**可辨识性**（Fisher 信息 / 参数间简并性）。CEP 尤其可疑：CEP 的影响在光电子谱中通常表现为亚周期对称性破缺，在二维动量谱中是否具备足够信噪比与空间分辨率来支撑 CEP 回归，是物理问题而非 ML 问题。dossier 对脉宽/啁啾/CEP 只写了"分别给出量化阈值"——这是把判据推迟，不是给出判据。

修改建议：在步骤二前置一个**可辨识性预研**——对 TDSE 真值谱计算四参数的 Fisher 信息矩阵 / 参数相关性，判定 (a) 单张谱是否足以支撑四参数联合反演；(b) 若不可辨识，是否需要多谱（不同延迟/不同偏振/不同取向）联合输入。若不可辨识，正确的研究问题应改为"在可辨识参数子集上做联合反演，并量化不可辨识方向的判据边界"——这仍是有价值的科学问题，且比宣称四参数联合更诚实。若可辨识，须给出 FIM 数值证据。

**失效点 3（中等）："迁移有效性优于等数据量纯 TDDFT 训练"缺少基线中的第三个对照。** Δ-学习的经典陷阱是"预训练模型隐含了 TDSE 层级的信息，该信息在 TDDFT 层级仍然部分有效"。当前对照（TDSE 预训练+微调 vs 等数据量纯 TDDFT）只能证明"预训练有增益"，不能证明"Δ-学习修正了层级差异"。建议增加第三个对照：**随机初始化 + 等数据量 + 同一微调预算**（即"直接微调"基线），以区分"预训练初始化"与"Δ-学习修正"两项贡献。

**失效点 4（中等）：判据 ④"仿真调用次数下降"与判据 ①"长时稳定性"之间存在未闭合的依赖。** 一个不保幺正性的代理当然也更快。要说明"加速"不是以牺牲物理正确性为代价，需给出**加速比在同等精度下的比较**（对标 Crank-Nicolson 在同一精度下的耗时），否则"更快的错解"也满足判据 ④。dossier 判据 ④只约束调用次数，不约束精度对齐方式。

**独立交叉验证路径**：存在且较强——文献已发表的 COLTRIMS 类实验光电子动量谱盲测（dossier 路线 3 末 + 边界界定"实验侧仅使用文献已发表的 COLTRIMS 类数据做离线盲测"）。这是真正的外部交叉验证，而非自证循环。予以肯定。

### 打分

- 判据与量化阈值：优秀
- 对照组：有一处失效（闭环增益基线错位）+ 一处缺失（可辨识性预研）+ 一处不完整（迁移三对照）
- 交叉验证：具备外部盲测路径，强
- 口径 B 评分：**0.76**

### 核查结果：增量说得清楚，但"已有工作"列有**两处经核实不成立**，其中一处直接动摇核心创新点

**A. 新颖性比对：通过。** `00_idea-dossier.md` 与三个最近邻课题的相似度分别为 0.01 / 0.01 / 0.00（key-transient-quantum-phase-optical-20260726、general-moire-strong-field-probe-20260726、general-quantum-geometry-inversion-20260726），组合重叠度 0 个课题 ≥ 0.30。与现有课题的方法骨架确属不同：

本课题以 TDSE/RT-TDDFT 代理 + 光电子谱反演为对象，与上述三者在物理对象、观测通道、方法骨架上均不同源。**不是换皮课题。** 这一维的底子是好的。

**B. 与三篇参考工作的逐项对比：形式完整，但"已有工作"列的事实错误必须更正。** dossier 对比表有五行、增量陈述清楚（结构保持传播子 / UQ-OOD / 多参数可解释反演 / 正逆闭环 / 跨层级迁移），确实"说得出增量"，符合模块⑤要求。但对参考工作的**事实描述**经联网核实存在以下问题：
