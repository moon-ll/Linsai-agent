## 各方法详细说明

### 方法 M1：含时密度泛函理论（TDDFT）+ 多带紧束缚模型

- **适用模块**：研究内容一（层间滑移的超快相干驱动）
- **理论基础**：含时密度泛函理论（Runge-Gross 定理）是处理含时多电子体系的标准理论框架，原则上可在任意时间依赖外电场下精确描述体系的电子动力学。在实际计算中，采用 adiabatic LDA（ALDA）交换-相关核作为默认近似，对于强场问题需检验是否需要引入 meta-GGA 或 hybrid 泛函修正多体效应。多带紧束缚模型用于参数化层间滑移坐标与电子结构之间的耦合关系——滑移坐标作为外参数引入 Hamiltonian，通过在不同的滑移构型下计算能带结构，得到自旋劈裂参数对滑移坐标的依赖关系（Δ_spread(k_s)）。
- **实现细节**：TDDFT 计算采用开源软件（如 Octopus 或 Q-e 配合的 TDDFPT 模块），平面波基组截断能 80–100 Ry，k 点网格 12×12×1（对于 2D 体系），时间步长 0.01–0.05 a.u.（约 0.24–1.2 as）。多带紧束缚模型基于 Wannier90 提取的 Wannier 函数，构造 4–6 带的有效 Hamiltonian。层间滑移坐标以滑移层之间的相对位移 u 为参数，范围 [0, d]（d 为晶格常数），在每个 u 值下冻结原子位置进行静态自洽计算，然后用插值的 u 依赖 Hamiltonian 做实时 TDDFT 演化。
- **关键参数**：THz 驱动场强 0.1–1.0 MV/cm；层间滑移势垒 16–40 meV/unitcell（来自 DFT 静态计算）；光应力与位移电流机制的主导场强分界（计算确定，需在不同场强下分别建模）；切换概率的不确定性以不同泛函（PBE、PBE+U、Heyd-Scuseria-Ernzerhof hybrid）的计算结果方差度量。
- **数据分析**：从 TDDFT 演化中提取层间滑移坐标的时间依赖 u(t)，通过傅里叶变换得到滑移模式的频率成分；切换事件的判定标准为 u(t) 跨越势垒最大值的一半；计算切换概率 P_sw = N_switch / N_total（其中 N_total 为总模拟轨迹数，N_switch 为发生切换的轨迹数）。
- **局限性**：ALDA 近似在强场下的适用性存在争议，非绝热效应（如电子-空穴对的激子效应）可能需要多体微扰理论修正；紧束缚模型的准确性受限于 Wannier 函数对能带的拟合精度，高能态的贡献可能被截断；大规模超快模拟的计算成本限制了对真实材料尺寸的模拟，通常采用 3–5 层的超胞。
- **参考文献**：M1 对应 content.md §2.2

### 方法 M2：i-wave 自旋劈裂的磁点群理论与 HHG 选择定则

- **适用模块**：研究内容二（第四型交变磁自旋劈裂的 HHG 谱学指纹）
- **理论基础**：磁点群理论是分析磁性晶体中光学选择定则的标准工具。i-wave 自旋劈裂具有四次旋转对称性（C4），节点线穿过 Γ 点，这使得其在多光子过程中具有独特的角动量选择规则。在圆偏振驱动下，HHG 的第 n 阶谐波对驱动光的圆偏振方向（σ⁺ 或 σ⁻）具有选择性响应，响应差异由自旋劈裂的对称性决定。螺旋度交替幅度 A_helicity 定义为 A_helicity = [I_n(σ⁺) - I_n(σ⁻)] / [I_n(σ⁺) + I_n(σ⁻)]，其中 I_n 为第 n 阶谐波强度。椭圆度响应斜率 S_ellipticity 定义为 S_ellipticity = ∂I_n / ∂ε |_{ε=0}，其中 ε 为驱动光椭圆度。
- **实现细节**：首先在多带紧束缚模型（来自 M1 的材料模型）上构造 i-wave 自旋劈裂的 Hamiltonian，然后利用非微扰 Volkov 近似或数值求解含时薛定谔方程（TDSE）计算 HHG 谱。对于每个驱动参数（场强、椭圆度、圆偏振方向），在 10–20 个光学周期内取平均以获得稳定的光谱。理论预言的 HHG 指纹（螺旋度交替幅度、椭圆度响应斜率、偏振旋转角）通过 Monte Carlo 方法加入 10% 高斯噪声后进行模式识别，验证在实验可达到的信噪比下能否区分 i-wave 与 d-wave/g-wave。
- **关键参数**：驱动激光波长（中红外，1.5–3 μm）；圆偏振驱动下左右旋的螺旋度交替幅度（理论预言值）；椭圆度响应斜率（理论预言值）；Monte Carlo 信噪比模拟中的噪声水平（10% 高斯噪声）；分类准确率的判定阈值（≥3σ）。
- **数据分析**：建立自旋劈裂参数（Δ，节点线位置）与 HHG 光谱指纹量（A_helocity、S_ellipticity、偏振旋转角 θ）之间的解析关系表；通过多元回归或神经网络拟合，得到从 HHG 光谱到自旋劈裂参数的反演映射；验证反演映射的准确性（决定系数 R² ≥ 0.8 为可接受阈值）和唯一性（ Jacobian 矩阵条件数 ≤ 10）。
- **局限性**：理论模型假设理想的 i-wave 自旋劈裂，实际材料中可能存在节点线弯曲、拓扑缺陷等修正项；Monte Carlo 噪声模拟仅考虑了高斯噪声，未考虑系统误差（如激光功率波动、样品不均匀性）；HHG 指纹的反演精度受限于理论模型本身对真实材料的近似程度。
- **参考文献**：M2 对应 content.md §2.3

### 方法 M3：THz 泵浦-圆偏振 HHG 探测方案与 Floquet 缀饰理论

- **适用模块**：研究内容三（Rashba-Berry-磁序三元耦合的时域分离）
- **理论基础**：泵浦-探测技术通过调节泵浦光与探测光之间的时间延迟 Δt，获取体系在激发后的超快动力学。THz 泵浦用于激发磁序动力学（ps-ns 量级），圆偏振 HHG 探测用于读取电子层的自旋劈裂状态。时间延迟扫描的时间分辨率由泵浦-探测光路的稳定性决定（亚 100 fs 为目标）。Floquet 理论用于处理周期驱动体系的非平衡态物理——在高频驱动下，体系的准能量和有效 Hamiltonian 可通过 Floquet 近似得到，驱动场的效应被吸收到有效势中。Floquet 缀饰的引入可以在特定参数空间内相干增强弱交变磁贡献，同时保持对 Rashba/Berry 响应的分辨能力。
- **实现细节**：泵浦-探测方案的数值实现分为两步。第一步，在 TDDFT 框架下对 THz 泵浦脉冲进行实时演化，记录磁序参量（如Néel 矢量）的时间依赖 N(t)；第二步，在延迟时间 Δt 处注入探测脉冲（圆偏振中红外），计算电子层 HHG 响应。电子层与磁序层的时域分离度定义为 D_sep = [I_HHG(Δt = 1 ps) - I_HHG_baseline] / [I_N(Δt = 1 ps) - I_N_baseline]，其中 I_HHG 为 HHG 探测信号，I_N 为磁序信号。Floquet 缀饰参数扫描在驱动频率 0.5–3.0 THz、驱动场强 0.01–0.3 MV/cm 的二维参数空间内进行，寻找弱交变磁 HHG 信号增强 ≥ 5 倍的区域。
- **关键参数**：THz 泵浦场强（0.1–1.0 MV/cm）；泵浦-探测时间延迟范围（-5 ps 至 +50 ps，步长 50 fs）；电子层与磁序层时域分离度的判定阈值（≥ 80%）；Floquet 增强倍数（≥ 5 倍为有效增强）；信噪比 SNR ≥ 10（实验可行性基准）。
- **数据分析**：时域延迟扫描数据 I_HHG(Δt) 经去基线、去噪声后，分解为电子层贡献（fs-ps 衰减分量）和磁序层贡献（ps-ns 上升/振荡分量）；采用双指数拟合或主成分分析分离两层的信号；Floquet 增强区的判定通过对比有/无 Floquet 驱动下的 HHG 谱强度比值。
- **局限性**：THz 泵浦的激发效率受限于 THz 场与材料的耦合强度，高介电常数材料中 THz 穿透深度有限；泵浦-探测方案对光路稳定性要求极高（< 10 fs 抖动），对实验设备提出较高要求；Floquet 增强方案的效果受限于驱动场的相干性，非相干加热效应可能掩盖增强信号。
- **参考文献**：M3 对应 content.md §2.4
