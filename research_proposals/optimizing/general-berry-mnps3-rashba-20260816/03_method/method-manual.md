## 2 方法 M1：TDDFT + 多带紧束缚模型

**支撑研究内容**：R1（层间滑移模式的超快相干驱动理论）

### 2.1 软件与硬件环境

- **第一性原理计算**：Octopus（实时 TDDFT 模块），v12.1 及以上。替代方案：Q-e 配合 TDDFPT 模块（用于对比校验）。
- **紧束缚参数化**：Wannier90（v3.1+）提取最大局域化 Wannier 函数；tbmodels 或 pythtb 构造 u 依赖有效 Hamiltonian。
- **高性能计算**：申请国家级超算中心机时（典型需求：单节点 128 核 × 5000–10000 卡时 / 参数点）；建议采用 CPU + MPI 并行，内存需求 ≈ 50–80 GB / 任务（12×12×1 k 点，80 Ry 截断能）。

### 2.2 计算流程（算法步骤）

**Step 1：静态 DFT 基准计算**

对每个材料平台（NiCl₂、VS₂、CrSe₂ 单层及双层堆叠构型；MnPS₃|WS₂ 异质结），在滑移坐标 u 的若干离散值（建议 u/d = 0, 0.25, 0.5, 0.75, 1.0，共 5 个构型）下分别做静态自洽 DFT 计算。

- 交换-相关泛函：PBE（基准）+ PBE+U（U 值来自文献或线性响应计算）+ HSE06（抽样校验）
- 平面波截断能：80–100 Ry（2D 体系收敛测试：能量误差 < 1 meV/atom）
- k 点网格：12×12×1（Γ中心化）
- 真空层厚度：≥ 20 Å（避免周期性图像相互作用）
- 层间距离固定为静态势能面最小值对应的平衡间距；仅允许层间滑移自由度驰豫（原子间作用力阈值 < 0.01 eV/Å）

**Step 2：Wannier 函数提取与紧束缚参数化**

对每个 u 构型，用 Wannier90 提取 4–6 带有效 Hamiltonian：

```
选择投影：d 轨道（Ni 3d、VS₂ 的 V 3d、Cr 3d）；S / P 轨道（用于插值能带）
去纠缠过程：选取 10–12 个外带以保证 wannierisation 的一致性
输出：H_R（跳跃积分），H_k（k 空间 Hamiltonian），Berry curvature (u)
```

以 u 为横坐标，以 Δ_spread(k_s) = E_spin_up(k_s) − E_spin_down(k_s) 为纵坐标，构造离散数据点。用三次样条插值得到连续的 Δ_spread(u, k_s) 依赖关系。

**Step 3：TDDFT 实时演化**

以 Step 2 的 u 依赖 Hamiltonian 为初始条件，执行实时 TDDFT 演化：

- 时间步长：0.01–0.05 a.u.（0.24–1.2 as）；验证方式：能量守恒检验（总能量漂移 < 0.1% 在 100 光学周期内）
- 驱动场：THz 脉冲，场强 0.1–1.0 MV/cm，中心频率 0.5–3.0 THz，包络为 sin² 或高斯型（光应力机制：以偶极矩时间导数作为光致晶格力；位移电流机制：以光致偏振电场作为带电离子的直接作用力）
- 演化总时长：≥ 10 个光学周期（稳态谐波充分建立）
- 初始电子温度：0 K（基态），或费米-狄拉克分布 T_e = 300 K（热力学校验）

**Step 4：光-晶格耦合通道分离**

在同一驱动场强下，分别激活和关闭两个机制：

- 光应力机制建模：在 TDDFT 演化中，对每个时间步计算电子密度 n(r,t)，求其时间导数 ∂n/∂t，乘以电子-离子相互作用核得到晶格受力 F_lattice(t)
- 位移电流机制建模：在 Hamiltonian 中显式引入光致偏振项 P(t)（由位移电流 J(t) = ∂P/∂t 积分得到），作用于离子实

在低场（0.1 MV/cm）下验证两机制的线性叠加性（偏差 < 5%）；在强场（0.5–1.0 MV/cm）下追踪非线性竞争区间。

**Step 5：切换概率统计**

定义切换事件：u(t) 跨越势垒最大值的一半。执行 N_total = 50–100 条独立轨迹（初始电子态在费米面附近随机采样，模拟热激发初始条件）：

```
P_switch = N_switch / N_total
ΔP_switch = sqrt(P_switch * (1 - P_switch) / N_total)  [二项分布置信区间]
```

不确定性评估：对同一参数点，用 PBE、PBE+U、HSE06 三种泛函各算一遍，取结果的标准差作为系统性不确定度。目标：σ_PBE_PBEU_HSE ≤ 10%。

### 2.3 关键参数汇总

| 参数 | 取值 | 依据 |
|---|---|---|
| 平面波截断能 | 80–100 Ry | 2D 体系收敛测试，能量误差 < 1 meV/atom |
| k 点网格 | 12×12×1 | 工业标准，兼顾精度与成本 |
| 时间步长 | 0.01–0.05 a.u. (0.24–1.2 as) | 亚周期分辨率：THz 周期 ~ 333 as，需 ≥ 100 步/周期 |
| 驱动场强范围 | 0.1–1.0 MV/cm | 与 THz 放大器参数匹配；h-BN 先例（0.4 V/Å ≈ 4 MV/cm） |
| 滑移坐标 u 采样点 | 5 个（u/d = 0, 0.25, 0.5, 0.75, 1.0） | 三次样条插值精度验证：增加至 9 点时结果偏差 < 2% |
| 紧束缚带数 | 4–6 带 | 覆盖价带顶和导带底的主要贡献带 |
| 独立轨迹数 N_total | 50–100 | 二项分布统计：P_switch = 50% 时，ΔP/P ≈ 10% for N=100 |
| 磁交换作用 U 值 | NiCl₂: U = 4–6 eV；VS₂: U = 2–4 eV（文献值） | 线性响应计算或文献校准 |

### 2.4 验证方式

1. **能量守恒检验**：在无驱动场演化中，总能量漂移 < 0.1%/100 光学周期。
2. **泛函交叉验证**：PBE / PBE+U / HSE06 三泛函结果的标准差 ≤ 10% 即接受为系统误差上限。
3. **与文献对标**：双层 h-BN 层间滑移势垒的理论值（文献 2403.06531）与本方案计算值偏差 < 20%。
4. **收敛性测试**：k 点从 8×8×1 加密到 12×12×1 时，Δ_spread(k_s) 变化 < 5%。

### 2.5 潜在风险与替代方案

**风险 1：ALDA 近似在 MV/cm 强场下失效**

- 表现：PBE+U 与 HSE06 的 Δ_spread 偏差 > 10%，暗示绝热近似不充分。
- 诊断方法：在 Year 2 Q1 完成首次泛函对比；若偏差 > 10%，立即启动 GW-BSE 修正计算。
- 替代方案 1（轻度）：引入 meta-GGA 泛函（SCAN）替代 ALDA，计算成本增加约 30%。
- 替代方案 2（彻底）：采用 GW-BSE 方法计算含激子效应的 HHG 谱；计算成本增加 10–50 倍（视材料体系大小），建议仅在关键参数点使用。
- 回退触发条件：若 GW-BSE 与 ALDA 结果偏差 > 20%，在论文中明确标注为系统误差上限，结论降级为定性描述。

**风险 2：紧束缚模型对高能态的截断误差**

- 表现：某些高阶谐波（> 15 阶）的强度与纯 DFT（Octopus平面波）结果偏差 > 30%。
- 替代方案：扩大紧束缚模型至 10–12 带，或在 HHG 高阶区切换为纯 TDDFT 计算（仅对 10–20 个高阶点）。

**风险 3：计算资源不足导致参数扫描不完整**

- 缓解策略：采用自适应采样——在切换概率变化剧烈的场强区间（如 0.3–0.6 MV/cm）加密采样点，在变化平缓区间减少采样点。
- 替代方案：与国内超算中心签订机时保障协议；或采用机器学习势能面替代 DFT 加速参数扫描。

## 3 方法 M2：i-wave 自旋劈裂磁点群 HHG 指纹理论

**支撑研究内容**：R2（i-wave 自旋劈裂的 HHG 指纹可辨识性）

### 3.1 理论框架概述

本方法在多带紧束缚模型（来自 M1 的材料参数化）上构造 i-wave 自旋劈裂 Hamiltonian，利用磁点群选择定则推导 HHG 允许阶次与圆偏振选择规则，最后通过数值求解含时薛定谔方程（TDSE）或 Volkov 近似校验理论预言。

**磁点群选择定则的推导步骤**：

1. 确定材料磁点群（如 NiCl₂ 为 C4h，MnPS₃|WS₂ 异质结需考虑界面对称性破缺）。
2. 构造 i-wave 自旋劈裂的 Hamiltonian：H_i-wave = Δ_i(k)·σ，其中 Δ_i(k) 在 C4 旋转下不变（四次旋转对称），且在镜面反射下变号——这是 i-wave 有别于 d-wave 和 g-wave 的本质特征。
3. 将驱动光场以 minimal coupling 引入 Hamiltonian：p → p − eA(t)，其中 A(t) 为圆偏振光的矢势。
4. 在旋转基底下展开多光子矩阵元，利用磁点群不可约表示的直积性质，得到"驱动圆偏振 → 谐波阶次 → 磁对称性"的解析选择定则。

**i-wave vs. d-wave vs. g-wave 的物理判据**：

- i-wave（C4）：节点线穿过 Γ 点；HHG 响应在单光子区间（低阶 n = 3–7）即显现，为奇数次谐波的选择性抑制/增强。
- d-wave（C2）：双光子过程（n = 2, 6, 10…）显现；在相同驱动条件下，d-wave 的 A_helicity 符号与 i-wave 相反。
- g-wave（C4 + 额外镜面破缺）：三光子过程（n = 3, 9, 15…）显现；在椭圆度扫描中，g-wave 的椭圆度过零点位置与 i-wave 相差 ≥ 0.2 个椭圆度单位。

### 3.2 指纹量定义与计算公式

以下五个指纹量为 R2 的核心可观测量，各自计算方法如下：

**指纹量 1：螺旋度交替幅度（Helicity Alternation）**

```
A_helicity(n) = [I_n(σ⁺) − I_n(σ⁻)] / [I_n(σ⁺) + I_n(σ⁻)]
```

计算步骤：对每个谐波阶次 n，分别用左旋（σ⁺）和右旋（σ⁻）圆偏振驱动光计算 HHG 谱，取第 n 阶谐波峰位（±0.2 eV 窗口内）的积分强度 I_n(σ⁺) 和 I_n(σ⁻)。计算 A_helicity 对 n 的依赖关系，提取其符号和幅度作为指纹特征。

**指纹量 2：椭圆度响应斜率（Ellipticity Slope）**

```
S_ellipticity(n) = ∂I_n/∂ε |_{ε=0}
```

计算步骤：保持驱动光总光强恒定，在椭圆度 ε ∈ [−0.5, +0.5] 范围内以步长 0.1 扫描（对应 11 个数据点），对 I_n(ε) 做线性拟合，斜率即为 S_ellipticity(n)。i-wave 的 S_ellipticity 在低阶（n = 5–9）显著异于零，d-wave / g-wave 在同等条件下接近零。

**指纹量 3：偏振旋转角（Polarization Rotation）**

计算步骤：对线性偏振驱动（ε = 0），计算 HHG 辐射的偏振态（Stokes 参数 S1, S2, S3），提取偏振主轴相对于驱动偏振的旋转角 θ。旋转角来源于自旋劈裂引起的非线性极化率非对称性。

**指纹量 4：螺旋度交替的阶次周期性**

计算步骤：绘制 A_helicity(n) 对 n 的函数图，提取符号交替模式。i-wave 的 C4 对称性导致 A_helicity 在相邻奇数阶之间呈现"+"、"−"、"+" 的交替（周期 ≈ 4 阶）；d-wave 的周期为 2 阶；g-wave 无明确交替规律。

**指纹量 5：椭圆度过零点位置**

计算步骤：对每个谐波阶次 n，在 ε ∈ [−1, +1] 范围内扫描 I_n(ε)，找到 I_n(ε) 从正转负对应的椭圆度值 ε_zero(n)。i-wave 的 ε_zero(n) 接近 ±0.3–0.5；d-wave 接近 ±0.1；g-wave 在该范围内无非零点。

### 3.3 数值求解流程

**路径 A：Volkov 近似（首选，适用于弱-中驱动场）**

适用于驱动场强 0.01–0.3 MV/cm（不破坏磁序的低场区）。在 Volkov 近似下，电子的含时波函数解析可得，HHG 谱的半经典公式为：

```
I_n ∝ |J_n(α, β)|²
```

其中 J_n 为 Bessel 函数，α = (eE₀/ℏω²)·(k·e_z)，β 与隧穿电离速率相关。计算成本：每个 (k, E₀, ω, ε) 参数点约 1–10 CPU 分钟。

**路径 B：数值 TDSE 求解（高场校验，0.3–1.0 MV/cm）**

采用劈裂傅里叶（split-step Fourier）方法：

```
ψ(t + Δt) = exp(−iH_0Δt/2) · exp(−iV[t]Δt) · exp(−iH_0Δt/2) · ψ(t)
```

其中 H_0 为紧束缚 Hamiltonian（不含驱动），V[t] = −eE(t)·r 为驱动势。时间步长 Δt = 0.01 a.u.；k 点网格同 M1。计算成本：每个参数点约 100–1000 CPU 小时（适合并行化）。

### 3.4 关键参数汇总

| 参数 | 取值 | 说明 |
|---|---|---|
| 驱动光波长（中红外） | 1.5–3 μm | 与 HHG 平台兼容；对 MnPS₃|WS₂ 带隙（~1.5 eV）共振 |
| 驱动场强（指纹计算） | 0.01–0.3 MV/cm | Volkov 近似适用区间；避免磁序破坏 |
| 椭圆度扫描范围 | ε ∈ [−1, +1]，步长 0.1 | 11 个数据点足以描述线性响应 |
| Monte Carlo 噪声水平 | 10% 高斯噪声 | 加于每个 I_n(σ⁺) 和 I_n(σ⁻)，模拟实验信噪比 |
| Monte Carlo 采样次数 | N = 500 次 | 保证 3σ 分类置信度 |
| 谐波阶次分析范围 | n = 3–21 | 覆盖单光子到三光子过程的主要区间 |
| 分类区分度阈值 | ≥ 3σ（> 99.7% 置信度） | i-wave 与 d-wave/g-wave 的模式识别准确率 |

### 3.5 验证流程

**阶段 1（平台一，纯 i-wave 基准）**：

1. 在 NiCl₂ / VS₂ / CrSe₂ 的紧束缚模型上计算五个指纹量的理论预言值。
2. 用 TDSE 数值模拟（路径 B）计算对应条件下的 HHG 谱，提取指纹量。
3. 对比理论值与数值模拟值：若 ≥ 4/5 个指纹量在 2 倍因子内一致，则基准建立成功。
4. 记录偏差最大的指纹量及其可能原因（模型近似、计算误差等）。

**阶段 2（平台二，含 Rashba 背景）**：

1. 在平台一的 Hamiltonian 中引入 Rashba 扰动项 H_R = α_R (σ × k)_z。
2. 逐步增加 Rashba 强度（α_R = 0 → α_R^real 的 0%、25%、50%、75%、100%），追踪每个指纹量的变化。
3. 敏感度判定：若某个指纹量在 Rashba 扰动 < 10% 时变化 > 50%，标记为"易受 Rashba 干扰"。
4. 降级使用策略：优先使用低敏感度量（A_helicity 和椭圆度周期性）建立反演关系。

**阶段 3（Monte Carlo 分类验证）**：

1. 构建训练数据集：i-wave、d-wave、g-wave 各 200 条样本（不同自旋劈裂参数 + 10% 高斯噪声）。
2. 用支持向量机（SVM）或随机森林（RF）做三分类：输入特征为五个指纹量的归一化向量。
3. 统计分类准确率：目标 ≥ 3σ（> 99.7%），即错误分类率 < 0.3%。

### 3.6 潜在风险与替代方案

**风险 1：i-wave 指纹在 Rashba 背景干扰下失去可辨识性**

- 触发条件：Rashba 强度 > 30% 时，≥ 3 个指纹量的值与纯 i-wave 偏差 > 50%。
- 替代方案 1（理论补救）：发展 Rashba 干扰的解析修正项，在指纹表中加入 Rashba 强度的反演（从 HHG 谱中同时提取 Rashba 强度和 i-wave 强度）。
- 替代方案 2（实验补救）：设计变角度实验（改变入射光相对于晶格的角度），利用角度依赖分离 Rashba 和 i-wave 的贡献。
- 替代方案 3（降级方案）：若 Rashba 干扰无法规避，聚焦于平台一（NiCl₂/VS₂/CrSe₂）的理想化研究，将平台二的研究定位调整为"验证 Rashba 干扰的可辨识性"而非"建立普适指纹表"。

**风险 2：Monte Carlo 模拟的噪声模型与实际实验噪声不符**

- 触发条件：实验上实现 SNR ≥ 10（对应噪声 < 10%）存在困难。
- 替代方案：扩展 Monte Carlo 到 SNR = 5（20% 噪声），检验分类准确率是否仍 ≥ 3σ。若低于阈值，则在论文中明确标注实验 SNR 要求，并提出信号平均策略（增加积分时间或提高驱动功率）。

**风险 3：磁点群分析未考虑实际材料的点群破缺**

- 触发条件：实际材料的对称性低于理想模型（如界面粗糙度、应变等）。
- 替代方案：在 M1 的 DFT 计算中引入真实材料的表面重构和应变分布（< 1% 应变），用对称性分析工具（如 Bilbao Crystallographic Server）重新计算磁点群，修正选择定则。

## 4 方法 M3：THz 泵浦 × 圆偏振 HHG 探测 + Floquet 缀饰

**支撑研究内容**：R3（泵浦-探测时域分离方案设计）

### 4.1 泵浦-探测实验方案设计

#### 4.1.1 光路布局与时间分辨率

**标准方案（目标：亚 100 fs 分辨率）**：

```
THz 泵浦光路：
  光参量放大器（OPA）→ THz 产生晶体（DSTMS 或 GaSe）→ 延迟线（分辨率 0.1 fs）→ 样品
  场强：0.1–1.0 MV/cm（可调）
  脉冲长度：1–3 ps（FWHM）

中红外 HHG 探测光路：
  掺铒光纤激光器（1560 nm）→ OPA（1.5–3 μm）→ 偏振光学元件（λ/4 波片产生圆偏振）→ 样品
  场强：0.01–0.1 MV/cm（探测场，远低于泵浦场）
  脉冲长度：亚 100 fs（FWHM）

时间延迟扫描：
  范围：−5 ps 至 +50 ps
  步长：50 fs（电子层 fs-ps，步长 50 fs 充分采样）
  总扫描点数：1100 个延迟点

光路稳定性要求：
  泵浦-探测相对抖动 < 10 fs（通过主动光学延迟线锁相环实现）
  样品位置稳定性 < 5 μm（防止空间漂移引入伪信号）
```

**降级方案（ps 分辨率，适用于光路稳定性不足的情况）**：

- 时间分辨率放宽至 500 fs–1 ps（通过延长泵浦-探测脉冲长度实现）
- 通过延长积分时间（每个延迟点 10–60 s，平均 100–1000 次扫描）补偿时间分辨率不足
- 理论可行性：电子层（< 1 ps）和磁序层（ps-ns）时间常数相差一个数量级，ps 分辨率下仍可分离（分离度 D_sep 下降约 10–15%）

#### 4.1.2 信号采集与数据处理流程

**原始数据**：I_HHG(Δt, σ⁺/σ⁻, ε)（每个延迟点 × 两个圆偏振 × 多个椭圆度）

**数据处理步骤**：

1. **去基线**：在负延迟区（Δt < −5 ps，电子层和磁序层均未响应）取平均作为基线，从全谱中减去。
2. **去噪声**：对每个延迟点做 10 次重复测量，取平均并计算标准偏差；使用小波去噪或萨维茨基-戈雷尔滤波器（window = 5 点）进一步降噪。
3. **椭圆度分解**：在同一延迟点，对 I_HHG(ε) 做最小二乘拟合，分离线性项和椭圆度响应项（对应指纹量 S_ellipticity）。
4. **时域分解**：对 I_HHG(Δt) 做双指数拟合：I_HHG(Δt) = A_e·exp(−Δt/τ_e) + A_m·exp(−Δt/τ_m) + C，其中下标 e 为电子层（τ_e ≈ 0.1–1 ps），下标 m 为磁序层（τ_m ≈ 1–100 ps）。
5. **分离度计算**：代入 §4.2 的 D_sep 公式，验证 D_sep ≥ 0.80。

### 4.2 分离度 D_sep 的定义与计算

分离度以归一化重叠积分定义：

```
D_sep = 1 − ∫f_e(t)·f_m(t)dt / √[∫f_e²(t)dt · ∫f_m²(t)dt]
```

其中：

- f_e(t)：电子层 HHG 响应的时间波形，从泵浦后瞬间（Δt ≈ 0）开始，按双指数拟合的电子层分量提取。
- f_m(t)：磁序层 HHG 响应的时间波形，取磁序层分量（延迟 > 1 ps 的区域）。
- 计算区间：[0, +50 ps]，积分步长 10 fs。

**D_sep 的物理意义**：

- D_sep = 1：两信号完全正交（在时间轴上不重叠），时域分离完全可行。
- D_sep = 0：两信号完全重叠，时域分离不可行。
- 目标：D_sep ≥ 0.80。

**可证伪条件**：若双指数拟合给出的 τ_e 和 τ_m 满足 τ_m < 2·τ_e（即时间常数相差不足 2 倍），则 D_sep 理论上限 < 0.60，时域分离在原理上不可行，项目需重新审视物理时域层次的划分。

### 4.3 Floquet 缀饰参数扫描方案

**背景**：Floquet 缀饰的作用是在弱场（0.01–0.3 MV/cm）下选择性增强弱交变磁 HHG 信号，同时保持对 Rashba/Berry 响应的分辨能力。

**参数空间**：

- 驱动频率：f = 0.5, 1.0, 1.5, 2.0, 2.5, 3.0 THz（共 6 个频率点）
- 驱动场强：E = 0.01, 0.05, 0.1, 0.2, 0.3 MV/cm（共 5 个场强点）
- 总计 30 个参数点

**扫描流程**：

1. 对每个参数点 (f, E)，在 TDDFT/M2 的紧束缚模型上施加 Floquet 驱动场，计算 HHG 谱。
2. 对比有/无 Floquet 驱动下的交变磁 HHG 信号强度 S_magnetic，计算增强倍数：

```
η = S_magnetic^Floquet / S_magnetic^no-Floquet
```

3. 寻找 η ≥ 5 的参数区域（增强目标区）。
4. 在增强目标区内，验证 Rashba/Berry 响应未被显著干扰（干扰程度 < 30%）。

**Floquet Hamiltonian 的数值构造**：

Floquet 理论将周期驱动体系的 Hamiltonian 表示为扩展的 Floquet 空间：

```
H_F = H_0 ⊗ 1 + V(t) ⊗ 1
V(t+T) = V(t),  T = 1/f

在 Floquet 基底 |α, n⟩（α 为原始量子态，n 为缀饰阶数）下，
准能量 ε_α^F = lim_{N→∞} (1/NT) ∫_0^{NT} ⟨α|U(t)|α⟩dt
```

数值实现：在多带紧束缚模型上构造 H(t) = H_0 + V(t)，采用 Floquet 传递矩阵方法（Floquet MMFT）求解准能量；在每个参数点计算到 |n| ≤ 3 的缀饰阶数（覆盖 0–3 THz 驱动的主要物理）。

### 4.4 关键参数汇总

| 参数 | 取值 | 说明 |
|---|---|---|
| THz 泵浦场强 | 0.1–1.0 MV/cm | 与 R1 驱动场强一致；上限受 THz 源峰值限制 |
| HHG 探测场强 | 0.01–0.1 MV/cm | 远低于泵浦场，避免探测场本身触发磁动力学 |
| 探测光波长 | 1.5–3 μm（中红外） | 与材料带隙匹配；平台二（MnPS₃\|WS₂）~1.5 eV 共振 |
| 时间延迟范围 | −5 ps 至 +50 ps | 覆盖电子层衰减（< 1 ps）和磁序层演化（ps-ns） |
| 时间延迟步长 | 50 fs | 亚 100 fs 分辨率目标；ps 分辨率降级方案下为 500 fs–1 ps |
| 分离度 D_sep 阈值 | ≥ 0.80 | 可证伪条件：若 D_sep < 0.80，时域分离方案不可行 |
| Floquet 增强倍数 η 阈值 | ≥ 5 | 弱交变磁信号需放大 5 倍以上方可达实验可探测水平 |
| Floquet 驱动场强 | 0.01–0.3 MV/cm | 弱场，避免破坏磁序；与泵浦驱动场（0.1–1.0 MV/cm）互补 |
| 信噪比 SNR | ≥ 10 | 10% 高斯噪声对应的信噪比；通过增加积分时间改善 |
| 光路抖动要求 | < 10 fs | 亚 100 fs 分辨率的必要条件；降级方案放宽至 < 50 fs |

### 4.5 潜在风险与替代方案

**风险 1：THz 泵浦-探测光路稳定性不足（最常见工程风险）**

- 触发条件：实测光路抖动 > 20 fs，或泵浦-探测相对延迟漂移 > 50 fs。
- 替代方案 1（主动稳定）：引入光学锁相环（OPLL）主动控制延迟线位置，将抖动压至 < 10 fs。
- 替代方案 2（被动延长积分）：在无法提升光路稳定性时，通过延长每个延迟点的积分时间（10–60 s，平均 100–1000 次扫描）将 SNR 提升至 ≥ 10；代价是完整扫描时间从 ~1 小时延长至 ~10–100 小时。
- 替代方案 3（降级分辨率）：切换至 ps 分辨率方案（步长 500 fs–1 ps），通过总扫描时间窗口延长（−20 ps 至 +200 ps）补偿采样不足。

**风险 2：THz 泵浦激发效率不足**

- 触发条件：实测泵浦后 HHG 信号变化 < 5%（远低于预期的 20–50% 变化）。
- 替代方案 1：更换 THz 产生晶体（GaSe → DSTMS 或倾斜波前光学参量放大，场强可提升 2–3 倍）。
- 替代方案 2：调整泵浦光与样品的耦合方式（使用硅透镜或金属线栅偏振器增强 THz 吸收）。
- 替代方案 3（降低场强要求）：将泵浦场强要求从 0.1 MV/cm 降至 0.05 MV/cm，同时延长积分时间以补偿信号强度。

**风险 3：Floquet 增强区与 Rashba/Berry 响应干扰区重叠**

- 触发条件：在 η ≥ 5 的参数点，Rashba/Berry 响应同时被放大 ≥ 3 倍，导致无法分辨。
- 替代方案 1（参数空间重扫）：在 (f, E) 二维参数空间中寻找"高 η、低干扰"的分离区域（帕累托优化）。
- 替代方案 2（时间门控）：利用电子层（fs）和磁序层（ps）的时间差异，在探测端引入时间门控（选通 ps 量级的信号分量），物理上抑制电子层干扰。

**风险 4：泵浦光破坏磁序**

- 触发条件：泵浦后磁序信号永久消失（强场磁有序被不可逆破坏）。
- 替代方案 1（降低泵浦场强）：切换至 0.01–0.05 MV/cm 的弱泵浦（牺牲泵浦效率，换取磁序存活）。
- 替代方案 2（改变泵浦波长）：从 THz 泵浦切换至中红外泵浦（直接共振激发磁振子而非通过电子-晶格耦合间接驱动），减少对磁序的非热破坏。
