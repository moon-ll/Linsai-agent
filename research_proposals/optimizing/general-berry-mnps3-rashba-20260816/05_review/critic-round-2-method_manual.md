## 五、新问题清单

### critical（1）

**N1｜§3.4.3 谷背景扣除的"90° 旋转 i-wave 不变"判据自反且算术错误**（L157 vs L209 / L213 / L226）
- L157：`cos6θ 在 C₃/C₆ 旋转下不变、镜面反射下不变、C₄ 旋转下变号`——手册自己的 §3.1 已写明 C₄（90°）使 cos6θ **变号**。
- L209：`i-wave Δ(k)∝cos6θ 在 90° 面内旋转下不变），两旋转位的 ΔI_n 差即纯谷背景贡献`
- L213：`旋转 90° 后纯谷背景扣除在 90° 位差为 0、i-wave 信号在 90° 位差为 0`
- 复算：cos6(θ+90°) = cos(6θ + 540°) = cos(6θ + 180°) = **−cos6θ**。故 i-wave 分量在 90° 旋转下与谷分量**同时反号**：ΔI(90°) = −ΔI(0°)，两旋转位互为相反数——差给出 2ΔI（全信号）、和为 0，"差值即纯谷背景"与"两项位差均为 0"互斥，协议照做必失败。
- 可行修正（供 writer 参考）：把旋转角改为 **60°（C₆）**——cos(6(θ+60°)) = cos(6θ+360°) = cos6θ（i-wave 不变），cos(3(θ+60°)) = cos(3θ+180°) = −cos3θ（谷手性反号），此时差分才成立。改角后 L213 的"两项位差为 0"必须删改为"谷项反号、i-wave 不变"。

### high（10）

**H1｜γ = 1 ↔ 约 50% 跃迁概率的锚点与 LZ 标准式不符**（L109、L20、L119）
- L20：`γ = Δ_gap²/(4ħ|dε/du|·v)，无量纲；约定 γ = 1 ↔ 约 50% 跃迁概率`
- L119：`γ = 1 场强处 P_switch 实测落在 40–60%（约 50% 的约定）`
- 复算：标准 Landau–Zener 取 P_diabatic = exp(−2πγ)（γ 即手册该式）。γ=1 → P = exp(−2π) = **0.19%**；P = 50% 需 γ = ln2/(2π) = **0.11**。若把 2π 并入 γ（P = exp(−γ)），50% 对应 γ = ln2 = **0.69**。两种约定都不是 1，故 L119 的验收带（40–60%）在理论上必然判失败。
- 附：L20"γ ≪ 1 微扰缀饰"与 L119"弱场 γ ≫ 1、强场越过 O(1)"语义相反（γ≪1 才是近绝热全跃迁）。

**H2｜D_sep 的"τ_m < 2τ_e → 上限 < 0.60"算术错误**（L19、L268、L382）
- L268：`若 τ_m < 2·τ_e → D_sep 理论上限 < 0.60，原理不可行`
- 复算：D_sep = 1 − √(2τ₁/τ₂)；τ₂ = 2τ₁ 时 √(2τ₁/2τ₁) = 1 → **D_sep = 0**；D_sep = 0.60 需 √(2τ₁/τ₂) = 0.4 → τ₂ = 2τ₁/0.16 = **12.5τ₁**。故正确表述应为"τ₂ < 12.5τ₁ 时 D_sep < 0.60"，现文把最不利用例写成 2τ_e，判据与数值反向。

**H3｜§2.4.4 的 Δ_gap 是全节唯一"中间量断链"**（L109）
- L109：`Δ_gap 取 TDDFT 输出中缀饰态与基态的 Floquet 准能量差——按光子数逐阶扫描，在 0.5–3.0 THz 驱动下取各阶 Floquet 副本能量带 K 点最低处的差值`
- 问题：M1 的流程链（Step 1 静态 DFT → Step 3 实时 TDDFT → Step 4 通道）**没有任何一步产出 Floquet 准能量**；Floquet MMFT 构造在 §4.4（M2 紧束缚）。执行者按手册无法知道"用哪个程序、在哪个步骤、以何 N 截断"取得 Δ_gap，与 skill 四节"中间量断链"同型。同句还写"与 §2.3 Step 1 同一批轨迹"，而 Step 1 为静态基态计算、无轨迹可言；"交叉场强处作中心差分"亦把 E(u) 位移坐标误称场强。

**H4｜§2.1 核时语义与申请书错位，导致 ⑦ 无法对账**（L49）
- L49：`单参数点 ~6000 核时（6000 条轨迹合计 1.8×10⁷–6×10⁷ 核时，样本参数点抽 600 条…）`
- 提案 L321：`单条轨迹典型 3×10³–10⁴ 核时…全网格（三泛函×约 10 场强×200 轨迹）合计约 6000 条，对应 1.8×10⁷–6×10⁷ 核时；抽样档…合计 600 条，对应 1.8×10⁶–6×10⁶`

## 六、停机判定

1. **是否存在"无论怎么改都拿不到分"的要素**：**否**。⑤ 的失分全部是可判定的算术/语义冲突（γ 指数约定、τ<2τ、90° 旋转角、2 vs 3 阈值），均可在一次修订内闭合；没有"结构性无法达标"的要素。
2. **是否存在评审反复在同一节扣分的失败模式**：**是，但属可修复型**：
   - 新模式 A「**主干改口径、尾部不同步**」：C2 在 §4.1/§4.3 主链已迁 5050，但同类旧口径仍活在 §4.3 风险 2（L331）与 §4.7 风险 1（L392）；§2.6 的 8×8 修复又制造了与 §2.3/§2.5 的新冲突。修复应改为"全文检索旧数值串（10 fs 步长 / 300 点 / 600 点 / 1 小时 / 600 条参数点）后逐处改写"，而非只改主干。
   - 新模式 B「**修订声明块回流**」：r1 已判"删声明块"，r2 不但保留，还扩充为 8 条并新增 3 处"已订正"（L278/L347/L361）。该模式连续两轮在同一位置扣分，若不制止将每轮复现。
3. **结论：可继续下一册（第 3 轮）。** 停机条件不成立；但第 3 轮应限定为"1 critical + 10 high 定点清偿 + 一次全文旧数值串与行号锚清扫"，不宜再扩写新小节（手册已 53.9K，接近 skill 60KB 压缩线）。
