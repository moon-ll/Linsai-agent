## §1 TDDFT+多带紧束缚计算框架

### 1.1 计算流程

本项目采用 TDDFT+多带紧束缚的组合方案，两者的分工与接口如下：

1. **多带紧束缚模型**：基于 Wannier90 提取的 Wannier 函数（4–6 带有效 Hamiltonian），参数化滑移坐标 u 与自旋劈裂参数 Δ_spread(k_s) 的依赖关系，为 TDDFT 提供初始 Hamiltonian 的 u 依赖修正项。

2. **实时 TDDFT**：以 Octopus（平面波基组，截断能 80–100 Ry，k 点网格 12×12×1，时间步长 0.01–0.05 a.u.，约 0.24–1.2 as）为计算引擎，在每个时间步将紧束缚模型提供的 u 依赖修正项嵌入 Kohn-Sham 方程，完成自洽场迭代。

3. **接口**：紧束缚提供 Hamiltonian H(k, u) = H₀(k) + ΔH_spread(k, u)，其中 ΔH_spread 是层间相对位移 u 的线性或非线性函数；TDDFT 在实时演化中保持电荷密度自洽，但不重复计算能带结构。

### 1.2 计算参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 平面波截断能 | 80–100 Ry | 2D 体系收敛精度 |
| k 点网格 | 12×12×1 | 对应 2D 体系收敛精度 |
| 时间步长 | 0.01–0.05 a.u. | 约 0.24–1.2 as，保证亚周期演化精度 |
| Wannier 带数 | 4–6 带 | 覆盖价带顶与导带底 |
| u 扫描范围 | [0, d] | d 为层间距，插值计算 |
| 泛函 | PBE / PBE+U / HSE | 三泛函方差度量不确定性 |
| U 值 | 典型值 2–4 eV（过渡金属 d 轨道） | 材料依赖 |

### 1.3 切换概率的定义与计算

切换概率 P_switch = N_switch / N_total，其中：

- N_total：总模拟轨迹数（收敛性测试：N_total ≥ 50 条轨迹）
- N_switch：u(t) 跨越势垒最大值一半（u > u_barrier/2）的轨迹数
- 初始条件：u(0) = 0（基态平衡位置），速度分布服从 Maxwell-Boltzmann（T = 300 K）

不确定性度量：以 PBE、PBE+U、HSE 三种泛函的计算结果方差为度量，目标不确定性 ≤ 10%。

### 1.4 光-晶格耦合通道建模

两条竞争机制的 TDDFT 建模方式：

**光应力机制**：在 TDDFT 中通过光场对电子云的极化作用自动包含（电荷密度自洽反馈），无需额外模型项。有效强度区间通过改变驱动场强（0.1–1.0 MV/cm）追踪。

**位移电流机制**：在 Hamiltonian 中引入光致偏振电场项 P(t) = ∫ χ^(3)(t-t₁-t₂)E(t₁)E(t₂)dt₁dt₂ 的等效作用，对带电离子产生直接力。该项以微扰方式加入 TDDFT 框架，验证其对低场响应的贡献可忽略。

### 1.5 失效边界

TDDFT+ALDA 近似在以下条件下失效：

- **强场条件**：驱动场强 > 1 MV/cm 时，电子动力学显著偏离绝热近似，ALDA 近似须用 GW-BSE 方法修正（见 §6 风险项）
- **通道间强耦合**：层间滑移导致的能带混合显著时（能量差 < 0.5 eV），双通道近似退化，须重新标定修正项形式
- **非平衡态初始条件**：光激发载流子密度 > 10¹⁸ cm⁻³ 时，电子-空穴对的激子效应须用多体微扰理论处理

## §2 i-wave HHG 指纹理论：磁点群分析与数值验证

### 2.1 磁点群选择定则（解析框架）

i-wave 自旋劈裂具有 C₄ 旋转对称，节点线穿过 Γ 点。对应磁点群为 4mm（O_h 的子群）。磁点群选择定则给出：

- HHG 允许阶次：由光跃迁矩阵元的对称性约化决定，i-wave 在圆偏振驱动下允许奇数阶（与 d-wave/g-wave 的偶数阶/三光子过程显现形成对比）
- 螺旋度交替符号：左/右旋圆偏振驱动下同阶谐波产额的符号差异由 C₄ 群的不可约表示决定
- 椭圆度响应：线性响应区间（ε → 0）的斜率由二阶非线性响应张量 χ^{(2)} 的对称性分量决定

### 2.2 五个指纹量的定义

| # | 指纹量 | 符号 | 定义 | 计算方式 |
|---|--------|------|------|---------|
| 1 | 螺旋度交替幅度 | A_helicity | [I_n(σ⁺) − I_n(σ⁻)] / [I_n(σ⁺) + I_n(σ⁻)] | 数值求解 TDSE，分别计算左/右旋圆偏振 HHG 谱 |
| 2 | 椭圆度响应斜率 | S_ellipticity | ∂I_n/∂ε \|_{ε=0} | 在 ε ∈ [−0.5, 0.5] 区间扫描，线性拟合 |
| 3 | 偏振旋转角 | θ | 谐波偏振主轴与驱动偏振的夹角 | 傅里叶分解谐波场的极化椭圆参数 |
| 4 | 阶次周期性 | P_periodicity | 不同阶次 n 的 A_helicity 符号交替模式 | 在 n = 3, 5, 7, 9 区间检验符号交替规律 |
| 5 | 椭圆度过零点 | ε_zero | I_n(ε) 从正转负对应的驱动椭圆度 | 在 ε ∈ [−1, 1] 区间精确扫描 |

### 2.3 区分度指标 d′ 的定义

区分度以两类指纹分布的分离显著性 d′ 计，定义为：

d′ = |μ₁ − μ₂| / √[(σ₁² + σ₂²)/2]

其中 μ₁, μ₂ 为 i-wave 和 d-wave/g-wave 两类指纹量均值，σ₁, σ₂ 为对应的标准差。Monte Carlo 验证参数：10% 高斯噪声、200 次采样。判据：d′ ≥ 3（等价分类准确率 ≥ 99%）。

### 2.4 Volkov 近似的适用条件

Volkov 近似（非微扰强场近似）忽略束缚态与库仑效应，仅适用于：

- **电离阈值以上**：驱动场强足以使电子隧穿出束缚态（Keldysh 参数 γ ≪ 1）
- **单带加速图像成立**：电子在驱动场中的运动可视为自由加速，束缚势的影响仅通过 Volkov 态的准能量修正计入
- **带间相干效应可忽略**：在低阶谐波区（n ≤ 5），带间相干效应显著，Volkov 近似失效，须用 TDSE 数值求解

**失效边界**：在固体多带体系中，低阶谐波区（n ≤ 7）的带间极化主导响应，Volkov 近似仅在解析定性估算中作极限校验使用，不作为定量计算工具。

## §3 泵浦-探测时域分离方案

### 3.1 三光束时序设计

| 光束 | 波长 | 场强 | 脉冲宽度 | 物理作用 |
|------|------|------|---------|---------|
| THz 泵浦 | 0.5–3.0 THz（对应 2–60 meV 光子能量） | 0.1–1.0 MV/cm | 1–3 ps | 激发磁序动力学（ps-ns）+ 触发层间滑移相干振荡（fs-ps） |
| Floquet 缀饰 | 0.5–3.0 THz | 0.01–0.3 MV/cm | 与泵浦脉冲同步 | 弱场探测性缀饰，增强弱交变磁 HHG 信号 |
| HHG 探测 | 中红外 1.5–3 μm | < 0.1 MV/cm | < 30 fs | 读取电子层自旋劈裂状态（HHG 螺旋度通道） |

时序关系：THz 泵浦先于 Floquet 缀饰（延迟约 0.5–1 ps），HHG 探测脉冲在泵浦后延迟扫描（−5 ps 至 +50 ps，步长 50 fs）。

### 3.2 分离度 D_sep 的计算

D_sep = 1 − ∫f_e(t)·f_m(t)dt / √[∫f_e²(t)dt · ∫f_m²(t)dt]

- f_e(t)：电子层 HHG 响应的时间波形（从 HHG 信号的延迟依赖性提取）
- f_m(t)：磁序层响应的时间波形（从 THz 反射率或二次谐波信号的延迟依赖性提取）
- D_sep = 1：完全正交分离（时间轴无重叠）
- D_sep = 0：完全重叠（时间轴完全重合）

目标：D_sep ≥ 0.80（在 ps 量级延迟处，电子层响应已衰减至基线，磁序层响应仍在演化）。

### 3.3 可证伪条件

若两响应峰时间差 Δt < 100 fs（实验分辨率极限），则时域分离在当前技术条件下不可行。若在 ps 分辨率（降级方案）下仍无法满足 D_sep ≥ 0.80，则须重新审视时域分离的物理前提。

## §4 Floquet 缀饰理论框架

### 4.1 参数空间

| 参数 | 范围 | 说明 |
|------|------|------|
| 驱动频率 | 0.5–3.0 THz | 与剪切声子频率重叠 |
| 驱动场强 | 0.01–0.3 MV/cm | 弱场，避免磁序破坏性驱动 |
| 缀饰阶数 | n = 0, ±1, ±2 | 扫描最优阶数 |
| 椭圆度 | ε ∈ [−1, 1] | 圆偏振/线偏振/椭圆偏振 |

### 4.2 目标函数

优化目标：在二维参数空间（频率 × 场强）内寻找使增强因子最大化同时保持 Rashba/Berry 分辨能力 d′ ≥ 3 的参数区域。

增强因子定义：G = I_Floquet / I_baseline，其中 I_Floquet 为 Floquet 缀饰条件下的弱交变磁 HHG 信号强度，I_baseline 为无 Floquet 缀饰的基线信号强度。目标：G ≥ 5 倍。

### 4.3 继承框架

本项目的 Floquet 理论框架继承 Yarmohammadi 等人 [22] 的二维 d-wave 交变磁体模型，推广至 i-wave 自旋劈裂体系。推广内容包括：

- 将 d-wave 的 C₂ 对称性分析替换为 i-wave 的 C₄ 对称性分析
- 在 Hamiltonian 中加入层间滑移坐标 u 的依赖项 ΔH_spread(u)
- 重新推导 Floquet 有效哈密顿量中的自旋劈裂修正项

## §6 失效边界与风险项

### 6.1 ALDA 近似失效（TDDFT）

**触发条件**：PBE+U 和 hybrid 泛函结果差异 > 10%

**修正方案**：在触发条件下用 GW-BSE 方法补充含激子效应的 HHG 谱计算，评估非绝热修正的量级

- 若修正量级 < 10%：ALDA 近似可接受，在论文中标注为系统误差上限
- 若修正量级 > 10%：须用多体微扰理论重新计算，并在论文中注明适用范围

### 6.2 Rashba 背景干扰

**触发条件**：某个指纹量在 < 10% Rashba 扰动下变化 > 50%

**处理方案**：在指纹表中标注该量为"易受 Rashba 干扰"，优先使用低敏感度量建立反演关系。若所有指纹量均敏感，则指纹方案在 Rashba 背景下不可行，须发展替代探测方案。

### 6.3 THz 泵浦效率不足

**触发条件**：THz 场与材料耦合强度不足以在 ps 窗口内激发可观测的磁序动力学

**回退方案**：降低泵浦场强要求至 0.05 MV/cm，延长积分时间（100× 以上）以补偿信号强度。

### 6.4 Volkov 近似失效边界（ §2.4 已述）

### 6.5 时间分辨率降级

**触发条件**：光路稳定性无法达到亚 100 fs

**降级方案**：ps 量级分辨率替代，通过延长延迟扫描时间窗口和增加平均次数弥补时间分辨率不足。理论上电子层（fs-ps）与磁序层（ps-ns）时间常数相差一个数量级以上，即使 ps 分辨率也能实现 D_sep ≥ 0.80。
