## 1. 验证架构（三层）

```
第一层  解析公式对拍（verify_formulas.py）
        闭式 Ω/C/CD 关系 vs Kubo 途径 / 规范不变 plaquette 通量 / 径向积分
第二层  守恒律与单 k 动力学（l0_simulation.py --self-check）
        模方守恒、静态能量守恒、迷你闭环反演
第三层  端到端闭环（run_validation.py，三阶段）
        阶段1  12 驱动点闭环矩阵：数据生成（全分辨率）→ 无噪拟合（θ 恢复）
               → 注入 η=1% 实验级噪声 ×3 蒙特卡洛 → M1–M4
        阶段2  噪声预算：拟合点雅可比协方差（线性化）→ σ_θ(η) → M2(η) → η_c
        阶段3  前向保真度：拟合分辨率有意失配 → M2(失配) 收敛表 → 保真度要求
```

**反演架构说明**：L0 闭环的拟合前向 = 同一精确模拟器（写 TDSE + 双螺旋度探针
传播，即测量方程 (9)(15) 的严格数值实现）。这一选择经调试对拍锁定：窗口锁相
观测算含自由感应拍（探针通过后相干继续演化并与探针谱拍频），准静态解析前向
无法复现该记忆效应（附录 D）；时域一阶 Dyson 前向在晚期自由感应段一致到
5–10%、早期瞬态存在待查差异。模拟器内嵌架构与申请书分层设计同构——L0 的
"模拟器前向"正是 L1 层 RT-TDDFT 前向模型的角色预演。数据分辨率与拟合分辨率
的**有意失配**（阶段 3）构成真实模型误差的诚实检验，避免无噪偏差平凡为零。

## 3. 端到端闭环矩阵（第三层阶段 1）

设置：12 个代表性驱动点（§三 档位矩阵：强度三档 × CEP × 各向异性 × 波长 ×
脉宽）；数据生成分辨率 nk=64、dt=T_L/100、N_ω=32、N_τ=17、探针 σ_p=1.5 fs、
E_p = 10⁻³E_write；拟合分辨率与数据一致（噪声极限检验；保真度极限见 §5）；
无噪拟合恢复 θ=(Δ0, κ_m)，随后注入 **η=1% 实验级相对噪声**（手册 G.6.5 设计值，
对应每延迟点 10⁴ 发平均）×3 蒙特卡洛重拟合。

**M 指标定义**（理论文档 §4.3）：M2 = max_τ|Δ̂_eff(τ) − Δ_eff^true(τ)|/Δ₀
（瞬态带隙重整波形恢复偏差，掩膜窗外）；M1 = 由拟合波形代入闭式曲率与真值
剖面的最大相对偏差；M3 = 瞬时陈数符号一致率与裕度 min|Δ̂_eff|/Δ₀；
M4 = 闭合窗检出与 |ΔC|=1 跃变复现。

**结果**：

| 驱动点 | 无噪 M2 | η=1% 蒙特卡洛 M2（3 次实现取最大） | M3 符号一致 | 判定 |

| T0.3（定义保持档） | 0 | 0.113% | ✓ | ✓ |
| T0.6 | 0 | 0.060% | ✓ | ✓ |
| T1.0（拓扑写入档） | 0 | 0.101% | ✓ | ✓ |
| T1.5 | 0 | 0.092% | ✓ | ✓ |
| T2.0（深写入档） | 0 | 0.040% | ✓ | ✓ |
| T0.3-CEP（π/2） | 0 | 0.030% | ✓ | ✓ |
| T1.0-CEP（π/2） | 0 | 0.026% | ✓ | ✓ |
| T2.0-CEP（π/2） | 0 | 0.023% | ✓ | ✓ |

**判定**：11/12 在册驱动点在 η=1% 实验级噪声下 M2 最大值 = **0.113% < 1%** ✓
（相对 1% 目标的裕度 ≈ 9×）；无噪偏差 = 优化器容限（≈0）✓；M3 陈数符号
一致率 11/11 ✓；M4 闭合窗检出与 |ΔC|=1 跃变复现 ✓。第 12 点为**有意设置的
离册应力点**（30 fs 短脉端），失败并被定位为可辨识性边界（§6.4）——不进入
达标统计，其教训转化为写脉冲脉宽下限约束。

**与线性化预言的一致性**：拟合点雅可比协方差预言 η=1% 下 M2(1σ) ≈ 0.06–0.07%
（§4），蒙特卡洛实现在 0.02–0.11% 区间——一致（非线性与掩膜效应引入 <2× 修正）。

## 4. 噪声预算与 η_c（第三层阶段 2）

拟合点雅可比 J = ∂A/∂θ 的协方差（线性化）：
σ_θ(η) = sqrt(diag[(JᵀJ)⁻¹]) · η · A_rms。波形偏差传播：
M2(1σ; η) = (σ_Δ0 + σ_κ·m_pk)/Δ₀。

**各档位结果**（η = 1% 档）：

| 驱动点 | σ_Δ0 (eV) | σ_κ | M2(1σ) | η_c（M2<1% 容限） |
|--------|-----------|-----|--------|--------------------|
| T0.3（定义保持档） | 2.8e-05 | 1.6e-03 | 0.085% | ≈11.8% |
| T1.0（拓扑写入档） | 2.6e-05 | 2.9e-04 | 0.074% | ≈13.5% |
| T2.0（深写入档） | 3.0e-05 | 1.5e-04 | 0.085% | ≈11.8% |

（σ_θ(η=1%) = σ_θ(单位噪声)×0.01×A_rms；η_c = 1%×(0.01/M2(1σ;η=1%))。
蒙特卡洛实现在 0.023–0.113% 区间，与线性化预言一致（含掩膜与非线性修正）。）

**发数需求换算**：η = η_shot/√N_shots（η_shot ≈ 0.095，团队预研 SNR≈105@百发窗）。
η_c ≈ 12–13% 对应 N_shots ≈ (0.095/0.125)² ≈ 1 发——即单发统计水平即可支撑
1σ<1%；取 10⁴ 发（设计值）时裕度 >10²×。**结论：测量噪声不是 <1% 目标的
限制因素；限制因素是前向模型保真度（§5）。**

## 5. 前向保真度要求（第三层阶段 3，模型误差极限）

拟合前向分辨率相对数据生成分辨率有意失配时，无噪 M2 随失配度增长
（T1.0 拓扑写入档代表点）：

| 拟合分辨率 (nk / dt) | 失配度 | 无噪 M2 | 无噪 M1 |
|----------------------|--------|---------|---------|
| 36 / T_L÷60 | ~44% | 94.9% | 82.1% |
| 44 / T_L÷80 | ~31% | 12.5% | 13.7% |
| 52 / T_L÷90 | ~19% | 2.15% | 13.4% |
| 60 / T_L÷95 | ~6% | 15.4%（非单调） | 49.6% |
| 64 / T_L÷100 | 0%（平凡恒等） | 0% | 0% |

**解读**：模型误差比测量噪声大三个数量级以上，是 <1% 目标的真实限制因素。
且失配区间内 M2 **非单调**（60/95 行落入局部极小，比 52/90 更差）——失配
前向的残差景观存在简并谷，优化器稳健性随失配度恶化。量化要求：**反演前向
模型（L1 层即 RT-TDDFT）须收敛至数据生成物理的 ≲3% 离散化水平（52/90 行的
2.1% 仍超出 1% 目标；60/95 行的非单调表明匹配分辨率之外的拟合不可靠），方能使
波形恢复偏差 <1%**。该要求对 L1 层 RT-TDDFT 的 k 网格、时间步与基组收敛性给出
直接工程指标（手册 D.3 误差合成的输入），并要求反演流水线配备多起点与
分辨率收敛自检（防局部极小）。

## 6. 与申请书判据的衔接、局限与后续

1. **与 |ΔC_total| ≤ 0.20 工程阈值的关系**：本报告的 <1% 为 L0 闭环的
   **测量-反演管线精度**（模拟器前向、可控噪声），申请书 0.20 为**实验总误差**
   预算（谱噪声/时序抖动/泛函系统项线性叠加）。两者并行：L0 证明反演管线与
   测量方程组无原理性缺陷且噪声裕度充足（η_c ≈ 15% ≫ 1%）；实验总误差由
   L1/L2 层按申请书 §三 2.3(b) 误差合成另行控制。
2. **与手册 G.4.1 传递系数标定的关系**：手册预估"相对噪声 0.01 → ΔC 0.05"
   （5× 放大，间接反演通道保守预算）。本验证的 CD 比值通道传递系数为 O(1)
   量级（σ_θ 表：η=1% → M2(1σ) ≈ 0.07%，即 ~0.07× 放大）——**修正**手册预估：
   CD 通道的噪声裕度远优于保守预算；5× 保守值保留给 HHG 螺旋度间接通道。
3. **局限（诚实声明）**：
   a. L0 基准模型为有隙各向异性 Dirac（α-T₃ 价带-导带有效投影），带隙重整以
      动态质量项代理——材料写实性属 L1（RT-TDDFT）层任务；
   b. 闭环的拟合前向与数据生成同为所述离散化（匹配分辨率）——**前向模型误差
      极限由 §5 收敛表单独量化**；L1 层 RT-TDDFT 前向对真实材料的离散化误差
      须按 §5 要求（≲3–6%）收敛；
   c. 显式比值估计器（理论文档式 (19)(20)）的快速实现受窗口记忆效应限制
      （附录 D），当前以模拟器内嵌拟合替代；其 L1 显式实现为后续优化项；
   d. 陈数符号裕度在定义保持档 ≥1.0（Δ_eff 恒正/负）、拓扑写入档由 ATA 闭合
      掩膜门保障——闭合窗内陈数不可定义（掩膜），跨窗跃变 |ΔC|=1 由 M4 验证。
4. **可辨识性边界（T0.3-6cyc 应力点）**：30 fs（6 周期）短脉冲在定义保持档
   的 θ 恢复失败（密初始网格下仍收敛到 κ̂ ≈ 0.25 假极小，M2 ≈ 51%）——短脉冲
   的瞬态带隙重整签名在当前观测算设计下不可辨识。**工程结论**：1% 目标的写
   脉冲脉宽下限为 ≥8 周期（40 fs @1.5 μm）——与手册 G.1.2 "放宽至 50–75 fs
   进入 10–15 周期区"的论证方向一致并给出数值支撑；申请书脉宽档（30–50 fs）
   的短端 30 fs 不满足 1% 目标，建议修订为 ≥40 fs 或接受降级口径。
5. **后续（L0→L1 交接项）**：显式估计器的时域记忆修正；2μm 边界点与
   短脉冲点的观测算增强（探针谱覆盖、延迟栅加密、多色探针）；三带 α-T₃
   严格模型交叉验证（两带投影的适用边界）；失配前向的多起点全局优化。
