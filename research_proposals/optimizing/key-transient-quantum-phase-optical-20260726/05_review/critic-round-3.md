#### [high] 结构缺陷 — 系统级架构图为"三块并列"结构，与正文"三段链路（写→读→反演）"叙事矛盾

#### [high] 算力时序不一致 — §1.2 "1–2 周/迭代" 与 §2.3a L1 "1–2 周/时间点" 单位错位

### 3. §3.2 各子课题技术方案（第 281–359 行）

#### [critical] 物理可行性 — Bi₂Se₃（反演对称晶体）用 SHG 偏振旋转作"实时触发信号"的物理基础存疑

- **位置**：第 303 行（§2.1b 第 4 条）："写窗口识别：以 SHG 偏振旋转 [21] 作为瞬态对称破缺的**实时标志信号**，触发 B 的阿秒探测扫描"
- **问题**：Bi₂Se₃ 属于 R-3m 空间群（菱面体结构），具有**体反演对称性**。在电偶极近似下，**体相 SHG 是对称性禁阻的**。文献中观测到的 Bi₂Se₃ SHG 来自表面态破缺或外电场诱导，非体相本征响应。**用 SHG 偏振旋转作为"实时触发"意味着 SHG 信号需在每个激光脉冲上都被检测到**——而表面态 SHG 信号强度比体相 SHG 弱 1–2 个数量级，时间分辨 SHG 触发在 kHz-100 kHz 重复频率下需高灵敏度+低噪声探测器。
- **更严重的物理论证**：(a) MoS₂ 单层（2H 相）是**非中心对称**的，SHG 信号强——但 MoS₂ 是 §2.1a 中"强非绝热模式"代表，与"准绝热"标签不符；(b) 1T-TaS₂ 中心对称，SHG 同 Bi₂Se₃ 一样受抑制；(c) MnBi₂Te₄ 体相 A 型反铁磁序下 SHG 特征复杂，与瞬态拓扑无简单对应。
- **对评审的影响**：把一个"体相禁阻"的二阶非线性过程作为"实时触发信号"，是**物理概念级错误**。任何做阿秒-非线性光学的评审专家都会识别。
- **建议（action: rewrite）**：
  1. 把"SHG 偏振旋转" 改为"反射式二阶谐波产生（SHG）的偏振依赖性，**对非中心对称相（如瞬态 2H-MoS₂ 或场致反演破缺态）**"；
  2. 对反演对称材料（Bi₂Se₃、1T-TaS₂），改用**三次谐波（THG）或瞬态反射率**作为实时标志信号；
  3. 显式说明 SHG/THG 的触发延迟（MHz 级电子学触发，非"每个脉冲实时"），澄清"实时"是指"每个数据采集周期"而非"每个光脉冲"。

#### [high] 物理定量 — 准绝热区判据 ℏω/E_g ≥ 2 在 Bi₂Se₃ + 1.5–2 μm 上仅勉强满足

- **位置**：第 293 行（§2.1a 表格 "准绝热区"）："判据：ℏω/E_g ≫ 1（取 ≥ 2）"；"对应驱动波长（Bi₂Se₃, E_g≈0.3 eV）：1.5–2 μm（ℏω ≈ 0.6–0.8 eV）"
- **定量核验**：
  - 1.5 μm：ℏω = 1240/1500 = 0.827 eV，ℏω/E_g = 0.827/0.3 = **2.76** ✓
  - 2.0 μm：ℏω = 1240/2000 = 0.620 eV，ℏω/E_g = 0.620/0.3 = **2.07** ✓（刚好过线）
  - 2.0 μm 是判据下界，再宽 0.1 μm（2.1 μm）就跌破 ≥2 阈值
- **问题**：(a) 1.5–2 μm 的"准绝热"是按 ℏω/E_g ≥ 2 的**最低门槛**实现的，没有工程裕度；(b) 申请人自定 ≥2 的判据——这一阈值在 Bukov-Polkovnikov 2017 原始论文中并未明确给出 2，申请人需要给出 ≥2 的物理根据（动量空间绝热条件、Landau-Zener 跃迁概率的极限等）；(c) 手册 A.2 第 56 行写"若 H(t) 满足准绝热条件，则 C_n(t) 可作为瞬态拓扑不变量"——但**没有显式说"瞬时陈数随时间连续"是 ℏω/E_g ≥ 2 的充分还是必要条件**。
- **对评审的影响**：判据边界 + 阈值自定义 + 裕度不足，叠加后让"准绝热"成为可被轻易证伪的区段。
- **建议（action: rewrite + recalculate）**：
  1. 把"取 ≥ 2"改为"取 ≥ 3（对应 Landau-Zener 跃迁概率 < 0.1）"，并给出该判据的物理推导（可放在方法学手册 A.2）；
  2. 把准绝热区波长范围改为 1.2–1.5 μm（ℏω = 0.83–1.03 eV，ℏω/E_g = 2.76–3.44），留出 30% 工程裕度；
  3. 或在文中明确承认"1.5–2 μm 是当前 OPCPA 装置可达的最优绝热区，进一步向短波优化受限于 OPA 泵浦能量"。

#### [high] 物理定量 — 强非绝热区判据对 MoS₂ 等宽带隙材料失效，表格仅以 Bi₂Se₃ 为例

- **位置**：第 294 行（§2.1a 表格 "强非绝热区"）："对应驱动波长（Bi₂Se₃, E_g≈0.3 eV）：4–8 μm（ℏω ≈ 0.15–0.31 eV，ℏω/E_g ≈ 0.5–1.03）"
- **定量核验**：对 MoS₂（E_g = 1.8 eV）：4–8 μm 给出 ℏω/E_g = **0.086–0.17**——比 Bi₂Se₃ 的 0.5–1.03 **小 3–6 倍**。这意味着 4–8 μm 对 MoS₂ 来说是**远低于带隙的子带隙跃迁**，**不构成"强场带间强耦合"**——手册 B.2 第 111 行自注"4–8 μm → 准绝热（ℏω/E_g ≪ 1 但驱动子带隙跃迁）"是自相矛盾的，**子带隙跃迁与"强场带间强耦合"在物理上不可同时成立**。
- **更深层问题**：申请人的"强非绝热模式"对 MoS₂ 来说物理上更接近"准绝热+子带隙多光子过程"，与对 Bi₂Se₃ 的"非绝热带间强耦合"是两种完全不同的物理图像。**用同一个 4–8 μm 波长段去统一处理两种物理机制，是分类错误**。
- **对评审的影响**：5 个核心靶材中，MoS₂、1T-TaS₂ 均为宽带隙（1.8 eV、0.5 eV），4–8 μm 驱动实际上**不在"强非绝热"范畴**，整个 §2.1a 的分区判据需要按材料重写而不是仅按 Bi₂Se₃。
- **建议（action: rewrite）**：
  1. 改写 §2.1a 的判据为"按材料逐一定制"：MoS₂ 用 0.8–1.2 μm（ℏω = 1.03–1.55 eV，ℏω/E_g = 0.57–0.86）作为"强非绝热"；1T-TaS₂ 用 2.5–4 μm（ℏω = 0.31–0.50 eV，ℏω/E_g = 0.62–1.0）作为强非绝热；

  3. 同步更新方法学手册 B.2 表的 MoS₂ 1T-TaS₂ 绝热分区归属。

#### [high] 算力可行性 — L2 "1 天/时间点" 缺 AI 加速比的定量论证

- **位置**：第 347 行（§2.3a L2 表 "时间目标"）："1 天/时间点"；第 350 行 L1 描述：单时间点 10⁶–10⁷ CPU·h，需 3000–6000 核 × 1–2 周

#### [high] 误差预算 — 线性求和、独立误差假定、XC 泛函 ΔC~0.1 均无支撑

- **位置**：第 355 行（§2.3b）："总体误差 ΔC ≤ 0.2（吸收谱噪声 ΔC~0.05 + 时间抖动 ΔC~0.02 + 温度漂移 ΔC~0.01 + 泛函误差 ΔC~0.1）"
- **问题 1（求和方式）**：四个独立误差源用线性求和（0.18），实际独立误差应使用平方和开根号（√(0.05²+0.02²+0.01²+0.1²) ≈ 0.114）。线性求和对应"极端最坏情形"，与正文"统计意义上的 ΔC"叙述自相矛盾。
- **问题 2（XC 泛函误差量级）**：RT-TDDFT 交换关联泛函在带隙预测中误差典型为 0.1–0.5 eV，**但其对 Berry 曲率积分（C 值）的影响不是 0.1**。Berry 曲率是导数量（∂u/∂k），对波函数细节高度敏感，XC 泛函的微小改变可能让 Berry 曲率分布剧烈变化（甚至改变符号），从而让 C 的整数值跳变而非"加 0.1 的小修正"。申请人将 XC 误差"四舍五入"为 ΔC~0.1 缺物理根据。
- **问题 3（与手册不一致）**：手册 D.3 第 188 行写"阿秒时间抖动 ≤ 50 as，ΔC~0.02"，但 §2.2a 改"≤100 as"。误差预算中用了 50 as 的 ΔC 值，与最新指标 100 as 矛盾（50 as → 100 as，ΔC 应翻倍到 0.04）。
- **对评审的影响**：误差预算是评审专家判断"瞬态陈数整数跃变（ΔC=1）是否可信"的关键数学依据。当前预算在求和方式、关键分量量级、参数一致性三方面均不严谨。
- **建议（action: rewrite + research）**：
  1. 改用平方和开根号，给出 ΔC ≤ 0.15（统计）+ 极端情形 0.20（最坏）；
  2. 对 XC 泛函误差的 ΔC 估算给出引用（如 [Wiley 2019 RT-TDDFT Berry curvature benchmark] 或类似），或保守改为"ΔC ≤ 0.3 不可控，需用更高阶 GW/BSE 校核"；
  3. 与手册同步把抖动指标统一为 100 as，并把 ΔC 相应改为 0.04。

#### [medium] 探测信号 — "空间共线 + 时间分时复用" 与 "同步采集" 矛盾

### 5. §3.4 关键技术难点（第 380–387 行）

#### [high] 备份方案失实 — D3 含时 GW/BSE "更稳定" 是物理误判

- **位置**：第 384 行（§4 D3 备份方案）："改用含时 GW/BSE 多体层级（成本更高但更稳定）"
- **问题**：含时 GW/BSE 的稳定性在**强场（4–8 μm，10¹⁴ W/cm²）下是未经验证的**——GW 在平衡态的收敛已需自能迭代，强场下需要含时自洽 GW，**当前文献中少有强场收敛性报道**。手册 A.3 第 76 行只列"含时 GW / Bethe-Salpeter"作为"多体关联"工具，**未承诺稳定性优于 RT-TDDFT**。"更稳定"是把平衡态的 GW 印象投射到强场，是经验性错误。

#### [medium] AI 训练数据假设过强 — D6 L0→L1→L2 迁移学习未考虑分布漂移

- **问题**：(a) L0 = 1D-TDSE 解析模型（α-T₃），L1 = RT-TDDFT 三维多体能带（Bi₂Se₃ / MoS₂）——**从 1D 解析模型到 3D 多体计算的分布漂移是巨大的**，简单迁移学习在文献中通常需要 10⁴–10⁵ 个微调样本，但 L0 给出 10⁵ 解析样本、L1 给出 10⁶ 高保真样本——样本量对比已经倒挂，微调后 AI 可能学不会；(b) "每步量化外推误差"是好的方法学，但**未给出量化指标**（如 L2 在 L1 测试集上的 RMSE 应小于多少）。
