### 1. 论文产出清单（5 年内 ≥ 12 篇 SCI，分级别与年度化承诺）

按照 NSFC 重点项目对"产出维度的可行性论证"要求，本项目论文产出承诺按"级别 + 数量 + 时间窗口"三元组明示，并以 attosecond / HHG / topological insulator 方向国际 5 年滚动产出节奏为可比基线[Varillas 2026 Roadmap]。**论文产出承诺按四档级别分层**：

| 论文级别 | 5 年累计 | 年度化分解 | 主要载体 | 国际可比基线 |
|---------|---------|-----------|---------|------------|
| **Nature 系刊**（Nature Photonics / Nature Physics / Nature Communications） | ≥ 3 篇 | 中期累计 ≥ 1 篇 / 结题累计 ≥ 3 篇 | 创新点 1（瞬态拓扑全光测量理论）、创新点 2（写-读-反演闭环演示）、1 篇国际首发工作 | MPQ-Krausz 阵营 attosecond 5 年累计 4-6 篇 Nature 系刊[Varillas 2026] |
| **PRL / PRX / Nat. Comput. Sci. / Nat. Mach. Intell.** | ≥ 4 篇 | 年度 ≥ 1 篇 / 中期 ≥ 2 篇 / 结题 ≥ 4 篇 | 创新点 3（物理约束 AI 反演算法）、创新点 4（绝热分区判据）、其他方法学增量 | Klimkin 2021 DNN HHG 反演为 PRL 级先例 |
| **Optica / Phys. Rev. A/B / Appl. Phys. Lett. 等专业顶刊** | ≥ 3 篇 | 年度 ≥ 0-1 篇 / 结题 ≥ 3 篇 | 5 靶材的实验反演结果、超快测量技术 | 国内 HHG+拓扑方向 PRX 级已发表先例[Lu 2022] |
| **SoftwareX / J. Open Source Softw. / Comput. Phys. Commun.** | ≥ 2 篇 | 年度 0 篇 / 中期 ≥ 1 篇 / 结题 ≥ 2 篇 | L0-L3 分层 AI 反演框架（创新点 5）、HHG-TopoInversion 开源包 | jinns[jinns 2024]、Quantum ESPRESSO 范式 |
| **合计** | **≥ 12 篇** | 年度 ≥ 2 篇 / 中期 ≥ 5 篇 / 结题 ≥ 12 篇 | — | — |

**可行性论证**：(a) **国际基线对齐**：attosecond 领域 5 年累计 Nature 系刊 4-6 篇是 Roadmap[Varillas 2026] 引用的活跃团队实证基线；本项目承诺 5 年 ≥ 3 篇 Nature 系刊**约为基线的 50–75%**，与申请人团队的现有积累 + 3 国际团队（MIT-Reis / MPQ-Krausz / ELI-ALPS）潜在合作加持相匹配。(b) **典型路径实证**：方法学创新从预印本推进到 Nature Photonics 的典型周期 2-3 年[McSweeney 2026 keV HHG]，本项目创新点 1+2 的"瞬态拓扑全光测量理论"首发工作预计于第 2-3 年发表。(c) **国内可比先例**：国内 HHG+拓扑方向已有 PRX 级发表能力[Lu 2022]，本项目承诺与国内既有水平相当。

**5 年发表节奏预测**：第 1 年发表首批方法学/可行性论文（1D-TDSE benchmark + L0 nursery 训练流程，~2 篇 PRL/PRA 级）；第 2 年发表创新点 4 绝热分区判据（1 篇 PRL 级）+ 1 篇实验范式（Optica 级）；第 3 年（中期）累计 ≥ 5 篇，包括 1 篇 Nature 子刊级创新点 1 理论首发 + 1 篇创新点 3 算法（Nat. Comput. Sci. 级）；第 4-5 年累计 7-9 篇，含剩余 Nature 系刊与 2 篇 SoftwareX 工程论文。

### 3. 数据集 / 软件 / 装置开放（NSFC 2026 改革硬要求）

NSFC 2026 改革明确要求"加强开放科学，推动科研数据 / 代码 / 装置开放共享"。本项目承诺以下 4 类开放科学产出。

**（a）核心数据集清单**（≥ 1 个核心数据集）：

| 数据集 | 内容 | 规模 | 公开平台 | 公开时点 |
|--------|------|------|---------|---------|
| **Bi₂Se₃ 瞬态拓扑全反演数据集** | 5 个参数组合 × 10 个时间点的 RT-TDDFT 原始数据 + 反演后的瞬时陈数 C(t) 与 Berry 曲率 Ω(k,t) | ~10⁵ CPU·h 计算量 / ~50 GB 原始数据 | Zenodo / Figshare / NSFC 数据共享平台 | 第 3 年中期 |
| **5 靶材全反演汇总数据集** | Bi₂Se₃ / MnBi₂Te₄ / Co₃Sn₂S₂ / MoS₂ / 1T-TaS₂ 五个靶材的全反演结果汇总 | ~10⁶-10⁷ CPU·h 计算量 / ~500 GB | 同上 | 第 5 年结题 |

数据组织参照国际 aatas 数据集[Volkov 2025] 的多维数组 + 标定参数 + 元数据规范，按 Zenodo / Figshare 字段标准发布。**国际依据**：attosecond roadmap[Varillas 2026] 明确倡议 attosecond 实验原始数据（HHG 谱、attosecond transient absorption traces、CEP 扫描数据）必须以可复现格式在公开平台共享。

**（b）开源软件清单**（≥ 1 个开源软件）：

| 软件 | 内容 | 代码组织 | 开源平台 | 公开时点 |
|------|------|---------|---------|---------|
| **HHG-TopoInversion** | L0-L3 分层 AI 反演 Python 包 + VAE + 扩散模型代码 + 训练脚本 + 文档 + pytest 测试集 + CI/CD | 参照 jinns[jinns 2024] 目录结构：model / loss / train / evaluate + reference docs + versioning | GitHub（Apache 2.0 或 MIT 协议）+ Zenodo（版本化归档） | 第 2 年起持续更新，第 5 年 v1.0 稳定版 |

**（c）装置开放方案**：

- **强场-阿秒联合装置机时对外开放**：第 3 年起，每年对外开放 **≥ 20% 机时**（参照 ELI-ALPS 国际旗舰 user facility[Nayak 2026] 的机时分配原则）；
- **用户委员会组建**：第 2 年起组建 **5-7 人用户委员会**（含国内同行代表 3-4 人 + 国际代表 1-2 人 + 申请人 PI），负责 user proposal 评审与机时分配；
- **申请通道**：建立标准化的 user proposal 申请通道（参考 ELI-ALPS / 欧洲 XFEL 的双层用户委员会架构）。

**（d）标准 / 协议贡献**：

- **白皮书**：第 3 年发布 **"写-读-反演闭环的反事实条件约束"白皮书**（中英文双语，10-30 页），形成行业标准 / 申请 1 项国家标准；
- **协议贡献**：将"反事实条件约束"机制纳入强场-阿秒联合实验的国际 community standard 讨论（依托 attosecond roadmap[Varillas 2026] 的 community 框架）。

### 6. 经费预算（5 年总预算 300 万，按 NSFC 重点项目标准分配）

**5 年总预算 300 万**（与 NSFC 重点项目 `funding_max_wan=300` 对齐），分 6 大类预算项：

| 预算类别 | 5 年总额（万）| 占比 | 年度化分解 | 国际/国内参照 |
|---------|-------------|------|-----------|--------------|
| **设备费**（强场-阿秒联合装置升级 / 维护 / 关键部件更换 / OPCPA 维护 / 低温恒温器）| **100** | 33% | 前 2 年占比 > 40%（装置升级集中），后 3 年 25% | 国内 SHINE/AttoSHINE[Yan 2025] 装置预算结构对标 |
| **材料费**（5 靶材制备 / 多元靶材开发 / 低温恒温器液氦消耗 / 各类耗材 / 标定靶）| **50** | 17% | 各年 10 万 / 年（基础消耗稳定）| 国内 PE NWA 装置[Nayak 2020] 材料费比例对标 |
| **测试 / 计算费**（天河 / 曙光超算机时 / GPU 节点 / 商业软件许可 / 存储）| **80** | 27% | 后 3 年占比 > 30%（反演计算集中）| ELI-ALPS 计算预算比例对标 |
| **会议 / 国际合作费**（国际会议注册 / 国际互访机票住宿 / 联合实验差旅 / 国际研讨会主办）| **30** | 10% | 各年 6 万 / 年（邀请报告与互访密集期）| attosecond roadmap[Varillas 2026] 倡议对标 |
| **人员费**（博士后工资 / 研究生补助 / 临时聘用）| **35** | 12% | 各年 7 万 / 年（培养规模递增）| 国内重点项目标准 |
| **其他**（论文发表 / 专利申请 / 数据集出版 / 不可预见费）| **5** | 2% | 各年 1 万 / 年 | NSFC 标准 |
| **合计** | **300** | 100% | 平均 60 万 / 年（前 2 年设备费高，后 3 年测试计算费高）| — |

**预算合理性论证**：(a) **国际 / 国内装置预算结构对标**：本项目"设备 33% / 材料 17% / 测试计算 27%"分配方案与国内 SHINE 装置[Yan 2025] 预算结构 + 国内 PE NWA 装置[Nayak 2020] 预算分布在量级上一致；(b) **年度节奏合理**：前 2 年设备费占比 > 40%（装置升级是前 2 年的关键瓶颈），后 3 年测试计算费占比 > 30%（反演计算集中在后 3 年），与研究方案 §1.3 五年技术推进表匹配。

### 7. 节点检查 / 中期评估 / 结题标准（NSFC 重点项目惯例）

| 产出类别 | 年度自查（每年底） | 中期评估（第 3 年累计） | 结题标准（第 5 年累计） |

| **发明专利** | 0 项（按需累积）| ≥ 1 项 | ≥ 3 项（含 1 项 PCT）|

### 9. 风险-产出降级备份（与研究方案 §4 风险表 D1-D6 对应）

| 风险编号 | 风险描述 | 产出降级方案 |
|---------|---------|-------------|
| **D1**（绝热-非绝热跨区理论衔接）| 两区交界处（ℏω/E_g ≈ 1）拓扑不变量连续性争议 | 第 1-2 年集中攻关；发表 1 篇 PRL 级跨区判据论文；若跨区不连续，把两区作为独立物理区间分别报告——产出降级为 2 篇独立 PRL 级判据论文而非 1 篇综合论文 |
| **D2**（驱动-探测 ≤100 as 时序稳定）| 时序抖动若超标（>200 as），瞬态相窗口时间分辨率退化 | 三重稳定机制（f-2f CEP + 双光梳 + 主动反馈）；若仍不达标，改用 attoclock 几何路径替代 RABBITT——产出降级为"阿秒条纹 + RABBITT 联合分析"转为"attoclock 单路径反演"，仍可完成主要靶材的反演 |
| **D3**（RT-TDDFT 强非绝热区收敛性）| 4-8 μm 强场下数值不收敛 | 改用含时 GW/BSE 多体层级；产出降级为 3 个靶材（Bi₂Se₃ / MoS₂ / 1T-TaS₂）的 RT-TDDFT + 2 个靶材（MnBi₂Te₄ / Co₃Sn₂S₂）的 TDSE 全量级计算 |
| **D4**（贝叶斯反演算力可达性）| L1 全反演需 10⁶-10⁷ CPU·h，依赖超算持续占用 | 第 2 年起申请天河/曙光超算机时；若机时不足，主动收窄至 Bi₂Se₃ + MoS₂ 两个代表体系做 L1 全反演，其余 3 体系只做 L2 采样——产出降级为"2 靶材 L1 全反演 + 3 靶材 L2 采样"，仍可完成主要科学目标 |
| **D5**（磁性拓扑副作用）| MnBi₂Te₄ / Co₃Sn₂S₂ 强场下磁背景污染拓扑信号 | 低温（4 K）+ 低重频（1 kHz）+ 多点扫描平均 + SHG / MCD 分离；若仍不可分离，退回非磁体系（Bi₂Se₃ / MoS₂）为主验证——产出降级为"3 个非磁靶材（Bi₂Se₃ / MoS₂ / 1T-TaS₂）完整闭环 + 2 个磁性靶材（L2 采样级）" |
| **D6**（AI 代理模型泛化性）| VAE + 扩散模型外推到真实材料失真 | 迁移学习 + 外推误差量化；若仍失真，L2 退回纯 RT-TDDFT 采样——产出降级为"L0-L1 + RT-TDDFT 完整保留 + L2 AI 加速版转为软件论文（SoftwareX）的备选模块而非主要反演路径" |

**国际降级范式参照**：attosecond roadmap[Varillas 2026] 显式列出 attosecond 领域各子方向的"风险触发 → 替代技术路径"（高重频源风险 → 备选：高平均功率激光器；CEP 主动控制风险 → 备选：被动共光路 Sagnac 稳定；HHG phase matching 失败 → 备选：部分 phase matching + 谱学反演[Nayak 2024]），本项目"6 大风险 → 降级方案"严格按 roadmap 的"主路径 + 备选路径"双重承诺模式制定。
