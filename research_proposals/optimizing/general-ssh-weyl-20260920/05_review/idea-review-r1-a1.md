## 2. 创新点可检验性（testability）

**得分：0.15**

### 已可观察的部分
- 文件本身**没有写出任何创新点**（"待填写"）。
- 仅在 `04_proposal/proposal-draft-merged.md` 的周末输入补充中可见到 5 个问题形式的"创新点草案"：
  1. 高阶拓扑绝缘体 HHG 拓扑特征为何消失？
  2. SSH 边界态的谐波压缩能否推广至 3D 拓扑材料？
  3. 半金属相 2–3 个数量级谐波增强的微观机制？
  4. ZnO 激子-HHG 竞争能否用于超快调控？
  5. 能否构建同时涵盖拓扑/多带/量子光场的统一理论框架？

### 具体问题
1. **所有草案均为"问句"，不是"可检验命题"**。问句无法被证伪，也不构成创新点陈述。NSFC 创新点应写为"本研究将首次建立/发现/观测到 X"，并给出可测量信号。
2. **缺乏量化判定指标**。例如草案 3（半金属 2–3 个数量级谐波增强），需要明确"本研究将把增强因子分解为 Weyl 节点贡献 X%、Berry 曲率贡献 Y%、载流子动力学 Z%"，并给出判别阈值。
3. **草案 1（拓扑特征消失）的检验标准模糊**。"消失"是相对什么参照？需要明确"与平庸相 HHG 谱相比，HOTI 的高阶圆二色性强度比 ≥ K 时判定为拓扑印记"。
4. **草案 5（统一理论框架）不可证伪**。"统一框架"是结构性贡献，本身不是实验检验对象；必须拆分为至少 2 条**可由 HHG 谱直接判定**的预言。
5. **草案 4（ZnO 调控）与三个拓扑体系脱钩**。这是另一个物理现象（激子-HHG 竞争），与拓扑物态探测无直接关联，留在同一课题里会让创新点之间缺乏内在一致性（详见维度 4）。

### 改进建议
- 每个创新点必须含三要素：**新事实/新方法/新理论 + 可测量物理量 + 判别阈值**。
- 草案 5 必须拆为可检验的子命题，例如"在同时具有 Weyl 节点与镜面对称的体系，HHG 圆二色性的角度依赖必须呈现 [具体函数形式]；若偏离 X%，则框架失效"。

## 4. 方向一致性（consistency）

**得分：0.40**

### 已可观察的部分
- 标题把三个体系（高阶拓扑绝缘体、SSH 边界态、Weyl 半金属）并列在同一课题下，**形式上是统一的**（都通过 HHG 探测）。
- 背景段也用"统一理论框架"作为收尾（多带模型 + Berry 相位 + 等离激元-半导体 + 量子光场），暗示作者想要构建一个能覆盖所有三个体系的统一图景。

### 具体问题
1. **三个体系的"拓扑类目不同维度"未被论证为可比**：
   - 高阶拓扑绝缘体：3D 二阶拓扑（如 SnTe、Bi₂Se₃ 家族）
   - SSH 模型：1D 二阶拓扑（边界态）
   - Weyl 半金属：3D 半金属（线性色散节点，非绝缘体）
   
   这是**三种本质不同的相**：绝缘 vs 金属、二阶 vs 半金属、维度 1 vs 3。把它们放在同一课题里，要么必须有"统一标尺"（如都用 Berry 曲率分布刻画），要么必须明确"分阶段逐步验证"。当前文件两种论证都没有。
   
2. **ZnO 不是拓扑材料**。背景段提到"ZnO 中强场 HHG 与激子光致发光竞争"，这是一个**激子物理**问题，与拓扑无关。如果放在"拓扑物态探测"的课题里，需要明确它扮演什么角色（参照体系？激子-HHG 通道作为对比？还是独立子项目？）。当前背景把它和拓扑体系并列描述，没有任何过渡性论证，会让审稿人质疑"为何把 ZnO 也放进课题"。

3. **量子光场效应 vs 拓扑 HHG 是两条并行前沿**。背景段末尾提到"等离激元-半导体混合纳米结构与量子光场效应"和"非经典光生成"，这是 HHG 研究的另一条主线（bright squeezed vacuum driven HHG，已有独立课题 `general-bsv-driven-hhg-quantum-20260726`）。**与本课题在 `00_idea-dossier.md` 中的新颖性判据是冲突的**——BSV-HHG 已被独立立项。

4. **建议的"统一理论框架"在尺度上不自洽**：
   - 多带 Berry 响应（动量空间，meV 精度）
   - 等离激元-半导体混合（纳米结构，空间尺度 10–100 nm）
   - 量子光场（光子统计，g² 测量）
   
   这三层物理在理论框架上不在同一层级；把它们"统一"是宏大但缺乏具体起点的宣称。

### 改进建议
- 把三个拓扑体系的关系明确化：
   - **方案 A**：把 SSH 视为"toy model 验证算法"，HOTI 和 Weyl 是"真实材料预测"，三层各司其职。
   - **方案 B**：聚焦于"通过 HHG 偏振依赖反推 Berry 曲率分布"作为统一物理量，三个体系都是案例。
   - **方案 C**：放弃统一化，明确写"三个独立子课题，共同方法学是 HHG 强场光谱"。
- 把 ZnO 部分独立出去，或者写明它作为"非拓扑对比样品"的角色。
- 量子光场部分要么删去，要么明确写成"理论框架的远期延伸"，避免与现有 BSV 课题重叠。
