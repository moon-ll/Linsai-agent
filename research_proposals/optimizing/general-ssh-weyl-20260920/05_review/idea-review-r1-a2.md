### 仍存在的问题

1. **三个创新点的"预期量化优势"均为相对量，缺乏绝对阈值**：
   - 创新点一："相对现有 CD 方案，新探针对高阶拓扑相的区分度提升一个数量级以上"——**一个数量级**是相对量，需明确"区分度"的定义（信噪比？强度比？角度分辨率？）和"现有 CD 方案"的参照体系。
   - 创新点二："精度优于已有定性结果"——**精度优于定性**几乎是无下界陈述，需明确"精度"指什么（谐波压缩度的数值误差？相变点位置的判定误差？）。
   - 创新点三："分解为可归因于各因素的百分比贡献，并提出 1–2 条实验可检验的调控判据"——这是最具体的，但"百分比贡献"的求和是否归一（X% + Y% + Z% = 100%）？调控判据的具体形式（CD 符号翻转角度？强度比阈值？）仍未给出。

2. **创新点一的"提升一个数量级以上"在 SSH/QWZ 模型中可能不是合理目标**。SSH 是 1D 二阶拓扑 toy model，QWZ 是 2D 一阶拓扑模型——两者都不是"高阶拓扑"的代表体系。预期在 SSH 上做出"高阶拓扑"探针，要么需要扩展 SSH 为多层 SSH（物理上仍是 SSH 类），要么需要换用 Bi₂Se₃/SnTe 这类真实 3D HOTI。当前预期值与模型选择之间存在隐含不匹配。

3. **创新点三"ZnO 激子-HHG 调控"与三体系拓扑物态的可检验性逻辑脱钩**。拓扑物态 HHG 是相干探测，激子-HHG 调控是超快开关——两者的可检验指标体系不同（前者看 Berry 曲率分布，后者看通道耦合强度）。把两个可检验逻辑不同的命题合并在同一个创新点下，会让"实验可检验的调控判据"被读者误解为"拓扑探测判据"。

4. **创新点四（统一理论框架）仍被遗漏**。r1-a1 已指出"统一框架是结构性贡献，本身不是实验检验对象"。文件第 62 行"技术路线四：统一理论框架的形式化"被纳入技术路线，但**未在创新点章节给出可检验的子命题**——这是结构性缺失。

### 改进建议
- 为每个创新点配套"判别阈值表"：例如创新点一附"高阶圆二色性强度 ≥ K (K=具体数值) 时判定为 HOTI 印记"；创新点三附"Weyl 节点贡献 ≥ X%、Berry 曲率贡献 ≤ Y% 时判定为分解成功"。
- 创新点一建议把模型选择修正为"在 Bi₂Se₃ 家族 HOTI 模型的 CD 谱上验证新探针"——避免 SSH/QWZ 与"高阶"语义错配。
- 增加创新点四（或拆分创新点三），把"统一框架"拆为可检验预言，如"在同时具有 Weyl 节点与镜面对称的体系中，HHG 圆二色性角度依赖必须呈现 [具体函数形式]；若偏离 X%，则框架失效"。
- 创新点三拆分为两个独立创新点：Weyl 半金属分解（拓扑物态 HHG）+ ZnO 调控（半导体相干光源），分别给出可检验指标。
