### 仍存在的问题

1. **核心问题陈述仍偏长且含条件从句**。第 38 行一句话核心问题实际上是两个并列子问题（统一可观测量问题 + ZnO 对照分离问题）的复合句——单个句号内含两个"能否…能否…"的并列疑问。NSFC 评审倾向读为单一聚焦问题；当前复合句容易被解读为"两个半独立问题"。

2. **"统一可观测量"的内涵与外延尚未被严格定义**。第 18 行提到三类 HHG 观测量（CD 角度谱 / 谐波压缩度 / Berry 曲率修正跃迁矩阵元），但核心问题只点名了"HHG 偏振依赖与谐波压缩度"两种——第三种"Berry 曲率修正跃迁矩阵元"在核心问题陈述中被边缘化，会让 Weyl 体系（创新点三、四的核心）的可测物理量在核心问题层面缺少显式位置。

3. **四个"如何/怎样"型问题（第 54–58 行）与第 38 行核心问题之间缺少收敛关系**。四个并列问题中，第 3 个（Weyl 半金属分解）属于核心问题的"Weyl 节点"分支，第 4 个（ZnO 对照）属于"ZnO 对照分离"分支；但第 1 个（高阶拓扑探针）和第 2 个（三维拓扑相变判定）各自独立，难以看出它们如何收敛到核心问题上的同一可测物理量。读者需要自行拼合——这是 r1-a2 已指出但本轮未彻底解决的问题的变体。

4. **第 18 行"ZnO 承担非拓扑参考体系角色"的论证隐含一个未声明假设**：Berry 曲率贡献与多通道耦合贡献在实验上可分离。这一假设在所有 HHG 文献中尚未被系统验证，本文件默认其成立，但未论证。如果该假设本身有争议，整个对照方案的可信度被削弱。

### 改进建议
- 把核心问题拆为两个清晰陈述句：第一句回答"统一可观测量"问题，第二句回答"对照分离"问题。
- 在第 38 行核心问题中显式加入"Berry 曲率修正跃迁矩阵元"，使三体系共用可观测量在核心问题陈述层面被平等对待。
- 在第 18 行论证 ZnO 对照方案时增加一句"Berry 曲率贡献与多通道耦合贡献可分离性的前置论证依据"——例如引用 Ghimire 2011、Plaja 等早期工作对带内/带间贡献可分性的论证。

### 仍存在的问题

1. **判别阈值均为"理论目标值"，缺乏"已发表实验的边界条件对照"**。四个创新点都给出"≥ 10"、"≥ 20%"、"≥ 30%"、阈值 T 等数值，但都没有指出"在已有的 CD 谱实验中，强度比的典型数值范围是多少"。如果 SSH/QWZ 实验中典型的 CD 强度比已经是 5–50 量级，阈值 ≥ 10 可能过松；若 Bi₂Se₃ HOTI 实验中典型强度比是 100–500，阈值 ≥ 10 可能过严。判别阈值的合理性需要与已发表实验对照——本文件未提供这一对照。

2. **创新点一"高阶 CD 强度比 ≥ 10"与"已发表实验对照"的逻辑链不闭合**。第 18 行提到"已有结果观察到高阶拓扑 CD 信号减弱乃至消失"——意味着高阶拓扑相的 CD 信号本身就弱。如果基线强度比已经 < 10（因为"消失"），那么"≥ 10"作为可观测判据的物理意义是什么？是相对于普通 CD 强度比的相对提升，还是绝对值？这是创新点一所用的"区分度"定义在第 104 行未被澄清。

3. **创新点三"X% + Y% + Z% = 100%"的归一化假设需论证**。Berry 曲率、Weyl 节点、非平衡载流子三类贡献是否真的可线性分解为归一化百分比？这是一个独立的物理问题：例如 Berry 曲率贡献本身可能就是 Weyl 节点贡献的副产品（节点附近 Berry 曲率发散），无法独立归一化。本文件默认三者独立可分，未论证。

4. **创新点四"强度比 ≥ 阈值 R"的 R 留空**。第 110 行明确写"具体数值以方向四的扫描结果为准"——这等于把创新点的判据推迟到计算阶段。在 NSFC 申请阶段，创新点必须给出明确的成功标准；"待扫描结果"会降低可检验性。这与 r1-a2 提出的"创新点阈值仍模糊"是同类问题，本轮未解决。

5. **方案五"统一理论框架"仍未作为可检验创新点出现**。r1-a2 明确指出"统一框架是结构性贡献，需拆为可检验预言"。本轮把统一框架放在方案五（第 72 行）作为技术抽象层，但创新点章节没有"统一框架的可检验预言"。这意味着申请书在 NSFC 评审中可能被读为"我做了一个统一框架"——这是结构性宣称而非可证伪命题。

### 改进建议
- 创新点一的"区分度 ≥ 10"补充定义：是绝对强度比（高阶 CD 强度 / 低阶 CD 强度）还是角度分辨灵敏度？建议明确写出度量定义。
- 创新点三在归一化假设之外，补一个反例检验：若三类贡献确实无法线性分解（如 Berry 曲率贡献与 Weyl 节点贡献强耦合），本创新点的退路是什么？

### 仍存在的问题

1. **ZnO 的双重角色（"非拓扑参考体系"与"激子-HHG 调控对象"）在文件内仍未完全统一**。第 18 行把 ZnO 定位为"非拓扑参考体系"——核心作用是对照。但第 50 行（方向四）把 ZnO 的研究重心放在"HHG 与激子光致发光通道的竞争"——这是 ZnO 自身的物理研究（激子相干 + HHG 通道耦合的统一描述），不只是"对照"。方案三（第 68 行）也把 ZnO 的研究重心放在"激子-HHG 通道耦合"，而不是"作为拓扑对照"。第 18 行的"参考体系"定位与第 50、68 行的"ZnO 自身物理研究"之间存在角色冲突。读者读完第 18 行后会预期 ZnO 是"对照组"；但读到第 50 行会发现 ZnO 是"研究对象之一"，会产生"那 ZnO 到底是研究对象还是对照"的疑问。

2. **统一理论框架（第 72、98 行）与四方向的具体产出的关系不明确**。方案五说"统一框架在三类拓扑材料与 ZnO 对照体系中实现"——这意味着统一框架是横跨四方向的横向产出。但方向一/二/三/四的预期产出（第 44、46、48、50 行）都没有把"统一框架的实现"列为具体产出。如果统一框架是横跨产出，应该在每个方向的预期产出末尾都提一句；如果是独立抽象，应该在方向安排中单列。

3. **方向二与方向三之间在物理上没有严格的"递进"关系**。第 52 行说"方向三依赖方向二的模型"——但方向三研究的是 Weyl 半金属（3D 半金属相），方向二研究的是 SSH 边界态的 3D 推广。Weyl 节点的物理（线性色散、节点处 Berry 曲率发散）与 SSH 边界态的物理（带隙中的局域态）是本质不同的拓扑结构。从 SSH 推广到 Weyl 不是物理上的"模型推广"，而是"换一套完全不同的能带"。方向二 → 方向三 的"递进"在物理上站不住脚。

4. **三体系拓扑类目差异与"统一标尺"的论证仍偏弱**。第 18 行论证三体系共用三个可观测量（CD 角度谱 / 谐波压缩度 / Berry 曲率修正跃迁矩阵元），但具体到每个体系：
   - HOTI 重点看高阶 CD（第 44 行）
   - SSH 重点看谐波压缩度（第 46 行）
   - Weyl 重点看 Berry 曲率修正跃迁矩阵元（第 48 行）
   
   这意味着三个体系实际上各自看不同的可测物理量——所谓"统一标尺"实际上是被分散到三个不同的观测上。如果三个体系的可测物理量不重合，"统一观测量"在操作层面被分裂为三个互不等价的量。

5. **方向四的"对照验证"逻辑与第 18 行的"ZnO 对照"角色存在隐含层级冲突**。第 18 行说 ZnO 是"对照体系"（即在方向一/二/三的拓扑体系产出之后作对照）；但方向四（第 50 行）实际上自己研究 ZnO 的激子-HHG 物理——这意味着 ZnO 不是"被动的对照"，而是"主动的研究对象"。如果 ZnO 是被动对照，方向四的前半段（ZnO 自身物理）应该归入方向三或独立子方向；如果 ZnO 是主动研究对象，对照的独立性就被削弱。

### 改进建议
