## （二）研究内容

### §2.0 研究目标与关键科学问题

四年期研究内容锚定三条可检验目标，每条对应立项依据凝练的三层可证伪口径之一。判据阈值的物理依据与文献不确定度的合成过程均在立项依据中给出，下文不复述。

G1（方法学对照层）。在 TiSe₂ CDW 对照体系上建立一套可转移的偏振分辨 HHG 正演—反演流程。判据：自建装置上复现 Tyulnev 等人 [6] 报道的 3/5/7 阶谐波偏振不对称方向，与 Zhang 等人 [7] 理论预测的幅度偏差不超过 10%（10% 取值合成规则见立项依据）。方向重合确认装置的偏振分辨精度，幅度偏差 ≤ 10% 确认正演模型的预测精度；两条件一并成立，方可迁移至 CrSb 主体系。该复现并非新物理发现；只有通过这一复现，经 TiSe₂ 验证的方法才有资格迁移到 altermagnet 主线。

G2（信号探测层）。在 CrSb 主体系（备选 MnTe）上完成偏振—温度—磁场三重联合扫描，锁定磁场反转差分信号。判据：差分偶次谐波或圆二色性的相对强度 ≥ σ × 1.5—2.0，且多次平均后信噪比 SNR > 5（σ 取值与 0.75%—1.6% 折算区间见立项依据）。两项一并成立方可触发 G3；任一项不满足即按 §2.6 终止条件转入 MnTe 备选或方法学边界界定。SNR > 5 阈值保证多次平均后差分信号可与装置长时漂移造成的虚假差分区分开。

G3（唯一归因层）。以多带正演模型（含 SOC）与可辨识性分析工具联合约束，把磁场依赖信号归因于 altermagnet 序参量相关对称性。判据分两档：可辨识档为费舍尔信息矩阵条件数 κ < 10² 且贝叶斯后验标准差 < 先验宽度 50%，两判据一并成立方可视为归因成立。不可辨识档分两种情形：一是边缘可辨识区，10² < κ < 10⁴，或后验分布多峰共存，只报告联合后验分布并明确边界条件；二是 No-Go 区，κ > 10⁴，结论为 HHG 在该驱动条件下无法独立辨识 altermagnet 序参量相关对称性。该三档分档规则与立项依据及方案的费舍尔信息矩阵（FIM）阈值定义保持一致。

关键科学问题与上述三条目标紧密对应，包含两个递进的子问题。Q1（信号探测）。在 CrSb（或备选 MnTe）altermagnet 的固体 HHG 谱中，是否存在随外磁场方向反转而切换的偶次谐波或圆二色性信号，且相对强度 ≥ σ × 1.5—2.0、SNR > 5（σ 取值见立项依据）？该问题对应 G2 的可检验判据，其答案直接决定主体系主线能否进入唯一归因环节。

Q2（替代解释排除）。观测到磁场依赖信号后，能否以多带正演模型与可辨识性分析排除能带各向异性、跃迁矩阵元等替代解释，把信号唯一归因于 altermagnet 序参量相关对称性？其操作定义见立项依据 §一.3，定量分析在 §2.4（R3）展开。Q1 与 Q2 是递进关系：Q1 的"看到磁场依赖信号"是 Q2 的必要条件而非充分条件。能带各向异性、跃迁矩阵元效应在磁场下同样可能产生变化（论证见立项依据）。这一区分决定了 R3 须以多带正演模型与可辨识性框架为唯一归因的定量判据。

### §2.1 主问题的三重可证伪口径与研究内容框架

立项依据凝练的科学命题落到四年期的研究内容上，按 G1/G2/G3 三层递进展开：信号是否存在，信号是否来自序参量，信号能否被唯一归因。每层对应一组可证伪判据，定义与具体实施在 §2.0 与 §2.2—§2.4 给出。

围绕该递进结构，研究内容按 R1（TiSe₂ 方法学标定）、R2（CrSb 主体系探测）、R3（序参量可辨识性分析与替代解释排除）三个方向依次推进。三者的衔接是单向递进：R1 复现未通过时，不进入 R2；R2 信号未达阈值时，转入差分信号适用边界界定或触发 MnTe 备选；只有 R2 给出信号且信号进入 R3，才能触发唯一归因分析或 No-Go 边界界定。三层对应三条目标的可证伪口径，与立项依据的判据链保持一致。

机制层利用含自旋轨道耦合的半导体布洛赫方程（SBE）多带正演模型生成合成谱，通过费舍尔信息矩阵条件数判别参数空间可分辨方向，并以贝叶斯反演报告参数后验分布；数学工具与公式在研究方案部分给出，本节不展开。

研究内容的范围限定于 altermagnet HHG 序参量可辨识性这一具体命题，不承诺覆盖超导涨落、激子凝聚、多序共存等其他序参量类型。这些方向作为项目完成后的方法学推广对象，不占用本项目的核心研究投入。

### §2.2 研究内容 R1：TiSe₂ CDW 对照体系上的方法学标定

R1 把"HHG 偏振指纹"作为标定尺，先在一个具备实验与理论双源证据的体系上完整建立并验证"正演—反演"流程。以温度扫描驱动 TiSe₂ 跨过 CDW 相变点（约 200 K），记录 3/5/7 阶谐波的偏振不对称比，检视其相对变化方向是否与 Tyulnev 等人的实验一致，从而在已知体系上完成对装置与流程的双重标定。同一套流程下，把多带 SBE 正演模型在相变点上下预测的偏振依赖与双源数据对齐。模型参数以 Zhang 等人的 TiSe₂ 现象学平均场拟合值为初值迁移标定；该工作的方法为含时薛定谔方程加现象学平均场多带模型，其三个晶格方向矢量不等价的假设对应迁移至本项目 SBE 参数化。R1 的产物不是新物理，而是把经 TiSe₂ 验证的复现能力直接迁移到 R2 与 R3。

复现判据的两条通过条件（方向重合与幅度偏差 ≤ 10%）已在 G1 中给出；相变点附近温度扫描加密到 0.5 K 步长，以分辨 CDW 相进入过程中可能的中间态涨落。方向重合确认装置的偏振分辨精度满足后续实验需求；幅度偏差 ≤ 10% 确认自建多带 SBE 模型在文献参数附近具有实验级预测精度。两条件一并成立，TiSe₂ 上的"正演—反演"流程才有资格迁移到 CrSb。

R1 还承担一项贯穿全局的逻辑功能：把"对序参量相关对称性敏感"与"对序参量大小的直接度量"明确区分。TiSe₂ 上的偏振不对称来自 CDW 相引起的各向异性对称性变化（其与 CDW 振幅的非直接对应关系见立项依据）。该机制给出的是"出现/不出现"的二态信号，并不与 CDW 振幅建立连续标定关系。该二态信号在 R2、R3 中作为"序参量相关对称性灵敏度"的内部对照基准：任何 CrSb 的实验信号在被判定为 altermagnet 序参量相关之前，其探测灵敏度均须达到与 TiSe₂ 指纹可比的水准。

### §2.3 研究内容 R2：CrSb 主体系上的磁场反转差分探测与候选信号捕获

通过 R1 之后，工作主线转向 CrSb。CrSb 的体系选择已在立项依据论证。Néel 温度约 733 K（中子衍射实测 733(4) K [27]），远高于可达温区 4—300 K，磁序稳定性满足实验温区。Terashima 等人 [25] 由量子振荡测量确认 CrSb 的多条自旋非简并频率分支，其结果与 d 波交错磁自旋分裂费米面的解释一致，给出 altermagnet 自旋分裂的体态证据（具体形式由实验拟合与群论交叉确定，本节不展开）。dHvA 角谱研究另有 g 波证认 [36]，与 d 波分类 [17] 构成开放争议，波型终判由立项预研群论初判与 dHvA 节点校准确定。Wang、Wang 与 Meng [20] 给出 CrSb 中经相干声子路径实现皮秒级磁序调控的理论方案。d 波自旋分裂的群论基础已由对称性框架锚定（见立项依据 §一.2）。

R2 的实验任务是在该已选体系上做偏振（线、圆、椭圆及方位角）、温度与外磁场（正反方向切换）的联合扫描。磁场正反方向切换的差分作为主提取维度，偏振配置切换作为对称性约束，温度作为能带背景稳定性的监测变量。偏振配置、温度扫描区间与磁场切换时序等工程参数，在研究方案部分给出。

候选信号具有可量化的理论形态。Werner 等人 [16] 在弱 SOC 与强 SOC 两个极限下给出形态截然不同的预言。CrSb 中 Sb 5p 原子 SOC 约 0.3—0.4 eV，经晶体场与 Cr 3d 杂化后的有效值落在两极限之间的连续过渡区。SOC 的中间取值不能简单地以"有无"二元处理，须在连续参数空间中定位 CrSb 的实际位置。这一连续处理是 R3 反演框架在 CrSb 上的直接物理输入。

候选信号机制的补充参照来自相邻体系实验与 CrSb 自旋激发维度的微观计算。Ma 等人 [23] 在 MnTe 单晶上以二次谐波晶体学各向异性独立观测到 d 波 altermagnet 对称性特征，在相邻体系中验证了光学手段捕获对称性敏感信号的可行性。磁序进动与相干声子两个方向的理论参照已在立项依据 §一.2 给出。Singh 等人由非弹性中子散射独立观测到 CrSb 中手性自旋分裂磁振子（见立项依据 §一.2），为高阶 altermagnet 交换相互作用给出实验锚点，与 R3 反演框架的 SOC—磁场交叉项约束形成互补。

信号捕获的可证伪判据形式化为两项：观测到随外磁场正反方向反转而切换的偶次谐波或圆二色性，相对强度 ≥ σ × 1.5—2.0、SNR > 5。两项判据构成 CrSb 上的 Go 终止条件。若实测未达阈值，或强场下样品反射率出现超出损伤阈值的突变，或磁场切换驻留不稳定导致的系统项超过差分信号，则触发 MnTe 备选主体系。MnTe 备选体系的 Néel 温度（约 310 K）落在可达温区上沿附近，可叠加近相变温度依赖扫描与磁场反转差分两类约束，提升参数可辨识性。

R2 探测到的磁场依赖信号在方法学上仅构成必要条件而非充分条件，能带各向异性、跃迁矩阵元效应同样可能在磁场下产生变化（论证见立项依据）；R2 的任务止于"信号是否存在及其基本特征"，唯一归因则留给 R3。

### §2.4 研究内容 R3：序参量可辨识性分析与替代解释排除

R3 是方法学的核心，也是连接 R1、R2 的分析枢纽。可靠的归因通过一组正演模型与一组可辨识性分析工具的联合约束来实现，不依赖单一谐波指纹；R3 的全部设计都围绕这一联合约束的构造展开。

参数空间被显式划分为三类。能带参数描述电子基态结构，包括带内有效质量、带间跃迁偶极矩幅度、带内退相干时间；序参量参数刻画 altermagnet 磁序本身，包括 d 波自旋分裂幅度与 Néel 矢量方向；SOC 参数描述自旋轨道耦合强度因子与晶体场修正。三类参数的物理来源各自独立可控：偏振改变光场与物质的相互作用通道，仅影响各跃迁通道的激发权重；温度改变晶格热膨胀与电子占据；外磁场直接耦合到磁矩。该独立可控性支撑参数空间按物理来源分块；磁场与 SOC 两个哈密顿项一般情形下不对易，参数可分性是否严格成立由方案的 FIM 条件数数值检验判定。

可辨识性方法以两个相互补充的定量判据为骨架。其一是参数空间的可分辨方向评估：以费舍尔信息矩阵条件数为标尺，κ < 10² 视为可辨识、10²—10⁴ 落入边缘可辨识区并降档报告联合后验分布、κ > 10⁴ 触发 No-Go。其二是参数后验分布的定量报告：以贝叶斯框架替代点估计，输出后验均值、标准差与参数间相关系数矩阵，并以后验标准差是否落入先验宽度 50% 以下作为参数被有效约束的判定阈值。两项判据联合把"可辨识性"从一个未经证明的假设，转变为一个可检验、可定量报告的方法学结果。数学工具与公式在研究方案部分给出，本节不再重复。偏振—温度—磁场三重独立测量维度构成三类参数的唯一约束输入。每个维度在不同取值的组合下对参数空间形成多点采样（而非三个标量约束）。连续变量区间与样本规模由方案给出。

替代解释排除是该框架的必要组成部分。能带各向异性效应（如带边重整化、激子效应）在偏振变化下产生可区分的谐波谱特征，其与 altermagnet 自旋分裂效应的差异体现在两个维度：温度维度上，前者在低温下趋于饱和；磁场维度上，后者存在 Zeeman 劈裂响应。CrSb 的 SOC 有效强度处于连续过渡区，使得 SOC 修正后的偶次谐波或圆二色性候选信号在理论上可与纯能带效应区分。若贝叶斯后验分布呈现多峰且条件数落入不可辨识区，则该区分失效，须在结论中明确声明。

载波包络相位与轨道角动量虽在固体 HHG 中携带附加信息，但 Granados 等人 [33] 证明二者存在耦合，不能默认为完全独立的约束维度。驱动场轨道角动量向谐波的相干转移已被证明与晶体对称性、相互作用范围及强自旋轨道耦合的存在与否无关 [35]，通道行为可预期、可校验。因此这两个变量不纳入核心反演模型，仅在必要时作为辅助验证手段。R3 的归因结论最终与独立结构/磁性表征结果交叉对照，作为最后一重方法学约束。

### §2.5 特色与创新

本项目的创新集中体现在三个相互支撑的层面，每点遵循"现有局限、本项目方案、量化优势、创新定位收束"的四步闭环。（一）科学问题层面的可证伪定位。现有 altermagnet HHG 文献多以"展示信号存在"为目标：相邻体系的时间分辨磁光与动量分辨 SHG 实验观测到 altermagnet 对称性特征（见立项依据 §一.2），但均未设计替代解释排除机制，也未对接反问题可辨识性议题。本项目把科学命题明确收缩为"在限定的 altermagnet 材料与多带正演模型条件下，HHG 能否在排除替代解释后辨识序参量相关对称性"，并设计四档判据使每种结果都具有明确科学价值。四档定义如下：正档为磁场依赖信号探测成功、κ < 10²、替代解释排除通过且定量反演成立；部分正档为观测到磁场依赖信号但替代解释无法完全排除，报告联合后验分布并明确边界条件。边缘档为 10² < κ < 10⁴ 或后验多峰共存，降档报告联合后验；负档为无可探测信号或 κ > 10⁴ 触发 No-Go，报告适用边界。可量化优势：四档判据的边界条件由 κ 与后验宽度共同锚定。任一档位的归属都需要双判据（κ 与后验宽度）一并给出，避免单变量误判。

（二）方法学层面的可靠性闭环。现有 altermagnet HHG 文献未给出反演可辨识性分析，差分设计与参数反演之间的方法学连接仍属空白。本项目以磁场—偏振—温度三重差分设计、多带正演模型（含 SOC）、费舍尔信息矩阵条件数分析与贝叶斯后验估计四项工具的联合约束，使序参量辨识不再停留于概念主张，而成为可检验、可定量报告的方法学结果。与现有工作不同，本项目在 TiSe₂ 对照体系上先验证正演模型的实验复现能力，再将同一流程迁移至 CrSb。可量化优势：差分协议对能带背景的压制效率不预设数值，由可辨识性分析在 κ < 10² 可辨识区间内定量给出，并以合成数据标定后报告，给出参数空间级的定量边界。对 7—9 维参数空间不确定性的完整刻画（后验均值、标准差、相关系数矩阵三项一并）在固体 HHG 反演方向未见同类报告。条件数 κ 把参数空间的可分辨方向与病态方向各以一个数定量刻画：κ < 10² 对应可独立提取，κ > 10⁴ 触发 No-Go。

（三）对照体系层面的独立验证基础。TiSe₂ CDW 上的方法学标定遵循"先验证已知、再检验未知"的原则。Tyulnev 等人的 3/5/7 阶谐波偏振不对称实验观测与 Zhang 等人以含时薛定谔方程加现象学平均场的理论复现，构成实验—理论双源证据链。本项目在该证据链上叠加本装置的偏振分辨精度与本项目正演模型的预测精度双重比对，并以 ≤ 10% 的复现偏差作为可测量的客观判据。可量化优势：复现偏差 ≤ 10% 给出可测量的客观标定尺，比"视觉一致"式判断具备可重复性。该 10% 为设计值，取文献实验不确定度量级与工程余量的合成经验取值，第 1 年 TiSe₂ 复现阶段以实测复现精度校准（依据见立项依据）。这一设计使主线结论（无论最终为正、为负、为边缘）都建立在已被独立验证的方法学基础之上，而非单一体系的孤立观测。

### §2.6 年度研究计划

四年执行期与 §2.2—§2.4 三项研究内容形成严格的单向对应。第 1 年完成 R1：搭建并标定偏振分辨 HHG 装置；建立 TiSe₂ 多带 SBE 正演模型。该年终止判据是在自建装置上复现 Tyulnev 等人 [6] 报道的偏振指纹，偏振不对称方向与原文一致，幅度偏差 ≤ 10%。偏差超出 10% 时转入装置诊断与模型参数调试，不进入第 2 年。

第 2 年执行 R2：建立 CrSb 含 SOC 多带 SBE 正演模型（含 d 波分裂与自旋轨道耦合项），在 CrSb 上完成偏振—温度—磁场三重联合扫描，锁定磁场依赖偶次谐波与圆二色性候选信号。该年终止判据是差分相对强度 ≥ σ × 1.5—2.0、SNR > 5。若实测未达阈值，或 CrSb 在本项目工作区间内出现超出损伤阈值的反射率突变，则触发 MnTe 备选主体系切换。MnTe 备选的 Néel 温度（约 310 K）落在可达温区上沿附近，可叠加近相变温度依赖扫描与磁场反转差分两类约束。装置损伤阈值的正式标定安排在项目启动后第 1 年内通过逐级升场测量完成。

第 3 年执行 R3：建立费舍尔信息矩阵条件数计算流程与贝叶斯反演框架，联合 CrSb 实验数据与正演模型完成参数后验估计。该年终止判据分三档，与 G3 一致。可辨识档：κ < 10² 且后验标准差 < 先验宽度 50% 视为参数被有效约束，归因成立。边缘档：10² < κ < 10⁴，降档报告联合后验分布。No-Go 档：κ > 10⁴，转为报告适用边界。

第 4 年集成三阶段产出，把反演结论与独立的结构与磁性表征结果对照，撰写方法学工具开源文档与论文。该年终止判据是反演提取的序参量方向与独立表征确认的磁结构对称性一致，序参量相关贡献比例的量级在合理区间内交叉核对（核对采用比例量级而非绝对数值，与 Q2 的操作定义一致）。偏差超出时返回定位噪声来源，必要时对不一致项补充测量。

年度间衔接的硬性规则只有一条：上一年的终止判据未通过，不进入下一年。该规则保证各年度的研究投入不被前序问题稀释，也保证每一年的产出在科学意义上独立可报告。
