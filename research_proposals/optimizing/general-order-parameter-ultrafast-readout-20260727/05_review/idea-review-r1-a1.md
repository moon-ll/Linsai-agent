## 3. 维度三：内容-方案逻辑切分（coherence）

**得分：0.30**

### 已观察到的形式结构
文件骨架按"标题 → 研究背景与动机 → 现存研究空白或瓶颈 → 拟开展研究内容和方案 → 拟采用技术路线 → 创新点 → 来源与可靠性"展开，**形式上具备"立项依据 → 内容 → 方案 → 创新点"四段式切分**。这一形式结构与 NSFC 面上项目申请书标准模块对应正确。

### 核心问题
1. **§"现存研究空白或瓶颈"未真正"瓶颈化"**。该节内容（位于文件第 20 行附近）实际上是"国内研究现状"的零散列举（孟胜、李亮、兰鹏飞、陆培祥、Hansen & Madsen），并未提炼出"现存研究的具体瓶颈是什么、为何这些瓶颈未被现有工作解决"。该段还出现了 **句子截断**——"截至 2026" 直接断句，未写完。
2. **"拟开展研究内容和方案"被合并为单一节**。NSFC 面上标准中"研究内容"与"研究方案"是 **两个独立模块**，本研究文件把它们合并到一处标题下，且该合并模块为空。这造成了 **模块空置** 与 **模块错配** 两种问题并存：空置是字面（待填写），错配是逻辑（把"做什么"和"怎么做"塞进同一节）。
3. **§"研究背景与动机" 的 §1 与 §"现存研究空白或瓶颈" 之间存在逻辑跳变**。前者以"三类瓶颈"归纳收尾，已接近于"指出空白"；后者却从国内研究综述重新起跳，未能与前者形成"瓶颈 → 空白 → 切入点"的连续递进。这一跳变在派生文件 04_proposal/rationale.md 中已被修补（rationale.md:25 用一段过渡把两条路径的局限串联起来），但 **设想文件未同步**。
4. **文件级重复**：§1 第 1 段与 §"现存研究空白" 都各自重新定义"序参量"，重复了同一基础定义。这是典型的"模块空置触发的内容回流"——当创新点和方案为空时，作者倾向于把基础概念重复两遍以撑篇幅，反而损害逻辑切分。

### 结论
形式骨架正确但实质内容缺位，逻辑切分在 "动机 → 空白 → 内容 → 方案 → 创新点" 的链路上于"空白 → 内容"之间断裂。该维度需要把派生文件的对应内容 **回收** 而非 **重写**，以恢复骨架与实质的匹配。

## 4. 维度四：方向一致性（consistency）

**得分：0.65**

### 观察到的方向锚点
- **单一主轴**：序参量 → 非平衡态测量 → HHG 作为候选工具 → 表面/时间/通道三类瓶颈 → 序参量谱学空白。这一主线在 §1 中是连贯的。
- **体系锚点**：标题区出现 "altermagnet HHG"，§1 第 1 段提到 "CDW、磁化强度、Néel 矢量"，但 §1 整体论证 **围绕"序参量谱学"这一抽象问题**，未在设想文件层把 **altermagnet 作为具体主体系** 显式确立。这一缺位让 §1 在"序参量谱学普遍问题"与"altermagnet 具体问题"之间摇摆。

### 核心问题
1. **"altermagnet 作为主体系"未在本设想文件中获得论证**。标题区有 "altermagnet HHG" 标签，§1 没有为 altermagnet 提供四点物理考量（Néel 温度、SOC 强度、可光场调控、已有自旋极化 HHG 指纹）。这些论证全部沉淀在 04_proposal/rationale.md §4 和 content.md §2 中。这意味着 **设想文件层面，体系选择的论证是缺失的**——评审专家在本文件中读不到"为什么是 altermagnet 而不是铁磁/反铁磁/kagome"的回答。
2. **超导、激子、CDW、磁序四类序参量在 §1 并列出现**（第 1 段），但标题聚焦 altermagnet。这造成 **文件内的"广覆盖"暗示 vs 标题的"窄聚焦"现实** 之间的张力。在派生文件 04_proposal/rationale.md:49 中已用"作为项目完成后的自然延伸提及"一句话把范围收住，但 **设想文件未做此收口**。
3. **"难点一" 编号暗示存在多难点，但未列出其余难点**。若本设想文件代表真实研究设想的多难点框架（这是它被命名为"难点一"的隐含意义），则其余难点的缺失导致 **方向一致性无法从单点判断**。

### 结论
方向主线可识别（序参量 → 非平衡态 → HHG → altermagnet），但 **altermagnet 作为主体系的确立过程在本设想文件内不闭合**。建议把"为什么是 altermagnet" 的论证从 04_proposal/rationale.md §4 **回收** 到本文件 §2（空白与瓶颈节），并明确"超导/激子/CDW 仅作为后续延伸"。
