## 2. 维度二：创新点可检验性（testability）

**得分：0.85**

### 已观察到的清晰部分
- **三项创新点均有可证伪判据**。§"创新点"列出三项（line 85、87、89），每项均锚定一组量化判据：
  - 创新点一（line 85）："正—部分正—边缘—负"四档判据，对应 04_proposal/content.md line 7 的判据体系。**可证伪**：四种结果之间互斥，且"负"也是合法结果，使该创新点具备 falsifiability 而非 verification 倾向。
  - 创新点二（line 87）：差分实验 + 正演可辨识性分析 + No-Go 判据的三重闭环。**可证伪**：费舍尔信息矩阵条件数 κ < 10² 可辨识 / > 10⁴ 触发 No-Go；贝叶斯后验标准差 < 先验宽度 50% 方视为有效约束——阈值明确，可由实验数据直接判定。
  - 创新点三（line 89）：TiSe₂ CDW 作为对照体系的双重证据链锚定。**可证伪**：自建装置上 3/5/7 阶谐波偏振不对称指纹的幅度偏差 ≤ 10%，超过该阈值即视为对照失败。
- **判据的物理依据有据可查**。1% 阈值基于 CrSb 背景漂移典型标准差；SNR > 5 保证差分信号与装置长时漂移的虚假差分区分；10% 阈值基于 Tyulnev 2025 [11] 报道的 ±8% 实验不确定度加 2% 工程余量；κ < 10² 与 > 10⁴ 的划分基于参数协方差矩阵特征值由收敛到发散的过渡区。这些物理依据具体、可被同行检验，不依赖未定义术语。
- **创新点之间无重叠且逐级递进**。创新点一聚焦科学问题定位（信号存在性 → 归因性），创新点二聚焦方法学闭环（差分 + 可辨识性 + No-Go），创新点三聚焦对照体系的独立验证。三者构成"问题 → 方法 → 验证"的完整链条，无重叠、无空白。

4. **三层判据的层级关系在创新点内未清晰标出**。例如创新点二的 κ 判据、后验判据、No-Go 判据三者之间的**逻辑运算**（"AND"还是"OR"）未在 idea 文件层明确。从 04_proposal/content.md line 43 来看是 OR（任一触发即 No-Go），但 idea 文件 line 87 用"判据"单数指代，易被误读为合取条件。
