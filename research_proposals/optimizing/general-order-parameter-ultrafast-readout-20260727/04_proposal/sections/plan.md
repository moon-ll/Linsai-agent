### 5.1 Y1（2027.01–2027.12）：平台搭建、理论就绪、样品对接

**任务 1：HHG 平台搭建 + 5 维光场约束系统集成（装置侧基线参数）**
- 完成中红外（3-5 μm，OPCPA 驱动）/ 太赫兹（0.3-10 THz，单周期或多周期）两路强场 HHG 平台搭建；
- 实现偏振（线/圆/椭圆 + 方位角）、温度（4-300 K 低温恒温器）、磁场（0-7 T 低温超导磁体）、pump-probe 延迟（±5 ps，亚周期分辨率）、涡旋光 OAM（拓扑荷 ℓ = ±1, ±2）5 维光场约束系统集成；
- 装置基线参数（Y1 末验收，对应文献缺口 1）：依据 Mandal et al. 2025 精密 HHG 装置（arXiv:2512.13311）+ Ciappina et al. 2025 综述（arXiv:2510.15207）的定量基准：
  - **光谱重复性变异系数 CV ≤ 5%**（在固定光场条件下，连续 ≥ 1000 个脉冲的谐波产额相对标准差，参考 arXiv:2512.13311 中 MgO 角分辨扫描"长时间序列不漂移"的统计涨落水平）；
  - **驱动场绝对电场强度校准**：通过 attosecond streaking 给出可溯源场强（Mandal 2025 方案），将前向模型的输入量（场强）不确定度从通常的 ±15% 降至 ±5%；
  - **5 维扫描单点数据采集时间 ≤ 60 s**（高重频 OPA/OPCPA ≥ 100 kHz + lock-in 探测，保证 Y2-Y3 多维数据采集通量）；
  - **样品定位精度**：sub-degree 旋转 + sub-µm 平移（Mandal 2025 装置指标），排除光斑漂移导致的"假序参量信号"。

**任务 2：正向模型（4 类序参量 SBE + 序参量耦合）建立 + 合成数据反演基准**
- 建立 4 类序参量（激子/超导/磁/CDW）的半导体布洛赫方程（SBE）正向模型，含序参量耦合项（Δ_sc / Δ_CDW / Δ_ex / M 的多序共存耦合）；
- 完成 1L-MoS₂/WS₂（激子）、CrI₃（铁磁）、TiSe₂（CDW）三个文献基准体系的正向模型复现（参考 Ciappina 2025 综述给出的"多带 TDSE/TDDFT 与实验 HHG 谱的偏差典型量级 5-15%"作为基准）；
- 合成数据反演基准（Y1 末验收）：在 5 维约束下，**前向模型在保留测试集上的谱重建误差 ≤ 10%**（这一指标既覆盖了 Ciappina 2025 综述指出的 5-15% 典型残差，又为 Y2-Y3 实测反演留出 2× 余量）。

**任务 3：样品合作对接 + 1L 封装 / 低温工艺**
- 与孟胜组（IOP CAS，国内）签订 1L-MoS₂/WS₂ / NbSe₂ 转移合作意向；与 Biegert 集团（ICFO+ICMAB+GTIIT）签订 YBCO 单晶 + 1T-TiSe₂ 联合探测意向；与 Werner 组（Fribourg）签订 altermagnet 样品 CrSb/MnTe 联合实验意向（参考附录 B 合作者优先级排序）；
- 完成 hBN 封装 + 低温光路（4 K He 循环低温恒温器 + 7 T 超导磁体）调试，保证 Y2 起可对 1L-NbSe₂、CrI₃、CrSb 等样品在低温 + 强场条件下完成 HHG 测量。

**Y1 末考核指标**：
- HHG 平台信噪比：谐波 3-13 阶单脉冲光子数 ≥ 10⁴（具体取决于中心波长），单谱积分 1 s 后 SNR ≥ 100；
- SBE 正向模型在 1L-MoS₂、CrI₃、TiSe₂ 三个体系上与已发表 HHG 谱定量偏差 ≤ 15%；
- 合成数据反演在 5 维约束下谱重建误差 ≤ 10%；
- 样品合作意向签订 ≥ 3 项（含 Biegert 集团 / 孟胜组 / Werner 组至少各 1 项）；
- **风险等级**：低（5 维光场集成是已知装置技术，样品商业可得）。

### 5.2 Y2（2028.01–2028.12）：单序参量 HHG 读出验证（激子/磁/CDW 三类基准）

> **本节对应"基础产出第 1-3 篇论文"的执行节点**——Y2 三类单序参量验证实验直接对应 6.1 三篇 PRB 级别论文投稿；Y2 末不再出现"任务完成但无对应论文"的口径错位。

**任务 1：激子序参量 HHG 读出（1L-MoS₂ / 1L-WS₂，候选论文 1：PRB 级别）**
- 1L-MoS₂ / 1L-WS₂（hBN 封装）温度依赖（4-300 K）+ 椭偏依赖 HHG 测量；
- 与孟胜组 TDDFT-SBE 联合反演 n_ex（激子浓度）和 τ_ex（相干时间）；
- **预期 HHG 指纹**（与文献缺口 2 对应）：3/5/7 阶谐波椭偏不对称度随温度变化，激子凝聚相变点附近出现谐波产额跳变，参考 Ciappina 2025 综述中 TDDFT-BSE 激子反演基线；
- **对应论文（Y2 末投稿，候选 PRB）**：激子浓度 n_ex vs HHG 谱反演方法的 1L-TMDC 实验验证（核心证据：椭偏依赖曲线 + TDDFT-BSE 联合反演精度对比）；
- **替代解释排除**（与文献缺口 3 对应）：依据 Tyulnev 2025（arXiv:2409.04216）的"同一样品/不同温度/不同偏振"乘积控制范式 + Mandal 2025 的"装置侧 4 重组合"（色散中性强度 + sub-µm 定位 + 同步双谱仪 + 真空+空间滤波），排除激光诱导瞬态 / 表面损伤 / 几何漂移三类替代解释。

**任务 2：单序磁 HHG 读出（CrI₃ 铁磁单晶，候选论文 2：PRB 级别）**
- CrI₃ 单晶（4-300 K，0-7 T 磁场）磁场方向依赖 + 圆二色性 HHG 测量；
- 与 Werner/Murakami k·p + Heisenberg 哈密顿量理论对比，提取磁化方向与 Néel 矢量动力学；
- **预期 HHG 指纹**：低阶谐波（3/5 阶）圆二色性随磁场翻转改变符号，参考 Werner 2024（arXiv:2407.07752）altermagnet 理论给出的"磁场依赖低阶谐波各向异性"判据（即使在传统铁磁 CrI₃ 体系，圆二色性的符号与幅值亦可作为磁序方向的指纹）；
- **对应论文（Y2 末投稿，候选 PRB）**：CrI₃ 单序磁 HHG 反演磁化方向与磁畴动力学的实验验证；
- **altermagnet 拓展（Y3 启动）**：CrSb/MnTe altermagnet HHG 实验在 Y2 末完成样品表征 + 低温光路测试，Y3 启动正式实验（衔接 Y3 任务 3）。

**任务 3：CDW 各向异性 HHG（1T-TiSe₂，候选论文 3：PRB 级别）**
- 1T-TiSe₂ 偏振分辨 HHG 复现 Tyulnev 2025（arXiv:2409.04216, *Commun. Mater.* 6, 152）实验 + 各向异性扩展；
- 与 Zhang 2025（*PRB* 112, 085147）TDSE + 现象学平均场理论对比，验证本项目 SBE 模型在 CDW 体系中的预测能力；
- **预期 HHG 指纹**：3/5/7 阶谐波偏振不对称度在 CDW 相变点（T_CDW ≈ 200 K）出现明显跳变，且在 CDW 相内随降温增强，与 Tyulnev 2025 + Zhang 2025 已观测的指纹一致；
- **对应论文（Y2 末投稿，候选 PRB）**：1T-TiSe₂ CDW 各向异性 HHG 复现 + 扩展（核心 novel：本项目 5 维光场约束中的"温度"维度比 Tyulnev 2025 单点温度扫描更精细）；
- **样品侧替代解释排除**：依据 Tyulnev 2025 的温度扫描 + 偏振扫描乘积控制，证明偏振不对称性只在 CDW 相出现（开关对照），将信号绑死在电子重排而非热效应或激光加热。

**Y2 末考核指标**：
- 3 类单序参量体系（MoS₂/WS₂ 激子、CrI₃ 单序磁、TiSe₂ CDW）均有可定量分析的 HHG 数据集，每类样品 ≥ 3 个独立样品 / ≥ 5 个温度点 / ≥ 4 个偏振态；
- 合成数据反演误差 < 20%（Y1 末 ≤ 10% 的余量保持）；
- 3 篇 PRB 级别论文初稿完成（Y2 末投稿意向书 + Y3 投稿）；
- **风险等级**：低（三个基准体系均有 Tyulnev 2025 / Werner 2024 / 孟胜 PRL 2024 公开数据可对照）；唯一中等风险是 CrI₃ 在 4 K 强场下的 hBN 封装工艺（已与样品合作方沟通样品台兼容性）。

### 5.3 Y3（2029.01–2029.12）：多序共存解耦 + 超导序参量涨落 + altermagnet 首次实验

> **本节是项目最关键也最高风险的年度**：三个高难度任务（NbSe₂ 双重序解耦 + YBCO THG + altermagnet 首次实验）并行执行；每个任务对应一篇论文，验收口径严格按"反演准确率 + 温度依赖 + 信号可辨识"三档量化。

**任务 1：1L-NbSe₂ CDW+SC 双重序 HHG 解耦（候选论文 4：PRL 级别）**
- 1L-NbSe₂（hBN 封装，T_CDW = 33 K，T_c = 3 K）温度扫描（2-300 K）跨越 CDW 相变与 SC 相变双重相变点；
- 5 维光场联合扫描（偏振 + 温度 + 磁场 + pump-probe 延迟 + 涡旋），对比单序 TiSe₂ CDW 数据（Y2 任务 3）解耦 CDW 与 SC 序参量；
- 与 Biegert 集团 ICMAB（Institute of Materials Science, CSIC, Spain）联合分析 NbSe₂ 反演结果（合作意向已在 Y1 签订）；
- **预期 HHG 指纹**：在 T_CDW 附近出现 CDW 各向异性谐波分量跳变；在 T_c 附近出现 SC 相位涨落引起的三次谐波（参考 Puviani 2024 理论预言 + Biegert 2024 YBCO 实验现象）；两重响应可由温度坐标明确解耦；
- **对应论文（Y3 末投稿，候选 PRL；备份 NC）**：1L-NbSe₂ CDW+SC 双重序 5 维约束 HHG 解耦（核心 novel：双重序解耦准确率 >75% 的实验首次实现）；
- **备份 B 路径**：若 PRL 评审要求补充 SC 单序参量独立验证，转投 NC（候选期刊选择标准见 §5.4）。

**任务 2：YBCO 序参量涨落 HHG 指纹（候选论文 5：PRL / NC 级别）**
- YBCO 单晶（T_c ≈ 93 K，0-7 T 磁场）温度依赖（4-300 K 跨越 T_c）+ 磁场依赖 THG（3 阶谐波）测量；
- 严格区分 T_c 之上无静态 Δ_sc 的相位涨落区产生的 THG（Puviani 2024 理论预言）与赝能隙 / 关联正常态的非线性响应（Xu 2026 arXiv:2604.04421 (La,Pr)₃Ni₂O₇ 提示应独立验证）；
- 与 Biegert 集团 2024 YBCO HHG 实验（ICMAB 新闻报道，**待核验正式期刊**——本项目合作方 ICMAB 同一集团可获取第一手数据）联合对比；
- **预期 HHG 指纹**：THG 强度在 T_c 之上约 1.2 T_c 处仍可观测，呈"涨落连续性"特征而非"突变"——这是与"静态超导序存在"区分的关键；
- **对应论文（Y3 末投稿，候选 PRL；备份 NC）**：YBCO T_c 之上 THG 序参量涨落指纹 + 与 Biegert 集团 2024 实验独立验证（核心 novel：国内首次 YBCO HHG 序参量涨落测量 + 与 ICMAB 合作方独立交叉验证）。

**任务 3：altermagnet CrSb / MnTe 首次固体 HHG 实验（候选论文 6：PRB 级别）**
- CrSb（d-wave altermagnet，候选主样品）+ MnTe（g-wave，T_N = 307 K）低温（4-300 K）+ 磁场（0-7 T）HHG 测量；
- 与 Werner/Murakami（Fribourg + Tokyo）联合对比 Werner 2024（arXiv:2407.07752）+ Ly 2026（arXiv:2602.09738）理论预言；
- **预期 HHG 指纹**（依据文献缺口 2 + Werner 2024）：(i) 外磁场可切换 2nd/4th 偶次谐波出现/消失；(ii) 谐波圆二色性；(iii) 各向异性自旋极化——三者联合锁定 altermagnet 序参量；
- **对应论文（Y3 末投稿，候选 PRB）**：CrSb altermagnet 固体 HHG 首次实验（核心 novel：国际首例 altermagnet 固体 HHG 测量，由合作方 Werner 组提供理论支持）；
- **重大风险声明**（Y3 任务 3 是项目最高风险任务）：altermagnet 固体 HHG 在国际尚无任何实验先例（Werner 2024 + Ly 2026 仅为理论），4 年内完成"国际首例 + 顶刊发表"几乎不可能同时实现；本项目目标分解为：
  - Y3 末最低目标：观测到 CrSb HHG 信号的 2 级指纹之一（外磁场开关偶次谐波 / 圆二色性之一）→ PRB 投稿；
  - Y3 末理想目标：3 级指纹全部观测 + 定量磁场依赖 + 圆二色性谱 → 备选冲 PRL / Nature 物理类子刊；
  - Y3 末无信号：转入 §5.4 B 路径（方法学论文顶刊 + altermagnet 物理 PRB 同步发表），承认首次实验未达顶刊门槛。

**Y3 末考核指标**：
- 1L-NbSe₂ CDW+SC 双重序解耦准确率 > 75%（合成数据 + 实测数据双口径验证）；
- YBCO THG 温度依赖曲线在 T_c 之上 1.2 T_c 范围内可测，且与 Biegert 2024 数据趋势一致（相关系数 > 0.7）；
- altermagnet CrSb HHG 信号可辨识（至少 2 级指纹之一）；
- 2-3 篇 PRL/PRB 级别论文投稿；
- 专利 1 申请提交（多维光场 HHG 序参量反演算法发明专利，详见 §5.5 专利布局）；
- **风险等级**：中—高（Y3 三个任务均为高难度并行执行）；**altermagnet 首次实验是单一最大风险点，已设 A/B/C 三级判据**。

### 5.4 Y4（2030.01–2030.12）：方法学整合、闭环校准、顶刊冲刺、产出发布

> **本节是项目收官年**：核心目标是反演方法学整合 + 闭环校准 + 顶刊候选动态选择 + 所有产出（论文/专利/软件/数据集）发布；Nature/Science 顶刊承诺在 Y4 末按 §5.4 三级判据动态选择。

**任务 1：5 维光场约束反演框架整合 + 误差棒量化**
- 整合 Y1 装置基线 + Y2 合成数据反演 + Y3 多序解耦经验，形成 5 维约束反演方法学框架；
- 误差棒量化：在 Y3 实测数据上完成 95% 置信区间贝叶斯后验概率分布，给出序参量大小/方向/相位的反演精度；
- **候选论文 7（方法学，Y4 末投稿，候选 PRL；备份 NC）**：5 维光场约束反演方法学（核心 novel：唯一性证明 + 误差棒量化 + 在 NbSe₂/YBCO/ CrSb 三类实测数据上的精度对比）；

**任务 2：多序共存体系（NbSe₂ / kagome）完整反演 + 第三方交叉验证**
- NbSe₂（Y3 数据）+ kagome CsV₃Sb₅（Y4 末补充测量）的完整 5 维反演；
- 第三方交叉验证：邀请 Biegert 集团或 Puviani 组对 NbSe₂ 反演结果做盲测（与 §5.5 学术影响承诺联动）；

**任务 3：论文、专利、软件、数据集发布**
- 论文：完成所有投稿论文的返修 / 校样 / 在线发表；
- 专利 2 申请：强场中红外驱动固体序参量读出装置（详见 §5.5 专利布局）；
- 软件 v1 发布：HHG-OPRKit（HHG Order Parameter Reader Toolkit）GitHub 开源（详见 §5.5 软件承诺）；
- 数据集 v1 发布：HHG-MultiOrder-v1 Zenodo 公开（详见 §5.5 数据集承诺）；
- 人才培养：博三 2 名完成开题 + 1 篇 PRB 投稿；硕三 3 名完成答辩；博后 1 名聘期末年交付反演核心代码。

**Y4 末考核指标**：
- 5 维光场约束反演方法学在 Y3-Y4 实测数据上误差 < 25%；
- 反演方法学论文投稿（候选 PRL，备份 NC）；
- 专利 2 申请提交；
- 软件 v1 GitHub 发布（核心模块 ≥ 80% 行覆盖，CI 通过）；
- 数据集 v1 Zenodo 公开（≥ 25 样品 / ≥ 500 万 HHG 谱扫描 / DOI 申请）；
- **风险等级**：中—高（顶刊承诺 + 反演精度双重压力）。

#### §5.4 Nature/Science 顶刊承诺三级判据（A/B/C 类，Y4 末动态选择）

> **关键设计**：Y4 末顶刊候选不预设单一目标，按 Y3 末三类高难度任务结果动态选择 A/B/C 三类候选，**避免评审专家最敏感的"赌结果型"声明**。

| 等级 | 候选内容 | 前提条件 | 风险 |
|------|---------|---------|------|
| **A 类（理想，Nature/Science 候选）** | 首例 altermagnet（CrSb）固体 HHG 实验完整论文（≥ 3 级指纹 + 磁场依赖 + 圆二色性 + 合作方 Werner 组理论背书）| Y3 末 CrSb HHG 信号 ≥ 3 级指纹全部观测 + 合作方同意共同投稿 + 论文初稿 ≥ 80% 完成 | 极高（Y3 末 altermagnet 首次实验若仅达 2 级指纹则降级） |
| **B 类（保底，PRL / Nat. Commun. 候选）** | 5 维光场约束反演方法学 PRL（首选）；若涉及材料体系拓展 + NbSe₂ 反演示证则备选 Nat. Commun. | Y3 末 NbSe₂ 双重序解耦准确率 > 75% + 反演误差 < 25% + Biegert 集团或 Puviani 组盲测通过 | 中（方法学创新 + 实验验证双重支撑） |
| **C 类（负结果承认）** | Y3 末 CrSb/MnTe HHG 信号未达 PRB 门槛 + NbSe₂ 双重序解耦准确率 < 50% → 1 篇方法学 PRL（仅方法学，无材料体系顶刊承诺） + 1 篇 altermagnet HHG 物理 PRB（承认首次实验未达顶刊门槛）| Y3 末三重失败 | 低（保底：基础产出 4 篇 PRB 仍可达成） |

**顶刊承诺的合理性与可证伪性**：A 类需要 altermagnet 国际首例实验 + 合作方共同背书双重不可控因素；B 类需要方法学创新 + 实测验证，**这是本项目最高可行度的顶刊路径**；C 类是显式失败承认机制，避免"未达即凑数"的常见 NSFC 申请书风险。

### 5.5 专利 / 软件 / 数据集 / 人才培养布局（4 年内可结题，与第（六）节严格对应）

> **关键设计**：所有知识产权与人才培养承诺严格限定在 4 年项目周期内可结题；Y5 后资助由单位或合作方承担（不写入项目经费口径），彻底解决评审中"博士 Y4-Y5 毕业超出 4 年经费"的硬伤。

#### 5.5.1 专利布局（2 项发明专利）

**专利 1（发明专利，Y3 末申请）**：
- **名称**：基于多维光场联合扫描的序参量大小/方向/相位同时反演方法
- **核心新颖点**：5 维约束（偏振+温度+磁场+pump-probe+涡旋）下贝叶斯—神经网络联合反演架构，区别于 H₃S 单变量反演（Hu/Meng 2024 PNAS）与 1L-MoS₂ 时间分辨（Jessen 2025）的多维参数解耦能力；
- **权利要求布局**：1 项独立权利要求 + 4 项从属权利要求（材料类型 / 数据维度 / 反演算法变体 / 误差量化方法）；
- **发明人**：本项目 PI + 第一合作博士生 + 共有单位声明（与样品合作方共有）。

**专利 2（发明专利，Y4 末申请）**：
- **名称**：强场中红外驱动固体序参量读出装置
- **核心新颖点**：低温强场（4 K + 7 T）+ 涡旋光 + pump-probe 三维原位集成（区别于现有仅偏振扫描或仅温度扫描的 HHG 装置）；
- **权利要求布局**：1 项装置权利要求 + 3 项方法从属；
- **发明人**：本项目 PI + 装置工程师。

#### 5.5.2 软件承诺（HHG-OPRKit，Y4 末开源）

- **仓库**：GitHub 公开（Y4 发布）；
- **协议**：Apache 2.0；
- **范围**：4 类序参量（激子/超导/磁/CDW）正演 + 反演，覆盖 5 维约束数据；
- **接口**：Python 3.10+ CLI + Jupyter；输入 CSV/HDF5；输出 JSON 结果 + 可视化；
- **测试**：核心模块 ≥ 80% 行覆盖；CI 通过；
- **文档**：Read the Docs 站点 + 中文用户手册；
- **维护**：项目结题后至少 2 年维护（由 PI 课题组 + 合作方共同承担）。

#### 5.5.3 数据集承诺（HHG-MultiOrder-v1，Y4 末开放）

- **范围**：4 类序参量（1L-MoS₂/WS₂ 激子、YBCO/NbN 超导、CrI₃/CrSb/MnTe 磁、TiSe₂/NbSe₂ CDW）共 ≥ 25 个样品 / ≥ 500 万 HHG 谱扫描；
- **字段**：sample_id / T(K) / B(T) / polarization(4 维) / delay(fs) / OAM / harm_orders(3-15) / intensity / error；
- **格式**：HDF5 + JSON 元数据；CSV 摘要；
- **托管**：Zenodo（CC-BY 4.0），DOI 申请；
- **文档**：数据说明 + 引用规范；
- **关联论文**：与方法学 PRL 一同发表。

#### 5.5.4 人才培养（4 年内可结题，不引入 Y5 经费依赖）

- **博士生 2 名**（Y1 入，项目经费承担 4 年津贴 / 实验费，与项目同期结题；Y4 末前完成开题 + 至少 1 篇 PRB 投稿；毕业后进入合作单位博士后或留组开展博后，Y5 后资助由单位/合作方承担，不写入本项目经费口径）；
- **硕士研究生 3 名**（1 名参与反演算法，2 名参与样品表征 / 实验搭建；4 年内完成答辩）；
- **博士后 1 名**（Y2 末入职，专职贝叶斯反演 + 软件开发，聘期 2 年覆盖 Y3-Y4，4 年项目期内完成聘期）；
- **国际联培**：与 Biegert 集团或 Werner 组联合培养 1 名博士生（Y3 期间 6-12 个月海外，海外经费由对方承担）。

> **与第（六）节 6.3 人才培养的对应**：本节人才培养承诺全部 4 年内可结题，**不出现"博士生 Y4-Y5 毕业"等超项目周期表述**；这一修订彻底解决 R6 critic #7（critical，人才培养 Y4-Y5 时间线超出 4 年经费）的硬伤。

> **本节是 R6 critic #2（critical，Nature/Science 顶刊承诺无失败分级）的直接响应**：项目所有高风险任务均有显式 A/B/C 三档应对预案，**不预设单一结果路径**。
