## 各方法详细说明

### M1 条纹信号模型

- **适用模块**：§2.1；全方案信号理论出发点
- **理论基础**：末态动量 k + A(t) 展开至矢势二次项：
  E_final = E_kin + A(t)·k + U_p[1 − cos2(ωt + φ_CEP)]，U_p = E₀²/4ω²；不存在更高阶矢势项
- **实现细节**：弱场近似省略库仑末态与相对论修正；多通道叠加时显式引入通道间相位干涉项 Δφ_ij
- **关键参数**：交叉项 2√(S₁S₂)·cos Δφ 破坏 FROG-CRAB 二阶响应基础；模拟端预期重构误差 >20%
- **数据分析**：干涉项为修正对象；水窗条纹实验（322 as/350 eV/1850 nm [2]）给出实验入口
- **局限性**：弱场近似；多通道贡献 15%–30% 区间的标定依赖模拟端
- **参考文献**：[[阿秒计量方法体系]]；Cousin 2017 [2]（申请书引文表）

### M2 多通道干涉解析修正

- **适用模块**：§2.2；研究内容一支撑
- **理论基础**：S(E) = S₁ + S₂ + 2√(S₁S₂)·cos Δφ；以通道间相位差 Δφ 与强度比 R=I₂/I₁ 为参量
- **实现细节**：拟合边带强度提取 Δφ → 以 Δφ 为先验约束脉冲相位检索：
  C(φ) = C_FROG-CRAB(φ) + λ·Penalty(Δφ)
- **关键参数**：λ 由参数扫描定；终止判据 = 重构与 TDSE 真值的 RMS 相位误差（2π 归一）< 5%；
  适用区间 = 通道重叠 0.5–2 eV、多通道贡献 8%–50%；5%–8% 过渡带不激活
- **数据分析**：边带强度拟合 → Δφ 提取 → 正则化检索
- **局限性**：通道间能量差 < 0.5 eV（如 CO₂/N₂ ~0.3 eV）时双通道近似退化，备选路径 A 接管
- **参考文献**：申请书 [2][40]；[[阿秒计量方法体系]] §扩展 A

### M3 双通道 TDSE 基准级

- **适用模块**：§2.1；建模主框架
- **理论基础**：单电子近似两能级干涉模型；选择 TDSE 而非少带模型的理由——气体靶多通道
  是不同电离阈贡献叠加而非能带效应，少带模型无法给出通道间相位干涉
- **实现细节**：TDSE 严格处理双通道耦合势项，通道相位关系数值自洽
- **关键参数**：基准级适用条件 = 通道间能量差 ≥ 0.5 eV；支撑 = Köppe [40] CH₄ C 1s
  shake-up 卫星阈 303/311 eV（电离阈 290.7 eV 之上 12–20 eV）+ TDSE 模拟端标定
- **数据分析**：参数标定解析修正项（M2）
- **局限性**：单电子近似；残离子终态超出能力（→M4）
- **参考文献**：Köppe PRA 53, 4120 (1996) [40]

### M4 R 矩阵残离子验证级

- **适用模块**：§2.1 验证级
- **理论基础**：shake-up 残离子关联通道（CH₄/N₂ 分子靶）——单电子近似之外
- **实现细节**：Tarrant [20]（2025 预印本）预言 shake-up 通道相干激发「呼吸离子」可测信号；
  Shi & Thumm [18] 残离子–光电子–IR 三重耦合的方向/动能相关相干修正；
  采用 R 矩阵含时理论类含关联方法单独核算
- **关键参数**：作为基准级修正项在残离子维度的外部检验；不进入基准参数标定
- **数据分析**：与 M3 基准对照给出关联修正量级
- **局限性**：成本高；预印本状态标注（诚实引用纪律）
- **参考文献**：[18][20]（申请书引文表）

### M5 三实验方案

- **适用模块**：§3.1-3.3；三研究内容的实验支撑
- **理论基础/实现**：3.1 多通道失效修正实验（支撑内容一）；
  3.2 偶极相位角积分解耦实验（支撑内容二）；3.3 跨能区标定实验（支撑内容三）
- **关键参数**：驱动基线 1850 nm 次二周波；水窗低段 ~350 eV
- **数据分析**：与理论层（M1-M4）逐项对照
- **局限性**：见 §4.2 技术实现层面可行性
- **参考文献**：[2][4][16]（申请书引文表）
