## M1：TDSE 双通道耦合数值模拟

### 物理模型

单电子近似下的含时薛定谔方程（原子单位）：

$$i\frac{\partial}{\partial t}\Psi(\mathbf{r},t) = \left[ -\frac{1}{2}\nabla^2 + V(\mathbf{r}) + \mathbf{r}\cdot\mathbf{E}(t) \right]\Psi(\mathbf{r},t)$$

其中 $V(\mathbf{r})$ 为原子库仑势，$\mathbf{E}(t) = \mathbf{E}_{\mathrm{XUV}}(t) + \mathbf{E}_{\mathrm{IR}}(t)$ 为 XUV 与 IR 联合电场。

波函数按原子本征态分波展开：

$$|\Psi(t)\rangle = \sum_n c_n(t)|n\rangle e^{-iE_n t}$$

通道间耦合势项取双电离通道耦合形式（参照 Tong et al., J. Phys. B 36, 2003）：

$$V_{ij}(t) = \langle\psi_i|\mathbf{r}\cdot\mathbf{E}(t)|\psi_j\rangle$$

### 算法伪代码（分波展开 + RK4 积分）

```
输入：靶材能级 {E_n}，通道数 N_ch，场参数 (E_XUV, E_IR, τ)
输出：条纹信号 S(E, τ)

# 步骤 1：初态制备
c(t=0) ← [1, 0, ..., 0]  # 选择性布居初始通道

# 步骤 2：预计算原子本征态矩阵元
for i in range(N_ch):
    for j in range(N_ch):
        d_ij ← ⟨ψ_i| r | ψ_j⟩  # 预计算，循环内不重复

# 步骤 3：时间演化（RK4）
t ← 0, dt ← 10 as
while t < t_final:
    # k1
    k1 ← -i * (H(t) @ c(t))
    # k2
    k2 ← -i * (H(t + dt/2) @ (c(t) + dt/2 * k1))
    # k3
    k3 ← -i * (H(t + dt/2) @ (c(t) + dt/2 * k2))
    # k4
    k4 ← -i * (H(t + dt) @ (c(t) + dt * k3))
    # 更新
    c(t+dt) ← c(t) + dt/6 * (k1 + 2*k2 + 2*k3 + k4)
    t ← t + dt
    # PML 边界条件在每步应用（乘以衰减因子）

# 步骤 4：谱计算
S(E) ← |FT{ c(t_final) }|²  # 对每个通道独立计算后叠加干涉项

# 步骤 5：延迟扫描
for τ in [−500:50:500] as:
    E_XUV_shifted ← E_XUV(t - τ)  # 延迟调制
    重复步骤 3-4，得到 S(E, τ)
```

### 算法步骤（执行层面的操作细节）

**步骤 1：初态制备**

选取靶材的初始电子态，设定电离通道数（2–3 通道）。通道能量差 ΔE > 1 eV（保证波函数在能量域可分离）。对于 C K 边（C 1s → 2π*，~284 eV）和 N K 边（N 1s → 2π*，~409.7 eV），通道能量差均大于 1 eV，满足可分离条件。

**步骤 2：场构型**

XUV 脉冲：中心光子能量覆盖 284–410 eV（水窗能区），脉冲宽度 100–300 as，半高全宽由高斯型或双曲正割型给出。IR 条纹场：800 nm（Ti:sapphire），峰值强度 $10^{14}$–$10^{15}$ W/cm²。两场在时空上共线共焦点，IR 场延迟相对于 XUV 场通过压电陶瓷扫描控制。

**步骤 3：时间积分**

展开系数的耦合 ODE 组通过四阶龙格-库塔法（RK4）积分。时间步长 Δt = 10 as（保证阿秒脉冲时间尺度的数值精度）。空间网格：柱坐标 $(r,\theta)$，$r$ 方向取 512–1024 个网格点，$r_{\max}=50$–100 a.u.，使用完美匹配层（PML）吸收边界条件。RK4 积分的收敛性由总概率守恒检验（6 位有效数字）确认。

**步骤 4：谱计算**

含时演化完成后，对 $c_n(t)$ 在 $t_{\mathrm{final}}$ 时刻做傅里叶变换，得到光电子能谱 $S(E)$。改变 XUV–IR 延迟 $\tau$（扫描范围 ±500 as，步长 50 as），重复步骤 1–4，得到二维条纹信号 $S(E,\tau)$。谱分辨由傅里叶变换的有限时间窗口决定，典型值 ΔE ≈ 0.1 eV（对应 40 fs 演化时长）。

**步骤 5：干涉特征提取**

对每个能量点 $E$ 在延迟方向做傅里叶变换，提取干涉项的相位 $\Delta\phi(E)$ 与通道强度比 $R(E) = I_2(E)/I_1(E)$。若通道重叠宽度 > 1 eV，修正项生效。干涉相位提取采用以下步骤：取条纹迹在 $[E-\Delta E/2, E+\Delta E/2]$ 能量窗口内的数据，对延迟方向做 FFT，提取峰值频率对应的相位，即为 $\Delta\phi(E)$。

### 通道混合度 η 的计算操作

通道混合度 $\eta$ 用于量化双通道间的强耦合程度，是触发备选路径 A 的判定量。计算步骤如下：

1. 对 TDSE 输出的光电子能谱 $S(E)$ 做多高斯拟合（通道数 = 2 或 3）：
$$S(E) = \sum_{i=1}^{N_{\mathrm{ch}}} A_i \exp\left[-\frac{(E-E_i)^2}{2\sigma_i^2}\right]$$

2. 从拟合结果中提取各通道的峰面积 $A_i$（高斯积分 $A_i\sqrt{2\pi}\sigma_i$），计算通道混合度：
$$\eta = \frac{A_2}{A_1 + A_2}$$

   对三通道体系，以主通道（最强信号）为分母，$\eta = (A_2+A_3)/(A_1+A_2+A_3)$。

3. 不确定度评估：在典型计数条件（$N_1, N_2 \geq 10^4$ 总光子事件）下，用泊松统计估计 $A_i$ 的标准差 $\delta A_i = \sqrt{N_i}$，传播至 $\eta$ 的相对不确定度 < 10%，满足 30% 触发条件的判定可靠性（信噪比 > 3σ）。

实验端无需运行 TDSE，直接对测得的光电子能谱做相同多高斯拟合，提取 $A_i$ 计算 $\eta$ 作为通道混合度的代理量。

### 验证方式

**解析基准验证**：在单通道极限（去除 $V_{ij}(t)$ 项）下，将 TDSE 结果与少带模型的解析结果比对，相对偏差应 < 1%。

**文献复现验证**：选取氖原子 $2s$/$2p$ 双通道体系（能量差约 4 eV），复现文献中已知的光电子能谱结构，验证模型正确性。

**收敛性测试**：以网格密度（512/1024/2048 点）和时间步长（50/25/10 as）为变量，确认结果在 < 1% 变化内收敛。

**守恒律验证**：检验总概率 $\sum_n |c_n(t)|^2$ 在演化全程守恒至 6 位有效数字，以确认数值稳定性。

**重构误差验证**：以 TDSE 模拟产生的条纹信号作为输入，运行传统 FROG-CRAB，测量重构误差。当多通道贡献 > 15% 时误差应跳升至 > 20%，以确认模拟信号确实捕获了多通道失效现象。

### 失效边界与风险缓解

**失效边界**：通道间能量差 < 0.5 eV 时，双通道近似的波函数可分离性丧失，此时 TDSE 结果失去物理意义。

**风险缓解**：在 0.5–1 eV 区间做参数扫描，确认修正项的适用性随能量差增大而单调恢复。若通道混合度 $\eta$ > 30%，触发备选路径 A（神经网络学习通道干涉模式）。

## M2：通道间相位干涉解析修正项

### 数学基础

总光电子能谱含两通道干涉项：

$$S(E) = S_1(E) + S_2(E) + 2\sqrt{S_1(E)S_2(E)}\cos[\Delta\phi(E)]$$

其中干涉项的相位 $\Delta\phi(E)$ 与通道强度比 $R(E) = S_2(E)/S_1(E)$ 为待提取参量。

修正项的物理来源：传统 FROG-CRAB 假设条纹信号是脉冲电场的二阶非线性响应，该假设在多通道叠加条件下因通道间相位干涉而失效。修正项在代价函数中引入通道干涉约束，使相位检索过程显式利用干涉相位信息。

### 算法步骤

**步骤 1：干涉特征提取**

从 TDSE 模拟或实验的条纹能谱 $S(E,\tau)$ 中，对每个能量点 $E$ 做延迟方向的短时傅里叶变换（窗口宽度 200 as），提取干涉项的相位 $\Delta\phi(E)$ 与强度比 $R(E)$。

**步骤 2：修正项构造**

以 $\Delta\phi$ 与 $R$ 为参量，修正项取以下形式：

$$\Phi_{\mathrm{corr}}(\omega) = \alpha \cdot \Delta\phi \cdot S_{\mathrm{interference}}(\omega)$$

其中 $\alpha$ 为通道强度相关加权系数（量纲为一），由 TDSE 模拟标定；$S_{\mathrm{interference}}(\omega)$ 为干涉项的光谱分布，从条纹迹中提取。

修正项有效性的数值判据：重构脉冲与真实脉冲的均方根相位误差 $\delta\phi_{\mathrm{RMS}} < 5\%$。

**步骤 3：嵌入代价函数**

将修正项嵌入 FROG-CRAB 代价函数：

$$\chi^2 = \sum_{i,j}\left|S_{\mathrm{exp}}(E_i,\tau_j) - S_{\mathrm{model}}(E_i,\tau_j;\Phi)\right|^2 + \lambda\cdot\|\Phi_{\mathrm{corr}}(\Phi) - \Phi_{\mathrm{extracted}}\|^2$$

其中 $\lambda$ 为正则化参数（通过 L-curve 法选取，典型值 $\lambda = 10^{-3}$–$10^{-1}$）。$\Phi$ 为待检索脉冲光谱相位。$\Phi_{\mathrm{extracted}}$ 为从条纹迹中提取的干涉相位（通过 FFT 提取），$\Phi_{\mathrm{corr}}(\Phi)$ 为当前迭代中由检索相位 $\Phi$ 推算的干涉相位估计，两者之差的二范数构成惩罚项，驱动检索过程向物理一致的干涉相位收敛。

L-curve 法选取 $\lambda$ 的具体步骤：在对数坐标下扫描 $\lambda \in [10^{-4}, 10^{0}]$，计算对应解的 $\|\chi^2\|$ 与 $\|\Phi_{\mathrm{corr}}-\Phi_{\mathrm{extracted}}\|^2$，在双对数图上通常呈现 L 形拐点，选取拐点处 $\lambda$ 值作为最优正则化参数。该步骤独立于主迭代，在预处理阶段完成。

**步骤 4：迭代检索**

使用共轭梯度法（CG）或主成分分析法（PCG）求解修正后的代价函数。CG 迭代公式：

$$\mathbf{p}_{k+1} = \mathbf{r}_k + \beta_k \mathbf{p}_k$$

$$\beta_k = \frac{\mathbf{r}_k^T \mathbf{r}_k}{\mathbf{r}_{k-1}^T \mathbf{r}_{k-1}}$$

其中 $\mathbf{r}_k = \nabla \chi^2(\Phi_k)$ 为残差梯度，$\mathbf{p}_k$ 为搜索方向。迭代终止条件：相邻两步 $\chi^2$ 变化 $< 10^{-4}$ 或达到 200 次迭代上限。

**步骤 5：误差评估**

以重构脉冲与真实脉冲的均方根相位误差为判据：

$$\delta\phi_{\mathrm{RMS}} = \sqrt{\frac{1}{N}\sum_{k=1}^{N}\left|\Phi_{\mathrm{retrieved}}(\omega_k) - \Phi_{\mathrm{true}}(\omega_k)\right|^2}$$

修正有效的阈值：$\delta\phi_{\mathrm{RMS}} < 5\%$。

### 关键参数表

| 参数 | 取值 | 说明 |
|------|------|------|
| 正则化参数 $\lambda$ | $10^{-3}$–$10^{-1}$（L-curve 法确定） | 控制修正项权重 |
| 修正项生效阈值 | 通道重叠宽度 > 1 eV | TDSE 模拟标定 |
| 通道数适用范围 | 2–3 通道 | 超出此范围需重新标定 |
| 迭代收敛阈值 | $\Delta\chi^2 < 10^{-4}$ | 梯度下降终止判据 |
| 最大迭代次数 | 200 | 防止过拟合 |
| 误差目标 | 重构脉冲相位均方根偏差 < 5% | 有效性判据 |
| 短时傅里叶窗口宽度 | 200 as | 干涉相位提取用 |
| 加权系数 $\alpha$ | 由 TDSE 模拟确定（典型值 0.5–1.5） | 通道强度相关 |

### 验证方式

**自洽性验证**：用修正后的脉冲相位重新计算条纹信号 $S_{\mathrm{model}}(E,\tau)$，与原始输入信号做二维相关，要求相关系数 > 0.95。

**参数敏感性验证**：在 $\alpha \pm 20\%$ 范围内扫描，确认 $\delta\phi_{\mathrm{RMS}}$ 变化 < 1%，以验证修正项对参数取值不敏感。

**通道数普适性验证**：分别用 2 通道和 3 通道 TDSE 数据测试，确认修正项形式不变，仅 $\alpha$ 系数需随通道数轻微调整。

**外部数据验证**：以 Cousin 等人（Phys Rev X 7, 041030, 2017）的公开数据集作为外部基准，确认修正算法将重构误差从 > 20% 降至 < 5%。

### 失效边界与风险缓解

**失效边界**：通道重叠宽度 < 0.5 eV 时，双通道近似的可分离性丧失，修正项不再适用。

**风险缓解**：触发条件为 TDSE 模拟中通道混合度（以通道投影算子衡量）> 30%。此时切换至备选路径 A（神经网络学习通道干涉模式，详见 §M5/M2 失效处置）。

## M3：角积分位置灵敏探测器测量

### 实验平台硬件配置

**Ti:sapphire 放大器（驱动激光）**：中心波长 800 nm，脉冲宽度 30 fs（半高全宽），重复频率 1 kHz，单脉冲能量 3 mJ。驱动激光经开孔分束器（transmission ~30% 用于 HHG，reflection ~70% 用作条纹场）分为两束。分束比 Tolerance ±5%，由熔融石英平板的厚度与入射角共同决定（以布鲁斯特角入射时 S 偏振反射率约 70%）。

**HHG 气体靶室**：同轴气体喷射靶，气压 5–50 mbar（可调），喷嘴孔径 0.5 mm，气体束与 XUV 光束交叉角约 45°，以避免再吸收。气体回收泵抽速 500 L/min，真空度维持 < 10^-1 mbar（差分级）/ < 10^-6 mbar（主真空级）。

**XUV–IR 条纹场几何构型**：采用非共线构型，IR 条纹场与 XUV 光束在空间上分离约 1 mrad 夹角（两束在靶室出口合束），延迟通过 IR 臂的压电陶瓷（PZT）扫描控制，扫描范围 ±500 as（对应光程 ±150 nm），PZT 分辨率 0.1 nm（对应 0.67 as）。延迟稳定性：亚 100 as RMS（通过主动稳定环路的载波包络相位监测器实时反馈校正 PZT 电压）。

**驱动激光 timing jitter**：Timing jitter 是指激光脉冲到达时间相对于参考时钟的起伏，会叠加在条纹迹的延迟轴上。Ti:sapphire 放大器的 timing jitter 通常优于 10 fs RMS（载波包络相位稳定环路），该值远大于阿秒条纹所需的 100 as 级延迟分辨率——因此需要主动延迟稳定环路压制至 100 as RMS 以下。技术方案采用 Huppert 等人（Rev Sci Instrum 86, 123106, 2015）的 He-Ne 激光联合白光干涉仪方案，在 XUV 与 IR 空间分离的几何构型中实现 26 as rms 延迟稳定。

### 16 通道 TOF 阵列探测器硬件规格

**XUV 光源**：高次谐波产生（HHG），驱动激光 1 kHz Ti:sapphire 放大器（30 fs、3 mJ/pulse），经开孔分束后一部分驱动气体靶产生 HHG，另一部分作为条纹场。

**延迟模块**：XUV–IR 干涉仪延迟主动稳定至 < 100 as RMS（亚光学周期稳定度），延迟扫描范围 ±500 as，步长 50 as。

**探测器**：16 通道 TOF 阵列探测器，具体参数：

| 参数 | 取值 | 说明 |
|------|------|------|
| TOF 通道数 | 16 | 独立记录，独立触发 |
| 能量分辨率 | $\Delta E/E \approx 1\%$ @ 400 eV | 单通道谱分辨 ~4 eV @ 400 eV |
| 角向覆盖 | 全 360° | 各通道等角距排列（每通道 22.5°） |
| 角分辨率 | ±2°（每通道覆盖 22.5°） | 角向 bin 宽度 |
| 最大计数率 | 120 counts/s/pulse | 受 1 kHz 激光重频限制 |
| TOF 窗口宽度 | 10–20 ns | 覆盖全能量范围 |
| 靶室真空度 | $< 10^{-6}$ mbar | TOF 工作要求 |

**触发时序逻辑**：16 通道 TOF 的共同触发信号来自 Ti:sapphire 激光器的同步输出（1 kHz TTL，上升沿 < 5 ns）。触发信号经延迟单元（分辨率 1 ns，可调范围 0–1 ms）分配至各通道的时域分析窗口，确保所有通道在相同激光脉冲事件下同步积分。触发路径：激光器 TTL → 触发分配器 → 16 通道独立延迟单元 → 各 TOF 通道门控信号。各通道的延迟偏移在实验前做系统校准，以消除电子学通道间触发时间差（< 100 ps）。

**通道-角度映射**：16 通道沿环形阵列等角距排列，每通道对应 $\theta_i = i \times 22.5°$（$i = 0\ldots15$），以 XUV 传播方向为法线，取第一通道指向右侧水平方向为 $\theta_0 = 0°$。角度标定在实验前使用准直电子源（微型电子枪，发射极细电子束）完成，通过旋转电子源方位角记录各通道响应峰位，确认通道-角度映射关系，偏差 < ±1°。

### 靶材配置

| 靶材 | 用途 | 多通道贡献 | 光子能量/电离阈 |
|------|------|-----------|--------------|
| 氖气（Ne） | 单通道极限基准 | < 5% | 21.6 eV（2p 电离），通道重叠最小 |
| 氩气（Ar） | 偶极相位主测靶材 | ~10% | 15.8 eV（3p 电离），无 K 边复杂结构 |
| 氪气（Kr） | 跨能区标定（软 X 射线） | ~20% | 14.0 eV（4p 电离），4d 内壳层影响可忽略 |
| 氮气（N₂） | 多通道主测靶材（水窗） | 15%–30% | 对应 N K 边 409.7 eV |
| 甲烷（CH₄） | 多通道主测靶材（水窗） | 15%–30% | 对应 C K 边 284 eV |
| 氦气（He） | 对照组（无偶极相位复杂结构） | ~0% | 24.6 eV（1s 电离），Z=2 基准 |

### 实验步骤

**步骤 1：通道效率标定**

在均匀光电子源（微通道板平场源，注：或用低密度氦气靶的单色光电子）下，测量各通道对同一能量的响应，获取相对效率因子 $k_i$（$i=1\ldots16$）。标定重复 3 次取平均，统计误差 < 0.5%。标定在每次实验前后各执行一次，确认无显著漂移（< 1%）。

**通道效率标定的操作细节**：标定时使用低密度氦气靶（气压 ~0.1 mbar），XUV 脉冲单独电离（不加 IR 条纹场），确保光电子来自单色过程。各通道的 TOF 谱中同一能量峰位的计数比值即为 $k_i$。若某通道的 $k_i$ 与平均值偏差 > 5%，该通道触发硬件检查（检查高压馈通、TOF 入口狭缝对准）。

**步骤 2：数据采集**

在设定靶材下采集条纹迹。各通道独立记录能量谱 $S_i(E,\tau)$，延迟 $\tau$ 扫描范围 ±500 as，步长 50 as。每组实验至少采集 5 次重复，以评估统计误差。

**数据采集的触发时序**：16 通道 TOF 的共同触发信号来自 Ti:sapphire 激光器的同步输出（1 kHz TTL）。触发信号经延迟单元（分辨率 1 ns，可调范围 0–1 ms）分配至各通道的时域分析窗口，确保所有通道在相同激光脉冲事件下同步积分。

**步骤 3：效率修正**

对每通道数据乘以修正因子 $1/k_i$，消除通道间灵敏度差异：

$$S_i^{\mathrm{corr}}(E,\tau) = S_i(E,\tau)/k_i$$

**步骤 4：角向求和（等效角积分）**

修正后各通道能谱做角向求和：

$$S_{\mathrm{int}}(E,\tau) = \sum_{i=1}^{16} S_i^{\mathrm{corr}}(E,\tau)$$

角积分过程中同时保留各通道的独立数据，以供 M4 第二级（能动量分辨）使用。

**步骤 5：角分辨数据导出**

从 16 通道 TOF 数据中提取 $(E,\theta)$ 二维能动量分布，其中 $\theta$ 为光电子发射角（每个通道对应 $\theta_i = i\times22.5°$）。用于第二级解耦。

### 验证方式

**均匀性验证**：以单通道极限靶材（氖气，多通道贡献 < 5%）为检验源，确认角积分谱的信噪比优于单通道谱 3 倍以上。

**偶极相位压制效率验证**：在氩气靶上对比角积分前后偶极相位贡献的占比，确认角积分对偶极相位的压制效率达到理论预估水平（< 2% 残余贡献）。

**通道响应一致性验证**：以双通道靶材（氮气）重复采集 5 次，确认各通道效率因子 $k_i$ 的长期稳定性（漂移 < 1%）。

**延迟稳定性验证**：以相同脉冲条件下的两次独立测量比对，确认延迟模块的 < 100 as RMS 稳定度要求被满足。

### 失效边界与风险缓解

**失效边界**：探测器各通道灵敏度差异若 > 5%，角积分结果的准确性将受严重影响。

**风险缓解**：每次实验前后均进行效率标定；数据处理中对通道响应做归一化修正，并估算修正引入的系统误差（< 1%）。若标定发现通道漂移 > 5%，该通道数据在后续处理中被剔除。

## M4：偶极相位二级解耦重构算法

### 物理背景

Pabst-Dahlström 定理（Phys. Rev. A 90, 013416, 2014）：角积分过程对不同磁量子数 $m$ 的偶极矩阵元做平均，使与角动量相关的偶极相位贡献被天然压制。角积分可压制偶极相位至 < 2% 的理论上限。

本方法利用这一天然压制效应，建立二级解耦策略：

- **第一级**：角积分提取脉冲包络，假设偶极相位已被压制至可忽略水平
- **第二级**：在能动量空间分离脉冲固有啁啾与残余偶极相位

### 算法步骤

**第一级（角积分提取脉冲包络）**

1. 将角积分能谱 $S_{\mathrm{int}}(E,\tau)$ 代入 FROG-CRAB 代价函数，检索脉冲包络 $I(t)$ 与光谱相位 $\Phi_{\mathrm{pulse}}(\omega)$：

$$\chi^2_1 = \sum_{i,j}\left|S_{\mathrm{int}}(E_i,\tau_j) - S_{\mathrm{model}}(E_i,\tau_j; I,\Phi_{\mathrm{pulse}})\right|^2$$

2. 以 $\chi^2_1$ 最小化为目标，采用主成分分析法（PCG）或共轭梯度法（CG），得到脉冲固有啁啾信息。

3. 评估偶极相位残余贡献：$\eta_{\mathrm{dip}} = |\Phi_{\mathrm{dip}}|/|\Phi_{\mathrm{total}}|$。若 $\eta_{\mathrm{dip}} < 2\%$ 则第一级成功，可进入第二级。若 $\eta_{\mathrm{dip}} \geq 5\%$ 则触发备选路径 B（CNN 端到端检索）。

**第一级的操作细节**：步骤 1 中代价函数使用 L-curve 法确定正则化参数 $\lambda_1$，扫描范围 $\lambda_1 \in [10^{-4}, 10^{0}]$。PCG 迭代的初始猜测取为平坦相位（$\Phi(\omega) = 0$），以避免陷入局部极小。

步骤 3 中 $\eta_{\mathrm{dip}}$ 的频域计算步骤如下：

1. 从重构结果中提取总光谱相位 $\Phi_{\mathrm{total}}(\omega)$，计算瞬时频率调谐 $\partial\Phi_{\mathrm{total}}/\partial\omega$。

2. 对 $\partial\Phi_{\mathrm{total}}/\partial\omega$ 做低通滤波分离慢变与快变分量。滤波器采用 8 阶巴特沃斯低通，**截止频率 5 THz** 的选取依据：阿秒脉冲固有啁啾的典型频率调谐在 0.1–3 THz 区间（对应 100–300 as 脉冲宽度的二阶相位展开），偶极相位残余的特征快变分量集中在 5–15 THz（与原子里德堡序列间隔量级一致，Ar 3p→4s 间隔约 20 meV ≈ 5 THz）。

3. 低通滤波后的慢变分量对应脉冲固有啁啾 $\Phi_{\mathrm{pulse}}$，快变分量为偶极相位残余 $\Phi_{\mathrm{dip}}$。计算 $\eta_{\mathrm{dip}} = \|\Phi_{\mathrm{dip}}\|_{\mathrm{RMS}} / \|\Phi_{\mathrm{total}}\|_{\mathrm{RMS}}$。

若 $\eta_{\mathrm{dip}} < 2\%$ 则第一级成功，可进入第二级。若 $2\% \leq \eta_{\mathrm{dip}} < 5\%$ 则继续第二级修正但增大 $\lambda_2$ 权重。若 $\eta_{\mathrm{dip}} \geq 5\%$ 则触发备选路径 B（CNN 端到端检索）。

**第二级（能动量分辨修正偶极相位）**

4. 以第一级得到的 $\Phi_{\mathrm{pulse}}(\omega)$ 为已知量，从角分辨数据中提取偶极相位：

$$\Phi_{\mathrm{dip}}(E,\theta) = \arg\left[\tilde{S}(E,\theta)\right] - \Phi_{\mathrm{pulse}}(\omega_E)$$

其中 $\theta$ 为光电子发射角，$\omega_E$ 为光电子动能 $E$ 对应的光学频率。

5. 构建二维能动量相位图 $(E,\theta)$，分离脉冲固有啁啾（与 $E$ 强相关，与 $\theta$ 弱相关）与靶材偶极相位（与 $\theta$ 强相关，与 $E$ 弱相关）的空间分布特征。

6. 跨靶材（Ar、Kr）比对二级解耦结果的可比性误差 $\delta_{\mathrm{cross}}$：

$$\delta_{\mathrm{cross}} = \frac{1}{N}\sum_k \left|\Phi_{\mathrm{pulse}}^{(\mathrm{Ar})}(\omega_k) - \Phi_{\mathrm{pulse}}^{(\mathrm{Kr})}(\omega_k)\right|$$

目标：$\delta_{\mathrm{cross}} < 5\%$。

### 关键参数表

| 参数 | 取值 | 说明 |
|------|------|------|
| 第一级正则化参数 $\lambda_1$ | $10^{-2}$–$10^{0}$（交叉验证确定） | 控制偶极相位惩罚强度 |
| 迭代收敛阈值 | $\Delta\chi^2 < 10^{-4}$ | 第一级重构终止判据 |
| 偶极相位压制目标 | < 2%（第一级残余贡献） | Pabst-Dahlström 理论预估 |
| 跨靶材可比性误差目标 | < 5% | 第二级终止判据 |
| 角向求和权重 | $w_i = 1/k_i$（通道效率修正因子） | 数据处理参数 |
| $\eta_{\mathrm{dip}}$ 触发阈值 | < 2%（正常），> 5%（触发备选） | 第一级判据 |
| 能动量相位图网格 | 16×能量 bins（每通道一个 $\theta$） | $(E,\theta)$ 分辨率 |

### 验证方式

**分解自洽性验证**：以第二级提取的 $\Phi_{\mathrm{dip}}$ 叠加第一级重构的 $\Phi_{\mathrm{pulse}}$，重新计算条纹迹，与原始测量数据比对，相关性应 > 0.95。

**跨靶材一致性验证**：在氩气与氪气靶上分别执行完整二级流程，确认 $\Phi_{\mathrm{pulse}}$ 提取结果一致（误差 < 5%），而 $\Phi_{\mathrm{dip}}$ 反映各自靶材特征。

**氦气对照组验证**：在无偶极相位复杂结构的氦气靶（Z=2）上执行流程，确认第二级提取的 $\Phi_{\mathrm{dip}}$ 接近零，验证方案的固有上限标定。

**重构误差独立验证**：以标准 FROG-CRAB 对单通道氖气数据重构为基准，比较 M4 与标准方法的 $\delta\phi_{\mathrm{RMS}}$，差异应 < 1%。

### 失效边界与风险缓解

**失效边界**：第一级角积分无法将偶极相位压制至 < 5% 时，二级解耦策略整体失效。

**风险缓解**：触发条件为氩气/氪气角积分数据中偶极相位残余贡献 > 5%。此时切换至备选路径 B（CNN 端到端相位检索）。

## M5：CNN 抗噪相位检索备选方案

### 架构

采用 U-Net 型编码器-解码器结构（参照 Zhu et al., J. Phys. B 59, 024001, 2026）。编码器部分采用 4 级下采样（每级 2 卷积层 + MaxPool），提取条纹迹的多尺度特征；解码器部分对应 4 级上采样，输出脉冲光谱相位 $\Phi(\omega)$ 的 2D 分布图（与输入条纹迹分辨率相同）。

**U-Net 架构参数**：

| 层 | 卷积核 | 通道数 | 输出尺寸 |
|----|--------|--------|---------|
| 输入 | — | 1 | H×W（条纹迹） |
| Enc1 | 3×3, ReLU | 64 | H/2 × W/2 |
| Enc2 | 3×3, ReLU | 128 | H/4 × W/4 |
| Enc3 | 3×3, ReLU | 256 | H/8 × W/8 |
| Enc4 | 3×3, ReLU | 512 | H/16 × W/16 |
| Bottleneck | 3×3, ReLU | 1024 | H/16 × W/16 |
| Dec4 | 3×3, ReLU + 上采样 | 512 | H/8 × W/8 |
| Dec3 | 3×3, ReLU + 上采样 | 256 | H/4 × W/4 |
| Dec2 | 3×3, ReLU + 上采样 | 128 | H/2 × W/2 |
| Dec1 | 3×3, ReLU + 上采样 | 64 | H × W |
| 输出 | 1×1 卷积 | 1 | H×W（相位图） |

跳跃连接将 Enc2/3/4 的特征图与对应 Dec 层拼接，以保留高分辨率细节。输入为单通道条纹迹图像 $S(E,\tau)$，输出为对应的脉冲光谱相位图 $\Phi(\omega)$。

### 训练数据生成

从 TDSE 模拟产生大量成对数据 $(\mathbf{S}_{\mathrm{noise}},\mathbf{S}_{\mathrm{clean}})$，其中 $\mathbf{S}_{\mathrm{noise}}$ 注入泊松噪声（模拟实际计数统计噪声），信噪比范围 5–30 dB。

**信噪比注噪的具体操作**：对干净条纹迹 $\mathbf{S}_{\mathrm{clean}}$，按以下方式注入泊松噪声：

$$\mathbf{S}_{\mathrm{noise}} = \frac{1}{N_{\mathrm{ph}}} \mathrm{Poisson}(N_{\mathrm{ph}} \cdot \mathbf{S}_{\mathrm{clean}})$$

其中 $N_{\mathrm{ph}}$ 为归一化因子，控制平均光子计数（$N_{\mathrm{ph}} = 10$–$10^4$ 对应 SNR ≈ 5–30 dB）。Poisson 采样对每个像素独立执行。

训练损失函数：

$$\mathcal{L} = \frac{1}{N}\sum_{k=1}^{N}\left|\Phi_{\mathrm{retrieved}}(\omega_k) - \Phi_{\mathrm{true}}(\omega_k)\right|^2 + \beta\cdot\mathrm{TV}(\Phi_{\mathrm{retrieved}})$$

其中 $\beta$ 为全变差正则化系数，典型值 **0.01**。$\beta$ 的选取通过验证集扫描确定：扫描范围 $\beta \in [0.001, 0.1]$，以验证集相位误差最小且 TV 项不过压制相位细节为双目标，取帕累托最优解。TV 项定义：

$$\mathrm{TV}(\Phi) = \sum_k |\Phi(\omega_{k+1}) - \Phi(\omega_k)|$$

**推理硬件要求**：推理速度 < 50 ms/pulse，需 NVIDIA A100 或同级 GPU（约 20 TFLOPS FP32 或 312 TFLOPS FP16 TensorCore），显存 ≥ 20 GB（模型参数约 $2\times10^6$，中间激活图约 8 GB）。若仅做相位检索（不训练），可在消费级 GPU（NVIDIA RTX 3090/4090，24 GB 显存）上运行，推理速度约 100–200 ms/pulse，仍可满足离线批处理需求。

**端到端微调策略**：实验数据微调（FROG-CRAB 已提取真实脉冲相位作为监督信号）使用 20–50 个实验条纹迹，每条含 5 次重复平均。微调时冻结编码器参数，仅微调解码器（12 层，约 $2\times10^6$ 参数），使用 AdamW 优化器，学习率 $10^{-5}$（预训练学习率的 1/10），余弦退火至 $10^{-6}$，训练 50 个 epoch。微调有效性判据：验证集损失下降 > 30%。

### 触发条件与验证

**触发条件**：角积分方案在特定靶材上压制效率低于预期（偶极相位残余贡献 > 5%）。

**验证方式**：在相同实验数据上对比 CNN 与 M4 的重构结果，确认 CNN 的 $\delta\phi_{\mathrm{RMS}}$ 不劣于 M4（允许 10% 的性能差距，以换取方法稳健性）。

### 局限性

**sim-to-real 差距**：仿真训练数据中的噪声模型可能不完全匹配实际实验条件。

**风险缓解**：采用物理启发的损失函数（加入先验约束，如脉冲相位平滑性、光谱支持约束），减少对仿真数据分布的依赖；在真实数据上做微调（fine-tuning），逐步缩小领域差距。微调后验证集损失下降 > 30% 即为微调有效。

## M6：双变量误差依赖图谱标定

### 实验设计

以光子能量区间（$E_{\mathrm{ph}}$）与通道重叠度（$R_{\mathrm{ch}}$，以多通道贡献占总截面的百分比表征）为自变量，以修正算法的重构误差 $\epsilon$（修正算法与传统 FROG-CRAB 的结果偏差）为因变量。

三能区 × 两种靶材配置（共 6 组独立测量）：

| 能区 | 光子能量范围 | 靶材 | 多通道贡献 $R_{\mathrm{ch}}$ | 预期修正效果 |
|------|------------|------|---------------------------|-------------|
| 极紫外 | 50–150 eV | Ne（单通道）、Ar | < 5% | 修正项自动退化为零（基准验证） |
| 水窗 | 284–410 eV | N₂、CH₄ | 15%–30% | 修正项显著有效（核心验证区） |
| 软 X 射线 | 410–543 eV | Kr、Xe | > 30% | 预期接近或超出失效边界 |

### 算法步骤

**步骤 1：误差提取**

对每组测量，计算修正算法与标准 FROG-CRAB 的重构偏差：

$$\epsilon = |\Phi_{\mathrm{corr}} - \Phi_{\mathrm{std}}|_{\mathrm{RMS}}$$

每组测量重复次数 ≥ 5 次，以评估统计误差。

**步骤 2：二维插值**

在 $(E_{\mathrm{ph}}, R_{\mathrm{ch}})$ 参数空间（极紫外/水窗/软X射线 × < 5%/15%–30%/> 30%）做双线性插值，构建 50×50 的误差网格。

**双线性插值的具体操作**：设 6 个实测点 $(E_i, R_i, \epsilon_i)$，$i=1\ldots6$，首先生成规则的 50×50 参数网格（50 个能量采样点 × 50 个重叠度采样点）。双线性插值按以下顺序执行：

1. 对每个 $R$ 固定值（行方向），在能量方向上对相邻两实测点做线性插值，得到中间值 $\epsilon(E_{\mathrm{interp}}, R)$。

2. 对每个 $E$ 固定值（列方向），在重叠度方向上对中间值做线性插值，得到网格每个点的 $\epsilon$ 估计。

若相邻实测点间存在非单调关系（如软 X 射线能区的非单调误差依赖），则在对应区间改用三次样条插值替代线性插值，以保证插值函数连续且导数光滑。

**留一交叉验证（LOOCV）的操作步骤**：

1. 剔除第 $i$ 个实测点（$i=1\ldots6$），用剩余 5 点重新执行双线性插值，得到预测值 $\hat{\epsilon}_i$。

2. 计算相对误差 $\delta_i = |\hat{\epsilon}_i - \epsilon_i| / \epsilon_i$。

3. 重复步骤 1–2 共 6 次，得到留一误差集 $\{\delta_1, \ldots, \delta_6\}$。

4. 取最大相对误差 $\max(\delta_i)$，若 < 10% 则插值通过验证。若不通过，检查 $\epsilon_i$ 异常的实测点，排除靶材系统误差后重新验证。

**等高线绘制参数**：使用 matplotlib `contour` 函数绘制等高线，等高线层级设置为 [0.02, 0.05, 0.08, 0.10]（对应 2%/5%/8%/10% 四级），其中 5% 为主等高线（线宽加粗），合格区（$\epsilon < 5\%$）用浅绿（`#90EE90`）填充，失效区（$\epsilon > 10\%$）用浅灰（`#D3D3D3`）填充，中间过渡区（$5\% < \epsilon < 10\%$）不填充仅标等高线。

**步骤 3：等高线绘制**

以 $\epsilon = 5\%$ 为合格线阈值，绘制等高线图，标注修正模块的适用区间与失效边界。以 $\epsilon = 10\%$ 为失效线，高于此值定义为方法学失效。

等高线绘制使用 matplotlib 的 `contour` 和 `contourf` 函数，合格区（$\epsilon < 5\%$）填充浅绿色，失效区（$\epsilon > 10\%$）填充浅灰色，中间过渡区（$5\% < \epsilon < 10\%$）不填充仅标等高线。

**步骤 4：边界方程拟合**

对 < 5% 合格区间边界做曲线拟合，给出解析边界方程 $R_{\mathrm{ch}}^{\mathrm{max}}(E_{\mathrm{ph}})$，用于预测新能区的适用性。

**边界方程拟合的具体操作**：合格边界在 $(E_{\mathrm{ph}}, R_{\mathrm{ch}})$ 平面内近似为单调曲线。采用有理函数形式 $R_{\mathrm{ch}}^{\mathrm{max}}(E) = (a_0 + a_1 E) / (1 + b_1 E + b_2 E^2)$ 拟合 6 个实测点的边界估计（边界点从等高线交点提取）。拟合使用非线性最小二乘法（Levenberg-Marquardt 算法），拟合残差 < 0.05 为通过。拟合结果以方程形式给出，并附带 95% 置信区间。

### 关键参数表

| 参数 | 取值 | 说明 |
|------|------|------|
| 能量采样点 | 每能区 3 个（低/中/高能量各 1 个） | 覆盖能区跨度 |
| 通道重叠度分级 | 低（< 5%）、中（15%–30%）、高（> 30%） | 三级梯度 |
| 插值网格分辨率 | 50×50 | 50 个能量 × 50 个重叠度 |
| 误差阈值 | < 5%（合格）、> 10%（失效） | 边界判定标准 |
| 每组测量重复次数 | ≥ 5 次 | 统计误差评估 |

### 验证方式

**单通道极限验证**：在极紫外能区（Ne、Ar），修正算法应自动退化为传统 FROG-CRAB，两者偏差 < 1%。若偏差显著 > 1%，说明修正项存在非物理的残余贡献。

**误差对称性验证**：水窗能区 N₂ 和 CH₄ 应给出相近的 $\epsilon$ 值（相同 $R_{\mathrm{ch}}$ 区间），若偏差 > 5%，提示实验系统误差未被充分控制。

**插值连续性验证**：6 个实测点的插值误差估计应 < 10%（通过留一交叉验证确定）。

### 失效边界与风险缓解

**失效边界**：当光电子动能 > 400 eV 或通道重叠度 > 50% 时，修正框架的近似假设不再成立。失效判据：$\epsilon > 10\%$ 且不随参数优化改善。

**风险缓解**：三能区实验并行安排以节省总实验周期；失效区域在图谱中以阴影区域标注，不再强求修正。

## M7：TDSE→FROG 门控自洽性校准流程

### 功能定位

M7 不产生独立物理输出，其功能是确保 R1 阶段 TDSE 模拟标定的修正项参数（通道间相位差 Δφ、通道强度比 R、修正项系数 α）在 R2 实验条件下仍然成立。该校准流程对应申请书 §4.3 方法学自洽性中"具体校准流程"。

### 校准逻辑

TDSE 模拟与 FROG 实验之间存在两类系统偏差来源：

1. **场参数偏差**：模拟中的 XUV 脉冲参数（中心能量、脉冲宽度）与实验真实值之间存在不确定度
2. **靶材模型偏差**：模拟中的原子能级结构（通道能量、振子强度）来自理论数据库，与真实靶材气体之间存在细微差异

若不消除这两类偏差，R1 阶段标定的修正项参数直接应用于 R2 会引入额外误差，导致门控判据失真。

### 算法步骤

**步骤 1：共同参量选取**

从 TDSE 模拟与 FROG 实验中提取一组对场参数和靶材模型不敏感的**共同参量**，作为校准锚点。选择条件：参量须同时可从模拟和实验两类数据源中独立提取，且对系统偏差来源的一阶导数为零。

候选共同参量及其适用性：

| 共同参量 | 从 TDSE 可提取性 | 从 FROG 可提取性 | 对场参数敏感性 | 对靶材模型敏感性 |
|------------|--------------|--------------|-------------|-------------|
| 通道间能量差 ΔE₁₂ | ✓（能级差已知） | ✓（从能谱峰位提取） | 低 | 中（与振子强度弱相关） |
| 通道强度比 R(E) | ✓（谱强度比） | ✓（需去除脉冲包络后提取） | 中（与脉冲能谱卷积相关） | 低 |
| 干涉相位 Δφ(E) | ✓（直接计算） | ✓（FFT 提取） | 高（与脉冲相位卷积） | 低 |

优先选用通道间能量差 ΔE₁₂ 与通道强度比 R(E) 作为共同参量，理由：两者对场参数不确定度的敏感度低于干涉相位。

**从 FROG 数据提取共同参量的操作步骤**：

1. **通道间能量差 ΔE₁₂**：对测得的光电子能谱 $S(E)$ 做多高斯拟合（2–3 个高斯分量），提取各分量峰位 $E_i$。通道间能量差即为相邻峰位之差：$\Delta E_{12} = |E_2 - E_1|$。典型计数 $N \geq 10^4$ 时，峰位提取精度约 0.1 eV（由探测器能量分辨率 1 eV @ 400 eV 决定），满足 ΔE₁₂ > 1 eV 的标定需求。

2. **通道强度比 R(E)**：从拟合结果提取各高斯分量的峰面积（积分强度），计算 $R(E) = A_2 / A_1$。需先去除脉冲包络的卷积效应：取单通道氖气数据的能谱作为脉冲强度参考 $I_{\mathrm{XUV}}(E)$，对双通道能谱做去卷积：$S_{\mathrm{chan},i}(E) = S_i(E) / I_{\mathrm{XUV}}(E)$，再用去卷积后的谱面积计算 $R(E)$。

**CO₂ 作为独立验证靶材的选择依据**：CO₂ 的 C 1s→2π* 共振位于 ~290 eV，与 CH₄ 的 C K 边 284 eV 通道能量相近，但分子结构不同（线形 CO₂ vs. 四面体 CH₄），振子强度分布存在显著差异，可验证修正算法的靶材普适性。同时 CO₂ 在常温常压下为气体（与 CH₄/N₂ 靶材形态一致），无需改造实验真空系统，是理想的独立验证靶材。

**步骤 2：偏差评估**

对每种靶材，分别从 TDSE 模拟和 FROG 实验提取共同参量，计算偏差：

$$\delta_{\mathrm{calib}} = \left| R_{\mathrm{TDSE}}(E) - R_{\mathrm{FROG}}(E) \right| / R_{\mathrm{TDSE}}(E)$$

若 $\delta_{\mathrm{calib}} < 5\%$，认为校准通过，修正项参数可直接应用于 R2。若 $5\% \leq \delta_{\mathrm{calib}} < 10\%$，进入步骤 3 参数重标定。若 $\delta_{\mathrm{calib}} \geq 10\%$，修正项参数整体失效，触发备选路径 A（神经网络）。

**步骤 3：参数重标定（偏差 5%–10% 时启用）**

以 FROG 提取的共同参量为真值，重新拟合修正项系数 α：

$$\alpha_{\mathrm{recal}} = \alpha_{\mathrm{TDSE}} \times \frac{R_{\mathrm{FROG}}}{R_{\mathrm{TDSE}}}$$

该线性重标定假设偏差来源于靶材振子强度的系统性缩放，不改变修正项的函数形式。重标定后再次执行步骤 2 验证，确认 $\delta_{\mathrm{calib}}$ 收敛至 < 5%。

**步骤 4：验证实验设计（平行于步骤 1–3）**

选取一组独立于 R1/R2 的验证数据集，该数据集须满足：靶材与 R1/R2 完全不同（建议使用 CO₂ 气体，C 1s→2π* 位于 ~290 eV，与 CH₄ 相近但独立），且实验条件与 R2 完全一致。在该验证集上运行修正算法（使用校准后参数），确认重构误差 < 5%。若 > 5%，返回步骤 1 重新校准。

### 关键参数表

| 参数 | 取值 | 说明 |
|------|------|------|
| 校准通过阈值 | δ_calib < 5% | 修正项参数可直接应用 |
| 重标定阈值 | 5% ≤ δ_calib < 10% | 进入线性重标定程序 |
| 失效阈值 | δ_calib ≥ 10% | 触发备选路径 A |
| 验证数据集靶材 | CO₂（独立于 CH₄/N₂） | 独立验证校准结果 |
| 每靶材重复测量次数 | ≥ 5 次 | 统计误差评估 |

### 时间节点安排

M7 校准流程设计为 R1 与 R2 **并行交接**：R1 模拟输出修正项参数后（预计第 12 个月），立即启动 M7 校准（约 1 个月），R2 正式实验在 M7 校准通过后才开始。该安排使总周期比串行方案（先完成全部 R1 再启动 R2）缩短约 30%，具体时间节省来自：R1 模拟在第 1–12 个月独立运行，与 R2 实验准备（光源调试、探测器标定）完全并行；R2 正式实验在第 13–24 个月执行，相比串行方案（需等 R1 全部完成，第 1–24 个月仅做模拟，第 25–36 个月才做实验）节省 12 个月。

## 三能区靶材递进逻辑与门控关系

### 递进设计原理

三能区（极紫外→水窗→软X射线）的靶材选取不是平行对照，而是遵循**单通道极限→多通道典型→多通道失效边缘**的递进逻辑，每一阶段的结论决定下一阶段的实验参数：

```
极紫外能区（Ne/Ar，< 5% 多通道贡献）
  → 目的：验证修正算法在单通道极限下可约至传统 FROG-CRAB
  → 预期结果：修正项自动趋于零（α → 0），偏差 < 1%
  → 门控输出：若偏差 > 1%，说明修正项存在非物理残余贡献，
     需重新检查 M2 的修正项构造逻辑，不进入下一阶段
  ↓ 通过门控 G5（单通道可约性）后进入

水窗能区（N₂/CH₄，15%–30% 多通道贡献）
  → 目的：标定修正模块的核心适用区间（申请书 §3.3 R3 核心验证区）
  → 预期结果：修正项显著有效，偏差从 > 20% 降至 < 5%
  → 门控输出：若偏差未降至 < 5%，检查通道干涉相位提取是否正确；
     若通道重叠宽度超出 2 eV，修正项参数需重新标定
  ↓ 通过门控 G5（多通道有效性）后进入

软X射线能区（Kr/Xe，> 30% 多通道贡献）
  → 目的：界定修正框架的失效边界（申请书 §3.3 失效条件触发区）
  → 预期结果：偏差接近或超过 10%，需通过参数重标定尝试恢复
  → 门控输出：若参数重标定后偏差仍 > 10%，该区域标注为失效边界，
     不再强求修正（M6 以阴影区标注）
```

### 门控信号与决策矩阵

| 能区转换 | 通过条件 | 未通过处置 |
|---------|---------|---------|
| 极紫外→水窗 | 单通道可约性验证：修正项趋于零（α < 0.05），偏差 < 1% | 进入水窗能区 | 修正项构造逻辑回溯检查 |
| 水窗→软X射线 | 多通道有效性验证：修正后偏差 < 5% | 进入软X射线能区 | 参数重标定（通道重叠度重扫） |
| 软X射线区段内 | 失效边界确认：偏差 > 10% 且不随参数优化改善 | 标注失效边界 | 以阴影区域标注，不外推 |
