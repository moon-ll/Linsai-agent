## M1：TDSE 双通道耦合数值模拟

### 物理模型与算法步骤

1. **模型构建**：采用单电子近似下的含时薛定谔方程，描述原子/分子在 XUV+IR 联合场中的光电离过程。光电子最终动能为 $E_{\mathrm{final}} = E_{\mathrm{kin}} + U_{\mathrm{p}}\sin^2(\omega t + \phi_{\mathrm{CEP}}) + \vec{A}(t)\cdot\vec{k}$，其中 $E_{\mathrm{kin}}$ 为无场光电子动能，$U_{\mathrm{p}}$ 为有质动力势，$\vec{A}(t)$ 为 IR 场矢势，$\vec{k}$ 为光电子动量。

2. **波函数展开**：波函数按原子本征态分波展开，$|\Psi(t)\rangle = \sum_n c_n(t)|n\rangle e^{-iE_n t}$，其中 $|n\rangle$ 为原子本征态，$c_n(t)$ 为含时展开系数。

3. **耦合通道势项**：通道间耦合势项取双电离通道耦合形式，$V_{12}(t) = \langle\psi_1|\vec{d}\cdot\vec{E}(t)|\psi_2\rangle$，$\vec{d}$ 为电偶极矩算符，$\vec{E}(t)$ 为激光场偏振方向。

4. **时间积分**：展开系数的耦合 ODE 组通过四阶龙格-库塔法积分。典型时间步长取 10–50 as（远小于阿秒脉冲时间尺度）。空间网格采用柱坐标 $(r,\theta)$，$r$ 方向取 512–1024 个网格点，$r_{\max}$ 设为 50–100 a.u.；使用完美匹配层（PML）吸收边界条件消除边界反射。

5. **谱计算**：含时演化完成后，对 $c_n(t)$ 做傅里叶变换得到光电子能谱 $S(E)$；改变 XUV–IR 延迟 $\tau$ 重复计算，得到二维条纹信号 $S(E,\tau)$。

### 关键参数表

| 参数 | 取值 | 说明 |
|------|------|------|
| 通道数 | 2–3 | 典型 C K 边双通道体系 |
| 光子能量 | 284–400 eV | 水窗能区（C K 边 284 eV、N K 边 400 eV） |
| 通道重叠宽度 | 0.5–2 eV | C K 边附近典型值 |
| 通道间能量差 | > 1 eV（适用），< 0.5 eV（失效） | 决定双通道近似是否成立 |
| 驱动场强度 | $10^{14}$–$10^{15}$ W/cm² | 非扰动强场区 |
| 阿秒脉冲宽度 | 100–300 as | 典型值 |
| 驱动场波长 | 800 nm（Ti: sapphire） | 基准驱动波长 |
| 时间步长 | 10–50 as | 四阶龙格-库塔稳定性要求 |
| 空间网格 | 512–1024 点（$r$ 方向） | 收敛性测试确定 |
| 模拟总时长 | 5–10 ps | 包含光电子全谱演化 |

### 验证方式

- **解析基准验证**：在单通道极限（去除 $V_{12}(t)$ 项）下，将 TDSE 结果与少带模型的解析结果比对，相对偏差应 < 1%。
- **文献复现验证**：选取氖原子 $2s$/$2p$ 双通道体系（能量差约 4 eV），复现文献中已知的光电子能谱结构，验证模型正确性。
- **收敛性测试**：以网格密度（512/1024/2048 点）和时间步长（50/25/10 as）为变量，确认结果在 < 1% 变化内收敛。
- **守恒律验证**：检验总概率 $\sum_n |c_n(t)|^2$ 在演化全程守恒至 6 位有效数字，以确认数值稳定性。

### 失效边界与风险

当通道间能量差 < 0.5 eV 时，双通道近似的波函数可分离性丧失，此时 TDSE 结果失去物理意义。应对策略为：在 0.5–1 eV 区间做参数扫描，确认修正项的适用性随能量差增大而单调恢复。

## M2：通道间相位干涉解析修正项

### 算法步骤

1. **干涉特征提取**：从模拟或实验的条纹能谱 $S(E,\tau)$ 中，对每个能量点 $E$ 做延迟方向的傅里叶变换，提取干涉项的相位 $\Delta\phi(E)$ 与强度比 $R(E) = I_2(E)/I_1(E)$。

2. **修正项构造**：以通道间相位差 $\Delta\phi$ 与通道强度比 $R$ 为参量，构造解析修正项：
   $$\Phi_{\mathrm{corr}}(\omega) = \alpha \cdot \Delta\phi \cdot S_{\mathrm{interference}}(\omega)$$
   其中 $\alpha$ 为通道强度相关加权系数，$S_{\mathrm{interference}}(\omega)$ 为干涉项的光谱分布。

3. **嵌入代价函数**：将修正项嵌入 FROG-CRAB 代价函数：
   $$\chi^2 = \sum_{i,j}\left|S_{\mathrm{exp}}(E_i,\tau_j) - S_{\mathrm{model}}(E_i,\tau_j;\Phi)\right|^2 + \lambda\cdot\Phi_{\mathrm{corr}}$$
   其中 $\lambda$ 为正则化参数（通过 L-curve 法选取典型值 $\lambda = 10^{-3}$–$10^{-1}$）。

4. **迭代检索**：使用梯度下降法求解修正后的代价函数，迭代终止条件为相邻两步 $\chi^2$ 变化 < $10^{-4}$ 或达到 200 次迭代上限。

5. **误差评估**：以重构脉冲与真实脉冲的均方根相位误差 $\delta\phi_{\mathrm{RMS}}$ 作为修正有效性判据：
   $$\delta\phi_{\mathrm{RMS}} = \sqrt{\frac{1}{N}\sum_{k=1}^{N}\left|\Phi_{\mathrm{retrieved}}(\omega_k) - \Phi_{\mathrm{true}}(\omega_k)\right|^2}$$
   有效修正的阈值：$\delta\phi_{\mathrm{RMS}} < 5\%$。

### 关键参数表

| 参数 | 取值 | 说明 |
|------|------|------|
| 正则化参数 $\lambda$ | $10^{-3}$–$10^{-1}$（L-curve 法确定） | 控制修正项权重 |
| 修正项生效阈值 | 通道重叠宽度 > 1 eV | TDSE 模拟标定 |
| 通道数适用范围 | 2–3 通道 | 超出此范围需重新标定 |
| 迭代收敛阈值 | $\Delta\chi^2 < 10^{-4}$ | 梯度下降终止判据 |
| 最大迭代次数 | 200 | 防止过拟合 |
| 误差目标 | 重构脉冲相位均方根偏差 < 5% | 有效性判据 |

### 验证方式

- **自洽性验证**：用修正后的脉冲相位重新计算条纹信号 $S_{\mathrm{model}}(E,\tau)$，与原始输入信号做二维相关，要求相关系数 > 0.95。
- **参数敏感性验证**：在 $\alpha \pm 20\%$ 范围内扫描，确认 $\delta\phi_{\mathrm{RMS}}$ 变化 < 1%，以验证修正项对参数取值不敏感。
- **通道数普适性验证**：分别用 2 通道和 3 通道 TDSE 数据测试，确认修正项形式不变，仅 $\alpha$ 系数需随通道数轻微调整。

### 失效边界与风险

当通道重叠宽度 < 0.5 eV 时，双通道近似的可分离性丧失，修正项不再适用。触发条件为：TDSE 模拟中通道混合度（以通道投影算子衡量）> 30%。此时切换至备选路径 A（神经网络学习通道干涉模式）。

## M3：角积分位置灵敏探测器测量

### 实验装置与参数

探测器采用 16 通道 TOF 阵列（与 Meier et al., arXiv:2501.08966 构型相当），具体参数：

| 参数 | 取值 | 说明 |
|------|------|------|
| TOF 通道数 | 16 | 独立记录，独立触发 |
| 能量分辨率 | $\Delta E/E \approx 1\%$ @ 400 eV | 单通道谱分辨 ~4 eV @ 400 eV |
| 角向覆盖 | 全 360° | 各通道等角距排列 |
| 角分辨率 | ±2°（每通道覆盖 22.5°） | 角向bin宽度 |
| 最大计数率 | 120 counts/s/pulse | 受 1 kHz 激光重频限制 |
| TOF 窗口宽度 | 10–20 ns | 覆盖全能量范围 |
| 延迟稳定性 | < 100 as RMS | XUV–IR 干涉仪主动稳定 |

### 实验步骤

1. **通道效率标定**：在均匀光电子源（微通道板平场源）下，测量各通道对同一能量的响应，获取相对效率因子 $k_i$（$i=1\ldots16$）。标定重复 3 次取平均，统计误差 < 0.5%。

2. **数据采集**：在设定靶材（Ar、Kr 等）下采集条纹迹。各通道独立记录能量谱 $S_i(E,\tau)$，延迟 $\tau$ 扫描范围 ±500 as，步长 50 as。

3. **效率修正**：对每通道数据乘以修正因子 $1/k_i$，消除通道间灵敏度差异。

4. **角向求和**：修正后各通道能谱做角向求和，等效于角积分：
   $$S_{\mathrm{int}}(E,\tau) = \sum_{i=1}^{16} S_i(E,\tau)/k_i$$

### 验证方式

- **均匀性验证**：以单通道极限靶材（氖气，多通道贡献 < 5%）为检验源，确认角积分谱的信噪比优于单通道谱 3 倍以上。
- **偶极相位压制效率验证**：在氩气靶上对比角积分前后偶极相位贡献的占比，确认角积分对偶极相位的压制效率达到理论预估水平（< 2% 残余贡献）。
- **通道响应一致性验证**：以双通道靶材（氮气）重复采集 5 次，确认各通道效率因子 $k_i$ 的长期稳定性（漂移 < 1%）。

### 失效边界与风险

探测器各通道灵敏度差异若 > 5%，角积分结果的准确性将受严重影响。风险缓解：在每次实验前后均进行效率标定；数据处理中对通道响应做归一化修正，并估算修正引入的系统误差（< 1%）。

## M4：偶极相位二级解耦重构算法

### 算法步骤

第一级（角积分提取脉冲包络）：

1. 将角积分能谱 $S_{\mathrm{int}}(E,\tau)$ 代入 FROG-CRAB 代价函数，检索脉冲包络 $I(t)$ 与光谱相位 $\Phi_{\mathrm{pulse}}(\omega)$：
   $$\chi^2_1 = \sum_{i,j}\left|S_{\mathrm{int}}(E_i,\tau_j) - S_{\mathrm{model}}(E_i,\tau_j; I,\Phi_{\mathrm{pulse}})\right|^2$$
2. 以 $\chi^2_1$ 最小化为目标，采用迭代相位检索（主成分分析法或共轭梯度法），得到脉冲固有啁啾信息。
3. 评估偶极相位残余贡献：$\eta_{\mathrm{dip}} = |\Phi_{\mathrm{dip}}|/|\Phi_{\mathrm{total}}|$，若 $\eta_{\mathrm{dip}} < 2\%$ 则第一级成功。

第二级（能动量分辨修正偶极相位）：

4. 以第一级得到的 $\Phi_{\mathrm{pulse}}(\omega)$ 为已知量，从角分辨数据中提取偶极相位：
   $$\Phi_{\mathrm{dip}}(E,\theta) = \arg\left[\tilde{S}(E,\theta)\right] - \Phi_{\mathrm{pulse}}(\omega_E)$$
   其中 $\theta$ 为光电子发射角，$\omega_E$ 为对应能量。
5. 构建二维能动量相位图 $(E,\theta)$，分离脉冲固有啁啾与靶材偶极相位的空间分布特征。
6. 跨靶材（Ar、Kr）比对二级解耦结果的可比性误差 $\delta_{\mathrm{cross}}$，目标 < 5%。

### 关键参数表

| 参数 | 取值 | 说明 |
|------|------|------|
| 第一级角积分约束 $\lambda_1$ | $10^{-2}$–$10^{0}$（通过交叉验证确定） | 控制偶极相位惩罚强度 |
| 迭代收敛阈值 | $\Delta\chi^2 < 10^{-4}$ | 第一级重构终止判据 |
| 偶极相位压制目标 | < 2%（第一级残余贡献） | Pabst-Dahlström 理论预估 |
| 跨靶材可比性误差目标 | < 5% | 第二级终止判据 |
| 角向求和权重 | $w_i = 1/k_i$（通道效率修正因子） | 数据处理参数 |

### 验证方式

- **分解自洽性验证**：以第二级提取的 $\Phi_{\mathrm{dip}}$ 叠加第一级重构的 $\Phi_{\mathrm{pulse}}$，重新计算条纹迹，与原始测量数据比对，相关性应 > 0.95。
- **跨靶材一致性验证**：在氩气与氪气靶上分别执行完整二级流程，确认 $\Phi_{\mathrm{pulse}}$ 提取结果一致（误差 < 5%），而 $\Phi_{\mathrm{dip}}$ 反映各自靶材特征。
- **氦气对照组验证**：在无偶极相位复杂结构的氦气靶（Z=2）上执行流程，确认第二级提取的 $\Phi_{\mathrm{dip}}$ 接近零，验证方案的固有上限标定。

### 失效边界与风险

当第一级角积分无法将偶极相位压制至 < 2% 时，二级解耦策略整体失效。触发条件：氩气/氪气角积分数据中偶极相位残余贡献 > 5%。此时切换至备选路径 B（CNN 端到端相位检索）。

## M5：CNN 抗噪相位检索备选方案

### 架构与训练

采用 U-Net 型编码器-解码器结构（与 Zhu et al., J. Phys. B 59, 024001, 2026 一致）。编码器部分采用 4 级下采样（每级 2 卷积层 + MaxPool），提取条纹迹的多尺度特征；解码器部分对应 4 级上采样，输出脉冲光谱相位 $\Phi(\omega)$ 的 2D 分布图（与输入条纹迹分辨率相同）。

训练数据生成：从 TDSE 模拟产生大量成对数据 $(\mathbf{S}_{\mathrm{noise}},\mathbf{S}_{\mathrm{clean}})$，其中 $\mathbf{S}_{\mathrm{noise}}$ 注入泊松噪声（模拟实际计数统计噪声），信噪比范围 5–30 dB。训练损失函数：
$$\mathcal{L} = \frac{1}{N}\sum_{k=1}^{N}\left|\Phi_{\mathrm{retrieved}}(\omega_k) - \Phi_{\mathrm{true}}(\omega_k)\right|^2 + \beta\cdot\mathrm{TV}(\Phi_{\mathrm{retrieved}})$$
其中 $\beta$ 为全变差正则化系数（典型值 0.01），抑制高频噪声。

推理速度：< 50 ms/pulse（单张 GPU，如 NVIDIA A100），满足在线运行需求。

### 触发条件与验证

触发条件：角积分方案在特定靶材上压制效率低于预期（偶极相位残余贡献 > 5%）。

验证方式：在相同实验数据上对比 CNN 与 M4 的重构结果，确认 CNN 的 $\delta\phi_{\mathrm{RMS}}$ 不劣于 M4（允许 10% 的性能差距，以换取方法稳健性）。

### 局限性

sim-to-real 差距是主要风险：仿真训练数据中的噪声模型可能不完全匹配实际实验条件。风险缓解：采用物理启发的损失函数（加入先验约束，如脉冲相位平滑性、光谱支持约束），减少对仿真数据分布的依赖；在真实数据上做微调（fine-tuning），逐步缩小领域差距。

## M6：双变量误差依赖图谱标定

### 实验设计

以光子能量区间（$E_{\mathrm{ph}}$）与通道重叠度（$R_{\mathrm{ch}}$，以多通道贡献占总截面的百分比表征）为自变量，以修正算法的重构误差 $\epsilon$（修正算法与传统 FROG-CRAB 的结果偏差）为因变量。

三能区 × 两种靶材配置（共 6 组独立测量）：

| 能区 | 光子能量范围 | 靶材 | 多通道贡献 $R_{\mathrm{ch}}$ | 预期修正效果 |
|------|------------|------|---------------------------|-------------|
| 极紫外 | 50–150 eV | Ne（单通道）、Ar | < 5% | 修正项自动退化为零（基准验证） |
| 水窗 | 284–400 eV | N₂、CH₄ | 15%–30% | 修正项显著有效（核心验证区） |
| 软 X 射线 | 400–543 eV | Kr、Xe | > 30% | 预期接近或超出失效边界 |

### 算法步骤

1. **误差提取**：对每组测量，计算修正算法与标准 FROG-CRAB 的重构偏差 $\epsilon = |\Phi_{\mathrm{corr}} - \Phi_{\mathrm{std}}|_{\mathrm{RMS}}$。

2. **二维插值**：在 $(E_{\mathrm{ph}}, R_{\mathrm{ch}})$ 参数空间（极紫外/水窗/软X射线 × < 5%/15%–30%/> 30%）做双线性插值，构建 50×50 的误差网格。

3. **等高线绘制**：以 $\epsilon = 5\%$ 为合格线阈值，绘制等高线图，标注修正模块的适用区间与失效边界。

4. **边界方程拟合**：对 < 5% 合格区间边界做曲线拟合，给出解析边界方程 $R_{\mathrm{ch}}^{\mathrm{max}}(E_{\mathrm{ph}})$，用于预测新能区的适用性。

### 关键参数表

| 参数 | 取值 | 说明 |
|------|------|------|
| 能量采样点 | 每能区 3 个（低/中/高能量各 1 个） | 覆盖能区跨度 |
| 通道重叠度分级 | 低（< 5%）、中（15%–30%）、高（> 30%） | 三级梯度 |
| 插值网格分辨率 | 50×50 | 50 个能量 × 50 个重叠度 |
| 误差阈值 | < 5%（合格）、> 10%（失效） | 边界判定标准 |
| 每组测量重复次数 | ≥ 5 次 | 统计误差评估 |

### 验证方式

- **单通道极限验证**：在极紫外能区（Ne、Ar），修正算法应自动退化为传统 FROG-CRAB，两者偏差 < 1%。若偏差显著 > 1%，说明修正项存在非物理的残余贡献。
- **误差对称性验证**：水窗能区 N₂ 和 CH₄ 应给出相近的 $\epsilon$ 值（相同 $R_{\mathrm{ch}}$ 区间），若偏差 > 5%，提示实验系统误差未被充分控制。
- **插值连续性验证**：6 个实测点的插值误差估计应 < 10%（通过留一交叉验证确定）。

### 失效边界与风险

当光电子动能 > 400 eV 或通道重叠度 > 50% 时，修正框架的近似假设不再成立。失效判据：$\epsilon > 10\%$ 且不随参数优化改善。此时将该参数区域界定为方法学失效边界，在图谱中以阴影区域标注，不再强求修正。

```
      ↓ 输出：角积分能谱 + 角分辨能谱
  M4: 二级解耦脉冲重构
      第一级：角积分 → 脉冲包络（η_dip < 2%）
      第二级：能动量分辨 → 偶极相位剥离（跨靶材误差 < 5%）
      第一级失效 → 触发备选路径 B（CNN）

阶段三（R3）——跨能区标定
  M6: 双变量误差依赖图谱
      极紫外（Ne/Ar）、水窗（N₂/CH₄）、软 X 射线（Kr/Xe）
      失效条件 → 触发备选路径 C（边界标注）
```

## 局限性汇总

| 方法 | 主要局限性 | 失效边界 | 风险缓解 |
|------|-----------|---------|---------|
| M1 TDSE 模拟 | 双通道近似在强耦合区失效 | 通道间能量差 < 0.5 eV | 参数扫描确认修正项适用性随能量差增大而单调恢复 |
| M2 解析修正项 | 依赖通道数 2–3 的参数化形式 | 通道重叠宽度 < 0.5 eV 或通道数 > 3 | 备选路径 A（神经网络） |
| M3 角积分测量 | 探测器各通道均匀性影响角积分准确性 | 通道响应不一致性 > 5% | 实验前后双标定，归一化修正 |
| M4 二级解耦 | 第一级若无法压制偶极相位则第二级整体失效 | 偶极相位残余贡献 > 5% | 备选路径 B（CNN） |
| M5 CNN 备选 | sim-to-real 差距，训练数据依赖 | 训练集与实验条件差异显著 | 物理启发损失函数 + 真实数据微调 |
| M6 误差图谱 | 标定实验周期长，参数空间覆盖有限 | 光电子动能 > 400 eV、通道重叠度 > 50% | 三能区并行安排；失效区域标注阴影而非外推 |
