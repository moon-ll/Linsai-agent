## 二、评审未指出但本轮独立核验发现的两处 critical 数值错误

这两项直接命中严谨性 0.75 的最弱环节，且均为跨章扩散型错误，须记录。

### 发现 A [critical] Up 系数错 10⁴ 倍，三档 Up 值全部虚高

**原状**：scheme §1 与 §3.1 写 `Up = 9.34×10⁻¹⁴·I·λ²`（I 取 W/cm²、λ 取 μm），据此给出 0.8 μm 端 0.006–0.12 eV、2.4 μm 端 0.054–1.08 eV、3.2 μm 端 0.096–1.91 eV。

**核验**：Up = e²E²/(4mω₀²)，配 I = cε₀E²/2、ω₀ = 2πc/λ，SI 直接推导得 Up(eV) = 9.337×10⁻¹⁸·I(W/cm²)·λ²(μm²)；与公开权威表述 Up[eV] = 9.33·I(10¹⁴ W/cm²)·λ²(μm²) 一致。原系数 9.34×10⁻¹⁴ 大 10⁴ 倍。

**影响**：全部 Up 值虚高 10⁴ 倍。更严重的是，若 Up 真为 0.006–1.91 eV，则 Eg + αUp 截止链中 Up 与带隙同量级、α 不可辨识；而按正确值 Up 为 10⁻⁷–10⁻⁴ eV，比带隙低三到四个数量级，α 才是可稳定拟合的标度自变量——即原数值使方案的核心标度律提炼失去可辨识性。

**处置**：§1 系数更正为 9.33×10⁻¹⁸，三档值全部更正为 6.0×10⁻⁷–1.2×10⁻⁵ / 5.4×10⁻⁶–1.1×10⁻⁴ / 9.6×10⁻⁶–1.9×10⁻⁴ eV，并补入定性结论「该区间低于四象限材料的带隙三到四个数量级，谐波发射以多光子带间激发与空穴回复为主」。§3.1 删去重复的 Up 计算链，改为按 §1 分档取值并承接「α 为稳定自变量」的论证。full_review 口径表 Up 行同步更新并注明公式与单位约定。00_research_idea 同步（原文件头注记录的是错误修复史）。

### 发现 B [critical] Landau-Zener 阈值错 10⁴ 倍

**原状**：scheme §3.4 写「按 I = n·E²/(2η₀)、n ≈ 1.74 计算，0.5 V/Å 对应约 5.8 TW/cm² 级峰值强度。本方案扫描上限 2 TW/cm² 约为其三分之一」。

**核验**：0.5 V/Å = 5×10⁹ V/m，代入 I = n·E²/(2η₀) = 1.74×(5×10⁹)²/(2×376.73) = 5.77×10¹⁶ W/cm² = **5.77×10⁴ TW/cm²**。5.8 TW/cm² 对应的场强实为 0.005 V/Å（5 mV/Å），与所写的 0.5 V/Å 差 100 倍。

**影响**：原表述把扫描上限说成「约为阈值的 1/3」，暗示扫描范围已接近 Landau-Zener 区；实际相差四个数量级，该结论方向性错误。

**处置**：更正为 5.8×10⁴ TW/cm²，并补入可复算的 Keldysh 判据 γ_K = √(I_p/2U_p)：取 MgO 有效电离能 I_p ≈ 10 eV，2 TW/cm²、3.2 μm 端（Up = 1.91×10⁻⁴ eV）对应 γ_K ≈ 160（程序复算 161.7）。据此把原「Zener 贡献受抑」的含糊表述改为「以多光子带间激发与空穴回复为主，Landau-Zener 直接隧穿在扫描范围内贡献可忽略」，并把方案动作从「把阈值推进到 1–2 TW/cm²」改为「在 γ_K ≫ 1 侧寻找 Zener 通道开始显现的 k 区域下限，作为标度律中隧穿贡献占比的外推边界」。full_review 口径表同步。

**旁证**：检索确认固态 HHG 实验确在 0.1–4.5 TW/cm² 运行（CdTe 4.5 TW/cm²、ZnO 1.2 TW/cm²、纳米锥 5 TW/cm²），故本项目的强度区间本身合理，需修正的是 Up 换算与 LZ 阈值两个派生量。
